第一步状态校准

在做任何判断之前，先问自己。如果任何一项不确定——先停。人在疲劳和情绪状态下做出的判断，噪声最大。

我现在是清醒的，还是被情绪推着走？
我上一次完整睡眠是几小时前？
如果24小时后重新做这个判断，答案会一样吗？

第二步五维快速自检

每个维度打分（1=完全没把握，5=非常稳固）

#维度校准问题1-5分
1时间轴"五年后，我会怎么看待今天的决定？"
2可行域"我的'够用就好'底线在哪里？"
3身心流"我的身体在告诉我什么？"
4信义观"钱和原则之间，他会怎么选？"
5直觉阈"关键时刻，我敢不敢信任自己的直觉？"
  • 任何维度 ≤ 2.0 → 🔴 立即停止。启动蓝军独立审计
  • 任何维度 ≤ 3.0 → 🟠 建立补偿机制（协议/退出条款/第三方）后再推进
  • 全部 ≥ 4.0 → 🟢 可推进。继续下面的检查

    • 第三步关系危机信号

    以下四个信号，诚实回答。Gottman 16年研究发现，这些信号预测关系破裂的准确率为91%。

    批评：我最近对他的评价，是从"这件事没做好"慢慢滑向了"他就是不行"吗？
    蔑视：我有没有在心里产生过"你看他那样"的想法？
    → 如果有，这是Gottman发现的头号关系破裂预测信号。不是"不喜欢"——是"看不起"。关系降级已经开始。
    防御：在最近的争议中，我有没有每次都找外部原因？
    冷漠：我们之间有没有一个话题，已经不聊了——因为聊也没用？

    第四步金字塔定位

    你们现在最脆弱的层级是哪一层？最脆弱的那一层——就是最需要修的地方。

    第1层·信任：你敢在合伙人面前承认自己不懂什么吗？
    第2层·冲突：上次你们为项目方向激烈辩论是什么时候？
    第3层·承诺：不吵就同意——是真的同意，还是放弃抵抗？
    第4层·问责：你敢跟合伙人说"你这次做得不够好"吗？
    第5层·结果：你们上次因为方向分歧各自为政是什么时候？

    第五步决策行动分级

    🔴 战略不可逆

    任何维度≤2.0 或 关系危机信号≥2个活跃 → 全流程审核 + 蓝军独立审计 + 不要今天做决定

    🟠 战略可逆

    任何维度≤3.0 或 金字塔第1-2层 → 24小时延时复核 + 和合伙人一起做这份清单

    🟡 运营不可逆

    整体3-4分但有一个维度偏低 → 聚焦最弱维度做深度对话

    🟢 运营可逆

    全部≥4.0 · 无活跃危机信号 · 金字塔第5层以上 → 标准流程可自主推进
