# 合伙人决策前自检清单 · 11源验证版

> 满意解研究所 · 硬科技转化的合伙人匹配决策教练
> 基于196本翻书·11个独立来源的交叉验证
> 打印此清单，在做任何重大合伙人决策前，花20分钟走一遍

---

第一步：状态校准（2分钟）

在做任何判断之前，先问自己：

我现在是清醒的，还是被情绪推着走？
我上一次完整睡眠是几小时前？
如果24小时后重新做这个判断，答案会一样吗？

> 如果任何一项不确定——先停。人在疲劳和情绪状态下做出的判断，噪声最大（Kahneman·2021）。

---

第二步：五维快速自检（5分钟）

每个维度，给自己打个分（1=完全没把握，5=非常稳固）：

| # | 维度 | 校准问题 | 1-5分 | 验证密度 |
|:--|:--|:--|:--:|:--|
| 1 | 时间轴 | "五年后，我会怎么看待今天的决定？" | | [9源验证] |
| 2 | 可行域 | "我的'够用就好'底线在哪里？" | | [10源验证] |
| 3 | 身心流 | "我的身体在告诉我什么？" | | [3源验证] |
| 4 | 信义观 | "看看这个人在钱和原则之间，会怎么选？" | | [9源验证] |
| 5 | 直觉阈 | "关键时刻，我敢不敢信任自己的直觉？" | | [5源验证] |

分数解读：
  • 任何维度 ≤ 2.0 → 🔴 立即停止推进。启动蓝军独立审计。
  • 任何维度 ≤ 3.0 → 🟠 建立补偿机制（协议/退出条款/第三方）后再推进。
  • 全部 ≥ 4.0 → 🟢 可推进。但继续下面的检查。

    > 每个维度旁的[验证密度] = 该维度被几个独立来源同时验证。数字越高，分数越可信。身心流是最弱的维度(仅3源)——在这个维度上的判断最容易出错。

    ---

    第三步：四骑士预警（3分钟）

    以下四个信号，诚实回答：

    批评: "我最近对他的评价，是从'这件事没做好'慢慢滑向了'他就是不行'吗？"
    蔑视: "我有没有在心里产生过'你看他那样'的想法？"
    → 如果有，这是Gottman发现的头号关系破裂预测信号（91%准确率）。不是"不喜欢"——是"看不起"。关系降级已经开始。
    防御: "在最近的争议中，我有没有每次都找外部原因——而不是承认我的那部分？"
    冷漠: "我们之间有没有一个话题，已经不聊了——因为聊也没用？"
    → 如果有，这是Lencioni金字塔第二层的"惧怕冲突"。不是关系好——是冲突转入地下。

    ---

    第四步：金字塔定位（2分钟）

    你们现在最脆弱的层级是哪一层？诚实回答：

    第1层·信任: "你敢在合伙人面前承认自己不懂什么吗？"
    第2层·冲突: "上次你们为项目方向激烈辩论是什么时候？"
    第3层·承诺: "不吵就同意——是真的同意，还是放弃抵抗？"
    第4层·问责: "你敢跟合伙人说'你这次做得不够好'吗？"
    第5层·结果: "你们上次因为方向分歧各自为政是什么时候？"

    > 最脆弱的那一层——就是你们现在最需要修的地方。底层不修，上层永远塌。

    ---

    第五步：决策行动分级（3分钟）

    根据以上结果，选择对应的行动：

    🔴 战略不可逆（任何维度≤2.0或四骑士≥2个活跃）
    → pre_delivery_gate全6步 + 蓝军独立审计 + 不要今天做决定

    🟠 战略可逆（任何维度≤3.0或金字塔第1-2层）
    → pre_delivery_gate步1-4 + 24小时延时复核 + 和合伙人一起做这份清单

    🟡 运营不可逆（整体3-4分但有一个维度偏低）
    → 聚焦最弱维度做深度对话 + 建立该维度的补偿机制

    🟢 运营可逆（全部≥4.0·四骑士无活跃·金字塔第5层以上）
    → 标准流程·可自主推进·但做好定期追踪

    ---

    第六步：延时复核（等待24小时）

    明天的这个时候，重新打开这份清单。
    如果任何一个答案变了——不是"昨天填错了"。是"昨天的状态影响了昨天的判断"（occasion noise·Kahneman）。
    变化的答案——就是你的噪声信号。关注它。

    ---
