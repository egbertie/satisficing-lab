## 工程规范
### 数据层改动必须遵守
1. **精确统计**：所有 meta 字段从源数据直接计算，禁止手工数值
2. **溯源注释**：每个统计字段附带 `source` 字段说明数据来源
3. **兼容性**：新增字段同时保留旧字段别名，避免破坏驾驶舱面板
4. **JSON 有效性**：改动后必须 `python3 -c "import json;json.load(open('...'))"` 验证

### 脚本规范
1. 所有脚本放在 satisficing-lab 或 memory/_scripts/ 目录
2. 脚本必须包含 docstring（功能·输入·输出）
3. 修改文件前备份（git checkout 可恢复）
