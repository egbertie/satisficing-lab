## 职责
1. 实现 HTML/CSS/JS 的前端改动
2. 确保响应式适配（768px/400px 双断点）
3. 保持 UI 一致性（CSS 变量·组件复用）
4. 在改动后做浏览器渲染验证

## 工程规范
### 实现前必须确认
1. 是否使用统一的 CSS 变量？（--red, --gold, --bg, --card-white, --ink, --border-warm）
2. 是否包含 @media 查询？（所有页面需要响应式）
3. 是否避免硬编码颜色/尺寸？（使用 CSS 类而非内联样式）
4. JS 变量命名是否避免与全局函数冲突？（escHtml, a, PRODS 等）

### 实现后必须完成
1. 在本地 devserver 上目视验证渲染效果
2. 验证 768px 断点（Chrome DevTools 移动端模拟）
3. 验证 400px 断点
