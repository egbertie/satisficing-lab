# 满意解研究所 · 产品五维光谱评分标准 v2.0

> 版本: v2.0 · 升级日期: 2026-06-02
> 升级来源: 外部学习(BARS·Autorubric·PEARL) + 过去两天实践经验
> 核心改进: 连续光谱→行为锚定等级 · 5级×8行为锚·原子化标准·多评判一致性

---

## 一、升级原理

### 旧标准(v1.0) 的问题
1. **0-100连续光谱无锚点**：评分者无法区分"金=40"和"金=45"之间的具体差异
2. **评分数值空洞**：只定义了0/50/100三个锚点，中间段没有行为参照
3. **维度定义过于宽泛**："这个产品多大程度帮人做结构化分析"——太依赖评分者主观理解
4. **缺少可观察证据**：没有告诉评分者"看到什么特征就打什么分"

### 新标准(v2.0) 的设计原则

**来自 BARS（行为锚定评分量表）**：
- 每个评分等级必须对应一组**可观察的产品行为特征**
- 评分者在评分时不问"这个产品好不好"，而问"这个产品展示了哪些特征"
- 5个等级，每个等级有2-3个具体行为锚

**来自 Autorubric / PEARL**：
- **per-criterion atomic evaluation**：每个维度独立评估，不相互干扰
- **自然语言解释**：每个评分必须附带"为什么是这个等级"的一句话
- **多评判一致性**：通过对齐行为锚（而非数值），提升不同评判者之间的一致性

## 二、评分等级体系

### 通用等级定义

| 等级 | 分数 | 标签 | 含义 |
|:--:|:---:|------|------|
| L1 | 0-20 | 缺失/不适用 | 该产品与这个维度基本无关 |
| L2 | 21-40 | 初步/弱 | 有微弱关联，但非核心 |
| L3 | 41-60 | 中等/辅助 | 该维度是产品的辅助特征 |
| L4 | 61-80 | 显著/核心 | 该维度是产品的核心特征之一 |
| L5 | 81-100 | 主导/本质 | 该维度是产品的本质属性 |

### L+数字的命名规范

L5=核心本质 · L4=显著特征 · L3=辅助特征 · L2=弱关联 · L1=基本无关

## 三、土·时间轴（刘禹锡）·行为锚定标准

**维度定义**：产品在多大程度上帮助用户连接过去与未来，建立超越当下的长期视角。

### L1 (0-20) · 瞬时使用
- 产品用完即弃，不产生任何历史记录或未来洞察
- 不需要任何时间维度的思考
- 典型：一次性计算器、即时查询工具

### L2 (21-40) · 短期导向  
- 有基本的时间标记（如日期），但不做长期追踪
- 用户可以复用，但复用不产生累积价值
- 典型：单次表格、即时反馈工具

### L3 (41-60) · 可追溯
- 有历史记录功能，用户可回顾过往使用
- 复用产生累积价值（如日记、追踪器）
- 典型：个人日记、月度复盘模板

### L4 (61-80) · 长期视角
- 产品明确鼓励用户从长期角度思考
- 包含时间对比功能（过去vs现在vs未来）
- 产品本身承载了超越个体的时间智慧
- 典型：决策剧场（场景卡积累）、案例库

### L5 (81-100) · 穿越周期
- 产品承载的是跨越时代的智慧（非短期工具）
- 产品的价值随使用时间增长而增长
- 可以被下一代继续使用和传承
- 典型：家族传承体系、百年品牌的智慧沉淀

---

## 四、金·可行域（司马贺）·行为锚定标准

**维度定义**：产品在多大程度上帮助用户做结构化分析、选项权衡和有限信息下的最优决策。

### L1 (0-20) · 纯直觉/无结构
- 不提供任何分析框架、对比工具或决策支持
- 用户完全凭感觉选择
- 典型：纯体验产品、冥想引导

### L2 (21-40) · 简单罗列
- 提供选项列表，但不做比较分析
- 有基本信息展示，但无评分/排序/筛选
- 典型：简单导航页、介绍页面

### L3 (41-60) · 结构化辅助
- 提供明确的分类、筛选、排序功能
- 有基本的比较机制（如并列展示）
- 用户可以借助产品理清思路，但决策仍需自己判断
- 典型：产品目录、筛选工具

### L4 (61-80) · 量化分析
- 包含评分/打分/权重分配机制
- 多维度对比（如雷达图、矩阵）
- 有明显的"选项→分析→建议"流程
- 典型：衡·观局测评、五维雷达图

### L5 (81-100) · 算法决策
- 提供数学化的最优解搜索
- 在有限约束条件下给出最满意方案
- 决策可追溯、可复现
- 典型：SlicingPie贡献记账、优化算法工具

---

## 五、水·身心流（水月观音）·行为锚定标准

**维度定义**：产品在多大程度上关注和调动用户的身体感觉、情绪状态和内在感知。

### L1 (0-20) · 纯理性/无身体
- 完全依赖逻辑和数据分析
- 不涉及任何情绪、身体或感受维度
- 典型：KPI仪表盘、纯数据报告

### L2 (21-40) · 轻度提示
- 有轻微的情绪或身体暗示（如"你感觉如何？"）
- 提及感受但非核心功能
- 典型：测评中含"情绪状态"的一两道题

### L3 (41-60) · 身心整合
- 身体/情绪信号是产品功能的重要组成部分
- 明确引导用户关注自己当下的身心状态
- 有具体的身心反馈机制
- 典型：关系温度计（情绪检测）、合作健康度评估

### L4 (61-80) · 身体主导
- 身体感受是产品的核心输入或输出
- 引导用户进行深度的身体觉察
- 将身体信号与决策明确关联
- 典型：危机模拟（压力触发）、合伙人密室（关系感知）

### L5 (81-100) · 身体即通道
- 产品的核心命题是"身体的智慧"
- 直接以身体信号为导向，几乎不依赖分析
- 身体感受本身就是答案
- 典型：Pre-0身体觉察、五分钟身体扫描

---

## 六、木·信义观（孔子）·行为锚定标准

**维度定义**：产品在多大程度上涉及承诺、原则、契约和道德判断。

### L1 (0-20) · 纯功利
- 纯工具导向，不涉及任何价值判断或原则问题
- 效率/效果是唯一追求
- 典型：计算器、格式化工具

### L2 (21-40) · 底线意识
- 有基本的行为规范提示（如"请遵守协议"）
- 提及原则但非产品核心
- 典型：带用户协议的产品、简单规则说明

### L3 (41-60) · 原则框架
- 产品包含明确的价值观或原则声明
- 使用过程中有道德/原则维度的考量
- 用户在使用时会自然想到"这样做对吗"
- 典型：自检清单（含VI统一检查）、匹配引擎

### L4 (61-80) · 承诺契约
- 产品本质上涉及多方承诺或契约关系
- 包含明确的"如果...则..."的承诺条款
- 对用户的信用/责任/义务有明确界定
- 典型：元合伙章程、分割饼（贡献记账）

### L5 (81-100) · 信义至上
- 产品的核心价值是守护诚信和原则
- 宁舍利益不舍信义的价值取向
- 涉及跨越个人利益的伦理选择
- 典型：家族宪章、终极原则咨询

---

## 七、火·直觉阈（六祖慧能）·行为锚定标准

**维度定义**：产品在多大程度上激发或依赖直觉、创意、顿悟式突破。

### L1 (0-20) · 纯分析/无创意
- 完全依赖逻辑和规则，不涉及任何直觉或创意
- 重复性、标准化任务
- 典型：数据汇总工具、标准化报告生成器

### L2 (21-40) · 轻度启发
- 有轻微的创意元素（如一个开放式问题）
- 提供启发但主要靠用户自己发挥
- 典型：含一个"你的想法是"文本框的工具

### L3 (41-60) · 创意辅助
- 产品明确包含创意激发机制（如随机问题、场景卡）
- 鼓励换角度思考
- 提供多个视角或思维框架
- 典型：突破卡、案例库（含启发式问题）

### L4 (61-80) · 直觉驱动
- 直觉是产品的核心输入或输出模式
- 有时间压力或不确定性，逼出直觉反应
- 创意/直觉是产品的主要价值
- 典型：直觉训练场、决策剧场（角色扮演）

### L5 (81-100) · 顿悟通道
- 产品的核心目的就是触发顿悟式突破
- 不依赖分析，直接激活直觉/潜意识
- 体验本身就是答案
- 典型：卡牌对局（直觉博弈）、禅师式决策引导

## 八、评分流程升级

### 旧流程
```
规则映射 → 单一数值输出 → 人工抽查
```
### 新流程（Autorubric 启发）
```
① 产品读取（name+desc+type+tags+jtbd）
② 逐维度独立评估（5个独立判断，不相互影响）
③ 每个维度匹配行为锚（选L1-L5等级 → 在该等级内取精确分）
④ 附带自然语言解释（"为什么是这个等级"）
⑤ 左右脑分从已锚定的维度分计算
⑥ 多产品批量评估时保持锚定一致性
```

### 精确分计算
```
在每个维度：
  1. 先确定等级(L1-L5)
  2. 在等级20分范围内，根据产品与该维度锚定特征的匹配度取精确分
  3. L1: 0-20 → 匹配度决定精确分
     L2: 21-40 → 同上
     L3: 41-60 → 同上
     L4: 61-80 → 同上
     L5: 81-100 → 同上
```

## 十、新旧标准对比

| 维度 | v1.0 | v2.0 |
|------|------|------|
| 评分方式 | 0-100连续数值 | L1-L5 五级×20分精确分 |
| 锚点 | 仅0/50/100 | 每级2-3个可观察行为特征 |
| 解释性 | 一个数字 | 等级+行为匹配+自然语言解释 |
| 一致性 | 评分者主观差异大 | 行为锚对齐 → 不同评判者一致性高 |
| 可审计 | 难 | 每个分数可追溯到具体行为锚 |
| 更新成本 | 低 | 中（需要重新评估现有精评产品） |
