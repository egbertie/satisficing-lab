## 一、测试金字塔（5层）

```
    📊 用户体验层 (UX)
    ┌─────────────────┐
    │ 视觉·可用·可读  │ ← 人工测试 + 浏览器实际渲染
    ├─────────────────┤
    │ 🧭 可访问性层    │ ← WCAG 2.2 AA check + 语义HTML
    ├─────────────────┤
    │ 📄 内容质量层    │ ← 品牌一致性·文案·文化标记·反馈组件

    │ 🔗 功能性层      │ ← 死链·JS语法·外部依赖·返回导航
    ├─────────────────┤

    └─────────────────┘
```

每层对应Lighthouse+站点测试的五个维度:
Performance → 结构完整性 + 功能性

UX → 用户体验

## 三、QAT 测试引擎（dev.sh verify 扩展版）

现有 `dev.sh verify` 覆盖 L1(结构)+L2(JS+死链)+L3(品牌)。现扩展为15项全量检查:

```bash
#!/bin/bash
# dev.sh verify — 满意解研究所 QAT 引擎
# 15项检查 · 对标 Lighthouse 5维

PASS=0
FAIL=0

echo "================================================"
echo "  满意解研究所 · 研发运维测试 QAT v2.0"
echo "  对标: Lighthouse + WCAG 2.2 + 静态站点最佳实践"
echo "================================================"

# === L1 · 结构完整性 (5项) ===
echo ""
echo "--- L1 · 结构完整性 ---"

# L1-01 DOCTYPE
check_l1_01() {
  local missing=$(find site/ -name "*.html" | xargs grep -L '<!DOCTYPE html>' | wc -l)
  if [ "$missing" -eq 0 ]; then echo "  ✅ L1-01 DOCTYPE声明: 全部存在"; ((PASS++))
  else echo "  ❌ L1-01 DOCTYPE声明: $missing 个文件缺失"; ((FAIL++)); fi
}

# L1-02 HTML标签闭合
check_l1_02() {
  local missing=$(find site/ -name "*.html" | while read f; do
    if ! grep -q '</html>' "$f" || ! grep -q '</body>' "$f"; then echo "$f"; fi
  done | wc -l)
  if [ "$missing" -eq 0 ]; then echo "  ✅ L1-02 HTML标签闭合: 全部配对"; ((PASS++))
  else echo "  ❌ L1-02 HTML标签闭合: $missing 个文件未闭合"; ((FAIL++)); fi
}

# L1-03~L5-05 同理...

check_l1_01
check_l1_02
# ... 其余13项

echo ""
echo "================ 验收: $PASS / 15 通过 ================"
if [ "$FAIL" -gt 0 ]; then
  echo "❌ $FAIL 项未通过"
  exit 1
else
  echo "✅ 全部通过"
fi
```
