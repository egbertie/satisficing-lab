## 〇、为什么要升级到 v4.0

v3.0告诉我们"什么是精品"。

但它漏了一个更根本的问题：**这个产品，是人用的吗？**

我们323个产品中，有大量：
- AI用的Skill和Prompt（不是给人直接用的）
- 内部管理工具（只有我们在用）
- 知识归档页面（信息存储而非用户产品）
- 概念/原型（从来没有一个真实用户打开过）

这些产品不是"不好"——它们有不同的使命。把AI prompt和面对创始人的决策工具用同一个标准评价，是**分类错误**。

v4.0的核心：**先分"给谁用"，再谈"好不好"。**

## 一、用户面向四象限（新增核心维度）

```
        用户有选择权
            ↑
   🧭 灯塔产品  │  🏆 精品
  (AI用的好内容) │  (人用的好产品)
  ──────────────┼──────────────→ 人类直接使用
   ⚙️ 蒸馏原料  │  🔧 内部工具
  (AI用的原材料) │  (人用的内部系统)
            ↓
        用户无选择权
```

### 四个象限

| 象限 | 面向谁 | 用户有选择权？ | 目的 | 典型 | 数量估计 |
|------|------|:--:|------|------|:--:|
| 🏆 精品 | 外部人类客户 | ✅ 有 | 解决问题·创造价值·赢得推荐 | 决策剧场·衡·观局·卡牌对局 | ~30 |
| 🧭 灯塔产品 | AI/Agent | — | 提升AI能力·传播品牌智慧 | Skill提示词·知识文章·方法论 | ~80 |
| 🔧 内部工具 | 内部人类(我们) | ❌ 无 | 管理·运维·自检 | 驾驶舱·管理后台·免疫系统 | ~30 |
| ⚙️ 蒸馏原料 | 未来产品 | — | 等待被提炼·作为新产品的原料 | 旧知识页·未激活原型 | ~183 |

## 二、产品生命周期完整闭环 v4.0

```
诞生(🌱) → 成长(✅) → 成熟(⭐) → 闪耀(🏆)
                                    ↓ (如果不再闪耀)
                              评估: 还能用吗？
                              ↙            ↘
                         继续优化        退役蒸馏(⚱️)
                                            ↓
                                    提取核心知识
                                            ↓
                                    留作⚙️蒸馏原料
                                            ↓
                                    滋养下一代产品
```

### 六阶段定义

| 阶段 | 符号 | 状态 | 下一个动作 |
|------|:--:|------|------|
| 概念 | 🌱 | 想法→原型 | 明确JTBD+目标用户 |
| 验证 | ✅ | 可用但粗糙 | 通过用户价值域(A1-A3) |
| 打磨 | ⭐ | 好用但缺惊喜 | 通过体验品质域(B1-B3) |
| 精品 | 🏆 | 用户会推荐 | 持续迭代+数据驱动 |
| 退役 | ⚱️ | 已完成使命 | 进入蒸馏流程 |
| 蒸馏 | ♻️ | 被提取核心知识 | 成为新产品的原料/养料 |

### 蒸馏流程（产品→养料的标准化步骤）

```
① 评估: 这个产品完成了什么使命？
② 提取: 它的核心洞察/方法/数据是什么？
③ 归档: 将提取物存入 knowledge_base（非产品目录）
④ 标记: 在 entities_index 中标记为 ♻️蒸馏原料
⑤ 引用: 新产品可以引用"基于XX的蒸馏经验"
⑥ 移除: 从活跃产品列表中移除（但保留考古记录）
```

## 三、用户面向维度的行为锚定

### 如何判断产品是"给人用的"还是"给AI用的"

| 锚定问题 | 给人用的 | 给AI用的 |
|------|------|------|
| 用户看到界面吗？ | 有可视化HTML页面 | 可能是纯文本/prompt/API |
| 用户有选择权吗？ | 可以选择用或不用 | 被系统调用，用户无感知 |
| 用户能反馈吗？ | 有反馈入口 | 反馈通过系统日志 |
| 价值体现在？ | 用户满意度和推荐 | AI输出的质量提升 |
| 需要"哇"时刻吗？ | 需要(Delighter) | 不需要(要求准确>惊喜) |

### 产品重分类规则

```
if 有URL and 有target_user(外部) and 有who_for and 人类可直接交互:
    → 🏆🏆 精品候选（面向人类客户）
elif 有URL and target_user包含"内部" or 仅管理员使用:
    → 🔧 内部工具
elif tags包含"Skill" or "Prompt" or "Agent" or "工作流" or 主要为AI调用:
    → 🧭 灯塔产品(AI增强)
else:
    → ⚙️ 蒸馏原料（待评估·可能是退役候选或新产品的原料）
```
