## 零、决策建议摘要（先读这里）

### 关于7大家族的建议：**废弃，用新的双光谱体系替代**

**理由**（独立第三方视角）：

1. **族与族之间无独有类型区分度**：跨家族 product_type 分析显示，8个族中只有「觉」有2个独有类型（infrastructure, simple_tool），其余6个族的类型全部被其他族共享。家族不是分类，只是标签堆叠。

2. **家族名语义不透明**：「章」「衡」「觉」「契」单字对用户毫无信息量。对比之下，「左脑63·右脑37·金78·火22」立刻传达产品本质。

3. **家族 = 伪分类**：112个「章」产品都是 knowledge_page + knowledge → 这不叫"家族"，叫"文件夹"。家族体系是产出物，不是设计物。

4. **认知负载违规**：用户需要同时记住 7个家族名 + 5个五维名 + 2个脑半球标签 → 14个维度。换成双光谱只需 2+5=7个维度，且语义自解释。

5. **数据诚实**：143/315个产品（45%）的 product_type 为空，67个状态为"资料·归入知识库"。大量产品并不具备"产品"资格。家族体系掩盖了这个问题。

**建议**：
- 废弃7大家族作为核心分类
- 保留 family 字段作为可选的考古标记（不做前台展示）
- 前台导航以左右脑象限 + 五维权重为组织逻辑
- 真正有区分度的维度是 JTBD 类别（diagnose/decide/grow/knowledge）+ 产品类型（diagnostic_tool/simulation_game/simple_tool/quantitative_tool/infrastructure）

## 一、双光谱评分体系定义

### 1.1 什么是双光谱

每个满意解产品拥有 **7个连续光谱评分**（0-100），构成该产品的**认知指纹**：

| 维度 | 符号 | 所属域 | 含义 |
|------|:----:|:------:|------|
| 左脑分 | L | 理性域 | 逻辑·分析·结构·量化的程度 |
| 右脑分 | R | 感性域 | 直觉·创意·情感·体验的程度 |
| 土·时间轴 | E | 时间域 | 长期视角·历史沉淀·复盘深度 |
| 金·可行域 | M | 实践域 | 资源权衡·选项分析·最满意解 |
| 水·身心流 | W | 感知域 | 身体觉察·压力信号·节奏感知 |
| 木·信义观 | Wo | 伦理域 | 承诺一致性·道德原则·契约精神 |
| 火·直觉阈 | F | 创意域 | 顿悟·灵感·突破·第一反应 |

**关键关系**：
- L = (M + E) / 2（金 + 土）
- R = (W + F) / 2（水 + 火）
- Wo（木·信义观）作为桥梁/平衡元素，不直接进入L或R
- 全脑平衡度 B = 1 - |L - R| / 100（0=极端偏侧，1=完美平衡）

### 1.2 左脑光谱锚点（0-100）

| 分数段 | 标签 | 特征 | 典型产品举例 |
|:------:|------|------|------|
| 0-20 | 🟣 极右脑 | 纯感性·纯直觉·无结构·无量化 | 冥想引导·身体觉察 |
| 21-40 | 🔵 偏右脑 | 感性主导·轻结构辅助 | 创始故事·品牌叙事 |
| 41-60 | 🟢 全脑平衡 | 左右脑均衡·理性与感性并重 | 决策剧场·星光方法论 |
| 61-80 | 🟠 偏左脑 | 理性主导·轻感性辅助 | 衡·观局测评·五维雷达图 |
| 81-100 | 🔴 极左脑 | 纯逻辑·纯数据·无情感·无叙事 | 数据面板·KPI仪表盘 |

### 1.3 五维光谱锚点

每个维度 0-100，定义如下：

#### 土·时间轴（刘禹锡）
- **0-20**：即时性产品，无历史视角，用完即弃
- **21-40**：短期导向，关注当下问题
- **41-60**：中长期视角，有复盘机制
- **61-80**：深度时间思维，历史类比+未来预判
- **81-100**：终极时间维度，穿越周期的智慧沉淀

#### 金·可行域（司马贺）
- **0-20**：无结构化分析，纯依靠直觉选择
- **21-40**：简单选项罗列，无系统权衡
- **41-60**：结构化决策框架，有选项评估
- **61-80**：多约束最优解搜索，资源边界清晰
- **81-100**：数学化决策，量化的满意解算法

#### 水·身心流（水月观音）
- **0-20**：纯理性·无身体感知
- **21-40**：轻度身心提示
- **41-60**：身心信号整合到决策流
- **61-80**：PRE-0深度自查，压力源定位
- **81-100**：身心合一，身体即决策仪表盘

#### 木·信义观（孔子）
- **0-20**：纯功利导向，不考虑道德维度
- **21-40**：基本合规，底线思维
- **41-60**：承诺一致性检查，原则框架
- **61-80**：多利益相关者伦理分析
- **81-100**：终极原则驱动，宁舍利益不舍信义

#### 火·直觉阈（六祖慧能）
- **0-20**：纯分析·零直觉
- **21-40**：偶尔灵感闪现
- **41-60**：直觉作为补充信号
- **61-80**：直觉作为核心驱动，经验模式匹配
- **81-100**：纯直觉·顿悟·无分析干扰

## 二、评分方法学

### 2.1 自动化初评规则

基于产品的现有字段，提供初步评分。核心映射：

#### product_type → 左右脑倾向

| product_type | 默认L | 默认R | 默认倾向 | 理由 |
|------|:--:|:--:|:--:|------|
| diagnostic_tool | 75 | 25 | 左脑 | 分析·诊断·量化评估 |
| quantitative_tool | 80 | 20 | 左脑 | 数据·KPI·模型 |
| infrastructure | 70 | 30 | 左脑 | 系统·架构·工程 |
| simulation_game | 30 | 70 | 右脑 | 角色扮演·场景·体验 |
| simple_tool | 50 | 50 | 平衡 | 轻工具·简约 |
| knowledge_page | 40 | 60 | 偏右脑 | 叙事·故事·文化 |
| (空) | 50 | 50 | 平衡 | 默认中性 |

#### jtbd_category → 五维倾向

| jtbd_category | 土 | 金 | 水 | 木 | 火 |
|------|:--:|:--:|:--:|:--:|:--:|
| diagnose | 40 | 75 | 50 | 30 | 40 |
| decide | 60 | 85 | 40 | 70 | 50 |
| grow | 70 | 40 | 50 | 60 | 65 |
| knowledge | 80 | 30 | 30 | 50 | 35 |

#### tags 加权调整

每条 tag 在五维上有微调方向：

| tag 关键词 | 调整方向 |
|------|------|
| 测评/诊断/分析/数据/KPI/量化 | 金+10, 左脑+5 |
| 创意/设计/灵感/故事/叙事/体验 | 火+10, 右脑+5 |
| 身体/觉察/直觉/感受/PRE-0 | 水+10, 右脑+5 |
| 长期/历史/复盘/沉淀/传承/日历 | 土+10 |
| 承诺/原则/道德/合规/契约/责任 | 木+10 |
| 系统/架构/工程/自动化/基础设施 | 金+5, 土+5, 左脑+5 |
| 品牌/首页/导航/入口 | 火+5, 水+5, 右脑+5 |

### 2.2 AI认知推理精评

初评后用 LLM 为每个产品进行认知推理精评。方法：

1. 读取产品的 name + description + tags + product_type + jtbd_category
2. LLM 从5个切面逐一打分（每个维度1-100），并给出一条推理依据
3. 评分 Prompt 模板：

```
你是满意解研究所的产品评估师。请从以下五个维度对产品评分(0-100)：

产品名：{name}
描述：{description}
类型：{product_type}
用途：{jtbd_category}

评分维度：
【土·时间轴】这个产品多大程度帮人看得更长远？
【金·可行域】这个产品多大程度帮人做结构化分析和选择？
【水·身心流】这个产品多大程度关注身体信号和内在状态？
【木·信义观】这个产品多大程度涉及承诺、原则和道德判断？
【火·直觉阈】这个产品多大程度依赖或激发直觉和创意？

每个维度给分数(0-100)和一句话推理依据。
```

### 2.3 人工校准机制

- 精评中 **任何维度分差 >30** 的产品标记为 `需要人工校准`
- 校准由满意姐或指定评审者完成
- 校准结果写入 `calibrated_by` + `calibrated_at`
- 校准后的评分作为权威值覆盖 AI 初评

### 2.4 评分流程

```
① 自动化初评（基于规则） → ② AI认知推理精评 → ③ 差异检测 → ④ 人工校准（按需） → ⑤ 写入 entities_index
```

## 三、产品分类矩阵

### 3.1 四象限分类

将左脑分值(L)和右脑分值(R)投射到二维平面：

```
        R(右脑)高
        ↑
  Ⅱ·体验型  │  Ⅰ·全脑型
  (L<40,R>60)│  (L>50,R>50)
  ──────────┼──────────→ L(左脑)高
  Ⅲ·真空型  │  Ⅳ·分析型
  (L<40,R<40)│  (L>60,R<40)
```

- **Ⅰ·全脑型**：既理性又感性，旗舰产品区（如：决策剧场、星光方法论）
- **Ⅱ·体验型**：偏感性体验（如：Pre-0身体觉察、星月传奇、品牌叙事）
- **Ⅲ·真空型**：左右脑都不强，概念/原型/测试区（如：未激活原型、早期概念）
- **Ⅳ·分析型**：偏理性分析（如：衡·观局测评、五维雷达图、数据面板）

### 3.2 健康平衡指标

不是均分，而是：

| 指标 | 健康目标 | 说明 |
|------|:---:|------|
| 全脑型占比 | ≥25% | 旗舰产品应同时具备理性和感性 |
| 偏侧产品比(L:R) | 1:1 ± 0.2 | 左右脑产品数量大致均衡 |
| 真空型占比 | ≤15% | 概念保持少量但不过多 |
| 极左脑(>80)占比 | ≤20% | 纯工具不宜过多 |
| 极右脑(>80)占比 | ≤20% | 纯体验不宜过多 |
| 五维离散度 | 各维CV<0.5 | 五维不能全挤在一个值域 |

### 3.3 三地平线 × 左右脑

```
H3·种子(未来)
    ↑ 主要右脑驱动
H2·成长(明天)
    ↑ 左右脑并重
H1·核心(今天)
    ↑ 主要左脑驱动
```

每个产品按成熟度分配到地平线，在地平线内再按左右脑平衡检查。

## 四、现有7大家族的评估（独立第三方视角）

### 4.1 家族分析结论

| 家族 | 数量 | 实质 | 问题 |
|------|:--:|------|------|
| 章 | 112 | 知识归档夹 | 35.6%产品不是"产品"，是知识文件 |
| 衡 | 102 | 诊断工具集 | 全部是diagnose，家族=JTBD类别 |
| 觉 | 36 | 基础设施+工具 | 唯一有独有类型的族，但语义模糊 |
| 契 | 34 | 决策工具 | 与「人」高度重叠(都是quantitative_tool) |
| 人 | 14 | 入口+界面 | 最小族，无独立类型 |
| 镜 | 12 | 模拟体验 | 最独特的族(体验型产品)，但太小 |
| 道 | 2 | 品牌叙事 | 太迷你 |
| 未知 | 3 | 测试 | 应清理 |

### 4.2 关键发现

**跨家族无独立类型区分度**：
- 只有「觉」有独有类型（infrastructure=7, simple_tool=24）
- 其他6个族的 product_type 全部被其他族共享
- 「人」「契」完全共享同一 product_type 集合
- 「章」「道」完全共享同一 product_type 集合

**143个产品(45%)的 product_type 为空**：
- 说明大量产品没有经过系统分类
- 家族体系掩盖了这一数据质量问题

**67个产品状态为"资料·归入知识库"**：
- 这些不应该出现在活跃产品矩阵中
- 按家族混在「章」里，用户无法区分

### 4.3 建议：废弃，改用双光谱

**废弃7大家族**作为核心分类体系。理由：

1. **认知负载**：用户需记住 7+5+2=14个分类维度。双光谱只需 2+5=7个，且语义自解释。
2. **区分度不足**：家族之间无独立类型，家族内产品同质化严重（章=全部knowledge，衡=全部diagnose）。
3. **语义不透明**：「章衡觉契人道镜」非中文常用字，不查字典无法理解。
4. **掩盖数据质量**：45%空product_type、21%资料状态，在家族体系下被掩盖。
5. **更好的替代方案**：JTBD(4类) × product_type(7类) 已经比7大家族更有信息量。

### 4.4 过渡方案

- `family` 字段保留在 entities_index 中作为**考古标记**（不废弃历史数据）
- 前台展示和导航全部切换为左右脑象限 + 五维权重
- 管理后台增加「家族考古」视图供查阅历史分类（降级到考古域）
- 新增 `spectrum` 对象承载双光谱数据

- 整体产品矩阵的五维均值雷达图

| 预警条件 | 级别 | 提示 |
|------|:--:|------|
| \|L-R均值\| >20 | 🟡 黄色 | 产品矩阵偏侧，关注平衡 |
| \|L-R均值\| >35 | 🟠 橙色 | 显著偏侧，需主动调整 |
| \|L-R均值\| >50 | 🔴 红色 | 严重失衡，P0行动 |
| 五维任一分<20的产品>20% | 🟡 黄色 | 某维度普遍薄弱 |
| 真空型产品>25% | 🟠 橙色 | 概念过多，落地不足 |

### 5.6 趋势追踪

- 每次双光谱重新评分后记录快照
- 展示 L均值/R均值/平衡度的 7日/30日趋势线
- 快照存入 `memory/_data/spectrum_snapshots/spectrum_YYYYMMDD.json`

## 八、附录：外部学习摘要

### HBDI 全脑模型关键洞察
- GE 大学开发，30年+百万级数据库验证
- 四象限非好坏之分，是偏好差异
- "全脑思维" = 根据情境灵活调用四个象限
- **对我们的启示**：产品也需要"全脑"——最成功的品牌(Nike/Tesla/Coca-Cola)都是左右脑平衡的

### 五行管理框架关键洞察
- 五行生克循环 ≈ 企业增长周期（初创→增长→规模化→优化→重塑）
- 木火土金水各代表组织的一种"能量模式"
- 失衡 = 某元素过剩或缺失
- **对我们的启示**：满意红五路图腾天然适配这一框架，土金水木火已形成完整闭环

### Double Diamond 关键洞察
- 发散(右脑)和收敛(左脑)交替出现
- 问题空间发散→收敛→解决方案空间发散→收敛
- **对我们的启示**：产品不应固定在一个脑半球——好产品在不同阶段需要不同思维模式

### McKinsey 三地平线关键洞察
- H1=今天（左脑重）、H2=明天（平衡）、H3=未来（右脑重）
- 健康组合 = H1:H2:H3 ≈ 60:30:10
- **对我们的启示**：满意红的产品在地平线上是否分布合理？这个也需要检查
