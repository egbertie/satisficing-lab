> 物理层的根基。没有这个，生物层就是空中楼阁。
> 对标: MDM (Master Data Management) + Dublin Core + Faceted Classification
> 目标: 全站信息可被精准查找、组合比对、自动流转

## 一、元数据标准（所有资产的统一描述语言）

对标 Dublin Core 15 核心元素，精简为满意解适用的 **12 个必填字段**：

| # | 字段 | 类型 | 必填 | 说明 | 示例 |
|---|------|------|:--:|------|------|
| 1 | `id` | string | ✅ | 全局唯一标识符 | `PROD-001`, `CUST-003`, `TASK-042` |
| 2 | `type` | enum | ✅ | 实体类型 | `product` / `customer` / `task` / `avatar` / `document` / `decision` / `milestone` / `term` / `event` / `script` / `cron` / `connection` |
| 3 | `name` | string | ✅ | 人类可读名称 | `决策剧场` |
| 4 | `description` | string | ✅ | 一句话描述（≤160字） | `五维决策场景模拟工具——角色扮演+场景卡+评分反馈` |
| 5 | `family` | enum | ⚠️ | 产品五族分类 | `镜` / `衡` / `契` / `觉` / `其他` |
| 6 | `status` | enum | ✅ | 当前状态 | `概念` / `原型` / `线上` / `精品` / `废弃` / `画像` / `待执行` / `进行中` / `已完成` |
| 7 | `tags` | array | ⚠️ | 多标签 | `["决策", "场景模拟", "角色扮演"]` |
| 8 | `url` | url | ⚠️ | 访问链接或文件路径 | `site/decision-theatre.html` |
| 9 | `created` | datetime | ⚠️ | 创建时间 | `2026-04-15T10:30:00+08:00` |
| 10 | `updated` | datetime | ⚠️ | 最后更新时间 | `2026-05-29T23:00:00+08:00` |
| 11 | `source` | string | ✅ | 数据来源出处 | `扣子通信·驾驶舱求助` / `飞书Base同步` / `文件系统扫描` / `手动录入` / `AI推断` |
| 12 | `confidence` | float | ✅ | 可信度 0-1 | `0.95` (高) / `0.5` (中等·需确认) / `0.2` (低·推断) |

## 二、核心实体定义

### 2.1 产品（Product）

```
扩展字段（继承标准12字段 +）：
  - maturity: 概念 | 原型 | 线上 | 精品 | 废弃
  - family: 镜 | 衡 | 契 | 觉 | 其他
  - size_kb: 文件大小
  - gate_protected: 是否需要密码
  - tier: L1公开 | L2产品体验 | L3内部管理
  - related_customers: [客户ID列表]
  - related_tasks: [任务ID列表]
  - related_avatars: [替身ID列表]
  - dependencies: [依赖的产品ID列表]
  - spec_standard: 规格标准化评分 (0-100)
```

### 2.2 客户（Customer）

```
扩展字段：
  - industry: 行业
  - stage: 画像 | 触达 | 试用 | 付费 | 流失
  - needs_level: 1-5 需求层次评分
  - key_questions: [核心追问列表]
  - related_products: [产品ID列表]
  - related_tasks: [任务ID列表]
  - last_contact: 最后互动时间
  - next_followup: 下次跟进时间
  - lifetime_value: 预估生命周期价值
```

### 2.3 任务（Task）

```
扩展字段：
  - priority: P0立即 | P1本周 | P2两周 | P3备用
  - assignee: 负责人
  - deadline: 截止日期
  - related_customer: 关联客户ID
  - related_product: 关联产品ID
  - related_avatar: 关联替身ID
  - dependencies: [依赖的任务ID列表]
  - blockers: [阻塞项描述]
  - log: [{timestamp, action, detail}] 变更日志
```

### 2.4 替身（Avatar）

```
扩展字段：
  - tier: L0图腾 | L1专家团 | L2产品Skills | L3独立审计 | L4评议会 | L5客户替身
  - element: 土 | 金 | 水 | 木 | 火 (L0专属)
  - dimension: 时间轴 | 可行域 | 身心流 | 信义观 | 直觉阈 (L0专属)
  - activation_count: 激活次数
  - contribution_score: 贡献值
  - last_activation: 最后激活时间
  - status: 活跃 | 休眠 | 待激活
```

### 2.5 知识资产（Document）

```
扩展字段：
  - category: 深度记忆 | 轻量记忆 | 创意火花 | 对话记录 | 系统配置 | 研究报告 | 外部学习
  - word_count: 字数
  - language: zh-CN | en
  - key_topics: [主题关键词列表]
  - related_entities: [关联的实体ID列表]
  - extract_quality: 0-1 提取质量评分
  - digest_status: 未消化 | 已提取 | 已索引 | 已连接
```

### 2.6 连接（Connection）

```
字段：
  - source_entity: 源实体ID
  - target_entity: 目标实体ID
  - relation_type: 关联 | 依赖 | 产出 | 引用 | 包含 | 替代
  - strength: 1-10 连接强度
  - discovered_by: 自动发现 | 手动标注
  - verified: 是否经过人工确认
```

## 三、分类体系（Faceted Taxonomy）

### 3.1 产品五族（核心分面）

```
镜 — 决策辅助工具 (decision-theatre, cards-play, knights, pre0, crisis-sim, match, ...)
衡 — 评估测评工具 (assessment, chemical-report, radar, checklist, thermometer, fulldiag, ...)
契 — 知识内容产品 (product-catalog, cases, creation, stars, roots, ...)
觉 — 系统运营工具 (dashboard, flywheel, exit-guide, workshop, wizard, guide, ...)
其他 — 基础支持页面 (index, about, go, gate, privacy, terms, symbols, ...)
```

### 3.2 成熟度分面

```
概念 → 仅有想法或Markdown文档
原型 → 有HTML初版但交互不完整
线上 → 可访问，基本功能可用
精品 → 完整交互流程 + VI统一 + 移动端适配 + 行动导向
废弃 → 不再维护，标记为历史资产
```

### 3.3 访问层级分面

```
L1 公开 — 无密码，任何访客可访问
L2 产品体验 — 无密码，但有使用次数/时间限制（未来）
L3 内部管理 — 需要密码(123654/12345678)
```

### 3.4 客户阶段分面

```
画像 → 内部构建的客户模型（替身文件）
触达 → 已发出首次联系
试用 → 正在使用免费/试用版产品
付费 → 已购买产品/套餐
流失 → 不再活跃
```

## 四、统一索引系统

### 4.1 全局ID命名规范

```
格式: {TYPE}-{SEQ:03d}

示例:
  PROD-001  决策剧场
  CUST-003  律所合伙人
  TASK-042  前端诊断工具包开发
  AVAT-005  六祖慧能（火·直觉阈）
  DOC-127   前端JS调试血泪教训_2026-05-29.md
  TERM-001  满意解
  DEC-007   术语变更: 观自在→水月观音
  MILE-003  夏至官宣日
  CRON-002  日起课(06:00)
  CONN-015  决策剧场→硬科技创始人 (产品→客户)
```

### 4.2 交叉引用矩阵

```
每个实体存储与其他实体的关联：

产品 PROD-001 (决策剧场):
  related_customers: [CUST-001, CUST-002]    ← 被哪些客户使用
  related_tasks: [TASK-003, TASK-007]        ← 关联哪些任务
  related_avatars: [AVAT-003, AVAT-005]      ← 哪些替身参与设计
  related_documents: [DOC-015]               ← 相关文档

客户 CUST-001 (硬科技创始人):
  related_products: [PROD-001, PROD-005]     ← 使用哪些产品
  related_tasks: [TASK-004, TASK-012]        ← 关联哪些任务
  related_avatars: [AVAT-001]                ← 用哪个替身建模

任务 TASK-007 (评分引擎缺陷修复):
  related_customer: CUST-003                 ← 为哪个客户
  related_product: PROD-008                  ← 涉及哪个产品
  related_avatar: AVAT-006                   ← 哪个替身在执行
  dependencies: [TASK-003]                   ← 依赖哪个任务先完成
  blockers: ["评分算法需要先重构"]             ← 阻塞项
```

## 五、数据字典索引

### 5.1 所有枚举值一览

```
状态 (status):
  概念 | 原型 | 线上 | 精品 | 废弃          — 产品
  画像 | 触达 | 试用 | 付费 | 流失          — 客户
  待执行 | 进行中 | 已完成 | 已取消 | 阻塞   — 任务
  活跃 | 休眠 | 待激活                      — 替身
  草稿 | 已发布 | 已归档 | 已废弃           — 文档
  未消化 | 已提取 | 已索引 | 已连接         — 知识资产

优先级 (priority):
  P0立即 | P1本周 | P2两周 | P3备用

五族 (family):
  镜 | 衡 | 契 | 觉 | 其他

层级 (tier):
  L0图腾 | L1专家团 | L2产品Skills | L3独立审计 | L4评议会 | L5客户替身

访问层级 (access_tier):
  L1公开 | L2产品体验 | L3内部管理

可信度 (confidence):
  1.0 硬事实 | 0.9 可靠文档提取 | 0.8 NLP自动提取 | 0.7 AI推断 | 0.5 可能过期 | 0.3 占位数据

连接类型 (relation_type):
  关联 | 依赖 | 产出 | 引用 | 包含 | 替代
```

## 六、查找协议

### 6.1 精准查找

```
按ID:     GET /entity/PROD-001
按类型:   GET /entities?type=product
按族:     GET /products?family=镜
按状态:   GET /tasks?status=待执行&priority=P0
按标签:   GET /entities?tags=决策
按关联:   GET /connections?source=PROD-001
```

### 6.2 复合查询

```
P0任务 + 关联客户 + 截止日期排序:
  tasks?priority=P0&sort=deadline&embed=customer

产品 + 成熟度 + 关联任务数:
  products?family=镜&maturity=精品&embed=tasks.count

客户 + 阶段 + 价值评分:
  customers?stage=画像&sort=lifetime_value

知识资产 + 消化状态 + 关联实体数:
  documents?digest_status=未消化&embed=connections.count
```

### 6.3 全文搜索

```
search?q=凌晨一点的创始人
  → 匹配: name, description, tags, key_topics
  → 返回: 按 relevance 排序的实体列表
  → 支持: 模糊匹配 + 中文分词
```
