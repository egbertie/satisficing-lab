# 五层流模型与范式转换 · 关键学习固化

> 2026-05-30 · 满意红 · 滚雪球Round 3

## 核心发现

### 范式转换：从连接到因果

| | 旧范式 (R1-R2) | 新范式 (R3) |
|------|------|------|
| 工作单元 | 新建连接(CONN-XXXXX) | 验证因果链(起点→过程→终点→证据) |
| 成功指标 | 连接↑密度↑覆盖率↑ | 验证链↑事件↑数据流完整性↑ |
| 组织方式 | 按实体类型 | 按流层(信号/认知/行动/验证/学习) |
| 替身评分 | 加权随机函数(83.0) | LLM认知推理(67.9) |

### 五层流模型

| 层 | 功能 | 关键发现 |
|:--:|------|------|
| **L1·信号** | 输入捕获 | 静态标签→动态事件·信号有了时间维度 |
| **L2·认知** | LLM推理 | 加权随机函数=量化假象·LLM推理低15分但更诚实 |
| **L3·行动** | 因果决策 | 认知→决策→产品改进·因果链首次形成 |
| **L4·验证** | 偏差分析 | 黑箱决策/量化假象/定位模糊/方法不接地气 |
| **L5·学习** | 规则进化 | 评分模型校准/场景适配/质量门禁更新 |

### 关键数据

- 5替身LLM评价 vs 加权随机: 平均差-15.1分
- 硬科技创始人评分: 89→57 (差-32!)  ← 最大偏差·"黑箱推演不可信"
- 首次验证: 1条完整五层因果链 (信号→认知→行动→验证→学习)

## 方法论固化

1. **加权随机不是认知**: 数学函数缺乏语义理解·LLM推理虽低分但更接近真实
2. **因果链 > 连接密度**: 12,463条声明连接不如果1条事件驱动的因果链
3. **替身评价的诚实区间**: 加权随机83为乐观上界·LLM推理68为保守下界·真实评分在两者之间
4. **五层流模型可复用**: 任何实体类型的知识闭环均适用此五层结构
