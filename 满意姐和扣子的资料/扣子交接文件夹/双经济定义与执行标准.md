## "双经济"定义

"双经济"包含三个维度（实际上是三个经济）：

### 1. Token经济学（成本控制）
**核心要求**：
- 本地KIA注入，零API调用
- 控制Token消耗
- 避免不必要的AI模型调用

**执行标准**：
- 🟢 最优：88份文件本地KIA注入，零API调用
- 🟡 可接受：在限额内使用
- 🔴 不可接受：超预算，浪费Token

---

### 2. 时间经济学（效率提升）
**核心要求**：
- 高效执行，批量处理
- 快速完成任务
- 避免返工

**执行标准**：
- 🟢 高效：10分钟批量处理，建立完整索引
- 🟡 可接受：在合理时间内完成
- 🔴 不可接受：拖延、返工、浪费时间

---

### 3. 效益经济学（价值产出）
**核心要求**：
- 高价值产出
- 与SKU/工具/专家全联动
- 使用时立即可寻

**执行标准**：
- 🟢 高价值：12类型与SKU/工具/专家全联动，使用时立即可寻
- 🟡 可接受：有价值但联动不足
- 🔴 不可接受：低价值，无法快速定位

---

## 双经济合规检查清单

### 每次任务执行前必须对照

| 维度 | 检查项 | 标准 |
|------|--------|------|
| **Token经济学** | 是否使用了API？ | 优先本地处理 |
| | Token消耗是否合理？ | 在限额内 |
| | 是否有零API调用方案？ | 优先选择 |
| **时间经济学** | 是否可以批量处理？ | 优先批量 |
| | 是否可以快速完成？ | 10分钟批量 |
| | 是否有返工风险？ | 一次性做对 |
| **效益经济学** | 产出是否有高价值？ | 与SKU/工具/专家联动 |
| | 使用时是否立即可寻？ | 建立索引 |
| | 是否有战略价值？ | 长期收益 |

## 违规后果

| 违规类型 | 后果 |
|----------|------|
| Token超预算 | 立即停止，优化方案 |
| 时间浪费 | 返工，影响绩效 |
| 低价值产出 | 重新评估任务价值 |
| 无双经济检查 | 任务报告不合格 |
