## 一、飞书生态全景图

### 1.1 飞书产品矩阵

飞书是一套完整的办公套件，各产品定位清晰、互相配合。

```
飞书生态全景
├── 即时通讯（IM）     ← 沟通层：消息、群聊、通知
├── 日历（Calendar）   ← 时间层：日程、会议、时间管理
├── 云文档（Docs）      ← 内容层：文档、Wiki、知识库
├── 多维表格（Bitable）  ← 数据层：数据库、自动化、仪表盘
├── 任务（Tasks）       ← 执行层：任务管理、项目追踪
├── 审批（Approval）    ← 流程层：审批、流程自动化
└── 视频会议/妙记       ← 协作层：会议、白板、妙记
```

### 1.2 各产品定位与配合

| 产品 | 核心定位 | 解决什么问题 | 与其他产品的配合 |
|:-----|:---------|:------------|:----------------|
| **即时通讯** | 沟通基础设施 | 随时找人、快速讨论 | 消息可关联日历/文档/任务 |
| **日历** | 时间管理 | 什么时间做什么 | 日程可转任务，会议可建文档 |
| **云文档** | 内容沉淀 | 积累知识、协作编辑 | 可内嵌多维表格、关联任务 |
| **多维表格** | 数据管理 | 结构化数据、自动化 | 可作为文档的数据源 |
| **任务** | 执行追踪 | 任务有没有在做 | 可从消息/日历/文档创建 |
| **审批** | 流程规范 | 规范化流程 | 可触发任务、日程通知 |

### 1.3 扣子与飞书的配合模式

```
扣子（决策/执行/协调）
      ↓
通过lark_cli操作飞书
      ↓
├── 创建/更新日历 → Egbertie看到日程安排
├── 写入多维表格 → Egbertie看到数据仪表盘
├── 创建任务 → Egbertie看到执行追踪
└── 发送消息 → Egbertie收到即时通知
```

## 二、飞书工作流设计

### 2.1 任务闭环工作流

```
任务创建（扣子 or Egbertie）
      ↓
进入多维表格（任务库）
      ↓
分配负责人 + 截止日期
      ↓
执行中（定期更新状态）
      ↓
完成 → 关闭任务 + 更新状态
      ↓
归档到文档（产出物）
```

**多维表格字段设计（推荐）：**
| 字段名 | 类型 | 说明 |
|:-------|:-----|:-----|
| 任务名称 | 文本 | 任务描述 |
| 负责人 | 人员 | 执行人 |
| 状态 | 单选 | 待办/进行中/已完成/阻塞 |
| 优先级 | 单选 | P0/P1/P2/P3 |
| 截止日期 | 日期 | 截止时间 |
| 创建时间 | 创建时间 | 自动填充 |
| 关联文档 | 文本 | 产出物链接 |
| 备注 | 文本 | 补充说明 |

---

### 2.2 会议工作流

```
发起会议（日历）
      ↓
确定时间 + 参与者 + 议程
      ↓
会议前：发送议程文档
      ↓
会议中：记录关键决议
      ↓
会议后：自动生成会议纪要（云文档）
      ↓
创建待办任务（任务）
      ↓
追踪执行
```

---

### 2.3 知识沉淀工作流

```
任务完成
      ↓
产出物归档（云文档）
      ↓
分类到知识库（Wiki）
      ↓
添加标签 + 摘要
      ↓
定期整理（多维表格管理）
      ↓
知识复用
```

---

### 2.4 扣子专用工作流

```
扣子接收任务
      ↓
判断：需要飞书操作？
      ↓
├── 需要日历 → lark_cli日历操作
├── 需要表格 → lark_cli多维表格操作
├── 需要文档 → lark_cli云文档操作
└── 需要通知 → 即时消息
      ↓
执行后更新MEMORY.md
```

## 三、飞书文档协作

### 3.1 文档类型选择

| 场景 | 推荐文档类型 | 说明 |
|:-----|:------------|:-----|
| 简单记录 | 传统文档 | 快速编辑、基础格式 |
| 结构化数据 | 多维表格 | 数据库、自动化 |
| 知识库 | Wiki | 分类、搜索、权限 |
| 流程规范 | 规范文档+审批 | 结合审批流 |
| 会议纪要 | 会议纪要模板 | 自动关联日历 |

---

### 3.2 权限管理

#### 权限层级

| 权限级别 | 可执行操作 | 适用场景 |
|:---------|:-----------|:---------|
| **只读** | 查看内容 | 外部协作、汇报 |
| **可评论** | 查看+评论 | 需要反馈的场景 |
| **可编辑** | 查看+编辑 | 核心协作成员 |
| **管理员** | 所有操作 | 文档所有者 |

#### 权限授予方式

1. **指定人员**：精确到个人的权限
2. **部门/群组**：批量授予同一部门
3. **链接权限**：通过链接分享（公开/仅组织内/仅受邀）

#### 最佳实践

| 原则 | 说明 |
|:-----|:-----|
| 最小权限 | 只给完成任务需要的最低权限 |
| 定期清理 | 人员变动后及时调整权限 |
| 区分内外 | 内部文档和外部文档权限分离 |
| 文档分级 | 按敏感度分级管理 |

---

### 3.3 版本控制

#### 版本功能

| 功能 | 说明 |
|:-----|:-----|
| 自动保存 | 实时保存，不丢数据 |
| 历史版本 | 查看任意历史版本 |
| 版本对比 | 比较两个版本的差异 |
| 恢复版本 | 一键恢复到任意历史版本 |

#### 版本管理建议

```
日常协作
      ↓
重大更新前创建「检查点」（复制一份）
      ↓
继续编辑
      ↓
如有需要可回退到检查点
      ↓
稳定后合并/归档
```

## 四、飞书多维表格

### 4.1 多维表格核心概念

| 概念 | 说明 |
|:-----|:-----|
| **数据表** | 类似Excel的一个Sheet |
| **字段** | 类似Excel的列 |
| **记录** | 类似Excel的行 |
| **视图** | 数据的不同展示形式 |

### 4.2 字段类型选择

| 字段类型 | 适用场景 | 示例 |
|:---------|:--------|:-----|
| **文本** | 简短内容 | 标题、备注 |
| **数字** | 数值数据 | 数量、金额 |
| **日期** | 日期选择 | 截止日期 |
| **人员** | 成员选择 | 负责人 |
| **单选/多选** | 选项分类 | 状态、优先级 |
| **复选框** | 是/否 | 是否完成 |
| **关联** | 关联其他表 | 关联任务表 |
| **公式** | 计算字段 | 自动计算 |
| **自动编号** | 唯一ID | 任务编号 |

---

### 4.3 自动化规则

#### 触发条件

| 触发类型 | 说明 |
|:---------|:-----|
| 当记录创建时 | 新增数据 |
| 当记录更新时 | 修改数据 |
| 当字段值变化时 | 特定字段变化 |
| 定时触发 | 每天/每周定时 |

#### 执行动作

| 动作 | 说明 |
|:-----|:-----|
| 创建记录 | 在本表或关联表创建 |
| 更新记录 | 修改字段值 |
| 发送消息 | 发送飞书消息 |
| 创建任务 | 创建待办任务 |
| 发送邮件 | 发送邮件通知 |

#### 自动化示例

**示例1：任务状态变更通知**
```
触发：当「状态」字段变为「已完成」
动作：发送消息通知创建者
```

**示例2：逾期提醒**
```
触发：当「截止日期」早于今天 AND 「状态」不是「已完成」
动作：发送消息提醒负责人
```

**示例3：数据汇总**
```
触发：每天早上9点
动作：统计昨日新增记录数，发送日报
```

### 4.4 仪表盘实战

#### 仪表盘组件

| 组件类型 | 用途 | 示例 |
|:---------|:-----|:-----|
| **统计卡片** | 显示关键指标 | 总任务数、完成率 |
| **柱状图** | 对比数据 | 各成员任务数 |
| **折线图** | 趋势变化 | 任务完成趋势 |
| **饼图** | 占比分布 | 任务状态分布 |
| **透视表** | 多维度汇总 | 按状态+负责人交叉统计 |

#### 仪表盘设计原则

```
明确目标 → 用户看这个仪表盘要知道什么？
      ↓
选择指标 → 关键指标不超过5个
      ↓
选择图表 → 对比用柱状图、趋势用折线图、占比用饼图
      ↓
布局优化 → 重要指标放左上角
      ↓
定期更新 → 确保数据实时
```

### 4.5 数据联动

#### 表间关联

```
主表：任务总表
├── 任务名称
├── 负责人（关联人员表）
├── 项目（关联项目表）
└── 状态

子表1：人员表
├── 姓名
├── 部门
└── 角色

子表2：项目表
├── 项目名称
├── 开始日期
└── 负责人
```

#### 关联查询

通过「关联」字段+「查找」字段实现跨表查询：

```
任务表.负责人.部门  → 可显示负责人所属部门
任务表.项目.开始日期  → 可显示关联项目的开始时间
```

| 类型 | 颜色建议 | 说明 |
|:-----|:---------|:-----|
| 外部会议 | 蓝色 | 外部人员参与 |
| 内部会议 | 绿色 | 团队内部 |

| 提醒 | 红色 | 重要截止 |

---

### 5.2 任务追踪最佳实践

#### 任务状态定义

| 状态 | 定义 | 说明 |
|:-----|:-----|:-----|
| **待办** | 还未开始 | 已规划但未执行 |
| **进行中** | 正在执行 | 已经开始处理 |
| **阻塞** | 有问题暂停 | 遇到障碍等待解决 |
| **已完成** | 全部完成 | 产出已交付 |

#### 优先级定义

| 优先级 | 定义 | 响应要求 |
|:-------|:-----|:---------|
| **P0** | 最高优先 | 立即处理，不拖延 |
| **P1** | 高优先 | 今日内完成 |
| **P2** | 中优先 | 本周内完成 |
| **P3** | 低优先 | 有空再做 |

## 六、飞书沟通技巧

### 6.1 群聊管理

#### 群类型选择

| 群类型 | 适用场景 | 管理重点 |
|:-------|:---------|:---------|
| **项目群** | 单一项目协作 | 聚焦主题、控制人数 |
| **部门群** | 部门内部沟通 | 定期清理、明确定位 |
| **专题群** | 特定话题讨论 | 有时限、完成后归档 |
| **全员群** | 公司通知 | 仅发通知、少互动 |

#### 群公告规范

```
位置：群设置 → 群公告
内容：
1. 本群定位（做什么的）
2. 成员规范（怎么用）
3. 相关链接（文档、表格）
4. 负责人联系方式
```

---

### 6.2 @规则

#### @使用场景

| 场景 | @方式 | 效果 |
|:-----|:------|:-----|
| 通知某人 | @姓名 | 发送通知 |
| 通知所有人 | @所有人 | 发送通知全员 |
| 请回复 | @姓名+具体问题 | 定向收集 |
| 紧急 | @姓名+[紧急] | 强调紧急 |

#### @注意事项

1. ❌ 不要滥用@所有人 → 降低重视度
2. ❌ 不要频繁@同一人 → 会造成打扰
3. ✅ 紧急事项才加[紧急]
4. ✅ @时说明需要对方做什么

---

### 6.3 消息优先级

#### 消息类型与响应

| 类型 | 示例 | 响应时效 | 方式 |
|:-----|:-----|:---------|:-----|
| **紧急** | 系统故障、截止提醒 | 5分钟内 | 立即回复+解决 |
| **重要** | 关键决策、项目阻塞 | 1小时内 | 尽快回复 |
| **常规** | 日常汇报、进度同步 | 当日内 | 正常回复 |
| **参考** | 信息分享、文档链接 | 不强制 | 有空再看 |

#### 消息格式规范

**汇报类：**
```
【日报-2024.01.15】
1. 完成：XXX
2. 进行中：XXX
3. 阻塞：XXX（原因+需要的支持）
4. 明日计划：XXX
```

**请求类：**
```
【请求】需要你确认XXX
选项：A / B / C
截止时间：今天18:00
```

**通知类：**
```
【通知】XXX已更新
变化：XXX
链接：xxx
请及时查看
```
