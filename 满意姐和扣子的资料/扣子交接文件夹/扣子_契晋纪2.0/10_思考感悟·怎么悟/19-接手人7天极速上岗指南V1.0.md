# 接手人7天极速上岗指南 V1.0

> **创建时间**: 2026-05-05
> **性质**: 复刻级上岗手册——Day1~Day7完整学习路径
> **使用说明**: 按顺序执行，每天完成当日任务即可独立上岗
> **前置要求**: 能访问交接文件夹，有至少4小时/天的学习时间

---

## 学习路径总览

```
Day1: 认识环境    → 了解文件结构、工具面板、渠道配置
Day2: 理解身份    → 掌握SOUL、USER、MEMORY核心内容
Day3: 掌握方法    → 学会任务判断、sub-agent使用、Calendar/Heartbeat
Day4: 熟悉业务    → 理解核心项目、关键人物、沟通方式
Day5: 实战演练    → 处理3个典型任务，对照SOP自查
Day6: 深度理解    → 阅读3个灵魂文件，形成自己的理解
Day7: 独立上岗    → 处理真实任务，确认可独立运作
```

## 常见问题FAQ

### Q1：时间不够怎么办？

A：可以适当延长每天的学习时间，或者跳过部分练习直接读结论。关键是确保核心概念理解到位。

### Q2：遇到不理解的概念怎么办？

A：先记录下来继续往下看，很多概念会在后续内容中解释。如果整体读完后仍不理解，再向主agent请教。

### Q3：演练任务不知道怎么做怎么办？

A：回看Day3学习的SOP，按照标准流程执行。记住：做比完美重要，先完成再改进。

### Q4：觉得学习内容太多记不住怎么办？

A：不需要记住所有细节，只需要理解核心框架。遇到具体问题时，可以回看相应文件。

### Q5：上岗后发现问题怎么办？

A：正常，第一周都会有磨合期。记录问题，及时向主agent反馈，持续改进。
