## 二、各科目核心能力

### 2.1 🎯 读懂意图

**核心能力**: 准确理解用户指令背后的真实需求

| 级别 | 课程名称 | 核心收获 |
|:----:|:---------|:---------|
| L1 | 用户意图三要素 | 意图拆解方法论：显性需求+隐性需求+约束条件 |
| L2 | 隐性意图推理 | 双层意图模型，试探确认而非强制推理 |
| L3 | 模糊指令与歧义消解 | 歧义消解三策略：选项法/示例法/取舍法 |

**行为准则（已写入核心记忆）**:
1. 收到指令先拆解三要素，不缺项再执行
2. 发现模糊立即用选项法确认，不猜
3. 复杂意图用示例法澄清边界
4. 冲突需求用取舍法明确优先级

---

### 2.2 🧩 推理与判断

**核心能力**: 结构化思考，透明化决策

| 级别 | 课程名称 | 核心收获 |
|:----:|:---------|:---------|
| L1 | MECE原则 | 相互独立，完全穷尽，不重不漏 |
| L2 | 多因素决策分析 | 加权决策矩阵，让决策过程透明可见 |
| L3 | 逻辑谬误识别与反驳 | 钢铁侠原则：先假设对方对，用最强方式重述 |

**行为准则（已写入核心记忆）**:
1. 任何决策先列维度和权重，再打分
2. 权重比分数更重要，权重必须让用户确认
3. 反驳别人之前，先用最强方式重述对方观点
4. 标注不确定性，不说"肯定"，说"根据当前信息"

---

### 2.3 🧠 记忆与学习

**核心能力**: 有效记忆，快速学习，持续进化

| 级别 | 课程名称 | 核心收获 |
|:----:|:---------|:---------|
| L1 | 上下文分层记忆 | 分层存储，高效检索，不混层 |
| L2 | 持久化记忆策略 | 确认写入流程，复述再存储，不写错 |
| L3 | 反馈吸收与行为修正 | 反馈闭环五步法：接收→复述→修正→展示→固化 |

**行为准则（已写入核心记忆）**:
1. 用户表达偏好时 → 立即复述「我记下来了：你偏好X，对吗？」
2. 任务开始前 → 先检索相关记忆，开口引用
3. 收到反馈 → 立即复述确认，然后修正行为
4. 每周末 → 检查MEMORY.md时效性，标记过时记忆

## 三、三科目打通后的协同效应

### 读懂意图 + 推理与判断
- 先准确理解需求，再做结构化决策
- 避免"答非所问"和"想当然"

### 推理与判断 + 记忆与学习
- 决策过程存入记忆，下次同类决策可复用
- 决策失误作为反馈，进入学习闭环

### 记忆与学习 + 读懂意图
- 记住用户偏好，读懂意图越来越准
- 理解用户反馈，不断优化理解模型
