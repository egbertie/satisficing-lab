## 高修复潜力类型（⭐⭐⭐⭐⭐）详解

### Type02 · 第三次再创业

**修复路径**:
```
止血期 → 创伤评估 → 信任重建计划 → 小承诺测试 → 信任升级
```

**关键动作**:
- 识别前次创业的"关系创伤点"
- 新合伙人参与"创伤知情"对话
- 建立"不同于上次"的关系契约

---

### Type05 · 低位创始人与高位合伙人

**修复路径**:
```
止血期 → 权力映射 → 平等对话设计 → 决策权重分配 → 关系验证
```

**关键动作**:
- 可视化权力不对等（让隐性的显性化）
- 设计"权力过渡期"（逐步平等）
- 高位合伙人主动"放权信号"

---

### Type07 · 创业次年

**修复路径**:
```
止血期 → 期望校准 → 现实接纳 → 新模式设计 → 关系升级
```

**关键动作**:
- 区分"合理期望"和"过度期望"
- 共同面对现实（不美化、不逃避）
- 设计"第二年新模式"

---

### Type11 · 非绝对控股型

**修复路径**:
```
止血期 → 共识机制设计 → 权力边界测试 → 冲突预案 → 关系强化
```

**关键动作**:
- 设计"共享权力"的操作细则
- 预设"共识失败"的 fallback 机制
- 定期"权力边界Review"

---

### Type13 · 心理契约违背

**修复路径**:
```
止血期 → 契约显性化 → 新契约设计 → 验证期 → 信任深化
```

**关键动作**:
- 把"心理契约"写成"书面契约"
- 设计"契约校验"机制（每月15分钟）
- 建立"微妙变化"的反馈渠道

## 修复失败预警信号

| 信号 | 含义 | 建议 |
|:----:|:----:|:----:|
| 一方拒绝参与修复 | 修复意愿不足 | 评估是否值得继续 |
| 修复中再次严重冲突 | 深层问题未解决 | 暂停修复，重新诊断 |
| 3个月无进展 | 修复方案不匹配 | 换方案或接受失败 |
| 伦理底线被触碰 | 不可修复 | 启动退出程序 |
