## 启动流程

### 内部发现创伤

```
创伤评估等级≥3
     │
     ▼
【第一步】内部通知HR/合伙人
     │
     ▼
【第二步】联系合作机构（1-3天内）
     │
     ▼
【第三步】安排首次咨询（1周内）
     │
     ▼
【第四步】跟踪进展（每2周）
     │
     ▼
【第五步】复测创伤等级（每月）
```

### 员工自行求助

```
员工表达心理困扰
     │
     ▼
【第一步】提供合作机构清单
     │
     ▼
【第二步】协助预约（如需要）
     │
     ▼
【第三步】保障隐私（不追踪具体内容）
     │
     ▼
【第四步】提供时间支持（咨询假）
```

---

## 隐私保护

| 原则 | 说明 |
|:----:|:----:|
| **自愿** | 员工/合伙人自愿求助，不强迫 |
| **保密** | 咨询内容不汇报给公司 |
| **匿名** | 可以使用匿名或化名 |
| **无报复** | 求助不影响绩效评估 |
