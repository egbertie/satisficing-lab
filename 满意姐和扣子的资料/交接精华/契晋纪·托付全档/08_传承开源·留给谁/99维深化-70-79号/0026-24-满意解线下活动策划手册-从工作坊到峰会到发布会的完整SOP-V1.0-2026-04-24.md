## 二、五维体验工作坊（月度）

### 活动定位

> "不是'听课'，是'体验'。
> 2小时，让参与者感受到五维框架的力量。
> 带走的不只是知识，是'啊哈'时刻。"

### 活动流程

```
18:30-19:00  签到 + 五维卡牌体验
              （入场时抽一张卡牌，作为今天的"决策图腾"）

19:00-19:10  开场：Egbertie的故事
              （10分钟，真实、脆弱、有温度）

19:10-19:40  模块1：五维框架体验
              （30分钟，讲解+互动）
              
19:40-20:10  模块2：合伙人匹配测评
              （30分钟，现场测评+解读）
              
20:10-20:20  茶歇 + 交流
              （提供满意解 branded 茶点）
              
20:20-20:50  模块3：真实案例演练
              （30分钟，分组讨论）
              
20:50-21:00  总结 + 行动承诺
              （每人写一张"我的下一个决策"卡片）
              
21:00-21:30  自由交流 + 咨询预约
```

### 现场布置

```
入口区：
- 品牌背景板（拍照打卡）
- 五维图腾展示
- 决策卡牌展示

主场地：
- U型座位（促进互动）
- 每组配备：五维画布、便签纸、笔
- 投影：五维框架图

茶歇区：
- 满意解 branded 茶点
- 决策卡牌试玩区
- 咨询预约台

拍照区：
- "我和五维框架"打卡墙
- 道具：五维眼镜、五维扇子
```

## 四、活动执行清单

### 活动前4周

```
□ 确定活动主题和目标
□ 制定预算
□ 确定场地（3个备选）
□ 确定日期（避开节假日）
□ 设计活动海报
```

### 活动前3周

```
□ 开放报名（早鸟价）
□ 邀请嘉宾
□ 准备活动物料（卡牌、画布、 branded 物品）
□ 确认餐饮
□ 宣传启动（公众号/小红书/社群）
```

### 活动前1周

```
□ 报名截止
□ 发送参会指南（时间/地点/准备）
□ 确认嘉宾行程
□ 物料到位检查
□ 志愿者培训
```

### 活动前1天

```
□ 场地布置
□ 设备调试
□ 物料清点
□ 彩排（如有表演/颁奖）
□ 嘉宾接待安排
```

### 活动当天

```
□ 提前2小时到场
□ 最终检查
□ 志愿者就位
□ 签到台准备
□ 摄影师就位
```

### 活动后

```
□ 当天：发送感谢邮件
□ 第2天：发布活动回顾（公众号）
□ 第3天：发送照片/视频
□ 第7天：收集反馈问卷
□ 第14天：发布活动总结报告
```
