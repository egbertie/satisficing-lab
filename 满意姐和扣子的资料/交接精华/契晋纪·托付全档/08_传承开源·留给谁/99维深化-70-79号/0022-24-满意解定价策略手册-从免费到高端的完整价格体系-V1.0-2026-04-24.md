## 一、定价哲学

### 满意解定价原则

```
1. 价值导向：价格 = 感知价值，而非成本+利润
2. 锚定效应：用高价产品衬托中价产品的性价比
3. 心理定价：利用心理学原理影响购买决策
4. 动态调整：根据市场反馈迭代价格
5. 透明坦诚：不玩套路，明码标价
```

## 三、价格心理学

### 锚定策略

```
展示顺序：
1. 先看高级认证 ¥29,999
2. 再看中级认证 ¥9,999
3. 最后看初级认证 ¥2,999

效果：¥2,999 显得"超值"
```

### 对比策略

```
竞品对比：
- MBA课程：¥200,000+（时间2年）
- 高管教练：¥50,000+/月
- 满意解高级认证：¥29,999（3个月）

效果：突出性价比
```

### 分期策略

```
¥29,999 看起来贵？
→ 分期：¥10,000 × 3个月
→ 或：¥2,500 × 12个月

效果：降低心理门槛
```

### 稀缺策略

```
每期限量：
- "本期仅招收30人"
- "早鸟价仅剩10个名额"
- "本期导师仅带5名高级学员"

效果：促进快速决策
```

### 禁止行为

```
❌ 未经审批擅自打折

❌ 过度承诺（"保证通过"）
❌ 贬低竞品（"其他课程没用"）
```

## 六、定价迭代

### 数据驱动

```
监测指标：
- 转化率：浏览→购买
- 客单价：平均每个客户消费
- 复购率：再次购买比例
- 退款率：购买后退费比例
- NPS：价格满意度

分析维度：
- 不同价格点的转化差异
- 促销对销量的影响
- 价格敏感度分析
```

### A/B测试

```
测试1：¥2,999 vs ¥2,499
测试2：早鸟-20% vs 赠送卡牌
测试3：分期付款 vs 一次性付款
测试4：免费测评→付费 vs 付费→测评
```
