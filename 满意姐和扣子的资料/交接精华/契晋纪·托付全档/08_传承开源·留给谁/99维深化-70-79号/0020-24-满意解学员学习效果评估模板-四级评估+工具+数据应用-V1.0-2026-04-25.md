## 第一部分：评估框架

### 1.1 四级评估

```
【Level 1：反应评估】（学员感受）
├─ 评估时机：课程结束时
├─ 评估方式：问卷
├─ 评估内容：
│   ├─ 课程满意度
│   ├─ 讲师评价
│   ├─ 内容评价
│   ├─ 形式评价
│   └─ 推荐意愿
├─ 目标：满意度>90%
└─ 工具：问卷

【Level 2：学习评估】（知识掌握）
├─ 评估时机：课程中/结束后
├─ 评估方式：测试
├─ 评估内容：
│   ├─ 概念理解
│   ├─ 方法掌握
│   ├─ 工具使用
│   └─ 案例分析
├─ 目标：通过率>80%
└─ 工具：在线测试

【Level 3：行为评估】（行为改变）
├─ 评估时机：课程后1-3个月
├─ 评估方式：观察/问卷/访谈
├─ 评估内容：
│   ├─ 是否使用所学方法
│   ├─ 决策方式是否改变
│   ├─ 合伙人沟通是否改善
│   └─ 冲突处理是否改善
├─ 目标：行为改变率>60%
└─ 工具：问卷+访谈

【Level 4：成果评估】（业务成果）
├─ 评估时机：课程后3-6个月
├─ 评估方式：数据追踪
├─ 评估内容：
│   ├─ 合伙人关系改善度
│   ├─ 决策质量提升
│   ├─ 冲突减少
│   ├─ 团队稳定性
│   └─ 业务指标变化
├─ 目标：成果改善率>50%
└─ 工具：复测+访谈
```

## 第二部分：评估工具

### 2.1 前测后测

```
【前测】（课程前）
├─ 知识测试：基础概念
├─ 技能自评：1-5分
├─ 行为基线：当前做法
├─ 关系基线：合伙人关系评分
└─ 期望：学习期望

【后测】（课程后）
├─ 知识测试：概念掌握
├─ 技能自评：1-5分
├─ 行为改变：新做法
├─ 关系改善：合伙人关系评分
└─ 满意度：课程评价

【对比】
├─ 知识提升：后测-前测
├─ 技能提升：后测-前测
├─ 行为改变：新做法-基线
├─ 关系改善：后测-前测
└─ 学习效果：综合评估
```
