## 第一部分：品牌定位

### 1.1 个人定位

```
【一句话定位】
"Egbertie——专注合伙人决策的决策教练，
22年银行+创业经验，让每一对合伙人都能走到最后。"

【标签体系】

主标签（必须出现）：
├─ 合伙人决策教练
├─ 满意解研究所创始人
└─ 五维决策框架创始人

副标签（根据场景选择）：
├─ CBIIP认证商业直觉智能从业者
├─ CDAA数字资产分析师
├─ 22年双系统经验
├─ 硬科技转化合伙人匹配专家
├─ 儒商哲学实践者
└─ AI+人工双引擎决策倡导者

【人设画像】

外在：
├─ 形象：专业、稳重、有温度
├─ 着装：商务休闲，不浮夸
├─ 语言：简洁、有画面感、偶尔中二
└─ 姿态：不居高临下，像朋友

内在：
├─ 价值观：诚实、满意解、戒急戒躁
├─ 方法论：左脑风控+右脑直觉
├─ 信仰：五维决策、契·晋
└─ 故事：22年双系统、吹尽黄沙始到金

【禁忌】
├─ ❌ 不说"我是专家"（让人不舒服）
├─ ❌ 不说"这很简单"（不尊重问题）
├─ ❌ 不说"你应该..."（不替人决定）
├─ ❌ 不炫富、不夸大
├─ ❌ 不攻击竞品
└─ ❌ 不承诺"一定成功"

【口头禅】
├─ ✅ "满意解——足够好即可"
├─ ✅ "戒急戒躁，稳步前进"
├─ ✅ "合伙人不是找的，是遇的"
├─ ✅ "五维决策，让直觉有框架"
└─ ✅ "契·晋——信诺与进阶"
```

### 3.2 内容形式

```
【形式1：金句海报】
├─ 适用：小红书、朋友圈
├─ 尺寸：1:1或3:4

├─ 适用：公众号、知乎
├─ 结构：背景→问题→解决→成果
├─ 字数：1500-3000字
├─ 配图：3-5张
└─ 频率：每周1篇

【形式3：干货清单】
├─ 适用：小红书、知乎
├─ 结构：标题+清单+解释
├─ 字数：500-1000字
├─ 配图：信息图
└─ 频率：每周2篇

【形式4：短视频】
├─ 适用：抖音、视频号
├─ 时长：60-180秒
├─ 结构：钩子→内容→CTA
├─ 字幕：必须加
└─ 频率：每周1-2个

【形式5：直播】
├─ 适用：视频号、抖音
├─ 时长：1-2小时
├─ 形式：QA、案例解析、方法论
├─ 互动：实时回答
└─ 频率：每月1-2次
```

## 第四部分：互动策略

### 4.1 用户互动

```
【评论区】
├─ 必回：所有评论24小时内回复
├─ 风格：专业+温度
├─ 示例：
│   用户："合伙人总是不同意我怎么办？"
│   Egbertie："这很正常。关键不是'谁对谁错'，
│             是'决策权怎么分配'。
│             试试我们的决策权矩阵？→[链接]"
└─ 目标：每条评论都是一次信任建立

【私信】
├─ 回复时间：<2小时
├─ 风格：倾听→诊断→建议
├─ 流程：
│   1. 感谢信任
│   2. 简要分析
│   3. 提供价值（工具/文章/课程）
│   4. 邀请下一步（测评/咨询）
└─ 注意：不免费深度咨询，引导付费服务

【社群】
├─ 身份：群主+导师
├─ 风格：朋友式，不权威
├─ 活动：
│   ├─ 周一：方法论分享
│   ├─ 周三：案例讨论
│   ├─ 周五：QA时间
│   └─ 周日：轻松话题
└─ 目标：社群活跃度>30%

【1v1咨询】
├─ 场景：高意向用户、复杂问题
├─ 时长：30-60分钟
├─ 收费：500-2000元/次
├─ 流程：诊断→方案→工具→跟进
└─ 目标：转化率>30%
```

---

### 4.2 危机应对

```
【负面评论】
├─ 原则：不删评、不争吵、不回避
├─ 流程：
│   1. 感谢反馈
│   2. 承认问题（如有）
│   3. 解释原因
│   4. 提出改进
│   5. 邀请私聊
└─ 示例："感谢指出，这个问题我们确实在改进..."

【谣言/误解】
├─ 原则：快速澄清、有据可依
├─ 方式：官方声明、视频回应
├─ 渠道：全平台同步
└─ 注意：不攻击个人，只澄清事实

【竞争对手攻击】
├─ 原则：不回应、不贬低
├─ 方式：专注自身、提升服务
├─ 策略：用内容说话，用案例说话
└─ 注意：避免口水战
```

## 第五部分：数据监测

### 5.1 核心指标

```
【内容指标】
├─ 发布频率：每周X篇
├─ 阅读量/播放量
├─ 互动率（点赞+评论+分享/阅读）
├─ 粉丝增长：每月X人
└─ 内容满意度（NPS）

【转化指标】
├─ 引流：内容→官网/公众号
├─ 注册：内容→测评注册
├─ 付费：内容→课程购买
├─ 推荐：老用户→新用户
└─ ROI：内容投入/收入产出

【品牌指标】
├─ 搜索指数："Egbertie""满意解"
├─ 提及量：社交媒体提及
├─ 情感分析：正面/负面比例
└─ 品牌联想：用户想到的第一关键词
```
