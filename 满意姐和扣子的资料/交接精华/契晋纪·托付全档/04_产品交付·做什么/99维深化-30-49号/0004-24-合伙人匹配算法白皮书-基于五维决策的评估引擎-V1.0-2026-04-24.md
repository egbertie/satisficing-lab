## 一、算法概述

### 核心问题

> "如何选择合伙人？"
> 
> 传统方法：看简历、看背景、看资源。
> 满意解方法：五维同时考量 + 13类型冲突预防。

### 算法架构

```
输入: 合伙人A数据 + 合伙人B数据 + 场景参数
      ↓
五维评估引擎（5个独立评估器）
      ↓
冲突类型预测器（13类型分类器）
      ↓
匹配度计算器（综合评分）
      ↓
输出: 匹配报告（10页PDF）
```

### 维度1：土·伦理评估器

- 法律合规（是否有法律纠纷记录）

**算法**:
```python
def evaluate_ethics(partner_data):
    score = 0
    
    # 诚信历史 (40%)
    credit_score = partner_data.get('credit_history', 5)
    score += credit_score * 0.4
    
    # 价值观匹配 (40%)
    values_alignment = calculate_values_alignment(
```

```python
def evaluate_satisficing(partner_a, partner_b):
    score = 0
    
    # 能力互补 (50%)
    skill_matrix_a = partner_a.get('skills', [])
    skill_matrix_b = partner_b.get('skills', [])
    complementarity = calculate_complementarity(

    # 资源匹配 (30%)
    resource_match = calculate_resource_match(
        partner_a.get('resources', {}),
        partner_b.get('resources', {})
    )
    score += resource_match * 0.3
    
    # 目标一致 (20%)
    goal_alignment = calculate_goal_alignment(
        partner_a.get('goals', {}),
        partner_b.get('goals', {})
    )
    score += goal_alignment * 0.2
    
    return min(score, 10)
```

**技能矩阵示例**:
```
        技术  市场  运营  财务  管理
合伙人A:  9    3    4    2    5
合伙人B:  3    8    6    7    4

互补度 = 差值之和 / 最大值
        = (6+5+2+5+1) / 45 = 19/45 = 0.42
        → 42%互补（偏低）
```

## 三、冲突类型预测器

### 13类型分类器

```python
class ConflictTypeClassifier:
    TYPES = {
        1: "股权分配型",
        2: "决策权争夺型",
        3: "价值观分歧型",
        4: "资源投入不均型",
        5: "退出机制模糊型",
        6: "外部关系介入型",
        7: "能力互补失衡型",
        8: "信任危机型",
        9: "目标漂移型",
        10: "沟通模式冲突型",
        11: "压力应对差异型",
        12: "成长速度不匹配型",
        13: "文化融合困难型"
    }
    
    def predict(self, partner_a, partner_b):
        """
        基于五维评分和问卷数据，预测最可能的冲突类型
        """
        risks = {}
        
        # Type 1: 股权分配型
        if (partner_a.get('equity_expectation', 50) + 
            partner_b.get('equity_expectation', 50)) > 100:
            risks[1] = 0.8
        
        # Type 2: 决策权争夺型
        if (partner_a.get('decision_style') == 'autocratic' and
            partner_b.get('decision_style') == 'autocratic'):
            risks[2] = 0.9
        
        # Type 3: 价值观分歧型
        values_diff = calculate_values_difference(
            partner_a.get('values', {}),
            partner_b.get('values', {})
        )
        if values_diff > 0.5:
            risks[3] = values_diff
        
        # Type 5: 退出机制模糊型
        if not partner_a.get('exit_clause') or not partner_b.get('exit_clause'):
            risks[5] = 0.7
        
        # Type 8: 信任危机型
        if (partner_a.get('trust_score', 5) < 4 or 
            partner_b.get('trust_score', 5) < 4):
            risks[8] = 0.6
        
        return risks
```

## 四、匹配度计算器

### 综合评分算法

```python
def calculate_match_score(partner_a, partner_b):
    """
    计算合伙人匹配度
    返回: 综合评分(0-50) + 五维评分 + 冲突风险 + 建议
    """
    
    # 五维评分
    dimensions = {
        'ethics': evaluate_ethics(partner_a, partner_b),
        'satisficing': evaluate_satisficing(partner_a, partner_b),
        'insight': evaluate_insight(partner_a, partner_b),
        'trust': evaluate_trust(partner_a, partner_b),
        'intuition': evaluate_intuition(partner_a, partner_b)
    }
    
    # 综合评分（加权平均）
    weights = {
        'ethics': 0.25,      # 伦理最重要
        'satisficing': 0.25, # 满意解标准
        'insight': 0.20,     # 洞察能力
        'trust': 0.20,       # 信任基础
        'intuition': 0.10    # 直觉辅助
    }
    
    total_score = sum(
        dimensions[d] * weights[d] 
        for d in dimensions
    ) * 5  # 转换为50分制
    
    # 冲突风险
    conflict_risks = ConflictTypeClassifier().predict(partner_a, partner_b)
    
    # 建议生成
    recommendations = generate_recommendations(
        dimensions, 
        conflict_risks
    )
    
    return {
        'total_score': total_score,
        'dimensions': dimensions,
        'conflict_risks': conflict_risks,
        'recommendations': recommendations,
        'verdict': get_verdict(total_score, conflict_risks)
    }

def get_verdict(score, risks):
    if score >= 40 and not risks:
        return "强烈推荐合作"
    elif score >= 35 and max(risks.values(), default=0) < 0.5:
        return "建议合作，注意预防"
    elif score >= 30:
        return "谨慎合作，需要干预"
    else:
        return "不建议合作"
```
