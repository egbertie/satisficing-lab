## 一、协议前言

### 满意解合伙人协议

**本协议基于"满意解决策框架"设计**

> 我们相信：合伙不是寻找"完美的人"，是构建"满意的系统"。
> 本协议的目标不是"预防所有冲突"，是"在冲突发生时，有章可循"。

## 三、基于13类型的冲突预防条款

### Type 1: 股权分配型 — 股权与贡献条款

**条款3.1 股权分配**

```
3.1.1 初始股权比例
      合伙人A: __%（对应出资__万元）
      合伙人B: __%（对应出资__万元）

3.1.2 动态调整机制
      每12个月评估一次贡献值，按以下公式调整：
      新股权 = 初始股权 × 60% + 贡献值 × 40%
      
      贡献值评估维度（五维框架）：
      - 资金投入（金）
      - 时间投入（土）
      - 资源引入（水）
      - 风险承担（火）
      - 团队建设（木）

3.1.3 股权成熟机制（Vesting）
      股权分4年成熟，每年成熟25%。
      提前退出，未成熟股权公司按原价回购。
```

**Type 1 预防机制**: 股权不是静态的，是动态的。每12个月重新评估，确保"贡献"与"股权"匹配。

---

### Type 2: 决策权争夺型 — 决策权限条款

**条款3.2 决策权限**

```
3.2.1 决策域划分（ RACI 模型）
      
      | 决策类型 | 负责人(R) | 审批人(A) | 咨询人(C) | 知情人(I) |
      |:---------|:----------|:----------|:----------|:----------|
      | 战略方向 | 双方共同 | 董事会 | 顾问 | 全员 |
      | 产品路线 | CTO | CEO | 团队 | 全员 |
      | 市场策略 | CEO | 双方 | 团队 | 全员 |
      | 融资决策 | CEO | 双方 | 投资人 | 全员 |
      | 招聘决策 | 部门负责人 | CEO | HR | 团队 |
      | 薪酬调整 | HR | CEO | CTO | 团队 |

3.2.2 僵局解决机制
      如果双方对某一决策无法达成一致：
      Step 1: 48小时冷静期
      Step 2: 五维评估（用满意解框架评估）
      Step 3: 如果仍无法达成一致，提交顾问委员会裁决
      Step 4: 如果顾问委员会无法裁决，CEO有一票决定权（限1年1次）

3.2.3 否决权
      以下事项必须双方一致同意，任何一方有否决权：
      - 公司出售/合并
      - 重大资产处置（>¥100万）
      - 股权结构变更
      - 核心团队开除
```

**Type 2 预防机制**: 决策域清晰划分 + 僵局解决机制 + 否决权保护。

---

### Type 3: 价值观分歧型 — 价值观对齐条款

**条款3.3 价值观宪章**

```
3.3.1 核心价值观（双方签字确认）
      
      我们共同相信：
      1. ________________（如：客户第一）
      2. ________________（如：诚实透明）
      3. ________________（如：长期主义）
      4. ________________（如：团队优先）
      5. ________________（如：持续学习）

3.3.2 价值观冲突解决
      如果双方在某一决策上价值观冲突：
      Step 1: 明确各自价值观立场
      Step 2: 评估冲突程度（核心 vs 非核心）
      Step 3: 核心冲突：必须达成一致，否则不执行
      Step 4: 非核心冲突：CEO决定，但需说明价值观考量

3.3.3 价值观审查
      每6个月进行一次价值观对齐审查。
      如果发现核心价值观分歧>2项，启动分离程序。
```

**Type 3 预防机制**: 价值观书面化 + 冲突分级 + 定期审查。

### Type 4: 资源投入不均型 — 投入与补偿条款

**条款3.4 资源投入**

```
3.4.1 投入标准
      
      | 投入类型 | 合伙人A | 合伙人B |
      |:---------|:--------|:--------|
      | 工作时间 | __小时/周 | __小时/周 |
      | 资金投入 | __万/月 | __万/月 |
      | 资源引入 | __ | __ |
      | 其他投入 | __ | __ |

3.4.2 投入不足补偿
      如果一方投入低于约定标准的80%，视为"投入不足"。
      投入不足方需在30天内补足，或接受股权稀释。
      稀释比例 = (约定投入 - 实际投入) / 约定投入 × 20%

3.4.3 超额投入奖励
      如果一方投入超过约定标准的120%，视为"超额投入"。
      超额投入方可获得：
      - 期权奖励（具体数量由双方协商）
      - 或现金补偿（按市场价的50%）
```

**Type 4 预防机制**: 投入量化 + 不足惩罚 + 超额奖励。

### Type 5: 退出机制模糊型 — 退出与回购条款

**条款3.5 退出机制**

```
3.5.1 主动退出（Good Leaver）
      
      触发条件：
      - 个人健康原因
      - 家庭重大变故
      - 双方协商一致
      
      退出价格 = 最近一轮估值 × 股权比例 × 80%
      支付方式：12个月分期

3.5.2 被动退出（Bad Leaver）
      
      触发条件：
      - 严重违反价值观宪章
      - 重大失职（造成公司损失>¥50万）
      - 竞业行为
      
      退出价格 = 初始出资额（原价回购）
      未成熟股权：全部丧失

3.5.3 公司回购
      
      公司在以下情况下可回购合伙人股权：
      - 合伙人死亡/丧失行为能力
      - 合伙人被司法机关追究刑事责任
      
      回购价格 = 最近一轮估值 × 股权比例 × 50%

3.5.4 估值方法
      
      如无最近一轮融资，按以下方法估值：
      - 方法1：最近12个月收入 × 3倍
      - 方法2：净资产 × 1.5倍
      - 方法3：双方协商聘请第三方评估
```

**Type 5 预防机制**: 退出条件明确 + 价格公式清晰 + 估值方法预设。

---

### Type 6: 外部关系介入型 — 边界与保密条款

**条款3.6 外部关系**

```
3.6.1 家庭成员
      
      合伙人家庭成员不得：
      - 参与公司日常决策
      - 在公司任职（除非双方一致同意）
      - 接触公司核心机密

3.6.2 外部顾问
      
      引入外部顾问需双方同意。
      顾问费用>¥5万/年，需双方签字。

3.6.3 保密义务
      
      合伙人不得向外部（包括家庭成员）透露：
      - 公司财务数据
      - 核心技术/商业机密
      - 合伙人之间的分歧
      
      违反保密义务：视为Bad Leaver退出。
```

**Type 6 预防机制**: 家庭成员边界 + 顾问审批 + 保密义务。

### Type 7: 能力互补失衡型 — 能力发展与调整条款

**条款3.7 能力发展**

```
3.7.1 能力矩阵（每6个月更新）
      
      | 能力维度 | 合伙人A | 合伙人B | 目标 |
      |:---------|:--------|:--------|:-----|
      | 技术 | __ | __ | __ |
      | 市场 | __ | __ | __ |
      | 运营 | __ | __ | __ |
      | 财务 | __ | __ | __ |
      | 管理 | __ | __ | __ |

3.7.2 能力补足计划
      
      如果一方在某维度评分<5分，需在6个月内：
      - 自我提升（培训/学习）
      - 或引入外部资源（招聘/顾问）
      - 或调整分工（让更适合的人负责）

3.7.3 角色调整
      
      如果能力矩阵发生重大变化，可调整角色：
      - CEO ↔ CTO ↔ COO 轮换
      - 需双方一致同意
      - 过渡期：3个月
```

**Type 7 预防机制**: 能力量化 + 补足计划 + 角色弹性。

---

### Type 8: 信任危机型 — 信任修复与分离条款

**条款3.8 信任机制**

```
3.8.1 透明度要求
      
      双方必须每月共享：
      - 个人财务状况（重大变化）
      - 外部投资/兼职情况
      - 与竞品的接触

3.8.2 信任修复程序
      
      如果发生信任危机：
      Step 1: 72小时内面对面沟通
      Step 2: 双方各自陈述事实（不评判）
      Step 3: 明确修复承诺（具体行动+时间）
      Step 4: 30天后复查
      
      如果30天后信任评分仍<5分，启动分离程序。

3.8.3 信任评分
      
      每3个月进行一次信任评分（1-10分）。
      评分<5分：进入信任修复程序
      评分<3分：启动分离程序
```

**Type 8 预防机制**: 透明度 + 修复程序 + 量化评分。

```
      如果一方目标发生重大变化：
      - 需在30天内书面通知对方
      - 双方重新评估合作基础
      - 如果目标不可调和，启动分离程序
```

**条款3.10 沟通协议**

```
3.10.1 沟通频率
      
      - 每日：15分钟站会
      - 每周：2小时深度沟通
      - 每月：4小时战略复盘
      - 每季：1天 retreat

3.10.2 沟通规则
      
      - 不隔夜矛盾（当天解决）
      - 不通过第三方传话
      - 不公开争吵（私下解决）
      - 不翻旧账（聚焦当前问题）
```

**条款3.11 压力应对**

```
3.11.1 压力识别
      
      以下信号表示合伙人处于高压状态：
      - 连续工作>14天无休
      - 情绪异常（易怒/沉默）
      - 决策质量下降
      - 回避沟通

3.11.2 压力支持
      
      如果发现对方高压：
      - 主动分担工作
      - 建议休假（强制休假权）
      - 引入外部支持（教练/顾问）
```

```
3.12.2 成长不匹配处理

      - 调整角色/分工
```

## 四、五维决策附录

### 附录A：五维评估工具

**签约前，双方必须完成五维评估**：

| 维度 | 评估方法 | 通过标准 |
|:-----|:---------|:---------|
| 土（伦理） | 价值观问卷 | ≥7分 |
| 金（满意解） | 能力矩阵 | 互补度≥60% |
| 水（洞察） | 决策案例测试 | ≥7分 |
| 木（信任） | 信任历史调查 | ≥7分 |
| 火（直觉） | 直觉准确率测试 | ≥6分 |

**总分≥35分（满分50分），方可签约。**

## 五、协议修订与终止

### 条款5.1 协议修订

```
5.1.1 修订条件
      以下情况可修订协议：
      - 双方一致同意
      - 公司融资/估值发生重大变化
      - 合伙人结构发生重大变化

5.1.2 修订程序
      Step 1: 一方提出修订建议
      Step 2: 双方讨论（2周内）
      Step 3: 达成一致，签署修订协议
      Step 4: 如无法达成一致，维持原协议
```

### 条款5.2 协议终止

```
5.2.1 终止条件
      - 双方协商一致
      - 一方触发退出机制
      - 公司解散

5.2.2 终止后义务
      - 保密义务持续3年
      - 竞业限制1年（如有约定）
      - 知识产权归属（按出资比例）
```
