## 第一部分：合伙人匹配度测评

### 1.1 测评设计

```
【测评名称】PMM-合伙人匹配度测评（Partner Matching Measure）
【题量】25题
【时间】5分钟
【方式】在线自评+互评
【适用】寻找合伙人、评估现有合伙人关系

【维度结构】

维度1：互补性（5题）
Q1: 你们的专业背景是否互补？
├─ A: 完全互补（技术+市场）
├─ B: 部分互补
├─ C: 有一定重叠
├─ D: 高度重叠
└─ 权重：高

Q2: 你们的性格是否互补？
├─ A: 完全互补（内向+外向）
├─ B: 部分互补
├─ C: 相似
├─ D: 高度相似
└─ 权重：高

Q3: 你们的经验是否互补？
├─ A: 行业经验+创业经验
├─ B: 部分互补
├─ C: 有重叠
├─ D: 高度重叠
└─ 权重：中

Q4: 你们的资源是否互补？
├─ A: 资金+技术+人脉互补
├─ B: 部分互补
├─ C: 有一定重叠
├─ D: 高度重叠
└─ 权重：中

Q5: 你们的工作风格是否互补？
├─ A: 计划型+灵活型
├─ B: 部分互补
├─ C: 相似
├─ D: 高度相似
└─ 权重：中

维度2：价值观（5题）
Q6: 你们创业的核心动机是否一致？
Q7: 你们对"成功"的定义是否相近？
Q8: 你们对"底线"的理解是否一致？
Q9: 你们对"时间投入"的期望是否一致？
Q10: 你们对"退出"的看法是否一致？

维度3：沟通风格（5题）
Q11: 你们表达意见的方式？
Q12: 你们处理分歧的方式？
Q13: 你们给予反馈的频率？
Q14: 你们决策时的参与方式？
Q15: 你们非工作时间的交流频率？

维度4：能力评估（5题）
Q16: 你们的核心能力是否覆盖创业所需？
Q17: 你们的学习速度是否匹配？
Q18: 你们的执行力是否相当？
Q19: 你们的领导力是否互补？
Q20: 你们的抗压能力是否足够？

维度5：承诺度（5题）
Q21: 你们的时间投入是否一致？（全职/兼职）
Q22: 你们的资金投入是否成比例？
Q23: 你们的精力优先级是否一致？
Q24: 你们的长期承诺是否一致？
Q25: 你们的退出预案是否达成共识？

【评分标准】
A=4分，B=3分，C=2分，D=1分
匹配度 = Σ(维度得分 × 维度权重)

【结果解读】
90-100：高度匹配 → 理想合伙人，建议立即合作
80-89：良好匹配 → 有潜力，关注弱项
70-79：一般匹配 → 需要磨合，建议先试运行
60-69：较低匹配 → 风险较高，建议深入沟通
<60：不匹配 → 建议 reconsider
```

## 第二部分：决策风格测评

### 2.1 测评设计

```
【测评名称】DSM-决策风格测评（Decision Style Measure）
【题量】15题
【时间】3分钟
【方式】在线自评
【适用】了解个人决策偏好

【维度结构】

维度1：信息收集（3题）
Q1: 做重大决策前，你通常收集多少信息？
├─ A: 尽可能多（数据驱动）
├─ B: 适中（关键信息）
├─ C: 较少（直觉为主）
└─ D: 很少（立即决定）

Q2: 你更信任哪种信息？
├─ A: 数据和分析
├─ B: 专家意见
├─ C: 直觉和经验
├─ D: 他人推荐

Q3: 你多长时间更新一次决策依据？
├─ A: 持续更新
├─ B: 定期更新
├─ C: 偶尔更新
├─ D: 很少更新

维度2：分析方式（3题）
Q4: 你更擅长哪种分析？
Q5: 面对复杂问题，你的第一反应？
Q6: 你如何验证自己的分析？

维度3：风险偏好（3题）
Q7: 你愿意承担多大风险？
Q8: 面对不确定性，你的感受？
Q9: 你愿意为多大回报承担风险？

维度4：决策速度（3题）
Q10: 你通常多快做出重大决策？
Q11: 面对时间压力，你的表现？
Q12: 你愿意为决策等待多久？

维度5：执行风格（3题）
Q13: 决策后，你多快开始执行？
Q14: 执行中遇到困难，你的反应？
Q15: 你如何追踪决策结果？

【结果解读】
根据得分，分为4种决策风格：
├─ 分析型（A型）：数据驱动，谨慎，适合战略决策
├─ 直觉型（I型）：快速，靠感觉，适合机会决策
├─ 依赖型（D型）：寻求共识，适合团队决策
└─ 回避型（R型）：拖延，回避，需要改进

【团队应用】
├─ 了解团队决策风格分布
├─ 优化决策流程（分析型+直觉型互补）
├─ 避免决策盲区（回避型需要提醒）
└─ 提升决策效率
```

## 第三部分：压力应对测评

### 3.1 测评设计

```
【测评名称】PSM-压力应对测评（Pressure Style Measure）
【题量】12题
【时间】3分钟
【方式】在线自评
【适用】评估压力下的行为模式

【场景题】

场景1：公司现金流紧张，下月工资可能发不出
Q1: 你的第一反应？
├─ A: 立即想办法筹钱
├─ B: 与合伙人商量对策
├─ C: 焦虑但不知道该做什么
├─ D: 逃避，希望问题自己解决

场景2：合伙人提出与你完全不同的战略方向
Q2: 你的反应？
├─ A: 激烈争论，坚持己见
├─ B: 冷静讨论，寻求共识
├─ C: 内心不满但表面妥协
├─ D: 完全退让，放弃自己的观点

场景3：连续3个月业绩不达标，投资人施压
Q3: 你的状态？
├─ A: 更加拼命工作
├─ B: 调整策略，寻求突破
├─ C: 焦虑失眠，影响决策
├─ D: 想放弃或逃避

【维度】
├─ 积极应对（A/B）：抗压能力强
├─ 消极应对（C/D）：需要提升抗压能力

【结果应用】
├─ 抗压能力强：适合高压岗位（CEO、销售）
├─ 抗压能力弱：需要配支持型合伙人
├─ 压力预警：抗压能力弱+高压环境=冲突风险
└─ 辅导建议：针对不同压力类型提供 coping 策略
```

## 第四部分：冲突模式测评

### 4.1 测评设计

```
【测评名称】CMM-冲突模式测评（Conflict Mode Measure）
【题量】10题
【时间】3分钟
【方式】在线自评+互评
【适用】了解冲突处理风格

【冲突风格类型】（基于Thomas-Kilmann模型）

类型1：竞争型（Competing）
├─ 特征：坚持己见，不顾他人感受
├─ 适用：紧急情况、原则性问题
├─ 风险：破坏关系
└─ 题例："在分歧中，我通常坚持自己的观点，即使对方反对"

类型2：协作型（Collaborating）
├─ 特征：寻求双赢，深入讨论
├─ 适用：重要决策、长期关系
├─ 风险：耗时较长
└─ 题例："我努力寻找让双方都满意的解决方案"

类型3：妥协型（Compromising）
├─ 特征：各让一步，快速解决
├─ 适用：时间紧迫、双方势均力敌
├─ 风险：双方都不满意
└─ 题例："我倾向于各退一步，快速达成协议"

类型4：回避型（Avoiding）
├─ 特征：回避冲突，不面对
├─ 适用：小事、情绪激动的场合
├─ 风险：问题积累
└─ 题例："我倾向于避免讨论可能引发冲突的话题"

类型5：迁就型（Accommodating）
├─ 特征：牺牲自己，满足他人
├─ 适用：维持关系、对方更专业
├─ 风险：自己利益受损
└─ 题例："我通常迁就对方的意见，避免冲突"

【测评题】
Q1-2: 竞争型
Q3-4: 协作型
Q5-6: 妥协型
Q7-8: 回避型
Q9-10: 迁就型

【结果解读】
├─ 最高分：主导冲突风格
├─ 次高分：备用冲突风格
├─ 团队组合：
│   ├─ 理想：1个协作型+1个妥协型
│   ├─ 危险：2个竞争型（权力斗争）
│   ├─ 危险：2个回避型（问题积累）
│   └─ 危险：2个迁就型（无人拍板）
└─ 改进建议：针对不同风格提供训练
```

## 第五部分：价值观排序测评

### 5.1 测评设计

```
【测评名称】VSM-价值观排序测评（Values Sorting Measure）
【题量】10题
【时间】2分钟
【方式**：在线排序
【适用**：了解核心价值优先级

【价值观清单】（10项）

V1: 财富积累（赚钱）
V2: 社会影响力（改变世界）
V3: 个人成长（学习进步）
V4: 工作生活平衡（有时间陪伴家人）
V5: 团队和谐（合伙人关系好）
V6: 创新突破（做新东西）
V7: 安全稳定（公司不倒闭）
V8: 独立自主（自己说了算）
V9: 认可尊重（被认可）
V10: 传承 legacy（留下点东西）

【测评方式】
排序题：将这10项按对你个人的重要性排序

【结果解读】
├─ Top 3：核心价值（不可妥协）
├─ 4-7：重要价值（可协商）
├─ 8-10：次要价值（可放弃）

【合伙人对比】
├─ 双方Top 3有重叠 → 价值观一致度高
├─ 双方Top 3完全无重叠 → 价值观冲突风险高
├─ 一方Top 3是另一方Bottom 3 → 高风险
└─ 建议：Top 3重叠至少2项

【应用】
├─ 招聘合伙人：筛选价值观匹配者
├─ 团队建设：理解彼此价值差异
├─ 冲突解决：回到价值观层面沟通
└─ 个人发展：明确核心价值，做重大决策时对照
```

## 第七部分：测评管理

### 7.1 测评实施流程

```
【Step 1：发起测评】
├─ 用户注册/登录
├─ 选择测评类型（个人/团队）
├─ 如果是团队：输入合伙人信息，邀请对方参与
└─ 系统自动发送测评链接

【Step 2：完成测评】
├─ 用户在线答题
├─ 系统自动保存进度（可中断继续）
├─ 答题完成后提交
└─ 系统计算结果

【Step 3：生成报告】
├─ 系统即时生成个人报告
├─ 如果是团队：生成对比报告（需双方都完成）
├─ 报告发送至用户邮箱
└─ 用户可在线查看/下载/分享

【Step 4：后续跟进】
├─ 系统自动推荐相关课程/工具
├─ 客服跟进（高潜力用户）
├─ 定期复测提醒（每季度）
└─ 数据归档（用于算法优化）
```

├─ 活跃用户：永久保留

└─ 用户可随时导出/删除自己的数据

> **核心原则**：
> 测评不是"审判"，是"镜子"。
>
> 不是给合伙人打分，
> 是帮助你们看见"看不见的问题"。
>
> 最好的测评结果：
> 不是"100分"，
> 是"看见了问题，知道怎么改进"。
>
> 满意解的测评信仰：
> "看清自己，理解对方，共同成长。"
