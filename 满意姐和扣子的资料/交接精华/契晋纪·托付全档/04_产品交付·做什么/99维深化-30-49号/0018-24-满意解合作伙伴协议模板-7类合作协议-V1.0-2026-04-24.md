## 通用条款框架（所有协议共用）

### 必备条款清单

```
每份协议必须包含：

【合作主体】
├─ 甲方（我方）：满意解研究所
├─ 乙方（合作方）：________
├─ 双方联系人及联系方式
└─ 协议签订日期

【合作内容】
├─ 合作目的
├─ 具体合作事项
├─ 双方权利与义务
└─ 合作期限

【费用与结算】
├─ 合作费用（如有）
├─ 结算方式（一次性/分期/按效果）
├─ 付款条件和时间
└─ 发票要求

【知识产权】
├─ 各自原有IP归属
├─ 合作产生的新IP归属
├─ 品牌使用授权范围
└─ 合作结束后IP处理

【保密义务】
├─ 保密信息定义
├─ 保密期限
├─ 保密例外（已公开/法律规定）
└─ 违约责任

【违约责任】
├─ 违约定义
├─ 违约通知和整改期
├─ 违约金或赔偿计算
└─ 严重违约的终止权

【协议终止】
├─ 正常终止（期满）
├─ 提前终止（需提前__天通知）
├─ 终止后义务（保密/交接）
└─ 争议解决方式

【争议解决】
├─ 协商解决（首选）
├─ 调解/仲裁（次选）
└─ 诉讼（最后手段）

【其他】
├─ 不可抗力
├─ 协议修改（书面）
├─ 完整协议（取代之前所有口头/书面约定）
└─ 签字盖章
```

```
【适用场景】
合作伙伴作为满意解的代理商/渠道方，
帮助推荐客户/销售课程/推广服务。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

协议编号：SAT-DA-____

甲方（委托方）：满意解研究所
地址：________
联系人：________

乙方（代理方）：________
地址：________
联系人：________

签订日期：____年__月__日

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

第一条 合作内容

1.1 代理范围
乙方作为甲方的[□独家代理 / □非独家代理]，
在[地域范围，如"华南地区"/"全国"/"线上"]内，
代理推广甲方的以下产品/服务：
□ 五维决策认证课程
□ 合伙人决策教练服务
□ 组织治理工具包
□ 企业内训服务
□ 其他：________

1.2 代理期限
自____年__月__日起至____年__月__日止。
期满前30天，双方可协商续签。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

第二条 代理费用与结算

2.1 佣金比例
乙方成功推荐客户并成交后，甲方支付乙方佣金：
├─ 认证课程：成交金额的___%
├─ 教练服务：成交金额的___%
├─ 企业内训：成交金额的___%
└─ 其他产品：成交金额的___%

2.2 结算方式
├─ 结算周期：月结/季度结
├─ 结算时间：每月__日/每季度末月__日
├─ 甲方在收到客户全款后__个工作日内支付佣金
└─ 支付方式：银行转账至乙方指定账户

2.3 最低业绩要求（可选）
□ 无最低业绩要求
□ 乙方承诺每[月/季度]最低推荐成交金额为____元
  未达标时：□ 降低佣金比例 / □ 取消代理资格 / □ 其他：____

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

第三条 双方权利与义务

3.1 甲方义务
├─ 提供产品/服务的详细资料和培训
├─ 提供销售话术和FAQ支持
├─ 按时支付佣金
└─ 保护乙方推荐的客户资源（不绕过乙方直接联系）

3.2 乙方义务
├─ 积极推广甲方产品/服务
├─ 不夸大宣传、不虚假承诺
├─ 及时反馈市场信息和客户需求
├─ 未经甲方书面同意，不得将代理权转授第三方
└─ 维护甲方品牌形象

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

第四条 客户归属与保护

4.1 客户归属
├─ 乙方推荐的客户，在首次成交后__个月内归乙方保护
├─ 保护期内，甲方不得绕过乙方直接联系该客户
└─ 保护期后，客户转为甲方直接客户，乙方不再享有佣金

4.2 客户信息保密
乙方对甲方提供的客户信息和销售数据保密，
不得用于非本协议目的。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

第五条 知识产权与品牌

5.1 品牌使用
├─ 乙方可在推广中使用甲方品牌名称和LOGO
├─ 使用方式必须符合甲方提供的品牌规范
└─ 协议终止后，乙方不得继续使用甲方品牌

5.2 宣传材料
├─ 甲方向乙方提供标准宣传材料
├─ 乙方如需自制宣传材料，需经甲方书面审核同意

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

第六条 违约责任

6.1 甲方违约
├─ 逾期支付佣金：每逾期1日，支付未付金额的0.05%作为违约金
└─ 绕过乙方联系客户：赔偿乙方该客户预期佣金的2倍

6.2 乙方违约
├─ 虚假承诺/夸大宣传：甲方有权终止协议，乙方退还已收佣金
├─ 泄露客户信息：赔偿实际损失，最低____元
└─ 未经同意转授代理权：甲方有权终止协议

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

第七条 协议终止

7.1 正常终止：协议期满，双方未续签

7.2 提前终止
├─ 任何一方提前__天书面通知对方
├─ 严重违约方被另一方立即终止
└─ 终止后，已完成交易的佣金仍应支付

7.3 终止后义务
├─ 乙方归还甲方所有资料
├─ 双方继续履行保密义务
└─ 已产生的佣金在__天内结清

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

第八条 争议解决

双方因本协议产生的争议，
先协商解决；协商不成，
提交[甲方所在地/乙方所在地/双方约定地]人民法院诉讼解决。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

第九条 其他

9.1 本协议一式两份，双方各执一份
9.2 本协议自双方签字盖章之日起生效
9.3 本协议的任何修改需书面形式并经双方签字确认

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

甲方（盖章）：________    乙方（盖章）：________
代表签字：________        代表签字：________
日期：____年__月__日      日期：____年__月__日
```

## 附录：协议使用流程

```
Step 1: 确定合作类型
→ 从7类模板中选择最接近的

Step 2: 填空
→ 填写双方信息、金额、期限等空白处
→ 标记不适用的条款（删除或标注"N/A"）

Step 3: 定制调整
→ 根据具体业务增加特殊条款
→ 调整费用结构和分成比例

Step 4: 法务审核（推荐）
→ 发给律师审核（1-2小时）
→ 根据律师意见修改

Step 5: 双方签署
→ 签字盖章
→ 各执一份
→ 扫描存档

总时间：
├─ 使用模板填空：30分钟
├─ 定制调整：1-2小时
├─ 律师审核：1-2小时
├─ 双方协商修改：1-3天
└─ 签署：1天
总计：3-5天
（vs 从零起草：2-4周）
```

---

> **核心原则**：
> 协议不是"不信任对方"，是"保护双方"。
> 
> 好的协议让合作更顺畅，
> 因为每个人都知道边界在哪里、规则是什么。
> 
> 没有协议的合作，
> 就像没有交通规则的城市——
> 大家都能走，但迟早会撞。
>
> **契 · 晋。**
