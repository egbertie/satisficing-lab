## 一、OKR框架

### 什么是OKR？

> **O**bjective（目标）：
> 你想要达成什么？
> 有挑战性、定性、鼓舞人心
>
> **K**ey **R**esult（关键结果）：
> 怎么知道达成了？
> 可衡量、定量、有时限

### 满意解OKR示例

```
年度OKR（2026）

O1: 成为合伙人决策领域的首选品牌
  KR1: 年营收达到¥1,000,000
  KR2: 付费学员达到334人
  KR3: NPS达到50+
  KR4: 媒体报道达到50篇

O2: 建立可复制的课程体系
  KR1: 14模块课程完课率>70%
  KR2: 认证考试通过率>80%
  KR3: 培养10名认证导师
  KR4: 学员成功案例收集30个

O3: 打造满意解技术护城河
  KR1: 合伙人匹配系统上线
  KR2: 测评工具日活>1000
  KR3: APP注册用户>5000
  KR4: 专利申请3项
```

## 二、制定流程

### 年度OKR制定

```
12月第2周：战略回顾
  → 回顾上年OKR完成情况
  → 分析成功/失败原因

12月第3周：战略设定
  → Egbertie确定3-5个年度O
  → 各部门根据O制定KR

12月第4周：对齐确认
  → 全员OKR对齐会
  → 上下级确认
  → 最终定稿

1月第1周：发布执行
  → 全员发布OKR
  → 公开透明
```

### 季度OKR制定

```
每季度第1周：
  → 回顾上季度KR完成度
  → 根据年度OKR分解季度KR
  → 调整（如需）
  → 发布执行
```

## 三、执行与追踪

### 周度检查

```
每周一 10:00：OKR站会（15分钟）

议程：
1. 上周KR进展（每人1分钟）
2. 本周重点任务
3. 阻塞/需要帮助

规则：
- 只讨论OKR相关事项
- 不展开细节讨论
- 阻塞当场确定解决人
```

### 月度复盘

```
每月最后一周：OKR复盘会（1小时）

议程：
1. 数据回顾（10分钟）
   → 各KR完成度
   → 趋势分析

2. 成功分享（15分钟）
   → 本月最成功的KR
   → 为什么成功？

3. 问题诊断（15分钟）
   → 本月最落后的KR
   → 为什么落后？
   → 怎么补救？

4. 下月计划（15分钟）
   → 下月重点任务
   → 资源调整

5. 个人反馈（5分钟）
   → 每人1句话总结
```

### OKR评分

```
评分标准（0-1分）：

0.0-0.3：红色（严重落后）
  → 需要紧急干预
  → 分析原因
  → 调整策略

0.4-0.6：黄色（有风险）
  → 加强执行
  → 寻求支持
  → 密切监控

0.7-1.0：绿色（正常/优秀）
  → 继续保持
  → 分享经验
  → 挑战更高目标

注意：
- OKR不是KPI，不需要100%完成
- 0.7分是理想状态（有挑战性但可达成）
- 1.0分可能意味着目标太简单
```

## 五、常见错误

| 错误 | 说明 | 正确做法 |
|:-----|:-----|:---------|
| **目标太多** | 一个人5个O | 最多3个O |
| **KR不可衡量** | "提升用户体验" | "NPS提升10分" |
| **目标太简单** | 100%完成是常态 | 0.7分是理想 |
| **不公开透明** | 只有上级知道 | 全员可见 |
| **设完不管** | 季度末才看 | 每周检查 |
| **与绩效挂钩** | OKR=奖金 | OKR≠KPI |
