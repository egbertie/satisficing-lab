## 二、合同管理

### 合同类型清单

| 合同类型 | 使用场景 | 优先级 |
|:---------|:---------|:-------:|
| **服务协议** | 学员购买课程 | P0 |
| **导师协议** | 导师合作 | P0 |
| **企业培训协议** | B端客户 | P0 |
| **渠道合作协议** | 渠道合作 | P1 |
| **保密协议(NDA)** | 员工/合作方 | P0 |
| **知识产权协议** | 内容创作 | P0 |
| **劳动合同** | 全职员工 | P0 |
| **兼职协议** | 兼职人员 | P1 |

### 合同关键条款

```
服务协议必备条款：

1. 服务内容
   → 明确课程/服务范围
   → 不包含的内容

2. 价格与付款
   → 金额
   → 付款方式
   → 退款政策

3. 知识产权
   → 课程内容归属
   → 学员使用权限

4. 保密
   → 双方保密义务
   → 保密期限

5. 责任限制
   → 满意解的责任上限
   → 不可抗力

6. 争议解决
   → 协商优先
   → 仲裁/诉讼
   → 管辖地

7. 退款政策
   → 7天无理由退款
   → 部分退款条件
```

## 四、数据合规

### 个人信息保护

```
合规要求：

1. 隐私政策
   → 公开透明
   → 用户同意
   → 可随时查看

2. 数据收集
   → 最小必要原则
   → 明确告知用途
   → 不收集无关信息

3. 数据存储
   → 境内存储（优先）
   → 加密存储
   → 访问控制

4. 数据使用
   → 不超范围使用
   → 不共享给第三方
   → 用于课程改进

5. 用户权利
   → 查看权
   → 修改权
   → 删除权
   → 导出权
```
