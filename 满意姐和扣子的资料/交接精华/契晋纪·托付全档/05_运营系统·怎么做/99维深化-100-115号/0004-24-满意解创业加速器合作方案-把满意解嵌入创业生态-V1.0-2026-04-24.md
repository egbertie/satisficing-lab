## 一、合作模式

### 模式1：决策工具嵌入

```
加速器提供：
- 入驻企业名单
- 创业课程时间
- 导师资源

满意解提供：
- 合伙人匹配测评（免费）
- 五维决策工作坊（付费）
- 决策卡牌（周边）

分成：
- 测评：免费（获客）
- 工作坊：收入分成（满意解70%:加速器30%）
- 卡牌：满意解100%
```

### 模式2：课程共建

```
共建课程："合伙人决策必修课"

内容：
- 满意解提供：方法论、案例、工具
- 加速器提供：场地、学员、导师

品牌：
- 联合品牌："XX加速器 × 满意解"

收费：
- 学员付费
- 分成：满意解50%:加速器50%
```

### 模式3：年度合作

```
年费制：¥50,000/年

服务：
- 季度合伙人诊断（4次）
- 月度五维工作坊（12次）
- 免费测评（不限次数）
- 决策卡牌赠送（100套）
```

## 三、合作流程

```
Step 1: 接触（1周）
  → 了解加速器需求
  → 提供合作方案

Step 2: 试点（1个月）
  → 1次测评
  → 1次工作坊
  → 收集反馈

Step 3: 签约（1周）
  → 确定合作模式
  → 签署协议

Step 4: 执行（持续）
  → 按约定提供服务
  → 月度复盘

Step 5: 扩展（年度）
  → 评估效果
  → 扩大合作
```
