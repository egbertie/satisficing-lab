---

## 一、社区架构

### 三级社区

```
一级：公开社区（所有人）
  → 公众号读者群
  → 知乎圈子
  → 小红书社群

二级：学员社区（付费学员）
  → 课程学习群
  → 校友会
  → 导师对接群

三级：核心社区（认证持证者）
  → CDA持证者群
  → 导师群
  → 合伙人群
```

---

## 二、运营节奏

| 时间 | 内容 | 负责 |
|:-----|:-----|:-----|
| **每日** | 早安分享、答疑、互动 | 运营 |
| **每周** | 主题讨论、案例分享 | 运营+导师 |
| **每月** | 月度总结、优秀学员 | 运营 |
| **每季** | 线下聚会、工作坊 | 活动团队 |
| **每年** | 年会、颁奖 | 全员 |

---

## 三、内容策略

```
社区内容比例：
- 60% 用户生成内容（UGC）
  → 学习心得、案例分享、问题求助

- 30% 官方内容（OGC）
  → 干货分享、活动通知、产品更新

- 10% 互动内容
  → 投票、话题、小游戏
```

---

## 四、用户成长体系

```
新用户 → 活跃用户 → 贡献用户 → 核心用户 → KOL

激励：
- 积分：发言、分享、点赞
- 勋章：完课、认证、贡献
- 特权：优先答疑、线下活动、导师对接
- 物质：周边、折扣、免费课程
```
