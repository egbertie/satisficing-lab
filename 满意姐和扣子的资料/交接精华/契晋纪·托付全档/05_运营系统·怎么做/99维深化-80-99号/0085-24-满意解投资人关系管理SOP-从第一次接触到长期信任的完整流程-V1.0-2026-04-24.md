## 一、投资人画像

### 目标投资人类型

| 类型 | 关注重点 | 决策周期 | 适合的轮次 |
|:-----|:---------|:---------|:-----------|
| **天使投资人** | 创始人、赛道 | 1-2个月 | 种子轮 |
| **VC** | 商业模式、增长 | 3-6个月 | Pre-A / A轮 |
| **产业资本** | 战略协同 | 3-6个月 | A轮后 |
| **政府基金** | 社会效益、就业 | 6-12个月 | 任何阶段 |

### 理想投资人画像

```
- 关注教育/企业服务赛道
- 有硬科技投资经验
- 认可满意解方法论
- 能提供投后支持
- 决策风格：满意解型（不追求最优，追求最适）
```

## 二、投资人接触流程

### 第一次接触 → 意向确认

```
Step 1: 触达（冷启动）
  → 渠道：行业峰会/FA推荐/创始人网络
  → 材料：一页纸介绍 + 演示视频
  → 目标：获得15分钟电话会议

Step 2: 初步沟通（15分钟电话）
  → Egbertie主讲
  → 内容：痛点→解决方案→市场规模→团队
  → 目标：获得1小时深度会议

Step 3: 深度会议（1小时）
  → 完整路演（20分钟PPT）
  → Q&A（40分钟）
  → 目标：获得尽职调查邀请

Step 4: 尽调（2-4周）
  → 提供：财务/法律/业务/团队资料
  → 配合：访谈/数据验证
  → 目标：获得Term Sheet

Step 5: Term Sheet谈判（1-2周）
  → 关键条款：估值、股权、董事会、对赌
  → 律师参与
  → 目标：签署Term Sheet

Step 6: 交割（1-2个月）
  → 最终尽调
  → 法律文件
  → 资金到账
```

### 季度董事会

```
季度董事会流程：

会前（提前1周）：
  → 准备：财务报表+业务报告+下季计划
  → 发送：提前发给董事

会中（2小时）：
  → 业务回顾（30分钟）
  → 财务回顾（20分钟）
  → 战略讨论（40分钟）
  → 风险识别（20分钟）
  → 决议（10分钟）

会后（48小时内）：
  → 发送：会议纪要+行动项
  → 跟进：行动项责任人
```

## 五、危机沟通

### 坏消息处理

```
原则：坏消息要早说、快说、诚实说

流程：
1. 发现坏消息
2. 24小时内内部评估
3. 48小时内通知投资人
4. 附带：原因分析+应对措施
5. 持续更新进展

禁忌：
❌ 等投资人发现后再说
❌ 粉饰或隐瞒
❌ 只说问题不说方案
```
