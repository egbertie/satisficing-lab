## 第一部分：测试框架

### 1.1 测试流程

```
【Step 1：提出假设】

格式：
"如果[改变X]，那么[指标Y]会[提升/降低Z%]，因为[原因]。"

示例：
"如果把'立即购买'按钮从蓝色改为金色，
那么点击率会提升15%，
因为金色更吸引注意力。"

要素：
├─ 变量：改变什么
├─ 指标：衡量什么
├─ 预期：预期效果
└─ 原因：为什么

【Step 2：设计实验】

确定变量：
├─ 对照组：A（当前版本）
├─ 实验组：B（新版本）
└─ 变量数：一次只测一个

确定指标：
├─ 核心指标：1个（如转化率）
├─ 辅助指标：2-3个（如停留时长、跳出率）
├─  guardrail指标：1个（如投诉率，不能变差）
└─ 统计显著性：p<0.05

确定样本：
├─ 样本量：根据预期效果和显著性计算
├─ 工具：样本量计算器
├─ 示例：预期提升10%，需样本1000人/组
└─ 分流：随机分配

确定周期：
├─ 最短：1周（覆盖完整周期）
├─ 推荐：2周
├─ 考虑：用户行为周期、季节性
└─ 原则：统计显著+业务完整周期

【Step 3：执行实验】

分流：
├─ 随机：确保随机性
├─ 均匀：各组流量均等
├─ 稳定：实验期间不变
└─ 监测：实时监测

监控：
├─ 数据收集：自动收集
├─ 异常检测：及时发现
├─ 样本充足：确保够量
└─ 不偷看：避免提前终止

【Step 4：分析结果】

统计分析：
├─ 均值对比：B vs A
├─ 显著性：p值<0.05？
├─ 置信区间：效果范围
├─ 效应量：实际影响
└─ 工具：统计软件/在线工具

业务解读：
├─ 结果：提升/下降/无变化
├─ 幅度：提升了多少
├─ 置信：有多确定
├─ 影响：对业务的影响
└─ 意外：意外发现

【Step 5：决策行动】

结果显著且正向：
├─ 全量上线
├─ 记录经验
├─ 分享团队
└─ 下一步优化

结果显著且负向：
├─ 不上线
├─ 分析原因
├─ 记录教训
└─ 设计新实验

结果不显著：
├─ 不上线（不浪费资源）
├─ 分析原因：样本不够？效果太小？
├─ 决定是否：增大样本/放弃/新假设
└─ 记录学习

Guardrail指标恶化：
├─ 立即终止
├─ 分析原因
├─ 不上线
└─ 记录教训
```

### 1.2 测试规范

```
【规范1：一次一变量】
├─ 原则：一次只测试一个变量
├─ 原因：多变量无法确定哪个有效
├─ 例外：MV测试（多变量）需专门设计
└─ 示例：不要同时改颜色和文案

【规范2：随机分流】
├─ 原则：用户随机分配到A/B组
├─ 方法：用户ID hash取模
├─ 检查：分流后两组用户特征一致
└─ 工具：分流系统

【规范3：足够样本】
├─ 原则：样本量足够检测到预期效果
├─ 计算：根据基线转化率、预期提升、显著性、功效
├─ 工具：样本量计算器
├─ 示例：基线5%，预期提升到6%，需要样本5000/组
└─ 底线：至少100人/组

【规范4：完整周期】
├─ 原则：覆盖完整业务周期
├─ 最短：1周（覆盖周中+周末）
├─ 推荐：2周
├─ 注意：避开节假日、活动期
└─ 原因：不同时间用户行为不同

【规范5：不提前终止】
├─ 原则：达到预定样本前不看结果
├─ 原因：提前终止会导致假阳性
├─ 例外：guardrail指标恶化
└─ 方法：设置自动警报

【规范6：记录存档】
├─ 原则：所有实验记录存档
├─ 内容：假设、设计、结果、结论
├─ 用途：知识积累、避免重复
└─ 工具：实验记录系统
```

## 第二部分：测试场景

### 2.1 产品功能测试

```
【场景：新功能上线】

假设：
"如果上线'合伙人匹配度对比'功能，
那么测评完成率会提升20%，
因为用户可以邀请合伙人一起测。"

设计：
├─ 对照组：无此功能
├─ 实验组：有此功能
├─ 指标：测评完成率
├─ 样本：2000人/组
└─ 周期：2周

执行：
├─ 开发功能
├─ 灰度发布：实验组可见
├─ 对照组：不可见
├─ 数据收集：埋点
└─ 监控异常

结果：
├─ 实验组完成率：85%
├─ 对照组完成率：70%
├─ 提升：+21.4%
├─ p值：0.001（显著）
└─ 结论：全量上线
```

### 2.2 页面设计测试

```
【场景：落地页优化】

假设：
"如果把落地页标题从'合伙人决策课程'
改为'65%的创业公司死于合伙人冲突，你准备好了吗？'，
那么注册率会提升15%，
因为痛点更明确。"

设计：
├─ 对照组：原标题
├─ 实验组：新标题
├─ 指标：注册率
├─ 样本：3000人/组
└─ 周期：1周

结果：
├─ 实验组注册率：12%
├─ 对照组注册率：10%
├─ 提升：+20%
├─ p值：0.01（显著）
└─ 结论：全量上线
```

---

### 2.3 定价策略测试

```
【场景：课程定价测试】

假设：
"如果把CDA初级课程从2999元改为3999元（附赠1v1咨询），
那么总收入会提升30%，
因为高价值感促进转化。"

设计：
├─ 对照组：2999元
├─ 实验组：3999元（含咨询）
├─ 指标：总收入=转化率×客单价
├─ 样本：1000人/组
└─ 周期：2周

结果：
├─ 实验组转化率：8%（vs 对照组10%）
├─ 实验组客单价：3999（vs 2999）
├─ 实验组总收入：31992（vs 29990）
├─ 提升：+6.7%
├─ p值：0.1（不显著）
└─ 结论：差异不大，保持原定价（更简单）
```
