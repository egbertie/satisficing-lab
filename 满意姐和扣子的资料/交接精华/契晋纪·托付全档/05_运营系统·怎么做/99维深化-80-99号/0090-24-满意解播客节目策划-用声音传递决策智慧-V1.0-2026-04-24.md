## 二、节目结构

### 标准结构

```
开场（2分钟）
  → 音乐起
  → 满意姐开场白
  → "欢迎来到决策时刻，我是满意姐"

本期话题（1分钟）
  → "今天的话题是..."
  → "为什么聊这个？因为..."

嘉宾介绍（2分钟）
  → "今天的嘉宾是..."
  → 嘉宾背景

主题对谈（25-35分钟）
  → 故事开场
  → 问题探讨
  → 方法论分享
  → 金句时刻

总结（3分钟）
  → 本期要点回顾
  → 行动建议
  → 下期预告

结束（1分钟）
  → "感谢收听，我们下周见"
  → 音乐落
  → "满意解，契·晋"
```

## 四、制作流程

### 制作周期

```
周一：选题确定
  → 确定本期话题
  → 联系嘉宾
  → 准备提纲

周二-周三：前期准备
  → 嘉宾沟通
  → 资料收集
  → 问题设计

周四：录制
  → 线上/线下录制
  → 时长：60分钟（剪辑后30-45分钟）

周五：剪辑
  → 粗剪
  → 精剪
  → 加音乐/音效

周六：审核
  → Egbertie听
  → 满意姐审
  → 修改

周日：发布
  → 上传各平台
  → 写Shownotes
  → 推广
```
