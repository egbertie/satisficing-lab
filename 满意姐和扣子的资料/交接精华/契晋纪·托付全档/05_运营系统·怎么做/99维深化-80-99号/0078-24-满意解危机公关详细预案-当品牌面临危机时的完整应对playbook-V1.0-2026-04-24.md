## 二、P0级危机应对（红色）

### 触发条件

- 用户数据大规模泄露
- 创始人严重负面新闻
- 认证体系被质疑造假
- 核心知识产权被盗
- 资金链断裂传闻

### 应对流程

```
Hour 0-1: 紧急响应
  → 成立危机小组（Egbertie+满意姐+蓝军+法务）
  → 确认事实（发生了什么？影响范围？）
  → 启动内部沟通（全员知情）

Hour 1-2: 决策
  → 确定应对策略（承认/否认/观望）
  → 确定发言人（统一口径）
  → 准备声明稿

Hour 2-4: 对外沟通
  → 发布官方声明
  → 主动接触核心媒体
  → 通知受影响用户
  → 开通专门沟通渠道

Hour 4-24: 持续应对
  → 监控舆情
  → 回复质疑
  → 更新进展
  → 准备深度回应

Day 2-7: 深度处理
  → 公布调查结果
  → 公布改进措施
  → 赔偿/补偿方案
  → 第三方审计（如需要）

Week 2+: 品牌修复
  → 持续透明沟通
  → 兑现改进承诺
  → 重建信任
  → 复盘总结
```

## 四、常见危机场景

### 场景1：学员公开投诉

```
情况：学员在微博/小红书公开投诉课程质量

应对：
1. 1小时内：私信联系学员，表达重视
2. 4小时内：了解详细情况，确认事实
3. 12小时内：提出解决方案（退款/补课/其他）
4. 24小时内：如学员同意，公开回应（不透露隐私）
5. 持续跟进：确保问题真正解决

禁忌：
❌ 公开争辩
❌ 指责学员
❌ 删除评论（除非恶意）
```

### 场景2：负面媒体报道

```
情况：媒体发布对满意解不利的报道

应对：
1. 立即：联系记者，了解报道依据
2. 评估：报道是否属实？影响多大？
3. 回应：
   - 属实：承认+改进计划
   - 不实：提供证据澄清
   - 部分属实：承认部分+澄清部分
4. 对冲：发布正面内容
5. 修复：邀请媒体深入了解
```

### 场景3：竞品恶意攻击

```
情况：竞品公开贬低满意解

应对：
1. 不直接回应攻击
2. 强调自身价值
3. 用数据和案例说话
4. 如攻击涉及虚假事实，发律师函
5. 专注做好自己的事

原则：
"不骂回去，用实力回应。"
```

## 五、危机预防

### 预防机制

| 机制 | 说明 | 频率 |
|:-----|:-----|:-----|
| **舆情监控** | 监测品牌提及 | 实时 |
| **NPS追踪** | 用户满意度 | 每季度 |
| **风险评估** | 识别潜在风险 | 每月 |
| **合规审查** | 内容/产品合规 | 每季度 |
| **应急演练** | 模拟危机应对 | 每半年 |

### 舆情监控

```
监控渠道：
- 微博：品牌提及
- 小红书：笔记/评论
- 知乎：问题/回答
- 公众号：文章提及
- 抖音：视频/评论
- 新闻：媒体报道

监控工具：
- 新浪舆情通
- 清博大数据
- 人工巡查

告警阈值：
- 负面提及>10条/天 → 预警
- 负面文章>1篇 → 预警
- 投诉>3件/天 → 预警
```
