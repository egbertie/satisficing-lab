## 第一部分：数据指标体系

### 1.1 北极星指标

```
【定义】
"用户成功完成合伙人决策改进"

【衡量】
├─ 测评完成率：>80%
├─ 课程完课率：>60%
├─ 咨询满意度：>90%
├─ 合伙人关系改善率：>70%
└─ NPS净推荐值：>50

【分解】
用户成功 = 测评→学习→应用→改善

测评阶段：
├─ 指标：测评完成率
├─ 目标：>80%
├─ 追踪：每日
└─ 优化：简化流程、降低门槛

学习阶段：
├─ 指标：课程完课率
├─ 目标：>60%
├─ 追踪：每周
└─ 优化：内容质量、学习体验

应用阶段：
├─ 指标：工具使用率
├─ 目标：>50%
├─ 追踪：每周
└─ 优化：工具易用性、场景引导

改善阶段：
├─ 指标：复测改善率
├─ 目标：>70%
├─ 追踪：每月
└─ 优化：方法有效性、跟进服务
```

## 第二部分：数据收集

### 2.1 埋点规范

```
【埋点原则】
├─ 全面：覆盖所有关键路径
├─ 准确：数据无误
├─ 实时：及时上报
├─ 规范：统一命名
└─ 隐私：合规收集

【埋点类型】

页面浏览（PV）
├─ 事件：page_view
├─ 参数：page_name, page_url, referrer
├─ 触发：页面加载
└─ 用途：流量分析

点击事件（Click）
├─ 事件：button_click
├─ 参数：button_name, page, user_id
├─ 触发：点击时
└─ 用途：交互分析

转化事件（Conversion）
├─ 事件：purchase / register / complete
├─ 参数：product_id, price, channel
├─ 触发：完成时
└─ 用途：转化分析

停留时长（Duration）
├─ 事件：page_exit
├─ 参数：page_name, duration
├─ 触发：离开页面
└─ 用途：内容质量

错误事件（Error）
├─ 事件：error
├─ 参数：error_code, error_msg, page
├─ 触发：出错时
└─ 用途：稳定性

【命名规范】
├─ 格式：模块_动作_对象
├─ 示例：course_click_play, purchase_complete_cda
├─ 规范：全小写，下划线分隔
└─ 管理：统一文档维护
```

## 第三部分：数据分析

### 3.1 分析框架

```
【漏斗分析】

获客漏斗：
曝光 → 点击 → 注册 → 测评 → 课程 → 付费 → 复购

| 阶段 | 转化率 | 优化点 |
|:-----|:-------|:-------|
| 曝光→点击 | 5% | 标题、封面 |
| 点击→注册 | 20% | 落地页 |
| 注册→测评 | 70% | 引导、催促 |
| 测评→课程 | 30% | 推荐、优惠 |
| 课程→付费 | 15% | 价值展示 |
| 付费→复购 | 40% | 服务、效果 |

【留存分析】

Cohort分析：
├─ 按注册日期分组
├─ 追踪留存率变化
├─ 对比不同渠道质量
└─ 识别最佳获客渠道

流失预警：
├─ 7天未登录
├─ 测评完成但未购课
├─ 课程未完成
├─ 会员即将到期
└─ 自动触发关怀

【路径分析】

用户路径：
├─ 最常访问路径
├─ 转化路径
├─ 流失路径
└─ 优化路径设计

【归因分析】

转化归因：
├─ 首次触点：哪个渠道带来
├─ 最后触点：哪个渠道转化
├─ 线性归因：平均分配
├─ 时间衰减：越近权重越高
└─ 选择：根据业务特点
```
