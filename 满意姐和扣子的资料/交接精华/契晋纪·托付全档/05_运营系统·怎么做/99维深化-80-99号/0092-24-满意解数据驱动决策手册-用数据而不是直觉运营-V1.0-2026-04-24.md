## 一、数据指标体系

### 北极星指标

> **北极星指标：月度活跃学员数（MAU）**
> 
> 为什么？
> 因为满意解的核心价值是帮助学员做更好的决策，
> 只有活跃学员，才能体现价值。

### 一级指标（业务健康）

| 指标 | 定义 | 目标 | 监测频率 |
|:-----|:-----|:-----|:---------|
| **MAU** | 月活跃学员数 | 1,000人 | 每日 |
| **付费转化率** | 付费用户/注册用户 | >5% | 每周 |
| **客单价** | 总收入/付费用户数 | >¥3,000 | 每月 |
| **LTV** | 用户生命周期价值 | >¥5,000 | 每季度 |
| **CAC** | 获客成本 | <¥500 | 每月 |
| **NPS** | 净推荐值 | >50 | 每季度 |

| 指标 | 定义 | 目标 | 监测频率 |

## 三、数据分析

### 分析框架

```
AARRR漏斗分析：

Acquisition（获客）
  → 流量来源分析
  → 渠道ROI分析
  → 获客成本分析

Activation（激活）
  → 注册转化率
  → 首次测评完成率
  → 新用户留存

Retention（留存）
  → 次日留存
  → 7日留存
  → 30日留存

Revenue（收入）
  → 付费转化
  → 客单价
  → 复购率

Referral（推荐）
  → NPS
  → 推荐人数
  → 裂变系数
```

### 分析示例

```
问题：为什么完课率只有60%？

分析步骤：
1. 按模块看流失：
   → 模块1：90%完成
   → 模块2：80%完成
   → 模块3：65%完成 ← 断崖
   → 模块4：60%完成

2. 分析模块3特征：
   → 内容难度高？
   → 作业量大？
   → 时间不合适？

3. 用户调研：
   → 问卷：你为什么停在模块3？
   → 访谈：5位学员深度访谈

4. 发现原因：
   → 模块3作业需要合伙人配合
   → 很多学员还没有合伙人

5. 优化方案：
   → 增加"虚拟合伙人"案例
   → 提供单人版作业
   → 增加互助配对

6. 验证：
   → A/B测试
   → 监测新完课率
```

## 五、实验文化

### A/B测试规范

```
Step 1: 假设
  → "如果我们把测评入口放在首页，
      测评完成率会提升10%"

Step 2: 实验设计
  → 对照组：原位置
  → 实验组：首页入口
  → 样本量：各1000人
  → 运行时间：2周

Step 3: 运行
  → 随机分配用户
  → 确保单一变量
  → 监控数据质量

Step 4: 分析
  → 统计显著性检验
  → 效果大小评估
  → 置信区间

Step 5: 决策
  → 显著正向：全量发布
  → 显著负向：放弃
  → 不显著：延长实验或放弃
```
