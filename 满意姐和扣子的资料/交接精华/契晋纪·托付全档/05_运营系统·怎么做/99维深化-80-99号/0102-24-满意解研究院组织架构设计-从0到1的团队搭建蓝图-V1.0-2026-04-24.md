## 一、组织架构

### 三阶段演进

```

Egbertie（创始人）
  ├── 满意姐（AI助理/运营）
  ├── 内容运营（1人）
  └── 技术合伙人（1人，兼职）

阶段2：成长期（6-18个月，10-15人）

  │   ├── 案例库（1人）
  │   └── 教材设计（1人）

  │   ├── 社群运营（1人）
  │   └── 活动运营（1人）

  │   ├── 产品开发（2人）
  │   └── 数据/AI（1人）
  └── 商业拓展
      ├── 企业客户（1人）
      └── 渠道合作（1人）

阶段3：成熟期（18-36个月，30-50人）

Egbertie（CEO）
  ├── 研究院
  │   ├── 学术委员会
  │   ├── 课程研发中心
  │   └── 认证中心
  ├── 运营中心
  │   ├── 品牌部
  │   ├── 内容部
  │   ├── 社群部
  │   └── 活动部
  ├── 技术中心
  │   ├── 产品部
  │   ├── 工程部
  │   └── 数据部
  ├── 商业部
  │   ├── 直销团队
  │   ├── 渠道团队
  │   └── 企业团队
  └── 中后台
      ├── 人力资源
      ├── 财务
      └── 法务

## 二、核心岗位JD

### 教研总监

```
岗位：教研总监
汇报：Egbertie
下属：3-5人

职责：
- 14模块课程持续迭代
- 案例库建设（13类型冲突案例）
- 教材标准化（口播级教案）
- 导师培训体系

要求：
- 5年以上教育/培训经验
- 熟悉成人学习理论
- 有课程设计成功案例
- 认同满意解方法论

薪酬：¥25,000-35,000/月 + 期权
```

### 内容运营负责人

```
岗位：内容运营负责人
汇报：Egbertie
下属：2-3人

职责：
- 公众号/小红书/知乎内容策略
- 90天内容日历执行
- AI提示词库管理
- 品牌一致性审计

要求：
- 3年以上内容运营经验
- 熟悉知识付费行业
- 有爆款内容案例
- 认同品牌调性（有温度、非官僚）

薪酬：¥15,000-25,000/月 + 绩效
```

### 产品经理

```
岗位：产品经理（合伙人匹配系统）
汇报：Egbertie
下属：2-3人（开发+设计）

职责：
- 合伙人匹配系统产品化
- 测评工具迭代
- APP产品规划
- 用户体验优化

要求：
- 3年以上B端/C端产品经验
- 有SaaS/工具类产品案例
- 懂AI/算法基础
- 认同满意解价值观

薪酬：¥20,000-30,000/月 + 期权

## 三、决策机制

### 三级决策

| 级别 | 决策人 | 范围 | 时效 |
|:-----|:-------|:-----|:-----|
| **一级** | Egbertie | 战略/人事/财务/品牌 | 48小时 |
| **二级** | 部门负责人 | 部门预算/招聘/执行 | 24小时 |
| **三级** | 一线员工 | 日常运营/客户问题 | 即时 |

### 五维决策机制

```
重大决策（>¥50,000或影响>10人）
必须经过五维框架：

土·伦理：这个决策站得住吗？
金·满意解：80分方案够了吗？
水·洞察：本质问题是什么？
木·信任：团队信任会受损吗？
火·直觉：内心怎么说？
```

## 四、文化规范

```
1. 减法优先

2. 诚实至上
   → 没做到就是没做到

4. 互评制度

   → 诚实反馈，不走过场

5. 温度在线
   → 关心同事的状态
   → 不只是工作，也是人
```
