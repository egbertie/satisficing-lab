## 第二部分：服务分类与处理流程

### 2.1 服务分类（6大类）

```
【类型1：产品咨询】（占比40%）
├─ 课程内容询问
├─ 价格询问
├─ 购买方式询问
├─ 产品对比询问
└─ 处理原则：快速、准确、不推销

【类型2：技术支持】（占比20%）
├─ 测评系统问题
├─ 课程访问问题
├─ 支付问题
├─ 账号问题
└─ 处理原则：技术优先，24小时内解决

【类型3：投诉建议】（占比15%）
├─ 课程内容投诉
├─ 服务质量投诉
├─ 退款申请
├─ 改进建议
└─ 处理原则：真诚、担当、解决导向

【类型4：退款售后】（占比10%）
├─ 退款申请
├─ 换课申请
├─ 延期申请
├─ 发票申请
└─ 处理原则：按政策执行，特殊情况灵活处理

【类型5：情感支持】（占比10%）
├─ 合伙人关系困扰
├─ 情绪倾诉
├─ 决策困惑
├─ 求助
└─ 处理原则：倾听、共情、引导（不替代心理咨询）

【类型6：合作洽谈】（占比5%）
├─ 企业内训咨询
├─ 渠道合作
├─ 媒体合作
├─ 投资咨询
└─ 处理原则：专业、高效、转交商务
```

### 2.2 处理流程（标准化+人性化）

```
【Step 1：接收】

用户消息到达 → 系统自动分类 → 分配给对应客服

自动分类规则：
├─ 含"退款""退课""不满意" → 投诉类
├─ 含"登录""密码""打不开" → 技术类
├─ 含"多少钱""怎么买""课程" → 咨询类
├─ 含"合伙人要退出""股权""分歧" → 情感/咨询类
├─ 含"合作""内训""演讲" → 商务类
└─ 其他 → 人工判断

【Step 2：响应】

首次响应模板（2小时内）：

"Hi [姓名]，

感谢联系满意解！

我是[客服名]，已经收到你的[问题类型]。

[如果是简单问题]：
立即给出答案。

[如果是复杂问题]：
这个问题需要一些时间来确认，
我会在[X小时]内给你详细回复。

如有紧急情况，请拨打：[电话]。

Egbertie + 满意姐"

【Step 3：解决】

解决问题 → 确认用户满意 → 关闭工单

解决标准：
├─ 用户明确表示"问题解决了"
├─ 或用户24小时内未回复（视为默认满意）
└─ 或客服判断已尽力但用户仍不满意（升级处理）

【Step 4：回访】

解决后3天：
├─ 发送回访消息："之前的问题是否彻底解决？还有其他需要帮助的吗？"
├─ 收集满意度："对我们的服务满意吗？1-10分"
└─ 记录反馈：用于改进

【Step 5：归档】

归档信息：
├─ 用户信息
├─ 问题描述
├─ 解决过程
├─ 解决结果
├─ 用户满意度
└─ 改进建议（如有）
```

### 3.1 产品咨询话术

```
【场景：询问课程内容】

用户："CDA初级课程包含什么内容？"

客服：
"Hi！CDA初级课程是我们的核心产品，
包含14个模块，系统学习五维决策框架。

具体内容：
├─ 模块1-2：五维决策基础（土金水木火）
├─ 模块3-5：合伙人评估与匹配
├─ 模块6-8：决策权与股权设计
├─ 模块9-11：沟通与冲突解决
├─ 模块12-14：实战案例与工具

学习方式：
├─ 视频课程（每模块15-20分钟）
├─ 在线测评（5分钟自评）
├─ 工具模板（可打印使用）
├─ 社群讨论（学员互助）

适合人群：
├─ 想系统学习合伙人决策的创始人
├─ 准备找合伙人的创业者
├─ 遇到合伙人问题的管理者

价格：2999元（现在报名送决策卡牌，价值199元）。

想要了解更多？我可以发你详细大纲。
或者预约15分钟免费咨询，我帮你判断是否适合。"

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【场景：价格犹豫】

用户："2999有点贵..."

客服：
"我完全理解，2999不是小数字。

让我帮你算一笔账：
├─ 合伙人冲突的隐性成本：每年10-30万（时间+机会+情感）
├─ 律师费：如果需要处理股权争议，3-30万
├─ 课程投入：2999元
├─ ROI：10-100倍

而且，课程不是一次性消费：
├─ 工具模板可以反复使用
├─ 社群可以长期交流
├─ 内容可以反复回看

如果还是觉得有压力，
我们有分期付款选项（3期免息）。

或者，你可以先从免费的'5分钟测评'开始，
看看是否真的有价值，再决定。

你觉得呢？"
```

### 3.3 情感支持话术

```
【场景：合伙人关系困扰】

用户："我和合伙人最近关系很差，不知道怎么办..."

客服：
"感谢你愿意分享这些。

我能感受到你现在很困扰。

先深呼吸——
合伙人关系出问题，不代表公司完蛋。
很多创始人都经历过，而且最后解决了。

我想先了解一下：
├─ 你们的核心分歧是什么？（方向/股权/角色/沟通？）
├─ 这个问题持续多久了？
├─ 你们尝试过沟通吗？结果如何？

[了解后]

基于你的情况，我建议：

第一步：做我们的免费测评
（5分钟，看清你们的关系健康度）

第二步：预约15分钟免费咨询
（Egbertie亲自帮你分析问题）

第三步：根据诊断结果，选择适合的产品
（可能是课程、工作坊，或1v1教练）

如果你现在就想聊聊，
我也可以在这里陪你聊一会儿。

但我是客服，不是专业咨询师，
如果问题比较复杂，
强烈建议预约免费咨询，
让Egbertie帮你系统分析。

你想怎么做？"

【重要原则】
├─ 倾听 > 给建议（先让用户说完）
├─ 共情 > 评判（"我理解"而不是"你应该"）
├─ 引导 > 替代（引导找专业帮助，不替代专业角色）
├─ 界限 > 侵入（明确客服边界，不过度介入）
└─ 如果用户情绪严重：建议寻求专业心理咨询
```

## 第四部分：服务质量管理

### 4.1 KPI指标

```
【响应速度】
├─ 平均首次响应时间：< 2小时
├─ 紧急问题响应时间：< 30分钟
├─ 节假日响应时间：< 4小时
└─ 目标：95%的咨询在标准时间内响应

【解决效率】
├─ 一次解决率：> 70%（不用反复沟通）
├─ 平均解决时间：< 24小时
├─ 复杂问题升级时间：< 4小时
└─ 目标：90%的问题在24小时内解决

【用户满意度】
├─ 服务满意度：> 90%（1-10分，≥8分算满意）
├─ NPS：> 50
├─ 投诉率：< 2%
└─ 目标：用户愿意推荐给朋友

【服务质量】
├─ 话术规范率：> 95%
├─ 信息准确率：> 98%
├─ 态度友好率：> 95%
└─ 目标：专业、温暖、高效
```
