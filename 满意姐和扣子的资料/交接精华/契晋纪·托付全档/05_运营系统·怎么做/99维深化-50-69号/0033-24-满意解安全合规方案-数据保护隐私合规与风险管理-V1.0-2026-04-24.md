## 二、数据保护

### 数据分类

| 级别 | 数据类型 | 保护措施 |
|:-----|:---------|:---------|
| **绝密** | 算法核心、商业机密 | 加密+最小权限+审计 |
| **机密** | 客户测评数据、支付信息 | 加密+访问控制+日志 |
| **内部** | 运营数据、员工信息 | 访问控制+日志 |
| **公开** | 课程内容、公开案例 | 无特殊保护 |

### 数据生命周期

```
收集 → 存储 → 使用 → 共享 → 归档 → 销毁
  ↓      ↓      ↓      ↓      ↓      ↓
最小化  加密   授权   审批   期限   彻底
```

**收集原则**:
- 最小必要：只收集服务必需的数据
- 明示同意：收集前明确告知用途
- 可选分离：非必要数据与必要数据分离

**存储原则**:
- 加密存储：AES-256
- 访问控制：RBAC
- 审计日志：全量记录

**销毁原则**:
- 用户注销：30天内删除
- 合同到期：90天内删除
- 备份数据：按保留期删除

## 三、隐私政策

### 隐私政策要点

```
《满意解隐私政策》V1.0

1. 我们收集什么信息
   - 账户信息（手机号/邮箱）
   - 测评答案（五维分数）
   - 使用数据（学习进度）
   - 设备信息（IP/UA）

2. 我们如何使用信息
   - 提供服务（测评/课程/教练）
   - 改进产品（数据分析）
   - 个性化推荐
   - 合规要求

3. 我们如何共享信息
   - 不卖给第三方
   - 仅在必要时共享（如支付服务商）
   - 匿名化后用于学术研究

4. 您的权利
   - 访问权：查看您的数据
   - 更正权：修改错误信息
   - 删除权：注销账户
   - 限制权：限制使用范围
   - 携带权：导出数据

5. 数据安全
   - 加密传输（TLS 1.3）
   - 加密存储（AES-256）
   - 定期安全审计

6. 联系我们
   - 隐私问题：privacy@satisficing.institute
   - 数据保护官：dpo@satisficing.institute
```

### 用户协议要点

| 入侵检测 | WAF + IDS | 实时 |
| 应急响应 | 预案+演练 | 每半年 |

### 应急响应预案

```
事件分级:
P0: 数据泄露、系统入侵 → 1小时内响应，立即报告监管
P1: 服务中断、勒索软件 → 4小时内响应
P2: 异常访问、可疑行为 → 24小时内响应

响应流程:
1. 发现 → 确认 → 遏制 → 根除 → 恢复 → 复盘
2. 内部通报 → 客户通知 → 监管报告 → 公开披露
3. 72小时内向监管报告（P0事件）
```
