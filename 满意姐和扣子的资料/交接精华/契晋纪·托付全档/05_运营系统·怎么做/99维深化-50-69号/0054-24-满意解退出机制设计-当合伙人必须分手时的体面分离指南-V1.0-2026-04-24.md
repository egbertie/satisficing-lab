## 一、退出决策框架

### 什么时候应该考虑退出

| 信号 | 严重程度 | 建议 |
|:-----|:---------|:-----|
| 信任评分<3分（持续3个月） | 🔴 | 立即评估 |
| 价值观分歧>3项 | 🔴 | 难以修复 |
| 连续3次重大决策冲突 | 🟡 | 尝试干预 |
| 一方长期投入不足 | 🟡 | 沟通+补偿 |
| 外部机会导致分心 | 🟢 | 调整分工 |
| 成长速度严重不匹配 | 🟡 | 角色调整 |

### 五维退出评估

```
用五维框架评估是否该退出：

土·伦理：是否还有共同底线？
  → 如果伦理冲突（如诚信问题），必须退出

金·满意解：是否还有互补价值？
  → 如果互补度<30%，考虑退出

水·洞察：是否还能共同思考？
  → 如果无法沟通本质问题，考虑退出

木·信任：信任是否可修复？
  → 如果<3分且30天修复无效，考虑退出

火·直觉：直觉怎么说？
  → 如果双方直觉都说"该走了"，尊重直觉
```

## 二、退出类型

### Type A：友好退出（Good Leaver）

**特征**:
- 双方协商一致
- 无重大过错
- 希望保持关系

**流程**:

```
Step 1: 坦诚对话（面对面）
  → "我想谈谈我们的合作关系，
      我觉得我们可能走到了需要调整的阶段。"

Step 2: 五维复盘
  → 回顾合作历程
  → 分析哪里出了问题
  → 确认无法修复

Step 3: 协商方案
  → 股权回购价格
  → 资产分割
  → 债务承担
  → 竞业限制

Step 4: 法律文件
  → 签署退出协议
  → 工商变更
  → 知识产权归属

Step 5: 体面公告
  → 对内：团队说明
  → 对外：客户/投资人通知
  → 措辞："战略调整"而非"分手"

Step 6: 关系维护
  → 保持联系
  → 未来合作可能性
  → 共同朋友的处理
```

**退出价格公式**:
```
友好退出价格 = 初始出资额 + 已成熟股权价值 × 80%

已成熟股权价值 = 公司最近估值 × 股权比例 × 成熟比例

示例：
- 初始出资：¥50万
- 股权：30%
- 成熟：75%（3年/4年）
- 公司估值：¥500万

退出价格 = ¥50万 + (¥500万 × 30% × 75%) × 80%
         = ¥50万 + ¥112.5万 × 80%
         = ¥50万 + ¥90万
         = ¥140万
```

---

### Type B：争议退出（Bad Leaver）

**特征**:
- 一方重大过错
- 协商困难
- 可能需要法律介入

**流程**:

```
Step 1: 证据收集
  → 收集对方过错的证据
  → 财务记录
  → 沟通记录
  → 第三方证言

Step 2: 正式通知
  → 律师函
  → 明确指控
  → 要求回应

Step 3: 调解尝试
  → 第三方调解
  → 行业协会介入
  → 仲裁申请

Step 4: 法律程序
  → 诉讼准备
  → 财产保全
  → 法庭程序

Step 5: 执行
  → 判决执行
  → 股权回购
  → 资产交割
```

**退出价格公式**:
```
争议退出价格 = 初始出资额（原价回购）

未成熟股权：全部丧失
已成熟股权：按协议折扣（通常50-80%）

示例：
- 初始出资：¥50万
- 股权：30%
- 成熟：75%
- 因重大过错退出

退出价格 = ¥50万（原价）
          + 已成熟部分按50%折扣
          = ¥50万 + (¥112.5万 × 50%)
          = ¥50万 + ¥56.25万
          = ¥106.25万
```

### Type C：公司解散

**触发条件**:
- 双方都无法继续
- 公司无法独立运营
- 清算价值 > 继续运营价值

**流程**:

```
Step 1: 解散决议
  → 股东会决议
  → 2/3以上表决权通过

Step 2: 清算组成立
  → 双方各派1人
  → 可选第三方会计师

Step 3: 资产清算
  → 债权债务清理
  → 资产评估
  → 剩余财产分配

Step 4: 注销登记
  → 税务注销
  → 工商注销
  → 银行账户注销

Step 5: 后续义务
  → 保密义务持续
  → 知识产权归属
  → 竞业限制（如有）
```

## 三、退出后管理

### 情感修复

| 阶段 | 时间 | 建议 |
|:-----|:-----|:-----|
| 冷却期 | 0-3个月 | 减少接触，各自疗伤 |
| 反思期 | 3-6个月 | 复盘经验教训 |
| 和解期 | 6-12个月 | 尝试恢复友好关系 |
| 重建期 | 12月+ | 未来合作可能性 |

### 业务切割

| 资产 | 处理方式 | 说明 |
|:-----|:---------|:-----|
| 客户资源 | 按贡献分配 | 不抢夺客户 |
| 知识产权 | 按出资比例 | 或买断 |
| 品牌/商标 | 一方买断或共用 | 需明确 |
| 社交媒体 | 账号归属协商 | 可新开账号 |
| 团队 | 尊重员工选择 | 不挖角 |
| 债务 | 按股权比例 | 或协商承担 |

## 四、预防机制

### 合伙前预防

```
1. 签署详细合伙协议
   → 退出条款
   → 股权成熟机制
   → 回购价格公式
   → 竞业限制

2. 定期关系体检
   → 每季度五维评估
   → 信任评分监控
   → 价值观对齐检查

3. 建立沟通机制
   → 定期1v1
   → 冲突解决流程
   → 第三方顾问
```

### 合伙中预警

| 预警信号 | 响应 |
|:---------|:-----|
| 连续2次互评<5分 | 立即对话 |
| 财务不透明 | 要求审计 |
| 决策僵局>30天 | 启动调解 |
| 外部投资/兼职 | 坦诚沟通 |
| 情绪波动异常 | 关心+支持 |

## 五、退出工具包

### 工具1：退出评估清单

```
□ 五维评分是否<15分（满分50）？
□ 信任评分是否<3分且30天修复无效？
□ 是否有不可调和的价值观冲突？
□ 是否有重大诚信问题？
□ 双方是否都同意退出？
□ 退出方案是否已协商？
□ 法律文件是否准备？
□ 团队/客户是否已通知？
□ 情感是否已处理？
□ 未来关系是否已规划？
```

### 工具2：退出对话脚本

```
开场：
"我想认真谈谈我们的合作关系。
这不是一时冲动，是深思熟虑后的想法。"

表达：
"我发现我们在[具体维度]上出现了不可调和的分歧。
我尝试过[具体努力]，但情况没有改善。
我认为，为了双方好，我们需要考虑调整合作关系。"

倾听：
"我想听听你的想法。
你觉得呢？"

协商：
"如果我们决定分开，我希望是体面的。
关于[股权/资产/债务]，我的想法是[方案]。
你怎么看？"

收尾：
"无论结果如何，我珍惜我们共事的时光。
希望未来我们都能更好。"
```
