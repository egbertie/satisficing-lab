## 第六部分：裂变数据管理

### 6.1 核心指标

```
【裂变指标】

指标1：裂变系数（K值）
├─ 定义：每个老用户带来多少新用户
├─ 计算：新用户数 / 邀请老用户数
├─ 目标：K > 1（每个用户带来>1个新用户）
└─ 例：100老用户带来150新用户，K=1.5

指标2：分享率
├─ 定义：分享用户 / 总用户
├─ 计算：分享人数 / 使用人数
├─ 目标：>20%
└─ 例：1000人使用，200人分享，分享率20%

指标3：邀请转化率
├─ 定义：被邀请人注册/消费比例
├─ 计算：被邀请注册人数 / 邀请次数
├─ 目标：>10%
└─ 例：1000次邀请，100人注册，转化率10%

指标4：裂变获客成本
├─ 定义：裂变获客总成本 / 裂变新客数
├─ 计算：（奖励成本+工具成本）/ 新客数
├─ 目标：<30元/人
└─ 例：奖励成本3000元，带来150人，成本20元/人

指标5：裂变贡献占比
├─ 定义：裂变新客 / 总新客
├─ 计算：裂变新客数 / 总新客数
├─ 目标：>30%
└─ 例：月度新客500人，其中200人来自裂变，占比40%
```

### 6.2 裂变优化

```
【A/B测试】
├─ 测试1：奖励金额（10% vs 15% vs 20%）
├─ 测试2：分享文案（A版 vs B版）
├─ 测试3：分享时机（即时 vs 24小时后）
├─ 测试4：海报设计（设计A vs 设计B）
└─ 目标：找到最优组合

【用户分层】
├─ 高裂变用户：K>2，重点维护，给予特权
├─ 中裂变用户：K=1-2，激励提升，给予奖励
├─ 低裂变用户：K<1，了解原因，给予教育
└─ 无裂变用户：激活尝试，给予工具

【迭代优化】
├─ 每月分析裂变数据
├─ 识别瓶颈环节
├─ 优化分享流程
├─ 更新奖励机制
└─ 持续迭代
```

> ├─ 流程顺（用户容易操作）
> └─ 体验佳（用户愿意再次分享）
