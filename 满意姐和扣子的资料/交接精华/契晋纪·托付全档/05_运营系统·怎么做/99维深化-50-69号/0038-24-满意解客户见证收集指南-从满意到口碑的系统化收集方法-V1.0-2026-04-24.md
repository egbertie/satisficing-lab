## 二、收集流程

### 流程1：APP内评价（自动）

```
用户完成测评/课程 → APP弹窗
  → "您的体验如何？1-5星"
  → 4-5星：引导文字评价
  → 1-3星：引导反馈改进
  → 评价自动入库
```

### 流程2：邮件收集（批量）

```
T+7天（完成课程后）
  → 发送感谢邮件
  → 附：3分钟评价问卷
  → 激励：完成送¥50优惠券

T+30天（认证后）
  → 发送深度访谈邀请
  → 附：访谈提纲
  → 激励：完成送决策卡牌
```

### 流程3：电话访谈（深度）

```
筛选：认证学员+高NPS+愿意分享
预约：提前3天预约，30分钟
准备：访谈提纲+录音设备
执行：深度访谈，挖掘故事
整理：24小时内整理成文
确认：发送客户确认，授权使用
```

## 三、访谈提纲

### 标准访谈提纲（30分钟）

**开场（2分钟）**
> "感谢您接受访谈。今天想聊聊您和满意解的故事。
> 全程约30分钟，会录音，仅用于内部分析和案例整理。
> 您可以随时叫停或跳过不想回答的问题。"

**背景（3分钟）**
1. 请简单介绍您的背景和行业。
2. 当时面临什么决策困境？

**痛点（5分钟）**
3. 在接触满意解之前，您如何解决合伙人/决策问题？
4. 当时最大的困扰是什么？
5. 是什么让您决定尝试满意解？

**体验（10分钟）**
6. 您使用了满意解的什么产品/服务？
7. 体验过程中，印象最深的是什么？
8. 五维框架中，哪个维度对您帮助最大？
9. 有没有一个具体的决策，因为满意解而改变？

**结果（5分钟）**
10. 使用满意解后，您的决策质量有什么变化？
11. 合伙人关系有什么改善？
12. 如果量化，满意解为您带来了什么价值？

**推荐（3分钟）**
13. 您会向朋友推荐满意解吗？为什么？
14. 如果推荐，您会怎么说？
15. 对满意解有什么建议？

**收尾（2分钟）**
> "感谢分享。您的故事对我们非常宝贵。
> 我们会将您的案例整理成文，发送给您确认。
> 如果同意，我们会在官网/公众号使用，会标注您的名字和公司（或匿名，您选择）。
> 送您一套决策卡牌作为感谢。"
