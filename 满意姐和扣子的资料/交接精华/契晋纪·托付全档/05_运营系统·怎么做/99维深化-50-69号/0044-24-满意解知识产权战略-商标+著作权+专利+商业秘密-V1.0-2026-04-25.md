### 7.2 维权流程

```
【Step 1：发现侵权】
├─ 监测发现/用户举报
├─ 初步判断侵权性质
└─ 收集证据（截图、链接、时间）

【Step 2：证据固定】
├─ 网页公证
├─ 购买侵权产品（保留凭证）
├─ 时间戳认证
└─ 律师评估

【Step 3：发送警告函】
├─ 律师函/公司函
├─ 要求停止侵权、赔偿损失
├─ 给予整改期限（7-15天）
└─ 保留法律追诉权

【Step 4：协商解决】
├─ 对方同意：签署和解协议
├─ 赔偿金额协商
├─ 停止侵权承诺
└─ 监督执行

【Step 5：法律诉讼】（协商失败）
├─ 起诉：向法院提起侵权诉讼
├─ 赔偿：要求赔偿损失
├─ 禁令：要求停止侵权
└─ 执行：判决后强制执行

【维权预算】
├─ 律师费：2-10万/案
├─ 公证费：1000-3000元/次
├─ 诉讼费：按标的额计算
├─ 赔偿收入：视案件而定
└─ 年度维权预算：5-10万
```
