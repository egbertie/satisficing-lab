## 第一部分：见证收集

### 1.1 收集时机

```
【时机1：课程结束后】
├─ 时间：课程结束后3-7天
├─ 方式：邮件/短信/社群
├─ 内容："课程结束了，想听听你的真实感受"
├─ 激励：完成评价送积分/优惠券
└─ 目标：收集课程体验见证

【时机2：解决问题后】
├─ 时间：问题解决了，用户满意时
├─ 方式：客服直接邀请
├─ 内容："很高兴帮到您，愿意分享您的故事吗？"
├─ 激励：感谢礼品
└─ 目标：收集服务体验见证

【时机3：取得成果后】
├─ 时间：用户取得明显成果（如合伙人关系改善）
├─ 方式：教练/Egbertie亲自邀请
├─ 内容："您的进步让我们很开心，愿意分享给更多人吗？"
├─ 激励：案例署名权、品牌曝光
└─ 目标：收集成果见证

【时机4：定期征集】
├─ 时间：每季度1次
├─ 方式：公众号/社群发起征集
├─ 内容："满意解用户故事征集活动"
├─ 激励：评选优秀故事，奖励课程/礼品
└─ 目标：批量收集见证

【时机5：主动挖掘】
├─ 时间：随时
├─ 方式：运营团队主动搜索
├─ 渠道：小红书、知乎、朋友圈、社群
├─ 内容：用户自发的好评
└─ 目标：收集自然传播的见证
```

---

### 1.2 收集方式

```
【方式1：文字评价】
├─ 工具：问卷星/腾讯问卷/飞书问卷
├─ 形式：结构化问卷
├─ 题量：5-10题
├─ 时间：3-5分钟
└─ 产出：文字评价+评分

【方式2：视频访谈】
├─ 工具：腾讯会议/Zoom（录制）
├─ 形式：30分钟访谈，剪辑成3-5分钟
├─ 流程：
│   ├─ 开场：自我介绍+背景
│   ├─ 问题1：遇到的问题
│   ├─ 问题2：为什么选择满意解
│   ├─ 问题3：具体收获
│   ├─ 问题4：成果展示
│   └─ 收尾：推荐给其他人
├─ 剪辑：加字幕、片头片尾
└─ 产出：视频见证

【方式3：案例访谈】
├─ 工具：文字访谈/语音访谈
├─ 形式：深度案例故事
├─ 结构：
│   ├─ 背景：公司/团队/个人情况
│   ├─ 问题：遇到的合伙人问题
│   ├─ 解决：如何使用满意解解决
│   ├─ 成果：具体成果（尽量量化）
│   └─ 心得：给其他创始人的建议
├─ 字数：1000-3000字
└─ 产出：案例文章

【方式4：数据收集】
├─ 工具：Excel/飞书表格
├─ 形式：量化成果收集
├─ 内容：
│   ├─ 合伙人冲突减少：从X次/月到Y次/月
│   ├─ 决策效率提升：从X天到Y天
│   ├─ 团队满意度：从X分到Y分
│   └─ 业绩增长：从X万到Y万
└─ 产出：数据成果表

【方式5：社交截图】
├─ 工具：截图+授权
├─ 形式：用户自发的好评截图
├─ 渠道：朋友圈、小红书、知乎、社群
├─ 要求：
│   ├─ 必须获得用户授权
│   ├─ 隐私信息打码
│   └─ 真实，不PS
└─ 产出：社交证明图
```

### 2.1 见证库管理

```
【见证库存储】

存储位置：飞书文档/Notion/飞书多维表格

字段：
├─ 见证ID：WIT-001
├─ 客户姓名：张三
├─ 客户公司：XX科技
├─ 客户职位：CEO
├─ 客户行业：SaaS
├─ 公司阶段：A轮
├─ 见证类型：文字/视频/案例/数据/截图
├─ 见证内容：[内容摘要]
├─ 使用场景：官网/销售/公众号/小红书
├─ 授权状态：已授权/待授权/匿名
├─ 质量评级：⭐⭐⭐⭐⭐
├─ 收集时间：2026-04-25
├─ 使用次数：3
└─ 备注：[其他信息]

【质量评级】
⭐⭐⭐⭐⭐（优秀）
├─ 具体成果（有数字）
├─ 情感真挚
├─ 品牌名提及
├─ 推荐意愿强烈
└─ 可公开使用

⭐⭐⭐⭐（良好）
├─ 有具体内容
├─ 正面评价
├─ 可公开使用
└─ 缺少量化成果

⭐⭐⭐（一般）
├─ 简短评价
├─ 内容泛泛
├─ 需要补充
└─ 可用于社交媒体

⭐⭐（较差）
├─ 内容空洞
├─ 或负面评价
├─ 需要处理
└─ 内部参考用

【标签体系】
├─ 场景标签：课程/服务/工具/咨询
├─ 产品标签：CDA初级/中级/高级/卡牌/内训
├─ 行业标签：SaaS/硬件/消费/教育/医疗
├─ 阶段标签：种子/天使/A轮/B轮/C轮
├─ 成果标签：关系改善/决策优化/股权设计/团队和谐
└─ 情感标签：感激/惊喜/认同/推荐
```

### 2.2 见证加工

```
【文字加工】
├─ 保留原意，不篡改
├─ 精简：从500字精简到100字（用于不同场景）
├─ 加粗：关键词加粗
├─ 配图：客户头像+公司LOGO（如有授权）
└─ 出处：署名+职位+公司

【视频加工】
├─ 剪辑：从30分钟剪辑到3-5分钟
├─ 字幕：加字幕（方便静音观看）
├─ 片头：统一片头（满意解LOGO+主题）
├─ 片尾：CTA（"了解更多，访问..."）
├─ 背景音乐：轻音乐
├─ 封面：客户照片+金句
└─ 格式：横屏（16:9）+竖屏（9:16）

【案例加工】
├─ 标题：吸引人（"从冲突到协作：XX科技的合伙人破局之路"）
├─ 结构：背景→问题→解决→成果→心得
├─ 配图：客户照片、公司照片、数据图表
├─ 数据：尽量量化（"决策效率提升50%"）
├─ 金句：提炼客户原话
└─ CTA："如果你也遇到类似问题..."

【数据加工】
├─ 图表：用图表展示前后对比
├─ 可视化：柱状图、折线图、雷达图
├─ 来源：标注数据来源
└─ 解读：简单解读数据含义
```

```
├─ 形式：PDF案例集、视频二维码
├─ 数量：按行业/场景准备3-5条

└─ 更新：每季度更新

【场景3：内容营销】
├─ 位置：公众号、小红书、知乎
├─ 形式：案例文章、用户故事、金句海报
├─ 数量：每周1-2条

├─ 位置：信息流广告、朋友圈广告
├─ 形式：短视频、图文
├─ 数量：每月2-3条
├─ 选择：3-5秒抓住眼球
└─ 更新：每月更新

├─ 位置：学员群、朋友圈
├─ 形式：截图、转发、口碑传播

```

### 3.2 使用规范

```
【授权规范】
├─ 必须获得客户书面/口头授权
├─ 明确使用范围（官网/销售/广告/社群）
├─ 明确署名方式（实名/匿名/公司名）
├─ 客户可随时要求撤回
└─ 违反后果：停止使用+道歉

【真实性规范】
├─ 不得篡改客户原意
├─ 不得编造见证
├─ 不得PS截图
├─ 不得购买假评价
└─ 违反后果：品牌信誉受损

【隐私规范】
├─ 敏感信息打码（金额、人数等）
├─ 未经同意不公开客户联系方式
├─ 匿名见证不透露身份信息
└─ 遵守《个人信息保护法》

【更新规范】
├─ 见证有有效期（建议2年）
├─ 过时见证及时下架
├─ 客户公司发生重大变化时复核
└─ 保持见证库的新鲜度
```

---

> **核心原则**：
> 见证不是"装饰"，是"证据"。
>
> 好的见证：
> ├─ 真实（用户真实感受）
> ├─ 具体（有细节、有数字）
> ├─ 可信（有姓名、有公司）
> └─ 相关（目标客户能共鸣）
>
> 满意解的见证信仰：
> "让用户的声音，成为最好的销售。"
