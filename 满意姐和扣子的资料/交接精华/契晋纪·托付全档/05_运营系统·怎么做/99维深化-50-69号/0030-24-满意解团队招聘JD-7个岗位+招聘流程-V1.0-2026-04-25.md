## 招聘流程

```
【标准流程】

Step 1: 简历筛选（1-3天）
├─ HR初筛
├─ 部门复筛
└─ 通知面试

Step 2: 初试（30分钟）
├─ HR面试
├─ 了解基本情况
├─ 考察文化匹配
└─ 介绍公司

Step 3: 复试（60分钟）
├─ 部门负责人面试
├─ 专业能力考察
├─ 项目经验深挖
└─ 案例/作业（如需）

Step 4: 终试（30分钟）
├─ Egbertie面试
├─ 价值观匹配
├─ 职业规划
└─ 薪资谈判

Step 5: Offer（1-3天）
├─ 发放Offer
├─ 背景调查
├─ 确认入职
└─ 入职准备

Step 6: 入职（Day 1）
├─ 欢迎仪式
├─ 入职培训
├─ 导师分配
├─ 工作环境
└─ 首日任务

【时间线】
├─ 简历到Offer：2-3周
├─ Offer到入职：2-4周
└─ 总计：1-2个月
```

> **核心原则**：
> 招聘不是"填坑"，是"找伙伴"。
>
> 满意解的招聘标准：
> ├─ 能力匹配（能做事）
> ├─ 文化匹配（能同行）
> ├─ 潜力匹配（能成长）
> └─ 价值匹配（能共创）
>
> 我们不找"员工"，找"合伙人"。
