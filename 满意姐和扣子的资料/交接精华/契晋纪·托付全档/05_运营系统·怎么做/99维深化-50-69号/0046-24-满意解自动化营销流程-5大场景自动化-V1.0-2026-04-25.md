# 满意解自动化营销流程 V1.0

> **编制时间**: 2026-04-25
> **编制者**: 满意姐（SAT-001）+ 蓝军 Skeptor-7
> **用途**: 自动化用户培育、转化、复购
> **原则**: 触发式、个性化、可追踪
> **目标**: 自动化贡献30%的转化，节省50%运营时间
> **配套**: 邮件营销序列（维度57）+ 数据分析仪表盘（维度52）

---

## 使用说明

```
🤖 满意解自动化营销流程 —— "让营销自动跑"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

为什么需要自动化营销？
因为"手工营销"不可持续。

手工营销的问题：
├─ 漏发：忘记给某个用户发消息
├─ 错发：发给不合适的人
├─ 慢发：用户已经凉了才发
├─ 累：运营团队疲于奔命
└─ 贵：需要大量人力

自动化营销：
├─ 触发式：用户做了什么，自动响应
├─ 个性化：根据用户行为发不同内容
├─ 及时：秒级响应
├─ 省力：一次配置，持续运行
└─ 可追踪：每个环节的数据都清楚

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

自动化场景：
1. 新用户培育（注册→激活→付费）
2. 付费用户关怀（学习→复购→推荐）
3. 沉睡用户召回（30天/60天/90天）
4. 生日/节日关怀
5. 行为触发（浏览未购买、测评未完成）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 第一部分：新用户培育流程

### 1.1 注册→激活流程

```
【触发条件】用户注册成功

Day 0（注册后即时）
├─ 渠道：邮件+短信+公众号
├─ 内容：欢迎消息+测评链接
├─ CTA："花5分钟做测评，看清你的合伙人关系"
└─ 目标：完成首次测评

Day 1（注册后24小时）
├─ 触发：未完成测评
├─ 渠道：邮件+短信
├─ 内容："Hi，测评还在等你"
├─ 激励："完成测评送50积分"
└─ 目标：催促完成测评

Day 3（注册后72小时）
├─ 触发：已完成测评
├─ 渠道：邮件+公众号
├─ 内容：测评结果解读+个性化推荐
├─ CTA："根据你的测评结果，推荐你学习..."
└─ 目标：引导学习/购买

Day 7（注册后7天）
├─ 触发：未付费
├─ 渠道：邮件+短信
├─ 内容：案例故事+限时优惠
├─ CTA："本周特价，CDA初级立减200"
└─ 目标：促进首次付费

Day 14（注册后14天）
├─ 触发：仍未付费
├─ 渠道：邮件
├─ 内容：深度内容（合伙人冲突成本计算）
├─ CTA："看看不解决的代价"
└─ 目标：教育用户，建立认知

Day 30（注册后30天）
├─ 触发：仍未付费
├─ 渠道：邮件+短信
├─ 内容：最后机会+大额优惠
├─ CTA："本月最后机会，立减500"
└─ 目标：最后转化尝试

【如果付费了】
→ 转入"付费用户关怀流程"

【如果仍未付费】
→ 转入"沉睡用户流程"
```

## 第五部分：技术实现

### 5.1 工具选型

```
【方案A：轻量级（初创期）】
├─ 邮件：Mailchimp（免费版）
├─ 短信：腾讯云短信
├─ 公众号：微信公众平台（自带自动化）
├─ CRM：飞书多维表格
├─ 触发：手动或简单脚本
├─ 成本：<500元/月
└─ 适用：<1000用户

【方案B：中量级（成长期）】
├─ 邮件+短信+微信：ConvertKit / Mailchimp
├─ CRM：HubSpot（免费版）/ 有赞
├─ 自动化：Zapier / Make
├─ 数据分析：Google Analytics
├─ 成本：<2000元/月
└─ 适用：1000-10000用户

【方案C：重量级（成熟期）】
├─ 全渠道营销自动化：Marketo / HubSpot / Salesforce
├─ CDP：Segment / Tealium
├─ 数据分析：Amplitude / Mixpanel
├─ AI个性化：Dynamic Yield / Optimizely
├─ 成本：>10000元/月
└─ 适用：>10000用户

【满意解当前建议】
├─ 阶段：初创期→成长期
├─ 选型：方案B（ConvertKit + HubSpot + Zapier）
├─ 预算：<2000元/月
├─ 时间：2周搭建
└─ 目标：覆盖核心场景，可扩展
```

### 5.2 自动化规则配置

```
【规则1：新用户欢迎】
触发：注册成功
条件：无
动作：
  ├─ 发送欢迎邮件（延迟0分钟）
  ├─ 发送测评链接（延迟0分钟）
  └─ 打标签：新用户

【规则2：测评催促】
触发：注册后24小时
条件：未完成测评
动作：
  ├─ 发送催促邮件
  └─ 打标签：待激活

【规则3：付费转化】
触发：完成测评
条件：未付费
动作：
  ├─ 发送个性化推荐（延迟0分钟）
  ├─ 发送案例故事（延迟3天）
  └─ 发送限时优惠（延迟7天）

【规则4：学习关怀】
触发：购买课程
条件：无
动作：
  ├─ 发送学习指南（延迟0分钟）
  ├─ 进度提醒（延迟7天，如果进度<30%）
  └─ 结业祝贺（课程完成后）

【规则5：沉睡召回】
触发：30天无互动
条件：无
动作：
  ├─ 发送召回邮件
  └─ 打标签：沉睡用户

【规则6：推荐激励】
触发：课程完成
条件：NPS>=9
动作：
  ├─ 发送推荐邀请
  ├─ 发放推荐工具包
  └─ 打标签：推荐者
```

> **核心原则**：
> 自动化不是"骚扰"，是"服务"。
>
> 好的自动化：
> ├─ 在用户需要时出现
> ├─ 提供有价值的内容
> ├─ 尊重用户选择（可随时退订）
> └─ 让人感觉"被关心"而非"被营销"
>
> 满意解的自动化信仰：
> "在正确的时间，给正确的人，发正确的内容。"
