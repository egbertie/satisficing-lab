# SPM-025: 卡牌游戏的多场景适配——一对一/小组/异步/混合模式

> **作者**: 满意解研究所 · Egbertie团队
> **日期**: 2026-04-22
> **分类**: 教学设计 · 场景适配 · 混合学习
> **关键词**: 卡牌游戏; 场景适配; 一对一; 小组; 异步; 混合模式**

---

## 摘要

决策卡牌游戏的价值不仅在于内容设计，更在于场景适配。本文基于教学设计理论（Instructional Design Theory）和混合学习理论（Blended Learning Theory），系统分析决策卡牌游戏在四种交付场景中的应用模式：一对一教练、小组工作坊、异步自学和混合模式。研究提出"场景-目标-卡牌类型"匹配矩阵，为每种场景设计最优的卡牌组合、流程和时间配置。本文还探讨了不同场景的边际成本与效果曲线，为满意解研究所的产品定价和交付策略提供决策依据。

**关键词**: 卡牌游戏; 场景适配; 一对一; 小组; 异步; 混合模式

---

## 1. 引言

同一套卡牌，在不同场景中发挥的作用截然不同。

- 一对一教练：深度探索个人决策模式
- 小组工作坊：模拟团队决策动态
- 异步自学：自主学习，灵活安排
- 混合模式：线上线下融合，最大化效果

本文的核心问题：如何让一套卡牌适配多种场景？

---

## 2. 四种场景的特征分析

### 2.1 一对一教练

**特征**：
- 深度：★★★★★
- 互动：★★★★☆
- 规模：1教练 + 1学员
- 成本：高（教练时间）

**卡牌功能**：
- 个人决策风格诊断
- 深度冲突场景探索
- 个人化反馈和行动计划

**流程设计**：
```
1. 诊断（15分钟）：抽取5张卡牌，识别个人决策倾向
2. 探索（30分钟）：抽取3个冲突场景，深度分析
3. 反馈（10分钟）：教练反馈 + 记录
4. 行动（5分钟）：制定个人行动计划
```

### 2.2 小组工作坊

**特征**：
- 深度：★★★☆☆
- 互动：★★★★★
- 规模：6-12人
- 成本：中（分摊成本）

**卡牌功能**：
- 团队决策动态模拟
- 角色扮演和换位思考
- 团队决策规范建立

**流程设计**：
```
1. 破冰（10分钟）：每人抽取1张"自我认知卡"
2. 场景模拟（40分钟）：抽取2个冲突场景，分组讨论
3. 反馈分享（20分钟）：各组分享 + 引导总结
4. 规范建立（10分钟）：团队决策规范共识
```

### 2.3 异步自学

**特征**：
- 深度：★★★☆☆
- 互动：★★☆☆☆
- 规模：不限
- 成本：低（边际成本趋零）

**卡牌功能**：
- 基础知识学习
- 自我诊断
- 案例探索

**流程设计**：
```
线上平台
├── 模块1：五路图腾基础（视频+卡牌互动）
├── 模块2：12类型冲突识别（自测+反馈）
├── 模块3：决策模拟（卡牌游戏+AI反馈）
└── 模块4：个人报告生成
```

### 2.4 混合模式

**特征**：
- 深度：★★★★☆
- 互动：★★★★☆
- 规模：灵活
- 成本：中高

**卡牌功能**：
- 线上学习基础
- 线下深度实践
- 持续跟踪反馈

**流程设计**：
```
Phase 1（线上，1周）：基础知识 + 自我诊断
Phase 2（线下，1天）：工作坊深度训练
Phase 3（线上，4周）：持续练习 + AI反馈
Phase 4（线下，半天）：复盘 + 进阶
```

## 7. 结论

一套好的卡牌，应该像瑞士军刀——在不同场景中发挥不同功能。场景适配不是"降级"或"简化"，而是"精准匹配"。

对于满意解研究所，这意味着：
- **产品线化**：基于场景开发不同产品形态
- **模块化设计**：卡牌可以组合为不同"套餐"
- **效果追踪**：不同场景的效果需要分别验证
