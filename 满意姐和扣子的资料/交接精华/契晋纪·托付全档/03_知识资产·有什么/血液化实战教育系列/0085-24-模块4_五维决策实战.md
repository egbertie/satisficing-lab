# 模块4：五维决策实战

> **核心命题**: 决策不是"选A还是选B"，是"五个维度同时扫描"——土金水木火，缺一不可
> **血液化资产**: 大学课程15章、五路图腾、科研论文集SPM-005
> **适用对象**: 创始人、合伙人、任何需要做复杂决策的人

---

## 一、核心理念

### 1.1 为什么传统决策框架不够用？

| 传统框架 | 局限 | 五维框架的优势 |
|:---------|:-----|:---------------|
| SWOT | 太宏观，不具体 | 五维具体到人格维度 |
| 决策树 | 假设信息完备 | 五维承认有限理性 |
| 加权打分 | 容易锚定 | 五维动态平衡 |
| 直觉判断 | 缺乏结构 | 五维结构+直觉结合 |
| 数据分析 | 忽略伦理 | 五维包含伦理维度 |

### 1.2 五维框架的本质

```
五维不是五个独立的维度，是一个动态平衡的系统:

土·信义（根基） → 金·标尺（边界） → 水·觉察（流动） → 木·伦理（生长） → 火·顿悟（突破）
     ↓                  ↓                  ↓                  ↓                  ↓
  品德评估          决策分析           定力/洞察          伦理判断           行动转化
     ↓                  ↓                  ↓                  ↓                  ↓
  信任优先          满意解标准         情绪不被劫持        团队伦理           压力中淬火
```

**关键洞察**: 五维不是"打分后选最高的"，是"五个维度都要及格，短板决定成败"。

## 二、血液化前 vs 血液化后

| 维度 | 血液化前（传统决策） | 血液化后（五维决策） |
|:-----|:---------------------|:---------------------|
| 决策依据 | 单一维度（如ROI） | 五维同时扫描 |
| 信息假设 | 假设信息完备 | 承认有限理性 |
| 情绪处理 | 忽略或压抑 | 水·觉察：0.3秒停 |
| 伦理考量 | 事后补救 | 木·伦理：前置检查 |
| 信任评估 | 凭感觉 | 土·信义：信义账户系统 |
| 边界设定 | 追求最优 | 金·标尺：满意解即可 |
| 行动转化 | 分析 paralysis | 火·顿悟：跟着心走 |
| 复盘方式 | 成败归因 | 五维回溯：哪一维失衡？ |

## 三、操作步骤

### Step 1: 理解五维的定义与机制

**土·信义（根基）**
```
定义: 合伙人之间的信任根基，隐性记账系统
机制:
  - 存入: 兑现承诺、诚实沟通、关键时刻在场
  - 支取: 请求帮助、临时变更、容错空间
  - 透支: 反复失信、隐瞒信息、背后议论
  - 破产: 信任崩塌，关系不可修复
  - 修复: 承认错误、持续行动、时间验证

训练方法:
  - 每日一信: 今天做了什么存入信义账户？
  - 信义账户系统: 定期评估余额
  - 关键时刻记录: 谁在关键时刻可靠？
```

**金·标尺（边界）**
```
定义: 满意解的边界科学，有限理性下的决策程序
机制:
  - 信息边界: 到什么信息量可以决策？
  - 时间边界: 到什么时间点必须决策？
  - 资源边界: 到什么投入度可以停止？
  - 标准边界: 到什么水平算"满意"？

核心公式: 满意解 = 足够好即可 ≠ 最优解

训练方法:
  - 设定满意解标准: 事前定义"做到什么程度算满意"
  - 30%换80%: 寻找最小投入换最大产出的路径
  - 边界检查: 决策前问自己"边界在哪里？"
```

**水·觉察（流动）**
```
定义: 认知觉察的神经科学，情绪不被劫持
机制:
  - 0.3秒停: 情绪触发时，0.3秒内暂停反应
  - 觉察标签: "我现在感到..."（命名情绪）
  - 身体扫描: 觉察身体信号（心跳、呼吸、肌肉）
  - 第三方视角: "如果我是旁观者，会怎么看？"

训练方法:
  - 每日觉察练习: 5分钟正念冥想
  - 情绪日志: 记录情绪触发点
  - 神经反馈训练: 脑电波监测（进阶）
```

**木·伦理（生长）**
```
定义: 儒商伦理的决策锚点，五常伦理
机制:
  - 仁: 利他与利己的平衡
  - 义: 该做与能做的边界
  - 礼: 程序正义与结果正义
  - 智: 知情权与决策权
  - 信: 承诺与兑现

训练方法:
  - 伦理自检: 决策前过五常检查
  - 伦理对话: 与合伙人讨论伦理边界
  - 伦理案例: 学习经典伦理困境
```

**火·顿悟（突破）**
```
定义: 压力中的创造性突破，直觉与行动的转化
机制:
  - 临界点: 信息+压力+时间→顿悟
  - 心流状态: 完全投入，时间感消失
  - 行动转化: 顿悟后立即行动，不犹豫
  - 淬火效应: 压力越大，突破越深刻

训练方法:
  - 压力测试: 在可控压力下做决策
  - 心流触发: 找到让自己进入心流的活动
  - 顿悟记录: 记录顿悟时刻的条件和结果
```

### Step 2: 使用五维扫描表

**1分钟版（紧急决策）**:
```
□ 土·信义: 这个人/团队的信任根基如何？
□ 金·标尺: 我的满意解标准是什么？
□ 水·觉察: 我现在情绪稳定吗？
□ 木·伦理: 这个决策符合五常吗？
□ 火·顿悟: 我的直觉告诉我什么？

→ 5个□都通过 → 决策
→ 任一□不通过 → 暂停，深入分析
```

**3分钟版（常规决策）**:
```
土·信义:
  □ 信义账户余额: 正/负/零？
  □ 关键时刻表现: 可靠/一般/不可靠？
  □ 诚实频率: 高/中/低？

金·标尺:
  □ 信息量: 足够/不足？
  □ 满意解标准: 已定义/未定义？
  □ 边界: 清晰/模糊？

水·觉察:
  □ 情绪状态: 平静/波动/激动？
  □ 0.3秒停: 已执行/未执行？
  □ 身体信号: 正常/紧张？

木·伦理:
  □ 仁义: 平衡/失衡？
  □ 程序正义: 符合/不符合？
  □ 知情权: 已告知/未告知？

火·顿悟:
  □ 直觉: 清晰/模糊/矛盾？
  □ 心流: 可能/不可能？
  □ 行动 readiness:  ready/ not ready？
```

### Step 3: 五维动态平衡

```
五维不是静态打分，是动态平衡:

示例: 合伙人决策
  土·信义 高 + 金·标尺 中 + 水·觉察 低 + 木·伦理 高 + 火·顿悟 中
  → 短板: 水·觉察低（情绪可能干扰）
  → 对策: 先执行0.3秒停，再做决策

示例: 战略方向选择
  土·信义 中 + 金·标尺 高 + 水·觉察 高 + 木·伦理 中 + 火·顿悟 低
  → 短板: 火·顿悟低（缺乏行动力）
  → 对策: 小步快跑，先试点再推广

关键: 不是"选总分最高的"，是"补短板"。
```

### Step 4: 13类型冲突的五维映射

```
Type01 创始人过度干预:
  土·信义 ↓（信任不足）
  金·标尺 ↓（边界不清）
  水·觉察 ↑（创始人觉察过度）
  → 干预: 重建信义 + 明确边界

Type07 技术合伙人退出:
  土·信义 ↓↓（信任崩塌）
  木·伦理 ↓（退出方式）
  火·顿悟 ↓（缺乏突破方案）
  → 干预: 信义账户修复 + 伦理对话 + 寻找顿悟点

Type12 外部压力型冲突:
  金·标尺 ↓（外部标准入侵）
  木·伦理 ↓（外部伦理压力）
  水·觉察 ↓（被外部情绪劫持）
  → 干预: 重建标尺 + 伦理坚守 + 觉察恢复
```

## 六、常见误区

| 误区 | 表现 | 后果 | 纠正 |
|:-----|:-----|:-----|:-----|
| 五维=打分选最高 | 总分最高就选 | 忽略短板 | 看短板，不是看总分 |
| 只用一个维度 | "只要信任就行" | 其他维度失控 | 五个维度都要扫描 |
| 静态评估 | 扫描一次就决策 | 动态变化未捕捉 | 重大决策前复扫 |
| 忽视水·觉察 | "我很理性" | 情绪劫持 | 0.3秒停必须执行 |
| 忽视木·伦理 | "先赚钱再说" | 伦理危机 | 前置伦理检查 |
| 追求火·顿悟 | "等灵感来了再行动" | 分析paralysis | 满意解即可，不必顿悟 |
| 土·信义=直觉 | "我感觉他靠谱" | 被表象欺骗 | 信义账户量化评估 |
| 金·标尺=妥协 | "差不多就行" | 标准过低 | 满意解是边界科学 |
| 五维=算命 | 过度解读 | 迷信框架 | 框架是工具，不是真理 |
| 不复盘 | 决策后不回顾 | 无法改进 | 建立五维决策日志 |

## 七、真实案例

### 案例1: "合伙人突然要退出"——五维扫描实战

**背景**: 技术合伙人突然要求退出，创始人慌乱。

**五维扫描**:
```
土·信义: 8/20（信义账户严重透支）
  → 原因: 近期多次承诺未兑现
  → 判断: 信任根基已受损

金·标尺: 12/20（边界不清）
  → 原因: 退出条款未明确
  → 判断: 需要法律边界

水·觉察: 10/20（情绪激动）
  → 原因: 创始人感到被背叛
  → 判断: 需要0.3秒停

木·伦理: 15/20（伦理底线未触碰）
  → 原因: 合伙人未做不道德之事
  → 判断: 可以体面分手

火·顿悟: 10/20（缺乏突破方案）
  → 原因: 慌乱中看不到出路
  → 判断: 需要时间冷静
```

**短板**: 土·信义最低（信任崩塌），水·觉察次低（情绪干扰）

**对策**:
1. 执行0.3秒停（水·觉察）
2. 启动信义账户修复对话（土·信义）
3. 明确退出条款法律边界（金·标尺）
4. 保持伦理底线，体面分手（木·伦理）
5. 给自己时间找顿悟点（火·顿悟）

**结果**: 3周后，创始人在冷静状态下找到了新的技术合伙人，决策质量显著提升。

### 案例2: "是否启动Z世代方向"——战略五维决策

**背景**: 奔月计划八方向中，方向②Z世代是否值得启动？

**五维扫描**:
```
土·信义: 12/20（团队对Z世代的理解有限）
金·标尺: 15/20（信息基本完备，但满意度不确定）
水·觉察: 14/20（创始人对Z世代有直觉好感，但可能偏误）
木·伦理: 16/20（不涉及伦理风险）
火·顿悟: 8/20（缺乏突破性的执行方案）
```

**短板**: 火·顿悟最低（缺乏行动力），土·信义次低（团队不匹配）

**Egbertie决策**: "先不启动Z世代。储备池放着，等团队成熟或顿悟到来。"

**教训**: 五维扫描帮助Egbertie看到了"直觉好感"背后的"火·顿悟不足"，避免了冲动决策。
