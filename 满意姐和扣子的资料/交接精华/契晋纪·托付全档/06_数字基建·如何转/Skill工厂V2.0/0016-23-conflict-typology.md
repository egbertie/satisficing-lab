# 13-Type Conflict Typology

## Overview

The 13-type typology maps all partnership conflicts to the Five Totems framework. 
Each type has: symptoms, affected dimensions, severity, and intervention strategy.

## Type 01: 愿景分歧 (Vision Divergence)

**Symptoms**: Different long-term goals, divergent market views, incompatible exit strategies
**Affected Totems**: 土(moderate), 金(high), 水(low)
**Severity**: 🟡 Medium
**Intervention**: 金·司马贺 — Set satisficing thresholds for shared goals; if irreconcilable, structured separation

## Type 02: 股权分配 (Equity Distribution)

**Symptoms**: Disputes over ownership %, contribution valuation disagreements, vesting conflicts
**Affected Totems**: 金(high), 土(moderate)
**Severity**: 🟡 Medium
**Intervention**: 金·司马贺 — Apply dynamic equity frameworks; use objective contribution metrics

## Type 03: 控制权争夺 (Control Struggle)

**Symptoms**: Decision deadlock, authority overlap, CEO power fights
**Affected Totems**: 金(high), 木(moderate), 土(moderate)
**Severity**: 🔴 High
**Intervention**: 木·孔子 — Define decision rights matrix; establish governance rituals

## Type 04: 信任破裂 (Trust Breach)

**Symptoms**: Secrecy, broken promises, verification demands escalating
**Affected Totems**: 土(critical), 水(high)
**Severity**: 🔴 High
**Intervention**: 土·刘禹锡 — Trust repair protocol; if irreparable, dignified separation

## Type 05: 资源分配 (Resource Allocation)

**Symptoms**: Budget fights, personnel disputes, priority conflicts
**Affected Totems**: 金(high), 土(moderate)
**Severity**: 🟡 Medium
**Intervention**: 金·司马贺 — Transparent resource allocation criteria; satisficing budget model

## Type 06: 退出路径 (Exit Path)

**Symptoms**: Different timelines for exit, valuation disagreements, buyer vs builder conflict
**Affected Totems**: 金(high), 土(high)
**Severity**: 🟡 Medium
**Intervention**: 金·司马贺 — Pre-negotiate exit triggers and valuation methods; write it into charter

## Type 07: 角色模糊 (Role Ambiguity)

**Symptoms**: Overlapping responsibilities, "not my job" syndrome, accountability gaps
**Affected Totems**: 木(high), 金(moderate)
**Severity**: 🟡 Medium
**Intervention**: 木·孔子 — RACI matrix + role definition ceremony

## Type 08: 文化冲突 (Culture Clash)

**Symptoms**: Different work styles, communication breakdowns, values misalignment
**Affected Totems**: 土(high), 木(high), 水(moderate)
**Severity**: 🟡 Medium
**Intervention**: 土·刘禹锡 + 木·孔子 — Culture mapping + shared values articulation

## Type 09: 能力不匹配 (Capability Mismatch)

**Symptoms**: One partner outpacing others, skill gaps creating dependency, imposter syndrome
**Affected Totems**: 金(high), 水(moderate)
**Severity**: 🟡 Medium
**Intervention**: 金·司马贺 — Honest capability assessment; training plan or graceful transition

## Type 10: 外部压力 (External Pressure)

**Symptoms**: Investor conflicts, market downturn stress, regulatory pressure dividing partners
**Affected Totems**: 水(high), 土(moderate)
**Severity**: 🟡 Medium
**Intervention**: 水·观自在 — Stress testing; scenario planning; collective resilience building

## Type 11: 家庭介入 (Family Intrusion)

**Symptoms**: Spouse conflicts, family business dynamics, inheritance disputes
**Affected Totems**: 土(critical), 木(high)
**Severity**: 🔴 High
**Intervention**: 土·刘禹锡 — Family governance protocol; clear boundaries between family and business

## Type 12: 道德/法律风险 (Ethical/Legal Risk)

**Symptoms**: Compliance violations, ethical gray zones, legal exposure concerns
**Affected Totems**: 木(critical), 土(high)
**Severity**: 🔴 High
**Intervention**: 木·孔子 — Immediate ethical audit; legal review; if confirmed, separation may be mandatory

## Type 13: 心理契约违背 (Psychological Contract Breach)

**Symptoms**: Unspoken expectations violated, feeling betrayed without formal breach, emotional withdrawal
**Affected Totems**: 土(critical), 水(high), 火(moderate)
**Severity**: 🔴 High
**Intervention**: 土·刘禹锡 + 水·观自在 — Surface unspoken expectations; facilitated dialogue; rebuild psychological safety

## Conflict Severity Matrix

| Severity | Criteria | Response |
|----------|----------|----------|
| 🔴 High | 3+ dimensions affected OR emotional damage present OR 土≤3 | Freeze; structured intervention; possible separation |
| 🟡 Medium | 2 dimensions affected OR trust breach suspected | Active mediation; framework application |
| 🟢 Low | 1 dimension affected; contained | Monitor; preventive measures |

## Five Totem Intervention Mapping

| Totem | Intervenes On | Method |
|-------|--------------|--------|
| 土·刘禹锡 | Trust issues, relationship repair | Rebuilding integrity, transparency rituals |
| 金·司马贺 | Structural conflicts (equity, control, resources) | Objective metrics, satisficing frameworks |
| 水·观自在 | Emotional turmoil, stress, awareness gaps | Mindfulness, 0.3-second pause, de-escalation |
| 木·孔子 | Ethical violations, role confusion, governance | Rituals, rules, five virtues application |
| 火·六祖慧能 | Stuck conflicts, creative blocks, breakthrough needs | Intuitive leap, pattern interruption, awakening |

## Diagnostic Flow

1. Identify symptoms → Match to type
2. Map to affected totems → Determine severity
3. Apply primary totem intervention → Set timeline
4. Check for escalation triggers → Decide: contain / mediate / separate
