## 三、核心工具使用说明

### 工具1：合伙人匹配引擎（partner_matcher.py）

**这是干什么用的？**
> 输入一个合伙人的信息，系统从5个维度给你打分，告诉你这个人适不适合。

**怎么用？**

```python
# 打开文件：demo_partner_match.py（我们准备好的示例）

# 第1步：导入工具
from partner_matcher import PartnerMatcher, PartnerCandidate

# 第2步：创建匹配引擎（就像打开一个App）
matcher = PartnerMatcher()

# 第3步：输入合伙人信息（就像填问卷）
candidate = PartnerCandidate(
    id="001",
    name="张三",
    attributes={
        "ability_tech": 8.5,      # 技术能力：8.5分
        "ability_business": 7.0,   # 商业能力：7分
        "ethics_score": 9.0,       # 伦理评分：9分
        "trust_score": 7.5,        # 信任评分：7.5分
        "intuition_match": 8.0     # 直觉匹配：8分
    },
    risk_factors={
        "financial_risk": 0.3,     # 财务风险：30%
        "reputation_risk": 0.1     # 声誉风险：10%
    },
    ethics_evidence={
        "仁义": [{"type": "事实", "desc": "曾帮助前合伙人度过难关", "confidence": 0.9}]
    },
    intuition_signals=[{"type": "正面", "description": "第一次见面感觉很好"}]
)

# 第4步：运行评估（就像点击"开始测评"按钮）
result = matcher.comprehensive_match(candidate)

# 第5步：看结果
print(f"综合评分：{result['total_score']}/100")
print(f"建议：{result['recommendation']}")
```

**运行结果示例：**
```

📊 前景理论评估...
📊 儒商伦理评估...

### 工具2：儒商伦理十观评估器（confucian_ethics_assessor.py）

**这是干什么用的？**
> 从10个儒家伦理维度评估一个人或企业。
> 比如：他是不是讲诚信？有没有社会责任感？ leadership怎么样？

**怎么用？**

```python
# 导入工具
from confucian_ethics_assessor import ConfucianEthicsAssessor

# 创建评估器
assessor = ConfucianEthicsAssessor(subject_name="李四")

# 输入10个维度的评分（每项1-10分）
scores = {
    "天人合一的发展观": 8,    # 企业发展和自然、社会和谐
    "知行合一的实践观": 7,    # 理论和实践结合
    "义利合一的价值观": 9,    # 道义和利益平衡
    "以人为本的管理观": 8,    # 关心员工成长
    "诚实守信的经营观": 9,    # 讲信用
    "经世济民的社会观": 7,    # 有社会责任感
    "协和万邦的世界观": 6,    # 开放合作
    "与时俱进的创新观": 8,    # 持续学习
    "洁身自好的廉洁观": 9,    # 廉洁自律
    "刚柔并济的领导观": 7     # 权威和关怀平衡
}

# 运行评估
result = assessor.assess(scores)

# 看结果
print(f"总评分：{result['total_score']}/100")
print(f"评级：{result['grade']}")
print("雷达图数据已生成，可粘贴到Excel制作图表")
```

**运行结果：**
```

评级：乙上（良好）

优势维度：
- 义利合一的价值观：9分 🌟
- 诚实守信的经营观：9分 🌟
- 洁身自好的廉洁观：9分 🌟

待改进维度：
- 协和万邦的世界观：6分（建议加强开放合作）

### 工具3：MCDA方法选择器（partner_mcda_selector.py）

**这是干什么用的？**
> 当你面对多个合伙人候选人，不知道选谁时，
> 这个工具帮你选择最合适的决策方法。

**怎么用？**

```python
from partner_mcda_selector import PartnerMCDASelector

# 创建选择器
selector = PartnerMCDASelector("我的合伙人选择")

# 描述你的情况（用True/False回答）
context = {
    "准则间可补偿": True,      # 某方面差可以用其他方面补
    "需明确权衡": True,        # 需要明确知道哪个更重要
    "决策者偏好清晰": True,   # 你清楚自己想要什么
    "大量方案": False,        # 候选人不多（<5个）
    "需要快速排序": True,     # 需要快速排出优先级
}

# 获取推荐
result = selector.recommend(context)

print(f"推荐方法：{result['recommended_method']}")
print(f"理由：{result['reason']}")
print(f"下一步：{result['next_steps']}")
```

**运行结果：**
```
推荐方法：AHP（层次分析法）

理由：
- 你的情况：准则间可补偿、需明确权衡、偏好清晰
- AHP方法：通过成对比较，帮你明确各维度权重
- 适合候选人数量少（<5个）的情况

下一步：
1. 列出所有评估维度（如：技术、商业、伦理、信任）
2. 两两比较，确定哪个更重要
3. 输入每位候选人的各维度评分
4. 系统自动计算最优选择

详细操作指南：
请查看文档《AHP方法操作手册-小白版.md》
```

### 工具4：风险扫描器（hardtech_partner_risk_scanner.py）

**这是干什么用的？**
> 扫描合伙人关系中的潜在风险点，提前预警。

**怎么用？**

```python
from hardtech_partner_risk_scanner import RiskScanner

# 创建扫描器
scanner = RiskScanner()

# 输入当前情况
situation = {
    "股权比例": {"你": 60, "合伙人": 40},
    "决策机制": "一人一票",
    "沟通频率": "每周1次",
    "冲突历史": ["2026-01-15 技术方向分歧"],
    "财务透明度": "部分透明",
    "退出条款": "无"
}

# 运行扫描
report = scanner.scan(situation)

# 看结果
print(f"风险等级：{report['risk_level']}")
print(f"发现 {len(report['risks'])} 个风险点：")
for risk in report['risks']:
    print(f"- {risk['type']}: {risk['description']} (建议：{risk['recommendation']})")
```

**运行结果：**
```
风险等级：🟡 中等风险

发现 3 个风险点：
- 决策权分歧：股权60:40但决策一人一票，易产生僵局
  建议：建立决策域划分（谁负责什么）

- 退出机制缺失：无退出条款
  建议：签署合伙协议，明确退出条件

- 沟通频率偏低：每周仅1次
  建议：重要决策前增加沟通频次

完整报告已生成：风险扫描报告_2026-04-24.md
```

## 五、常见问题（FAQ）

**Q1: 我完全不懂代码，能用吗？**
> 能！只需要：
> 1. 安装Python（像安装微信一样）
> 2. 下载代码包（像下载zip文件）
> 3. 运行示例文件（双击运行）
> 我们已经准备了 `一键运行.bat`（Windows）和 `一键运行.sh`（Mac）

**Q2: 运行报错怎么办？**
> 常见错误和解决方法：
> - "No module named 'xxx'" → 运行 `pip install xxx`
> - "Permission denied" → 在命令前加 `sudo`（Mac/Linux）
> - "File not found" → 检查文件路径是否正确
> 更多错误请查看《错误排查手册.md》

**Q3: 能导出Excel吗？**
> 能！每个工具都支持导出CSV/Excel：
> ```python
> result.to_csv("结果.csv", index=False)  # 导出CSV
> result.to_excel("结果.xlsx", index=False)  # 导出Excel
> ```

**Q4: 数据安全吗？**
> 所有数据处理都在你的本地电脑上进行，
> 不会上传到任何服务器。
> 你的合伙人信息，只有你自己能看到。

**Q5: 能用于商业用途吗？**
