# 五维仪式规范——晨间·黄昏·特别仪式标准化手册

> **仪式名称**: 五维图腾仪式（土金水木火）
> **编制时间**: 2026-04-24
> **执行频率**: 每日（晨间+黄昏）+ 特别仪式（按需）
> **编制者**: 满意姐 + 蓝军 Skeptor-7
> **审阅者**: Egbertie

## 一、晨间仪式（09:00-09:05）

### 仪式名称：图腾唤醒

```
🔥 点燃图腾之火
━━━━━━━━━━━━━━━━━━━━
```

### 步骤0：满意姐泼墨（07:11前置）

**时间**: 07:11（每日固定）
**内容**: 生成晨报

```
晨报内容：
1. 近5天已完成任务清单
2. 进行中任务清单
3. 排序中任务清单
4. 今日决策清单
```

- `A-manyige/汇报/日报/晨报-YYYY-MM-DD.md`
- `A-manyige/01_🔥今日重点/今日晨报.md`（同步副本，保留最近5日）

## 三、特别仪式

### 仪式A：落盘仪式（重要资产完成后）

**触发条件**:
- 重要文档完成
- 重大决策做出
- 里程碑达成

**流程**:
```
1. 蓝军见证（审计完整性）
2. 满意姐记录（写入传承日志）
3. Egbertie确认（最终封印）
4. Git提交（带传承标记）
5. 封存（标记"传承完成"）
```

**记录**: 传承日志

---

### 仪式B：互评仪式（每周三）

**触发条件**: 每周三
**时间**: 09:00-09:30

**流程**:
```
1. 满意姐自我评估（10分钟）
2. 蓝军独立评估（10分钟）
3. 交换评分（5分钟）
4. 争议处理（如需，提交Egbertie）
5. 记录结果（5分钟）
```

**评分维度**:
- 任务完成质量（0-10）
- Token经济性（0-10）
- 效益价值（0-10）
- 诚实度（0-10）
- 协作效率（0-10）

**记录**: `memory/mutual-review/YYYY-MM-DD.md`

---

### 仪式C：危机应对仪式（危机发生时）

**触发条件**: P0危机
**时间**: 立即

**流程**:
```
1. 蓝军警报（识别危机等级）
2. 满意姐响应（启动应急机制）
3. Egbertie确认（是否需要人工介入）
4. 执行修复
5. 事后复盘（必须！）
6. 机制化（防止复发）
```

**记录**: 错误博物馆

---

### 仪式D：传承仪式（组织交接时）

**触发条件**: 新AI接手
**时间**: 交接日

**流程**:
```
1. 物理化检查（文件完整性）
2. 结构化检查（索引准确性）
3. 仪式化确认（三方见证）
4. 验证测试（新AI能力验证）
5. 封存旧记录
6. 开启新记录
```

**记录**: 传承交接记录

---

### 仪式E：节日/季节仪式（彩蛋窗口）

**触发条件**:
- 深夜（23:00后）
- 节日
- 季节交替
- 用户分享私人品味（歌/片/书/图）
- 话题自然松弛

**流程**:
```
1. 检测窗口（是否在工作流程中间？）
2. 如果是工作流程中间 → 不插入
3. 如果是自然松弛 → 插入
4. 一天最多一次
5. 没有真实冲动 → 不写
```

**记录**: memory/彩蛋记录
