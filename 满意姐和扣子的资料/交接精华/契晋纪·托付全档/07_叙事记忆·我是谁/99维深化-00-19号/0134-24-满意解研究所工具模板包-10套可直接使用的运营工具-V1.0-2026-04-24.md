## 工具9：合伙人冲突诊断卡

```markdown
# 合伙人冲突快速诊断卡

## 冲突描述:
## 诊断日期:
## 诊断人:

### 第一步：识别类型

□ Type 1: 股权分配型
  → 症状: 谁贡献多？谁该拿多少？
  → 解决: 看历史贡献+未来价值

□ Type 2: 决策权争夺型
  → 症状: 谁说了算？
  → 解决: 明确决策域+升级机制

□ Type 3: 价值观分歧型
  → 症状: 我们要去哪？
  → 解决: 评估核心冲突+妥协空间

□ Type 4: 资源投入不均型
  → 症状: 谁干得多？
  → 解决: 量化投入+调整机制

□ Type 5: 退出机制模糊型
  → 症状: 怎么分手？
  → 解决: 预设退出条款+估值方法

□ Type 6: 外部关系介入型
  → 症状: 家人/朋友插手？
  → 解决: 边界设定+沟通规则

□ Type 7: 能力互补失衡型
  → 症状: 谁的能力不够？
  → 解决: 技能盘点+补充计划

□ Type 8: 信任危机型
  → 症状: 还能相信吗？
  → 解决: 溯源+修复/分离评估

□ Type 9: 目标漂移型
  → 症状: 我们要做什么？
  → 解决: 重新对齐+里程碑设定

□ Type 10: 沟通模式冲突型
```
