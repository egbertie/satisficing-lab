# 第一站 · 有为篇·治

> **来源**: 星月传奇·后记卷三三生万物  
> **核心问题**: 12类型冲突，何时需要全力干预？  
> **产出**: 12类型×有为决策树 + 五维全开干预清单  
> **原则**: 有为不是"用力过猛"，是"该用力时用力"

---

## 有为的定义

> "有为" = 当冲突的**破坏速度** > 组织**自愈速度**时，必须全力干预。

就像医生面对急诊病人——不是所有病都需要开刀，但大出血时必须立即手术。

**有为的判断标准**：
- 冲突已在消耗团队每日≥20%的精力
- 冲突已影响关键决策的推进
- 冲突已导致第三方（客户/投资人/团队）感知到异常
- 冲突一方已出现"退出"或"法律行动"的迹象

如果以上任一条件满足 → **进入有为模式**。

---

## 12类型 × 有为决策树

### 通用有为框架（适用于所有类型）

```
冲突发生
  ↓
评估：破坏速度 vs 自愈速度
  ↓
破坏速度 > 自愈速度？
  ├── 否 → 无为/无不为模式（见第二站/第三站）
  └── 是 → 有为模式启动
          ↓
    五维全开干预流程
          ↓
    ① 土·信义修复（紧急止血）
    ② 水·觉察恢复（麻醉镇痛）
    ③ 金·满意标尺（诊断定位）
    ④ 木·伦理对齐（手术方案）
    ⑤ 火·顿悟突破（康复治疗）
          ↓
    循环验证 → FIN
```

### 各类型有为细则

#### Type 01 愿景分歧 → 有为：「强制对齐」

**触发有为的条件**：
- 双方已开始各自向团队传达不同方向
- 投资人已表达担忧
- 关键员工开始"站队"

**有为干预**：
1. **土**：紧急召开合伙人闭门会议，明确"当前不对外释放任何方向信息"
2. **水**：会议前各做3分钟正念，确保觉察在线
3. **金**：用满意解标准评估——"如果必须今天选一个方向，哪个对团队伤害最小？"
4. **木**：对齐"我们如何定义'公司的最佳利益'"——不是"我的最佳利益"
5. **火**：如果无法共识 → 引入第三方顾问或董事会裁决（顿悟=接受外部视角）

**有为底线**：
- 愿景分歧不能无限拖延 → 设定 deadline（如：2周内必须对齐）
- 如果2周仍无法对齐 → 进入 Type 08（退出机制）有为流程

---

#### Type 02 角色模糊 → 有为：「强制边界」

**触发有为的条件**：
- 同一项工作两人同时在改，导致版本混乱
- 团队开始"不知道听谁的"
- 外部合作伙伴收到矛盾指令

**有为干预**：
1. **土**：紧急签署「角色边界协议」——不是讨论，是签署
2. **水**：双方承认"之前的模糊是我的责任"（各承担一部分）
3. **金**：用RACI表（Responsible/Accountable/Consulted/Informed）量化每个关键决策
4. **木**：对齐"越界的惩罚机制"——如：未经协商擅自决策，罚款或让权
5. **火**：设立「90天实验期」——边界不是永久的，先跑90天再优化

**有为底线**：
- 角色模糊不能靠"默契"解决 → 必须书面化
- 90天后如果边界不适配 → 进入无不为模式（本能调整）

---

#### Type 03 信任崩塌 → 有为：「强制修复」

**触发有为的条件**：
- 出现背叛行为（私下接触投资人/泄露信息/挪用资金）
- 一方已启动法律程序
- 双方已停止直接沟通

**有为干预**：
1. **土**：背叛方必须立即做三件事——书面道歉、具体修复行动、预防机制
2. **水**：被背叛方需要表达感受（不是指责，是"我因为X感到Y"）
3. **金**：评估修复可能性——"这个信任裂缝，是否还在满意解修复区间内？"
4. **木**：对齐"什么样的行为是不可接受的"——写入协议
5. **火**：如果修复失败 → 体面退出流程（见Type 08有为）

**有为底线**：
- 信任崩塌是有为中最紧急的 → 必须在72小时内启动干预
- 如果72小时双方都不愿修复 → 默认进入退出流程

---

#### Type 04 利益分配 → 有为：「强制量化」

**触发有为的条件**：
- 双方对"公平"的定义完全冲突
- 一方已拒绝继续投入（时间/资金/资源）
- 外部审计/投资人要求明确分配方案

**有为干预**：
1. **土**：双方先列出"过去6个月各自的具体贡献"（用事实替代感觉）
2. **水**：承认"公平是主观的，满意解是客观的"
3. **金**：用「贡献量化表」打分（时间/资金/资源/人脉/决策质量等维度）
4. **木**：对齐"未来分配的调整机制"——不是一次性，是动态
5. **火**：如果仍无法满意解 → 引入第三方评估（如：共同信任的会计/顾问）

**有为底线**：
- 利益分配必须在30天内解决 → 拖延会 exponential 损耗信任
- 如果30天仍无法解决 → 进入Type 08（退出机制）有为

---

#### Type 05 决策僵局 → 有为：「强制破题」

**触发有为的条件**：
- 关键决策已拖延超过决策周期的50%（如：应在1周内决定，已拖3周）
- 团队已开始"绕过合伙人"自行决策
- 客户/投资人已催促

**有为干预**：
1. **土**：明确"谁有最终决定权"——如果之前没有约定，现在必须约定
2. **水**：双方承认"僵局本身正在造成损害"
3. **金**：用「决策影响表」量化——拖延每天的成本是多少？
4. **木**：对齐"如果我们是共同CEO，如何设计决策机制？"
5. **火**：如果仍无法破题 → 掷骰子/抛硬币（满意解=不完美的决定 > 完美的拖延）

**有为底线**：
- 决策僵局必须在48小时内破题 → 拖延越久，选项越少
- 掷骰子不是玩笑 → 是接受"没有最优解"的顿悟

---

#### Type 06 沟通断裂 → 有为：「强制破冰」

**触发有为的条件**：
- 双方已超过72小时没有直接沟通
- 所有沟通通过第三方转达
- 团队已感知到"合伙人之间有问题"

**有为干预**：
1. **土**：一方（任意一方）必须主动发起直接沟通——"我有话想当面说"
2. **水**：破冰前先做3分钟正念，确保不是"带着炸弹去"
3. **金**：设定破冰目标——"今天不是要解决所有问题，只是恢复对话"
4. **木**：对齐"沟通规则"——如：不打断、不翻旧账、不人身攻击
5. **火**：如果破冰失败 → 引入调解人（共同信任的中立第三方）

**有为底线**：
- 沟通断裂不能靠"时间治愈" → 72小时是警戒线
- 如果一方拒绝破冰 → 默认进入Type 08（退出机制）有为

---

#### Type 07 价值观冲突 → 有为：「强制对齐」

**触发有为的条件**：
- 冲突已触及"不可接受"的底线（如：欺诈客户/剥削员工/违法操作）
- 一方已公开表示"如果这样做，我退出"
- 外部已开始质疑公司伦理（社交媒体/行业口碑）

**有为干预**：
1. **土**：紧急确认——"我们是否还在同一个伦理基准面上？"
2. **水**：承认价值观冲突比利益冲突更难解决，需要更多耐心
3. **金**：评估"妥协空间"——哪些价值观可以求同存异，哪些是底线？
4. **木**：对齐"公司伦理宣言"——写入公司章程/官网
5. **火**：如果底线冲突无法调和 → 体面分手，保留各自价值观的尊严

**有为底线**：
- 价值观冲突是有为中最难处理的 → 可能需要1-3个月
- 如果底线完全冲突 → 分手是唯一满意解

---

#### Type 08 退出机制 → 有为：「强制清算」

**触发有为的条件**：
- 一方已明确提出退出
- 双方对退出条件有分歧
- 公司账上资金不足以支持退出方案

**有为干预**：
1. **土**：确认退出的真实意图——"是情绪冲动，还是长期决策？"
2. **水**：承认"退出是正常选项，不是失败"
3. **金**：用「退出成本核算表」量化——股份回购/债务承担/竞业条款/客户交接
4. **木**：对齐"退出过程中的伦理底线"——不伤害团队/客户/投资人
5. **火**：设计「退出后关系」——不是仇人，是前合伙人

**有为底线**：
- 退出机制必须在60天内完成清算 → 拖延越久，伤害越大
- 如果无法和平退出 → 法律途径是最后的满意解

---

#### Type 09 第三方介入 → 有为：「统一战线」

**触发有为的条件**：
- 第三方已实际影响公司决策（如：投资人要求换人/客户要求换对接人）
- 合伙人一方已借助第三方力量对抗另一方
- 第三方开始"选边站"

**有为干预**：
1. **土**：合伙人必须先"统一战线"——"我们之间的矛盾，我们先自己解决"
2. **水**：承认"第三方介入往往是因为我们内部先出了问题"
3. **金**：评估第三方的真实诉求——"他们要什么？我们能给什么？"
4. **木**：对齐"如何共同面对第三方"——不是各自为战
5. **火**：如果第三方要求必须牺牲一方 → 共同决定，不让第三方分化

**有为底线**：
- 第三方介入必须在24小时内统一战线 → 每拖一天，第三方影响力增大
- 如果合伙人无法统一 → 第三方将决定结果

---

#### Type 10 成长速度差 → 有为：「强制匹配」

**触发有为的条件**：
- 速度快的一方已开始绕过慢的一方做决策
- 慢的一方感到"被边缘化"
- 团队开始"只听一个人的"

**有为干预**：
1. **土**：确认"速度差"是能力问题还是意愿问题
2. **水**：承认"速度快的一方也有焦虑——怕慢的一方拖后腿"
3. **金**：用「角色再设计」匹配速度——快的一方负责探索，慢的一方负责落地
4. **木**：对齐"我们对'成长'的定义"——不是速度，是互补
5. **火**：如果速度差无法匹配 → 考虑「联合创始人→顾问」的角色转型

**有为底线**：
- 成长速度差不能靠"等待"解决 → 必须在90天内找到新平衡
- 如果90天仍无法匹配 → 进入Type 08（退出机制）有为

---

#### Type 11 家族/情感因素 → 有为：「强制隔离」

**触发有为的条件**：
- 家族成员已实际参与公司运营/决策
- 情感因素已影响商业判断（如：因个人恩怨拒绝合理方案）
- 团队已感知到"合伙人关系不一般"

**有为干预**：
1. **土**：建立「工作与私人边界」——书面化，明确家族成员不参与决策
2. **水**：承认"情感是真实的，但不能让它替代商业判断"
3. **金**：用「边界测试」评估——"如果我们的关系明天结束，公司还能运转吗？"
4. **木**：对齐"我们对'专业'的定义"——私人关系≠商业关系
5. **火**：如果边界无法建立 → 考虑一方退出日常运营

**有为底线**：
- 家族/情感因素的干预必须立即 → 每拖一天，边界越模糊
- 如果无法隔离 → 分手是唯一满意解

---

#### Type 12 外部危机应对 → 有为：「强制行动」

**触发有为的条件**：
- 危机已直接影响公司生存（诉讼/重大事故/核心客户流失）
- 合伙人还在"争谁的责任"，没有行动
- 外部已开始倒计时

**有为干预**：
1. **土**：立即成立「危机应对小组」，合伙人必须同时在组
2. **水**：承认"现在不是争对错的时候，是先止血"
3. **金**：用「危机影响表」量化——每拖一天，损失多少？
4. **木**：对齐"危机中的伦理底线"——如：不甩锅、不隐瞒、不牺牲员工
5. **火**：如果无法共同应对 → 明确分工：一人对外，一人对内

**有为底线**：
- 外部危机的干预必须在**24小时内**启动 → 危机不会等人
- 如果24小时内无法统一行动 → 公司可能无法存活

## 有为的通用 checklist

无论哪种类型，进入有为模式时，必须：

| 检查项 | 必须完成 | 时间限制 |
|--------|:--------:|:--------:|
| 确定冲突类型 | ✅ | 30分钟内 |
| 评估破坏速度 | ✅ | 30分钟内 |
| 启动五维干预 | ✅ | 立即 |
| 设定 deadline | ✅ | 首次干预时 |
| 书面化结果 | ✅ | 每次干预后 |
| 循环验证 | ✅ | 每次干预后 |

**有为的最高原则**：
> "该用力时用力，不该用力时不勉强。但**判断该不该，本身就需要力**——这就是有为的起点。"
