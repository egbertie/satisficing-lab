# 第三站 · 产品篇·从知识到服务

> **来源**: 星月传奇·后记卷五远航篇  
> **核心问题**: 四卷内容怎么变成可卖的服务？  
> **产出**: 产品化路径 + 服务设计 + 客户旅程  
> **原则**: 产品不是"包装知识"，是**设计体验**——让客户从"知道"到"做到"

---

## 产品化路径

### 四卷→产品的转化逻辑

```
卷一（知识）→ 免费内容 → 获客
卷二（工具）→ 付费产品 → 首次收入
卷三（境界）→ 高端服务 → 深度收入
卷四（契约）→ B2B服务 → 规模化收入
```

### 产品金字塔

```
                    ▲
                   /  \
                  / 长期陪伴 \
                 /  ¥5-15K/月  \        ← 卷三+卷四
                /----------------\
               /   1对1教练/认证   \
              /    ¥800-2K/h      \      ← 卷三
```

## 服务设计

### 核心服务：合伙人关系健康检查

**服务名称**：「五维体检」  
**时长**：2小时  
**流程**：

| 阶段 | 时长 | 内容 | 产出 |
|:----:|:----:|------|------|
| 预热 | 15min | 双方独立填写V2.0测评 | 个人五维画像 |
| 诊断 | 30min | 教练解读双方画像+交叉分析 | 关系诊断书 |
| 干预 | 45min | 用卡牌游戏处理一个真实冲突 | 冲突类型诊断书 |
| 规划 | 20min | 制定30天改善计划 | 行动计划 |
| 收尾 | 10min | 发放五维自检卡+约定跟进 | 持续支持 |

**定价**：¥3,800（首客体验价）/ ¥8,000（标准价）  
**适用场景**：
- 合伙人关系出现摩擦，但尚未崩溃
- 融资前/重大决策前，需要"关系健康检查"
- 新合伙人加入，需要"关系对齐"

---

### 升级服务：合伙人关系深度陪伴

**服务名称**：「五维陪伴」  
**时长**：3-6个月  
**内容**：

| 周期 | 内容 | 产出 |
|:----:|------|------|
| 第1月 | 每周1次1对1教练（双方轮流） | 个人觉察提升 |
| 第2月 | 每两周1次三方会议（教练+双方） | 关系修复 |
| 第3月 | 每月1次工作坊（团队扩展） | 团队信任建设 |
| 第4-6月 | 每月1次跟进+按需教练 | 持续优化 |

**定价**：¥15,000/月 × 3-6个月 = ¥45,000-90,000  
**适用场景**：
- 严重冲突，需要持续干预
- 重大转型（如：IPO前/并购前）
- 从"联合创始人"到"核心合伙人"的晋级

---

### B2B服务：孵化器/加速器合伙人教练计划

**服务名称**：「五维教练营」  
**对象**：孵化器运营者  
**内容**：

| 模块 | 时长 | 内容 |
|:----:|:----:|------|
| 培训 | 2天 | 培养孵化器自己的五维教练（Level 1认证） |
| 工具包 | — | 卡牌游戏×50套 + 测评系统账号×10 |
| 督导 | 6个月 | 每月1次教练督导会议 |
| 品牌 | — | 联合品牌活动（如："XX孵化器×满意解研究所 合伙人健康日"） |

**定价**：¥28,000（培训+工具包）+ ¥3,000/月（督导）  
**适用场景**：
- 孵化器想提供差异化服务
- 投资方要求孵化器加强投后管理
- 毕业项目合伙人冲突频发

## 客户旅程设计

### 旅程地图

```
【认知】→ 【兴趣】→ 【评估】→ 【购买】→ 【体验】→ 【复购】→ 【推荐】
```

| 阶段 | 客户行为 | 我们的动作 | 触点 |
|:----:|----------|:----------:|------|
| **认知** | 刷到公众号文章/听播客 | 内容营销 | 公众号/知乎/播客 |
| **兴趣** | 下载免费工具/加社群 | 提供价值 | 官网/社群/小程序 |
| **评估** | 做免费测评/看案例 | 建立信任 | 测评系统/案例库 |
| **购买** | 预约工作坊/1对1 | 简化流程 | 官网预约/微信支付 |
| **体验** | 参加工作坊/教练 | 超预期交付 | 线下场地/线上视频 |
| **复购** | 购买进阶服务/卡牌 | 持续跟进 | 定期回访/新活动 |
| **推荐** | 推荐给其他创始人 | 激励口碑 | 推荐奖励/案例征集 |

### 关键转化点

| 转化点 | 从 | 到 | 策略 |
|:------:|:--:|:-:|:----:|
| 1 | 内容→测评 | 认知→兴趣 | 文章结尾放"免费测评"入口 |
| 2 | 测评→工作坊 | 兴趣→评估 | 测评报告末尾推荐"深度解读工作坊" |
| 3 | 工作坊→教练 | 评估→购买 | 工作坊结束时提供"30天陪伴"优惠 |
| 4 | 教练→推荐 | 体验→推荐 | 3个月后回访，征集成功案例 |
