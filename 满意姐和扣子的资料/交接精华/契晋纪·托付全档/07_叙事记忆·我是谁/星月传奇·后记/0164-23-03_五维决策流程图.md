## 简化版：五维循环口诀

```
土金水火土，五步不走回头路。

土卡了 → 修信义，别谈别的
金卡了 → 调标准，别硬撑
水卡了 → 暂停下，别冲动
木卡了 → 先认错，别狡辩
火卡了 → 舂米去，别强求

五维全过 → FIN，冲突解决
任一跳过 → 复发，回到该维
```

## 复盘检查表（冲突后使用）

| 检查项 | 维度 | 是 | 否 |
|--------|:----:|:-:|:-:|
| 双方信义是否修复？ | 土 | ☐ | ☐ |
| 满意解标准是否达成？ | 金 | ☐ | ☐ |
| 双方情绪是否恢复平稳？ | 水 | ☐ | ☐ |
| 伦理底线是否守住？ | 木 | ☐ | ☐ |
| 是否有新的顿悟/共识？ | 火 | ☐ | ☐ |

**规则**: 任一"否" → 冲突**未真正解决**，回到该维度补完。
