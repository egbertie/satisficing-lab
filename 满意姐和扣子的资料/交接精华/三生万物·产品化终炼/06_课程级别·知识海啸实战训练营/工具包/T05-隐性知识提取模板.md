# T05: 隐性知识提取模板

> **编号**: SSW-654
> **用途**: 结构化提取隐性知识

---

## 模板

```markdown
## 隐性知识 #[编号]
**来源文件**: [路径]
**信号类型**: □感觉 □缺失 □标注 □差异
**机器猜测**: [机器的理解]
**人工确认**: [你的修正]
**萃取模板**: 如果[场景]，那么[做法]，因为[未明说的原因]
**适用边界**: [什么时候适用/不适用]
**相关文件**: [关联的其他文件]
```

## 示例

```markdown
## 隐性知识 #1
**来源文件**: /cases/contract_review_notes.md
**信号类型**: □感觉 □缺失 ☑标注
**机器猜测**: 合同审核有特定流程
**人工确认**: 审核时重点看第7条违约责任，90%纠纷出在那里
**萃取模板**: 如果[审核合同]，那么[重点看第7条]，因为[90%纠纷来源]
**适用边界**: 适用于乙方合同，不适用于框架合作协议
**相关文件**: /templates/contract_checklist.md
```
