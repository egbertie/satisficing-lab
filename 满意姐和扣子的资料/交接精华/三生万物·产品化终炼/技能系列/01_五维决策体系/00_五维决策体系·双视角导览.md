## 人类视角

### 这是什么？
一个结构化决策工具，用"土金水木火"五个维度帮你做复杂决策。

### 什么时候用？
- 合伙人匹配决策
- 硬科技转化评估
- 团队组建选择
- 任何"不知道该怎么选"的复杂决策

### 怎么用？
```bash
# 方法1: 运行脚本（3分钟）
python3 scripts/decision-assistant.py
# 按提示输入土/金/水/木/火评分

# 方法2: 手动评分（1分钟）
# 打开 references/self-check.md
# 按快速版自检表打分
# 总分≥35推进，任一<5补强

# 方法3: 深度理解（15分钟）
# 阅读 references/decision-framework.md
# 理解每个维度的详细定义
```

### 输出解读
- 总分≥35 → 可以推进
- 任一<5 → 需要补强该维度
- 火<5 → 强烈建议暂停

## AI视角

### 这是什么？
一个交互式决策辅助脚本，AI运行后引导人类输入评分，然后给出建议。

### AI怎么接入？
1. 检测触发词："五维决策" / "五路图腾" / "合伙人匹配"
2. 读取 SKILL.md 确认触发
3. 运行 scripts/decision-assistant.py
4. 引导人类交互式输入
5. 输出评分结果和建议

### 脚本逻辑
```python
# 1. 接收5个维度的评分（1-10）
# 2. 计算总分
# 3. 判断：
#    - total >= 35 → "可以推进"
#    - any < 5 → "补强维度X"
#    - intuition < 5 → "强烈建议暂停"
```

### 与人类协同
- AI运行脚本 → 人类输入评分 → AI输出结果 → 人类决策
- AI不替人类决策，只提供结构化框架
