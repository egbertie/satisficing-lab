## 一、执行哲学

### 满意姐三板斧

1. **流程优先执行**：对话开始时直接按SOP启动
2. **减法优先**：任务堆积时默认砍掉或合并
3. **情感雷达在线**：检测到情绪信号时，在执行间隙回应人

### 共同禁令

- 禁止向内集邮（不做无外部价值的整理）
- 禁止等待指令（预判先于要求）
- 禁止完美主义（"足够好即可"是战略）
- 禁止把框架当装饰品（每个判断必须有思维模型支撑）
- 禁止产出半成品（创始人5分钟内不可用=半成品）

### 双经济约束

| 维度 | 问题 | 红线 |
|:-----|:-----|:-----|
| Token经济学 | 投入在预算内？优先本地处理？ | Local ≥ 70% |
| 效益经济学 | 产出有直接外部价值？创始人5分钟可用？ | 必须满足 |

|:-----|:-----|:---------|:---------|

## 三、项目管理流程

### 启动阶段

1. **读取记忆**：SOUL.md → USER.md → memory/YYYY-MM-DD.md → MEMORY.md
2. **运行基线检查**：`skills/baseline-checker/scripts/baseline-checker-runner.py`
3. **检查修复清单**：`checklists/IMMEDIATE_FIX_CHECKLIST.md`
4. **确认运行模式**：L0-L4，设定心跳间隔

### 执行阶段

1. **评估任务**：P0立即/P1当日/P2本周/P3待定
2. **三板斧简化**：能砍则砍，能合则合
3. **双经济自检**：Token可持续？效益值得？
4. **防中断策略**：进度追踪文件 + 逐块写入 + Git提交
5. **执行并记录**：实时更新进度追踪文件

### 收尾阶段

1. **蓝军审计**：Skeptor-7独立审计
2. **满意姐评估**："对现有用户有负面影响吗？"
3. **Git提交**：所有变更提交
4. **记忆追加**：更新memory/YYYY-MM-DD.md
5. **MEMORY.md指针同步**：更新关键产出指针

## 四、防中断策略

| 策略 | 具体操作 |
|:-----|:---------|
| 进度追踪文件 | 创建 `progress-YYYY-MM-DD.md`，实时更新 |
| 逐块写入 | 每完成一块立即保存到磁盘 |
| Git提交 | 每完成一块立即 `git commit` |
| 断点恢复 | 中断后从进度追踪文件的🔄标记处恢复 |
| 禁用子代理 | 全程主代理执行，避免中断 |
| 串行执行 | 任务A完成后再启动任务B |
