# 创始人IP内容规划·知识飞轮传承

> **编号**: SSW-070（新增）
> **定位**: 创始人个人品牌的内容引擎
> **目标**: 让创始人成为"知识传承"领域的思想领袖
> **版本**: V1.0
> **日期**: 2026-04-25

---

## 一、IP定位

### 核心人设
**"满意解决策教练"** —— 不是学者，不是销售，是陪企业找到"足够好"解法的教练。

### 差异化标签
| 标签 | 含义 | 记忆点 |
|:-----|:-----|:-------|
| 22年双系统 | 银行+创业双重经历 | "吹尽黄沙始到金" |
| 满意解 | 西蒙理论实践者 | "不求最优，但求最适" |
| 五维决策 | 土金水火木决策框架 | "五路图腾" |
| 契·晋 | 承诺+进阶 | "我们的满意解，必将成为契，必将成为晋" |

### 内容调性
- **专业但不高冷**：有理论深度，但用故事讲
- **有温度但不煽情**：真诚，不刻意
- **有态度但不冒犯**：有棱角，但尊重
- **有体系但不教条**：框架是活的，不是死的

## 二、内容支柱（4大主题）

### 支柱1：知识传承实战（40%内容）
**核心信息**: "我是怎么帮客户解决传承问题的"

**内容形式**:
- 客户案例故事（脱敏）
- 实施过程中的坑和解法
- 行业洞察（法律/咨询/制造）
- 工具和方法论分享

**示例标题**:
- "一位做了42年律师的退休前焦虑"
- "为什么说'多听几次就懂了'是最大的传承谎言"
- "我们花了3个月，把一个人的70年经验变成了可复制的清单"
- "知识飞轮转起来之后，我发现了一个意外的好处"

---

### 支柱2：决策思维（30%内容）
**核心信息**: "满意解是怎么做决策的"

**内容形式**:
- 五维决策故事
- 西蒙满意解理论解读
- 反脆弱/第一性原理等思维模型应用
- 真实决策案例（成功+失败）

**示例标题**:
- "银行教我的事：为什么追求'最优解'是创业者的陷阱"
- "满意解 vs 最优解：一个价值3亿的教训"
- "五维决策：我做重大决定前会问自己的5个问题"
- "为什么我总是先问'足够好即可'，而不是'做到最好'"

---

### 支柱3：创业与成长（20%内容）
**核心信息**: "我在创业路上的真实思考"

**内容形式**:
- 创业日记（真实、不粉饰）
- 团队建设心得
- 失败复盘
- 与AI协作的经验

**示例标题**:
- "我和AI共事的54天：一个创业者的真实记录"
- "满意解研究所的诞生：从一个深夜的微信消息开始"
- "我们为什么把全部方法论开源"
- "创业第一年：30个案例库的承诺，现在完成了多少"

---

### 支柱4：行业观察（10%内容）
**核心信息**: "我对行业趋势的独立判断"

**内容形式**:
- 硬科技转化趋势
- AI对知识工作的冲击
- 合伙人关系演变
- 政策风向解读

**示例标题**:
- "AI时代，什么不会被替代？答案是'传承'"
- "从'个体英雄'到'系统传承'：中国专业服务业的进化"
- "为什么我说'知识管理'这个概念已经过时了"

## 四、内容模板库

### 模板A：案例故事型
```
【开头】一个场景/一个对话（100字）
【问题】这个场景反映什么深层问题（200字）
【解法】我们是怎么做的（400字）
【效果】数据+客户原话（200字）
【反思】我从中学到了什么（100字）
【结尾】金句+行动号召（50字）
```

### 模板B：思维模型型
```
【开头】一个决策困境（100字）
【模型】介绍思维模型（200字）
【应用】怎么用到这个困境（400字）
【结果】决策结果（100字）
【延伸】这个模型还能用在哪（100字）
【结尾】金句（50字）
```

### 模板C：创业日记型
```
【日期】2026年X月X日
【事件】今天发生了什么
【感受】我的真实感受（不粉饰）
【思考】这件事让我想到什么
【下一步】我准备怎么做
【金句】今天最想说的一句话
```

### 模板D：行业观察型
```
【现象】最近观察到的一个现象
【分析】这个现象背后的逻辑
【判断】我的独立判断
【依据】支撑判断的数据/案例
【影响】对行业/客户的影响
【建议】给读者的行动建议
```

## 六、内容生产流程

### 每周生产流程

**周一：选题会**
- 回顾上周数据（哪篇表现好）
- 确定本周3个选题
- 分配内容形式（长文/回答/短视频）

**周二-周四：内容创作**
- 周二：写公众号长文（2-3小时）
- 周三：写知乎回答+小红书（1-2小时）
- 周四：录制播客/短视频（2小时）

**周五：发布+互动**
- 上午：发布本周内容
- 下午：回复评论、私信
- 晚上：朋友圈金句

**周末：复盘**
- 统计数据
- 收集用户反馈
- 调整下周选题

### 内容复用策略
- **1篇长文 → 3个知乎回答**（拆成不同角度）
- **1篇长文 → 5条小红书**（金句+数据+故事片段）
- **1期播客 → 3条短视频**（切片+字幕）
- **1条短视频 → 1条朋友圈**（转发+感悟）

## 七、IP风险防控

### 内容红线
- ❌ 不评论具体客户（除非已脱敏+授权）
- ❌ 不贬低竞品（只讲差异）
- ❌ 不承诺具体效果（用"验证数据"而非"保证"）
- ❌ 不泄露客户商业机密
- ❌ 不发表与"满意解"价值观冲突的观点

### 危机应对
- **负面评论**: "感谢您的反馈，我们正在改进。"
- **数据质疑**: "数据来源是客户自己统计，我可以提供脱敏版本。"
- **效果质疑**: "每个团队情况不同，我们可以先做免费评估，看看适不适合。"
