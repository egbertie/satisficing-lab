## 一、合作模式

### 模式A：分销合作
| 项目 | 内容 |
|:-----|:-----|
| 合作方式 | 合作伙伴销售我们的产品，获得佣金 |
| 佣金比例 | 销售额的20-30%（按量级阶梯） |
| 结算周期 | 客户付款后15个工作日 |
| 支持内容 | 销售培训+物料支持+客户支持 |
| 适合对象 | 有客户资源的行业顾问/培训机构/咨询公司 |

### 模式B：联合品牌
| 项目 | 内容 |
|:-----|:-----|
| 合作方式 | 联合开发行业专属版本，共享品牌 |
| 投入分工 | 我们出方法论，合作伙伴出行业知识 |
| 收益分配 | 按投入比例分成 |
| 支持内容 | 方法论培训+技术对接+联合营销 |
| 适合对象 | 有行业深耕资源的机构 |

### 模式C：API集成
| 项目 | 内容 |
|:-----|:-----|
| 合作方式 | 将知识飞轮能力集成到合作伙伴的产品中 |
| 技术对接 | 提供API接口+技术文档 |
| 收费模式 | 按调用量计费 |
| 支持内容 | 技术文档+开发支持+联合推广 |
| 适合对象 | SaaS厂商/知识管理平台 |

## 二、合作伙伴 onboarding（7天）

### Day 1：产品理解
- **上午**: 学习传播策略总纲（SSW-062）
- **下午**: 学习客户旅程地图（SSW-063）
- **作业**: 用自己的话复述"知识飞轮是什么"

### Day 2：销售技巧
- **上午**: 学习冷启动话术（SSW-057）+ FAQ异议处理（SSW-059）
- **下午**: 模拟销售演练（角色扮演）
- **作业**: 录制一段2分钟电梯演讲视频

### Day 3：行业知识
- **上午**: 学习行业定制版大全（SSW-065）
- **下午**: 选择一个目标行业，整理该行业的"痛点话术库"
- **作业**: 写3个该行业的电梯演讲版本

### Day 4：工具使用
- **上午**: 学习销售工具包（SSW-064）
- **下午**: 练习使用需求问卷、报价框架
- **作业**: 模拟完成一次需求挖掘问卷

### Day 5：实战陪同
- **上午**: 跟我们的销售一起拜访客户（旁听）
- **下午**: 复盘：客户说了什么？我们怎么回应的？
- **作业**: 写出3个可以改进的地方

### Day 6：独立演练
- **全天**: 独立完成一次从冷启动到提案的完整流程
- 我们扮演客户，给反馈

### Day 7：考核与授权
- **上午**: 考核（电梯演讲+FAQ应对+需求挖掘）
- **下午**: 授权证书+物料包发放
- **结营**: 确定首个目标客户

## 六、合作伙伴常见问题

**Q1: 我需要投入什么？**
A: 主要是时间和客户资源。不需要技术投入，不需要额外人力。我们提供全套销售物料和培训。

**Q2: 我的客户信息会不会被抢走？**
A: 不会。合作伙伴的客户资源归合作伙伴所有。我们只提供产品和培训支持，不直接联系您的客户（除非您授权）。

**Q3: 如果我不会销售怎么办？**
A: 我们有7天 onboarding 培训，从0教到能独立销售。还有月度销售复盘会，持续提升。

**Q4: 产品更新了我怎么知道？**
A: 每季度产品更新 webinar + 实时网盘同步 + 微信群通知。

**Q5: 我能定制产品吗？**
A: 可以。联合品牌模式下，我们可以为您的行业/客户定制专属版本。

**Q6: 佣金怎么结算？**
A: 客户付款后15个工作日内，按合同约定的佣金比例结算。提供正规发票。

## 七、合作伙伴申请流程

```
提交申请 → 资质审核（3天） → 电话沟通（1次） → 签署协议 → onboarding培训（7天） → 授权证书 → 开始销售
```

**申请条件**:
- 有目标客户资源（法律/咨询/制造/其他经验型行业）
- 有销售团队或顾问团队
- 认同"满意解"理念
- 愿意投入时间学习
