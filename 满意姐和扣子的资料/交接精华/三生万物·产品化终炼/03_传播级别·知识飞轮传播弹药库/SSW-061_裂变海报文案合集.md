## 海报设计规范

### 尺寸
| 用途 | 尺寸 |
|:-----|:-----|
| 微信朋友圈 | 1080×1920px（9:16） |
| 公众号头图 | 900×383px |
| 线下印刷 | A3（297×420mm） |
| 社群传播 | 1080×1080px（1:1） |

### 视觉元素
| 元素 | 规范 |
|:-----|:-----|
| 主色调 | 深蓝(#1A365D) |
| 强调色 | 金色(#D69E2E) |
| 背景 | 浅色纹理，不抢内容 |
| 字体 | 标题：思源黑体Bold 72pt，正文：24pt |
| 二维码 | 底部居中，配简短行动文案 |
| Logo | 右下角，不抢眼 |

### 文案原则
- 大标题≤10个字，一句话能记住
- 副标题≤20个字，补充说明
- 正文≤50个字，快速阅读
- 行动指令明确，"扫码[做什么]"

## 裂变机制设计

### 基础裂变
1. 用户扫码→领取资料（PDF/工具）
2. 资料内嵌入："转发海报到朋友圈，领《行业专属传承指南》"
3. 用户转发→截图发回→领取进阶资料

### 进阶裂变
1. 用户完成"知识资产评估"→生成专属报告
2. 报告底部："分享您的评估结果，邀请同事一起评估"
3. 每邀请1人，解锁1个新模块

### 社群裂变
1. 扫码入群→领取《知识传承避坑指南》
2. 群内每日分享：1个传承小技巧
3. 满100人解锁：行业大咖直播分享
