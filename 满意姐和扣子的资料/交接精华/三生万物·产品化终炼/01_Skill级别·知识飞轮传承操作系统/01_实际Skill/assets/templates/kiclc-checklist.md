# KICL 12步速查卡 · 血液化闭环

```
1.触发 → 2.去重 → 3.转换 → 4.存储 → 5.洞察 → 6.映射
→ 7.血液化 → 8.子文档 → 9.报告 → 10.任务 → 11.记忆 → 12.Git
```

## 每步一句话

| 步骤 | 动作 | 输出 |
|:-----|:-----|:-----|
| 1.触发 | 确认文件已下载，记录来源 | 接收日志（1句话） |
| 2.去重 | 搜索类似主题，确认是否已有 | 去重结论 |
| 3.转换 | PDF→pypdf / 图片→OCR / 链接→kimi_fetch | 原始MD文件 |
| 4.存储 | 放入素材库/内化知识库 | 物理落盘，命名规范 |
| 5.洞察 | 回答3个问题 + 四维度拆解 | 洞察笔记 |
| 6.映射 | 对照现有框架建立连接 | 映射表格 |
| 7.血液化 | 产出≥1项L4可直接用成果 | 血液化成果物 |
| 8.子文档 | 整合Step 5-7为完整MD | 血液化子文档 |
| 9.报告 | 1页纸总结同步到对话文件夹 | 汇总报告 |
| 10.任务 | 更新TASK_MASTER.md | 任务清单 |
| 11.记忆 | 追加memory/ + 同步MEMORY.md | 记忆记录 |
| 12.Git | git commit，记录hash | commit记录 |

## 血液化五级检验

| 级别 | 名称 | 检验 |
|:-----|:-----|:-----|
| L0 | 归档 | 文件物理落盘 |
| L1 | 摘要 | 有1页以内核心摘要 |
| L2 | 洞察 | 提取底层方法论 |
| L3 | 映射 | 与现有框架建立连接 |
| L4 | 血液化 | 可转化为直接可用产出 |

**只有L4才算真正的"入库"完成。**

## 自检三问

处理完一份资料后，问自己：
1. 这个知识能直接用于一次客户交付吗？
2. 能变成一句Egbertie可以直接用的话术吗？
3. 能催生一个新任务吗？

如果3个都是"否" → 没有血液化，需要回到Step 5-7重做。
