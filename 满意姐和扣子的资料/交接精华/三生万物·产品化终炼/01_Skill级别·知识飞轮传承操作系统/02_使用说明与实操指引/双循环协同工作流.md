# 双循环协同工作流

> **用途**: 人类与AI如何每双周协同，具体到每一步
> **适用**: L2及以上（团队/组织/生态级）
> **频率**: 每双周一次，每次30分钟

---

## 一、会前准备（会前30分钟）

### AI准备（10分钟）
- [ ] 统计本周入库文件数
- [ ] 列出本周发现的连接数
- [ ] 列出本周识别的空白数
- [ ] 列出本周血液化产出
- [ ] 准备抽查样本（2-3个产出）

### 人类准备（10分钟）
- [ ] 回顾上周会议决议
- [ ] 标记本周遇到的"AI产出问题"
- [ ] 准备2-3个"抽查问题"
- [ ] 思考"下周优先级"

### 共同准备（10分钟）
- [ ] 确定会议时间（固定时段）
- [ ] 准备会议记录模板
- [ ] 确认参会人员

---

## 二、会议流程（30分钟）

### 阶段1：AI展示（5分钟）

**AI汇报模板**：
```
本周入库: [X]份
发现连接: [Y]个
识别空白: [Z]个
血液化产出: [具体列表]
待裁决冲突: [A说X，B说Y]
```

**人类动作**：听，不评判，先记录。

---

### 阶段2：人类验证（10分钟）

**抽查项1**（3分钟）
- AI展示产出A
- 人类快速判断：准确 / 需修正 / 不适用
- 记录判断理由

**抽查项2**（3分钟）
- AI展示产出B
- 人类快速判断
- 记录判断理由

**发现AI遗漏**（4分钟）
- 人类提问："这个领域，AI似乎忽略了什么？"
- AI回应："我确实没注意到..."
- 记录遗漏项，加入下周优先

---

### 阶段3：冲突处理（5分钟）

**冲突呈现**（1分钟）
- AI说："A文档说X，B文档说Y，两者冲突"

**人类裁决**（3分钟）
- 选项1：支持X，理由是...
- 选项2：支持Y，理由是...
- 选项3：待进一步验证

**记录逻辑**（1分钟）
- 为什么这样裁决？
- 记录到"冲突裁决日志"

---

### 阶段4：优先级调整（5分钟）

**下周重点**（2分钟）
- 人类提出："下周重点处理主题A"
- AI确认："主题A涉及文件X、Y、Z，预计耗时..."

**紧急插入**（2分钟）
- 如有紧急任务，插入队列
- 如有必要，暂停低优先级项

**资源确认**（1分钟）
- 人类确认："我下周有3小时投入"
- AI确认："需要我调整自动处理优先级吗？"

---

### 阶段5：飞轮检查（5分钟）

**指标1：新人上手时间**（1分钟）
- 缩短 / 持平 / 延长
- 如果延长，分析原因

**指标2：同类任务复用率**（1分钟）
- 提升 / 持平 / 下降
- 如果下降，分析原因

**指标3：知识查找时间**（1分钟）
- 缩短 / 持平 / 延长
- 如果延长，分析原因

**指标4：血液化占比**（2分钟）
- L3+L4占比是否≥30%？
- 如果不足，制定血液化计划

---

## 三、会后跟进（会后30分钟）

### AI动作（15分钟）
- [ ] 根据人类裁决，修正冲突项
- [ ] 调整下周自动处理优先级
- [ ] 生成会议纪要的AI部分

### 人类动作（15分钟）
- [ ] 阅读AI生成的会议纪要
- [ ] 补充人类部分的判断逻辑
- [ ] 将决议同步到TASK_MASTER.md
- [ ] 准备下周的"人类输入"

## 五、常见问题

**Q: 如果AI和人类意见不一致，谁说了算？**
A: 人类说了算。AI提供数据和选项，人类做最终裁决。记录裁决逻辑，供未来参考。

**Q: 如果会议时间不够，优先砍哪个阶段？**
A: 优先保证"冲突处理"和"飞轮检查"。AI展示可以会后发文档，人类验证可以抽查减少为1项。

**Q: 如果连续几次会议都没有冲突，说明什么？**
A: 可能是好事（知识一致性高），也可能是坏事（AI没有发现深层冲突）。建议人类主动提出一个"假设性冲突"，测试AI的深度。
