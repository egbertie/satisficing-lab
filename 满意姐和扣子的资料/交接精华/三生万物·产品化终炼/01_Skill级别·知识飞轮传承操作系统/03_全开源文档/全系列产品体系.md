# 全系列产品体系

> **用途**: 理解Skill/课程/传播三者的关系，以及如何从"骨头"到"血肉"
> **适用**: 体系设计者、产品经理、品牌运营

---

## 一、产品矩阵

```
              触达广度
                 ↑
    传播级别 ●────────────● 课程级别
   (5平台触达)           (12模块训练)
                 │
                 │
    Skill级别 ●──┘
   (工具级操作系统)
                 ↓
              使用深度
```

---

## 二、三层关系

### Skill级别（工具级）—— 骨头

**定位**: 可直接安装、配置、运行的操作系统
**用户**: 技术用户、AI管理员、知识管理专员
**交付**: Skill文件 + 脚本 + 模板 + 使用手册
**价值**: "给我一个工具，我自己能转起来"

### 课程级别（训练级）—— 血肉

**定位**: 系统学习的训练体系
**用户**: 学习者、团队负责人、组织管理者
**交付**: 12模块口播稿 + 工具包 + 学习路径
**价值**: "给我一套方法，我能教别人转起来"

### 传播级别（触达级）—— 皮肤

**定位**: 快速传播的理念弹药
**用户**: 影响者、内容创作者、品牌运营
**交付**: 5平台传播材料
**价值**: "给我一个故事，能让更多人想转起来"

---

## 三、转化路径

```
传播触达 → 产生兴趣 → 课程学习 → 掌握方法 → Skill实践 → 飞轮转动
   ↑                                                              ↓
   └──────────────── 口碑反哺 ───────────────────────────────────┘
```

**示例路径**:
1. 用户在小红书看到"为什么知识传不下去"笔记
2. 产生兴趣，搜索课程
3. 学完12模块，掌握方法
4. 下载Skill，安装运行
5. 飞轮转动，产出新经验
6. 新经验反哺课程和Skill，形成闭环
