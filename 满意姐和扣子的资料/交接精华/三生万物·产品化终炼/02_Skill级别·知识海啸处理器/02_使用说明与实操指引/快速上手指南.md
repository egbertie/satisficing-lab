# 快速上手指南

> **5分钟启动知识海啸处理器**
> **编号**: SSW-252

---

## 前提条件

- Python 3.8+
- 已安装 `skills/knowledge-tsunami-processor/` 或 `.skill.tar.gz`

---

## 极速启动（1条命令）

```bash
python3 skills/knowledge-tsunami-processor/scripts/tsunami-pipeline.py \
  --input /path/to/your/scattered/files \
  --output ./tsunami-output/ \
  --mode standard
```

**等效分步命令**（如需精细控制）:

```bash
# Step 1: 扫描（2分钟）
python3 scripts/tsunami-ingest.py \
  --input /path/to/files --output ./out/01_ingest

# Step 2: 分类（5分钟）
python3 scripts/smart-triage.py \
  --input ./out/01_ingest --output ./out/02_triage

# Step 3: 萃取（10分钟）
python3 scripts/core-extractor.py \
  --input ./out/02_triage --output ./out/03_extract

# Step 4: 转化（15分钟）
python3 scripts/quality-transform.py \
  --input ./out/03_extract --output ./out/04_transform

# Step 5: 打包（5分钟）
python3 scripts/package-builder.py \
  --input ./out/04_transform --output ./out/05_package
```

## 三种模式选择

| 模式 | 适用场景 | 文件数 | 时间 | 质量 |
|:-----|:---------|:-------|:-----|:-----|
| **express** | 快速验证 | ≤100 | 1-4小时 | L2 |
| **standard** | 日常工作 | ≤1000 | 1-3天 | L3 |
| **full** | 深度传承 | ≤10000 | 7-10天 | L4 |

## 关键参数速查

```bash
--batch-size 1000      # 每批处理文件数
--quality L3           # 质量等级 L1-L5
--max-depth 10         # 最大扫描目录深度
--exclude "*.tmp"      # 排除模式
--verbose              # 详细输出
--archive-source       # 处理后归档源文件
```

## 常见问题

**Q: "处理到一半中断了怎么办？"**
A: 重新运行相同命令，自动从断点恢复（checkpoint机制）。

**Q: "P0标记错了怎么修正？"**
A: 修改 `./out/02_triage/04_P0-P1-P2-P3标记.json`，重新运行Step 3-5。

**Q: "输出质量不满意怎么办？"**
A: 使用 `--quality L4` 重新运行，或人工补充 `04_隐性知识/` 后重新打包。
