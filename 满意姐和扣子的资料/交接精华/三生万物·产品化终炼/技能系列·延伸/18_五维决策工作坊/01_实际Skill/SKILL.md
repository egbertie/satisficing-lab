# 五维决策工作坊

> **编号**: SANSHENG-SKILL-018
> **定位**: 基于五维决策体系（土金水木火）的实战工作坊，将理论转化为可操作的决策流程
> **触发词**: "五维决策" / "工作坊" / "土金水木火" / "决策流程" / "五维" / "图腾"
> **五维映射**: 土+金+水+木+火（全覆盖）

---

## 一、Why

**知道五维决策很好，但怎么用？**

**问题**:
- 学了理论，实战时还是"凭感觉"
- 五维是五个维度，但不知道怎么一步步走
- 紧急决策时，没有时间去翻理论

**解决**: 五维决策工作坊 — 把五维决策变成"按按钮就能走"的标准流程。

---

## 二、What

### 2.1 五维决策流程

```
[土] 聚贤才为伍 → 谁参与决策？利益相关者是谁？
    ↓
[金] 满意解标准 → 什么是"足够好"？最优解陷阱在哪？
    ↓
[水] 流动洞察 → 还有哪些信息？直觉怎么说？
    ↓
[木] 伦理生长 → 这个决定对团队/客户/社会的影响？
    ↓
[火] 顿悟行动 → 时机到了吗？执行的最小步骤是什么？
```

### 2.2 工作坊形式

| 形式 | 时长 | 人数 | 适用场景 |
|------|------|------|---------|
| **个人版** | 30分钟 | 1人 | 日常决策 |
| **团队版** | 2小时 | 3-7人 | 重大团队决策 |
| **教练版** | 1天 | 1对1 | 深度决策辅导 |

### 2.3 输出物

- 五维决策记录表（每维度的分析结果）
- 决策建议书（含风险/收益/时机）
- 行动计划（最小可执行步骤）

---

## 三、How

### 3.1 触发方式

```
"启动五维决策工作坊"
"用五维框架分析这个问题"
"土金水木火，走一遍"
```

### 3.2 个人版流程（30分钟）

```
Step 1 [土, 5min]: 写下所有利益相关者
Step 2 [金, 5min]: 定义"满意解"标准（什么算足够好）
Step 3 [水, 5min]: 列出已知信息 + 直觉感受
Step 4 [木, 5min]: 检查伦理影响（信任/长期关系）
Step 5 [火, 5min]: 确定执行步骤 + 时机
Step 6 [整合, 5min]: 输出决策建议
```

### 3.3 团队版流程（2小时）

```
[开场, 10min]: 决策背景与目标
[土, 20min]: 利益相关者分析（小组讨论）
[金, 20min]: 满意解标准定义（共识达成）
[水, 20min]: 信息补充与直觉分享
[茶歇, 10min]
[木, 20min]: 伦理影响评估
[火, 20min]: 执行方案与时机确定
[整合, 20min]: 决策建议书撰写
```

## 五、红线与边界

| 红线 | 说明 |
|------|------|
| 不走完五维不做决策 | 五维是完整流程，跳过任何一维都有风险 |
| 不追求完美解 | [金]维度明确"满意解"，拒绝最优解陷阱 |
| 不忽略直觉 | [水]维度必须记录直觉，不纯理性 |
| 不损害信任 | [木]维度检查伦理，信任优先于短期利益 |
