# 快速上手指南

> **编号**: SANSHENG-SKILL-009-REF-002
> **目标**: 15分钟学会使用深研·静流

---

## 第一步: 触发技能

```
"深研 [你的研究主题]"
```

示例:
- "深研 中国数据出境安全评估制度"
- "快速深研 某竞争对手的融资历程"
- "深度研究 脑机接口在医疗领域的应用前景"

---

## 第二步: 选择模式

| 你的情况 | 选择模式 | 预期时长 |
|:---------|:---------|:---------|
| "我明天就要汇报" | 快速版 | 30分钟 |
| "我要写一份正式报告" | 标准版 | 80分钟 |
| "这是重大战略决策" | 深度版 | 180分钟 |

---

## 第三步: 补充边界信息

机器会生成研究任务书，你需要补充:
1. **边界**: 时间范围？地域范围？行业范围？
2. **目标读者**: 给谁看？（客户/团队/投资人/自己）
3. **预期产出**: 要报告？摘要？清单？PPT？

---

## 第四步: 执行流水线

机器按六阶段执行，每阶段结束会汇报进度:
```
[理解] ✅ → [搜索] ✅ → [验证] ⏳ → ...
```

你可以随时打断、调整方向、补充信息。

---

## 第五步: 验收产出

标准版产出物:
- 📄 研究报告（Markdown，含结构标题）
- 📋 来源清单（可追溯）
- 📝 一页摘要（核心结论）

---

## 脚本直接调用

```bash
# 标准版
python3 scripts/deep-research.py --topic "主题" --mode standard

# 快速版
python3 scripts/quick-research.py "主题"

# 验证来源
python3 scripts/source-validator.py sources.md

# 质量检查
python3 scripts/research-quality-check.py research.md
```
