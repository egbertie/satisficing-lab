# 快速上手指南

> **编号**: SANSHENG-SKILL-010-REF-002
> **目标**: 5分钟学会使用静水流深·协作者

---

## 第一步: 触发技能

```
"静水 [你的内容]"
```

示例:
- "静水 帮我润色这段给客户的消息"
- "严格静水 帮我检查这份报告的口吻"
- "宽松静水 日常对话用这个"

---

## 第二步: 选择过滤级别

| 级别 | 适用场景 |
|:-----|:---------|
| 宽松级 | 日常对话、内部讨论 |
| 标准级 | 对外输出、客户沟通 |
| 严格级 | 正式报告、公开发布 |

---

## 第三步: 验收过滤结果

机器会输出:
- 发现的问题（建议型/请教型/关心型）
- 过滤级别
- 修正建议

---

## 脚本直接调用

```bash
# 标准级过滤
python3 scripts/communication-filter.py --input draft.md

# 严格级过滤
python3 scripts/communication-filter.py --input draft.md --level strict

# 自检报告
python3 scripts/self-check-report.py draft.md
```
