# 编号决策协议 — 麦肯锡电梯演讲版

> **一句话**: 每个决策有编号，改了也知道为什么改

---

## 30秒版本

**创业者最烦什么？**

不是决策难，是**决策后忘了**。

我们的编号决策协议：
- 选项编号：A-①、B-②，精确不模糊
- 决策存档：每个决策有DEC编号
- 修改留痕：改了什么、为什么改，全部记录

**不是一言九鼎不能改，是改了之后知道为什么改。**

## 2分钟版本

你有没有这种经历？

上周说"先做这个"，这周说"还是做那个吧"。
问起来——"我们之前不是决定了吗？"
"是啊，但那个决定是基于当时的条件……"
条件变了？什么时候变的？为什么没记录？

**决策没有编号 = 没有追溯 = 可以任意改 = 没有责任。**

我们的编号决策协议解决这个问题：

**选项编号**：
不是"选第一个"，是"A-①"。
多主题时："A-①, B-②"。
精确到字符，没有歧义。

**决策存档**：
每个决策有唯一编号：DEC-042、DEC-043……
包含：选项、用户原始响应、影响评估、关联决策。

**修改留痕**：
改了决策？没问题。
但必须记录：原决策是什么 → 改为什么 → 为什么改 → 影响了哪些后续决策。

**追溯链**：
```
DEC-042 (当前)
  ← 基于 DEC-038 (范围定义)
  → 影响 DEC-045 (执行计划)
```

**让你知道：这个决定基于什么、影响了什么、如果前提变了，哪些决策需要重新评估。**
