# 知识内化引擎

> **曾用名**: 一堂内化引擎
> **更名原因**: 去品牌名，提升通用性，聚焦核心能力
> **更名时间**: 2026-04-26

---

## 技能定位

将任何外部方法论、知识体系、专家观点，系统性地转化为满意解研究所的自有知识资产。

**核心能力**:
1. **提取骨架** — 从外部内容中提取核心逻辑框架
2. **映射转化** — 将外部框架映射到五维决策体系
3. **血液化** — 转化为可直接使用的工作流、检查清单、决策模板
4. **产出配套** — 生成开源版、微信传播版等多形态输出

**适用场景**:
- 参加完一堂课程/讲座后，需要内化吸收
- 阅读完一本书/一篇论文后，需要提取 actionable insights
- 研究完竞品/行业案例后，需要转化为自有方法论
- 与专家交流后，需要固化交流成果

**触发词**:
- "内化" / "吸收" / "转化" / "血液化" / "提取框架"
- "一堂" / "课程笔记" / "学习总结" / "知识转化"
- "外部方法论" / "竞品分析" / "专家观点" / "论文提取"

## 使用流程

### Step 1: 输入处理

接收外部内容（多种格式）:
- 课程视频/音频 → 转录为文字
- PDF/文档 → 提取核心内容
- 图片/PPT → OCR识别
- 网页/文章 → 抓取正文
- 手写笔记 → 结构化整理

### Step 2: 骨架提取

从外部内容中提取核心逻辑：
- **核心论点** — 作者最想传达的3个核心观点
- **逻辑结构** — 内容的组织方式（递进/并列/对比）
- **方法论** — 可操作的方法/工具/框架
- **案例证据** — 支撑论点的关键案例
- **边界条件** — 方法论适用的前提与限制

### Step 3: 五维映射

将外部框架映射到满意解五维决策体系：

| 外部内容维度 | 五维映射 | 转化问题 |
|-------------|----------|----------|
| 人际关系/合作 | 🟤 土·刘禹锡 | 如何聚贤才为伍？ |
| 决策方法/标准 | ⚪ 金·司马贺 | 满意解标准是什么？ |
| 洞察/定力 | 🔵 水·观自在 | 如何在方寸之间以价值致远？ |
| 伦理/信任 | 🟢 木·孔子 | 仁义礼智信如何体现？ |
| 直觉/突破 | 🔴 火·六祖慧能 | 如何在压力中顿悟淬火？ |

### Step 4: 血液化输出

生成可直接使用的内部资产：
- **工作流** — 将方法论转化为步骤化的操作流程
- **检查清单** — 将要点转化为可勾选的检查项
- **决策模板** — 将框架转化为填空式的决策工具
- **话术库** — 将观点转化为可直接使用的表达
- **案例映射** — 将外部案例映射到满意解场景

### Step 5: 多形态产出

根据目标受众，生成不同形态的输出：

| 形态 | 内容特点 | 输出格式 |
|------|----------|----------|
| **内部深度版** | 完整逻辑+五维映射+实操细节 | Markdown文档 |
| **开源版** | 去敏感信息，可公开分享 | Markdown/PDF |
| **微信传播版** | 精简+故事化+视觉冲击 | 朋友圈文案/公众号文章 |
| **小红书版** | 年轻态+emoji+互动性 | 小红书笔记 |
| **培训课件版** | 结构化+可视化+互动设计 | PPT/Markdown |

## 质量检查点

每份内化报告完成后，自问：
- [ ] 核心论点是否准确提炼，无遗漏无曲解？
- [ ] 五维映射是否自然，非强行套用？
- [ ] 血液化成果是否可直接使用，无需二次加工？
- [ ] 是否区分了"作者观点"和"我的转化"？
- [ ] 开源版是否已去除所有敏感信息？

## 注意事项

⚠️ 内化不是复制，是创造性转化
⚠️ 尊重原创，明确标注来源
⚠️ 五维映射不是装饰，必须体现真实关联
⚠️ 血液化成果必须经过实际场景验证
⚠️ 定期回顾旧内化报告，更新迭代
