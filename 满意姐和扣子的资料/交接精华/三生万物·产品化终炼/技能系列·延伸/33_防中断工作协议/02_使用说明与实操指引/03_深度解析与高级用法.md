# 03_深度解析与高级用法

## 高级用法1：多任务防中断

**场景**：多个长任务同时进行

**方法**：
每个任务独立的进度追踪文件
切换任务时，先存档当前任务，再读取新任务进度

**示例**：
```
任务A（进行中）
  ↓ 用户插入紧急任务B
存档任务A → 创建任务B进度文件 → 执行任务B
  ↓ 任务B完成
存档任务B → 读取任务A进度 → 恢复任务A
```

## 高级用法2：团队防中断

**场景**：人类+AI协作的长任务

**方法**：
- 共享进度追踪文件（飞书/Notion）
- 人类执行时更新"人类部分"
- AI执行时更新"AI部分"
- 切换时阅读对方更新的进度

## 高级用法3：极端中断恢复

**场景**：系统崩溃、会话丢失、AI重启

**恢复步骤**：
1. 读取进度追踪文件（最可靠的线索）
2. 读取Git log（查看最后提交的内容）
3. 检查磁盘上的文件（确认哪些已完成）
4. 与创始人确认状态
5. 重新进入防中断模式
