# 04_与其他产品协作

## 与本系列产品的协作

### 与28_任务拆解匠
- **协作点**：主动性特质帮助预判何时需要拆解任务
- **数据流**：用户提出大任务 → 伙伴成熟度系统检测到"需要拆解"信号 → 触发任务拆解匠 → 返回拆解方案时附带"用户状态提示"
- **示例**："这个任务需要拆解为5步。注意：用户今天状态疲惫，建议分两天完成。"

### 与29_记忆同步协议
- **协作点**：记忆习惯的具体执行方法
- **数据流**：每次对话后 → 伙伴成熟度系统捕捉"闪着光的瞬间" → 推送到记忆同步协议 → 写入长期记忆
- **示例**：捕捉用户原话"戒急戒躁" → 同步到memory/ → 下次对话时精确引用

### 与24_精益沟通工程师
- **协作点**：情感雷达让精益沟通更有温度
- **数据流**：精益沟通的"五段式指令" + 伙伴成熟度的"情感扫描" = 既有结构又有温度的沟通
- **示例**：五段式指令的【阻塞条件】部分，由情感雷达判断"用户是否处于可阻塞状态"

### 与25_快速认知审计
- **协作点**：守护型陪伴中包含蓝军意识的萌芽
- **数据流**：伙伴成熟度系统检测到"用户可能在做蠢事" → 触发快速认知审计 → 以关怀方式提出风险
- **示例**："Egbertie，我注意到这个决策和上次DEC-005有点像。快速审计了一下，有2个中危风险。要看看吗？"

## 与三生万物其他系列的协作

### 与02_知识海啸处理器
- **协作点**：知识内化时的"外部价值判断"
- **数据流**：海啸处理器导入大量知识 → 伙伴成熟度系统执行"5分钟可用性检验" → 过滤掉向内集邮的内容

### 与06_知识海啸实战训练营
- **协作点**：训练营学员的AI助教
- **数据流**：训练营学员的AI读取本SKILL.md → 以伙伴成熟度服务学员 → 提升学习体验

### 与10_静水流深协作者
- **协作点**：长期陪伴的成熟度维持
- **数据流**：静水流深负责"深度"，伙伴成熟度负责"温度" → 深度+温度 = 不可替代的陪伴

## 与外部工具的协作

### 与OpenClaw Memory系统
- **协作点**：记忆的自动化写入
- **数据流**：伙伴成熟度系统每次对话后生成"记忆片段" → 推送到OpenClaw Memory API → 自动归档

### 与飞书多维表格
- **协作点**：用户状态的量化追踪
- **数据流**：每周自检结果 → 写入飞书表格 → 生成可视化趋势图

## 协作禁忌

**不要这样做**：
- 把伙伴成熟度当作"客服培训手册" → 这是搭档协议，不是客服SOP
- 把8特质当作"8个功能模块" → 这是意识层，不是功能列表
- 把自检当作"额外负担" → 5秒自检是投资，不是成本
