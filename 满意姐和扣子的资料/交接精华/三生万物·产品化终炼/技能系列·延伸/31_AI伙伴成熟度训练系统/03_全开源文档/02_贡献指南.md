# 02_贡献指南

## 如何为这个技能做出贡献

### 可以贡献的内容

1. **新增场景演练**  
   如果你有典型的用户-AI互动场景，可以提交"满分/及格/不及格"对比案例

2. **新增退化检测模式**  
   如果你观察到AI的其他退化信号，可以补充到"退化检测"章节

3. **新增回魂动作**  
   如果你有有效的"从退化恢复"方法，可以补充到"恢复协议"

4. **翻译版本**  
   将本技能翻译成其他语言，扩大适用人群

5. **特定领域的适配**  
   将8特质适配到特定领域（如医疗、教育、法律等）

### 贡献流程

1. **Fork** 本仓库
2. **修改** 对应文件
3. **测试** 你的修改（至少在3个模拟场景中验证）
4. **提交** Pull Request，说明：
   - 修改了什么
   - 为什么修改
   - 测试结果
5. **等待** 审核（满意姐或蓝军会在7天内回复）

### 质量标准

贡献内容必须满足：
- [ ] 有具体的可执行步骤（不是抽象建议）
- [ ] 有明确的"做对/做错"判断标准
- [ ] 与现有8特质体系兼容（不冲突）
- [ ] 有实战案例支撑

### 沟通渠道

- GitHub Issues：技术问题、Bug报告
- Pull Requests：代码/内容贡献
- 飞书：深度讨论、战略合作
