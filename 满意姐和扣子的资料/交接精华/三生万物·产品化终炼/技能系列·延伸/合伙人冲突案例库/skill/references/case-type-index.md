## Type13: 心理契约违背型

**核心特征**: 未明说的期望与承诺被违背，导致深层情感伤害与关系破裂
**危险等级**: 🔴 高危
**新增类型说明**:
> 心理契约（Psychological Contract）概念源自组织行为学，指雇佣关系中双方对彼此义务的非书面期望。在合伙人关系中，心理契约更为复杂——它包含了创始人之间的隐性承诺、共同愿景的默契、以及对"我们"这一身份的认同。当这些未被言明的期望被违背时，伤害往往比书面合同的违约更深。

**常见场景**:
- 创始人承诺"一起走到最后"，却在困难时期选择保全自己
- 隐性承诺的"平等伙伴关系"被实际行动否定（如信息不对称、单方面决策）
- "兄弟情义"被商业利益优先的现实击碎
- 共同创业时的"理想主义"被后来的"现实主义"背叛
- 对方的行为违背了你对"合伙人"这一角色的深层定义

**典型案例标签**:
- 兄弟情义变质
- 隐形承诺破灭
- "你变了"综合征
- 理想主义崩塌
- 身份认同危机

**五维决策要点**:
- 🟤 土: 心理契约是"同行"的无形根基——斯是陋室，惟吾德馨，德馨不在合同里，在心里
- ⚪ 金: 心理契约的修复几乎没有满意解，因为伤害发生在情感层面，理性方案难以触及
- 🔵 水: 观自在：你对"合伙人"的期望是否现实？对方是否知道这些期望？
- 🟢 木: "信"（信任）和"仁"（仁爱）是心理契约的核心——一旦违背，五常动摇
- 🔴 火: 直觉最早感知到"不对劲"，但理性会自我说服"不要想太多"

**与Type02（信任破裂型）的区别**:
| 维度 | Type02 信任破裂 | Type13 心理契约违背 |
|------|----------------|-------------------|
| **契约形式** | 明确的合同/承诺被违背 | 隐性的、未言明的期望被违背 |
| **伤害性质** | 理性层面的"被欺骗" | 情感层面的"被辜负" |
| **修复可能** | 通过补偿/道歉可能修复 | 几乎无法修复，因为期望本身未被认可 |
| **典型话语** | "你骗了我" | "你不再是那个你了" |
| **诉讼可能** | 有法律追索权 | 无法诉诸法律 |

**预警信号**:
1. 频繁出现"我以为...""我以为你知道..."
2. "如果当初知道是这样，我不会..."
3. 一方感到"被利用"而非"被尊重"
4. 关系中的"不平等感"无法通过理性解释消除
5. "心寒""失望"等情感词汇频繁出现

**治理工具**:
- **心理契约显性化协议**: 定期将隐性期望转化为书面共识
- **角色期望书**: 明确每个人对"合伙人"角色的定义与期望
- **情感温度季度评估**: 不仅是业务复盘，更是关系复盘
