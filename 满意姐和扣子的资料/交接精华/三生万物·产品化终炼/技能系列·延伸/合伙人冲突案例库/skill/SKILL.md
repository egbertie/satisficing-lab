# Partner Conflict Case Library — 13类型合伙人冲突案例库

## 核心能力

基于满意解研究所84份真实案例（含模拟案例），覆盖**13种**典型合伙人冲突类型，
为硬科技创业企业的合伙人匹配与关系治理提供决策支持。

## 使用流程

### Step 1: 冲突类型诊断

用户提供合伙人冲突描述后，按以下维度进行快速分类：

| 诊断维度 | 关键问题 |
|----------|----------|
| **权力维度** | 谁说了算？是否有明确的决策权划分？ |
| **信任维度** | 是否存在隐瞒、欺骗、背叛行为？ |
| **利益维度** | 股权/分红/资源分配是否公平？ |
| **价值维度** | 对公司方向、文化、底线是否有根本分歧？ |
| **角色维度** | 各自职责是否清晰？是否有重叠或真空？ |

### Step 2: 13类型匹配

根据诊断结果，匹配到13类型之一：

| 类型 | 名称 | 核心特征 | 危险等级 |
|------|------|----------|----------|
| Type01 | 控制权争夺型 | 决策权归属不明，"谁说了算"成为核心矛盾 | 🔴 高危 |
| Type02 | 信任破裂型 | 隐瞒、欺骗、背叛导致信任基础崩塌 | 🔴 高危 |
| Type03 | 利益分配型 | 股权/分红/资源分配感知不公 | 🟡 中危 |
| Type04 | 价值观冲突型 | 对公司方向、文化、底线有根本分歧 | 🔴 高危 |
| Type05 | 角色模糊型 | 职责边界不清，重叠或真空 | 🟡 中危 |
| Type06 | 能力不匹配型 | 合伙人能力与角色要求严重不匹配 | 🟡 中危 |
| Type07 | 退出机制型 | 退出条款缺失或执行争议 | 🟡 中危 |
| Type08 | 外部干预型 | 外部力量（投资人/家人/政府）介入冲突 | 🟡 中危 |
| Type09 | 沟通障碍型 | 信息不透明，沟通渠道失效 | 🟢 可控 |
| Type10 | 决策僵局型 | 重大事项无法达成一致，公司陷入停滞 | 🟡 中危 |
| Type11 | 资源争夺型 | 预算、人才、客户等资源分配冲突 | 🟢 可控 |
| Type12 | 代际传承型 | 创始人代际交接中的权力与价值传承 | 🟡 中危 |
| Type13 | 心理契约违背型 | 未明说的期望与承诺被违背，深层情感伤害 | 🔴 高危 |

### Step 3: 案例匹配与策略建议

确定类型后：
1. **读取对应类型的典型案例摘要**（见 references/case-type-index.md）
2. **提取该类型的共性规律与应对框架**
3. **结合五维决策体系给出建议**

### Step 4: 深度案例链接

如需详细案例，链接到案例库：
```
A-manyige/项目版本/V1.6/案例库/模拟案例/Type{NN}_{类型名}/
```

## 五维决策框架应用

每种类型的应对策略都应嵌入五维决策视角：

| 维度 | 对应图腾 | 核心问题 |
|------|----------|----------|
| **土·刘禹锡** | 聚贤才为伍 | 这个人还值得同行吗？ |
| **金·司马贺** | 满意解标准 | 什么结果是可以接受的？ |
| **水·观自在** | 方寸价值 | 冷静后，真正重要的是什么？ |
| **木·孔子** | 伦理五常 | 仁义礼智信，哪一条被触犯了？ |
| **火·六祖慧能** | 顿悟红莲 | 直觉告诉你什么？ |

## 注意事项

⚠️ 案例库中的模拟案例基于真实场景改编，已脱敏处理
⚠️ 每份案例包含7文档结构：背景/冲突描述/五维分析/决策建议/预防措施/延伸思考/参考资源
⚠️ Type01/02/04/**13** 为高危类型，建议立即启动深度介入
⚠️ 本技能不提供法律建议，涉及法律问题必须转介专业律师
