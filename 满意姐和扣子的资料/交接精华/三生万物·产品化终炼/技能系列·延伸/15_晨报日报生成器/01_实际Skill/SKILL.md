# 晨报日报生成器

> **编号**: SANSHENG-SKILL-015
> **定位**: 自动化生成每日晨报与日报，整合任务追踪、决策清单、Token监控、系统健康检查
> **触发词**: "晨报" / "日报" / "今日重点" / "晨间仪式" / "07:11" / "今日概览"
> **五维映射**: 土(根基) + 水(流动) + 金(标尺)

---

## 一、Why

创始人每天早上最需要什么？

**不是更多信息，是"今天该聚焦什么"。**

**问题**:
- 早上起来，不知道昨天走到哪了
- 任务太多，不知道哪个最优先
- Token用了多少？系统健康吗？容易忽略

**解决**: 每日07:11自动生成晨报，3分钟看完，聚焦今日。

---

## 二、What

### 2.1 晨报内容（07:11生成）

| 模块 | 内容 | 来源 |
|------|------|------|
| **日期标识** | 今日日期 + 星期 | 系统 |
| **今日重点** | Top 3 必须完成的任务 | TASK_MASTER.md |
| **决策清单** | 待确认/待执行的决策 | 决策索引 |
| **Token状态** | 本周用量 + 档位 | session_status |
| **系统健康** | 磁盘/内存/Git状态 | 系统检查 |
| **昨日完成** | 昨日已完成的关键交付 | 进度追踪 |
| **风险提示** | 最高1个风险项 | 风险评估 |

### 2.2 日报内容（18:00生成）

| 模块 | 内容 |
|------|------|
| **今日完成** | 已完成任务清单 |
| **未完成任务** | 及原因 |
| **Token消耗** | 当日消耗 + 累计 |
| **新决策** | 今日做出的决策 |
| **明日计划** | Top 3 明日任务 |

### 2.3 输出格式

```markdown
# 晨报 - YYYY-MM-DD 星期X

## 🔥 今日重点
1. {任务A}
2. {任务B}
3. {任务C}

## 📋 决策清单
- [ ] DEC-042: 待确认
- [x] DEC-041: 已执行

## 💰 Token状态
本周: X% | 档位: L1正常

## 🖥️ 系统健康
磁盘: 53% 🟢 | 内存: OK 🟢

## ✅ 昨日完成
- {交付物}

## ⚠️ 风险
{最高风险项}
```

## 三、How

### 3.1 触发方式

**自动**:
```
Cron: 每日07:11自动生成晨报
Cron: 每日18:00自动生成日报
```

**手动**:
```
"生成今日晨报"
"帮我看看今天该做什么"
"今日重点"
```

### 3.2 数据来源

```
TASK_MASTER.md → 任务状态
memory/YYYY-MM-DD.md → 当日日志
decisions/INDEX.md → 决策状态
session_status → Token数据
系统检查 → 磁盘/内存/Git
```

### 3.3 配套脚本

```bash
# 生成晨报
python3 scripts/morning_report_generator.py

# 生成日报
python3 scripts/evening_report_generator.py

# 查看今日重点（简化版）
python3 scripts/today_focus.py
```

## 四、与三生万物体系衔接


## 五、红线与边界

| 红线 | 说明 |
|------|------|
| 不替代思考 | 晨报是聚焦工具，不是决策工具 |
| 不超过5项 | 重点超过5项=没有重点 |
| 不重复信息 | 晨报只展示"变化"，不变的不展示 |
| 不忽略风险 | 即使有1个风险，也必须展示 |
