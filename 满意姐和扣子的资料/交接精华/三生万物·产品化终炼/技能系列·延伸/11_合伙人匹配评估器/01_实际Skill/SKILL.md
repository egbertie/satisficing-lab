# 合伙人匹配评估器 (Partner Match Evaluator)

> **定位**: 硬科技合伙人匹配的量化评估工具，从五维视角评估合伙人适配度
> **触发词**: "匹配评估" / "合伙人" / "评估匹配" / "团队互补"
> **编号**: SANSHENG-SKILL-011
> **五维映射**: 土(根基) + 金(标尺) + 水(流动)

---

## 一、Why

硬科技创业最致命的风险：合伙人不匹配。
- 技术创始人找商业合伙人 → 价值观冲突
- 连续创业者找技术合伙人 → 沟通断层
- 投资人看团队 → 看不出互补性

**核心价值**: 用五维模型量化评估合伙人适配度，从"凭感觉"到"有依据"。

---

## 二、What

### 2.1 评估维度

基于满意解研究所五维决策体系：

| 维度 | 评估内容 | 权重 |
|:-----|:---------|:-----|
| 土(根基) | 价值观、诚信、长期承诺 | 25% |
| 金(标尺) | 决策风格、风险偏好、目标一致性 | 25% |
| 水(流动) | 沟通模式、冲突处理、适应性 | 20% |
| 木(生长) | 成长意愿、学习能力、互补性 | 15% |
| 火(洞察) | 直觉判断、创新思维、行动力 | 15% |

### 2.2 评估输出

- **适配度评分**: 0-100分
- **风险雷达图**: 五维可视化
- **互补性矩阵**: 双方各维度对比
- **建议清单**: 提升适配度的具体行动

### 2.3 三档评估

| 模式 | 时长 | 深度 |
|:-----|:-----|:-----|
| 🟢 快速扫描 | 15分钟 | 10个关键问题 |
| 🟡 标准评估 | 45分钟 | 五维全量问卷 |
| 🔴 深度诊断 | 90分钟 | 五维+冲突模拟+压力测试 |

---

## 三、How

### 3.1 触发方式

```
"匹配评估 [合伙人A] [合伙人B]"
"快速匹配 [候选人] [岗位]"
"深度诊断 [现有团队]"
```

### 3.2 配套脚本

```bash
# 标准评估
python3 scripts/partner-evaluator.py --a partnerA.md --b partnerB.md

# 快速扫描
python3 scripts/quick-match.py --target role.md --candidate candidate.md

# 互补性分析
python3 scripts/complementarity-matrix.py --team team.md

# 风险雷达图生成
python3 scripts/radar-chart.py --scores scores.json
```

## 四、红线与边界

| 红线 | 说明 |
|:-----|:-----|
| 不做决定 | 只提供评估，决策由人类做 |
| 不替代面谈 | 评估不能替代真实相处 |
| 动态更新 | 人是变化的，评估需定期更新 |
| 保密原则 | 评估数据属于用户，不得外泄 |
