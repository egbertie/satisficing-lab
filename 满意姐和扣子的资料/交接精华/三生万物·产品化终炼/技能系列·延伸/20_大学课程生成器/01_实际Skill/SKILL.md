# 大学课程生成器

> **编号**: SANSHENG-SKILL-020
> **定位**: 《满意解决策科学：五维决策体系》大学课程的自动化生成与管理
> **触发词**: "大学课程" / "课程生成" / "五维决策课程" / "满意解课程" / "教学大纲"
> **五维映射**: 土(根基) + 金(标尺) + 木(伦理)

---

## 一、Why

**决策科学应该走进大学课堂。**

**问题**:
- 现有商学院课程缺少"满意解"视角
- 合伙人决策没有系统化教学
- 五维决策体系需要载体传播

**解决**: 大学课程生成器 — 自动生成《满意解决策科学》完整课程体系。

---

## 二、What

### 2.1 课程结构

| 编 | 章节 | 课时 | 形式 |
|----|------|------|------|
| 总纲 | 课程导论 | 2 | 讲授 |
| 第一编 | 决策科学基础 | 8 | 讲授+案例 |
| 第二编 | 五维决策体系 | 12 | 讲授+工作坊 |
| 第三编 | 合伙人决策专题 | 10 | 案例+模拟 |
| 第四编 | 硬科技转化决策 | 8 | 项目实战 |
| 第五编 | 决策教练执业 | 6 | 实习+认证 |

**总计**: 46课时 + 2课时导论 = 48课时（16周 × 3课时）

### 2.2 课程特色

- **双认证对称**: CBIIP（商业直觉）× CDAA（数字资产分析）
- **12类型案例库**: 每章配套真实案例
- **五维工作坊**: 理论与实践结合
- **决策卡牌游戏**: 互动教学工具

### 2.3 输出物

- 教学大纲（16周）
- 每章讲义（Markdown）
- PPT课件
- 案例库索引
- 考试题库
- 学生作业模板

---

## 三、How

### 3.1 触发方式

```
"生成大学课程大纲"
"生成第X章讲义"
"生成考试题目"
"课程进度追踪"
```

### 3.2 配套脚本

```bash
# 生成完整课程
python3 scripts/course_generator.py --full

# 生成单章
python3 scripts/chapter_generator.py --chapter 3 --topic "五维决策体系"

# 生成考试题
python3 scripts/exam_generator.py --chapter 1-5 --difficulty medium
```
