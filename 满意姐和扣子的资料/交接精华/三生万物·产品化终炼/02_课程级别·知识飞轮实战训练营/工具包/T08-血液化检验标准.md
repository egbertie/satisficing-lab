# T08 血液化检验标准（L0-L4）

## L0: 存储（未血液化）
- [ ] 过去30天被打开过？
- [ ] 和其他文件有关系？
- [ ] 接到任务时会主动想到？

**占比建议**: ≤20%

## L1: 读取（初级）
- [ ] 能回答"讲了什么"？
- [ ] 能提取3个关键要点？
- [ ] 能判断和当前任务的关系？

**占比建议**: 30-40%

## L2: 连接（中级）
- [ ] 和≥3个其他知识点有关系？
- [ ] 条件改变能自动调用？
- [ ] 能判断"该用A还是B"？

**占比建议**: 20-30%

## L3: 执行（高级）
- [ ] 能不看原始文件直接执行？
- [ ] 执行中能自动调用知识？
- [ ] 意外情况能合理判断？

**占比建议**: 10-20%

## L4: 创新（完全）
- [ ] 能提出"如果...会怎样"？
- [ ] 能发现盲区或矛盾？
- [ ] 能设计实验验证？

**占比建议**: 5-10%

## 检验流程
1. 随机抽样10个知识点
2. 自评L0-L4
3. 他评L0-L4
4. 差距>1级，讨论原因
5. 对L0/L1制定血液化计划

## 健康指标
L3+L4占比 ≥30% → 飞轮能自转
