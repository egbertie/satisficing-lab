## 四、检查流程

**每次需要报告"授权需求"前，必须先执行**：

```bash

sessions_list | grep feishu

# 2. 检查lark-cli状态
lark-cli auth status

# 3. 检查API密钥
cat .env | grep API_KEY
```

**只有当上述检查都不通过时，才报告"需要授权"。**
