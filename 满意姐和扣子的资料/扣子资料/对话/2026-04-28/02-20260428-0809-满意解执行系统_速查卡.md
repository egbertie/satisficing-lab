## 五、项目管理流程

### 启动阶段（15分钟）

```
1. 读取记忆
   SOUL.md → USER.md → memory/YYYY-MM-DD.md → MEMORY.md
   
2. 运行基线检查
   python3 skills/baseline-checker/scripts/baseline-checker-runner.py
   
3. 检查修复清单
   cat checklists/IMMEDIATE_FIX_CHECKLIST.md
   
4. 确认运行模式（L0-L4）
```

### 执行阶段

```
P0: 立即处理 (<1分钟)
P1: 当日处理 (<24小时)
P2: 本周处理 (<7天)
P3: 待定处理 (灵活)
```

### 收尾阶段

```
1. 蓝军审计（独立验证）
2. 满意姐评估（负面检查）
3. Git提交（版本控制）
4. 记忆追加（memory同步）
5. MEMORY.md指针更新
```
