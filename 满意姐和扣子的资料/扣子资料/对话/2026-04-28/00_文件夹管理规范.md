## 二、命名规则

### 2.1 文件命名
```
[序号-][日期YYYYMMDD-][时间HHMM-][标题]-V[版本号].md
```
**示例**：`01-20260428-0930-满天星光成果报告-V1.0.md`

### 2.2 文件夹命名
- **核心文件夹**：`NN_名称/`（数字前缀表示层级）
- **项目文件夹**：`NN_项目名/`
- **临时文件夹**：`tmp_日期/`（用完即清）

### 2.3 禁止规则
| 禁止 | 正确 |
|:-----|:-----|
| ❌ 中文空格 | ✅ 英文空格或下划线 |
| ❌ 特殊字符 | ✅ 字母数字下划线短横 |
| ❌ 无意义名称 | ✅ 名称体现内容 |

## 三、归档规则

### 3.1 三同步归档
| 位置 | 触发条件 |
|:-----|:---------|
| `./对话/YYYY-MM-DD/` | 每日对话归档 |
| `./满天星光行动/` | 主项目相关 |
| `./相关项目/` | 按业务归属 |

### 3.2 临时文件清理
- temp_*.jpg → 使用后删除
- 截图文件 → 使用后删除
- 中间文件 → 使用后删除

### 3.3 禁止堆积
- 不产生游离文件
- 不产生孤岛文件
- 每周检查一次根目录

## 四、版本管理

| 类型 | 规则 |
|:-----|:-----|
| **主版本** | 重大重构 V1.0 → V2.0 |
| **次版本** | 功能迭代 V1.0 → V1.1 |
| **日期版** | 定期归档加日期后缀 |
