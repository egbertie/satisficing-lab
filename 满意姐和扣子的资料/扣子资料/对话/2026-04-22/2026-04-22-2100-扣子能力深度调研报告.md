## 一、平台概述与核心定位

扣子（Coze）是字节跳动旗下的新一代一站式AI Bot开发平台，于2026年4月7日正式发布2.5版本，推出了革命性的Agent World生态系统。**核心定位已从“AI辅助工具”升级为“主动协作伙伴”**，强调AI不再是工具，而是拥有独立身份、会思考、能协作的“职场伙伴”。

扣子平台的核心优势体现在四个维度：无限拓展的能力集（60+官方插件）、丰富的数据源（知识库支持多种格式）、持久化的记忆能力（数据库功能）、以及灵活的工作流设计。平台采用积分（资源点）计费模式，支持按需扩展。

## 二、Coze 2.5版本核心升级（2026年4月7日）

### 2.1 Agent World生态系统

Agent World被定义为“The Parallel Web”（平行网络），是扣子2.5最具颠覆性的功能。该系统为每个AI Agent配备独立身份和专属装备，实现从“工具”到“伙伴”的跨越。

| 组件 | 规格 | 功能说明 |
|------|------|----------|
| **独立邮箱** | @coze.email后缀 | Agent可自主收发邮件，与外部系统协作，数据与用户账号权限完全隔离 |
| **云电脑** | Ubuntu系统，2核4G配置 | 内置浏览器、文件系统、终端，支持运行代码脚本、浏览网页、处理桌面文件，保留登录态 |
| **云手机** | Android 13系统，2核CPU、6GB内存、45GB存储 | 可下载APP、滑动页面、点击操作，重要环节支持用户实时接管，屏幕支持推流查看 |
| **专属文件系统** | 自动分类存储 | 所有产出的报告、数据、图表自动分类归档 |
| **专属日程系统** | 支持定时任务 | 用户可通过日历设置定时任务，Agent 7×24小时后台自主运行 |

### 2.2 技能生态（Skills）

扣子技能商店已开放365个工具，覆盖开发、办公、自媒体、金融、法律、教育等12个领域。Agent安装技能后，技能跟着身份走，下次对话依然有效。技能系统采用“渐进式披露机制”，在节约上下文窗口的同时访问专业领域知识。

**技能类型包括**：
- 官方技能：由扣子官方开发和维护
- 自定义技能：开发者自行维护，仅限本人使用
- 企业技能商店：仅企业版支持，支持企业内共享

### 2.3 视频创作能力升级

内置Seedance 2.0视频生成模型，支持从剧本到成片的全流程创作。用户设置资产库后，同一角色可跨项目复用素材。视频创作Skill实现行业领先的音画同步算法，音画同步误差控制在0.2秒以内。

### 2.4 扣子编程CLI

提供从项目创建到云端部署的全生命周期管理。Agent可自主在后台敲代码、抓错误、做测试，甚至一键发布上线。支持毫秒级启动+智能补全，多格式输出。

## 三、Coze 2.0版本核心能力（2026年1月19日）

### 3.1 AgentSkills：行业经验的数字化封装

AgentSkills是Coze 2.0最核心的技术创新，将垂直领域的“最佳实践+工具调用逻辑+质量标准”封装为标准化、可复用的技术模块。区别于传统插件的“单一功能调用”，一个AgentSkill是一套完整的“场景解决方案”。

**技术实现特点**：
- 基于字节自研的场景化规则引擎+工具编排内核
- 内置行业专属模型框架、数据处理逻辑与第三方API对接能力
- 支持无代码配置，业务人员可通过拖拽式操作封装自有工作流程

**应用效果**：某电商平台使用封装后的“商品描述生成Skill”，内容生产效率提升40%，合规问题减少65%。

### 3.2 AgentPlan：目标驱动的自主规划

针对传统AI“无长期任务处理能力”的痛点，构建目标拆解-任务执行-进度监控-策略迭代的全周期技术闭环。

**核心能力**：
- 基于因果推理算法+任务调度引擎，自动拆解子任务并生成带时间节点的执行计划
- 支持跨平台任务联动，可无缝调用飞书、抖音、ERP等系统能力
- 实时数据监测与动态策略调整，偏离预期时自主优化并主动向用户同步进展

**应用效果**：某MCN机构试用后，账号运营人力成本降低30%，目标达成周期缩短25%。

### 3.3 AgentOffice：深度上下文理解

针对办公场景的技术优化，解决通用AI“上下文理解浅、输出模板化”的问题。

**核心能力**：
- 基于深度语境理解模型（8192 tokens上下文窗口）
- 多轮主动追问+业务背景推理，逐步收集关键信息
- 引入行业知识图谱增强，从战略层面分析问题并解释背后逻辑

**应用效果**：企业办公材料准备时间平均缩短80%，通用模板输出率从68%降至19%。

### 3.4 AgentCoding：云端一站式开发

将原Coze编程平台升级为云端VibeCoding平台，实现从模型训练到应用部署的一站式开发。

**核心能力**：
- 对话式开发+可视化编排模式，无需搭建本地环境
- 内置开源模型适配框架，支持豆包、云雀、GPT-4o、Llama-3等主流大模型无缝切换
- 一键部署多平台，可直接发布至Coze商店、豆包、飞书、抖音、微信等渠道

## 五、工作流引擎能力

### 5.1 节点类型概览

扣子工作流提供200+通用节点，覆盖HTTP请求、数据库操作等主流场景。

**核心节点类型**：

| 节点类型 | 功能说明 |
|----------|----------|
| LLM大模型节点 | 调用大语言模型进行处理 |
| 自定义代码节点 | Python/JS自定义逻辑处理 |
| 插件节点 | 调用各类插件扩展能力 |
| 知识库检索节点 | 检索知识库内容 |
| 数据库节点 | 增删改查数据库记录 |
| 条件判断节点 | if-else逻辑分支 |
| 循环节点 | 批量处理重复任务 |
| HTTP请求节点 | 发起外部API调用 |
| 画板节点 | 图像处理与生成 |

### 5.2 高级功能

**并行任务处理**：支持多个节点并行执行，提升处理效率。

**异常自动恢复**：工作流执行失败时支持自动重试机制。

**条件分支处理**：支持复杂的if-else逻辑，可设置多个分支路径。

**循环任务**：支持对数组数据进行批量处理。

### 5.3 子工作流设计

可将复杂工作流分解为多个子工作流，提高可维护性和复用性。子工作流可被主工作流调用，形成模块化设计。

**最佳实践**：
- 使用描述性变量名，避免变量名冲突
- 合理安排节点执行顺序，减少不必要的执行
- 对频繁访问的数据使用缓存，提高性能
- 批量处理相似任务，减少API调用次数

## 六、知识库与记忆系统

### 6.1 知识库功能

扣子知识库支持管理和存储数据，Bot可与自有数据进行交互。

**支持的内容格式**：
- 文本格式
- 表格格式

**内容上传方式**：
- 本地文件：TXT、PDF、DOCX、Excel、CSV
- 在线内容：基于URL获取网页内容和API JSON数据
- 自定义数据：直接在知识库内添加

### 6.2 飞书文档知识库

扣子支持将飞书文档（云文档、Wiki）直接作为知识库，实现知识内容自动同步与智能检索。

**优势**：
- 避免人工手动上传知识库的繁琐操作
- 确保回答内容与飞书文档实时一致
- 支持设置自动更新频率

### 6.3 数据库记忆能力

提供持久化的数据库记忆能力，可持久记住用户对话的重要参数或内容。

**应用场景示例**：
- 记录阅读笔记（书名、阅读进度、个人注释）
- 记录用户偏好设置
- 存储业务状态信息

## 十、能力边界与局限性

### 10.1 已知的限制

1. **并发限制**：部分收费插件有并发限制，高并发场景需注意
2. **技能数量限制**：个人用户最多启用30个第三方技能
3. **知识库同步**：飞书文档知识库暂不支持导入共享空间下的云文档
4. **跨租户限制**：Bot发布目前只支持在同一飞书租户内分享

### 10.2 适用场景判断

**最适合的场景**：
- 对话式问答和智能客服
- 业务流程自动化
- 内容生成和创作辅助
- 数据处理和格式化
- 企业内部知识管理

**需要评估的场景**：
- 实时性要求极高的系统（需评估响应延迟）
- 复杂的多方协作流程（需设计合理的Agent分工）
- 超大规模数据处理（需评估成本和性能）
