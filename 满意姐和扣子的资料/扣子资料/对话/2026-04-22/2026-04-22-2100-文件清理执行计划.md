## 二、删除任务执行

### 2.1 删除文件分类

| 分类 | 数量 | 删除条件 | 风险等级 |
|:-----|:----:|:---------|:--------:|
| 重复文件 | 300+ | 飞书已同步的本地副本 | 🟡 中 |
| 临时文件 | 200+ | 测试、调试、临时工作文件 | 🟢 低 |
| 过期文件 | 150+ | V1.5及更早版本 | 🟡 中 |
| 损坏文件 | 50+ | 无法正常打开的文件 | 🟢 低 |
| 无效引用 | 60+ | 引用链接已失效 | 🟢 低 |

### 2.2 删除执行步骤

```
步骤1：确认删除清单
├── 检查待删除文件清单是否存在
├── 核对文件数量和分类
└── 确认无重要文件遗漏

步骤2：备份重要文件
├── 备份到 _待删除/_backup
└── 保留7天后自动清理备份

步骤3：执行删除
├── 第一批：临时文件（200+）
├── 第二批：重复文件（300+）
├── 第三批：过期文件（150+）
└── 第四批：损坏+无效（110+）

步骤4：验证删除结果
├── 检查已删除文件数量
├── 验证无重要文件被误删
└── 生成删除报告
```

### 2.3 删除清单预览

**第一批：临时文件（风险低，优先删除）**
```
_临时/
├── temp_*.tmp
├── debug_*.log
├── test_*.*
└── *_backup.*
```

**第二批：重复文件（需核对后删除）**
```
重复文件判断标准：
├── 文件名相同
├── 内容相同（MD5校验）
└── 飞书已存在副本
```

**第三批：过期文件**
```
过期文件判断标准：
├── 版本标注为V1.5或更早
├── 创建日期早于2026-04-01
└── 内容已被新版本替代
```
