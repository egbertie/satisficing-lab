# 重复内容缓存机制

> **文档版本**: V1.0
> **编制时间**: 2026-04-22
> **任务来源**: TO-04 重复内容缓存机制设计
> **维护原则**: 减少重复计算，节省Token消耗

---

## 一、设计背景

### 1.1 问题痛点

| 问题类型 | 表现 | Token消耗影响 |
|---------|------|---------------|
| 重复搜索 | 相同问题多次搜索 | 浪费搜索Token |
| 重复读取 | 同一文件反复读取 | 极低但可优化 |
| 重复生成 | 相似内容重复生成 | 高额Token消耗 |
| 重复理解 | 上下文累积未清理 | 指数级增长 |

### 1.2 设计目标

```
目标：构建多层级缓存体系，实现"一次计算，多次复用"
```

| 层级 | 缓存内容 | 预期节省 |
|------|----------|----------|
| L1 本地缓存 | 文件内容片段 | 0 Token |
| L2 记忆缓存 | 历史对话摘要 | 极低 |
| L3 语义缓存 | 相似问答结果 | 50%+ |
| L4 工具缓存 | API响应结果 | 30%+ |

## 三、缓存策略细则

### 3.1 L1 本地文件缓存

**策略**：利用本地文件系统作为天然缓存

| 场景 | 缓存方法 | Token节省 |
|------|----------|-----------|
| 重复读取同一文件 | read_file + 记录已读 | 0 |
| 检查文件更新 | ls + mtime对比 | 0 |
| 批量读取 | bash + 预加载 | 0 |
| 文件存在性检查 | bash + test | 0 |

**执行标准**：
```bash
# 已读取文件记录到上下文
已读文件: [文件路径列表]
# 再次需要时先检查是否已读
```

### 3.2 L2 记忆缓存

**策略**：通过memory_search复用历史理解

| 场景 | 缓存方法 | Token节省 |
|------|----------|-----------|
| 搜索历史答案 | memory_search语义搜索 | 极低 |
| 验证记忆准确性 | read_file交叉验证 | 极低 |
| 任务状态查询 | 记忆检索 | 极低 |

**执行标准**：
```
任务开始 → memory_search(关键词) → 有结果 → 复用
                                     ↓ 无结果
                                  执行新计算 → 结果入库
```

### 3.3 L3 语义缓存

**策略**：基于问题语义相似度复用答案

| 场景 | 缓存方法 | Token节省 |
|------|----------|-----------|
| 相似问题 | 语义匹配 | 50%+ |
| 模板查询 | 模板库检索 | 40%+ |
| 知识点复用 | 知识库查询 | 60%+ |

**相似度判定标准**：
| 相似度 | 处理方式 | Token消耗 |
|--------|----------|-----------|
| ≥90% | 直接复用 | 0 |
| 70-90% | 轻微调整后复用 | 10% |
| 50-70% | 参考后生成 | 30% |
| <50% | 重新计算 | 100% |

### 3.4 L4 工具缓存

**策略**：缓存工具调用结果

| 场景 | 缓存方法 | Token节省 |
|------|----------|-----------|
| 搜索结果缓存 | 搜索结果写入临时文件 | 30%+ |
| API响应缓存 | JSON文件存储 | 40%+ |
| 图片URL缓存 | file_to_url结果 | 20%+ |

## 四、缓存管理机制

### 4.1 缓存存储结构

```
./04_系统资产/缓存资产/
├── L1_本地缓存/
│   ├── 已读文件清单.md
│   └── 文件状态记录.md
├── L2_记忆缓存/
│   ├── 对话摘要库.md
│   └── 任务记录库.md
├── L3_语义缓存/
│   ├── 问答配对库.md
│   ├── 知识点库.md
│   └── 模板库/
├── L4_工具缓存/
│   ├── 搜索结果缓存/
│   └── API响应缓存/
└── cache_index.md  # 缓存索引
```

### 4.2 缓存有效期

| 缓存类型 | 有效期 | 更新策略 |
|---------|--------|----------|
| 文件缓存 | 文件mtime变化前有效 | 检查mtime |
| 记忆缓存 | 长期有效 | 记忆模块管理 |
| 语义缓存 | 30天 | 定期复核 |
| 工具缓存 | 24小时 | 时间戳比对 |

### 4.3 缓存清理规则

| 触发条件 | 清理范围 | 执行频率 |
|---------|---------|---------|
| 缓存文件超100个 | L4临时缓存 | 每周 |
| 单缓存超1MB | 单文件清理 | 实时 |
| 系统重启 | L4清理，L1-3保留 | 按需 |
| 手动触发 | 可指定 | 按需 |
