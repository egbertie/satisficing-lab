## 二、各交付物详细说明

### 2.1 问卷.md

#### 文件路径
```
./满意解研究所/02_案例体系/TYPE01-股权分配冲突/A01-技术合伙人的委屈/问卷.md
```

#### 核心内容

| 模块 | 内容 | 用途 |
|:-----|:-----|:-----|
| 前测问卷 | 7道题 | 了解用户背景、角色、经验、满意解认知 |
| 决策问卷 | 场景描述 + 5道题 | 引导用户做出4选1决策 |
| 后测问卷 | 7道题 | 评估学习效果、满意度、推荐意愿 |
| 数据结构 | 飞书多维表格字段设计 | 数据存储和关联 |

#### 问卷设计亮点

1. **前测问卷** - 用户分层
   - 识别新手用户 vs 有经验用户
   - 为个性化报告打基础

2. **决策问卷** - 沉浸式场景
   - 第一人称代入感
   - 多维度考察决策逻辑

3. **后测问卷** - 学习闭环
   - 学习收获评估
   - 推荐意愿追踪

### 2.2 卡牌设计.md

#### 文件路径
```
./满意解研究所/02_案例体系/TYPE01-股权分配冲突/A01-技术合伙人的委屈/卡牌设计.md
```

#### 核心内容

| 模块 | 内容 | 说明 |
|:-----|:-----|:-----|
| 卡牌正面 | 标题、插图、金句 | 第一印象，唤起共鸣 |
| 卡牌背面 | 背景故事、冲突分析、决策问题 | 完整场景呈现 |
| 选项详解 | A/B/C/D四个选项的完整分析 | 每个选项的逻辑、风险、结果 |
| 满意解 | C+D结合方案 | 最优路径详解 |

#### 卡牌设计亮点

1. **场景真实感**
   - AI创业背景贴合当下热点
   - 具体数字（3倍薪资、30%诉求）
   - 多方利益相关者

2. **选项平衡性**
   - 每个选项都有合理性和局限性
   - 推荐选项不是唯一答案
   - 强调"满意解"而非"最优解"

3. **实施路径清晰**
   - 决策树辅助快速选择
   - 满意解的详细执行步骤
   - 风险提示到位

### 3.1 标准化使用流程

```
┌─────────────────────────────────────────────────────────────┐
│                    标准化使用流程                           │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【Step 1】案例学习入口                                     │

│  └── 机器人记录用户ID和开始时间                            │
│                                                             │
│  【Step 2】前测问卷                                         │
│  ├── 发送前测问卷卡片（Card 2）                            │
│  ├── 用户完成7道题并提交                                   │
│  ├── 数据存入飞书多维表格                                  │
│  └── 自动打标签：新手用户/有经验用户                       │
│                                                             │
│  【Step 3】场景展示                                         │
│  ├── 发送场景卡片（Card 3）                                │
│  ├── 展示完整背景故事                                      │
│  ├── 用户做出4选1决策                                     │
│  └── 记录用户选择和决策时间                                │
│                                                             │
│  【Step 4】结果反馈                                         │
│  ├── 根据选择发送对应结果卡片                              │
│  │   ├── A选择 → Card 4-A（红色警告）                    │
│  │   ├── B选择 → Card 4-B（橙色）                        │
│  │   ├── C选择 → Card 4-C（绿色推荐）                    │
│  │   └── D选择 → Card 4-D（蓝色）                        │
│  ├── 展示五维雷达图                                        │
│  └── 提供「后测问卷」入口                                  │
│                                                             │
│  【Step 5】后测问卷                                         │
│  ├── 发送后测问卷卡片（Card 5）                            │
│  ├── 用户完成7道题并提交                                   │
│  ├── 数据存入飞书多维表格                                  │
│  └── 计算成长值和推荐意愿                                  │
│                                                             │
│  【Step 6】成长报告                                         │
│  ├── 发送报告卡片（Card 6）                                │
│  ├── 展示决策回顾和五维分析                                │
```
