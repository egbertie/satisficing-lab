## 七、零Token执行标准

### 7.1 决策流程

```
收到任务 → 判断是否可本地处理 → 是 → 执行本地操作
                    ↓否
         判断是否可使用Skill → 是 → 调用Skill
                    ↓否
         判断是否可优化搜索 → 是 → 精准搜索
                    ↓否
              调用AI能力 → 输出结果
```

### 7.2 优先级原则

| 优先级 | 处理方式 | Token消耗 |
|--------|----------|-----------|
| P0 | 本地文件操作 | 0 |
| P1 | 内置工具（file_to_url等） | 极低 |
| P2 | Skill工具 | 低 |
| P3 | 优化后的搜索 | 低 |
| P4 | 标准AI对话 | 中 |
| P5 | 复杂多轮对话 | 高 |

### 7.3 验证检查

| 检查项 | 执行标准 |
|--------|----------|
| 任务是否可本地完成 | 查看文件操作类场景 |
| 是否使用了最优工具 | 查看Skill选择原则 |
| 搜索是否精准 | 查看关键词策略 |
| 对话是否简洁 | 查看问答优化策略 |
