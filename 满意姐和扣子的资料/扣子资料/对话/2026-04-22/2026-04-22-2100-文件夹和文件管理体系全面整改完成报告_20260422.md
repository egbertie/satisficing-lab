## 四、建立的机制

### 4.1 文件归位流程

```
任务完成 → 识别文件类型 → 归位到对应目录 → 更新索引 → 完成
```

### 4.2 用户上传处理流程

```
收到上传 → 24小时内处理 → 识别类型 → 归位/删除 → 完成
```

### 4.3 对话存档流程

```
每日对话结束 → 整理对话文件 → 归档到对应日期 → 更新索引 → 完成
```

### 4.4 检查机制

| 检查类型 | 频率 | 负责内容 |
|----------|------|----------|
| 每日检查 | 每日任务完成后 | 根目录、临时文件、任务输出、用户上传 |
| 每周检查 | 每周日 | 临时工作区清理、待删除区清理、索引更新 |
| 每月检查 | 每月最后一天 | 体系审查、归档、大文件检查、性能检查 |
