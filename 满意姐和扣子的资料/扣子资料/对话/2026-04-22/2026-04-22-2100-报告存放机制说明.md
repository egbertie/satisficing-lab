## 第一章：机制概述

### 1.1 设计目标
- **信息归属清晰**：每份报告放到其应在之处
- **双重备份**：标准存放 + 当日对话文件夹
- **可追溯**：任何时候都能找到报告来源

### 1.2 核心原则
> **任何报告 = 标准存放 + 同步复制**

## 第三章：同步机制

### 3.1 强制同步规则

**所有报告必须执行双重存放**：

```
[生成报告]
    ↓
[步骤1] 放入标准存放位置（按类型）
    ↓
[步骤2] 同步一份到当日对话文件夹
    ↓
[步骤3] 在MEMORY.md中记录锚点
```

### 3.2 同步示例

假设今日是 2026-04-22，生成了知识入库报告：

```
# 步骤1：标准存放
满意解研究所/04_知识资产/入库报告/PRJ1/RPT_KI_PRJ1知识分级_2026-04-22_V1.0.md

# 步骤2：同步到当日对话
对话/2026-04-22/RPT_KI_PRJ1知识分级_2026-04-22_V1.0.md

# 步骤3：MEMORY.md记录
- [2026-04-22] PRJ1知识分级报告 → 满意解研究所/04_知识资产/入库报告/PRJ1/
```

## 第五章：执行检查

### 5.1 报告生成检查清单

- [ ] 判断报告类型
- [ ] 确定标准存放路径
- [ ] 执行标准存放
- [ ] 同步到当日对话文件夹
- [ ] 在MEMORY.md中记录锚点
- [ ] 验证两个位置都存在

### 5.2 异常处理

| 情况 | 处理方式 |
|:-----|:---------|
| 目录不存在 | 先创建目录再存放 |
| 同名文件已存在 | 询问是否覆盖或重命名 |
| 无法判断归属 | 暂时放对话文件夹，后续整理 |
