## 一、设计原则

### 1.1 核心理念
- **主人翁精神**: 像满意姐一样，主动思考、主动建立机制、主动维护
- **全局性**: 从顶层设计到细节执行，一以贯之
- **系统性**: 每类文件都有明确的归属，避免散落
- **逻辑性**: 使用数字前缀排序，清晰明了

### 1.2 命名规范
| 类型 | 规范 | 示例 |
|------|------|------|
| 一级文件夹 | `XX_中文描述` | `00_驾驶舱`, `01_核心设定` |
| 二级文件夹 | `中文描述` 或 `XX_中文描述` | `图片资产`, `任务报告` |
| 文件名 | `描述性中文名.md` 或 `描述性中文名.png` | `任务完成报告.md` |
| 脚本文件 | `小写下划线.py` 或 `小写下划线.sh` | `download_files.py` |

### 1.3 文件分类标准
| 类别 | 定义 | 存放位置 |
|------|------|----------|
| 系统核心 | 维持系统运行的核心配置 | `01_核心设定/` |
| 产品体系 | 满意解研究所产品相关 | `02_满意研究所/` |
| 品牌资产 | 图片、二维码等视觉资产 | `04_系统资产/图片资产/` |
| 任务输出 | 任务执行产生的报告、文档 | `05_工作区/任务报告/` |
| 对话存档 | 对话历史的存档 | `05_工作区/对话存档/` |
| 临时文件 | 任务中产生的临时文件 | `06_临时工作区/` |
| 历史归档 | 已完成项目的历史归档 | `07_归档区/` |
| 待删除 | 确认删除前的暂存 | `08_待删除区/` |

## 三、各文件夹详细说明

### 3.1 00_驾驶舱
**用途**: 汇总、入口、索引、检查清单

| 子目录 | 说明 |
|--------|------|
| 检查清单/ | 每日、每周、每月检查清单 |
| README.md | 驾驶舱说明 |
| 文件管理体系规范.md | 本文档 |
| 索引总表.md | 全量文件的索引 |

**内容规范**:
- 检查清单必须按时执行并更新
- 索引总表必须与实际文件同步

### 3.2 01_核心设定
**用途**: 系统核心配置和设定文件

**包含文件**:
- `BOOTSTRAP.md` - 启动配置
- `MEMORY.md` - 记忆文件
- `SECRET.md` - 密钥文件
- `USER.md` - 用户信息

**禁止**:
- 禁止将其他文件混入此目录
- 禁止删除任何文件除非确认不再需要

### 3.3 02_满意研究所
**用途**: 满意解研究所产品体系

**结构** (来自满意姐原始设计):
- `00_驾驶舱` - 驾驶舱汇总
- `01_理论体系` - 底层方法论
- `02_产品体系` - 产品相关
- `03_运营体系` - 运营相关
- `04_知识资产` - 知识管理
- `05_行业借鉴` - 外部参考
- `06_技术配置` - 技术相关
- `07_归档区` - 历史沉淀
- `08_临时工作区` - 临时文件
- `09_索引` - 索引
- `对话/` - 对话存档
- `蓝军/` - 蓝军相关

### 3.4 04_系统资产
**用途**: 系统生成的品牌资产、脚本工具等

| 子目录 | 说明 |
|--------|------|
| 图片资产/品牌视觉/ | 品牌VI图片，如logo、设计图等 |
| 图片资产/二维码/ | 各类二维码图片 |
| 图片资产/卡牌素材/ | 卡牌设计素材 |
| 文档资产/ | PDF等文档资产 |
| 脚本工具/ | Python和Shell脚本 |

### 3.5 05_工作区
**用途**: 各类工作文件，是最活跃的区域

| 子目录 | 说明 |
|--------|------|
| 任务报告/ | 任务完成报告、检查报告等 |
| 对话存档/ | 对话历史的存档 |
| 卡牌方案/ | 卡牌相关方案 |
| 项目前期基础信息/ | 项目前期资料 |
| 深度洞察/ | 深度分析报告 |
| 时间节点/ | 时间节点文档 |
| 身份修正/ | 身份相关文档 |
| 配合体系/ | 配合体系文档 |

### 3.6 06_临时工作区
**用途**: 临时工作文件

**规则**:
- 临时文件完成后必须归位或删除
- 每周至少清理一次
- 禁止将临时工作区作为永久存储

### 3.7 07_归档区
**用途**: 历史归档

**规则**:
- 已完成项目的文件归档至此
- 按项目或时间分类
- 归档后更新索引总表

### 3.8 08_待删除区
**用途**: 确认删除前的暂存

**规则**:
- 放入待删除区的文件7天内必须删除
- 删除前确认无保留价值
- 定期清理，避免堆积

### 3.9 09_索引
**用途**: 索引和映射

**包含**:
- 文件映射表
- 目录索引
- 快速入口

## 四、文件命名规范

### 4.1 文档文件
- 使用描述性中文命名
- 包含时间时可加后缀 `_YYYYMMDD`
- 示例: `任务完成报告.md`, `任务完成报告_20260422.md`

### 4.2 图片文件
- 使用描述性中文命名
- 示例: `品牌logo.png`, `二维码.png`

### 4.3 脚本文件
- 使用小写字母和下划线
- 示例: `download_files.py`, `generate_qr.sh`

### 4.4 临时文件
- 临时文件命名: `temp_xxx.ext`
- 示例: `temp_analysis.txt`

---

## 五、禁止事项

1. **禁止根目录散落文件**: 任何文件必须有归属目录
2. **禁止临时文件永久化**: 临时文件用完必须删除或归档
3. **禁止命名混乱**: 必须遵循命名规范
4. **禁止未归位就完成**: 任务完成后文件必须归位

## 六、执行检查

### 每日检查
- 检查根目录是否有散落文件
- 检查临时工作区是否有可清理文件

### 每周检查
- 清理临时工作区
- 更新索引总表
- 检查各目录文件数量

### 每月检查
- 全面审查文件体系
- 更新文档
- 归档过期文件
