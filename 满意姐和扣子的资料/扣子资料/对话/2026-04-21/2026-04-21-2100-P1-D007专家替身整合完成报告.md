## 九、使用示例

### 9.1 基本使用

```python
from ExpertTwinManager import ExpertTwinManager

# 创建并初始化
manager = ExpertTwinManager()
manager.initialize_all()

# 单专家咨询
result = manager.consult("dr_li", "合伙人选择标准")
print(result)

# 多专家咨询
result = manager.multi_consult(
    expert_ids=["dr_li", "dr_luo_han", "dr_xie_bao_jian"],
    topic="硬科技创业团队构建"
)

# 生成报告
report = manager.generate_multi_expert_report(
    topic="技术孵化评估报告",
    scenario="技术驱动型"
)
print(report)
```

### 9.2 场景推荐
