## 三、关键设计决策

### 3.1 映射关系设计

#### 问卷维度→卡牌类型映射矩阵

| 问卷维度 | 高分区推荐 | 中分区推荐 | 低分区推荐 |
|:---------|:-----------|:-----------|:-----------|
| 时间轴（土） | Type02-A/D | Type01-A/B | Type01-C/D |
| 可行域（金） | Type01-D | Type01-B/C | Type01-A |
| 身心流（水） | Type02-A/C/D | Type01-B/D | Type01-A, Type02-B |
| 信义观（木） | Type02-C | Type01-C/D | Type01-A/B |
| 直觉阈（火） | Type02-A/D | Type01-A/D | Type01-C, Type02-B |

#### 推荐算法

```python
推荐得分 = (
    基础匹配度 × 0.30 +
    维度权重加成 × 0.35 +
    标签相似度 × 0.25 +
    行为相似度 × 0.10
)
```

### 3.2 数据模型设计

**统一用户画像**：
- 五维决策得分（土/金/水/木/火）
- 诊断标签数组
- 行为轨迹

**跨产品关联**：
- `triggered_from`：触发来源（questionnaire/card/case）
- `triggered_id`：触发记录ID
- `recommend_context`：推荐上下文

### 3.3 技术选型

| 组件 | MVP方案 | 说明 |
|:-----|:--------|:-----|
| 后端 | FastAPI | 异步、高性能 |
| 数据库 | SQLite | 本地存储、快速迭代 |
| 内容存储 | JSON/Markdown | 便于版本控制 |
| 部署 | Docker | 可扩展性 |
