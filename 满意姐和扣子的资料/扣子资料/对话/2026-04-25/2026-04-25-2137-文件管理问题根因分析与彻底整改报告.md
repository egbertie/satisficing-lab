## 四、预防措施

### 1. 全局扫描规则（固化到 TOOLS.md）
**规则**：执行任何文件清理操作前，必须执行全局扫描：
```bash
find /app/data -type d -name "*满意研究所*" 2>/dev/null | grep -v "满意解研究所"
find /app/data -type d -name "02_*" 2>/dev/null  # 检查重复编号
```

### 2. 目录结构认知
**系统目录结构**：
```
/app/data/
├── 所有对话/
│   ├── 02_满意研究所/  ← 历史错误（已删除）
│   ├── 主对话/  ← 当前工作目录（根目录）
│   └── 邮箱/
```

### 3. 文件夹创建规范
- **禁止**：直接用完整路径创建文件夹
- **必须**：先确认当前位置，再创建
- **禁止**：使用重复编号（如 01_、02_）

### 4. 满天星光行动命名规范
- 文件夹名不带版本后缀
- 如需版本管理，使用 `V1/`、`V2/` 子文件夹
- 禁止嵌套同名文件夹
