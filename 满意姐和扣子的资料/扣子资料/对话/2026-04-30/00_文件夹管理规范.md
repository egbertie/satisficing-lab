## 二、命名规则

### 2.1 文件命名
```
[序号_]Skill名称-文件类型.扩展名
```
**示例**：`01_知识飞轮传承操作系统-内化报告.md`

### 2.2 统一存放位置

| 文件类型 | 统一存放位置 | 说明 |
|:---------|:------------|:-----|
| **内化报告** | `./满天星光行动/技能内化报告-统一/` | 全部内化报告统一存放 |
| **程序化方案** | `./满天星光行动/执行机制/Skill程序化/` | 全部程序化方案统一存放 |
| **学习报告** | `./满天星光行动/技能学习报告/` | 学习阶段产出 |
| **联用练习** | `./满天星光行动/联用练习/` | Skill联用测试 |
| **速查卡** | `./满天星光行动/技能内化报告-统一/` | 与对应内化报告同目录 |
| **审计报告** | `./满天星光行动/审计报告/` | 蓝军/自审报告 |
| **总结报告** | `./满天星光行动/总结报告/` | 日/周/月总结 |
| **SOP文件** | `./满天星光行动/SOP/` | 标准化操作流程 |

### 2.3 归位检查清单（每任务必检）

创建文件后必须检查：
- [ ] 文件是否在正确目录？
- [ ] 文件命名是否符合规范？
- [ ] 是否需要同步到对话文件夹？

### 2.4 禁止规则

| # | 禁止 | 正确 |
|:--|:-----|:-----|
| 1 | ❌ 文件创建后不归位 | ✅ 立即检查归位 |
| 2 | ❌ 同类文件散落多目录 | ✅ 统一存放 |
| 3 | ❌ 历史文件不整合 | ✅ 定期整合 |
| 4 | ❌ 临时文件放根目录 | ✅ 临时文件用完即删 |

### 2.2 文件夹命名
- **核心文件夹**：`NN_名称/`（数字前缀表示层级）
- **项目文件夹**：`NN_项目名/`
- **临时文件夹**：`tmp_日期/`（用完即清）

### 2.3 禁止规则
| 禁止 | 正确 |
|:-----|:-----|
| ❌ 中文空格 | ✅ 英文空格或下划线 |
| ❌ 特殊字符 | ✅ 字母数字下划线短横 |
| ❌ 无意义名称 | ✅ 名称体现内容 |

## 三、归档规则

### 3.1 三同步归档
| 位置 | 触发条件 |
|:-----|:---------|
| `./对话/YYYY-MM-DD/` | 每日对话归档 |
| `./满天星光行动/` | 主项目相关 |
| `./相关项目/` | 按业务归属 |

### 3.2 临时文件清理
- temp_*.jpg → 使用后删除
- 截图文件 → 使用后删除
- 中间文件 → 使用后删除

### 3.3 禁止堆积
- 不产生游离文件
- 不产生孤岛文件
- 每周检查一次根目录

## 四、版本管理

| 类型 | 规则 |
|:-----|:-----|
| **主版本** | 重大重构 V1.0 → V2.0 |
| **次版本** | 功能迭代 V1.0 → V1.1 |
| **日期版** | 定期归档加日期后缀 |
