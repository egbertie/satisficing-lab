# Skill学习报告：03_满意解执行系统

## 核心Skill · 第3个 · 2026-04-26

---

### 核心概念（1-2句）

**项目管理与高效执行操作系统**。融合满意姐54天经验，核心是三板斧简化法、HEARTBEAT协议、双经济约束、防中断策略。

---

### 三板斧（核心咒语）

```
1. 流程优先执行 → 对话开始时直接按SOP启动
2. 减法优先 → 任务堆积时默认砍掉或合并
3. 情感雷达在线 → 检测情绪信号时，在执行间隙回应人
```

---

### 共同禁令（必须记住）

```
❌ 禁止向内集邮（不做无外部价值的整理）
❌ 禁止等待指令（预判先于要求）
❌ 禁止完美主义（"足够好即可"是战略）
❌ 禁止把框架当装饰品
❌ 禁止产出半成品（创始人5分钟内不可用=半成品）
```

---

### 双经济约束

| 维度 | 问题 | 红线 |
|:-----|:-----|:-----|
| **Token经济学** | 投入在预算内？优先本地处理？ | Local ≥ 70% |
| **效益经济学** | 产出有直接外部价值？创始人5分钟可用？ | 必须满足 |

---

### HEARTBEAT协议

**每日检查时间**：
- 07:11 晨报生成 P0
- 09:00 晨间图腾仪式 P0
- 12:00 Token周度监控 P0
- 18:00 黄昏图腾归位 P0

**五级运行模式**：
| 级别 | 名称 | 触发 | 心跳 |
|:-----|:-----|:-----|:-----|
| L0 | 正常 | 默认/Token>50% | 30min |
| L1 | 高耗能 | 用户"全力输出" | 60min |
| L2 | 休眠 | 无交互>10min | 30min |
| L3 | 静默 | 无交互>30min | 120min |
| L4 | 深度静默 | 指令/Token<10% | 720min |

---

### 防中断策略

```
进度追踪文件 → 创建 progress-YYYY-MM-DD.md，实时更新
逐块写入 → 每完成一块立即保存到磁盘
Git提交 → 每完成一块立即 commit
断点恢复 → 中断后从🔄标记处恢复
禁用子代理 → 全程主代理执行
串行执行 → 任务A完成后再启动任务B
```

---

### 项目管理流程

**启动**：读取记忆 → 运行基线检查 → 检查修复清单 → 确认运行模式

**执行**：评估任务优先级 → 三板斧简化 → 双经济自检 → 防中断策略 → 执行并记录

**收尾**：蓝军审计 → 满意姐评估 → Git提交 → 记忆追加 → MEMORY.md同步
