# 学习报告：04_知识保鲜系统

## 核心概念（1-2句）
自动检测知识过期、触发更新提醒、保持知识库时效性的系统。知识是"生鲜产品"，有保质期，需定期检查。

## 使用场景（何时用）
- 知识入库时打保质期标签
- 到期前触发更新提醒
- 定期扫描过期知识
- 触发词："知识保鲜" / "过期检查" / "知识更新" / "时效审计"

## 核心咒语/原则（必须会背）

**知识保质期分类**：
| 类型 | 保质期 | 检查频率 |
|:-----|:---------|:---------|
| 技术文档 | 6个月 | 每月 |
| 市场数据 | 3个月 | 每周 |
| 政策法规 | 1个月 | 每周 |
| 方法论 | 12个月 | 每季度 |
| 案例库 | 6个月 | 每月 |

**保鲜机制**：
```
知识入库 → 打保质期标签 → 到期前提醒 → 更新/归档/丢弃
```
