# 学习报告：21_双经济审计师（最高效力条款）

## 核心概念（1-2句）
**最高效力条款**。任何行动必须同时通过Token经济学+效益经济学双重检查。不满足任一维度即拦截行动。以后所有要求默认按双经济执行。

## 使用场景（何时用）
- 任何任务执行前
- 任何决策前
- 任何产出创建前
- 触发词："双经济" / "审计" / "Token够吗" / "效益值得吗" / "向内集邮" / "创始人5分钟"

## 核心咒语/原则（必须会背）

**双经济 = Token经济学 + 效益经济学**

**检查点1: Token经济学**
```
□ 本次行动预估Token消耗: ______
□ 当前剩余Token预算: ______
□ 本地处理比例预估: ______% (目标≥70%)
□ 是否有免费替代方案: ______
```

**检查点2: 效益经济学**
```
□ 产出物名称: ______
□ 直接外部价值描述: ______
□ 创始人5分钟可用性: □是 □否
□ 不做的最坏后果: ______
```

**向内集邮检测（3问）**：
1. 这个产出会被创始人直接用于决策或交付吗？
2. 这个产出会在7天内被市场/客户/合作伙伴看到吗？
3. 不做这个，已有的东西会崩溃吗？

**3个问题都是"否" → 🔴 向内集邮确认，强制拦截**

**拦截等级**：🟢放行 / 🟡警告 / 🔴拦截（任一红灯即拦截）
