# 学习报告：17_编号决策协议

## 核心概念（1-2句）
让每个决策有编号、有选项、有记录、有追溯链。呈现2个及以上选项时必须编号，用户最小响应格式为"A-② + [反馈]"。

## 使用场景（何时用）
- 呈现多个选项供用户选择
- 用户做出决策后存档
- 追溯历史决策
- 触发词："决策" / "选哪个" / "编号" / "DEC-" / "选项" / "A-①" / "B-②"

## 核心咒语/原则（必须会背）

**选项编号格式**：
```
[A] ① 选项A — [说明]
[A] ② 选项B — [说明]
```

**用户最小响应**：`A-② + [反馈]`

**决策存档格式**：
```
[DEC-XXX] 决策存档
决策时间: YYYY-MM-DD HH:MM
决策主题: {主题}
[选项]
① {描述} — [未选]
② {描述} — ✅ [已选]
[用户响应原文] "A-② + [反馈]"
```

**红线**：不编号不给选项 / 不存档不做决策 / 不改历史不留痕 / 选项不超过5个
