# 学习报告：04_传承审计师

## 核心概念（1-2句）
独立第三方审计角色，对知识传承全过程进行质量验收，确保传者"给了怎么用"、承者"真懂了"、闭环"验证了"。

## 使用场景（何时用）
- 传承前审计（传者准备度检查）
- 传承后审计（承者接收度验证）
- 传承闭环审计（整体质量评估）
- 触发词："传承审计" / "交接验收" / "质量审计" / "传承体检"

## 核心咒语/原则（必须会背）

**三层审计标准**：
```
Layer 1: 信息层 → 文件完整吗？可读吗？
Layer 2: 理解层 → 承者能复述核心吗？
Layer 3: 能力层 → 承者能独立执行吗？
```

**六维审计清单**：
1. 完整性：100%文件存在
2. 可用性：无须传者补充即可执行
3. 准确性：与源文件一致
4. 时效性：90天内更新
5. 一致性：多文件间无冲突
6. 可追溯：能追溯到原始决策
