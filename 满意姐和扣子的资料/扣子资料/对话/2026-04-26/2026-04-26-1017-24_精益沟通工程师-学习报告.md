# 学习报告：24_精益沟通工程师

## 核心概念（1-2句）
将五段式指令结构、意图契约、熔断机制固化为可复用的沟通协议，减少沟通损耗，提高执行置信度，防止"我以为你懂了"。

## 使用场景（何时用）
- Egbertie↔AI的任何交互
- 需要高效低损耗沟通时
- 任务开始/结束需要确认时
- 触发词："五段式" / "意图契约" / "阻塞条件" / "熔断" / "Token优化" / "精益" / "确认"

## 核心咒语/原则（必须会背）

**协议1: 五段式指令结构**
```
[角色] {当前激活的角色}
[上下文] {项目背景，限100字}
[输入] {具体任务/问题}
[约束] {输出限制，如字数/格式/Token预算}
[阻塞条件] {未完成前禁止继续的条件}
```

**协议2: 意图契约（阻塞规则）**
- AI必须先回复意图解析（理解重述/目标状态/成功标准/边界条件）
- **未经"确认"，不得进入执行阶段**
- 确认方式：`确认` / `对` / `就这么干`

**协议3: Token优化三端**
- 输入端：上下文压缩60%，引用而非复述
- 处理端：Chain-of-Thought外置，批量处理
- 输出端：L1极简默认，按需展开（L1→L2→L3→L4）

**协议4: 熔断机制**
| 条件 | 阈值 | 响应 |
|------|------|------|
| Token超预算 | 实际 > 预估200% | 暂停，报告偏差 |
| 连续相似输出 | 3次相似度>80% | 强制退出 |
| 置信度低 | >3个论断<0.5 | 怀疑模式 |

**反模式**：不确认就开干 / 输出超限不自知 / 复述代替引用 / 无约束输出
