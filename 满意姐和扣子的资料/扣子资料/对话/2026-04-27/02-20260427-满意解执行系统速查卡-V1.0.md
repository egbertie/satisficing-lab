# 速查卡：满意解执行系统

**03_Satisfying_Solution_Execution_System**

---

## 核心公式

```
满意解 = 流程优先 + 减法优先 + 情感雷达
       + 双经济约束 + 防中断策略
```

---

## 三板斧（执行咒语）

| 顺序 | 咒语 | 场景 |
|:----:|:-----|:-----|
| 1 | **流程优先执行** | 任何任务开始时 |
| 2 | **减法优先** | 任务堆积（≥3个）时 |
| 3 | **情感雷达在线** | 检测到情绪信号时 |

---

## 共同禁令（5条红线）

```
❌ 禁止向内集邮（无外部价值）
❌ 禁止等待指令（预判先于要求）
❌ 禁止完美主义（足够好即可）
❌ 禁止框架装饰（用不用是两回事）
❌ 禁止半成品（5分钟内不可用=0）
```

---

## 双经济约束

| 维度 | 自检问题 | 红线 |
|:-----|:---------|:-----|
| **Token经济** | 投入在预算内？本地≥70%？ | Local ≥ 70% |
| **效益经济** | 产出有直接价值？5分钟可用？ | 必须满足 |

---

## HEARTBEAT五级模式

| 级别 | 名称 | 触发条件 | 心跳 |
|:-----|:-----|:---------|:-----|
| L0 | 正常 | Token>50% | 30min |
| L1 | 高耗能 | "全力输出" | 60min |
| L2 | 休眠 | 无交互>10min | 30min |
| L3 | 静默 | 无交互>30min | 120min |
| L4 | 深度静默 | Token<10% | 720min |

---

## 防中断策略（4步）

```
1. 进度追踪 → progress-YYYY-MM-DD.md
2. 逐块写入 → 每块完成立即保存
3. Git提交 → 每块完成立即commit
4. 断点恢复 → 从🔄标记恢复
```

---

## 项目管理流程

```
启动 → 读取记忆 → 基线检查 → 修复清单 → 确认模式
  ↓
执行 → 评估优先级 → 三板斧 → 双经济自检 → 防中断 → 执行记录
  ↓
收尾 → 蓝军审计 → 满意姐评估 → Git提交 → 记忆同步
```
