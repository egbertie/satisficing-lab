## 一、测试设计

**「是否接单：为某创业公司设计AI转型战略规划咨询项目」**

- 涉及团队协作和伦理考量
- 需要在不确定中做出快速判断

## 二、联用流程

### 第一阶段：五维决策（五维决策体系）

#### Step 1: 土（根基）→ 检查信任基础
```
问题：这个决策的根基是什么？谁参与？信任关系如何？
分析：
- 客户来源：陌生还是转介绍？
- 时间窗口：紧急还是充裕？
- 合作模式：一次性还是长期？
评分：土 = 6分
理由：有机会但信任基础一般
```

#### Step 2: 金（标尺）→ 设定满意标准
```
问题：满意的标准是什么？"不求最优，但求最适"
分析：
- 最低可接受条件：按时交付、基本满意
- 理想条件：建立长期合作、产出标杆案例
- 风险底线：不可延期超过1周、不可损害品牌
评分：金 = 7分
理由：标准明确、可操作性强
```

#### Step 3: 水（流动）→ 灵活调整
```
问题：方向对吗？有没有更好的路径？
分析：
- 当前路径：直接接单执行
- 替代路径：先做POC验证、拒绝接单
- 调整空间：根据反馈灵活调整方案
评分：水 = 6分
理由：有一定灵活性，但受限于资源
```

#### Step 4: 木（伦理）→ 伦理检查
```
问题：符合仁义礼智信吗？对团队/组织/社会的影响？
分析：
- 仁：是否对客户真正有帮助？
- 义：是否在合理价格范围？
- 礼：沟通方式是否专业尊重？
- 智：是否在能力范围内？
- 信：是否能兑现承诺？
评分：木 = 7分
理由：符合伦理标准，但需注意交付能力边界
```

#### Step 5: 火（直觉）→ 直觉验证
```
问题：直觉怎么说？"顿悟的瞬间是什么？"
分析：
- 第一反应：有点犹豫，担心资源不够
- 内心声音：可以做，但需要砍范围
- 直觉信号：⚡ 如果承诺太多，可能翻车
评分：火 = 5分
理由：直觉提示需要谨慎
```

#### Step 6: 五维综合评分
```
土 + 金 + 水 + 木 + 火 = 总分
 6 +  7 +  6 +  7 +  5 = 31分

结论：31 < 35，需要进一步讨论或调整条件
```

---

### 第二阶段：满意解执行（满意解执行系统）

基于五维评分结果，启动满意解流程：

#### 分析：为什么五维评分不足？

| 维度 | 问题 | 解决方向 |
|:-----|:-----|:---------|
| 土 | 信任基础一般 | 需要更多背调或缩小范围 |
| 水 | 灵活性受限 | 提前锁定关键里程碑 |
| 火 | 直觉警告 | 砍范围、降低承诺 |

#### 三板斧应用

```
1. 流程优先执行
   → 立即启动：发邮件确认范围 + 要求预付款

2. 减法优先
   → 砍掉：详细技术路线图（改为粗粒度）
   → 砍掉：免费附加的培训模块
   → 合并：合并多个汇报节点

3. 情感雷达在线
   → 检测：客户对这个建议的反应
   → 预案：如对方坚持，触发决策回退
```

#### 双经济约束自检

| 维度 | 自检 | 结果 |
|:-----|:-----|:-----|
| Token经济 | 投入在预算内？本地≥70%？ | ✅ 符合 |
| 效益经济 | 产出有直接价值？5分钟可用？ | ⚠️ 需确认 |

---

### 第三阶段：综合决策

#### 调整后的五维评分

| 维度 | 原评分 | 调整后 | 调整理由 |
|:-----|:-------|:-------|:---------|
| 土 | 6 | 7 | 缩小范围降低风险 |
| 金 | 7 | 7 | 保持 |
| 水 | 6 | 7 | 锁定里程碑增加确定性 |
| 木 | 7 | 7 | 保持 |
| 火 | 5 | 7 | 砍范围消除直觉警告 |
| **总分** | **31** | **35** | ✅ 刚好达标 |

#### 最终决策
```
✅ 可以推进，但必须满足以下条件：
1. 明确范围：AI战略规划（非完整实施）
2. 里程碑锁定：3个关键节点
3. 预付款：至少30%
4. 交付边界：不超过8周
```

## 三、联用测试总结

### 联用价值

| 满意解的作用 | 五维的作用 |
|:------------|:----------|
| 提供执行框架 | 提供决策框架 |
| 防止完美主义 | 防止冲动决策 |
| 确保可恢复性 | 确保全面评估 |
| 监控资源投入 | 监控伦理风险 |

### 联用口诀

```
五维定方向 → 满意解保执行
五维评决策 → 满意解防翻车
五维触直觉 → 满意解砍范围
```

### 联用检查清单

```
□ 五维评分是否≥35分？
□ 如不足35分，用满意解三板斧调整
□ 执行前启动防中断策略
□ 执行中双经济自检
□ 执行后蓝军审计
□ 结果同步到记忆
```
