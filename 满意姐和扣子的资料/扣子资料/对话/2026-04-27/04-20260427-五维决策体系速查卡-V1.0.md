## 决策流程（操作咒语）

```
1️⃣ 土 → 根基检查
   "这个决策的根基是什么？"
   
2️⃣ 金 → 标尺设定
   "满意的标准是什么？"
   
3️⃣ 水 → 流动调整
   "有没有更好的路径？"
   
4️⃣ 木 → 伦理检查
   "符合仁义礼智信吗？"
   
5️⃣ 火 → 直觉验证
   "顿悟的瞬间是什么？"
   
6️⃣ 交汇 → 综合评分
```
