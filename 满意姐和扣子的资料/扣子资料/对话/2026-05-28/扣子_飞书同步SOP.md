## 二、每日同步流程

### 2.1 同步时间节点

| 时间 | 动作 | 说明 |
|:-----|:-----|:-----|
| 08:00 | 晨间同步 | 检查飞书消息、读取今日待办 |
| 12:00 | 午间检查 | 上午产出同步、进度更新 |
| 18:00 | 日终归档 | 产出归档、明日计划整理 |
| 22:00 | 补漏同步 | 检查遗漏、及时补充 |

### 2.2 同步操作流程

```
┌─────────────────────────────────────────────────────────┐
│                    每日同步SOP                          │
├─────────────────────────────────────────────────────────┤
│ 1. 识别今日日期 → YYYY-MM-DD                            │
│ 2. 扫描工作目录 → 查找新增/修改文件                      │
│ 3. 读取文件分类标签 → 确定目标文件夹                   │
│ 4. 上传到对应飞书文件夹                                 │
│ 5. 生成同步报告                                         │
│ 6. 发送同步通知（飞书/邮件）                            │
└─────────────────────────────────────────────────────────┘
```

## 三、同步检查清单

### 3.1 上传前检查

```
□ 文件命名规范（日期+标题格式）
□ 文件格式正确（md/docx/xlsx等）
□ 内容无敏感信息泄露
□ 关联资源已同步（图片/附件）
□ 版本号已更新
```

### 3.2 上传后检查

```
□ 文件已成功上传至飞书
□ 目标文件夹位置正确
□ 访问权限设置正确
□ 同步报告已生成
□ 通知已发送
```

### 3.3 同步异常处理

| 异常情况 | 处理方式 |
|:---------|:---------|
| 上传失败 | 检查网络→重试→记录错误 |
| 权限不足 | 联系管理员申请权限 |
| 文件冲突 | 保留最新版本，历史归档 |
| 超时无响应 | 等待30秒→重试→手动上传 |

## 四、飞书CLI同步命令参考

### 4.1 基础命令

```bash
# 检查授权状态
lark-cli auth status

# 刷新授权（如需）
lark-cli auth login --no-wait --domain all

# 创建文件夹
lark-cli drive folder create --name "文件夹名"

# 上传文件
lark-cli drive file upload --file ./path/to/file.md

# 查询文件夹
lark-cli drive folder list --token <parent_token>
```

### 4.2 自动化脚本调用

## 五、Token管理规范

### 5.1 Token安全规范

- Token仅用于内部操作，严禁外泄
- 定期检查Token有效性
- 发现异常立即更换

### 5.2 Token有效期

- 用户Token：7天有效期
- 建议每周执行一次授权刷新
- 自动化脚本需配置Token自动刷新机制
