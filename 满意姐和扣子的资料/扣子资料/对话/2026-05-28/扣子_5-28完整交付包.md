## 三、使用说明

### 3.1 每日同步流程
```bash
# 1. 运行同步脚本
python3 满天星光行动/外宣体系/scripts/飞书每日同步.py

# 2. 查看同步报告
cat 满天星光行动/外宣体系/scripts/sync_log.txt

# 3. 手动上传关键文件到飞书
lark-cli drive +upload --file <文件路径> --folder-token <目标文件夹token>
```

### 3.2 邮件发送流程
1. 参照「邮件通讯体系完整SOP.md」选择对应模板
2. 填充内容后执行发送
3. 按P0级归档规则保存沟通记录
