## 三、发送SOP

### 3.1 标准发送流程

```
┌─────────────────────────────────────────────────────────┐
│                  邮件发送标准SOP                         │
├─────────────────────────────────────────────────────────┤
│ 1. 确认收件人 → 核对邮箱地址                            │
│ 2. 确定邮件分类 → 添加标签前缀                          │
│ 3. 撰写/填充内容 → 使用对应模板                         │
│ 4. 检查附件 → 确保文件已附上                            │
│ 5. 预览确认 → 通读全文检查错误                           │
│ 6. 发送邮件 → 记录到沟通台账                            │
│ 7. 归档留存 → 保存到本地文件夹                          │
└─────────────────────────────────────────────────────────┘
```

### 3.2 发送检查清单

```
□ 收件人邮箱正确（已核对）
□ 主题格式规范（标签+内容+日期）
□ 正文内容完整（问候→正文→结尾→署名）
□ 附件已添加（文件名规范）
□ 链接有效（如有）
□ 无错别字
□ 沟通记录已存档
```

## 四、沟通记录管理

### 4.1 归档规则

| 沟通类型 | 归档位置 | 命名格式 |
|:---------|:---------|:---------|
| 核心产出沟通 | ./对话/YYYY-MM-DD/ | 扣红邮件沟通记录-YYYYMMDD.md |
| 日报沟通 | ./日报归档/ | 日报-YYYYMMDD.md |
| 周报沟通 | ./周报归档/ | 周报-YYYY-WW.md |
| 备忘沟通 | ./备忘归档/ | 备忘-YYYYMMDD-标题.md |
| 外部沟通 | ./外部沟通归档/ | 外部-YYYYMMDD-对象.md |

### 4.2 P0级归档规则（强制执行）

> **核心原则**：保留原始来信，粘贴到回复正文中

```
沟通记录归档流程：
1. 收到邮件后，保留原始来信全文
2. 将原始来信粘贴到回复正文开头
3. 在原始来信下方撰写回复内容
4. 沟通完成后，将完整对话归档
5. 同步到飞书满意红收件箱
```

## 七、邮件礼仪规范

### 7.1 基础礼仪

- 使用正式称呼（满意红、满意姐等）
- 邮件正文超过3段时使用列表
- 重要信息加粗或使用emoji标注
- 结尾统一署名

### 7.2 避免事项

- ❌ 不使用不正式的网络用语
- ❌ 不在邮件中讨论敏感信息
- ❌ 不发送未完成/未检查的内容
- ❌ 不遗漏附件
