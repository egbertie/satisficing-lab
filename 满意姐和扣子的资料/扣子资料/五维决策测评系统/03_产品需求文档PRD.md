## 一、产品概述

### 1.1 产品定位

| 维度 | 内容 |
|:----:|:-----|
| **产品名称** | 五维决策测评系统 |
| **一句话描述** | "5分钟，用五维框架评估你的决策能力" |
| **产品类型** | 在线测评工具（H5 + 小程序 + 插件） |
| **核心功能** | 五维决策能力测评 + 个性化报告 |
| **目标用户** | 创始人、投资人、职场人、创业者 |

### 1.2 解决的问题

| 用户痛点 | 我们的解决方案 |
|:---------|:----------------|
| 决策时不知道该考虑什么 | 五维框架提供系统化思考路径 |
| 不知道自己的决策短板 | 五维雷达图直观展示能力分布 |
| 做完决策没有反馈 | 直觉验证对比，发现认知盲区 |
| 缺乏可执行的改进建议 | 针对性行动建议，立竿见影 |

### 1.3 核心价值

| 维度 | 价值 | 证据 |
|:----:|:----:|:-----|
| **快** | 5分钟完成 | 比传统测评快80% |
| **准** | 22年经验算法 | 基于满意解决策科学 |
| **易** | 零门槛 | 不需要决策学背景 |
| **用** | 即时报告 | 雷达图 + 建议 + PDF |

### 3.2 功能详细说明

#### F01: 问卷展示

**描述**: 展示五维测评问卷

**详细需求**:
```
1. 问卷结构
   - 引导页（产品介绍 + 开始按钮）
   - 25道基础题（每维5题）
   - 3道直觉验证题
   - 提交按钮

2. 题目展示
   - 单题展示（非分页滚动）
   - 显示当前题号 / 总题号
   - 显示所属维度
   - 5个选项，单选

3. 维度标识
   - 显示当前题目所属维度
   - 显示维度图标和颜色
```

**验收标准**:
- [ ] 25道题正确分组到5个维度
- [ ] 3道直觉题单独标识
- [ ] 进度条实时更新

#### F03: 评分计算

**描述**: 计算各维度得分和综合评分

**详细需求**:
```
1. 维度得分计算
   公式: 维度得分 = (该维度5题得分之和) × 2
   满分: 50分/维度
   及格线: 30分
   警告线: 20分
   阻断线: 10分

2. 直觉验证分
   公式: 直觉分 = (3题得分之和) × 1.2
   满分: 36分
   火维度加成: 直觉分 × 0.5

3. 综合评分
   公式: 综合分 = (土×0.2 + 金×0.2 + 水×0.2 + 木×0.2 + 火×0.2)
   满分: 50分

4. 评级
   - 优秀: 40-50分
   - 良好: 30-39分
   - 一般: 20-29分
   - 待提升: <20分
```

**验收标准**:
- [ ] 维度得分计算正确
- [ ] 直觉验证分计算正确
- [ ] 综合评分计算正确
- [ ] 评级正确

#### F05: 报告生成

**描述**: 生成个性化评估报告

**详细需求**:
```
1. 报告内容
   - 五维雷达图
   - 各维度得分详情
   - 综合评级
   - 风险预警（13类型冲突预测）
   - 行动建议（针对短板）

2. 行动建议规则
   - 土·信义 < 30 → "建议建立信义账户系统"
   - 金·标尺 < 30 → "建议设定满意解阈值标准"
   - 水·觉察 < 30 → "建议练习0.3秒觉察"
   - 木·伦理 < 30 → "建议建立伦理检查清单"
   - 火·顿悟 < 30 → "建议给自己设定压力截止日期"

3. 风险预警规则
   - 综合分 < 30 → "整体决策能力待提升"
   - 任一维度 < 20 → "该维度需要重点关注"
   - 直觉分与自评差异 > 20 → "可能存在认知盲区"
```

**验收标准**:
- [ ] 报告包含所有必需内容
- [ ] 行动建议有针对性
- [ ] 风险预警准确
