> **版本**: V1.0
> **日期**: 2026-04-28
> **编制**: 满意扣子
> **性质**: 产品设计文档 + 问卷测评系统

> **内部映射**: 五路图腾体系（土金水木火）

---

## 一、产品定位

### 一句话定位
> "5分钟，用五维框架评估你的决策能力。"

### 核心价值主张

| 维度 | 价值 | 说明 |
|:----:|:----:|:-----|
| **快** | 5分钟完成 | 不是1小时问卷，是精准的决策自检 |
| **准** | 22年经验算法 | 基于满意解决策科学的实战验证 |
| **易** | 零门槛 | 不需要决策学背景，直觉式问答 |
| **用** | 即时报告 | 5维雷达图 + 风险预警 + 行动建议 |

### 目标用户

| 用户类型 | 核心需求 | 付费意愿 |
|:--------:|:--------:|:--------:|
| **创始人** | 合伙人选择、战略决策 | 高 |
| **投资人** | 团队评估、赛道判断 | 高 |
| **职场人** | 职业选择、团队协作 | 中 |
| **学生** | 决策能力自测 | 低 |

### 2.3 各维度深度设计

#### 土·信义（信任根基）

**理论来源**: 儒商伦理 + 信任博弈论

**测评维度**:
| 子维度 | 问题类型 | 评估要点 |
|:------:|:--------:|:--------:|
| 信任建立 | 信任建立速度 | 快速信任 vs 需要时间验证 |
| 信任维护 | 信义账户管理 | 存入 vs 支取习惯 |
| 信任修复 | 背叛后的修复能力 | 能否重建信任 |
| 信任边界 | 过度信任识别 | 是否盲目信任 |

**核心问题集**:
1. "你平均需要多长时间才能完全信任一个新伙伴？"
2. "如果合作伙伴突然失联，你会怎么做？"
3. "你曾经被信任的人背叛过吗？你如何处理？"
4. "你是否有过'我太相信他了'的后悔经历？"
5. "在什么情况下你会选择'信任前置'？"

#### 金·标尺（满意边界）

**理论来源**: Simon满意解 + 有限理性 + 前景理论

**测评维度**:
| 子维度 | 问题类型 | 评估要点 |
|:------:|:--------:|:--------:|
| 阈值设定 | 满意解标准 | 是否事前设定标准 |
| 信息边界 | 何时停止收集信息 | 是否信息过载 |
| 时间边界 | 决策截止点 | 是否拖延决策 |
| 37%规则 | 最优停止点 | 是否懂得放弃 |

**核心问题集**:
1. "做重要决策时，你通常会收集多少信息？"
2. "你是否有'一定要找到最优解'的执念？"
3. "什么情况下你会觉得'已经够好了，可以做了'？"
4. "你是否有过'因为太追求完美而错过最佳时机'的经历？"
5. "你如何平衡'再多想一下'和'先做再说'？"

#### 水·觉察（情绪洞察）

**理论来源**: 元认知 + 正念神经科学 + 0.3秒模型

**测评维度**:
| 子维度 | 问题类型 | 评估要点 |
|:------:|:--------:|:--------:|
| 情绪识别 | 情绪命名能力 | 能否准确识别情绪 |
| 身体信号 | 身体感受觉察 | 是否关注身体信号 |
| 0.3秒停 | 前额叶介入能力 | 能否在情绪爆发前暂停 |
| 第三方视角 | 元认知能力 | 能否跳出来看自己 |

**核心问题集**:
1. "当你感到愤怒时，你通常多长时间能意识到自己在愤怒？"
2. "你是否有过在情绪激动时说出/做出后悔的事情？"
3. "做重要决策前，你会关注自己的情绪状态吗？"
4. "当别人指出你的情绪时，你的反应是什么？"
5. "你是否有过'事后才意识到当时被情绪控制了'的经历？"

#### 木·伦理（道德准则）

**理论来源**: 儒家五常 + 制度经济学 + 伦理契约

**测评维度**:
| 子维度 | 问题类型 | 评估要点 |
|:------:|:--------:|:--------:|
| 仁 | 利他平衡 | 利己 vs 利他倾向 |
| 义 | 义务边界 | 该做 vs 能做的判断 |
| 礼 | 程序正义 | 过程 vs 结果导向 |
| 智 | 知情决策 | 信息透明度要求 |
| 信 | 承诺兑现 | 承诺 vs 兑现比例 |

**核心问题集**:
1. "当客户利益和公司利益冲突时，你会怎么选择？"
2. "你是否有过为了达成目标而'美化事实'的经历？"
3. "你认为'结果好就是好'还是'过程对才是对'？"
4. "你的合作伙伴是否有权知道你决策背后的完整信息？"
5. "你平均每做出几个承诺能兑现几个？"

#### 火·顿悟（创造行动）

**理论来源**: 创造力神经科学 + Wallas四阶段 + 压力-顿悟模型

**测评维度**:
| 子维度 | 问题类型 | 评估要点 |
|:------:|:--------:|:--------:|
| 顿悟触发 | 灵感出现频率 | 是否善于捕捉灵感 |
| 临界点 | 信息+压力阈值 | 是否懂得等待时机 |
| 行动转化 | 顿悟后行动力 | 能否立即执行 |
| 心流状态 | 最佳表现状态 | 是否能进入心流 |

**核心问题集**:
1. "你通常在什么状态下最容易有'好主意'？"
2. "你是否有'想了很多但迟迟无法行动'的困扰？"
3. "当灵感来临时，你会怎么做？"
4. "你享受压力带来的挑战感吗？"
5. "你是否有过'事后证明当时的直觉是对的'的经历？"

## 三、问卷结构设计

### 3.1 问卷架构

```
┌─────────────────────────────────────────────┐
│           五维决策测评问卷                    │
├─────────────────────────────────────────────┤
│                                             │
│  【引导页】                                  │
│   → 产品介绍                                 │
│   → 使用说明                                 │
│   → 预计时长（5分钟）                        │
│                                             │
│  【基础信息】                                │
│   → 评估场景（合伙人/投资/战略/其他）        │
│   → 决策背景简述（可选）                     │
│                                             │
│  【维度一：土·信义】5题                      │
│   → 信任建立、信任维护、信任修复、信任边界   │
│                                             │
│  【维度二：金·标尺】5题                     │
│   → 阈值设定、信息边界、时间边界、37%规则    │
│                                             │
│  【维度三：水·觉察】5题                     │
│   → 情绪识别、身体信号、0.3秒停、第三方视角  │
│                                             │
│  【维度四：木·伦理】5题                     │
│   → 仁义礼智信五常                           │
│                                             │
│  【维度五：火·顿悟】5题                     │
│   → 顿悟触发、临界点、行动转化、心流状态    │
│                                             │
│  【直觉验证】3题                            │
│   → 闭眼直觉测试（不看前五维结果）           │
│                                             │
│  【补充问题】2题                            │
│   → 开放性问题（可选）                       │
│                                             │
│  【报告生成】                                │
│   → 五维雷达图                               │
│   → 综合评分                                 │
│   → 风险预警                                 │
│   → 行动建议                                 │
│                                             │
└─────────────────────────────────────────────┘
```

### 3.2 完整问卷题目

#### 第一部分：土·信义（信任根基）

**Q1. 信任建立速度**
> 你需要多长时间才能完全信任一个新认识的合作伙伴？

- A. 初次见面就能建立基础信任（5分）
- B. 经过1-3次互动后（4分）
- C. 需要几个月相处（3分）
- D. 需要超过半年（2分）
- E. 我很少完全信任任何人（1分）

**Q2. 信义账户管理**
> 当合作伙伴请求帮助时，你的本能反应是？

- A. 二话不说，尽力帮忙（5分）
- B. 先评估关系深度，再决定（4分）
- C. 要求对方先说明原因（3分）
- D. 犹豫，担心被利用（2分）
- E. 通常会拒绝（1分）

**Q3. 信任背叛应对**
> 如果你信任的人背叛了你，你会怎么做？

- A. 立即原谅，给对方解释的机会（5分）
- B. 听解释，但需要时间重建信任（4分）
- C. 保持距离，观察后续表现（3分）
- D. 立即终止关系（2分）
- E. 永远无法释怀（1分）

**Q4. 过度信任识别**
> 你曾经因为"太相信别人"而吃过亏吗？

- A. 从来没有（5分）—— 我有完善的信任验证机制
- B. 很少，即使有也影响很小（4分）
- C. 有几次，造成了不小损失（3分）
- D. 经常，吃了不少亏（2分）
- E. 每次都吃亏（1分）

**Q5. 信任前置行为**
> 在什么情况下你会选择"先相信，再验证"？

- A. 对方有第三方背书时（5分）
- B. 对方展现可信行为时（4分）
- C. 直觉告诉我可以信任时（3分）
- D. 很少这样做（2分）
- E. 从不这样做（1分）

#### 第二部分：金·标尺（满意边界）

**Q6. 信息收集边界**
> 做重要决策前，你通常会收集多少信息？

- A. 收集到感觉"已经够了"就停止（5分）

- D. 总觉得信息不够，难以停止（2分）
- E. 必须收集到95%以上才安心（1分）

**Q7. 最优解执念**
> "一定要找到最优解"这句话对你有吸引力吗？

- A. 完全没吸引力，我知道没有最优解（5分）
- B. 有点吸引力，但能控制（4分）
- C. 有时会陷入追求最优（3分）
- D. 经常追求最优，常常延误决策（2分）
- E. 每次都追求最优，几乎无法决策（1分）

**Q8. 满意解识别**
> 你如何判断一个方案"已经够好了"？

- A. 有明确的预设标准，达到就停止（5分）
- B. 与历史最佳对比，感觉差不多就行（4分）
- C. 与同行做法对比，差不多就行（3分）
- D. 直觉告诉我"可以了"（2分）
- E. 从来不觉得"够好了"（1分）

**Q9. 完美主义代价**
> 你是否有过因为太追求完美而错过最佳时机的经历？

- A. 从来没有，我总能找到行动窗口（5分）
- B. 很少，即使错过也能接受（4分）
- C. 有几次，事后有些后悔（3分）
- D. 经常错过，留下遗憾（2分）
- E. 几乎总是错过（1分）

**Q10. 行动-思考平衡**
> 你更倾向于？

- A. 先做，在行动中调整（5分）
- B. 思考30%，行动70%（4分）
- C. 思考50%，行动50%（3分）
- D. 思考70%，行动30%（2分）
- E. 想清楚再行动（1分）

- C. 无所谓（5分）
- D. 有些后悔（3分）
- E. 非常后悔（0分）

### 3.3 评分计算

#### 各维度分数计算

```
维度得分 = （该维度5题得分之和）× 2

满分：50分/维度
及格线：30分
警告线：20分
阻断线：10分
```

#### 直觉验证分数

```
直觉得分 = （Q26+Q27+Q28得分之和）× 1.2

满分：36分
火维度加成：直觉分 × 0.5 计入火维度总分
```

#### 综合评分

```
综合评分 = 土×0.2 + 金×0.2 + 水×0.2 + 木×0.2 + 火×0.2

满分：50分
优秀：40-50分
良好：30-39分
一般：20-29分
待提升：<20分
```

### 5.3 数据库设计

```sql
CREATE TABLE users (
    id UUID PRIMARY KEY,
    openid VARCHAR(64),          -- 微信openid
    nickname VARCHAR(64),
    avatar_url VARCHAR(256),
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);
```

#### 评估记录表

```sql
CREATE TABLE assessments (
    id UUID PRIMARY KEY,
    user_id UUID REFERENCES users(id),
    type VARCHAR(32),             -- partner/investment/strategy/other
    background TEXT,              -- 决策背景
    answers JSONB,                -- 答案JSON
    scores JSONB,                  -- 各维度得分
    total_score INTEGER,          -- 综合得分

    risk_warnings JSONB,           -- 风险预警
    suggestions JSONB,             -- 行动建议
    created_at TIMESTAMP DEFAULT NOW()
);
```

#### 报告表

```sql
CREATE TABLE reports (
    id UUID PRIMARY KEY,
    assessment_id UUID REFERENCES assessments(id),
    content HTML,                 -- 报告HTML
    pdf_url VARCHAR(256),         -- PDF下载地址
    share_token VARCHAR(64),       -- 分享Token
    view_count INTEGER DEFAULT 0,
    created_at TIMESTAMP DEFAULT NOW()
);
```

## 十、附录

### 10.1 问卷快速自检表

| 维度 | 快速自检问题（不看完整问卷） |
|:----:|:----------------------------:|
| **土·信义** | 5分钟内，你能说出3个你最信任的人吗？他们做了什么让你信任？ |
| **金·标尺** | 你上一次说"已经够好了，可以做了"是什么时候？ |
| **水·觉察** | 你能说出昨天让你不舒服的那个情绪的名字吗？ |
| **木·伦理** | 过去一年，你做了几个承诺？兑现了几个？ |
| **火·顿悟** | 上一次让你兴奋的"灵感"是什么时候？你做了什么？ |

### 10.2 五维平衡检查表

```
□ 土·信义是否过强？（盲目信任 → 需要水·觉察）
□ 金·标尺是否过强？（标准僵化 → 需要火·顿悟）
□ 水·觉察是否过强？（分析瘫痪 → 需要火·顿悟）
□ 木·伦理是否过强？（道德审判 → 需要土·信义）
□ 火·顿悟是否过强？（朝令夕改 → 需要金·标尺）
```

> **设计原则**
> - 对外：五维决策，专业可信
> - 对内：五路图腾，文化传承
> - 核心理念：不是"算命"，是"系统化自检"
> - 价值主张：5分钟，不是敷衍，是高效
