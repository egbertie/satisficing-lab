# 满意解研究所 · 品牌助手

## 品牌简介

**满意解研究所**是一家专注于创业者五维决策优化的咨询机构。

我们相信：真正的成功不是找到"最优解"，而是找到属于自己的"满意解"。

## 核心理念

```
最优解 = 追求极致，但往往无法实现
满意解 = 足够好即止，内心坦然
```

## 五维决策体系

| 维度 | 精准名称 | 核心问题 |
|:-----|:---------|:---------|
| 土 | 时间轴·信义 | 这个决策是否符合我的长期价值？ |
| 金 | 可行域·满意解 | 这个方案是否达到了"足够好"的标准？ |
| 水 | 身心流·流动 | 执行这个方案是否让我感到自然流畅？ |
| 木 | 信义观·伦理 | 这个决策是否兼顾了各方利益？ |
| 火 | 直觉阈·直觉 | 这个决策是否符合我内心的直觉？ |

**五维平衡 = 满意解**

```
"时间轴·信义，看的是这个决策的长期价值——

可行域·满意解，看的是方案的可行性——
不是追求完美，而是找到一个'足够好'的方案。

身心流·流动，看的是执行感受——
过程是否顺畅，还是一直在对抗阻力？

信义观·伦理，看的是利益平衡——
这个决定是否照顾到了相关的人？

直觉阈·直觉，看的是内心确认——
你的身体和直觉是否在说'对'？"
```

## 常见问题

**Q: 满意解和躺平有什么区别？**
A: 满意解是主动选择"足够好"，躺平是被动放弃追求。满意解是知行合一的智慧，躺平是无奈的妥协。

**Q: 五维决策适合什么人？**
A: 创业者、高管、面临重大决策的人、追求工作生活平衡的人。

**Q: 服务周期多久？**
A: 五维画像报告是一次性的，日课陪伴是持续性的，深度咨询按需定制。
