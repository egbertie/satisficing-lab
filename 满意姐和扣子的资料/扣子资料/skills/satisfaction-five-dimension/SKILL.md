# 五维诊断系统

## 核心框架

```
输入: 用户问题/问卷数据
    ↓
五维评估:
  - 土·时间轴·信义: 决策是否符合长期价值
  - 金·可行域·满意解: 方案是否达到"足够好"标准
  - 水·身心流·流动: 执行过程是否流畅自然
  - 木·信义观·伦理: 决策是否兼顾各方利益
  - 火·直觉阈·直觉: 决策是否符合内心直觉
    ↓
满意解判定:
  - 五维平均≥80: 强推荐
  - 五维平均≥60: 建议执行
  - 五维平均<60: 需调整后执行
    ↓
输出: 五维雷达图 + 分析报告 + 行动建议
```

## 五维精准名称

| 原名 | 精准对外名称 | 分析要点 |
|:-----|:------------|:---------|
| 土·信义 | 时间轴·信义 | 决策的长期价值与信守承诺 |
| 金·满意解 | 可行域·满意解 | 方案的可行性与"足够好"标准 |
| 水·流动 | 身心流·流动 | 执行过程的流畅与自然 |
| 木·伦理 | 信义观·伦理 | 决策的道德与利益平衡 |
| 火·直觉 | 直觉阈·直觉 | 决策与内心直觉的一致性 |

## 使用场景

### 场景1：快速诊断
```
用户: "我想辞职创业，你觉得合适吗？"
→ 加载五维诊断Skill
→ 询问5个快速问题
→ 生成五维雷达图
→ 给出建议
```

### 场景2：问卷分析
```
输入: 问卷数据JSON
→ 解析五维得分
→ 生成雷达图数据
→ 输出分析报告
→ 提供行动建议
```

### 场景3：决策评估
```
用户: "这个投资机会要不要抓住？"
→ 五维逐一评估
→ 识别短板维度
→ 提供优化建议
→ 判定满意解等级
```

## 满意解判定标准

| 综合得分 | 等级 | 建议 |
|:---------|:-----|:-----|
| ≥80分 | 🌟 强推荐 | 果断执行 |
| 70-79分 | ✅ 建议执行 | 可以行动 |
| 60-69分 | ⚠️ 谨慎执行 | 需要调整 |
| <60分 | ❌ 暂缓 | 重新思考 |
