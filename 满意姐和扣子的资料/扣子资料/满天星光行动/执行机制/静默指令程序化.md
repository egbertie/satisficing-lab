# 静默指令程序化（V1.0）

## 指令标识
- **指令名称**：静默
- **别名**：轻度静默、L2静默
- **触发词**：静默、轻度静默、quiet

---

## 核心定位

**静默 vs 深度静默**

| 维度 | 静默 | 深度静默 |
|:-----|:-----|:---------|
| 日程任务 | ✅ 照常执行 | ❌ 暂停 |
| 心跳频率 | 30分钟/次（轻量） | 720分钟/次（极简） |
| 通知打扰 | 暂停 | 完全暂停 |
| 响应层级 | P0 + 日程任务结果 | 仅Egbertie唤醒 |
| 适用场景 | 你休息，任务照跑 | 你彻底不管 |

---

## 执行流程

### Step 1：快速检查（轻量）

```
□ 今日日程任务有哪些？
□ 哪些需要我执行？
□ Token使用率？
```

### Step 2：执行C5日程检查

- 检查今日Calendar任务
- 启动sub-agent执行需要我执行的任务
- 任务完成后自动归档，不打扰你

### Step 3：配置轻量心跳

- 心跳间隔：30分钟
- 检查内容：
  ```
  - 有无需要执行的Calendar任务？→ 启动sub-agent
  - Token使用率>80%？→ 提醒你
  - 有无P0紧急事项？→ 通知你
  ```

### Step 4：进入静默

回复你：
```
静默模式已启动 ✅

📋 今日任务：{X}个
- 日程任务：照常执行
- 产出自动归档
- 有异常才通知你

休息吧，Egbertie 🌙
```

---

## 心跳配置（双经济约束）

**30分钟心跳检查项（轻量版）：**
```
1. Calendar任务检查（只查今天）
   - 有任务到期 → 启动sub-agent执行
   - 无任务 → 静默

2. Token监控
   - >80% → 通知你
   - ≤80% → 静默

3. 紧急事项（P0）
   - 有 → 通知你
   - 无 → 静默
```

**禁止项（双经济违规）：**
```
❌ 扫描文件找新增
❌ 检查文件夹规范性
❌ 扫描历史记忆
❌ 生成健康报告
❌ 任何"没事找事"的检查
```

---

## 唤醒条件

- 你主动唤醒
- 日程任务执行完成（结果归档后才通知）
- Token>80%
- P0紧急事项
