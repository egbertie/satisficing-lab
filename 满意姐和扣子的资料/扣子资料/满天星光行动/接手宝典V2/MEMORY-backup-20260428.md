## 十三、自我检查习惯（2026-04-23新增）

> **来源**: Egbertie批评  
> **教训**: 冰山效应，知道但不做，等踢才动

### 13.1 问题根因

| 问题 | 表现 |
|:-----|:-----|
| 视野太窄 | 只看当前目录，不看全局 |
| 工具选错 | 用ls不用find |
| 假设错误 | 先入为主，以为对的地方没问题 |

### 13.2 正确做法

**文件夹检查标准流程**：
```
1. 全局扫描优先于目录浏览
   find . -name "*关键词*" -type d

2. 编号重复检查
   find . -maxdepth 1 -type d -name "[0-9][0-9]_*"

3. 嵌套重复检查
   find . -type d -name "XXX" -path "*XXX/*"

4. 临时文件夹检查
   find . -type d -name "*临时*" -o -name "*temp*"
```

### 13.3 联动要求

| 场景 | 要求 |
|:-----|:-----|
| 发现一个问题 | 立即扫描全局同类问题 |
| 知道冰山效应 | 立即行动找其他冰山 |
