## 二、各环节详解

### 2.1 获客入口

| 渠道 | 入口形式 | 转化路径 |
|:-----|:---------|:---------|
| 小红书 | 笔记→评论区→私信 | 私信→问卷链接 |
| 公众号 | 文章→阅读原文 | 原文→问卷 |
| 飞书 | 云文档分享 | 文档→问卷 |
| 口碑推荐 | 直接咨询 | 转问卷 |

### 2.2 问卷填写

**问卷设计（精简版5题）**：

| 题号 | 问题 | 对应维度 |
|:-----|:-----|:---------|
| Q1 | 您目前面临的核心挑战是什么？ | 开放式 |
| Q2 | 做决策时，您最看重什么？（时间/利益/感受/伦理/直觉） | 五维识别 |
| Q3 | 您对"足够好"的标准是什么？ | 满意解标准 |
| Q4 | 您最近的状态如何？（1-10分） | 身心流 |
| Q5 | 您希望达到什么状态？ | 目标设定 |

**问卷技术实现**：

```
方案A: 飞书多维表格表单
- 优点: 免费、快速
- 缺点: 需要飞书账号

方案B: 腾讯问卷 + 飞书Webhook
- 优点: 无需账号
- 缺点: 需配置Webhook

方案C: 自建H5页面
- 优点: 品牌统一
- 缺点: 开发成本
```

### 2.3 数据采集

**自动化采集流程**：

```python
# 伪代码示例
def on_survey_submit(data):
    # 1. 新增CRM记录
    crm.add_record(data)
    
    # 2. 提取五维得分
    scores = calculate_five_dimension(data)
    
    # 3. 生成报告
    report = generate_report(scores)
    
    # 4. 发送邮件
    email.send(report, data.email)
    
    # 5. 通知运营
    feishu_bot.notify("新客户完成问卷")
```

| **总计** | ~5300 | 约$0.02 |

| 来源 | 单选 | 小红书/公众号/推荐/其他 |
| 问卷得分 | JSON | 五维数据 |
| 雷达图 | 图片 | ECharts生成 |
| 服务状态 | 单选 | 潜在/跟进中/已服务/已完成 |
| 创建时间 | 创建时间 | 自动 |
| 跟进人 | 人员 | |

### 3.2 自动化公式

```
五维总分 = AVERAGE(问卷得分)
服务等级 = IF(五维总分>=80, "A类", IF(总分>=60, "B类", "C类"))
跟进提醒 = DATEADD(创建时间, 3, "day")
```

### 3.3 视图设计

| 视图 | 用途 | 筛选条件 |
|:-----|:-----|:---------|
| 全部客户 | 总览 | 全部 |

| 本周新增 | 快速跟进 | 创建时间=本周 |
| 待跟进 | 避免遗漏 | 服务状态="跟进中" |
| 已完成 | 归档查看 | 服务状态="已完成" |

## 五、Token经济学分析

| 环节 | Token消耗 | 频率 | 月度Token | 优化空间 |
|:-----|:----------|:-----|:----------|:---------|
| 问卷分析 | 2000 | 100次/月 | 200,000 | 模板缓存 |
| 报告生成 | 3000 | 100次/月 | 300,000 | 模板填充 |
| 邮件发送 | 200 | 100次/月 | 20,000 | 简化模板 |
| **总计** | 5200 | 100次/月 | 520,000 | **38%** |

**优化策略**：

1. **模板缓存**：通用解读预生成，减少重复计算
2. **批量处理**：同批次问卷合并分析
3. **分级服务**：A类客户详细分析，B/C类简化处理

---
