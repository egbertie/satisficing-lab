# 五维诊断 Skill

## 基本信息

- **Skill名称**：五维诊断
- **版本**：1.0.0
- **适用场景**：当用户需要进行五维决策系统诊断、填写问诊问卷、分析个人画像时使用
- **触发关键词**：五维诊断、问诊问卷、个人画像分析、五维报告

## 五维精准对外名称

| 维度 | 精准名称 | 五行属性 | 说明 |
|------|----------|----------|------|
| 第一维 | 时间轴·信义 | 土 | 时间和承诺相关 |
| 第二维 | 可行域·满意解 | 金 | 决策空间和选择 |
| 第三维 | 身心流·流动 | 水 | 身心状态和流动 |
| 第四维 | 信义观·伦理 | 木 | 人际关系和道德 |
| 第五维 | 直觉阈·直觉 | 火 | 直觉和创造力 |

## 核心功能

### 1. 问诊问卷引导
- 引导用户完成五维度问诊
- 每个维度5-10道测试题
- 记录用户回答

### 2. 五维得分计算
- 根据问卷回答计算各维度得分
- 生成五维雷达图数据
- 输出结构化诊断结果

### 3. 报告生成
- 生成五维画像报告
- 包含雷达图、个人分析、建议方案
- 可导出为飞书文档

## 输出格式

```
五维诊断报告

## 封面
- 姓名：[用户姓名]
- 日期：[诊断日期]

## 五维得分
| 维度 | 得分 |
|------|------|
| 时间轴·信义（土） | XX分 |
| 可行域·满意解（金） | XX分 |
| 身心流·流动（水） | XX分 |
| 信义观·伦理（木） | XX分 |
| 直觉阈·直觉（火） | XX分 |

## 个人分析
[基于得分的个性化分析]

## 建议方案
[针对性的改进建议]
```

## 使用流程

1. **问诊启动**：询问用户姓名、基本信息
2. **问卷填写**：引导完成五个维度的问卷
3. **数据收集**：记录所有回答
4. **得分计算**：根据规则计算五维得分
5. **报告生成**：生成诊断报告
6. **结果发送**：将报告发送给用户

## 技术要求

- 支持飞书多维表格数据写入
- 支持飞书文档报告生成
- 支持ECharts雷达图渲染
- 支持邮件/飞书消息发送
