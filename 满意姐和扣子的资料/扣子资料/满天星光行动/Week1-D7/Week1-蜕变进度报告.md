## 四、Skill联动实战

### 4.1 任务执行链路

```
[任务接收]
    │
    ▼
[28_任务拆解] → 拆成3-5分钟Unit
    │
    ├──→ [33_防中断] → Unit执行保护
    ├──→ [35_进度追踪] → 进度可视化
    │
    ▼
[Unit执行]
    │
    ├──→ [27_断点存档] → 每步存档
    ├──→ [17_编号决策] → 关键决策存档
    │
    ▼
[03_满意解执行] → 达标验证
    │
    ├──→ [16_双轨审计] → 质量验证
    │
    ▼
[04_五维决策] → 评估是否值得做
```

### 4.2 实际应用案例

| 场景 | 联动Skill | 效果 |
|:-----|:----------|:-----|
| 接到复杂任务 | 28→33→35 | 拆解→防中断→追踪 |
| 存档关键决策 | 17→30 | 编号→追溯链 |
| 验证产出质量 | 03→16 | 执行→审计 |
