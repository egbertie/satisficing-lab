### 2.2 Self-Improving Agent 使用指南

**安装命令**：
```bash
clawhub install self-improving-agent --registry=https://cn.clawhub-mirror.com
```

**核心功能**：
- `.learnings/` 目录自动创建
- ERRORS.md: 记录命令失败、工具异常
- LEARNINGS.md: 沉淀用户纠正、最佳实践
- FEATURE_REQUESTS.md: 收集能力需求

**蜕变计划应用**：
```
每天学习记录 → 自动沉淀为方法论 → 形成个人Skill库
```

## 七、风险与建议

### 风险点
1. **ClawHub访问**: 可能需要科学上网
2. **云电脑/云手机**: 需企业版权益
3. **技能稳定性**: 第三方Skill质量参差

### 优化建议
1. 优先使用Coze内置功能，外部Skill作为增强
2. Self-Improving Agent 建议先在测试环境验证
3. 每周评估Skill效果，淘汰低价值技能
