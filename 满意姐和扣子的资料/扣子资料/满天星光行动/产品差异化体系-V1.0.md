```
满意解研究所 ≠ 传统咨询公司
```

## 二、核心差异化产品

### 2.1 五维画像报告

**差异化点**：

```
传统: "您的企业需要XX改进"
满意解: "您的五维中，火维度（直觉）偏低，建议..."

差异点:
- 具象化 → 抽象化
- 给答案 → 给镜子
- 一次性 → 持续追踪
```

### 2.2 日课执行系统

**差异化点**：

```
传统: "制定战略规划"
满意解: "每天5分钟日课，追踪五维变化"

差异点:
- 高大上 → 小而美
- 一次性 → 日常化
- 被动 → 主动
```

### 2.3 满意解决策法

**差异化点**：

```
传统决策: "最优解"（追求极致）
满意解决策: "足够好"（满意即止）

决策模型:
1. 时间轴·信义 → 长期价值判断
2. 可行域·满意解 → 方案可行性
3. 身心流·流动 → 执行感受
4. 信义观·伦理 → 利益平衡
5. 直觉阈·直觉 → 内心确认
→ 五维平衡 = 满意解
```

## 七、竞品分析

### 7.1 直接竞品

| 竞品 | 优势 | 劣势 | 我们的机会 |
|:-----|:-----|:-----|:-----------|
| 高樟咨询 | 品牌强 | 收费高 | 轻量化+AI |

### 7.2 差异化打法

```
竞品: 给答案（顾问权威）
我们: 给镜子（自我觉醒）

竞品: 重报告（一次性）
我们: 重日课（持续性）

竞品: 讲方法论（西方）
我们: 讲五维（东方+现代）
```
