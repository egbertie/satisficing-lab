## Skill 1: 五维诊断系统

### SKILL.md

```yaml
---
name: satisfaction-five-dimension
description: 满意解研究所五维诊断系统。当用户需要：(1)分析决策问题的五维属性 (2)生成五维画像报告 (3)解读五维得分 (4)提供满意解建议时使用。本Skill封装了土金水木火五维分析框架，输出精准、结构化、可执行的诊断结果。
---
```

### 核心逻辑

```
输入: 用户问题/问卷数据
    ↓
五维评估:
  - 土·时间轴·信义: 决策是否符合长期价值
  - 金·可行域·满意解: 方案是否达到"足够好"标准
  - 水·身心流·流动: 执行过程是否流畅自然
  - 木·信义观·伦理: 决策是否兼顾各方利益
  - 火·直觉阈·直觉: 决策是否符合内心直觉
    ↓
满意解判定:
  - 五维≥80: 强推荐
  - 五维≥60: 建议执行
  - 五维<60: 需调整后执行
    ↓
输出: 五维雷达图 + 分析报告 + 行动建议
```

### 使用示例

```
用户: "我想辞职创业，你觉得合适吗？"
扣子: [加载五维诊断Skill]
→ 评估五维得分
→ 生成雷达图
→ 给出建议
```

## Skill 3: 日课执行标准

### SKILL.md

```yaml
---
name: daily-practice-standard
description: 满意解研究所日课执行系统。当需要：(1)执行日课 (2)自检质量 (3)记录复盘 (4)追踪进度时使用。本Skill封装了日课执行标准、5秒自检协议、质量评估方法，确保日课执行有标准、可追踪、能复盘。
---
```

### 5秒自检协议

```
每次执行前自问：
1. 我要做什么？（预判）
2. 我怎么做？（行动）
3. 对方在意什么？（在意）
4. 足够好了吗？（满意解）
5. 记住了吗？（记忆）
```

### 日课类型

| 类型 | 时间 | 核心动作 |
|:-----|:-----|:---------|
| 晨间日课 | 起床后 | 今日计划+优先级 |
| 午间日课 | 午休前 | 执行复盘+调整 |
| 晚间日课 | 睡前 | 成果记录+感恩 |

### SKILL.md

```yaml
---
name: client-growth-tracker
description: 客户全生命周期管理系统。当需要：(1)管理客户档案 (2)追踪服务进度 (3)提醒跟进 (4)分析客户状态时使用。本Skill封装了客户分层、服务流程、跟进提醒、效果评估等CRM逻辑。
```

### 客户分层

```
A类客户（高价值）
- 五维得分高
- 复购意愿强
- 每月至少1次深度服务

B类客户（培育中）
- 有需求未转化
- 每月跟进
- 培育满意解产品

C类客户（观望中）
- 低频互动
- 按需服务
- 保持联系
```

## 安装与使用

### 安装命令

```bash
HOME=/root PATH=$PATH:/root/.local/bin skillhub install satisfaction-five-dimension
```

### 本地创建

```bash
mkdir -p skills/satisfaction-five-dimension/{scripts,references,assets}
```

### 目录结构

```
satisfaction-five-dimension/
├── SKILL.md              # 核心逻辑
├── scripts/
│   ├── radar_chart.py    # 雷达图生成
│   └── score_calc.py     # 五维计算
├── references/
│   ├── dimension_guide.md
│   └── case_study.md
└── assets/
    └── template.docx     # 报告模板
```
