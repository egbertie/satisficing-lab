## 🔖 标签1: 满意解方法论

### 标签描述
> 当内容涉及满意解研究所核心方法论（满意解执行系统、五维决策体系、满意度经济学）时，推荐此标签。

### 推荐收藏内容

#### 1. 核心定义
```
满意解 = 在时间、信义、可行域、身心流、直觉五维平衡下的最优决策点

不是"最优解"（追求极致），而是"满意解"（足够好即止）
- 时间轴·信义：长期价值判断
- 可行域·满意解：方案可行性
- 身心流·流动：执行感受
- 信义观·伦理：利益平衡
- 直觉阈·直觉：内心确认
```

#### 2. 满意解执行系统核心
```
血液化五级检验：
Lv1 见过 - 知道概念
Lv2 会做 - 能独立操作
Lv3 讲透 - 能教会别人
Lv4 渗透 - 融入日常习惯
Lv5 无意识 - 不自觉运用

满意解标准：
30%投入 → 80%效果
追求"足够好"而非"完美"
```

#### 3. 五维决策框架
```
五维自检问题：
1. 时间轴：这件事的长期影响是什么？
2. 可行域：这个方案我能做到吗？
3. 身心流：做这件事时感受如何？
4. 信义观：是否符合我的价值观？
5. 直觉阈：我内心是否接受这个决定？

五维平衡 = 满意解
```

## 🔖 标签2: 五维报告库

### 标签描述
> 当内容涉及客户五维诊断报告、雷达图分析、个性化方案时，推荐此标签。

### 推荐收藏内容

#### 五维雷达图维度说明
```
五维画像：
├── 时间轴·信义 (土) - 长期价值、信义积累
├── 可行域·满意解 (水) - 方案可行、效果评估
├── 身心流·流动 (木) - 执行感受、信息流动
├── 信义观·伦理 (金) - 利益平衡、伦理边界
└── 直觉阈·直觉 (火) - 内心直觉、灵感判断

雷达图解读：
- 面积均衡 = 五维平衡
- 某维突出 = 该维需重点关注
- 某维凹陷 = 该维存在明显短板
```

#### 示例报告框架
```
五维诊断报告结构：
1. 客户基本信息
2. 问卷数据解读
3. 五维深度分析（每维评分+建议）
4. 综合评分与建议
5. 最优服务路径
```
