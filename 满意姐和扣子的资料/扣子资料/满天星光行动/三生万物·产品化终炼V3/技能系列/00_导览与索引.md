## 系列定位

技能系列是三生万物体系的能力延伸。

如果说"知识飞轮传承"是"如何把知识传下去"，
那么技能系列就是"如何做出好决策"、"如何防止犯错"、"如何高效执行"。

三者构成满意解研究所的**核心能力三角**：
- **知识**（飞轮传承）→ 积累与传承
- **决策**（五维体系）→ 判断与选择
- **执行**（满意解系统）→ 行动与交付
- **免疫**（蓝军验证）→ 审计与纠错

## 使用说明

### 五维决策体系

**适用场景**:
- 合伙人匹配决策
- 硬科技转化评估
- 团队组建选择
- 任何"不知道该怎么选"的复杂决策

**使用方法**:
1. 描述决策场景（3句话）
2. 运行 `scripts/decision-assistant.py`
3. 按土→金→水→木→火顺序评分
4. 总分≥35推进，任一<5补强

### 蓝军批判性验证

**适用场景**:
- 任何声称"完成"的产出
- 重大决策前的风险把关
- 发现"看起来太顺利"时的自我审计

**使用方法**:
1. 运行 `scripts/audit-checker.py`
2. 逐项回答10项认知审计
3. 获得风险等级（🔴🟡🟢）
4. 按整改要求修正

### 满意解执行系统

**适用场景**:
- 项目启动
- 任务管理
- 防中断执行
- 双经济约束检查

**使用方法**:
1. 读取项目模板 `assets/templates/project-template.md`
2. 按启动→执行→收尾三阶段操作
3. 运行 `scripts/progress-tracker.py` 创建追踪文件
4. 每完成一块Git提交
