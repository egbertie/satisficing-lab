# 飞书产品交付平台 · 模板设计

> **版本**: V1.0
> **编制日期**: 2026-04-28
> **面向**: 满意解研究所全产品矩阵

---

## 一、客户CRM多维表格

### 1.1 核心字段设计

| 字段名 | 类型 | 说明 | 自动化目标 |
|:-------|:-----|:-----|:-----------|
| 客户ID | 自动编号 | 唯一标识 | 自动生成 |
| 姓名 | 单行文本 | 客户姓名 | 手动录入 |
| 联系方式 | 手机/邮箱 | 联系方式 | 手动录入 |
| 来源渠道 | 单选 | 问卷/推荐/自访 | 手动录入 |
| 五维得分 | 数字 | 5个维度JSON | 自动计算 |
| 服务状态 | 单选 | 潜在/进行中/已完成 | 自动更新 |
| 跟进记录 | 多行文本 | 历史跟进 | 自动追加 |
| 下次跟进 | 日期 | 计划时间 | 提醒设置 |
| 创建时间 | 日期 | 档案创建 | 自动记录 |

### 1.2 五维得分数据结构

```
五维得分 = {
  "时间轴·信义": 78,
  "可行域·满意解": 85,
  "身心流·流动": 72,
  "信义观·伦理": 80,
  "直觉阈·直觉": 65
}
```

### 1.3 自动化规则

| 触发条件 | 执行动作 | Token消耗 |
|:---------|:---------|:----------|
| 问卷提交 | 新增记录 + 发邮件确认 | 低 |
| 五维分析完成 | 更新五维得分 + 状态变更 | 低 |
| 服务完成 | 状态→已完成 + 归档 | 低 |
| 7天未跟进 | 提醒通知 | 低 |

## 二、五维画像报告模板

### 2.1 报告结构

```
【封面】
- 标题：五维画像报告
- 客户姓名
- 报告日期

【一、五维雷达图】
- ECharts雷达图可视化
- 五维得分一目了然

【二、五维分析解读】
1. 时间轴·信义（分值/解读/建议）
2. 可行域·满意解（分值/解读/建议）
3. 身心流·流动（分值/解读/建议）
4. 信义观·伦理（分值/解读/建议）
5. 直觉阈·直觉（分值/解读/建议）

【三、综合建议】
- 基于五维平衡的整体建议
- 优先级排序

【四、后续行动计划】
- 建议的下一步服务
- 预期效果

【五、服务记录】
- 历史服务时间线
```

### 2.2 自动化工作流

```
问卷提交 → 数据采集 → 五维分析 → 报告生成 → 文档创建 → 邮件发送
    ↓           ↓           ↓          ↓          ↓          ↓
  触发器     API获取     AI分析    模板填充   飞书文档   自动发送
```

## 三、日课执行系统

### 3.1 日课记录多维表格

| 字段名 | 类型 | 说明 |
|:-------|:-----|:-----|
| 日期 | 日期 | 记录日期 |
| 日课类型 | 单选 | 晨间/午间/晚间 |
| 执行内容 | 多行文本 | 具体执行 |
| 质量自评 | 评分1-5 | 自我评价 |
| 改进点 | 多行文本 | 反思记录 |
| 拍照凭证 | 附件 | 执行证据 |
| 状态 | 单选 | 已完成/部分完成/未完成 |
| 执行时长 | 数字 | 分钟数 |

### 3.2 日课统计仪表盘

| 统计项 | 计算方式 | 展示形式 |
|:-------|:---------|:---------|
| 本周完成率 | 已完成/总数 | 百分比 |
| 连续执行天数 | 统计连续 | 数字+徽章 |
| 平均质量分 | 平均值 | 数字 |
| 改进点汇总 | 文本聚合 | 词云 |

## 四、问诊问卷系统

### 4.1 问卷字段

| 问题 | 类型 | 分值 | 维度对应 |
|:-----|:-----|:-----|:---------|
| Q1: 您做决策时最看重什么？ | 单选 | 1-5 | 时间轴·信义 |
| Q2: 您对"足够好"的标准是？ | 单选 | 1-5 | 可行域·满意解 |
| Q3: 您最近的状态流动吗？ | 单选 | 1-5 | 身心流·流动 |
| Q4: 您如何处理利益冲突？ | 单选 | 1-5 | 信义观·伦理 |
| Q5: 您凭直觉做决定后后悔吗？ | 单选 | 1-5 | 直觉阈·直觉 |

### 4.2 问卷自动化

```
问卷提交 → 飞书多维表格新增记录 → 五维得分自动计算 → 
触发报告生成 → 发送确认邮件 → 进入客户CRM
```

## 六、执行优先级

| 优先级 | 模板 | Token预估 | 效益 |
|:-------|:-----|:----------|:-----|
| P0 | 客户CRM | 低 | 高 |
| P0 | 五维报告模板 | 中 | 高 |
| P1 | 日课系统 | 低 | 中 |
| P1 | 问卷系统 | 中 | 高 |
| P2 | 知识库 | 高 | 中 |

---

> **核心原则**：先建立数据基础设施（CRM），再扩展服务能力（报告、日课），最后完善资产沉淀（知识库）。
