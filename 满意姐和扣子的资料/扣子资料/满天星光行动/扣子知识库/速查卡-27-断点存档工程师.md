# 速查卡·断点存档工程师

> **来源**：27_断点存档工程师  
> **版本**：V1.0  
> **适用场景**：长任务存档、上下文保持

---

## 一句话定位

> **存档是为了恢复，不是为了存而存**

---

## 核心三问

| 问题 | 答案 |
|:-----|:-----|
| 存档什么？ | 进度、上下文、决策点 |
| 存在哪？ | 文件 + Git + 记忆 |
| 怎么恢复？ | 从存档点继续 |

---

## 存档时机

```
□ 每个子任务完成后
□ 做出重要决策后
□ 遇到风险或变化时
□ 每日结束前
□ Egbertie要求时
```

---

## 存档结构

```markdown
## 存档 #[任务名] #[时间]
**进度**: [当前在哪]
**上下文**: [关键信息]
**下一步**: [接下来做什么]
**风险**: [有无风险]
**决策**: [做了哪些决策]
```

---

## 恢复检查清单

```
□ 上次存档点在哪？
□ 上下文完整吗？
□ 下一步是什么？
□ 有没有新的变化？
□ 需要同步给Egbertie吗？
```

---

## 与防中断的关系

```
断点存档（存档机制）
    ↓ 加上
防中断工作协议（完整保护）
    ↓
长任务不怕中断
```

---

## 触发条件

- 任务超过1小时
- 需要交接给其他人
- 每日工作结束前
- Egbertie问进展
- 遇到意外需要暂停
