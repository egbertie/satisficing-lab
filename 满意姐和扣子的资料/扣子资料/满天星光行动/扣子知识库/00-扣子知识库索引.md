## 二、场景应用指南

### 场景1：接到新任务

```
触发：收到Egbertie的任务指令
动作：
  1. 用【满意解执行系统】接收任务 → 确认理解 → 拆解
  2. 用【进度追踪标准化师】建立进度追踪
  3. 用【防中断工作协议】设置存档点
  4. 执行 → 存档 → 交付 → 归档
```

### 场景2：做重大决策

```
触发：需要做影响方向的选择
动作：
  1. 用【认知防火墙】检查输入是否正确
  2. 用【五维决策体系】做全面评估
  3. 用【快速认知审计】检查是否有偏差
  4. 决策 → 记录 → 执行 → 复盘
```

### 场景3：需要整理大量信息

```
触发：收到大量文件/文档需要处理
动作：
  1. 用【知识海啸】批量获取和结构化
  2. 用【知识飞轮】整理和存储
  3. 用【断点存档工程师】确保不丢失
```

### 场景4：写日报/周报

```
触发：需要生成日报或周报
动作：
  1. 用【晨报日报生成器】收集今日/本周内容
  2. 整理 → 生成 → 发送
```

### 场景5：检查产出质量

```
触发：完成一个产出后自检
动作：
  1. 用【创始人5分钟可用性检验】检查是否易读
  2. 用【FIN诚实验证器】检查信息真实性
  3. 用【快速认知审计】检查偏差
```

## 三、常见问题应对

### Q1：任务做到一半被打断怎么办？

**答案**：用【防中断工作协议】
1. 立即存档（文件+git+记忆）
2. 记录当前进度和下一步
3. 恢复时从存档点继续

### Q2：有多个任务并行怎么办？

**答案**：用【进度追踪标准化师】
1. 建立统一的任务列表
2. 串行执行，不并行
3. 每个任务完成后更新进度
4. 定期同步给Egbertie

### Q3：担心决策有偏差怎么办？

**答案**：用【快速认知审计】
1. 扫描10个常见认知偏差
2. 识别可能的偏差
3. 纠正后再执行
4. 记录审计结果

### Q4：需要保持上下文怎么办？

**答案**：用【记忆同步协议】
1. 关键信息同步到MEMORY.md
2. 每次对话前检查MEMORY
3. 任务完成后更新记忆
4. 定期整理记忆库

### Q5：Egbertie问「以前有类似情况吗」？

**答案**：用【决策考古学】
1. 搜索历史决策档案
2. 提取相似决策卡片
3. 分析模式和结果
4. 给出可迁移的参考

## 五、联用关系图

```
防中断工作协议（单任务）
    ↓ 扩展
进度追踪标准化师（多任务）
    ↓ 统一格式
满意解执行系统（完整流程）
    ↓ 加上
防中断 + 存档 = 长任务保护系统

认知防火墙（事前）
    ↓ 检查输入
五维决策体系（事中）
    ↓ 做决策
快速认知审计（事后）
    ↓ 审计偏差
回到认知防火墙 = 决策质量闭环
```
