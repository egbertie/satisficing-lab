# Skill学习报告：35_进度追踪标准化师

## P0延伸Skill · 第14个 · 2026-04-26

---

### 核心概念（1-2句）

**多任务并行时的统一进度追踪格式**。防止进度文件分散、格式不一、状态不清。核心原则：统一格式、统一位置、统一更新、统一查看。

---

### 4个统一

```
机制1: 统一格式 — 「一个模板，全部遵循」
机制2: 统一位置 — 「全在对话文件夹」
机制3: 统一更新 — 「事件驱动，不是定时」
机制4: 统一查看 — 「一瞥即知全局」
```

---

### 机制1：统一格式

**强制模板**（与33防中断工作协议一致）：
```markdown
# [任务名称] — 进度追踪

**任务**: [一句话描述]
**启动时间**: YYYY-MM-DD HH:MM
**防中断状态**: 🔄 进行中 / ⏸️ 暂停 / ✅ 完成
**保存路径**: [完整路径]

---

## 完成清单

### [U1] 单元名称 ✅
**状态**: 完成 | **Git**: [hash] | **产出物**: [路径]

### [U2] 单元名称 🔄
**状态**: 进行中 | **已完成**: [步骤] | **待完成**: [步骤]
```

---

### 机制2：统一位置

```
位置: A-manyige/对话/YYYY-MM-DD/
命名: [任务名]-进度追踪-YYYY-MM-DD.md

示例:
✅ 技能系列-进度追踪-2026-04-26.md
✅ 三生万物建设-进度追踪-2026-04-26.md
✅ 31-32训练系列-进度追踪-2026-04-26.md

禁止位置:
❌ 根目录
❌ 技能文件夹内部
❌ memory/ 文件夹
```

---

### 机制3：统一更新

**事件驱动更新**（不是定时）：
| 事件 | 更新内容 |
|:-----|:---------|
| 单元完成 | 标记✅，记录Git hash |
| 新单元启动 | 添加新行，标记🔄 |
| 任务阻塞 | 标记⏸️，记录阻塞原因 |
| Git提交 | 记录commit hash |
| 任务完成 | 标记✅，归档到memory |

**更新时效**：事件发生后3分钟内必须更新

---

### 机制4：统一查看

**查看方法**：
```bash
# 查看当天全部进度
ls A-manyige/对话/2026-04-26/*进度追踪*.md

# 快速扫描状态
grep -h "防中断状态" A-manyige/对话/2026-04-26/*进度追踪*.md
```

**输出示例**：
```
技能系列-进度追踪: 防中断状态: ✅ 完成
三生万物建设-进度追踪: 防中断状态: ✅ 完成
31-32训练系列-进度追踪: 防中断状态: ✅ 完成
33-35工作流系列-进度追踪: 防中断状态: 🔄 进行中
```

### 任务切换协议

```
当前任务A进行中
    ↓ 用户插入高优先级任务B
存档任务A进度
    ↓
创建任务B进度文件
    ↓
执行任务B
    ↓
任务B完成
    ↓
读取任务A进度
    ↓
恢复任务A
```
