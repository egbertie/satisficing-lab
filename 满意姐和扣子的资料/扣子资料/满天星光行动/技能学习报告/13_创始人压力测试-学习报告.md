# 学习报告：13_创始人压力测试（P2）

## 核心概念（1-2句）
模拟投资人/合伙人的拷问场景，提前暴露决策盲区。创始人在投资人面前崩溃的原因：没想过这个问题 / 答案在PPT但讲不清楚 / 被问到痛点情绪失控。

## 使用场景（何时用）
- 融资路演前准备
- 重要谈判前演练
- 决策信心提升
- 触发词："压力测试" / "拷问模拟" / "决策体检" / "投资人模拟"

## 核心咒语/原则（必须会背）

**拷问题库示例**：
| 类别 | 示例问题 | 难度 |
|:-----|:---------|:-----|
| 商业模式 | "你的护城河是什么？" | 中等 |
| 财务预测 | "如果收入只有预测的30%怎么办？" | 高 |
| 团队风险 | "如果CTO离职，你怎么办？" | 高 |
| 竞争格局 | "如果巨头进来，你怎么办？" | 极高 |
| 估值逻辑 | "为什么值这个价？" | 中等 |

**压力等级**：
| 等级 | 问题数 | 追问深度 | 情绪干扰 |
|:-----|:-------|:---------|:---------|
| 🟢 温和 | 10题 | 1层追问 | 无 |
| 🟡 标准 | 20题 | 2层追问 | 偶尔质疑 |
| 🔴 高压 | 30题 | 3层追问 | 持续施压 |

**核心价值**：提前模拟拷问 → 暴露盲区 → 强化应答
