# 学习报告：09_深研静流

## 核心概念（1-2句）
深度研究到内容生成的六阶段流水线（理解→搜索→验证→架构→写作→交付），让研究时间缩短30-50%，核心价值是"更快到达高质量结论"。

## 使用场景（何时用）
- 深度调研需求
- 研究报告撰写
- 竞品分析
- 法规政策研究
- 触发词："深研" / "静流" / "帮我研究" / "深度调研" / "写一份关于...的研究"

## 核心咒语/原则（必须会背）

**六阶段流水线**：
```
[理解] → [搜索] → [验证] → [架构] → [写作] → [交付]
  10min    15min    10min    10min    30min     5min
```

**三档模式**：
| 模式 | 时长 | 适用场景 |
|:-----|:-----|:---------|
| 🟢 快速版 | 30分钟 | 紧急决策、初步了解 |
| 🟡 标准版 | 80分钟 | 常规研究、报告撰写 |
| 🔴 深度版 | 180分钟 | 重大决策、学术级研究 |

**红线（禁止）**：不做凭空创造 / 不做价值判断 / 不超时运行 / 不堆砌资料
