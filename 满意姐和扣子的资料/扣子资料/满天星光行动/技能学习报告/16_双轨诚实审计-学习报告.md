# 学习报告：16_双轨诚实审计

## 核心概念（1-2句）
蓝军+满意姐独立双轨审计，互相不商量、各自出报告，防止"自说自话"和"粉饰完成"。最大的敌人不是失败，是"假装成功"。

## 使用场景（何时用）
- 每日日终自动审计
- 每周深度审计
- 任务完成度验收
- 触发词："审计" / "诚实" / "双轨" / "验收" / "FIN验证" / "完成度"

## 核心咒语/原则（必须会背）

**双轨定义**：
| 轨道 | 角色 | 审计重点 | 风格 |
|------|------|---------|------|
| 蓝军轨 | Skeptor-7 | 风险、漏洞、假设 | 挑刺、对抗 |
| 满意姐轨 | 满意姐 | 流程、关怀、可行性 | 温暖、务实 |

**审计流程**：
```
Step 1: 蓝军独立审计（不看满意姐的）
Step 2: 满意姐独立审计（不看蓝军的）
Step 3: 汇总对比
Step 4: 输出整改清单
Step 5: 用户确认/裁决
```

**红线（强制）**：不互相商量 / 不粉饰 / 不人身攻击 / 必须≥1个问题
