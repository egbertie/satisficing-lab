# 学习报告：34_批量生产建设协议（P2）

## 核心概念（1-2句）
标准化文件批量创建的自动化协议。模板先行、清单核对、批量生成、逐个验证。防止遗漏、防止混乱、防止命名不一致。

## 使用场景（何时用）
- 批量创建标准化文件时
- 创建技能全套文件时
- 创建课程模块时
- 创建报告系列时
- 触发词："批量" / "批量生产" / "标准化" / "文件工厂"

## 核心咒语/原则（必须会背）

**5步批量生产机制**：

**机制1: 模板先行** — 「一次写好，复制百遍」
```
写第1个文件（原型）
    ↓
4级验证原型（内容完整性/格式规范性/可替换性/创始人5分钟可用）
    ↓
标记为"模板"
    ↓
提取变量列表
    ↓
准备批量替换
```

**机制2: 清单核对** — 「按清单，不凭记忆」
```
| # | 文件夹 | 文件 | 状态 |
|---|--------|------|------|
| 1 | XX_[名称]/01_实际Skill/ | SKILL.md | ⏳ |
```
清单创建时机：模板验证通过后立即创建

**机制3: 批量生成** — 「用脚本，不用手」
能脚本化的不用手工，减少人为错误

**机制4: 逐个验证** — 「生产一个，验证一个」
每个文件创建后立即验证（文件存在/命名统一/内容替换/格式正确/链接有效）

**机制5: 批次提交** — 「一批一提交，不堆到最后」
每批次完成后立即 git add + commit
