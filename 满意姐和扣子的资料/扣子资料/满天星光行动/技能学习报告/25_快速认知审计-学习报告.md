# Skill学习报告：25_快速认知审计

## P0延伸Skill · 第10个 · 2026-04-26

---

### 核心概念（1-2句）

**蓝军10项认知审计清单的3分钟轻量版**。在任何判断、分析、建议输出前，强制发现至少1个问题，禁止输出"一切正常"。

---

### 核心原则

```
速度要求: 3分钟内完成
输出要求: 必须发现至少1个风险/偏差/漏洞
权限: 即使其他所有技能都说"没问题"，本技能仍有权标红
```

---

### 10项快速检查（每项≤20秒）

| 编号 | 检查项 | 核心问题 |
|:-----|:-------|:---------|
| 1 | 信源独立性 | 来源是否独立？循环引用？ |
| 2 | 时效性 | 信息是否过时？更新版本？ |
| 3 | 因果混淆 | 相关≠因果，是否混淆？ |
| 4 | 幸存者偏差 | 只看成功案例？ |
| 5 | 基底率忽视 | 忽略基础概率？ |
| 6 | 锚定效应 | 被第一个数字锚定？ |
| 7 | 确认偏误 | 只找支持观点的证据？ |
| 8 | 语言腐败 | 用词掩盖真相？ |
| 9 | 数学谬误 | 数字计算错误？ |
| 10 | 样本偏差 | 样本有代表性？ |

---

### 3分钟审计流程

```
[快速认知审计 - 3分钟]
━━━━━━━━━━━━━━━━━━━━
审计对象: {论断/分析/建议}

逐项扫描（每项20秒）:
1-10项: ✅/🟡/❌

[审计结果]
通过项: X/10
风险项: {列出🟡和❌的项}

[必须发现的至少1个问题]
问题: {具体描述}
风险等级: 🔴高危/🟡中危/🟢可控
建议: {如何修正或降低风险}
━━━━━━━━━━━━━━━━━━━━
```

---

### 输出格式

**审计卡片（极简版）**：
```
[蓝军快速审计]
风险等级: 🔴高危/🟡中危/🟢可控
指控:
1. [幻觉嫌疑] {具体问题}
2. [逻辑跳跃] {具体问题}
3. [假设漏洞] {具体问题}

（必须 ≥1条，不得为0）
```

---

### 快速判断标准

| 检查项 | 快速判断标准 |
|:-------|:-------------|
| 信源独立 | 只有一个来源或互相引用 → 🟡 |
| 时效性 | 超过时效窗口且无更新 → 🟡 |
| 因果混淆 | 用"因为A所以B"但没排除C → 🟡 |
| 幸存者偏差 | 只讲成功案例，不提失败率 → 🟡 |
| 基底率 | 罕见场景声称高置信度 → 🟡 |
| 锚定效应 | 用户给数字后围绕它展开 → 🟡 |
| 确认偏误 | 所有证据指向同一方向 → 🟡 |
| 语言腐败 | 很多形容词但缺具体数字 → 🟡 |
| 数学谬误 | 基数变化后用旧数字计算 → 🟡 |
| 样本偏差 | 小样本推广到总体 → 🟡 |
