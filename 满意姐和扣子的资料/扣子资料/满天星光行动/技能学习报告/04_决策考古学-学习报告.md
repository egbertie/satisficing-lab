# 学习报告：04_决策考古学

## 核心概念（1-2句）
系统性"挖掘"契晋纪历史决策，从散落对话中提取决策点，形成可复用的决策模式库，包含情境、约束、判断逻辑、结果反馈。

## 使用场景（何时用）
- "我们以前有类似情况吗？"
- "这个决策是谁做的？为什么这样决定？"
- "我们最常见的决策类型是什么？最容易犯什么错误？"
- 触发词："决策考古" / "历史决策分析" / "复盘这个选择"

## 核心咒语/原则（必须会背）

**决策卡片结构（必须能默写）**：
```markdown
## 决策卡片 #[编号]
**时间**: YYYY-MM-DD
**情境**: [当时面对什么问题]
**约束**: [有哪些限制条件]
**选项**: [考虑过哪些选择]
**决策**: [最终选择了什么]
**依据**: [关键判断依据]
**结果**: [实际结果如何]
**复盘**: [如果重来会怎么做]
**可迁移度**: [高/中/低]
```

**五大核心能力**：决策提取 / 模式识别 / 因果重构 / 效果评估 / 模式迁移
