# Skill学习报告：02_知识海啸处理器

## 核心Skill · 第2个 · 2026-04-26

---

### 核心概念（1-2句）

**海量散乱信息的智能导入、分类、萃取、质量转化一体化系统**。将10,000个杂乱文件、100GB数据在7天内转化为可直接传承的标准传承包。

---

### 使用场景（何时用）

| 场景 | 触发 |
|:-----|:-----|
| 收到U盘/网盘的大量历史文件 | "海啸导入"、"批量处理" |
| 资深专家70年积累需要整理 | "核心萃取"、"知识资产转化" |
| 大量文件需要结构化分类 | "智能分类"、"P0/P1/P2标记" |
| 生成标准传承包 | "输出打包"、"质量转化" |

---

### 五步处理流程（核心咒语）

```
Step 1: 海啸导入 → 生成初始索引
        命令: tsunami-ingest.py
        输出: 01_初始索引.json + 02_文件元数据.csv

Step 2: 智能分类 → P0/P1/P2标记
        命令: smart-triage.py
        输出: 03_分类索引.md + 04_P0-P1-P2标记.json

Step 3: 核心萃取 → 提取核心知识
        命令: core-extractor.py
        输出: 05_核心知识清单.md + 06_隐性知识候选.md

Step 4: 质量转化 → 五维映射+双视角
        命令: quality-transform.py
        输出: 07_质量转化包/

Step 5: 输出打包 → 标准传承包
        命令: package-builder.py
        输出: 08_标准传承包/
```

---

### 人机协同边界

| 机器做 | 人做 |
|:-------|:-----|
| 批量扫描分类 | 确认P0/P1/P2 |
| 统计排序 | 表达隐性知识 |
| 格式转换重组 | 验证质量 |
| 生成模板 | 最终决策 |

**质量公式**：机器处理上限80% + 人工确认7小时 = 95%质量

---

### 输出结构

```
08_标准传承包/
├── 00_开篇语.md
├── 00_导览总纲/（人类视角+AI视角+五维映射）
├── 01_P0核心层/（必须读，无它系统崩溃）
├── 02_P1支撑层/（应该读，无它效率降低）
├── 03_P2背景层/（可以读，有了更好）
├── 04_隐性知识/（最难传，对账时传）
├── 05_原始文件索引/
├── 06_检验清单/
└── 07_附录/
```

---

### 核心原则

```
【渐进式处理】
第1轮：只处理P0（核心层）
第2轮：处理P1（支撑层）
第3轮：处理P2（背景层）
第4轮：处理隐性知识

【不要一次性处理】
- 人一次只能确认20-30个文件
- 核心层确认后，承者可以开始读
```
