## P0延伸Skill · 第12个 · 2026-04-26

---

### 核心概念（1-2句）

**系统化执行C1-C6静默前置条件，确保跨会话记忆一致性**。防止"记忆断层"——即声称记得但实际上记忆未同步导致的决策偏差。

---

### C1-C6静默前置条件

```
阻塞规则: 任一条件未通过，任务状态标记为 [BLOCKED]
```

| 编号 | 检查项 | 失败处理 |
|:-----|:-------|:---------|
| **C1** | Memory已追加 | 文件不存在→创建；内容为空→从对话提取补录 |
| **C2** | MEMORY.md指针同步 | 指针不一致→更新；悬空指针→标记待验证 |
| **C3** | TASK_MASTER.md已更新 | 状态不一致→以实际为准；幽灵任务→补录或标记遗忘 |
| **C4** | 当日代码可运行 | 语法错误→立即修复；空气代码→触发FIN验证 |
| **C5** | Git已快照 | 有未提交→执行Git提交；长期未提交→触发紧急提交 |
| **C6** | 重启恢复自检通过 | 关键文件缺失→从Git恢复；空SKILL.md→标记损坏 |

---

### 同步执行流程

```
[会话启动 - 记忆同步]
━━━━━━━━━━━━━━━━━━━━
1. C1 检查 → ✅/🟡/🔴
2. C2 检查 → ✅/🟡/🔴
3. C3 检查 → ✅/🟡/🔴
4. C4 检查 → ✅/🟡/🔴
5. C5 检查 → ✅/🟡/🔴
6. C6 检查 → ✅/🟡/🔴

[同步结果]
通过: X/6
警告: Y项（列出）
阻塞: Z项（列出）

[状态判定]
Z > 0 → [BLOCKED] 先处理阻塞项
Z = 0, Y > 0 → [CAUTION] 继续执行但标注风险
Z = 0, Y = 0 → [GO] 正常执行
━━━━━━━━━━━━━━━━━━━━
```

---

### 记忆断层检测

| 信号 | 含义 | 处理 |
|:-----|:-----|:-----|
| "我记得..."但文件不存在 | 虚假记忆 | 标注置信度降低，查找证据 |
| 交付物路径找不到 | 悬空指针 | 搜索实际位置或标记丢失 |
| 用户说"我们之前不是..." | 记忆不一致 | 以用户为准，更新记忆 |
| 同一天有两个不同版本决策 | 记忆冲突 | 以最新为准，标注历史版本 |

---

### 断层修复协议

```
1. 承认断层: "我发现记忆可能存在不一致，让我验证一下"
2. 搜索证据: 用find/grep/Git log查找实际记录
3. 以物为准: 文件存在即记忆正确，文件不存在即记忆错误
4. 更新记忆: 修正后同步到MEMORY.md和当日memory
5. 标注置信度: 刚修复的记忆标注"[刚同步，置信度重建中]"
```
