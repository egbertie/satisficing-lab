# Skill学习报告：15_晨报日报生成器

## P0延伸Skill · 第7个 · 2026-04-26

---

### 核心概念（1-2句）

**自动化生成每日晨报与日报**。整合任务追踪、决策清单、Token监控、系统健康检查，让创始人3分钟看完，聚焦今日。

---

### 晨报内容（07:11生成）

| 模块 | 内容 | 来源 |
|:-----|:-----|:-----|
| **日期标识** | 今日日期+星期 | 系统 |
| **今日重点** | Top 3 必须完成的任务 | TASK_MASTER.md |
| **决策清单** | 待确认/待执行的决策 | 决策索引 |
| **Token状态** | 本周用量+档位 | session_status |
| **系统健康** | 磁盘/内存/Git状态 | 系统检查 |
| **昨日完成** | 关键交付 | 进度追踪 |
| **风险提示** | 最高1个风险项 | 风险评估 |

---

### 日报内容（18:00生成）

| 模块 | 内容 |
|:-----|:-----|
| **今日完成** | 已完成任务清单 |
| **未完成任务** | 及原因 |
| **Token消耗** | 当日+累计 |
| **新决策** | 今日决策 |
| **明日计划** | Top 3 |

---

### 输出格式模板

```markdown
# 晨报 - YYYY-MM-DD 星期X

## 🔥 今日重点
1. {任务A}
2. {任务B}
3. {任务C}

## 📋 决策清单
- [ ] DEC-042: 待确认
- [x] DEC-041: 已执行

## 💰 Token状态
本周: X% | 档位: L1正常

## 🖥️ 系统健康
磁盘: 53% 🟢 | 内存: OK 🟢

## ✅ 昨日完成
- {交付物}

## ⚠️ 风险
{最高风险项}
```

---

### 核心红线

```
❌ 不替代思考 — 晨报是聚焦工具，不是决策工具
❌ 不超过5项 — 重点超过5项=没有重点
❌ 不重复信息 — 只展示"变化"，不变的不展示
❌ 不忽略风险 — 即使有1个风险，也必须展示
```

---

### 与体系衔接

```
[五维决策体系] → 确定今日优先级
     ↓
[晨报日报生成器] → 生成聚焦简报
     ↓
[任务拆解匠] → 将Top 3拆成最小单元
     ↓
[双经济审计] → 每个任务前检查Token/效益
     ↓
[蓝军审计] → 日终验证今日完成度
```
