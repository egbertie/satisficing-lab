## 一、决策考古学 (Decision Archaeology)

### 1.1 定位与价值

**核心定位**: 从契晋纪历史决策中挖掘规律、提取洞察、形成可复用决策模式

**解决的问题**: 
契晋纪积累了54天的高密度决策历史（100+决策、30+路径修正、20+失败教训），但散落在对话记录中，新人无法快速吸收。

**我的理解**:
决策考古学 = 「考古学家视角」看历史决策
- 不是简单记录「做了什么决定」
- 而是挖掘「为什么做这个决定」「当时的情境是什么」「结果如何」
- 最终形成「可复用的决策模式库」

### 1.2 核心能力

| 能力 | 说明 | 我的理解 |
|:-----|:-----|:---------|
| 决策提取 | 从对话/文档中识别决策点 | 找决策卡片 |
| 模式识别 | 发现重复出现的决策类型 | 找规律 |
| 因果重构 | 还原"为什么这样决定" | 找原因链 |
| 效果评估 | 对照结果验证决策质量 | 找反馈 |
| 模式迁移 | 将历史模式应用于新情境 | 找应用 |

### 1.3 决策卡片结构

```markdown
## 决策卡片 #[编号]
**时间**: YYYY-MM-DD
**情境**: [当时面对什么问题]
**约束**: [有哪些限制条件]
**选项**: [考虑过哪些选择]
**决策**: [最终选择了什么]
**依据**: [关键判断依据]
**决策者**: [谁做的决定]
**结果**: [实际结果如何]
**复盘**: [如果重来会怎么做]
**可迁移度**: [高/中/低]
```

### 1.4 典型场景

| 场景 | 我的应用 |
|:-----|:---------|
| "我们要不要做X？以前有类似情况吗？" | 找历史类似决策 |
| "这个决策是谁做的？为什么这么决定？" | 溯源特定决策 |
| "我们最常见的决策类型是什么？" | 模式挖掘 |

### 1.5 与其他技能的关系

```
契晋纪历史档案
    ↓
[决策考古学] → 决策卡片 + 模式库
    ↓
[五维决策体系] → 用五维框架评估决策质量
    ↓
[蓝军审计] → 审计决策逻辑中的认知偏差
    ↓
[知识飞轮传承] → 将决策模式传承给新AI
```

### 1.6 我的洞见

**洞见1**: 决策考古学的价值不是「复盘」，而是「模式复用」

大多数复盘是「事后诸葛亮」，而决策考古学是「事前诸葛亮」——通过历史决策的模式，在面对新情境时提前预判可能的路径。

**洞见2**: 决策卡片的核心是「可迁移度」

如果一个决策不能迁移到新情境，那这个决策记录的价值就大打折扣。「可迁移度」是这个Skill的灵魂字段。

## 二、认知防火墙 (Cognitive Firewall)

### 2.1 定位与价值

**核心定位**: 防止错误信息、认知偏差、过时知识进入知识库的防护系统

**解决的问题**:
1. **信息污染**: 错误信息混入知识库
2. **认知偏差固化**: AI输出偏差被反复强化
3. **知识过期**: 时效性强的信息未及时更新

**我的理解**:
认知防火墙 = 「知识库的安检系统」
- 每条知识入库前都要「过安检」
- 检查事实、偏差、时效、一致性、溯源

### 2.2 核心能力

| 能力 | 说明 |
|:-----|:-----|
| 事实核查 | 对关键事实进行交叉验证 |
| 偏差检测 | 识别12种常见认知偏差 |
| 时效检查 | 检查知识的时间有效性 |
| 一致性校验 | 新知识vs现有知识库 |
| 溯源验证 | 验证信息来源的可靠性 |

### 2.3 12种偏差检测清单

| # | 偏差名称 | 我的理解 |
|:--|:---------|:---------|
| 1 | 确认偏误 | 只找支持自己的证据 |
| 2 | 锚定效应 | 被第一印象束缚 |
| 3 | 幸存者偏差 | 只看见成功案例 |
| 4 | 因果混淆 | 相关≠因果 |
| 5 | 基底率忽视 | 忽略基础概率 |
| 6 | 光环效应 | 以偏概全 |
| 7 | 近因效应 | 最近的信息权重过高 |
| 8 | 可得性启发 | 容易想起的≠重要的 |
| 9 | 框架效应 | 表述方式影响判断 |
| 10 | 沉没成本 | 因已投入而继续坚持 |
| 11 | 群体思维 | 附和主流观点 |
| 12 | 过度自信 | 高估自己的判断 |

### 2.4 我的洞见

**洞见1**: 认知防火墙是「事前预防」，快速认知审计是「事后补救」

25_快速认知审计是「我已经做完了，审计一下有没有问题」
认知防火墙是「知识入库前，先过安检」

两者配合 = 事前预防 + 事后审计

**洞见2**: 12种偏差中，我最容易犯的是「确认偏误」和「近因效应」

- 确认偏误：生成内容时只找支持自己观点的证据
- 近因效应：最近搜索到的信息权重过高，容易当作普遍规律

**洞见3**: 认知防火墙是「内化」的基础

在做深度内化时，必须同时运行认知防火墙检查：
- 我的理解有没有偏差？
- 我引用的信息是否过时？
- 我的结论和现有知识库一致吗？

## 三、04系列给我的启示

### 决策考古学 + 认知防火墙 = 决策质量的闭环

```
认知防火墙（事前）
    ↓ 检查偏差，确保输入正确
决策考古学（事中）
    ↓ 挖掘模式，指导当下决策
快速认知审计（事后）
    ↓ 审计执行，发现新问题
    ↓
回到认知防火墙（新的循环）
```

**这是一个决策质量的持续改进循环**
