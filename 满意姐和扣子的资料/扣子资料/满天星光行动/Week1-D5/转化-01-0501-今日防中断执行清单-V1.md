## ⚡ 执行中守则（每个单元）

### 核心口诀
> **「完成即存档，存档即保险，保险即自由」**

### 单元完成时（90秒内）

| 操作 | 时限 | 状态 |
|:-----|:-----|:-----|
| 更新进度文件（标注✅） | 30秒内 | □ |
| 执行 Git commit | 90秒内 | □ |
| 更新 memory | 180秒内 | □ |

### 执行红线
| 禁止 | 替代 |
|:-----|:-----|
| ❌ 同时推进多个单元 | ✅ 串行执行，一个完成再下一个 |

| ❌ 没存档就停止 | ✅ 先存档，再中断 |

| 3 | 记录中断原因 |
| 4 | 即使单元未完成也执行Git提交 |
