## ⚡ 操作步骤

### 步骤1：停下来，先考古（5分钟）

```
□ 问自己：以前有类似决策吗？结果如何？
□ 问自己：这个决策的决策者是谁？为什么这样决定？
□ 查决策考古档案，找相似模式
□ 评估「可迁移度」：历史模式适用于当前情境吗？
```

### 步骤2：过认知防火墙（5分钟）

```
□ 我的判断有没有事实依据？交叉验证过吗？
□ 我在找支持自己观点的证据吗？（确认偏误）
□ 最近的信息是否权重过高？（近因效应）
□ 我的结论和现有知识库一致吗？
```

### 步骤3：五维自检（3分钟）

| 维度 | 检查问题 | 状态 |
|:-----|:---------|:-----|
| 土（根基） | 价值观层面是否匹配我的长期目标？ | □ |
| 金（标尺） | 这个决策的风险偏好和目标一致吗？ | □ |
| 水（流动） | 执行路径的沟通成本高吗？ | □ |
| 木（生长） | 这个决策有成长空间吗？ | □ |
| 火（洞察） | 直觉告诉我什么？有创新机会吗？ | □ |
