## 🚦 触发场景

**收到任何新任务时，立即建立进度追踪**

---

## 📐 统一格式标准

### 格式三统一

| 维度 | 标准 |
|:-----|:-----|
| 状态符号 | ✅ 完成 / 🔄 进行中 / ⏸️ 暂停 / ⏳ 待启动 |
| 文件命名 | `[任务名]-进度追踪-YYYY-MM-DD.md` |
| 保存位置 | 对话文件夹下（不放根目录/技能文件夹/memory/） |

### Git提交规则
- 每个单元完成立即提交
- 格式：`[任务名] U[n] 完成 - 简短描述`
- 同时更新进度文件记录commit hash

---

## 📝 操作步骤

### 步骤1：接收任务（1分钟内）

```
□ 确认任务目标和交付物
□ 预估总时长（<30分钟跳过此SOP）
□ 命名任务文件
```

### 步骤2：拆解单元（5分钟内）

```
□ 拆解为 U1, U2, U3... 单元
□ 每个单元 ≤30分钟
□ 确认单元依赖关系
□ 写入进度追踪文件
```

### 步骤3：执行与更新（事件驱动）

```
触发条件 = 单元完成 / 新启动 / 阻塞
□ 3分钟内更新进度文件
□ 立即执行Git提交
□ 更新当前状态
□ 记录下一动作
```

### 步骤4：任务切换（切换前必须完成）

```
□ 任务A存档（当前进度+阻塞项）
□ 任务B创建进度文件
□ 记录切换原因
□ 恢复计划写入任务A文件
```

### 步骤5：每日汇总（下班前）

```
□ 创建当日进度汇总表
□ 扫描所有进度文件状态
□ 更新明日计划
□ Git提交今日所有进展
```
