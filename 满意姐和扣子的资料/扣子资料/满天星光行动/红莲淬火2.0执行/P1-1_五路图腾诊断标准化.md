## 三、决策树

### 3.1 图腾诊断决策树

```
决策场景
    │
    ├─ 核心问题类型？
    │   ├─ "我们该怎么做" → 决策问题 → 金
    │   ├─ "我们该相信什么" → 信念问题 → 火
    │   ├─ "我们是谁" → 身份问题 → 木
    │   ├─ "我们能做什么" → 能力问题 → 土
    │   └─ "我们如何相处" → 关系问题 → 水
    │
    ├─ 决策紧迫性？
    │   ├─ 紧急 → 火/土
    │   └─ 不紧急 → 木/金/水
    │
    └─ 利益相关方？
        ├─ 内部为主 → 土/木
        ├─ 外部为主 → 金/水
        └─ 混合 → 水
```

### 3.2 冲突化解决策树

```
冲突发生
    │
    ├─ 价值观冲突？
    │   └─ → 木（建立共同价值观）
    │
    ├─ 利益冲突？
    │   └─ → 金（水月观音→逻辑分配）
    │
    ├─ 风格冲突？
    │   └─ → 水（包容+共识）
    │
    └─ 能力冲突？
        └─ → 土（培训+支持）
```

## 六、使用说明

### 6.1 使用流程

1. **识别场景**: 用决策树判断场景类型
2. **选择图腾**: 用速查卡选择主/辅/第三图腾
3. **按序激活**: 按模板顺序激活图腾
4. **验证效果**: 检查决策质量和接受度

### 6.2 注意事项

- 图腾组合不是固定公式，需根据实际情况调整
- 主图腾决定沟通主基调
- 辅图腾补充主图腾的不足
- 第三图腾收尾确保闭环
