## 四、报告体验操作说明书

### 4.1 PDF生成配置步骤

```
【Step 1】选择PDF生成方案
  - 推荐: HTML模板 + 服务端渲染 + puppeteer导出
  - 或: Coze PDF技能

【Step 2】设计HTML模板
  - 15页结构，对应上述设计
  - CSS: 使用A4尺寸 @page规则
  - 字体: 使用系统默认字体保证兼容性

【Step 3】配置数据注入
  - 接收问卷数据: userData = {answers, type, scores...}
  - 模板变量: {{user.name}}, {{report.type}}, {{report.date}}
```
