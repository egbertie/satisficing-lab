## 二、方案A：扣子Bot菜单入口

### 2.1 设计规格

| 项目 | 内容 |
|-----|------|
| 入口形式 | 扣子Bot底部菜单 |
| 按钮文案 | "合伙人诊断" |
| 入口图标 | 🔍 或 🩺 |
| 点击路径 | Bot菜单 → 合伙人诊断 → SKU-A |

### 2.2 交互流程

```
用户进入满天星光Bot
        ↓
    底部菜单
        ↓
    [合伙人诊断]
        ↓
    Bot欢迎语
        ↓
    [快速诊断] ← 用户点击
        ↓
    进入SKU-A问诊流程
```

### 2.3 配置操作步骤

```
【Step 1】进入扣子后台
  - 打开 https://coze.cn
  - 登录满天星光账户
  - 进入Bot编辑界面

【Step 2】配置Bot菜单
  - 进入"快捷入口"设置
  - 添加菜单项:
    名称: 合伙人诊断
    图标: 🔍
    关键词: ["合伙人诊断", "开始诊断", "1"]

【Step 3】配置欢迎话术
  - 标题: 合伙人诊断
  - 欢迎语: 欢迎使用满天星光合伙人诊断服务，
    我们将通过3道题快速了解您的现状
  - CTA按钮: [立即开始诊断]

【Step 4】保存并发布
  - 保存配置
  - 点击「发布」
  - 等待审核通过（通常10分钟内）
```

### 2.4 验证检查清单

```
□ Bot菜单"合伙人诊断"按钮已配置
□ Bot欢迎语显示正常
□ "立即开始诊断"按钮可点击
□ 点击后进入快速问卷流程
□ 全流程测试通过（3次）
```

## 四、方案C：分享链接入口

### 4.1 设计规格

| 项目 | 内容 |
|-----|------|
| 入口形式 | 分享链接/二维码 |
| 适用场景 | 公众号/社群/邮件/私信 |

### 4.2 分享文案模板

```
┌─────────────────────────────────────┐
│ 🔍 合伙人诊断邀请                    │
│                                     │
│ [用户昵称] 邀请您一起做合伙人诊断    │
│                                     │
│ "我刚做了满天星光的诊断，发现了一些 │
│ 很有意思的洞察，你也来试试~"         │
│                                     │
│ [点击参与诊断]                       │
│ https://xxx.coze.cn/p/sku-a        │
│ ?from=invite&inviter=[用户ID]      │
└─────────────────────────────────────┘
```

### 4.3 配置操作步骤

```
【Step 1】生成专属链接
  - 在扣子后台 → Bot设置 → 分享
  - 生成带有追踪参数的链接
  - 格式: [基础URL]?source=share&user_id=[用户ID]&from=[来源]

【Step 2】生成二维码
  - 使用草料二维码/联图等工具
  - 生成带Logo的二维码
  - 尺寸: 300px × 300px

【Step 3】制作分享素材
  - 准备朋友圈/社群分享海报
  - 准备私信话术模板
  - 准备公众号推文嵌入

【Step 4】配置追踪
  - 设置分享数据统计
  - 记录各渠道分享效果
```

## 五、入口追踪矩阵

| 入口类型 | 标识参数 | 追踪指标 |
|---------|---------|---------|
| Bot菜单 | `entry=menu` | 点击量、转化率 |
| 落地页 | `entry=landing` | UV、停留时长、转化率 |
| 分享链接 | `entry=share` | 分享数、受邀转化率 |
| 二维码 | `entry=qr` | 扫码量、来源分布 |
