## 二、快速问卷（3题）

### 2.1 设计概述

快速问卷用于首次接触用户，3题控制在30秒内，快速定位用户类型和核心需求。

### 2.2 Q1: 创业阶段

```
┌─────────────────────────────────────────────────────┐
│  🔍 快速合伙人诊断                                  │

│                                                     │
│  Q1. 您的创业目前处于什么阶段？                     │
│                                                     │
│  ○ A. 初创期（0-1年，团队刚组建）                  │
│  ○ B. 成长期（1-3年，业务逐步成型）                 │
│  ○ C. 成熟期（3年以上，规模化发展）                │
│                                                     │
│  【Type映射】                                       │
│  A → Type05（探索型）                              │

## 三、深度问卷（20题，4模块×5题）

### 3.1 模块结构

```
深度问卷总时长: 约10-15分钟
题目数量: 20题
模块分布:
├── 模块1: 基本信息（Q1-Q5）
├── 模块2: 问题诊断（Q6-Q10）
├── 模块3: 决策风格（Q11-Q15）
└── 模块4: 期望目标（Q16-Q20）
```

### 3.2 模块1：基本信息（Q1-Q5）

```
【模块引导语】
📋 让我们先了解一下您的基本情况

Q1. 您目前创业多久了？
○ A. 不到6个月
○ B. 6个月-1年
○ C. 1-3年
○ D. 3-5年
○ E. 5年以上

Q2. 您目前团队规模？
○ A. 2-3人
○ B. 4-10人
○ C. 11-50人
○ D. 50人以上

Q3. 您在团队中的角色？
○ A. 创始人/CEO
○ B. 联合创始人
○ C. 核心合伙人
○ D. 早期成员

Q4. 您与其他合伙人的合作方式？
○ A. 全职共同创业
○ B. 兼职+投资
○ C. 纯投资关系
○ D. 资源合作

Q5. 您们是否签署了正式协议？
○ A. 已签署完整协议（股权/分工/退出）
○ B. 部分协议（仅股权）

## 五、问诊体验操作说明书（面向Egbertie）

### 5.1 快速问卷体验流程

```
【Step 1】进入问卷
  - 从Bot菜单点击"合伙人诊断"
  - 或发送"开始诊断"

【Step 2】回答Q1
  - 选择当前创业阶段
  - 点击"下一题"

【Step 3】回答Q2
  - 选择最困扰的合伙人问题
  - 点击"下一题"

【Step 4】回答Q3
  - 选择期望获得的帮助
  - Q3选B时: 点击"提交并开始深度问卷"
  - Q3选A时: 推送卡牌咨询入口
  - Q3选C时: 推送SKU-B服务入口

【Step 5】查看快速结果
  - Bot展示Type类型
  - Bot展示核心发现摘要
  - 引导完成深度问卷或购买完整报告
```

### 5.2 深度问卷体验流程

```
【Step 1】开始深度问卷
  - 收到模块引导语
  - 点击"开始"进入Q1

【Step 2】完成各模块
  - 模块1: 基本信息（Q1-Q5）
  - 模块2: 问题诊断（Q6-Q10）
  - 模块3: 决策风格（Q11-Q15）
  - 模块4: 期望目标（Q16-Q20）

【Step 3】提交问卷
  - 确认所有题目已作答
  - 点击"提交问卷"

【Step 4】等待报告生成
  - 显示: "感谢您的耐心回答，正在生成专属报告..."
  - 预计30秒生成时间
  - 收到报告下载链接或PDF
```

### 5.3 验证检查清单

```
□ 快速问卷3题可正常答题
□ Type映射逻辑正确
□ SKU分流规则生效
□ 深度问卷20题可正常答题
□ 模块引导语清晰
□ 问卷进度可视化
□ 提交后可正常生成报告
□ 报告内容与问卷回答一致
```
