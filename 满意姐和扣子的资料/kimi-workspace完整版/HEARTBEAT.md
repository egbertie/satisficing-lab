## 四、响应规则

### 4.1 HEARTBEAT_OK 回复条件

**必须同时满足以下条件方可回复 HEARTBEAT_OK：**

| 条件编号 | 检查项 | 判定标准 |
|----------|--------|----------|
| C1 | ~~紧急邮件~~ | ~~无2小时内需回复的邮件~~ **【暂停】** |
| C2 | 即将发生日程 | 无2小时内开始的日程 |
| C3 | 未处理提及 | 无未读的重要提及通知 |
| C4 | 被遗忘任务 | 未发现超期被遗忘任务 |
| C5 | 系统异常 | 无API错误或系统告警 |
| C6 | 上次检查 | 距离上次报告>30分钟 |

**回复格式**：`HEARTBEAT_OK [L0]` / `HEARTBEAT_OK [L1]` / `HEARTBEAT_OK [L2]` / `HEARTBEAT_OK [L3]` / `HEARTBEAT_OK [L4]`

**档位定义**：
- **L0**: 绝对静默模式（Mode A）。用户主动选择。心跳≤12小时/次，仅P0紧急响应，其余全部暂停。由用户指令"绝对静默"触发。
- **L1**: Token 30-100%，正常频率（基于用户校准值）
- **L2**: Token 20-30%，降频33%
- **L3**: Token 10-20%，降频50%
- **L4**: Token < 10%，降频75%，仅P0

**Token校准协议**：
1. 用户发送"token消耗校准：X%"时立即记录
2. 更新`memory/token-weekly-monitor.json`校准历史
3. 调整HEARTBEAT.md档位状态
4. 用于训练预测模型准确性

**附加静默规则（满足任一即可静默）：**
- 深夜时段 (00:00-08:00)，除非 P1 紧急
- 上次检查后 30 分钟内无状态变化
- 用户明确忙碌中（连续消息>5条/5分钟）
- 已进入勿扰模式

### 4.2 主动报告条件

**【必须立即报告】P1 级事件：**

| 场景 | 报告内容 | 响应要求 |
|------|----------|----------|
| 紧急邮件到达 | 发件人 + 主题 + 截止时间 | 立即文字摘要 |
| 日程事件 < 2小时 | 事件名称 + 时间 + 准备事项 | 立即提醒 |

| 外部服务告警 | 服务名 + 错误码 + 备选方案 | 立即报告 |

**【可以选择报告】P2 级事件：**

| 场景 | 报告内容 | 判断标准 |
|------|----------|----------|

## 五、特殊场景处理

### 5.1 首次启动（无历史状态）

**处理流程：**
1. 创建 `memory/heartbeat-state.json` 初始化文件
2. 执行完整检查清单（必检+轮检）
3. 报告检查结果和当前状态摘要
4. 创建当日日志文件
5. 标记首次启动完成

### 5.2 长时间中断（> 8小时）

**处理流程：**
1. 检查所有必检项目
2. 扫描中断期间的所有消息
3. 检查被遗忘任务
4. 报告关键发现和待处理事项
5. 更新状态追踪文件

### 5.3 用户明确忙碌

**处理规则：**
- 仅检查 P1 紧急事项
- 其他项目延后至下次心跳
- 记录待检查清单
- 用户空闲时批量报告

### 5.4 系统重启/恢复

**处理流程：**
1. 读取重启前状态保存文件
2. 检查关键文件完整性
3. 恢复待办事项状态
4. 报告恢复完成

### 5.5 节假日/特殊日期

**处理规则：**
- 检查当日特殊日程（生日/纪念日等）
- 调整检查频率（可延长间隔）
- 减少非必要报告

### 5.6 多平台消息聚合

**处理规则：**
- 聚合所有平台通知
- 按优先级排序
- 去重处理
- 统一报告格式

## 附录：快速参考

### A. 优先级定义
- **P1**: 紧急，需立即处理
- **P2**: 重要，需当日处理
- **P3**: 一般，可延后处理

### B. 检查频率代码
- **always**: 每次心跳必检
- **daily**: 每日1次
- **Xdays**: 每X天1次
- **scheduled**: 按计划时间

### C. 响应时间要求
- **立即**: < 1分钟
- **快速**: < 5分钟
- **当日**: 24小时内

### D. 绝对静默模式（L0）快速参考
- **触发**: 用户指令"绝对静默"
- **心跳**: ≤12小时/次
- **保留检查**: Token熔断监控（24h）、P0紧急日程（12h）
- **暂停检查**: 晨间/黄昏图腾、资产激活、信息防火墙、知识OS、天气、邮件等全部
- **回复**: 无异常时不回复（NO_REPLY）
- **HEARTBEAT标签**: `HEARTBEAT_OK [L0]`（仅在系统要求回传时使用）
- **唤醒**: 用户发送任意消息，即时唤醒
