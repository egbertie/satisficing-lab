## 三、普通版（¥199）产品设计

### 3.1 题目清单（共15题，每题5个选项）

**计分规则**：每题1-5分，1=完全不符合，5=完全符合

#### 【刘禹锡·土】价值观契合度（3题）

**关于钱和理想**：如果项目赚到第一桶金，我们最想做的第一件事是？
1. 分钱，各回各家（1分）
2. 扩大团队，招更多人（2分）
3. 投入研发，做更好的产品（3分）
4. 回报当初支持我们的人（4分）
5. 先留足公司发展基金，再考虑个人（5分）

**关于失败**：如果项目遇到重大挫折，我们最先想到的是？
1. 怪对方没做好（1分）
2. 后悔当初不该干（2分）
3. 赶紧找下一个机会（3分）
4. 复盘原因，商量怎么调整（4分）
5. 互相打气，一起扛过去（5分）

**关于成功**：如果项目成了，我们最看重的是？
1. 身价翻了多少倍（1分）
2. 行业里有了名气（2分）
3. 证明了自己的技术/能力（3分）
4. 帮助了很多客户/用户（4分）
5. 我们一起做成了一件难事（5分）

#### 【司马贺·金】决策风格匹配度（3题）

**关于信息**：做一个重要决定前，我们通常？
1. 等所有信息都齐了再说（1分）
2. 一边做一边看，错了就改（2分）
3. 先做个最小版本试试水（3分）
4. 听专家的，专家说行就行（4分）
5. 相信自己的判断，先干再说（5分）

**关于分歧**：我们意见不合时，通常？
1. 谁职位高听谁的（1分）
2. 谁也不让，僵着（2分）
3. 互相妥协，取中间值（3分）
4. 找个第三方来评理（4分）
5. 列出利弊，用数据说话（5分）

**关于风险**：面对不确定的机会，我们？
1. 坚决不碰，保住现有（1分）
2. 算清楚概率再决定（2分）
3. 小范围试，亏得起就干（3分）
4. 看别人做成了再跟进（4分）
5. 有60%把握就敢冲（5分）

#### 【观自在·水】压力应对模式（3题）

**关于加班**：连续加班一个月，我们会？
1. 抱怨公司、抱怨对方（1分）
2. 自己硬扛，但不高兴（2分）
3. 找个机会放松一下（3分）
4. 商量调整分工，互相替班（4分）
5. 互相打气，一起熬过去（5分）

**关于冲突**：我们吵架时，最常出现的情况是？
1. 互相指责，翻旧账（1分）
2. 冷战，几天不说话（2分）
3. 一方服软，息事宁人（3分）
4. 冷静下来再聊（4分）
5. 吵完很快和好，不记仇（5分）

**关于突发**：遇到突发危机（比如客户跑单），我们会？
1. 互相推卸责任（1分）
2. 慌张，不知道怎么办（2分）
3. 各自想办法，不沟通（3分）
4. 先稳住局面，再复盘（4分）
5. 一起商量，快速分工（5分）

#### 【孔子·木】伦理风险信号（3题）

**关于灰色地带**：为了拿下订单，客户暗示可以"操作"，我们会？
1. 觉得正常，按客户意思办（1分）
2. 心里不舒服，但还是做了（2分）
3. 假装听不懂，看对方反应（3分）
4. 直接拒绝，坚持原则（4分）
5. 换一种合规的方式满足需求（5分）

**关于利益分配**：如果股权分配方案出来后，发现有一方贡献更大，我们会？
1. 按协议来，谁也别改（1分）
2. 心里不平衡，但不说（2分）
3. 私下商量，重新调整（3分）
4. 公开讨论，重新分配（4分）
5. 主动提出给对方更多（5分）

**关于承诺**：答应客户的事情，我们通常？
1. 看情况，做不到就算了（1分）
2. 尽量做，但不会死磕（2分）
3. 想办法做到，但会抱怨（3分）
4. 全力以赴，说到做到（4分）
5. 宁可自己吃亏也要兑现（5分）

#### 【慧能·火】直觉警报指数（3题）

**关于第一印象**：第一次见面，你对他/她的感觉是？
1. 很不舒服，说不清为什么（1分）
2. 一般，没特别感觉（2分）
3. 还行，可以聊聊（3分）
4. 挺投缘，想多接触（4分）
5. 就是他了，感觉对了（5分）

**关于隐藏信号**：最近有没有某个瞬间，让你心里"咯噔"一下？
1. 经常有，而且不舒服（1分）
2. 有过一两次，但没在意（2分）
3. 好像有，但想不起来了（3分）
4. 偶尔有，但对方解释了（4分）
5. 从来没有，很踏实（5分）

**关于信任**：如果对方有一个重大决定没告诉你，你会？
1. 觉得被背叛，无法信任（1分）
2. 很生气，要问清楚（2分）
3. 理解可能有苦衷，但难受（3分）
4. 相信他/她有自己的理由（4分）
5. 主动去问，但不会怀疑（5分）
