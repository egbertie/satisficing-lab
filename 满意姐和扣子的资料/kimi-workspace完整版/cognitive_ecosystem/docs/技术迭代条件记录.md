## 三、技术债务清单

### 高优先级
1. **API 401 问题排查**
   - 根因: `GITHUB_TOKEN` 对 Azure inference endpoint 失效
   - 方案: 验证 token 权限，或迁移到 Kimi/OpenAI 直连
   - 验收: `python3 -c openai.client.chat.completions.create(...)` 成功

### 中优先级
2. **批量旧文档处理**
   - 根因: 目前只处理了 1 个测试文档
   - 方案: 编写 `batch_runner.py`，遍历 archive 目录
   - 验收: 一次性处理 >20 个文档无报错

3. **压缩比计算失真**
   - 根因: 短文本 JSON overhead 导致 ratio > 1.0
   - 方案: 用纯文本摘要长度而非 JSON 长度计算
   - 验收: 任意长度文档 ratio ∈ [0, 1]

### 低优先级
4. **Kuzu 并发锁管理**
   - 根因: 进程异常退出时锁残留
   - 方案: 封装 `with KuzuLock():` 上下文管理器
   - 验收: 强制 kill 后 5 秒内可重新打开 DB

5. **Chroma 模型预下载脚本**
   - 根因: 首次运行时动态下载不可控
   - 方案: `scripts/download_embed_model.py`
   - 验收: 离线环境下无需外网即可初始化 Chroma
