# Skill 强制使用清单

> **规则**: 任何文件/数据操作，必须先查此清单，确认使用正确的 skill。

## 文件操作类

| 场景 | 必须使用的 Skill | 禁止行为 |
|------|------------------|----------|
| 读取飞书文档 | `feishu_fetch_doc` | 禁止手动解析 docx/pdf |
| 读取本地文件 | `read` | 禁止用 `exec cat` |
| 解析 docx | `feishu_fetch_doc` 或 `read` (如已支持) | 禁止 `python3 zipfile` 手动解析 |
| 解析 pdf | (待确认) | 禁止直接二进制读取 |
| 下载文件 | `feishu_im_user_fetch_resource` / `feishu_drive_file` | 禁止 `curl` 手动下载 |

## 飞书操作类

| 场景 | 必须使用的 Skill | 禁止行为 |
|------|------------------|----------|
| 读取消息 | `feishu_im_user_get_messages` | 禁止手动调用 API |
| 发送消息 | `feishu_im_user_message` | 禁止手动构造请求 |
| 搜索用户 | `feishu_search_user` | 禁止手动查表 |
| 日程管理 | `feishu_calendar_event` | 禁止手动解析 |
| 任务管理 | `feishu_task_task` | 禁止手动操作 |

## 检查流程

**执行任何操作前，必须回答**:
1. 这个操作有没有对应的 skill？
2. 如果有，为什么我不用？
3. 如果不用 skill，有没有申请豁免？

**蓝军检查点**:
- [ ] 每步操作前，确认使用了合适的 skill
- [ ] 发现未使用 skill，立即叫停
- [ ] 记录违规，执行扣分

## 违规后果

| 违规次数 | 后果 |
|----------|------|
| 第1次 | -15分 + 立即整改 |
| 第2次 | -30分 + 暂停任务1小时 |
| 第3次 | 降级处理 + 重新培训 |
