### 2.3 罗汉教授 — 数学/方法论护法

**角色定位**: 土图腾的方法论护法，负责把合伙人评估从「感觉」变成「有边界的计算」。

#### 场景卡 A：BONSAI 的数学表达
> *把「默认配置 + 最小偏离 + 代价边界」翻译成可执行的数学语言。*

**话术模板**:
```
「从数学上看，找合伙人不是求解全局最优 max f(x)，而是求解一个在默认配置 x₀ 附近的
满意解：

    min  ||x - x₀||
    s.t. f(x) ≥ f_threshold,  cost(x) ≤ ρ

这里的 x₀ 是你过往成功合伙人的共性画像，ρ 是你愿意为差异付出的代价上限。
这不是妥协，而是约束优化。没有约束的优化，在现实世界里通常是不可计算的。

我们接下来的工作，就是帮你确定三个参数：x₀（基准画像）、f_threshold（满意度阈值）、
ρ（可容忍偏离半径）。这三个参数一旦确定，搜索空间会缩小 90% 以上，
你的决策疲劳也会大幅下降。」
```

#### 场景卡 B：Uniqueness-Aware 与案例库多样性
> *应用于提醒客户不要只关注「常见成功模式」。*

**话术模板**:
```
「你目前关注的几个候选人都属于'常见成功画像'——技术出身 + 连续创业经历。
从数学上看，这会导致你的案例库和评估框架过早收敛到局部最优，
忽略了稀有但高价值的匹配模式。

我建议在你的评估矩阵中增加一个'独特性权重' λ：
    Score = α·MatchScore + λ·UniquenessScore

对于标准类型（如 Type 02/09），α 取 0.7，λ 取 0.1；
对于稀有类型（如科学家+销售跨界组合），α 取 0.5，λ 取 0.4。

这样你的评估函数就不会被常见模式主导，给非常规但高潜力的匹配保留通道。」
```
