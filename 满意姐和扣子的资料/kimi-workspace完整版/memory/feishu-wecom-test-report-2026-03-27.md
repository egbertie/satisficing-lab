## 四、最终使用方案

### 双通道分工矩阵

| 场景 | 飞书 | 企微 | Token策略 |
|------|------|------|-----------|
| **日程/日历** | ✅ 主控 | ❌ 不重复 | 飞书查日程，结果存文件 |
| **文档协作** | ⏸️ 待授权 | ✅ 主控 | 企微文档全功能可用 |
| **知识库存档** | ⏸️ 待授权 | ✅ 主控 | 企微智能表格存储 |
| **即时消息** | ❌ 静默 | ✅ 主控 | 企微接收指令 |
| **晨报/晚报** | ⏸️ 待授权 | ✅ 推送 | 先通过企微推送 |
| **紧急通知** | ⏸️ 备用 | ✅ 主控 | 企微优先 |
| **文件备份** | ⏸️ 待授权 | ✅ 主控 | 企微文档+文件传输助手 |

### 信息流转规则（零Token浪费）

```
用户（任意渠道）
    ↓
[文件操作] → 更新工作文件 → 零Token ✅
    ↓
[需要AI处理] → 仅当前渠道响应 → 节省Token ✅
    ↓
[跨渠道同步] → 仅文件同步，不重复发送 → 零Token ✅
```

### 双外备份机制

| 数据类型 | 主存储 | 备份1 | 备份2 | Token成本 |
|----------|--------|-------|-------|-----------|
| 核心记忆 | `MEMORY.md` | 企微文档 | GitHub私有仓 | 0 |
| 每日日志 | `memory/` | 企微文件传输助手 | 本地压缩 | 0 |
| 知识库 | `knowledge/` | 企微智能表格 | 本地备份 | 0 |
| Skill文件 | `skills/` | GitHub | 企微文档 | 0 |
| 任务追踪 | `docs/TASK_MASTER.md` | 企微智能表格 | - | 0 |
