# 决策/确认任务清单 ✅ 建议选项规范 V1.0

> 生效日期: 2026-04-12
> 来源: Egbertie 直接指令 + AGENTS.md 编号决策响应协议 V1.1

## 规则

每次向 Egbertie 提交需他决策或确认的任务清单时，**必须**为每个决策点提供 2 个及以上的编号选项，并附带决策块代码格式。

## 输出格式模板

```
[A] ① 选项A — [一句话说明]
[A] ② 选项B — [一句话说明]
[B] ① 选项X — [一句话说明]
[B] ② 选项Y — [一句话说明]
```

## 用户最小响应格式

`A-② + [反馈]`

## 示例

**决策 A: 下一步执行顺序**
[A] ① 先完成 Gateway 根治，再处理 Skill 清理 — 风险低、顺序清晰
[A] ② 两者并行推进 — 节省时间但 Token 消耗更高

**决策 B: 报告粒度**
[B] ① 合并为 1 份简报 — 省 Token，适合今日收尾
[B] ② 拆为 3 份完整报告 — 信息完整，但消耗大

## 执行检查项

- [ ] 清单中出现 "需要你决策/确认/选择" 字样时，触发本规范
- [ ] 每个决策点 ≥2 个编号选项
- [ ] 带决策块代码前缀 [A], [B], [C]...
- [ ] 选项后紧跟一句话说明（帮助 5 秒内理解）

---
*此规范为硬性约束， omission 视为执行缺陷。*
