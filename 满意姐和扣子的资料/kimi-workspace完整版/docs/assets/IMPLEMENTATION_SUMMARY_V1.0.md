## 三、三批实施计划

### 第一批（Week 1-4）：知识内化系统（P0）
**目标**: 解决"知识入库断层"问题

| 周 | 任务 | 交付物 |
|----|------|--------|
| 1-2 | 基础设施 | PostgreSQL + MinIO + 备份 |
| 3-4 | **五重门内化** | 工作流+飞书集成+10个文档入库 |

**五重门流程**:
1. **登记门**（3分钟）: 文件指纹+五图腾分类+3-2-1备份
2. **通读门**（Pass 1）: 理解核心，AI生成结构大纲
3. **笔记门**（Pass 2）: 深度消化，五图腾模板引导
4. **总结门**（Pass 3）: 内化输出，形成可复用资产
5. **验证门**（5题抽查）: AI自评+蓝军审计，80分通过

### 第二批（Week 5-8）：Workflow + Memory（P0-P1）
**目标**: 补齐Workflow缺口，结构化Memory

| 周 | 任务 | 交付物 |
|----|------|--------|
| 5-6 | **Workflow引擎** | YAML DSL + 五图腾检查点 + 并行执行 |
| 7-8 | **知识图谱** | 实体抽取 + 五维语义 + RAG检索 |

**Workflow特色**: 每个关键决策点自动触发五图腾检查

## 四、Token优化专项（关键！）

### 问题
单次知识入库 **2500-4500T** → 成本过高

### 解决方案（节省80%）

| 策略 | 实现 | 节省 |
|------|------|------|
| **边缘预处理** | 本地Qwen-7B模型 | 60% |
| **分级处理** | 轻量(<150T)/标准(<300T)/深度(<800T) | 15% |
| **三级缓存** | L1内存+L2Redis+L3语义 | 5% |

### 效果
- **优化后**: 单次入库 **430-950T**
- **月度成本**: ¥5250 → ¥1050（节省¥4200）
- **本地模型成本**: ¥2000/月
- **净节省**: ¥2200/月

### 立即部署清单
```bash
# 1. 本地LLM服务
docker run -d --gpus all \
  -p 8000:8000 \
  -v /models:/models \
  registry.cn-hangzhou.aliyuncs.com/qwen/qwen2.5:7b-instruct \
  --model /models/Qwen2.5-7B-Instruct

# 2. 分级处理Pipeline
python3 -m sri_agent_os.token_optimizer.tiered_processor

# 3. 缓存服务
docker run -d -p 6379:6379 redis:7-alpine
```
