## 一、Token节省策略

### 1.1 禁止行为（浪费Token）
| 行为 | 浪费原因 | 替代方案 |
|------|---------|----------|
| ❌ 全文复述 | 重复已知内容 | ✅ 只输出洞察和资产 |
| ❌ 逐字摘要 | 无价值信息 | ✅ 结构化提取 |
| ❌ 多轮试探 | 无效对话 | ✅ 一次性精准提问 |
| ❌ 过度解释 | 冗余说明 | ✅ 结果导向输出 |

### 1.2 强制输出格式（固定模板）

## 二、过程到位策略

### 2.1 强制阅读流程（每文件必须执行）
```
第1遍（5分钟）: 速读框架
  - 输出: 3句话概括全文
  - 不深入细节

第2遍（15分钟）: 精读提取
  - 逐段阅读
  - 标记可执行内容
  - 记录疑问点

第3遍（10分钟）: 结构化整理
  - 按模板输出
  - 验证完整性
  - 自测3个问题
```

### 2.2 最小有效输出标准
不满足以下条件，视为**未完成**：
- [ ] 核心洞察 ≥3条（一句话/条）
- [ ] 可执行资产 ≥3个（可复制/执行）
- [ ] 实施步骤 ≥3步（可勾选）
- [ ] 能回答蓝军3个抽查问题

## 三、结果清晰策略

### 3.1 蓝军抽查机制（随机）
每个文件完成后，蓝军随机抽取1-2个问题：

| 问题类型 | 示例 | 合格标准 |
|---------|------|----------|
| 存在性 | 这份文件在哪里？ | 5秒内说出路径 |
| 理解性 | 核心目标是什么？ | 一句话说清 |
| 结构性 | 有几个解决方案？ | 数字准确 |
| 应用性 | 能立即执行什么？ | 具体可执行 |
| 整合性 | 如何与XX结合？ | 有明确方案 |

**不合格 = 返工 + 记录**
