# 项目情报采集系统 - 详细需求文档

> 需求版本: v1.0  
> 提出方: 满意解研究所 / Egbertie  
> 期望交付: 可部署运行的采集脚本 + 摘要生成模块 + 推送配置  

---

## 一、背景与目标

### 1.1 背景
满意解研究所专注于**硬科技初创企业的合伙人匹配决策教练**服务。需要持续追踪：
- 硬科技领域投融资动态
- 相关政策变化
- 行业趋势与热点

为合伙人匹配提供情报支持，也为案例库积累素材。

### 1.2 目标
构建自动化情报采集系统，实现：
1. **多源采集**: 覆盖IT桔子、36氪、动脉网等硬科技信息源
2. **智能筛选**: 自动识别AI芯片、生物医药、新能源等关注领域
3. **AI摘要**: 提取关键信息，生成影响评估
4. **定时推送**: 日报/周报推送到飞书/邮件

## 三、数据源详细规格

### 3.1 IT桔子 (itjuzi.com)

**采集内容**: 投融资事件
**频率**: 每日1次
**URL**: https://www.itjuzi.com/investevents

**采集字段**:
```json
{
  "company_name": "公司名称",
  "industry": "所属行业",
  "sub_industry": "细分行业",
  "funding_round": "融资轮次",
  "funding_amount": "融资金额",
  "funding_date": "融资日期",
  "investors": ["投资方1", "投资方2"],
  "company_location": "公司所在城市",
  "company_desc": "公司简介",
  "source_url": "原始链接"
}
```

**筛选规则**:
- 行业包含：人工智能、芯片、生物医药、新能源、新材料、机器人、航空航天
- 轮次包含：天使轮、Pre-A轮、A轮
- 时间范围：最近7天内

### 3.2 36氪 (36kr.com)

**采集内容**: 硬科技赛道文章
**频率**: 每日2次（上午10点、下午4点）
**URL**: 
- https://36kr.com/information/technology （科技）
- https://36kr.com/information/healthcare （医疗）

**采集字段**:
```json
{
  "title": "文章标题",
  "summary": "文章摘要",
  "content_text": "正文内容（前2000字）",
  "publish_time": "发布时间",
  "author": "作者",
  "keywords": ["关键词1", "关键词2"],
  "source_url": "原始链接",
  "read_count": "阅读数"
}
```

**筛选规则**:
- 标题/摘要包含硬科技关键词
- 排除：广告、活动推广、招聘信息
- 优先级：阅读量>5000的文章

### 3.3 动脉网 (vbdata.cn)

**采集内容**: 医疗科技动态
**频率**: 每日1次
**URL**: https://www.vbdata.cn/

**采集字段**: 同36氪

**筛选规则**:
- 仅限生物医药、医疗器械、数字医疗
- 融资新闻优先

### 3.4 政府政策

**采集内容**: 科创政策、人才政策、补贴政策
**频率**: 每周1次（周一上午）
**来源**:
- 深圳科创委官网
- 上海市科委
- 北京市科委
- 各高新区官网

**采集字段**:
```json
{
  "policy_title": "政策名称",
  "issuing_body": "发布机构",
  "publish_date": "发布日期",
  "effective_date": "生效日期",
  "policy_type": "政策类型",
  "beneficiary": "受益对象",
  "key_content": "核心内容摘要",
  "funding_scale": "资金规模（如有）",
  "application_deadline": "申报截止日期",
  "source_url": "原始链接"
}
```

**筛选规则**:
- 政策类型：创业扶持、人才补贴、研发补贴
- 受益对象：初创企业、高层次人才

## 四、AI摘要生成需求

### 4.1 摘要类型

| 类型 | 触发条件 | 输出格式 |
|------|----------|----------|
| 融资快讯 | IT桔子新融资事件 | 3句话快讯 |
| 深度分析 | 36氪/动脉网长文 | 要点+影响评估 |
| 政策解读 | 政府新政策 | 核心条款+适用性评估 |


### 4.4 摘要质量要求

- **准确性**: 事实错误率 < 1%
- **相关性**: 仅保留硬科技相关内容
- **时效性**: 融资新闻24小时内摘要
- **洞察性**: 不仅转述，要提供"合伙人匹配视角"的分析

### 6.2 数据表结构

```sql
-- 采集源表
CREATE TABLE sources (
    id INTEGER PRIMARY KEY,
    name VARCHAR(50),           -- IT桔子/36氪/动脉网
    type VARCHAR(20),           -- funding/news/policy
    url VARCHAR(500),
    last_crawl_time TIMESTAMP
);

-- 原始数据表
CREATE TABLE raw_data (
    id INTEGER PRIMARY KEY,
    source_id INTEGER,
    external_id VARCHAR(100),   -- 源站ID
    title VARCHAR(500),
    content TEXT,
    url VARCHAR(500),
    publish_time TIMESTAMP,
    crawl_time TIMESTAMP,
    raw_html TEXT,
    status VARCHAR(20)          -- new/processed/filtered
);

-- 处理后情报表
CREATE TABLE intelligence (
    id INTEGER PRIMARY KEY,
    raw_id INTEGER,
    type VARCHAR(20),           -- funding/article/policy
    company_name VARCHAR(100),
    industry VARCHAR(50),
    funding_round VARCHAR(20),
    funding_amount VARCHAR(50),
    investors TEXT,             -- JSON数组
    summary TEXT,               -- AI摘要
    tags TEXT,                  -- JSON数组
    importance_score INTEGER,   -- 1-10
    created_at TIMESTAMP,
    pushed BOOLEAN DEFAULT FALSE
);

-- 推送记录表
CREATE TABLE push_logs (
    id INTEGER PRIMARY KEY,
    intel_id INTEGER,
    channel VARCHAR(20),        -- feishu/email
    push_time TIMESTAMP,
    status VARCHAR(20)          -- success/failed
);
```

### 6.3 去重策略

- URL去重：同一链接不重复采集
- 内容去重：标题相似度>85%视为重复
- 公司+轮次去重：同一公司同轮次仅保留一条

### 6.4 反爬策略

- 请求间隔：5-10秒随机延迟
- User-Agent轮换
- 失败重试：指数退避（1s, 2s, 4s, 8s）
- Cookie管理（如需登录）

## 八、验收标准

1. **采集成功率**: 各站点>95%
