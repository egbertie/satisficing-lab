## 核心原则

### 原则1: 零遗漏入库
- 所有有价值的外部文件必须登记入库
- 不入库 = 不存在
- 入库后100%可检索

### 原则2: 3-2-1备份
- 3份副本: 本地工作区 + 飞书文档 + GitHub
- 2种介质: 磁盘 + 云存储
- 1份离线: GitHub即离线备份
- 0错误容忍: 哈希校验

### 原则3: 先入库再内化
- KIP负责"物理入库"
- PMP/WEP负责"深度处理"
- 不跳步、不混步

## Step 1: 文件接收与登记 (5分钟)

**目标**: 建立文件身份档案

**检查清单**:
- [ ] 接收文件
- [ ] 提取元数据（文件名/大小/格式/来源）
- [ ] 初步分类（P0/P1/P2）
- [ ] 登记入库

**输出模板**:
```markdown
## 文件入库记录
- 文件名: [原名]
- 文件路径: [绝对路径]
- 文件大小: [X KB]
- 来源: [上传者/顾问/会议/网络]
- 接收时间: [YYYY-MM-DD HH:MM]
- 优先级: [P0/P1/P2]
- 预计处理时间: [X分钟]
- 分配流程: [PMP/WEP/KIP]
- 蓝军监督: [Skeptor-7]
```

**GDN检查点**:
- 元数据是否完整
- 文件是否可正常打开
- 优先级判定是否合理

## Step 2: 物理入库与备份 (10分钟)

**目标**: 文件可持久化访问

**检查清单**:
- [ ] 内容完整提取（文本/图片/表格）
- [ ] 格式标准化（保留原始+生成.md副本）
- [ ] 执行3-2-1备份
- [ ] 建立知识索引

**GDN检查点**:
- 备份完整性抽查
- 索引可检索性验证

---

## Step 3: 深度消化与结构化 (15-30分钟)

**目标**: 将原始文件转化为结构化认知

### 3.1 三遍阅读法

| 遍数 | 时间 | 目标 | 输出 |
|------|------|------|------|
| 第一遍 | 5分钟 | 速读框架 | 3句话概括 |
| 第二遍 | 15分钟 | 精读提取 | 标记重点段落 |
| 第三遍 | 10分钟 | 结构化 | 按模板整理 |

### 3.2 强制输出模板

```markdown
# [文件名] 内化报告

## 元信息
- 消化时间: [YYYY-MM-DD HH:MM]
- 实际耗时: [X分钟]
- 执行者: [满意姐]
- 蓝军验收: [通过/返工]

## 核心洞察（3-5条，必须）
1. [一句话洞察]
2. [一句话洞察]
3. [一句话洞察]

## 可执行资产（≥3个，如适用）
### 资产1: [类型-名称]
- 内容:
- 用途:
- 位置:

## 实施检查清单
- [ ] [步骤1]
- [ ] [步骤2]
- [ ] [步骤3]

## 与现有系统的关联
- 依赖: [需要哪些已有技能/资产]
- 冲突: [是否有冲突内容]
- 整合建议: [如何与现有系统融合]

## 知识图谱标签
- 领域: [硬科技/管理/方法论]
- 类型: [技术方案/案例/理论]
- 关联文件: [相关文件ID]
- 应用场景: [合伙人匹配/情报采集/决策支持]
```

### 3.3 类型判定（KIP核心决策）

**判定后分流**:
- [ ] **程序类** → 后续由PMP处理
  - 特征: 代码/架构/组件/系统
- [ ] **知识类** → 后续由WEP处理
  - 特征: 方法论/经验/案例/培训
- [ ] **混合类** → 拆分处理
  - 技术部分走PMP，知识部分走WEP

**GDN检查点**:
- 三遍阅读是否执行
- 输出模板是否完整
- 类型判定是否准确

---

## Step 4: 内化验证与审计 (15分钟)

**目标**: 验证消化的真实性和质量

### 4.1 蓝军5题抽查

| 题型 | 问题示例 | 合格标准 |
|------|---------|----------|
| 存在性 | 这份文件在哪里？ | 5秒内说出完整路径 |
| 理解性 | 核心目标是什么？ | 一句话，50字内说清 |
| 结构性 | 提供了几个方案？ | 数字准确，不模糊 |
| 应用性 | 哪个能立即执行？ | 具体，不抽象 |
| 整合性 | 如何与XX系统结合？ | 有明确方案 |

**评分**:
- 5题全对: ✅ 内化完成
- 3-4题对: ⚠️ 部分内化，需补充
- <3题对: ❌ 未内化，返工Step 3

### 4.2 可执行资产验证

蓝军随机抽取1个资产验证:
- [ ] 可直接复制吗？
- [ ] 复制后能运行/使用吗？
- [ ] 用途描述准确吗？

**任一未通过 = 返工**

---

## Step 5: 归档与索引更新 (5分钟)

**目标**: 知识正式进入可用资产池

**检查清单**:
- [ ] 内化报告归档（存入知识库/方法论层）
- [ ] 更新MEMORY.md索引
- [ ] 标记文件状态为"已内化/待处理"
- [ ] 同步进度看板

**最终状态标记**:
```
[文件名] 状态: ✅ 已入库 / 待PMP / 待WEP
```

## 验收标准

### 单文件验收标准

| 维度 | 标准 | 权重 |
|------|------|------|
| 元数据完整 | 6项必填齐全 | 10% |
| 备份完成 | 3-2-1法则执行 | 15% |
| 核心洞察 | ≥3条，一句话/条 | 20% |
| 可执行资产 | ≥3个（如适用） | 15% |
| 抽查测试 | 5题答对≥4题 | 25% |
| 资产验证 | 随机抽1个可用 | 10% |
| 归档索引 | 已更新MEMORY | 5% |
| **总分** | **≥80分 = 通过** | **100%** |

### 批量验收标准（周度）

| 指标 | 目标 | 监控频率 |
|------|------|----------|
| 入库完成率 | 100% | 每日 |
| 内化通过率 | ≥90% | 每周 |
| 平均耗时/文件 | ≤35分钟 | 每周 |
| 返工率 | ≤10% | 每周 |
