## 快速选择指南

### 第一步: 判定文件性质

| 判定维度 | PMP (精密制造) | WEP (智慧萃取) | KIP (知识摄入) |
|----------|----------------|----------------|----------------|
| **文件来源** | 技术方案、架构设计 | 培训内容、直播转录 | 外部新知识源 |
| **内容形态** | 结构化架构、代码 | 线性叙述、案例 | 原始未处理内容 |
| **关键词特征** | System、架构、组件 | 方法论、经验、观点 | 新领域、新来源 |
| **处理阶段** | 深度制造 | 深度萃取 | 初步摄入 |
| **直接产出** | 可执行代码 | 方法论文档 | 结构化入库 |

### 第二步: 选择处理流程

```
收到新知识源
    ↓
[KIP执行] ← 采集/清洗/入库/初评
    ↓
类型判定
    ├── 程序类文件 ──→ [PMP执行]
    └── 知识类文件 ──→ [WEP执行]
                ↓
          [GDN守护] ← 全过程质量监督
                ↓
          归档闭环
```

### 第三步: 执行对应流程

| 步骤 | PMP | WEP | KIP | GDN |
|------|-----|-----|-----|-----|
| 1 | 前置确认 | 前置确认 | 接收登记 | 前置检查 |
| 2 | 质量门控 | 自动提取 | 物理备份 | 过程监督 |
| 3 | 深度洞察 | 质量分级 | 深度消化 | 后置审计 |
| 4 | 实施设计 | 保护蒸馏 | 内化验证 | 定期检查 |
| 5 | 分层实施 | 情境适配 | 归档索引 | - |
| 6 | 验证闭环 | 索引固化 | - | - |
| 7 | 归档固化 | 追踪评估 | - | - |

## 流程详细说明

### PMP-V1.0: 精密制造流程

```yaml
全称: 精密制造流程
英文: Precision Manufacturing Process
代号: PMP
版本: V1.0
类型: Type-A (制造类)
适用: 程序类/技术类文件
时间: 90-150分钟（动态）
质量: 🟢高置信（可直接执行）
```

**核心特点**:
- 质量门控前置（阶段1）

## 协同规则

### 规则1: KIP为入口
所有外部知识源必须先经过KIP，判定类型后再进入PMP或WEP。

### 规则2: GDN贯穿全程
GDN在KIP/PMP/WEP的前置、过程、后置三个阶段均可介入监督。

### 规则3: 命名规范统一
所有流程必须遵循:
- 3字母大写代号（如PMP, WEP, KIP, GDN）
- 4字中文全称（如精密制造, 智慧萃取）
- 3单词英文全称
- V主.次版本号

### 规则4: 检查清单配套
每个流程必须有对应的CKL检查清单（Checklist的缩写）。
