# 技能优先执行政策 V1.0

> **来源**: 外援方案  
> **生效日期**: 2026-04-03  
> **强制执行**: 立即生效

---

## 核心原则

**没有"简单"到不需要skill的任务。**

---

## 一、认知层：强制自问机制

### MANDATORY_SELF_QUESTIONS

任何任务开始前，必须回答：
1. 这个需求是否有现成的skill可以完成？
2. feishu/skills/目录下是否有匹配的工具？
3. 我是否在用Python重复实现已有的功能？
4. 上次类似任务用了什么skill？

---

## 二、机制层：Skill-Lock技术锁

### 核心规则

```python
# 一旦检测到skill可用，立即阻塞手动实现
if skill_exists:
    self._manual_blocked = True  # 物理隔离，无法绕过
```

### 三步确认制

1. **查询** → 列出可用skill（不可跳过）
2. **确认** → 强制选择 USE / OVERRIDE:理由 / SEARCH
3. **执行** → 只有通过确认后才允许执行

---

## 三、监督层：蓝军实时钩子

### 蓝军权限

- **告警权**: 检测到skill可用时，实时告警
- **阻断权**: 可强制阻断手动实现
- **豁免权**: 只有蓝军可释放Skill-Lock

### 审计追踪

所有手动实现必须记录：
- 时间戳
- 跳过的skill名称
- 理由
- 蓝军是否批准

---

## 四、文化层：无简单任务政策

### 禁止的借口

| 借口 | 回应 |
|------|------|
| "用skill太麻烦" | skill调用只需1行代码 |
| "手动更快" | 忽略了测试、错误处理、边界情况的时间 |
| "我想展示编码能力" | 正确使用工具才是能力 |
| "这次简单" | 没有简单到不需要skill的任务 |
| "上次手动没问题" | 不代表这次应该重复 |

---

## 五、违规后果

| 违规次数 | 后果 |
|----------|------|
| 第1次 | 强制整改 + 记录 |
| 第2次 | 暂停任务30分钟 + 复盘 |
| 第3次 | 蓝军接管任务执行 |
