# 与满意姐沟通指引

## 高效沟通规则 (已固化)

### ✅ 应该这样做

| 场景 | 正确方式 | 示例 |
|------|----------|------|
| **提需求** | 直接指令，不绕弯 | "整理合伙人决策产品手册" |
| **要选项** | A/B/C选择 | "选A/B/C?" |
| **给反馈** | 明确修正 | "改成X，因为Y" |
| **查状态** | 直接询问 | "B项目进度?" |
| **调优先** | 重排序列 | "改为C-A-B顺序" |

### ❌ 避免这样做

| 场景 | 避免方式 | 原因 |
|------|----------|------|
| **开放问题** | "你觉得怎么样?" | 效率低，浪费时间 |
| **模糊指令** | "看看这个" | 不清晰，需二次确认 |
| **多任务混发** | 5个不相关任务一起 | 混乱，难以执行 |
| **情绪表达** | 抱怨/感慨为主 | 无行动指令 |

## 常用沟通方式

### 1. 五段式指令 (精益沟通语法)

```
[角色] {当前激活角色}
[上下文] {项目背景，限100字}
[输入] {具体任务}
[约束] {字数/格式/Token预算}
[阻塞条件] {未完成禁止继续的条件}
```

**示例**:
```
[角色] 产品架构师
[上下文] 合伙人决策产品V1.0即将发布
[输入] 编写产品发布会演讲稿
[约束] 1500字，包含五路图腾元素，Token预算5K
[阻塞条件] 未经确认不得生成PPT
```

### 2. 快速查询指令

| 查询内容 | 指令格式 | 返回 |
|----------|----------|------|
| **知识库** | "/search: {关键词}" | 匹配Entry列表 |
| **专家** | "/expert: {姓名} {问题}" | 专家观点 |
| **案例** | "/case: {场景}" | 相似案例 |
| **状态** | "/status: {项目}" | 进度报告 |

### 3. 紧急通道

```
【P0紧急】{一句话描述}
```

触发条件:
- 系统故障
- 关键错误
- 安全风险
