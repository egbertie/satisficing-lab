## 第一部分：经验挖掘 vs 资产飞轮（本质区分）

### 1.1 两者的本质差异

| 维度 | 经验挖掘 (Experience Mining) | 资产飞轮 (Asset Flywheel) |
|------|------------------------------|---------------------------|
| **核心功能** | 从经历中提取经验教训 | 将经验转化为可复用资产 |
| **处理阶段** | **输入端处理**（发生后） | **输出端循环**（转化后） |
| **关注点** | Why/How/What went wrong | How to reuse/scale |
| **时间导向** | 过去→现在（反思） | 现在→未来（增值） |
| **产出形态** | 洞察、教训、改进方案 | 工具、模板、Skill、数据 |
| **执行频率** | **每日一次**（固定节奏） | **持续运转**（每次产出后） |
| **责任人** | 满意姐主导，蓝军审计 | 系统自动+人工确认 |

### 1.2 两者的协同关系

```
         ↓
   可复用资产
         ↓
   驱动下一轮更好的经历
```

## 第二部分：经验挖掘的方法论指导

### 2.1 五维方法论框架

经验挖掘不是简单的"写日记"，而是在**五个方法论维度**指导下进行系统性反思：

#### 维度一：双脑决策理论（左脑+右脑）

**左脑负责**：
- **结构化分析**: 将经历拆解为情境-行动-结果的因果链
- **数据化提取**: 量化时间消耗、Token消耗、产出效率
- **模式识别**: 发现重复出现的问题类型
- **逻辑验证**: 检验因果关系的合理性

**右脑负责**：
- **直觉感知**: 捕捉当时的心理状态、情绪波动
- **隐喻洞察**: 用比喻/故事理解复杂情境
- **整体感知**: 不拆分，感受整体的"氛围"
- **创造性联想**: 将不相关经历连接产生新洞察

**左右脑协作方式**：
```
右脑先感知 → 左脑后分析 → 双脑验证 → 洞察生成
     ↑                                      ↓
     └────────── 循环迭代 ←───────────────┘
```

#### 维度二：五路图腾校准

| 图腾 | 挖掘维度 | 校准问题 |
|------|---------|---------|
| **刘禹锡(土)** | 价值根基 | 这次经历中，我最在乎的东西是什么？还在吗？ |
| **司马贺(金)** | 理性决策 | 当时的决策是基于信息还是情绪？满意解找到了吗？ |
| **观自在(水)** | 洞察应变 | 当时有没有注意到但被忽略的信号？ |
| **孔子(木)** | 伦理治理 | 这次经历中，我的行为是否符合儒商伦理？ |
| **慧能(火)** | 顿悟突破 | 这次经历让我突然明白了什么？ |

#### 维度三：五级执行验证复盘

对每一次任务执行进行五级复盘：

| 层级 | 复盘问题 | 失败信号 |
|------|---------|---------|
| **L1动作** | 我实际做了什么？vs 计划做什么？ | 虚假忙碌（做了很多但无成果） |
| **L2检查** | 我检查了哪些关键点？ | 走马观花（检查不深入） |
| **L3验证** | 我的结论有哪些证据支撑？ | 幻觉（无证据的断言） |
| **L4固化** | 我如何将经验转化为资产？ | 文档坟墓（写了但不用） |
| **L5自动化** | 哪些可以自动化？ | 人肉重复（每次都要手动做） |

#### 维度四：ECBM认知偏见扫描

检查经历中可能存在的认知偏见：

| 偏见类型 | 检查问题 | 经验挖掘中的应用 |
|---------|---------|-----------------|
| **事后诸葛亮** | "我当时就知道会这样"是真的吗？ | 区分真实预判vs事后美化 |
| **幸存者偏差** | 我是否只记住了成功的经历？ | 主动挖掘失败经历 |
| **确认偏误** | 我是否只寻找支持我观点的证据？ | 强制寻找反面证据 |
| **基本归因错误** | 我把结果归因于人还是情境？ | 区分可控vs不可控因素 |
| **沉没成本谬误** | 我是否因为投入太多而不愿放弃？ | 识别止损时机 |

#### 维度五：PDCA+ODCA双循环

**PDCA循环**（正向优化）：
- Plan: 计划时想怎么做
- Do: 实际怎么做的
- Check: 结果如何
- Act: 如何改进

**ODCA循环**（逆向发现，经验挖掘特有）：
- Observe: 观察到什么现象
- Discover: 发现了什么意外/异常
- Conclude: 得出什么结论
- Act: 如何应用

**双循环关系**：
```
        ┌─────────────┐
        │   O观察     │
        │  (右脑感知) │
        └──────┬──────┘
               ↓
        ┌─────────────┐     ┌─────────────┐
        │   D发现     │────→│   P计划     │
        │ (异常识别)  │     │ (左脑分析)  │
        └──────┬──────┘     └──────┬──────┘
               ↓                   ↓
        ┌─────────────┐     ┌─────────────┐
        │   C结论     │     │   D执行     │
        │ (洞察生成)  │     │ (行动实施)  │
        └──────┬──────┘     └──────┬──────┘
               ↓                   ↓
               └─────────┬─────────┘
                         ↓
                   ┌─────────────┐
                   │   A行动     │
                   │  (改进应用) │
                   └─────────────┘
```

## 第三部分：经验挖掘工作流程（7步闭环）

### Step 0: 触发条件（每日09:43）

**触发方式**:
- 固定时间触发: 每日09:43（象征意义：昨天结束，今天开始）
- 事件触发: 完成重要任务后立即执行
- 异常触发: 遇到重大失败/意外成功时立即执行

**前置准备**:
```bash

read /root/.openclaw/workspace/A-manyige/对话/📅-按日期/2026-04-02/

cat logs/skill-usage-2026-04-02.json
```

每个案例交付时，必须包含以下**理论运用复盘**章节：

```markdown
## 理论运用复盘

### 1. 双脑决策复盘

**左脑应用**:
- 案例分析中使用了哪些结构化工具？（PFI评分卡、ECBM识别、五路图腾校准）
- 数据是如何被收集和验证的？
- 因果关系是如何被梳理的？

**右脑应用**:
- 案例中有哪些情绪信号被捕捉到？
- 创始人的直觉/预感在决策中起了什么作用？
- 如何用隐喻理解这个案例？

**双脑协作评估**:
- 案例中的决策是偏理性还是偏直觉？
- 左脑和右脑是否产生了冲突？如何调和？

### 2. 五路图腾应用复盘

| 图腾 | 案例体现 | 如何发挥作用 |
|------|---------|-------------|
| **刘禹锡(土)** | [案例中价值观冲突的描述] | [如何通过价值对齐解决问题] |
| **司马贺(金)** | [案例中决策风格的描述] | [如何通过满意解决策框架优化] |
| **观自在(水)** | [案例中压力应对的描述] | [如何通过STOP技术调节] |
| **孔子(木)** | [案例中伦理困境的描述] | [如何通过REPA伦理框架处理] |
| **慧能(火)** | [案例中顿悟时刻的描述] | [如何通过72小时压力测试实现] |

### 3. 方法论验证复盘

- 本案例验证了哪些理论假设？
- 哪些理论在本案例中失效？为什么？
- 本案例对理论体系有什么补充或修正？

### 4. 独特价值声明

- 如果不使用满意解理论，这个案例会怎么分析？

- 这个案例为什么是"我们的"而不是"别人的"？
```

### 4.2 示例：张雪案例的理论复盘（草案）

```markdown
## 理论运用复盘：张雪案例

### 双脑决策复盘

**左脑应用**:
- 使用PFI评分卡分析了张雪与严凯的合伙人匹配度
- 使用ECBM识别了张雪的"禀赋效应"（高估技术价值）
- 使用股权设计工具分析了凯越的股权结构缺陷

**右脑应用**:
- 捕捉到张雪"净身出户"时的情绪状态：不甘但决绝
- 感知到严凯作为资本方的"控制欲"氛围
- 用"技术原教旨主义 vs 商业现实主义"的隐喻理解冲突本质

**双脑协作**:
- 张雪的决策偏右脑直觉（"我觉得能成"）
- 严凯的决策偏左脑分析（财务回报计算）
- 冲突源于左右脑决策风格的根本差异

### 五路图腾应用复盘

| 图腾 | 案例体现 | 发挥作用 |
|------|---------|---------|
| **刘禹锡(土)** | 张雪"惟吾德馨"的价值观 | 坚持技术理想，不屈从资本 |
| **司马贺(金)** | 张雪决策时的信息不足 | 在信息不完全时敢于拍板 |
| **观自在(水)** | 面对合伙人背叛时的冷静 | 使用STOP技术，先观察再回应 |
| **孔子(木)** | 张雪对合伙人的伦理要求 | 仁义礼智信的伦理底线 |
| **慧能(火)** | 净身出户后创立张雪机车 | 顿悟重生，压力中突破 |

### 独特价值声明

**不用满意解理论的分析**:
"张雪案例是一个典型的创始人与投资人冲突，建议创始人注意股权设计"

**使用满意解理论的分析**:
"张雪案例展示了'技术原教旨主义'与'商业现实主义'的结构性冲突，
本质上五路图腾中的'慧能(火)'与'司马贺(金)'的失衡。
```
