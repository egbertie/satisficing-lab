## 要素1: 摘要（Abstract）

**字数**: 200-300字

**结构**:
```
[背景] + [冲突] + [决策] + [结果] + [教学价值]
```

**示例**:
> 某AI芯片公司（2019年成立，创始人技术背景）在B轮融资后，技术合伙人主张继续投入研发高性能芯片，商业合伙人主张转向中低端市场快速变现。双方股权对等（各40%），决策陷入僵局。最终技术合伙人退出，公司转向中低端市场，但错过技术窗口期，3年后被竞争对手超越。本案例展示了Type 3升级期+超维冲突（技术原教旨主义）的典型场景，适用于讨论技术vs商业话语权平衡、股权设计对决策的影响。

## 要素3: 冲突升级（Conflict Escalation）

**按时间线呈现冲突如何逐步升级**，包括：

### 3.1 触发事件（Trigger Event）
- 是什么事件引发了冲突？
- 当时的具体情境

### 3.2 第一次分歧（First Disagreement）
- 双方最初的立场
- 沟通方式
- 情绪状态

### 3.3 冲突升级节点（Escalation Points）
```
节点1: [时间/事件]
├─ 发生了什么
├─ 双方反应
└─ 冲突程度: [1-10评分]

节点2: [时间/事件]
├─ 发生了什么
├─ 双方反应
└─ 冲突程度: [1-10评分]

...
```

### 3.4 冲突现状（Current State）
- 当前冲突的状态
- 已采取的措施
- 未解决的问题

## 要素4: 决策时刻（Decision Point）⭐

**这是HBR案例的核心**，必须呈现：

### 4.1 决策情境
```
┌────────────────────────────────────────┐
│ 决策情境                                │
├────────────────────────────────────────┤
│ 决策时间: [具体时间]                    │
│ 决策地点: [具体地点]                    │
│ 参与方: [参与决策的人]                  │
│ 决策时限: [是否有时间压力]              │
│ 决策信息: [已知信息 + 信息缺口⚠️]        │
└────────────────────────────────────────┘
```

### 4.2 可选方案（Options）
**必须呈现2-3个合理选项，而非唯一正确答案**

```
选项A: [方案描述]
├─ 优势: [优点]
├─ 劣势: [风险]
└─ 支持方: [谁支持这个方案]

选项B: [方案描述]
├─ 优势: [优点]
├─ 劣势: [风险]
└─ 支持方: [谁支持这个方案]

选项C: [方案描述]（可选）
├─ 优势: [优点]
├─ 劣势: [风险]
└─ 支持方: [谁支持这个方案]
```

### 4.3 决策问题（Decision Question）
**向读者/学员提出的问题**:
> "如果你是[角色]，你会选择哪个方案？为什么？"

## 附录：质量检查清单

**撰写完成后检查**:

- [ ] 摘要是否包含背景-冲突-决策-结果？
- [ ] 背景是否足够详细支持分析？
- [ ] 冲突升级是否有明确时间线？
- [ ] 决策时刻是否呈现多个合理选项？
- [ ] 是否保留信息缺口（不完全信息）？
- [ ] 是否呈现多方观点（非单一视角）？
- [ ] 理论框架是否明确链接？
- [ ] 教学笔记是否完整（目标/问题/要点/作业）？
- [ ] 所有敏感信息是否已脱敏？
- [ ] 信源是否已标注？
