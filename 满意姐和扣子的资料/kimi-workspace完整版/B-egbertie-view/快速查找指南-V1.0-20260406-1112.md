## 📊 文件命名规则

### 日期文件
```
2026-MM-DD.md                    # 每日主记录
2026-MM-DD_补充说明.md            # 当日补充
2026-MM-DD-主题关键词.md          # 主题记录
```

### 项目文件
```
{项目名}执行状态.md               # 项目状态
{项目名}-完成报告.md              # 完成报告
WIP-{编号}-{描述}.md              # 工作进行中
```

### 专家文件
```
{姓名}-{领域}-专家档案-v{版本}.md  # 专家档案
{姓名}-待确认.md                  # 待确认信息
```

```
{主题}-{编号}.md                  # 知识库Entry
```
