## 核心功能

### 1. 双引擎搜索架构

```
用户查询 → Tavily（全球搜索） ──┐
                              ├──→ 结果聚合 → 信源分级 → 报告生成
        → 腾讯云（中文优化）──┘
```

**优势：**
- ✅ Tavily：覆盖全球英文资源，学术/技术内容强
- ✅ 腾讯云：覆盖微信生态，中文内容优化
- ✅ 互补优势，提高搜索质量和审核通过率

---

### 2. 四种预设模板

| 模板 | 场景 | 时间范围 | 信源等级 | 输出深度 |
|------|------|---------|---------|---------|
| **academic** | 学术论文、文献综述 | 5 年 | S/A | 深度 |
| **commercial** | 市场分析、竞品研究 | 2 年 | S/A/B | 全面 |
| **quick** | 快速核实、获取概览 | 1 年 | S/A | 简报 |
| **wechat** | 微信公众号、小程序 | 1 年 | S/A/B | 全面 |

---

### 3. 信源分级过滤系统

**S 级（权威信源）**
- 政府 (.gov.cn)、学术 (.edu.cn)、权威媒体
- 策略：✅ 免过滤，直接使用

**A 级（行业权威）**
- 咨询公司 (McKinsey)、研究机构 (Gartner)
- 策略：✅ 轻度过滤，建议保留

**B 级（垂直媒体）**
- 知乎、简书、GitHub、CSDN
- 策略：⚠️  严格过滤，需交叉验证

**C 级（未认证）**
- 个人网站、未知来源
- 策略：❌ 默认排除

---

### 4. 三种输出格式

**简报摘要（默认）**
- 核心发现 Top3
- 关键数据表格
- 信源统计
- 适用：快速汇报、决策参考

**完整报告**
- 详细分析
- 完整引用链接
- 原始数据
- 适用：深度研究、存档备案

**CSV 导出**
- 结构化数据
- Excel 可直接打开
- 适用：二次分析、数据可视化

## 用户配置流程

### Step 1: 获取 API Key

**Tavily（必选）：**
1. 注册 https://app.tavily.com
2. Dashboard → API Keys → Create New Key
3. 复制密钥（`tvly-xxxxxxxx`）
4. 免费额度：1000 次/月

**腾讯云（可选）：**
1. 登录 https://console.cloud.tencent.com
2. 实名认证 → 开通"内容安全"服务
3. 访问管理 → API 密钥管理 → 新建密钥
4. 复制 SecretId 和 SecretKey
5. 免费额度：新用户¥300 代金券

---

### Step 2: 运行配置向导

```bash
python main.py --setup
```

交互式输入 API Key，自动保存到 `~/.researchpro/config.json`

---

### Step 3: 开始调研

```bash
python main.py --query "2026 年 AI 芯片市场趋势" --template commercial
```
