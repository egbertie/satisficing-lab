# API Key 配置完全指南

本文档详细说明如何获取和配置 ResearchPro 所需的 API Key。

---

## 一、Tavily API 配置

### 1.1 注册账号

**访问地址：** https://app.tavily.com

**步骤：**
1. 打开 Tavily 官网
2. 点击 "Sign Up" 或 "Get Started"
3. 使用邮箱注册（推荐 Gmail 或公司邮箱）
4. 验证邮箱（检查垃圾邮件箱）
5. 设置密码完成注册

![注册流程](assets/tavily_signup.png)

---

### 1.2 获取 API Key

**步骤：**
1. 登录 Tavily Dashboard
2. 点击左侧菜单 "API Keys"
3. 点击 "Create New Key" 按钮
4. 输入密钥名称（如：ResearchPro-Main）
5. 点击 "Generate" 生成密钥
6. **立即复制保存**（格式：`tvly-xxxxxxxxxxxxxxxx`）

⚠️ **重要提示：** API Key 仅显示一次，关闭后无法再次查看完整密钥！

![获取 API Key](assets/tavily_api_key.png)

---

### 1.3 查看使用量

- 剩余配额查询
- 调用历史记录

**路径：** Dashboard → Usage → Current Month

### 1.5 故障排查

#### 问题 1: "Invalid API Key"

**原因：**
- API Key 复制不完整
- 包含多余空格
- Key 已失效

**解决：**
```bash
# 重新运行配置向导
python main.py --setup

# 或手动编辑配置文件
~/.researchpro/config.json
```

---

#### 问题 2: "Quota exceeded"

**原因：** 本月免费额度已用完

**解决：**
1. 等待下月 1 号自动重置
2. 升级到付费方案
3. 配置自己的腾讯云 API 作为补充

---

#### 问题 3: "Rate limit reached"

**原因：** 短时间内请求过于频繁

**解决：**
- 降低并发请求数
- 添加请求间隔（建议 1-2 秒）
- 启用缓存避免重复查询

## 二、腾讯云 API 配置

### 2.1 注册账号

**访问地址：** https://console.cloud.tencent.com

**步骤：**
1. 使用微信扫码登录
2. 完成实名认证（个人认证即可）
   - 上传身份证正反面
   - 人脸识别验证
   - 审核时间：通常 5-10 分钟
3. 绑定手机号
4. 设置支付密码（用于后续计费）

![腾讯云注册](assets/tencent_signup.png)

---

### 2.2 开通服务

**方式 A：内容安全 CMS**

1. 登录控制台
2. 搜索 "内容安全" 或 "CMS"
3. 点击进入产品页面
4. 点击 "立即开通"
5. 同意服务协议

**方式 B：搜索引擎 API**

1. 登录控制台
2. 搜索 "搜索引擎"
3. 选择 "智能搜索" 服务
4. 点击 "开通服务"

---

### 2.3 获取密钥对

**步骤：**
1. 进入控制台首页
2. 点击右上角头像 → "访问管理"
3. 左侧菜单选择 "访问密钥" → "API 密钥管理"
4. 点击 "新建密钥" 按钮
5. 确认创建（可能需要短信验证）
6. **立即复制 SecretId 和 SecretKey**

⚠️ **重要提示：** 
- SecretKey 仅显示一次，务必妥善保存
- 建议下载 CSV 备份文件
- 不要将密钥提交到代码仓库

![腾讯云密钥](assets/tencent_secret_key.png)

### 2.4 配置子账号（推荐）

**为什么使用子账号：**
- 权限隔离，主账号更安全
- 可设置独立配额
- 便于团队协作管理

**创建步骤：**
1. 访问管理 → 用户列表 → 新建用户
2. 选择 "编程访问"（非控制台登录）
3. 自定义用户名（如：researchpro-bot）
4. 授予权限：
   - QcloudCMSFullAccess（内容安全完全访问权）
   - 或自定义策略（仅读权限）
5. 创建成功后自动生成密钥对

### 2.6 故障排查

#### 问题 1: "Signature failure"

**原因：** API 签名错误

**解决：**
- 检查 SecretId/SecretKey 是否正确
- 确保签名算法正确（HMAC-SHA256）
- 参考官方文档实现签名逻辑

**签名示例代码：**
```python
import hmac
import hashlib
import base64

def generate_signature(secret_key, message):
    signature = hmac.new(
        secret_key.encode(),
        message.encode(),
        hashlib.sha256
    ).digest()
    return base64.b64encode(signature).decode()
```

---

#### 问题 2: "Insufficient balance"

**原因：** 账户余额不足

**解决：**
1. 费用中心 → 充值管理
2. 选择充值金额（最低¥10）
3. 使用微信支付/支付宝/银行卡
4. 充值后立即生效

---

#### 问题 3: "Service not activated"

**原因：** 未开通对应服务

**解决：**
- 返回 2.2 节，确认已开通服务
- 检查是否开通了正确的地域（Region）
- 部分服务需要单独申请白名单

## 四、最佳实践

### 4.1 密钥安全管理

✅ **应该做的：**
- 使用环境变量存储密钥
- 定期轮换密钥（建议每季度）
- 为不同项目创建独立密钥
- 启用密钥使用监控

❌ **不应该做的：**
- 将密钥硬编码到代码中
- 通过微信/QQ 传输密钥
- 截图分享密钥
- 使用同一密钥多人共享

---

### 4.2 成本优化技巧

**1. 启用缓存**
```json
{
  "preferences": {
    "enable_cache": true,
    "cache_days": 7
  }
}
```
相同查询 7 天内不重复调用

**2. 选择合适的模板**
- 快速验证用 `quick` 模板（调用量少）
- 深度研究用 `commercial` 模板（性价比高）

**3. 批量处理**
- 合并相似查询，减少总调用次数
- 使用分页获取结果，而非多次独立查询

**4. 监控用量**
```bash
# 每日查看用量
python main.py --stats
```

**A:** 
1. **立即删除泄露的密钥**
2. 在控制台禁用该密钥
3. 重新生成新密钥
4. 更新配置文件
