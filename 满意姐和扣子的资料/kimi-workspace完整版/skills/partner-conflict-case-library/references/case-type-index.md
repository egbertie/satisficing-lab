## Type01: 控制权争夺型

**核心特征**: 决策权归属不明，"谁说了算"成为核心矛盾
**危险等级**: 🔴 高危
**常见场景**:
- 股权比例与决策权不匹配（如50:50股权结构）
- CEO/CTO/COO权限边界模糊
- 重大投资决策需要全票通过导致僵局
- 创始人与投资人争夺董事会控制权

**典型案例标签**:
- 50:50股权陷阱
- 双CEO结构崩塌
- 董事会席位战争
- 一票否决权滥用

**五维决策要点**:
- 🟤 土: 控制权争夺往往意味着"同行基础"已动摇
- ⚪ 金: 满意解可能是"一方退出+合理补偿"
- 🔵 水: 冷静评估：争夺控制权的真实动机是什么？
- 🟢 木: 仁义礼智信中，"信"（信任）和"礼"（规则）被严重破坏
- 🔴 火: 直觉往往早已预警，但被理性压制

---

## Type02: 信任破裂型

**核心特征**: 隐瞒、欺骗、背叛导致信任基础崩塌
**危险等级**: 🔴 高危
**常见场景**:
- 财务信息不透明，存在暗箱操作
- 私自在外设立竞争公司
- 关键技术/客户资源被转移
- 隐瞒个人债务或法律风险

**典型案例标签**:
- 关联交易黑洞
- 竞业禁止违约
- 客户资源转移
- 财务造假曝光

**五维决策要点**:
- 🟤 土: 信任是合伙的根基，根基崩塌则"陋室"难存
- ⚪ 金: 修复信任的cost可能高于重建
- 🔵 水: 观自在：能否在内心真正原谅？
- 🟢 木: "信"为五常之本，一次背叛，百次难复
- 🔴 火: 直觉已在第一时间发出警报，是否被忽视？

---

## Type03: 利益分配型

**核心特征**: 股权/分红/资源分配感知不公
**危险等级**: 🟡 中危
**常见场景**:
- 贡献与股权比例不匹配
- 后续融资稀释引发的不满
- 退出时的估值分歧
- 知识产权归属争议

**典型案例标签**:
- 出力多股权少
- 融资稀释冲突
- 退出估值鸿沟
- 知识产权争执

**五维决策要点**:
- 🟤 土: 利益分配是"同行"的试金石
- ⚪ 金: 满意解：双方都能接受的分配方案
- 🔵 水: 公平感比数学公平更重要
- 🟢 木: "义"（正当性）优先于"利"
- 🔴 火: 对金钱的态度反映深层价值观

---

## Type04: 价值观冲突型

**核心特征**: 对公司方向、文化、底线有根本分歧
**危险等级**: 🔴 高危
**常见场景**:
- 短期盈利 vs 长期主义
- 激进扩张 vs 稳健经营
- 产品优先 vs 销售优先
- 合规底线分歧

**典型案例标签**:
- 增长vs利润路线之争
- 合规红线踩踏
- 产品vs销售文化冲突
- 长期主义vs及时行乐

**五维决策要点**:
- 🟤 土: 价值观是"同行"的精神契约
- ⚪ 金: 价值观冲突几乎没有满意解，只能分离
- 🔵 水: 观自在：各自真实的优先级是什么？
- 🟢 木: "仁"（仁心）与"智"（智慧）的边界
- 🔴 火: 这是"原则问题"还是"策略分歧"？

## Type05: 角色模糊型

**核心特征**: 职责边界不清，重叠或真空
**危险等级**: 🟡 中危
**常见场景**:
- 人人都是CEO，无人做执行
- 关键决策无人负责
- 跨部门协作反复扯皮
- 汇报关系混乱

**典型案例标签**:
- 三头马车失控
- 决策真空地带
- 责任推诿循环
- 组织扁平化陷阱

**五维决策要点**:
- 🟤 土: 角色清晰是"引智士同行"的前提
- ⚪ 金: RACI矩阵是最低成本的满意解
- 🔵 水: 观自在：谁真正适合这个角色？
- 🟢 木: "礼"（秩序）在组织中的体现
- 🔴 火: 直觉知道谁在"占坑不做事"

## Type06: 能力不匹配型

**核心特征**: 合伙人能力与角色要求严重不匹配
**危险等级**: 🟡 中危
**常见场景**:
- 技术创始人被迫做管理
- 联合创始人无法跟上公司成长速度
- 关键岗位能力缺位
- "好朋友"但非"好搭档"

**典型案例标签**:
- 技术宅CEO困境
- 成长速度不匹配
- 关系型合伙人瓶颈
- 创始人天花板

**五维决策要点**:
- 🟤 土: 能力是"同行"的硬通货
- ⚪ 金: 降级、转岗、退出，哪一个是满意解？
- 🔵 水: 观自在：是能力不足还是意愿不足？
- 🟢 木: "智"（知人善任）vs "仁"（不忍下手）
- 🔴 火: 早就知道，只是不愿面对

## Type07: 退出机制型

**核心特征**: 退出条款缺失或执行争议
**危险等级**: 🟡 中危
**常见场景**:
- 合伙协议中无退出条款
- 股权回购价格无法达成一致
- 竞业禁止范围争议
- 知识产权归属不清

**典型案例标签**:
- 无退出条款的陷阱
- 股权回购僵局
- 竞业范围争议
- 分手费谈判

**五维决策要点**:
- 🟤 土: 退出机制是"同行"的体面保障
- ⚪ 金: 事前约定远胜事后谈判
- 🔵 水: 观自在：好聚好散，避免双输
- 🟢 木: "信"（契约精神）与"义"（人情体面）
- 🔴 火: 和平分手是最高级的商业智慧

**危险等级**: 🟡 中危

- 家族成员介入经营
- 政府监管政策突变
- 关键客户要求股权

**典型案例标签**:
- 投资人夺权
- 家族企业内斗
- 政策黑天鹅
- 客户绑架

**五维决策要点**:
- 🟤 土: 外部力量改变"同行"的生态环境
- ⚪ 金: 如何在约束条件下找到满意解？
- 🔵 水: 观自在：区分可控与不可控
- 🟢 木: "智"（借势）与"仁"（护团队）
- 🔴 火: 危机中往往隐藏着转机

## Type09: 沟通障碍型

**核心特征**: 信息不透明，沟通渠道失效
**危险等级**: 🟢 可控
**常见场景**:
- 重要决策无会议记录
- 信息只在小圈子流通
- 冲突被回避而非解决
- 反馈机制缺失

**典型案例标签**:
- 信息孤岛
- 会议无记录
- 冲突回避
- 反馈黑洞

**五维决策要点**:
- 🟤 土: 沟通是"同行"的日常维护
- ⚪ 金: 建立最低限度的沟通机制
- 🔵 水: 观自在：谁在害怕透明？
- 🟢 木: "礼"（仪式感）促进"信"（信任）
- 🔴 火: 直觉知道问题在哪，只是没人说

## Type10: 决策僵局型

**核心特征**: 重大事项无法达成一致，公司陷入停滞
**危险等级**: 🟡 中危
**常见场景**:
- 融资条款分歧导致融资失败
- 产品路线争议导致开发停滞
- 关键 hires 无法达成一致
- 市场进入策略分歧

**典型案例标签**:
- 融资僵局
- 产品路线之争
- 关键 hires 否决
- 市场策略分歧

**五维决策要点**:
- 🟤 土: 决策僵局消耗"同行"的能量
- ⚪ 金: 设定决策时限，避免无限拖延
- 🔵 水: 观自在：各自的底线是什么？
- 🟢 木: "智"（智慧决策）vs "仁"（顾虑太多）
- 🔴 火: 有时"先干再说"比"完美方案"更重要

## Type12: 代际传承型

**核心特征**: 创始人代际交接中的权力与价值传承
**危险等级**: 🟡 中危
**常见场景**:
- 创始人退休/退出后的接班问题
- 二代接班人与元老团队冲突
- 企业精神/文化的传承断裂
- 股权代际转移争议

**典型案例标签**:
- 创始人退休综合征
- 二代接班危机
- 文化传承断裂
- 股权代际转移

**五维决策要点**:
- 🟤 土: 传承是"同行"的终极考验
- ⚪ 金: 制度化的传承优于人格化的传承
- 🔵 水: 观自在：功成身退也是一种自在
- 🟢 木: "仁"（仁爱传承）与"智"（智慧交接）
- 🔴 火: 最好的传承是让企业不再需要创始人
