# 文章分类存储与简报技能

## 触发条件

当用户通过微信（wechat-access）发送文章链接或内容时，本技能被激活。

## 核心功能

### 1. 文章分类存储

**一级分类（10 个，不可随意扩充）**：
1. 技术前沿 - AI、区块链、云计算等
2. 商业财经 - 投资、市场、经济分析
3. 产品管理 - 产品设计、用户体验、方法论
4. 职场成长 - 职业发展、技能提升、领导力
5. 健康养生 - 运动、饮食、心理健康
6. 科学探索 - 物理、生物、天文等自然科学
7. 人文社科 - 历史、哲学、社会学
8. 文化艺术 - 文学、电影、音乐、艺术
9. 生活技巧 - 家居、旅行、美食、效率工具
10. 新闻资讯 - 时事、政策、行业动态

**分类规则**：
- 根据文章内容自动判断一级分类
- 在一级分类下动态创建二级、三级分类（基于文章主题）
- 如需扩充一级分类，必须先询问用户

**存储结构**（本地文件目录）：
```
C:\Users\lifei08\Documents\文章收藏\
├── 技术前沿/
│   ├── AI 大模型/

│   └── 区块链/
│       └── 2026-03-10_文章标题.md
├── 商业财经/
└── ...
├── _index.json              # 文章索引文件
└── _briefings/              # 简报目录
    ├── 2026-03-week3.md     # 周报
    ├── 2026-03.md           # 月报
    └── 2026-Q1.md           # 季报
```

**存储方式**：
- 使用 `write` 工具创建本地 Markdown 文件
- 使用 `read`/`edit` 工具更新索引文件
- 简报以 Markdown 文件形式存储在 `_briefings/` 目录

### 2. 定期简报生成

**生成频率**：
- 周报：每周五下午生成
- 月报：每月最后一个工作日生成
- 季报：每季度末生成

**简报内容**：
1. 本期收集文章数量统计（按分类）
2. 核心内容摘要（每篇 50-100 字）
3. 趋势观点分析
4. 对经济、生活的影响分析
5. 针对性建议：
   - 发展建议（职业/技能方向）
   - 投资建议（行业/领域洞察）
   - 个人提升建议（学习/成长方向）

**简报模板**：见 `templates/briefing-template.md`

## 工作流程

### 接收文章
1. 从微信消息中提取文章链接或内容
2. 使用 `web_fetch` 获取文章内容（如为链接）
3. 分析内容确定分类
4. 在本地 `C:\Users\lifei08\Documents\文章收藏\<一级分类>\<二级分类>\` 目录下创建 Markdown 文件
5. 文件命名格式：`YYYY-MM-DD_文章标题.md`
6. 更新 `_index.json` 索引文件（记录标题、分类、日期、来源、文件路径）

### 生成简报
1. 读取 `_index.json` 获取指定时间段内的文章列表
2. 读取对应 Markdown 文件内容
3. 按分类整理，生成趋势分析和建议
4. 将简报写入 `C:\Users\lifei08\Documents\文章收藏\_briefings\` 目录
5. 通过微信发送简报内容给用户
