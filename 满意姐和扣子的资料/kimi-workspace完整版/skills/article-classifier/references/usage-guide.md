# article-classifier 使用指南

## 快速开始

### 1. 发送文章

通过飞书发送文章链接或内容给机器人，格式如下：

```
请保存这篇文章：[文章链接]
或
请分类存储：[文章内容]
```

### 2. 查看已存储文章

```
查看我存储的技术前沿类文章
显示商业财经分类下的内容
```

### 3. 生成简报

```
生成本周简报
生成 3 月月报
生成 2026 年第一季度季报
```

## 分类规则

- 一级分类固定 10 个，不可随意扩充
- 二级、三级分类根据文章内容自动创建
- 如需新增一级分类，系统会先询问确认

## 简报时间

- **周报**：每周五下午 5 点生成
- **月报**：每月最后一个工作日下午 5 点生成
- **季报**：每季度末工作日下午 5 点生成

可联系管理员调整生成时间。

## 存储位置

文章存储于：`skills/article-classifier/storage/`

索引文件：`skills/article-classifier/storage/index.json`

## 注意事项

1. 首次使用建议先测试几篇文章
2. 定期检查分类是否准确
3. 简报生成后可下载或分享到飞书
