# 知识海啸处理器 V1.0 — 产品规格说明书

> **产品定位**: 海量散乱信息 → 结构化知识资产的转化器
> **核心场景**: 接收1000+杂乱无章的文件（文档/图片/数据/代码/音频转录），自动分类、萃取核心知识、转化为三生万物级别质量的标准传承包
> **擅长领域**: 文字处理（含OCR图片文字提取），可处理图片信息（识别+标注）
> **版本**: V1.0
> **日期**: 2026-04-26
> **来源**: 满意解研究所·三生万物产品体系

---

## 一、文件处理类型支持

| 日志文件 | `.log` | 时间戳分块，异常提取 | ⭐⭐⭐ |

## 三、五步处理流水线详解

### Step 1: 海啸导入（tsunami-ingest.py）

```
输入: 散乱文件目录
输出: 
  - 01_初始索引.json（全部文件元数据）
  - 02_文件元数据.csv（统计报表）
  - 00_扫描报告.md（人类可读摘要）

处理逻辑:
  1. 递归扫描目录树
  2. 识别文件类型（扩展名+magic number）
  3. 提取元数据（大小/修改时间/路径深度/文件名语义分析）
  4. 按类型分箱（文字/图片/代码/数据/其他）
  5. 生成扫描报告

参数:
  - --input: 输入目录
  - --output: 输出目录
  - --batch-size: 每批处理文件数（默认1000）
  - --max-depth: 最大扫描深度（默认无限）
  - --exclude: 排除模式（如node_modules/, .git/）
```

### Step 2: 智能分类（smart-triage.py）

```
输入: 01_初始索引.json
输出:
  - 03_分类索引.md（分类树+文件清单）
  - 04_P0-P1-P2-P3标记.json（优先级标记）

分类维度:
  - 按内容类型: 案例/操作手册/理论/数据/通信/其他
  - 按时间维度: 近期(1年)/中期(1-3年)/历史(3年+)
  - 按来源维度: 内部原创/外部引用/混合改编
  - 按完整性: 完整文档/草稿片段/待补充

P0/P1/P2/P3判定规则:
  P0(核心): 高价值+完整+可独立使用
  P1(重要): 高价值+需补充/中等价值+完整
  P2(参考): 中等价值+需补充/背景信息
  P3(归档): 低价值/重复/过时可丢弃

参数:
  - --input: 初始索引路径
  - --output: 输出目录
  - --auto-mark: 自动标记策略（conservative/aggressive）
```

### Step 3: 核心萃取（core-extractor.py）

```
输入: 分类索引 + 原始文件
输出:
  - 05_核心知识清单.md（≤5项核心知识）
  - 06_隐性知识候选.md（需人工确认的隐性知识）

萃取模板:
  模板A: 决策判断型 → 如果[条件A]，那么[判断B]，因为[依据C]
  模板B: 操作手感型 → 操作[步骤X]时，注意[细节Y]，避免[错误Z]
  模板C: 关系分寸型 → 与[对象M]互动时，[做法N]有效，因为[原因O]
  模板D: 核心知识定义 → [知识名称] = [定义] + [边界] + [反例]

隐性知识识别信号:
  - "感觉""直觉""经验""惯例""通常""老办法"
  - 操作描述中缺失的"为什么"
  - 文档中标注"TODO""FIXME""待补充"
  - 同一主题多个版本之间的差异

参数:
  - --input: 分类索引路径
  - --output: 输出目录
  - --max-core: 最大核心知识数（默认5）
  - --template: 萃取模板选择（A/B/C/D/auto）
```

### Step 4: 质量转化（quality-transform.py）

```
输入: 核心知识清单 + 隐性知识候选
输出:
  - 07_质量转化包/
    ├── 00_导览总纲.md（传承包入口）
    ├── 01_P0核心层/（按五维映射排列）
    ├── 02_P1支撑层/
    ├── 03_P2背景层/
    ├── 04_隐性知识/
    └── 05_阅读指引.md（承者使用指南）

五维映射自动标注:
  土(信任基础): 涉及关系/伦理/价值观的文件
  金(质量标准): 涉及判断/评估/标准的文件
  水(灵活应变): 涉及策略/调整/变通的文件
  木(生长发展): 涉及积累/传承/迭代的文件
  火(直觉确认): 涉及洞察/顿悟/关键转折的文件

双视角适配:
  - 人类视角: 导览总纲+阅读顺序+决策要点
  - AI视角: 操作指令+脚本调用+自动化路径

参数:
  - --input: 萃取结果路径
  - --output: 质量转化包路径
  - --quality-level: 质量等级（L1-L5，默认L3）
```

### Step 5: 输出打包（package-builder.py）

```
输入: 质量转化包
输出:
  - 08_标准传承包/
    ├── 00_索引.md（中央导航）
    ├── 01_P0核心层/（≤5项核心知识，五维映射）
    ├── 02_P1支撑层/（关键支撑材料）
    ├── 03_P2背景层/（参考资料）
    ├── 04_隐性知识/（待人工确认）
    ├── 05_质量报告.md（处理统计+质量评级）
    └── 06_交接清单.md（传者→承者交接凭证）

打包标准:
  - 人类可独立阅读（无需传者补充）
  - AI可执行操作（脚本+指令清晰）
  - 五维决策融入（每文件有映射标注）
  - 双视角齐备（人类视角+AI视角）

参数:
  - --input: 质量转化包路径
  - --output: 标准传承包路径
  - --format: 输出格式（markdown/csv/json/yaml）
```

## 四、并发与性能架构

### 4.1 并发模型

```
┌─────────────────────────────────────┐
│         任务调度器 (Scheduler)       │
│         最大并发: 20文件             │
├─────────────────────────────────────┤
│  队列1: 文字处理 (8并发)  │  队列2: OCR处理 (4并发)  │
│  队列3: 代码解析 (4并发)  │  队列4: 数据表格 (4并发)  │
└─────────────────────────────────────┘

调度策略:
  - P0文件优先处理
  - 同类型文件批量处理（减少上下文切换）
  - 大文件自动降级到低优先级队列
  - 内存不足时触发分块加载
```

### 4.2 分批处理策略

| 批次规模 | 适用场景 | 处理时间 | 内存需求 |
|:---------|:---------|:---------|:---------|
| 极速版 | ≤100文件，快速验证 | 1-4小时 | 2GB |
| 标准版 | ≤1000文件，日常工作 | 1-3天 | 8GB |
| 完整版 | ≤10000文件，深度传承 | 7-10天 | 16GB |
| 极限版 | ≤100000文件，生态级迁移 | 30-90天 | 32GB+外部存储 |

### 4.3 断点续传机制

```
每完成一个批次，自动生成检查点:
  - checkpoint-batch-{N}.json（进度状态）
  - 中断后从最后检查点恢复
  - 支持手动指定恢复点
  - 错误批次自动重试（最多3次）
```

## 五、质量等级定义

### 5.1 L1-L5质量等级

| 等级 | 名称 | 适用场景 | 机器完成度 | 人工参与度 | 输出标准 |
|:-----|:-----|:---------|:-----------|:-----------|:---------|
| **L1** | 极速草稿 | 紧急预览 | 90% | 10%（快速浏览） | 结构正确，内容待校对 |
| **L2** | 工作底稿 | 内部使用 | 80% | 20%（关键确认） | 核心知识完整，细节待补充 |
| **L3** | 标准传承 | 正式交接 | 70% | 30%（深度审校） | 可直接进入传承流程 |
| **L4** | 精品知识 | 对外发布 | 60% | 40%（专家审核） | 达到出版/培训标准 |
| **L5** | 经典资产 | 长期传承 | 50% | 50%（多人协作） | 达到三生万物/契晋纪级别 |

### 5.2 默认质量: L3（标准传承）

L3标准传承包的验收标准:
- ✅ P0核心知识≤5项，每项可独立理解
- ✅ P1支撑材料完整引用
- ✅ P2背景层有清晰分类
- ✅ 隐性知识有识别标记+待确认提示
- ✅ 五维映射覆盖全部P0/P1文件
- ✅ 双视角导览齐备（人类+AI）
- ✅ 阅读指引含操作步骤
- ✅ 质量报告含处理统计
