# 商业模式分析器 (Business Model Analyzer)

基于 SKILL 框架的商业模式分析工具，帮助你系统性地研究和构建商业模式。

## SKILL 框架

- **S**tructural Blocks（结构板块）：商业模式画布9大板块
- **K**ey Dimensions（研究维度）：逻辑四维 + 深化三维
- **I**ndustrial Position（产业链位置）：上中下游与生态定位
- **L**ultural & Cognitive Layer（文化主张与认知解决）：4C框架与认知层级

## 商业模式画布 (9大板块)

| 板块 | 核心问题 | 关键要素 |
|------|---------|---------|
| CS 客户细分 | 为谁创造价值？ | 大众/利基/多元化市场 |
| VP 价值主张 | 提供什么价值？ | 产品/服务/价格/创新 |
| CH 渠道通路 | 如何触达用户？ | 线上/线下/全渠道 |
| CR 客户关系 | 如何维系关系？ | 订阅/社群/自助服务 |
| RS 收入来源 | 如何赚钱？ | 销售/订阅/佣金/广告 |
| KR 核心资源 | 拥有什么资产？ | 实体/知识/人力/数据 |
| KA 关键业务 | 必须做什么？ | 生产/研发/平台运营 |
| KP 重要伙伴 | 谁在帮你？ | 供应商/联盟/生态伙伴 |
| CS 成本结构 | 钱花在哪？ | 固定/可变成本 |

## 研究维度

### 逻辑四维（硬实力）
- 价值创造：VP与CS的匹配度（PMF）
- 价值传递：CH与CR的运营效率
- 价值获取：RS与CS的盈利可持续性
- 系统协同：KR/KA/KP的资源匹配

### 深化三维（软实力）
- 文化价值观：价值主张的道德边界
- 情感连接：用户粘性的非理性因素
- 组织韧性：文化对长期战略的支撑

## 产业链位置

| 位置 | 角色 | 定价权 | 示例 |
|------|------|--------|------|
| 上游 | 资源/技术掌控者 | 高 | 芯片、原材料 |
| 中游 | 整合/制造者 | 中 | 品牌商、制造商 |
| 下游 | 触点/服务者 | 低-中 | 零售商、平台 |
| 生态 | 规则/系统定义者 | 极高 | iOS、微信 |

## 4C文化框架

- **C**onviction（信念）：解决"信仰什么"
- **C**ommunity（社群）：解决"归属感"
- **C**onvenience（便利）：解决"时间贫困"
- **C**ontent（内容）：解决"意义空虚"

## 认知路径（5层）

1. 感知层：不知道→知道
2. 理解层：不理解→理解
3. 认同层：不认同→认同
4. 行动层：不行动→行动
5. 传播层：行动→推荐

## 使用方法

### 1. 安装依赖

```bash
python scripts/install_dependencies.py
```

### 2. 准备数据文件

参考 `examples/xiaomi_example.json`

### 3. 生成报告

```bash
python scripts/generate_report.py data.json 商业模式调研报告.docx
```

## 示例：小米商业模式分析

```bash
python scripts/generate_report.py examples/xiaomi_example.json 小米商业模式分析.docx
```

## 输出成果

**Word文档格式的商业模式调研报告**，包含：

1. 📄 **封面** - 标题、分析对象、日期
2. 📊 **商业模式画布** - 9大板块详细填充
3. 📈 **研究维度分析** - 逻辑四维 + 深化三维
4. 🏭 **产业链定位** - 位置分析与策略建议
5. 🎯 **文化与认知** - 4C框架 + 认知路径
6. ✅ **综合评估** - 健康度评估与优化建议
