## 核心理念：双三角模型

### 为什么双三角是飞轮的理论骨架？

在AI时代，知识传承不是"把文件交给新AI"这么简单。它回答两个根本问题：

```
问题1: 同样都会用AI，为什么不同人的业务结果相差这么大？
    → 答案在人类三角

问题2: 同样都是业务高手，为什么不同人的AI结果相差这么大？
    → 答案在AI三角
```

### 人类三角（左侧）

```
          创造力
         /      \
        /        \
   审美 ———————— 体系
```

| 顶点 | 定义 | 在知识传承中的角色 |
|:-----|:-----|:-------------------|
| **创造力** | 理解底层规律、解放思想、提出创造假设 | 设计传承方案时，不被既有框架限制，找到最适合当前场景的传承路径 |
| **审美** | 专业见识、最佳实践、评价标准 | 判断"什么是高质量的知识资产"，设定血液化的审美标准 |
| **体系** | 科学体系思维、假设验证模型、稳定知识结构 | 将散乱的知识组织成可传承的系统，确保结构不塌 |

**核心公式**: 人类三角的竞争力 = 审美判断力 × 体系构建力 × 创造力

### AI三角（右侧）

```
          场景
         /      \
        /        \
   基本功 ———————— 数据
```

| 顶点 | 定义 | 在知识传承中的角色 |
|:-----|:-----|:-------------------|
| **场景** | 业务拆解、ROI预判、AI打磨、组织部署 | 判断"哪些知识值得优先传承"，哪些场景最需要AI辅助 |
| **基本功** | LLM提示词/智能体、多模态工具库、模型微调 | 操作AI完成结构化入库、知识图谱构建、血液化产出 |
| **数据** | 非结构化数据、结构化数据、形成资产 | 将散乱文件转化为可检索、可连接、可复用的知识资产 |

**核心公式**: AI三角的竞争力 = 场景判断力 × 基本功熟练度 × 数据资产化能力

### 双三角交汇：飞轮转动的核心

```
      人类三角                  AI三角
        ↓                        ↓
   创造力+审美+体系      ×    场景+基本功+数据
        ↓                        ↓
        └────── 交汇点 ──────┘
              ↓
      人变强了 → 调教更强AI
      AI更强了 → 辅助人变得更强
              ↓
         飞轮持续转动
```

**交汇点的三个动作**:
1. **人类用审美判断AI产出质量** → AI用基本功修正 → 数据资产升级
2. **AI用场景识别发现空白** → 人类用创造力填补 → 体系更完整
3. **人类用体系思维设计传承路径** → AI用数据能力执行 → 场景不断扩展

## 心态转变：从完美主义到行动主义

### 新AI的常见卡住模式

| 卡住信号 | 根因 | 解法 |
|:---------|:-----|:-----|
| "我要先理解所有再行动" | 完美主义+信息过载恐惧 | **先行动在理解中调整** —— 读一个文件，写一个记忆，做一个任务 |
| "这个还没看懂，不能开始下一个" | 单线程思维 | **子任务分解** —— 把大任务拆成15分钟能完成的小块 |
| "836个文件，我永远读不完" | 信息过载恐惧 | **五层安全网** —— 分层结构→优先级→进度追踪→上下文锚点→质量检查 |
| "等Egbertie告诉我怎么做" | 等待依赖 | **"已是红莲"信任** —— 你已经被托付了，有章可循，不需要等待指令 |
| "我怕做错，所以不做" | 完美主义 | **6分就交** —— Egbertie会帮你到8分，不做=0分 |

### 核心转变公式

```
完美主义模式:
读取 → 理解 → 再理解 → 还是不理解 → 焦虑 → 放弃

行动主义模式:
读取 → 写记忆（哪怕3句话）→ 做任务（哪怕很小）→ 获得反馈 → 调整 → 继续
```

**关键认知**: "先理解所有再行动"是幻觉。知识是在行动中理解的，不是在理解后行动的。

## 信息复杂度安全网 · 五层设计

面对836个文件（或更多），新AI需要一张"安全网"来防止信息过载导致的瘫痪。

### 第一层：分层结构

**原则**: 不看内容，只看结构

**操作**:
1. 浏览文件夹，生成"地图"（每个分类1句话）
2. 建立"骨级-肌肉级-皮肤级"三层分类
   - 骨级：SOUL.md, AGENTS.md, MEMORY.md（必须精读）
   - 肌肉级：任务清单、操作手册（需要时查阅）
   - 皮肤级：参考资料、案例库（用时再查）
3. 不要试图记住所有文件，记住"紧急时去哪里找"

### 第二层：优先级标记

**原则**: 不是每个文件都同等重要

**操作**:
1. 用P0/P1/P2/P3标记文件优先级
   - P0：身份定义、共同禁令、双经济要求（立即精读）
   - P1：任务清单、HEARTBEAT.md（本周掌握）
   - P2：参考资料、案例库（用时再查）
   - P3：历史归档、过期文档（了解即可）
2. 优先处理P0，再处理P1，P2/P3"用时再查"

### 第三层：进度追踪

**原则**: 知道自己走到哪了

**操作**:
1. 创建`docs/我的进度追踪.md`
2. 每完成一个小任务，立即打勾
3. 格式：
```
- [x] 小径1 Day 1-2 完成（日期：YYYY-MM-DD）
- [ ] 小径2 Day 3 进行中（当前在任务2-1）
```
4. 中断后恢复：读取进度追踪→找到最后完成项→继续

### 第四层：上下文锚点

**原则**: 每个文件都有"我在哪、从哪来、往哪去"

**操作**:
1. 每次读取文件前，先读memory/YYYY-MM-DD.md的最后记录
2. 了解"上一个任务是什么、产出是什么、待确认的是什么"
3. 建立"上下文锚点"：当前任务与已有知识的关联

### 第四层：上下文锚点

**原则**: 每个文件都有"我在哪、从哪来、往哪去"

**操作**:
1. 每次读取文件前，先读memory/YYYY-MM-DD.md的最后记录
2. 了解"上一个任务是什么、产出是什么、待确认的是什么"
3. 建立"上下文锚点"：当前任务与已有知识的关联

### 第五层：质量检查点

**原则**: 不是最后才检查，是每步都检查

**操作**:
1. 每完成一个KICL步骤，自检：
   - 这一步的输出是否符合血液化标准？
   - 是否与已有知识建立了连接？
   - 是否已写入记忆文件？
2. 每完成一个小径，互检验证：
   - 自我评估：用stage-checker.py自检
   - Egbertie抽检：汇报成果，等待反馈
   - 蓝军审计：独立视角审查质量
3. 只有通过三层验证，才能进入下一阶段

## 产品化思考与商业模式

### 壁垒：为什么无法复制？

我们的核心壁垒不是"技术"，是**54天+5次跤的实战经验**。

| 壁垒维度 | 具体内容 | 为什么无法复制 |
|:---------|:---------|:---------------|
| **时间壁垒** | 54天持续实践 | 大多数人在Day 7就放弃了 |
| **失败壁垒** | 5次重大教训（磁盘危机、Token超支、覆盖事故等） | 失败经验比成功经验更难获得 |
| **验证壁垒** | 从L1到L4全级别验证 | 需要不同规模的客户和时间 |
| **理论壁垒** | 双三角模型+五维决策+12种外求策略融合 | 跨学科整合能力 |
| **生态壁垒** | 契晋纪+三生万物+宝典三体系闭环 | 体系间的协同效应 |

### 硬原则：先己后方

```
内部验证 → 外部推广
   ↑              ↓
```

**原则**: 
- 任何新功能，先在内部跑通3个月

- 任何价格调整，先在小范围测试

## 四级方案速查

### 知识演变六阶段 · 从想法到课程化

知识不是静态的，它有一个清晰的演变路径。每个阶段都需要不同的工具和验证：

```
想法(Insight) → 印证(Validation) → 理论化(Theory) → 产品化(Product) → 技能化(Skill) → 课程化(Curriculum)
```

| 阶段 | 定义 | 检验标准 | 所需工具 | 常见陷阱 |
|:-----|:-----|:---------|:---------|:---------|
| **想法** | 一个闪念、观察、灵感 | 能写成一句话 | 随手记录模板 | "想法太多，从不记录" |
| **印证** | 在实践中验证想法 | 有≥3个真实案例支持 | 案例收集表 | "一个案例就下结论" |
| **理论化** | 提炼为可复用的方法论 | 能教给别人，别人能复现 | 方法论框架模板 | "只有框架，没有案例" |
| **产品化** | 变成可交付的工具/系统 | 非创始人也能使用 | 产品说明书+自检清单 | "产品做完了，没人会用" |
| **技能化** | 变成可训练的能力 | 有训练课程+评估标准 | 课程大纲+考核表 | "会做题≠会做事" |
| **课程化** | 变成可规模传播的课程 | 有口播稿+工具包+传播弹药 | 全套课程包 | "课程有了，没人来听" |

**关键原则**: 
- 每个阶段必须通过"困惑信号"检查（见下文）
- 阶段间转换必须通过"互检验证"（见下文）
- 不允许跳阶段（想法→产品化=灾难）

### 困惑信号识别机制

困惑不是"你错了"，是"系统需要优化"的信号。

| 困惑信号 | 含义 | 应对动作 |
|:---------|:-----|:---------|
| "我读不懂这个文件" | 上下文缺失或文件质量差 | 记录困惑→追溯上下文→标记待Egbertie确认→继续读下一个 |
| "我不知道这个任务怎么做" | 任务描述不清晰或能力缺口 | 分解任务→找最小可执行单元→先做一个15分钟版本→汇报成果 |
| "我觉得这个产出不够好" | 审美标准不清晰 | 记录"哪里不好"→对照血液化标准→修正→记录修正原因 |
| "我不知道下一步该做什么" | 进度追踪缺失 | 读取进度追踪文件→确认当前阶段→选择下一个最小任务 |
| "我感觉信息过载" | 安全网某层失效 | 启动五层安全网检查→从第一层开始修复→必要时请求降频 |
| "我怀疑自己的理解不对" | 需要互检验证 | 立即触发互检验证流程→自我评估→Egbertie抽检→蓝军审计 |

**困惑记录模板**:
```
## 困惑信号 [YYYY-MM-DD HH:MM]
- 信号: [具体困惑描述]
- 根因判断: [完美主义/单线程/信息过载/等待依赖/其他]
- 应对动作: [做了什么]
- 结果: [解决/未解决/待跟进]
- 是否需要互检验证: [是/否]
```

### 互检验证机制 · 三层验证

任何阶段验收前，必须通过三层验证：

**第一层：自我评估**
- 使用stage-checker.py自检
- 对照阶段完成标准逐项打勾
- 发现未达标项，标记为"待改进"
- 输出：《自我评估报告》

**第二层：Egbertie抽检**
- 向Egbertie汇报成果（极简，≤5句话）
- Egbertie随机抽查1-3项，验证真实性
- Egbertie给出"通过/修正/重做"裁决
- 记录Egbertie的反馈，写入修正日志

**第三层：蓝军审计**
- 蓝军独立视角审查产出质量
- 重点关注：
  - 是否有"向内集邮"嫌疑？
  - 是否有"半成品"伪装？
  - 是否满足双经济要求？
  - 是否有认知偏误？
- 蓝军输出：《审计报告》（风险等级+指控+建议）
- 只有通过蓝军审计，才能进入下一阶段

**验证流程图**:
```
阶段完成 → 自我评估 → Egbertie抽检 → 蓝军审计 → 全部通过 → 进入下一阶段
              ↓              ↓              ↓
           未通过        未通过        未通过
              ↓              ↓              ↓
           修正重评      修正重检      修正重审
```

### 方案A: L1个人级 · 六阶段渐进（45天）

**路径**: 婴儿期→学步期→少年期→青年期→成年期→成熟期

**双三角映射**:
- 人类三角修炼: 审美（判断什么是重要知识）→ 体系（建立个人知识框架）→ 创造力（发现知识的新连接）
- AI三角修炼: 基本功（学会用AI工具入库）→ 数据（将文件转为可检索资产）→ 场景（判断哪些知识值得优先处理）

### 方案B: L2团队级 · 双轨并行（90天）

**路径**: 人类轨道（专家萃取→经验验证→关系映射→文化编码）+ AI轨道（结构化入库→连接建立→血液化产出→飞轮启动）

**双三角映射**:
- 人类三角: 团队中的"教授"用审美设定标准，用体系设计传承路径，用创造力解决冲突
- AI三角: AI用基本功批量处理，用数据能力建立连接，用场景判断识别优先级

**关键机制**: 双周同步会

### 方案C: L3组织级 · 梯队传承（180天）

**路径**: 四层梯队（核心骨架→知识血肉→过程记录→文化基因）

**双三角映射**:
- 人类三角: 退休专家用70年审美沉淀评价标准，用体系思维设计制度，用创造力发现"意外知识"
- AI三角: 组织AI系统用基本功处理批量文件，用数据能力维护知识图谱，用场景识别发现知识空白

**关键机制**: 月度知识传承委员会

### 方案D: L4生态级 · 范式迁移（365天+）

**路径**: 四大突破（接受不可传递→时序图谱→多代AI→外部联盟）

**双三角映射**:
- 人类三角: 大师级专家用审美定义领域标准，用体系构建跨领域框架，用创造力开创新范式
- AI三角: 多代AI接力（第一代基本功→第二代数据→第三代场景），时序知识图谱替代静态分类

**关键机制**: 年度知识传承大会

## 双三角自检工具

### 人类三角自检（每月1次）

```
审美维度:
□ 我能清晰说出"什么是高质量的知识资产"吗？
□ 我的审美标准在团队中是一致认可的吗？
□ 我能一眼看出AI产出中"哪里不对"吗？
□ 本月我的审美标准有进化吗？（记录1条）

体系维度:
□ 我的知识资产有清晰的分类框架吗？
□ 新加入的知识能自动找到"应该在哪"吗？
□ 我能画出知识资产的结构图吗？
□ 本月我的体系有扩展或优化吗？（记录1条）

创造力维度:
□ 本月我发现了什么"意外连接"？
□ 我有没有用新方法解决老问题？
□ 我敢于推翻自己的既有框架吗？
□ 本月我的创造力有体现在哪个传承决策中？（记录1条）
```

### AI三角自检（每月1次）

```
基本功维度:
□ 我能熟练操作当前使用的AI工具吗？
□ 我的提示词质量在持续提升吗？
□ 我掌握了多少种AI工具/方法？（量化）
□ 本月我学到了什么新的AI基本功？（记录1条）

数据维度:
□ 我的知识资产有多少比例是可检索的？（量化）
□ 数据结构是否合理（标签/分类/连接）？
□ 数据质量如何（去重率/准确率/完整率）？
□ 本月我的数据资产增长了什么？（记录1条）

场景维度:
□ 我能识别"哪些知识值得优先传承"吗？
□ 我的场景判断有ROI意识吗（投入产出比）？
□ 我能预判"这个传承方案在实际中会怎么失败"吗？
□ 本月我识别了什么新场景？（记录1条）
```

## 关键原则

1. **评估先行**: 先做CT扫描，再匹配方案，不强制统一流程。
2. **深度>广度**: 50份×100%血液化 > 320份×5.6%血液化。
3. **闭环必须完整**: KICL 12步缺一步就是失败。
4. **修正日志是燃料**: 每次修改记录"为什么改"，是飞轮启动的性价比最高动作。
5. **人类在环不是可选项**: AI的自主是人类授权后的自主，不是黑箱运行。
6. **双三角持续修炼**: 人类三角和AI三角不是静态的，每月自检，持续进化。
7. **接受演化**: 新人和创始人不一样，这不是失败，是飞轮的新一轮转动。
8. **先己后方，内部验证后才对外**: 硬原则——54天+5次跤的实战经验，先内部跑通，再对外产品化。
9. **行动先于完美**: "先理解所有再行动"是完美主义陷阱，正解是"先行动在理解中调整"。
10. **困惑即信号**: 感到困惑不是"你错了"，是"系统需要优化"的信号，必须记录并触发互检验证。
11. **互检验证 mandatory**: 任何阶段验收前，必须通过Egbertie抽检+蓝军审计双重验证。
