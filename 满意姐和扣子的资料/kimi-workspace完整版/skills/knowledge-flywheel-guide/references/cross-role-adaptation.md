# 跨角色适配指南·知识飞轮传承

> **编号**: SSW-077（新增）
003e **定位**: 不同角色组合（人/AI）的传承策略适配
003e **目标**: 每种组合都有定制的传承方案
003e **版本**: V1.0
003e **日期**: 2026-04-25

---

## 一、四种角色组合

| 组合 | 传者 | 承者 | 核心挑战 | 适配策略 |
|:-----|:-----|:-----|:---------|:---------|
| **A** | 人类 | 人类 | 时间不同步、表达偏差 | 面对面+师徒制+文档化 |
| **B** | 人类 | AI | 认知模式差异、验证困难 | 提示词+对账+自动化验证 |
| **C** | AI | AI | 知识迁移、一致性校验 | 结构化传输+校验机制 |
| **D** | AI | 人类 | 解释性输出、交互验证 | 可视化+交互式教学 |

---

## 二、组合A：人传人

### 特点
- 传者：资深专家，隐性知识丰富
- 承者：人类新人，有直觉但缺经验
- 优势：面对面沟通，可以"感觉"到理解
- 劣势：时间不同步，传者忙，承者等

### 适配策略

**1. 时间同步机制**
```
问题：传者没时间，承者等不及
解决：
- 约定固定时段（如每周三下午2小时）
- 其他时间用异步方式（文档+留言）
- 紧急问题用"困惑信号"标记，等固定时段处理
```

**2. 隐性知识面对面传**
```
问题：隐性知识说不清
解决：
- 传者现场演示（"你看我是怎么做的"）
- 承者现场模仿（"你做一次我看看"）
- 即时纠正（"这里不对，应该…"）
```

**3. 人类理解验证**
```
验证方式：
- 让承者"教传者"（反向教学）
- 观察承者的"微表情"（真懂还是假懂）
- 给"边缘案例"看承者的直觉反应
```

## 三、组合B：人传AI

### 特点
- 传者：人类专家，有隐性知识
- 承者：AI助手，处理能力强但缺直觉
- 优势：AI可以处理大量文档，不会遗忘
- 劣势：AI可能"假懂"（表面理解，实际不会）

### 适配策略

**1. 提示词工程化**
```
问题：AI理解偏差
解决：
- 把隐性知识转化为"判断条件"（If X then Y）
- 把"感觉"转化为"特征列表"（当出现A/B/C时…）
- 把"分寸"转化为"边界条件"（不超过X，不低于Y）
```

**2. 自动化验证**
```
验证方式：
- 给AI测试任务，对比人类专家的结果
- 差异>20% → 标记偏差 → 回溯修正
- 用"困惑信号"机制：AI遇到超出训练范围的情况自动标记
```

**3. 双周对账模板（人-AI版）**
```
对账内容：
- AI汇报："我这周处理了X个任务，结果如下…"
- 人类检查："这个结果符合我的预期吗？"
- 偏差分析："差异在哪里？为什么？"
- 知识更新："我这周学到了新东西，需要更新你的知识库"
```

## 四、组合C：AI传AI

### 特点
- 传者：AI系统（老AI）
- 承者：AI系统（新AI）
- 优势：结构化传输，可以精确复制
- 劣势：可能复制了错误，缺乏人类判断

### 适配策略

**1. 结构化知识迁移**
```
传输方式：
- 知识图谱导出（不是文档，是结构化数据）
- 参数迁移（权重、阈值、规则）
- 案例库复制（带标签和结果）
```

**2. 一致性校验**
```
校验方式：
- 给新老AI同样的输入，对比输出
- 输出一致性>95% → 迁移成功
- 输出一致性<95% → 找出差异点，修正
```

**3. 人类在环**
```
关键规则：
- AI传AI后，必须由人类验证第1次
- 人类做"极端场景测试"，确认新AI的判断合理
- 人类审核"知识图谱"，确认没有明显错误
```

## 五、组合D：AI传人

### 特点
- 传者：AI系统（有结构化知识）
- 承者：人类用户（需要学习使用）
- 优势：AI可以无限耐心，反复解释
- 劣势：AI可能"过度解释"或"解释不清"

### 适配策略

**1. 可视化输出**
```
输出方式：
- 把抽象概念转化为图表/流程图
- 把规则转化为"决策树"（如果A→选B，如果C→选D）
- 把案例转化为"故事"（有时间、地点、人物、结果）
```

**2. 交互式教学**
```
教学方式：
- AI提问："你遇到这个情况会怎么做？"
- 人类回答，AI反馈："你的思路和系统的区别是…"
- AI给出"对比表"：人类做法 vs 系统做法
```

**3. 渐进释放**
```
释放策略：
- 第1周：只给"是什么"（概念）
- 第2周：给"为什么"（逻辑）
- 第3周：给"怎么做"（操作）
- 第4周：给"什么时候做"（判断）
- 绝不一次性给全部
```

## 六、组合选择速查卡

```
传者是___（人/AI）？
承者是___（人/AI）？

如果是 人→人：
  → 重点：时间同步+面对面+反向教学
  → 工具：师徒制+固定时段+现场演示

如果是 人→AI：
  → 重点：提示词工程+自动化验证+困惑信号
  → 工具：If-then规则+测试任务+双周对账

如果是 AI→AI：
  → 重点：结构化迁移+一致性校验+人类在环
  → 工具：知识图谱+参数迁移+极端场景测试

如果是 AI→人：
  → 重点：可视化+交互式+渐进释放
  → 工具：决策树+对比表+分周释放
```
