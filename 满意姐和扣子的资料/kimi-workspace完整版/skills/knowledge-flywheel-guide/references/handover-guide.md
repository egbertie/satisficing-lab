## 一、传者核心问题

作为传者，你需要回答：

```
"我怎么把我知道的传出去？"

→ 哪些该传、哪些不该传？
→ 按什么顺序传？
→ 我怎么知道对方接住了？
→ 如果对方接不住，是我的问题还是对方的问题？
→ 我的隐性知识怎么表达？
→ 我需要投入多少时间？
→ 传完之后，我怎么验证传成功了？
```

**本手册解决以上全部问题。**

## 三、核心知识萃取法（Step 1）

### 3.1 核心知识识别

**问题**：如果我明天消失，哪些知识的缺失会让团队/组织遭受最大损失？

**萃取方法——"5问法"**：

```
问1：客户最常问我什么问题？（列10个）
问2：哪些问题的答案，我"凭感觉"就知道，但新人怎么都学不会？（标3个）
问3：哪些决策，我几乎不假思索就能做对，但新人总是犹豫或做错？（标3个）
问4：哪些工具/模板/清单，是我用了10年以上的"秘密武器"？（列5个）
问5：如果我只能传3样东西，我会选哪3样？（最终筛选）
```

**输出**：你的"核心知识清单"（≤5项）

### 3.2 优先级标记工具（P0/P1/P2/P3）

**标记规则**：

| 级别 | 名称 | 判断标准 | 不传的后果 | 标记方式 |
|:-----|:-----|:---------|:-----------|:---------|
| **P0** | 必须传 | 没有它，承者无法启动 | 系统崩溃 | 🔴 红色标签 |
| **P1** | 应该传 | 没有它，承者效率降低50%+ | 严重低效 | 🟡 黄色标签 |
| **P2** | 可以传 | 有了更好，没有也行 | 轻微不便 | 🟢 绿色标签 |
| **P3** | 不用传 | 存了也不会用，或已经过时 | 无影响 | ⚪ 灰色/不标记 |

**操作步骤**：
1. 列出所有你想传的知识（不超过20项）
2. 对每一项问："如果承者没有这个，会怎样？"
3. 按后果严重程度标记P0/P1/P2/P3
4. **只传P0和P1**，P2可选，P3不传

**常见错误**：
- ❌ "这个很重要"→ 重要≠P0，要看"没有它能不能启动"
- ❌ "这个花了我很长时间积累"→ 投入时间≠P0，要看"对承者的必要性"
- ❌ "这个未来可能有用"→ 未来≠现在，P3先不传

## 四、隐性知识表达法（Step 2）

### 4.1 隐性知识识别

**隐性知识的特征**：
- 你知道怎么做，但说不清楚为什么
- 你"凭感觉"判断，但给不出明确标准
- 你"自然而然"就做了，没意识到是知识

**识别方法——"反事实提问"**：
```
"如果让一个聪明但没有经验的人来做这件事，
他会在哪里卡住？
为什么他会卡住？
我是怎么跨过这个卡点的？"
```

### 4.2 隐性知识表达模板

**模板A：决策判断模板**
```
场景：当遇到______时
我的判断：我会选______
判断依据：
  - 第一看______（权重40%）
  - 第二看______（权重30%）
  - 第三看______（权重20%）
  - 例外情况：当______时，我改为选______
常见陷阱：新手容易______，实际上应该______
我的验证方法：我会用______来确认判断正确
```

**模板B：操作手感模板**
```
操作：______
标准动作：先做______，再做______，最后______
手感信号：
  - 当______时，说明对了
  - 当______时，说明快了/慢了/过了
  - 当______时，说明需要调整______
常见错误：
  - 错误1：______ → 后果：______ → 纠正：______
  - 错误2：______ → 后果：______ → 纠正：______
我的"老中医"经验：______（无法用数据表达的感觉）
```

**模板C：关系分寸模板**
```
对象：______（客户/同事/上级/下属）
情境：______
我的分寸：
  - 说什么：______
  - 不说什么：______
  - 说到什么程度：______
为什么：因为______（背后的逻辑）
如果越界：会出现______（具体后果）
我的修复方法：______
```

### 4.3 隐性知识表达示例

**示例：资深律师的"庭审节奏"**

```
场景：当对方律师在庭审中突然改变策略时
我的判断：我会判断他是"真变"还是"诈变"
判断依据：
  - 第一看他的眼神是否稳定（权重40%）
    → 眼神飘忽=诈变（他在试探）
    → 眼神坚定=真变（他有新证据）
  - 第二看他的文件是否整齐（权重30%）
    → 文件乱=临时起意（没有准备）
    → 文件整齐=早有预谋（准备了Plan B）
  - 第三听他的语气是否有停顿（权重20%）
    → 流畅=胸有成竹
    → 卡壳=内心犹豫
  - 例外情况：当他是资深律师时，以上信号可能都是演技
    → 此时我看他的助理表情（助理不会演戏）
常见陷阱：新手容易被对方的"气势"带走，跟着对方节奏走
  → 实际上应该：按自己的大纲推进，把节奏拉回来
我的验证方法：庭审结束后，复盘"我当时的判断是否准确"
  → 记录准确率，长期追踪
```

### 5.3 时间投入决策

**如果你的时间 < 准备期所需时间**：
- 选择L1级别（最小可行传承）
- 只传P0（1-2项核心知识）
- 使用"极速传承模板"（见下方）

**极速传承模板（2小时完成）**：
```
1. 回答1个问题：如果我只能传1样东西，是什么？（15分钟）
2. 用模板A写1个决策判断（30分钟）
3. 交付给承者，说明："这是我最核心的判断方法"（15分钟）
4. 约定1次对账时间（10分钟）
5. 等待承者反馈，准备修正（50分钟预留）
总计：2小时
```

```
Day 1-2：准备

  □ 完成核心知识萃取（Step 1）
  □ 完成优先级标记（P0/P1/P2/P3）
  
Day 3-5：表达
  □ P0知识→用显性化模板表达
  □ P1知识→用显性化模板表达（可选）
  □ 隐性知识→用隐性知识表达模板

  □ 按"承者上手顺序"排列文件
  □ 每个文件头部加"阅读指引"（见下方）
  □ 生成"传承清单"（见下方）

  □ 与承者进行"传承启动会"（30分钟）
  □ 说明P0/P1/P2的优先级

  □ 每2周一次对账（见双周对账模板）

  □ 执行传承验收清单（Step 5）
```

## 七、传承验收清单（Step 5）

### 7.1 三层验证

**第一层：信息传递验证**
```
□ 承者收到了所有P0文件
□ 承者知道P0/P1/P2的优先级
□ 承者能说出每个P0文件的核心主题（用自己的话）
□ 承者知道在哪里找到补充信息
```

**第二层：理解达成验证**
```
□ 承者能解释"核心知识"是什么（不是背诵，是解释）
□ 承者能举出1个自己遇到的例子，并用传者的框架分析
□ 承者能指出"这里我理解不了"（诚实说出困惑）
□ 承者能区分"我知道"和"我理解了"
```

**第三层：能力迁移验证**
```
□ 承者能在不看传者文件的情况下，执行核心任务
□ 承者的执行结果与传者的预期一致（或差异在可接受范围）
□ 承者能处理"没见过的情况"（用传者的判断逻辑）
□ 承者能发现传者的遗漏/错误（反哺传者）
```

### 7.2 验收方式

**方式A：任务测试**
- 给承者一个真实任务（与传承内容相关）
- 承者独立完成，传者不干预
- 对比结果：如果传者做，会是什么结果？
- 差异分析：差异在哪里？为什么？

**方式B：反向教学**
- 让承者给传者"讲一遍"传承内容
- 如果承者能讲清楚，说明理解了
- 如果讲不清楚，问题出在哪里？

**方式C：极端场景测试**
- 给承者一个"边缘案例"（传者没教过的情况）
- 看承者是否能用传承的"判断逻辑"处理
- 如果能，说明能力迁移成功

### 7.3 验收通过标准

| 层级 | 要求 | 通过标准 |
|:-----|:-----|:---------|
| **信息传递** | 100% | 所有P0文件已收到且优先级明确 |
| **理解达成** | ≥80% | 能解释+能举例+能指出困惑 |
| **能力迁移** | ≥60% | 能独立执行+能处理边缘案例 |

**如果未通过**：
- 分析未通过的层级
- 回溯到该层级的起点，重新执行
- 不要跳到下一层级

## 八、传者自检清单（日常使用）

### 8.1 每次对账前自检

```
□ 我是否准备好了本次对账的重点？
□ 我是否回顾了承者上次的困惑？
□ 我是否准备了新的隐性知识表达？
□ 我是否预设了承者可能的新困惑？
□ 我是否控制了时间（不超过60分钟）？
```

### 8.2 每月传承健康检查

```
□ 承者是否还在使用传承的内容？（如果不用，为什么？）
□ 是否有新的隐性知识产生，需要补充传承？
□ 传承的内容是否需要更新（过时了？）
□ 承者是否有新的困惑，我没发现？
□ 我是否有新的核心知识，需要加入传承？
```

## 九、常见问题（传者FAQ）

**Q1: 我时间很少，只能传一点点，怎么选？**
A: 用"极速传承模板"（2小时）。只选1个P0，用模板A表达1个决策判断，交付，约定1次对账。

**Q2: 我的隐性知识真的说不清楚怎么办？**
A: 用"场景+反事实"法。不要说"我感觉"，说"当X发生时，如果Y出现，我会做Z，因为…"。如果还是说不清，现场演示+录屏/录音。

**Q3: 承者接不住，是我的问题还是他的问题？**
A: 先看"传承清单"里的验证方法，承者做到了吗？
- 如果没做到→可能是我的表达问题，换模板再试
- 如果做到了但做不好→可能是承者的练习不足，增加对账频率
- 如果做到了也做好了→传承成功，进入持续优化

**Q4: 传承过程中，我自己也在学习新东西，怎么同步？**
A: 每次对账后，用5分钟更新"传承清单"：新增P2→标记"待升级"→下次对账时评估是否升P1。

**Q5: 如果承者走了，传承是不是白费了？**
A: 传承文件还在，就是资产。新承者可以从清单开始，不用从零。而且，飞轮转了一圈，你的知识已经增值了。

## 十、快速启动卡

**如果只有5分钟，做这3件事：**

1. **写1个P0**："如果我只能传1样东西，它是______"
2. **用模板A表达1个判断**："当______时，我选______，因为______"
3. **告诉承者**："这是我最核心的东西，你先读这个，其他的都是补充"

**然后，约定第1次对账时间。**
