# 传承衰减防护机制·知识飞轮传承

> **编号**: SSW-076（新增）
> **定位**: 防止多代传承中的信息失真与质量衰减
> **目标**: 第5代传承的质量 ≥ 第1代的80%
> **版本**: V1.0
> **日期**: 2026-04-25

---

## 一、问题：传承衰减

```
第1代传第2代：质量100%
第2代传第3代：质量85%（丢失15%）
第3代传第4代：质量70%（又丢失15%）
第4代传第5代：质量55%（接近不可用）

为什么会衰减？
- 传者传了"自己理解的"，不是"原始准确的"
- 承者理解了"自己以为的"，不是"传者想说的"
- 每代都丢失一些"说不清"的隐性知识
- 每代都增加一些"自己发挥"的误解
```

**本机制防止衰减。**

---

## 二、衰减监测指标

### 2.1 每代传承的质量评分

| 维度 | 第1代基准 | 第2代 | 第3代 | 衰减警戒线 |
|:-----|:---------|:------|:------|:---------|
| 核心知识完整度 | 100% | ≥90% | ≥80% | <80% |
| 隐性知识保留度 | 100% | ≥70% | ≥60% | <50% |
| 判断逻辑一致性 | 100% | ≥85% | ≥75% | <70% |
| 执行结果偏差 | 0% | ≤15% | ≤25% | >30% |

### 2.2 监测方法

**每代传承完成后，对比**：

```
1. 核心知识测试
   → 用同一套问题问每一代承者
   → 看答案是否与第1代一致
   
2. 极端场景测试
   → 给每一代相同的边缘案例
   → 看判断是否与第1代一致
   
3. 反向教学测试
   → 让每一代给新承者讲
   → 看讲的内容是否与第1代一致
```

## 三、衰减防护措施

### 3.1 源头锚定（第1代传者必须做）

```
1. 录制"源头视频"（可选但强烈建议）
   → 传者对着摄像头，讲核心知识（30分钟）
   → 这不是给当前承者的，是给未来第N代的
   → 视频比文字更不容易衰减

2. 写"源头文档"（必须）
   → 用"隐性知识表达模板"完整表达
   → 不是摘要，是完整版
   → 标注："这是第1代原始表达，未经任何转述"

3. 建立"源头索引"
   → 记录：核心知识在哪里、隐性知识在哪里
   → 每代传承都要引用源头索引
   → 不能跳过源头，只传"自己的理解"
```

### 3.2 每代校准（每代承者必须做）

```
1. 传承前校准
   → 承者先读"源头文档"，再看"上一代传承"
   → 对比：上一代讲的和源头一致吗？
   → 如果不一致，标记差异，回溯到源头

2. 传承中校准
   → 每次对账，用"源头文档"作为参考
   → 如果传者（上一代）的表述和源头矛盾
   → 优先相信源头，标记矛盾

3. 传承后校准
   → 传承完成后，用"极端场景测试"验证
   → 如果结果与第1代偏差 > 20%
   → 回溯检查，找出衰减点
```

### 3.3 知识保鲜（定期更新机制）

```
1. 季度回顾
   → 每季度，当前传承者回顾源头文档
   → 问自己："我现在理解的，和源头一致吗？"
   → 如果不一致，修正当前理解

2. 年度校验
   → 每年，用"源头视频/文档"重新培训
   → 相当于"回炉重造"
   → 确保没有"积累性偏差"

3. 版本控制
   → 每代传承生成"传承版本号"
   → V1.0（第1代）→ V2.0（第2代）→ ...
   → 记录每版的差异和衰减点
```

## 四、跨代追溯机制

### 4.1 衰减定位

**如果第5代发现质量下降，怎么找到问题出在哪一代？**

```
追溯方法：
1. 第5代做极端场景测试
2. 同时让第4代、第3代、第2代、第1代做同样的测试
3. 对比结果：
   → 如果第1代和第2代差异大：问题在第2代传承
   → 如果第2代和第3代差异大：问题在第3代传承
   → 以此类推

4. 找到"衰减代"后：
   → 回溯该代的传承记录
   → 看对账记录中是否有"偏差信号"
   → 修正该代的问题，重新传承
```

### 4.2 衰减类型诊断

| 衰减类型 | 表现 | 根因 | 修复方法 |
|:---------|:-----|:-----|:---------|
| **理解衰减** | 承者理解偏差 | 传者表达不清 | 回溯到源头，重新表达 |
| **遗忘衰减** | 知识丢失 | 承者没记住 | 增加验证频率，强化记忆 |
| **简化衰减** | 复杂知识变简单 | 传者图省事 | 强制使用完整模板 |
| **发挥衰减** | 增加传者自己的理解 | 传者"创新" | 锚定源头，禁止发挥 |
| **环境衰减** | 知识在新环境不适用 | 场景变化 | 更新场景适配说明 |

## 五、最小防护（MVP）

**如果只能做1件事防止衰减**：

```
建立"源头文档"并强制每代引用。

规则：
- 任何传承，必须引用源头文档
- 不能只说"我师父告诉我的"
- 必须说"源头文档X说…"
- 如果源头文档和师父说法矛盾，优先相信源头

这样，即使某一代理解错了，
下一代还能回到源头纠正。
```
