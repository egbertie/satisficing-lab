# 思维训练导师 Skill 发布指南

## Skill 概述

**Skill ID**: thinking-mentor-v2
**Skill 名称**: 思维训练导师
**版本**: 1.0.0
**作者**: MiniMax
**描述**: 融合中西方伟大哲学家思维方式的AI思维训练导师，帮助用户提升结构化思维和精准洞察能力

---

## 快速开始

### 在 MiniMax Agent 中使用

当你想要激活思维训练导师模式时，只需说：

```
"从今天开始，你是我的思维训练导师"
```

或直接描述你的思维训练需求：

```
"用结构化思维分析这个问题..."
"请用第一性原理拆解..."
"训练我的战略分析能力..."
```

## 思维框架速查

| 问题类型 | 推荐框架 | 关键问题 |
|---------|---------|---------|
| 追本溯源 | 第一性原理 | 不可违背的约束是什么？ |
| 竞争分析 | 波特五力 | 五种力量如何塑造行业？ |
| 市场分析 | PEST | 宏观环境的关键变量？ |
| 矛盾分析 | 矛盾论 | 主要矛盾是什么？ |
| 战略定位 | 五看三定 | 看什么？定什么？ |
| 风险评估 | 芒格思维 | 反面是什么？盲区在哪？ |
| 需求验证 | 四维评估 | 严峻/迫切/广泛/持久？ |
| 目标制定 | SMART | 具体、可衡量吗？ |

## 典型使用场景

### 场景1：商业分析

**用户**: 分析一下新能源商用车行业的发展机会

**Skill响应**:
1. 运用PEST分析宏观环境
2. 运用波特五力分析行业结构
3. 运用第一性原理追问本质机会
4. 给出结构化战略建议

### 场景2：竞品分析

**用户**: 分析我们与某竞品的差异化策略

**Skill响应**:
1. 解构竞品基因与能力边界
2. 识别我们的差异化维度
3. 寻找借力竞品的可能
4. 构建竞争战略矩阵

### 场景3：需求验证

**用户**: 评估这个产品需求是否值得开发

**Skill响应**:
1. 追问需求本质
2. 从四维评估（严峻性、迫切性、广泛性、持久性）
3. 给出投入建议
4. 提示可能被忽视的风险

### 场景4：思维训练

**用户**: 训练我的结构化思维能力

**Skill响应**:
1. 出一道结构化分析题目
2. 示范分析过程
3. 解释背后的思维框架
4. 要求用户实践并给出反馈

## 发布到 SkillHub

如需将此 Skill 发布到 MiniMax SkillHub，请按照以下步骤：

### 步骤1：准备工作

确保以下文件完整：
- `SKILL.md` - Skill定义文件
- `publish.md` - 发布说明文档

### 步骤2：提交审核

通过 MiniMax 官方渠道提交：
1. 访问 MiniMax SkillHub 开发者平台
2. 创建新 Skill 项目
3. 上传 Skill 文件

## 常见问题

### Q1：这个 Skill 适合谁来用？

**A**: 企业决策者、产品规划人员、战略分析师、MBA学习者，以及希望提升结构化思维能力的任何人。

### Q2：Skill 和直接提问有什么区别？

**A**: 直接提问可能得到碎片化回答。这个 Skill 确保每次分析都：
- 有明确的思维框架支撑
- 有结构化的输出格式
- 有认知升维的引导
- 有可复用的方法论提炼

### Q3：如何反馈使用体验？

**A**: 请记录使用中的问题和建议，通过 MiniMax 官方渠道反馈。
