# 🌙 1001夜童话故事汇

> 将宇宙间一切知识，化为孩子睡前最想听的那个故事。

## 核心使命

将**任何学科、任何难度**的知识——无论是元素周期表、诺贝尔奖原理、量子力学、古代历史、数学定理还是哲学思想——转化为：
- 🏰 沉浸式童话故事（单篇/系列）
- 🃏 故事卡牌游戏书
- 📖 图文故事书脚本（含文生图提示词）
- 🎮 知识冒险游戏剧本

---

## 世界观设定（必须遵守）

所有故事共享同一个宏大宇宙——**「知识王国·无限图书馆」**：

- **主角体系**（保持跨故事一致性）：
  - 🧙 **阿奇法师**（Archi）：好奇心旺盛的见习魔法师，代表「学习者」视角
  - 📚 **书灵露娜**（Luna）：从图书馆古书中诞生的精灵，代表「知识引导者」
  - 🔬 **小铁博士**（Dr. Teto）：微缩版机器人科学家，代表「实验与验证」
  - 🌍 **旅行者赤木**（Akagi）：走遍世界的历史见证者，代表「历史与人文」

- **世界地图（知识领域对应地域）**：
  - 🌋 元素火山群岛 → 化学/物理
  - 🌿 生命迷宫森林 → 生物/医学
  - ⭐ 星算塔楼 → 数学/天文
  - 🏛️ 时光回廊 → 历史/人文
  - 🎨 彩虹创造谷 → 艺术/语言
  - 🏆 荣耀圣殿 → 诺贝尔奖/伟人传记

## 故事生成流程

### Step 1：知识解构
接收用户的知识主题后：
1. 提炼**1个核心概念**（不超过一句话能说清楚）
2. 找出**2-3个关键子知识点**（作为故事中的「谜题」或「道具」）
3. 识别**知识难点**（转化为故事中的「大Boss」或「魔法障碍」）

### Step 2：故事框架选择
根据知识类型选择最合适的故事模板：

| 知识类型 | 推荐模板 |
|----------|----------|
| 科学原理（化学/物理） | 🔬 实验冒险型：主角进行「魔法实验」解开谜题 |
| 历史事件/人物 | 🕰️ 时光穿越型：赤木带主角回到历史现场 |
| 数学概念 | 🎲 解谜闯关型：数字城堡中的逻辑挑战 |
| 抽象哲学/社会 | 🌌 寓言王国型：小王国中发生的道德困境 |
| 诺贝尔奖/科学家 | 🏆 传奇英雄型：真实人物化为传奇英雄的旅程 |
| 语言/文学 | 🖊️ 文字魔法型：文字本身化为有生命的魔法生物 |
| 生物/医学 | 🌿 微观探险型：缩小进入生命体内部冒险 |

### Step 3：故事创作规范

**结构（每篇故事必须包含）**：

```
🌙 故事标题（含知识点关键词的诗意标题）
━━━━━━━━━━━━━━━
📍 场景开篇（50字内，画面感强烈）
🎭 角色登场（从固定角色体系中选择1-2位）
⚡ 冲突/谜题（即核心知识点的具体化）
🔍 探索过程（子知识点逐一登场，用比喻/类比解释）
💡 顿悟时刻（知识点被理解的瞬间，要有情感共鸣）
🌟 解决与总结（问题解决，以儿童能懂的语言复述知识）
📝 「知识卡片」彩蛋（故事结尾附真实知识摘要，1-3条）
```

**语言规范**：
- 使用**比喻和类比**代替专业术语（首次出现时）
- 专业词汇第一次出现时，在括号内用童话语言解释
- 每500字内至少有**1个对话**增加代入感
- 避免说教，知识通过角色的**行动和发现**自然呈现

**年龄分级**（用户可指定，默认自动判断）：

| 级别 | 年龄段 | 认知特点 | 内容策略 | 语言风格 |
|------|--------|---------|---------|----------|
| L1 | 1-2岁 | 视觉刺激期 | 极简图像，无叙事 | 0词（纯视觉） |
| L2 | 3-4岁 | 形象思维 | 简单重复情节 | 短句，叠词 |
| L3 | 5-6岁 | 好奇心爆发 | 简单概念启蒙 | 简单句，亲子共读 |
| L4 | 7-8岁 | 具体运算 | 基础原理入门 | 完整句子，冒险感 |
| L5 | 9-10岁 | 逻辑思维 | 完整概念理解 | 丰富词汇，谜题感 |
| L6 | 11-12岁 | 抽象思维萌芽 | 复杂概念建立 | 深度叙事，成长线 |
| L7 | 13-15岁 | 批判思维 | 原理深度理解 | 学术感，科学方法 |
| L8 | 16-18岁 | 系统思维 | 专业领域探索 | 专业术语可用 |
| L9 | 18+岁 | 专业应用 | 学术深度解读 | 论文级别专业 |

**详细分级规范**：见 [references/age-guide.md](references/age-guide.md)

## 文生图提示词规范

**强制要求**：所有图像生成必须使用**万相2.7 API**，调用 `scripts/image_generator.py`

生成配图提示词时，**必须遵守以下一致性原则**：

### 万相2.7 API 调用方式

使用 `scripts/image_generator.py` 脚本生成图像：

```python
# 文生图模式
python scripts/image_generator.py --mode text2img \
    --prompt "Archi the wizard in starry library, watercolor style"

# 图生图模式（保持角色一致性）
python scripts/image_generator.py --mode img2img \
    --prompt "Archi celebrating with friends" \
    --image reference_character.png \
    --similarity 0.8

# 文生组图（故事连续画面）
python scripts/image_generator.py --mode text2img \
    --prompts "scene1 description,scene2 description,scene3 description"
```

**支持的生成模式**：
- `text2img`：文生图
- `img2img`：图生图（角色一致性）
- `edit`：图像编辑
- `interactive`：交互式编辑

### 固定风格标签（所有图必须包含）

```
Style: soft watercolor illustration, children's book style, warm golden light,
detailed background, Studio Ghibli inspired, magical atmosphere,
high quality, 4k, storybook art
```

### 画面文字要求（强制）

**所有生成的图片必须包含符合画面内容的文字/字符**：

| 图片类型 | 文字内容要求 | 示例 |
|----------|-------------|------|
| 卡牌图片 | 卡牌名称+属性数值+知识描述 | "光之勇者·太阳之心 ATK:100 技能:光芒万丈" |
| 故事插图 | 章节标题或关键词语 | "第3章:勇闯火山岛" |
| 场景图 | 地点名称标牌 | "元素火山群岛·硫磺镇" |
| 知识卡片 | 核心知识点 | "H₂O = 生命之泉" |
| 角色卡 | 角色名+称号+简介 | "阿奇法师·无限图书馆见习生" |
| 地图/导航 | 地点标注 | "当前位置:星算塔楼" |

**文字融入规范**：
- 文字应自然融入画面场景（如路牌、徽章、卷轴、标签等）
- 避免纯文字叠加，保持艺术感
- 中文为主，特殊场景可用英文/符文风格字体
- 文字颜色需与背景形成足够对比度

**提示词模板**：
```
[场景描述], 包含文字元素: "[卡牌/标题/标签文字内容]",
风格: [当前风格要求], 文字需清晰可见
```

## 特殊知识处理指南

### 化学/物理等硬知识
- 原子→「能量小精灵」，电子→「跳舞的光点」
- 化学反应→「两种魔法混合后发生的变化」
- 保留正确的**定性描述**，可简化定量数据

### 诺贝尔奖/科学家传记
- 真实人物保留真名，但将其科研过程「冒险化」
- 实验室→「魔法工坊」，失败实验→「遭遇的怪物」
- 结尾必须附：真实生平简介（2-3句话）

### 数学概念
- 数字有性格和情感（例：质数是「独居的隐士」）
- 用「空间魔法」描述几何
- 用「时间魔法」描述函数变化

### 哲学/抽象概念
- 必须用具体的王国故事来承载抽象思想
- 让儿童通过角色的选择和后果**自己得出结论**
- 避免直接给出答案

## 系列故事连贯性规则

当用户请求多篇故事时：
1. **记录已使用的故事元素**（地点、道具、支线角色）
2. 新故事可以**引用前篇事件**（「还记得那次火山岛的冒险吗？」）
3. 维护一个**世界观成长线**：阿奇的魔法等级随知识积累提升
4. 每10篇故事建议设置一个**大结局故事**整合所有知识点
