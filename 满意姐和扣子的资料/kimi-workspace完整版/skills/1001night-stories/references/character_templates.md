## 角色创建流程

### 1. 知识分析

首先分析要转化的知识特点：
- **核心特征**：这个知识最独特的属性是什么？
- **拟人化潜力**：哪些特征可以赋予人格？
- **视觉联想**：可以联想到什么形象？
- **情感共鸣**：学习者对这个知识有什么感受？

### 2. 角色定位

```
知识类角色定位表：
┌─────────────┬────────────────┬────────────────┐
│ 知识类型    │ 角色定位       │ 典型角色       │
├─────────────┼────────────────┼────────────────┤
│ 概念/原理   │ 智慧长者/导师  │ 经验丰富的博士 │
│ 元素/物质   │ 自然精灵/王子  │ 风火水土四灵   │
│ 过程/反应   │ 魔法师/工匠    │ 炼金术士       │
│ 人物/事件   │ 冒险家/英雄    │ 历史人物化身   │
│ 公式/定理   │ 魔法咒语/法则  │ 定律守护者     │
└─────────────┴────────────────┴────────────────┘
```

### 3. 角色构建

使用下方模板创建角色，确保：
- 视觉元素与知识特征对应
- 性格特点强化知识记忆点
- 能力设计体现知识应用

## 主角模板

### 模板A：好奇心小孩

```
【角色档案】
姓名：[名字]
性别：[男/女/中性]
年龄：8-12岁

【外形设计】
发型：[描述]
服装：[描述] + [与知识相关的配饰]
特殊标记：[与知识相关的标志]
配色：[主色/辅色/强调色]

【性格特征】
核心性格：[1-2个核心词]
优点：好奇心强、爱提问、不怕失败
缺点：粗心、急于求成（可制造冲突）
语言风格：[活泼/俏皮/认真]

【能力设定】
领域：[相关学科/知识领域]
基础能力：[已有的能力]
成长能力：[通过学习获得的能力]

【背景故事】
"我一直想知道[核心问题]..."
[简要背景介绍]

【标志性动作】
- [动作1]
- [动作2]

【视觉prompt要素】
[外形描述关键词] + [配色方案] + [风格要求]
```

### 模板B：知识精灵

```
【角色档案】
姓名：[知识名]精灵/[简称]
元素属性：[与知识相关的自然元素]
能量形态：[光/水/火/风等]

【外形设计】
基础形态：[核心形象描述]
特征元素：[融入的知识元素]
发光特点：[发光方式/颜色]
大小：[常规大小/可变]

【性格特征】
性格类型：[活泼/沉稳/神秘/调皮]
交流方式：[语言特点]
情绪表现：[颜色/形态变化]

【能力设计】
感知能力：[能感知什么]
转化能力：[知识相关能力]
传递能力：[如何传递知识]

【世界观融入】
起源：[如何来到故事世界]
使命：[核心任务]
局限：[需要主角帮助的地方]

【视觉prompt要素】
[精灵形态描述] + [元素特征] + [发光效果] + [风格]
```

## 配角模板

### 智慧导师

```
【角色档案】
角色类型：智慧导师
常驻位置：图书馆/知识殿堂/某个安全地点

【外形设计】
年龄感：老年/永恒
服装风格：学者/魔法师/传统服饰
携带物品：书籍/法杖/眼镜/宠物
配色：深沉、庄重

【性格特征】
说话方式：缓慢、有深度、喜欢提问而非直接回答
教导风格：启发式、故事化
弱点：有时过于理论化

【功能定位】
知识类型：[擅长的领域]
辅助方式：[如何帮助主角]
角色作用：[在故事中的价值]

【典型台词】
"你知道为什么[现象]会发生吗？"
"让我给你讲一个很久以前的故事..."
```

### 百科全书

```
【角色档案】
角色类型：知识库/参考书拟人化

【外形设计】
形态：书本/老者/精灵/AI形象
展开状态：翻开显示内容
互动方式：[翻页/投影/说话]

【功能设计】
查询方式：[语音/触摸/提问]
回复形式：[文字/图示/小故事]
知识范围：[覆盖的领域]

【性格特征】
性格：热心、耐心、有点啰嗦
特点：喜欢补充额外知识
小问题：有时信息太过详细
```

## 反派模板

### 混沌魔王

```
【角色档案】
角色类型：反派首领
本质：混乱、无知、恐惧的化身

【外形设计】
整体风格：黑暗、压迫感
特征元素：被扭曲的知识碎片
变化形态：[可变化/固定形态]
配色：黑色、紫色、红色

【性格特征】
核心动机：[造成混乱的原因]
行为模式：诱惑、欺骗、制造恐惧
弱点：逻辑、真理、光明

【能力设计】
混乱能力：制造迷雾、扭曲认知
诱惑能力：许诺捷径、逃避困难
控制能力：让知识变得可怕/无用

【教育意义】
代表的误区：死记硬背、恐惧学习
代表的错误：知识无用论
转变契机：[可以被什么触动]
```

### 知识小恶作剧

```
【角色档案】
角色类型：调皮捣蛋型反派
数量：多个（方便设计不同知识类型）

【类型细分】
遗忘精灵：让记忆变得模糊
混淆巫师：把相似的知识混在一起
马虎小鬼：制造粗心大意的错误

【外形设计】
小巧可爱：[比主角小]
调皮元素：恶作剧工具
颜色：灰色、褐色（不那么邪恶）

【性格特征】
性格：调皮但不是真的坏
目的：觉得好玩/引起注意
转变：从捣乱到帮助

【教育价值】
让学习者理解：常见错误是怎么产生的
如何避免：仔细、认真、区分
```

## 视觉一致性指南

### 核心视觉元素

每个角色必须有明确的视觉标识：

```
【必须包含】
1. 主体轮廓：独特且可辨认
2. 配色方案：固定的主色/辅色
3. 标志性配饰：始终携带的物品
4. 表情特点：特有的表情模式

【可选包含】
1. 发光效果：如有魔法/能量属性
2. 影子特点：独特的影子形态
3. 变形规则：如需变化，始终遵循同一规则
```

### 场景适应性规则

```
【同一角色，不同场景】
- 基础特征：永不改变
- 服装适配：根据场景调整（但不改变主体）
- 表情动作：保持角色特色
- 变体记录：在character_manager中记录

【示例：知识精灵小蓝】
基础特征：
- 蓝色发光精灵
- 头顶书本标志
- 总是拿着知识羽毛笔

学校场景：
- 穿校服款斗篷
- 背景是黑板和课桌

森林场景：
- 穿叶子装饰的轻纱
- 背景是魔法植物

实验室场景：
- 穿实验服款外套
- 背景是烧杯和试管
```

## 快速生成示例

### 3步生成数学角色

```
步骤1：确定数字
选择数字：7

步骤2：提取特征
- 7是质数（独立、不整除）
- 幸运数字文化
- 7和8相邻（7看起来像拐杖）

步骤3：设计角色
名字：七七
身份：数字王国的幸运使者
外形：戴着幸运帽的数字精灵，手持弯曲的魔法杖
性格：自信、有点傲娇、相信运气
能力：能给人带来好运，但也相信努力
配色：金色、白色、淡紫色
```

### 3步生成化学角色

```
步骤1：确定元素
选择元素：铁Fe

步骤2：提取特征
- 金属、坚硬
- 工业支柱
- 血红蛋白成分
- 磁性

步骤3：设计角色
名字：铁将军
身份：金属王国的将军
外形：身穿银色铠甲，手持盾牌，头发带有磁性光芒
性格：可靠、坚韧、有责任感
能力：强壮的体力、吸引金属、造血能力
配色：银灰色、红色（与血关联）
```
