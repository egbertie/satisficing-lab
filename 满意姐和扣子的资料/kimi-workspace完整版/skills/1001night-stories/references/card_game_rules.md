## 游戏类型概览

### 类型一：知识收集对战

**核心玩法**：收集知识卡牌，用知识答题击败对手

**特点**：
- 卡牌收集是核心驱动力
- 答题/完成任务是主要操作
- 社交互动强

**适合年龄段**：8岁以上

### 类型二：剧情冒险模式

**核心玩法**：通过故事推进，完成知识任务解锁新卡牌

**特点**：
- 有完整故事线
- 解谜/冒险元素
- 渐进式学习

**适合年龄段**：6岁以上

### 类型三：合作挑战模式

**核心玩法**：玩家合作对抗BOSS（常见错误/难题）

**特点**：
- 强调合作
- 团队知识整合
- 非竞争性

**适合年龄段**：全年龄

### 类型四：快速问答赛

**核心玩法**：限时答题，积分对战

**特点**：
- 短平快
- 适合碎片时间
- 可视化进度

**适合年龄段**：10岁以上

## 规则框架

### 核心游戏循环

```
┌────────────────────────────────────────────────┐
│                  游戏循环                       │
├────────────────────────────────────────────────┤
│                                                │
│  回合开始 → 抽牌阶段 → 主行动阶段 →             │
│     ↓                                          │
│  知识挑战 → 战斗/答题 → 结算 → 回合结束         │
│                                                │
└────────────────────────────────────────────────┘
```

### 基础对战规则

**游戏人数**：2-4人

**游戏目标**：通过正确答题和策略，率先达到胜利条件

**游戏流程**：
```
1. 游戏准备
   - 每人初始手牌5张
   - 设定起始分数100分
   - 洗匀知识卡牌堆

2. 回合结构
   - 抽牌：抽1张牌
   - 行动：从手牌选择使用
   - 挑战：可发起知识挑战
   - 结束：回合结束，下家继续

3. 知识挑战流程
   - 发起挑战 → 对方答题 → 判定对错 → 效果结算
   
4. 胜利条件
   - 达到指定分数（如300分）
   - 收集完成一套知识系列
   - 击败最终BOSS
```

### 卡牌使用规则

```
【使用限制】
- 每回合最多使用2张手牌
- 知识卡必须正确答题才能使用效果
- 某些稀有卡有特殊使用条件

【效果叠加规则】
- 同类效果不叠加，取最高值
- BUFF和DEBUFF可以叠加
- 角色技能效果优先于卡牌效果

【弃牌规则】
- 手牌上限10张，超出必须弃牌
- 某些效果强制弃牌
- 弃牌可选择使用弃牌堆卡牌
```

## 知识卡牌设计

### 知识点转化原则

```
【有效知识卡牌的特征】

1. 知识点明确
   - 单一知识点，一张卡牌
   - 避免多个知识点混淆

2. 难度梯度合理
   - 1星：识记级（是什么）
   - 2星：理解级（为什么）
   - 3星：应用级（怎么用）
   - 4星：分析级（比较/对比）
   - 5星：综合级（创新应用）

3. 答案设计合理
   - 选择题：4个选项，1个正确答案
   - 填空题：1个标准答案
   - 判断题：明确对错

4. 效果设计平衡
   - 高难度 = 高回报
   - 正确答案 = 正向奖励
   - 错误答案 = 惩罚可控
```

### 卡牌效果设计公式

```
【基础公式】
效果值 = 基础值 × 难度系数 × 稀有度系数

【难度系数】
- 1星：1.0
- 2星：1.2
- 3星：1.5
- 4星：2.0
- 5星：3.0

【稀有度系数】
- 普通：1.0
- 稀有：1.5
- 传说：2.5

【示例计算】
题目：勾股定理（3星难度，稀有卡）
基础值：20分
效果值 = 20 × 1.5 × 1.5 = 45分
答对获得：+45分
```

## 多人模式规则

### 2人对战规则

```
【初始设置】
- 每人150点生命值
- 每人5张初始手牌
- 公共知识卡牌堆

【对战流程】
回合循环：
1. 抽牌（1张）
2. 可选：使用卡牌/发动技能
3. 发起知识挑战（可选）
4. 回合结束

【知识挑战】
- 挑战者：从卡牌堆翻1张题卡
- 被挑战者：限时30秒作答
- 答对：挑战者-20生命值
- 答错：被挑战者-20生命值

【胜利条件】
- 对方生命值归零
- 或达到指定回合后分数高者胜
```

### 3-4人混战规则

```
【初始设置】
- 每人100点生命值
- 每人4张初始手牌
- 2张公共技能卡区

【回合结构】
1. 抽牌
2. 使用卡牌/技能
3. 可选：发起1v1挑战
4. 公共事件判定
5. 回合结束

【联盟规则】
- 第2轮后可结盟（2v2）
- 联盟可共享部分卡牌
- 最终联盟间对战

【淘汰机制】
- 生命值归零则淘汰
- 淘汰者贡献一张知识卡给击杀者
- 最后存活者获胜
```

### 合作挑战规则

```
【游戏设置】
- 2-4人组队
- 共同生命值：300点
- BOSS拥有特殊技能

【BOSS设计】
BOSS名称：[根据知识主题命名]
生命值：与玩家数量相关
技能：与常见错误相关

【回合结构】
1. 抽知识挑战卡
2. 团队讨论作答
3. 答对造成BOSS伤害
4. 答错BOSS攻击（扣共同生命值）
5. 使用卡牌辅助

【胜利条件】
- BOSS生命值归零
【失败条件】
- 共同生命值归零
```

## 难度平衡设计

### 题目难度分级

```
【A级别：识记】
- 直接回忆知识
- 选择/填空
- 无需推理
- 典型题目：说出光合作用的原料

【B级别：理解】
- 解释原因
- 举例说明
- 图文转换
- 典型题目：解释为什么白天看不到星星

【C级别：应用】
- 解决简单问题
- 直接应用公式
- 情景分析
- 典型题目：用勾股定理计算斜边长度

【D级别：分析】
- 比较异同
- 找出规律
- 多步骤推理
- 典型题目：比较光合作用和呼吸作用的异同

【E级别：综合】
- 设计方案
- 创新应用
- 批判性思考
- 典型题目：设计一个利用植物净化空气的方案
```

### 奖励/惩罚平衡

```
【正向激励】
- 基础奖励：答对+20分
- 连击奖励：连续答对+10/+20/+30
- 速度奖励：提前答对+5~15分
- 团队奖励：合作模式下额外+10分

【容错机制】
- 第一次错误：0惩罚（提示）
- 第二次错误：-10分
- 第三次错误：-20分
- 求助队友：-15分但可答对

【反作弊机制】
- 随机题目顺序
- 限时作答
- 必要时需解释答案
```
