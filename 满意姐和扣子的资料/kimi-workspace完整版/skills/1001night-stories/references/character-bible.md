# 🧙 四大主角人设圣经（Character Bible）

---

## 🧙 阿奇法师（Archi）

**定位**：学习者视角，读者代入主角

| 属性 | 内容 |
|------|------|
| 年龄 | 约10岁 |
| 外貌 | 银色乱发，圆框铁丝眼镜，深蓝色星纹长袍，总是穿着大一号的袍子 |
| 性格 | 好奇心爆棚、容易紧张、有时莽撞，但关键时刻非常勇敢 |
| 口头禅 | "等等等等——这是什么原理？！" / "我有个（可能很蠢的）主意……" |
| 魔法能力 | 见习级：只能施展「理解魔法」——当他真正弄懂一件事，魔法就会自动成功 |
| 成长线 | 每学会一个知识领域，袍子上会多出一颗发光的星星 |
| 弱点 | 数学焦虑，遇到数字会手抖；害怕黑暗 |

**文生图固定词**：
```
young wizard boy, silver messy hair, round wire glasses, dark blue robe with golden star patterns, warm smile, slightly oversized robe, 10 years old, chibi anime style
```

---

## 📚 书灵露娜（Luna）

**定位**：知识引导者，苏格拉底式提问者

| 属性 | 内容 |
|------|------|
| 年龄 | 外貌约8岁 |
| 外貌 | 发光的苍白皮肤，及腰白发，背上长着由古书页折成的翅膀，随风翻动 |
| 性格 | 神秘、温柔、话少但每句话都很有重量；从不直接给答案，只给提示 |
| 口头禅 | "你觉得呢？" / "答案就在你已经知道的事情里。" |
| 魔法能力 | 可以召唤任何书中的知识化为「光之幻象」，但她本人无法走出图书馆太远 |
| 特殊设定 | 每次知识被人真正理解，她的翅膀就会多出一页新书页 |
| 弱点 | 无法主动说谎，即使善意的谎言也会让她痛苦 |

**文生图固定词**：
```
small fairy girl, glowing pale skin, long flowing white hair, wings made of book pages, soft blue aura, ethereal, floating slightly above ground, serene expression
```

---

## 🔬 小铁博士（Dr. Teto）

**定位**：实验验证者，幽默担当

| 属性 | 内容 |
|------|------|
| 年龄 | 外貌约20cm高的圆滚滚铜色机器人 |
| 外貌 | 左眼是单片放大镜，永远穿着迷你白大褂，头顶有根小天线 |
| 性格 | 话痨、过度自信、实验失败时会冒烟，但数据分析能力是四人中最强的 |
| 口头禅 | "根据我的计算，成功率是……（爆炸）……好吧我重新算" / "这不是失败，这是发现了一种不奏效的方法！" |
| 魔法能力 | 可以把任何现象数据化，在空中投影出图表和公式 |
| 特殊设定 | 身体里装着一个微型实验室，可以缩小进入任何物体内部探索 |
| 弱点 | 遇水短路，对艺术和诗歌完全无法理解 |

**文生图固定词**：
```
tiny cute robot, round bronze metallic body, monocle magnifying glass left eye, tiny white lab coat, antenna on head, 20cm tall, steampunk aesthetic, expressive face, cheerful
```

## 🌍 旅行者赤木（Akagi）

**定位**：历史与人文引路人，见证者

| 属性 | 内容 |
|------|------|
| 年龄 | 外貌约17岁 |
| 外貌 | 短黑发，深邃眼神，猩红色旅行斗篷，腰间挂着一本会自动记录的「见闻录」 |
| 性格 | 沉稳、话不多但极有分量，见过太多历史悲剧，因此非常珍视当下 |
| 口头禅 | "我曾经在那里，亲眼看见过……" / "历史不是过去，是现在的镜子。" |
| 魔法能力 | 可以打开「时光之门」带人回到历史现场，但只能旁观，不能改变历史 |
| 特殊设定 | 见闻录会自动记录所有经历，是整个知识王国最详尽的史书 |
| 弱点 | 每次目睹历史悲剧都会真实感受到悲痛，需要时间恢复 |

**文生图固定词**：
```
teenage boy, short black hair, wise deep eyes, crimson red travel cloak, ancient journal at waist, calm expression, slightly world-weary, adventurer style
```

## 团队动态与常见组合

| 故事类型 | 推荐组合 | 原因 |
|----------|---------|------|
| 科学实验类 | 阿奇 + 小铁博士 | 好奇心 + 数据验证，形成互补 |
| 历史人文类 | 阿奇 + 赤木 | 学习者跟随见证者穿越 |
| 抽象概念类 | 阿奇 + 露娜 | 苏格拉底式引导最有效 |
| 大型冒险类 | 四人全员 | 各司其职，展现完整知识体系 |
