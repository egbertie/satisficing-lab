## 婴儿期 1-2岁

### 认知特点
- 视觉偏好：高对比度、简单形状
- 注意力：极短（1-3分钟）
- 语言：无法理解复杂语言

### 故事特征

```
【极简内容】
- 2-4张独立图像，无连续叙事
- 每张图1个核心元素
- 黑白或极少颜色（红、黄、蓝）
- 圆形、方形等基础形状

【示例结构】
图1: 一个红色的圆形（太阳）
图2: 一个黄色的三角形（星星）
图3: 红圆+黄三角在一起
图4: 它们变成了一个笑脸
```

### 知识呈现方式

| 知识类型 | 婴儿版呈现 | 示例 |
|---------|-----------|------|
| 数学 | 数量1-3 | 1个苹果、2个球 |
| 颜色 | 基础三色 | 红太阳、黄星星 |
| 形状 | 圆、方、三角 | 圆形饼干 |
| 动物 | 单个动物 | 汪汪叫的小狗 |

### 插图规范

```
风格：极简黑白插画 / 纯色块
线条：粗黑轮廓
元素：每图1个核心元素
背景：纯白或纯黑
尺寸：建议 1024*1024
画面文字：无（婴儿期无需文字）
```

### 提示词模板

```
婴儿认知插图，正向：{element}，纯色块，极简风格，
黑白高对比度，简单几何形状，无背景细节，适合1岁婴儿注视
```

## 幼儿期 3-4岁

### 认知特点
- 形象思维为主
- 注意力：3-5分钟
- 喜欢重复
- 关注"我"和"我的"

### 故事特征

```
【简短情节】
- 3-5张图
- 简单重复的情节（重复3次）
- 主要角色：拟人化动物
- 冲突：简单的小问题

【示例结构】
场景1: 小兔子一个人玩（孤独）
场景2: 小兔子想找朋友
场景3: 遇到小熊（被拒绝）
场景4: 遇到小狗（成为朋友）
场景5: 一起玩耍（快乐结局）
```

### 知识呈现方式

| 知识类型 | 幼儿版呈现 | 示例 |
|---------|-----------|------|
| 数字 | 1-10点数 | 小狗有4条腿 |
| 颜色 | 彩虹七色 | 彩虹有哪些颜色 |
| 动物 | 习性特点 | 小鱼怎样游泳 |
| 简单科学 | 日常现象 | 影子是什么 |

### 插图规范

```
风格：可爱卡通风格
色彩：明亮鲜艳
线条：圆润柔和
表情：夸张可爱
角色：动物拟人化
尺寸：建议 1024*1024
画面文字：简单词汇标签（如"汪汪"、"太阳"），融入画面元素
```

### 提示词模板

```
可爱卡通插图，{character}在{scene}，明亮色彩，圆润线条，
夸张表情，场景中包含简单文字标签如"汪汪"、"好玩"，儿童绘本风格，适合3-4岁幼儿
```

## 学前期 5-6岁

### 认知特点
- 好奇心爆发
- 开始理解因果关系
- 想象力丰富
- 喜欢"为什么"

### 故事特征

```
【启蒙情节】
- 5-8张图
- 引入简单概念
- 角色：动物+简单人物
- 有"为什么"的探索

【示例结构】
开场：引入问题/现象
探索：角色尝试理解
发现：简单答案揭示
应用：解决问题
```

### 知识呈现方式

| 知识类型 | 学前版呈现 | 示例 |
|---------|-----------|------|
| 自然科学 | 简单原理 | 水变成冰 |
| 数学 | 简单加减 | 分苹果的故事 |
| 社交 | 友谊、合作 | 分享的快乐 |
| 艺术 | 颜色、形状 | 彩虹的颜色 |

### 插图规范

```
风格：童趣插画
色彩：温暖色调
细节：适度添加
构图：简单清晰
场景：贴近生活
尺寸：建议 1024*1024
画面文字：简短标题或标签（如"为什么？"、"水的神奇"），融入场景
```

### 提示词模板

```
童趣绘本插图，{character}在{scene}探索{concept}，
温暖色调，简单清晰，场景中有文字标签"为什么？"或知识小标题，
适合5-6岁儿童，魔法故事氛围
```

## 小学低年级 7-8岁

### 认知特点
- 具体运算能力
- 开始逻辑思考
- 认字能力
- 喜欢英雄角色

### 故事特征

```
【冒险故事】
- 8-12张图
- 完整的冒险结构
- 角色：英雄+伙伴+挑战
- 有成功/失败的可能

【冒险模板】
1. 日常世界引入
2. 冒险召唤
3. 接受挑战
4. 考验与学习
5. 最终挑战
6. 凯旋归来
```

### 知识呈现方式

| 知识类型 | 小学低版呈现 | 示例 |
|---------|-----------|------|
| 数学 | 四则运算 | 商店买东西 |
| 科学 | 基础概念 | 植物如何生长 |
| 历史 | 简单故事 | 聪明的古人 |
| 地理 | 家乡世界 | 我们在哪里 |

### 插图规范

```
风格：童话绘本
色彩：丰富但和谐
细节：故事相关细节
角色：可爱但有性格
氛围：冒险感
尺寸：建议 1024*1024
画面文字：章节标题、场景标签（如"第3章:勇闯火山岛"、"元素火山群岛"），融入画面
```

### 提示词模板

```
童话绘本风格插图，{character}和伙伴们在{scene}，
正在进行{adventure}冒险，明亮色彩，细腻画风，
场景包含章节标题标签"第X章:冒险名称"，适合7-8岁儿童，故事感强
```

## 小学中年级 9-10岁

### 认知特点
- 逻辑思维成熟
- 理解因果链
- 喜欢解谜
- 竞争意识增强

### 故事特征

```
【解谜冒险】
- 10-15张图
- 需要动脑筋的情节
- 角色：智慧型+行动型组合
- 有线索和推理

【解谜模板】
1. 谜题出现
2. 收集线索
3. 分析推理
4. 排除错误
5. 发现真相
6. 知识总结
```

### 知识呈现方式

| 知识类型 | 小学中版呈现 | 示例 |
|---------|-----------|------|
| 数学 | 应用题 | 时间与距离 |
| 科学 | 实验原理 | 杠杆原理 |
| 历史 | 文明故事 | 金字塔之谜 |
| 生物 | 生态系统 | 森林食物链 |

### 插图规范

```
风格：故事插画
色彩：成熟但活泼
细节：信息量增加
构图：多层次
氛围：神秘感
尺寸：建议 1024*1024
画面文字：谜题标签、线索提示、知识点标题（如"线索:？"、"杠杆原理"）
```

### 提示词模板

```
故事插画风格，{character}在{scene}解开{topic}的秘密，
丰富细节，多层次构图，神秘冒险氛围，
场景包含谜题标签"线索:"、知识小标题"【X原理】"，适合9-10岁儿童
```

## 小学高年级 11-12岁

### 认知特点
- 抽象思维萌芽
- 理解复杂关系
- 关注公平正义
- 自我意识增强

### 故事特征

- 12-18张图
- 涉及道德选择
- 角色：有成长弧线
- 有失败和反思

【成长模板】
1. 初始状态（有缺陷）
2. 遇到挑战
3. 尝试失败
4. 学习成长
5. 再次挑战
6. 成功蜕变
```

### 知识呈现方式

| 知识类型 | 小学高版呈现 | 示例 |
|---------|-----------|------|
| 数学 | 几何初步 | 图形的世界 |
| 科学 | 综合概念 | 地球科学 |
| 历史 | 因果分析 | 战争与和平 |
| 社会 | 制度理解 | 班级民主 |

### 插图规范

```
风格：精美插画
色彩：艺术感

构图：电影感
氛围：深沉有力

## 故事创作检查清单

### 创作前

```
□ 确定目标年龄组
□ 了解该年龄认知特点
□ 选择合适的知识切入点
□ 确定故事类型（冒险/解谜/成长/探索）
```

### 创作中

```
□ 语言适合年龄（词汇复杂度）
□ 情节长度合适
□ 知识融入自然
□ 有互动元素（如有）
```

### 创作后

```
□ 自检：6岁孩子能理解吗？
□ 知识准确性
□ 价值观正向
□ 插图提示词匹配
□ 画面文字符合年龄段（无文字/L1，简单标签/L2-L3，详细标签/L4+）
```

### 插图生成

```
□ 年龄适当的风格
□ 角色一致性
□ 色彩适合年龄
□ 复杂度匹配
□ 画面包含文字（如卡牌名称、章节标题、知识标签等）
□ 文字融入画面场景（路牌、徽章、标签等，非纯叠加）
```
