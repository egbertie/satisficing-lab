## Prompt基础结构

### 优质Prompt公式

```
┌────────────────────────────────────────────────────┐
│  Prompt = 主体 + 场景 + 风格 + 氛围 + 细节         │
└────────────────────────────────────────────────────┘

【主体】：谁/什么在画面中（角色、物品）
【场景】：在哪里/什么环境
【风格】：艺术风格（绘本、卡通、写实等）
【氛围】：情绪、光线、天气等
【细节】：构图、色调、特定元素
```

### 基础模板

```
【童话绘本风格模板】
[主角描述]，[场景描述]，童话绘本插画风格，
色彩温暖明亮，笔触细腻，构图精美，[氛围描述]，
[额外细节]

【示例】
一只穿着蓝色斗篷的小狐狸，漫步在开满鲜花的
魔法森林中，阳光透过树叶洒落，童话绘本插画
风格，色彩温暖明亮，笔触细腻，构图精美，
神秘而温馨的氛围，画面中点缀着发光的小精灵
```

### Prompt分层技巧

```
【第一层：主体描述（30%）】
- 核心角色/物品
- 主要动作/状态
- 关键特征

【第二层：环境描述（25%）】
- 地点/背景
- 时间/天气
- 空间关系

【第三层：风格描述（25%）】
- 艺术风格
- 参考风格
- 色调偏好

【第四层：氛围描述（20%）】
- 情绪基调
- 光线效果
- 特殊氛围
```

## 角色一致性保持

### 核心特征锁定

```
【必须固定的元素】
1. 面部特征
   - 脸型：圆脸/方脸/尖脸
   - 眼睛：形状、大小、颜色
   - 其他：眉毛、鼻子、嘴巴特点

2. 发型发色
   - 发型：长短、样式
   - 发色：具体颜色
   - 特殊：刘海、辫子等

3. 体型特征
   - 高矮胖瘦
   - 体型比例
   - 肢体特点

4. 标志性配饰
   - 必带物品：帽子、项链、武器等
   - 种族标志：翅膀、尾巴、角等

5. 配色方案
   - 服装主色
   - 皮肤色调
   - 发色/瞳色
```

### 角色Prompt模板

```
【基础角色Prompt】
[角色名]，[基础描述+核心特征]，[服装描述]，
[标志性配饰]，[配色方案：[颜色1]/[颜色2]/[颜色3]]，
[风格描述]

【带表情动作】
[角色名]，[基础描述]，[当前表情]，[当前动作]，
[服装描述]，[配色方案]，[风格]，[氛围]

【不同场景适配】
[角色名]，[场景适配服装/外观变化]，
[核心特征保持不变]，[配色方案]，[新场景描述]
```

### 角色Prompt示例

```
【知识精灵小蓝 - 基础】
小蓝，蓝色发光的小精灵，有着大眼睛和温暖的笑容，
头顶有书本形状的发光标志，身穿星星图案的浅蓝色长袍，
配色方案：蓝色(#4169E1)/金色(#FFD700)/白色(#FFFFFF)，
童话绘本风格，可爱Q版

【知识精灵小蓝 - 课堂场景】
小蓝，蓝色发光的小精灵，有着大眼睛和温暖的笑容，
身穿学生款星袍（校服风格），头戴小型博士帽，
手拿羽毛笔，正在认真记笔记，
配色方案：蓝色(#4169E1)/金色(#FFD700)/白色(#FFFFFF)，
童话绘本风格，温馨学习氛围

【知识精灵小蓝 - 冒险场景】
小蓝，蓝色发光的小精灵，有着大眼睛和勇敢的表情，
身穿探险家斗篷（配有口袋和工具），背后展开小翅膀，
手持魔法放大镜，正在探索森林，
配色方案：蓝色(#4169E1)/金色(#FFD700)/绿色(#228B22)，
童话绘本风格，冒险氛围
```

### 角色档案Prompt提取

```
从角色档案中提取Prompt要点：

1. 提取"description"中的外形描述
2. 提取"color_palette"中的配色
3. 提取"style_notes"中的风格要点
4. 组合为核心Prompt
5. 根据场景添加环境描述

【提取示例】
档案内容：
{
  "name": "小蓝",
  "description": "蓝色发光精灵，大眼睛，书本标志",
  "color_palette": {"primary": "#4169E1", "accent": "#FFD700"},
  "style_notes": "圆润可爱，线条柔和"
}

提取后Prompt：
小蓝，蓝色发光精灵，大眼睛，头顶书本发光标志，
配色：蓝色(#4169E1)/金色(#FFD700)，圆润可爱Q版风格
```

## 场景生成技巧

### 场景Prompt结构

```
【场景Prompt公式】
[主要元素] + [环境设定] + [时间/天气] + [氛围] + [构图]

【示例】
开满鲜花的魔法森林，有巨大的发光蘑菇和会说话的树，
午后金色阳光透过树冠，温暖神秘，蝴蝶飞舞，
中心构图，童话绘本风格
```

### 常用场景Prompt

```
【魔法森林】
神秘的魔法森林，古老的大树，发光的蘑菇，
萤火虫飞舞，魔法光芒点点，迷雾缭绕，
色调偏蓝紫色调，神秘氛围

【知识殿堂】
巨大的图书馆，无数悬浮的书籍，发光知识球，
温暖烛光，书架延伸到云端，知识精灵飞舞，
金色主色调，庄严而温馨

【元素王国】
元素大陆的王国，根据元素不同变化：
- 火焰王国：红色橙色岩浆背景，火焰装饰
- 水晶王国：蓝紫色晶体，透明感，闪光
- 森林王国：绿色植物，藤蔓缠绕，自然光

【学校课堂】
温馨的教室，漂浮的黑板，知识精灵在空中讲解，
课桌是小动物的书桌，学生是各种小精灵，
色彩明亮，学习氛围轻松愉快
```

### 背景与角色融合

```
【问题】角色和背景风格不统一

【解决技巧】
1. 在Prompt中明确角色和背景使用同一风格
2. 使用"in harmony with"连接角色和场景
3. 添加"matching art style"强调风格一致

【修正示例】
错误：小蓝坐在真实的教室里，穿着卡通服装
修正：小蓝坐在童话教室里，教室也是绘本风格，
服装和教室风格统一，in harmony with background
```

## 风格控制

### 常用风格词汇

```
【童话绘本风格】
fairy tale illustration, storybook style,
children's book art, warm and cozy,
soft colors, delicate brushstrokes

【卡通Q版风格】
chibi style, cute cartoon, big head small body,
kawaii, expressive eyes, pastel colors

【水彩插画风格】
watercolor illustration, soft edges,
flowing colors, dreamy atmosphere

【写实风格】
realistic, detailed, natural lighting

【扁平插画风格】
flat illustration, vector art,
clean lines, solid colors, minimal shading
```

### 风格组合技巧

```
【主流推荐：童话绘本风】
关键词组合：
fairy tale + storybook + warm colors + 
delicate details + soft lighting + 
whimsical atmosphere

【次选：可爱卡通风】
关键词组合：
chibi + kawaii + pastel + 
big eyes + cute expression + 
bubble background

【进阶：故事感强】
关键词组合：
illustrated story + cinematic composition +
emotional lighting + narrative moment +
detailed background
```

### 光线和氛围

```
【光线类型】
- 温暖阳光：warm sunlight, golden hour
- 月光：moonlight, silver glow
- 魔法光：magical glow, ethereal light
- 烛光：candlelight, warm flicker
- 荧光：bioluminescent, soft glow

【氛围词汇】
- 温馨：cozy, warm, comforting
- 神秘：mysterious, enchanting, magical
- 欢乐：joyful, cheerful, bright
- 紧张：dramatic, tense, dynamic
- 平静：peaceful, serene, tranquil
```

## 多图连续性

### 连续场景设计

```
【同一场景多图策略】
1. 建立场景模板Prompt
2. 每次变化1-2个元素
3. 保持其他元素固定

【示例：知识精灵的一天】

第一张：早晨起床
[小蓝]在[小小的树洞房间]里[揉眼睛刚起床]，
[阳光从窗户照进来]，[温暖温馨]，[童话绘本风格]

第二张：上学路上
[小蓝]走在[通往知识学堂的小路]上，
[背着书本样式的书包]，[哼着歌]，
[路边有回答问题的小花]，[轻快活泼]，[童话绘本风格]

第三张：课堂学习
[小蓝]坐在[知识学堂的教室]里[认真听讲]，
[黑板上写着魔法公式]，[老师是智慧老猫头鹰]，
[专注认真]，[知识殿堂氛围]，[童话绘本风格]
```

### 变化维度控制

```
【每次只变化以下1-2个维度】

1. 角色动作/表情
2. 场景位置/背景
3. 天气/光线
4. 时间/时间段

【保持不变】
- 角色核心外形
- 配色方案
- 风格设定
- 整体色调
```

### 图生图一致性保持

```
【使用参考图生成新图的技巧】

1. 明确保留元素
   "保持角色[角色名]的所有特征不变"

2. 场景变化描述
   "背景变为[新场景]，角色保持原有形象"

3. 动作/表情变化
   "角色做出[新动作/表情]，其他不变"

4. 相似度控制
   similarity: 0.7-0.85（平衡一致性和新意）

【示例Prompt】
保持小蓝的所有特征不变：蓝色发光身体，
大眼睛，星星图案斗篷，头顶书本标志。
现在小蓝在魔法厨房里，正在用火焰魔法煮汤，
表情是惊讶和开心的混合。
```

## 常见问题解决

### 问题1：角色变形

```
【原因】
- Prompt描述不够具体
- 缺少特征锁定词
- 风格不一致

【解决】
1. 添加更多特征描述
2. 使用"保持"类关键词
3. 提取并复用之前的Prompt
4. 使用图生图模式

【示例修正】
原Prompt：蓝色小精灵
修正Prompt：小蓝，蓝色发光精灵，大眼睛，
圆润身体，头顶书本标志，穿星星斗篷，
配色蓝色#4169E1金色#FFD700，必须保持这些特征
```

### 问题2：风格不统一

```
【原因】
- 每次使用不同风格词
- 光线/色调变化大
- 画师风格差异

【解决】
1. 固定风格关键词，每次必用
2. 统一色调范围
3. 使用"consistent with"强调一致

【示例修正】
每次都添加：童话绘本风格，温暖色调，
精美细节，统一的光线设定
```
