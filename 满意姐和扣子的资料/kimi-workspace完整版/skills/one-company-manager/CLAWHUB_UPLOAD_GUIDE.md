## 上传步骤

### 1. 准备文件
确保已准备好：
- one-company-manager.zip（打包文件）
- 技能图标（可选，建议 512x512 PNG）
- 技能截图（可选，建议 2-3 张）

### 2. 登录 Clawhub
1. 访问 Clawhub 平台
2. 登录账号
3. 进入"技能市场"或"我的技能"

### 3. 创建技能
1. 点击"创建技能"或"上传技能"
2. 选择"上传 ZIP 文件"
3. 上传 one-company-manager.zip

### 4. 填写技能信息

#### 基本信息
- **技能名称**：one-company-manager（自动识别）
- **显示名称**：一人公司智能管家
- **技能描述**：一人公司智能管家，提供从战略规划到执行管理的完整商业框架；当用户需要构建商业模型、拆解实现路径、监控市场动态或优化业务优先级时使用
- **技能分类**：商业管理
- **子分类**：效率工具

#### 详细介绍
```
一人公司智能管家是面向一人公司、自由职业者、个体创业者的全维度商业管理系统，提供从战略规划到执行管理的完整解决方案。

核心功能：
- 商业模型构建：从愿景、使命、价值观到战略目标的系统性构建
- 实现路径拆解：自动将业务方向拆解为可执行的路径和里程碑
- 业务全景视图：展示从战略到执行的完整关联关系
- 外部信号感知：实时监控市场动态、政策变化和竞品动作
- 智能决策增强：基于多维度数据优化业务方向排序
- 日常运营管理：业务、财务、时间、健康、关系管理
- 行业定制化模板：自媒体、电商、咨询、教培、UP主/主播
- 外部系统集成：支持20+个外部工具集成

适用对象：
- 一人公司创业者
- 自由职业者
- 个体创业者
- 独立开发者
- 内容创作者
- 咨询顾问

使用方式：
- 自然语言交互："构建我的商业模型"、"拆解AI工具开发方向"
- 快捷命令：/战略、/方向、/全景、/市场、/优化
- 多轮对话："帮我做下周计划"、"我最近太累了"
```

#### 使用说明
```
第一次使用：
1. 加载技能
2. 输入："我是做自媒体的，想用一人公司智能管家管理我的业务"
3. One-Pilot：引导完成商业模型构建
4. 选择行业模板（可选）
5. 开始使用

推荐流程：
1. 构建商业模型
2. 创建业务方向
3. 拆解实现路径
4. 创建行动项
5. 监控外部信号
6. 查看业务全景
7. 优化决策
```

### 5. 上传图标和截图（可选）
- 技能图标：512x512 PNG，建议使用简洁的设计
- 技能截图：展示核心功能界面，建议 2-3 张

### 6. 设置价格（可选）
- 免费使用
- 付费使用（根据技能价值定价）

### 7. 提交审核
1. 检查所有信息是否正确
2. 点击"提交审核"
3. 等待审核通过（通常 1-3 个工作日）

## 审核要点

### ✅ 必须符合
- SKILL.md 格式正确（YAML 前言区）
- name 字段规范（英文小写+连字符）
- description 字段符合要求（100-150字符）
- 文件结构规范
- 无恶意代码
- 无侵犯版权的内容

### ❌ 常见问题
- name 字段包含中文或特殊字符
- description 超过150字符
- 缺少 SKILL.md 文件
- 文件结构混乱
- 包含敏感内容

## 审核通过后

- 审核通过后技能自动发布
