# One-Pilot 商业框架管理

## 概述

One-Pilot 商业框架管理是一套完整的战略到执行管理体系，参考 BMA（Business Model Architecture）框架，为一人公司提供从愿景定义到具体执行的完整解决方案。

## 核心理念

### 从战略到执行
One-Pilot 建立了清晰的层级关系：
```
商业模型（愿景、使命、价值观）
    ↓
业务方向（中长期目标）
    ↓
实现路径（里程碑）
    ↓
行动项（具体任务）
```

### 动态调整
支持业务框架的实时调整和优化：
- 业务方向的新增、修改、暂停、关闭
- 实现路径的动态重构
- 行动项的重新分配

### 外部感知
实时监控市场动态和政策变化，为战略调整提供依据：
- 自动识别外部信号
- 评估信号对业务的影响
- 提供应对建议

## 核心模块

### 1. 商业模型构建模块

#### 1.1 战略规划能力

**功能描述**
为一人公司提供从愿景、使命、价值观到具体业务方向的系统性构建。

**数据模型**
- `business_model.md`：存储商业模型核心信息
  - 公司愿景
  - 公司使命
  - 核心价值观
  - 商业模式画布
  - 战略目标（长期/中期/短期）
  - 业务方向映射

**使用方式**

**创建商业模型**
```
用户: 构建我的商业模型
One-Pilot: 好的，我们来一起构建你的商业模型。

第一步：定义愿景
用户: 成为自媒体领域最有影响力的知识服务商
One-Pilot: 愿景已记录。第二步：定义使命
用户: 帮助一人公司通过系统化管理实现可持续增长
One-Pilot: 使命已记录。第三步：定义核心价值观
用户: 诚信、创新、客户第一
One-Pilot: 价值观已记录。第四步：构建商业模式画布
[引导填写商业模式画布的9个模块]
One-Pilot: 商业模型已构建完成，是否保存？
```

**修改商业模型**
```
用户: 修改我的愿景
One-Pilot: 当前愿景：成为自媒体领域最有影响力的知识服务商
用户: 改为：成为全球领先的AI工具服务商
One-Pilot: 愿景已更新，是否需要调整战略目标？
```

**查看商业模型**
```
用户: 显示我的商业模型
One-Pilot: [展示结构化的商业模型]
```

**快捷命令**
- `/战略`：显示战略规划
- `/方向`：显示业务方向
- `/商业模型`：显示商业模型详情

#### 1.2 实现路径拆解

**功能描述**
将抽象的业务方向拆解为可执行的实现路径和里程碑。

**数据模型**
- `paths.md`：存储实现路径信息
  - 路径列表
  - 里程碑
  - 依赖关系
  - 状态管理

**使用方式**

**拆解业务方向**
```
用户: 拆解自媒体运营方向
One-Pilot: 好的，我来帮你拆解自媒体运营方向。

基于成功标准"6个月内粉丝达到10000+"，我建议拆解为3个路径：

路径1: 内容体系建设（预计2个月）
  - 里程碑1: 完成10篇优质文章
  - 里程碑2: 建立3个内容栏目

路径2: 流量增长（预计3个月）
  - 里程碑1: 优化SEO
  - 里程碑2: 矩阵运营（公众号+抖音+小红书）

路径3: 变现探索（预计1个月）
  - 里程碑1: 开发付费课程
  - 里程碑2: 接广告合作

是否确认这些路径？需要调整吗？
```

**创建实现路径**
```
用户: 创建路径：内容体系建设
One-Pilot: 为内容体系建设创建路径，请设置里程碑。

用户: 第一个里程碑：完成10篇优质文章
One-Pilot: 里程碑已添加，设置截止时间。

用户: 2025年2月28日
One-Pilot: 里程碑已设置，还有其他里程碑吗？

用户: 第二个里程碑：建立3个内容栏目
One-Pilot: 里程碑已添加，设置截止时间。

用户: 2025年3月31日
One-Pilot: 实现路径已创建，开始创建行动项吗？
```

**查看路径依赖**
```

One-Pilot: [展示路径依赖图]

路径1（内容体系建设）
  ├─→ 路径2（流量增长）

⏳ 阶段5: 外部信号感知（预计2天）

阻塞项：无
```

#### 5.2 流程自动化

**功能描述**
实现业务流程的自动化执行，减少用户操作成本。

**使用方式**

**配置流程自动化**
```
用户: 配置流程自动化
One-Pilot: 当前自动化规则配置：

1. 自动创建行动项：已启用
   - 触发条件：里程碑或路径创建
   - 规则：为每个里程碑自动创建1-3个行动项

2. 自动关联关系：已启用
   - 触发条件：业务方向、路径、行动项创建
   - 规则：自动创建关联关系

3. 自动推进阶段：已禁用
   - 触发条件：前置阶段完成
   - 规则：自动启动下一阶段

4. 自动提醒：已启用
   - 触发条件：阶段超时、里程碑延期
   - 规则：自动发送提醒

要修改哪个规则？
```

**启用/禁用自动化**
```
用户: 启用自动推进阶段
One-Pilot: 已启用自动推进阶段。

配置：
- 触发条件：前置阶段完成
- 推进策略：立即启动下一阶段
- 通知方式：发送通知

注意：自动推进可能导致未完全准备好就进入下一阶段，建议谨慎使用。
```

**快捷命令**
- `/自动化`：配置流程自动化
- `/规则`：查看自动化规则
- `/启用`：启用自动化

## 最佳实践

### 1. 商业模型构建
- 从愿景开始，确保长期方向清晰
- 商业模式画布要完整覆盖9个模块
- 战略目标要具体、可衡量、可达成

### 2. 业务方向管理
- 业务方向数量建议3-5个，避免过多
- 每个方向要有明确的成功标准和关键指标
- 定期评估方向优先级，动态调整

### 3. 实现路径拆解
- 路径要具体、可执行
- 里程碑要有明确的时间节点和交付物
- 依赖关系要清晰，避免循环依赖

### 4. 行动项管理
- 行动项要具体，可在一周内完成
- 及时更新状态，保持数据准确性
- 定期回顾，总结经验

### 5. 外部信号监控
- 设置合理的监控关键词
- 定期查看信号，及时应对
- 区分机会和威胁，制定应对策略

### 6. 流程管理
- 使用标准流程确保完整性
- 合理配置自动化规则
- 定期回顾流程效果，持续优化
