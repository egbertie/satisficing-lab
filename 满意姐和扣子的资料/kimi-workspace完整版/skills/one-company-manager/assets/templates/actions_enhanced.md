## 使用说明

### 创建行动项
用户说："创建行动项：开发AI工具原型"
One-Pilot：
1. 引导用户选择关联的业务方向和路径
2. 输入行动描述和时间规划
3. 设置财务和客户关联
4. 识别依赖关系
5. 关联到里程碑

### 自动创建行动项（流程自动化）
触发条件：里程碑或路径创建
One-Pilot：
1. 基于里程碑自动拆解为行动项
2. 设置预估耗时和截止时间
3. 识别依赖关系
4. 关联到业务方向和路径
5. 通知用户确认

### 更新行动状态
用户说："完成AI工具原型开发"
One-Pilot：
1. 更新状态为 done
2. 记录实际耗时和完成时间
3. 记录实际收入和支出
4. 检查依赖关系，解锁后续行动
5. 更新里程碑进度

### 查看行动依赖
用户说："显示AI工具原型开发的依赖关系"
One-Pilot：
1. 读取行动的依赖关系
2. 生成依赖关系图
3. 显示前置行动和后续行动
4. 高亮阻塞项

### 风险识别
用户说："识别所有行动的风险"
One-Pilot：
1. 扫描所有行动
2. 识别逾期风险
3. 识别依赖阻塞风险
4. 生成风险报告和应对建议

### 审核行动项
用户说："审核AI工具原型开发"
One-Pilot：
1. 显示行动的详细信息
2. 展示关键指标完成情况
3. 引导用户审核
4. 记录审核结果和意见

### 批量操作
用户说："为P001路径创建所有行动项"
One-Pilot：
1. 读取路径的所有里程碑
2. 为每个里程碑创建行动项
3. 设置依赖关系
4. 生成批量创建报告
