# 业务流程管理

## 流程模板

### 标准流程：商业框架构建（6阶段）
流程ID: STD-001
流程名称: 商业框架构建标准流程
阶段数: 6
创建时间: 2025-01-15

#### 阶段1: 系统初始化
- 阶段ID: PHASE-001
- 阶段名称: 系统初始化
- 描述: 初始化 One-Pilot 系统，配置基础信息
- 预计耗时: 1天
- 前置条件: 无
- 后续阶段: 阶段2
- 自动化任务:
  - 创建工作目录
  - 复制模板文件
  - 配置基础信息

#### 阶段2: 构建商业模型
- 阶段ID: PHASE-002
- 阶段名称: 构建商业模型
- 描述: 定义愿景、使命、价值观，构建商业模式画布
- 预计耗时: 3天
- 前置条件: 阶段1完成
- 后续阶段: 阶段3
- 自动化任务:
  - 创建 business_model.md
  - 引导填写商业模型
  - 关联战略目标

#### 阶段3: 拆解实现路径
- 阶段ID: PHASE-003
- 阶段名称: 拆解实现路径
- 描述: 将业务方向拆解为可执行的实现路径
- 预计耗时: 5天
- 前置条件: 阶段2完成
- 后续阶段: 阶段4
- 自动化任务:
  - 创建 paths.md
  - 拆解业务方向为路径
  - 设置里程碑和依赖关系

#### 阶段4: 创建任务跟踪
- 阶段ID: PHASE-004
- 阶段名称: 创建任务跟踪
- 描述: 为每个里程碑创建具体的行动项
- 预计耗时: 3天
- 前置条件: 阶段3完成
- 后续阶段: 阶段5
- 自动化任务:
  - 创建 actions.md
  - 为里程碑创建行动项
  - 关联路径和里程碑

#### 阶段5: 外部信号感知
- 阶段ID: PHASE-005
- 阶段名称: 外部信号感知
- 描述: 配置外部信号监控，识别市场机会和威胁
- 预计耗时: 2天
- 前置条件: 阶段4完成
- 后续阶段: 阶段6
- 自动化任务:
  - 创建 external_signals.md
  - 配置监控关键词
  - 初始化信号扫描

#### 阶段6: 综合视图
- 阶段ID: PHASE-006
- 阶段名称: 综合视图
- 描述: 生成业务全景视图，展示从战略到执行的完整关联
- 预计耗时: 1天
- 前置条件: 阶段5完成
- 后续阶段: 无
- 自动化任务:
  - 生成业务全景视图
  - 导出为 Markdown 或 PDF
  - 验证框架完整性

## 流程自动化规则

### 自动创建行动项
- 触发条件: 路径或里程碑创建
- 规则: 为每个里程碑自动创建 1-3 个行动项
- 配置: enabled/disabled

### 自动关联关系
- 触发条件: 业务方向、路径、行动项创建
- 规则: 自动创建关联关系
- 配置: enabled/disabled

### 自动推进阶段
- 触发条件: 前置阶段完成
- 规则: 自动启动下一阶段
- 配置: enabled/disabled

### 自动提醒
- 触发条件: 阶段超时、里程碑延期
- 规则: 自动发送提醒
- 配置: enabled/disabled

## 使用说明

### 启动标准流程
用户说："开始商业框架构建流程"
One-Pilot：
1. 加载标准流程模板
2. 创建流程实例
3. 开始阶段1：系统初始化
4. 引导用户完成每个阶段
5. 自动推进到下一阶段

### 创建自定义流程
用户说："创建自定义流程"
One-Pilot：
1. 引导用户定义流程名称和描述
2. 逐步添加阶段
3. 设置自动化规则
4. 保存为自定义流程模板

### 查看流程状态
用户说："查看当前流程状态"
One-Pilot：
1. 读取当前流程实例
2. 显示当前阶段和进度
3. 展示后续阶段
4. 高亮阻塞项

### 暂停/恢复流程
用户说："暂停当前流程"
One-Pilot：
1. 更新流程状态为 paused
2. 记录暂停时间
3. 保存当前进度

用户说："恢复流程"
One-Pilot：
1. 更新流程状态为 in_progress
2. 从暂停点继续
3. 提醒后续任务

### 配置流程自动化
用户说："配置流程自动化"
One-Pilot：
1. 显示自动化规则列表
2. 引导用户启用/禁用规则
3. 设置触发条件
4. 保存配置
