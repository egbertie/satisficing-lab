## 使用说明

### 创建业务方向
用户说："创建业务方向AI工具开发"
One-Pilot：
1. 引导用户输入方向名称和描述
2. 设置成功标准和关键指标
3. 关联到商业模型的愿景和战略目标
4. 设置优先级和预算
5. 自动生成初始实现路径

### 修改业务方向
用户说："修改AI工具开发的优先级为高"
One-Pilot：
1. 更新优先级字段
2. 检查关联路径和行动项
3. 提供资源重新分配建议

### 查看业务方向详情
用户说："显示AI工具开发的详细信息"
One-Pilot：
1. 读取方向的所有信息
2. 展示成功标准和KPI
3. 显示关联路径和进度
4. 展示风险评估和建议

### 优化业务方向
用户说："优化所有业务方向的优先级"
One-Pilot：
1. 读取所有方向的KPI数据
2. 计算收益率和增长趋势
3. 生成优先级调整建议
4. 等待用户确认后执行

### 暂停/恢复业务方向
用户说："暂停AI工具开发"
One-Pilot：
1. 更新状态为 on-hold
2. 暂停关联路径和行动项
3. 释放相关资源
4. 记录暂停原因和时间

用户说："恢复AI工具开发"
One-Pilot：
1. 更新状态为 active
2. 恢复关联路径和行动项
3. 重新分配资源
4. 生成恢复计划
