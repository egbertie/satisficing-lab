# info-intake

> **中文名**: 信息摄入系统
> **定位**: 外部信息的智能筛选、分类、学习与内化机制
> **版本**: V1.0
> **日期**: 2026-04-25

---

## 一、产品概述

### 1.1 解决什么问题

**场景**: 每天面对海量信息——
- 几十个公众号文章
- 十几封邮件
- 几条新闻推送
- 几个行业报告
- 各种"必看""重磅"

**问题**: 
- 信息过载，不知道哪些该读
- 读了很多，但没记住
- 记住了，但没内化
- 内化了，但没用起来

**信息摄入系统**: 筛选→阅读→提取→内化→应用，五步闭环。

### 1.2 核心流程

```
信息源 → [防火墙筛选] → 优先级标记 → [深度阅读] → 核心提取 → [内化写入] → 知识资产
```

### 1.3 防火墙规则

| 规则 | 作用 | 示例 |
|:-----|:-----|:-----|
| **时效性** | 只看最新/最相关 | 超过3个月的文章降级 |
| **信源质量** | 优先权威来源 | 学术论文 > 行业报告 > 自媒体 |
| **相关性** | 只保留与当前项目相关 | 标记"相关/待观察/不相关" |
| **去重** | 跳过重复内容 | 同一事件只保留最早/最完整的 |
| **能量评估** | 评估阅读价值 | 预估ROI，低价值跳过 |

## 二、快速启动

### 2.1 使用

**Step 1: 信息筛选**
```bash
python3 scripts/firewall-filter.py --input "今日待读列表" --criteria "时效+信源+相关"
# 输出: P0必读(3篇) + P1选读(5篇) + P2参考(10篇) + 忽略(20篇)
```

**Step 2: 深度阅读+提取**
```bash
python3 scripts/extract-core.py --input "文章URL/路径" --template "3句话+1理解+关联"
# 输出: 结构化笔记（自动写入memory）
```

**Step 3: 周度内化**
```bash
python3 scripts/weekly-synthesis.py --week "2026-W17"
# 输出: 本周知识图谱 + 可行动的洞察 + 待验证假设
```

## 三、核心脚本

### 3.1 防火墙筛选器 (firewall-filter.py)

自动评估信息优先级：
- P0: 与当前项目直接相关 + 权威来源 + 时效性强
- P1: 与长期目标相关 + 可靠来源
- P2: 拓展视野 + 任意来源
- P3: 不相关/重复/低质量 → 忽略

### 3.2 核心提取器 (extract-core.py)

强制输出格式：
```markdown
## [文章标题]
### 核心内容（3句话）
1. [要点1]
2. [要点2]
3. [要点3]

### 我的理解（1句话）
[这句话对我来说意味着什么]

### 关联知识
- [已有知识A] → [关系]

### 待确认
- [不确定的点]

--- 写入时间: [YYYY-MM-DD HH:MM] ---
```

### 3.3 周度合成器 (weekly-synthesis.py)

每周自动：
- 汇总本周所有提取笔记
- 识别重复主题（出现>2次的概念）
- 生成"本周知识图谱"
- 提取"可行动的洞察"
- 标记"待验证假设"

## 四、设计原则

1. **同步写入**: 读完一个→整理一个→写入一个，不是"先整理完再统一写"
2. **记忆即断点**: memory文件就是断点存档，写入即保存
3. **70%跳过**: 大部分信息不值得深入，筛选比阅读更重要
4. **输出驱动**: 只有能转化为"可行动的洞察"的信息才有价值
