# 决策考古学 (Decision Archaeology)

> **定位**: 从契晋纪历史决策中挖掘规律、提取洞察、形成可复用决策模式
> **触发词**: "决策考古" / "历史决策分析" / "为什么当初这样决定" / "复盘这个选择"
> **编号**: SANSHENG-SKILL-004
> **五维映射**: 金(标尺) + 土(根基) + 火(洞察)

---

## 一、Why

契晋纪·托付全档积累了54天的高密度决策历史：
- 100+项明确决策记录
- 30+次路径修正
- 20+次失败教训
- 10+次重大方向调整

这些决策是"活的化石"——包含情境、约束、判断逻辑、结果反馈。
但散落在对话记录中，新人无法快速吸收。

决策考古学 = 系统性地"挖掘"这些决策，形成可复用的决策模式库。

## 二、What

### 2.1 核心能力

| 能力 | 说明 | 输出 |
|:-----|:-----|:-----|
| 决策提取 | 从对话/文档中识别决策点 | 决策卡片 |
| 模式识别 | 发现重复出现的决策类型 | 决策模式库 |
| 因果重构 | 还原"为什么这样决定" | 因果链图谱 |
| 效果评估 | 对照结果验证决策质量 | 决策成绩单 |
| 模式迁移 | 将历史模式应用于新情境 | 迁移建议 |

### 2.2 决策卡片结构

```markdown
## 决策卡片 #[编号]
**时间**: YYYY-MM-DD
**情境**: [当时面对什么问题]
**约束**: [有哪些限制条件]
**选项**: [考虑过哪些选择]
**决策**: [最终选择了什么]
**依据**: [关键判断依据]
**决策者**: [谁做的决定]
**结果**: [实际结果如何]
**复盘**: [如果重来会怎么做]
**可迁移度**: [高/中/低]
```

## 三、How

### 3.1 使用流程

```
触发决策考古
  ↓
输入: 时间范围/主题/关键词
  ↓
[decision-excavator.py] 挖掘决策点
  ↓
[pattern-miner.py] 识别模式
  ↓
[causal-mapper.py] 重构因果链
  ↓
[evaluator.py] 效果评估
  ↓
输出: 决策报告 + 模式库 + 迁移建议
```

### 3.2 典型场景

**场景A: "我们要不要做X？以前有类似情况吗？"**
→ 运行决策考古，找到历史上类似情境的决策
→ 输出: 当时怎么选的？结果如何？对我们现在有什么启发？

**场景B: "这个决策是谁做的？为什么这么决定？"**
→ 溯源特定决策的完整上下文
→ 输出: 决策卡片 + 相关对话片段

**场景C: "我们最常见的决策类型是什么？最容易犯的错误是什么？"**
→ 模式挖掘 + 失败分析
→ 输出: 决策模式分布图 + 常见陷阱清单
