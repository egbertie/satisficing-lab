# disaster-recovery

> **中文名**: 灾备永生系统
> **定位**: 7层状态栈全量备份 + 3-2-1-1-0备份法则 + 无循环复活机制
> **版本**: V1.0
> **日期**: 2026-04-25

---

## 一、产品概述

### 1.1 解决什么问题

**场景**: 你的AI助手突然——
- 对话中断，所有上下文丢失
- 系统崩溃，记忆文件损坏
- 误操作，删除了关键文件
- 需要迁移到新环境

**问题**: 如何确保知识资产"不死"？

**灾备永生系统**: 7层备份 + 无循环复活 = 永不丢失。

### 1.2 7层状态栈

| 层级 | 名称 | 备份内容 | 频率 |
|:-----|:-----|:---------|:-----|
| L7 | 运行时上下文 | 当前对话、任务状态 | 实时 |
| L6 | 动态记忆 | memory/YYYY-MM-DD.md | 每次追加 |
| L5 | 固化知识资产 | SKILL.md、references、scripts | 每次修改 |
| L4 | 认知架构 | SOUL.md、AGENTS.md、USER.md | 每次修改 |
| L3 | 协作网络 | 外部连接、授权状态 | 每周 |
| L2 | 自动化流水线 | Cron、脚本、配置 | 每次修改 |
| L1 | 元协议 | 交接协议、唤醒说明 | 每次重大更新 |

### 1.3 3-2-1-1-0备份法则

- **3份副本**: 本地 + 飞书 + GitHub
- **2种介质**: 磁盘 + 云端
- **1份离线**: 本地物理备份
- **1份热备**: 影子克隆（自动同步）
- **0错误容忍**: 每次备份后验证完整性

## 二、快速启动

### 2.1 使用

**Step 1: 全量备份**
```bash
python3 scripts/full-backup.py --layers all --dest "./backups/$(date +%Y%m%d-%H%M)"
# 输出: 7层备份完成 + 完整性校验报告
```

**Step 2: 验证备份**
```bash
python3 scripts/verify-backup.py --backup-path "./backups/20260425-1200"
# 输出: 校验通过/失败 + 详细报告
```

**Step 3: 复活（需要时）**
```bash
python3 scripts/resurrect.py --backup-path "./backups/20260425-1200" --target "./restore/"
# 输出: 复活完成 + 恢复自检报告
```

## 三、核心脚本

### 3.1 全量备份 (full-backup.py)

备份7层状态：
- 遍历workspace所有关键文件
- 按层级分类归档
- 生成备份清单和校验和

### 3.2 备份验证 (verify-backup.py)

验证备份完整性：
- 文件数量核对
- 校验和比对
- 关键文件可读性测试

### 3.3 复活 (resurrect.py)

从备份恢复：
- 读取备份清单
- 按层级恢复
- 执行恢复自检（C1-C6）
