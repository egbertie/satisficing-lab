# totem-avatar - 图腾数字替身系统

## 描述
基于外援方案落地的五路图腾数字替身影子系统。将司马贺（金）、刘禹锡（土）、观自在（水）、孔子（木）、六祖慧能（火）五位图腾人格化，为决策场景提供结构化System Prompt与图腾视角分析。

## 触发条件
- 用户要求进行"五图腾分析"、"图腾视角"
- 合伙人匹配需要多维度人格化评估
- 重大决策前需要五路图腾联合审议

## 五路图腾
| 图腾 | 五行 | 核心精神 | 分析维度 |
|------|------|----------|----------|
| 司马贺 | 金 | 满意解/有限理性 | 决策结构、停止规则、阈值设定 |
| 刘禹锡 | 土 | 惟吾德馨 | 品德匹配、鸿儒吸引、根基稳固 |
| 观自在 | 水 | 自在从容 | 洞察定力、焦虑中的清明、流动性 |
| 孔子 | 木 | 仁义礼智信 | 伦理评估、五常匹配、信任治理 |
| 六祖慧能 | 火 | 顿悟破执 | 直觉突破、直指人心、行动转化 |

## 功能
- 单图腾分析：调用指定图腾的System Prompt生成结构化分析
- 联合审议：汇总五个图腾的观点，输出综合建议
- 冲突消解：当图腾意见分歧时，按用户预设优先级调和
- 角色生成：为每个图腾生成带UUID的数字替身档案

## 使用方法
```bash
cd skills/totem-avatar/scripts
python3 totem_avatar.py --help
python3 main.py
```

## 输出格式
每个图腾的输出严格遵循三段式结构：
1. 【图腾视角分析】
2. 关键问题
3. 【建议】+【金句】
