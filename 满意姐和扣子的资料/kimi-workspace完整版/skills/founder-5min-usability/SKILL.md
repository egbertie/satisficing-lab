# Founder 5-Min Usability — 创始人5分钟可用性检验

> **底层身份宪章约束**。蓝军Skeptor-7：每个代码资产必须能被焦虑的创始人5分钟内看懂并用上，否则标为`半成品`，禁止宣称FIN。

## 核心假设

**创始人的状态**：
- 焦虑（不是悠闲学习的心态）
- 时间碎片化（不是连续2小时的深度阅读时间）
- 注意力稀缺（同时处理10件事）
- 技术背景不确定（不一定是程序员）
- 需求明确："我现在就要用，别让我读说明书"

**如果创始人不能5分钟内上手 → 它就是半成品，不管代码多优雅。**

---

## 5分钟检验协议（精确到秒）

### 第0分钟（0:00-0:30）— 第一眼印象

```
[0分钟检查]
□ 文件/目录命名直观（不是abc123、temp、final_final）
□ 有README或入口文件在最外层
□ 打开第一眼能看到"这是什么"和"怎么开始"
□ 没有需要解码的缩写或内部黑话
```

**判定**：任一"否" → 0分钟淘汰，标记为[看不懂]

### 第1分钟（0:30-1:30）— 找到入口

```
[1分钟检查]
□ 有明确的"快速开始"段落或入口
□ 知道第一步该运行哪个文件/命令
□ 依赖列表清晰（如果需要安装）
□ 有"如果只想试一下"的最小示例
```

**判定**：任一"否" → 1分钟淘汰，标记为[找不到门]

### 第2-3分钟（1:30-3:30）— 成功运行

```
[3分钟检查]
□ 按照文档指示执行，无报错
□ 第一次运行就能看到有意义的结果/输出
□ 不需要修改配置文件就能跑起来（或配置有默认值）
□ 错误信息友好（如果出错，知道下一步）
```

**判定**：任一"否" → 3分钟淘汰，标记为[跑不通]

### 第4-5分钟（3:30-5:00）— 理解价值

```
[5分钟检查]
□ 看到输出后，知道这个东西解决什么问题
□ 知道下一步可以怎么调整/扩展
□ 有信心把它用在实际工作里
□ 不觉得"这东西还需要我再折腾半天"
```

**判定**：任一"否" → 5分钟淘汰，标记为[不知道有什么用]

## 检验执行方法

### 方法A：自我检验（开发者自己测）

1. 假设自己是焦虑的创始人
2. 清空大脑，假装第一次看到
3. 严格计时5分钟
4. 记录每一分钟的卡点
5. 修复卡点，重新测，直到5分钟通过

### 方法B：抽样检验（蓝军审计）

```
[抽样检验报告]
被测资产: {路径}
检验日期: YYYY-MM-DD
检验人: {蓝军/满意姐}

[0分钟] 状态: ✅/❌ | 问题: {描述}
[1分钟] 状态: ✅/❌ | 问题: {描述}
[3分钟] 状态: ✅/❌ | 问题: {描述}
[5分钟] 状态: ✅/❌ | 问题: {描述}

总分: X/4
结论: ✅可用 / 🟡有条件可用 / 🔴半成品
整改项: {清单}
```

## 快速改进清单（常见卡点修复）

### 命名灾难修复
❌ `process_aibot.py` → ✅ `process_ai_articles.py`
❌ `final_v2_REAL.py` → ✅ `generate_daily_report.py`
❌ `utils/` → ✅ `helpers/` 或保留但要说明

### 入口缺失修复
❌ 无README → ✅ 添加 `README.md` 含：
  - 一句话描述
  - 安装命令（一行）
  - 运行命令（一行）
  - 预期输出示例

### 依赖地狱修复
❌ "安装依赖" → ✅ "pip install -r requirements.txt"（提供requirements.txt）
❌ 需要配置文件 → ✅ 提供 `config.example.json` + 复制命令

### 零示例修复
❌ 只有功能描述 → ✅ 提供 `examples/` 目录，含最小可运行示例

## 反模式（常见失败原因）

❌ **文档和代码分离** — README在A目录，代码在B目录
❌ **假设用户知道上下文** — "像平时一样运行"（用户不知道"平时"是什么）
❌ **需要读3个文件才能开始** — 快速开始应该在一个文件内完成
❌ **配置地狱** — 需要手动填写10个配置项才能跑
❌ **输出不可读** — 打印一堆日志，找不到结果在哪
❌ **依赖未声明** — 运行时报错缺包，文档里没提

---

## 最佳实践

✅ **一文件入门** — 所有入门信息集中在README或一个入口文件
✅ **复制粘贴即用** — 关键命令可直接复制执行
✅ **默认值覆盖80%场景** — 不配置也能跑，配置是为了优化
✅ **错误即向导** — 报错时告诉用户该做什么，不只是报错误码
✅ **示例即文档** — 一个完整的示例胜过10页API说明
