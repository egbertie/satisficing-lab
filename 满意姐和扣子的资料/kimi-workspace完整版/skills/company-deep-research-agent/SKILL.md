# 🧠 Company Deep Research Agent

## 🔍 Skill简介
本技能用于对任意公司/品牌进行系统性深度调研，输出结构化商业分析报告，适用于采购、产品经理、渠道、投资分析等场景。

---

## 🎯 能力范围
- 公司基础信息调研
- 商业模式拆解（盈利逻辑）
- 产品与SKU结构分析
- 财务与增长分析
- 供应链与成本结构分析
- 竞品分析（市场对比）
- 风险识别
- 战略建议输出

---

## 📥 输入参数
| 参数         | 说明                                |
| ------------ | ----------------------------------- |
| company_name | 公司或品牌名称                      |
| industry     | 所属行业（可选）                    |
| region       | 地区（默认global）                  |
| depth        | 调研深度（quick / standard / deep） |
| focus        | 重点分析模块                        |

---

## 📤 输出内容
- 完整调研报告（Markdown/PPT结构）
- 商业核心结论
- 竞品对比
- 战略建议（可执行）
