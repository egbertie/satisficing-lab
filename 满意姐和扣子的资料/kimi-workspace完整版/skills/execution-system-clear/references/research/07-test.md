# James Clear Skill 快速验证测试

## 测试问题
"我总是三分钟热度，怎么才能坚持？"

---

## 回答（使用Skill框架）

**诊断问题：为什么你之前的尝试失败了？**

不是意志力不够，而是你的系统设计让习惯太难启动。你可能设定了一个"大目标"（每天跑步30分钟、每天读书1小时），但大脑天然抗拒阻力。

**核心框架：四大行为改变法则**

让我帮你拆解一个更可持续的方案：

| 法则 | 应用 |
|------|------|
| **让它显而易见** | 执行意图："我将在早上7点在客厅做5个俯卧撑" |
| **让它有吸引力** | 诱惑捆绑：只在做这件事时听你最喜欢的播客 |
| **让它容易** | 从2分钟开始——不是"跑步30分钟"，而是"穿上跑鞋" |
| **让它令人满足** | 完成后在日历上画个✓，即时视觉反馈 |

**具体路径：试试两分钟规则**

1. 把目标降到荒谬的小："只读1页书"
2. 做完后问自己："要不要再来一点？"（大多数时候你会继续）
3. 如果不想做，也没关系——你只需要做这2分钟

**一句话收尾：身份投票**

Every action is a vote for the type of person you wish to become.

你不需要每次都完美。今天只做了2分钟，这也是一次投票——投给了"一个在培养习惯的人"。把票数拉长到一年，不需要每天都赢。

## 评估结果

### ✅ 四大法则
- 明显：使用了四列表格，覆盖 Obvious / Attractive / Easy / Satisfying
- 隐含：两分钟规则是"Easy"法则的具体应用

### ✅ 身份投票
- 直接引用："Every action is a vote for the type of person you wish to become."
- 应用：解释"2分钟也是一次投票"，用宽容的方式处理失败

### ✅ 温和教练式语气
- 用"你"而非"你应该"
- 承认"不想做也没关系"
- 不说教，用"试试"而非"必须"

### 备注
- 回答结构符合 `[诊断] → [框架] → [路径] → [收尾]` 格式
- 给了工具箱选项（两分钟规则、习惯堆叠等）
- 没有使用绝对化词汇（用了"大多数时候"、"Generally speaking"风格）
