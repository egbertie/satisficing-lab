# 五维决策手册

> **用途**: 五维决策体系的详细操作指南
> **适用**: 面临复杂决策的个人/团队/组织
> **阅读时间**: 15分钟

---

## 一、五维决策流程

### Step 1: 土（根基）—— 检查信任基础

**核心问题**:
- 这个决策涉及哪些人？
- 彼此的信任关系如何？
- 是否有"聚贤才为伍"的基础？

**行动**:
- 列出所有利益相关者
- 评估信任等级（1-10分）
- 如果信任基础<5分，先修复关系再决策

### Step 2: 金（标尺）—— 设定满意标准

**核心问题**:
- 什么是"足够好"？不是"最好"
- 满意的标准是什么？
- 时间和资源的约束是什么？

**行动**:
- 列出3个"满意"的标准
- 列出3个"不满意"的红线
- 确认：不求最优，但求最适

### Step 3: 水（流动）—— 灵活调整

**核心问题**:
- 当前方向对吗？
- 有没有更好的路径？
- 信息是否充分？

**行动**:
- 列出至少2个备选方案
- 评估每个方案的ROI
- 选择"足够好"而非"理论上最好"的

### Step 4: 木（生长）—— 伦理检查

**核心问题**:
- 符合仁义礼智信吗？
- 对团队/组织/社会的长期影响？
- 有没有人在不知情的情况下被伤害？

**行动**:
- 用"孔子视角"审视决策
- 问自己："如果我公开这个决策，会感到羞愧吗？"

### Step 5: 火（转化）—— 直觉验证

**核心问题**:
- 直觉怎么说？
- 身体有什么反应？（紧张/放松）
- 顿悟的瞬间是什么？

**行动**:
- 闭眼30秒，感受直觉
- 记录第一反应（不要过滤）
- 如果直觉和理性冲突，暂停决策

### Step 6: 交汇—— 五维综合评分

| 维度 | 得分(1-10) | 说明 |
|:-----|:----------:|:-----|
| 土（根基） | __ | 信任基础 |
| 金（标尺） | __ | 满意标准 |
| 水（流动） | __ | 方向灵活 |
| 木（伦理） | __ | 伦理合规 |
| 火（转化） | __ | 直觉确认 |
| **总分** | __ | |

**判断**:
- 总分≥35分 → 可以推进
- 任一维度<5分 → 需要补强该维度
- 火（直觉）<5分 → 强烈建议暂停

## 二、12类型冲突快速匹配

**使用步骤**:
1. 描述你的冲突场景（3句话）
2. 对照12类型，找到最匹配的类型
3. 查看该类型的五维权重
4. 重点强化权重最高的维度

**示例**:
场景："我和合伙人在技术路线上争执不下，A主张稳健，B主张激进"
匹配：Type03 方向分歧（水权重最高）
行动：重点检查"水"维度——灵活调整方向，寻找第三条路

## 三、常见误区

| 误区 | 真相 |
|:-----|:-----|
| "五维都要满分" | 不需要，总分≥35即可 |
| "直觉不可靠" | 火（直觉）是重要维度，不可忽视 |
| "伦理可以妥协" | 木（伦理）是底线，不可突破 |
| "满意=凑合" | 满意解=在约束下做到最好，不是凑合 |
