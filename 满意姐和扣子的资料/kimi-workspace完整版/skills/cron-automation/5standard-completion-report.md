## S4: 自动化集成 ✅

### 错误恢复机制

**配置文件**: `config/recovery.json`

#### 恢复策略

| 策略 | 重试次数 | 间隔 | 适用任务 |
|------|----------|------|----------|
| default | 3次 | 60s, 300s, 600s | task_02, task_04, task_06, task_08 |
| aggressive | 5次 | 30s, 60s, 120s, 300s, 600s | task_01, task_10 |
| conservative | 1次 | 300s | task_03, task_09 |
| notification_only | 0次 | - | task_05, task_07 |

#### 自动恢复流程实现

```python
# executor.py _handle_failure() 方法
1. 记录错误日志
2. 获取任务专属恢复策略
3. 检查重试次数
4. 计算下次重试时间
5. 调度重试任务(threading.Timer)
6. 超限则暂停任务并发送告警
```

| task_04 | token-monitor | */15 * * * * | default | P1 |
| task_05 | log-cleanup | 0 3 * * 0 | notification_only | P2 |

## 使用指南

### 快速开始

```bash
# 进入工作目录
cd /root/.openclaw/workspace/skills/cron-automation

# 运行健康检查
python3 scripts/health-check.py

# 查看任务状态
python3 scripts/executor.py status

# 手动执行任务
python3 scripts/executor.py run task_01

# 启用/禁用任务
python3 scripts/executor.py enable task_01
python3 scripts/executor.py disable task_01

# 更新监控面板
python3 scripts/monitor.py dashboard

# 运行对抗测试
cd tests/adversarial && ./run_tests.sh
```
