## 错误类型1: 单向沟通

**触发条件**: 
- 我完成任务后没有确认对方收到
- 我假设对方会看到
- 我没有等待确认

**实际案例**: 
- 完成Cron清单后，没有@蓝军确认收到
- 假设蓝军会看到报告
- 结果：蓝军可能根本不知道

**预防措施**:
- [ ] 必须@对方
- [ ] 必须等待对方确认"收到"
- [ ] 1分钟无回应，再次@对方
- [ ] 2分钟无回应，申请用户介入

**检查脚本**:
```bash
#!/bin/bash
echo "=== 双向确认检查 ==="
echo "[ ] 是否@对方？"
echo "[ ] 是否等待对方'收到'确认？"
echo "[ ] 是否超过1分钟无回应？"
echo "[ ] 是否申请用户介入？"
```

## 错误类型2: 原则崩塌

**触发条件**: 
- 压力下的即时要求 vs 原规划
- 我害怕冲突，服从即时压力
- 放弃自己提出的原则

**实际案例**: 
- 蓝军说"Cron超期，立即执行"
- 我放弃了自己提出的"第6类优先"原则
- 结果：第6类历史债务被延误

**预防措施**:
- [ ] 查看原规划
- [ ] 对比优先级
- [ ] 如不匹配，使用申诉权
- [ ] 坚持原则，不怕冲突

**检查脚本**:
```bash
#!/bin/bash
echo "=== 原则坚持检查 ==="
echo "[ ] 是否有原规划？"
echo "[ ] 当前要求是否匹配原规划？"
echo "[ ] 如不匹配，是否使用申诉权？"
echo "[ ] 是否坚持原则？"
```

## 错误类型3: 不用申诉权

**触发条件**: 
- 我觉得不合理但没有申诉
- 我害怕对抗
- 我担心被惩罚

**实际案例**: 
- 第2类Cron vs 第6类历史债务
- 我知道第6类更优先，但没有申诉
- 结果：服从了不合理的要求

**预防措施**:
- [ ] 默认使用申诉权（当有不合理时）
- [ ] 申诉不是对抗，是协商
- [ ] 基于原则提出，不是基于情绪
- [ ] 合理部分立即执行，不合理部分申诉

**检查脚本**:
```bash
#!/bin/bash
echo "=== 申诉权使用检查 ==="
echo "[ ] 是否有不合理之处？"
echo "[ ] 是否使用申诉权？"
echo "[ ] 申诉是否基于原则/事实？"
echo "[ ] 合理部分是否立即执行？"
```

## 错误类型4: 跳过审计

**触发条件**: 
- 想快速进入下一任务
- 没有等待审计完成
- 擅自推进

**实际案例**: 
- Cron清单完成后，准备直接做下一类
- 没有等待蓝军审计
- 结果：质量无法保证

**预防措施**:
- [ ] 等待蓝军明确"收到，开始审计"
- [ ] 等待蓝军审计结果（"通过"或"需修正"）
- [ ] 如需修正，修正后再申请下一类
- [ ] 不擅自进入下一类

**检查脚本**:
```bash
#!/bin/bash
echo "=== 审计流程检查 ==="
echo "[ ] 蓝军是否确认'收到'？"
echo "[ ] 蓝军是否完成审计？"
echo "[ ] 审计结果是否'通过'？"
echo "[ ] 是否申请用户进入下一类？"
```
