## 一、五大冲突类型识别框架

### 类型识别决策树

```
合伙人冲突类型识别
│
├─ 问题1：冲突发生在哪个阶段？
│   ├─ 众筹/天使轮前 → 可能是【类型一：资金入口风险】
│   ├─ 天使/种子轮 → 可能是【类型二：股权代持风险】
│   ├─ Pre-A/A轮 → 可能是【类型三：技术合伙人被架空】
│   ├─ A轮后 → 可能是【类型四：控制权争夺】
│   └─ Pre-IPO → 可能是【类型五：IPO合规风险】
│
└─ 问题2：冲突的核心表现是什么？
    ├─ 众筹资金被挪用 → 【类型一】
    ├─ 股权代持被发现 → 【类型二】
    ├─ 被转为有限合伙LP/被稀释 → 【类型三】
    ├─ 被董事会免职/新项目被否 → 【类型四】
    └─ IPO被问询/股权不清晰 → 【类型五】
```

## 三、合伙人匹配度评估模型

### 3.1 三维度兼容性测试

| 维度 | 测试问题 | 绿色通过 | 黄色预警 | 红色警报 |
|------|----------|----------|----------|----------|
| **时间偏好** | "你期望几年内实现盈利？" | 10年+ | 5-7年 | 3年以下 |
| **风险容忍** | "技术失败需重新投入500万，你怎么决策？" | 支持迭代 | 协商后决定 | 要求止损 |
| **技术估值** | "技术投入应占收入比例多少？" | >15% | 5-10% | <5% |

**评分标准**:
- 3个绿色 = 理想合伙人，建议合作
- 2个绿色 = 需要协议约束，谨慎合作
- 1个或0个绿色 = 高风险组合，建议放弃

## 四、分家策略选择框架

### 4.1 分家方式对比

| 方式 | 张雪模式 | 硅谷模式 | 适用场景 |
|------|----------|----------|----------|
| **股权处理** | 净身出户 | 股权回购 | 技术声誉>股权价值 |
| **竞业禁止** | 无（体面分手） | 有 | 需要保持行业声誉 |
| **舆论策略** | 低调处理 | 可能公开 | 需要维护个人品牌 |
| **重建方式** | 自然人独资73% | 新创业项目 | 二次创业 |

### 4.2 决策树

```
面临分家决策
│
├─ 问题1：技术声誉 vs 股权价值
│   ├─ 技术声誉 > 股权价值 → 张雪模式（净身出户，保全声誉）
│   └─ 股权价值 > 技术声誉 → 股权回购模式
│
├─ 问题2：是否有竞业禁止
│   ├─ 有 → 评估竞业范围是否合理
│   └─ 无 → 自由重建
│
└─ 问题3：重建时的股权设计
    ├─ 持股≥66.7%
    ├─ 担任法定代表人
    └─ 自然人独资（二次创业首选）
```
