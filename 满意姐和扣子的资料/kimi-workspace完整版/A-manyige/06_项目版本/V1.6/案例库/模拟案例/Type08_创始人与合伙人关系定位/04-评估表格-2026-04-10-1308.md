# 创始人与合伙人关系定位 —— 评估工具包

> **服务代号**：Type-8 关系锚  
> **版本**：V1.0  
> **生成时间**：2026-04-10 13:08

---

## 工具一：合伙人关系定位清晰度评分表

### 评估说明

**适用对象**：合伙人团队（2-4 人）的"关系定位"健康度评估
**评估周期**：建议在每次融资前、新合伙人加入前、或出现重大冲突时进行评估
**评估方式**：所有合伙人分别自评 + 互评，教练汇总后计算综合得分
**总分**：100 分

---

### 评分维度

| 维度 | 权重 | 评分标准 | 得分 |
|------|------|----------|------|
| **D1：CEO/最高决策者明确性** | 20 分 | 公司已明确书面约定一位最高决策者（CEO/总经理），且所有合伙人一致认可，得 20 分；有约定但部分合伙人仍有异议，得 10 分；完全没有明确 CEO 或存在"双头领导"，得 0 分。 | |
| **D2：角色-能力匹配度** | 15 分 | 每位合伙人的角色定位与其能力长板高度匹配（如技术天才负责产品、销售高手负责市场），得 15 分；基本匹配但存在明显的"能力错位"或"情感安排"，得 8 分；严重不匹配（如让不擅管理的联合创始人强行担任 COO），得 0 分。 | |
| **D3：关系叙事清晰度** | 15 分 | 合伙人之间能够明确区分"私人关系叙事"（兄弟/朋友/战友）与"商业关系叙事"（合伙人/股东/高管），且不会混用，得 15 分；能区分但偶尔会混淆，得 8 分；完全混同（如经常用"当初一起吃苦"来替代商业论证），得 0 分。 | |
| **D4：冲突处理能力** | 15 分 | 合伙人之间建立了"对事不对人"的冲突处理文化，出现分歧时能够聚焦问题本身而非情感攻击，得 15 分；偶有情感化表达但能修复，得 8 分；冲突经常被上升为情感背叛或信任危机，得 0 分。 | |
| **D5：新成员融入支持度** | 15 分 | 创始合伙人团队对新加入成员持开放态度，愿意分享信息、明确边界、让渡部分非正式权力，得 15 分；态度中立但偶有排他行为，得 8 分；明显封闭，形成"创始团队 vs 外人"的二元对立，得 0 分。 | |
| **D6：关系框架进化意愿** | 10 分 | 合伙人团队认同"关系规则需要随企业发展而动态升级"，并愿意每年进行至少一次正式的合伙人关系复盘，得 10 分；理论上认同但实践中回避，得 5 分；坚决反对任何改变，认为"我们以前那样挺好的"，得 0 分。 | |
| **D7：外部专业支持接受度** | 10 分 | 合伙人团队愿意在必要时引入外部教练、顾问或 mediator 来帮助处理关系议题，得 10 分；勉强接受但内心抗拒，得 5 分；完全排斥外部介入，认为"这是我们自己的事"，得 0 分。 | |

---

### 阈值说明与健康等级

| 总分 | 健康等级 | 含义 | 建议动作 |
|------|----------|------|----------|
| **85-100 分** | 🟢 健康 | 合伙人关系定位清晰，角色分工合理，能够支撑企业持续发展 | 维持现有模式，每年进行一次关系复盘 |
| **65-84 分** | 🟡 亚健康 | 存在 1-3 个定位模糊点，虽未爆发冲突，但已构成隐患 | 3 个月内组织一次合伙人定位工作坊，优先澄清 CEO 和权责边界 |
| **45-64 分** | 🟠 病态 | 合伙人关系定位已严重阻碍企业发展，冲突可能随时爆发 | 立即启动深度诊断，必要时引入第三方 facilitator |
| **≤44 分** | 🔴 高危 | 合伙人关系定位处于崩溃边缘，企业生存受到直接威胁 | 紧急启动危机干预，创始人必须亲自主导关系重构或拆分谈判 |

### 标杆案例对照

| 标杆 | 关键教训 | 本表映射 |
|------|----------|----------|
| **某同居式创业** | 创始人与合伙人情感高度混同，未能区分"室友""兄弟"与"合伙人"三重角色，导致任何分歧都被情感化 | D3 关系叙事清晰度 |
| **某权责不清** | 两位联合创始人均认为自己是"实际 CEO"，公司存在事实上的双头领导，战略反复、执行瘫痪 | D1 CEO/最高决策者明确性 |
| **某关系恶化** | 原有合伙人团队极度排外，新加入的 CFO 和 CTO 均在一年内离职，错失最佳发展窗口 | D5 新成员融入支持度 |

## 工具二：权责边界健康度评估表

### 评估说明

**适用对象**：合伙人团队的"权责边界"健康度评估，重点审查合伙协议与公司章程的落地性
**评估周期**：公司成立时（基线评估）、每次融资前、出现重大权责争议时
**评估方式**：外部教练/顾问主导评估，合伙人团队提供文件并进行访谈确认
**总分**：100 分

---

### 评分维度

| 维度 | 权重 | 评分标准 | 得分 |
|------|------|----------|------|
| **D1：合伙协议的权责清晰度** | 20 分 | 合伙协议中明确约定了每位合伙人的具体职责范围、KPI 指标、决策权限（如人事权、财务权、合同签署权），得 20 分；有约定但过于笼统（如仅写'负责市场'），得 10 分；完全没有书面约定或约定流于形式，得 0 分。 | |
| **D2：决策僵局处理机制** | 15 分 | 合伙协议或公司章程中明确规定了"合伙人出现重大分歧且无法达成一致时的最终裁决机制"（如 CEO 一票否决权、董事会投票、外部仲裁），得 15 分；有约定但可操作性差，得 8 分；完全没有约定，得 0 分。 | |
| **D3：日常决策的分权程度** | 15 分 | 日常运营决策（如单笔 10 万元以下的开支、非核心岗位招聘）有明确授权，不需要所有合伙人事事商量，得 15 分；部分授权但边界模糊，得 8 分；几乎所有决策都需要合伙人集体商议，得 0 分。 | |
| **D4：岗位与股权的匹配性** | 15 分 | 合伙人的股权比例与其职责范围、时间投入、业绩贡献基本匹配，不存在"持股多但不干活"或"干活多但持股少"的极端失衡，得 15 分；存在轻微失衡但能解释，得 8 分；严重失衡且已成为冲突焦点，得 0 分。 | |
| **D5：退出机制的可执行性** | 15 分 | 合伙协议中已约定清晰的合伙人退出机制（触发条件、股权回购定价、付款节奏、竞业限制），且条款经过律师审核，得 15 分；有约定但关键条款模糊（如定价方式未明确），得 8 分；完全没有退出机制约定，得 0 分。 | |
| **D6：引入机制的可执行性** | 10 分 | 合伙协议中已约定新合伙人加入的决策流程、股权授予标准、Vesting 规则，得 10 分；有约定但不完善，得 5 分；完全没有约定，得 0 分。 | |
| **D7：文件更新频率** | 10 分 | 合伙协议/公司章程在企业发展的关键节点（融资、股权变更、业务转型）都进行了同步更新，得 10 分；基本未更新或更新严重滞后于实际运营，得 0 分。 | |

---

### 阈值说明与健康等级

| 总分 | 健康等级 | 含义 | 建议动作 |
|------|----------|------|----------|
| **85-100 分** | 🟢 健康 | 权责边界清晰，决策机制有效，合伙协议具备较强的落地约束力 | 维持现有模式，在关键节点持续更新协议 |
| **60-84 分** | 🟡 亚健康 | 存在 1-3 个结构性风险点，可能在企业发展中被触发 | 3 个月内针对性整改，优先处理 D1/D2/D5 |
| **35-59 分** | 🟠 病态 | 权责边界已对企业运营构成实质性障碍，合伙人冲突风险极高 | 必须暂停重大决策，6 个月内完成合伙协议重构 |
| **≤34 分** | 🔴 高危 | 权责结构处于崩溃边缘，极有可能爆发控制权争夺或团队分裂 | 立即启动危机干预，创始人必须亲自坐镇谈判 |

---

### 特别说明：各维度的"一票否决"红线

以下情况出现时，无论其他维度得分多高，**总体健康等级最多只能评为 🟠 病态**：

1. **D1 合伙协议的权责清晰度 = 0 分**：一份不写明权责的合伙协议，本质上就是一颗定时炸弹。
2. **D2 决策僵局处理机制 = 0 分**：没有僵局处理机制，意味着任何重大分歧都可能把企业拖入 paralysis。
3. **D5 退出机制的可执行性 = 0 分**：没有退出机制，合伙人一旦关系破裂，拆分成本将高到无法承受。

---

### 标杆案例对照

| 标杆 | 关键教训 | 本表映射 |
|------|----------|----------|
| **某权责不清** | 合伙协议只约定股权比例，未约定决策机制和分工边界，融资后因"谁当 CEO"争论三个月 | D1 + D2 |
| **某关系恶化** | 创始人因情感原因给予联合创始人过高股权，但后者实际贡献远低于股权比例，最终引发新合伙人不满 | D4 岗位与股权的匹配性 |
| **某同居式创业** | 两位创始人从未考虑过"如果有人要离开怎么办"，最终拆伙时因股权定价问题撕破脸 | D5 退出机制的可执行性 |

## 工具三：情感混同与公私边界风险评估表

### 评估说明

**适用对象**：创始人与联合创始人之间存在"前置情感关系"（同学、室友、前同事、亲友等）的创业团队
**评估周期**：建议每年评估一次，或在出现财务透明度质疑、新合伙人融入困难时立即评估
**评估方式**：所有合伙人自评 + 新加入合伙人/高管匿名参评，教练汇总分析
**总分**：100 分（得分越高，风险越低；得分越低，风险越高）

---

### 评分维度

| 维度 | 权重 | 评分标准 | 得分 |
|------|------|----------|------|
| **D1：财务账户分离度** | 20 分 | 公司账户与所有合伙人个人账户完全分离，不存在任何公私混用，得 20 分；偶有临时借用但能及时归还和说明，得 10 分；存在经常性的公私账户混用，得 0 分。 | |
| **D2：财务信息透明度** | 15 分 | 公司每月财务报表对所有合伙人完全透明，不存在"某合伙人独自掌握财务信息"的情况，得 15 分；基本透明但偶有延迟或省略，得 8 分；财务信息严重不透明，部分合伙人长期看不到真实账目，得 0 分。 | |
| **D3：报销规则公平性** | 15 分 | 所有合伙人的报销、差旅、招待费用适用统一标准和审批流程，不存在情感特权，得 15 分；标准存在但执行有偏心，得 8 分；完全没有统一标准，或存在明显的"双重标准"，得 0 分。 | |
| **D4：决策的情感干扰度** | 15 分 | 商业决策基本不受私人情感影响，合伙人之间能够"对事不对人"，得 15 分；偶有情感因素干扰，但能自我觉察和修正，得 8 分；商业决策频繁被"兄弟情义""当初一起吃苦"等情感叙事绑架，得 0 分。 | |
| **D5：工作和生活空间分离度** | 10 分 | 合伙人的工作关系和生活关系有相对清晰的边界（如不住在一起、不共用私人账户、家庭事务不介入公司事务），得 10 分；边界模糊但尚有基本区分，得 5 分；工作与生活高度混同（如同居式创业、家庭成员深度介入公司日常），得 0 分。 | |
| **D6：情感债务的显性化程度** | 10 分 | 合伙人之间不存在"说不出口的情感债务"，或已有的情感债务已经被公开讨论并达成了心理平衡，得 10 分；存在隐性情感债务但尚未影响重大决策，得 5 分；存在强烈的隐性情感债务（如"他当初辞职跟我创业，我一辈子欠他的"），且正在显著影响决策，得 0 分。 | |
| **D7：冲突的"情感升级率"** | 10 分 | 合伙人之间的冲突基本能够停留在"事情层面"，很少升级为"感情问题"或"信任危机"，得 10 分；冲突偶有情感升级，但事后能修复，得 5 分；几乎所有冲突最终都会演变成"你还当不当我是兄弟"式的情感对抗，得 0 分。 | |
| **D8：外部监督接受度** | 5 分 | 合伙人团队愿意接受外部审计、财务顾问或教练对公私边界的监督和建议，得 5 分；勉强接受，得 3 分；完全排斥外部监督，得 0 分。 | |

---

### 阈值说明与风险等级

| 总分 | 风险等级 | 含义 | 建议动作 |
|------|----------|------|----------|
| **85-100 分** | 🟢 低风险 | 公私边界清晰，情感混同程度低，财务透明度高 | 维持现有模式，每年例行评估 |
| **65-84 分** | 🟡 中风险 | 存在 1-2 个摩擦点，但通过规则建设可以化解 | 启动财务透明度建设和合伙人沟通工作坊 |
| **45-64 分** | 🟠 高风险 | 多个维度亮起红灯，情感混同已对企业治理构成实质性威胁 | 立即启动深度诊断，创始人必须亲自参与边界重构 |
| **≤44 分** | 🔴 极高风险 | 情感混同和公私边界失守极有可能引爆重大危机 | 建议启动危机干预，必要时聘请第三方审计和 mediator |

---

### 特别警示："情感-财务"崩溃组合

若某位合伙人或整个团队的评估结果同时满足以下任意组合，需立即升级为最高警戒：

**组合 A：财务黑洞型**
- D1 财务账户分离度 = 0 分
- D2 财务信息透明度 = 0 分
- **预示**：公司财务存在严重的公私混同和信息黑箱，极有可能在融资或审计时爆发合规危机，或因"钱"的问题导致信任崩塌。

**组合 B：情感绑架型**
- D4 决策的情感干扰度 = 0 分
- D6 情感债务的显性化程度 = 0 分
- D7 冲突的"情感升级率" = 0 分
- **预示**：合伙人之间的关系已被情感化叙事完全绑架，任何制度化尝试都会被视为情感背叛，企业决策质量将持续恶化。

**组合 C：生活-工作混同型**
- D5 工作和生活空间分离度 = 0 分
- D1 财务账户分离度 ≤ 5 分
- **预示**："同居式创业"的极端形态，私人生活与公司运营已经完全融为一体，拆分成本极高，关系破裂时极易演变为"全方位的战争"。

### 标杆案例对照

| 标杆 | 关键教训 | 本表映射 |
|------|----------|----------|
| **某同居式创业** | 两位创始人同住同办公，个人账户与公司账户不分，最终导致"谁先垫了多少钱"都成为争吵焦点 | D1 + D5 |
| **某关系恶化** | 创始人因"怕伤感情"而长期默许联合创始人的公私混同行为，新 CFO 入职后试图整改，却被视为"外人挑唆" | D3 + D4 + D8 |

## 评估工具包使用流程图

```
Step 1: 确定评估对象和时机
    ├─ 关系定位清晰度 → 合伙人团队，每年/融资前/冲突时
    ├─ 权责边界健康度 → 重点审查合伙协议和公司章程
    └─ 情感混同与公私边界 → 存在前置情感关系的团队优先

Step 2: 指定评估人和权重
    ├─ 所有核心合伙人必须参与
    ├─ 新加入合伙人/高管参与情感混同评估（匿名）
    ├─ 外部教练全程参与并提供交叉验证
    └─ 必要时引入律师和财务顾问

Step 3: 逐项打分并记录依据
    └─ 每个得分都需附 1-2 句话的事实依据

Step 4: 汇总总分并定位阈值
    └─ 输出红绿灯判定

Step 5: 制定针对性行动计划
    └─ 对黄灯/橙灯/红灯项，给出 30/60/90 天整改计划

Step 6: 教练复盘会议
    └─ 向合伙人团队汇报评估结果，讨论下一步资源配置
```
