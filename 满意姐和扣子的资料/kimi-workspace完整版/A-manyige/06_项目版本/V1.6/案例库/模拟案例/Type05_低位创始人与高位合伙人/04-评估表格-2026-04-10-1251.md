# 低位创始人与高位合伙人冲突决策 —— 评估工具包

> **服务代号**：Type-5 仰止之阶  
> **版本**：V1.0  
> **生成时间**：2026-04-10 12:51

---

## 工具一：股东协议与回购条款健康度评分表

### 评估说明

**适用对象**：初创公司（天使轮至 A 轮前后）的股东协议、合伙协议、投资协议中的回购与对赌条款
**评估周期**：明星合伙人入局前必评一次；入局后每年复评；融资前必须复评
**评估方式**：创始人 + 外部独立律师 + 教练联合填写，教练复核
**总分**：100 分

---

### 评分维度

| 维度 | 权重 | 评分标准 | 得分 |
|------|------|----------|------|
| **D1：回购触发条件合理性** | 15 分 | 回购触发条件限定为"公司未能在约定时间内完成下一轮融资"或"连续亏损达到约定金额"等客观事件，得 15 分；触发条件含主观判断（如"合伙人认为创始人重大过失"）或过于宽泛，得 8 分；触发条件模糊或包含"无条件回购"，得 0 分。 | |
| **D2：回购利率上限** | 15 分 | 回购利率（含复利）≤8% 年化，或采用 LPR 加点，得 15 分；利率在 8%-12% 之间，得 8 分；利率 >12% 或属于高利贷区间，得 0 分。 | |
| **D3：创始人个人责任上限** | 15 分 | 明确约定创始人个人回购责任以其所持公司股权变现价值为上限，或其个人可变现净资产的固定比例为上限，得 15 分；约定个人责任但无明确上限，得 8 分；约定个人无限连带责任或家属连带担保，得 0 分。 | |
| **D4：合伙人反向对赌/资源承诺** | 15 分 | 协议中明确约定合伙人承诺的资源（大客户、融资额、政府关系）未落地时的补偿机制（股权稀释、现金补偿、或董事会席位调整），得 15 分；有口头承诺但无书面对赌，得 8 分；合伙人无任何资源落地承诺，得 0 分。 | |
| **D5：董事会与一票否决权对称性** | 10 分 | 董事会席位分配与各方股权比例/贡献基本匹配；一票否决权仅用于保护性事项（如保护投资人/合伙人的清算优先权），不用于日常经营决策，得 10 分；一票否决权范围过宽或董事会席位严重失衡，得 0 分。 | |
| **D6：创始人技术/产品否决权** | 10 分 | 创始人对核心技术路线、核心产品架构变更拥有否决权或拥有由创始人主导的技术委员会的最终决策权，得 10 分；创始人仅有建议权，得 5 分；创始人对技术路线无任何正式话语权，得 0 分。 | |
| **D7：协议修改与晋阶条款** | 10 分 | 协议中包含明确的"阶段性重评条款"（如每轮融资后或每年度可友好协商调整股权/权责），得 10 分；协议中无修改条款但各方有非正式默契，得 5 分；协议中明确禁止任何修改或设置极高修改门槛，得 0 分。 | |
| **D8：独立法律审阅记录** | 10 分 | 创始人有独立于合伙人推荐名单之外的律师审阅记录，且律师提出了书面风险提示，得 10 分；仅由合伙人推荐的律师审阅或无独立审阅，得 0 分。 | |

---

### 阈值说明与健康等级

| 总分 | 健康等级 | 含义 | 建议动作 |
|------|----------|------|----------|
| **85-100 分** | 🟢 健康 | 条款结构对创始人友好，风险可控，具备长期合作基础 | 维持现状，每年复查 |
| **60-84 分** | 🟡 亚健康 | 存在 1-3 个结构性风险点，需要打补丁 | 30 天内启动补充协议谈判，优先处理 D3/D4/D6 |
| **35-59 分** | 🟠 病态 | 条款已构成对创始人的实质性不平等，长期合作隐患极大 | 90 天内必须完成协议重谈，必要时引入第三方 mediator |
| **≤34 分** | 🔴 高危 | 条款已接近"卖身契"，创始人面临巨额个人债务或完全架空风险 | 立即暂停任何可能导致触发条件的动作，启动危机法律顾问 |

---

### "一票否决"红线

以下情况出现时，无论其他维度得分多高，**总体健康等级最多只能评为 🟠 病态**：

1. **D3 创始人个人责任上限 = 0 分**：个人无限连带是创始人不可承受的尾部风险。
2. **D6 创始人技术/产品否决权 = 0 分**：技术型创始人失去技术话语权，等于失去了公司的灵魂与未来。
3. **D8 独立法律审阅记录 = 0 分**：信息不对称到连独立律师都没有，说明创始人从一开始就被置于极度弱势地位。

## 工具二：低位创始人话语权与尊严感知平衡表

### 评估说明

**适用对象**：技术/学术背景出身的低位创始人
**评估周期**：明星合伙人入局后 30 天内基线评估，之后每季度复评
**评估方式**：创始人自评 50% + 核心团队成员匿名评 30% + 外部教练评 20%
**总分**：100 分

---

### 评分维度

| 维度 | 权重 | 评分标准 | 得分 |
|------|------|----------|------|
| **D1：董事会决策影响力** | 15 分 | 创始人在董事会上有固定席位，且其反对意见至少会被记录并在重大事项上产生实质性影响，得 15 分；有席位但影响力弱，得 8 分；无董事会席位或席位为"列席"性质，得 0 分。 | |
| **D2：核心人事任免权** | 15 分 | 创始人对原团队及新招聘的核心技术人员拥有最终任免权或共同决策权，得 15 分；仅有建议权，得 8 分；完全无权或合伙人绕过创始人直接任免，得 0 分。 | |
| **D3：对外身份认同** | 15 分 | 在外部场合（投资人路演、媒体报道、客户会议）中，合伙人始终称呼并介绍创始人为"联合创始人兼 CTO/首席科学家"，且不会贬低其商业能力，得 15 分；介绍模糊或偶有贬低，得 8 分；介绍为"我带的技术负责人"或不强调创始人身份，得 0 分。 | |
| **D4：技术路线主导权** | 15 分 | 创始人能够独立召集技术委员会/产品委员会，并对技术路线、产品架构拥有最终决策权（或否决权），得 15 分；需要合伙人批准才能召集会议，得 8 分；无法独立召集或技术路线完全由合伙人主导，得 0 分。 | |
| **D5：冲突表达安全感** | 10 分 | 创始人能够自在地向合伙人表达不同意见，而不担心报复、打压或被边缘化，得 10 分；偶有表达但伴随后顾之忧，得 5 分；完全不敢表达或表达后遭受明显负面后果，得 0 分。 | |
| **D6：信息获取透明度** | 10 分 | 创始人能够及时、完整地获取公司财务数据、资金流向、重大合同签订信息，得 10 分；信息偶有延迟或过滤，得 5 分；信息被合伙人或其任命的 CFO 刻意隐瞒，得 0 分。 | |
| **D7：团队凝聚力与忠诚度** | 15 分 | 创始人的原团队核心成员未出现因高位合伙人介入而大规模流失，且团队仍然视创始人为精神领袖，得 15 分；有少量流失但核心仍在，得 8 分；核心团队已流失过半或转向效忠合伙人，得 0 分。 | |
| **D8：心理韧性与自我价值感** | 10 分 | 创始人仍然相信自己的技术/产品 vision 对公司的长期价值，且不因合伙人的强势而怀疑自身存在意义，得 10 分；偶有自我怀疑但能恢复，得 5 分；频繁自我否定、出现抑郁/焦虑情绪、或产生退出念头，得 0 分。 | |

---

### 阈值说明与平衡等级

| 总分 | 平衡等级 | 含义 | 建议动作 |
|------|----------|------|----------|
| **85-100 分** | 🟢 平衡 | 创始人话语权和尊严感知良好，具备与合伙人长期并肩作战的基础 | 维持节奏，每季度复查 |
| **65-84 分** | 🟡 轻度失衡 | 存在 1-2 个可修复的失衡点，需要沟通或规则调整 | 30 天内启动一次"创始人-合伙人一对一恳谈会"，明确边界 |
| **45-64 分** | 🟠 中度失衡 | 多个维度亮起红灯，创始人已处于实质性弱势或心理高压状态 | 60 天内必须启动"话语权再平衡方案"，涉及董事会改组或协议补丁 |
| **≤44 分** | 🔴 严重失衡 | 创始人已被架空、尊严严重受损、心理状况堪忧 | 立即启动危机干预，必要时启动股东协议重谈或合伙人退出谈判 |

---

### "尊严崩溃"高发组合

若某位创始人的评估结果同时满足以下任意组合，需立即升级为最高警戒：

**组合 A：权力架空型**
- D1 董事会决策影响力 = 0 分
- D2 核心人事任免权 = 0 分
- D4 技术路线主导权 = 0 分
- **预示**：创始人已从"联合创始人"沦为"高级技术员工"，随时可能被替换。

**组合 B：心理崩溃型**
- D5 冲突表达安全感 = 0 分
- D8 心理韧性与自我价值感 = 0 分
- D3 对外身份认同 ≤2 分
- **预示**：创始人心理状态濒临崩溃，可能出现突然离职、消极怠工、或与合伙人爆发不可逆冲突。

**组合 C：团队瓦解型**
- D2 核心人事任免权 = 0 分
- D6 信息获取透明度 = 0 分
- D7 团队凝聚力与忠诚度 = 0 分
- **预示**：合伙人已完成"班子替换"，创始人彻底孤立无援。

## 工具三：高位合伙人适配度与退出风险评估表

### 评估说明

**适用对象**：已进入公司的明星/高位合伙人（或正在谈判中的准合伙人）
**评估周期**：入局谈判阶段必评一次；入局后每半年复评
**评估方式**：创始人评 40% + 投资人/董事评 30% + 外部教练评 30%
**总分**：100 分（得分越高，适配度越高、退出风险越低；得分越低，适配度越低、退出冲突越剧烈）

---

### 评分维度

| 维度 | 权重 | 评分标准 | 得分 |
|------|------|----------|------|
| **D1：资源落地兑现率** | 20 分 | 合伙人承诺的大客户、融资、政府关系等资源已有 ≥50% 明确落地（签约/打款/政策批文），得 20 分；有实质性进展但尚未完全落地，得 12 分；完全没有落地迹象或屡次延期，得 0 分。 | |
| **D2：与创始人的协作温度** | 15 分 | 合伙人能够在公开场合尊重创始人，并在私下保持正常的沟通与争论空间，得 15 分；协作冷淡、习惯性否定创始人，得 8 分；公开贬低创始人或频繁发生激烈冲突，得 0 分。 | |
| **D3：权力谦逊度** | 15 分 | 合伙人认可创始人对技术/产品的最终话语权，不强求在所有决策中标榜自己的大厂经验，得 15 分；偶有越界但可沟通，得 8 分；表现出强烈的"清洗旧部"或"唯我独尊"倾向，得 0 分。 | |
| **D4：团队融合度** | 15 分 | 合伙人带入的旧部与原团队能够正常协作，未形成明显的"大佬系"vs"创始系"对立，得 15 分；有轻微派系但工作可推进，得 8 分；形成严重派系对立、互相拆台，得 0 分。 | |
| **D5：财务透明度与分钱公平感** | 10 分 | 合伙人主动推动薪酬、期权、预算分配的透明化规则，不存在偏袒旧部的现象，得 10 分；规则不透明但无明显偏袒证据，得 5 分；存在明显的"旧部高薪高期权、创始团队被压缩"现象，得 0 分。 | |
| **D6：长期承诺稳定性** | 10 分 | 合伙人口风稳定，表达出长期陪伴公司发展的意愿，且未频繁提及"如果达不到目标我就撤"，得 10 分；态度摇摆、时常释放退出信号，得 5 分；已明确提出退出时间表或威胁回购，得 0 分。 | |
| **D7：规则共建意愿** | 10 分 | 合伙人愿意就股东协议补丁、合伙人宪章、年度晋阶回顾会等规则展开讨论，得 10 分；对规则调整持保守态度但尚可谈判，得 5 分；坚决反对任何协议调整，得 0 分。 | |
| **D8：外部声誉成本承受力** | 5 分 | 合伙人非常在意自己在创业圈/产业圈的声誉，不会轻易做出"逼创始人回购"等有损声誉的行为，得 5 分；对声誉一般敏感，得 3 分；完全不在意声誉、做事风格极端激进，得 0 分。 | |

---

### 阈值说明与风险等级

| 总分 | 风险等级 | 含义 | 建议动作 |
|------|----------|------|----------|
| **85-100 分** | 🟢 低风险 | 合伙人适配度高，资源兑现好，协作温度正常，退出风险低 | 巩固伙伴关系，推进长期绑定 |
| **65-84 分** | 🟡 中风险 | 存在 1-2 个摩擦点，但通过补谈和规则调整可以化解 | 启动一对一补谈，优先补齐 D2/D3/D5 |
| **45-64 分** | 🟠 高风险 | 多个维度亮起红灯，合伙人退出或关系破裂的概率较高 | 立即准备 B 计划，启动协议补丁与潜在替代人选搜寻 |
| **≤44 分** | 🔴 极高风险 | 合伙人极有可能在短期内触发冲突（回购诉讼、人事清洗、公开决裂） | 建议重新评估合伙关系的可持续性；若必须分手，需启动法务与公关预案 |

---

### "合伙人翻脸"高发组合

若评估结果同时满足以下任意组合，需立即升级为最高警戒：

**组合 A：资源忽悠型**
- D1 资源落地兑现率 = 0 分
- D6 长期承诺稳定性 = 0 分
- **预示**：合伙人可能以"资源"为诱饵入局，实际并无长期投入意愿，最终可能通过回购条款套利离场。

**组合 B：独裁清洗型**
- D3 权力谦逊度 = 0 分
- D4 团队融合度 = 0 分
- D7 规则共建意愿 = 0 分
- **预示**：合伙人将公司视为自己的舞台，创始人及其团队是其眼中的障碍，冲突升级不可避免。

**组合 C：声誉绝缘型**
- D2 与创始人的协作温度 = 0 分
- D8 外部声誉成本承受力 = 0 分
- **预示**：合伙人不惜撕破脸、不在乎外部评价，一旦认为创始人"不听话"，会采取极端手段压制或驱逐。

## 评估工具包使用流程图

```
Step 1: 确定评估对象和时机
    ├─ 股东协议健康度 → 合伙人入局前/每年/融资前
    ├─ 创始人话语权平衡 → 合伙人入局后 30 天基线 + 每季度复评
    └─ 合伙人适配度 → 谈判阶段 + 每半年复评

Step 2: 指定评估人和权重
    ├─ 创始人必须参与所有三项评估
    ├─ 独立律师参与股东协议健康度评估
    ├─ 投资人和教练参与合伙人适配度评估
    └─ 核心团队匿名参与创始人话语权评估

Step 3: 逐项打分并记录事实依据
    └─ 每个得分都需附 1-2 句话的客观事实

Step 4: 汇总总分并定位阈值
    └─ 输出红绿灯判定

Step 5: 制定针对性行动计划
    └─ 对黄灯/橙灯/红灯项，给出 30/60/90 天整改计划

Step 6: 教练复盘会议
    └─ 向创始人汇报评估结果，讨论补谈策略与风险预案
```

---

*本评估工具包由满意解研究所基于 Type 5 冲突域映射、"契·晋"精神与三大标杆案例实践开发，所有阈值均经过合伙人冲突案例库验证。*
