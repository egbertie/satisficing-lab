# 项目升级期合伙人冲突决策 —— 评估工具包

> **服务代号**：Type-3 升级契约盾  
> **版本**：V1.0  
> **生成时间**：2026-04-10 13:08

---

## 工具一：股权结构 + Vesting 健康度评分表

### 评估说明

**适用对象**：B轮后硬科技企业的股权架构与合伙人绑定机制
**评估周期**：建议在每轮融资后3个月内评估一次，合伙人变动前必须评估
**评估方式**：创始人 + 财务负责人 + 外部法律顾问联合填写，教练复核
**总分**：100 分

---

### 评分维度

| 维度 | 权重 | 评分标准 | 得分 |
|------|------|----------|------|
| **D1：Vesting 协议完备性** | 20 分 | 所有联合创始人/早期合伙人均已签署明确的 4 年 Vesting 协议（含 1 年 cliff），条款经律师审核，得 20 分；有协议但不够完善（如未约定 cliff 或回购价格模糊），得 10 分；完全无 Vesting 协议，得 0 分。 | |
| **D2：股权稀释后的再平衡机制** | 15 分 | 已在合伙人协议中约定融资稀释后的股权再平衡规则（如反稀释条款、补充授予机制），得 15 分；有口头约定但无书面文件，得 7 分；无任何再平衡机制，得 0 分。 | |
| **D3：创始人/联合创始人控制权** | 15 分 | 创始人/联合创始人合计持股比例 ≥51%（或拥有同比例投票权），得 15 分；34%-50.9%，得 8 分；≤33.3%，得 0 分。 | |
| **D4：期权池空间** | 10 分 | 现有期权池 ≥10%，且足够覆盖未来 12-18 个月的核心人才引进需求，得 10 分；期权池 5%-9.9%，得 5 分；期权池 <5% 或已耗尽，得 0 分。 | |
| **D5：股权回购/退出机制** | 10 分 | 所有股东已签署明确的股权回购/退出协议，约定触发条件、定价方式（如净资产法/净资产倍数法/最近一轮估值折扣法）、付款节奏，得 10 分；有约定但定价方式模糊，得 5 分；无任何书面退出机制，得 0 分。 | |
| **D6：代持与隐名股东风险** | 10 分 | 已完成全面代持排查，确认无任何代持或隐名股东安排，得 10 分；有代持但已签署经公证的代持协议并清晰约定还原路径，得 5 分；存在未规范代持，得 0 分。 | |
| **D7：税务筹划前置性** | 10 分 | 已在股权架构设计阶段考虑税务优化（如有限合伙持股平台、地区性税收优惠、期权税务递延安排），得 10 分；有初步意识但未系统规划，得 5 分；完全未考虑税务成本，得 0 分。 | |
| **D8：财务信息透明度** | 10 分 | 股权结构、融资条款、期权分配等关键信息对核心合伙人团队完全透明，得 10 分；部分透明但存在信息壁垒，得 5 分；高度不透明，合伙人之间互相不清楚彼此持股，得 0 分。 | |

---

### 阈值说明与健康等级

| 总分 | 健康等级 | 含义 | 建议动作 |
|------|----------|------|----------|
| **85-100 分** | 🟢 健康 | 股权结构和 Vesting 机制对接班友好，具备足够的调整弹性 | 维持现状，每年复查 |
| **60-84 分** | 🟡 亚健康 | 存在 1-3 个结构性风险点，升级期可能被触发 | 3 个月内针对性整改，优先处理 D1/D2/D5 |
| **35-59 分** | 🟠 病态 | 股权结构已对升级期构成实质性障碍，任何人员变动都可能引发连锁冲突 | 必须暂停重大人事变动，6 个月内完成股权重构 |
| **≤34 分** | 🔴 高危 | 股权结构处于崩溃边缘，极有可能爆发诉讼、分家或控制权争夺 | 立即启动危机干预，建议创始人亲自坐镇谈判 |

### 标杆案例对照

| 标杆 | 关键做法 | 本表映射 |

## 工具二：技术 vs 市场话语权平衡度评估表

### 评估说明

**适用对象**：存在技术合伙人（CTO/联合创始人）与市场合伙人（CMO/销售VP）冲突的硬科技企业
**评估周期**：建议在技术vs市场冲突激化时评估，或每季度作为合伙人健康度的一部分
**评估方式**：CEO 评 30% + CTO 评 30% + CMO 评 30% + 外部教练评 10%
**总分**：100 分

---

### 评分维度

| 维度 | 权重 | 评分标准 | 得分 |
|------|------|----------|------|
| **D1：决策边界清晰度** | 20 分 | 已书面明确"技术决策（如架构选型、可靠性标准）"与"商业决策（如定价、上市时间、客户选择）"的边界，且双方均认可，得 20 分；边界口头约定但常有越界，得 10 分；边界完全模糊，得 0 分。 | |
| **D2：产品路线图共识度** | 15 分 | 技术团队和市场团队对当前产品路线图（含 MVP/Tier 1/Tier 2 迭代计划）有高度共识，得 15 分；有路线图但双方理解不一致，得 8 分；没有统一路线图，得 0 分。 | |
| **D3：技术合伙人商业敏感度** | 15 分 | CTO 能够理解并尊重"现金流""竞争窗口""客户付费意愿"等商业约束，不会在公开场合否定市场策略，得 15 分；能理解但偶有冲突，得 8 分；完全以技术视角排斥商业逻辑，得 0 分。 | |
| **D4：市场合伙人技术理解度** | 15 分 | CMO 能够理解并尊重"技术债务""可靠性风险""迭代周期"等技术约束，不会为了销量强行压缩不合理的开发周期，得 15 分；能理解但偶有冲突，得 8 分；完全以销售视角否定技术逻辑，得 0 分。 | |
| **D5：冲突解决机制有效性** | 15 分 | 设有技术委员会/产品委员会等机制，用于制度化地解决技术vs市场冲突，且运作良好，得 15 分；有机制但形同虚设，得 8 分；完全依赖 CEO 个人仲裁，得 0 分。 | |
| **D6：联合 KPI 设计** | 10 分 | 技术团队和市场团队至少共享 1 个联合 KPI（如客户 NPS、因技术问题导致的客户流失率），得 10 分；KPI 各自独立、互不挂钩，得 5 分；不仅没有联合 KPI，还存在对立的 KPI，得 0 分。 | |
| **D7：创始人仲裁负担** | 10 分 | CEO 很少需要直接介入技术vs市场的日常冲突，双方能在机制内自行协商，得 10 分；CEO 需要频繁介入（每月 ≥2 次），得 5 分；CEO 已感到疲惫不堪，冲突成为其主要工作内容，得 0 分。 | |

---

### 阈值说明与平衡等级

| 总分 | 平衡等级 | 含义 | 建议动作 |
|------|----------|------|----------|
| **85-100 分** | 🟢 高度平衡 | 技术与市场在规则和共识下协作，冲突可控且建设性 | 维持现有机制，每季度复评 |
| **65-84 分** | 🟡 轻度失衡 | 存在偶发性冲突，但尚未影响业务推进 | 1 个月内召开技术与市场联席会议，明确边界和路线图 |
| **45-64 分** | 🟠 明显失衡 | 冲突已常态化，开始影响产品进度和团队士气 | 立即建立阶段门决策委员会，引入外部 facilitator |
| **≤44 分** | 🔴 严重失衡 | 技术vs市场冲突已成为公司的主要内耗源，CEO 疲于奔命 | 建议启动专项合伙人关系教练介入，必要时调整 CTO 或 CMO 的汇报结构和权责 |

---

### 特别说明：一票否决红线

以下情况出现时，无论其他维度得分多高，**总体平衡等级最多只能评为 🟠 明显失衡**：

1. **D1 决策边界清晰度 = 0 分**：边界模糊是所有冲突的根源，没有边界就没有协作基础。
2. **D7 创始人仲裁负担 = 0 分**：CEO 已成为唯一的仲裁者，说明机制完全失败，个人关系正在快速透支。
3. **D3 技术合伙人商业敏感度 = 0 分 且 D4 市场合伙人技术理解度 = 0 分**：双方完全互不理解，处于敌对状态。

## 工具三：新老合伙人融合度评估表

### 评估说明

**适用对象**：B轮后引入外部高管合伙人的硬科技企业
**评估周期**：新高管入职后 3 个月、6 个月、12 个月分别评估
**评估方式**：创始人评 30% + 早期合伙人均值 30% + 新高管自评 20% + 外部教练评 20%
**总分**：100 分

---

### 评分维度

| 维度 | 权重 | 评分标准 | 得分 |
|------|------|----------|------|
| **D1：文化认同度** | 15 分 | 新高管对公司的技术文化、创业精神、核心价值观有深度认同，不会在公开场合贬低早期团队的工作方式，得 15 分；基本认同但偶有不适，得 8 分；明显不认同，频繁批评"小公司习气"，得 0 分。 | |
| **D2：权力嵌入路径清晰度** | 15 分 | 新高管的权责范围、汇报关系、决策权限在入职时有明确书面约定，且实际执行与约定一致，得 15 分；有约定但执行中常被挑战，得 8 分；约定模糊，实际权限随创始人心情变化，得 0 分。 | |
| **D3：早期合伙人接纳度** | 15 分 | 早期合伙人对新高管持开放、接纳态度，愿意在其负责领域配合工作，得 15 分；态度冷淡、观望，得 8 分；公开排斥、质疑其能力或动机，得 0 分。 | |
| **D4：信息透明度与信任** | 10 分 | 新高管能够及时、完整地向早期合伙人分享其负责领域的信息，不存在"信息垄断"或"唯 CEO 汇报"的情况，得 10 分；信息分享偶有延迟或保留，得 5 分；信息不对称严重，早期合伙人感到被排除在外，得 0 分。 | |
| **D5：差异化契约接受度** | 15 分 | 早期合伙人和新高管都理解并接受双方在股权、薪酬、身份上的差异化安排，不存在强烈的"不公平感"，得 15 分；有一方偶有抱怨，得 8 分；有一方持续强烈不满，得 0 分。 | |
| **D6：协作产出** | 15 分 | 新高管与早期合伙人团队已成功协作完成至少一个可量化的业务成果（如新产品上线、新客户签约、新流程落地），得 15 分；有协作但成果不显著，得 8 分；协作频繁失败或产出被互相否定，得 0 分。 | |
| **D7：创始人调解负担** | 10 分 | 创始人不需要频繁调解新高管与早期合伙人之间的日常摩擦，得 10 分；需要每月介入 1-2 次，得 5 分；需要每周介入或已感到身心俱疲，得 0 分。 | |
| **D8：离职风险** | 5 分 | 新高管和早期合伙人团队中，均没有人近期表达过因对方而考虑离职的念头，得 5 分；有一方私下表达过不满或试探性讨论外部机会，得 3 分；有一方已明确提出离职或开始招聘下家，得 0 分。 | |

---

### 阈值说明与融合等级

| 总分 | 融合等级 | 含义 | 建议动作 |
|------|----------|------|----------|
| **85-100 分** | 🟢 高度融合 | 新高管已成功嵌入团队，文化与权力均获得认可 | 继续授权，逐步扩大其决策范围 |
| **65-84 分** | 🟡 基本融合 | 存在轻度摩擦，但不影响日常工作推进 | 1 个月内组织新老合伙人团建+工作坊，澄清权责边界 |
| **45-64 分** | 🟠 融合受阻 | 存在明显派系对立，新高管或老团队处于被孤立状态 | 创始人需亲自出面做"情感打底"，必要时调整新高管的汇报线或职责范围 |
| **≤44 分** | 🔴 融合失败 | 新老合伙人之间已产生不可调和的矛盾，公司存在分裂风险 | 建议立即启动危机干预，评估是否保留新高管或调整早期合伙人股权/岗位 |

## 工具四：早期合伙人倦怠风险评分表

### 评估说明

**适用对象**：跟随创始人 4 年以上的联合创始人/早期核心合伙人
**评估周期**：B轮后每半年评估一次，或在高强度融资/上市筹备期每季度评估
**评估方式**：创始人评 40% + 被评估人自评 30% + 人力资源负责人评 30%
**总分**：100 分（得分越高，倦怠风险越低；得分越低，倦怠风险越高）

---

### 评分维度

| 维度 | 权重 | 评分标准 | 得分 |
|------|------|----------|------|
| **D1：工作投入度** | 20 分 | 仍然保持高强度工作投入，主动加班、主动承担困难任务，得 20 分；投入度尚可但明显下降，得 10 分；经常迟到早退、逃避责任、会议中明显走神，得 0 分。 | |
| **D2：情绪稳定性** | 15 分 | 面对压力和挫折时情绪稳定，不会频繁发脾气或表现出消极悲观，得 15 分；偶有情绪失控但事后能恢复，得 8 分；频繁情绪失控、经常抱怨、传递负能量，得 0 分。 | |
| **D3：对公司未来的信心** | 15 分 | 对公司未来 2-3 年的发展路径有清晰认知并保持信心，不会公开质疑公司方向，得 15 分；有疑虑但主要在私下表达，得 8 分；频繁公开质疑战略方向、散布悲观情绪，得 0 分。 | |
| **D4：与创始人关系温度** | 15 分 | 与创始人/CEO 保持超越工作关系的私人信任，愿意单独沟通非工作话题，得 15 分；关系尚可但明显疏远，得 8 分；关系冷淡或带有敌意，得 0 分。 | |
| **D5：家庭/身体支持度** | 10 分 | 家庭对当前工作状态支持，身体状况良好，能够支撑高强度工作至少 2 年，得 10 分；家庭偶有抱怨或身体状况开始出现亚健康信号，得 5 分；家庭强烈反对或身体出现明显疾病信号，得 0 分。 | |
| **D6：外部选择动机** | 15 分 | 没有表达过离职或创业的念头，对外部机会的探索为零或极低，得 15 分；偶有试探性讨论外部机会，得 8 分；已明确提出离职意向、开始接触猎头或筹备创业，得 0 分。 | |
| **D7：对股权/财务回报的满意度** | 10 分 | 对当前股权价值、薪酬待遇和未来的财务回报预期感到满意，得 10 分；有不满但尚可忍受，得 5 分；强烈不满，认为自己的付出与回报严重不匹配，得 0 分。 | |

---

### 阈值说明与风险等级

| 总分 | 风险等级 | 含义 | 建议动作 |
|------|----------|------|----------|
| **85-100 分** | 🟢 低风险 | 早期合伙人状态良好，无明显倦怠信号 | 维持现有激励和沟通节奏 |
| **65-84 分** | 🟡 中风险 | 存在轻度倦怠信号，需要关注但尚不紧急 | 1 个月内安排创始人一对一深度沟通，了解真实诉求 |
| **45-64 分** | 🟠 高风险 | 倦怠信号明显，离职风险上升 | 启动专项 retention 计划：股权补发、岗位调整、休假安排、心理辅导 |
| **≤44 分** | 🔴 极高风险 | 早期合伙人极有可能在短期内离职或消极怠工 | 建议创始人立即亲自出面挽留，同时启动知识交接和应急响应预案 |

---

### 特别警示：倦怠战争高发组合

若某位早期合伙人的评估结果同时满足以下任意组合，需立即升级为最高警戒：

**组合 A（离心型）**：D1 工作投入度 ≤10 分 + D6 外部选择动机 = 0 分 + D4 与创始人关系温度 = 0 分  
*含义*：此人已在心理上退出公司，且与创始人关系破裂，挽留难度极大。

**组合 B（破坏型）**：D2 情绪稳定性 = 0 分 + D3 对公司未来的信心 = 0 分 + D7 对股权/财务回报的满意度 = 0 分  
*含义*：此人处于强烈的怨愤状态，可能会在团队中散布负面情绪，甚至带走核心人员。

**组合 C（健康型）**：D5 家庭/身体支持度 = 0 分 + D1 工作投入度 ≤10 分 + D6 外部选择动机 ≤8 分  
*含义*：此人因家庭或身体原因已无法支撑高强度创业工作，需要考虑体面的退出或转岗安排。
