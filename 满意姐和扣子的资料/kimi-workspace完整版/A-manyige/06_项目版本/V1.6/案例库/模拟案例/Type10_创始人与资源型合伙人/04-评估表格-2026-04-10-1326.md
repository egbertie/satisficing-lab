# 创始人与资源型合伙人 —— 评估工具包

> **服务代号**：Type-10 资源对价镜  
> **版本**：V1.0  
> **生成时间**：2026-04-10 13:26

---

## 工具一：资源对价健康度评分表

### 评估说明

**适用对象**：创始人与资源型合伙人之间的股权-资源对价关系
**评估周期**：资源合伙人入职时（基线评估）、每6个月复评一次、重大资源交付节点前**
**评估方式**：创始人评 50% + 外部教练/顾问评 30% + 投资人评 20%（如有）
**总分**：100 分

---

### 评分维度

| 维度 | 权重 | 评分标准 | 得分 |
|------|------|----------|------|
| **D1：承诺具体度** | 15 分 | 资源承诺有书面清单、量化指标、明确时间表、可验证标准，得 15 分；有书面但不够量化，得 8 分；仅有口头承诺，得 0 分。 | |
| **D2：兑现完成度** | 20 分 | 承诺资源兑现率 ≥70%，且有完整的财务/合同/批文凭证，得 20 分；兑现率 40%-69%，得 10 分；兑现率 <40%，得 0 分。 | |
| **D3：股权对价计算逻辑** | 15 分 | 股权比例有明确的计算逻辑或市场可比案例支撑（如每1000万资源=X%股权），得 15 分；有粗略估算但未经严谨论证，得 8 分；完全拍脑袋或人情让步，得 0 分。 | |
| **D4：里程碑绑定机制** | 15 分 | 股权归属/解锁与资源兑现里程碑严格挂钩（Vesting/Clawback/Milestone），条款经律师审核，得 15 分；有约定但不够严密，得 8 分；无任何绑定机制（一次性授予或过早归属），得 0 分。 | |
| **D5：控制权保护** | 10 分 | 创始团队仍拥有绝对控制权（≥67%）或至少相对控制权（≥51%），得 10 分；创始团队持股 34%-50%，得 5 分；≤33%，得 0 分。 | |
| **D6：关系网络共享度** | 10 分 | 创始人可直接参与或掌握关键政府/客户/投资人对接渠道（至少50%），得 10 分；创始人可间接获知但无法直接参与，得 5 分；创始人被完全排除在外，得 0 分。 | |
| **D7：资源可持续性** | 10 分 | 已经建立不依赖于资源合伙人个人的组织化渠道（公司有直接联系人、备案文件、长期合作协议），得 10 分；部分资源已组织化但仍有大量依赖个人，得 5 分；几乎完全依赖个人关系，得 0 分。 | |
| **D8：退出/调整机制** | 5 分 | 已有明确的资源合伙人退出/股权回购/对价调整条款，得 5 分；有约定但不够清晰，得 3 分；无任何退出机制，得 0 分。 | |

---

### 阈值说明与健康等级

| 总分 | 健康等级 | 含义 | 建议动作 |
|------|----------|------|----------|
| **85-100 分** | 🟢 健康 | 资源对价关系规范、可控、可预期 | 维持现有机制，每6个月复查 |
| **60-84 分** | 🟡 亚健康 | 存在 1-3 个结构性风险点，可能在资源交付或股权争议时被触发 | 3 个月内针对性整改，优先处理 D2/D4/D6 |
| **35-59 分** | 🟠 病态 | 资源对价已构成实质性障碍，资源不兑现与股权沉没的风险极高 | 必须立即启动对价重构谈判，暂停新的股权解锁 |
| **≤34 分** | 🔴 高危 | 资源合伙人关系处于崩溃或反噬边缘，极有可能爆发控制权争夺或决裂 | 立即启动危机干预，建议创始人亲自主导谈判并准备法律预案 |

---

### 特别说明：一票否决红线

以下情况出现时，无论其他维度得分多高，**总体健康等级最多只能评为 🟠 病态**：

1. **D5 控制权保护 = 0 分**：创始团队已丧失控制权或处于被架空的边缘，这是非常危险的信号。
2. **D2 兑现完成度 = 0 分**：资源兑现率低于40%且无改善迹象，说明股权对价已经严重失衡。
3. **D6 关系网络共享度 = 0 分**：创始人被完全排除在关键外部关系之外，资源合伙人已实质上将企业外部接口私有化。

## 工具二：创始人决策准备度评估表

### 评估说明

**适用对象**：面临资源合伙人争议的技术/市场创始人
**评估周期**：在启动资源合伙人谈判/重构/退出前进行评估**
**评估方式**：创始人自评 40% + 外部教练评 30% + 核心团队评 30%
**总分**：100 分

---

### 评分维度

| 维度 | 权重 | 评分标准 | 得分 |
|------|------|----------|------|
| **D1：信息掌握度** | 15 分 | 创始人对资源合伙人承诺的资源清单、兑现进度、关系网络结构、股权协议条款有完整、准确的掌握，得 15 分；掌握大部分但有关键盲区，得 8 分；掌握程度低，很多信息依赖资源合伙人单方面告知，得 0 分。 | |
| **D2：法律文件审查** | 15 分 | 创始人已仔细阅读过与资源合伙人相关的所有法律文件（股权协议、合伙协议、公司章程、竞业禁止协议），并理解其中的关键条款，得 15 分；看过但不完全理解，得 8 分；从未完整看过，得 0 分。 | |
| **D3：心理边界清晰度** | 15 分 | 创始人清楚知道自己在这条关系中的底线（最多还能让多少股权、哪些资源必须组织化、哪些行为不可接受），得 15 分；有大致想法但不坚定，得 8 分；没有太多边界概念，容易被对方情绪或压力左右，得 0 分。 | |
| **D4：谈判勇气与意愿** | 15 分 | 创始人有明确的意愿与资源合伙人进行坦诚、甚至艰难的对话来调整规则，不因"怕伤感情"而无限拖延，得 15 分；有意愿但希望"再等等看"，得 8 分；完全回避 confrontation，寄希望于问题自己消失，得 0 分。 | |
| **D5：Plan B 完备性** | 15 分 | 创始人已考虑过"如果谈判失败/资源合伙人退出"的应对方案，并在心理上、策略上、资源上有所准备，得 15 分；有大致想法但不够具体，得 8 分；完全没有 Plan B，感到恐慌或无法自拔，得 0 分。 | |
| **D6：团队支持度** | 10 分 | 核心团队成员（联合创始人、CTO、CFO等）理解并支持创始人对资源合伙人的调整立场，得 10 分；团队态度中立或观望，得 5 分；团队中有重要成员站在资源合伙人一边，得 0 分。 | |
| **D7：外部资源候补** | 10 分 | 创始人已经或正在建立不依赖于该资源合伙人的替代性资源渠道（如直接对接政府招商部门、开拓新的销售代理、引入其他投资人），得 10 分；有初步接触但尚未成型，得 5 分；没有任何替代渠道，完全将该资源合伙人视为唯一救命稻草，得 0 分。 | |
| **D8：专业顾问支持** | 5 分 | 创始人已聘请或愿意聘请专业的法律顾问/财务顾问/教练顾问来协助处理资源合伙人争议，得 5 分；尚未聘请但表示愿意考虑，得 3 分；拒绝任何外部专业支持，认为自己可以搞定，得 0 分。 | |

---

### 阈值说明与准备等级

| 总分 | 准备等级 | 含义 | 建议动作 |
|------|----------|------|----------|
| **85-100 分** | 🟢 充分准备 | 创始人在信息、心理、策略、团队、候补资源等方面都已做好准备，可以果断启动谈判 | 立即启动资源合伙人关系重构谈判 |
| **65-84 分** | 🟡 基本准备 | 创始人在主要维度上达标，但仍有 1-2 个明显短板，谈判过程需要辅以专业顾问陪伴 | 启动谈判但需聘请外部顾问全程参与，重点补强短板 |
| **45-64 分** | 🟠 准备不足 | 创始人在多个关键维度上存在 Gap，若强行谈判容易因信息不足、心理软弱或团队分裂而处于下风 | 先进行 4-8 周的准备期（信息收集、团队对齐、Plan B 建设），暂缓谈判 |
| **≤44 分** | 🔴 严重准备不足 | 创始人远未做好谈判准备，强行推进将对企业和个人都造成重大伤害 | 优先进行自我能力建设（法律认知、心理辅导、替代资源拓展），必要时考虑"创始人个人决策教练"先行 |

---

### 特别说明：各维度的"一票否决"红线

以下情况出现时，无论其他维度得分多高，**总体准备等级最多只能评为 🟠 准备不足**：

1. **D3 心理边界清晰度 = 0 分**：一个没有底线的谈判者，注定会在压力下不断退让。
2. **D5 Plan B 完备性 = 0 分**：没有退路的人，在谈判桌上没有筹码。
3. **D7 外部资源候补 = 0 分**：如果把全部希望寄托在唯一的资源合伙人身上，谈判不可能公平。

## 工具三：资源型合伙人风险评估表

### 评估说明

**适用对象**：已引入或拟引入的资源型合伙人
**评估周期**：引入前尽职调查、入职后每6个月复评、重大资源交付节点后专项评估**
**评估方式**：创始人评 40% + 外部教练/顾问评 30% + 投资人/董事会代表评 30%
**总分**：100 分（得分越高，风险越低；得分越低，风险越高）

---

### 评分维度

| 维度 | 权重 | 评分标准 | 得分 |
|------|------|----------|------|
| **D1：资源可验证度** | 20 分 | 承诺资源已有可验证的书面/财务凭证（合同、批文、到账记录），或已被第三方独立验证，得 20 分；有部分凭证但无法完全独立验证，得 10 分；仅有口头描述、合影照片、微信截图等不可验证信息，得 0 分。 | |
| **D2：资源兑现进度** | 15 分 | 入职以来承诺资源兑现率 ≥60%，且近期（3个月内）有持续兑现动作，得 15 分；兑现率 30%-59%，得 8 分；兑现率 <30%或长期无进展，得 0 分。 | |
| **D3：关系网络开放度** | 15 分 | 愿意让创始人直接参与关键政府/客户/投资人对接，不设置信息隔离，得 15 分；允许创始人部分参与但有所保留，得 8 分；刻意将关系网络私有化、拒绝创始人接触，得 0 分。 | |
| **D4：合作态度与文化适配** | 10 分 | 能够接受结果导向的管理方式（KPI、里程碑、量化考核），不将规则视为不信任，得 10 分；态度尚可但偶有抵触，得 5 分；强烈排斥量化管理、频繁以"人情"为由拒绝 accountability，得 0 分。 | |
| **D5：综合商业素养** | 10 分 | 对公司的技术/产品/财务/战略有基本的理解，能在对外谈判中准确代表公司利益，得 10 分；理解有限但愿意学习，得 5 分；完全不懂业务，对外谈判中容易损害公司利益，得 0 分。 | |
| **D6：诚信记录与背景调查** | 10 分 | 背景调查未发现重大诚信问题（夸大履历、历史诉讼、与前合作伙伴的恶性纠纷），得 10 分；有小瑕疵但不影响合作，得 5 分；存在重大诚信风险或背景严重造假，得 0 分。 | |
| **D7：退出配合度（如适用）** | 10 分 | 对于股权回购/对价调整/岗位变更等敏感话题，能够保持理性沟通、不 Threaten 创始人或带走资源，得 10 分；态度情绪化但尚可谈判，得 5 分；以"带走全部资源""让公司活不下去"等进行要挟，得 0 分。 | |
| **D8：资源持续性** | 10 分 | 资源本身是可持续的（如长期政府关系、稳定渠道代理），而非依赖一次性机会或个人退休前的人脉，得 10 分；部分资源可持续但部分是一次性机会，得 5 分；几乎全部为一次性机会或濒临失效的人脉，得 0 分。 | |

---

### 阈值说明与风险等级

| 总分 | 风险等级 | 含义 | 建议动作 |
|------|----------|------|----------|
| **85-100 分** | 🟢 低风险 | 资源合伙人可信、可验、可控，关系预计平稳 | 维持现有合作模式，按里程碑继续解锁股权 |
| **65-84 分** | 🟡 中风险 | 存在 1-2 个摩擦点，但通过规则完善和沟通可以化解 | 启动对价规则优化谈判，明确剩余资源的验收标准和时间表 |
| **45-64 分** | 🟠 高风险 | 多个维度亮起红灯，资源不兑现或资源私有化问题显著，冲突可能升级 | 暂停新的股权解锁，创始人亲自介入资源验证和关系共享谈判 |
| **≤44 分** | 🔴 极高风险 | 资源合伙人极有可能对企业造成重大伤害（财务损失、控制权争夺、资源绑架） | 建议立即启动退出谈判或法律程序，同时加速建设替代渠道 |

---

### 特别警示："资源反噬"高发组合

若某位资源合伙人的评估结果同时满足以下任意组合，需立即升级为最高警戒：

**组合 A：资源欺诈型**
- D1 资源可验证度 = 0 分
- D6 诚信记录与背景调查 = 0 分
- **预示**：该"资源合伙人"可能存在严重的履历造假或资源夸大，是典型的"空手套白狼"。

**组合 B：关系绑架型**
- D3 关系网络开放度 = 0 分
- D7 退出配合度 = 0 分
- D4 合作态度与文化适配 ≤5 分
- **预示**：资源合伙人正在将外部关系网络转化为个人要挟资本，极有可能在后续谈判中索要更多股权或控制权。

**组合 C：资源衰减型**
- D2 资源兑现进度 = 0 分
- D8 资源持续性 = 0 分
- D5 综合商业素养 ≤5 分
- **预示**：资源合伙人原有的资源已基本耗尽或从未存在，且不具备其他商业价值，股权对价已经严重失衡。

## 评估工具包使用流程图

```
Step 1: 确定评估对象和时机
    ├─ 资源对价健康度 → 入职时/每6个月/重大节点
    ├─ 创始人决策准备度 → 谈判前必备
    └─ 资源型合伙人风险 → 引入前尽调/入职后定期复评

Step 2: 指定评估人和权重
    ├─ 创始人必须参与所有三项评估
    ├─ 投资人/董事会参与资源对价和资源合伙人风险评估
    ├─ 资源合伙人不参与创始人决策准备度评估（避免偏见）
    └─ 外部教练全程参与并提供交叉验证

Step 3: 逐项打分并记录依据
    └─ 每个得分都需附 1-2 句话的事实依据

Step 4: 汇总总分并定位阈值
    └─ 输出红绿灯判定

Step 5: 制定针对性行动计划
    └─ 对黄灯/橙灯/红灯项，给出 30/60/90 天整改计划

Step 6: 教练复盘会议
    └─ 向创始人汇报评估结果，讨论下一步资源配置
```

## 附录：快速决策参考卡（创始人5分钟可用）

### 一问：资源可验证吗？
- 有政府批文原件/复印件吗？
- 有客户合同和回款记录吗？
- 有投资协议或资金到账凭证吗？

### 二问：股权有绑定吗？
- 股权解锁与资源里程碑挂钩吗？
- 资源不兑现时能收回股权吗？
- 还有多少股权未归属可以谈判？

### 三问：关系共享吗？
- 我能直接参加政府/客户会议吗？
- 公司有外部合作协议的存档吗？
- 他走了，这些关系还能用吗？

### 四问：控制权安全吗？
- 创始团队还控股吗？
- 他能单方面否决重大决策吗？
- 下一轮融资后我们还有控制权吗？

### 五问：有Plan B吗？
- 他不干了，我有替代渠道吗？
- 最坏情况下，公司现金流能撑多久？
- 我准备好和他谈规则了吗？
