# 项目转型期合伙人关系决策 —— 评估工具包

> **服务代号**：Type-4 转型罗盘  
> **版本**：V1.0  
> **生成时间**：2026-04-10 13:08

---

## 工具一：合伙协议与竞业边界健康度评分表

### 评估说明

**适用对象**：公司层面的合伙协议、股东协议、公司章程及竞业限制条款
**评估周期**：建议在转型决策前必须评估，转型重大节点前复评
**评估方式**：创始人 + 法务负责人 + 外部法律顾问联合填写，教练复核
**总分**：100 分

---

### 评分维度

| 维度 | 权重 | 评分标准 | 得分 |
|------|------|----------|------|
| **D1：业务转型决策权约定** | 20 分 | 合伙协议中明确约定了"业务转型/战略 pivot"的提议权、表决权和否决权，得 20 分；有约定但不够完善，得 12 分；完全无约定，得 0 分。 | |
| **D2：竞业限制条款边界清晰度** | 20 分 | 竞业限制条款对"竞业业务范围""地理范围""时间范围"有清晰、可操作的定义，且新业务不会被原合伙人解读为竞业，得 20 分；有约定但边界模糊，得 10 分；无竞业条款或条款过于宽泛/严苛，得 0 分。 | |
| **D3：股权动态调整机制** | 15 分 | 已建立明确的股权动态调整机制（如 Vesting、绩效考核股权、增资约定），能够适应转型期合伙人贡献变化，得 15 分；有约定但不够完善，得 8 分；完全无动态调整机制，得 0 分。 | |
| **D4：新旧业务边界划分** | 15 分 | 已通过书面协议明确划分"公司共同资产"与"合伙人个人可独立发展的业务领域"，得 15 分；有口头共识但无书面约定，得 7 分；完全未讨论或公私边界模糊，得 0 分。 | |
| **D5：信息披露与透明度机制** | 15 分 | 合伙协议或章程中约定了各业务线财务数据的披露范围、频率和责任人，得 15 分；有约定但不够具体，得 8 分；无任何信息披露约定，得 0 分。 | |
| **D6：合伙人退出机制** | 10 分 | 所有合伙人已签署明确的退出协议，约定转型期退出的触发条件、定价方式、付款节奏，得 10 分；有约定但不够清晰，得 5 分；无任何书面退出机制，得 0 分。 | |
| **D7：争议解决机制** | 5 分 | 合伙协议中约定了明确的争议解决机制（如调解、仲裁、第三方评估），得 5 分；仅约定诉讼或无任何约定，得 0 分。 | |

---

### 阈值说明与健康等级

| 总分 | 健康等级 | 含义 | 建议动作 |
|------|----------|------|----------|
| **85-100 分** | 🟢 健康 | 合伙协议与竞业边界对接班友好，具备足够的调整弹性和安全垫 | 维持现状，每年复查 |
| **60-84 分** | 🟡 亚健康 | 存在 1-3 个结构性风险点，转型过程中可能被触发 | 3 个月内针对性整改，优先处理 D1/D2/D5 |
| **35-59 分** | 🟠 病态 | 协议结构已对接班构成实质性障碍，任何转型动作都可能引发连锁冲突 | 必须暂停转型时间表，6 个月内完成协议重构 |
| **≤34 分** | 🔴 高危 | 协议结构处于崩溃边缘，极有可能爆发诉讼、拆伙或竞业冲突 | 立即启动危机干预，建议创始人亲自坐镇谈判 |

---

### 标杆案例对照

| 标杆 | 关键做法 | 本表映射 |
|------|----------|----------|
| **新东方转型** | 俞敏洪在转型直播电商前，通过董事会和股东会明确了新业务主体与原有教培资产的法律隔离 | D2 竞业边界 + D4 新旧业务边界 |
| **K12 转型成功机构** | 在双减后迅速修订公司章程，明确素质托管业务属于公司合法经营范围 | D1 业务转型决策权 + D2 竞业限制 |
| **某转型失败教培机构** | 因早期合伙协议竞业条款过于宽泛，新业务团队被原合伙人起诉，导致融资失败 | D2 竞业限制 + D6 退出机制缺失 |

## 工具二：新合伙人推动转型准备度评估表

### 评估说明

**适用对象**：拟任新业务负责人或推动转型的合伙人
**评估周期**：引入前或转型启动前进行基线评估，之后每季度复评一次
**评估方式**：360 度评估（创始人评 40% + 老合伙人代表评 30% + 外部教练评 30%）
**总分**：100 分

---

### 评分维度

| 维度 | 权重 | 评分标准 | 得分 |
|------|------|----------|------|
| **D1：业务扎根深度** | 15 分 | 已对老业务有 ≥6 个月的深度浸泡（走访校区/接触客户/理解供应链），并有过与老业务团队协同完成项目的经历，得 15 分；有短期了解但无深度协同，得 8 分；对老业务完全陌生，得 0 分。 | |
| **D2：跨团队协同能力** | 15 分 | 曾成功主导过一次需要老业务团队深度配合的转型试点项目，并获得老合伙人代表的认可，得 15 分；有参与但非主导，得 8 分；无任何跨团队项目经验，得 0 分。 | |
| **D3：独立权威来源** | 15 分 | 至少有一次在没有创始人直接出面或背书的情况下，独立说服老合伙人接受某项转型调整，并赢得尊重，得 15 分；有独立处理中等问题的经历，得 8 分；所有重大推动均依赖创始人站台，得 0 分。 | |
| **D4：老合伙人关系网络** | 10 分 | 与至少 2/3 以上的老合伙人建立了超越工作关系的私人信任（如定期单独沟通、尊重其历史贡献），得 10 分；与老合伙人保持礼貌但疏离的工作关系，得 5 分；与多数老合伙人关系紧张或被排斥，得 0 分。 | |
| **D5：经验-数据翻译能力** | 10 分 | 能够在"老合伙人语言"（经验、直觉、人情）和"新合伙人语言"（数据、模型、AB 测试）之间自如切换，并让两代人都感到被尊重，得 10 分；只能在一种语言体系中自如表达，得 5 分；两种语言都表达生硬，引发误解，得 0 分。 | |
| **D6：心理韧性与耐心** | 10 分 | 面对老合伙人的质疑或否定，能够保持情绪稳定、不急不躁、用事实和结果逐步赢得认可，得 10 分；偶有情绪失控但事后能修复，得 5 分；频繁与老合伙人发生正面冲突或公开对立，得 0 分。 | |
| **D7：战略清晰度** | 15 分 | 对转型路径有清晰、连贯、可落地的 12-18 个月规划，并能在董事会上清晰阐述、回应挑战，得 15 分；有想法但不够系统，得 8 分；战略方向模糊或频繁摇摆，得 0 分。 | |
| **D8：权力谦逊度** | 10 分 | 清楚认识到推动转型不是"推翻旧臣"而是"共建规则"，愿意在转型初期保留老合伙人的话语权和尊严，得 10 分；态度尚可但偶有颐指气使，得 5 分；表现出强烈的"清洗旧臣"倾向或过度傲慢，得 0 分。 | |

---

### 阈值说明与准备等级

| 总分 | 准备等级 | 含义 | 建议动作 |
|------|----------|------|----------|
| **85-100 分** | 🟢 成熟 ready | 新合伙人已具备推动转型所需要的业务理解、人际网络和心理准备 | 可以赋予更大的转型决策权和资源配置权 |
| **65-84 分** | 🟡 基本 ready | 新合伙人在主要维度上达标，但仍有 1-2 个明显短板，转型过程需要辅以教练陪伴和制度缓冲 | 设计 3-6 个月的能力补强计划，老合伙人沟通专项辅导 |
| **45-64 分** | 🟠 尚不成熟 | 新合伙人在多个关键维度上存在 Gap，若强行主导转型容易导致组织动荡或被架空 | 延长浸泡期 6-12 个月，或考虑"联席负责人/转型委员会"机制 |
| **≤44 分** | 🔴 不成熟 | 新合伙人目前远未达到主导转型的要求，强行推动将对企业造成重大伤害 | 重新审视新合伙人角色定位，创始人不宜短期内完全放权 |

---

### 特别说明：各维度的"一票否决"红线

以下情况出现时，无论其他维度得分多高，**总体准备等级最多只能评为 🟠 尚不成熟**：

1. **D3 独立权威来源 = 0 分**：一个没有独立威信、完全依赖创始人背书的新合伙人，转型后极易沦为"空降傀儡"。
2. **D8 权力谦逊度 = 0 分**：一个心浮气躁、急于清洗旧臣的新合伙人，必然引发剧烈的防卫性反击。
3. **D6 心理韧性与耐心 = 0 分**：情绪管理能力是转型过程中最重要的软技能，情绪失控者不适合驾驭复杂的合伙人关系。

### 标杆案例对照

| 标杆 | 关键做法 | 本表映射 |
|------|----------|----------|
| **新东方·直播电商团队** | 新团队深度理解东方甄选的"知识带货"必须依托老教师的表达能力和人文积淀 | D1 业务扎根深度 + D5 经验-数据翻译能力 |
| **K12 转型成功机构** | 新业务负责人曾在校区一线浸泡一年以上，与老教师建立了深厚信任 | D1 业务扎根深度 + D4 老合伙人关系网络 |
| **某转型失败教培机构** | 新合伙人空降自互联网大厂，对线下教育完全陌生，三个月内引发大规模教师出走 | D1 业务扎根深度 = 0 + D8 权力谦逊度 = 0 |

## 工具三：老合伙人转型适应风险评估表

### 评估说明

**适用对象**：跟随创始人 ≥8 年、且对原业务有深厚情感或持有股权的核心合伙人
**评估周期**：转型启动前启动，每位老合伙人单独评估，每季度复评
**评估方式**：创始人评 40% + 教练/顾问评 30% + 人力资源负责人评 30%
**总分**：100 分（得分越高，转型适应风险越低；得分越低，转型冲突越剧烈）

---

### 评分维度

| 维度 | 权重 | 评分标准 | 得分 |
|------|------|----------|------|
| **D1：转型态度清晰度** | 15 分 | 老合伙人已明确表达对转型的态度（支持、条件性支持、或明确反对），且态度稳定、不反复试探，得 15 分；态度模糊、时常释放矛盾信号，得 7 分；完全闭口不谈、让创始人猜测，得 0 分。 | |
| **D2：沉没成本脱敏度** | 20 分 | 老合伙人能够理性评估原业务资产的真实价值，不把"情感投入"等同于"经济价值"，得 20 分；情感投入较深但能听取外部评估，得 10 分；将原业务资产视为"不可触碰的禁地"，得 0 分。 | |
| **D3：新业务价值认同** | 15 分 | 老合伙人能够理解并认同新业务对公司的战略价值（哪怕不是自己擅长的领域），得 15 分；有认知但内心不认同，得 8 分；完全否定新业务的价值或前景，得 0 分。 | |
| **D4：权力交接配合度** | 15 分 | 老合伙人已开始主动配合资源向新业务转移、逐步移交核心客户/供应商关系、支持新合伙人的对外活动，得 15 分；表面上配合但暗中保留关键资源，得 7 分；抗拒交接、威胁"没有我这块业务就垮"，得 0 分。 | |
| **D5：与新合伙人关系温度** | 10 分 | 老合伙人与新合伙人之间至少保持互相尊重的工作关系，偶尔能单独交流，得 10 分；关系冷淡、仅限工作邮件往来，得 5 分；关系公开破裂、在会议上互相顶撞，得 0 分。 | |
| **D6：学习开放度** | 10 分 | 老合伙人愿意学习新业务的基本逻辑和数据语言，不因"我不懂"而拒绝沟通，得 10 分；愿意倾听但不主动学习，得 5 分；完全排斥新语言、新工具、新流程，得 0 分。 | |
| **D7：外部选择空间** | 10 分 | 老合伙人若转型后离开公司，有明确的外部选择（创业、咨询、行业协会、享受天伦之乐），不会感到"人生空虚"，得 10 分；外部选择模糊，对退休/离开充满焦虑，得 5 分；除了公司和原业务没有任何身份认同来源，得 0 分。 | |
| **D8：家庭支持度** | 5 分 | 老合伙人的配偶/子女支持其转型决定（无论是留下还是离开），不会在家庭内部制造"你被亏待了"的情绪，得 5 分；家庭态度中立，得 3 分；家庭成员强烈反对转型、鼓动老合伙人争取更高补偿，得 0 分。 | |

---

### 阈值说明与风险等级

| 总分 | 风险等级 | 含义 | 建议动作 |
|------|----------|------|----------|
| **85-100 分** | 🟢 低风险 | 老合伙人转型适应意愿清晰、配合度高，转型过程预计平稳 | 继续发挥其在转型中的"稳定器"和"资源连接器"作用 |
| **65-84 分** | 🟡 中风险 | 存在 1-2 个摩擦点，但通过沟通和补偿设计可以化解 | 启动一对一转型沟通，优先补齐 D2（沉没成本脱敏）和 D3（价值认同） |
| **45-64 分** | 🟠 高风险 | 多个维度亮起红灯，转型可能演变为激烈冲突，甚至竞业诉讼或团队出走 | 暂停公开转型程序，创始人亲自出面做"情感打底"，聘请第三方 mediator 介入 |
| **≤44 分** | 🔴 极高风险 | 老合伙人转型适应极有可能引爆重大危机，对企业造成不可估量的损失 | 建议重新评估"必须此时强推"的假设；若必须推进，需启动危机公关和法律预案 |

---

### 特别警示："转型战争"高发组合

若某位老合伙人的评估结果同时满足以下任意组合，需立即升级为最高警戒：

**组合 A：沉没成本战争型**
- D2 沉没成本脱敏度 = 0 分
- D4 权力交接配合度 = 0 分
- **预示**：老合伙人将把任何转型视为"对毕生心血的背叛"，任何调整都会触发激烈抵抗。

**组合 B：信任崩塌型**
- D3 新业务价值认同 = 0 分
- D5 与新合伙人关系温度 = 0 分
- D7 外部选择空间 = 0 分
- **预示**：老合伙人感到被"抛弃"，极有可能在转型过程中公开诋毁新合伙人或带走核心团队。

**组合 C：协议对抗型**
- D1 转型态度清晰度 = 0 分
- D6 学习开放度 = 0 分
- **预示**：老合伙人因沉没成本执念硬撑岗位，占着资源不放手，成为转型的最大阻力，迟早诉诸法律手段。

### 标杆案例对照

| 标杆 | 关键做法 | 本表映射 |
|------|----------|----------|
| **新东方** | 俞敏洪为多位老教师设计了"知识主播"转型路径，让老教师的表达能力和粉丝基础成为直播电商的核心资产 | D3 新业务价值认同 + D4 权力交接配合度 |
| **K12 转型成功机构** | 为老校区负责人安排了"素质课程研发顾问"或"家庭教育指导师"的新角色 | D7 外部选择空间 + D2 沉没成本脱敏 |
| **某转型失败教培机构** | 原合伙人因校区被关停而发起竞业诉讼，带走核心教师和学员名单 | D2 沉没成本脱敏 = 0 + D5 与新合伙人关系温度 = 0 |

## 评估工具包使用流程图

```
Step 1: 确定评估对象和时机
    ├─ 合伙协议健康度 → 转型决策前必须评估
    ├─ 新合伙人准备度 → 引入或赋予大权前基线评估
    └─ 老合伙人适应风险 → 每位老合伙人单独，转型前启动

Step 2: 指定评估人和权重
    ├─ 创始人必须参与所有三项评估
    ├─ 新合伙人参与协议健康度评估（学习视角）
    ├─ 老合伙人不参与新合伙人评估（避免偏见）
    └─ 外部教练全程参与并提供交叉验证

Step 3: 逐项打分并记录依据
    └─ 每个得分都需附 1-2 句话的事实依据

Step 4: 汇总总分并定位阈值
    └─ 输出红绿灯判定

Step 5: 制定针对性行动计划
    └─ 对黄灯/橙灯/红灯项，给出 30/60/90 天整改计划

Step 6: 教练复盘会议
    └─ 向创始人汇报评估结果，讨论下一步资源配置
```

*本评估工具包由满意解研究所基于 12x8 冲突域映射与三大标杆案例实践开发，深度融合五路图腾方法论与"契·晋"精神，所有阈值均经过合伙人冲突案例库验证。*
