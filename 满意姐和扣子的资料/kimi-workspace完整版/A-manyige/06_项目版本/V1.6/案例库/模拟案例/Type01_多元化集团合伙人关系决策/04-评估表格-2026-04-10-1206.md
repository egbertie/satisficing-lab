# 多元化集团合伙人关系决策 —— 评估工具包

> **服务代号**：Type-1 接班人盾  > **版本**：V1.0  > **生成时间**：2026-04-10 12:06

---

## 工具一：股权结构健康度评分表

### 评估说明

**适用对象**：集团层面（含母公司及核心业务板块控股公司）的股权架构
**评估周期**：建议在接班窗口期每年评估一次，接班重大节点前必须评估
**评估方式**：创始人 + 财务负责人 + 外部法律顾问联合填写，教练复核
**总分**：100 分

---

### 评分维度

| 维度 | 权重 | 评分标准 | 得分 |
|------|------|----------|------|
| **D1：创始人/家族控制权** | 20 分 | 创始人或家族合计持股 ≥66.7%（拥有绝对控制权），得 20 分；50%-66.6%，得 12 分；33.4%-49.9%，得 6 分；≤33.3%，得 0 分。 | |
| **D2：法定代表人配置** | 15 分 | 法定代表人由创始人或二代担任，得 15 分；由创始人/二代信任的家族成员担任，得 8 分；由非家族职业经理人或元老担任，得 0 分。 | |
| **D3：股权动态调整机制** | 15 分 | 已建立明确的股权动态调整机制（如 Vesting、绩效考核股权、增资约定），且文件经律师审核，得 15 分；有约定但不够完善，得 8 分；完全无动态调整机制，得 0 分。 | |
| **D4：反稀释与保护条款** | 10 分 | 创始人/家族持股享有明确的反稀释条款、优先认购权或一票否决权（至少具备一项），得 10 分；无任何保护条款，得 0 分。 | |
| **D5：代持风险排查** | 10 分 | 已完成全面代持排查，确认无任何代持安排，得 10 分；有代持但已签署经公证的代持协议并清晰约定还原路径，得 5 分；存在未规范代持，得 0 分。 | |
| **D6：有限合伙架构审查** | 10 分 | 无有限合伙平台，或有限合伙平台的 GP 由创始人/家族控制，得 10 分；有有限合伙但 GP 由外部投资人或元老控制，得 3 分；有限合伙架构不清、GP/LP 权利边界模糊，得 0 分。 | |
| **D7：股东退出机制** | 10 分 | 所有股东（含元老）已签署明确的股权回购/退出协议，约定触发条件、定价方式、付款节奏，得 10 分；有约定但不够清晰（如定价方式模糊），得 5 分；无任何书面退出机制，得 0 分。 | |
| **D8：板块间股权隔离** | 10 分 | 各业务板块股权边界清晰，不存在混同、交叉持股导致责任不清的情况，得 10 分；存在一定混同但可梳理，得 5 分；板块股权严重混同，得 0 分。 | |

---

### 阈值说明与健康等级

| 总分 | 健康等级 | 含义 | 建议动作 |
|------|----------|------|----------|
| **85-100 分** | 🟢 健康 | 股权结构对接班友好，具备足够的调整弹性和安全垫 | 维持现状，每年复查 |
| **60-84 分** | 🟡 亚健康 | 存在 1-3 个结构性风险点，接班过程中可能被触发 | 3 个月内针对性整改，优先处理 D1/D2/D7 |
| **35-59 分** | 🟠 病态 | 股权结构已对接班构成实质性障碍，任何接班动作都可能引发连锁冲突 | 必须暂停接班时间表，6 个月内完成股权重构 |
| **≤34 分** | 🔴 高危 | 股权结构处于崩溃边缘，极有可能爆发诉讼、分家或控制权争夺 | 立即启动危机干预，建议创始人亲自坐镇谈判 |

---

### 标杆案例对照

| 标杆 | 关键做法 | 本表映射 |
|------|----------|----------|
| **美的集团** | 何享健通过事业部制+股权激励，让方洪波既有动力又有约束 | D3 股权动态调整机制 + D6 有限合伙激励平台 |
| **新希望** | 刘永好保持家族绝对控制权，同时给予职业经理人充分的经营授权 | D1 控制权 + D2 法定代表人配置 |
| **万向集团** | 鲁冠球在世时已完成治理结构现代化，股权清晰、代持清零 | D5 代持风险排查 + D8 板块间股权隔离 |

## 工具二：二代接班准备度评估表

### 评估说明

**适用对象**：拟任接班人的二代子女（或家族选定接班人）
**评估周期**：接班前 2-3 年进行基线评估，之后每半年复评一次
**评估方式**：360 度评估（创始人评 40% + 元老代表评 30% + 外部教练评 30%）
**总分**：100 分

---

### 评分维度

| 维度 | 权重 | 评分标准 | 得分 |
|------|------|----------|------|
| **D1：业务扎根深度** | 15 分 | 已在集团核心业务板块一线历练 ≥5 年，且有过独立负责一个 BU/子公司并取得可量化业绩增长的经历，得 15 分；历练 3-5 年但无独立掌舵经历，得 8 分；历练时间 <3 年或全程在总部/职能部门，得 0 分。 | |
| **D2：跨板块协同能力** | 15 分 | 曾成功主导过一次涉及 2 个及以上业务板块的协同项目（如资源整合、人力调配、供应链共享），并获得板块负责人的认可，得 15 分；有参与但非主导，得 8 分；无任何跨板块项目经验，得 0 分。 | |
| **D3：独立权威来源** | 15 分 | 至少有一次在没有创始人直接出面或背书的情况下，独立解决过重大危机或复杂矛盾，并赢得各方尊重，得 15 分；有独立处理中等问题的经历，得 8 分；所有重大决策均依赖创始人站台，得 0 分。 | |
| **D4：元老关系网络** | 10 分 | 与至少 2/3 以上的元老建立了超越工作关系的私人信任（如定期单独沟通、节日问候、家庭往来），得 10 分；与半数以上元老保持礼貌但疏离的工作关系，得 5 分；与多数元老关系紧张或被排斥在小圈子外，得 0 分。 | |
| **D5：文化翻译能力** | 10 分 | 能够在"老臣语言"（人情、义气、经验）和"新管理语言"（数据、流程、KPI）之间自如切换，并让两代人都感到被尊重，得 10 分；只能在一种语言体系中自如表达，得 5 分；两种语言都表达生硬，引发误解，得 0 分。 | |
| **D6：心理韧性与耐心** | 10 分 | 面对元老的质疑或否定，能够保持情绪稳定、不急不躁、用事实和结果逐步赢得认可，得 10 分；偶有情绪失控但事后能修复，得 5 分；频繁与元老发生正面冲突或公开对立，得 0 分。 | |
| **D7：战略清晰度** | 15 分 | 对集团未来 3-5 年的发展路径有清晰、连贯、可落地的战略规划，并能在董事会上清晰阐述、回应挑战，得 15 分；有想法但不够系统，得 8 分；战略方向模糊或频繁摇摆，得 0 分。 | |
| **D8：权力谦逊度** | 10 分 | 清楚认识到接班不是"继承王位"而是"重新谈判入场券"，愿意在接班初期保留元老的话语权和尊严，得 10 分；态度尚可但偶有颐指气使，得 5 分；表现出强烈的"清洗老臣"倾向或过度傲慢，得 0 分。 | |

---

### 阈值说明与准备等级

| 总分 | 准备等级 | 含义 | 建议动作 |
|------|----------|------|----------|
| **85-100 分** | 🟢 成熟 ready | 二代已具备接班所需要的业务根基、人际网络和心理准备，可以启动正式接班程序 | 启动权力交接，创始人可逐步后撤 |
| **65-84 分** | 🟡 基本 ready | 二代在主要维度上达标，但仍有 1-2 个明显短板，接班过程需要辅以教练陪伴和制度缓冲 | 设计 6-12 个月的能力补强计划，元老沟通专项辅导 |
| **45-64 分** | 🟠 尚不成熟 | 二代在多个关键维度上存在 Gap，若强行接班容易导致组织动荡或被架空 | 延长历练期 1-2 年，或考虑"联席 CEO/过渡总裁"机制 |
| **≤44 分** | 🔴 不成熟 | 二代目前远未达到接班要求，强行接班将对企业和家族都造成重大伤害 | 重新审视接班人选，启动 Plan B 评估；创始人不宜短期内退居二线 |

---

### 特别说明：各维度的"一票否决"红线

以下情况出现时，无论其他维度得分多高，**总体准备等级最多只能评为 🟠 尚不成熟**：

1. **D3 独立权威来源 = 0 分**：一个没有独立威信、完全依赖创始人背书的接班人，接班后极易沦为傀儡。
2. **D8 权力谦逊度 = 0 分**：一个心浮气躁、急于清洗老臣的接班人，必然引发剧烈的防卫性反击。
3. **D6 心理韧性与耐心 = 0 分**：情绪管理能力是接班过程中最重要的软技能，情绪失控者不适合驾驭复杂的合伙人关系。

---

### 标杆案例对照

| 标杆 | 关键做法 | 本表映射 |
|------|----------|----------|
| **美的集团·方洪波** | 从基层业务员做起，历任多个事业部负责人，在何享健的观察下逐步证明自己的能力 | D1 业务扎根深度 + D3 独立权威来源 |
| **新希望·刘畅** | 早期从边缘业务开始历练，2013 年正式出任董事长前已积累近 10 年内部信任 | D4 元老关系网络 + D6 心理韧性与耐心 |
| **万向集团·鲁伟鼎** | 父亲在世时深度参与战略决策，同时保持低调谦逊，不急于彰显个人权威 | D5 文化翻译能力 + D8 权力谦逊度 |

## 工具三：元老退出风险评估表

### 评估说明

**适用对象**：跟随创始人 ≥10 年、且持有股权或担任核心高管的元老合伙人
**评估周期**：接班窗口期前两年启动，每位元老单独评估，每半年复评
**评估方式**：创始人评 40% + 教练/顾问评 30% + 人力资源负责人评 30%
**总分**：100 分（得分越高，退出风险越低；得分越低，退出风险越高/退出冲突越剧烈）

---

### 评分维度

| 维度 | 权重 | 评分标准 | 得分 |
|------|------|----------|------|
| **D1：退出意愿清晰度** | 15 分 | 元老已明确表达退出意愿（想退或不想退），且态度稳定、不反复试探，得 15 分；态度模糊、时常释放矛盾信号（一会儿想退一会儿又表忠心），得 7 分；完全闭口不谈、让创始人猜测，得 0 分。 | |
| **D2：退出经济保障** | 20 分 | 股权回购/退出金额已有清晰计算，且元老及其家属对价格有基本认可，得 20 分；有框架但尚未细化到具体数字，得 10 分；完全未讨论或双方预期差距极大（如 10 倍以上），得 0 分。 | |
| **D3：退出后荣誉安排** | 15 分 | 已有明确的荣誉安排（如终身名誉职位、公司历史馆署名、周年庆典特邀嘉宾、家族礼遇），得 15 分；有口头承诺但无制度化安排，得 8 分；完全没有荣誉安排意识，得 0 分。 | |
| **D4：权力交接配合度** | 15 分 | 元老已开始主动培养接替者、逐步移交核心客户/供应商关系、配合二代出席对外活动，得 15 分；表面上配合但暗中保留关键资源，得 7 分；抗拒交接、威胁"我走了客户也跟着走"，得 0 分。 | |
| **D5：与二代关系温度** | 10 分 | 元老与二代之间至少保持互相尊重的工作关系，偶尔能单独交流，得 10 分；关系冷淡、仅限工作邮件往来，得 5 分；关系公开破裂、在会议上互相顶撞，得 0 分。 | |
| **D6：身体健康与精力** | 10 分 | 元老身体状况良好、精力充沛，退出更多是主动的人生规划选择，得 10 分；身体尚可但明显感到力不从心，得 5 分；身体状况差、频繁因病缺席，但出于沉没成本执念硬撑，得 0 分。 | |
| **D7：外部选择空间** | 10 分 | 元老退出后有明确的外部选择（创业、咨询、行业协会、享受天伦之乐），不会感到"人生空虚"，得 10 分；外部选择模糊，对退休生活充满焦虑，得 5 分；除了公司没有任何身份认同来源，得 0 分。 | |
| **D8：家庭支持度** | 5 分 | 元老的配偶/子女支持其退出决定，不会在家庭内部制造"你被亏待了"的情绪，得 5 分；家庭态度中立，得 3 分；家庭成员强烈反对退出、鼓动元老争取更高补偿，得 0 分。 | |

---

### 阈值说明与风险等级

| 总分 | 风险等级 | 含义 | 建议动作 |
|------|----------|------|----------|
| **85-100 分** | 🟢 低风险 | 元老退出意愿清晰、经济条件可接受、交接配合度高，退出过程预计平稳 | 按既定时间表推进退出仪式，重点做好荣誉安排 |
| **65-84 分** | 🟡 中风险 | 存在 1-2 个摩擦点，但通过谈判和补偿设计可以化解 | 启动一对一退出谈判，优先补齐 D2（经济保障）和 D3（荣誉安排） |
| **45-64 分** | 🟠 高风险 | 多个维度亮起红灯，退出可能演变为激烈冲突，甚至诉讼或出走带客户 | 暂停公开退出程序，创始人亲自出面做"情感打底"，聘请第三方 mediator 介入 |
| **≤44 分** | 🔴 极高风险 | 元老退出极有可能引爆重大危机，对企业造成不可估量的损失 | 建议重新评估"必须此时退出"的假设；若必须退出，需启动危机公关和法律预案 |

---

### 特别警示："退出战争"高发组合

若某位元老的评估结果同时满足以下任意组合，需立即升级为最高警戒：

**组合 A：经济战争型**
- D2 退出经济保障 = 0 分
- D8 家庭支持度 = 0 分
- **预示**：元老及其家庭将把退出视为"最后的利益争夺战"，谈判极易破裂。

**组合 B：情感反噬型**
- D3 退出后荣誉安排 = 0 分
- D5 与二代关系温度 = 0 分
- D7 外部选择空间 = 0 分
- **预示**：元老感到被"抛弃"，极有可能在离开后公开诋毁二代或带走核心团队。

**组合 C：硬撑拖累型**
- D1 退出意愿清晰度 = 0 分
- D4 权力交接配合度 = 0 分
- D6 身体健康与精力 = 0 分
- **预示**：元老因沉没成本执念硬撑岗位，占着位置不做事，成为二代改革的最大阻力。

---

### 标杆案例对照

| 标杆 | 关键做法 | 本表映射 |
|------|----------|----------|
| **美的集团** | 何享健为老臣设计了丰厚的退休包和荣誉董事制度，老臣体面离场后仍被视为"美的家人" | D2 退出经济保障 + D3 荣誉安排 |
| **新希望** | 刘永好在刘畅接班前后，为多位元老安排了创业投资基金合伙人或行业协会职务 | D7 外部选择空间 + D3 荣誉安排 |
| **万向集团** | 鲁冠球在世时逐步将元老从经营一线转移到战略顾问角色，完成了心理上的"软着陆" | D1 退出意愿清晰度 + D4 权力交接配合度 |

## 评估工具包使用流程图

```
Step 1: 确定评估对象和时机
    ├─ 股权结构健康度 → 集团层面，每年一次
    ├─ 二代接班准备度 → 拟任接班人，基线+半年复评
    └─ 元老退出风险 → 每位元老单独，接班前两年启动

Step 2: 指定评估人和权重
    ├─ 创始人必须参与所有三项评估
    ├─ 二代参与股权结构评估（学习视角）
    ├─ 元老代表不参与二代评估（避免偏见）
    └─ 外部教练全程参与并提供交叉验证

Step 3: 逐项打分并记录依据
    └─ 每个得分都需附 1-2 句话的事实依据

Step 4: 汇总总分并定位阈值
    └─ 输出红绿灯判定

Step 5: 制定针对性行动计划
    └─ 对黄灯/橙灯/红灯项，给出 30/60/90 天整改计划

Step 6: 教练复盘会议
    └─ 向创始人汇报评估结果，讨论下一步资源配置
```

---

*本评估工具包由满意解研究所基于 12x8 冲突域映射与三大标杆案例实践开发，所有阈值均经过合伙人冲突案例库验证。*
