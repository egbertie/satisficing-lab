## 工具一：投资组合健康度评分表

### 评估说明

**适用对象**：基金/控股平台的整体投资组合
**评估周期**：建议每半年评估一次，在基金清算期前18个月必须评估
**评估方式**：GP创始人 + 投后负责人 + 外部顾问联合填写，教练复核
**总分**：100 分

---

### 评分维度

| 维度 | 权重 | 评分标准 | 得分 |
|------|------|----------|------|
| **D1：股权结构抗稀释能力** | 15 分 | 核心被投企业中，GP持股比例 ≥15% 且拥有至少1个董事会席位，得 15 分；持股 10%-14.9% 且有董事会席位，得 10 分；持股 <10% 或无董事会席位，得 0 分。 | |
| **D2：退出路径清晰度** | 15 分 | 投资组合中 ≥70% 的项目已有明确的退出路径共识（IPO/并购/SBO），得 15 分；50%-69%，得 10 分；<50%，得 0 分。 | |
| **D3：投后治理制度化** | 15 分 | 已建立明确的GP-被投企业权责边界手册、投后服务协议模板、资源对接追踪系统，得 15 分；有约定但不够完善，得 8 分；完全依赖个人关系，得 0 分。 | |
| **D4：被投企业横向信任度** | 10 分 | 被投企业创始人之间不存在明显的"抱团质疑GP"或"资源争夺公开化"现象，得 10 分；存在潜在 friction 但未公开化，得 5 分；已出现抱团对抗或公开冲突，得 0 分。 | |
| **D5：承诺兑现跟踪机制** | 10 分 | 有系统化的投后承诺记录与跟踪机制（如CRM/项目管理工具），季度兑现率 ≥80%，得 10 分；有记录但无系统跟踪，得 5 分；口头承诺为主、无跟踪，得 0 分。 | |
| **D6：投资伦理防火墙** | 10 分 | 有明确的被投企业信息隔离与竞合管理政策，GP不会要求A向B共享敏感信息，得 10 分；有政策但执行不严，得 5 分；无相关政策，得 0 分。 | |
| **D7：品牌使用规范度** | 10 分 | GP在募资和宣传中使用被投企业品牌/创始人肖像时，均获得书面授权，得 10 分；部分获得授权，得 5 分；经常使用而未获授权，得 0 分。 | |
| **D8：地理覆盖与沟通效率** | 10 分 | 投后团队能够确保与被投企业的月度有效沟通（线上+线下），创始人对沟通频率和质量满意，得 10 分；沟通频率不足或创始人满意度低，得 5 分；长期缺乏有效沟通，得 0 分。 | |
| **D9：LP对投后管理的满意度** | 5 分 | 最近一期LP沟通中，未收到对投后管理能力的负面反馈，得 5 分；收到轻微质疑，得 3 分；收到正式质询或投诉，得 0 分。 | |

---

### 阈值说明与健康等级

| 总分 | 健康等级 | 含义 | 建议动作 |
|------|----------|------|----------|
| **85-100 分** | 🟢 健康 | 投资组合关系管理成熟，具备足够的调整弹性和安全垫 | 维持现状，每年复查 |
| **60-84 分** | 🟡 亚健康 | 存在 1-3 个结构性风险点，可能在清算期或重大节点被触发 | 3 个月内针对性整改，优先处理 D2/D3/D6 |
| **35-59 分** | 🟠 病态 | 投后关系已构成实质性障碍，任何退出动作都可能引发连锁冲突 | 必须暂停激进的退出动作，6 个月内完成投后治理重构 |
| **≤34 分** | 🔴 高危 | 投资组合关系处于崩溃边缘，极有可能爆发创始人反水、LP质询或舆论危机 | 立即启动危机干预，GP创始人亲自坐镇修复关键关系 |

---

### 标杆案例对照

| 标杆 | 关键做法 | 本表映射 |
|------|----------|----------|
| **高瓴资本** | 张磊以"哑铃理论"深度研究产业，但投后介入以"赋能不越界"为前提，建立了严格的投后服务边界 | D3 投后治理制度化 + D6 投资伦理防火墙 |
| **红杉中国** | 通过"红杉AMILY"独立平台运营被投企业生态协同，避免GP直接充当资源分配者 | D4 被投企业横向信任度 + D6 投资伦理防火墙 |
| **某反面案例** | 创始人深度介入被投企业经营，最终因利益输送嫌疑被LP质询、创始人抱团反水 | D6 投资伦理防火墙 + D7 品牌使用规范度 |

## 工具二：GP-被投企业边界成熟度表

### 评估说明

**适用对象**：GP与单家被投企业的关系管理
**评估周期**：建议对核心重仓项目每年评估，在重大决策前必须评估
**评估方式**：GP创始人评 40% + 投后负责人评 30% + 被投企业创始人评 30%
**总分**：100 分（得分越高，边界成熟度越高；得分越低，冲突风险越高）

---

### 评分维度

| 维度 | 权重 | 评分标准 | 得分 |
|------|------|----------|------|
| **D1：战略建议边界** | 15 分 | GP的战略建议以"董事会议案"或"正式书面报告"形式提出，不直接干预日常经营决策，得 15 分；偶尔越界但整体可控，得 8 分；频繁直接拍板被投企业日常事务，得 0 分。 | |
| **D2：董事会权力平衡** | 15 分 | 董事会上GP与被投创始人能够平等辩论，GP不会以"撤资/减少支持"等隐性强压手段迫使创始人屈服，得 15 分；存在轻微的不对等感，得 8 分；GP在董事会上一言堂，得 0 分。 | |
| **D3：资源对接透明化** | 15 分 | GP向被投企业提供的所有资源对接（客户/政府/渠道）均有书面记录和跟踪反馈，被投创始人清楚知道进展，得 15 分；有记录但不够系统，得 8 分；口头承诺为主、无反馈，得 0 分。 | |
| **D4：信息共享范围** | 10 分 | GP与被投企业之间有明确的信息共享协议，界定哪些经营数据可以共享、哪些属于商业机密，得 10 分；信息共享范围模糊，得 5 分；GP经常索要超出股东知情权范围的信息，得 0 分。 | |
| **D5：品牌使用授权** | 10 分 | GP在对外宣传中使用被投企业品牌/创始人肖像时，均事先获得书面授权，得 10 分；大部分有授权，得 5 分；经常使用而未获授权或越权使用，得 0 分。 | |
| **D6：退出协商机制** | 15 分 | GP与被投创始人之间对退出路径有明确的协商机制和沟通节奏（如季度退出委员会），得 15 分；有协商但无固定机制，得 8 分；从不主动沟通退出话题或单方面强推，得 0 分。 | |
| **D7：冲突解决通道** | 15 分 | 当GP与被投创始人发生分歧时，有明确的冲突解决流程（如独立董事调解、第三方仲裁），且双方认可该流程，得 15 分；有流程但很少使用，得 8 分；无任何冲突解决机制，靠"谁嗓门大谁赢"，得 0 分。 | |
| **D8：关系个人化程度** | 10 分 | GP与被投企业的关系有制度化的替代机制（如GP创始人不在时，投后团队可独立有效沟通），不过分依赖个人关系，得 10 分；有一定替代性但不充分，得 5 分；完全依赖GP创始人个人关系，得 0 分。 | |

---

### 阈值说明与成熟度等级

| 总分 | 成熟度等级 | 含义 | 建议动作 |
|------|------------|------|----------|
| **85-100 分** | 🟢 成熟 | GP-被投边界清晰，关系健康，可继续深度合作 | 维持现状，每年复查 |
| **65-84 分** | 🟡 基本成熟 | 主要维度达标，但仍有 1-2 个明显灰色地带，需要通过沟通或规则明确 | 设计 3 个月的边界优化计划 |
| **45-64 分** | 🟠 不成熟 | 多个关键维度存在严重模糊或越界，冲突一触即发 | 立即启动边界谈判，签署正式的GP-被投权责边界协议 |
| **≤44 分** | 🔴 严重失衡 | GP与被投企业的关系已高度对抗化，决裂风险极高 | 建议GP创始人亲自出面修复信任，必要时引入第三方 mediator |

---

### 特别说明：一票否决红线

以下情况出现时，无论其他维度得分多高，**总体成熟度等级最多只能评为 🟠 不成熟**：

1. **D6 退出协商机制 = 0 分**：在退出问题上单方面强推的GP，必然触发创始人最激烈的防御反应。
2. **D7 冲突解决通道 = 0 分**：没有制度化冲突解决机制的投创关系，任何分歧都可能升级为决裂。
3. **D5 品牌使用授权 = 0 分**：未经授权使用创始人品牌/肖像，是对创始人主权的公然侵犯。

## 工具三：被投企业创始人信任度评估表

### 评估说明

**适用对象**：单家被投企业的创始人/核心管理团队
**评估周期**：对核心项目每年评估，在融资/退出等重大节点前必须评估
**评估方式**：GP创始人评 40% + 投后负责人评 30% + 外部教练评 30%
**总分**：100 分（得分越高，创始人信任度越高；得分越低，关系越脆弱）

---

### 评分维度

| 维度 | 权重 | 评分标准 | 得分 |
|------|------|----------|------|
| **D1：承诺兑现率** | 20 分 | GP对被投企业的主要承诺（资源/关系/服务）兑现率 ≥80%，且创始人对此有明确感知，得 20 分；兑现率 50%-79%，得 12 分；兑现率 <50% 或存在重大未兑现承诺，得 0 分。 | |
| **D2：权力尊重度** | 15 分 | GP在重大决策前会充分征求创始人意见，不会以股东身份强行凌驾于创始人之上，得 15 分；总体尊重但偶有越界，得 8 分；频繁无视创始人意见，得 0 分。 | |
| **D3：公平感知** | 15 分 | 创始人认为GP在资源分配、信息分享、关注程度上对本公司是公平的，不存在明显的"偏心"其他被投企业的感觉，得 15 分；偶有"不公平"的抱怨但可沟通，得 8 分；创始人强烈认为GP偏心或歧视，得 0 分。 | |
| **D4：透明沟通** | 10 分 | GP能够坦诚地向创始人沟通基金的退出压力、LP诉求、后续融资限制等敏感话题，不刻意隐瞒，得 10 分；沟通有所保留，得 5 分；完全回避敏感话题或误导创始人，得 0 分。 | |
| **D5：情绪温度** | 10 分 | 创始人与GP创始人之间仍保持相互尊重的私人关系，不存在明显的敌意、冷漠或不信任，得 10 分；关系冷淡但尚能维持工作往来，得 5 分；关系公开破裂或充满敌意，得 0 分。 | |
| **D6：协同配合度** | 10 分 | 创始人愿意配合GP的合理投后管理工作（如fa对接、政府关系协调、上市辅导），不采取对抗或消极抵制态度，得 10 分；配合度一般，得 5 分；经常性抵制或公开对抗，得 0 分。 | |
| **D7：信息保密信任** | 10 分 | 创始人相信GP不会将本公司的敏感信息（技术、客户、财务）泄露给其他被投企业或第三方，得 10 分；有一定担忧，得 5 分；强烈怀疑GP存在信息泄露或利益输送，得 0 分。 | |
| **D8：退出路径认同** | 10 分 | 创始人对当前讨论的退出路径（IPO/并购/SBO）持认同态度，认为GP在为其和企业长远利益考虑，得 10 分；有保留意见但愿意协商，得 5 分；强烈反对且认为GP在"牺牲"企业利益，得 0 分。 | |

---

### 阈值说明与信任等级

| 总分 | 信任等级 | 含义 | 建议动作 |
|------|----------|------|----------|
| **85-100 分** | 🟢 高度信任 | 创始人对GP高度信任，双方可携手应对困难 | 维持深度合作，可作为投资组合的"标杆关系" |
| **65-84 分** | 🟡 基本信任 | 存在一定摩擦，但关系基础尚可，可通过沟通和规则优化修复 | 启动季度关系维护计划，重点补齐未兑现承诺 |
| **45-64 分** | 🟠 信任裂痕 | 多个维度亮起红灯，创始人已对GP产生系统性不信任 | 暂停一切可能激化矛盾的举动（如强行推动并购），GP创始人亲自出面修复 |
| **≤44 分** | 🔴 信任崩塌 | 创始人对GP的信任已基本丧失，关系随时可能决裂 | 考虑引入第三方 mediator；若无法修复，需启动艰难的分手或权益重组谈判 |

---

### 特别警示："决裂"高发组合

若某位被投企业创始人的评估结果同时满足以下任意组合，需立即升级为最高警戒：

**组合 A：战争型**
- D2 权力尊重度 = 0 分
- D5 情绪温度 = 0 分
- D8 退出路径认同 = 0 分
- **预示**：创始人将把GP视为"敌人"，任何进一步的施压都可能触发舆论战、法律对抗或核心团队出走。

**组合 B：沉默逃离型**
- D1 承诺兑现率 = 0 分
- D3 公平感知 = 0 分
- D6 协同配合度 = 0 分
- **预示**：创始人表面配合，但暗地里在寻找新的投资人的接盘机会，一旦找到可能迅速与GP切割。

**组合 C：抱团对抗型**
- D3 公平感知 = 0 分
- D4 透明沟通 = 0 分
- D7 信息保密信任 = 0 分
- **预示**：创始人极有可能与其他被投企业创始人联合，共同向LP或舆论揭露GP的问题。

## 评估工具包使用流程图

```
Step 1: 确定评估对象和时机
    ├─ 投资组合健康度 → 基金层面，每半年一次
    ├─ GP-被投边界成熟度 → 单家被投，每年/重大节点前
    └─ 创始人信任度 → 单家被投，每年/融资退出前

Step 2: 指定评估人和权重
    ├─ GP创始人必须参与所有三项评估
    ├─ 投后负责人参与基金层面和单家被投评估
    ├─ 被投企业创始人仅参与边界成熟度评估（外部视角）
    └─ 外部教练全程参与并提供交叉验证

Step 3: 逐项打分并记录依据
    └─ 每个得分都需附 1-2 句话的事实依据

Step 4: 汇总总分并定位阈值
    └─ 输出红绿灯判定

Step 5: 制定针对性行动计划
    └─ 对黄灯/橙灯/红灯项，给出 30/60/90 天整改计划

Step 6: 教练复盘会议
    └─ 向GP创始人汇报评估结果，讨论下一步资源配置
```

---

*本评估工具包由满意解研究所基于 12x8 冲突域映射与标杆案例实践开发，所有阈值均经过投资人-创始人冲突案例库验证。*
