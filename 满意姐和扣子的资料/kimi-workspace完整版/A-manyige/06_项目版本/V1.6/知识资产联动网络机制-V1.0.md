## 三、联动路径设计 (场景化)

### 路径A: 新客户咨询场景

```
触发: 新客户询问"你们做什么"
↓
调用: 总纲底稿 (战略定位一句话) 
+ 知识复利飞轮产品定义 (Layer 1价值)
+ SKU-A标准化扫描 (轻量级入口)
+ 五路图腾体系 (精神底座说明)
↓
输出: 5分钟快速认知包 (整合上述4节点)
```

### 路径B: 合伙人冲突深度咨询

```
触发: 客户描述具体冲突场景
↓
调用: 12类型案例体系 (快速匹配类型)
+ 真实案例库 (同类型实战案例)
+ 工具模板 (BONSAI偏离度速算卡)
+ 专家档案 (匹配领域专家)
↓
输出: 类型定位+案例对标+工具评估+专家背书
```

### 路径C: 内部项目复盘

```
触发: 季度/项目节点复盘
↓
调用: 执行路线图 (阶段验证)
+ 任务总览 (进度核查)
+ 互评审计 (质量验证)
+ Token治理 (资源消耗复盘)
↓
输出: 阶段达成度+遗留任务+质量评分+资源效率
```

### 路径D: 内容生产/课程开发

```
触发: 需要生产新内容
↓
调用: 知识复利飞轮 (内容分层)
+ WX系列洞察 (外部情报)
+ 一堂方法论 (借鉴框架)
+ 12案例体系 (素材库)
↓
输出: 内容选题+素材包+借鉴框架+案例支撑
```

### 路径E: 专家沟通/邀约

```
触发: 需要联系某领域专家
↓
调用: 专家档案 (背景+联系方式)
+ 外援专家文档 (标准沟通材料)
+ 文化根脉纲领 (价值观对齐)
+ 总纲底稿 (项目全景)
↓
输出: 个性化邀约方案+标准材料包
```
