## 详细变更说明

### 1. 时间哲学：22年 → 三个11年·三生万物

| 阶段 | 核心叙事 |
|:-----|:---------|
| **前11年** | 大型商业银行风控体系历练 |
| **再11年** | 创业实战，3亿项目退出 |
| **现11年** | 满意解研究所（2026-2037），方法论体系化 |

**关键洞察**: 银行追求"最优解"，创业需要"满意解"——从个人经验到可复制框架。

---

### 2. 决策框架：五路图腾 → 五维决策罗盘

| 旧框架（五路图腾） | 新框架（五维决策罗盘） | 核心问题 |
|:-------------------|:-----------------------|:---------|
| 刘禹锡·土（价值纯度） | **时间轴** | 五年后如何看待今天？ |
| 司马贺·金（理性框架） | **可行域** | 我的"足够好"底线在哪？ |
| 观自在·水（压力管理） | **身心流** | 身体是否发出警报？ |
| 孔子·木（合伙人伦理） | **信义观** | 合伙人的"玉"经得起考验？ |
| 六祖慧能·火（直觉突破） | **直觉阈** | 聆听内心第一声音？ |

**变更原因**: "五路图腾"对非内部人是认知门槛，"五维决策罗盘"更直白、更可操作。

---

### 3. 产品体系：SKU-A/B/C/D → P0-P5五层金字塔

```
                    ┌─────────────┐
                    │    P5 认证层   │  ← 教练认证体系（长期）
                    │  ¥长期价值    │
                    └──────┬──────┘
                           ▼
                    ┌─────────────┐
                    │    P4 赋能层   │  ← 五维罗盘认证工作坊
                    │  ¥0.88-1.98万/人│
                    └──────┬──────┘
                           ▼
                    ┌─────────────┐
                    │    P3 干预层   │  ← 合伙人冲突急诊服务
                    │  ¥5.8-12万   │
                    └──────┬──────┘
                           ▼
                    ┌─────────────┐
                    │    P2 诊断层   │  ← 创始人决策深度校准（核心产品）
                    │  ¥3.8-5.8万  │
                    └──────┬──────┘
                           ▼
                    ┌─────────────┐
                    │    P1 感知层   │  ← 合伙人健康度自测卡
                    │  ¥0-999      │
                    └──────┬──────┘
                           ▼
                    ┌─────────────┐
                    │    P0 引流层   │  ← 深度内容资产（免费）
                    │     免费      │
                    └─────────────┘
```

**SKU与P0-P5映射**:
- SKU-A（自测卡）→ P1（感知层）
- SKU-B（深度咨询）→ P2（诊断层）
- SKU-C（危机干预）→ P3（干预层）
- SKU-D（课程授权）→ P4/P5（赋能层/认证层）

### 4. 定价策略：核心收入锚定

| 层级 | 定价 | 定位 |
|:-----|:-----|:-----|
| P0 | 免费 | 获客引流 |
| P1 | ¥0-999 / ¥15,000-30,000(机构) | 入口产品 |
| **P2** | **¥38,000-58,000** | **核心收入，利润中心** |
| **P3** | **¥58,000-120,000** | **增值服务，危机急诊** |
| P4 | ¥8,800-19,800/人 | 规模化 |
| P5 | 长期价值交换 | 生态构建 |

**定价锚定逻辑**:
- P2: 低于传统咨询（¥10万+/月），高于纯AI工具（¥999），占据"人机协同决策教练"心智位置
- P3: 72小时紧急响应 + 冲突调解专业技能，溢价100%

### 6. 发布时间：夏至（2026-06-21）

**为什么选择夏至？**
- 一年中白昼最长、阳气最盛的日子
- 象征"光明正大的展示"、"事业达到小高峰"
- 与五维罗盘的"直觉阈·火"维度呼应：红莲淬火，蓄势而发
- **契·晋之道**: 从契约到进阶，正式踏上"晋"之路

**夏至发布内容**:
- 《合伙人决策有据可依》白皮书V1.0
- 五维决策罗盘在线测评工具（P1正式上线）
- 寻契之旅纪录片/图文
- 首批客户案例集（8-12个）
- P2诊断服务正式发售

1. **P2/P3定价**: P2¥3.8-5.8万、P3¥5.8-12万是否仍偏低？DS原建议P2¥5-15万。
