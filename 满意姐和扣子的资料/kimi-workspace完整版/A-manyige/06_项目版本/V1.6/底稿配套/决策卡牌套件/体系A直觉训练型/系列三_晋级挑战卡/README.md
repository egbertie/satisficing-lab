## 🎯 系列定位

**晋级挑战卡™**是体系A直觉训练型的考核系列，用于段位晋级认证。

### 三级挑战

| 等级 | 适合人群 | 目标 | 认证段位 |
|:-----|:---------|:-----|:---------|
| **初级** | 新合伙人、创业者 | 建立基础决策能力 | 🥈 白银 |
| **中级** | 有经验决策者 | 提升复杂决策能力 | 🥇 黄金 |
| **高级** | 资深决策者 | 掌握战略决策能力 | 💎👑 铂金/钻石 |

### 核心特色

- 🎓 **考试模式**：不是练习，是能力认证
- 📜 **段位证书**：通过获得认证证书
- 🎖️ **特权解锁**：新段位解锁新训练模式
- 👨‍🏫 **教练资格**：钻石段位可申请认证教练

## 🚀 快速开始

### 挑战流程

```
1. 选择等级：初级/中级/高级
2. 了解规则：阅读通过标准
3. 开始挑战：连续完成10个场景（不可中断）
4. 场景决策：限时决策，记录选择
5. 教练点评：查看得分和分析
6. 累计得分：10个场景平均分
7. 判定结果：通过=晋级，失败=重考
8. 颁发认证：获得段位证书
```

### 通过标准

| 等级 | 通过平均分 | 失败重考 |
|:-----|:----------:|:---------|
| 初级 | ≥ +7.0 | 7天后 |
| 中级 | ≥ +8.0 | 14天后 |
| 高级 | ≥ +8.5 | 30天后 |

### 段位与特权

| 段位 | 通过挑战 | 特权 |
|:-----|:---------|:-----|
| 🥉 青铜 | 初始 | 基础训练 |
| 🥈 白银 | 初级 | 解锁对抗模式 |
| 🥇 黄金 | 中级 | 解锁教练引导 |
| 💎 铂金 | 高级（1-10）| 解锁盲选模式 |
| 👑 钻石 | 高级（全部）| 解锁自定义+教练资格 |

## 📖 详细规则

完整规则请参见：`体系A_系列三_机制文档_V1.0.md`

### 计分规则

| 选项 | 得分 | 评价 |
|:-----|:----:|:-----|
| A | -8~-5 | 重大错误，认知陷阱 |
| B | -4~-1 | 次优选择，有待改进 |
| C | +6~+8 | 较好选择，基本正确 |
| D | +9~+10 | **满意解**，最优平衡 |

### 重考限制

- 同一等级最多重考3次
- 连续3次失败，需降一级重新训练
