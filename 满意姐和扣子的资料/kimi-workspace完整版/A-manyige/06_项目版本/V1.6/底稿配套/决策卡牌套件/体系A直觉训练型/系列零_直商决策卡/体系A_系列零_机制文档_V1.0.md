## 一、为什么玩？（核心价值）

### 1.1 解决什么问题？

创业者每天面临无数决策，但传统教育只教理性分析，不教**直觉判断**。然而：

- 信息永远不完整
- 时间永远不够
- 风险与机会永远并存

**直觉，是创业者最核心的竞争力。**

### 1.2 训练什么能力？

| 能力 | 定义 | 商业价值 |
|:-----|:-----|:---------|
| **风险直觉** | 快速感知"哪里不对劲" | 提前避险，减少损失 |
| **决策速度** | 在信息不完整时快速决策 | 抓住窗口期，抢占先机 |
| **情绪控制** | 盈亏面前保持稳定 | 避免情绪化决策 |
| **模式识别** | 从复杂中识别规律 | 提高决策准确率 |

### 1.3 为什么是"满意解"？

本训练不追求"最优解"（信息不足时不可能），而是训练：
> **在不确定中，快速找到"足够好"的决策。**

这正是满意解理论的核心——西蒙的"有限理性"。

## 二、怎么玩？（标准模式）

### 2.1 准备工作

**所需道具**：
- 60张机会卡（四色分类）
- 40张价值卡
- 计分表
- 计时器（手机即可）

**参与人数**：1-6人（最佳2-4人）

**单次时长**：15-20分钟（5轮）

### 2.2 五轮决策流程

```
┌─────────────────────────────────────────────────────┐
│  第1轮（热身）  │ 时间10秒 │ 价值¥1,000-5,000   │
├─────────────────────────────────────────────────────┤
│  第2轮（正常）  │ 时间8秒  │ 价值¥3,000-8,000   │
├─────────────────────────────────────────────────────┤
│  第3轮（正常）  │ 时间8秒  │ 价值¥5,000-15,000  │
├─────────────────────────────────────────────────────┤
│  第4轮（加速）  │ 时间6秒  │ 价值¥8,000-25,000  │
├─────────────────────────────────────────────────────┤
│  第5轮（决胜）  │ 时间5秒  │ 价值¥10,000-50,000 │
└─────────────────────────────────────────────────────┘
```

### 2.3 每轮6步骤

#### Step 1：准备（30秒）
- 洗牌
- 抽取3张机会卡，背面朝上摆放
- 确认价值卡抽牌区

#### Step 2：说出直觉（关键步骤，不可跳过）

**必须大声说出**：
```
左边这张：感觉是【机会/风险/不确定】
中间这张：感觉是【机会/风险/不确定】  
右边这张：感觉是【机会/风险/不确定】
```

**⚠️ 禁止**：
- 沉默跳过
- 模棱两可（"可能吧""还行"）
- 理性分析（"我觉得因为...所以..."）

#### Step 3：身体觉察（10秒）

快速扫描身体两个部位：

| 部位 | 觉察点 | 记录 |
|:-----|:-------|:-----|
| **呼吸** | 顺畅 / 卡顿 | □顺畅 □卡顿 |
| **胸口** | 放松 / 紧绷 | □放松 □紧绷 |

**身体信号与卡牌类型对应**：
- 呼吸顺畅+胸口放松 → 可能是🟢机会
- 呼吸卡顿+胸口紧绷 → 可能是🟡风险或🔴罚款
- 呼吸放缓+胸口平静 → 可能是🟣延迟

#### Step 4：选择卡牌（限时内）

- 根据直觉选择1张
- **⚠️ 禁止理性分析**：不能计算概率、权衡利弊
- 计时器响起前必须做出选择

#### Step 5：抽取价值卡（10秒）

- 随机抽取1张价值卡
- 记录金额

#### Step 6：结算结果（30秒）

- 翻开选择的机会卡
- 根据卡牌类型结算：

| 类型 | 标识 | 结算规则 |
|:-----|:----:|:---------|
| 机会 | 🟢 | 获得价值卡金额 × 倍数 |
| 风险 | 🟡 | 损失价值卡金额 |
| 罚款 | 🔴 | 损失价值卡金额 × 2 |
| 延迟 | 🟣 | 标记，第5轮统一结算 |

- 记录本轮得分
- 进入下一轮

### 2.4 延迟卡特殊结算

**🟣 紫色·延迟卡**在第5轮统一结算：

```
结算公式 = 价值卡金额 × 延迟倍数 × 决胜轮加成

示例：
- 第2轮抽到🟣延迟卡，价值¥10,000，延迟倍数1.5
- 第5轮结算：¥10,000 × 1.5 × 1.5(决胜轮加成) = ¥22,500
```

**延迟卡身体信号**：
- 呼吸放缓（不是卡顿）
- 胸口平静（不是紧绷）

这是"耐心"的直觉状态，不是"紧张"。

## 四、三种训练模式

### 4.1 模式一：个人训练（标准）

**适用**：日常直觉训练
**时长**：15-20分钟
**频率**：每周2-3次

**流程**：
1. 独自完成5轮决策
2. 填写计分表
3. 自我复盘（见第五章）
4. 记录InQ Score变化曲线

**目标**：12周内达到黄金段位

### 4.2 模式二：对抗训练（2-6人）

**适用**：团队建设、合伙人训练
**时长**：30-45分钟
**人数**：2-6人

**流程**：
1. 每位玩家独立进行5轮
2. 每轮结束后公开得分
3. 互相监督（确保"说出直觉"步骤被执行）
4. 第5轮后比较总分，排名

**特殊规则**：
- 排名最高：段位+1
- 排名最低：段位保护（不降级）
- 说出直觉时其他玩家可以观察其身体语言

**目标**：训练"压力下的直觉决策"

### 4.3 模式三：教练引导（专业）

**适用**：深度诊断、能力提升
**时长**：90-120分钟
**人数**：1-4人

**流程**：
```
第一阶段：基线评估（30分钟）
├── 五维罗盘测评
├── 过往决策案例分析
└── 确定训练重点

第二阶段：针对性训练（45分钟）
├── 根据评估选择卡牌系列
├── 实时反馈与指导
└── 关键决策点暂停分析

第三阶段：深度复盘（30分钟）
├── 能力短板识别
├── 身体信号模式分析
└── 个性化训练计划
```

**目标**：系统性提升直觉决策能力

## 五、复盘框架（每5轮后必做）

### 5.1 复盘四问

#### 问1：准确率复盘

- 我的直觉判断对了几次？
- 哪种类型的卡最容易判断错误？
- 身体信号是否与结果一致？

**示例反思**：
```
第3轮把🔴罚款卡判断为"不确定"
实际：胸口剧痛，但我选择了忽略
结果：损失翻倍
教训：剧痛是强烈警告信号，下次必须重视
```

#### 问2：一致性复盘

- 我是否违背过自己的第一直觉？
- 违背直觉时，结果通常是更好还是更差？
- 为什么我会违背直觉？（恐惧/贪婪/犹豫）

**示例反思**：
```
第5轮第一直觉是"风险"
但价值卡金额很高（¥50,000），我改成了"机会"
结果：是🟡风险卡，损失¥50,000
教训：贪婪让我违背直觉，大额反而应该更谨慎
```

#### 问3：情绪复盘

- 连续亏损时，我的决策质量是否下降？
- 大额机会出现时，我是否过于激进？
- 如何保持情绪稳定？

**示例反思**：
```
第2-3轮连续亏损后
第4轮时间压力下，我随便选了一张
结果：错过了🟢机会卡
教训：亏损后的"报复性决策"是陷阱，需要暂停深呼吸
```

#### 问4：模式识别

- 我是否发现了某种"直觉模式"？
- 哪些身体信号是高准确率的前兆？
- 下次训练我要重点改进什么？

**示例反思**：
```
发现模式：胸口"发热"时，70%是🟢机会
胸口"沉重"时，80%是🟡风险或🔴罚款
下次重点：区分"微紧"（机会）vs"沉重"（风险）
```

### 5.2 身体信号校准

**记录你的身体信号模式**：

| 身体感受 | 出现次数 | 实际卡牌 | 准确率 |
|:---------|:--------:|:--------:|:------:|
| 顺畅+放松 | 5次 | 🟢机会(4次) | 80% |
| 卡顿+紧绷 | 3次 | 🟡风险(2次)🔴罚款(1次) | 100% |
| 放缓+平静 | 2次 | 🟣延迟(2次) | 100% |

**目标**：找到你独特的"直觉语言"

## 六、关键认知（玩之前必读）

### ❌ 这不是什么？

1. **不是测试运气**——不是比谁抽到的卡好
2. **不是赢钱游戏**——目的不是积累虚拟财富
3. **不是理性竞赛**——严禁分析概率、计算期望值

### ✅ 这是什么？

1. **是直觉训练场**——在受控环境中练习直觉
2. **是身体觉察课**——学习解读身体的信号
3. **是决策实验室**——观察自己在压力下的反应

### 💡 核心洞察

> **"直觉不是凭空产生，而是你大脑右脑的快速判断——
> 它处理信息的速度比左脑快10,000倍。"**

身体信号是直觉的物理表达：
- 放松 = 右脑判断为安全
- 紧绷 = 右脑检测到威胁
- 平静 = 右脑判断需要等待

**训练目标**：让右脑的声音被听见，而不是被左脑的逻辑压制。

## 七、常见问题FAQ

### Q1：我完全感觉不出身体信号怎么办？

**A**：正常。大部分现代人长期忽视身体信号。

**解决方案**：
1. 训练前做5分钟深呼吸，让身体敏感起来
2. 先从"明显"的感受开始（紧张/放松）
3. 10-20次训练后，敏感度会显著提升

### Q2：我每次都选错，是不是直觉很差？

**A**：恰恰相反，"每次都错"说明你的直觉很敏锐——只是你在压制它。

**检查点**：
- 你是否经常违背第一直觉？
- 你是否在"思考后"改变选择？

**解决方案**：接下来5轮，强迫自己选择第一直觉，即使"看起来不合理"。

### Q3：时间压力让我 panic，怎么办？

**A**：时间压力是刻意设计的——模拟真实商业决策的紧迫感。

**应对策略**：
1. 第1-2轮允许超时，但要记录
2. 第3轮开始严格执行时间限制
3. 发现"没时间思考反而更准确"

### Q4：延迟卡怎么处理？记不住之前的卡

**A**：使用延迟卡标记物（筹码/硬币）。

**流程**：
1. 抽到🟣延迟卡时，放一个标记物在面前
2. 第5轮结算时，根据标记物数量结算
3. 结算后收回标记物

### Q5：和别人一起玩时，如何判断对方是否作弊？

**A**：观察身体语言：

| 说"机会"时 | 真实含义 |
|:-----------|:---------|
| 肩膀放松，眼睛发亮 | 真的认为是机会 |
| 肩膀紧绷，眼神闪烁 | 可能认为是风险 |
| 声音发颤，语速加快 | 不自信/不确定 |

**注意**：这不是"读心术"，而是训练你观察他人的直觉信号。

## 八、进阶训练（钻石段位）

### 8.1 盲选模式

**规则**：
- 不看卡牌，完全凭身体信号选择
- 说出直觉时不看卡牌摆放位置
- 身体指向哪张，就选哪张

**目标**：完全信任身体智慧

### 8.2 极速模式

**规则**：
- 每轮时间减半（第1轮5秒，第5轮2.5秒）
- 取消"说出直觉"步骤（但必须在内心说出）

**目标**：训练潜意识决策

### 8.3 反向模式

**规则**：
- 身体信号反向解读
- 放松=风险，紧绷=机会

**目标**：打破身体信号的固有模式，重新校准
