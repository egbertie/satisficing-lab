## 一、为什么玩？（核心价值）

### 1.1 决策的五个维度

大多数决策失败，不是因为信息不足，而是因为**维度缺失**。

| 维度 | 核心问题 | 常见陷阱 |
|:-----|:---------|:---------|
| **时间轴** | 短期 vs 长期 | 短视、即时满足 |
| **可行域** | 理想 vs 现实 | 空中楼阁、脱离实际 |
| **身心流** | 理性 vs 直觉 | 过度分析、忽视身体 |
| **信义观** | 利益 vs 信任 | 唯利是图、关系破裂 |
| **直觉阈** | 思考 vs 行动 | 分析瘫痪、错失良机 |

**五维罗盘 = 五个维度 × 同步扫描 = 满意解决策**

### 1.2 训练什么能力？

| 能力 | 定义 | 商业价值 |
|:-----|:-----|:---------|
| **多维度思考** | 同时考虑五个维度 | 决策更全面，遗漏更少 |
| **维度权重调整** | 根据情境调整维度优先级 | 灵活应对，不被框架限制 |
| **维度冲突平衡** | 解决维度间的冲突 | 找到平衡点，而非极端 |
| **五维整合** | 将五维思维内化为习惯 | 决策质量系统性提升 |

### 1.3 为什么是"罗盘"？

罗盘有五个方向，决策也有五个维度：
- 不看罗盘 = 盲人骑瞎马（凭感觉决策）
- 只看一维 = 管中窥豹（片面决策）
- 五维扫描 = 全局视野（满意解决策）

## 二、五维详解

### 维度一：时间轴（Temporal）

**核心问题**：这个决策在10分钟后、10个月后、10年后分别会怎样？

**思维工具**：
```
10分钟测试：当下最紧迫的影响是什么？
10个月测试：中期会有什么变化？
10年测试：长期后果是什么？
```

**典型场景**：
- 短期诱惑 vs 长期价值
- 当下痛苦 vs 未来收益
- 技术债务偿还时机
- 投资回收期评估

**满意解原则**：
> 时间轴思维的关键是"看终局"。

**身体信号**：
- 胸口发紧 = 忽视长期后果
- 呼吸顺畅 = 时间维度平衡

---

### 维度二：可行域（Feasible）

**核心问题**：基于现有资源约束，什么是可实现的？

**思维工具**：
```
资源盘点：人、财、物、时间、关系
约束识别：硬性约束（不可突破）vs 软性约束（可协商）
可行域绘制：在约束边界内寻找最大价值
```

**典型场景**：
- 理想方案 vs 可行方案
- 资源约束下的优先级
- 多目标优化的权衡
- 极限情况下的生存策略

**满意解原则**：
> 可行域内的最优解，才是真正的最优解。

**身体信号**：
- 肩膀沉重 = 资源不足，需要调整目标
- 身体放松 = 可行域清晰，可以执行

---

### 维度三：身心流（Mind-Body Flow）

**核心问题**：我的身体在说什么？直觉信号是否被忽视？

**思维工具**：
```
身体扫描：呼吸、胸口、肩膀、胃部
直觉记录：第一感觉是什么？
理性验证：直觉与理性是否一致？
整合决策：两个声音都听
```

**典型场景**：
- 直觉 vs 数据分析
- 情绪识别与管理
- 身体信号的解读
- 压力下的决策质量

**满意解原则**：
> 身体知道答案，理性负责验证。

**身体信号**：
- 胸口放松 = 方向正确
- 胸口发紧 = 需要警惕
- 呼吸顺畅 = 可以前进
- 呼吸急促 = 需要暂停

---

### 维度四：信义观（Trust & Ethics）

**核心问题**：这个决策会如何影响信任和关系？

**思维工具**：
```
利益相关者识别：谁会受影响？
信任影响评估：信任会增加还是减少？
伦理底线检查：是否触碰不可妥协的底线？
关系长期性：短期利益 vs 长期关系
```

**典型场景**：
- 短期利益 vs 长期信任
- 透明沟通 vs 信息隐瞒
- 承诺兑现的困境
- 伦理底线的坚守

**满意解原则**：
> 信任是复利，一旦失去，需要10倍努力重建。

**身体信号**：
- 内心平静 = 符合伦理
- 良心不安 = 触碰底线
- 坦荡 = 可以公开
- 隐瞒冲动 = 需要反思

---

### 维度五：直觉阈（Intuitive Threshold）

**核心问题**：什么时候停止分析，开始行动？

**思维工具**：
```
信息充足度评估：还需要多少信息？
决策时机判断：窗口期还有多久？
行动准备度：是否具备执行条件？
后悔最小化：不做 vs 做错的后悔比较
```

**典型场景**：
- 信息充足度判断
- 分析瘫痪的克服
- 决策时机的把握
- 后悔最小化策略

**满意解原则**：
> 满意解就是停止分析的临界点。

**身体信号**：
- 越来越清楚 = 继续分析
- 越来越混乱 = 立即行动
- 平静但坚定 = 准备充分
- 焦虑但兴奋 = 时机到来

## 三、怎么玩？（标准模式）

### 3.1 准备工作

**所需道具**：
- 五维训练卡 60张（每维12张）
- 五维罗盘图（5个维度可视化）
- 计分表
- 计时器

**参与人数**：1-6人（最佳2-4人）

**单次时长**：20-40分钟（5-10个场景）

### 3.2 游戏流程

```
┌─────────────────────────────────────────────────────┐
│  Step 1: 抽取场景  │ 从60张卡中随机抽取1张        │
├─────────────────────────────────────────────────────┤
│  Step 2: 阅读场景  │ 理解决策困境（1分钟）          │
├─────────────────────────────────────────────────────┤
│  Step 3: 五维扫描  │ 分别用五维视角分析场景         │
│                    │ 时间轴→可行域→身心流→信义观→直觉阈│
├─────────────────────────────────────────────────────┤
│  Step 4: 个人决策  │ 写下你的选择和五维评估         │
├─────────────────────────────────────────────────────┤
│  Step 5: 身体觉察  │ 记录身体信号                  │
├─────────────────────────────────────────────────────┤
│  Step 6: 公开讨论  │ 分享五维分析，讨论满意解        │
├─────────────────────────────────────────────────────┤
│  Step 7: 查看答案  │ 揭晓得分和五维满意解解析        │
├─────────────────────────────────────────────────────┤
│  Step 8: 罗盘校准  │ 标记本次训练的维度强弱         │
└─────────────────────────────────────────────────────┘
```

### 3.3 计分规则

| 选项 | 得分 | 含义 |
|:-----|:----:|:-----|
| A | -3 至 -5 | 单维极端，忽视其他维度 |
| B | -1 至 -2 | 维度失衡，过度侧重某维 |
| C | +6 至 +8 | 多维平衡，较好方案 |
| D | +9 至 +10 | **满意解**，五维最优平衡 |

**五维罗盘评分**：

每完成一个场景，评估五维表现：

| 维度 | 评估 | 得分 |
|:-----|:-----|:----:|
| 时间轴 | 是否考虑了短期/中期/长期？ | 0-2 |
| 可行域 | 是否考虑了资源约束？ | 0-2 |
| 身心流 | 是否关注了身体信号？ | 0-2 |
| 信义观 | 是否考虑了信任影响？ | 0-2 |
| 直觉阈 | 是否把握了决策时机？ | 0-2 |
| **五维总分** | | **0-10** |

**能力指数** = 五维总分 × 10 = 0-100

### 3.4 段位晋级系统

| 段位 | 能力指数 | 称号 | 解锁特权 |
|:-----|:--------:|:-----|:---------|
| 🥉 **青铜** | 0-399 | 单维思考者 | 单维度专项训练 |
| 🥈 **白银** | 400-599 | 二维思考者 | 双维度组合训练 |
| 🥇 **黄金** | 600-799 | 三维思考者 | 三维度组合训练 |
| 💎 **铂金** | 800-899 | 四维思考者 | 四维度组合训练 |
| 👑 **钻石** | 900-1000 | 五维大师 | 五维综合+教练模式 |

**晋级规则**：
- 单次训练能力指数达到段位下限即晋级
- 每种维度至少完成3个场景才能晋级

## 四、五维联动训练

### 4.1 维度组合训练

**双维组合**：
- 时间轴 + 可行域 = "在有限资源下，长期最优是什么？"
- 身心流 + 信义观 = "身体信号是否提醒我伦理问题？"
- 直觉阈 + 时间轴 = "现在必须决定，还是还能等？"

**三维组合**：
- 时间轴 + 可行域 + 身心流 = "长期可行且身体认同的方案"
- 信义观 + 身心流 + 直觉阈 = "伦理正确、身体舒服、时机合适的决策"

**四维组合**：
- 任选四维，寻找遗漏的那个维度

**五维综合**：
- 同时扫描五维，寻找满意解

### 4.2 个人五维画像

**训练10个场景后，绘制你的五维画像**：

```
            时间轴 (T)
               8
              /|\
             / | \
            /  |  \
     身心流 5---+----5 可行域 (F)
     (M)    \  |  /
            \ | /
             \|/
       信义观3---3直觉阈 (I)
           (E)

示例画像：时间轴强(8)、可行域中(5)、身心流中(5)、信义观弱(3)、直觉阈弱(3)
改进方向：加强信义观和直觉阈训练
```

## 五、复盘框架

### 5.1 单场景复盘

**五问法**：
1. 我考虑了时间轴吗？短期/中期/长期分别是什么？
2. 我识别了可行域吗？资源约束是什么？
3. 我听从了身体信号吗？直觉告诉我什么？
4. 我评估了信义影响吗？信任会怎样变化？
5. 我把握了决策时机吗？是应该行动还是等待？

### 5.2 五维强弱分析

**我最强的维度**：_______（为什么？）
**我最弱的维度**：_______（如何加强？）
**我忽略的维度**：_______（代价是什么？）

### 5.3 真实迁移

**这个训练对我真实决策的启示**：
- 我过去的决策缺失了什么维度？
- 下次遇到类似情况，我会怎么做？
- 我需要建立什么新习惯？

## 七、附录

### A. 五维速查卡

| 维度 | 关键词 | 核心问题 | 身体信号 |
|:-----|:-------|:---------|:---------|
| 时间轴 | 10-10-10 | 10分/月/年后会怎样？ | 发紧=忽视长期 |
| 可行域 | 资源约束 | 什么是可实现的？ | 沉重=资源不足 |
| 身心流 | 身体智慧 | 身体在说什么？ | 放松=方向正确 |
| 信义观 | 信任复利 | 信任会怎样？ | 坦荡=符合伦理 |
| 直觉阈 | 行动时机 | 停止分析的时间？ | 焦虑=时机到来 |

### B. 满意解五维检验

一个满意解必须同时通过五维检验：

- [ ] 时间轴检验：短期可接受，长期有价值
- [ ] 可行域检验：资源可支撑，约束可应对
- [ ] 身心流检验：身体不抗拒，直觉不反对
- [ ] 信义观检验：信任不受损，伦理不触碰
- [ ] 直觉阈检验：信息已充足，时机正合适

**通过≥4维 = 满意解**  
**通过<4维 = 需要调整**
