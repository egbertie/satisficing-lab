# 满意解决策卡牌套件 · 体系A（直觉训练型）
## 设计使用说明书 V1.0

---

## 一、产品概述

### 1.1 产品定位

**满意解决策卡牌套件·体系A（直觉训练型）**是一款面向创业者、合伙人、高管及决策者的**直觉训练与冲突识别工具**。它基于认知心理学、决策科学与组织行为学的学术研究成果，通过游戏化的卡牌互动，帮助使用者在短时间内提升对合伙人冲突情境的直觉识别能力与决策质量。

**核心价值主张**：
- 🎯 **直觉训练**：通过系统化场景暴露，培养快速识别冲突模式的能力
- 🔍 **冲突预警**：提前识别潜在合伙风险，防患于未然
- ⚡ **决策加速**：在信息不完备情境下做出高质量满意解决策
- 🧠 **认知升级**：建立结构化的冲突类型学认知框架

### 1.2 设计理念

**理论基础**（详见附录学术研究报告）：
- **双系统理论**（Kahneman）：训练系统1（直觉系统）的模式识别能力
- **满意解理论**（Simon）：在有限理性约束下寻求"足够好"的决策
- **心流理论**（Csikszentmihalyi）：通过挑战-技能平衡创造沉浸学习体验
- **具身认知理论**（Damasio）：重视身体信号在决策中的作用

**设计原则**：
1. **直觉优先**：强制先表达直觉，再启动理性分析
2. **场景真实**：所有案例基于真实创业冲突情境改编
3. **即时反馈**：选择后立即获得结果解析与评分
4. **渐进难度**：从青铜到钻石的分级挑战体系

## 二、目标用户与使用场景

### 2.1 目标用户画像

| 用户类型 | 典型场景 | 使用目的 |
|:---------|:---------|:---------|
| **创业合伙人** | 合伙前评估、冲突处理 | 识别潜在冲突类型，预防纠纷 |
| **创业者** | 融资谈判、团队建设 | 提升决策直觉，快速判断人性 |
| **投资人** | 尽职调查、投后管理 | 评估团队稳定性，识别风险信号 |
| **企业高管** | 战略决策、团队管理 | 训练高压情境下的决策能力 |
| **管理顾问** | 客户诊断、培训交付 | 作为诊断工具与教学道具 |
| **商学院学员** | 案例学习、能力训练 | 理解合伙冲突的系统性知识 |

### 2.2 使用场景

**场景A：合伙前评估（预防性使用）**
- 在正式合伙前，合伙人共同进行体系A训练
- 通过场景卡了解彼此在各类冲突中的直觉反应
- 提前识别潜在价值观分歧与认知差异
- **推荐系列**：系列零（基础）+ 系列一（冲突识别）

**场景B：冲突处理（治疗性使用）**
- 当合伙关系出现紧张或冲突时
- 使用特定冲突类型的场景卡进行诊断
- 通过游戏化方式降低防御心理，促进沟通
- **推荐系列**：系列一对应冲突类型 + 系列二（五维罗盘分析）

**场景C：能力训练（发展性使用）**
- 定期（如每周一次）进行晋级挑战训练
- 逐步提升段位，系统性提升决策直觉
- 个人或团队竞赛模式
- **推荐系列**：系列三（晋级挑战）+ 系列四（价值结算）

**场景D：教学培训（教育性使用）**
- 在创业培训、MBA课程中作为教学工具
- 讲师引导学员讨论场景卡背后的决策逻辑
- 结合学术理论进行深度解析
- **推荐系列**：系列一（案例分析）+ 系列二（方法论）

## 四、各系列详细使用指南

### 4.1 系列零：InQ直商决策卡（入门系列）

**系列定位**：
决策直觉训练的入门系列，适合首次接触体系A的用户。通过简单的决策场景建立"直觉表达→觉察→选择→结算"的基础认知框架。

**卡牌构成**：
- **场景卡**（10张）：涵盖日常决策与简单商业情境
- **特殊效果卡**（5张）：
  - 🔵 机会卡（×2分）
  - 🔴 风险卡（得分/损失×1.5倍）
  - ⚫ 罚款卡（×2倍负面结果）
  - 🟡 延迟卡（下轮收益×2或损失×2）
  - 🟢 续作卡（额外获得一张卡）

**使用流程**：

```
单人模式（基础训练）
━━━━━━━━━━━━━━━━━━━━━━━
1. 洗牌，抽取1张场景卡
2. 阅读情境描述（限时30秒）
3. 【直觉表达】立即说出第一反应（大声/记录）
4. 【觉察身体】扫描身体反应（心跳/呼吸/紧张部位）
5. 【选择】从2-4个选项中选择（限时15秒）
6. 【结算】查看结果与评分（-10到+10分）
7. 【反思】阅读满意解提示，记录学习要点
8. 重复步骤1-7，建议3-5张/次，总时长15-20分钟
```

**计分规则**：
- **+10分**：极佳决策，符合满意解标准
- **+5分到+9分**：良好决策，方向正确
- **0分到+4分**：一般决策，有改进空间
- **-1分到-5分**：欠佳决策，存在明显盲区
- **-6分到-10分**：严重失误，需重点复盘

**特殊效果卡使用规则**：
- 抽到特殊效果卡时，先结算当前场景，再执行特殊效果
- 效果卡可累积，负面效果优先结算
- 建议每3-5张场景卡插入1张特殊效果卡增加变数

### 4.2 系列一：合伙人冲突类型卡（核心系列）

**系列定位**：
体系A的核心内容，包含13种合伙人冲突类型 × 16张场景卡 = 208张场景卡。覆盖创业合伙关系中从股权分配到心理契约违背的全谱系冲突情境。

**13种冲突类型速查表**：

| 类型编号 | 冲突名称 | 核心问题 | 典型触发点 |
|:--------:|:---------|:---------|:-----------|
| Type01 | 股权分配冲突 | 股份比例与贡献不匹配 | 创业初期股权划分 |
| Type02 | 控制权争夺 | 决策权与治理结构 | 战略方向分歧 |
| Type03 | 利益分配冲突 | 利润分配与再投资 | 公司盈利后分红争议 |
| Type04 | 退出机制争议 | 股权转让与退出条款 | 合伙人离职/退出 |
| Type05 | 责任边界模糊 | 职责划分与 accountability | 跨职能协作障碍 |
| Type06 | 价值观念冲突 | 经营理念与企业文化 | 战略决策根本分歧 |
| Type07 | 信任破裂 | 信任基础崩塌 | 背叛/隐瞒/失信 |
| Type08 | 能力不匹配 | 合伙人能力跟不上发展 | 公司成长阶段转换 |
| Type09 | 引入新合伙人 | 新合伙人加入的整合 | 融资后团队重组 |
| Type10 | 家族关系干预 | 家族因素与商业逻辑 | 家族成员参与经营 |
| Type11 | 融资与估值分歧 | 融资时机与估值认知 | 投资人进入谈判 |
| Type12 | 知识产权争议 | 技术/品牌归属 | 核心资产权属 |
| Type13 | 心理契约违背 | 隐性期望未兑现 | 承诺未履行/期望落差 |

**场景卡标准结构**：

每张场景卡包含以下要素：

```
┌─────────────────────────────────────────┐
│ 【Type01】股权分配冲突 L2               │ ← 类型标识 + 难度等级
├─────────────────────────────────────────┤
│ 情境描述：                               │
│ 你与合伙人共同创业2年，公司估值从100万   │
│ 增长到5000万。初始股权50:50分配，但      │
│ 你认为自己的贡献远大于对方...            │
├─────────────────────────────────────────┤
│ 决策点：                                 │
│ 面对股权不平衡，你决定：                 │
│                                           │
│ A. 提出重新分配股权（60:40）             │
│ B. 维持现状，但要求更高薪酬              │
│ C. 引入期权池，通过新增股份调整          │
│ D. 暂时搁置，等公司上市后再说            │
├─────────────────────────────────────────┤
│ 【结果解析】                             │
│ A. (+6分) 直接但风险高，可能引发冲突     │
│ B. (+3分) 短期缓解，长期问题累积         │
│ C. (+9分) ★满意解 兼顾公平与关系        │
│ D. (-2分) 回避问题，错失最佳时机          │
├─────────────────────────────────────────┤
│ 【满意解提示】                           │
│ 股权调整的最佳时机是新一轮融资前...        │
│ 关键：用增量解决存量问题，而非直接       │
│ 触动既有利益。引入期权池是经典手法。     │
└─────────────────────────────────────────┘
```

**三种使用模式**：

**模式A：类型诊断模式**（单人/双人）
1. 确定当前面临的冲突类型（如不确定可先做类型测试）
2. 选取对应类型的16张场景卡
3. 逐一进行决策训练，记录得分
4. 统计平均分，低于+5分建议寻求专业咨询

**模式B：全类型扫描模式**（单人进阶）
1. 从13类型中每类抽取2-3张（共30-40张）
2. 混洗后进行连续决策
3. 按类型统计得分，识别薄弱环节
4. 针对低分类型进行专项训练

**模式C：双人对抗模式**（合伙人/团队）
1. 同一场景，双方独立决策
2. 比较选择差异，讨论分歧点
3. 特别适合合伙前评估或冲突调解

### 4.3 系列二：五维罗盘训练卡（方法论系列）

**系列定位**：
提供系统化的决策分析框架，帮助使用者从五个维度全面评估决策情境，训练结构化思考能力。

**五维度框架**：

| 维度 | 核心问题 | 训练目标 | 使用时机 |
|:-----|:---------|:---------|:---------|
| **维度一：时间轴** | "何时是最佳决策时机？" | 识别决策窗口期与紧迫感 | 面临时机选择时 |
| **维度二：风险谱** | "最坏情况是什么？我能承受吗？" | 评估风险与制定预案 | 高风险决策前 |
| **维度三：利益网** | "谁是利益相关方？他们的诉求是什么？" | 绘制利益关系图谱 | 涉及多方利益时 |
| **维度四：认知层** | "我的直觉可靠吗？有没有认知盲区？" | 验证直觉与识别偏见 | 直觉与理性冲突时 |
| **维度五：身体感** | "我的身体在告诉我什么？" | 觉察躯体标记信号 | 任何重要决策前 |

**使用流程**：

```
五维罗盘分析流程
━━━━━━━━━━━━━━━━━━━━━━━
1. 选取一张系列一的场景卡（或真实决策情境）
2. 【时间轴分析】
   - 绘制时间线：过去(相关历史) → 现在(决策点) → 未来(可能后果)
   - 识别：窗口期/截止期/等待成本
3. 【风险谱分析】
   - 列出最好/最坏/最可能三种结果
   - 评估：可承受性/可逆性/Plan B
4. 【利益网分析】
   - 绘制利益相关方图谱
   - 标注：支持者/中立者/反对者/潜在联盟
5. 【认知层分析】
   - 直觉检查：第一反应是什么？为何？
   - 偏见扫描：确认偏误/锚定效应/沉没成本谬误？
   - 反方论证：如果我的直觉错了，可能是因为...？
6. 【身体感分析】
   - 身体扫描：心跳/呼吸/肌肉紧张/ gut feeling
   - 情绪标记：焦虑/兴奋/恐惧/平静
   - 生理信号解读：身体在支持还是警告这个决策？
7. 【综合决策】
   - 整合五维度分析结果
   - 做出最终选择
   - 记录决策理由，供后续复盘
```

**与系列一的结合使用**：
- 先用系列一进行直觉训练（快速反应）
- 再用系列二进行深度分析（慢思考）
- 对比两次决策的差异，识别直觉与理性的张力

### 4.4 系列三：晋级挑战卡（进阶系列）

**系列定位**：
为进阶使用者设计的段位挑战系统，通过90张高难度场景卡（L1-L3 + 大师层）的系统化训练，实现决策直觉的阶梯式提升。

**段位体系**：

| 段位 | 对应难度 | 场景特征 | 认证要求 |
|:-----|:---------|:---------|:---------|
| 🥉 青铜 | L1初级 | 单一冲突类型，信息完整 | 连续10张平均得分≥+5分 |
| 🥈 白银 | L2中级 | 双重冲突叠加，时间压力 | 连续10张平均得分≥+6分 |
| 🥇 黄金 | L3高级 | 多冲突交织，信息不完整 | 连续10张平均得分≥+7分 |
| 💎 铂金 | 大师层A | 真实案例改编，无解情境 | 连续5张平均得分≥+6分 |
| 🏆 钻石 | 大师层B | 实时事件，需外部信息 | 专家评审通过 |

**难度递增设计**：

```
L1初级 → L2中级 → L3高级 → 大师层
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
冲突数量    1个    →   2个    →   3+个   →   复合复杂
信息完整度  完整   →   部分缺失 → 大量缺失 → 需主动获取
时间压力    无     →   中等     →   高      →   极高
情绪干扰    低     →   中       →   高      →   极端
利益相关方  2方    →   3-4方   →   5+方   →   网络状
```

**挑战模式**：

**单人晋级模式**：
1. 选择目标段位
2. 从对应难度抽取10张场景卡
3. 连续决策，记录每张得分
4. 计算平均分，达到标准则晋级
5. 未达标则针对性训练后重试

**双人竞赛模式**：
1. 同段位同一场景，双方独立决策
2. 得分高者获得该场景胜利
3. 先赢得6/10场景者段位提升
4. 适合合伙人之间的友好竞争

**专家认证模式（钻石段位）**：
- 需提交5个真实决策案例的分析报告
- 通过满意解研究所专家评审
- 获得"决策直觉教练"资格认证

### 4.5 系列四：价值与结算卡（量化系列）

**系列定位**：
提供决策的量化分析工具，帮助使用者从经济学视角评估决策的价值与成本。

**卡牌功能说明**：

| 卡牌名称 | 核心功能 | 使用场景 |
|:---------|:---------|:---------|
| **价值锚定卡** | 明确决策的核心价值基准 | 决策前定义成功标准 |
| **沉没成本计算卡** | 识别并剥离沉没成本干扰 | 面临"已经投入太多"情境 |
| **EV估值卡** | 计算各选项的期望价值 | 量化比较多个选项 |
| **机会成本对比卡** | 评估放弃的次优选项价值 | 资源有限选择时 |
| **合作剩余分配卡** | 计算合作收益与分配方案 | 谈判与利益分配时 |

**使用示例（EV估值）**：

```
情境：选择是否接受某投资人的条款
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
选项A：接受投资（出让20%股权，估值1000万）
  - 成功概率70%：公司估值3000万，你的股权价值2400万
  - 失败概率30%：公司清算，你的股权价值0
  - EV = 0.7×2400 + 0.3×0 = 1680万

选项B：拒绝投资，继续独立发展
  - 成功概率40%：公司估值2000万，你的股权价值1600万
  - 失败概率60%：公司清算，你的股权价值0
  - EV = 0.4×1600 + 0.6×0 = 640万

决策建议：选项A的EV更高（1680万 > 640万），
但需考虑：成功概率估算是否准确？控制权损失的价值？
```

**与系列一/二的结合**：
- 先用系列一训练直觉判断
- 再用系列四进行量化验证
- 识别直觉与量化分析的差异点，深度反思

## 五、完整游戏流程指南

### 5.1 个人日常训练流程（推荐频次：每周2-3次）

```
标准训练流程（15-20分钟）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【准备阶段】2分钟
  - 选择安静环境，准备计分板
  - 确定本次训练目标（如：练习Type07信任破裂类型）

【热身阶段】3分钟
  - 抽取1张系列零场景卡
  - 快速完成直觉表达→觉察→选择→结算流程
  - 目的是激活决策直觉状态

【主训阶段】10分钟
  - 抽取3-5张目标类型场景卡（系列一）
  - 每张严格遵循标准流程：
    * 阅读情境（30秒）
    * 直觉表达（大声说出）
    * 身体觉察（扫描反应）
    * 做出选择（15秒）
    * 查看结果，记录得分
  - 每2-3张插入1张五维罗盘卡做深度分析

【结算阶段】3分钟
  - 统计平均分
  - 记录今日最佳与最差决策
  - 写下1条今日学习要点

【段位追踪】持续记录
  - 每完成10张同类型卡计算平均分
  - 达到标准申请段位认证
```

### 5.2 合伙人联合诊断流程（推荐时机：合伙前/冲突时）

```
双人联合诊断流程（45-60分钟）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【开场】5分钟
  - 说明目的：了解彼此在冲突情境中的直觉反应模式
  - 强调规则：无对错，只了解差异

【类型选择】5分钟
  - 共同选择3-5个关注的冲突类型
  - 或针对当前面临的实际冲突类型

【同步决策】30分钟
  - 每类型选取2-3张场景卡
  - 同一场景，双方独立阅读
  - 同步做出选择（背对背或写纸条）
  - 同时揭示选择，讨论差异

【差异分析】15分钟
  - 统计选择一致率与分歧率
  - 针对分歧场景深度讨论：
    * "你为什么选A？"
    * "我担心选B会导致..."
    * "我们的价值观差异在哪里？"

【共识建立】5分钟
  - 记录双方在哪些类型上容易达成共识
  - 识别需要特别关注的分歧类型
  - 制定"冲突预警协议"
```

```
工作坊流程（4小时/8小时）
```

## 六、高级使用技巧

### 6.1 直觉校准技术

**问题**：如何判断我的直觉是"可靠的直觉"还是"偏见驱动的错觉"？

**校准方法**：

1. **历史验证法**：
   - 回顾过去10个重大决策
   - 标记哪些是直觉决策，哪些是理性分析
   - 统计两类决策的成功率
   - 如果直觉决策成功率显著低于理性决策，说明直觉需要训练

2. **专家对照法**：
   - 在系列三挑战中，记录你的选择与"满意解"的差异
   - 如果长期偏离满意解，说明直觉模式有问题

3. **身体信号验证**：
   - 记录每次决策时的身体反应
   - 事后验证：身体紧张时决策成功率高还是身体放松时高？
   - 建立个人"身体-决策质量"关联图谱

- 重点：熟悉13类型基本特征
- 方法：每种类型连续训练5张，建立模式识别

- 重点：在信息不完整时做出决策

- 重点：处理无解情境与极端情绪
- 方法：研究真实案例，学习满意解思维：不求最优，求最不坏

## 七、常见问题解答（FAQ）

**Q1：体系A与体系B有什么区别？**
> A：体系A聚焦"直觉训练"，培养快速识别冲突模式的能力；体系B聚焦"策略博弈"，培养理性分析与策略计算能力。两者互补，建议先A后B。

**Q2：我应该从哪个系列开始？**
> A：新手建议从系列零（InQ直商决策卡）开始，建立基础流程认知；有创业经验的用户可直接从系列一（冲突类型卡）开始，识别自己最关心的冲突类型。

**Q3：单人使用和双人使用有什么区别？**
> A：单人使用适合日常训练和能力提升；双人使用特别适合合伙人之间的相互了解和冲突调解，能够看到彼此在相同情境下的不同直觉反应。

**Q4：如何判断我的直觉训练是否有效？**
> A：三个指标：(1) 系列三同段位得分逐步提升；(2) 在现实生活中识别冲突的速度加快；(3) 决策后的后悔感减少。

**Q5：遇到真实冲突时，如何使用这套卡牌？**
> A：(1) 先用"信号词速查"识别冲突类型；(2) 找到对应类型的场景卡进行模拟训练；(3) 用五维罗盘进行全面分析；(4) 与合伙人一起进行双人诊断流程。

**Q6：卡牌中的"满意解"是什么意思？**
> A：满意解（Satisficing）是诺贝尔经济学奖得主赫伯特·西蒙提出的概念，指在有限理性约束下，不求最优解，而是寻求"足够好"的解决方案。这更符合真实决策情境。
