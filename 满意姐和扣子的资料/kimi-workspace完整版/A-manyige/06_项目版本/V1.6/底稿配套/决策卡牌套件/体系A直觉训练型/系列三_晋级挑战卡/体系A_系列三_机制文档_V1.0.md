## 一、为什么玩？（核心价值）

### 1.1 晋级的意义

训练了系列零（直觉决策）、系列一（冲突处理）、系列二（五维罗盘），你需要一次**综合实战检验**。

晋级挑战卡 = 期末大考 = 能力认证

### 1.2 挑战什么？

| 挑战类型 | 目标 | 对应能力 |
|:---------|:-----|:---------|
| **初级挑战** | 建立基础决策能力 | 识别常见陷阱 |
| **中级挑战** | 提升复杂决策能力 | 处理不确定性 |
| **高级挑战** | 掌握战略决策能力 | 系统性思考 |

### 1.3 为什么是"挑战"？

- 不是练习，是**考试**
- 有通过标准，有失败可能
- 成功后**段位晋升**，获得新特权

## 三、挑战机制

### 3.1 挑战流程

```
┌─────────────────────────────────────────────────────┐
│  Step 1: 选择等级  │ 初级/中级/高级               │
├─────────────────────────────────────────────────────┤
│  Step 2: 了解规则  │ 阅读该等级的通过标准         │
├─────────────────────────────────────────────────────┤
│  Step 3: 开始挑战  │ 连续完成10个场景（不可中断）  │
├─────────────────────────────────────────────────────┤
│  Step 4: 场景决策  │ 每个场景限时决策，记录选择    │
├─────────────────────────────────────────────────────┤
│  Step 5: 教练点评  │ 查看得分和教练点评           │
├─────────────────────────────────────────────────────┤
│  Step 6: 累计得分  │ 10个场景平均分计算           │
├─────────────────────────────────────────────────────┤
│  Step 7: 判定结果  │ 通过 = 晋级，失败 = 重考     │
├─────────────────────────────────────────────────────┤
│  Step 8: 颁发认证  │ 获得段位证书和新特权         │
└─────────────────────────────────────────────────────┘
```

### 3.2 计分规则

**单场景评分**：

| 选项 | 得分 | 评价 |
|:-----|:----:|:-----|
| A | -8 至 -5 | 重大错误，认知陷阱 |
| B | -4 至 -1 | 次优选择，有待改进 |
| C | +6 至 +8 | 较好选择，基本正确 |
| D | +9 至 +10 | **满意解**，最优平衡 |

**累计评分**：

```
总得分 = 场景1得分 + 场景2得分 + ... + 场景10得分
平均分 = 总得分 ÷ 10
```

### 3.3 通过标准

| 等级 | 通过平均分 | 失败后果 | 重考规则 |
|:-----|:----------:|:---------|:---------|
| 初级 | ≥ +7.0 | 保持青铜，需重考 | 7天后可重考 |
| 中级 | ≥ +8.0 | 保持白银，需重考 | 14天后可重考 |
| 高级 | ≥ +8.5 | 保持黄金，需重考 | 30天后可重考 |

**重考限制**：
- 同一等级最多重考3次
- 连续3次失败，需降一级重新训练

## 五、教练模式（钻石段位特权）

### 5.1 教练资格

通过高级挑战并获得钻石段位，可申请成为**认证教练**。

### 5.2 教练权限

1. **指导他人**：带领学员完成训练
2. **颁发证书**：为学员申请段位认证
3. **设计场景**：创建新的挑战场景
4. **晋级评审**：参与学员晋级考核评审

### 5.3 教练责任

1. **保持专业**：每年完成10小时继续教育
2. **遵守伦理**：不泄露学员信息
3. **客观公正**：评审不受个人关系影响
4. **持续改进**：收集反馈，优化训练

## 六、与其他系列的联动

### 6.1 挑战前准备

**必须通过前置训练**：
- 初级挑战：需完成系列零基础训练
- 中级挑战：需通过初级挑战
- 高级挑战：需通过中级挑战

### 6.2 挑战中使用

**可调用其他系列资源**：
- 遇到直觉问题 → 调用系列零（直商决策卡）
- 遇到冲突问题 → 调用系列一（合伙人冲突类型卡）
- 需要全面分析 → 调用系列二（五维罗盘）

### 6.3 挑战后复盘

**晋级者需完成**：
1. 撰写晋级心得（500字）
2. 为其他学员分享经验
3. 提出训练改进建议

## 七、特殊挑战模式

### 7.1 限时挑战模式

**规则**：
- 10个场景总时间限制（初级60分钟，中级45分钟，高级30分钟）
- 超时自动交卷
- 增加时间压力，模拟真实决策紧迫性

### 7.2 盲选挑战模式

**规则**：
- 场景描述隐藏关键信息
- 需根据直觉和有限信息决策
- 铂金段位以上解锁

### 7.3 组队挑战模式

**规则**：
- 2-3人组队完成挑战
- 每个场景需达成共识
- 评分团队决策质量

### B. 认知陷阱速查

| 陷阱 | 定义 | 破解方法 |
|:-----|:-----|:---------|
| 沉没成本 | 因已投入而继续 | 只看未来收益 |
| 幸存者偏差 | 只看成功案例 | 研究失败案例 |
| 锚定效应 | 被第一个信息绑架 | 多来源数据 |
| 确认偏误 | 只找支持证据 | 主动找反面证据 |
| 损失厌恶 | 害怕损失超过追求收益 | 客观评估概率 |
