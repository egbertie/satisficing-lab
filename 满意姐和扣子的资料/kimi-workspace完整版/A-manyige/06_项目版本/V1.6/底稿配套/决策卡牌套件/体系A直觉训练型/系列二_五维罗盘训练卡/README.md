## 🎯 系列定位

**五维罗盘训练卡™**是体系A直觉训练型的框架系列，训练决策的五个维度思维。

### 五维罗盘

```
            时间轴 (T)
               |
              /|\
             / | \
            /  |  \
     身心流 ----+---- 可行域 (F)
     (M)      |      (信义观E / 直觉阈I)
            \ | /
             \|/
           直觉阈 (I)
```

### 核心特色

- 🧭 **五维扫描**：时间轴、可行域、身心流、信义观、直觉阈
- 🎯 **满意解检验**：5维检验法，通过≥4维=满意解
- 📊 **五维画像**：绘制个人维度强弱图
- 🔄 **维度组合**：双维、三维、四维、五维联动训练

## 🚀 快速开始

### 单人训练（20分钟）

```
1. 抽取场景：从60张卡中随机1张
2. 阅读场景：理解决策困境（1分钟）
3. 五维扫描：
   - 时间轴：10分/月/年后会怎样？
   - 可行域：资源约束是什么？
   - 身心流：身体在说什么？
   - 信义观：信任会怎样？
   - 直觉阈：时机合适吗？
4. 做出决策：选择A/B/C/D
5. 身体觉察：记录身体信号
6. 查看答案：揭晓得分和满意解
7. 罗盘校准：标记本次维度强弱
```

### 五维速查

| 维度 | 关键词 | 核心问题 |
|:-----|:-------|:---------|
| 时间轴 | 10-10-10 | 10分/月/年后会怎样？ |
| 可行域 | 资源约束 | 什么是可实现的？ |
| 身心流 | 身体智慧 | 身体在说什么？ |
| 信义观 | 信任复利 | 信任会怎样？ |
| 直觉阈 | 行动时机 | 停止分析的时间？ |

### 满意解五维检验

- [ ] 时间轴：短期可接受，长期有价值
- [ ] 可行域：资源可支撑，约束可应对
- [ ] 身心流：身体不抗拒，直觉不反对
- [ ] 信义观：信任不受损，伦理不触碰
- [ ] 直觉阈：信息已充足，时机正合适

**通过≥4维 = 满意解**
