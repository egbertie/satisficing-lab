## 🚀 快速开始

### 单人训练（30分钟）

```
1. 选择类型：根据当前困扰或随机选择
2. 抽取场景：从该类型16张卡中随机1张
3. 阅读场景：理解冲突背景（1分钟）
4. 个人决策：写下选择A/B/C/D
5. 说出直觉："我的直觉是选X"
6. 身体觉察：记录呼吸和胸口感受
7. 查看答案：揭晓得分和满意解解析
8. 记录复盘：关键洞察
```
