## 🚀 快速开始

### 单人训练（15分钟）

```
1. 准备卡牌：洗牌，抽取3张背面朝上
2. 说出直觉："左边这张感觉是..."
3. 身体觉察：呼吸顺畅？胸口放松？
4. 选择卡牌：根据直觉选1张
5. 抽取价值卡：随机抽取金额
6. 结算结果：翻开卡牌，计算得分
7. 重复5轮，计算InQ Score
```

## 📖 详细规则

完整规则请参见：`体系A_系列零_机制文档_V1.0.md`

### 核心规则

1. **必须说出直觉**：每张卡都要说出"机会/风险/不确定"
2. **严格限制时间**：从看到卡牌到选择，限时内完成
3. **禁止理性分析**：只能依靠第一直觉，不能计算概率
4. **必须定期复盘**：每5轮后复盘准确率、一致性、情绪

### 身体信号指南

| 信号 | 含义 | 行动 |
|:-----|:-----|:-----|
| 顺畅+放松 | 🟢机会 | 大胆选择 |
| 卡顿+紧绷 | 🟡风险 | 谨慎回避 |
| 急促+剧痛 | 🔴罚款 | 立即止损 |
| 放缓+平静 | 🟣延迟 | 耐心等待 |
