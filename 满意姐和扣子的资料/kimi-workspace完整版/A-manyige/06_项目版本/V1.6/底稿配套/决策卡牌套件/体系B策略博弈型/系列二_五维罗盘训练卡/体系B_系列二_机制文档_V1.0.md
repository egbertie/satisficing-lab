## 一、为什么玩？（核心价值）

### 1.1 五维 + 博弈

体系A的五维罗盘训练直觉，体系B的五维罗盘训练**策略博弈**——在资源约束和对手存在的情况下，如何优化五维决策。

### 1.2 训练什么能力？

| 能力 | 定义 | 商业价值 |
|:-----|:-----|:---------|
| **资源约束下的五维优化** | 有限资源下的最优五维平衡 | 约束决策能力 |

## 二、五维策略博弈框架

### 2.1 时间轴策略（Temporal Strategy）

**博弈要素**：
- 先发优势 vs 后发优势
- 承诺的时间绑定
- 退出时机的博弈

**策略工具**：
```
时间承诺："我将在X时间前完成Y"
延迟披露："暂时不透露长期计划"
加速惩罚："如果你不配合，我将加速推进"
```

---

### 2.2 可行域策略（Feasible Strategy）

**博弈要素**：
- 资源展示的虚实
- 约束条件的谈判
- 可行域的共同扩展

**策略工具**：
```
资源展示：展示/隐藏真实资源状况
约束释放："如果我们合作，我可以调动更多资源"
可信承诺："我将投入X资源，不可撤回"
```

---

### 2.3 身心流策略（Mind-Body Strategy）

**博弈要素**：
- 身体信号的读取与隐藏
- 直觉作为私人信息
- 情绪的策略性表达

**策略工具**：
```
信号传递：通过身体语言传递信心/担忧
信号干扰：故意展示虚假身体信号
情绪控制：在压力下保持冷静的策略优势
```

---

### 2.4 信义观策略（Trust Strategy）

**博弈要素**：
- 声誉的建立与利用
- 信任作为博弈资本
- 背叛的成本与收益

**策略工具**：
```
声誉投资：长期建立可信声誉
信任绑定："如果我背叛，将损失X"
阶段性信任：逐步建立，而非一次性给予
```

---

### 2.5 直觉阈策略（Threshold Strategy）

**博弈要素**：
- 决策时机的博弈
- 信息获取的边际价值
- 后悔最小化的博弈

**策略工具**：
```
抢先决策："我先决定，你跟不跟？"
等待博弈："我需要更多信息，你呢？"
后悔绑定："如果我们现在不做，都会后悔"
```

## 三、怎么玩？（策略博弈模式）

### 3.1 初始设置

**资源池（每位玩家）**：
- 信息点：10点（用于获取五维信息）
- 信任资本：5点（用于建立承诺）
- 时间压力：每轮递减

**信息成本**：
| 维度信息 | 成本 | 价值 |
|:---------|:----:|:----:|
| 时间轴情报 | 2信息点 | 成功率+10% |
| 可行域情报 | 2信息点 | 资源优化+20% |
| 身心流情报 | 3信息点 | 对手意图+15% |
| 信义观情报 | 2信息点 | 信任评估+10% |
| 直觉阈情报 | 3信息点 | 时机判断+15% |

### 3.2 回合流程

```
┌─────────────────────────────────────────────────────┐
│  Step 1: 抽取场景  │ 从60张卡中随机抽取1张        │
├─────────────────────────────────────────────────────┤
│  Step 2: 信息采购  │ 决定是否购买维度情报        │
├─────────────────────────────────────────────────────┤
│  Step 3: 五维评估  │ 评估各维度的策略价值        │
├─────────────────────────────────────────────────────┤
│  Step 4: 对手建模  │ 预测对手的五维偏好          │
├─────────────────────────────────────────────────────┤
│  Step 5: 策略选择  │ 选择A/B/C/D，考虑博弈效应   │
├─────────────────────────────────────────────────────┤
│  Step 6: 结果结算  │ 根据成功率和对手反应结算    │
├─────────────────────────────────────────────────────┤
│  Step 7: 资源更新  │ 更新信息点和信任资本        │
└─────────────────────────────────────────────────────┘
```

### 3.3 博弈结算

**成功率计算**：
```
基础成功率（选项D=90%）
+ 情报加成（每点情报+5%）
+ 信任资本加成（每点+3%）
- 对手对抗（如果有）
= 最终成功率
```

**资源收益**：
```
成功：获得资源池×成功率
失败：损失资源池×(1-成功率)×0.5
```

## 四、五维博弈技巧

### 4.1 信息博弈

**信息获取 vs 信息隐藏**：
- 获取对手信息：投入信息点购买情报
- 隐藏自身信息：投入信息点隐藏真实五维状态

**信息价值评估**：
```
如果信息能改变决策 → 价值高，值得购买
如果信息仅确认已知 → 价值低，不购买
```

### 4.2 承诺博弈

**可信承诺的设计**：
- 时间绑定：延迟生效，不可撤回
- 资源绑定：投入不可回收的资源
- 声誉绑定：公开承诺，违约损失声誉

**承诺的信号效应**：
- 强承诺 = 高置信度，对手更可能配合
- 弱承诺 = 低置信度，对手可能对抗

### 4.3 合作博弈

**五维合作空间**：
- 寻找五维偏好重叠区
- 设计五维互惠方案
- 建立五维重复博弈机制

**合作破裂的防范**：
- 五维监测机制
- 早期预警系统
- 退出保护条款
