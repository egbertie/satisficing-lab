## 一、为什么玩？（核心价值）

### 1.1 策略博弈的晋级认证

体系B的晋级挑战是**策略博弈能力**的认证，与体系A的直觉训练段位独立。

### 1.2 挑战什么？

| 挑战类型 | 目标 | 对应能力 |
|:---------|:-----|:---------|
| **初级策略挑战** | 建立基础博弈能力 | 资源管理+概率评估 |
| **中级策略挑战** | 提升复杂博弈能力 | 信息博弈+承诺设计 |
| **高级策略挑战** | 掌握战略博弈能力 | 多轮博弈+联盟形成 |

## 二、三级策略挑战体系

### 2.1 初级策略挑战（30张）

**适合人群**：
- 已完成体系B系列零/一/二基础训练

**挑战目标**：
- 建立基础博弈能力
- 资源管理+概率评估
- 通过策略青铜→白银段位考核

**通过标准**：
- 完成10个挑战场景
- 终局资源池 ≥ ¥15,000
- 未破产

---

### 2.2 中级策略挑战（30张）

**适合人群**：
- 已通过初级策略挑战

**挑战目标**：
- 提升复杂博弈能力
- 信息博弈+承诺设计
- 通过策略白银→黄金段位考核

**通过标准**：
- 完成10个挑战场景
- 终局资源池 ≥ ¥20,000
- 信息利用率 ≥ 70%

---

### 2.3 高级策略挑战（30张）

**适合人群**：
- 已通过中级策略挑战

**挑战目标**：
- 掌握战略博弈能力
- 多轮博弈+联盟形成
- 通过策略黄金→铂金→钻石段位考核

**通过标准**：
- 完成10个挑战场景
- 终局资源池 ≥ ¥25,000
- 至少形成1次有效联盟

## 三、策略挑战机制

### 3.1 初始设置

**资源池**：
- 现金：¥10,000
- 信息点：10点
- 信任资本：5点

### 3.2 挑战流程

```
┌─────────────────────────────────────────────────────┐
│  Step 1: 选择等级  │ 初级/中级/高级               │
├─────────────────────────────────────────────────────┤
│  Step 2: 初始资源  │ 获得初始资源池              │
├─────────────────────────────────────────────────────┤
│  Step 3: 开始挑战  │ 连续完成10个场景            │
├─────────────────────────────────────────────────────┤
│  Step 4: 信息决策  │ 决定是否购买情报            │
├─────────────────────────────────────────────────────┤
│  Step 5: 策略选择  │ 考虑资源消耗和博弈效应      │
├─────────────────────────────────────────────────────┤
│  Step 6: 对手反应  │ 根据策略触发对手反应        │
├─────────────────────────────────────────────────────┤
│  Step 7: 结果结算  │ 更新资源池                  │
├─────────────────────────────────────────────────────┤
│  Step 8: 判定结果  │ 终局资源池决定通过/失败     │
└─────────────────────────────────────────────────────┘
```

### 3.3 破产与胜利

**破产条件**：
- 现金归零 = 破产淘汰

**胜利条件**：
- 完成10个场景且资源池达标

**排名规则**：
- 1st：资源池最高者
- 2nd：资源池次高者
- ...以此类推

## 五、特殊挑战模式

### 5.1 信息战模式

**规则**：
- 信息点翻倍（20点）
- 情报成本翻倍
- 信息优势放大

**解锁**：策略白银以上

### 5.2 联盟模式

**规则**：
- 2-3人可临时结盟
- 共享部分资源
- 背叛机制存在

**解锁**：策略黄金以上

### 5.3 多轮博弈模式

**规则**：
- 10个场景分为3轮
- 每轮结束后资源部分重置
- 长期声誉累积

**解锁**：策略铂金以上

## 六、与其他系列的联动

### 6.1 挑战前准备

**必须通过前置训练**：
- 初级策略挑战：需完成体系B系列零基础训练
- 中级策略挑战：需通过初级策略挑战
- 高级策略挑战：需通过中级策略挑战

### 6.2 挑战中使用

**可调用其他系列资源**：
- 遇到资源问题 → 调用系列零（直商策略卡）
- 遇到冲突问题 → 调用系列一（合伙人策略卡）
- 需要全面分析 → 调用系列二（五维策略卡）
