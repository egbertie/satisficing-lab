## 一、为什么玩？（核心价值）

### 1.1 策略博弈 vs 直觉训练

| 维度 | 体系A（直觉型） | 体系B（策略型） |
|:-----|:----------------|:----------------|
| 核心问题 | "我的身体告诉我什么？" | "我的资源允许我做什么？" |
| 决策依据 | 身体直觉信号 | 资源池状态+概率评估 |
| 胜利条件 | InQ Score高分 | 终局资源池最大 |
| 博弈重点 | 识别类型 | 资源管理+策略选择 |

### 1.2 训练什么能力？

| 能力 | 定义 | 商业价值 |
|:-----|:-----|:---------|
| **资源管理** | 管理有限资源达成目标 | 约束下的最优化 |
| **概率评估** | 评估各选项的成功概率 | 理性决策基础 |
| **风险对冲** | 降低不确定性的影响 | 保护核心利益 |
| **策略组合** | 多步骤策略协同 | 长期博弈优势 |

## 三、怎么玩？（策略博弈模式）

### 3.1 初始设置

**资源池（每位玩家）**：
- 现金：¥10,000
- 信任点：5点
- 谈判筹码：3个

**资源用途**：
| 资源 | 用途 | 获取方式 |
|:-----|:-----|:---------|
| 现金 | 支付补偿、收购股权 | 机会卡收益 |
| 信任点 | 发起谈判、建立合作 | 成功解决冲突 |
| 谈判筹码 | 强制决策、打破僵局 | 每轮恢复1个 |

### 3.2 回合流程

```
┌─────────────────────────────────────────────────────┐
│  Step 1: 抽取冲突  │ 随机抽取1张冲突场景卡        │
├─────────────────────────────────────────────────────┤
│  Step 2: 资源评估  │ 评估当前资源池状态            │
├─────────────────────────────────────────────────────┤
│  Step 3: 概率评估  │ 评估各选项的成功概率（0-100%）│
├─────────────────────────────────────────────────────┤
│  Step 4: 策略选择  │ 选择A/B/C/D，考虑资源消耗     │
├─────────────────────────────────────────────────────┤
│  Step 5: 资源结算  │ 支付策略成本，获得收益        │
├─────────────────────────────────────────────────────┤
│  Step 6: 信任结算  │ 成功解决+1信任点，失败-1      │
├─────────────────────────────────────────────────────┤
│  Step 7: 记录策略  │ 记录本次策略和结果            │
└─────────────────────────────────────────────────────┘
```

### 3.3 资源成本与收益

**选项成本表**（示例）：

| 选项 | 现金成本 | 信任点 | 成功率 | 预期收益 |
|:-----|:--------:|:------:|:------:|:--------:|
| A（对抗） | ¥0 | -2 | 30% | ¥0 |
| B（妥协） | ¥2,000 | 0 | 60% | ¥1,000 |
| C（平衡） | ¥3,000 | +1 | 75% | ¥3,000 |
| D（满意解） | ¥4,000 | +2 | 90% | ¥5,000 |

**预期价值计算**：
```
EV = 成功率 × 预期收益 - 现金成本
```

### 3.4 策略组合技

**连招1：信任建立流**
```
Type07 信任破裂 → 选择C（坦诚沟通）
  ↓ 信任点+2

  ↓ 信任点+2
Type02 控制权争夺 → 使用谈判筹码强制通过D
  ↓ 低成本获得控制权保护
```

**连招2：资源整合流**
```
Type09 引入新合伙人 → 选择C（试用期+vesting）
  ↓ 节省现金¥2,000
Type01 股权分配 → 使用谈判筹码强制通过D
  ↓ 股权结构优化
Type04 退出机制 → 选择D（分期回购）
  ↓ 现金流保护
```

**连招3：风险对冲流**
```
Type06 价值观念冲突 → 选择D（底线明确）
  ↓ 建立红线
Type11 融资估值分歧 → 选择C（多方比价）
  ↓ 降低单一依赖
Type12 知识产权争议 → 选择D（预先协议）
  ↓ 法律保护
```

## 五、终局结算

### 5.1 胜利条件

**资源池最大者获胜**：
```
终局资源池 = 初始¥10,000 + 累计收益 - 累计成本 + 剩余信任点×¥500
```

### 5.2 破产机制

**现金归零 = 破产**：
- 失去决策权
- 可被其他玩家收购剩余资源
- 游戏结束，排名最后

### 5.3 排名规则

| 排名 | 条件 | 段位提升 |
|:-----|:-----|:---------|
| 1st | 资源池最高 | +2段位 |
| 2nd | 资源池次高 | +1段位 |
| 3rd | 资源池中等 | 段位不变 |
| Last | 破产 | -1段位 |
