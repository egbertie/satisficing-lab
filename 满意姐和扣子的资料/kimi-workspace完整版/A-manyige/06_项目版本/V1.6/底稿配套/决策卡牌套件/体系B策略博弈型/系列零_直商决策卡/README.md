## 🎯 系列定位

**直商决策卡™（策略版）**是体系B策略博弈型的核心系列，专注于训练创业者的资源管理和风险对冲能力。

### 核心特色

- 🎲 **策略博弈**：四色均衡（各15张），明牌决策
- 💰 **资源管理**：初始¥10,000，终局结算排名
- 🛡️ **风险对冲**：预防、转移、保险多种手段
- ⚡ **组合技**：卡牌之间的协同效应

### 卡牌构成

| 类型 | 数量 | 标识 | 特征 |
|:-----|:----:|:----:|:-----|
| 机会卡 | 15张 | 🟢 | 需要投入的正向收益 |
| 风险卡 | 15张 | 🟡 | 可预防的损失 |
| 罚款卡 | 15张 | 🔴 | 可转移的确定损失 |
| 延迟卡 | 15张 | 🟣 | 时间套利型 |
| **总计** | **60张** | - | - |

### 与体系A的差异

| 维度 | 体系A（直觉型） | 体系B（策略型） |
|:-----|:----------------|:----------------|
| 核心问题 | "我的身体告诉我什么？" | "我的资源允许我做什么？" |
| 揭示方式 | 背面朝上（盲选） | 正面朝上（明牌） |
| 决策依据 | 身体直觉信号 | 资源池状态+概率评估 |
| 胜利条件 | InQ Score高分 | 终局资源池最大 |
| 失败条件 | 无 | 资源池归零（破产） |

## 🚀 快速开始

### 标准游戏（30-45分钟，2-6人）

```
初始：每位玩家资源池¥10,000

第1-4轮（每轮3分钟）：
1. 揭示3张卡牌（正面朝上）
2. 评估资源状态
3. 选择1张卡牌+价值卡
4. 执行效果（投入/收益/损失/延迟）
5. 更新资源池

第5轮（终局）：
1. 结算所有🟣延迟卡
2. 结算期间效果
3. 偿还债务
4. 确定最终资源池
5. 排名，资源池最高者获胜
```

## 📖 详细规则

完整规则请参见：`体系B_系列零_机制文档_V1.0.md`

### 核心机制

**资源池管理**：
- 初始：¥10,000
- 用途：支付投入、预防措施、对冲损失
- 归零 = 破产淘汰

**四色卡策略**：
- 🟢机会：投入资源，获得回报
- 🟡风险：采取预防，减少损失
- 🔴罚款：使用对冲，转移风险
- 🟣延迟：时间套利，终局爆发

**组合技示例**：
```
🟢技术研发（投入50%）
  ↓
🟣研发周期（额外投入¥5,000）
  ↓
第5轮结算：6倍回报
```
