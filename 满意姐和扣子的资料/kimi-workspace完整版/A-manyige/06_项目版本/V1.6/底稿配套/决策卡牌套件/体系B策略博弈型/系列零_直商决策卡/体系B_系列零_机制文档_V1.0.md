# 体系B：零系列直商决策卡™ · 机制设计与使用说明 V1.0

> **体系**: 体系B（纯四色策略博弈型）  
> **与体系A差异**: 从"直觉训练"转向"策略博弈"  
> **核心机制**: 资源池管理+四色卡组合+风险对冲  
> **生成时间**: 2026-04-18

---

## 一、为什么玩？（核心价值）

### 1.1 解决什么问题？

创业者不仅需要做决策，还需要**管理决策的后果**：
- 如何在资源有限时选择最佳投资组合？
- 如何对冲不可避免的风险？
- 如何平衡短期收益与长期回报？

**策略博弈，是创业者的第二大脑。**

### 1.2 训练什么能力？

| 能力 | 定义 | 商业价值 |
|:-----|:-----|:---------|
| **资源配置** | 在约束条件下优化资源分配 | 提高ROI，避免浪费 |
| **风险对冲** | 识别风险并提前布局 | 降低损失，提高韧性 |
| **组合思维** | 卡牌之间的协同效应 | 创造1+1>2的效果 |
| **终局意识** | 以第5轮结果为最终目标 | 避免短视决策 |

### 1.3 为什么是"满意解"？

本训练不追求"最优策略"（对手策略未知），而是训练：
> **在不完全信息博弈中，找到"足够稳健"的策略。**

这正是博弈论中的"满意解"概念——不求最优，但求不败。

## 二、与体系A的核心差异

### 2.1 对比总表

| 维度 | 体系A（直觉型） | 体系B（策略型） |
|:-----|:----------------|:----------------|
| **核心问题** | "我的身体告诉我什么？" | "我的资源允许我做什么？" |
| **决策依据** | 身体直觉信号 | 资源池状态+概率评估 |
| **卡牌分布** | 机会40%/风险30%/罚款20%/延迟10% | 四色各25%（均衡） |
| **关键机制** | 说出直觉、身体觉察 | 资源池、对冲、组合技 |
| **胜利条件** | InQ Score高分 | 第5轮资源池最大 |
| **失败条件** | 无（都是训练） | 资源池归零 |
| **学习重点** | 感知能力 | 决策能力 |

### 2.2 选择哪个体系？

**选择体系A（直觉型）如果你**：
- 感觉自己"想太多"，希望培养直觉
- 面临选择时经常犹豫
- 想学习身体信号的解读
- 偏好个人内省式训练

**选择体系B（策略型）如果你**：
- 感觉自己"太冲动"，希望培养理性
- 面临多选项时难以权衡
- 想学习资源管理和风险对冲
- 偏好竞技对抗式训练

## 三、怎么玩？（标准模式）

### 3.1 准备工作

**所需道具**：
- 60张机会卡（四色各15张）
- 40张价值卡
- 资源池记录表
- 延迟卡标记物（筹码/硬币）
- 计时器

**初始资源池**：¥10,000（每位玩家）

**参与人数**：2-6人（最佳3-4人）

**游戏时长**：30-45分钟（5轮）

### 3.2 五轮决策流程

```
┌─────────────────────────────────────────────────────────┐
│ 轮次 │ 阶段1（揭示）│ 阶段2（决策）│ 阶段3（执行）│ 时间  │
├──────┼─────────────┼─────────────┼─────────────┼───────┤
│  1   │ 揭示3张卡牌  │ 选择1张+价值卡│ 执行效果    │ 3分钟 │
├──────┼─────────────┼─────────────┼─────────────┼───────┤
│  2   │ 揭示3张卡牌  │ 选择1张+价值卡│ 执行效果    │ 3分钟 │
├──────┼─────────────┼─────────────┼─────────────┼───────┤
│  3   │ 揭示3张卡牌  │ 选择1张+价值卡│ 执行效果    │ 3分钟 │
├──────┼─────────────┼─────────────┼─────────────┼───────┤
│  4   │ 揭示3张卡牌  │ 选择1张+价值卡│ 执行效果    │ 3分钟 │
├──────┼─────────────┼─────────────┼─────────────┼───────┤
│  5   │ 结算所有🟣   │ 终局计算    │ 确定胜者    │ 3分钟 │
└──────┴─────────────┴─────────────┴─────────────┴───────┘
```

### 3.3 每轮3阶段

#### 阶段1：揭示（30秒）

从60张卡牌中随机抽取3张，**正面朝上**展示给所有玩家。

**与体系A的区别**：体系B是明牌博弈，不是盲选。

**示例揭示**：
```
┌─────────────┐  ┌─────────────┐  ┌─────────────┐
│ 🟢OPP-B03   │  │ 🟡RISK-B07  │  │ 🟣DEL-B01   │
│ 技术研发    │  │ 技术路线错误│  │ 长期投资    │
│ 投入50%→3倍 │  │ 损失×1.5    │  │ 投入→2.5倍  │
└─────────────┘  └─────────────┘  └─────────────┘
```

#### 阶段2：决策（90秒）

**决策步骤**：

1. **评估当前状态**（30秒）
   - 查看自己的资源池余额
   - 查看已持有的🟣延迟卡数量
   - 查看已激活的效果（如护盾、豁免权）

2. **选择卡牌**（30秒）
   - 从3张揭示卡中选择1张
   - 考虑：收益、风险、与已有卡的组合

3. **抽取价值卡**（10秒）
   - 随机抽取1张价值卡
   - 记录金额

4. **确认决策**（20秒）
   - 宣布选择的卡牌和价值卡
   - 计算并宣布预期效果

**决策示例**：
```
当前资源池：¥15,000
已持有：🟣DEL-B01（¥5,000投入）

揭示卡牌：🟢OPP-B03 / 🟡RISK-B07 / 🟣DEL-B01

决策分析：
- 若选🟢OPP-B03：投入¥7,500（50%），第5轮获得¥22,500
- 若选🟡RISK-B07：有🟢OPP-B03则可豁免，但本轮未投资OPP-B03
- 若选🟣DEL-B01：再投入¥X，第5轮两张延迟卡一起结算

最终选择：🟢OPP-B03 + 价值卡¥10,000
预期：投入¥7,500，第5轮获得¥22,500
```

#### 阶段3：执行（60秒）

**执行顺序**：

1. **支付成本**（若🟢机会卡有投入成本）
   - 从资源池扣除投入金额
   - 若资源不足，无法选择该卡

2. **结算即时效果**
   - 🟢机会卡：获得即时收益（若有）
   - 🟡风险卡：触发损失（若有预防措施可减免）
   - 🔴罚款卡：触发损失（可对冲）
   - 🟣延迟卡：放置标记物，记录投入金额

3. **激活期间效果**
   - 如"后续3轮每轮+¥2,000"
   - 如"风险卡损失-20%"

4. **更新资源池**
   - 记录新的资源池余额

**执行示例**：
```
选择：🟢OPP-B03技术研发 + 价值卡¥10,000

执行：
1. 支付投入：¥15,000 × 50% = ¥7,500
   资源池：¥15,000 → ¥7,500

2. 即时效果：无（技术研发是延迟回报）

3. 期间效果：无

4. 放置延迟标记：¥7,500投入🟣延迟池

本轮结束：资源池¥7,500 + 延迟池¥7,500
```

### 3.4 第5轮特殊规则

**终局结算顺序**：

1. **结算所有🟣延迟卡**（按延迟卡顺序）
   - 每张延迟卡根据投入金额和倍数结算
   - 加入资源池

2. **结算期间效果**
   - 如"若资源池>¥30,000，额外获得¥10,000"

3. **结算终局卡**
   - VAL-B08终局卡效果
   - 🟣DEL-B15终局博弈

4. **偿还债务**
   - 🟢OPP-B11金融杠杆：偿还¥20,000
   - VAL-B06借贷卡：偿还¥12,000

5. **确定最终资源池**

6. **排名确定胜者**

**终局示例**：
```
第5轮结算前：
- 资源池：¥25,000
- 延迟池1：¥7,500（DEL-B01）×2.5 = ¥18,750
- 延迟池2：¥5,000（DEL-B03）×1.5 = ¥7,500
- 期间效果：资源池>¥20,000，满足OPP-B12条件

结算：
1. 延迟结算：+¥18,750 + ¥7,500 = +¥26,250
   资源池：¥25,000 → ¥51,250

2. 期间效果：满足OPP-B12，+¥20,000
   资源池：¥51,250 → ¥71,250

3. 偿还杠杆：-¥20,000
   最终资源池：¥51,250

结果：胜利！
```

## 四、核心机制详解

### 4.1 资源池管理

**资源池 = 你的生命值+法力值**

```
资源池用途：
├─ 支付🟢机会卡的投入成本
├─ 支付预防措施费用
├─ 对冲🔴罚款损失
└─ 应对突发事件

资源池归零 = 游戏结束（破产）
```

**资源策略原则**：
- **早期**（第1-2轮）：保守积累，确保生存
- **中期**（第3-4轮）：积极投资，建立优势
- **晚期**（第5轮）：结算兑现，确保领先

### 4.2 四色卡策略定位

| 颜色 | 定位 | 策略角色 |
|:-----|:-----|:---------|
| 🟢 **机会** | 进攻 | 资源增值，建立优势 |
| 🟡 **风险** | 防御 | 识别威胁，提前预防 |
| 🔴 **罚款** | 危机 | 应对损失，转移风险 |
| 🟣 **延迟** | 储蓄 | 延迟满足，终局爆发 |

**四色平衡原则**：
- 纯🟢：高风险高回报，可能早期破产
- 纯🟣：稳健但缺乏爆发力
- 均衡配置：🟢40% + 🟣30% + 风险对冲20% + 应急10%

### 4.3 对冲机制

**对冲 = 降低不确定性的策略**

**常见对冲组合**：

| 风险 | 对冲工具 | 效果 |
|:-----|:---------|:-----|
| 🟡市场波动 | 🟢供应链整合 | 损失-50% |
| 🟡人才流失 | 🟢人才投资 | 豁免 |
| 🔴罚款 | 🟢战略合作护盾 | 抵消 |
| 🔴资产减值 | 🟣延迟卡 | 损失-50% |

**对冲原则**：
- 不要为所有风险买保险（成本太高）
- 优先对冲高概率、高损失的风险
- 保留一部分"自担风险"（资源池10-20%）

### 4.4 组合技机制

**组合技 = 卡牌之间的协同效应**

**示例组合1：研发流水线**
```
🟢OPP-B03技术研发（投入¥X）
  ↓
🟣DEL-B02研发周期（额外投入¥5,000）
  ↓
第5轮结算：总投入×3倍×2倍 = 6倍回报

效果：投入¥10,000 → 第5轮获得¥60,000
```

**示例组合2：风险免疫**
```
🟢OPP-B13知识产权（¥6,000）
  ↓
豁免所有🟡知识产权纠纷风险
  ↓
🟢OPP-B06供应链整合（¥6,000）
  ↓
豁免🟡供应链中断风险

效果：投资¥12,000，免疫两类常见风险
```

**示例组合3：延迟复利**
```
🟣DEL-B05生态构建（投入¥X）
  ↓
每持有一张🟣延迟卡，每轮+¥500
  ↓
持有5张🟣延迟卡 = 每轮+¥2,500
  ↓
第1-4轮累计：+¥10,000
第5轮结算：各延迟卡本金×2

效果：延迟卡越多，期间收益越高
```

### 4.5 终局博弈

**第5轮是关键，但不是全部**

**常见终局策略**：

| 策略 | 适用情况 | 操作 |
|:-----|:---------|:-----|
| **保守型** | 领先 | 选择🟣延迟卡或冻结卡，锁定优势 |
| **激进型** | 落后 | 选择🟢OPP-B11杠杆或🟣DEL-B15终局博弈 |
| **平衡型** | 胶着 | 稳健投资，等待延迟结算 |

**终局风险**：
- 过度杠杆：可能债务压垮
- 过度保守：可能被反超
- 延迟卡不足：缺乏爆发力

## 五、三种训练模式

### 5.1 模式一：单人模拟（学习）

**适用**：学习规则、测试策略
**时长**：20-30分钟

**流程**：
1. 设定初始资源池¥10,000
2. 模拟5轮决策（自己扮演所有角色）
3. 记录每轮资源池变化
4. 复盘策略效果

**目标**：理解卡牌效果和组合

### 5.2 模式二：多人对抗（竞技）

**适用**：策略对抗、排名竞技
**时长**：45-60分钟
**人数**：3-6人

**流程**：
1. 每位玩家初始¥10,000
2. 每轮同时揭示3张卡牌
3. 玩家同时选择（可相同）
4. 同时执行，同时更新资源池
5. 第5轮后排名

**特殊规则**：
- 若多名玩家选择同一张卡，该卡效果均生效（不冲突）
- 资源池归零者淘汰，但可旁观

**目标**：资源池最高者获胜

### 5.3 模式三：教练引导（深度）

**适用**：策略诊断、能力提升
**时长**：90-120分钟
**人数**：2-4人

**流程**：
```
第一阶段：策略评估（30分钟）
├── 分析玩家历史决策模式
├── 识别策略偏好（进攻/防御/均衡）
└── 确定改进重点

第二阶段：实战训练（45分钟）
├── 进行3-5轮对抗
├── 教练实时点评
└── 关键决策点暂停分析

第三阶段：复盘优化（30分钟）
├── 资源曲线分析
├── 策略失误识别
└── 改进建议
```

**目标**：系统性提升策略决策能力

## 六、复盘框架（每局后必做）

### 6.1 资源曲线分析

**绘制你的资源池变化**：

```
资源池
  │
60K│                    ★终点
  │                 ╱
40K│            ★第4轮
  │        ╱
20K│   ★第2轮
  │★第1轮
10K├────┬────┬────┬────┬────→ 轮次
  0    1    2    3    4    5
```

**分析要点**：
- 曲线平滑度：是否有大幅波动？
- 增长趋势：是前高后低还是持续上升？
- 终局爆发：延迟卡贡献了多少？

### 6.2 策略审计四问

#### 问1：资源配置是否合理？

- 早期是否过于激进导致资源紧张？
- 后期是否有足够资源抓住机会？
- 四色卡比例是否均衡？

#### 问2：对冲是否到位？

- 哪些损失本可预防？
- 哪些保险买了但没触发？
- 哪些风险自担是正确的？

#### 问3：组合技是否充分利用？

- 错过了哪些组合机会？
- 哪些组合效果超出预期？
- 下局要优先尝试哪些组合？

#### 问4：终局策略是否正确？

- 领先时是否过于保守/激进？
- 落后时是否有翻盘尝试？
- 延迟卡数量是否足够？

### 6.3 对手分析（多人模式）

**观察对手策略倾向**：

| 类型 | 特征 | 应对策略 |
|:-----|:-----|:---------|
| **激进型** | 早期大举投资🟢 | 保持稳健，等他犯错 |
| **保守型** | 大量持有🟣 | 中期加速拉开差距 |
| **均衡型** | 四色均衡配置 | 寻找他的对冲漏洞 |
| **投机型** | 喜欢高风险卡 | 避免与他正面对抗 |

## 七、关键认知（玩之前必读）

### ❌ 这不是什么？

1. **不是赌博**——虽然有随机性，但决策质量决定长期胜率
2. **不是计算题**——无法精确计算最优解（对手策略未知）
3. **不是单人游戏**——多人模式需要考虑对手策略

### ✅ 这是什么？

1. **是资源管理模拟**——学习在约束条件下做选择
2. **是风险教育工具**——理解对冲和保险的价值
3. **是策略思维训练**——培养组合思维和终局意识

### 💡 核心洞察

> **"在商业中，完美的决策不存在，
> 但'不败'的策略是可以设计的。"**

体系B教你：
- 不要追求每一轮都赢
- 要追求终局资源池最大化
- 要设计"即使最坏情况也能生存"的策略
