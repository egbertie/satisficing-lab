## 🎯 系列定位

**五维罗盘训练卡（策略版）**是体系B策略博弈型的框架系列，训练五维决策的博弈思维。

### 体系A vs 体系B

| 维度 | 体系A（直觉型） | 体系B（策略型） |
|:-----|:----------------|:----------------|
| 核心问题 | "我的身体告诉我什么？" | "我的资源允许我做什么？" |
| 五维训练 | 直觉感知 | 策略博弈 |
| 决策依据 | 身体信号 | 信息价值+承诺设计 |

### 资源系统

| 资源 | 初始值 | 用途 |
|:-----|:------:|:-----|
| 信息点 | 10点 | 获取五维情报 |
| 信任资本 | 5点 | 建立承诺 |
| 时间压力 | 每轮递减 | 决策紧迫性 |

## 🚀 快速开始

### 策略博弈模式（2-6人，30-45分钟）

```
初始设置：
- 每位玩家：信息点10 + 信任资本5

回合流程：
1. 抽取场景：从60张卡中随机1张
2. 信息采购：决定是否购买维度情报
   - 时间轴情报（2点）：成功率+10%
   - 可行域情报（2点）：资源优化+20%
   - 身心流情报（3点）：对手意图+15%
   - 信义观情报（2点）：信任评估+10%
   - 直觉阈情报（3点）：时机判断+15%
3. 五维评估：评估各维度的策略价值
4. 对手建模：预测对手的五维偏好
5. 策略选择：选择A/B/C/D，考虑博弈效应
6. 结果结算：根据成功率和对手反应结算
7. 资源更新：更新信息点和信任资本
```

### 成功率计算

```
基础成功率（选项D=90%）
+ 情报加成（每点情报+5%）
+ 信任资本加成（每点+3%）
- 对手对抗（如果有）
= 最终成功率
```
