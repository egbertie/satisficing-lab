### 体系A vs 体系B

| 维度 | 体系A（直觉型） | 体系B（策略型） |
|:-----|:----------------|:----------------|
| 核心问题 | "我的身体告诉我什么？" | "我的资源允许我做什么？" |
| 决策依据 | 身体直觉信号 | 资源池+概率评估 |

## 🚀 快速开始

### 策略博弈模式（2-6人，45-60分钟）

```
初始设置：
- 每位玩家：现金¥10,000 + 信任点5 + 谈判筹码3

回合流程：
1. 抽取冲突：随机抽取1张冲突场景卡
2. 资源评估：评估当前资源池状态
3. 概率评估：评估各选项成功率
4. 策略选择：选择A/B/C/D，考虑资源消耗
5. 资源结算：支付成本，获得收益
6. 信任结算：成功+1，失败-1
7. 记录策略：记录本次策略和结果

终局结算：
- 资源池 = 初始¥10,000 + 累计收益 - 累计成本 + 信任点×¥500
- 资源池最高者获胜
- 现金归零=破产淘汰
```
