## 第二部分：深度洞察与优化方向

### 2.1 InQ现有设计优势（保持）

| 优势 | 说明 | 优化策略 |
|:-----|:-----|:---------|
| **直觉优先** | 强制禁止理性分析，训练系统1 | 保留核心规则 |
| **身体觉察** | 呼吸/胸口觉察，具身认知应用 | 扩展至多维度身体信号 |
| **量化评分** | InQ Score三维评估 | 升级为五维罗盘适配版 |
| **即时反馈** | 结算结果立即呈现 | 增加延迟反馈变体 |
| **高频训练** | 10-20轮/次，每周2-3次 | 设计进阶频率 |

### 2.2 InQ现有局限与优化点

| 局限 | 深度洞察 | 优化方向 |
|:-----|:---------|:---------|
| **单一维度训练** | 仅训练直觉，未关联合伙人决策场景 | 嫁接至合伙人冲突类型 |
| **无晋级机制** | 60张机会卡固定，缺乏进阶感 | 设计L1-L4认知深度晋级 |
| **无降级风险** | 只有分数高低，无能力退化模拟 | 增加"决策疲劳"机制 |
| **孤立训练** | 个人直觉训练，未结合团队协作 | 增加多人协作变体 |
| **理论深度不足** | 说明书未体现学术支撑 | 增加理论溯源与解释 |

## 第三部分：满意解项目深度优化方案

### 3.1 核心嫁接：五维决策罗盘 × InQ卡牌

将InQ的直觉训练与满意解的五维罗盘深度融合：

```
五维决策罗盘 · InQ增强版

        时间轴 (时机感知)
           ▲
          /│\
         / │ \    ← 每张卡牌增加"时机"维度
        /  │  \      （太早/正好/太晚）
       /   │   \
信义观◄────┼────►可行域
(信任直觉)  │    (资源感知)
      \    │    /
       \   │   /
        \  │  /
         \ │ /
          ▼
        身心流 (身体觉察 ← InQ核心)
           │
      直觉阈 (直觉验证 ← InQ核心)
```

### 3.2 系列卡牌设计：满意解决策卡牌矩阵

#### 卡牌系列一：合伙人冲突类型卡（12 Types Card）

**定位**: 嫁接12类型案例库至卡牌游戏

| 卡牌类型 | 数量 | 内容 | 训练目标 |
|:---------|:----:|:-----|:---------|
| **Type01-12场景卡** | 36张 | 每类型3张典型场景 | 模式识别 |
| **冲突信号卡** | 24张 | 早期/中期/晚期信号各8张 | 风险直觉 |
| **干预时机卡** | 12张 | 教练介入点判断 | 决策速度 |
| **情绪反应卡** | 12张 | 创始人常见情绪陷阱 | 情绪控制 |
| **价值锚定卡** | 16张 | 不同情境下的价值权衡 | 满意解判断 |

**玩法变体**: 
- **单人模式**: 抽卡→识别类型→选择干预策略→验证
- **双人模式**: 一人扮演创始人，一人扮演教练，角色互换
- **团队模式**: 多人竞争识别速度与准确度

---

#### 卡牌系列二：五维罗盘训练卡（Five-Dimension Compass Card）

**定位**: 专项训练五维决策能力

| 维度 | 卡牌数量 | 卡牌类型 | 训练机制 |
|:-----|:--------:|:---------|:---------|
| **时间轴** | 12张 | 时机判断卡 | 过早/正好/太晚决策后果 |
| **可行域** | 12张 | 资源评估卡 | MVP验证/尽调/信任实验 |
| **身心流** | 12张 | 身体觉察卡 | 呼吸/胸口/ Gut Feeling |
| **信义观** | 12张 | 信任测试卡 | 信号识别/背叛预警 |
| **直觉阈** | 12张 | 直觉验证卡 | 感知力校准/反思日记 |

**核心玩法**: 
```
五维罗盘训练流程（每轮5分钟）

Step 1: 抽取1张维度卡（如"时间轴"）
Step 2: 快速阅读场景（30秒）
Step 3: 身体觉察（说出感受，30秒）
Step 4: 直觉判断（时机选择，1分钟）
Step 5: 翻开结果卡（看到决策后果，30秒）
Step 6: 五维评分（记录InQ Score，2分钟）
```

#### 卡牌系列三：晋级挑战卡（L1-L4认知深度卡）

**定位**: 结合COGROUTER认知深度理论，设计晋级/降级机制

| 层级 | 卡牌数量 | 难度 | 晋级条件 | 降级风险 |
|:----:|:--------:|:----:|:---------|:---------|
| **L1 现象层** | 20张 | ⭐ | 完成基础识别 | 无 |
| **L2 模式层** | 20张 | ⭐⭐ | 识别重复模式+历史关联 | 连续3次失败→退回L1 |
| **L3 结构层** | 20张 | ⭐⭐⭐ | 绘制结构图+敏感性分析 | 连续2次失败→退回L2 |
| **L4 元认知层** | 20张 | ⭐⭐⭐⭐ | 认知验证+盲点挖掘 | 连续2次失败→退回L3 |
| **大师层** | 10张 | ⭐⭐⭐⭐⭐ | 综合运用+创新解法 | 失败→退回L4 |

**晋级机制详解**:
```
晋级判定（每完成5轮）

┌─────────────────────────────────────────────────────┐
│  准确率 ≥ 80% + 一致性 ≥ 90% + 速度达标             │
│        ↓                                            │
│  获得"认知跃迁"资格 → 挑战下一层级卡牌（3张）      │
│        ↓                                            │
│  挑战成功（2/3通过）→ 正式晋级，解锁新层级          │
│  挑战失败 → 留在当前层级，继续训练                  │
└─────────────────────────────────────────────────────┘
```

**降级机制详解**:
```
降级判定（保护机制）

┌─────────────────────────────────────────────────────┐
│  连续N次准确率 < 60%（N=3 for L2, N=2 for L3+）      │
│        ↓                                            │
│  触发"认知回退" → 退回上一层级（非惩罚，是保护）    │
│        ↓                                            │
│  在新层级重新建立信心 → 再次挑战晋级                │
└─────────────────────────────────────────────────────┘

降级不是失败，是为了防止"认知超载"导致的训练损伤。
如同健身中的"减量周"，是为了更好的长期进步。
```
