## 第三部分：12类型合伙人冲突案例库

### 3.1 案例库架构

**12场景类型 × 8冲突域 = 96分类矩阵**

| 类型 | 场景 | 学术映射 |
|:--|:--|:--|
| Type 1 | 多元化集团合伙人关系决策 | 多元派vs聚焦派冲突 |
| Type 2 | 第三次再创业 | 经验固化vs新情境 |
| Type 3 | 项目升级期（从1到100） | 战略愿景分歧 |
| Type 4 | 项目转型期 | 业务转型冲突 |
| Type 5 | 低位创始人与高位合伙人 | 权力不对称 |
| Type 6 | 产品成型打磨期（TRL 7-8） | 任务型冲突 |
| **Type 7** | **创业次年合伙人关系** | **冲突爆发高峰（35%）** |
| Type 8 | 创始人与合伙人关系定位 | 角色期望分歧 |
| **Type 9** | **创始人与技术合伙人** | **市场派vs技术派原型** |
| Type 10 | 创始人与资源型合伙人 | 资源承诺vs兑现 |
| Type 11 | 非绝对控股型创始人 | 控制权博弈 |
| Type 12 | 投资型公司创始人 | 财务vs战略投资者 |

### 3.2 标杆案例（学术增强）

**比特大陆案例**（Type 9）
- **冲突类型**：市场派vs技术派（孙继伟，2024）
- **演化阶段**：分化期→碰撞期→治理期（和解失败）
- **教训**：双CEO结构是高不稳定的权力配置

**Intel三位一体**（Type 9）
- **成功要素**：Noyce（魅力领袖）+ Moore（技术天才）+ Grove（管理铁腕）
- **学术映射**：技能互补性（Skill Complementarity）
