## 二、合伙人关系 MVP 验证清单

### 核心理念

在正式合伙（签股权、分控制权）之前，先用**最小可行合伙关系**验证以下 3 个关键假设：

1. **能力假设**: 他真的能解决你需要他解决的问题吗？
2. **协作假设**: 你们真的能在一起高效共事吗？
3. **价值观假设**: 当利益冲突时，你们的选择方向一致吗？

---

### MVP 设计：1 周验证实验

#### 实验目标
设计一个**真实的小型项目**，让候选合伙人在 1 周内完成一个紧密协作的任务。

| 实验要素 | 设计要求 |
|:--|:--|
| **时间** | 3-7 天，最长不超过 2 周 |
| **任务** | 一个你们未来合伙时会反复遇到的典型场景 |
| **投入** | 双方都需要付出真实时间和精力（不能是纯聊天） |
| **产出** | 一个可评估的交付物或决策结果 |
| **成本** | 总成本（时间+金钱）不超过你们正式合伙 1 个月的风险敞口 |

---

#### 典型 MVP 任务示例

| 合伙人类型 | MVP 任务示例 |
|:--|:--|
| **技术合伙人** | 用 1 周时间完成一个核心功能原型的技术可行性验证 |
| **市场合伙人** | 用 1 周时间接触 5 个目标客户并带回真实反馈 |
| **资源合伙人** | 用 1 周时间落实一个他声称可以带来的关键合作意向 |
| **运营合伙人** | 用 1 周时间优化一个现有业务流程并量化效率提升 |
| **联合创始人** | 用 1 周时间共同完成一份商业计划书并模拟路演 1 次 |

---

### 验证清单（7 问）

在 MVP 实验结束后，双方分别独立回答以下 7 个问题，然后对答案：

1. **交付质量**: 他的实际产出，符合你的预期吗？（1-10 分）
2. **沟通效率**: 你们的沟通是顺畅的，还是经常需要「翻译」？（1-10 分）
3. **决策体验**: 在至少一次有分歧的决策中，你们是怎么处理的？满意吗？（1-10 分）
4. **时间投入**: 他实际投入的时间/精力，和他承诺的一致吗？（是 / 否 / 超出 / 不足）
5. **压力反应**: 当任务出现突发问题时，他的第一反应是什么？（积极解决 / 抱怨 / 推诿 / 求助）
6. **价值观闪现**: 在 MVP 过程中，有没有一个瞬间让你觉得「这种人不能合伙」？（记录具体事件）
7. **继续意愿**: 如果现在要签正式合伙协议，你的第一反应是兴奋、犹豫还是抗拒？（三选一）

---

### 决策规则

```
┌─────────────────────────────────────────────────────────┐
│                    MVP 实验决策树                        │
├─────────────────────────────────────────────────────────┤
│                                                         │
│   7 个问题平均分 ≥ 8 分  →  进入正式合伙谈判            │
│                                                         │
│   7 个问题平均分 6-7 分  →  延长 MVP（再做一个实验）    │
│                                                         │
│   任意一题 ≤ 4 分        →  暂停合伙，明确问题后再评估  │
│                                                         │
│   第 6 题有具体内容      →  红灯，建议终止              │
│                                                         │
│   第 7 题 = 抗拒         →  红灯，无论分数多高都建议终止│
│                                                         │
└─────────────────────────────────────────────────────────┘
```

## 四、使用场景

| 场景 | 使用方式 | 效果 |
|:--|:--|:--|
| **朋友圈/公众号传播** | 只发金句 + 一页纸传播卡 | 快速建立「理性合伙」品牌心智 |
| **客户初次破冰** | 在咨询前发给客户 MVP 清单 | 降低客户决策焦虑，提升信任度 |
| **合伙人谈判前** | 提议先做 1 周 MVP | 把「要不要合伙」拆成「要不要先试试」 |
| **现有合伙危机** | 回顾当初是否做过 MVP 验证 | 找到问题的历史根因 |
