# SKU-B Week 2「Orient 定向」—— 合伙人假设验证清单

> **来源**: 四文档洞察血液化（失败课六步思维 + 私董陪跑战略实现因子迁移）  
> **版本**: V1.0  
> **生成时间**: 2026-04-12  
> **使用时机**: SKU-B 合伙人决策教练陪跑第 2 周，创始人与决策教练共同完成

---

## 一、清单目的

在 SKU-B 的 Week 2，创始人往往已度过「情绪宣泄」阶段，开始理性审视合伙人选择的核心假设。本清单基于「失败课」六步思维中的风险前置诊断逻辑，将「方向-逻辑-切点-团队-竞争-融资」迁移为「合伙人假设验证」的 6 个维度，帮助创始人在引入合伙人之前，系统性地暴露并验证关键假设。

---

## 二、六维假设验证表

### 维度 1：方向假设 —— 合伙人是否与企业的战略方向一致？

| 验证问题 | 创始人回答 | 证据/反证 | 风险评级 |
|----------|-----------|-----------|----------|
| 候选人对我们 3-5 年战略方向的理解是什么？ | | | |
| 如果他来写我们的战略，会有本质不同吗？ | | | |
| 他对行业终局的判断与我们是否在同一频道？ | | | |

**关联五路图腾**：刘禹锡·土 —— 五年后还会对吗？

---

### 维度 2：逻辑假设 —— 合伙人的资源/能力是否能按预期转化为企业价值？

| 验证问题 | 创始人回答 | 证据/反证 | 风险评级 |
|----------|-----------|-----------|----------|
| 他声称的能力/资源有哪些已经经过第三方验证？ | | | |
| 这些资源进入我们公司后，转化的路径是否清晰？ | | | |
| 如果以 18 个月为周期，他的价值创造的单元模型是什么？ | | | |

**关联五路图腾**：司马贺·金 —— 价值创造逻辑是否闭环？

---

### 维度 3：切点假设 —— 合伙人是在当前阶段引入，还是过早/过晚？

| 验证问题 | 创始人回答 | 证据/反证 | 风险评级 |
|----------|-----------|-----------|----------|
| 如果我们现在不引入他，6 个月后会有什么后果？ | | | |
| 如果我们 6 个月后再引入他，会失去什么窗口期？ | | | |
| 他是否处于「刚好够用」的状态，还是「超前配置」？ | | | |

**关联五路图腾**：司马贺·金 —— 满意解时机的判断

---

### 维度 4：团队假设 —— 合伙人补充了哪些核心能力？是否形成互补？

| 验证问题 | 创始人回答 | 证据/反证 | 风险评级 |
|----------|-----------|-----------|----------|
| 用一张表列出「创始人自己做不了、必须合伙人来做」的 3 件事。 | | | |
| 这 3 件事，候选人是否都有独立闭环完成的真实案例？ | | | |
| 如果他中途退出，我们是否有替代方案或缓冲期？ | | | |

**关联五路图腾**：观自在·水 —— 缺口识别的 clarity

---

### 维度 5：竞争假设 —— 合伙人的加入是否显著增强了企业的竞争壁垒？

| 验证问题 | 创始人回答 | 证据/反证 | 风险评级 |
|----------|-----------|-----------|----------|
| 他的加入是否让竞争对手更难复制我们的模式？ | | | |
| 他带来的壁垒是「关系型」还是「能力型」？关系型壁垒的可迁移性如何？ | | | |
| 3 年后，这些壁垒是否依然存在？ | | | |

**关联五路图腾**：六祖慧能·火 —— 晋卦校准：进阶还是拖累？

---

### 维度 6：融资假设 —— 合伙人对融资的助力/阻力是什么？

| 验证问题 | 创始人回答 | 证据/反证 | 风险评级 |
|----------|-----------|-----------|----------|
| 投资人对他的评价是什么？是加分项还是「需要解释」的项？ | | | |
| 他在下一轮谈判中的角色定位是什么？（站台/对赌/背书？） | | | |
| 他的股权要求是否会影响后续融资的 CAP Table 健康度？ | | | |

**关联交付物**：鼎玉评估 —— 资源是否经过市场验证？

## 三、风险评级汇总与下一步动作

### 风险评级颜色标准
- 🟢 **低风险**（0-1 个黄色警告）：方向基本清晰，可推进深度谈判
- 🟡 **中风险**（2-3 个黄色警告）：存在关键假设未验证，需补充访谈或尽调
- 🔴 **高风险**（≥1 个红色警告或 ≥4 个黄色警告）：建议暂停引入，重新评估候选名单

### Week 2 输出物
1. 本清单的完整填写版本（创始人手写/打字均可）
2. 一份「高风险假设」的专项补充访谈提纲
3. 决策教练的校准意见：哪些假设是创始人一厢情愿，哪些是需要第三方验证的
