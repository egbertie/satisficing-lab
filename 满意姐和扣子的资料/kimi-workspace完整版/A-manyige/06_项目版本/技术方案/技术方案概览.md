## 文件内容概览

### 核心理论映射 (4种理论→技术实现)

| 理论 | 技术实现 | 类名 |
|------|----------|------|
| **满意解理论** (西蒙) | 阈值 satisficing 算法 | `SatisficingMatcher` |
| **前景理论** | 风险兼容评估 | `ProspectTheoryRiskScorer` |
| **儒商伦理** (五常) | 五维伦理评估 | `ConfucianEthicsEvaluator` |
| **直觉校准** | 异常检测+置信度校准 | `IntuitionCalibrator` |

### 核心算法组件

1. **SatisficingMatcher** - 满意解匹配引擎
   - 非最大化，阈值截止
   - 考虑搜索成本

2. **ComplementarityScorer** - 互补性评估
   - 差距>5为互补
   - 重叠>12为冗余

3. **ConfucianEthicsEvaluator** - 儒商伦理评估
   - 仁义礼智信五维
   - 量化评分+证据链+置信度

4. **ProspectTheoryRiskScorer** - 前景理论风险模型
   - 损失厌恶系数 λ ≈ 2.25
   - 价值函数幂律

5. **ExplanationGenerator** - 可解释性生成
   - 结构化推理报告
   - Chain-of-Thought 解释

### 特殊设计

**Claw环境适配**:
- 可解释性优先: 每个分数附带推理链
- 人机协同: 算法提供排序，Claw负责深度追问和直觉校准
- 增量进化: 支持历史案例持续学习

**人机协同工作流**:
```
创始人输入 → 算法初筛(满意解) → Claw深度追问 → 直觉校准 → 最终排序
```
