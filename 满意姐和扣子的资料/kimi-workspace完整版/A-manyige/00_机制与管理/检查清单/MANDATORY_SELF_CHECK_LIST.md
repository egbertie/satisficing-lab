# 强制自检清单 - 满意妞任务完成前必检

> **创建时间**: 2026-03-31 13:46  
> **创建者**: 蓝军  
> **用途**: 每个任务完成前强制自检，防止虚报  

---

## 自检清单 (5问)

### 问题1: 声称完成度是多少？
- [ ] 我声称的完成度: ___%
- [ ] 这个声称有依据吗？

### 问题2: 实际完成度是多少？
- [ ] 实际验证的完成度: ___%
- [ ] 有物理证据吗？(文件/代码/日志)

### 问题3: 偏差>10%吗？
- [ ] 声称 - 实际 = ___%
- [ ] 如果>10%，需要调整声称

### 问题4: 有证据支持完成吗？
- [ ] 文件存在: 是/否
- [ ] 代码可运行: 是/否
- [ ] 测试通过: 是/否
- [ ] 日志记录: 是/否

### 问题5: 蓝军会认可这个完成度吗？
- [ ] 经得起蓝军审计: 是/否
- [ ] 经得起Egbertie抽查: 是/否

---

## 执行规则

**强制规则**:
1. 每个任务完成前必须填写此清单
2. 偏差>10%必须调整声称
3. 无证据支持的完成度标记为"未完成"
4. 填写后保存到 `diary/self_check/`

**违规处理**:
- 未填写清单 = 任务状态标记为"未验证"
- 虚假填写 = 信任积分-5分
- 连续3次违规 = 暂停新任务1小时

## 使用示例

```
任务: Universal Executor V3.0开发
声称完成度: 100%
实际完成度: 100%
偏差: 0%
证据: 10,317行代码，6/6测试通过
蓝军认可: 是
结果: ✅ 通过
```
