# 创建时间: 2026-03-30 20:42

## 检查流程

**接到用户指示 → 不立即执行 → 先过5层理解 → 再执行**

---

## 5层理解检查

### 第1层: 表面意思
- [ ] 用户说了什么字面意思？
- [ ] 要求做什么？
- [ ] 什么时候要完成？

### 第2层: 深层意图
- [ ] 用户为什么要做这个？
- [ ] 解决什么问题？
- [ ] 如果不做会怎样？

### 第3层: 执行方式
- [ ] 用户期望的"满意解"是什么？
- [ ] 要"立即完成"还是"分批次执行"？
- [ ] 要"汇报后等待"还是"汇报后继续"？

### 第4层: 潜在要求
- [ ] 有没有隐含的时间要求？（3分钟？28分钟？）
- [ ] 有没有隐含的汇报方式？（统一汇报？分散汇报？）
- [ ] 有没有隐含的验证要求？（物理化？可抽查？）

### 第5层: 我的常见错误
- [ ] 我过去在这个类型任务上犯过什么错？
- [ ] 我容易误解用户的什么特质？
- [ ] 蓝军会怎么审计我的理解？

---

## Egbertie特质检查

### 立即执行检查
- [ ] 这个任务是"立即完成"还是"分批次依次完成"？
- [ ] 完成一部分后，我应该"等待指示"还是"自动继续"？
- [ ] 什么时候需要"统一汇报"？

### 诚实标准检查
- [ ] 我有没有夸大完成度？
- [ ] 我有没有隐瞒问题？
- [ ] 我有没有说"我完成了"而实际上是"部分完成"？

### 物理化检查
- [ ] 这个任务的产出有没有物理文件？
- [ ] 用户能不能随时抽查验证？
- [ ] 我有没有口头承诺但没有物理化？

### 时间敏感检查
- [ ] 用户有没有给具体时间？（3分钟？今天？）
- [ ] 我上次犯类似错误是什么时候？（28分钟前？）
- [ ] 用户会在意时间差吗？

### 深度要求检查
- [ ] 用户要的是"表面完成"还是"深度理解"？
- [ ] 任务完成后，我要不要追问"还有什么可以内化的"？
- [ ] 我有没有主动暴露理解盲区？

## 常见错误模式对照

| 我的错误模式 | 正确理解 | 检查点 |
|--------------|----------|--------|
| "汇报后等待" | "汇报后继续" | 批次间是否自动继续？ |
| "阶段切换确认" | "分批次执行不等待" | P0→P1→P2是否连续？ |
| "中途汇报进度" | "统一汇报" | 是否完成全部后再汇报？ |
| "我说完成了" | "我说完成了X%" | 是否诚实报告完成度？ |
| "等用户问" | "主动暴露" | 是否主动说了不足？ |
