## 强制检查项

### 1. 原始数据提取
- [ ] 读取了全部源数据（附命令）
- [ ] 提取了所有相关记录（附数量）
- [ ] 保存了原始数据文件（附路径）

### 2. 量化统计
- [ ] **样本数量**（如：分析了X个文件）
- [ ] **统计结果**（如：模式A出现Y次，占比Z%）
- [ ] **置信度**（如：基于W%的数据）

### 3. 分层分析（L1-L5）
- [ ] **L1: 原始数据** - 原始记录是什么
- [ ] **L2: 分类统计** - 各类别数量分布
- [ ] **L3: 模式识别** - 发现了什么模式
- [ ] **L4: 原因分析** - 为什么会有这些模式
- [ ] **L5: Actionable Insights** - 能采取什么行动

### 4. 交付物验证
- [ ] 原始数据文件存在
- [ ] 分析脚本存在
- [ ] 结果文件存在

### 5. 五维度深度检查（2026-03-31新增）
- [ ] **时间维度**: 系统重启/时间变化/过期会影响吗？
  - 数据存储在/tmp？→ 必须迁移到持久化
  - 有有效期限制？→ 必须设置过期处理
  - 依赖外部时间？→ 必须考虑时间漂移
- [ ] **空间维度**: 这是全部数据的100%还是更少？
  - 搜索必须5遍（基础/变体/标记/深度/配置）
  - 必须报告数据完整性百分比
  - 如果<100%，必须说明剩余数据在哪
- [ ] **深度维度**: 这是表面现象还是根本原因？
  - 必须追问5层（表面→浅层→中层→深层→根源）
  - 必须找到根本原因
  - 必须制定防止再发的措施
- [ ] **关联维度**: 与历史问题有关联吗？
  - 类似问题过去发生过吗？
  - 与哪些系统/人员/流程/文化有关联？
  - 关联程度：高/中/低/无
- [ ] **演进维度**: 这个任务培养了我什么能力？
  - 培养了什么能力？
  - 能力提升多少（1-10分）？
  - 如何运用到未来？

## 失败处理

缺少任何一项 = 分析不合格
