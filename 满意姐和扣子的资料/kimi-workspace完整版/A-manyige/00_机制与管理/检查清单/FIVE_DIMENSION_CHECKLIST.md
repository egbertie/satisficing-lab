## 五项维度检查清单

### 一、时间维度检查
**问题**: 系统重启/时间变化/过期会影响吗？

| 检查项 | 回答 | 风险等级 | 应对措施 |
|--------|------|----------|----------|
| 数据存储在/tmp？ | | 🔴/🟢 | |
| 数据存储在内存？ | | 🔴/🟢 | |
| 有有效期限制？ | | 🟡/🟢 | |
| 定时任务时间敏感？ | | 🟡/🟢 | |
| 依赖外部时间？ | | 🟡/🟢 | |

**必须回答**: 如果时间倒流/重启/过期，这个机制会怎样？

---

### 二、空间维度检查
**问题**: 这是全部数据的100%还是更少？

| 检查项 | 回答 | 数据完整性 |
|--------|------|------------|
| 这是全量搜索吗？ | 是/否 | % |
| 搜索了几遍？ | X遍 | - |
| 覆盖所有目录了吗？ | 是/否 | - |
| 有遗漏的存储位置吗？ | 有/无 | - |
| 数据可验证吗？ | 是/否 | % |

**必须回答**: 这是全部数据的百分之多少？如果是<100%，剩余的在哪？

---

### 三、深度维度检查
**问题**: 这是表面现象还是根本原因？

| 层级 | 问题 | 回答 |
|------|------|------|
| 表面 | 看到的问题是什么？ | |
| 浅层 | 直接原因是什么？ | |
| 中层 | 制度原因是什么？ | |
| 深层 | 根本原因是什么？ | |
| 根源 | 系统/文化原因是什么？ | |

**必须回答**: 这个问题的根本原因是什么？如何防止再次发生？

---

### 四、关联维度检查
**问题**: 与历史问题有关联吗？

| 关联类型 | 检查项 | 关联程度 | 说明 |
|----------|--------|----------|------|
| 历史 | 类似问题过去发生过吗？ | 高/中/低/无 | |
| 系统 | 与其他系统有关联吗？ | 高/中/低/无 | |
| 人员 | 与人员能力有关联吗？ | 高/中/低/无 | |
| 流程 | 与流程缺陷有关联吗？ | 高/中/低/无 | |
| 文化 | 与文化习惯有关联吗？ | 高/中/低/无 | |

**必须回答**: 这个问题与历史上的XX问题有关联吗？

---

### 五、演进维度检查
**问题**: 这个任务培养了我什么能力？

| 能力维度 | 培养前 | 培养后 | 提升度 |
|----------|--------|--------|--------|
| 全局思维 | 1-10分 | 1-10分 | +X分 |
| 历史思维 | 1-10分 | 1-10分 | +X分 |
| 发展思维 | 1-10分 | 1-10分 | +X分 |
| 边界预判 | 1-10分 | 1-10分 | +X分 |
| 深度追问 | 1-10分 | 1-10分 | +X分 |

**必须回答**: 通过这个任务，我培养了什么能力？如何运用到未来？
