# Token管理强制检查清单
## 防止Token浪费和红线突破

**版本**: v1.0.0  
**更新时间**: 2026-03-31  
**审核状态**: ✅ 蓝军已审计

---

## P0级检查项（零容忍）

### 1. Token成本估算

- [ ] **TOKEN_COST_ESTIMATE** 部分存在
- [ ] 每次API调用成本已估算
- [ ] 总成本上限已设定
- [ ] 成本与效益比已计算

**检查标准**: 无成本估算 = 不合格

### 2. Token效益红线

- [ ] **TOKEN_RED_LINES** 部分存在
- [ ] 单次调用上限已设定（如≤5000 tokens）
- [ ] 日消费上限已设定
- [ ] 任务总预算已设定

**检查标准**: 无红线 = 不合格

### 3. Token优化空间评估

- [ ] **TOKEN_OPTIMIZATION** 部分存在
- [ ] 已识别可优化点
- [ ] 优化方案已制定
- [ ] 预期节省已量化

**检查标准**: 无优化评估 = 不合格

---

## P1级检查项（建议）

### 4. 红线数值合理性

- [ ] 单次调用上限 ≤ 5000 tokens
- [ ] 日消费上限 ≤ 50,000 tokens
- [ ] 任务预算与复杂度匹配
- [ ] 有10-20%的缓冲空间

### 5. 监控机制

- [ ] Token使用实时监控
- [ ] 超出80%时预警
- [ ] 超出95%时熔断
- [ ] 使用记录自动保存

### 6. 优化实施

- [ ] 批量操作代替单个调用
- [ ] 缓存机制减少重复请求
- [ ] 压缩提示词减少输入token
- [ ] 选择更经济的模型

---

## 检查流程

```
任务启动
    ↓
估算Token成本
    ↓
设定红线数值
    ↓
识别优化空间
    ↓
执行并监控
    ↓
事后复盘优化效果
```

## 失败处理

**P0项缺失**: 任务不得启动，必须补充后重新提交

**P1项缺失**: 警告记录，建议在下个版本补充
