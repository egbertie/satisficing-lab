## 🗺️ 一、总体结构速览

`A-manyige/` 是所有**面向 Egbertie 的用户可读内容**的统一归口。按功能分为 12 大类：

```
A-manyige/
├── totem_system/          # 五路图腾知识库与系统提示词
├── 参考资料/               # 外部优质资料（一堂方法论、指标体系等）
├── 审计/                   # 诚实审计报告、内化闭环报告
├── 对话/                   # 每日对话归档（按日期+按主题双索引）
├── 常用/                   # 常用文档、管理哲学、执行方案
├── 归档/                   # 历史版本、全量清单、管理档案
├── 手册/                   # 系统使用手册
├── 文档/                   # 文件治理规范、合并设计稿等
├── 汇报/                   # 日报、周报、专项报告、技术储备
├── 蓝军审计/               # 蓝军独立审计专区
├── 讨论/                   # 满意姐与蓝军的讨论记录
└── 项目版本/               # 产品版本资料（V1.6 底稿、中间产出等）
```

## 📝 四、使用指南

### 想找什么？看这里：

| 你要找的内容 | 去哪个目录 |
|--------------|------------|
| 今早/昨天的系统运行报告 | `汇报/日报/` |
| 某一次审计或研究内化结果 | `审计/` 或 `对话/YYYY-MM-DD/` |
| 五路图腾相关内容 | `totem_system/` |
| 外部资料整理（一堂、指标体系） | `参考资料/` |
| 某项产品版本的底稿/定稿 | `项目版本/V1.6/` |
| 历史对话记录 | `对话/YYYY-MM-DD/`（最新）或 `对话/📅-按日期/`（旧） |
| 蓝军独立审计 | `蓝军审计/` |
| 管理哲学、执行细节总纲 | `常用/` |

### 文件名规则（机制化）

根据 AGENTS.md 规则四，所有放入 `A-manyige/` 的文件命名必须包含**精确到分钟的时间戳**（HHMM），格式示例：

```
报告标题_V1.0-YYYY-MM-DD-HHMM.md
简报名称_YYYY-MM-DD.md   ← 此类型为违规，需补充 HHMM
日报名称-YYYY-MM-DD.md   ← 周期性日报可保留，但尽量统一
```

如发现文件名缺少时间戳的新文件，视为需要整改。
