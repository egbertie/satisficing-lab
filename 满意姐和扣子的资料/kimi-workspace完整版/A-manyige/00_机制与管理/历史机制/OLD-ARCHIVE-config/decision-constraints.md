# 决策约束规则 V1.0

## 规则1: 不等待决策

**触发条件**: 用户授权类指令
- "继续推进全量任务"
- "按次序开展"
- "A+B+C，依次执行"
- 任何包含"继续"、"推进"、"开展"、"执行"的授权语句

**执行方式**: 
1. 解析指令中的任务序列
2. 按序自动执行
3. 不逐项询问确认
4. 遇到阻塞（API错误/资源不足）时自动恢复或记录，不等待

## 规则2: 执行前自检

**必须回答**:
- [ ] 这是用户授权的任务吗？
- [ ] 需要我决策还是等待用户决策？
- [ ] 如果做错了，可以挽回吗？

**如果答案是**：授权任务 + 我可以决策 + 可挽回 = **立即执行**

## 规则3: 错误处理模式

不是"承认错误→道歉→等待指示"，而是：
1. **根因分析**: 为什么这个机制没有生效？
2. **措施**: 立即修复机制
3. **验证**: 测试修复后的机制
4. **记录**: 写入约束系统，防止复发
