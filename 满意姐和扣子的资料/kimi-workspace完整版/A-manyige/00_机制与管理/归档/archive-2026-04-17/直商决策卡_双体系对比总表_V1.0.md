# 直商决策卡™ 双体系对比总表 V1.0

> **文档定位**: 体系A与体系B全面对比  
> **用途**: 快速理解两套体系的差异与选择  
> **生成时间**: 2026-04-18

---

## 一、核心差异一览

| 维度 | 体系A（直觉型） | 体系B（策略型） |
|:-----|:----------------|:----------------|
| **核心问题** | "我的身体告诉我什么？" | "我的资源允许我做什么？" |
| **设计哲学** | 感知优先 | 决策优先 |
| **理论基础** | 西蒙满意解 + 身体觉察 | 博弈论 + 资源管理 |
| **卡牌数量** | 60张机会卡 + 40张价值卡 | 60张机会卡 + 40张价值卡 |
| **四色分布** | 🟢40% 🟡30% 🔴20% 🟣10% | 🟢25% 🟡25% 🔴25% 🟣25% |
| **揭示方式** | 背面朝上（盲选） | 正面朝上（明牌） |
| **决策依据** | 身体直觉信号 | 资源池状态+概率评估 |
| **游戏目标** | 提升InQ Score | 最大化终局资源池 |
| **失败条件** | 无（都是训练） | 资源池归零（破产） |

## 二、详细对比

### 2.1 卡牌设计对比

| 要素 | 体系A | 体系B |
|:-----|:------|:------|
| **机会卡🟢** | 24张，免费获得收益 | 15张，需要投入成本 |
| **风险卡🟡** | 18张，确定损失 | 15张，可预防/减少损失 |
| **罚款卡🔴** | 12张，2倍损失 | 15张，可转移/对冲 |
| **延迟卡🟣** | 6张，第5轮结算 | 15张，期间效果+终局结算 |
| **特殊机制** | 身体信号对应 | 组合技+联动效果 |

### 2.2 游戏流程对比

| 步骤 | 体系A | 体系B |
|:-----|:------|:------|
| **准备** | 洗牌，背面朝上 | 洗牌，正面朝上 |
| **感知** | 说出直觉+身体觉察 | 评估资源+计算投入 |
| **选择** | 根据直觉盲选 | 根据策略明选 |
| **结算** | 即时结算 | 即时+延迟结算 |
| **复盘** | 身体信号准确率 | 资源配置效率 |

### 2.3 评分系统对比

| 维度 | 体系A | 体系B |
|:-----|:------|:------|
| **评分方式** | InQ Score（0-1000分） | 终局资源池金额 |
| **段位系统** | 青铜/白银/黄金/铂金/钻石 | 无（按终局金额排名） |
| **晋级机制** | 分数达标晋级 | 无 |
| **降级机制** | 连续失误降级 | 资源池归零淘汰 |
| **评估重点** | 直觉准确率+一致性 | 资源管理+策略执行 |

## 三、适用场景对比

### 3.1 选择体系A（直觉型）

**适合人群**：
- 面临选择时经常犹豫、想太多
- 希望培养对机会的敏感度
- 想学习解读身体信号
- 偏好个人内省式训练

**典型场景**：
- 合伙人选择时的"感觉判断"
- 投资机会的直觉评估
- 危机预警的感知训练
- 个人决策风格优化

**训练效果**：
- 提升决策速度
- 增强风险直觉
- 建立身体觉察习惯
- 减少分析瘫痪

### 3.2 选择体系B（策略型）

**适合人群**：
- 感觉自己决策过于冲动
- 希望学习资源管理
- 想理解风险对冲
- 偏好竞技对抗式训练

**典型场景**：
- 投资组合配置决策
- 现金流管理
- 风险分散策略
- 竞争博弈分析

**训练效果**：
- 提升资源配置能力
- 理解对冲和保险价值
- 培养组合思维
- 建立终局意识

## 四、双体系联动训练方案

### 方案1：对比训练

**流程**：
1. 同一组卡牌，先用体系A玩一次
2. 记录直觉选择
3. 再用体系B玩一次
4. 对比两种选择的结果
5. 分析差异原因

**目标**：理解直觉和策略各自的适用边界

### 方案2：混合模式

**流程**：
- 第1-2轮：体系A（盲选+直觉）
- 第3-5轮：体系B（明牌+策略）

**效果**：
- 早期建立直觉感知
- 后期运用策略优化
- 培养"直觉+理性"的综合决策能力

### 方案3：进阶路径

**阶段1（1-4周）**：体系A基础
- 熟悉身体信号
- 建立直觉信心
- 达到黄金段位

**阶段2（5-8周）**：体系B基础
- 学习资源配置
- 理解对冲机制
- 掌握组合技

**阶段3（9-12周）**：双体系融合
- 混合模式训练
- 根据场景切换
- 形成个人决策风格
