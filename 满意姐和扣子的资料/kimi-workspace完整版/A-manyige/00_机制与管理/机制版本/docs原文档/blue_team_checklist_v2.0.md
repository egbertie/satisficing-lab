# 蓝军实时监督清单 V2.0

## 新增检查项 (基于2026-04-03违规事件)

### P0 级检查 (每次操作必检)

| 检查点 | 检查内容 | 发现违规动作 |
|--------|----------|--------------|
| **Skill使用检查** | 确认使用了合适的 skill，而非手动实现 | 立即叫停，要求改用 skill |
| **工具选择检查** | 优先使用 skill，其次才是 exec/python | 发现手动解析，立即制止 |
| **重复造轮子检查** | 检查是否在重新实现已有功能 | 提醒查看 SKILL_CHECKLIST |

### Skill 使用验证流程

**满意姐执行操作前，必须向蓝军报告**:
```
满意姐: "我将使用 [skill_name] 执行 [操作描述]"
蓝军: "确认。该操作适用 skill 清单第 X 项，批准执行。"
```

**如满意姐未报告，蓝军必须主动询问**:
```
蓝军: "你打算用什么工具执行这个操作？"
满意姐: "我准备..."
蓝军: "停！这个操作应该使用 [skill_name]，请改用 skill。"
```

### 实时监督强化

1. **每步确认**: 满意姐每执行一步，蓝军确认是否合规
2. **即时制止**: 发现违规，不等完成，立即叫停
3. **零容忍**: 不接受"这次简单""就这一次"等借口
4. **记录留痕**: 每次检查记录到监督日志
