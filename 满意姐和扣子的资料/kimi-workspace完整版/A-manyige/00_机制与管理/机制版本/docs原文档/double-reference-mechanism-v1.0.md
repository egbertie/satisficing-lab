# 双重借鉴机制（Double Reference Mechanism）

## 核心原则（永久生效）

> **所有方法论、技巧、知识，不仅仅要面向客户和产品，也要面向满意解研究所项目和自身运营管理提升。这才是真正的闭环。**

**双重借鉴 = 对外（客户/产品）+ 对内（项目/运营）**

---

## 双重借鉴定义

### Layer 1：对外借鉴（External Reference）
**面向**：客户价值、产品设计、服务交付
**目标**：帮助客户解决合伙人决策难题
**示例**：
- 一堂五步法 → SKU-A/B/C/D产品映射
- AI做课 → SKU-D课程授权开发
- 外部专家反馈 → 风险预警响应

### Layer 2：对内借鉴（Internal Reference）
**面向**：项目运作、运营管理、组织成长
**目标**：提升满意解研究所自身能力
**示例**：
- 一堂增长飞轮 → 我们的增长飞轮设计
- 一堂单元模型 → 我们的首单ROI/里程碑验证
- 一堂壁垒六条 → 我们的护城河强化
- AI做课经验提取 → Egbertie22年经验体系化

### 双重闭环（True Closed Loop）
**只有同时完成 Layer 1 + Layer 2，才是真正的闭环**

| 资料/方法论 | Layer 1（对外） | Layer 2（对内） | 闭环状态 |
|:-----------|:--------------|:--------------|:--------:|
| 一堂五步法 | SKU产品映射 | 项目运作对标 | ✅ 双重闭环 |
| AI做课 | 课程开发 | 经验体系化 | ✅ 双重闭环 |
| 外部专家反馈 | 风险响应 | 方法论优化 | ✅ 双重闭环 |
| 12类型案例库 | 客户服务 | 教练培训 | ✅ 双重闭环 |
| 五路图腾 | 客户校准 | 团队文化 | ✅ 双重闭环 |

### 血液化（Blood Mapping）双重字段

**原字段**：
- 适用场景
- 可复用模块
- 与五路图腾关联
- 与案例库关联

**新增字段**：
- **对外借鉴（External）**：客户价值、产品映射、服务应用
- **对内借鉴（Internal）**：项目运作、运营管理、组织成长
- **双重闭环（Double Loop）**：Layer 1 + Layer 2 完成确认

## 双经济模型双重借鉴条款

### Token经济学（投入端）

**原则**：投入不仅看客户价值，也要看对项目自身成长的价值

| 评估维度 | 问题 |
|:---------|------|
| 对外价值 | 这个投入能帮助客户解决什么问题？ |
| **对内价值（新增）** | **这个投入能提升我们项目自身的什么能力？** |
| 综合评估 | 对外+对内价值 > Token投入？ |

### 效益经济学（产出端）

**原则**：产出不仅要创始人5分钟可用，也要项目团队5分钟可用

| 评估维度 | 问题 |
|:---------|------|
| 对外可用性 | 创始人客户5分钟内能用上吗？ |
| **对内可用性（新增）** | **我们项目团队5分钟内能用上吗？** |
| 综合评估 | 对外+对内可用性 > 投入成本？ |

### 双重效益公式

```
双重效益 = (对外客户价值 + 对内项目价值) / (Token投入 + 时间投入)

只有当双重效益 > 1 时，投入才是合理的
```

## 执行检查清单（Checklist）

### 每次知识入库前必须检查

- [ ] **对外借鉴（Layer 1）**：已识别客户/产品价值？
- [ ] **对内借鉴（Layer 2）**：已识别项目/运营价值？
- [ ] **双重闭环**：Layer 1 + Layer 2 都已完成？
- [ ] **KIA索引**：已更新双重借鉴字段？
- [ ] **血液化**：对外+对内可复用模块都已提取？

### 不满足双重借鉴的处理

| 情况 | 处理 |
|:-----|------|
| 只有Layer 1 | 标记"⏳ 单层闭环"，补充Layer 2后再标记完成 |
| 只有Layer 2 | 标记"⏳ 单层闭环"，补充Layer 1后再标记完成 |
| Layer 1+2都缺失 | 标记"🔄 待完成"，补充双重借鉴后再入库 |
