### 请求2: 司马贺Agent满意解算法设计 [高优先级]

**任务编号**: 任务7  
**关联**: 五图腾Agent核心

#### 需求描述
实现**司马贺**(Herbert Simon)Agent，基于"满意解理论"(Satisficing)进行决策分析。

#### 满意解核心概念
1. **约束边界**: 识别决策的硬性约束
2. **满意阈值**: 设定"足够好"的标准 (非最优)
3. **备选生成**: 生成可行方案
4. **Adequacy评估**: 评估是否满足阈值
5. **停止规则**: 找到第一个满足阈值的方案即停止

#### 输入示例
```json
{
  "scenario": "寻找硬科技项目合伙人",
  "constraints": ["有产业资源", "全职投入", "接受较低估值"],
  "founder_profile": "技术背景，首次创业，资金有限",
  "candidates": [
    {"name": "A", "experience": "10年销售", "network": "强", "equity_expectation": "高"},
    {"name": "B", "experience": "5年产品", "network": "中", "equity_expectation": "中"},
    {"name": "C", "experience": "8年投资", "network": "强", "equity_expectation": "低"}
  ]
}
```

#### 期望输出
```json
{
  "constraints_analysis": {
    "hard_constraints": ["全职投入"],
    "soft_constraints": ["产业资源", "接受低估值"]
  },
  "satisficing_threshold": {
    "min_requirement": "有产业资源 + 全职 + 可接受估值",
    "acceptable_deviation": "产业资源可以用其他补偿"
  },
  "candidates_evaluation": [
    {"name": "A", "adequacy": false, "reason": "不满足'接受低估值'"},
    {"name": "B", "adequacy": true, "reason": "满足所有约束"},
    {"name": "C", "adequacy": true, "reason": "满足所有约束，且有额外优势"}
  ],
  "recommendation": {
    "stop_at": "C",  // 第一个满足阈值的方案
    "rationale": "C是第一个满足所有约束的候选人，且优于B"
  }
}
```

#### 技术约束
- **规则引擎优先**，非机器学习
- 可解释性强 (每一步都有理由)
- 支持不同场景的约束动态调整
- Token预算: **~3000 tokens/分析**

#### 请外援提供
1. **满意解算法设计**: 如何将理论转化为可执行算法
2. **约束识别方法**: 如何从场景中提取约束
3. **阈值设定策略**: 如何设定"足够好"的标准
4. **停止规则实现**: 何时停止搜索

#### 交付物
- 算法设计文档 (含伪代码)
- Python实现框架
- 3个测试用例 (不同场景)
- 可解释性说明文档

| **慧能** | 顿悟、创新突破 | 火 | 突破性思维、压力转化 |
