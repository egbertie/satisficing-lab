## Step 3: 深度消化与结构化

### 三遍阅读法
- [ ] 第一遍速读框架 (5min)
- [ ] 第二遍精读提取 (15min)
- [ ] 第三遍结构化整理 (10min)

### 强制输出
- [ ] 核心洞察 ≥3条（一句话/条）
- [ ] 可执行资产 ≥3个（如适用）
- [ ] 实施检查清单 ≥3步
- [ ] 与现有系统关联已分析
- [ ] 知识图谱标签已标注

### 类型判定
- [ ] 程序类/知识类/混合类已判定
- [ ] 后续流程分流已明确
  - [ ] 程序类 → PMP
  - [ ] 知识类 → WEP
  - [ ] 混合类 → 拆分处理

---

## Step 4: 内化验证与审计

### 蓝军5题抽查
- [ ] 存在性: 5秒内说出完整路径
- [ ] 理解性: 一句话50字内说清核心目标
- [ ] 结构性: 数字准确（方案数/步骤数）
- [ ] 应用性: 指出至少1个可立即执行项
- [ ] 整合性: 说明与现有系统的结合方式

**评分**
- [ ] 5题全对 ✅ 通过
- [ ] 3-4题对 ⚠️ 补充后通过
- [ ] <3题对 ❌ 返工Step 3

### 可执行资产验证
- [ ] 随机抽取1个资产
- [ ] 可直接复制
- [ ] 复制后可用
- [ ] 用途描述准确
