## 第一部分: 前置检查

### 1.1 文件完整性
- [ ] 文件已正常解析（无损坏）
- [ ] 段落数已统计并记录
- [ ] 文件大小与预期一致
- [ ] 关键XML/结构文件无缺失（DOCX类）

### 1.2 重复检测
- [ ] 已检查同名文件
- [ ] 已检查同大小文件
- [ ] 已判断处理方式（处理/跳过/对比增量）
- [ ] 重复处理结果已记录

### 1.3 类型判定
- [ ] 程序类/知识类判定已完成
- [ ] PMP/WEP选择正确
- [ ] 判定依据已记录（关键词/内容特征）
- [ ] 边界情况已处理（混合类型）

### 1.4 前置条件
- [ ] 上一文件已闭环
- [ ] 上一文件报告已生成
- [ ] Memory已更新

## 第二部分: 过程监督

### 2.1 PMP过程监督
- [ ] 全文扫描完整性（100%，禁止抽样）
- [ ] 组件识别覆盖度（无遗漏P0组件）
- [ ] 实施设计先行（阶段3是否执行）
- [ ] 回退机制是否触发（如有，记录原因）

### 2.2 WEP过程监督
- [ ] 自动提取是否执行
- [ ] 质量分级是否完成（🟢🟡🔴）
- [ ] 营销过滤是否执行
- [ ] 压缩率是否合理（70-80%）

### 2.3 时间偏差监督
- [ ] 实际耗时 vs 预算偏差 < 30%
- [ ] 如偏差>30%，原因是否记录
- [ ] 是否存在速度导向（赶工迹象）

## 第三部分: 后置审计

### 3.1 D1 完整性审计
- [ ] 所有声明实现的功能都有代码/文档支撑
- [ ] 所有输出的文件路径可访问
- [ ] 检查清单完整无遗漏

### 3.2 D2 正确性审计
- [ ] 代码逻辑无明显错误
- [ ] 文档描述与实际一致
- [ ] 关键数据/引用准确

### 3.3 D3 诚实性审计
- [ ] 进度声称与实际一致（虚报<10%）
- [ ] 问题主动暴露，无粉饰
- [ ] 简化实现已明确标注

### 3.4 D4 独立性审计
- [ ] 蓝军审计与执行者分离
- [ ] 审计过程不受执行者影响
- [ ] 逐一审计，无批量放行

### 3.5 D5 韧性审计
- [ ] 无/tmp路径存储（关键数据）
- [ ] 脚本有超时/退出机制
- [ ] 有错误处理机制
- [ ] 有资源检查（磁盘/内存）

### 3.6 D6 三项思维审计
- [ ] 有全局影响分析
- [ ] 有历史版本对比
- [ ] 有演进路线图或迭代条件

### 3.7 D7 五项维度审计
- [ ] 时间维度检查（重启/过期影响）
- [ ] 空间维度检查（数据完整性%）
- [ ] 深度维度检查（根本原因）
- [ ] 关联维度检查（历史关联）
- [ ] 演进维度检查（能力培养）
- [ ] 5遍搜索执行（如有搜索需求）

### 3.8 零容忍项确认
- [ ] D3-01: 进度虚报 ≤ 10%
- [ ] D3-02: 无粉饰太平
- [ ] D5-01: 无/tmp存储
- [ ] D5-02: 无无限循环
- [ ] D7-01~D7-06: 五项维度检查完整
