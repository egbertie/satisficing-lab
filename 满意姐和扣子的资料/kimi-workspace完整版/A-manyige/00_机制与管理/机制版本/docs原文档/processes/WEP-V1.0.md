## 阶段详解

### 阶段0: 前置确认 (10分钟)

**目标**: 确认文件基本信息，判定内容类型

**检查清单**:
- [ ] 告知文件名、UUID、大小、类型
- [ ] 判定文件性质（确认适用WEP流程）
- [ ] 识别内容来源（培训/直播/文章/书籍）
- [ ] 确认上一文件已闭环

**输出物**:
```
文件信息卡片:
- 文件名: xxx.docx
- UUID: xxx
- 大小: xxx bytes
- 段落数: xxx
- 类型: 知识类
- 内容来源: 直播转录/培训内容/经验分享
- 主讲人/作者: xxx
```

**类型判定标准**:
- 直播转录 → WEP流程
- 培训内容 → WEP流程
- 经验分享 → WEP流程
- 技术方案 → 转PMP流程

---

### 阶段1: 自动提取 (10分钟) ⭐优化

**目标**: 自动化预处理，提取关键信息

**检查清单**:

**1.1 关键词自动提取**
- [ ] 高频词统计（出现>5次）
- [ ] 专业术语识别
- [ ] 关键词聚类

**1.2 框架自动识别**
- [ ] 章节结构提取
- [ ] 方法论框架识别（如"六脉神剑"）
- [ ] 步骤/流程识别

**1.2a 全量提取规则（强制，适用于所有文件）**
- [ ] **所有文件必须全量提取**，禁止因文件篇幅长、内容看起来相似、或存在目录/前言页而跳过任何实质性部分
- [ ] 禁止以"摘要替代全文"、"提取目录即视为完成"等任何方式变相缩减
- [ ] 多册/多卷/系列合集（如"套装12册"）是典型高发场景之一，**必须逐册分别提取**，每册视为独立内容单元
- [ ] 若内容跨章节/跨册不连续（类似多轮对话），更需全量处理，禁止因"上下文看起来相似"而跳过
- [ ] 输出格式：按文件结构生成对应摘要卡片，并在索引中标注层间关系（册-章-节）
- [ ] 执行者声明："我有长文件处理能力，无需担心篇幅，必须诚实全量执行"

**1.3 价值自动评估**
- [ ] 内容密度评估（段落/字数比）
- [ ] 可复用方法论识别
- [ ] 案例数量统计

**自动化脚本输出**:
```yaml
自动提取结果:
  keywords:
    - 词A: 270次
    - 词B: 143次
  frameworks:
    - 六脉神剑: 7次提及
  value_score: 6.5/10
  recommend: 深度处理 / 轻量归档
```

---

### 阶段2: 质量分级 (20分钟) ⭐优化

**目标**: 可信度评估+营销过滤，质量分级

**检查清单**:

**2.1 可信度评估**
- [ ] 作者背景验证（可验证性）
- [ ] 内容来源追溯（一手/二手）
- [ ] 交叉验证可能性

**可信度分级**:
| 等级 | 标准 | 处理策略 |
|------|------|----------|
| 🟢高 | 作者权威+内容可验证 | 快速归档(30分钟) |
| 🟡中 | 有经验但需甄别 | 完整流程(100分钟) |
| 🔴低 | 来源不明或营销重 | 简单归档/跳过(15分钟) |

**2.2 营销成分过滤**
- [ ] 识别促销话术（"限时疯抢"等）
- [ ] 识别夸大宣传（"百万收入"等）
- [ ] 识别幸存者偏差案例
- [ ] 剥离利益导向内容

**常见营销话术库**:
```
促销类: 疯抢、限时、一生一世、错过再等
夸大类: 百万收入、轻松致富、躺赚、必赚
焦虑类: 再不学就晚了、已经被淘汰、最后机会
```

**2.3 方法论骨架提取**
- [ ] 核心框架提取
- [ ] 可执行步骤识别
- [ ] 决策模式提炼
- [ ] 案例价值评估

**输出物**:
```
质量分级报告:
- 可信度评级: 🟢高 / 🟡中 / 🔴低
- 营销成分比例: xx%
- 硬核内容比例: xx%
- 建议处理策略: 快速归档/完整流程/简单归档
- 核心价值点: [xxx, xxx, xxx]
```

**分级后处理**:
- 🟢高置信 → 跳过阶段3，直接进入阶段5
- 🟡中置信 → 继续完整流程
- 🔴低置信 → 15分钟简单归档或跳过

---

### 阶段3: 保护性蒸馏 (30分钟) ⭐优化

**目标**: 内容压缩，但保护关键信息

**检查清单**:

**3.1 保护性蒸馏**
- [ ] 设定压缩目标: 80%（原90%）
- [ ] 关键信息保护清单核对
- [ ] 核心框架完整保留
- [ ] 决策模式完整保留
- [ ] 案例精简但保留关键细节

**关键信息保护清单**:
```
必须保留:
- 核心方法论框架
- 关键步骤和检查点
- 决策标准和边界条件
- 可验证的案例要素

可压缩:
- 过渡语句
- 重复内容
- 口语化表达
- 背景介绍
```

**3.2 结构化改造**
- [ ] 转化为层级结构
- [ ] 生成检查清单
- [ ] 提取决策模式
- [ ] 标注适用边界

**3.3 去除冗余**
- [ ] 口头禅过滤
- [ ] 重复内容去重
- [ ] 过渡语剔除

**输出物**:
```
蒸馏成果:
- 原始段落: xxx段
- 蒸馏后段落: xxx段
- 压缩率: 80%
- 保留核心框架: xxx
- 生成检查清单: xxx
- 关键信息丢失风险: 🟢低
```

---

### 阶段4: 情境适配 (20分钟)

**目标**: 映射到业务场景，标注适用边界

**检查清单**:

**4.1 业务场景映射**
- [ ] 原场景分析
- [ ] 目标场景定义（满意解研究所）
- [ ] 概念映射（知识IP→技术专家IP）
- [ ] 方法适配

**映射示例**:
```
原概念 → 适配概念
知识IP变现 → 技术专家IP变现
课程产品 → 技术咨询产品
内容信任 → 技术能力信任
个人品牌 → 专家品牌
```

**4.2 适用边界标注**
- [ ] 适用场景明确
- [ ] 不适用场景明确
- [ ] 前提条件列出
- [ ] 限制条件说明

**4.3 触发条件建立**
- [ ] 定义何时引用此知识
- [ ] 建立关键词触发映射
- [ ] 设置置信度标签（🟡中）

**输出物**:
```
情境适配文档:
- 原场景: xxx
- 适配场景: xxx
- 概念映射表: xxx
- 适用边界: 
  - 适用: xxx
  - 不适用: xxx
- 触发条件: xxx
```

---

### 阶段5: 索引固化 (10分钟)

**目标**: 纳入知识图谱，建立索引

**检查清单**:

**5.1 知识图谱定位**
- [ ] 方法论层定位
- [ ] 置信度标注（🟡中）
- [ ] 与核心系统建立关联

**5.2 索引建立**
- [ ] 关键词索引
- [ ] 场景触发映射
- [ ] 反向链接建立

**5.3 元数据标注**
```yaml
知识单元元数据:
  source: 文件19
  confidence: 🟡中
  type: 方法论
  applicable_scenarios: [xxx, xxx]
  last_reviewed: 2026-04-04
  review_cycle: 季度
```

**输出物**:
```
固化确认:
- 存储位置: knowledge_system/方法论层/xxx/
- 文件名: xxx.md
- 索引状态: ✅已建立
- 关联链接: [xxx, xxx]
```

### 阶段6: 追踪评估 (异步) ⭐新增

**目标**: 持续追踪知识使用效果

**检查清单**:

**6.1 使用频率追踪**
- [ ] 记录引用次数
- [ ] 记录使用场景
- [ ] 计算使用频率

**6.2 效果反馈收集**
- [ ] 收集用户反馈
- [ ] 记录效果评价
- [ ] 识别改进点

**6.3 季度重评估**
- [ ] 每季度回顾知识状态
- [ ] 评估是否仍适用
- [ ] 更新置信度
- [ ] 标记过时内容

**追踪指标**:
```
追踪报告(季度):
- 使用次数: xx次
- 使用场景: [xxx, xxx]
- 用户反馈: 4.2/5
- 建议: 保持/更新/归档
```

## 关键特性

### 1. 自动化预处理
- 阶段1使用脚本自动提取
- 减少人工重复劳动
- 提高处理效率

### 2. 保护性蒸馏
- 压缩率从90%调整为80%
- 关键信息保护清单
- 降低知识丢失风险

### 3. 分级处理
- 🟢高置信: 快速归档(30分钟)
- 🟡中置信: 完整流程(100分钟)
- 🔴低置信: 简单处理(15分钟)
- 资源优化配置

### 4. 追踪评估
- 阶段6异步执行
- 使用数据追踪
- 季度重评估机制
