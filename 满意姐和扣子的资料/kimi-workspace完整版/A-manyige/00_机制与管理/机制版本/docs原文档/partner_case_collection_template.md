# 硬科技合伙人匹配案例数据收集模板

> 用途：为 `hardtech_partner_risk_scanner.py`、`partner_mcda_selector.py`、`confucian_ethics_assessor.py` 等 20+ 评估器注入真实数据，使其从"规则引擎"升级为"有数据可用"的决策工具。
> 填写方式：每条案例复制一个「案例区块」，尽量完整填写；无法提供的字段标注"不详"即可。
> 匿名化要求：隐去真实姓名、企业全称、具体金额（可保留量级，如"百万级"/"千万级"）。

## 案例一

### 基础信息
- **案例编号**: P001（由收集者自行编号）
- **收集日期**: YYYY-MM-DD
- **行业领域**: 如半导体 / 机器人 / 新能源 / 生物医药 / 航空航天 / 其他
- **企业阶段**: 种子期 / 天使轮 / Pre-A / A轮 / B轮及以后
- **融资规模**: 如"天使轮，千万级人民币"
- **团队规模**: 如"5-10人" / "10-30人" / "30-50人" / "50人以上"
- **地域**: 如"深圳" / "东莞" / "上海" / "北京" / 其他

### 合伙人画像
#### 合伙人 A（通常为非技术背景，如CEO/运营/市场）
- **角色定位**: 如 CEO / COO / 市场负责人 / 融资负责人
- **专业背景**: 如金融 / 连续创业者 / 大厂管理 / 销售 / 政府关系
- **出资/资源情况**: 出资比例、带来的客户/渠道/政府资源
- **决策风格**: 激进 / 稳健 / 犹豫 / 数据驱动 / 关系驱动
- **风险信号（如有）**: 如过度乐观、回避细节、履历存疑、家庭负担重等

#### 合伙人 B（通常为技术背景，如CTO/首席科学家）
- **角色定位**: 如 CTO / 首席科学家 / 技术合伙人
- **专业背景**: 如高校教授 / 海归博士 / 大厂技术专家 / 科研院所
- **知识产权**: 专利数量、核心技术是否已转让到公司
- **出资/资源情况**: 技术入股比例、是否全职投入
- **决策风格**: 技术完美主义 / 商业敏感度低 / 沟通直接 / 回避冲突
- **风险信号（如有）**: 不愿全职、知识产权归属不清、过度技术导向忽视市场

### 匹配动因
- **双方为何走到一起**: 校友 / 前同事 / 投资人介绍 / 行业会议 / 家族关系
- **核心互补点**: 技术+市场 / 产品+渠道 / 本土+海外 / 资金+资源
- **当时最看重对方的什么**: 如"技术壁垒" / "政府关系" / "融资能力" / "人品可靠"

### 决策过程
- **是否做过正式评估**: 是 / 否
- **评估维度（如有）**: 如人品 / 能力互补 / 股权分配 / 退出机制 / 家庭支持 / 价值观
- **是否签署股东协议/合伙协议**: 是 / 否 / 仅有口头约定
- **股权分配结构**: 如"5:3:2" / "创始人 51%，技术合伙人 34%"
- **退出机制设计**: 如股权回购 / 竞业限制 / 离职条款 / 完全没谈

### 结果与现状
- **最终结果**: 成功协作至今 / 分道扬镳 / 一方退出 / 企业倒闭 / 仍在磨合
- **如果失败，核心原因**: 如股权纠纷 / 价值观冲突 / 技术路线分歧 / 一方不作为 / 融资后内斗 / 家庭因素
- **如果成功，核心因素**: 如定期沟通机制 / 清晰分工 / 股权动态调整 / 第三方调解 / 共同信仰

### 教训与洞察
- **最大的一个教训**:（一句话）
- **重来一次会怎么做 differently**:（一句话）
- **是否符合"满意解"而非"最优解"**: 是 / 否 / 难以判断

### 数据可用性
- **可匿名化程度**: 高（可完全脱敏） / 中（需保留部分背景） / 低（涉及敏感信息）
- **信息完整度自评**: 1-10分
- **是否愿意后续补充细节**: 是 / 否
