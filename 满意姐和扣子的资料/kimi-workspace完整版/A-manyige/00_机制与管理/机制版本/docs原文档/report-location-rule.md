# 研究报告存放规则

> **生效日期**: 2026-04-10
> **来源**: 用户指令 — "研究成果如果是给我看的，应该放在哪个文件夹？请调整一下，并记住这个规则。"

---

## 核心规则

**所有需要给用户阅读、供用户决策参考的研究报告，统一存放于：**

```
A-manyige/汇报/专项报告/
```

---

## 目录结构说明

```
A-manyige/
├── 汇报/
│   ├── 日报/              # 每日工作摘要
│   ├── 周报/              # 每周复盘与计划
│   ├── 月报/              # 月度总结
│   └── 专项报告/          # ⭐ 给用户看的核心研究报告
├── 蓝军审计/              # 对抗性验证报告
├── 讨论/                  # 待讨论事项
├── 归档/                  # 历史资料
└── ...
```

---

## 操作流程

1. **生成研究报告时**：
   - 先在 `research/` 或 `docs/` 编写草稿/过程版本
   - 定稿后，**必须复制一份到 `A-manyige/汇报/专项报告/`**
   - 文件名建议：`报告主题_YYYYMMDD.md`

2. **不用给用户看的内部文档**：
   - 技术迭代条件记录 → `docs/condition_records/`
   - 过程草稿 → `research/`
   - 代码注释/配置 → 原项目目录
