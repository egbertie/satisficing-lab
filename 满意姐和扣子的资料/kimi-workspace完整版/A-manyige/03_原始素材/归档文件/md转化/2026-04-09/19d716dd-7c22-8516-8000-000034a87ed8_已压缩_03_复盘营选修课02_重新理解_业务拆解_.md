关键假设发挥作用的机会，以及具体如何理解假设应用的 场景 呢？​

第一个案例：一堂复盘营
我们应该99%的同学，都上过复盘营吧？这是259+10选3+毕业直播转化的营。​
大家当初上这个营的感受如何？hh​
先跟大家分享一下复盘营的背景，在2019年底，我们决定走"低转高"的模型，需要一个建立信任的体
验营，来完成新用户的落地Landing、信任构建和销售转化。​
"低转高"在市场上，是一个非常成熟的商业模式了，尤其是各种成人教育公司，" 投放-低转高-正价课 
"是一个非常经典的商业模式。​
【提问🙋♂️】 我不知道大家能不能猜得到，这个模型在真实实践层面，最大的挑战在哪里？​
———
​
投放低转高，核心追求的指标是 ROI = 首单ARPU/综合CAC。​
一堂的核心单元模型是：单用户14天模型。​
这个模型有两个非常大的挑战：
1. ROI跑通赚钱，不容易：很多公司的ROI都是亏损的。​
2. 持续跑通，规模化，不容易：做着做着，就亏损了。
你们应该能回忆起，市场上这5年出现过各种公司：​
•
有些一直疯狂投放一直亏损，最后现金流撑不住，被迫关停；
•
有一些疯狂投放，吃红利，一旦融资不顺，关门跑路；
•
还有大堆公司，卡在一个很小的规模线上，无法精进，还在随着时间，不断缓慢下滑中。
而我们因为"建学科"的愿景，选了一条更难的路： 不刻意追红利，用长期稳定渠道，提供长期稳定的
服务。
而我们从2019年底开始，复盘营这个模型开始启动测试，一口气做了200多期，从最早的每2周100个
人，再到每周 100人，200人，500人，1000人 ，到今年每周有 3000-4000人 ，而且ROI一直为正，
在健康可控的水平。
甚至在一些关键的环节，迭代出了超出同行 2-10倍 的转化率，比如作业率，老带新推荐率等等，正常
业务，随着规模其实ROI会非常不稳定、缓慢显著下滑，我们竟然这5年，一直守住了，而且规模还在
持续增长。

也就是说：用户首单ARPU 值= ￥199 + ￥4000*15% = ￥800​
如果以经验值CAC 200-500来对标，这个模型我们初步判断：能跑通了。​
但是业务遇到了第一个卡点： 招生困难 。​
做过训练营产品的同学都知道，这个模式最大的挑战，就是持续招生，早期靠过往用户和私域，冷启
动很容易，但是正式跑起来，到3-5期，就会遭遇重大挑战： 招生很难持续，难以为继。​
第一期：轻松100人；第二期：努力100人；第三期：努力70人；第四期：努力50人；​
对于复盘营来说，低于50人，班级氛围/运营质量就会显著下滑了。​
所以，我们做了第一阶段的优化： 自建流量池计划。​
于是我们开始尝试建了一个招生公式：百川入海，把各种潜在用户的地方，全部都盘了一遍，建了一
个大公式， 一边 建，一边测，提出了大概30+实验假设，铺了一遍：​

招生数量 = 直接购买 + 服务号新粉丝 x 购买率​
•
直接购买 = 过往学习群 + 文章末 + 朋友圈​
•
服务号粉丝 = 知乎引流 + 官网引流 + 材料引流​
•
购买率 = 关注转化率 + 3min转化率 + 24h转化率 + 47h转化率
结果是，我们终于把流量一点点汇集到一堂了： 每两周可以稳定招募50-100个人。​
忙活一个月，我们终于可以收收心，专心做实验了，每周有源源不断的流量进来。

怎么办呢？我们开始加速迭代，复盘营2周改为1周，开始建立了复盘营第一个粗糙的运营模型：​

每一期获客 = 渠道铺设数量 x 落地页UV x 落地页购买率（糙）​

第9招：判断空间​

有的假设预期能提升5%，有的能预期提升30%，空间非常不一样，我们可以优先选择空间比较大的关

【划重点💡】 怎么思考一个假设的 提升空间 呢？一般来说有三个维度：​
1. 看差距 ，距离100%的剩余空间（5%，20%，50%，100%）​
2. 看对标 ，历史和同行的Benchmark差距（落后，有差距，接近，领先）​
3. 看成熟 ，是否经过了持续优化（原始未优化，做过优化，充分测试过）​
综合考虑这三个维度， 如果距离同行有差距，未优化且转化率很低，就是最理想的假设机会。​
罗列一些同学们和一堂的例子：
1. 面向大B的SaaS续费率 ：Benchmark是 85% ，如果低于这个数值，需要努力提高。​
2. 饭店服务的超预期满意度 ：如果是80%，距离100% 还有20%的空间 。​
3. 一堂做「我请客」 ： 第一版K就达到0.2以上 ，后续达到0.4，0.5，持续优化。​
4. 漫展卖动漫周边的人均件数 ：第一场就做到人均2.5个，后续不断优化到3件，5件。​
