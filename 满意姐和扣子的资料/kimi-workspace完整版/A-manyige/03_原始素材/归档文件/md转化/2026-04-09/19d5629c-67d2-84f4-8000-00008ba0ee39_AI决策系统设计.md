### 给决策科学专家

Q: 如何将隐性决策经验(tacit knowledge)外化为AI可学习的形式？

建议采用分层外化策略： 1. 行动层：记录”做什么”（决策记录） 2. 规则层：提取”何时做”（条件-行动规则） 3. 启发式层：提取”为什么”（启发式原则，如”技术强但价值观偏差是red flag”） 4. 元认知层：提取”如何判断”（决策框架选择逻辑）

使用Repertory Grid + Think-aloud Protocol组合技术，通过系统性地对比历史案例，逐步外化个人建构。

Q: 如何量化”决策质量”，而不仅仅是”决策结果”？

建议构建多维决策质量评估框架： - 过程质量：信息覆盖度、视角多样性、逻辑一致性 - 风格一致性：与Egbertie历史决策模式的匹配度 - 鲁棒性：在反事实情境下的稳定性 - 可解释性：决策理由的清晰度与可追溯性

### 给AI系统设计专家

Q: 如何设计”统一对话界面”，背后是多Agent协同？

关键设计原则：透明化多Agent存在，而非隐藏

界面应显式呈现： - “司马贺视角认为…但观自在视角提醒…” - 让用户看到”内心的多方辩论”，增强可解释性

技术实现：渐进式披露 (Progressive Disclosure) - 简要回答：综合结论 - 展开详情：各图腾分析 - 深度探索：冲突点与权衡

Q: 如何平衡AI的”引导”与用户的”自主性”？

引入决策主权层级： - Level 1 (信息提供)：系统仅提供事实与分析 - Level 2 (建议给出)：系统给出倾向性判断，明确标注不确定性 - Level 3 (模拟推演)：系统模拟”如果是我(Egbertie)会怎么做”，但用户保留最终决策权 - Level 4 (代理决策)：仅在Egbertie明确授权的领域执行（如初步筛选）

### 给认知科学专家

Q: 如何在AI系统中实现”框架转换”（在不同认知框架间切换）？

实现框架切换触发器 (Frame Switching Triggers)： - 情境触发：识别关键词（如”合伙人”触发孔子框架，“风险”触发司马贺框架） - 冲突触发：当理性分析与直觉冲突时，自动引入”观自在”进行冥想式审视 - 元认知触发：当系统检测到”分析瘫痪”时，切换至慧能框架进行顿悟式突破

Q: 如何让AI掌握”直觉”这种非语言化的认知能力？

方案：模式识别 + 身体标记模拟 - 训练”直觉识别器”：从历史数据中学习”不对劲”信号的模式（如语言中的回避、矛盾的时间线等） - 引入躯体标记假说 (Somatic Marker Hypothesis)：模拟” gut feeling”作为决策权重因子 - 显式表达：“我（系统）检测到某种模式，类似于你过去感到不安的案例，建议关注X”

### 给知识管理专家

Q: 如何设计知识创造的SECI闭环？

技术实现方案： - S (社会化)：语音/文字对话系统，捕捉非结构化反思 - E (外化)：AI辅助结构化（自动提取关键决策点、情感标记、价值观冲突） - C (组合)：知识图谱构建，连接案例-理论-框架 - I (内化)：个性化推荐系统，将萃取的知识推送到Egbertie的新决策场景，完成内化循环

### 给系统架构专家

Q: 如何确保系统不会”过度拟合”过去的经验？

防过度拟合机制： 1. 正则化项：在风格学习中加入”创新偏差”奖励，鼓励探索性决策 2. 情境漂移检测：监控决策环境的变化（如行业周期、技术变革），当检测到重大变化时，降低历史案例权重 3. 反事实模拟：定期运行”如果当时选择B会怎样”的模拟，验证经验有效性 4. 人类在环：重大决策保留Egbertie的最终审核权

### 问题1: 如何自动识别客户类型？（首次对话的哪些问题能分类？）

#### 明确方案

决策树 + 快速分类器：在首次对话的前3-5轮内，通过决策风格探测问题和场景线索自动分类，而非直接询问”你是哪类客户”。

必须在5轮对话内完成分类，否则影响后续服务体验

            keyword_hits = sum(1 for kw in indicators['keywords'] if kw in all_text)
            scores[client_type] += keyword_hits * 2.0
            
            # 问题模式匹配
            question_hits = sum(1 for pattern in indicators['question_patterns'] 
                              if pattern in all_text)
            scores[client_type] += question_hits * 1.5
            
            # 关注焦点分析（简单关键词匹配，实际可用主题模型）
            concern_hits = sum(1 for concern in indicators['concern_focus'] 
                              if concern in all_text)
            scores[client_type] += concern_hits * 1.0
            
            evidence[client_type] = {
                'keywords': [kw for kw in indicators['keywords'] if kw in all_text],
                'questions': [q for q in indicators['question_patterns'] if q in all_text]
            }
        
        # 归一化并选择最高分的类型
        total = sum(scores.values())
        if total == 0:
            return 'unknown', 0.0, {}
        
        max_type = max(scores, key=scores.get)
        confidence = scores[max_type] / total
        
        return max_type, confidence, evidence[max_type]

class ServiceRouter:
    def __init__(self):

    async def route(self, client_type: str, client_persona: ClientPersona) -> ServiceFlow:
        flow = self.flows.get(client_type)

        if client_persona.risk_appetite < 0.3:
            # 风险偏好低，增加司马贺（理性）权重
            flow.totems_priority.insert(0, '司马贺')
        
        if client_persona.information_need > 0.8:
            # 信息需求高，增加教育内容
            flow.analysis_depth = 'deep'
            
        return flow
    
    async def execute_flow(self, flow: ServiceFlow, context: DialogueContext):
        # 执行信息收集
        collector = InfoCollector(flow.info_collection)
        candidate_data = await collector.collect(context)
        
        # 执行分析（调用五图腾引擎）
        analyzer = TotemEngine(
            depth=flow.analysis_depth,
            priority=flow.totems_priority,
            persona=context.client_persona
        )
        analysis_result = await analyzer.analyze(candidate_data)
        
        # 生成输出
        formatter = OutputFormatter(flow.output_format)
        output = await formatter.format(analysis_result, context.client_persona)
        
        # 安排跟进
        scheduler = FollowUpScheduler(flow.follow_up)
        await scheduler.schedule(context.client_id, analysis_result.id)
        
        return output

@dataclass
class DecisionMaturityMetrics:
    # 维度1：认知复杂度
    cognitive_complexity: float  # 0-1，从单一维度到多维度思考
    
    # 维度2：元认知能力
    metacognition: float  # 0-1，对自己决策过程的反思能力
    
    # 维度3：风险驾驭
    risk_mastery: float  # 0-1，从风险厌恶到风险驾驭
    
    # 维度4：决策速度
    decision_velocity: float  # 0-1，在保证质量前提下的决策速度
    
    # 维度5：知识迁移
    knowledge_transfer: float  # 0-1，能否将经验应用到新情境

class MaturityAssessor:
    def assess(self, client_persona: ClientPersona) -> DecisionMaturityMetrics:
        history = client_persona.decision_history
        
        # 计算认知复杂度：问题从"对不对"到"如何平衡X和Y"
        complexity_scores = []
        for decision in history[-10:]:  # 最近10次决策
            question = decision.original_question
            # 简单启发：问题长度、关键词多样性、条件从句数量
            score = min(1.0, len(question) / 100 + question.count('如何') * 0.1)
            complexity_scores.append(score)
        
        # 计算元认知：是否经常问"为什么你这么建议"而非仅问"我该怎么做"
        metacognition_signals = sum(1 for f in client_persona.feedback_patterns[-20:] 
                                   if 'why' in f.content or 'reasoning' in f.content)
        metacognition = min(1.0, metacognition_signals / 10)
        
        # 计算风险驾驭：决策中风险词汇从"害怕"到"管理"
        early_risk_language = self.analyze_risk_language(history[:5])
        recent_risk_language = self.analyze_risk_language(history[-5:])
        risk_mastery = 1.0 if recent_risk_language > early_risk_language else 0.5
        
        return DecisionMaturityMetrics(
            cognitive_complexity=sum(complexity_scores) / len(complexity_scores),
            metacognition=metacognition,
            risk_mastery=risk_mastery,
            decision_velocity=self.calculate_velocity(history),
            knowledge_transfer=self.assess_transfer(client_persona)
        )
    
    def detect_stage_transition(self, metrics: DecisionMaturityMetrics, 
                               current_stage: str) -> Optional[str]:
        # 首次创业者 -> 连续创业者：认知复杂度>0.7 + 元认知>0.6 + 至少3次决策
        if current_stage == 'first_time':
            if (metrics.cognitive_complexity > 0.7 and 
                metrics.metacognition > 0.6 and
                metrics.risk_mastery > 0.5):
                return 'first_to_serial'
        
        # 连续创业者 -> 导师/投资者：知识迁移能力高 + 开始问批量问题
        if current_stage == 'serial_entrepreneur':
            if (metrics.knowledge_transfer > 0.8 and
                '批量' in self.recent_queries):
                return 'serial_to_investor'
        
        return None

价值阶梯 + 信任积累 + 自然过渡：通过服务交付中的自然延伸点触发跃迁，而非推销。设计”无法回头的价值体验”让客户自发想要更多。

#### 理由说明

强迫升级会引起反感，必须让客户感到”这是我需要的”而非”被推销”

每次服务都埋设”下一层价值的预览”（如单次服务中展示长期跟踪的价值）

信任是跃迁的前提，需要三次成功交付后才触发跃迁提议

class NeedHierarchyDetector:
    def detect_current_level(self, client_persona: ClientPersona) -> int:
        signals = {
            1: ['背景', '信息', '调查', '资料', '简历'],  # 信息获取
            2: ['分析', '评估', '建议', '判断', '选择'],  # 单次服务
            3: ['跟踪', '持续', '后续', '变化', '更新'],  # 长期伙伴
            4: ['团队', '教', '学', '传承', '分享', '培训'],  # 知识传承
            5: ['提升', '成长', '系统', '方法论', '成为']  # 自我实现
        }
        
        # 分析最近对话
        recent_queries = " ".join([q.content for q in client_persona.recent_queries[-20:]])
        
        level_scores = {}
        for level, keywords in signals.items():
            score = sum(1 for kw in keywords if kw in recent_queries)
            level_scores[level] = score
        
        # 加权历史行为：如果之前用过Tier 3服务，当前层至少为3
        if client_persona.highest_service_tier_used >= 3:
            return max(client_persona.highest_service_tier_used, 
                      max(level_scores, key=level_scores.get))
        
        return max(level_scores, key=level_scores.get)

class TrustBasedTransition:
    def __init__(self):
        self.required_successful_deliveries = 3  # 三次成功交付
        self.trust_threshold = 0.8
        
    async def evaluate_transition_timing(self, client_id: str):

        history = client.service_history
        
        # 计算成功交付
        successful = [h for h in history 
                     if h.outcome == 'positive' and h.satisfaction >= 4.5]
        
        if len(successful) < self.required_successful_deliveries:
            return {'allow_transition': False, 'reason': 'insufficient_trust'}
        
        # 计算信任度（综合满意度、采纳率、主动互动频率）
        trust_score = self.calculate_trust_score(client)
        
        if trust_score < self.trust_threshold:
            return {'allow_transition': False, 'reason': 'trust_not_mature'}
        
        # 检查最近一次服务是否有跃迁钩子被响应
        last_service = history[-1]
        if last_service.hook_clicked:
            return {'allow_transition': True, 'trigger': 'user_interest'}
        
        # 如果已达标但未点击钩子，软性提示

### 问题5: 如何确保生成客户符合真实分布？（避免过度简化或偏见）

#### 明确方案

数据驱动的分布约束 + 对抗性验证：使用真实客户数据的统计特征作为生成约束（非简单复制），并通过对抗性判别器验证生成分布的保真度。

#### 理由说明

纯随机生成会产生”平均客户”，缺乏真实世界的长尾特征（如极端风险偏好者）

必须防止归纳偏见（如默认所有技术创业者都是理性的），需从真实数据学习联合分布

需要可量化的保真度指标，而非主观”看起来真实”

#### 具体实现

A. 真实分布提取器（从现有数据学习）

@dataclass
class RealDistributionProfile:
    """真实客户分布的统计画像"""
    # 单变量分布
    marginal_dists: Dict[str, Distribution]  # 行业、阶段、规模等
    
    # 联合分布（关键：避免独立假设）
    joint_correlations: pd.DataFrame  # 变量间相关系数矩阵
    
    # 条件分布（关键场景）
    conditional_dists: Dict[str, Dict]  # 如"给定AI行业，风险偏好分布"
    
    # 长尾模式（罕见但重要）
    tail_patterns: List[Dict]  # 极端案例的统计特征

class DistributionExtractor:
    def extract_from_real_clients(self, real_client_data: List[ClientPersona]) -> RealDistributionProfile:
        df = self.to_dataframe(real_client_data)
        
        # 1. 提取边缘分布（带核密度估计）
        marginals = {}
        for col in ['risk_appetite', 'information_need', 'decision_velocity']:
            marginals[col] = KDE1D(df[col].values)  # 核密度估计，非简单正态分布
        
        # 2. 提取联合分布（ copula 方法保留相关性）
        # 例如：技术背景强的客户往往信息需求度高
        joint_corr = df[['tech_background', 'information_need', 'risk_appetite']].corr()
        
        # 3. 提取条件分布（决策树分箱）
        conditional = {}
        for industry in df['industry'].unique():
            subset = df[df['industry'] == industry]
            conditional[industry] = {
                'risk_dist': KDE1D(subset['risk_appetite'].values),
                'typical_concerns': subset['concerns'].mode().tolist()
            }
        
        # 4. 提取长尾（Isolation Forest检测异常值模式）
        from sklearn.ensemble import IsolationForest
        clf = IsolationForest(contamination=0.1)
        outliers = clf.fit_predict(df[['risk_appetite', 'information_need']])
        tail_patterns = df[outliers == -1].to_dict('records')
        
        return RealDistributionProfile(marginals, joint_corr, conditional, tail_patterns)

B. 约束满足生成器（确保统计保真）

class ConstrainedSyntheticGenerator:
    """在统计约束下生成客户"""
    
    def __init__(self, dist_profile: RealDistributionProfile):
        self.profile = dist_profile
        self.validator = DistributionValidator(dist_profile)
        
    def generate(self, n_samples: int, validation_strictness: float = 0.95) -> List[ClientPersona]:
        accepted = []
        rejected = []
        
        while len(accepted) < n_samples:
            # 1. 从联合分布采样（使用copula保持相关性）
            sample = self.sample_from_copula()
            
            # 2. 应用领域约束（业务逻辑）
            if not self.satisfy_domain_constraints(sample):
                rejected.append(sample)
                continue
            
            # 3. 验证与真实分布的距离（Wasserstein距离）
            if self.validator.wasserstein_distance(sample) < validation_strictness:
                accepted.append(self.to_persona(sample))
            else:
                rejected.append(sample)
            
            # 4. 如果拒绝率过高，调整生成参数（自适应）
            if len(rejected) > len(accepted) * 3:
                self.adjust_generation_parameters()
        
        return accepted
    
    def sample_from_copula(self) -> Dict:
        # 使用高斯copula保持变量间相关性
        # 将均匀分布映射到真实边缘分布
        normal_samples = np.random.multivariate_normal(
            mean=[0]*len(self.profile.marginal_dists),
            cov=self.profile.joint_correlations.values,
            size=1
        )[0]
        
        # 转换为均匀分布（通过CDF）
        uniform_samples = norm.cdf(normal_samples)
        
        # 映射到真实边缘分布
        sample = {}
        for i, (key, dist) in enumerate(self.profile.marginal_dists.items()):
            sample[key] = dist.ppf(uniform_samples[i])  # 分位数函数
        
        return sample
    
    def satisfy_domain_constraints(self, sample: Dict) -> bool:
        # 业务逻辑约束：例如早期创业者不可能有极高决策速度
        if sample['stage'] == 'seed' and sample['decision_velocity'] > 0.8:
            return False
        # 连续创业者不可能完全风险厌恶
        if sample['client_type'] == 'serial_entrepreneur' and sample['risk_appetite'] < 0.2:
            return False
        return True

C. 对抗性验证（GAN风格判别器）

class AdversarialValidator:
    """训练判别器区分真实客户和生成客户"""
    
    def __init__(self):
        self.discriminator = self.build_discriminator()
        
    def build_discriminator(self):
        # 简单的MLP分类器
        model = tf.keras.Sequential([
            tf.keras.layers.Dense(64, activation='relu'),
            tf.keras.layers.Dropout(0.3),
            tf.keras.layers.Dense(32, activation='relu'),
            tf.keras.layers.Dense(1, activation='sigmoid')
        ])
        model.compile(optimizer='adam', loss='binary_crossentropy')
        return model
    
    def train(self, real_clients: List[ClientPersona], synthetic_clients: List[ClientPersona]):
        # 准备训练数据
        X_real = self.vectorize(real_clients)
        X_synthetic = self.vectorize(synthetic_clients)
        
        X = np.vstack([X_real, X_synthetic])
        y = np.array([1]*len(X_real) + [0]*len(X_synthetic))
        
        # 训练判别器
        self.discriminator.fit(X, y, epochs=50, verbose=0)
        
    def validate(self, new_synthetic: ClientPersona) -> float:
        """返回被识别为真实的概率（越接近1越真实）"""
        X = self.vectorize([new_synthetic])
        return self.discriminator.predict(X)[0][0]
    
    def iterative_refinement(self, target_acceptance_rate: float = 0.7) -> List[ClientPersona]:
        """迭代优化直到生成样本骗过判别器"""
        batch_size = 100
        accepted = []
        
        while len(accepted) < batch_size:
            candidates = self.generate_raw(batch_size * 2)
            scores = [self.validate(c) for c in candidates]
            
            # 保留能骗过判别器的样本
            batch_accepted = [c for c, s in zip(candidates, scores) if s > 0.5]
            accepted.extend(batch_accepted)
            
            # 如果接受率太低，调整生成器参数（简化示意）
            if len(batch_accepted) / len(candidates) < target_acceptance_rate:
                self.adjust_generator()
                
        return accepted[:batch_size]

class DistributionMonitor:
    """监控生成分布是否漂移"""
    
    def __init__(self, baseline_profile: RealDistributionProfile):
        self.baseline = baseline_profile
        self.ks_test_threshold = 0.05  # Kolmogorov-Smirnov检验阈值
        
    def check_drift(self, recent_synthetic: List[ClientPersona]) -> DriftReport:
        report = DriftReport()
        
        for key, baseline_dist in self.baseline.marginal_dists.items():
            current_values = [getattr(c, key) for c in recent_synthetic]
            current_dist = KDE1D(current_values)
            
            # KS检验
            ks_statistic, p_value = ks_2samp(baseline_dist.samples, current_values)
            
            if p_value < self.ks_test_threshold:
                report.add_alert(
                    metric=key,
                    severity='high' if p_value < 0.01 else 'medium',
                    message=f"生成分布与真实分布发生漂移 (p={p_value:.4f})",
                    suggested_action="重新提取真实分布或调整生成器"
                )
        
        return report

### 问题6: 如何设计”边界案例”生成？（极端但有价值的训练场景）

#### 明确方案

对抗性场景生成（Adversarial Scenario Generation）：主动寻找能让系统失败或矛盾的极端情境，通过压力测试提升鲁棒性。

#### 理由说明

平均案例训练不出优秀系统，边界案例才是能力边界拓展的关键

需要区分“高价值边界”（罕见但可能发生）和“无意义极端”（不可能发生）

边界案例应针对系统的当前弱点动态生成（如系统刚在”价值观冲突”上犯错，就生成更多此类案例）

#### 具体实现

A. 边界类型定义与生成策略

@dataclass
class BoundaryScenario:
    category: str  # 边界类型
    extremity_score: float  # 极端程度 0-1
    business_validity: float  # 业务合理性 0-1（过滤无意义极端）
    training_value: float  # 训练价值（基于系统当前弱点）
    scenario: DecisionScenario

class BoundaryCaseGenerator:
    def __init__(self, weakness_analyzer: WeaknessAnalyzer):
        self.weakness_analyzer = weakness_analyzer
        self.validity_checker = BusinessValidityChecker()
        
    def generate_boundary_cases(self, n_cases: int) -> List[BoundaryScenario]:
        # 1. 分析系统当前弱点
        weaknesses = self.weakness_analyzer.identify_weaknesses()
        
        cases = []
        for weakness in weaknesses:
            # 针对每个弱点生成边界案例
            category_cases = self.generate_for_weakness(weakness, n_cases // len(weaknesses))
            cases.extend(category_cases)
        
        # 2. 过滤无意义极端，按训练价值排序
        valid_cases = [c for c in cases if c.business_validity > 0.6]
        return sorted(valid_cases, key=lambda x: x.training_value, reverse=True)
    
    def generate_for_weakness(self, weakness: WeaknessPattern, n: int) -> List[BoundaryScenario]:
        generators = {
            'value_conflict_high': self._gen_extreme_value_conflict,
            'time_pressure_extreme': self._gen_time_pressure,
            'info_asymmetry_max': self._gen_info_asymmetry,
            'multi_stakeholder_conflict': self._gen_stakeholder_conflict,
            'ethical_dilemma': self._gen_ethical_dilemma,
            'intuition_rational_conflict': self._gen_cognitive_dissonance
        }
        
        generator = generators.get(weakness.category, self._gen_generic_extreme)
        return [generator(weakness.severity) for _ in range(n)]

class WeaknessAnalyzer:
    """分析系统在哪些类型的决策上表现不佳"""
    
    def __init__(self, decision_history: List[SimulatedDecisionRecord]):
        self.history = decision_history
        
    def identify_weaknesses(self) -> List[WeaknessPattern]:
        weaknesses = []
        
        # 1. 按场景类型分析错误率
        by_category = defaultdict(list)
        for record in self.history:
            by_category[record.scenario_category].append(record)
        
        for category, records in by_category.items():
            error_rate = sum(1 for r in records if r.outcome_mismatch) / len(records)
            if error_rate > 0.3:  # 错误率超过30%
                weaknesses.append(WeaknessPattern(
                    category=category,
                    severity=min(1.0, error_rate),
                    sample_cases=[r for r in records if r.outcome_mismatch][-5:]
                ))
        
        # 2. 分析决策一致性（系统是否对相似案例给出矛盾建议）
        inconsistency_clusters = self.detect_inconsistencies()
        for cluster in inconsistency_clusters:
            weaknesses.append(WeaknessPattern(
                category=f'inconsistency_{cluster.feature}',
                severity=cluster.inconsistency_score,
                sample_cases=cluster.examples
            ))
        
        return sorted(weaknesses, key=lambda x: x.severity, reverse=True)

        scores.append(industry_valid)

        scores.append(human_valid)

        similarity_to_real = self.calculate_similarity_to_real_cases(scenario)
        scores.append(similarity_to_real)

    def check_human_plausibility(self, scenario: DecisionScenario) -> float:
        """检查候选人档案是否像真实人类而非 caricature"""
        candidate = scenario.options[0]
        
        red_flags = 0
        
        # 过于完美的候选人（不现实）
        if candidate.technical_score > 0.95 and candidate.business_score > 0.95 and candidate.ethical_score > 0.95:
            red_flags += 1
        
        # 矛盾特质组合（如极度外向但社交账户空白）
        if candidate.personality.get('extroversion') == 'high' and candidate.social_presence < 0.2:
            red_flags += 1
        
        # 经历断层无解释（不现实）
        gaps = [g for g in candidate.work_history if g.get('gap', False) and not g.get('explanation')]
        if len(gaps) > 2:
            red_flags += 1
        
        return max(0, 1 - red_flags * 0.3)

B. 动态客户进化模拟器

class EvolvingClientSimulator:
    """模拟客户随时间进化"""
    
    def __init__(self, initial_persona: ClientPersona):
        self.persona = initial_persona
        self.current_stage = self.infer_stage(initial_persona)
        self.history = [self.snapshot()]
        self.months_in_stage = 0
        
    def infer_stage(self, persona: ClientPersona) -> str:
        # 基于公司特征推断阶段
        if '融资' not in persona.company_history:
            return 'seed'
        elif 'A轮' in str(persona.company_history):
            return 'angel'
        else:
            return 'series_a'
    
    def step(self, months: int = 1):
        """推进时间，可能触发进化"""
        for _ in range(months):
            self.months_in_stage += 1
            stage_config = self.stages[self.current_stage]
            
            # 检查是否触发阶段转换
            if self.should_evolve(stage_config):
                self.evolve_to_next_stage()
                self.months_in_stage = 0
            else:
                # 在同阶段内微调特征（渐进进化）
                self.evolve_within_stage()
            
            self.history.append(self.snapshot())
    
    def should_evolve(self, stage_config: LifecycleStage) -> bool:
        # 基于概率 + 时间检查
        min_months, max_months = stage_config.typical_duration_months
        
        if self.months_in_stage < min_months:
            return False
        
        # 基础概率随时间增加
        base_prob = self.transition_probabilities.get(
            (self.current_stage, self.next_stage()), 0.05
        )
        time_modifier = (self.months_in_stage - min_months) / (max_months - min_months)
        probability = base_prob * (1 + time_modifier)
        
        return np.random.random() < probability
    
    def evolve_to_next_stage(self):
        """进入新阶段，特征发生显著变化"""
        next_stage_name = self.next_stage()
        next_config = self.stages[next_stage_name]
        
        # 决策特征更新
        self.persona.decision_characteristics.update(next_config.decision_characteristics)
        
        # 关注点变化（保持部分历史关注，添加新关注）
        old_concerns = set(self.persona.current_concerns)
        new_concerns = set(next_config.key_concerns)
        self.persona.current_concerns = list(old_concerns & new_concerns) + list(new_concerns)
        
        # 风险偏好调整（通常随阶段降低）
        if next_stage_name in ['series_a', 'series_b']:
            self.persona.risk_appetite *= 0.8
        
        # 决策速度降低（组织复杂度增加）
        self.persona.decision_velocity *= 0.9
        
        self.current_stage = next_stage_name
        
        # 记录进化事件
        self.persona.lifecycle_events.append({
            'timestamp': datetime.now(),
            'event': f'进化至{next_stage_name}',
            'trigger': self.detect_trigger()
        })
    
    def evolve_within_stage(self):
        """阶段内的渐进微调"""
        # 经验积累导致信息需求变化
        self.persona.information_need *= 0.98  # 逐渐降低（经验增加）
        
        # 信任积累（如果之前决策成功）
        if np.random.random() < 0.3:  # 30%概率有成功决策
            self.persona.trust_level = min(1.0, self.persona.trust_level + 0.02)

class CrossStageConsistencyLearner:
    """学习客户在不同阶段的一致性模式"""
    
    def analyze_consistency(self, evolving_client: EvolvingClientSimulator) -> ConsistencyProfile:
        """分析该客户在进化中保持不变的决策核心"""
        
        history = evolving_client.history
        
        # 跟踪价值权重变化
        value_trajectory = [h.value_weights for h in history]
        
        # 识别稳定维度（如"诚信"始终高权重）
        stable_values = []
        changing_values = []
        
        for value_dim in ['仁', '义', '礼', '智', '信']:
            weights = [v[value_dim] for v in value_trajectory]
            cv = np.std(weights) / np.mean(weights)  # 变异系数
            if cv < 0.15:  # 变化小于15%
                stable_values.append((value_dim, np.mean(weights)))
            else:
                changing_values.append((value_dim, weights))
        
        # 识别决策模式的一致性
        pattern_consistency = self.analyze_decision_patterns(history)
        
        return ConsistencyProfile(
            client_id=evolving_client.persona.id,
            stable_values=stable_values,
            evolving_dimensions=changing_values,
            core_identity=self.synthesize_core_identity(stable_values),
            stage_specific_adaptations=self.identify_adaptations(history)
        )
    
    def synthesize_core_identity(self, stable_values: List[Tuple]) -> str:
        """合成客户的核心决策身份（不随阶段改变的部分）"""
        # 例如："无论处于哪个阶段，始终把'信'放在首位"
        dominant_value = max(stable_values, key=lambda x: x[1])
        return f"核心锚点：{dominant_value[0]}（权重{dominant_value[1]:.2f}）"

### 问题8: 如何从真实案例中提取”场景模式”？

#### 明确方案

分层模式提取（Hierarchical Pattern Mining）：从原始案例中通过实体提取→关系发现→模式抽象→模式验证四步，提取可复用的决策场景模式。

#### 理由说明

原始案例是叙事性的（故事），场景模式是结构性的（框架）

需要区分表面特征（行业、职位）和深层结构（冲突类型、决策困境）

提取的模式必须可泛化（适用于相似但非相同情境）

class PatternExtractionEngine:
    def __init__(self, nlp_pipeline, knowledge_graph):
        self.nlp = nlp_pipeline
        self.kg = knowledge_graph
        
    def extract_from_case(self, raw_case: RawCase) -> List[ScenePattern]:
        """从单个案例中提取多个模式"""
        
        # 步骤1：实体与关系提取
        entities = self.nlp.extract_entities(raw_case.narrative)
        relations = self.nlp.extract_relations(raw_case.narrative, entities)
        
        # 步骤2：识别决策点与困境
        dilemmas = self.identify_dilemmas(raw_case.narrative, entities, relations)
        
        # 步骤3：抽象化（去除具体细节，保留结构）
        patterns = []
        for dilemma in dilemmas:
            abstract_pattern = self.abstract_dilemma(dilemma, raw_case)
            patterns.append(abstract_pattern)
        
        # 步骤4：与知识图谱关联，寻找相似模式
        enriched_patterns = self.enrich_with_similarity(patterns)
        
        return enriched_patterns

B. 具体提取技术：困境识别与抽象

def identify_dilemmas(self, narrative: str, entities: List[Entity], relations: List[Relation]) -> List[Dilemma]:
        """识别叙事中的决策困境"""
        
        dilemmas = []
        
        # 模式1：能力vs价值观冲突（通过关键词和句法）
        capability_value_clues = ['技术很强', '但是', '人品', '价值观', '担心', '冲突']
        if self.check_pattern_presence(narrative, capability_value_clues):
            dilemmas.append(Dilemma(
                type='capability_vs_values',
                description='候选人能力出众但价值观存疑',
                involved_entities=[e for e in entities if e.type in ['person', 'value']],
                conflict_indicators=self.extract_conflict_sentences(narrative, capability_value_clues)
            ))
        
        # 模式2：时间压力vs信息完整性
        time_info_clues = ['时间紧', '来不及', '必须决定', '信息不全', '再等等']
        if self.check_pattern_presence(narrative, time_info_clues):
            dilemmas.append(Dilemma(
                type='time_vs_information',
                description='时间压力与信息收集需求的冲突',
                involved_entities=[e for e in entities if e.type in ['time_constraint', 'information']],
                urgency_signals=self.extract_urgency_signals(narrative)
            ))
        
        # 模式3：多方利益冲突
        multi_stakeholder_clues = ['合伙人', '投资人', '团队', '意见不统一', '分歧']
        if len([e for e in entities if e.type == 'stakeholder']) > 2:
            dilemmas.append(Dilemma(
                type='multi_stakeholder_conflict',
                description='不同利益相关方对候选人有不同评价',
                stakeholders=[e for e in entities if e.type == 'stakeholder'],
                conflict_descriptions=self.extract_stakeholder_views(narrative)
            ))
        
        return dilemmas
    
    def abstract_dilemma(self, dilemma: Dilemma, raw_case: RawCase) -> ScenePattern:
        """将具体困境抽象为可复用模式"""
        
        # 去除具体细节，保留结构
        structural_elements = {
            'conflict_type': dilemma.type,
            'dimension_a': self.abstract_dimension(dilemma.involved_entities[0]),
            'dimension_b': self.abstract_dimension(dilemma.involved_entities[1]) if len(dilemma.involved_entities) > 1 else None,
            'pressure_source': self.abstract_pressure(dilemma),
            'decision_moment': self.identify_decision_moment(raw_case.narrative)
        }
        
        # 保留可变化的表面特征（用于生成多样化场景）
        surface_vars = [
            f"行业：{[e.name for e in raw_case.entities if e.type == 'industry']}",
            f"职位：{[e.name for e in raw_case.entities if e.type == 'role']}",
            f"轮次：{[e.name for e in raw_case.entities if e.type == 'funding_stage']}"
        ]
        
        # 生成适用条件（何时此模式适用）
        conditions = [
            f"当{structural_elements['dimension_a']}与{structural_elements['dimension_b']}存在显著差距时",
            f"当{structural_elements['pressure_source']}较高时"
        ]
        
        return ScenePattern(
            pattern_id=f"{dilemma.type}_{raw_case.case_id}",
            category=dilemma.type,
            structural_elements=structural_elements,
            surface_variations=surface_vars,

class PatternClusteringValidator:
    """验证提取的模式是否具有良好的泛化性"""
    
    def cluster_patterns(self, patterns: List[ScenePattern]) -> List[PatternCluster]:
        """聚类相似模式，识别通用架构"""
        
        # 使用结构相似性而非表面相似性
        vectors = [self.vectorize_structure(p.structural_elements) for p in patterns]
        
        # 层次聚类
        clustering = AgglomerativeClustering(n_clusters=None, distance_threshold=0.3)
        labels = clustering.fit_predict(vectors)
        
        clusters = defaultdict(list)
        for pattern, label in zip(patterns, labels):
            clusters[label].append(pattern)
        
        # 为每个聚类生成通用模板
        validated_clusters = []
        for label, cluster_patterns in clusters.items():
            if len(cluster_patterns) >= 3:  # 至少3个案例支持
                general_template = self.generalize_cluster(cluster_patterns)
                validated_clusters.append(PatternCluster(
                    template=general_template,
                    instances=cluster_patterns,
                    coverage=len(cluster_patterns),
                    confidence=self.calculate_confidence(cluster_patterns)
                ))
        
        return validated_clusters
    
    def generalize_cluster(self, patterns: List[ScenePattern]) -> GeneralPattern:
        """从聚类中提取通用模式"""
        
        # 找出共同结构
        common_structure = self.find_common_structure([p.structural_elements for p in patterns])
        
        # 合并表面变化（所有可能的变体）
        all_variations = set()
        for p in patterns:
            all_variations.update(p.surface_variations)
        
        # 生成通用适用条件
        general_conditions = self.intersect_conditions([p.applicable_conditions for p in patterns])
        
        return GeneralPattern(
            structure_template=common_structure,
            variation_space=all_variations,
            applicability_rules=general_conditions,
            example_cases=[p.similar_cases[0] for p in patterns[:3]]  # 保留3个示例
        )

class ImplicitFeedbackCollector:
    """通过行为数据推断满意度，无需询问"""
    
    def collect(self, client_id: str, session: SessionData) -> ImplicitFeedback:
        signals = {}
        
        # 信号1：参与度（Engagement）
        signals['engagement_score'] = self.calculate_engagement(session)
        # - 平均响应时间（秒）：<5秒（高度投入），5-30秒（正常），>30秒（分心）
        # - 消息长度：长消息=深入思考
        # - 追问次数：追问=需求未满足或高度兴趣
        
        # 信号2：价值认可（Value Recognition）
        signals['value_signals'] = self.detect_value_signals(session)
        # - 保存/收藏行为（是否点击收藏建议）
        # - 分享行为（是否转发报告给合伙人）
        # - 截图行为（移动端检测到截图=认为内容有价值）
        # - 复制粘贴（复制关键句子去其他地方使用）
        
        # 信号3：流失信号（Churn Risk）
        signals['frustration_signals'] = self.detect_frustration(session)
        # - 重复提问（同一问题问多次=没理解答案）
        # - 否定词频率："但是"、"不对"、"没解决"
        # - 突然离开（长时间无响应后关闭）
        # - 降级使用（从频繁使用变为偶尔使用）
        
        # 信号4：采纳指标（Adoption）
        signals['adoption_likelihood'] = self.predict_adoption(session)
        # - 决策速度：获得建议后多久做决策（太快=可能未采纳，太慢=犹豫）
        # - 后续查询：是否查询相关主题（如建议后去查"竞业协议"）
        
        return ImplicitFeedback(
            client_id=client_id,
            timestamp=datetime.now(),
            signals=signals,
            inferred_satisfaction=self.infer_satisfaction(signals),
            confidence=self.calculate_confidence(signals)
        )
    
    def infer_satisfaction(self, signals: Dict) -> float:
        """综合信号推断满意度（0-1）"""
        weights = {
            'engagement_score': 0.3,
            'value_signals': 0.4,
            'frustration_signals': -0.3,  # 负面权重
            'adoption_likelihood': 0.3
        }
        
        score = sum(signals.get(k, 0) * w for k, w in weights.items())
        return max(0, min(1, score + 0.5))  # 归一化到0-1

class AsyncOutcomeTracker:
    """长期追踪决策结果"""
    
    def __init__(self):
        self.scheduler = AsyncScheduler()
        self.notification_service = NotificationService()
        self.incentive_manager = IncentiveManager()
    
    async def schedule_tracking(self, decision_id: str):
        """为决策安排全生命周期追踪"""
        lifecycle = await self.get_lifecycle(decision_id)
        
        for milestone in lifecycle.milestones:
            scheduled_time = lifecycle.decision_date + timedelta(days=milestone.expected_days)
            
            await self.scheduler.schedule(
                job_id=f"{decision_id}_{milestone.name}",
                execute_at=scheduled_time,
                coroutine=self.execute_checkin(decision_id, milestone),
                retry_policy='gentle'  # 温和重试：3次，间隔3天
            )
    
    async def execute_checkin(self, decision_id: str, milestone: Milestone):
        """执行特定里程碑的检查"""
        client = await self.get_client_by_decision(decision_id)
        
        # 根据客户层级选择接触方式
        if client.tier == 1:
            # Tier 1：异步消息，低打扰
            await self.notification_service.send_async(
                client_id=client.id,
                channel='feishu_message',
                content=self.format_milestone_message(milestone, tone='light'),
                response_timeout_days=7,
                incentive='case_library_credits'  # 积分激励
            )
        elif client.tier == 2:
            # Tier 2：结构化问卷，专业感
            await self.notification_service.send_async(
                client_id=client.id,
                channel='email_or_feishu',
                content=self.format_structured_survey(milestone),
                response_timeout_days=14,
                incentive='consulting_credit_30min'
            )
        else:
            # Tier 3：人工深度访谈（Egbertie或团队执行）

                client_id=client.id,
                decision_id=decision_id,

            )
    
    async def handle_response(self, decision_id: str, milestone_name: str, response: Dict):

class ProxyIndicatorsAnalyzer:
    """用过程指标预测最终结果"""
    
    def calculate_proxy_metrics(self, decision_id: str) -> Dict:
        """计算可用于早期验证的代理指标"""
        
        metrics = {}
        
        # 代理指标1：建议采纳度（客户是否按建议执行）
        dd_completion = self.check_due_diligence_completion(decision_id)
        metrics['adoption_rate'] = dd_completion.score  # 0-1
        
        # 代理指标2：验证质量（是否验证了关键维度）
        if dd_completion.report:
            validated_dimensions = set(dd_completion.report.keys())
            recommended_dimensions = self.get_recommended_dimensions(decision_id)
            metrics['validation_coverage'] = len(validated_dimensions & recommended_dimensions) / len(recommended_dimensions)
        
        # 代理指标3：早期互动质量（30天内的合作摩擦信号）
        early_signals = self.analyze_early_collaboration(decision_id)
        metrics['early_friction_score'] = early_signals.friction_indicators
        
        # 代理指标4：客户置信度变化（从决策时的confidence到30天后的confidence）
        confidence_trajectory = self.get_confidence_trajectory(decision_id)
        metrics['confidence_stability'] = confidence_trajectory.stability
        
        return metrics
    
    def predict_outcome_likelihood(self, metrics: Dict) -> str:
        """基于代理指标预测最终成功概率"""
        # 简单模型：采纳率高+验证全面+早期摩擦低 = 高成功概率
        score = (metrics['adoption_rate'] * 0.3 + 
                metrics['validation_coverage'] * 0.3 + 
                (1 - metrics['early_friction_score']) * 0.4)
        
        if score > 0.8:
            return 'likely_success'
        elif score < 0.4:
            return 'likely_failure'
        else:
            return 'uncertain'
    
    async def early_intervention(self, decision_id: str):
        """当代理指标显示风险时，早期干预"""
        metrics = self.calculate_proxy_metrics(decision_id)
        prediction = self.predict_outcome_likelihood(metrics)
        
        if prediction == 'likely_failure':
            client = await self.get_client(decision_id)
            # 发送预警和建议
            await self.send_early_warning(
                client_id=client.id,
                message="检测到潜在风险信号。建议提前进行合伙人关系诊断，避免问题扩大。",
                offer='free_mid_course_correction_session'

### 问题13: 如何区分”随机误差”和”系统性偏差”？（避免过度修正）

#### 明确方案

统计显著性检验 + 贝叶斯更新 + 模式聚类：通过假设检验判断偏差是否超出随机波动范围，利用贝叶斯方法区分偶然错误与持续偏差，并通过跨情境验证确认系统性。

#### 理由说明

单次预测失败可能是噪声（随机），连续同类型失败才是信号（系统）

过度修正（over-correction）会导致模型” chasing noise”，破坏已学习的有效模式

需要量化置信度：只有当偏差统计显著且跨情境一致时，才触发修正

@dataclass
class DeviationReport:
    observation: str           # 观察到的偏差
    magnitude: float          # 偏差幅度
    statistical_significance: float  # p-value
    pattern_consistency: float # 跨情境一致性
    recommended_action: str     # 'ignore', 'monitor', 'adjust', 'urgent_fix'

class StatisticalDeviationAnalyzer:
    """区分随机误差与系统性偏差"""
    
    def __init__(self, window_size: int = 30):
        self.window_size = window_size  # 观察窗口
        self.min_sample_size = 10       # 最小样本量
        
    async def analyze(self, decision_type: str, metric: str) -> DeviationReport:
        # 获取近期预测与实际结果
        recent_cases = await self.get_recent_cases(decision_type, self.window_size)
        
        if len(recent_cases) < self.min_sample_size:
            return DeviationReport(
                observation="样本不足",
                statistical_significance=1.0,  # 不显著
                recommended_action='monitor'
            )
        
        # 1. 统计显著性检验（Z-test或T-test）
        prediction_errors = [c.predicted - c.actual for c in recent_cases]
        historical_errors = await self.get_historical_errors(decision_type, metric)
        
        # 计算当前误差分布是否与历史分布显著不同
        t_stat, p_value = ttest_ind(prediction_errors, historical_errors)
        
        # 2. 贝叶斯更新：计算P(系统性偏差|数据)
        prior_systematic = 0.2  # 先验概率20%
        likelihood = self.calculate_likelihood(prediction_errors, 'systematic')
        posterior = self.bayesian_update(prior_systematic, likelihood)
        
        # 3. 跨情境一致性检查
        consistency = await self.check_cross_scenario_consistency(decision_type, prediction_errors)
        
        # 4. 决策树：确定行动
        if p_value < 0.01 and posterior > 0.8 and consistency > 0.7:
            action = 'urgent_fix'
        elif p_value < 0.05 and posterior > 0.6:
            action = 'adjust'
        elif p_value < 0.1:
            action = 'monitor'
        else:
            action = 'ignore'  # 随机误差
            
        return DeviationReport(
            observation=f"{metric}在{decision_type}场景下偏离{baseline:.2f}个标准差",
            magnitude=np.mean(prediction_errors),
            statistical_significance=p_value,
            pattern_consistency=consistency,
            systematic_probability=posterior,
            recommended_action=action
        )
    
    def check_cross_scenario_consistency(self, decision_type: str, errors: List[float]) -> float:
        """检查偏差是否在同类型不同子场景中一致出现"""
        # 获取同类型但不同细分场景的数据
        sub_scenarios = await self.get_sub_scenarios(decision_type)
        
        consistency_scores = []
        for sub in sub_scenarios:
            sub_errors = await self.get_errors_for_scenario(sub)
            if sub_errors:
                # 计算与主场景偏差的相关性
                correlation = np.corrcoef(errors[:len(sub_errors)], sub_errors)[0,1]
                if correlation > 0.5:  # 正相关说明系统性
                    consistency_scores.append(correlation)
        
        return np.mean(consistency_scores) if consistency_scores else 0.0

class ErrorPatternClustering:
    """聚类相似错误，识别系统性问题"""
    
    async def cluster_errors(self, errors: List[PredictionError]) -> List[ErrorCluster]:
        """将错误聚类为模式"""
        
        # 特征提取
        features = []
        for error in errors:
            feature_vector = [
                error.deviation_direction,  # 高估/低估
                error.scenario_complexity,
                error.candidate_profile.get('industry_code'),
                error.decision_maker_stress_level,
                error.information_completeness
            ]
            features.append(feature_vector)
        
        # DBSCAN聚类（发现密集的错误模式）
        clustering = DBSCAN(eps=0.3, min_samples=5).fit(features)
        
        clusters = []
        for label in set(clustering.labels_):
            if label == -1:  # 噪声点（随机误差）
                continue
            
            cluster_errors = [e for e, l in zip(errors, clustering.labels_) if l == label]
            clusters.append(ErrorCluster(
                cluster_id=label,
                size=len(cluster_errors),
                common_features=self.extract_common_features(cluster_errors),
                severity=self.calculate_severity(cluster_errors),
                is_systematic=len(cluster_errors) >= 10  # 10个以上视为系统
            ))
        
        return clusters
    
    def extract_common_features(self, errors: List[PredictionError]) -> Dict:
        """提取聚类的共同特征（系统性根源）"""
        # 例如：发现所有错误都发生在"AI行业+连续创业者+高时间压力"场景
        industries = set(e.candidate_profile['industry'] for e in errors)
        client_types = set(e.client_type for e in errors)
        
        return {
            'common_industries': industries,
            'common_client_types': client_types,
            'common_conditions': self.find_common_conditions(errors)
        }

        control_group = await self.select_control_group(size=100, matching_criteria=correction.target_scenarios)
        treatment_group = await self.select_treatment_group(size=100, matching_criteria=correction.target_scenarios)
        
        # 对照组：原模型
        control_predictions = [await self.predict_with_original_model(case) for case in control_group]
        
        # 实验组：修正后模型
        treatment_predictions = [await self.predict_with_corrected_model(case, correction) for case in treatment_group]
        
        # 等待真实结果（或模拟验证）
        await self.wait_for_outcomes(control_group + treatment_group, timeout_days=90)
        
        # 评估指标
        control_accuracy = self.calculate_accuracy(control_predictions)
        treatment_accuracy = self.calculate_accuracy(treatment_predictions)
        
        # 统计检验
        improvement = treatment_accuracy - control_accuracy
        p_value = self.calculate_significance(control_predictions, treatment_predictions)
        
        if improvement > 0.05 and p_value < 0.05:  # 显著提升5%且显著
            return ValidationResult(
                valid=True,
                improvement=improvement,
                confidence=1-p_value,
                recommendation='deploy'
            )
        elif improvement < 0:
            return ValidationResult(
                valid=False,
                degradation=abs(improvement),
                recommendation='abort_correction'
            )
        else:
            return ValidationResult(
                valid='partial',
                improvement=improvement,
                recommendation='refine_correction'
            )

### 问题14: 如何设计”保守修正”机制？（渐进调整而非突变）

#### 明确方案

学习率衰减 + 影子模式 + 回滚机制：采用小步快跑策略（学习率随时间衰减），部署时保留影子模型对比，并设计一键回滚能力防止灾难性更新。

#### 理由说明

决策风格的突变会让客户感到困惑（“上周你不是这样说的”）

AI模型的灾难性遗忘（catastrophic forgetting）可能破坏已学习的有效模式

需要双轨运行：新模型验证期与旧模型并行，确保安全

A. 渐进式权重更新（学习率控制）

class ConservativeWeightUpdater:
    """保守的模型参数更新"""
    
    def __init__(self):
        self.base_learning_rate = 0.01
        self.min_learning_rate = 0.001
        self.stability_threshold = 0.95  # 稳定性阈值
        
    async def calculate_update_step(self, 
                                     current_weights: Dict,
                                     target_weights: Dict,
                                     model_age_days: int) -> Dict:
        """计算保守的更新步长"""
        
        # 学习率随模型成熟度衰减（老模型更保守）
        experience_factor = min(1.0, model_age_days / 365)  # 1年后达到最大保守
        effective_lr = self.base_learning_rate * (1 - experience_factor * 0.5)
        effective_lr = max(effective_lr, self.min_learning_rate)
        
        # 计算目标方向
        weight_deltas = {k: target_weights[k] - current_weights[k] for k in current_weights}
        
        # 限制单次最大调整幅度（防止突变）
        max_delta = 0.1  # 单次最多调整10%
        clamped_deltas = {k: np.clip(v, -max_delta, max_delta) for k, v in weight_deltas.items()}
        
        # 应用学习率
        final_updates = {k: v * effective_lr for k, v in clamped_deltas.items()}
        
        new_weights = {k: current_weights[k] + final_updates[k] for k in current_weights}
        
        return {
            'new_weights': new_weights,
            'max_adjustment': max(abs(v) for v in final_updates.values()),
            'learning_rate_applied': effective_lr,
            'update_magnitude': 'conservative' if effective_lr < 0.005 else 'moderate'
        }
    
    async def staged_rollout(self, update: WeightUpdate, stages: List[float] = [0.1, 0.3, 0.6, 1.0]):
        """分阶段 rollout，每阶段验证稳定性"""
        for stage in stages:
            # 部分更新
            partial_weights = self.interpolate_weights(current_weights, update.new_weights, stage)
            await self.deploy_to_subset(partial_weights, subset_size=stage)
            
            # 观察期
            await self.observe_stability(days=3)
            
            # 检查稳定性指标
            stability = await self.calculate_stability_metrics()
            if stability < self.stability_threshold:
                await self.rollback(stage)
                return RollbackResult(stage=stage, reason='stability_degradation')
        
        return SuccessResult(final_weights=update.new_weights)

class ShadowModelSystem:
    """影子模型：并行运行但不影响生产"""
    
    def __init__(self):
        self.production_model = None  # 当前生产模型
        self.shadow_candidates = []   # 候选新模型队列
        
    async def propose_update(self, new_model_config: Dict, validation_score: float):
        """提议新模型进入影子队列"""
        shadow_model = await self.load_model(new_model_config)
        
        self.shadow_candidates.append({
            'model': shadow_model,
            'validation_score': validation_score,
            'shadow_start_time': datetime.now(),
            'production_predictions': [],
            'shadow_predictions': []
        })
    
    async def shadow_step(self, input_data: Input):
        """每步推理同时运行影子模型（但只用生产模型输出）"""
        production_output = await self.production_model.predict(input_data)
        
        # 异步记录影子模型预测（不阻塞生产）
        for candidate in self.shadow_candidates:
            shadow_output = await candidate['model'].predict(input_data)
            candidate['shadow_predictions'].append(shadow_output)
            
            # 记录生产模型结果用于对比
            candidate['production_predictions'].append(production_output)
    
    async def evaluate_shadows(self, actual_outcomes: List[Outcome]):
        """评估影子模型表现"""
        for candidate in self.shadow_candidates:
            prod_accuracy = self.calculate_accuracy(candidate['production_predictions'], actual_outcomes)
            shadow_accuracy = self.calculate_accuracy(candidate['shadow_predictions'], actual_outcomes)
            
            candidate['advantage'] = shadow_accuracy - prod_accuracy
            candidate['confidence'] = self.calculate_confidence_interval(candidate['shadow_predictions'])
            
            # 如果影子模型显著更好且稳定，提升为生产候选
            if candidate['advantage'] > 0.03 and candidate['confidence'] > 0.95:
                await self.promote_to_canary(candidate)

class SafeRollbackSystem:
    """确保可回滚到之前版本"""
    
    def __init__(self):
        self.version_history = []
        self.max_versions = 10
        
    async def deploy_with_checkpoint(self, new_model, deployment_metadata: Dict):
        """部署时自动创建检查点"""
        # 保存当前状态
        checkpoint = {
            'timestamp': datetime.now(),
            'model_state': await self.serialize_model(),
            'performance_baseline': await self.get_current_metrics(),
            'metadata': deployment_metadata
        }
        self.version_history.append(checkpoint)
        
        # 限制历史版本数
        if len(self.version_history) > self.max_versions:
            self.version_history.pop(0)
        
        # 部署新模型
        try:
            await self.deploy(new_model)
            await self.monitor_health(window_minutes=30)
        except Exception as e:
            await self.rollback(steps=1)
            raise DeploymentError(f"部署失败，已自动回滚: {e}")
    
    async def rollback(self, steps: int = 1, target_timestamp: Optional[datetime] = None):
        """执行回滚"""
        if target_timestamp:
            checkpoint = next((c for c in self.version_history if c['timestamp'] == target_timestamp), None)
        else:
            checkpoint = self.version_history[-steps]
        
        # 恢复模型状态
        await self.restore_model(checkpoint['model_state'])
        
        # 验证恢复成功
        current_metrics = await self.get_current_metrics()
        baseline = checkpoint['performance_baseline']
        
        # 确保回滚后性能与基线相当
        if abs(current_metrics.accuracy - baseline.accuracy) > 0.02:
            await self.alert_manual_intervention()
        
        return RollbackResult(
            restored_to=checkpoint['timestamp'],
            performance_restored=(current_metrics.accuracy >= baseline.accuracy * 0.98)
        )
    
    async def automated_health_check(self):
        """自动化健康检查，触发条件回滚"""
        metrics = await self.get_realtime_metrics()
        
        # 触发条件
        if metrics.error_rate > 0.05:  # 错误率>5%
            await self.rollback(steps=1)
            await self.alert_egbertie(reason='high_error_rate_auto_rollback')
        elif metrics.latency_p99 > 5000:  # 延迟过高
            await self.rollback(steps=1)
        elif metrics.user_satisfaction < 3.0:  # 满意度骤降
            await self.request_approval_for_rollback()

class TwoWeekSprint:
    """双周冲刺管理"""
    
    def __init__(self, sprint_id: str, hypotheses: List[Hypothesis]):
        self.sprint_id = sprint_id
        self.hypotheses = hypotheses
        self.start_date = datetime.now()
        self.end_date = self.start_date + timedelta(days=14)
        self.status = 'running'
        
    async def daily_check(self):
        """每日检查假设状态"""
        for hypothesis in self.hypotheses:
            current_data = await self.collect_data(hypothesis)
            
            # 检查kill criteria
            if await self.check_kill_criteria(hypothesis, current_data):
                await self.kill_hypothesis(hypothesis, reason='kill_criteria_met')
                continue
            
            # 检查success criteria
            if await self.check_success_criteria(hypothesis, current_data):
                await self.validate_hypothesis(hypothesis)
                continue
            
            # 检查时间进度
            progress = (datetime.now() - self.start_date).days / hypothesis.max_duration_days
            if progress > 0.7 and not self.showing_trend(hypothesis, current_data):
                await self.flag_at_risk(hypothesis)
    
    async def sprint_review(self):
        """双周评审"""
        results = []
        for hypothesis in self.hypotheses:
            result = {
                'hypothesis': hypothesis.statement,
                'status': hypothesis.status,  # validated/killed/pending
                'data': hypothesis.collected_data,
                'decision': 'proceed' if hypothesis.status == 'validated' else 'pivot_or_kill'
            }
            results.append(result)
        
        # 生成下一步决策
        validated = [r for r in results if r['status'] == 'validated']
        killed = [r for r in results if r['status'] == 'killed']
        
        if len(validated) >= len(self.hypotheses) * 0.5:
            recommendation = 'proceed_to_next_milestone'
        elif len(killed) >= len(self.hypotheses) * 0.5:
            recommendation = 'pivot_or_stop'
        else:
            recommendation = 'extend_or_iterate'
        
        return SprintReview(
            results=results,
            recommendation=recommendation,
            next_sprint_plan=self.generate_next_plan(validated)
        )

### 问题16: 如何平衡”标准化”与”定制化”？（效率vs个性化）

#### 明确方案

分层架构：标准化引擎 + 个性化适配器 + 客户特定插件：底层使用标准化决策框架（确保质量和效率），中层通过客户画像动态适配（个性化权重），顶层通过插件机制支持完全定制（高价值客户）。

完全定制化：无法规模服务，且质量难以保证

需要帕累托最优：80%标准化确保效率，20%定制化处理关键差异

### 问题17: 如何预测客户的”下一个需求”？（主动而非被动）

#### 明确方案

行为序列挖掘 + 生命周期阶段预测 + 相似客户扩散：通过分析客户行为轨迹（如从”信息查询”→“深度分析”→“团队分享”的跃迁信号），结合相似客户历史路径，主动在客户意识到需求前提供解决方案。

需要置信度阈值：只有当预测置信度>70%时才主动推送，避免打扰

@dataclass
class BehavioralSequence:
    """客户行为序列模式"""
    sequence: List[str]  # 如 ['info_query', 'deep_analysis', 'case_download', 'share']
    support: float       # 出现频率
    confidence: float    # 置信度

class NextNeedPredictor:
    """预测客户下一步需求"""
    
    def __init__(self):
        self.sequence_miner = SequencePatternMiner()
        self.lifecycle_model = LifecycleStageModel()
        
    async def predict_next_need(self, client_id: str) -> PredictionResult:
        """预测客户接下来的需求"""
        client = await self.get_client(client_id)
        
        # 1. 获取近期行为序列（滑动窗口）
        recent_actions = await self.get_recent_actions(client_id, window_days=30)
        action_sequence = [a.type for a in recent_actions]
        
        # 2. 序列模式匹配（关联规则挖掘）
        patterns = await self.sequence_miner.mine_frequent_patterns(
            min_support=0.1,  # 至少10%客户出现
            min_confidence=0.6
        )
        
        matched_patterns = []
        for pattern in patterns:
            # 检查当前序列是否匹配模式前缀
            if self.is_prefix_match(action_sequence, pattern.sequence):
                matched_patterns.append(pattern)
        
        # 3. 生命周期阶段预测
        lifecycle_stage = await self.lifecycle_model.predict_stage(client_id)
        stage_typical_next = self.get_stage_typical_needs(lifecycle_stage)
        
        # 4. 相似客户扩散（Collaborative Filtering）
        similar_clients = await self.find_similar_clients(client_id, n=20)
        similar_next_actions = await self.get_next_actions_of_similar(similar_clients)
        
        # 5. 融合预测（加权投票）
        predictions = self.ensemble_predictions(
            sequence_predictions=matched_patterns,
            lifecycle_prediction=stage_typical_next,
            collaborative_prediction=similar_next_actions
        )
        
        # 6. 过滤已满足需求（不预测已有服务的需求）
        unsatisfied_predictions = [
            p for p in predictions 
            if not await self.is_need_already_satisfied(client_id, p.need)
        ]
        
        return PredictionResult(
            top_predictions=unsatisfied_predictions[:3],
            confidence_scores={p.need: p.confidence for p in unsatisfied_predictions},
            suggested_timing=self.calculate_optimal_timing(client_id, unsatisfied_predictions[0]),
            recommended_approach=self.decide_approach(unsatisfied_predictions[0])
        )
    
    def is_prefix_match(self, current: List[str], pattern: List[str]) -> bool:
        """检查当前序列是否匹配模式前缀"""
        # 当前序列: [A, B, C], 模式: [A, B, C, D, E] -> 匹配，预测D
        if len(current) >= len(pattern):
            return False
        return current == pattern[:len(current)]
    
    async def find_similar_clients(self, client_id: str, n: int) -> List[str]:
        """基于决策风格、行业、阶段找相似客户"""
        client = await self.get_client(client_id)
        
        # 多维度相似度计算
        candidates = await self.get_all_clients()
        similarities = []
        
        for other in candidates:
            if other.id == client_id:
                continue
            
            sim_score = self.calculate_similarity(
                client.decision_style, other.decision_style,
                weight=0.4
            ) + self.calculate_similarity(
                client.industry, other.industry,
                weight=0.3
            ) + self.calculate_similarity(
                client.lifecycle_stage, other.lifecycle_stage,
                weight=0.3
            )
            similarities.append((other.id, sim_score))
        
        # 返回Top N
        similarities.sort(key=lambda x: x[1], reverse=True)
        return [s[0] for s in similarities[:n]]

class ProactiveNeedDelivery:
    """主动交付预测到的需求"""
    
    async def deliver_if_appropriate(self, client_id: str, prediction: PredictionResult):
        """判断何时以及如何主动提供"""
        
        # 检查1：置信度阈值（避免错误预测打扰）
        if prediction.confidence < 0.7:
            return  # 静默等待更多信号
        
        # 检查2：客户当前状态（不打扰忙碌客户）
        client_context = await self.get_current_context(client_id)
        if client_context.stress_level == 'high' or client_context.in_conversation:
            await self.schedule_for_later(client_id, prediction, delay_hours=48)
            return
        
        # 检查3：近期是否已主动推送（避免频繁）
        last_proactive = await self.get_last_proactive_time(client_id)
        if last_proactive and (datetime.now() - last_proactive).days < 7:
            return
        
        # 检查4：历史响应率（如果客户从不响应主动推送，减少频率）
        response_rate = await self.get_historical_response_rate(client_id)
        if response_rate < 0.2:  # 响应率<20%
            return
        
        # 交付方式选择（基于需求类型）
        delivery_method = self.select_delivery_method(prediction)
        
        if prediction.recommended_approach == 'soft_content':
            # 软性内容：发送相关文章/案例，不直接推销服务
            await self.send_content(
                client_id=client_id,
                content_type='case_study',
                topic=prediction.top_predictions[0].need,
                framing='thought_sharing',  # "看到这篇觉得对你有启发"而非"你需要这个"
                cta='learn_more'  # 软CTA
            )
        
        elif prediction.recommended_approach == 'value_preview':
            # 价值预览：展示功能但不强求
            await self.show_capability_preview(
                client_id=client_id,
                capability=prediction.top_predictions[0].need,
                demo_data=client_id,  # 用客户自己的数据做Demo
                message="基于您之前的查询，我为您生成了[功能X]的预览（使用您的数据）。如需完整版，可随时开启。"
            )
        
        elif prediction.recommended_approach == 'direct_offer' and client_context.tier >= 2:
            # 直接提供（仅对高价值客户且高置信度）
            await self.send_personalized_offer(
                client_id=client_id,
                service=prediction.top_predictions[0].need,
                timing='proactive',
                discount='loyalty_reward',
                message="检测到您可能正在准备[下一阶段]。我们的[服务X]可协助，作为老客户享专属礼遇。"
            )
        
        # 记录主动交付
        await self.log_proactive_delivery(client_id, prediction, delivery_method)
    
    def select_delivery_method(self, prediction: PredictionResult) -> str:
        """根据需求类型选择最佳交付方式"""
        need_type = prediction.top_predictions[0].need
        
        # 内容型需求（知识传承）-> 软性内容
        if need_type in ['team_training', 'methodology_development']:
            return 'soft_content'
        
        # 工具型需求（效率提升）-> 价值预览
        elif need_type in ['batch_analysis', 'automation_tools']:

### 问题18: 如何设计”服务创新”的实验机制？（小规模测试再推广）

#### 明确方案

需要真实客户参与（模拟客户无法验证真实接受度），但需知情同意和退出机制

创新必须有时间盒（如4周验证），防止无限期实验

class MultiTheoryAnalyzer:
    """多理论并行分析器"""
    
    async def analyze_with_all_theories(self, scenario: DecisionScenario) -> MultiTheoryResult:
        """用所有适用理论并行分析"""
        
        # 1. 筛选适用理论
        applicable = []
        for theory in self.registry.theories.values():
            if self.is_applicable(theory, scenario):
                applicable.append(theory)
        
        # 2. 并行执行（使用asyncio.gather）
        tasks = [self.run_theory(theory, scenario) for theory in applicable]
        theory_results = await asyncio.gather(*tasks)
        
        # 3. 结果集成（考虑权重）
        integrated = await self.integrate_results(theory_results, scenario)
        
        return MultiTheoryResult(
            individual_results=theory_results,
            integrated_conclusion=integrated,
            conflict_analysis=self.analyze_conflicts(theory_results),
            confidence=self.calculate_integrated_confidence(theory_results)
        )
    
    async def integrate_results(self, results: List[TheoryResult], scenario: DecisionScenario) -> IntegratedConclusion:
        """集成多个理论的结果"""
        
        # 策略1：简单投票（分类决策）
        if scenario.decision_type == 'binary':
            votes = [r.recommendation for r in results]
            consensus = max(set(votes), key=votes.count)
            dissidents = [r for r in results if r.recommendation != consensus]
            
            return IntegratedConclusion(
                recommendation=consensus,
                confidence=len([v for v in votes if v == consensus]) / len(votes),
                dissenting_views=dissidents,
                reasoning='majority_vote'
            )
        
        # 策略2：加权平均（连续评分）
        elif scenario.decision_type == 'scoring':
            # 权重基于理论的历史准确性
            weights = await self.get_theory_accuracy_weights(scenario.category)
            
            weighted_score = sum(
                r.score * weights.get(r.theory_id, 0.2) 
                for r in results
            )
            
            return IntegratedConclusion(
                score=weighted_score,
                confidence=self.calculate_variance_confidence(results),
                contributing_theories=weights,
                reasoning='weighted_average'
            )
        
        # 策略3：条件集成（情境依赖）
        else:
            # 根据情境特征选择主导理论
            if scenario.time_pressure > 0.8:
                dominant = [r for r in results if r.theory_id in ['recognition_primed_decision', 'satisficing']]
            elif scenario.ethical_complexity > 0.8:
                dominant = [r for r in results if r.theory_id == 'egbertie_wisdom']
            else:
                dominant = results
            
            return IntegratedConclusion(
                recommendation=self.find_consensus(dominant),
                alternative_views=[r for r in results if r not in dominant],
                reasoning='context_dependent_selection'
            )
    
    def analyze_conflicts(self, results: List[TheoryResult]) -> ConflictAnalysis:
        """分析理论间的冲突（这本身就是洞察）"""
        
        # 找出结论分歧最大的理论对
        conflicts = []
        for i, r1 in enumerate(results):
            for r2 in results[i+1:]:
                if self.are_contradictory(r1, r2):
                    conflicts.append({
                        'theory_pair': (r1.theory_id, r2.theory_id),
                        'nature_of_conflict': self.describe_conflict(r1, r2),
                        'confidence_difference': abs(r1.confidence - r2.confidence),
                        'suggested_resolution': self.suggest_resolution(r1, r2)
                    })
        
        return ConflictAnalysis(
            conflicts=conflicts,
            has_irresolvable_conflict=any(c['confidence_difference'] < 0.1 for c in conflicts),
            recommended_deliberation_depth='deep' if conflicts else 'standard'
        )

class TheoryAccuracyLeague:

                                  theory_id: str, 
                                  prediction: Prediction, 
                                  actual_outcome: Outcome):
        """评估单个理论的预测准确性"""
        
        # 计算准确性指标
        accuracy = self.calculate_accuracy(prediction, actual_outcome)
        calibration = self.calculate_calibration(prediction.confidence, accuracy)
        discrimination = self.calculate_discrimination(prediction, actual_outcome)
        
        # 更新联赛表
        if theory_id not in self.league_table:
            self.league_table[theory_id] = TheoryStats()
        
        stats = self.league_table[theory_id]
        stats.total_predictions += 1
        stats.cumulative_accuracy = (stats.cumulative_accuracy * (stats.total_predictions - 1) + accuracy) / stats.total_predictions
        
        # 分情境统计（理论可能在某些情境更好）
        scenario_type = self.classify_scenario(actual_outcome.scenario)
        if scenario_type not in stats.accuracy_by_scenario:
            stats.accuracy_by_scenario[scenario_type] = []
        stats.accuracy_by_scenario[scenario_type].append(accuracy)
    
    async def get_dynamic_weights(self, scenario_category: str) -> Dict[str, float]:
        """获取基于实证数据的动态权重"""
        
        weights = {}
        for theory_id, stats in self.league_table.items():
            # 基础权重：整体准确性
            base_weight = stats.cumulative_accuracy
            
            # 情境调整：如果该理论在该情境表现特别好/差
            if scenario_category in stats.accuracy_by_scenario:
                scenario_accuracy = np.mean(stats.accuracy_by_scenario[scenario_category])
                # 如果情境准确性显著不同于整体，调整权重
                if abs(scenario_accuracy - base_weight) > 0.1:
                    adjusted_weight = 0.7 * base_weight + 0.3 * scenario_accuracy
                else:
                    adjusted_weight = base_weight
            else:
                adjusted_weight = base_weight
            
            weights[theory_id] = adjusted_weight
        
        # 归一化
        total = sum(weights.values())
        return {k: v/total for k, v in weights.items()}
    
    async def generate_league_report(self) -> LeagueReport:
        """生成理论联赛报告"""
        
        rankings = sorted(
            self.league_table.items(),
            key=lambda x: x[1].cumulative_accuracy,
            reverse=True
        )
        
        return LeagueReport(
            overall_rankings=[(t, s.cumulative_accuracy) for t, s in rankings],
            scenario_specific_strengths=self.identify_scenario_specialists(),
            declining_theories=self.identify_declining_performers(),  # 需要退役的理论
            rising_theories=self.identify_improving_performers(),      # 新星理论
            recommendation=self.generate_weight_update_recommendation()
        )

### 问题20: Multi-Agent框架技术实现（五图腾协同的架构细节）

#### 明确方案

分层消息总线 + 状态共享存储 + 冲突仲裁器：采用Actor模型（每个图腾Agent是独立Actor），通过异步消息传递协作，使用共享上下文存储保持状态一致，由中央仲裁器处理冲突。

五图腾必须并行运行（模拟人类同步多维度思考），不能串行（否则太慢且丢失冲突张力）

需要去中心化（避免单点故障），但需中心化协调（确保输出一致性）

必须支持长程依赖（如司马贺的边界分析影响孔子的伦理评估）

@dataclass
class AgentMessage:
    """Agent间消息"""
    sender: str           # 发送者图腾ID
    receiver: str         # 接收者（或broadcast）
    message_type: str     # 'analysis_result', 'challenge', 'support', 'inquiry'

    timestamp: datetime
    correlation_id: str   # 关联ID（追踪对话）

@dataclass
class SharedContext:
    """共享决策上下文（所有Agent可读写）"""
    decision_id: str
    candidate_profile: Dict
    client_persona: Dict
    accumulated_insights: Dict[str, Any]  # 各Agent贡献的洞察
    conflict_register: List[Dict]         # 记录的冲突

class TotemAgent:
    """图腾Agent基类"""
    
    def __init__(self, agent_id: str, totem_config: Dict):
        self.id = agent_id
        self.config = totem_config
        self.inbox = asyncio.Queue()
        self.context: Optional[SharedContext] = None
        self.state = 'idle'  # idle, analyzing, waiting, done
        
    async def run(self, context: SharedContext):
        """Agent主循环"""
        self.context = context
        self.state = 'analyzing'
        
        # 1. 独立分析阶段（并行执行）
        analysis = await self.analyze(context)
        
        # 2. 发布分析结果到共享上下文
        await self.publish_insight(analysis)
        
        # 3. 参与协同讨论（多轮）
        rounds = 0
        max_rounds = 3  # 最多3轮互动
        
        while rounds < max_rounds and context.consensus_level < 0.8:
            # 检查 inbox
            if not self.inbox.empty():
                msg = await self.inbox.get()
                response = await self.process_message(msg)
                if response:
                    await self.send_message(response)
            
            # 主动挑战/支持其他Agent（基于分析结果）
            if rounds == 0:  # 第一轮后发起挑战
                challenges = await self.identify_conflicts()
                for challenge in challenges:
                    await self.send_message(challenge)
            
            rounds += 1
            await asyncio.sleep(0.1)  # 避免CPU空转
        
        self.state = 'done'
        return analysis
    
    async def analyze(self, context: SharedContext) -> Dict:
        """各图腾的具体分析逻辑（子类实现）"""
        raise NotImplementedError
    
    async def identify_conflicts(self) -> List[AgentMessage]:
        """识别与其他Agent的潜在冲突（批判性思维）"""
        conflicts = []
        other_insights = self.context.accumulated_insights
        
        # 检查价值观冲突（孔子Agent示例）
        if self.id == 'confucius' and 'simon' in other_insights:
            simon_view = other_insights['simon']
            if simon_view.get('recommendation') == 'proceed' and self.ethical_score < 0.6:
                conflicts.append(AgentMessage(
                    sender=self.id,
                    receiver='simon',
                    message_type='challenge',
                    payload={
                        'issue': 'ethical_risk_ignored',
                        'severity': 'high',
                        'reason': '司马贺建议推进，但五常评估显示"信"维度不足0.6，存在伦理风险',
                        'proposed_resolution': '要求补充伦理尽调或设定观察期'
                    },
                    timestamp=datetime.now(),
                    correlation_id=self.context.decision_id
                ))
        
        return conflicts
    
    async def process_message(self, msg: AgentMessage) -> Optional[AgentMessage]:
        """处理收到的消息（响应挑战或支持）"""
        if msg.message_type == 'challenge' and msg.receiver == self.id:
            # 被挑战时：评估挑战有效性
            if self.evaluate_challenge(msg.payload):
                # 有效挑战：修正立场或提供解释
                return AgentMessage(
                    sender=self.id,
                    receiver=msg.sender,
                    message_type='acknowledge',
                    payload={'adjustment': 'partial', 'explanation': '...'}
                )
            else:
                # 无效挑战：坚持立场并提供论据
                return AgentMessage(
                    sender=self.id,
                    receiver=msg.sender,
                    message_type='defend',
                    payload={'reasoning': '...'}
                )
        return None

        else:

        final_output = await self.synthesize_output(
            analyses=analyses,
            resolution=resolution,
            context=context
        )
        
        return final_output

        """仲裁冲突（当共识度<0.8时触发）"""
        
        conflicts = context.conflict_register
        
        # 策略1：权重投票（基于客户画像偏好）

                    return {'decision': 'reject', 'authority': 'confucius', 'reason': 'ethical_red_line'}

        if context.consensus_level < 0.5:
            return {
                'decision': 'defer',
                'recommendation': 'require_more_info',
                'conflict_summary': self.summarize_conflicts(conflicts),
                'human_escalation': True  # 建议人工介入
            }
        
        return {'decision': 'weighted_consensus', 'weights': weights, 'score': weighted_votes}

class AgentStateManager:
    """管理Agent状态，支持故障恢复"""
    
    async def checkpoint(self, decision_id: str):
        """创建检查点（每30秒）"""
        context = self.context_store.get(decision_id)
        if not context:
            return
        
        checkpoint_data = {
            'timestamp': datetime.now(),
            'context': context,
            'agent_states': {
                agent_id: {
                    'state': agent.state,
                    'last_analysis': agent.last_analysis if hasattr(agent, 'last_analysis') else None
                }
                for agent_id, agent in self.agents.items()
            }
        }
        
        await self.persist_to_redis(f"checkpoint:{decision_id}", checkpoint_data, ttl=3600)
    
    async def recover(self, decision_id: str) -> Optional[SharedContext]:
        """从检查点恢复"""
        checkpoint = await self.load_from_redis(f"checkpoint:{decision_id}")
        if not checkpoint:
            return None
        
        # 恢复上下文
        self.context_store[decision_id] = checkpoint['context']
        
        # 通知各Agent恢复状态
        for agent_id, state_data in checkpoint['agent_states'].items():
            if agent_id in self.agents:
                self.agents[agent_id].state = state_data['state']
                if state_data['last_analysis']:
                    self.agents[agent_id].last_analysis = state_data['last_analysis']
        
        return checkpoint['context']

from enum import Enum

class SECIStage(Enum):
    SOCIALIZATION = "socialization"      # 隐性→隐性（对话、观察）
    EXTERNALIZATION = "externalization"  # 隐性→显性（结构化为文本/图表）
    COMBINATION = "combination"          # 显性→显性（关联、分类）
    INTERNALIZATION = "internalization"  # 显性→隐性（模型学习）

class SECIPipeline:
    """SECI知识转化管道"""
    
    def __init__(self):
        self.stages = {
            SECIStage.SOCIALIZATION: SocializationModule(),
            SECIStage.EXTERNALIZATION: ExternalizationModule(),
            SECIStage.COMBINATION: CombinationModule(),
            SECIStage.INTERNALIZATION: InternalizationModule()
        }
        self.knowledge_graph = Neo4jKnowledgeGraph()
        self.vector_store = PineconeVectorStore()
        
    async def process_interaction(self, interaction: DialogueInteraction):
        """处理一次对话交互（可能触发全流程）"""
        
        # 阶段1：社会化 - 捕获原始互动（总是执行）
        tacit_capture = await self.stages[SECIStage.SOCIALIZATION].capture(interaction)
        await self.store_raw_experience(tacit_capture)
        
        # 阶段2：外化 - 尝试提取结构化知识（如果互动包含洞察）
        if tacit_capture.contains_insight:
            explicit_knowledge = await self.stages[SECIStage.EXTERNALIZATION].extract(
                tacit_capture
            )
            kg_node_id = await self.knowledge_graph.add_explicit_knowledge(explicit_knowledge)
            
            # 阶段3：组合 - 关联现有知识（如果外化成功）
            if explicit_knowledge.is_valid:
                await self.stages[SECIStage.COMBINATION].integrate(
                    new_knowledge_id=kg_node_id,
                    graph=self.knowledge_graph
                )
                
                # 阶段4：内化 - 更新模型（如果组合产生新模式）
                if await self.detect_new_pattern(kg_node_id):
                    await self.stages[SECIStage.INTERNALIZATION].learn(
                        pattern=self.extract_pattern(kg_node_id),
                        vector_store=self.vector_store,
                        model_api=self.model_api
                    )

class SocializationModule:
    """捕获隐性知识（对话、非结构化数据）"""
    
    async def capture(self, interaction: DialogueInteraction) -> TacitKnowledge:
        """捕获对话中的隐性知识"""
        
        # 1. 记录完整对话（文本+元数据）
        raw_record = {
            'dialogue_id': interaction.id,
            'timestamp': interaction.timestamp,
            'participants': interaction.participants,
            'transcript': interaction.messages,
            'emotional_signals': self.extract_emotion(interaction.messages),
            'pause_patterns': interaction.timing_analysis,  # 停顿=思考深度
            'follow_up_questions': interaction.follow_ups  # 追问=兴趣点
        }
        
        # 2. 识别"洞察时刻"（Egbertie说"这个点很重要"或客户"啊哈"时刻）
        insight_moments = self.detect_insight_markers(interaction.messages)
        
        return TacitKnowledge(
            raw_record=raw_record,
            insight_moments=insight_moments,
            contains_insight=len(insight_moments) > 0
        )
    
    def detect_insight_markers(self, messages: List[Message]) -> List[Dict]:
        """检测对话中的洞察标记"""
        markers = []
        insight_keywords = ['关键点', '本质', '核心', '注意', '教训', '经验']
        
        for i, msg in enumerate(messages):
            if any(kw in msg.content for kw in insight_keywords):
                markers.append({
                    'message_idx': i,
                    'marker_type': 'explicit',
                    'context': messages[max(0,i-2):min(len(messages), i+3)]
                })
            
            # 隐式标记：长停顿后的短消息（顿悟表达）
            if msg.response_time > 30 and len(msg.content) < 50 and i > 0:
                markers.append({
                    'message_idx': i,
                    'marker_type': 'implicit_pause',
                    'pause_seconds': msg.response_time
                })
        
        return markers

class ExternalizationModule:
    """将隐性知识外化为结构化显性知识"""
    
    async def extract(self, tacit: TacitKnowledge) -> ExplicitKnowledge:
        """从对话中提取结构化知识"""
        
        # 使用LLM进行结构化提取（Prompt Engineering）
        extraction_prompt = f"""
        分析以下决策对话，提取结构化知识：
        
        对话内容：{tacit.raw_record['transcript']}
        洞察时刻：{tacit.insight_moments}
        
        请提取：
        1. 决策情境（Scenario）：行业、阶段、候选人类型
        2. 关键信号（Signals）：哪些具体行为/言语触发了判断
        3. 决策逻辑（Logic）：从信号到结论的推理链
        4. 行动建议（Action）：给出的具体建议
        5. 伦理考量（Ethics）：涉及的价值观判断
        6. 适用边界（Scope）：此经验适用的条件

class CombinationModule:
    """将新知识组合入现有知识体系"""
    
    async def integrate(self, new_knowledge_id: str, graph: Neo4jKnowledgeGraph):
        """关联新知识"""
        
        new_node = await graph.get_node(new_knowledge_id)
        
        # 1. 相似性关联（找到图谱中相似案例）
        similar_cases = await graph.find_similar(
            embedding=new_node.embedding,
            threshold=0.85,
            node_type='DecisionCase'
        )
        
        # 2. 因果关联（识别前置/后置条件）
        if new_node.context.get('outcome'):
            await graph.create_relationship(
                from_node=new_knowledge_id,
                to_nodes=[case.id for case in similar_cases if case.outcome == new_node.outcome],
                relation_type='SIMILAR_OUTCOME'
            )
        
        # 3. 模式泛化（提取通用模式）
        if len(similar_cases) >= 3:
            pattern = await self.generalize_pattern(new_node, similar_cases)
            pattern_node_id = await graph.add_pattern(pattern)
            
            await graph.create_relationship(
                from_node=pattern_node_id,
                to_node=new_knowledge_id,
                relation_type='INSTANCE_OF'
            )
        
        # 4. 矛盾检测（发现与现有知识的冲突）
        contradictions = await graph.find_contradictions(new_node)
        if contradictions:
            await self.flag_for_review(new_knowledge_id, contradictions)

class DataConsistencyPipeline:
    """确保多存储间数据一致性"""
    
    async def sync_interaction_to_graph(self, interaction_id: str):
        """将新互动同步到知识图谱"""
        
        # 1. 从PostgreSQL读取
        interaction = await pg_client.get_interaction(interaction_id)
        
        # 2. 提取实体（NER）
        entities = await nlp_service.extract_entities(interaction.messages)
        
        # 3. 写入Neo4j（案例节点）
        case_node_id = await neo4j_client.create_case({
            'source_interaction': interaction_id,
            'entities': entities,
            'embedding': await embedding_service.encode(interaction.messages)
        })
        
        # 4. 更新PostgreSQL（回写图谱ID）
        await pg_client.update_interaction(interaction_id, {
            'knowledge_graph_node_id': case_node_id
        })
        
        # 5. 异步写入向量库（用于检索）
        await pinecone_client.upsert(
            id=interaction_id,
            vector=await embedding_service.encode(interaction.summary),
            metadata={
                'case_node_id': case_node_id,
                'timestamp': interaction.timestamp.isoformat()
            }
        )
    
    async def handle_deletion_request(self, client_id: str):
        """处理客户删除请求（GDPR/隐私合规）"""
        
        # 1. 删除PostgreSQL中的PII（保留脱敏统计数据）
        await pg_client.anonymize_client_data(client_id)
        
        # 2. 删除S3中的原始文档
        await s3_client.delete_prefix(f"client-{client_id}/")
        
        # 3. 知识图谱中保留节点但断开与客户ID的链接（知识沉淀，身份脱敏）
        await neo4j_client.detach_client_identity(client_id)
        
        # 4. 删除向量库中的个人画像（保留通用模式）
        await pinecone_client.delete_by_filter({'client_id_hash': hash(client_id)})
        
        # 5. 审计日志
        await audit_log.record_deletion(client_id, timestamp=datetime.now())

class ApprovalQueue:
    """Egbertie审批队列"""
    
    def __init__(self):
        self.pending = []
        self.batch_size = 20  # 每批最多20项
        
    async def get_batch_for_review(self) -> ApprovalBatch:
        """获取待审批批次"""
        
        # 优先级排序
        sorted_items = sorted(
            self.pending, 
            key=lambda x: (x.priority, x.timestamp)
        )
        
        batch = sorted_items[:self.batch_size]
        
        return ApprovalBatch(
            items=batch,
            summary={
                'total_pending': len(self.pending),
                'by_category': self.categorize(batch),
                'estimated_review_time': len(batch) * 2  # 每项2分钟
            },
            quick_actions=self.suggest_batch_actions(batch)
        )
    
    def suggest_batch_actions(self, items: List[ApprovalItem]) -> List[BatchAction]:
        """建议批量操作（减少重复点击）"""
        
        # 检测相似项可批量批准
        similar_patterns = self.cluster_by_similarity(items)
        
        suggestions = []
        for cluster in similar_patterns:
            if cluster.similarity > 0.9 and cluster.risk_level == 'low':
                suggestions.append(BatchAction(
                    action='approve_all',
                    items=cluster.items,
                    reason='低风险且高度相似，建议批量批准'
                ))
        
        return suggestions

class SafetyGuardrails:
    """多层安全防护"""
    
    def __init__(self):
        self.layers = [
            InputSanitizer(),      # 层1：输入清洗
            BiasDetector(),        # 层2：偏见检测
            EthicalReviewer(),     # 层3：伦理审查
            UncertaintyQuantifier(), # 层4：不确定性量化
            OutputSanitizer(),     # 层5：输出审核
            AuditLogger()          # 层6：全程审计
        ]
    
    async def process_with_safety(self, request: DecisionRequest) -> SafeResponse:
        """带安全防护的处理流程"""
        
        current_data = request
        
        # 逐层通过防护
        for layer in self.layers:
            result = await layer.process(current_data)
            
            if result.status == 'blocked':
                # 被拦截：记录并升级
                await self.escalate_to_human(result, layer.name)
                return SafeResponse(
                    status='blocked',
                    reason=result.reason,
                    human_review_required=True
                )
            
            elif result.status == 'warning':
                # 警告：附加风险标签但继续
                current_data.risk_flags.append(result.warning)
            
            elif result.status == 'modified':
                # 被修正：使用修正后数据
                current_data = result.modified_data
        
        return SafeResponse(status='safe', data=current_data)

                    'historical_outcomes': anti_pattern.typical_outcomes,  # 通常灾难

        if temporal_taboo:
            violations.append(temporal_taboo)

            is_prohibited=len(violations) > 0,

            alternative_paths_suggested=await self.generate_safe_alternatives(decision_path, violations)
