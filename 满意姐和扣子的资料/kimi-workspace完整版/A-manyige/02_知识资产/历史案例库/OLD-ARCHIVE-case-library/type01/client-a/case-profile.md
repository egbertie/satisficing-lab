## 四、模拟训练脚本

### 场景: 新能源板块IPO前的权力博弈

**背景设定**：
- 李卫东主导的新能源板块准备科创板IPO
- 王志强要求地产板块同步注入资产
- 张子涵反对，认为会拖累估值
- PE投资人提出对赌条款

**角色分配**：
- 用户扮演：陈建华（董事长）
- AI扮演：王志强、李卫东、张子涵、PE代表

**决策点1：是否同意地产资产注入？**
- 王志强的论据："集团整体上市，不能厚此薄彼"
- 李卫东的论据："地产重资产会拖累新能源估值"
- 张子涵的论据："科技投资板块也会被波及"

**躯体信号触发点**：
- 当你感到"胸口发紧"时 → 可能是沉没成本谬误
- 当你"下意识维护老王"时 → 检查禀赋效应
- 当你"觉得女儿不懂事"时 → 警惕代际偏见

**72小时压力测试任务**：
1. 分别与三位合伙人单独深度沟通（各2小时）
2. 收集各方真实诉求（非表面立场）
3. 设计3套妥协方案
4. 进行沙盘推演，预测各方反应
5. 做出最终决策并承担后果
