# Type 5: 低位创始人与高位合伙人关系决策
## Client C - 创始人vs明星合伙人场景

---

## 一、客户数字替身档案

| 维度 | 内容 |
|------|------|
| **姓名** | 小陈（28岁） |
| **身份** | 连续创业失败者，第三次项目AI教育 |
| **高位合伙人** | 李教授（AI领域院士，60岁） |
| **关系** | 李教授技术入股30%，挂名首席科学家 |

### 核心痛点
1. **光环绑架**: 投资人只看李教授，小陈被边缘化
2. **决策僵局**: 李教授不常来公司，但重大事项必须他点头
3. **代沟冲突**: 李教授要"学术严谨"，小陈要"快速迭代"

---

## 二、躯体信号档案

**小陈的躯体语言**:
- 投资人会议：缩在角落，声音小 → 自卑
- 与李教授通话：频繁点头（电话那头看不见）→ 习惯性服从
- 独处时：锤桌子，摔手机 → 压抑的愤怒

**关键信号**:
> 小陈在团队面前说"李教授说了..."，私下说"那个老东西..."

**解读**: 公开场合依附权威，私下极度不满。

---

## 三、合伙人冲突诊断

### PFI评分

| 维度 | 小陈-李教授 | 危机阈值 |
|------|-------------|----------|
| **价值观契合** | 🔴 30 | <30 |
| **能力互补** | 🟢 80 | - |
| **权力平衡** | 🔴 20:80 | - |
| **沟通效率** | 🔴 20 | <30 |
| **信任基础** | 🟡 50 | - |

### 冲突焦点

**小陈的困境**:
- "没有李教授，我融不到资"
- "有了李教授，我像个傀儡"
- "我想证明我自己，但没人看我"

**李教授的视角**:
- "小陈太急躁，不尊重科学"
- "我挂名是帮他，他还抱怨"
- "我不在公司，但重大决策我要把关"

---

## 四、干预方案

### 第一步：重新定义角色

**与李教授谈判**:
```
角色分工
├── 李教授：首席科学家（技术方向+学术背书）
│   └── 决策范围：技术路线、学术合作、政府关系
│   └── 不参与：日常运营、产品迭代、团队管理
├── 小陈：CEO（全面运营）
│   └── 决策范围：产品、市场、融资、人事
│   └── 定期向李教授汇报（月度）

股权调整
├── 李教授：30% → 20%（技术入股）
├── 小陈：50% → 60%（创始人+运营）
└── 期权池：20%
```

### 第二步：建立小陈权威

**公开场合**:
- 李教授明确表态："小陈是CEO，我听他的"
- 投资人会议：小陈主讲，李教授压轴背书
- 媒体采访："年轻有为的创业者小陈"

**私下补偿**:
- 李教授获得：学术成果署名权、政府项目主导权
- 小陈获得：运营自主权、团队控制权

### 第三步：小陈心理建设

**躯体信号训练**:
- 每天对着镜子说："我是CEO，我值得被尊重"
- 记录自己的决策，增强自信
- 与李教授对话时，保持身体挺直

---

## 五、压力测试

### 场景1: 李教授不放手
**触发**: 李教授坚持审批所有支出  
**应对**:
- 明确协议：列出李教授的决策范围
- 引入独立董事：作为仲裁
- 最坏情况：股权回购，李教授退出

### 场景2: 投资人只认李教授
**触发**: 投资人要求李教授任董事长  
**应对**:
- 李教授拒绝："我只管技术，小陈管公司"
- 小陈提升：做出业绩，证明自己
- 股权稀释：引入新投资，平衡李教授影响力

### 场景3: 小陈崩溃
**触发**: 小陈抑郁，想放弃  
**应对**:
- 心理咨询
- 暂时调整：李教授多参与，小陈休息
- 长期考虑：寻找新CEO，小陈转产品

---

## 六、决策建议

### 核心问题：小陈能否摆脱李教授的光环？

**建议**: **支持小陈争取自主权**，但需要：

1. 与李教授明确分工（书面协议）
2. 小陈必须在6个月内做出独立业绩
3. 建立团队对小陈的忠诚（不是只认李教授）
4. 设置止损：如李教授不放手，考虑和平分手

### 躯体信号最终测试

**观察小陈与李教授下次对话**:
- 身体姿势：挺直 vs 蜷缩
- 眼神交流：直视 vs 躲避
- 声音：坚定 vs 颤抖

**评估**:
- 3项都正面 → 小陈在成长，继续支持
- 2项负面 → 需要更多心理建设
- 3项都负面 → 考虑小陈是否适合当CEO

## 七、诚实边界

**满意解边界**:
- ✅ 可提供合伙人分工框架
- ✅ 可提供权威建立建议
- ✅ 可提供躯体信号训练
- ❌ 无法改变李教授的态度
- ❌ 无法替小陈建立自信
- ❌ 无法保证投资人的行为

**建议**:
小陈需要先建立自己的价值，而不是依附李教授。
