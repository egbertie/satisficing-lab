# Type 5: 低位创始人与高位合伙人关系决策
## Client A - 案例模拟档案

---

## 一、客户数字替身档案

| 维度 | 内容 |
|------|------|
| **姓名** | 郑小雨（化名） |
| **年龄** | 29岁 |
| **身份** | 连续创业者，两次失败 |
| **当前项目** | AIGC内容生成工具 |
| **团队规模** | 8人 |
| **合伙人结构** | 郑小雨(CEO,35%) + 张总(行业大咖,40%) + 技术合伙人(15%) + 期权池(10%) |

### 权力不对等核心矛盾
| 维度 | 郑小雨 | 张总 |
|------|--------|------|
| 年龄 | 29岁 | 52岁 |
| 行业经验 | 4年 | 25年 |
| 过往成就 | 两次失败 | 一家上市公司 |
| 持股比例 | 35% | 40% |
| 董事会席位 | 1席 | 2席（含自己） |
| 资源网络 | 有限 | 顶级 |

### 核心痛点
- **话语权失衡**：张总习惯性"这是为你好"替郑小雨做决策
- **尊严受损**：投资人只认张总，郑小雨被当作"前台吉祥物"
- **成长受限**：张总不让郑小雨参与关键谈判，"你还太嫩"
- **身份危机**：自我怀疑"我真的配当CEO吗？"

## 二、权力不对等诊断书

```
张总的权力来源:                    郑小雨的反击资源:
├─ 法定权力（40%股权+董事会）      ├─ 正式职位（CEO）
├─ 专家权力（25年行业经验）         ├─ 信息权力（掌握日常运营细节）
├─ 参照权力（行业地位/人脉）        ├─ 关系权力（与技术合伙人联盟）
└─ 强制权力（资源控制）             └─ 个人权力（韧性/学习能力）
```

## 三、决策工具输出

### 工具1: 尊严守护协议

```
《CEO权威重建框架》
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【底线声明】（必须坚守）
1. 对团队的直接管理权不可让渡
2. 日常运营决策权不可让渡
3. 对外PR中CEO身份必须被尊重

【权力重构谈判要点】
- 董事会: 从2:1改为1:1:1（引入独立董事）
- 决策分级: 明确哪些决策CEO可独立做出
- 对外形象: 张总担任董事长，郑小雨担任CEO，双头对外

【尊严修复行动】
Week 1: 与合伙人一对一会谈，重申CEO角色
Week 2: 在团队面前展示决策能力（小型项目）
Week 3: 要求参与关键谈判，哪怕只是旁听
Week 4: 寻求外部导师支持（非张总圈子）
```

### 工具2: 权力重构路线图

| 阶段 | 目标 | 关键行动 | 时间 |
|------|------|----------|------|
| 生存期 | 守住底线 | 明确不可让渡的权力边界 | 0-30天 |
| 建设期 | 建立独立资源 | 培养直接汇报团队，减少依赖 | 1-3月 |
| 博弈期 | 重新谈判 | 引入新投资人，稀释张总股权+话语权 | 3-6月 |
| 平衡期 | 建立平等伙伴关系 | 董事会改组，决策机制重构 | 6-12月 |

### 工具3: 心理建设方案

**身份认知重塑**：
- "我的价值不在于比张总经验丰富"
- "我的价值在于：年轻/韧性/对新事物敏感/全职投入"
- "失败经历是财富，不是耻辱"

**躯体信号管理**：
- 当感到"被轻视"时：深呼吸，延迟反应24小时
- 当"自我怀疑"时：列出本周的3个正确决策
- 当"愤怒"时：转化为"我要证明给你看"的动力
