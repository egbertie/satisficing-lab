## 一、客户数字替身档案

| 维度 | 内容 |
|------|------|
| **姓名** | 马东（化名） |
| **年龄** | 45岁 |
| **身份** | 连续成功创业者（已退出2家公司） |
| **当前角色** | 天使投资人 + 新创公司联合创始人 |
| **投资型公司** | 持有5家初创公司股权 |

### 双重身份冲突
| 场景 | 作为投资人 | 作为联合创始人 | 冲突 |
|------|-----------|---------------|------|
| 估值谈判 | 希望估值低，自己占股多 | 希望估值高，自己股权不被稀释 | 利益对立 |
| 资源分配 | 应该投给最有潜力的公司 | 优先支持自己参与的公司 | 公平性质疑 |
| 决策参与 | 应该放手让团队决策 | 作为联合创始人必须参与 | 角色模糊 |
| 退出选择 | portfolio整体回报最大化 | 这家公司必须成功 | 优先级冲突 |

## 二、双重利益防火墙

### 防火墙设计原则
```
《投资人与创始人双重身份治理》
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【原则1: 信息披露】
- 向所有相关方披露双重身份
- 每次决策前主动声明潜在利益冲突
- 建立"利益冲突日志"，记录所有相关决策

【原则2: 角色分离】
- 投资人会议 ≠ 联合创始人会议
- 投资人帽子 ≠ 创始人帽子
- 物理分离：不同邮箱、不同日历、不同决策记录

【原则3: 回避机制】
- 涉及自身利益的决策必须回避
- 由独立董事/其他合伙人代为决策
- 重大利益冲突需合伙人会议表决

【原则4: 公平优先】
- 当无法确定时，默认选择对"公司"最有利的选项
- 而非对"马东个人"最有利的选项
```

## 三、决策工具输出

### 工具1: 身份切换仪式手册

| 场景 | 切换仪式 | 决策原则 |
|------|----------|----------|
| 参加被投公司会议 | 手机静音，开场声明"今天我是投资人" | 支持但不干预 |
| 参加联合创业公司会议 | 开场声明"今天我是联合创始人" | 全情投入，共担风险 |
| 涉及资源分配决策 | 回避投票，由其他合伙人决定 | 公平优先 |
| 涉及估值谈判 | 聘请独立顾问代表公司方 | 避免自我交易 |

### 工具2: 双重身份决策检查清单

每次决策前自问：
- [ ] 我现在戴的是哪顶帽子？
- [ ] 这个决策是否对我个人有特殊利益？
- [ ] 其他合伙人知道这个利益冲突吗？
- [ ] 如果我是其他合伙人，会觉得公平吗？
- [ ] 有没有更公平的替代方案？

**如果以上任一答案为"是"或"不确定"**：
- 披露冲突
- 回避决策
- 寻求独立意见
