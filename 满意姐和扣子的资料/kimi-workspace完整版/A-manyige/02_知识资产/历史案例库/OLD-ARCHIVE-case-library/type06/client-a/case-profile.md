## 三、决策工具输出

### 工具1: 打磨期状态管理方案

```
《TRL 7-8合伙人韧性管理》
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【生理韧性】
- 强制休假制度：核心合伙人每2个月必须休3天
- 躯体信号监测：每周五下午15分钟"状态check-in"
- 睡眠底线：连续熬夜不超过3天

【情绪韧性】
- "红温"预警：当合伙人声音提高/语速加快时暂停讨论
- 情绪记录：记录引发强烈情绪的事件，寻找模式
- 外部支持：每位合伙人配备独立导师（非公司顾问）

【认知韧性】
- 每周"最坏情况"演练：如果这个项目失败，Plan B是什么？
- 认知重构：从"必须成功"到"即使失败也有收获"
- 信息透明：所有坏消息必须在24小时内共享

【关系韧性】
- 合伙人契约重签：明确打磨期的角色、责任、退出机制
- 冲突解决机制：约定"如果吵到第3次，引入调解人"
- 定期关系评估：每月1次PFI评分卡快速评估
```
