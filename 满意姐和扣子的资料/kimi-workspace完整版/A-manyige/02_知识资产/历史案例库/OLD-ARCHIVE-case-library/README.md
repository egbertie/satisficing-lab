## 一、案例库架构

### 1.1 存储结构

```
case-library/
├── README.md                    # 案例库总览
├── taxonomy/                    # 分类体系
│   ├── by-industry.md          # 按行业分类
│   ├── by-stage.md             # 按创业阶段分类
│   ├── by-challenge.md         # 按核心挑战分类
│   └── by-outcome.md           # 按结果分类
├── cases/                       # 案例目录
│   ├── CASE-001-xxx/           # 每个案例独立目录
│   │   ├── profile.md          # 案例档案
│   │   ├── timeline.md         # 时间线
│   │   ├── decisions/          # 关键决策点
│   │   ├── analysis/           # 深度分析
│   │   └── lessons.md          # 经验教训
│   └── ...
├── templates/                   # 模板
│   ├── case-profile-template.md
│   ├── decision-record-template.md
│   └── simulation-script-template.md
└── simulations/                 # 模拟演练
    ├── sim-001-xxx.md
    └── ...
```

### 1.2 案例档案标准格式

每个案例必须包含以下模块：

| 模块 | 必需 | 说明 |
|------|------|------|
| **基础信息** | ✅ | 行业、阶段、团队规模、融资情况 |
| **合伙人背景** | ✅ | 每位合伙人的履历、专长、角色 |
| **匹配挑战** | ✅ | 面临的核心合伙人匹配问题 |
| **决策过程** | ✅ | 如何做出合伙人选择/调整决策 |
| **结果** | ✅ | 成功/失败，关键数据 |
| **深度分析** | ✅ | 三维度评估、满意解分析 |
| **模拟脚本** | ✅ | 可复现的决策模拟演练 |

## 三、产品资料准备标准

每个案例类型的"产品资料"包含：

### 3.1 类型定义文档
- 类型名称与定义
- 典型场景描述
- 核心痛点分析
- 决策关键要素

### 3.2 参考案例清单
- 该类型的典型案例（公开信息）
- 案例来源与引用
- 可学习的关键点

### 3.3 模拟场景设计
- 虚拟公司背景
- 合伙人候选人档案（3-5人）
- 决策情境设定
- 预期决策路径

### 3.4 评估工具
- 三维度评估表（该类型定制版）
- 雷达图模板
- 满意解决策检查清单
