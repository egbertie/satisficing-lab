## 一、客户数字替身档案

| 维度 | 内容 |
|------|------|
| **姓名** | 徐晓峰（化名） |
| **年龄** | 39岁 |
| **项目** | 生物医药CDMO |
| **股权结构** | 徐晓峰(35%) + 联合创始人A(20%) + 联合创始人B(15%) + 投资人A(15%) + 投资人B(15%) |

### 控制权焦虑核心
- **最大股东但不是绝对控股**：任何两方联合就能否决徐晓峰的决策
- **董事会席位**：5席中徐晓峰只有2席（自己+一位联合创始人）
- **关键决策历史**：2次重大决策被投资人联合否决
- **心理影响**：开始过度防御，不信任任何合伙人

## 二、小股比防御性治理方案

### 控制权工具箱

| 工具 | 应用场景 | 实施难度 | 效果 |
|------|----------|----------|------|
| **AB股设计** | 融资前设定 | 中 | ★★★★★ |
| **一致行动人协议** | 与联合创始人联合 | 低 | ★★★★☆ |
| **超级投票权事项** | 章程约定 | 中 | ★★★★☆ |
| **董事会提名权** | 投资协议谈判 | 高 | ★★★☆☆ |
| **金色降落伞** | 创始人保护 | 中 | ★★★☆☆ |

### 徐晓峰可用策略

```
【策略组合】
1. 与联合创始人A签署一致行动人协议
   - 联合持股55%，形成绝对控制
   - 约定重大决策前协商，对外统一投票

2. 章程约定超级投票权事项
   - 以下事项需2/3以上表决权通过：
     * CEO任免
     * 公司出售/合并
     * 核心知识产权转让
     * 章程修改

3. 董事会层面
   - 争取独立董事提名权
   - 关键委员会（审计/薪酬）主席由创始人指定
```

## 三、决策工具输出

### 工具1: 控制权焦虑管理手册

**认知重构**：
- "控制≠控股"：阿里马云持股<5%，仍有控制权
- "控制是通过规则实现的，不是股权比例"
- "过度控制会赶走优秀合伙人和投资人"

**实用 checklist**：
- [ ] 是否有一致行动人协议？
- [ ] 章程中是否有超级投票权条款？
- [ ] 董事会中是否有可信赖的盟友？
- [ ] 是否有"金色降落伞"保护？
- [ ] 关键员工是否绑定（竞业+期权）？

### 工具2: 防御性治理条款库

```
【条款1: 创始人否决权】
以下事项未经创始人书面同意不得执行：
- 修改创始人享有的权利
- 出售公司全部或实质性资产
- 变更主营业务

【条款2: 创始人回购权】
若创始人被无故罢免CEO职务，有权以账面净资产价格回购公司

【条款3: 信息权】
创始人有权获得公司所有财务和经营信息，不受持股限制

【条款4: 反稀释保护】
创始人股权享有与其他股东同等的反稀释保护
```
