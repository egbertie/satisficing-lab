# Client B 套 - 差异化案例概要
## Type 4-12 快速档案

---

### Type 4: 项目转型期
**客户**: 张伟 - 传统出版社 → 知识付费平台  
**与A差异**: 不是业务萎缩被迫转型，而是主动寻求增长  
**核心痛点**: 老团队文化（慢/稳） vs 新业务要求（快/试错）  
**工具输出**: 文化冲突解决框架、老团队安置方案

---

### Type 5: 低位创始人与高位合伙人
**客户**: 小林 - 25岁，连续失败2次，第三次AI项目  
**与A差异**: 合伙人不是"大咖"而是"大机构"（某巨头战略投资部派驻）  
**核心痛点**: 机构意志 vs 创业灵活性，董事会议程被机构主导  
**工具输出**: 机构合伙人谈判框架、自主权保护条款

---

### Type 6: 产品成型打磨期
**客户**: 王博士 - 脑机接口设备，从实验室到产品  
**与A差异**: 学术背景创始人，缺乏产品化经验  
**核心痛点**: 学术追求（完美） vs 商业现实（时间/成本）  
**工具输出**: 学术创始人产品化转型辅导、产学研合伙人协调

---

### Type 7: 创业次年
**客户**: 刘洋 - 跨境电商，3位大学同学合伙  
**与A差异**: 平等合伙人结构（各33%），无明确CEO  
**核心痛点**: 决策僵局，"谁都不愿意当坏人"  
**工具输出**: 轮值CEO制度、平等合伙人决策机制

---

### Type 8: 关系定位
**客户**: 陈晨 - 设计师背景创始人，与技术合伙人"同居式创业"  
**与A差异**: 办公场地混在一起，公私边界模糊  
**核心痛点**: "我们一起创业"变成"我们什么时候分手"  
**工具输出**: 公私边界设定、创业公司"离婚协议"模板

---

### Type 9: 创始人与技术合伙人
**客户**: 马总 - 50岁传统行业老板，跨界科技  
**与A差异**: 年龄代沟 + 行业代沟双重鸿沟  
**核心痛点**: "我不懂技术，但我怕被骗" vs "老板不懂还爱瞎指挥"  
**工具输出**: 非技术创始人技术管理指南、信任建立机制

---

### Type 10: 资源型合伙人
**客户**: 阿杰 - 网红创始人，资源型合伙人是"流量主"  
**与A差异**: 资源是"流量"而非"政府关系"，可量化但易衰减  
**核心痛点**: 流量主要求股权越来越多，但流量在下降  
**工具输出**: 流量对赌协议、动态资源评估模型

---

### Type 11: 非绝对控股
**客户**: 三位海归博士联合创业，各30%  
**与A差异**: 不是"创始人小股比"而是"三位平等创始人"  
**核心痛点**: 没有人有最终决定权，陷入"学术式讨论"  
**工具输出**: 博士团队决策机制、学术讨论 vs 商业决策区分

---

### Type 12: 投资型创始人
**客户**: 老李 - 成功退出后做天使投资，投了10+公司  
**与A差异**: 不是"投资+创业"而是"投资成为主业，创业是偶尔参与"  
**核心痛点**: portfolio管理 vs 深度参与的单公司冲突  
**工具输出**: 天使投资人时间管理、portfolio优先级框架
