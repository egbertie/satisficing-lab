# Type 2: 第三次再创业创始人项目
## Client C - 破产重启场景

---

## 一、客户数字替身档案

| 维度 | 内容 |
|------|------|
| **姓名** | 老周（58岁） |
| **身份** | 两次创业失败，负债3000万，第三次AI创业 |
| **前两次失败** | 第一次（O2O，2015，烧光2亿）| 第二次（共享办公，2019，疫情倒闭） |
| **当前项目** | AI养老服务机器人 |
| **合伙人** | 前两次的CFO老王（追债中）+ 新拉的技术合伙人小李 |

### 与Client A/B的核心差异
| 维度 | Client A（王建国） | Client B（李明） | Client C（老周） |
|------|-------------------|------------------|-----------------|
| 年龄 | 45岁 | 36岁 | **58岁（临近退休）** |
| 资金 | 有积蓄 | 有资产 | **负债3000万** |
| 合伙人 | 可信朋友 | 可转化供应商 | **前合伙人追债** |
| 心理状态 | 东山再起 | 背水一战 | **赌徒心态+恐惧** |

### 核心痛点
1. **信誉破产**: 前两次投资人拉黑，无法融资
2. **合伙人矛盾**: 老王要求先还债再合作，小李担心被拖累
3. **年龄焦虑**: "这是我最后一次机会"

## 二、躯体信号档案

### 老周的躯体语言
| 场景 | 信号 | 解读 |
|------|------|------|
| 提及前两次失败 | 右手握拳，指节发白 | 压抑的愤怒/不甘 |
| 谈及老王 | 左肩下沉，叹气 | 愧疚+无奈 |

| 深夜独处 | 失眠，早醒 | 焦虑+恐惧 |

### 关键躯体信号
> 老周说"这次不一样"时，**右手不自觉地摸向口袋里的安眠药**。

**解读**: 表面自信，内心极度焦虑。身体知道真相。

## 三、合伙人冲突诊断

### 三方博弈

```
老周（创始人）
    ↕️ 债务纠纷
老王（前CFO，现债权人）
    ↕️ 不信任
小李（新技术合伙人）
    ↕️ 担心被坑
老周
```

### PFI评分（当前 vs 理想）

| 维度 | 老周-老王 | 老周-小李 | 危机阈值 |
|------|-----------|-----------|----------|
| **价值观契合** | 🔴 20 | 🟡 60 | <30 |
| **能力互补** | 🟡 70 | 🟢 80 | - |
| **信任基础** | 🔴 10 | 🟡 50 | <20 |
| **利益平衡** | 🔴 0 | 🟡 60 | - |

### 冲突焦点

**老王视角**:
- "老周欠我300万工资+投资款"
- "他说新项目赚钱就还我，我不信"
- "要么先签还款协议，要么我起诉"

**小李视角**:
- "技术我出，但老周没钱"
- "老王整天催债，影响我心态"
- "我要占大股，不然风险太大"

**老周视角**:
- "老王是我兄弟，应该再信我一次"
- "小李技术牛，但不懂商业"
- "我必须控股，不然我没动力"

## 四、干预方案

### 第一步：债务隔离（紧急）

**方案**: 债务与股权分离
```
新公司架构
├── 老周：51%（技术+经验入股）
├── 小李：34%（技术入股）
├── 老王：10%（债权转股）
└── 期权池：5%

债务处理
├── 老王债权：200万转新公司股权，100万延期2年
├── 其他债权人：分期还款计划
└── 老周个人担保：新项目收入优先还债
```

### 第二步：信任重建

**对老王**:
- 老周手写道歉信+还款承诺
- 每月财务透明报告
- 老王委派财务观察员

**对小李**:
- 技术入股估值独立评估
- 设置对赌：产品上线后调整股权
- 老周个人担保小李最低收益

### 第三步：躯体信号训练

**老周必须每天记录**:
1. 今天说了几次"这次不一样"？
2. 失眠了吗？几点睡的？
3. 有没有想放弃的念头？
4. 身体哪里不舒服？

**触发条件**: 
- 连续3天失眠 → 暂停决策，先调心态
- 说"这次不一样">5次/天 → 警惕赌徒心态

## 五、压力测试

### 场景1: 老王起诉
**触发**: 老王等不及，冻结老周资产  
**应对**:
- 紧急谈判，提高转股比例
- 寻求第三方担保
- 最坏情况：老周出局，小李接手

### 场景2: 小李退出
**触发**: 小李拿到大厂offer  
**应对**:
- 提高股权+现金补偿
- 设置竞业限制
- 寻找替代技术合伙人

### 场景3: 产品失败
**触发**: MVP测试数据不佳  
**应对**:
-  pivot or persevere决策
- 老周必须接受"可能没有第四次"
- 心理退出机制

## 六、决策建议

### 核心问题：老周是否应该第三次创业？

**司马贺满意解评估**:
- ✅ 行业经验（养老+AI）
- ✅ 失败教训（O2O/共享办公的坑）
- ❌ 信誉破产
- ❌ 合伙人关系复杂
- ❌ 年龄/身体压力

**建议**: **谨慎支持**，但需满足以下条件：

1. **债务隔离完成**（法律层面）
2. **合伙人协议签署**（老王转股+小李对赌）
3. **老周完成心理评估**（确认非赌徒心态）
4. **设置止损线**（6个月无进展即退出）

### 躯体信号最终测试

**问老周**: "如果这次又失败了，你怎么办？"

| 回答 | 解读 | 建议 |
|------|------|------|
| "不可能失败" | 赌徒心态 | ❌ 不建议支持 |
| "我可以接受" | 理性评估 | ✅ 支持 |
| "我不知道" | 逃避 | ⚠️ 需心理干预 |
| "我会死" | 极度危险 | ❌ 强烈反对 |
