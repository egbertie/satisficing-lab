# Client C 套 - 极端/边界案例概要
## Type 1-12 快速档案

---

### Type 1: 多元化集团 - 家族内斗
**客户**: 香港某家族，四兄弟各25%，父亲去世无遗嘱  
**极端点**: 无单一控制人，完全的集体决策 paralysis  
**工具输出**: 家族宪法制定、信托架构设计、家族理事会机制

---

### Type 2: 第三次再创业 - 破产重组后
**客户**: 老周 - 第二次创业破产，负债2000万，个人破产清算中  
**极端点**: 法律限制 + 信用破产 + 心理创伤三重打击  
**工具输出**: 破产创业者重启指南、信用重建路径、心理康复方案

---

### Type 3: 项目升级期 - 收购整合
**客户**: 某独角兽收购3家小公司后的整合  
**极端点**: 不是内部合伙人问题，而是"强制合伙人关系"（被收购方创始人）  
**工具输出**: 收购后整合 playbook、被收购方创始人留任激励

---

### Type 4: 项目转型期 - 被迫转型（政策）
**客户**: K12教育公司，双减政策下必须在30天内转型  
**极端点**: 时间压力极端 + 团队恐慌 + 现金流断裂边缘  
**工具输出**: 危机转型72小时行动清单、团队紧急沟通话术

---

### Type 5: 低位创始人 - 明星合伙人
**客户**: 素人创始人 + 一线明星合伙人（流量入口）  
**极端点**: 权力不对等达到极致，明星一句话可决定公司生死  
**工具输出**: 明星合伙人协议特殊条款、风险分散策略

---

### Type 6: 产品成型期 - 生死线
**客户**: 医疗AI公司，产品出bug导致临床试验暂停，FDA警告  
**极端点**: 生死存亡 + 监管压力 + 团队恐慌  
**工具输出**: 危机响应SOP、监管沟通策略、团队信心重建

---

### Type 7: 创业次年 - 联合创始人突然去世
**客户**: 夫妻店创业，丈夫突然去世，妻子独自面对  
**极端点**: 情感创伤 + 法律混乱（股权继承）+ 经营压力  
**工具输出**: 合伙人意外应对预案、股权继承法律框架、哀伤辅导

---

### Type 8: 关系定位 - 离婚影响
**客户**: 联合创始人夫妻离婚，各自带走一半团队  
**极端点**: 私人关系破裂公开化，公司面临分裂  
**工具输出**: 创始人离婚影响评估、公司分割协议、团队稳定方案

---

### Type 9: 技术合伙人 - 核心代码归属争议
**客户**: CTO声称核心代码是他个人知识产权，非公司资产  
**极端点**: 知识产权纠纷 + 技术绑架 + 投资人恐慌  
**工具输出**: IP归属争议解决、代码托管机制、预防性IP协议

---

### Type 10: 资源型合伙人 - 资源被收回
**客户**: 资源型合伙人离职后，带走所有客户资源  
**极端点**: 资源不是"公司资产"而是"个人关系"，离职即归零  
**工具输出**: 客户关系公司化机制、资源型合伙人退出条款

---

### Type 11: 非绝对控股 - 恶意收购威胁
**客户**: 创始人持股40%，遭遇恶意收购要约  
**极端点**: 外部威胁 + 内部合伙人站队不明  
**工具输出**: 反恶意收购防御机制、合伙人忠诚协议、白衣骑士策略

---

### Type 12: 投资型创始人 - 利益输送指控
**客户**: 创始人同时管理的基金被指控利益输送  
**极端点**: 法律风险 + 声誉危机 + 多重合伙人关系同时破裂  
**工具输出**: 合规防火墙、独立调查配合、危机公关策略

---
