# Type 4: 项目转型期合伙人关系决策
## Client A - 案例模拟档案

---

## 一、客户数字替身档案

| 维度 | 内容 |
|------|------|
| **姓名** | 吴丽娜（化名） |
| **年龄** | 38岁 |
| **项目** | 线下教育培训机构 → 转型在线教育 |
| **转型触发** | 疫情+双减政策，原业务萎缩70% |
| **团队规模** | 从200人裁员到40人 |
| **合伙人结构** | 吴丽娜(CEO,55%) + 联合创始人(20%) + 投资人(25%) |

### 核心痛点
- **方向分歧**：联合创始人坚持保留线下业务，吴丽娜想All in线上
- **信任崩塌**：裁员过程中，联合创始人质疑吴丽娜"冷血"
- **资源争夺**：剩余现金如何使用，双方立场对立
- **身份焦虑**：从"成功女企业家"到"转型求生者"的心理落差

**当前评估**：
- 价值对齐：否（方向分歧）

**初步结论**：分手概率高，需设计和平分手方案

## 三、决策工具输出

### 工具1: 转型能力Gap分析

| 能力维度 | 吴丽娜(CEO) | 联合创始人 | 转型要求 |
|----------|------------|-----------|----------|
| 线上产品思维 | 60 | 40 | 80 |
| 互联网运营 | 55 | 35 | 85 |
| 技术理解 | 50 | 30 | 70 |
| 资本运作 | 70 | 45 | 75 |

**结论**：两人在新赛道能力均有显著Gap

### 工具2: 和平分手协议框架

```
《合伙人退出协议》
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【股权回购】
- 回购价格: 最近一轮估值 × 80% × 20%股权
- 支付方式: 30%现金 + 70%分3年支付
- 担保措施: 公司营收优先用于支付回购款

【竞业限制】
- 限制期: 2年
- 限制范围: 在线教育K12赛道
- 补偿: 每月2万元

【客户资源】
- 原线下客户资源归公司
- 联合创始人不得主动联系
- 过渡期6个月联合维护

【品牌声誉】
- 双方对外统一口径：战略方向分歧，和平分手
- 禁止相互诋毁
- 保留双方为公司贡献的公开认可
```
