## 一、客户数字替身档案

| 维度 | 内容 |
|------|------|
| **姓名** | 杨波（化名） |
| **年龄** | 37岁 |
| **项目** | 智慧城市解决方案 |
| **资源型合伙人** | 老马（前政府官员，退休） |
| **股权结构** | 杨波(60%) + 技术合伙人(20%) + 老马(10%) + 期权池(10%) |

### 老马承诺的资源
- **政府关系**：承诺帮助拿到3个城市的智慧交通项目
- **客户资源**：承诺介绍5家国企客户

### 现实情况（12个月后）
- 政府关系：只促成1个小项目，且回款困难
- 客户资源：介绍3家，但都没有成交
- 资质支持：没有任何进展
- **新问题**：老马开始干预公司日常管理，以"我经验多"为由

## 二、资源验真报告

### 72小时资源验真测试（应在合作前完成）

| 承诺资源 | 验真方法 | 72小时测试内容 | 实际结果 |
|----------|----------|----------------|----------|
| 政府关系 | 要求安排与相关领导非正式会面 | 能否在3天内安排？ | ❌ 未能安排 |
| 客户资源 | 要求提供客户名单并允许直接联系 | 能否提供真实联系方式？ | ⚠️ 提供但拒绝直接联系 |
| 资质支持 | 要求提供资质申请路径文档 | 能否提供具体流程？ | ❌ 只有口头描述 |

### 资源对价评估模型

```
资源价值 = 承诺价值 × 可信度系数 × 时间折扣

老马案例:
- 承诺价值: 3000万订单
- 可信度系数: 30%（验真测试结果）
- 时间折扣: 50%（12个月无实质进展）
- 实际价值: 3000万 × 30% × 50% = 450万

股权对价: 10%股权
假设公司估值5000万 → 股权价值500万

结论: 500万股权换取450万资源 → 基本合理，但风险在于"承诺未兑现"
```

## 三、决策工具输出

### 工具1: 资源型合伙人协议框架

```
《资源对赌协议》
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【股权结构】
- 基础股权: 5%（立即授予）
- 业绩股权: 最高5%（对赌解锁）

【对赌条款】
- 政府项目落地: 每1000万合同额解锁1%
- 客户成交: 每500万回款解锁1%
- 资质获批: 关键资质获批解锁1%

【退出机制】
- 12个月内无任何资源落地: 公司以1元回购5%基础股权
- 资源方主动退出: 已解锁股权保留，未解锁股权作废

【管理边界】
- 资源方不参与日常经营决策
- 可参与战略讨论，无投票权
- 每季度向董事会汇报资源落地进展
```

### 工具2: 资源合伙人预警信号

| 信号 | 含义 | 应对 |
|------|------|------|
| "关系还在疏通"超过3个月 | 资源可能不存在或不够硬 | 启动对赌条款 |
| 拒绝具体验真测试 | 资源真实性存疑 | 重新谈判股权 |
| 开始干预日常管理 | 角色边界模糊 | 明确管理边界 |
| 要求更多股权 | 对当前对价不满 | 评估实际贡献后决定 |
