# blackboard-manager Skill 设计文档

**Skill名称**: blackboard-manager  
**功能**: 共享内存状态管理，Worker间状态共享  
**版本**: 1.0.0  
**状态**: ✅ **FIN**（7/7测试通过，可生产使用）  
**依赖**: checkpoint-manager（状态持久化）

---

## S1: 输入定义

### 功能需求
- Worker间状态共享（通过Blackboard模式）
- 状态读写（键值对形式）
- 状态版本控制（乐观锁）
- 状态订阅/通知（变更时通知订阅者）

### 输入数据
- 状态键（字符串）
- 状态值（任意JSON序列化对象）
- Worker ID（谁写入的）
- 版本号（乐观锁）

---

## S2: 处理流程

### Blackboard模式
```
┌─────────────────────────────────────┐
│           Blackboard                │
│  ┌─────────┐ ┌─────────┐           │
│  │ Worker1 │ │ Worker2 │ ...       │
│  └────┬────┘ └────┬────┘           │
│       │           │                 │
│       └─────┬─────┘                 │
│             ▼                       │
│    ┌─────────────────┐              │
│    │  Shared Memory  │              │
│    │  (YAML文件)     │              │
│    └─────────────────┘              │
└─────────────────────────────────────┘
```

### 核心流程
1. **写入状态**: 验证版本 → 写入新值 → 更新版本 → 通知订阅者
2. **读取状态**: 获取当前值 + 版本号
3. **订阅状态**: 注册回调，状态变更时触发
4. **持久化**: 定期保存到检查点

---

## S3: 输出定义

### 成功输出
- 状态写入成功（返回新版本号）
- 状态读取成功（返回值+版本）
- 订阅注册成功

### 失败处理
- 版本冲突：返回冲突错误，提供当前版本
- 序列化失败：返回错误，不写入
- 存储失败：回滚变更

---

## S4: 自动化集成

### 集成点
- 被 worker-orchestrator 调用（Worker状态共享）
- 调用 checkpoint-manager（状态持久化）
- 被 hibernation-protocol 调用（休眠前保存）

### 触发条件
- Worker任务开始/结束（状态更新）
- 定期自动保存（每5分钟）
- Token<20%时（立即保存）
