## 六、具体改进建议（细化到行动）

### 6.1 针对安全问题的SOP

**写入任何文件前的检查清单**：
```
☐ 是否包含Token/密钥？→ 替换为[REDACTED]
☐ 是否包含密码？→ 替换为****
☐ 文件权限是否600？→ chmod 600
☐ 是否需Git提交？→ 检查pre-commit钩子
☐ 敏感信息是否进Git历史？→ 用git-filter-branch检查
```

### 6.2 针对执行边界的SOP

**"立即执行"前的确认流程**：
```
1. 列出要执行的具体任务（1/2/3...）
2. 预估Token消耗
3. 列出可能的风险
4. 等待用户回复"确认"或"修改"
5. 执行后汇报结果
```

### 6.3 针对Token效率的SOP

**长文档输出策略**：
```
<5,000字：单次输出
5,000-15,000字：分2-3次输出
>15,000字：必须先询问用户"是否分页输出"
```
