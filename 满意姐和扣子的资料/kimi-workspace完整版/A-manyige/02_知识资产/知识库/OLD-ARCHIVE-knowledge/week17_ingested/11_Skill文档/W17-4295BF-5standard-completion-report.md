## S6: 认知谦逊 (Epistemic Humility)

### 认知状态标注

所有担忧项必须标注认知状态：

| 状态 | 含义 | 示例 |
|------|------|------|
| **KNOWN** | 已验证的事实 | "磁盘使用率85%"(已查系统) |
| **INFERRED** | 基于数据的合理推断 | "月底可能耗尽"(趋势推算) |
| **UNKNOWN** | 信息不足的假设 | "第三方可能调整"(无证据) |

### 黑天鹅事件警告

系统明确声明以下局限：

```
⚠️ 【认知谦逊声明 - 黑天鹅事件】

1. 不可预测性
   - 系统只能基于已知模式识别担忧
   - 真正改变游戏规则的事件(黑天鹅)无法提前预警
   - 例如：突发政策变化、技术颠覆、市场崩溃等

2. 认知盲区
   - 我们不知道自己不知道什么(未知的未知)
   - 过度依赖历史数据可能错过新型风险

3. 建议
   - 保持警觉，不要完全依赖自动化系统
   - 定期进行人工风险评估
   - 请记住：没有预警≠没有风险
```

### 查看警告

```bash
python3 scripts/worry_runner.py warning
```
