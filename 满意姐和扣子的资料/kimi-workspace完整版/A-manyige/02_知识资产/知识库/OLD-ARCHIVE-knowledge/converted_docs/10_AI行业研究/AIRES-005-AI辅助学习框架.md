## 核心洞察

### AI时代学习公式
> **学习 = AI负责80%的低效环节 + 人负责20%的不可替代环节**

### 80% AI负责
- 选型、内容生产、出题、重复练习、知识检索

### 20% 人负责
- 理解、判断、经验注入、验证纠错

### 六步学习链路

| 步骤 | 工具 | 作用 |
|------|------|------|
| 1. 选型决策 | Claude Opus | 多维度匹配 |
| 2. 认知概览 | Gemini NotebookLM | AI对话播客，全局框架 |
| 3. 定制课程 | Claude Opus | 30天学习安排 |
| 4. 多模态输入 | Claude Code + Remotion | 文档→视频→练习 |
| 5. 实战陪练 | OpenClaw | 7×24陪练Agent |
| 6. 验证纠错 | 双AI交叉 | 检验学习成果 |

### 四层产物模型
同一知识点，四种认知模态同时编码：
- 阅读材料
- 讲解视频
- 动手练习
- 纠错反馈

> 认知科学「多模态编码」——记忆留存率从10%拉到75%
