## 核心洞察

### 安装流程
两步安装，零门槛：
1. 发送安装提示词给Agent
2. 配置Key（AI自动完成剩余配置）

### 核心功能

| 功能 | 操作 |
|------|------|
| 上传PDF到知识库 | 本地PDF自动上传 |
| 上传网页链接 | URL自动抓取入库 |
| 上传本地笔记 | Obsidian笔记同步 |
| 智能问答 | 直接对知识库提问 |

### 痛点解决
> Obsidian本地优先理念在对外分享上偏弱。有了ima-skill后，知识管理流程的最后一公里路被打通了。

**完整工作流**:
- 灵感收集 → Agent处理 → ima知识库
- 创作回顾 → 深度探讨 → Agent辅助
- 对外分享 → 知识库链接 → 他人访问

### 自动化思路
设置任务：知识库文件夹有更新时，自动同步到ima知识库。
