## S1: 输入定义

### 输入类型
- **任务创建**: 标题、描述、优先级、截止日期
- **任务更新**: 状态变更、进度更新、备注添加
- **任务查询**: 按状态/优先级/时间筛选
- **任务提醒**: 到期提醒、逾期告警

### 输入格式
```yaml
todo:
  action: create|update|list|delete|remind
  title: string
  description: string
  priority: P0|P1|P2|P3
  due_date: YYYY-MM-DD
  status: todo|doing|done|blocked
```

---

## S2: 处理流程

### 核心功能

| 功能 | 描述 | 存储位置 |
|------|------|----------|
| `create` | 创建新任务 | `memory/todos/` |
| `update` | 更新任务状态 | 原地更新 |
| `list` | 列出任务 | 按筛选条件 |
| `delete` | 删除任务 | 归档到`archive/` |
| `remind` | 提醒机制 | Cron触发 |

### 处理步骤
1. **解析输入**: 提取任务参数
2. **验证**: 检查必填字段
3. **存储**: 写入JSON文件
4. **索引**: 更新任务索引
5. **提醒**: 设置Cron提醒

## S4: 自动化集成

### 触发方式
- **手动**: 用户指令
- **自动**: 每日09:00检查逾期任务
- **Cron**: 到期前1小时提醒

### 集成点
- 飞书/企微: 提醒推送
- 晨报: 任务摘要
- 驾驶舱: 任务统计
