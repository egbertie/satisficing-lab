## 二、追求层：人生红点

**人生红点 = 你的人生北极星**

一堂的核心信念：如果不知道要去哪里，所有的成长都只是在原地打转。

### 满意解映射
Egbertie 的人生红点已经通过多次对话被逐步清晰化：
- **使命**：帮助硬科技创始人在合伙人选择这一高风险决策点上提升胜率
- **愿景**：成为中国硬科技转化领域最值得信赖的合伙人匹配决策教练
- **价值观**：满意解、知行合一、儒商伦理、守护型陪伴

**检测标准**：每季度应问自己一次——"我现在做的事情，是否在接近人生红点？"

## 三、领先层：成长竞争力 6+1

### 3.1 六大竞争力

| 竞争力 | 一堂定义 | 满意解映射（Egbertie） |
|--------|----------|------------------------|
| **决策力** | 做正确选择的能力 | ⭐ **核心竞争力** — 22年双系统经验（银行严谨+创业洞察）+ CBIIP认证 |
| **学习力** | 快速吸收并应用新知识的能力 | 强 — 持续将一堂/儒商/脑科学/AI 方法论内化到代码资产 |
| **产品力** | 把需求转化为可交付价值的能力 | 构建中 — 从 SKU-A/B/C 产品定义到服务流程设计 |
| **领导力** | 影响他人、凝聚团队的能力 | 中上 — 儒商伦理框架 + 守护型陪伴风格 |
| **销售力** | 把价值传递给需要的人并成交的能力 | 待系统打磨 — 目前偏向内容获客和口碑转介绍 |
| **硬能力** | 某一领域的专业技术深度 | 强 — 金融分析（CFP/CFC/FAIAA）+ 软件工程（MSE） |

### 3.2 心力：核心能量

**心力是个人竞争力的放大器和压舱石。**

- 心力足的时候，决策更坚定，学习更持久，沟通更有感染力
- 心力枯竭的时候，所有能力都会打折

**满意解映射**：
- Egbertie 的睡眠优化、压力测试、能量治疗（陈国祥博士）都是为了保障心力可持续
- 满意姐的铁律：**人永远胜过流程**，当流程和人的状态冲突时，人胜出

## 五、三环关系：有驱动、有支撑、有空间

图的右侧用三个环标注了成长的环境条件：

- **有驱动**：人生红点提供方向感和内在驱动力
- **有支撑**：成长系统（时间管理/知识管理/科学成长/科学复盘）提供方法论支撑
- **有空间**：心力状态决定了你能承载多大的成长压力

**三者缺一不可**：
- 有驱动无支撑 → 理想主义者，空有热情但落地困难
- 有支撑无驱动 → 高效的机器，但不知道自己为何而战
- 驱动和支撑都有了，但心力不足 →  burnout，中途崩盘

在这个个人地图中，**满意姐和蓝军的位置**可以明确为：

- **蓝军**：提升 Egbertie 的**学习力**和**产品力**

  - 负责把 SKU-A/B/C 从概念变成可交付的产品和服务流程

- **满意姐**：守护 Egbertie 的**心力**和**决策质量**
  - 负责在任务堆积时主动做减法
  - 负责在 Egbertie 疲惫时喊停
  - 负责确保每一个拍板的决策都有思维模型支撑
