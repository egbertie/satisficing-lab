## 一、测试目标

验证从 **图片 → OCR → 深度洞察 → MD 归档** 的最低 Token 路径，确保后续 260+ 张图片可以用模板化方式批量血液化，不走「每张图都调用多模态大模型」的高成本老路。

---

## 二、双经济数据（诚实记录）

| 指标 | 数值 | 说明 |
|------|------|------|
| **总样本量** | 10 张 | 从 270 张中策略抽样 |
| **深度洞察样本** | 4 张 | 覆盖 A/B/C/D 四类 |
| **L1 层（OCR）** | 0 API Token | Tesseract `chi_sim+eng` 本地识别 |
| **L1 层耗时** | ~3 分钟 | 含分类脚本运行 |
| **L2 层（深度洞察）** | 4 张图模型输入 | 固定成本，后续可摊薄 |
| **L3 层（MD 生成）** | 0 Token | 模板套用，人工复检 |
| **Batch-0 总产出** | 1 份综合报告 + 10 份 OCR 原始文本 | 可规模化的知识资产 |

**蓝军审计**: Batch-0 的 4 张深度洞察，确实可以覆盖后续同类型 260+ 张图的批量处理模板，固定成本回收比极高。双经济验证 **通过**。

## 三、图片分类结果与处理策略

| 自动分类 | 特征 | Batch-0 数量 | 后续处理策略 |
|----------|------|--------------|--------------|
| **A-纯文字密集页** | OCR > 200 字符，连续段落 | 1 张 | OCR 清洗后直接转 MD 段落 |
| **B-表格/数据页** | 含结构化符号、清单矩阵 | 6 张 | OCR + 规则脚本 → Markdown 表格 |
| **C-示意图/框架图** | 层级、冰山、流程、循环结构 | 3 张* | 人工结构化描述 → 模板化 MD |
| **D-混合页** | 文字少、背景图、核心价值卡片 | 3 张* | 提取核心命题/金句即可 |

\* 注：OCR 按字符量把部分 C/D 类误判为 B 类，经人工读取图片后已校正。这说明 **C 类不能完全靠字符数判断，必须结合视觉结构**。后续分类规则已升级。

## 五、批量血液化 L3 标准操作（4 类模板）

基于 Batch-0 的 4 张深度洞察，提炼出后续**无需再调多模态模型**的批量处理模板。

### Type-A 纯文字密集页处理 SOP
1. Tesseract OCR 提取全文（`chi_sim+eng`）
2. 自动清洗：删除二维码、广告页脚、课堂口号（「一堂·坚持只做必修课」等）
3. 按段落分块，生成标准 Markdown
4. 末尾追加标签：`#一堂 #文字 #Step?`

### Type-B 表格/数据页处理 SOP
1. OCR 提取文本
2. **规则识别行列关系**：通过 `|`、空格规律、换行缩进判断表格结构
3. 转换为 Markdown 表格或无序列表
4. 追加「满意解映射」注释块（1-2 句话）
5. 末尾追加标签：`#一堂 #表格 #工具包`

### Type-C 示意图/框架图处理 SOP
1. OCR 提取文字节点（作为原材料）
2. **人工/抽检方式识别框架结构**：判断是「流程图 / 冰山图 / 循环图 / 矩阵图」
3. 套用以下**结构化描述模板**输出 MD（后续同类图只需替换内容）：

```markdown
## [图标题]
- **模型类型**: [框架图 / 冰山图 / 流程图 / 循环图]
- **核心结构**: [X 层 / Y 阶段 / Z 要素]
- **关键节点**:
  - L1: ...
  - L2: ...
- **一堂映射**: [五步法对应阶段]
- **满意解借鉴**: [军转民的具体转化]
- **血液化建议**: [写入哪个文档 / 开发什么工具]
```

4. 末尾追加标签：`#一堂 #框架图 #方法论`

### Type-D 混合页（金句卡）处理 SOP
1. 忽略背景装饰元素
2. 提取核心命题/金句（通常 ≤ 2 句话）
3. 如果有四要素拆解，保留为「一句话 + 四要素」的卡片格式
4. 追加「满意解改写版」
5. 末尾追加标签：`#一堂 #金句 #传播素材`

## 六、蓝军审计与风险提示

| 审计项 | 结论 | 风险等级 |
|--------|------|----------|
| Tesseract OCR 准确率 | 对复杂 PPT 框架图约 60-70%，部分节点会漏字或错位 | 🟡 中危 |
| 分类脚本准确率 | C 类容易被误判为 B 类，需视觉确认 | 🟡 中危 |
| 双经济性 | Batch-0 固定成本可控，后续摊薄后单张成本趋近于 0 | 🟢 可控 |
| 可运行性 | 模板已固定，脚本已验证，可直接 Batch-1 | 🟢 可控 |

**硬指控**: OCR 不能替代对 C 类框架图的**视觉结构化校验**。扩大到 50 张时，必须保留「人工抽检 C 类」的环节，否则会导致血液化失真。

## 七、Batch-1 扩大方案

- **规模**: 从 10 张扩大到 **50 张**（约占总量 18%）
- **策略**:
  - L1: 自动化 OCR + 分类（已验证脚本）
  - L2: **不再逐张做深度洞察**，仅对「无法套用模板」的边缘案例做抽检
  - L3: 套用本报告中的 4 类模板批量生成 MD
- **Token 预算**: 几乎为 0（L1+L3 零 Token，L2 抽检控制在 2-3 张）
- **人力投入**: 满意姐 30 分钟内完成分类和模板套用
- **验收标准**:
  1. 50 张 MD 全部生成并放入 `内化知识库/batch1-md/`
  2. 按 Type 建立索引文件
  3. 挑出 3-5 条可直接军转民的高价值洞察，写入 `AGENTS.md`
