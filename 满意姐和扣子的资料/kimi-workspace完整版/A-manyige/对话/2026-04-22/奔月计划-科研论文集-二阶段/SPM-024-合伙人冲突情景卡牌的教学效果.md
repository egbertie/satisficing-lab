# SPM-024: 合伙人冲突情景卡牌的教学效果——基于12类型的准实验研究设计

> **作者**: 满意解研究所 · Egbertie团队

> **分类**: 教育研究 · 准实验设计 · 决策训练
> **关键词**: 合伙人冲突; 情景卡牌; 教学效果; 准实验; 决策能力**

## 摘要

本文提出一项基于12类型合伙人冲突案例库的"合伙人冲突情景卡牌"教学效果准实验研究设计。基于Kolb经验学习理论和情境学习理论，本文构建了"前测-干预-后测-延迟测"的准实验框架，旨在验证卡牌训练对决策者"冲突识别能力"、"策略选择能力"和"伦理判断能力"的提升效果。本文设计了实验组（卡牌训练）与对照组（传统案例阅读）的对比方案，提出了以"冲突类型识别准确率"、"策略多样性指数"和"伦理判断一致性"为核心指标的测量体系。本文为满意解研究所的卡牌产品效果验证提供了可操作的研究方案。

**关键词**: 合伙人冲突; 情景卡牌; 教学效果; 准实验; 决策能力

---

## 1. 引言

"通过游戏化的卡牌训练，决策者能否更好地识别和应对合伙人冲突？"

这一问题的答案，不能仅靠理论推导，而需要实证检验。本文提出一项准实验研究设计，为满意解研究所的卡牌产品提供效果验证框架。

---

## 2. 研究设计

### 2.1 研究问题

**主问题**：合伙人冲突情景卡牌训练是否显著提升决策者的冲突应对能力？

**子问题**：
1. 卡牌训练是否提升冲突类型识别准确率？
2. 卡牌训练是否增加策略选择的多样性？
3. 卡牌训练是否提升伦理判断的一致性？
4. 训练效果的持续性如何（延迟测试）？

### 2.2 准实验设计

采用"非等组前后测设计"（Nonequivalent Groups Pretest-Posttest Design）：

```
实验组：前测(O1) → 卡牌训练(X) → 后测(O2) → 延迟测(O3)
对照组：前测(O1) → 传统案例阅读(C) → 后测(O2) → 延迟测(O3)
```

**被试**：
- 实验组：30名创业者/企业管理者
- 对照组：30名创业者/企业管理者
- 匹配变量：创业年限、教育背景、企业规模

**干预**：
- 实验组：4次卡牌训练（每次60分钟，间隔1周）
- 对照组：4次传统案例阅读（每次60分钟，内容相同但无卡牌游戏化）

### 2.3 基于12类型的卡牌内容

从12类型冲突案例库中选取12个代表性案例，每个类型1个：

| 类型 | 核心冲突 | 训练目标 |
|------|----------|----------|
| Type 01 | 技术vs市场 | 识别能力互补冲突 |
| Type 02 | 股权分配不公 | 识别利益分配冲突 |
| Type 03 | 价值观分裂 | 识别文化冲突 |
| Type 04 | 角色边界模糊 | 识别权责冲突 |
| Type 05 | 决策风格对立 | 识别流程冲突 |
| Type 06 | 信任崩塌 | 识别诚信冲突 |
| Type 07 | 能力不匹配 | 识别成长冲突 |
| Type 08 | 外部干预 | 识别治理冲突 |
| Type 09 | 退出机制缺失 | 识别退出冲突 |
| Type 10 | 家族因素 | 识别情感冲突 |
| Type 11 | 信息不对称 | 识别沟通冲突 |
| Type 12 | 目标漂移 | 识别战略冲突 |

## 3. 测量体系

### 3.1 冲突类型识别准确率

**测量方法**：
- 呈现冲突场景描述（未标注类型）
- 被试判断属于12类型中的哪一类
- 计算正确率

**预期提升**：
- 前测：基线水平（约30-40%，随机水平为8.3%）
- 后测：实验组提升至70%+，对照组提升至50%+

### 3.2 策略多样性指数

**测量方法**：
- 呈现冲突场景
- 被试提出应对策略
- 编码策略类型，计算多样性（Shannon指数）

**预期提升**：
- 前测：每个场景平均2-3种策略
- 后测：实验组提升至5-6种，对照组提升至3-4种

### 3.3 伦理判断一致性

**测量方法**：
- 呈现涉及伦理困境的冲突场景
- 被试做出伦理判断
- 计算与"专家共识"的一致性

**预期提升**：
- 前测：基线一致性
- 后测：实验组显著提升，对照组小幅提升

### 3.4 延迟测试

**时间点**：干预结束后3个月

**目的**：检验效果的持续性

**预期**：实验组保持显著优势，但效果可能有衰减

## 4. 数据分析

### 4.1 描述性统计

| 变量 | 实验组前测 | 实验组后测 | 对照组前测 | 对照组后测 |
|------|-----------|-----------|-----------|-----------|
| 识别准确率 | M±SD | M±SD | M±SD | M±SD |
| 策略多样性 | M±SD | M±SD | M±SD | M±SD |
| 伦理一致性 | M±SD | M±SD | M±SD | M±SD |

### 4.2 推断统计

**2×2混合设计方差分析**（组间×时间）：
- 组间因素：实验组 vs 对照组
- 时间因素：前测 vs 后测
- 预期结果：显著的交互作用（实验组提升 > 对照组提升）

**效应量**：
- Cohen's d > 0.5：中等效应
- Cohen's d > 0.8：大效应

## 5. 伦理考虑

### 5.1 知情同意
- 明确告知研究目的和流程
- 告知可以随时退出
- 告知数据匿名化处理

### 5.2 数据保护
- 个人身份信息与测试数据分离存储
- 数据仅用于研究目的
- 研究结果以汇总形式呈现

### 5.3 利益冲突
- 满意解研究所既是研究发起方也是卡牌设计者
- 需在论文中明确披露
- 建议邀请独立第三方进行数据分析

---

## 6. 讨论

### 6.1 理论贡献

1. 首次为合伙人冲突卡牌训练设计系统的准实验方案
2. 构建了"识别-策略-伦理"三维测量体系
3. 为游戏化决策训练的效果验证提供了方法论示范

### 6.2 局限

- 准实验设计无法完全排除选择偏差
- 样本量较小（n=60），统计功效有限
- 干预时长较短（4次），可能不足以产生持久变化

---

## 7. 结论

本文提出的准实验研究设计，为验证合伙人冲突情景卡牌的教学效果提供了系统框架。如果实验结果支持假设，将为满意解研究所的卡牌产品提供重要的实证背书。

科学研究的核心价值，不在于证明"我们是对的"，而在于诚实地回答"我们的方法是否有效"。
