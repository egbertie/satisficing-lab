# 问卷测评自动化系统 — 合伙人决策成熟度测评

> **编号**: SANSHENG-SKILL-014
> **定位**: 五维度合伙人决策成熟度自动化评估 + 12类型案例库匹配 + 自动化报告生成
> **触发词**: "测评" / "问卷" / "成熟度" / "评估" / "合伙人测评" / "决策成熟度"
> **五维映射**: 金(标尺) + 水(流动) + 土(根基)

---

## 一、Why

合伙人决策是创业者最重要的决策之一，但大多数人是"凭感觉选"。

**问题**: 
- 不知道自己的决策盲点在哪里
- 选合伙人时缺少系统化评估框架
- 冲突发生后才意识到"当初没看清楚"

**解决**: 5维度量化评估 + 12类型案例库匹配 + 自动化报告 = 让决策成熟度"可测量、可改进"

---

## 二、What

### 2.1 五维度评估模型

| 维度 | 权重 | 核心问题 | 成熟度标志 |
|------|------|---------|-----------|
| **自我认知** | 20% | 我清楚自己缺什么吗？ | 能清晰说出团队能力缺口 |
| **候选人评估** | 20% | 我有系统的评估方法吗？ | 有结构化面试/尽调流程 |
| **协议设计** | 20% | 我懂合伙协议的关键条款吗？ | 能列出5个以上必备条款 |
| **风险预判** | 20% | 我能预见合伙关系破裂的方式吗？ | 能说出3种以上失败模式 |
| **关系维护** | 20% | 我有定期沟通机制吗？ | 有固定合伙人会议/对齐机制 |

### 2.2 成熟度等级

| 分数 | 等级 | 特征 | 建议 |
|------|------|------|------|
| 0-40 | 新手 | 凭感觉，无结构 | 优先学习五维决策框架 |
| 41-60 | 发展中 | 有结构但不一致 | 重点补强最弱维度 |
| 61-75 | 胜任 | 系统化，有提升空间 | 案例库实战训练 |
| 76-90 | 高级 | 高度系统化，循证 | 可指导他人 |
| 91-100 | 专家 | 精通且能传授 | 成为决策教练 |

### 2.3 12类型案例库匹配

测评完成后，系统自动匹配最相关的3个冲突类型：
- Type 1: 股权分配冲突
- Type 2: 职责边界模糊
- ...（共12种）

匹配逻辑：根据五维度分数缺口 → 对应历史上该缺口导致的高频冲突类型

## 三、How

### 3.1 触发方式

```
"帮我做一个合伙人决策成熟度测评"
→ 生成飞书问卷链接
→ 用户填写（约10分钟）
→ 系统自动评分
→ 生成报告（PDF/Markdown）
```

### 3.2 自动化流水线

```
[用户填表] → [飞书多维表格] → [Python评分引擎] → [报告生成器] → [交付]
```

**技术栈**: Python3 + 飞书多维表格 + Cron + Markdown/PDF

### 3.3 配套脚本

```bash
# 轮询检查新记录
python3 scripts/partner_assessment_automation.py

# 单条记录分析
python3 scripts/partner_assessment_v1.py --record-id xxx

# 批量生成报告
python3 scripts/batch_report_generator.py --date 2026-04-26
```

## 五、红线与边界

| 红线 | 说明 |
|------|------|
| 不做诊断 | 测评是"成熟度评估"不是"心理疾病诊断" |
| 不替代决策 | 提供信息支持，不替用户做合伙决定 |
| 不保证结果 | 高成熟度≠合伙成功，只是降低风险 |
| 保护隐私 | 测评数据仅用于生成报告，不留存个人敏感信息 |
