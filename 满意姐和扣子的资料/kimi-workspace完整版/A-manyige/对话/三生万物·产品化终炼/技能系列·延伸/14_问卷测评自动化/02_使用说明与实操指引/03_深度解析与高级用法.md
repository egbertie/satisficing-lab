# 深度解析与高级用法

> **编号**: SANSHENG-SKILL-014-REF-003
> **定位**: 测评系统的高级功能与定制方法

---

## 高级功能1: 多人对比分析

**场景**: 创始团队3人同时测评，对比决策盲区

**操作**:
```bash
python3 scripts/team_comparison.py --team-id TEAM001
```

**输出**:
- 团队五维雷达图叠加
- 盲区热力图（哪里 weakest）
- 互补性分析（谁弥补谁的缺口）

---

## 高级功能2: 成长曲线追踪

**场景**: 同一创始人每季度复测，看成长

**操作**:
```bash
python3 scripts/growth_tracker.py --user-id USER001 --period quarterly
```

**输出**:
- 历次测评分数趋势
- 成长最快/最慢的维度
- 与行业基准对比

---

## 高级功能3: 案例库深度匹配

**场景**: 不仅匹配类型，还要匹配具体案例

**操作**:
```bash
python3 scripts/deep_case_match.py --record-id xxx --depth full
```

**输出**:
- Top 3 冲突类型
- 每个类型的1个详细案例
- 预警信号清单
- 预防建议

---

## 定制方法: 修改权重

默认权重: 五维度各20%

如需调整（如技术合伙人侧重"候选人评估"）：
```python
# 在 partner_assessment_v1.py 中修改
WEIGHTS = {
    "self_awareness": 0.15,
    "candidate_assessment": 0.30,  # 提高
    "agreement_design": 0.20,
    "risk_anticipation": 0.20,
    "relationship_maintenance": 0.15
}
```

---

## 定制方法: 添加新维度

如需增加"文化匹配度"维度：
1. 在问卷中增加5道新题
2. 在评分引擎中添加新维度处理
3. 在报告模板中添加新章节
