# 贡献指南

> **编号**: SANSHENG-SKILL-014-OS-002
> **目标**: 如何为这个技能贡献改进

---

## 欢迎的贡献类型

| 类型 | 示例 | 优先级 |
|------|------|--------|
| **Bug修复** | 评分算法错误、报告生成失败 | P0 |
| **新维度** | 添加"文化匹配度"等新评估维度 | P1 |
| **语言支持** | 翻译成英文/日文等其他语言 | P1 |
| **集成扩展** | 增加企业微信/钉钉集成 | P2 |
| **文档改进** | 教程、FAQ、使用案例 | P2 |

---

## 贡献流程

1. **Fork** 本技能仓库
2. **创建分支** `feature/你的改进`
3. **修改** 代码/文档
4. **测试** 确保不破坏现有功能
5. **提交** Pull Request，描述改进内容

---

## 代码规范

- Python代码遵循 PEP 8
- 文档使用 Markdown
- 所有新增功能必须有使用示例
