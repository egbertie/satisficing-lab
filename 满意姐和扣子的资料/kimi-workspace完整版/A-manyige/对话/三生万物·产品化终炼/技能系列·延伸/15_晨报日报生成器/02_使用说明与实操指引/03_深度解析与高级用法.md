# 深度解析与高级用法

> **编号**: SANSHENG-SKILL-015-REF-003
> **定位**: 晨报日报的高级定制

---

## 定制内容模块

默认模块: 日期/重点/决策/Token/健康/昨日/风险

可增删模块：
- **市场动态**: 添加竞品/行业简讯
- **专家提醒**: 特定专家档期/预约
- **里程碑**: 距离关键节点的天数
- **团队状态**: 协作项目的最新进展

---

## 定制输出格式

```bash
# 极简版（只有Top 3）
python3 scripts/morning_report_generator.py --mode minimal

# 详细版（全模块）
python3 scripts/morning_report_generator.py --mode full

# JSON版（供其他系统调用）
python3 scripts/morning_report_generator.py --format json
```

---

## 与其他工具联动

**飞书推送**:
- 晨报自动生成飞书卡片
- 日报推送到指定群

**邮件推送**:
- 设置为邮件简报
- 定时发送给团队成员
