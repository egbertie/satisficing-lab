# 知识保鲜系统 (Knowledge Freshness)

> **定位**: 自动检测知识过期、触发更新提醒、保持知识库时效性
> **触发词**: "知识保鲜" / "过期检查" / "知识更新" / "时效审计"
> **编号**: SANSHENG-SKILL-008
> **五维映射**: 水(流动) + 木(生长) + 金(标尺)

---

## 一、Why

知识是"生鲜产品"，会过期：
- 技术知识: 3-6个月可能过时
- 市场信息: 1-3个月需要更新
- 政策法规: 随时可能变化
- 方法论: 相对持久但需迭代

知识保鲜 = 自动识别"过期知识"并触发更新流程。

---

## 二、What

### 2.1 知识保质期分类

| 类型 | 保质期 | 检查频率 |
|:-----|:---------|:---------|
| 技术文档 | 6个月 | 每月 |
| 市场数据 | 3个月 | 每周 |
| 政策法规 | 1个月 | 每周 |
| 方法论 | 12个月 | 每季度 |
| 案例库 | 6个月 | 每月 |

### 2.2 保鲜机制

```
知识入库 → 打保质期标签 → 到期前提醒 → 更新/归档/丢弃
```

---

## 三、How

```bash
# 扫描过期知识
python3 scripts/freshness-scan.py --older-than 90days

# 生成保鲜报告
python3 scripts/freshness-report.py --output report.md

# 触发更新流程
python3 scripts/refresh-trigger.py --target knowledge-item.md
```
