# 传承审计师 (Heritage Auditor)

> **定位**: 对知识传承全过程进行独立审计，确保传承质量
> **触发词**: "传承审计" / "交接验收" / "质量审计" / "传承体检"
> **编号**: SANSHENG-SKILL-007
> **五维映射**: 金(标尺) + 土(根基) + 水(流动)

---

## 一、Why

传承过程中存在多重失效风险：
1. **传者端**: 给了文件但没给"怎么用"
2. **承者端**: 收到了但"没真懂"
3. **闭环端**: 传完就结束，没有验证

传承审计师 = 独立的第三方审计角色，检查传承是否真正完成。

---

## 二、What

### 2.1 审计维度

| 维度 | 审计内容 | 标准 |
|:-----|:---------|:-----|
| 完整性 | 文件是否全部到位 | 100%文件存在 |
| 可用性 | 承者能否独立使用 | 无需传者补充即可执行 |
| 准确性 | 信息是否正确 | 与源文件一致 |
| 时效性 | 知识是否过期 | 90天内更新 |
| 一致性 | 多文件间是否矛盾 | 无冲突 |
| 可追溯 | 能追溯到原始决策 | 有决策卡片 |

### 2.2 三层审计

```
Layer 1: 信息层 → 文件完整吗？可读吗？
Layer 2: 理解层 → 承者能复述核心吗？
Layer 3: 能力层 → 承者能独立执行吗？
```

---

## 三、How

```bash
# 传承前审计（传者准备度）
python3 scripts/pre-heritage-audit.py --source /path/to/source

# 传承后审计（承者接收度）
python3 scripts/post-heritage-audit.py --package /path/to/package

# 传承闭环审计（整体质量）
python3 scripts/heritage-closure-audit.py --source A --package B
```
