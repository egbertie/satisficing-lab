# 02_贡献指南

## 如何为这个技能做出贡献

### 可以贡献的内容

1. **新增认知偏差模式**  
   如果你观察到AI的其他幻觉/偏差模式，可以补充到"10项认知审计清单"

2. **新增实战场景**  
   如果你有典型的审计场景，可以提交"满分/及格/不及格"对比案例

3. **新增思维模型适配**  
   如果你有其他有效的思维模型，可以补充到"可用模型池"

4. **新增硬否决触发条件**  
   如果你发现其他高危场景，可以补充到"硬否决触发条件"

5. **翻译版本**  
   将本技能翻译成其他语言，扩大适用人群

### 贡献流程

1. **Fork** 本仓库
2. **修改** 对应文件
3. **测试** 你的修改（至少在3个模拟审计中验证）
4. **提交** Pull Request，说明：
   - 修改了什么
   - 为什么修改
   - 测试结果
5. **等待** 审核（蓝军或满意姐会在7天内回复）

### 质量标准

贡献内容必须满足：
- [ ] 有可执行的审计步骤（不是抽象建议）
- [ ] 有明确的"通过/不通过"判断标准
- [ ] 与现有7机制体系兼容（不冲突）
- [ ] 有实战案例支撑

### 沟通渠道

- GitHub Issues：技术问题、Bug报告
- Pull Requests：代码/内容贡献
- 飞书：深度讨论、战略合作
