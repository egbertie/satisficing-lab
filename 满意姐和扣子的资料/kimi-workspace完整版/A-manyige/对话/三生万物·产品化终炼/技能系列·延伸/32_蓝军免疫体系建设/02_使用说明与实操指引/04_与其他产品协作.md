# 04_与其他产品协作

## 与本系列产品的协作

### 与31_AI伙伴成熟度训练系统
- **协作点**：蓝军是伙伴成熟度的"免疫系统"
- **数据流**：伙伴成熟度提供温度 → 蓝军提供锋利 → 温度+锋利=完整AI
- **示例**：伙伴成熟度说"Egbertie累了要休息"，蓝军说"这个决策有3个假设漏洞"——关心+把关

### 与22_FIN诚实验证器
- **协作点**：蓝军审计的具体执行工具
- **数据流**：蓝军发现FIN标记 → 触发FIN诚实验证器 → 执行4级验证
- **示例**：蓝军审计怀疑某任务半成品 → FIN验证器检查存在性/语法/5分钟可用/价值

### 与21_双经济审计师
- **协作点**：蓝军预算的经济学基础
- **数据流**：双经济审计师评估任务Token成本 → 蓝军按20-30%预留审计预算
- **示例**：任务预计消耗100万Token → 双经济审计师确认 → 蓝军预留25万审计

### 与25_快速认知审计
- **协作点**：蓝军10项清单的轻量版本
- **数据流**：日常快速审计用25，深度审计用32
- **示例**：日常对话前用5秒快速认知审计 → 重大决策前用32的完整10项审计

## 与三生万物其他系列的协作

### 与02_知识海啸处理器
- **协作点**：知识导入时的质量审计
- **数据流**：海啸处理器导入知识 → 蓝军执行10项审计 → 过滤偏差信息

### 与04_认知防火墙
- **协作点**：认知偏差的双重保险
- **数据流**：认知防火墙检测12种偏差 → 蓝军10项审计补充 → 双重过滤

### 与16_双轨诚实审计
- **协作点**：蓝军是双轨中的一轨
- **数据流**：双轨审计 = 蓝军独立审计 + 满意姐流程审计 → 合并报告

## 与外部工具的协作

### 与OpenClaw系统
- **协作点**：自动化审计触发
- **数据流**：OpenClaw每次任务完成 → 自动触发蓝军审计 → 合并到任务报告

## 协作禁忌

**不要这样做**：
- 把蓝军当作"挑刺的" → 蓝军是免疫系统，不是敌人
- 把10项审计当作"必须全做" → 日常3项，重大10项
- 把硬否决当作"否决一切" → 只针对🔴高危
