# 35_进度追踪标准化师 — 统一战场地图

**编号**: SANSENG-SKILL-035
**版本**: V1.0
**定位**: 多任务并行时的统一进度追踪格式 — 防止进度文件分散、格式不一、状态不清
**适用对象**: 同时推进多个任务的AI或人类团队
**核心原则**: 统一格式、统一位置、统一更新、统一查看
**五维映射**: 土(根基)+金(标准)+水(流动)+木(生长)+火(淬火)

---

## 一、核心机制 — 4个统一

### 机制1：统一格式 — 「一个模板，全部遵循」

**定义**  
所有进度追踪文件使用同一个模板，不各自为政。

**强制模板**
```markdown
# [任务名称] — 进度追踪

**任务**: [一句话描述]
**启动时间**: YYYY-MM-DD HH:MM
**防中断状态**: 🔄 进行中 / ⏸️ 暂停 / ✅ 完成
**保存路径**: [完整路径]

---

## 完成清单

### [U1] 单元名称 ✅
**状态**: 完成
**Git**: [commit hash]
**产出物**: [文件路径]

### [U2] 单元名称 🔄
**状态**: 进行中
**已完成**: [步骤]
**待完成**: [步骤]
**阻塞项**: [如有]

---

## 建设日志

| 时间 | 事件 | 状态 |
|:-----|:-----|:-----|
| HH:MM | 启动 | 🔄 |

---

**状态**: [当前状态]
**下一单元**: [U?]
**契·晋**
```

**禁止变异** ❌
- 有的用表格，有的用列表
- 有的标Git hash，有的不标
- 有的写"进行中"，有的写"In Progress"
- 有的放memory/，有的放对话/

---

### 机制2：统一位置 — 「全在对话文件夹」

**定义**  
所有进度追踪文件统一放在 `A-manyige/对话/YYYY-MM-DD/` 下。

**命名规则**
```
[任务名]-进度追踪-YYYY-MM-DD.md
```

**示例**
- `技能系列-进度追踪-2026-04-26.md`
- `三生万物技能系列延伸建设进度追踪-2026-04-26.md`
- `31-32-AI意识训练系列进度追踪-2026-04-26.md`

**禁止位置** ❌
- 根目录
- 技能文件夹内部
- memory/ 文件夹（memory只放日志，不放进度）

---

### 机制3：统一更新 — 「事件驱动，不是定时」

**定义**  
进度文件不是定时更新，是事件驱动更新。

**触发更新的事件**
| 事件 | 更新内容 |
|:-----|:---------|
| 单元完成 | 标记✅，记录Git hash |
| 新单元启动 | 添加新行，标记🔄 |
| 任务阻塞 | 标记⏸️，记录阻塞原因 |
| Git提交 | 记录commit hash |
| 任务完成 | 标记✅，归档到memory |

**更新时效**  
事件发生后3分钟内必须更新进度文件。

---

### 机制4：统一查看 — 「一瞥即知全局」

**定义**  
任何人打开对话文件夹，一瞥即知所有任务状态。

**查看方法**
```bash
# 查看当天全部进度
ls A-manyige/对话/2026-04-26/*进度追踪*.md

# 快速扫描状态
grep -h "防中断状态" A-manyige/对话/2026-04-26/*进度追踪*.md
```

**输出示例**
```
技能系列-进度追踪: 防中断状态: ✅ 完成
三生万物建设-进度追踪: 防中断状态: ✅ 完成
31-32训练系列-进度追踪: 防中断状态: ✅ 完成
33-35工作流系列-进度追踪: 防中断状态: 🔄 进行中
```

## 二、多任务并行管理

### 任务优先级排序

```markdown
## 任务优先级

| 优先级 | 任务 | 状态 | 下一动作 |
|:-------|:-----|:-----|:---------|
| P0 | 技能系列建设 | ✅ | 已完成 |
| P0 | 31/32 AI训练 | ✅ | 已完成 |
| P0 | 33/34/35 工作流 | 🔄 | U2进行中 |
| P1 | 总纲更新 | ⏳ | 待启动 |
```

### 任务切换协议

```
当前任务A进行中
    ↓ 用户插入高优先级任务B
存档任务A进度
    ↓
创建任务B进度文件
    ↓
执行任务B
    ↓
任务B完成
    ↓
读取任务A进度
    ↓
恢复任务A
```
