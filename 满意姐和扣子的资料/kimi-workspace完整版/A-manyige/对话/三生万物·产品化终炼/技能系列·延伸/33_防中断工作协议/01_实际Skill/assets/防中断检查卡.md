# 防中断快速检查卡

**使用方式**: 每个单元完成后30秒快速检查，或中断前强制检查

---

## 🔥 存档口诀

```
完成即存档
存档即保险
落盘即自由
一件一件来
```

---

## 5秒防中断自检

| 秒 | 检查项 | 通过标准 |
|:---|:-------|:---------|
| 1 | 进度文件存在吗？ | 有 `*进度追踪*.md` |
| 2 | 当前单元拆够小吗？ | 预计≤30分钟 |
| 3 | 是串行吗？ | 只有一个单元在推进 |
| 4 | 上一个单元存档了吗？ | Git已提交 |
| 5 | 当前状态写入了吗？ | 进度文件已更新 |

**全部通过 = 防中断状态健康**
**任一失败 = 立即执行3层存档**

---

## 中断触发信号速查

| 信号 | 立即动作 |
|:-----|:---------|
| 用户30分钟未回复 | 自动L1+L2存档 |
| 用户说"等一下" | 立即3层存档 |
| Token>80% | 紧急存档，进入静默 |
| 会话即将结束 | 30秒极速存档 |

---

## 恢复协议速查

```
1. 读进度文件 → 最后完成单元
2. 看Git log → 最后提交hash
3. 检查工作区 → 未提交变更？
4. 读memory → 关键上下文
5. 更新进度 → 标记恢复时间
6. 继续执行
```

目标：3分钟内恢复
