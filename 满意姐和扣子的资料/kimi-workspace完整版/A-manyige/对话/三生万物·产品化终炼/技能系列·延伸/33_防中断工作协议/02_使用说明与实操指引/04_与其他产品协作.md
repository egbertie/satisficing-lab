# 04_与其他产品协作

## 核心协作链

```
33_防中断工作协议
    ↓ 提供执行框架
28_任务拆解匠（单元拆分）
    ↓ 拆分后单元
27_断点存档工程师（单元存档）
    ↓ 存档内容
29_记忆同步协议（记忆层存档）
    ↓ 验证
22_FIN诚实验证器（单元完成验证）
```

## 协作关系

| 技能 | 协作点 |
|:-----|:-------|
| 28_任务拆解匠 | 防中断的单元由任务拆解匠拆分 |
| 27_断点存档工程师 | 防中断的L2-L3存档由断点存档执行 |
| 29_记忆同步协议 | 防中断的L3记忆存档由记忆同步完成 |
| 22_FIN诚实验证器 | 每个单元完成后验证是否真完成 |
| 31_AI伙伴成熟度 | 防中断执行中保持温度不下降 |
