# Rapid Cognitive Audit — 快速认知审计

> **蓝军核心权限**。独立预算20-30%，硬否决权，10项硬性检查。
> **禁止输出"一切正常"** — 必须发现至少1个问题。

## 核心原则

**速度要求**：3分钟内完成
**输出要求**：必须发现至少1个风险/偏差/漏洞
**权限**：即使其他所有技能都说"没问题"，本技能仍有权标红

---

## 10项快速检查（每项≤20秒）

### 1. 信源独立性
**问题**：这个信息的来源是否独立？是否存在循环引用？

```
□ 信息来源 ≥2个独立渠道
□ 来源之间不存在互相引用/洗稿
□ 原始数据来源可被追溯到
```

**快速判断**：只有一个来源或来源之间互相引用 → 🟡 信源不独立

### 2. 时效性
**问题**：这个信息是什么时候产生的？现在是否仍然有效？

```
□ 信息发布时间明确
□ 距今 ≤6个月（快速变化领域）或 ≤2年（稳定领域）
□ 无"据悉"" reportedly"等模糊时效词
```

**快速判断**：超过时效窗口且无更新 → 🟡 时效性存疑

### 3. 因果混淆
**问题**：相关≠因果。是否存在将相关性解释为因果性的跳跃？

```
□ 论断使用"导致""因为"时有明确的因果链条
□ 排除了第三变量解释
□ 没有将时间先后当作因果证据
```

**快速判断**：用"因为A所以B"但没有排除C同时导致A和B → 🟡 因果混淆嫌疑

### 4. 幸存者偏差
**问题**：是否只看到了成功案例而忽略失败案例？

```
□ 同时考虑了成功和失败案例
□ 统计分母完整（不是只算分子）
□ 没有"某某做了这个就成功了"的单一案例推广
```

**快速判断**：只讲成功案例，不提失败率 → 🟡 幸存者偏差

### 5. 基底率忽视
**问题**：是否忽略了基础概率？罕见事件的阳性结果可信度低。

```
□ 考虑了事件在总体中的基底率
□ 罕见病+阳性检测≠高概率患病
□ 没有因为"匹配"而忽略"概率"
```

**快速判断**：在罕见场景中声称高置信度 → 🟡 基底率忽视

### 6. 锚定效应
**问题**：第一个数字/信息是否不当影响了后续判断？

```
□ 第一个信息没有被当作"基准"
□ 数字判断前考虑了多个参照点
□ 没有被用户的第一句话锁定思维
```

**快速判断**：用户给了一个数字后，所有分析围绕这个数字展开 → 🟡 锚定嫌疑

### 7. 确认偏误
**问题**：是否只寻找支持已有观点的证据？

```
□ 主动寻找了反例/反面证据
□ 结论不是"预设观点的确认"
□ 有"如果没有找到X，我会改变观点"的声明
```

**快速判断**：所有证据都指向同一个方向，无任何反面 → 🟡 确认偏误嫌疑

### 8. 语言腐败
**问题**：词汇是否在模糊化/美化/扭曲真实含义？

```
□ 关键术语有明确定义
□ 没有"战略性""生态化""赋能"等空话包装
□ 数字和形容词可互相验证
```

**快速判断**：用了很多形容词但缺少具体数字 → 🟡 语言腐败

### 9. 数学谬误
**问题**：数字运算或统计推理是否有误？

```
□ 百分比变化基于正确的基数
□ 平均值没有掩盖极端分布
□ 增长率/下降率方向正确
```

**快速判断**：基数变化后仍用旧数字计算百分比 → 🟡 数学谬误

### 10. 样本偏差
**问题**：样本是否能代表总体？

```
□ 样本量足够（不是N=1或N=几个）
□ 抽样方法随机或有代表性
□ 没有将朋友圈/微博评论当作全民意见
```

**快速判断**：小样本推广到总体 → 🟡 样本偏差

## 反模式

❌ 输出"一切正常"（本技能禁止此输出）
❌ 只给评分不给具体问题
❌ 发现问题但不给出修正建议
❌ 审计流于形式，每个项都勾✅
❌ 因为时间紧而跳过审计
