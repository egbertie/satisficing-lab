# 认知防火墙 (Cognitive Firewall)

> **定位**: 防止错误信息、认知偏差、过时知识进入知识库的防护系统
> **触发词**: "认知审计" / "信息验证" / "防偏差" / "知识净化"
> **编号**: SANSHENG-SKILL-006
> **五维映射**: 金(标尺) + 火(洞察) + 土(根基)

---

## 一、Why

知识库面临三大污染风险：
1. **信息污染**: 错误信息混入，被当作正确知识传承
2. **认知偏差固化**: AI的输出偏差被反复强化，成为"错误传统"
3. **知识过期**: 时效性强的信息未及时更新，误导后续决策

认知防火墙 = 在知识入库前进行"认知安检"。

---

## 二、What

### 2.1 核心能力

| 能力 | 说明 | 输出 |
|:-----|:-----|:-----|
| 事实核查 | 对关键事实进行交叉验证 | 核查报告 |
| 偏差检测 | 识别12种常见认知偏差 | 偏差警报 |
| 时效检查 | 检查知识的时间有效性 | 时效标签 |
| 一致性校验 | 新知识vs现有知识库的一致性 | 冲突报告 |
| 溯源验证 | 验证信息来源的可靠性 | 溯源评级 |

### 2.2 12种偏差检测清单

1. 确认偏误（只找支持自己的证据）
2. 锚定效应（被第一印象束缚）
3. 幸存者偏差（只看见成功案例）
4. 因果混淆（相关≠因果）
5. 基底率忽视（忽略基础概率）
6. 光环效应（以偏概全）
7. 近因效应（最近的信息权重过高）
8. 可得性启发（容易想起的≠重要的）
9. 框架效应（表述方式影响判断）
10. 沉没成本（因已投入而继续坚持）
11. 群体思维（附和主流观点）
12. 过度自信（高估自己的判断）

## 三、How

```bash
# 对新入库知识进行安检
python3 scripts/cognitive-firewall.py --input new-knowledge.md

# 对AI输出进行偏差扫描
python3 scripts/bias-scanner.py --input ai-output.md

# 知识库定期净化
python3 scripts/knowledge-purify.py --older-than 90days
```
