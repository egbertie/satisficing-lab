# 深研·静流 (Deep Research · Quiet Flow)

> **定位**: 深度研究到内容生成的六阶段流水线，让研究时间缩短30-50%
> **触发词**: "深研" / "静流" / "帮我研究" / "深度调研" / "写一份关于...的研究"
> **编号**: SANSHENG-SKILL-009
> **五维映射**: 水(流动) + 金(标尺) + 火(洞察)

---

## 一、Why

信息过载时代，研究不是缺资料，而是缺"高质量的筛选和结构"。

一个律所合伙人准备新领域案件：
- 传统方式: 3天翻200篇资料 → 写1份报告 → 发现遗漏
- 深研·静流: 90分钟6阶段流水线 → 输出结构化研究包 → 可直接复用

**核心价值**: 不是搜索更多，而是"更快到达高质量结论"。

---

## 二、What

### 2.1 六阶段流水线

```
[理解] → [搜索] → [验证] → [架构] → [写作] → [交付]
```

| 阶段 | 时长 | 核心动作 | 输出 |
|:-----|:-----|:---------|:-----|
| 1.理解 | 10min | 明确研究问题、边界、目标读者 | 研究任务书 |
| 2.搜索 | 15min | 多源信息收集（学术/新闻/政策/行业） | 原始素材包 |
| 3.验证 | 10min | 交叉验证、去伪存真、标注信源 | 验证清单 |
| 4.架构 | 10min | 结构化组织信息、确定叙述逻辑 | 内容大纲 |
| 5.写作 | 30min | 按架构生成内容、保持客观中性 | 初稿 |
| 6.交付 | 5min | 格式化输出、生成摘要、标注引用 | 最终交付包 |

**总时长**: 80分钟（标准版）/ 30分钟（快速版）/ 180分钟（深度版）

### 2.2 三档模式

| 模式 | 时长 | 适用场景 | 特点 |
|:-----|:-----|:---------|:-----|
| 🟢 快速版 | 30分钟 | 紧急决策、初步了解 | 3阶段压缩（理解→搜索→交付） |
| 🟡 标准版 | 80分钟 | 常规研究、报告撰写 | 完整6阶段 |
| 🔴 深度版 | 180分钟 | 重大决策、学术级研究 | 6阶段+多轮验证+专家访谈 |

### 2.3 量化指标（自评）

| 指标 | 快速版 | 标准版 | 深度版 |
|:-----|:-------|:-------|:-------|
| 信源数量 | ≥3 | ≥8 | ≥15 |
| 交叉验证轮次 | 1 | 2 | 3+ |
| 信息密度(字/结论) | ≤500 | ≤300 | ≤200 |
| 可追溯引用 | 有 | 有 | 完整APA |

## 三、How

### 3.1 触发方式

```
"深研 [主题]" → 标准版
"快速深研 [主题]" → 快速版
"深度研究 [主题]" → 深度版
```

### 3.2 配套脚本

```bash
# 六阶段研究流水线
python3 scripts/deep-research.py --topic "主题" --mode standard

# 快速版（30分钟）
python3 scripts/quick-research.py --topic "主题"

# 信源验证器
python3 scripts/source-validator.py --input sources.md

# 研究质量评估
python3 scripts/research-quality-check.py --output research.md
```

### 3.3 使用示例

**示例1: 律所合伙人研究新领域**
```
用户: "深研 中国数据出境安全评估制度"
→ 生成研究任务书（边界: 2024-2025法规，读者: 客户法务）
→ 搜索: 网信办官网、学术数据库、行业报告
→ 验证: 3个来源交叉确认关键条款
→ 架构: 政策背景→法规框架→企业义务→合规路径→风险清单
→ 写作: 生成8000字研究报告
→ 交付: Markdown报告+摘要+引用清单
```

**示例2: 创始人了解竞品**
```
用户: "快速深研 某竞争对手的融资历程和产品策略"
→ 压缩3阶段：理解→搜索→交付
→ 15分钟输出：融资时间线+产品迭代图谱+关键决策点
```

## 五、红线与边界

| 红线 | 说明 |
|:-----|:-----|
| 不做凭空创造 | 所有结论必须有信源支撑 |
| 不做价值判断 | 保持客观中立，不替用户做决定 |
| 不超时运行 | 严格按档位时间执行，到点就交付 |
| 不堆砌资料 | 不是资料越多越好，是结构越清晰越好 |
