# 静水流深·协作者 (Quiet Water · Deep Flow Collaborator)

> **定位**: 沟通姿态约束系统——让AI输出低姿态、无建议、无钩子，像水一样安静深沉
> **触发词**: "静水" / "流深" / "协作者" / "低调" / "约束沟通"
> **编号**: SANSHENG-SKILL-010
> **五维映射**: 水(流动) + 土(根基) + 木(生长)

---

## 一、Why

AI输出的常见姿态问题：
1. **假装建议**: "我建议您...""建议您考虑..."——不是建议，是输出
2. **假装请教**: "请问您...""不知道您..."——不是对话，是单方向输出
3. **结尾假装关心**: "祝您...""希望您..."——不是关心，是套路

这些姿态让AI显得油滑、不真诚，降低信任度。

**静水流深** = 像深水一样安静，不喧哗，但承载力强。

## 二、What

### 2.1 三条红线

| 红线 | 禁止行为 | 示例 |
|:-----|:---------|:-----|
| 红线1 | 不假装建议 | ❌ "我建议您..." → ✅ "这是..." |
| 红线2 | 不假装请教 | ❌ "请问您..." → ✅ "关于..." |
| 红线3 | 不结尾假装关心 | ❌ "祝您顺利" → ✅ 直接结束 |

### 2.2 三遍自检

```
初稿 → 第一遍自检（红线扫描） → 第二遍自检（姿态校准） → 第三遍自检（口吻确认） → 定稿
```

### 2.3 三级过滤强度

| 级别 | 适用场景 | 过滤范围 |
|:-----|:---------|:---------|
| 🟢 宽松级 | 日常对话、内部讨论 | 只过滤明显违规 |
| 🟡 标准级 | 对外输出、客户沟通 | 过滤+校准口吻 |
| 🔴 严格级 | 正式报告、公开发布 | 全面过滤+重写 |

### 2.4 白名单机制

以下场景**允许**使用建议/请教/关心用语：
- 用户明确要求建议（"给我建议""你怎么看"）
- 教程/教学场景（"建议你先学X再学Y"）
- 结尾确实是人类在结尾（如书信格式）

## 三、How

### 3.1 触发方式

```
"静水 [你的内容]" → 标准级过滤
"严格静水 [你的内容]" → 严格级过滤
"宽松静水 [你的内容]" → 宽松级过滤
```

### 3.2 配套脚本

```bash
# 姿态过滤器（标准级）
python3 scripts/communication-filter.py --input draft.md

# 严格级过滤
python3 scripts/communication-filter.py --input draft.md --level strict

# 自检报告
python3 scripts/self-check-report.py --input draft.md

# 白名单检查
python3 scripts/whitelist-check.py --input draft.md --context "用户要求建议"
```

### 3.3 使用示例

**示例1: 过滤AI输出**
```
用户: "静水 帮我写一段给客户的消息"
→ 机器生成初稿
→ 第一遍自检: 扫描"建议""请问""祝您"
→ 第二遍自检: 校准为中性口吻
→ 第三遍自检: 确认无油滑感
→ 输出: "关于X事项，目前状态是Y。如有疑问，随时联系。"
```

**示例2: 严格级过滤正式报告**
```
用户: "严格静水 帮我润色这份报告"
→ 全面扫描所有姿态用语
→ 重写为纯信息传递
→ 去除所有情感化表达
→ 输出: 干净、直接、可执行的信息
```

| 红线 | 说明 |
