# T01: 散乱文件CT扫描问卷

> **编号**: SSW-650
> **用途**: 3分钟评估你的散乱文件灾难等级

---

## 问卷

| 问题 | 选项 | 得分 |
|:-----|:-----|:-----|
| 1. 你的文件总数? | ≤100 / 100-1000 / 1000-10000 / 10000+ | 1/2/3/4 |
| 2. 文件类型有几种? | ≤3 / 4-6 / 7-10 / 10+ | 1/2/3/4 |
| 3. 有多少比例是图片/扫描件? | ≤10% / 10-30% / 30-60% / 60%+ | 1/2/3/4 |
| 4. 有完整的文件索引吗? | 有 / 部分 / 很少 / 无 | 1/2/3/4 |
| 5. 新人能独立找到关键文件吗? | 能 / 需指导 / 很难 / 不可能 | 1/2/3/4 |
| 6. 有隐性知识文档化吗? | 大部分 / 部分 / 很少 / 无 | 1/2/3/4 |
| 7. 上次整理是什么时候? | 1月内 / 3月内 / 1年内 / 1年+ | 1/2/3/4 |
| 8. 文件去重做过吗? | 完全 / 部分 / 很少 / 无 | 1/2/3/4 |
| 9. 有版本控制吗? | 有Git / 手动 / 混乱 / 无 | 1/2/3/4 |
| 10. 传承紧迫感? | 不紧急 / 近期 / 半年内 / 立即 | 1/2/3/4 |

## 评分

| 总分 | 等级 | 建议 |
|:-----|:-----|:-----|
| 10-15 | 🟢 轻度 | 可手工整理 |
| 16-25 | 🟡 中度 | 建议引入海啸处理器 |
| 26-35 | 🔴 重度 | 立即启动海啸处理器 |
| 36-40 | ⚫ 灾难 | 紧急启动+外部支援 |
