# 快速上手指南

> **用途**: 15分钟安装、配置、运行知识飞轮操作系统
> **适用**: 第一次接触的用户
> **前提**: 已安装OpenClaw，有基本的文件操作能力

---

## Step 1: 下载Skill文件（2分钟）

**方式A：从本体系获取**
```bash
# Skill文件位置
A-manyige/对话/三生万物·产品化终炼/01_Skill级别·知识飞轮传承操作系统/01_实际Skill/dist/knowledge-flywheel-guide.skill
```

**方式B：从ClawHub安装**
```bash
# 如果已发布到ClawHub
openclaw skill install knowledge-flywheel-guide
```

---

## Step 2: 安装与配置（3分钟）

```bash
# 解压Skill文件到OpenClaw skills目录
cp knowledge-flywheel-guide.skill ~/.openclaw/skills/
cd ~/.openclaw/skills/
openclaw skill install knowledge-flywheel-guide

# 验证安装
openclaw skill list | grep knowledge-flywheel-guide
```

**配置检查**:
- [ ] OpenClaw版本 ≥ 2026.3.13
- [ ] Python3可用
- [ ] Git已配置

---

## Step 3: 运行自检脚本（5分钟）

```bash
# 运行阶段自检脚本
cd ~/.openclaw/skills/knowledge-flywheel-guide/scripts
python3 stage-checker.py
```

**脚本会交互式询问**:
1. 你的知识资产有多少文件？
2. 能列出最重要的10个吗？
3. "写不出来的"知识占比？
4. 明天不能工作，多少知识会丢？
5. 传承有deadline吗？

**输出**: 你的级别（L1/L2/L3/L4）+ 推荐方案（A/B/C/D）

---

## Step 4: 生成知识地图（3分钟）

```bash
# 运行知识地图生成器
python3 knowledge-map.py /path/to/your/knowledge/assets
```

**输出**:
- 目录结构树
- 文件统计（按类型/大小/日期）
- 初步分类建议

---

## Step 5: 选择你的方案（2分钟）

根据自检结果，选择对应方案：

| 你的级别 | 方案 | 下一步 |
|:---------|:-----|:-------|
| L1 | A-六阶段渐进 | 读 `references/onboarding-guide.md`，开始45天计划 |
| L2 | B-双轨并行 | 读 `references/handover-guide.md` + `references/dual-sync-meeting-template.md` |
| L3 | C-梯队传承 | 读 `references/handover-guide.md`，建立知识传承委员会 |
| L4 | D-范式迁移 | 读 `SKILL-v2.0.md` 第八部分，设计四大突破 |

## 常见问题

**Q: 我是个人用户，只有50个文件，适用吗？**
A: 适用。你是L1，用方案A，45天六阶段渐进。

**Q: 我没有技术背景，能操作吗？**
A: 能。脚本都是交互式的，按提示输入即可。实在不行，找一位"技术伙伴"帮你运行脚本，你负责决策。

**Q: 飞轮转起来之后，还需要维护吗？**
A: 需要。每月健康检查，每季度深度审计，每年范式校准。详见 `SKILL-v2.0.md` 第八部分。

**Q: 旧版本资料怎么处理？**
A: 不要删除！移到 `archive/` 目录。新版本在前，旧版本在后，可追溯。
