# 四级方案操作手册

> **用途**: L1-L4逐层操作指南，每一步都有具体动作
> **适用**: 已确定级别的用户
> **配合**: `references/scale-assessment-ct.md`（CT扫描问卷）

---

## 方案A：L1个人级——六阶段渐进（45天）

### 适用条件
- 10-100个文件
- 隐性知识20-40%
- 无紧急deadline
- 一个人操作

### 六阶段操作清单

**第一阶段：婴儿期（Day 1-7）——建地图**
- [ ] Day 1: 列出所有文件清单（不读内容）
- [ ] Day 2-3: 按主题分类，统一命名规则
- [ ] Day 4-5: 画知识资产地图（思维导图或表格）
- [ ] Day 6-7: 标记文件级别（S/A/B/C/D）

**第二阶段：学步期（Day 8-14）——读核心**
- [ ] Day 8-9: 选出Top 10核心文件
- [ ] Day 10-12: 精读核心文件，每份写3句摘要
- [ ] Day 13-14: 整理疑问清单

**第三阶段：少年期（Day 15-21）——画关联**
- [ ] Day 15-17: 两两对比，标记关系类型（引用/因果/互补/独立）
- [ ] Day 18-19: 画关联图
- [ ] Day 20-21: 识别空白清单

**第四阶段：青年期（Day 22-28）——上手干**
- [ ] Day 22-23: 选一个真实任务
- [ ] Day 24-26: 只用知识库完成，记录卡点
- [ ] Day 27-28: 整理"哪里缺什么"

**第五阶段：成年期（Day 29-35）——血液化**
- [ ] Day 29-31: 整理卡点，逐个解决
- [ ] Day 32-33: 写任务指令（"如果遇到X，执行Y"格式）
- [ ] Day 34-35: 检验可执行性（让AI或朋友执行）

**第六阶段：成熟期（Day 36-45）——飞轮转**
- [ ] Day 36-38: 监控指标1：信息就绪度
- [ ] Day 39-41: 监控指标2：初稿质量
- [ ] Day 42-43: 监控指标3：时间再分配
- [ ] Day 44-45: 制定修正计划，设定下阶段目标

## 方案B：L2团队级——双轨并行（90天）

### 适用条件
- 100-1000个文件
- 隐性知识40-60%
- 5-20人团队
- 需要多人协同

### 双轨操作清单

**人类轨道（教授团）**

**Week 1-2：建立教授团**
- [ ] 确定1-2名专家（教授）
- [ ] 确定1名AI管理员
- [ ] 召开启动会，明确双循环规则

**Week 3-6：专家萃取**
- [ ] 每周1次专家访谈（1小时）
- [ ] 产出：结构化访谈纪要 + 决策逻辑图谱
- [ ] 交叉验证：多专家对同一问题的回答比对

**Week 7-10：关系映射**
- [ ] 画出"谁和谁讨论什么"网络
- [ ] 识别非正式沟通渠道
- [ ] 编码文化："我们在这里怎么做决定"

**Week 11-12：整合与交接**
- [ ] 整合所有萃取成果
- [ ] 向AI轨道移交
- [ ] 召开第一次双周同步会

**AI轨道（小白群）**

**Week 1-6：结构化入库**
- [ ] 按P0/P1/P2/P3优先级批量处理
- [ ] 自动去重、分类、生成摘要
- [ ] 建立初步知识图谱

**Week 7-10：连接与血液化**
- [ ] 自动建立知识连接
- [ ] 识别知识空白
- [ ] 生成SOP片段和模板

**Week 11-12：飞轮启动**
- [ ] 团队共享知识库上线
- [ ] 新人上手测试
- [ ] 飞轮健康基线测量

**关键机制：双周同步会**
- [ ] AI展示（5分钟）
- [ ] 人类验证（10分钟）
- [ ] 冲突处理（5分钟）
- [ ] 优先级调整（5分钟）
- [ ] 飞轮检查（5分钟）

## 方案C：L3组织级——梯队传承（180天）

### 适用条件
- 1000-10000个文件
- 隐性知识60-80%
- 面临退休/离职
- 需要制度化传承

### 四层梯队操作清单

**第一层：核心骨架（S级）——专家访谈程序**
- [ ] Month 1-2: 每周2次结构化访谈（每次90分钟）
- [ ] 关键问题："你最核心的方法论是什么？""如果新人只学一个，学什么？"
- [ ] 产出：访谈纪要 + 决策逻辑图谱
- [ ] 验证：跨代际交叉review

**第二层：知识血肉（A级）——师徒制+影子计划**
- [ ] Month 3-4: 1名专家带1-2名继任者（持续3个月）
- [ ] 影子计划：新人跟着专家工作
- [ ] 产出：带注释案例库 + 工作流图谱
- [ ] 验证：模拟场景测试

**第三层：过程记录（B级）——AAR+故事讲述**
- [ ] Month 5: 每项目结束后1小时复盘
- [ ] AAR四问：原计划？实际？差异？下次？
- [ ] 故事讲述："当时我怎么想的"
- [ ] 产出：经验教训库 + 口述史

**第四层：文化基因（隐性）——实践社区**
- [ ] Month 6: 每月1次实践社区活动
- [ ] 非正式聚会：每周五茶歇
- [ ] 产出：文化手册

**关键机制：知识传承委员会**
- [ ] 每月1次会议
- [ ] 议程：进度/意外知识/AI质量/优先级/风险预警

## 方案D：L4生态级——范式迁移（365天+）

### 适用条件
- 无边界知识资产
- 隐性知识80-95%
- 跨领域大师级
- 接受"不可完全传递"

### 四大突破操作清单

**突破一：接受不可完全传递**
- [ ] Quarter 1: 列出"永远无法传递"的知识清单
- [ ] 策略：传递思维框架，培育新生长
- [ ] 验证：新人5年后的判断，和创始人不一样但同样有效

**突破二：时序知识图谱**
- [ ] Quarter 2: 为每个知识点标注"有效期"
- [ ] 技术：Graphiti时序知识图谱
- [ ] 规则："什么曾经是对的，现在被什么取代了"

**突破三：多代AI接力**
- [ ] Quarter 3: 部署第一代AI（结构化入库）
- [ ] Quarter 4: 部署第二代AI（深度洞察）
- [ ] Year 2: 部署第三代AI（范式创新）
- [ ] 原则：每代AI叠加，不是替代

**突破四：外部知识联盟**
- [ ] Year 1: 识别"独特知识"（护城河）和"可共享知识"（飞轮燃料）
- [ ] Year 2: 建立第一个知识交换伙伴
- [ ] Year 3: 扩展为跨领域知识联盟

**关键机制：年度知识传承大会**
- [ ] 每年一次
- [ ] 议程：飞轮转速/意外收获/遗憾清单/下年计划/传承仪式
