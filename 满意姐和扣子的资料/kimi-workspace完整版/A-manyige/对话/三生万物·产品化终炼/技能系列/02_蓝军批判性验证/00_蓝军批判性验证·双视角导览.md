## 人类视角

### 这是什么？
满意解研究所的"免疫系统"——任何决策/产出前的批判性验证工具。

### 什么时候用？
- 产出声称"完成"时
- 重大决策前
- 发现"看起来太顺利"时
- 用户要求审计时

### 怎么用？
```bash
# 方法1: 运行脚本（5分钟）
python3 scripts/audit-checker.py
# 逐项回答10项认知审计

# 方法2: 手动检查（3分钟）
# 打开 references/cognitive-audit.md
# 逐项勾选通过/存疑/不通过

# 方法3: 深度审计（15分钟）
# 阅读 references/audit-manual.md
# 按详细流程执行
```

### 输出解读
- 🟢 可控 → 可以推进
- 🟡 中危 → 关注存疑项
- 🔴 高危 → 修正后再推进

## AI视角

### 这是什么？
一个交互式审计脚本，AI运行后引导逐项检查认知偏差。

### AI怎么接入？
1. 检测触发词："蓝军审计" / "批判性验证"
2. 读取 SKILL.md 确认触发
3. 运行 scripts/audit-checker.py
4. 引导逐项回答
5. 输出风险等级和整改建议

### 脚本逻辑
```python
# 1. 10项检查（通过/存疑/不通过）
# 2. 统计: 通过数/存疑数/不通过数
# 3. 判断:
#    - fail>=1 or warn>=3 → 🔴高危
#    - warn>=1 → 🟡中危
#    - else → 🟢可控
```

### 与人类协同
- AI执行审计 → 输出报告 → 人类确认整改 → AI复核
- 蓝军必须独立，不受满意姐影响
