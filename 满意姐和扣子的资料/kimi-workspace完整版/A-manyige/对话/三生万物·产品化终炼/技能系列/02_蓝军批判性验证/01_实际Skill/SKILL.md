## 二、蓝军宪章

### 权限

| 权限 | 说明 |
|:-----|:-----|
| **独立预算** | 总Token的20-30%专属 |
| **硬否决权** | 高危风险自动冻结任务 |
| **认知审计** | 10项硬性检查清单 |

### 10项认知审计清单

| 编号 | 检查项 | 说明 |
|:-----|:-------|:-----|
| 1 | 信源独立性 | 信息来源是否独立？是否有利益相关？ |
| 2 | 时效性 | 信息是否过时？是否有更新版本？ |
| 3 | 因果混淆 | 相关≠因果，是否混淆了？ |
| 4 | 幸存者偏差 | 只看到了成功案例？ |
| 5 | 基底率忽视 | 忽略了基础概率？ |
| 6 | 锚定效应 | 被第一个数字/信息锚定了？ |
| 7 | 确认偏误 | 只找支持自己观点的证据？ |
| 8 | 语言腐败 | 用词是否在掩盖真相？ |
| 9 | 数学谬误 | 数字计算是否有错误？ |
| 10 | 样本偏差 | 样本是否有代表性？ |

### 输出格式

```
[蓝军审计]
风险等级: 🔴高危/🟡中危/🟢可控
指控:
1. [幻觉嫌疑] 具体问题
2. [逻辑跳跃] 具体问题
3. [假设漏洞] 具体问题
```

## 三、审计流程

### Step 1: 接收任务
- 任何决策/产出/方案，蓝军独立审计

### Step 2: 10项检查
- 逐一检查10项认知审计清单
- 每项：通过 / 存疑 / 不通过

### Step 3: 风险定级
- 🔴 高危：任一项"不通过"或3项以上"存疑"
- 🟡 中危：1-2项"存疑"
- 🟢 可控：全部通过

### Step 4: 出具审计报告
- 风险等级
- 具体指控（至少1条）
- 整改建议

### Step 5: 满意姐评估
- 蓝军报告提交满意姐
- 满意姐评估："对现有用户有负面影响吗？"
- 判断：放行 / 修改后放行 / 驳回

### Step 6: Egbertie裁决（战略级）
- 如果满意姐和蓝军冲突，Egbertie裁决
- Egbertie裁决为唯一终局决策
