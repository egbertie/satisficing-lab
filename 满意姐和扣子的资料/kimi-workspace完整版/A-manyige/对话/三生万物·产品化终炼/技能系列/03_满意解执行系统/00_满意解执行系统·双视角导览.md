## 人类视角

### 这是什么？
满意解研究所的项目管理与高效执行操作系统——三板斧+HEARTBEAT+双经济。

### 什么时候用？
- 项目启动时
- 任务管理时
- 防中断执行时
- 双经济约束检查时

### 怎么用？
```bash
# 方法1: 生成进度追踪文件
python3 scripts/progress-tracker.py "项目名称"

# 方法2: 使用项目模板
cp assets/templates/project-template.md my-project.md
# 按模板填写并执行

# 方法3: 阅读执行手册
cat references/execution-manual.md
```

### 核心原则
1. 三板斧：流程优先/减法优先/情感雷达
2. HEARTBEAT：每日检查+五级运行模式
3. 双经济：Token可持续+效益值得

## AI视角

### 这是什么？
AI的日常操作系统——启动→执行→收尾的标准流程。

### AI怎么接入？
1. 检测触发词："满意解执行" / "项目管理" / "三板斧"
2. 读取 SKILL.md 确认触发
3. 按执行手册操作：
   - 启动：读记忆→基线检查→确认模式
   - 执行：评估→三板斧→双经济自检→防中断
   - 收尾：蓝军审计→满意姐评估→Git提交→记忆追加

### 每日Checklist
```
□ 读取SOUL.md/USER.md/memory/MEMORY.md
□ 运行基线检查
□ 检查修复清单
□ 确认运行模式(L0-L4)
□ 双经济自检
□ 执行并记录进度
□ 蓝军审计
□ Git提交
□ 记忆追加
```

### 与人类协同
- AI按流程执行 → 人类抽查验证 → 飞轮监控
- 情感雷达在线：检测到情绪信号时，在执行间隙回应
