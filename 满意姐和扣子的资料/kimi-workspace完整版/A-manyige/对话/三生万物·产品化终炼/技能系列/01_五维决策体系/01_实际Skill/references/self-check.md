## 完整版（5分钟）

### 土（根基）
- [ ] 利益相关者已明确？
- [ ] 信任关系已评估？
- [ ] 有共同价值观基础？

### 金（标尺）
- [ ] "满意"标准已定义？
- [ ] 约束条件已明确？
- [ ] 不求最优只求最适？

### 水（流动）
- [ ] 至少2个备选方案？
- [ ] 信息充分可决策？
- [ ] 方向可灵活调整？

### 木（伦理）
- [ ] 符合仁义礼智信？
- [ ] 长期影响已考虑？
- [ ] 无人被不知情伤害？

### 火（转化）
- [ ] 直觉第一反应记录？
- [ ] 身体反应已觉察？
- [ ] 顿悟信号已捕捉？
