## 视频1：痛点共鸣型（1分钟）

**标题**: 老师傅退休那天，我才意识到...

**时长**: 60秒

### 分镜脚本

| 秒 | 画面 | 台词/字幕 | 音效 |
|:---|:-----|:----------|:-----|
| 0-3 | 黑屏，白字缓缓出现 | "老师傅退休那天" | 无 |
| 3-6 | 办公室场景，老师傅在收拾桌面 | "我才发现" | 轻柔钢琴 |
| 6-10 | 镜头切换到空荡的工位 | "他脑子里那些'多听几次就懂了'的东西" | 钢琴渐弱 |
| 10-15 | 文件柜打开，里面堆满文件但无序 | "全没了" | 翻页声 |
| 15-20 | 年轻人面对电脑，一脸茫然 | "新人还是从零开始" | 键盘敲击声 |
| 20-25 | 飞轮动画出现，开始缓慢转动 | "直到我们做了一个'数字徒弟'系统" | 齿轮声 |
| 25-30 | 飞轮加速，光芒四射 | "让知识变成会自己转的飞轮" | 飞轮加速声 |
| 30-40 | 对比画面：左边"传统传承"（老人讲，新人记）vs 右边"飞轮传承"（人判断，AI整理，双周对账） | "不是塞知识" | 对比音效 |
| 40-45 | 数据弹出：2年→3个月 | "新人上手，从2年缩到3个月" | 数据弹出音 |
| 45-50 | 老师傅微笑着点头 | "老师傅只需要'在场'，不用动手" | 温暖和弦 |
| 50-55 | 文件夹图标出现，标注"知识飞轮传承操作系统" | "文件夹已备好，内有完整指引" | 确认音 |
| 55-60 | 黑屏，白字 | "静水流深，流的是能让时间复利的方法" | 钢琴回归 |

**字幕风格**: 大字幕，关键词加粗，每句不超过8个字

**BGM**: 开场钢琴→中段节奏感→结尾温暖

## 视频2：知识科普型（2分钟）

**标题**: 什么是"知识飞轮"？30秒讲清楚

**时长**: 120秒

### 分镜脚本

| 秒 | 画面 | 台词/字幕 | 音效 |
|:---|:-----|:----------|:-----|
| 0-5 | 主持人出镜（或AI配音+动画） | "什么是知识飞轮？" | 提问音效 |
| 5-10 | 飞轮3D模型出现 | "不是知识库，不是培训课程" | 否定音效 |
| 10-15 | 飞轮开始转动，5个环节依次亮起 | "是5个环节组成的循环系统" | 点亮音效 |
| 15-25 | 环节1：老人做判断的画面 | "第一步：老人判断——哪些经验值千金" | 环节1音效 |
| 25-35 | 环节2：AI整理的画面 | "第二步：AI整理——变成可执行的任务清单" | 环节2音效 |
| 35-45 | 环节3：新人执行的画面 | "第三步：新人执行——按清单产出结果" | 环节3音效 |
| 45-55 | 环节4：发现新问题的画面 | "第四步：新洞察——发现'这个方法不适用'" | 环节4音效 |
| 55-65 | 环节5：知识更新的画面 | "第五步：回流——更新知识库，下次更聪明" | 环节5音效 |
| 65-75 | 飞轮转动的全景，越转越快 | "转一圈，知识增值一次" | 飞轮加速 |
| 75-85 | 对比数据：传统传承 vs 飞轮传承 | "传统：2年上手。飞轮：3个月上手" | 数据对比音 |
| 85-95 | 真实案例快闪：法律/咨询/制造 | "已验证3个行业" | 案例音效 |
| 95-105 | 主持人出镜总结 | "人判断，AI整理，双周对账" | 总结音效 |
| 105-115 | 二维码/链接出现 | "获取完整指引" | 引导音效 |
| 115-120 | 黑屏金句 | "不求最优，但求最适" | 结束音效 |

**字幕风格**: 每环节配大字标题，数据用动态图表

**BGM**: 轻快的电子乐，节奏感强
