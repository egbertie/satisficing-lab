# 与其他产品协作

> 海啸→飞轮→课程→传播全链路
> 编号: SSW-258

---

## 协作全景图

```
原始散乱文件
    ↓
[知识海啸处理器] → 08_标准传承包（L3质量）
    ↓
[知识飞轮传承操作系统] → 可执行传承（开/关模式）
    ↓
[五维决策体系] → 校准与优化
    ↓
[蓝军审计] → 质量验证
    ↓
[课程级别] → 培训素材
    ↓
[传播级别] → 触达受众
```

## 与知识飞轮传承操作系统协作

| 协作点 | 海啸处理器输出 | 飞轮系统输入 |
|:-------|:-------------|:-------------|
| 标准传承包 | 08_标准传承包/ | 进入"开"模式（Handover） |
| P0核心知识 | 01_P0核心层/ | 核心资产清单 |
| 隐性知识 | 04_隐性知识/ | 需人工补充清单 |
| 质量报告 | 05_质量报告.md | 自检参考 |

## 与五维决策体系协作

- 海啸处理器自动标注五维映射
- 五维决策体系对映射进行校准
- 冲突时提交 `conflict-resolver.py` 裁决

## 与蓝军审计协作

- 蓝军审计传承包质量
- 发现至少1个问题
- 输出风险等级和整改清单

## 双向循环

```
[知识海啸处理器] → 标准传承包 → [知识飞轮传承]
      ↑                                    ↓
   修正反馈                            使用反馈
      ↑                                    ↓
   新散乱文件 ← 实践产生 ← [用户工作场景]
```
