# 并发与性能架构

> 调度/队列/断点续传全量说明
> 编号: SSW-256

---

## 并发模型

```
┌─────────────────────────────────────┐
│         任务调度器 (Scheduler)       │
│         最大并发: 20文件             │
├─────────────────────────────────────┤
│  队列1: 文字处理 (8并发)  │  队列2: OCR处理 (4并发)  │
│  队列3: 代码解析 (4并发)  │  队列4: 数据表格 (4并发)  │
└─────────────────────────────────────┘
```

**调度策略**:
- P0文件优先处理
- 同类型文件批量处理（减少上下文切换）
- 大文件自动降级到低优先级队列
- 内存不足时触发分块加载

## 断点续传机制

每完成一个批次，自动生成检查点:
- `checkpoint-batch-{N}.json`（进度状态）
- 中断后从最后检查点恢复
- 支持手动指定恢复点
- 错误批次自动重试（最多3次）

## 资源限制策略

| 资源 | 限制 | 超限处理 |
|:-----|:-----|:---------|
| 内存 | 16GB | 分块加载+临时文件溢出 |
| 磁盘 | 输入×2 | 自动清理临时文件 |
| CPU | 8核 | 队列等待+优先级调度 |
| 时间 | 单批次≤4小时 | 自动保存进度+可中断 |
