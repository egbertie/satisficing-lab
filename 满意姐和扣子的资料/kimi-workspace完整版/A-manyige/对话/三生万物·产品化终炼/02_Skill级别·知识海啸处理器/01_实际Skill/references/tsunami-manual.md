## 一、产品定位

**知识海啸处理器** = 海量散乱信息 → 结构化知识资产的**转化器**

### 解决的痛点

| 痛点 | 传统做法 | 知识海啸处理器 |
|:-----|:---------|:---------------|
| 1000+文件杂乱无章 | 人工整理3-6个月 | 机器处理7天+人工确认7小时 |
| 不知道哪些是核心 | 凭感觉判断 | 机器分析+人工确认 |
| 隐性知识传不出去 | 说不清楚 | 模板引导+场景化表达 |
| 质量不稳定 | 依赖整理者水平 | 标准化模板+五维映射 |
| 承者接不住 | 给一堆文件自己看 | 结构化传承包+阅读指引 |

### 核心假设

1. **机器做80%，人做20%**: 机器负责批量处理，人负责关键决策
2. **不完美优于不存在**: 70%质量的传承包 > 没有传承包
3. **渐进式优化**: 先交付可用版本，再持续迭代
4. **人机协同**: 机器推荐，人拍板

## 二、五步处理流程详解

### Step 1: 海啸导入（Tsunami Ingest）

**目标**: 把散乱文件"扫"进系统

**输入**: 任意文件夹（含子文件夹）
**输出**: 
- `01_初始索引.json`（完整文件列表+元数据）
- `02_文件元数据.csv`（Excel可打开）
- `00_扫描报告.md`（统计概览）

**执行**:
```bash
python3 scripts/tsunami-ingest.py --input /path/to/your/files --output ./tsunami-output/
```

**关键参数**:
- `--input`: 原始文件文件夹路径
- `--output`: 输出文件夹路径

**处理内容**:
- 递归扫描所有文件（跳过隐藏文件）
- 识别文件类型（文档/图片/音频/视频/代码/压缩包/其他）
- 提取元数据（文件名、扩展名、大小、修改时间、路径深度）
- 生成统计报告（按类型/扩展名/深度分布）

**耗时**: 约1000个文件/10分钟

**人工干预**: 无需

---

### Step 2: 智能分类（Smart Triage）

**目标**: 自动分类并标记优先级

**输入**: `01_初始索引.json`
**输出**:
- `03_分类索引.md`（按P0/P1/P2/P2分类的阅读顺序）
- `04_P0-P1-P2标记.json`（机器分类结果）

**执行**:
```bash
python3 scripts/smart-triage.py --input ./tsunami-output/01_初始索引.json --output ./tsunami-output/
```

**分类规则**:

| 类别 | 关键词示例 | 默认优先级 |
|:-----|:-----------|:-----------|
| 核心知识 | 核心、关键、原则、方法论、框架 | P0 |
| 案例研究 | 案例、项目、案件、经验、实战 | P1 |
| 模板工具 | 模板、工具、清单、表格 | P1 |
| 流程指南 | 流程、步骤、操作、SOP | P1 |
| 参考资料 | 参考、文献、论文、报告 | P2 |
| 沟通记录 | 邮件、会议、纪要、讨论 | P2 |
| 个人笔记 | 笔记、备忘、日记、随想 | P2 |
| 草稿临时 | 草稿、临时、备份、旧版 | P3 |

**P0强制规则**（高优先级覆盖）:
- 文件名含"README/INDEX/总纲/导览"
- 文件名含"核心知识/方法论/框架"
- 编号靠前的文件（如00_, 01_）

**P3强制规则**（低优先级覆盖）:
- 文件名含"草稿/draft/temp/备份"
- 副本文件（copy/副本/复件）
- 临时文件（~$）

**⚠️ 重要**: 机器分类准确率约70-80%，**必须人工确认**

**耗时**: 约1000个文件/15分钟

**人工干预**: 确认P0/P1/P2标记（2小时）

---

### Step 3: 核心萃取（Core Extraction）

**目标**: 从海量文件中提取≤5项核心知识

**输入**: `03_分类索引.md` + 原始文件
**输出**:
- `05_核心知识清单.md`（机器萃取的核心知识候选）
- `06_隐性知识候选.md`（可能含隐性知识的文件）

**执行**:
```bash
python3 scripts/core-extractor.py --input ./tsunami-output/ --output ./tsunami-output/
```

**萃取方法**:

1. **全局关键词分析**
   - 扫描所有P0文件的文本内容
   - 统计词频（出现>3次的概念）
   - 提取Top 30高频词

2. **核心知识生成**
   - 从高频词中选出Top 5作为"核心知识候选"
   - 每项标注：名称、出现频率、置信度、来源
   - 生成"传者确认区"（供人工确认）

3. **隐性知识识别**
   - 扫描文件名和内容中的信号词（感觉、经验、诀窍、分寸等）
   - 标记"案例研究"和"个人笔记"类文件（通常含隐性知识）
   - 生成"隐性知识候选清单"

**⚠️ 重要**: 
- 机器只能识别"高频概念"，真正的核心知识需要传者确认
- 隐性知识候选只是"可能"，需要传者用模板提取

**耗时**: 约1000个文件/30分钟

**人工干预**: 
- 确认核心知识清单（1小时）
- 提取隐性知识（2小时）

---

### Step 4: 质量转化（Quality Transform）

**目标**: 转化为三生万物级别质量的知识资产

**输入**: `05_核心知识清单.md` + 原始文件
**输出**: `07_质量转化包/`（含阅读指引+五维映射+导览）

**执行**:
```bash
python3 scripts/quality-transform.py --input ./tsunami-output/ --output ./tsunami-output/07_质量转化包/
```

**转化内容**:

1. **阅读指引**（每个文件）
   - 优先级标记
   - 建议阅读时间
   - 前置要求
   - 核心产出
   - 验证方法
   - 困惑信号

2. **五维映射**（每个文件）
   - 土（根基/品德）相关度和自检问题
   - 金（标尺/质量）相关度和自检问题
   - 水（流动/智慧）相关度和自检问题
   - 木（生长/伦理）相关度和自检问题
   - 火（转化/行动）相关度和自检问题
   - 综合评分表

3. **导览总纲**
   - 人类视角导览（面向传者/承者）
   - AI视角导览（面向AI助手）
   - 五维决策底层逻辑

**⚠️ 重要**: 
- 阅读指引是机器推断的，可能不准确
- 五维映射的评分需要传者填写

**耗时**: 约1000个文件/1小时

**人工干预**:
- 修正阅读指引（1小时）
- 填写五维映射评分（1小时）

---

### Step 5: 输出打包（Package Builder）

**目标**: 生成可直接交付的标准传承包

**输入**: `07_质量转化包/`
**输出**: `08_标准传承包/`（可直接交付）

**执行**:
```bash
python3 scripts/package-builder.py --input ./tsunami-output/07_质量转化包/ --output ./08_标准传承包/
```

**输出结构**:
```
08_标准传承包/
├── README.md                    ← 入口文件
├── 00_开篇语.md                 ← 这是什么、给谁用、怎么用
├── 00_导览总纲/
│   ├── 01_人类视角导览.md
│   ├── 02_AI视角导览.md
│   └── 03_五维决策底层逻辑.md
├── 01_P0核心层/                 ← 必须传
│   ├── 00_核心知识清单.md
│   └── [每个P0文件一个子文件夹]/
│       ├── 原文_[文件名]
│       ├── 阅读指引.md
│       └── 五维映射.md
├── 02_P1支撑层/                 ← 应该传
├── 03_P2背景层/                 ← 可以传
├── 04_隐性知识/                 ← 最难传
├── 05_原始文件索引/             ← 全部原始文件索引
├── 06_检验清单/                 ← 自检和验收工具
└── 07_附录/                     ← 处理日志和统计
```

**耗时**: 约10分钟

**人工干预**: 无需（但后续需要传者确认）

## 三、人工确认清单（关键！）

**机器处理完成后，传者必须完成以下确认**：

### 确认1: P0/P1/P2标记（2小时）

```
□ 检查所有P0文件：是否"没有它系统会崩溃"？
  → 如果是，保留P0
  → 如果不是，降级为P1或P2

□ 检查所有P1文件：是否"没有它效率降低50%"？
  → 如果是，保留P1
  → 如果不是，降级为P2

□ 检查所有P2文件：是否"有了更好，没有也行"？
  → 如果是，保留P2
  → 如果不是，降级为P3或删除

□ 检查所有P3文件：是否"存了也不会用"？
  → 如果是，删除或归档
  → 如果不是，升级为P2
```

### 确认2: 核心知识清单（1小时）

```
□ 机器列出的Top 5高频词是否真的是核心？
  → 如果有遗漏，补充
  → 如果有不重要的，删除

□ 如果只能传3项，是哪3项？
  → 回答为什么

□ 哪些知识是"传了也没用"的？
  → 删除
```

### 确认3: 隐性知识提取（2小时）

```
□ 检查隐性知识候选清单
□ 对每个有效候选，使用模板提取：
  → 场景：当遇到______时
  → 我的判断：我会选______
  → 判断依据：第一看…第二看…第三看…
  → 常见陷阱：新手容易…
  → 我的验证方法：…

□ 如果候选文件没有隐性知识，标记"无"并移出
```

### 确认4: 五维映射评分（1小时）

```
□ 随机检查5个文件的"五维映射.md"
□ 填写每个维度的"深度"和"评分"
□ 计算总分
□ 如果总分<20，考虑是否删除该文件
```

### 确认5: 阅读指引修正（1小时）

```
□ 随机检查5个文件的"阅读指引.md"
□ 修正不准确的"前置要求"
□ 修正不准确的"核心产出"
□ 修正不准确的"验证方法"
```

**总计**: 约7小时人工确认 → 质量从80%提升到95%

## 四、系统上限与降级方案

### 正常处理（≤1000个文件）

- 按标准五步流程执行
- 机器处理2-3天
- 人工确认7小时
- 输出标准传承包

### 超大规模处理（1000-10000个文件）

- **分批处理**: 每批1000个文件
- **抽样分析**: 不分析全部，抽样分析10%
- **分层索引**: 先生成总索引，再逐层深入
- **预估时间**: 机器5-7天，人工确认2-3天

### 极端规模处理（>10000个文件）

- **预筛选**: 先删除明显无关的文件（如系统文件、临时文件）
- **抽样萃取**: 只分析5%的文件，推断整体
- **人工主导**: 机器辅助，人做主要决策
- **预估时间**: 机器7-14天，人工确认1周

### 降级方案（时间紧急）

**极速版（1天完成）**:
```
Step 1: 海啸导入（自动，1小时）
Step 2: 智能分类（自动，1小时）
Step 3: 跳过核心萃取，直接用P0文件列表
Step 4: 只生成阅读指引（不生成五维映射）
Step 5: 简单打包
人工确认: 只确认P0标记（1小时）
总计: 约4小时
质量: 约70%（可用，但需后续优化）
```

## 五、常见问题

**Q1: 机器分类准确率多少？**
A: 约70-80%。文件名清晰的准确率更高。人工确认是必须的。

**Q2: 1000个文件处理要多久？**
A: 机器约2-3天（自动运行），人工确认约7小时（分2-3天完成）。

**Q3: 如果文件是手写笔记/扫描件怎么办？**
A: 先使用OCR工具转化为文本，再使用海啸处理器。OCR不属于本skill范围。

**Q4: 处理过程中可以中断吗？**
A: 可以。每个Step都有持久化输出，中断后从当前Step继续。

**Q5: 输出质量能达到"创始人5分钟可用"吗？**
A: 经过人工确认后，可以。机器单独输出约80%质量。

**Q6: 可以处理非中文文件吗？**
A: 可以。文件名和关键词分析支持中英文，但隐性知识识别主要优化中文。

**Q7: 如果传者不会用Python怎么办？**
A: 可以请技术人员执行脚本，传者只需做"人工确认"部分。脚本执行可以外包。
