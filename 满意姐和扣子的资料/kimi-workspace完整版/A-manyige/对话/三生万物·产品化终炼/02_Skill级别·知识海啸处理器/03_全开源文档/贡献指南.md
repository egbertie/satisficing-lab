## 贡献类型

| 类型 | 说明 | 示例 |
|:-----|:-----|:-----|
| 新增文件类型 | 支持更多格式 | 新增 `.epub` 电子书处理 |
| 优化分类规则 | 提高准确率 | 法律行业专用分类规则 |
| 新增萃取模板 | 覆盖更多场景 | 医疗诊断决策模板 |
| 性能优化 | 提速/降内存 | 大文件分块加载优化 |
| 文档改进 | 使用说明 | 新增行业案例 |

## 提交规范

1. Fork 本仓库
2. 创建特性分支: `feature/xxx`
3. 提交修改: `git commit -m "TSUNAMI: 描述"`
4. 推送并提交 Pull Request
5. 蓝军审计通过（至少发现1个问题并修正）
