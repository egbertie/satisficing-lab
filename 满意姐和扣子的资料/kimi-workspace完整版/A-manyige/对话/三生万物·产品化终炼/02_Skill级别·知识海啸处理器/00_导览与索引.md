## 四、五维决策底层逻辑

### 土（信任基础）— 为什么可靠
- **来源**: 基于满意姐54天实战经验 + 梁主席70年法律积累场景提炼
- **验证**: 46文件实测通过，5步流水线跑通
- **兼容**: 与知识飞轮传承操作系统完全兼容（复用P0/P1/P2、五维映射、双视角）

### 金（满意标准）— 质量如何保障
- **分类准确率**: 85%（规则引擎+关键词混合）
- **核心萃取上限**: ≤5项/批（防止信息过载）
- **隐性知识识别**: 60%自动 + 人工确认后95%
- **质量等级**: L1-L5，默认L3（标准传承）
- **验收标准**: 6项检查清单（见 quality-standards.md）

### 水（灵活应变）— 能适应什么场景
- **规模弹性**: 极速版(100文件) → 标准版(1000) → 完整版(10000) → 极限版(100000)
- **类型弹性**: 主处理10种文字类型 + 5种图片OCR + 5种辅助类型
- **质量弹性**: L1极速草稿 → L5经典资产，按需选择
- **并发弹性**: 1-50文件并发，自动队列调度

### 木（生长发展）— 如何迭代进化
- **版本机制**: V1.0 → V2.0（外求资源 + 实战反馈驱动）
- **反馈闭环**: 使用→问题→修正→升级→再使用
- **贡献开放**: 参考知识飞轮传承操作系统开源模式
- **技能联动**: 输出接入五维决策体系、蓝军审计、执行系统

### 火（直觉确认）— 核心洞察
- **核心假设**: 机器做80%（扫描/分类/统计/重组），人做20%（确认P0/提取隐性知识/评分五维）
- **关键洞察**: 杂乱无章的信息本身有价值，缺少的是"结构化桥梁"
- **价值转化**: 散乱文件 → 标准传承包 → 可执行知识资产

## 五、人类视角快速入口

### 5.1 我是传者（有散乱文件要处理）

**快速路径**:
1. 确认文件量级 → 读 `理论最大量参数手册.md`（SSW-254）
2. 确认文件类型 → 读 `文件类型支持详解.md`（SSW-253）
3. 选择质量等级 → 读 `质量等级操作指南.md`（SSW-257）
4. 执行五步流水线 → 读 `快速上手指南.md`（SSW-252）
5. 验收输出包 → 用 `quality-standards.md` 的验收清单

### 5.2 我是承者（要接手处理后的传承包）

**快速路径**:
1. 读传承包中的 `00_索引.md`
2. 按 `05_阅读指引.md` 顺序阅读
3. 先读 `01_P0核心层/`（≤5项核心知识）
4. 再按需深入 `02_P1支撑层/`
5. 最后参考 `03_P2背景层/`

### 5.3 我是管理者（评估是否引入）

**评估清单**:
- [ ] 团队是否有100+散乱文件待整理？
- [ ] 现有整理方式是否耗时超过3天/次？
- [ ] 整理后的文件是否缺少结构化索引？
- [ ] 是否有跨代传承需求（老人→新人）？
- [ ] 是否需要将非结构化信息转化为培训材料？

如果≥3项勾选 → 引入海啸处理器

### 6.2 我是工作AI（日常使用）

**标准工作流**:
```
收到散乱文件目录
  → 运行 tsunami-ingest.py（扫描+索引）
  → 运行 smart-triage.py（分类+标记P0-P3）
  → 人工确认P0标记（关键步骤，不可跳过）
  → 运行 core-extractor.py（萃取核心知识）
  → 人工确认隐性知识候选
  → 运行 quality-transform.py（五维映射+双视角）
  → 运行 package-builder.py（输出标准传承包）
  → 验收：按 quality-standards.md 检查
  → 交付：传承包进入知识飞轮传承操作系统
```

### 6.3 权限边界

**可自主执行**:
- 扫描文件、生成索引、自动分类（P0-P3初标）
- 统计报告、元数据提取、去重合并

**需人类确认**:
- P0标记确认（机器建议，人类拍板）
- 隐性知识提取（机器候选，人类验证）
- 五维映射评分（机器初标，人类校准）
- 质量等级判定（机器建议，人类确认）

## 八、常见问题FAQ

**Q1: "我的文件只有50个，需要用海啸处理器吗？"**
A: 50个文件可以用极速版（1-4小时），但也可以手工整理。建议≥100文件或文件类型混杂时引入。

**Q2: "处理后的传承包质量能达到契晋纪/三生万物级别吗？"**
A: 默认L3质量（标准传承），经过人工确认后可达L4（精品知识）。达到L5（经典资产）需要多轮迭代+专家审核。

**Q3: "图片中的手写文字能识别吗？"**
A: 印刷体识别率较高，手写体质量会下降，标记为P3需人工确认。建议手写文件单独处理。

**Q4: "处理10,000个文件需要多长时间？"**
A: 完整版约7-10天（机器自动）+ 3天（人工确认）。可拆分为多个批次并行处理。

**Q5: "如果我中途想修改分类规则怎么办？"**
A: 修改 `references/classification-rules.md`，重新运行 Step 2（smart-triage.py）。支持断点续传，无需从头开始。

**Q6: "传承包生成后，原来的散乱文件可以删除吗？"**
A: 建议保留至少30天，确认传承包质量后再归档。使用 `--archive-source` 参数可自动归档源文件。
