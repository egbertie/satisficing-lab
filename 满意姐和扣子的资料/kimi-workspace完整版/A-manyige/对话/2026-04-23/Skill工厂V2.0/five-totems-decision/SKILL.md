# Five Totems Decision Framework

## Overview

The Five Totems (五路图腾) represent five dimensions of decision-making:

| Totem | Element | Name | Core Principle | Modern Expert |
|-------|---------|------|----------------|---------------|
| 土 | Earth | 刘禹锡 | Trust and integrity as foundation | 黎红雷 (Confucian business ethics) |
| 金 | Metal | 司马贺 | Satisficing and bounded rationality | 罗汉 (Mathematics/Software Engineering) |
| 水 | Water | 观自在 | Inward awareness and non-attachment | 谢宝剑 (Shenzhen-HK strategy) |
| 木 | Wood | 孔子 | Ethical governance and five virtues | 黎红雷 (Confucian business ethics) |
| 火 | Fire | 六祖慧能 | Intuitive breakthrough and awakening | 方翊沣 (Neuroscience/BCI) |

Read `references/framework.md` for complete theoretical construction.

## Core Capabilities

### 1. Five-Dimensional Assessment

When evaluating any decision or partnership:

1. Score each of the 5 dimensions (1-10)
2. Identify the weakest dimension — this is the constraint
3. Apply the corresponding totem's wisdom to strengthen it
4. Check for dimension conflicts (e.g., 金·boundaries vs 火·intuition)

Read `references/framework.md` §3 for scoring methodology.

### 2. 13-Type Conflict Diagnosis

When a partnership conflict arises:

1. Match symptoms to one of 13 conflict types
2. Map the conflict to the 5 totems — which dimensions are most affected?
3. Generate intervention strategy using the affected totems' wisdom
4. Provide escalation guidance if type is 🔴高危

Read `references/conflict-typology.md` for complete type definitions with symptoms, 
totem mappings, and intervention strategies.

### 3. Totem Activation Sequence

For morning rituals or decision preparation:

1. **土·刘禹锡** — Ground in trust and integrity
2. **金·司马贺** — Set the satisficing threshold
3. **水·观自在** — Scan for risks with calm awareness
4. **木·孔子** — Check ethical boundaries
5. **火·六祖慧能** — Ignite intuitive readiness

Read `references/framework.md` §4 for ritual details.

### 4. Workshop Facilitation

When facilitating a Five Totems workshop:

1. Open with the user's real story (hook)
2. Introduce one totem at a time with physical anchor
3. Use the partner decision card game for practice
4. Close with personal commitment (契) and growth vow (晋)

Read `references/workshop-guide.md` for complete facilitation script.

## Key Formulas

**Satisficing Threshold**: 
```
Acceptable Outcome = Minimum Viable Standard + Safety Margin
```

**Five-Dimensional Score**:
```
Overall Readiness = MIN(土, 金, 水, 木, 火)
```
(Chain is only as strong as its weakest link)

**Conflict Severity**:
```
🔴 = 3+ dimensions affected AND emotional damage present
🟡 = 2 dimensions affected OR trust breach suspected
🟢 = 1 dimension affected, contained
```
