## 二、设计理念

### 2.1 大脑银行三层架构

```
Layer 1: 知识层 (Knowledge)
    ↓ 游戏化封装
Layer 2: 体验层 (Experience)  ← 卡牌游戏系列
    ↓ 习惯化内化
Layer 3: 本能层 (Instinct)    ← 日常训练工具
```

卡牌游戏是 Layer 2 的核心载体——把 Layer 1 的抽象知识转化为可触摸、
可互动、可记忆的体验。

### 2.2 游戏设计原则

| 原则 | 说明 | 反面 |
|:-----|:-----|:-----|
| **教育即娱乐** | 玩家在游戏中自然习得，不自知在学习 | 说教式卡牌 |
| **决策即玩法** | 每一次卡牌抽取都是一次微型决策 | 纯运气抽卡 |
| **关系即场景** | 多人游戏模拟真实合伙关系动态 | 单机对抗 |
| **失败即反馈** | 游戏中的"错误"提供即时学习 | 惩罚机制 |
| **重复即深化** | 同一框架反复出现，形成肌肉记忆 | 一次用完 |

### 2.3 与大富翁的差异化

| 维度 | 传统大富翁 | 满意解系列 |
|:-----|:----------|:-----------|
| 目标 | 积累财富 | 积累信任+智慧 |
| 冲突 | 零和竞争 | 合作-竞争平衡 |
| 决策 | 简单选择 | 多维度满意解权衡 |
| 结局 | 唯一赢家 | 多人共赢路径 |
| 学习 | 无 | 每次游戏都有决策日志 |

## 三、各游戏详设

### 游戏1: 五路图腾·合伙人决策卡

**定位**: 旗舰产品，五维决策框架的体验化入口

**玩家**: 2-6人，适合工作坊、训练营、团队建设
**时长**: 60-90分钟
**场地**: 桌面，需要空间摆放五维版图

**核心机制**:

1. **角色抽取**: 每位玩家抽取一个图腾角色（土/金/水/木/火）
2. **场景卡**: 抽取合伙决策场景（融资、分工、退出等）
3. **五维评估**: 每位玩家从自己的图腾视角评估场景
4. **维度卡**: 打出维度卡增强或削弱某个维度
5. **共识达成**: 集体决策，记录五维得分
6. **契晋仪式**: 游戏结束时的承诺与成长

**卡牌构成**:

| 卡牌类型 | 数量 | 功能 |
|:---------|:----:|:-----|
| 图腾角色卡 | 5张 | 定义玩家视角和能力 |
| 场景卡 | 50张 | 真实合伙决策情境 |
| 维度卡 | 40张 | 增强/削弱/转换维度 |
| 事件卡 | 30张 | 突发事件（外部压力、家庭介入等） |
| 契晋卡 | 10张 | 游戏结束时的承诺仪式 |

**胜利条件**: 不是击败对手，而是通过场景后五维总分提升最多。

---

### 游戏2: 13类型冲突·诊断卡

**定位**: 冲突诊断工具，单人自测或团队讨论

**玩家**: 1-6人
**时长**: 20-40分钟
**场地**: 任何桌面

**核心机制**:

1. **症状卡**: 抽取症状描述（"我们三个月没说话了"）
2. **类型匹配**: 从13类型中选择最匹配的冲突类型
3. **图腾映射**: 判断哪些维度受影响
4. **干预卡**: 选择干预策略
5. ** severity 评估**: 判断🔴🟡🟢
6. **方案生成**: 输出结构化建议

**卡牌构成**:

| 卡牌类型 | 数量 | 功能 |
|:---------|:----:|:-----|
| 症状卡 | 65张 | 5张/类型，覆盖各种表现 |
| 类型卡 | 13张 | 冲突类型定义 |
| 干预卡 | 39张 | 3张/类型，不同策略 |
| 严重度卡 | 10张 | 事件升级或降级 |

**使用模式**:
- **单人模式**: 自测当前 partnership 健康度
- **双人模式**: 双方各自诊断，对比结果
- **团队模式**: 讨论真实案例，集体学习

---

### 游戏3: 满意解大富翁

**定位**: 创业决策全流程模拟，团队建设神器

**玩家**: 2-4人
**时长**: 90-120分钟
**场地**: 大桌面，类似传统大富翁版图

**核心机制**:

1. **角色创建**: 每位玩家创建自己的"创始人角色"（技能点分配）
2. **棋盘推进**: 掷骰子前进，每格是一个决策点
3. **五维资源**: 收集土/金/水/木/火五种资源
4. **合伙人相遇**: 棋盘上相遇可形成 partnership
5. **冲突事件**: 抽取冲突卡，考验 partnership
6. **里程碑**: 通过关键节点获得胜利点数
7. **满意解判定**: 游戏结束时，评估 overall 满意度而非单纯财富

**棋盘设计**:

```
起点 → 种子期 → 合伙人相遇 → 天使轮 → 团队扩张 → 
A轮 → 文化冲突 → B轮 → 退出抉择 → IPO/并购/独立 → 终点
```

**创新点**:
- 可以"满意解退出"——不一定追求IPO，达到满意阈值即可获胜
- partnership 可以解散重组
- 每位玩家有"直觉骰"（火）和"分析骰"（金），不同情境用不同骰

---

### 游戏4: 契晋·双人对话卡

**定位**: 合伙人深度对话工具，关系修复与建立

**玩家**: 2人
**时长**: 30-60分钟
**场地**: 安静私密空间

**核心机制**:

1. **热身轮**: 轻松问题建立安全感（"你最喜欢的决策是什么？"）
2. **探索轮**: 深度问题（"你最担心这个 partnership 的什么？"）
3. **挑战轮**: 对抗性问题（"如果我们必须分开，你会怎么做？"）
4. **承诺轮**: 契卡——双方各写一句承诺
5. **成长轮**: 晋卡——双方各写一句成长愿望
6. **封存仪式**: 将契晋卡放入信封，约定开启时间

**卡牌构成**:

| 卡牌类型 | 数量 | 功能 |
|:---------|:----:|:-----|
| 热身卡 | 20张 | 破冰问题 |
| 探索卡 | 30张 | 深度对话 |
| 挑战卡 | 20张 | 压力测试 |
| 契卡 | 10张 | 承诺模板 |
| 晋卡 | 10张 | 成长模板 |

**设计原则**: 问题设计基于心理学安全递进模型，确保不会过早暴露脆弱。

---

### 游戏5: 0.3秒觉察·快反卡（线上）

**定位**: 日常直觉训练APP，个人决策素养养成

**玩家**: 1人
**时长**: 每日5-10分钟
**平台**: 微信小程序 / APP

**核心机制**:

1. **每日情境**: 推送一个决策情境（"合伙人提出改变股权结构"）
2. **0.3秒反应**: 限时3秒，选择直觉反应
3. **分析回合**: 不限时，进行结构化分析
4. **对比反馈**: 显示直觉 vs 分析的差异
5. **模式识别**: 长期追踪用户的直觉准确率
6. **训练升级**: 根据表现调整情境难度

**特色功能**:
- **神经反馈集成**: 如用户有可穿戴设备，可记录心率变异性（HRV）
- **决策日志**: 自动记录所有决策，生成个人决策风格报告
- **社区对比**: 匿名查看同龄/同行业的决策模式

---

### 游戏6: 寻根之旅·地点卡

**定位**: 寻根之旅的辅助工具，增强物理锚点体验

**玩家**: 1-6人（配合实地旅行）
**时长**: 随旅程（11天）
**场地**: 五个朝圣地点

**核心机制**:

1. **地点卡**: 每到一个地点，抽取该地点的仪式卡
2. **任务卡**: 完成特定任务（"在阏伯台点燃一支蜡烛"）
3. **记录卡**: 记录当下的感受和决定
4. **分享卡**: 与其他玩家（如团队旅行）分享体验
5. **整合卡**: 旅程结束时，整合所有地点的收获

**与实体 pilgrimage 配合**:
- 实体卡牌作为纪念品
- 扫码解锁线上内容（专家语音讲解、冥想引导）
- 完成全部地点解锁"五维觉醒"数字证书

---

### 游戏7: 满意解·每日一卡（线上）

**定位**: 日常决策素养微训练

**玩家**: 1人
**时长**: 每日2-3分钟
**平台**: 微信小程序 / 订阅号推送

**核心机制**:

1. **晨间抽卡**: 每日随机抽取一张决策原则卡
2. **情境应用**: 用户简要记录今日如何应用该原则
3. **晚间回顾**: 晚上推送回顾，评估应用效果
4. ** streak 追踪**: 连续打卡记录
5. **周度报告**: 每周生成决策素养趋势

**卡牌库**: 100+张原则卡，覆盖五维决策、冲突处理、情绪管理等

---

### 游戏8: 决策成熟度·测评卡（线上）

**定位**: 决策能力诊断与成长追踪

**玩家**: 1人
**时长**: 初次15分钟，后续每次5分钟
**平台**: 网页 / APP

**核心机制**:

1. **维度测评**: 五维度自评（1-10分）
2. **情境测试**: 3个决策情境，记录选择过程
3. **成熟度评分**: 生成 Overall Maturity Score
4. **成长路径**:  weakest dimension 的改进建议
5. **定期复测**: 建议每3个月复测，追踪成长

**与线下联动**: 测评结果可导入"五路图腾·合伙人决策卡"作为角色能力值

## 七、风险与应对

| 风险 | 影响 | 应对 |
|:-----|:-----|:-----|
| 游戏复杂度太高 | 用户学习成本 | 设计"5分钟上手"快速规则 |
| 教育内容太明显 | 用户抗拒"被教育" | 隐藏教学，强调娱乐 |
| 实体卡牌成本 | 毛利率低 | 众筹预售，控制首印量 |
| 线上游戏同质化 | 差异化不足 | 深度绑定五维决策IP |
| 用户留存低 | 一次性消费 | 订阅制+社区+数据追踪 |
