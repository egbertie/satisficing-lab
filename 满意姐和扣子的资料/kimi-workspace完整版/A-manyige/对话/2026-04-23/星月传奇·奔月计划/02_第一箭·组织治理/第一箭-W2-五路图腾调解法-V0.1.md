# 五路图腾调解法 V0.1

> **工具定位**: 合伙人冲突时，用五维框架系统化解  
> **适用场景**: 合伙人意见分歧、价值观冲突、决策僵局  
> **核心理念**: 冲突不是敌人，是系统需要升级的信号

---

## 一、调解原则

### 1.1 五维调解 ≠ 和稀泥

| 传统调解 | 五路图腾调解 |
|:--------:|:------------:|
| "各退一步" | "找到根因" |
| "差不多就行" | "标准清晰" |
| "听双方的" | "觉察深层需求" |
| "讲道德" | "伦理底线" |
| "尽快结束" | "创造性解决" |

### 1.2 调解者角色

**不是裁判**，是**流程引导者**——引导合伙人自己找到解决方案。

---

## 二、五路图腾调解流程（5步法）

### Step 1: 土·信义——建立安全空间（10分钟）

**目标**: 让双方愿意开口

**行动清单**:
- [ ] 选择中立地点（不在任何一方的办公室）
- [ ] 明确规则: "今天不评判，只听"
- [ ] 重申共同目标: "我们都想让公司好"
- [ ] 保密承诺: "今天说的，不对外传"

**开场白**:
> "我们今天不是来争对错的，是来找到让公司更好的路。
> 我相信你们都想让公司好，否则不会坐在这里。
> 所以，让我们先放下立场，说说各自的担忧。"

**信号**: 双方开始说话，不再防御 → ✅ 进入下一步

---

### Step 2: 金·标尺——明确评估标准（15分钟）

**目标**: 让双方用同一套标准评估

**行动清单**:
- [ ] 写下决策的核心标准（如: 客户利益>团队利益>个人利益）
- [ ] 双方确认标准优先级
- [ ] 如果有分歧，先解决标准分歧

**关键提问**:
- "如果一年后回头看，什么结果算'好'？"
- "我们的核心标准是什么？利润？客户满意度？团队稳定？"
- "如果只能选一个，哪个最重要？"

**常见陷阱**:
- 双方用不同标准 → 永远吵不完
- 标准模糊 → 谁都可以说自己对

**解决方案**: 强制排序——列出所有标准，必须排出1-2-3

---

### Step 3: 水·觉察——倾听深层需求（20分钟）

**目标**: 听到"话下面的需求"

**行动清单**:
- [ ] A方陈述（5分钟，不打断）
- [ ] B方复述A的需求（"我听到你说的是……"）
- [ ] A方确认/修正（"对/不对，我真正需要的是……"）
- [ ] B方陈述（5分钟，不打断）
- [ ] A方复述B的需求
- [ ] B方确认/修正

**深层需求对照表**:

| 表面立场 | 深层需求 |
|:--------:|:--------:|
| "我要更多股权" | "我需要安全感" |
| "这个方向不对" | "我担心失控" |
| "他做事太慢" | "我需要效率" |
| "她不尊重我" | "我需要认可" |
| "必须按我说的做" | "我需要掌控感" |

**调解者任务**: 帮双方把"立场"翻译成"需求"

> "你说'要更多股权'，背后是'担心未来没有保障'，对吗？
> 他说'方向不对'，背后是'担心公司走错路'，对吗？
> 你们的需求其实不冲突——都需要安全感。"

---

### Step 4: 木·伦理——检查伦理底线（10分钟）

**目标**: 确保解决方案不触碰伦理红线

**检查清单**:
- [ ] 是否有人会被不公平对待？
- [ ] 是否有人会被欺骗？
- [ ] 是否符合公司价值观？
- [ ] 是否符合法律？
- [ ] 如果公开，我们会羞愧吗？

**伦理底线**:
1. **不说假话**——即使对己方有利
2. **不伤害**——解决方案不能故意伤害任何一方
3. **不逃避**——该承担的责任要承担

**如果触碰底线**:
> "这个方案在X方面触碰了伦理底线。
> 我们不能这样做，即使它看起来最'高效'。
> 让我们重新想一个既有效又符合伦理的方案。"

---

### Step 5: 火·顿悟——创造性解决（15分钟）

**目标**: 找到双方都满意的方案（不是妥协，是创造）

**创造性提问**:
- "如果资源无限，理想的方案是什么？"
- "有没有一个方案，让双方都得到想要的？"
- "如果角色互换，你会接受什么方案？"
- "有没有第三选择？"

**常见创造性方案**:

| 冲突 | 传统方案 | 创造性方案 |
|:----:|:--------:|:----------:|
| 股权分配 | 各退一步 | 动态股权+里程碑触发 |
| 决策权 | 轮流决策 | R/I/A/E/C矩阵 |
| 方向分歧 | 投票决定 | 小规模试验+数据验证 |
| 资源争夺 | 按比例分 | 外部融资+共同做大 |

**顿悟信号**:
- 一方说"原来可以这样！"
- 双方开始共同完善方案
- 情绪从对抗变成合作

## 三、调解时间线

| 阶段 | 时间 | 核心任务 |
|:----:|:----:|:--------:|
| 准备 | 前一天 | 了解背景，选择地点，通知双方 |
| 土·信义 | 10分钟 | 建立安全空间 |
| 金·标尺 | 15分钟 | 明确评估标准 |
| 水·觉察 | 20分钟 | 倾听深层需求 |
| 木·伦理 | 10分钟 | 检查伦理底线 |
| 火·顿悟 | 15分钟 | 创造性解决 |
| 总结 | 10分钟 | 书面记录方案，双方签署 |
| **总计** | **80分钟** | **约1.5小时** |

## 四、调解失败怎么办？

### 4.1 失败信号

- 双方拒绝开口
- 标准无法统一
- 深层需求完全对立（如: 一方要解散，一方要坚持）
- 触碰伦理底线且无法绕开

### 4.2 升级路径

```
五维调解失败
     │
     ▼
第三方调解（共同认可的顾问）
     │
     ▼
律师协商（法律框架内解决）
     │
     ▼
仲裁（强制裁决）
     │
     ▼
诉讼（最后手段）
```

**原则**: 每升一级，成本×10，关系伤害×10。
**目标**: 在五维调解层解决80%的冲突。

## 五、调解者自检清单

### 5.1 调解前

- [ ] 我了解冲突背景吗？
- [ ] 我中立吗？（与双方无利益关系）
- [ ] 地点中立吗？
- [ ] 双方同意调解吗？

### 5.2 调解中

- [ ] 我打断了吗？（不应该）
- [ ] 我评判了吗？（不应该）
- [ ] 双方都有机会说话吗？
- [ ] 深层需求被挖出来了吗？

### 5.3 调解后

- [ ] 方案书面化了吗？
- [ ] 双方签署了吗？
- [ ] 有执行时间表吗？
- [ ] 有复盘机制吗？（1个月后检查）
