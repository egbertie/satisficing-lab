# 访谈计划：3-5位女性科技创业者案例推演

> **定位**: 方向①女性视角的深度验证——通过真实案例提炼模式
> **核心理念**: 不是"研究女性"，是"向女性学习"
> **目标**: 3-5个案例 → 提炼共性 → 形成可复用的决策模式

## 访谈提纲

### 开场（10分钟）

- "请用5分钟讲讲你和合伙人的故事——从认识到冲突"
- "如果用一句话描述你们的关系，是什么？"

### 五维深挖（30分钟）

**土·信义**:
- "你们有明确的合伙人协议吗？什么时候签的？"
- "有没有一次，你觉得信任被透支了？"

**金·标尺**:
- "你们如何决定'够好'的标准？"
- "有没有一个决策，你觉得标准不公平？"

**水·觉察**:
- "你的身体有没有提前告诉你'有问题'？"
- "你记录过这些直觉吗？后来验证了吗？"

**木·伦理**:
- "你们的伦理底线一致吗？举例。"
- "有没有一次，你为了维护关系而妥协了底线？"

**火·顿悟**:
- "冲突后，有没有一个时刻你突然'明白了'？"
- "如果重来，你会在哪个时间点做不同选择？"

### 女性视角特有问题（15分钟）

- "作为女性创始人，你觉得合伙人关系中有哪些独特的挑战？"
- "有没有人对你说过'你太敏感了'？你怎么回应？"
- "你的决策方式（直觉+数据）被合伙人认可吗？"
- "如果给另一位女性创始人一个建议，是什么？"

### 收尾（5分钟）

- "如果用满意解五维框架评价你的合伙人关系，你会怎么打分？"
- "你愿意让我们的案例（匿名）帮助其他女性创始人吗？"

每个案例整理为以下结构：

```
案例 #[编号]: [昵称] · [行业] · [阶段]

【背景】
- 创始人画像:
- 合伙人画像:
- 关系历史:

【冲突事件】
- 触发点:
- 升级路径:
- 当前状态:

【五维分析】
- 土·信义: 余额□高 □中 □低 → 证据:
- 金·标尺: 标准□清晰 □模糊 → 证据:
- 水·觉察: 觉察□敏锐 □迟钝 → 证据:
- 木·伦理: 底线□一致 □分歧 → 证据:
- 火·顿悟: 顿悟□有 □无 → 证据:

【女性视角洞察】
- 独特挑战:
- 应对策略:
- 成功/失败因素:

【满意解建议】
- 如果当时用五维框架，可以在哪个环节介入？
- 现在的修复建议:

【授权状态】
- □ 可匿名公开 □ 仅内部使用 □ 不可使用
```
