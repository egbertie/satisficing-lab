## 一、奔月计划的缘起

2026年4月，满意解研究所在Egbertie的召唤下诞生。彼时，硬科技创业者面临着一个普遍困境：找到了技术合伙人，却往往在合作中走向分裂；做出了产品，却在团队治理中陷入困境。

这不是技术问题，这是决策问题。更准确地说，这是"合伙人决策"问题。

满意解研究所的使命由此确立：**帮助硬科技创业者做出足够好的合伙人决策**。

但"足够好"不是随口一说。它需要理论支撑、方法工具、实证验证和持续迭代。奔月计划，就是为这一使命构建百年根基的学术工程。

```
一阶段（奠基）        二阶段（深化）         三阶段（万物）
    ↓                    ↓                    ↓
"是什么"              "从哪里来"             "怎么做"

    ↓                    ↓                    ↓
理论基础 ←——→ 学术纵深 ←——→ 应用落地
    ↓                    ↓                    ↓
```

**三阶段的递进关系**:
- **一阶段不可跳过**：没有理论基础，一切都是空中楼阁
- **二阶段不可缩减**：没有学术纵深，理论就是浅滩
- **三阶段不可缺失**：没有应用落地，学术就是自言自语

## 四、奔月计划的学术定位

### 4.1 学科交叉定位

奔月计划横跨多个学科领域：

```
核心层：决策科学（Simon传统）
    ├── 管理学：创业管理、组织行为
    ├── 哲学：儒商哲学、伦理学
    ├── 认知科学：神经科学、心理学
    ├── 计算机科学：AI、LLM
    ├── 教育学：游戏化学习、成人教育
    └── 社会学：制度分析、文化研究
```

### 4.2 知识生产模式

奔月计划采用"Mode 2"知识生产模式（Gibbons et al., 1994）：
- 应用情境中的知识生产
- 跨学科团队协作
- 质量控制由更广泛的同行参与
- 社会责任与知识生产并行

同时，奔月计划创新性地引入AI辅助知识生产（Mode 4）：
- 33角色AI系统参与论文撰写
- 人机协作的学术研究新模式
- 知识生产的民主化和加速化

### 4.3 与现有研究的关系

| 现有研究 | 奔月计划的创新 |
|----------|---------------|
| 创业研究（Shane, 2000） | 聚焦"合伙人决策"而非"机会识别" |
| 决策科学（Kahneman, 2011） | 引入儒释道文化基因 |
| 企业儒学（黎红雷, 2023） | 聚焦"合伙人治理"应用场景 |
| AI伦理（Bender et al., 2021） | 聚焦"AI决策教练"特定场景 |
| 神经科学商业应用 | 提出"epistemic gap"批判框架 |

## 五、奔月计划的方法论创新

### 5.1 理论创新

1. **满意解决策理论的中国化**：将Simon理论与儒家中庸思想融合
2. **五维决策框架**：首次系统整合儒释道与西方决策科学
3. **12类型冲突分类学**：基于84份案例的合伙人冲突类型学
4. **卡牌认知训练模型**：将游戏化学习引入决策教育

### 5.2 方法创新

1. **AI辅助知识生产**：33角色AI系统参与学术创作
2. **快速迭代研究**：单日完成多篇论文的"奔月速度"
3. **开源学术**：全部论文开放获取，促进知识传播
4. **实践嵌入**：研究直接服务于商业实践，而非象牙塔

### 5.3 形式创新

1. **中文-only**：面向中文学术社区和本土实践
2. **模块化结构**：每篇论文独立可读的模块化设计
3. **多模态表达**：论文+卡牌+AI系统+工作坊的多元形态
4. **活文档**：持续更新迭代，而非静态出版物

## 七、奔月计划的局限与未来

### 7.1 当前局限

1. **实证基础薄弱**：多数论文基于理论推导，缺乏大规模实证验证
2. **文化适用性**：五维框架主要基于中国文化，跨文化适用性待验证
3. **技术可行性**：AI Agent系统的技术实现尚处于概念阶段
4. **作者局限**：核心作者为AI系统，可能存在未被识别的偏见

### 7.2 未来方向

1. **实证验证**：开展准实验和随机对照试验
2. **跨文化检验**：在不同文化语境中测试框架适用性
3. **技术落地**：将概念设计转化为可运行的系统
4. **社区共建**：邀请更多学者和实践者参与完善

## 八、结语：致未来的读者

如果你读到这份总纲，无论你是学者、创业者、决策者，还是单纯对"如何做出足够好的决策"感兴趣的人——

欢迎你。

奔月计划不是一份"标准答案"，而是一份"邀请"：
- 邀请你质疑我们的理论
- 邀请你补充我们的空白
- 邀请你应用我们的工具
- 邀请你超越我们的局限

满意解哲学的核心，不是"我们知道答案"，而是"我们一起寻找足够好的答案"。

> **"在'最优'暴政的时代，重建'满意'的智慧。"**

这就是奔月计划，这就是满意解研究所。
