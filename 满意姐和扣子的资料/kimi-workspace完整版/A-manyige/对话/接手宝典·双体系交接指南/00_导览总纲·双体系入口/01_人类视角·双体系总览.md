## 三、接手策略

### 策略A：先历史，后能力（推荐）

**适合**: 想理解"我们是谁"的人

1. **Phase 1（2小时）**: 读契晋纪
   - `01_精神内核·为什么/README.md`
   - `02_项目演进·怎么做/README.md`
   - `99_附录/`下的关键文档

2. **Phase 2（4小时）**: 读三生万物
   - `01_Skill级别/00_导览与索引.md`
   - `02_课程级别/00_导览与索引.md`
   - `03_传播级别/00_导览与索引.md`

3. **Phase 3（1天）**: 实操
   - 安装一个Skill（`01_Skill级别/01_实际Skill/dist/`）
   - 运行一个脚本（`scripts/`目录）
   - 完成一个自检清单

### 策略B：先能力，后历史

**适合**: 急着要用的人

1. **Phase 1（1小时）**: 快速上手三生万物
   - `01_Skill级别/02_使用说明与实操指引/快速上手指南.md`
   - 运行 `stage-checker.py`

2. **Phase 2（2小时）**: 理解契晋纪的精神内核
   - `01_精神内核·为什么/`

3. **Phase 3（按需）**: 深入

### 策略C：按需取用

**适合**: 有明确需求的人

| 你的需求 | 先看 | 再看 |
|:---------|:-----|:-----|
| "我要做决策" | 三生万物·五维决策Skill | 契晋纪·五维决策体系融合 |
| "我要审计质量" | 三生万物·蓝军验证Skill | 契晋纪·蓝军宪章 |
| "我要管理项目" | 三生万物·执行系统Skill | 契晋纪·HEARTBEAT协议 |
| "我要传承知识" | 三生万物·知识飞轮Skill | 契晋纪·托付全档 |
| "我要理解历史" | 契晋纪·项目演进 | 三生万物·设计理念溯源 |
| "我要传播理念" | 三生万物·传播级别 | 契晋纪·星月传奇 |

## 四、操作路径

### 顶层操作（双体系总览）

```bash
# 1. 确认你拿到了两个体系
cd A-manyige/对话/
ls -d 契晋纪·托付全档 三生万物·产品化终炼 接手宝典·双体系交接指南

# 2. 阅读开篇语
cat 接手宝典·双体系交接指南/00_开篇语.md

# 3. 选择你的策略（A/B/C）
# 见上文
```

### 中层操作（单体系深入）

**契晋纪**:
```bash
# 1. 读体系导览
cat 契晋纪·托付全档/00_总纲README.md

# 2. 按兴趣深入子目录
cd 契晋纪·托付全档/01_精神内核·为什么/
cat README.md

# 3. 运行基线检查
python3 skills/baseline-checker/scripts/baseline-checker-runner.py
```

**三生万物**:
```bash
# 1. 读体系导览
cat 三生万物·产品化终炼/04_体系导览与索引/全体系索引.md

# 2. 安装一个Skill
cp 三生万物·产品化终炼/01_Skill级别/01_实际Skill/dist/knowledge-flywheel-guide.skill ~/.openclaw/skills/

# 3. 运行自检脚本
python3 三生万物·产品化终炼/01_Skill级别/01_实际Skill/scripts/stage-checker.py
```

### 底层操作（产品功能级）

**示例：使用五维决策Skill**

```bash
# 1. 找到Skill
cd 三生万物·产品化终炼/技能系列/01_五维决策体系/01_实际Skill/

# 2. 阅读Skill入口
cat SKILL.md

# 3. 运行决策脚本
python3 scripts/decision-assistant.py
# 按提示输入土金水木火评分

# 4. 查看决策手册
cat references/decision-framework.md
```
