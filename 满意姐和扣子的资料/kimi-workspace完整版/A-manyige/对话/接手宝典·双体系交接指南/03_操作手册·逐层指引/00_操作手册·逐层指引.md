# 操作手册·逐层指引

> **定位**: 从顶层到中层到底层的完整操作路径
> **用途**: 让接班人知道"每一步该做什么"
> **前提**: 已读双体系总览导览
> **阅读时间**: 30分钟
> **版本**: V1.0

## 第一部分：顶层操作（双体系总览）

### 目标
15分钟内，确认你拿到了完整的双体系，知道从哪开始。

### 操作清单

**Step 1: 确认文件完整性（2分钟）**

```bash
cd A-manyige/对话/
ls -d 契晋纪·托付全档 三生万物·产品化终炼 接手宝典·双体系交接指南
# 预期输出：三个文件夹都存在
```

**Step 2: 确认核心文件存在（3分钟）**

```bash
# 契晋纪核心
cat 契晋纪·托付全档/00_总纲README.md | head -20

# 三生万物核心
cat 三生万物·产品化终炼/00_开篇语.md | head -20

# 接手宝典核心
cat 接手宝典·双体系交接指南/00_开篇语.md | head -20
```

**Step 3: 选择视角（1分钟）**

- 我是人类 → 读 `00_导览总纲/01_人类视角·双体系总览.md`
- 我是AI → 读 `00_导览总纲/02_AI视角·双体系总览.md`

**Step 4: 运行五维自检（5分钟）**

人类：
```bash
# 读自检表
cat 接手宝典·双体系交接指南/04_检验清单/01_人类自检清单.md
# 手动评分
```

AI：
```
read: 接手宝典·双体系交接指南/04_检验清单/02_AI自检清单.md
# 按提示评分
```

**Step 5: 确认总分≥35（1分钟）**

- ≥35 → 进入中层操作
- <35 → 先补强弱项（见本文档第三部分）

**Step 6: 设定首次同步会时间（3分钟）**

如果你是AI：
- 向人类报告："双体系自检完成，总分X分，准备进入中层操作"
- 请求确认："是否需要先补强弱项？"

## 第四部分：应急手册

### 常见问题FAQ

**Q1: "我找不到某个文件"**
A: 
1. 查全量索引：
   - Markdown版：`04_体系导览与索引/全量文件索引-Markdown.md`
   - CSV版：`04_体系导览与索引/全量文件索引-CSV.csv`
2. 用编号查找：SSW-XXX 或 契晋纪编号
3. 用搜索：`grep -r "关键词" 三生万物·产品化终炼/`

**Q2: "脚本运行报错"**
A:
1. 确认Python3可用：`python3 --version`
2. 确认文件权限：`chmod +x scripts/*.py`
3. 查看错误信息，搜索解决方案
4. 如无法解决，记录到 `memory/YYYY-MM-DD.md`

**Q3: "Skill安装失败"**
A:
1. 确认Skill文件完整：`ls -l *.skill`
2. 确认目标目录存在：`ls ~/.openclaw/skills/`
3. 查看OpenClaw版本：支持 ≥ 2026.3.13
4. 手动解压：`unzip -l *.skill`

**Q4: "自检分数<35，不知道从哪补"**
A:
1. 找到最弱的维度（得分最低）
2. 查五维映射表，找到对应文件
3. 阅读对应文件
4. 重新自检

**Q5: "我是AI，不知道怎么向人类汇报"**
A:
1. 使用双周同步会模板：`01_Skill级别/01_实际Skill/references/dual-sync-meeting-template.md`
2. 汇报格式：AI展示→人类验证→冲突处理→优先级调整→飞轮检查
3. 每次汇报控制在30分钟内

### 故障排除流程

```
遇到问题
  ↓
查应急手册（本部分）
  ↓
找到对应Q&A？
  ├─ 是 → 按指引解决
  └─ 否 → 记录问题
          ↓
    查全量索引，定位相关文件
          ↓
    阅读相关文件
          ↓
    仍无法解决？
      ├─ 是 → 记录到 memory/YYYY-MM-DD.md，等待人类裁决
      └─ 否 → 解决，记录修正逻辑
```
