# 合伙人章程自检清单 V0.1

> **工具定位**: 创始人5分钟能看懂的合伙人关系健康检查表  
> **适用场景**: 创业初期、合伙人变动前、年度关系复盘  
> **填写人**: 创始人/合伙人共同填写  
> **时间**: 15分钟  
> **产出**: 5大治理场景的健康评分 + 风险预警

---

## 使用说明

1. **打印本清单**（或复制到共享文档）
2. **每位合伙人独立填写**（不要商量，独立打分）
3. **汇总对比**——分歧最大的项就是风险点
4. **每季度复测一次**

---

## 一、决策权 · 谁决定什么

| 检查项 | 现状 | 你的评分(1-5) | 合伙人A | 合伙人B |
|:------|:-----|:-------------:|:-------:|:-------:|
| 1. 日常运营决策（<¥1万）由谁决定？ | | | | |
| 2. 中等决策（¥1-10万）需要几人同意？ | | | | |
| 3. 重大决策（>¥10万/战略方向）必须全体吗？ | | | | |
| 4. 人事任免（招聘/解雇合伙人级别）谁有否决权？ | | | | |
| 5. 如果意见分歧，最终听谁的？有明确机制吗？ | | | | |

**评分标准**: 1=完全混乱，3=有规则但不清晰，5=规则清晰且所有人认同

**风险预警**: 
- 单项≤2分 → 🔴 立即讨论
- 总分≤10分 → 🟡 需要制度化的信号

## 二、股权设计 · 蛋糕怎么分

| 检查项 | 现状 | 你的评分(1-5) | 合伙人A | 合伙人B |
|:------|:-----|:-------------:|:-------:|:-------:|
| 6. 股权比例与贡献匹配吗？ | | | | |
| 7. 有vesting（分期兑现）条款吗？ | | | | |
| 8. 离职/退出时的回购价格和机制明确吗？ | | | | |
| 9. 新合伙人加入时的稀释规则有吗？ | | | | |
| 10. 如果公司被收购，分配顺序和比例明确吗？ | | | | |

**评分标准**: 1=口头约定，3=有协议但不完善，5=律师审核过的完整协议

**风险预警**: 
- 第7项≤2分 → 🔴 没有vesting=没有长期绑定
- 第8项≤2分 → 🔴 退出机制=分手协议，没有=分手战争

## 三、角色分工 · 谁做什么

| 检查项 | 现状 | 你的评分(1-5) | 合伙人A | 合伙人B |
|:------|:-----|:-------------:|:-------:|:-------:|
| 11. 每位合伙人的职责范围书面化了吗？ | | | | |
| 12. 职责重叠区域有明确协调人吗？ | | | | |
| 13. 合伙人可以跨领域干预吗？边界在哪？ | | | | |
| 14. 如果某合伙人长期无法履职，有替代方案吗？ | | | | |
| 15. 绩效考核标准和周期明确吗？ | | | | |

**评分标准**: 1=完全靠默契，3=有分工但不清晰，5=书面化的岗位说明书

**风险预警**: 
- 第11项≤2分 → 🔴 "我以为你负责"=冲突温床
- 第15项≤2分 → 🟡 没有考核=没有改进

## 四、沟通机制 · 信息怎么流

| 检查项 | 现状 | 你的评分(1-5) | 合伙人A | 合伙人B |
|:------|:-----|:-------------:|:-------:|:-------:|
| 16. 合伙人定期会议（1对1或全体）的频率？ | | | | |
| 17. 会议有议程和记录吗？ | | | | |
| 18. 不满/冲突有安全的表达渠道吗？ | | | | |
| 19. 重大信息（财务/战略）对所有合伙人透明吗？ | | | | |
| 20. 如果合伙人之间有不信任，有第三方调解机制吗？ | | | | |

**评分标准**: 1=很少沟通，3=有沟通但不系统，5=结构化的沟通机制

**风险预警**: 
- 第18项≤2分 → 🔴 不满不能表达=不满积累到爆发
- 第20项≤2分 → 🟡 没有调解=只有对抗

## 五、退出机制 · 好聚好散

| 检查项 | 现状 | 你的评分(1-5) | 合伙人A | 合伙人B |
|:------|:-----|:-------------:|:-------:|:-------:|
| 21. 合伙人主动退出的流程明确吗？ | | | | |
| 22. 被动退出（业绩不达标/违反伦理）的标准和流程？ | | | | |
| 23. 退出时的股权回购价格怎么算？ | | | | |
| 24. 竞业禁止条款有吗？合理吗？ | | | | |
| 25. 知识产权归属明确吗？ | | | | |

**评分标准**: 1=没想过，3=有想法但没书面化，5=律师审核的完整退出协议

**风险预警**: 
- 第21-23项任一项≤2分 → 🔴 退出=最痛的场景，没有准备=最坏的结果
- 第25项≤2分 → 🔴 IP归属不清=分手后扯皮

### 健康等级

| 分数 | 等级 | 建议 |
|:----:|:----:|:----:|
| 100-125 | 🟢 健康 | 保持，每季度复测 |
| 75-99 | 🟡 警示 | 2周内补齐短板 |
| 50-74 | 🟠 风险 | 1周内紧急会议，律师介入 |
| <50 | 🔴 危险 | 立即停止其他工作，全力修复 |

### 下一步行动清单

1. **本周**: 召集合伙人会议，讨论分歧最大的3项
2. **本月**: 找律师起草/完善合伙人协议
3. **每季度**: 复测本清单，追踪改善进度
