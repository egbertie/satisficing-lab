# 分离伦理指南：如何"好聚好散"

> **定位**: 合伙人关系无法修复时的伦理分手指南
> **核心理念**: 分手不是失败，是"另一种形式的满意解"
> **目标**: 保护双方尊严+保护公司+保护未来关系

---

## 分离伦理原则

| 原则 | 说明 | 反面 |
|:----:|:----:|:----:|
| **不伤害** | 不因分手而故意损害对方 | 恶意散播负面信息、破坏声誉 |
| **不欺骗** | 资产/股权清算透明 | 隐瞒资产、虚报债务 |
| **不拖延** | 在规定时间内完成分离 | 利用程序拖延、消耗对方 |
| **不独占** | 知识产权/客户资源合理分配 | 独占全部成果、抹杀对方贡献 |
| **留余地** | 为未来合作或和解留空间 | 断绝一切联系、制造敌意 |

---

## 分离类型与伦理标准

### 友好分离

| 场景 | 双方协商一致，无重大分歧 |
|:----:|:------------------------:|
| **伦理标准** | |
| 时间 | 提前3个月通知 |
| 沟通 | 面对面告知，不用微信/邮件 |
| 资产 | 按协议执行，无争议 |
| 关系 | 保持基本礼貌，不拉黑 |
| 未来 | 留一句"如果有需要，可以找我" |

---

### 协商分离

| 场景 | 有分歧，但愿意谈 |
|:----:|:----------------:|
| **伦理标准** | |
| 时间 | 6个月内完成 |
| 沟通 | 调解者在场，书面记录 |
| 资产 | 第三方评估，双方认可 |
| 关系 | 不公开负面信息 |
| 未来 | 不主动破坏对方新机会 |

---

### 争议分离

| 场景 | 分歧严重，需法律介入 |
|:----:|:--------------------:|
| **伦理标准** | |
| 时间 | 法律程序内尽快完成 |
| 沟通 | 律师代理，减少直接冲突 |
| 资产 | 法律判决，接受结果 |
| 关系 | 不公开攻击对方人格 |
| 未来 | 胜诉方不炫耀，败诉方不报复 |

---

### 强制分离

| 场景 | 违法/严重损害公司利益 |
|:----:|:---------------------:|
| **伦理标准** | |
| 时间 | 立即停止，法律程序 |
| 沟通 | 法律途径，不私了 |
| 资产 | 依法追回，不超额 |
| 关系 | 就事论事，不人身攻击 |
| 未来 | 接受法律结果，不私刑 |

## "好聚好散"操作手册

### Step 1: 决定分离（1天）

| 行动 | 伦理检查 |
|:----:|:--------:|
| 确认分离是唯一选项 | "我们真的尽力修复了吗？" |
| 确认分离是双方或单方的决定 | "如果是单方，通知方式是否尊重？" |
| 确认分离时机不故意恶劣 | "为什么选择这个时间？有没有更好的时机？" |

### Step 2: 通知对方（1-3天）

| 行动 | 伦理检查 |
|:----:|:--------:|
| 面对面告知（如可能） | "我是否给了对方被尊重的感觉？" |
| 说明原因，不指责 | "我说的是'行为'还是'人格'？" |
| 给对方表达时间 | "我有没有听对方说完？" |
| 不公开化（除非对方先公开） | "我有没有保护对方的隐私？" |

### Step 3: 清算资产（1-4周）

| 行动 | 伦理检查 |
|:----:|:--------:|
| 透明化所有资产 | "我有没有隐瞒？" |
| 按协议或法律执行 | "我有没有利用优势地位？" |
| 给对方合理时间准备 | "时间是否充裕？" |
| 不破坏公司运营 | "员工/客户是否被无辜牵连？" |

### Step 4: 关系收尾（1-2周）

| 行动 | 伦理检查 |
|:----:|:--------:|
| 正式告别（如可能） | "我有没有留下怨恨？" |
| 归还对方个人物品 | "我有没有扣留不该扣的？" |
| 不传播负面信息 | "我有没有说过对方坏话？" |
| 给推荐信（如对方应得） | "我有没有因为个人情绪而否定对方贡献？" |

### Step 5: 自我疗愈（持续）

| 行动 | 伦理检查 |
|:----:|:--------:|
| 处理自己的情绪 | "我有没有把情绪发泄到无关的人身上？" |
| 不美化/不妖魔化对方 | "我的回忆是否客观？" |
| 从经验中学习 | "我有没有推卸全部责任？" |
| 开放未来合作可能 | "我有没有因为一次失败而关闭所有门？" |

## 分离伦理自检清单

| 检查项 | 是/否 |
|:------|:-----:|
| 我尽了最大努力修复关系？ | |
| 分离通知是尊重的？ | |
| 资产清算是透明的？ | |
| 我没有故意损害对方声誉？ | |
| 我没有牵连无辜（员工/客户）？ | |
| 我给了对方合理的准备时间？ | |
| 我没有因为情绪而否定对方贡献？ | |
| 我保留了未来合作的可能？ | |
| 我处理了分离后的自我情绪？ | |
| 我从这次经验中学习了？ | |

**评分**:
- 10个"是": 🟢 伦理分离
- 7-9个"是": 🟡 基本伦理，有小瑕疵
- 4-6个"是": 🟠 伦理有缺，需要补救
- <4个"是": 🔴 伦理失败，需要反思

## "好聚好散"金句

> "我们不适合一起创业，但这不代表你是坏人。"
>
> "感谢你曾经的贡献，即使现在我们选择分开。"
>
> "如果未来有合作机会，我不会因为今天的分离而拒绝。"
>
> "分手是公司的决定，不是我对你的否定。"
>
> "我希望你下一段旅程更好。"

## 反面教材："坏聚坏散"

| 行为 | 后果 | 为什么 unethical |
|:----:|:----:|:--------------:|
| 微信通知分手 | 对方感到不被尊重 | 缺乏基本尊重 |
| 隐瞒资产 | 法律纠纷 | 欺骗 |
| 公开攻击对方 | 双方声誉受损 | 伤害 |
| 挖走团队 | 公司崩溃 | 破坏 |
| 拒绝写推荐信 | 对方未来受阻 | 报复 |
| 拉黑所有联系 | 未来合作不可能 | 断绝 |
