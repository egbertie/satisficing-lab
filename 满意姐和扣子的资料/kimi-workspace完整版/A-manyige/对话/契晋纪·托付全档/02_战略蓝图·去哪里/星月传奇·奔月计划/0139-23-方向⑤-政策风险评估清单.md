# 政策风险评估清单：换届风险/法规变动/补贴依赖

> **定位**: 硬科技创业中政策风险的识别与量化评估
> **核心理念**: 政策不是"机遇"，是"变量"——变量需要管理
> **适用**: 依赖政策补贴/政府项目/监管行业的硬科技企业

---

## 风险三维模型

| 维度 | 风险类型 | 说明 | 典型案例 |
|:----:|:--------:|:----:|:--------:|
| **换届风险** | 人事变动导致政策中断 | 领导更换→项目搁置 | 地方产业园项目 |
| **法规变动** | 新规出台改变游戏规则 | 监管加强→业务受限 | 数据安全法 |
| **补贴依赖** | 补贴退坡导致现金流断裂 | 补贴减少→亏损 | 新能源补贴 |

---

## 换届风险评估

### 评估维度

| # | 检查项 | 评分(1-5) |
|:--:|:------|:---------:|
| 1 | 当前政策支持者与我们的关系深度 | |
| 2 | 支持者任期剩余时间 | |
| 3 | 继任者对我们的了解程度 | |
| 4 | 项目是否已写入地方规划（非个人承诺） | |
| 5 | 项目是否有上级政府背书 | |

**风险等级**:
- 20-25: 🟢 低——政策已制度化，不依赖个人
- 15-19: 🟡 中——有部分制度化，但有人事风险
- 10-14: 🟠 高——依赖特定个人，换届可能中断
- <10: 🔴 极高——完全依赖个人，无制度保障

### 应对策略

| 等级 | 策略 |
|:----:|:----:|
| 🟢 | 保持关系，但不过度依赖 |
| 🟡 | 推动项目制度化（写入规划、获得上级背书） |
| 🟠 | 寻找替代政策渠道，降低单一依赖 |
| 🔴 | 紧急寻找市场化收入，准备政策断供 |

## 法规变动风险评估

### 评估维度

| # | 检查项 | 评分(1-5) |
|:--:|:------|:---------:|
| 6 | 当前业务是否处于监管敏感期 | |
| 7 | 行业是否有新规待出台 | |
| 8 | 新规出台后，合规成本预估 | |
| 9 | 是否有备选业务模式（法规友好型） | |
| 10 | 团队是否有法规跟踪能力 | |

**风险等级**: 同上

### 应对策略

| 等级 | 策略 |
|:----:|:----:|
| 🟢 | 定期跟踪法规动态，保持合规 |
| 🟡 | 建立法规预警机制，预留合规预算 |
| 🟠 | 开发备选业务模式，降低原模式依赖 |
| 🔴 | 紧急转型，或寻求政策豁免/过渡期 |

## 补贴依赖风险评估

### 评估维度

| # | 检查项 | 评分(1-5) |
|:--:|:------|:---------:|
| 11 | 补贴收入占总收入比例 | |
| 12 | 补贴是否有明确的退坡时间表 | |
| 13 | 去掉补贴后，业务是否盈利 | |
| 14 | 是否有替代收入来源（市场收入） | |
| 15 | 补贴申请的成功率历史 | |

**风险等级**:
- 🟢 补贴<20%，有替代收入
- 🟡 补贴20-50%，部分替代收入
- 🟠 补贴50-80%，少量替代收入
- 🔴 补贴>80%，无替代收入

### 应对策略

| 等级 | 策略 |
|:----:|:----:|
| 🟢 | 保持补贴申请，但不作为核心战略 |
| 🟡 | 逐步提升市场收入占比，设定目标 |
| 🟠 | 紧急开拓市场收入，设定退出补贴的时间表 |
| 🔴 | 立即启动市场化转型，否则面临生存危机 |
