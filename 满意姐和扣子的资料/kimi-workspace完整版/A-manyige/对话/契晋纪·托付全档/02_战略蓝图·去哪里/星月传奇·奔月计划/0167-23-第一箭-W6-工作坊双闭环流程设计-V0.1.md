# 工作坊双闭环流程设计 V0.1

> **定位**: 五维决策工作坊升级版——匹配闭环（找对人）+ 治理闭环（管好人）
> **适用场景**: 合伙人匹配决策、合伙人关系修复、年度合伙人复盘
> **时长**: 1天工作坊（6小时）或 2天深度版（12小时）
> **人数**: 4-12人（2-6组合伙人）

---

## 一、为什么需要"双闭环"？

### 单闭环的问题

传统工作坊只解决"匹配"——帮你找到对的合伙人。

但找到之后呢？

**70%的合伙人冲突发生在"找到之后"。**

### 双闭环架构

```
┌─────────────────────────────────────────┐
│          双闭环工作坊架构                  │
├─────────────────────────────────────────┤
│  上午: 匹配闭环（找对人）                  │
│  ├── 土·信义扫描 → 信任账户余额          │
│  ├── 金·标尺设定 → 满意解标准            │
│  ├── 水·觉察唤醒 → 0.3秒直觉             │
│  ├── 木·伦理过滤 → 底线检查              │
│  ├── 火·顿悟验证 → 压力测试              │
│  └── 输出: 合伙人匹配决策卡               │
├─────────────────────────────────────────┤
│  下午: 治理闭环（管好人）                  │
│  ├── 章程自检 → 找规则缺口                 │
│  ├── 决策权矩阵 → 明确谁决定什么           │
│  ├── 动态股权设计 → 公平分配蛋糕           │
│  ├── 退出机制预签 → 分手协议              │
│  ├── 五维调解法演练 → 冲突化解            │
│  └── 输出: 合伙人治理协议草案             │
└─────────────────────────────────────────┘
```

## 二、匹配闭环（上午·3小时）

### 2.1 开场（30分钟）

**目标**: 建立安全空间，明确工作坊规则

**流程**:
1. **土·信义**——主持人宣读保密承诺
2. **金·标尺**——明确今日目标："匹配决策卡"
3. **水·觉察**——参与者闭眼30秒，感受此刻状态
4. **木·伦理**——规则："不评判，只观察"
5. **火·顿悟**——快速破冰："用一个词形容你和合伙人的关系"

**产出**: 安全空间建立，参与者进入状态

---

### 2.2 五维扫描（2小时）

#### Step 1: 土·信义扫描（25分钟）

**工具**: 信任账户清单

**流程**:
- 每组合伙人独立填写"信任账户明细"
- 列出：存款事件 / 取款事件 / 当前余额
- 交换阅读，不说话，只标记

**关键问题**:
- "过去6个月，TA做了哪些让你信任的事？"
- "有没有一次，你觉得信任被透支了？"

**产出**: 信任账户余额（高/中/低）

---

#### Step 2: 金·标尺设定（25分钟）

**工具**: 满意解标准卡

**流程**:
- 每人独立写下："我对合伙人的最低要求"
- 合并同类项，排出Top 5
- 双方确认："如果这5条都满足，我就满意"

**关键问题**:
- "如果只能选一个，你最看重什么？"
- "什么情况下，你会说'够了，不再要求更多'？"

**产出**: 双方认可的满意解标准（5条）

---

#### Step 3: 水·觉察唤醒（25分钟）

**工具**: 0.3秒觉察练习

**流程**:
- 播放合伙人冲突场景视频（3个案例）
- 每个视频后，闭眼30秒，感受身体反应
- 记录：紧绷/放松/心跳/呼吸
- 分享："哪个场景让我最不舒服？"

**关键问题**:
- "你的身体比大脑更诚实。它告诉你什么？"

**产出**: 觉察日志（身体信号记录）

---

#### Step 4: 木·伦理过滤（20分钟）

**工具**: 伦理底线清单

**流程**:
- 每人独立勾选："我绝对不能接受的合伙人行为"
- 对比双方清单
- 如果有冲突（一方接受、一方拒绝），标记为"关键分歧"

**关键问题**:
- "如果TA做了X，我们的关系就不可修复。X是什么？"

**产出**: 伦理对齐度（一致/部分一致/严重分歧）

---

#### Step 5: 火·顿悟验证（25分钟）

**工具**: 压力测试场景

**流程**:
- 模拟3个高压场景：
  1. "公司账上只剩3个月钱，怎么办？"
  2. "核心客户要求返点20%，给不给？"
  3. "有一个合伙人必须离开，选谁？"
- 每组讨论，观察：谁在压力下变了？谁稳定？

**关键问题**:
- "压力下，TA还是TA吗？"

**产出**: 压力反应记录（稳定/波动/崩溃）

---

### 2.3 匹配决策（30分钟）

**流程**:
1. **汇总五维数据**——填入匹配决策卡
2. **独立打分**——每人给关系打分（1-10）
3. **交换评分**——如果不一致，讨论原因
4. **决策**——继续/调整/暂停/终止

**匹配决策卡模板**:

```
┌─────────────────────────────────────────┐
│ 合伙人匹配决策卡                          │
├─────────────────────────────────────────┤
│ 合伙人A: _______ 合伙人B: _______         │
├─────────────────────────────────────────┤
│ 土·信义: 余额□高 □中 □低               │
│ 金·标尺: 标准□一致 □部分 □分歧         │
│ 水·觉察: 身体□放松 □紧绷 □不适         │
│ 木·伦理: 底线□一致 □部分 □分歧         │
│ 火·顿悟: 压力□稳定 □波动 □崩溃         │
├─────────────────────────────────────────┤
│ A评分: ___ B评分: ___                   │
│ 差距: ___ 分（>3分需关注）               │
├─────────────────────────────────────────┤
│ 决策: □继续 □调整 □暂停 □终止           │
│ 调整方案（如选调整）: _______________    │
├─────────────────────────────────────────┤
│ 下一步行动: _______________              │
│ 复测日期: _______________               │
└─────────────────────────────────────────┘
```

## 三、治理闭环（下午·3小时）

### 3.1 治理现状诊断（30分钟）

**工具**: 合伙人章程自检清单（工具包#3）

**流程**:
- 每组独立填写25项检查
- 汇总评分，识别最低分项
- 讨论："我们的最大缺口是什么？"

**产出**: 治理健康评分（5维度）

---

### 3.2 决策权设计（30分钟）

**工具**: 决策权矩阵（工具包#4）

**流程**:
- 列出本组所有常见决策事项
- 分配R/I/A/E/C
- 如果有分歧，用五维调解法Step 2（金·标尺）解决

**产出**: 一页纸决策权矩阵

---

### 3.3 股权设计（45分钟）

**工具**: 动态股权框架（工具包#5）

**流程**:
- 确定基础层（保障股权）
- 设计贡献层（动态调整机制）
- 设定里程碑触发条件
- 明确vesting条款

**关键讨论**:
- "如果一年后贡献变化，股权怎么调？"
- "退出时，股权怎么回购？"

**产出**: 股权框架草案（3层）

---

### 3.4 退出机制预签（30分钟）

**工具**: 退出路径图（工具包#6）

**流程**:
- 讨论："如果分手，我们希望怎么分？"
- 选择退出类型（友好/协商/争议/强制）
- 确定：通知期/回购价格/竞业禁止
- 签署"退出意向书"（非法律约束，但道义约束）

**产出**: 退出机制意向书

---

### 3.5 调解法演练（45分钟）

**工具**: 五路图腾调解法（工具包#7）

**流程**:
- 模拟一个真实冲突场景（由参与者提供）
- 选一名"调解者"（可以是另一组合伙人）
- 按5步法执行：土→金→水→木→火
- 观察者记录：哪一步最有效？哪一步最难？

**产出**: 调解法实操经验 + 改进建议

---

## 六、 facilitator（引导者）指南

### 6.1  facilitator 资质

- 完成满意解研究所五维决策认证
- 至少引导过3场工作坊
- 具备冲突调解经验
- 中立立场（无利益关系）

### 6.2 关键技巧

| 场景 | 技巧 |
|:----:|:----:|
| 参与者情绪激动 | 暂停，深呼吸，重申安全空间 |
| 合伙人分歧严重 | 切换到五维调解法Step 3（水·觉察） |
| 时间不够 | 优先保证匹配决策卡+治理协议草案 |
| 有人拒绝参与某项 | 尊重，记录，不强迫 |

### 6.3 禁止行为

- ❌ 替参与者做决定
- ❌ 评判任何一方的对错
- ❌ 透露其他组的信息
- ❌ 超出能力范围时硬撑（应及时引入专家）
