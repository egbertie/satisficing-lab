## 投资决策中的满意解方法论

### 场景1：投不投这个项目？

**传统方法**: 看BP、看团队、看市场、看财务模型

**满意解方法**: 五维投资决策框架

```
土（伦理底座）
  → 这个项目的伦理风险是什么？
  → 如果爆出丑闻，我们的声誉损失？

金（满意解标准）
  → 不是"最好的项目"，是"最适合我们基金的项目"
  → 边界：我们的投资领域、阶段、金额
  → 标准：IRR>30%？还是战略价值？

水（洞察本质）
  → 这个项目的"第一性原理"是什么？
  → 去掉包装，核心价值是什么？

木（信任治理）
  → 创始人的"仁义礼智信"如何？
  → 合伙人关系稳定吗？

火（行动转化）
  → 直觉：这个创始人靠谱吗？
  → 压力测试：如果市场环境恶化，这个项目能活吗？
```

---

### 场景2：估值谈不拢

**传统方法**: 对标法、DCF、可比交易

**满意解方法**: "满意解估值"

```
不是"市场公允价值"，是"双方都能接受的区间"

步骤1: 明确边界
  → 创始人最低接受价
  → 投资人最高出价

步骤2: 探索选项
  → 纯现金？
  → 现金+对赌？
  → 现金+资源？

步骤3: 满意解标准
  → 不是"谁赢了"，是"双方都不满意但都能接受"

步骤4: 执行+反思
  → 设定里程碑
  → 如果偏离，重新谈判
```

### 场景3：投后管理——创始人出问题了

**传统方法**: 董事会席位、对赌条款、强制回购

**满意解方法**: 合伙人冲突诊断

```
识别冲突类型:
□ Type 5: 退出机制模糊 → 重新谈退出条款
□ Type 8: 信任危机 → 溯源修复或启动分离
□ Type 11: 压力应对差异 → 提供心理/资源支持
□ Type 12: 成长速度不匹配 → 调整角色或补充团队

干预策略:
1. 蓝军视角（独立审计）→ 发现问题
2. 满意姐视角（关怀执行）→ 提供支持
3. 五维决策 → 找到满意解
```

---

### 场景4：基金内部决策——合伙人有分歧

**传统方法**: 投票、一把手决策、搁置

**满意解方法**: 双Agent治理

```
设立"蓝军"角色:
  → 每个投资决策必须有反对意见
  → 强制发现至少1个风险
  → 不能只说"好"，必须说"但是"

互评制度:
  → 投前：独立评估
  → 投后：独立跟踪
  → 退出：独立复盘

编号决策:
  → 每个重大决策编号记录
  → 可追溯、可复盘、可学习
```
