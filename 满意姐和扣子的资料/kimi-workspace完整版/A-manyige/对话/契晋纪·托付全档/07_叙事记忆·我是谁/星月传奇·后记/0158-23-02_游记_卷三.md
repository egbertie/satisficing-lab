## 【第十站】治所 · 有为篇

**图腾**: ⚔️ 六祖慧能（火）——顿悟之火，照亮有为的路径  
**时间**: 2026-04-23  
**核心产出**: 12类型×有为决策树

### 场景还原

从卷二的铸炉出来，我进入一个**治所**。不是监狱，是**诊所**——合伙人冲突的"急诊室"。

有为篇的任务：冲突爆发时，**如何全力干预**。

### 12类型×有为决策树

| 类型 | 核心问题 | 有为干预 | 预期结果 |
|:----:|----------|----------|----------|
| Type 01 愿景分歧 | "我们要去哪？" | 愿景对齐工作坊 | 重新定义共同目标 |
| Type 02 角色模糊 | "谁负责什么？" | 角色重新划分+书面确认 | 边界清晰 |
| Type 03 信任崩塌 | "你背叛了我" | 第三方调解+信义修复计划 | 重建信任 |
| Type 04 利益分配 | "凭什么他拿得多？" | 贡献量化评估+股权调整 | 公平感恢复 |
| Type 05 决策僵局 | "听谁的？" | 决策权重新分配+僵局打破机制 | 决策流畅 |
| Type 06 沟通失效 | "他从来不听我说" | 沟通训练+定期sync机制 | 信息流通 |
| Type 07 价值观冲突 | "他做事的方式我无法接受" | 价值观对齐工作坊 | 底线共识 |
| Type 08 退出机制 | "我想走，但不知道怎么谈" | 退出协议+过渡期设计 | 和平分手 |
| Type 09 第三方介入 | "投资人/客户介入导致分裂" | 统一战线+外部关系管理 | 内部团结 |
| Type 10 成长速度差 | "我跟不上他的节奏" | 角色调整+能力补位计划 | 同步发展 |
| Type 11 家族/情感因素 | "他老婆不喜欢我" | 边界设定+家庭沟通 | 公私分明 |
| Type 12 外部危机应对 | "灾难来了，我们互相指责" | 危机应对预案+责任分配 | 共同抗敌 |

### 创始人5分钟可用性检验

- 12类型，一眼定位当前冲突类型 → ✅
- 每种类型有明确干预动作 → ✅
- 预期结果可量化验证 → ✅

## 【第十一站】留白轩 · 无为篇

**图腾**: 🌿 六祖慧能（火）——顿悟后的空白，是无为的空间  
**时间**: 2026-04-23  
**核心产出**: 12类型×无为留白指南

### 场景还原

治所后面是留白轩。不是空房间，是**有意的空白**——知道什么时候不干预。

无为篇的任务：冲突轻微时，**如何最小干预**，让系统自我修复。

### 12类型×无为留白指南

| 类型 | 无为留白 | 为什么有效 |
|:----:|----------|------------|
| Type 01 | 给双方各自写愿景的时间 | 愿景需要时间沉淀，不是讨论出来的 |
| Type 02 | 让自然分工浮现 | 角色在行动中自然形成，不是分配出来的 |
| Type 03 | 不立即追问"为什么" | 信任崩塌后，追问=施压，留白=给对方修复空间 |
| Type 04 | 暂缓讨论钱 | 利益敏感时，讨论=对抗，留白=让情绪降温 |
| Type 05 | 不强行拍板 | 僵局需要孵化，不是打破 |
| Type 06 | 不安排"沟通会议" | 沟通失效时，正式会议=表演，留白=让非正式对话自然发生 |
| Type 07 | 不争论"谁对谁错" | 价值观冲突没有对错，争论=加深分裂 |
| Type 08 | 不主动提退出 | 退出是对方的权利，主动提=逼迫 |
| Type 09 | 不立即回应外部 | 第三方介入时，立即回应=被牵着走 |
| Type 10 | 不给"学习建议" | 成长速度差时，建议=暗示"你不够好" |
| Type 11 | 不涉及家庭 | 家族因素，干预=越界 |
| Type 12 | 不立即"复盘" | 外部危机后，复盘=指责，留白=让创伤愈合 |

### 无为的边界

无为不是"什么都不做"。是：
- **观察**（但不评判）
- **等待**（但不放弃）
- **信任**（但不盲目）

### 创始人5分钟可用性检验

- 12类型，一眼知道"该不该干预" → ✅
- 无为有明确时间边界（如：观察2周） → ✅
- 有"无为失败"的升级机制 → ✅

## 【第十二站】本能殿 · 无不为篇

**图腾**: 🔥 六祖慧能（火）——顿悟内化到本能，是无不为  
**时间**: 2026-04-23  
**核心产出**: 五维内化训练路线图（三阶阶梯）

### 场景还原

留白轩深处是本能殿。不是健身房，是**大脑的力量训练中心**——让五维决策成为本能。

### 三阶阶梯

| 阶梯 | 名称 | 目标 | 训练内容 | 时间 |
|:----:|:----:|:----:|:--------:|:----:|
| 第一阶 | **知** | 知道五维是什么 | 工作坊+测评+卡牌游戏 | 2天 |
| 第二阶 | **行** | 能在冲突中调用五维 | 模拟冲突+教练反馈+案例演练 | 3个月 |
| 第三阶 | **化** | 五维成为本能 | 日常觉察训练+月度信义对账+年度复盘 | 1年 |

### 内化标志

| 阶段 | 标志 |
|:----:|------|
| 知 | 能说出五维的名称和含义 |
| 行 | 冲突爆发时，能想起"先用五维自检卡" |
| 化 | 冲突还没爆发，已经觉察到"信义账户在透支" |

### 创始人5分钟可用性检验

- 三阶阶梯，每阶有明确标志 → ✅
- 训练内容可执行 → ✅
- 时间预期合理 → ✅

## 【第十三站】归一亭 · 三生归一

**图腾**: 🌀 六祖慧能（火）——有为/无为/无不为，归一为"道"  
**时间**: 2026-04-23  
**核心产出**: 动态切换模型

### 场景还原

本能殿之外是归一亭。不是亭子，是**瞭望台**——从高处看，有为/无为/无不为不是三个独立的亭子，是一个亭子的三面。

### 动态切换模型

```
【觉察】冲突信号出现
  ↓
评估：紧急程度？
  ↓
高紧急 → 有为（全力干预）
中紧急 → 观察（无为留白）
低紧急 → 预防（无不为训练）
  ↓
【行动】→ 再次觉察 → 循环
```

### 切换的关键

| 从 | 到 | 触发条件 |
|:--:|:--:|:--------:|
| 无为 | 有为 | 冲突升级/有人受伤/业务受损 |
| 有为 | 无为 | 冲突降级/双方需要空间 |
| 无不为 | 有为 | 预防失败/冲突突然爆发 |
| 无不为 | 无为 | 系统稳定/不需要干预 |

### 创始人5分钟可用性检验

- 切换条件明确 → ✅
- 有"回退"机制 → ✅
- 模型可视化（流程图） → ✅
