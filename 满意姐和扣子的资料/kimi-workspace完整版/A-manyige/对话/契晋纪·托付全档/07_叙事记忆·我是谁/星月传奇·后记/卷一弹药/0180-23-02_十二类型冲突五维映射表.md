# 十二类型冲突 × 五维决策映射表

> **来源**: 星月传奇·后记五路图腾寻根之旅 + 奔月计划12类型案例库  
> **核心逻辑**: 每种冲突类型，有其"第一介入维度"和"辅助维度"  
> **使用场景**: 面对具体冲突时，快速定位从哪一维切入最有效

---

## 映射总表

| 类型 | 冲突名称 | **第一介入维度** | 辅助维度 | 核心判断 | 常见误区 |
|:----:|----------|:----------------:|:--------:|----------|----------|
| **Type 01** | 愿景分歧 | 🔴 **火·顿悟** | 土·信义 | 双方"真正想要"的东西可能一致，只是表达不同 | 急着说服对方，错过顿悟时刻 |
| **Type 02** | 角色模糊 | 🟢 **木·伦理** | 金·标尺 | 职责不清=伦理失位（礼），需要重新定义"义" | 直接分权，不先澄清伦理边界 |
| **Type 03** | 信任崩塌 | 🟤 **土·信义** | 水·觉察 | 没有信义根基，其他维度都无效 | 急着签补充协议，不先修复信义 |
| **Type 04** | 利益分配 | ⚪ **金·标尺** | 土·信义 | 用满意解标准量化，避免"最优解"内卷 | 陷入"谁贡献更多"的无限举证 |
| **Type 05** | 决策僵局 | 🔵 **水·觉察** | 火·顿悟 | 僵局往往是情绪劫持，觉察后才能重见选项 | 强行投票或独裁，跳过觉察 |
| **Type 06** | 沟通断裂 | 🔵 **水·觉察** | 木·伦理 | 不是"不会说"，是"被情绪挡住说不出口" | 上沟通培训课，不解决情绪 |
| **Type 07** | 价值观冲突 | 🟢 **木·伦理** | 火·顿悟 | 底层伦理框架不同，需要"顿悟"才能兼容 | 试图说服对方"你错了" |
| **Type 08** | 退出机制 | ⚪ **金·标尺** | 土·信义 | 退出是"满意解"的边界条件，不是失败 | 回避讨论，怕伤感情 |
| **Type 09** | 第三方介入 | 🟤 **土·信义** | 水·觉察 | 外部压力测试的是内部信义强度 | 责怪第三方，不反思内部 |
| **Type 10** | 成长速度差 | ⚪ **金·标尺** | 火·顿悟 | 速度不是好坏，是满意解标准的差异 | 快的一方指责慢的一方"不努力" |
| **Type 11** | 家族/情感因素 | 🟢 **木·伦理** | 土·信义 | "情"和"义"的张力是伦理问题，不是技术问题 | 用理性分析处理情感，越理越乱 |
| **Type 12** | 外部危机应对 | 🔴 **火·顿悟** | ⚪ 金·标尺 | 危机中需要顿悟式突破，不是渐进优化 | 按部就班开会，错过突破窗口 |

## 维度介入优先级速查

### 当冲突爆发时，先用这个速查：

```
【土·信义】有人提到"背叛/不守承诺/你怎么能这样"？
   → 是。必须先修复信义，其他维度延后。
   → 否。进入下一问。

【水·觉察】双方情绪明显失控（脸红/拍桌/沉默冷战）？
   → 是。先暂停，恢复觉察，再谈事。
   → 否。进入下一问。

【火·顿悟】这个问题有没有"不直接对抗"的解法？
   → 是。先舂米（孵化），等顿悟浮现。
   → 否。进入结构化分析。

【木·伦理】涉及"谁对谁错/公平与否/价值观"？
   → 是。先对齐伦理框架，再谈具体方案。
   → 否。进入量化分析。

【金·标尺】所有前置条件满足，需要具体分配/决策？
   → 是。用满意解标准量化，避免最优解陷阱。
```

## 经典场景映射

### 场景A：合伙人A突然说"我不想干了"
→ Type 08（退出机制）+ 可能伴随 Type 03（信任崩塌）  
→ **先土（信义）**："是什么让你走到了这一步？"  
→ **再金（标尺）**："什么样的退出方案，对双方都是满意解？"

### 场景B：合伙人A和B对公司的方向争吵不休
→ Type 01（愿景分歧）+ 可能伴随 Type 05（决策僵局）  
→ **先水（觉察）**："你们吵的是同一个东西吗？"  
→ **再火（顿悟）**："如果抛开现有方案，你们真正想要的结果是什么？"

### 场景C：合伙人A觉得自己的贡献被低估
→ Type 04（利益分配）+ 可能伴随 Type 11（情感因素）  
→ **先木（伦理）**："公平的定义是什么？"  
→ **再金（标尺）**："用可量化的满意解标准重新评估"

## 五维循环完整性检查

无论哪种类型，最终都需要走完五维循环：

```
冲突发生
  ↓
【土】信义账户是否健康？否→先修复
  ↓ 是
【水】觉察是否在线？否→先暂停
  ↓ 是
【火】有无顿悟可能？是→舂米孵化
  ↓ 否
【木】伦理是否对齐？否→先对齐
  ↓ 是
【金】满意解是否达成？是→FIN
  ↓ 否
【土】回到信义，检查是否受损
  ↓
循环直至五维全部通过
```
