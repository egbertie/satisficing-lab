# 第四站 · 契晋归一·动态契约模型

> **来源**: 星月传奇·后记卷四契晋共生  
> **核心问题**: 契·晋·共生如何动态统一？  
> **产出**: 动态契约模型 + 有为/无为/无不为在契约中的应用 + 卷四全旅程地图  
> **原则**: 契约不是"签完就完"，是**活文档**——随关系进化而进化

---

## 动态契约的定义

> "动态契约" = 契约条款随关系阶段自动调整。
>
> 不是"一年一签"，是**"条件触发时自动升级"**。
> 
> 就像游戏里的"升级系统"——达到条件，自动解锁新能力。

---

## 动态契约模型

### 核心机制

```
【触发条件】→ 【条款升级】→ 【新阶段协议】→ 【循环验证】

触发条件 = 量化指标（如：融资轮次/收入/团队规模）
条款升级 = 自动调整（如：决策权/股权/退出机制）
新阶段协议 = 双方确认（仪式化签署）
循环验证 = 季度/年度评估
```

### 四阶动态契约

| 阶段 | 触发条件 | 契约升级内容 | 五维模式 |
|:----:|----------|:------------:|:--------:|
| **契·初创** | 公司成立 | 基础合伙协议 + 信义账户建立 | 有为（建立基础） |
| **晋·成长** | A轮/年收入>1000万/团队>20人 | 角色重新定义 + 决策权调整 + 引入期权池 | 有为→无为（减少干预） |
| **共生·成熟** | C轮/年收入>1亿/团队>100人 | 事业合伙人制 + 传承条款 + 文化守护 | 无为（自动运行） |
| **传承·永续** | IPO/并购/创始人退出日常 | 董事会协议 + 创始人基金 + 行业导师制 | 无不为（本能守护） |

## 有为/无为/无不为在契约中的应用

### 有为模式 = 契约的"建立期"

**适用场景**：关系初期，或重大变化期。

**契约特征**：
- 条款详细（"如果X发生，则Y"）
- 约束明确（惩罚/退出/竞业）
- 频率：每月 review
- 目标：建立底线，防止最坏情况

**五维全开**：
- 🟤 土：详细记录所有承诺
- ⚪ 金：量化所有标准
- 🔵 水：觉察情绪，防止冲动签约
- 🟢 木：伦理底线写入条款
- 🔴 火：重大决策前24-48小时冷静期

---

### 无为模式 = 契约的"运行期"

**适用场景**：关系稳定，信任积累。

**契约特征**：
- 条款简化（"原则+例外处理机制"）
- 留白增加（"未尽事宜，双方协商"）
- 频率：每季度 review
- 目标：减少契约的"存在感"，让关系自然运行

**五维简化**：
- 🟤 土：信义对账（月度）
- ⚪ 金：年度满意解评估
- 🔵 水：觉察"契约疲劳"——"我们是不是被合同绑太紧了？"
- 🟢 木：伦理对齐（年度）
- 🔴 火：允许"契约外"的顿悟——"这个决策不在合同里，但感觉对"

---

### 无不为模式 = 契约的"内化期"

**适用场景**：共生阶段，信任自动化。

**契约特征**：
- 契约变成"背景文档"（"哦对，我们有那个"）
- 日常运行不需要引用契约
- 频率：年度 review 或仅在重大变化时
- 目标：契约"退休"，信任"上岗"

**五维内化**：
- 🟤 土：不需要"对账"，信义已自动化
- ⚪ 金：不需要"评估"，满意解已内化
- 🔵 水：不需要"觉察"，冲突自动降级
- 🟢 木：不需要"对齐"，伦理已一致
- 🔴 火：不需要"舂米"，顿悟自然发生

## 动态契约的"升级仪式"

### 为什么需要仪式？

> 契约升级不是"改个条款"，是**关系形态的正式转变**。
> 
> 就像游戏升级——不是"属性变了"，是"你解锁了新技能"，需要被标记。

### 升级仪式框架

```
【动态契约升级仪式】

1. 触发确认（5分钟）
   - "我们已达到X条件，契约升级到Y阶段"
   - 双方确认

2. 回顾旧契约（10分钟）
   - "上一阶段的契约，哪些条款我们一次也没用过？"
   - "哪些条款救了我们？"

3. 新契约解读（15分钟）
   - 逐条解读新条款
   - 重点：变化点（新增/删除/修改）

4. 五维对齐（10分钟）
   - 新阶段的信义账户余额
   - 新阶段的满意解标准
   - 新阶段的觉察状态
   - 新阶段的伦理底线
   - 新阶段的顿悟空间

5. 签署与庆祝（5分钟）
   - 签署新契约
   - 拍照/纪念
   - 小庆祝（不是"庆功"，是"标记转变"）

总计：45分钟
```

## 动态契约的"降级保护"

> 动态契约不只是"升级"，还需要**"降级保护"**。
> 
> 关系可能倒退——从共生回到契约驱动，或从核心合伙人回到联合创始人模式。

### 降级信号

| 信号 | 含义 | 应对 |
|------|------|------|
| 开始频繁引用合同 | 信任在下降 | 启动信义修复（有为） |
| 恢复"正式会议" | 默契在消失 | 增加非工作互动（无为） |
| 冲突解决时间变长 | 自动修复能力在退化 | 用五维框架干预（有为） |
| 信息透明度下降 | 关系在疏远 | 强制信息共享机制（有为） |

### 降级流程

```
降级信号出现
  ↓
评估：暂时波动 vs 结构性倒退？
  ↓
暂时波动 → 无为观察（2-4周）
结构性倒退 → 有为干预（立即）
  ↓
干预成功 → 恢复当前阶段
干预失败 → 正式降级到前一阶段
  ↓
降级仪式（与升级仪式类似，但氛围更严肃）
```
