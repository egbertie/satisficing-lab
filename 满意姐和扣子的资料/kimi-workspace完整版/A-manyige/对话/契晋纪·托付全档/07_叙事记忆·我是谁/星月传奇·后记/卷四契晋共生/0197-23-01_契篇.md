# 第一站 · 契篇·承诺的制度化

> **来源**: 星月传奇·后记卷四契晋共生  
> **核心问题**: 如何把信义从道德变成制度？  
> **产出**: 合伙人协议模板库（6版本）+ 承诺追踪系统 + 信义账户制度化  
> **原则**: 契不是束缚，是保护——保护双方免受"默认假设"的伤害

---

## 契的定义

> "契" = 把隐性的承诺变成显性的制度。
>
> 不是不相信对方，是**给信任一个容器**。
> 
> 就像把空气装进瓶子——空气还在，但有了形状，可以携带，可以测量，可以传递。

---

## 为什么需要制度化？

### 隐性契约的陷阱

合伙人最常见的错误："我们是兄弟/闺蜜/老同学，不用写那么清楚。"

**数据**：
- 70%的合伙人冲突，表面是利益，底层是**"我以为你懂" vs "我以为你懂"**
- 书面化合伙协议的团队，冲突解决速度比口头约定快**3倍**
- 有退出机制约定的团队，和平分手率是未约定团队的**5倍**

**核心洞察**：**信义需要制度化，不是因为不信任，是因为太信任——太信任"默契"不会出错。**

## 合伙人协议模板库（6版本）

### 版本矩阵

| 维度 | 选项A | 选项B | 选项C |
|------|-------|-------|-------|
| **人数** | 2人 | 3人 | 4人+ |
| **背景** | 技术+商业 | 技术+技术 | 商业+商业 |
| **阶段** | 初创期 | 成长期 | 成熟期 |

**组合 = 6个核心版本**（覆盖80%场景）：

---

### 版本1：2人·技术+商业·初创期

**适用场景**：最常见组合——一位技术创始人 + 一位商业联合创始人。

#### 核心条款

**条款1：股权结构**
```
创始人A（技术）：55%
联合创始人B（商业）：35%
期权池：10%

vesting：4年，1年cliff，之后按月兑现
```

**条款2：决策权**
```
日常决策：各自负责领域自主决策
重大决策（>X万元/人员变动/融资）：需双方一致同意
僵局处理：引入第三方顾问或董事会裁决
```

**条款3：角色边界**
```
创始人A：产品/技术/研发
联合创始人B：市场/销售/融资
交集区（战略/招聘/文化）：共同决策
```

**条款4：信义账户**
```
双方同意建立"信义账户"——记录承诺与兑现。
每月最后一周：15分钟信义对账。
未兑现承诺需在72小时内书面说明原因+补救方案。
```

**条款5：退出机制**
```
主动退出：提前6个月通知，按vested股份回购
被动退出（重大违约/能力不匹配/价值观冲突）：
  - 董事会评估
  - 按公允价值回购vested股份
  - 6个月竞业限制
```

**条款6：冲突解决**
```
第一阶段：双方直接沟通（72小时内）
第二阶段：引入共同信任的调解人（1周内）
第三阶段：专业教练/仲裁（1月内）
第四阶段：法律途径（最后手段）
```

---

### 版本2：2人·技术+技术·初创期

**适用场景**：两位技术背景合伙人（如：CTO + 首席架构师）。

#### 与版本1的差异

| 条款 | 版本1（技术+商业） | 版本2（技术+技术） |
|------|:-----------------:|:-----------------:|
| 股权 | 55:35 | 50:50（技术对等） |
| 决策 | 商业方主导市场 | 需引入外部商业顾问 |
| 角色 | 清晰分工 | 技术重叠区需特别约定 |
| 风险 | 商业能力不足 | 决策僵局风险更高 |

**特别条款**：
```
技术重叠区处理：
- 各自明确"核心技术领地"
- 交集区采用"轮流决策"或"第三方评估"
- 每季度评估技术分工效率
```

---

### 版本3：2人·商业+商业·初创期

**适用场景**：两位商业背景合伙人（如：CEO + CMO）。

#### 与版本1的差异

| 条款 | 版本1（技术+商业） | 版本3（商业+商业） |
|------|:-----------------:|:-----------------:|
| 股权 | 55:35 | 50:50 或 51:49 |
| 决策 | 技术方主导产品 | 产品决策需引入技术顾问 |
| 角色 | 清晰分工 | 市场/销售重叠区需约定 |
| 风险 | 技术能力不足 | 技术外包依赖风险 |

**特别条款**：
```
技术外包管理：
- 核心技术必须内部化（18个月内）
- 外包团队需签署保密+竞业协议
- 技术债每季度评估
```

---

### 版本4：3人·混合背景·成长期

**适用场景**：三人合伙（如：CEO + CTO + COO），公司已进入成长期。

#### 核心条款

**股权结构**
```
CEO：40%
CTO：30%
COO：20%
期权池：10%

特别约定：
- 任何两人联合可否决第三人决策
- 防止"51%独裁"或"33%僵局"
```

**决策机制**
```
三级决策：
- 一级（日常）：各自领域自主
- 二级（重大）：2/3同意
- 三级（战略）：全体一致或董事会

僵局处理：
- 48小时内无法达成一致 → 暂停48小时 → 仍未达成 → CEO有最终决定权（每季度限用1次）
```

**退出机制**
```
三人退出比两人复杂：
- 一人退出 → 剩余两人按原比例吸收股份
- 两人联合退出 → 触发公司清算或收购条款
- 引入新合伙人 → 需全体一致 + 90天考察期
```

---

### 版本5：4人+·混合背景·成长期

**适用场景**：四人及以上合伙团队，常见于连续创业或并购整合。

#### 核心条款

**股权结构**
```
创始人A：30%
创始人B：25%
创始人C：20%
创始人D：15%
期权池：10%

特别约定：
- "动态股权"机制：根据贡献每年调整±5%
- 调整依据：事先约定的KPI（如：融资额/收入/产品里程碑）
```

**决策机制**
```
- 日常：各自领域自主
- 重大：>50%同意
- 战略：>75%同意
- 章程修改：全体一致

防止"小团体"：
- 任何两人私下协议不得损害其他人利益
- 信息披露：所有合伙人共享核心信息
```

**退出机制**
```
- 退出需提前3个月通知
- 股份回购：剩余合伙人按比例认购或引入新合伙人
- 竞业限制：12个月
- 客户/知识产权交接：60天过渡期
```

---

### 版本6：成熟期·事业合伙人制

**适用场景**：公司成熟后，从"创始人合伙"转向"事业合伙人制"——吸引外部高管成为合伙人。

#### 核心条款

**事业合伙人定义**
```
不是联合创始人，是"核心管理层+长期利益绑定"。
条件：
- 入职≥2年
- 业绩排名前20%
- 价值观评估通过
- 创始人推荐+合伙人委员会批准
```

**利益绑定**
```
- 虚拟股权/分红权（非实股）
- 3年锁定期
- 业绩挂钩的动态调整
- 退出时按约定公式回购
```

**与创始合伙人的区别**

| 维度 | 创始合伙人 | 事业合伙人 |
|------|:----------:|:----------:|
| 股权 | 实股 | 虚拟股权/分红权 |
| 决策权 | 重大决策参与 | 领域决策参与 |
| 退出 | 复杂 | 简单（按公式回购） |
| 风险 | 共同承担 | 有限承担 |
| 数量 | 2-4人 | 可扩展至10-20人 |

## 承诺追踪系统

### 为什么需要？

合伙人冲突的底层，往往是**"信义账户透支"**——一方觉得"你答应的没做到"，另一方觉得"你没理解我的意思"。

承诺追踪系统 = **给信义账户一本账**。

### 系统设计

```
【承诺追踪表】每周更新

| 日期 | 承诺人 | 承诺内容 | 兑现期限 | 状态 | 备注 |
|:----:|:------:|----------|:--------:|:----:|------|
| 4/1 | A | 完成产品原型 | 4/15 | ✅ | 提前2天 |
| 4/3 | B | 联系3位投资人 | 4/10 | ⚠️ | 联系了2位 |
| 4/5 | A | 参加行业会议 | 4/20 | ❌ | 因其他事务取消 |

【月度信义对账】
- 时间：每月最后一周的周五下午，30分钟
- 形式：面对面或视频
- 内容：
  1. 本月承诺兑现率
  2. 未兑现承诺的原因分析
  3. 下月关键承诺确认
  4. 信义账户余额评估（+/-）
```

### 信义账户余额评估

| 评估项 | 权重 | A→B | B→A |
|--------|:----:|:---:|:---:|
| 承诺兑现率 | 40% | 85% | 70% |
| 紧急时刻"讲义气" | 30% | ⭐⭐⭐ | ⭐⭐ |
| 信息共享透明度 | 20% | ⭐⭐⭐⭐ | ⭐⭐⭐ |
| 主动帮助对方 | 10% | ⭐⭐⭐ | ⭐⭐⭐ |
| **加权总分** | 100% | **+8** | **+3** |

**解读**：
- +10 ~ +7：信义深厚，可进入无为模式
- +6 ~ +3：信义稳健，需要日常维护
- +2 ~ -2：信义薄弱，需要有为修复
- -3 ~ -10：信义透支，需要紧急干预
