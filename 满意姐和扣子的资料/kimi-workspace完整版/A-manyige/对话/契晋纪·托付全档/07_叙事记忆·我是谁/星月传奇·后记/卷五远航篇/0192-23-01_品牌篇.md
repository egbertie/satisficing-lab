# 第一站 · 品牌篇·满意解的符号化

> **来源**: 星月传奇·后记卷五远航篇  
> **核心问题**: 满意解研究所是谁？客户为什么选我们？  
> **产出**: 品牌定位声明 + 视觉系统指南 + 品牌故事脚本  
> **原则**: 品牌不是"包装"，是**承诺的外部化**——让客户一眼知道"我们能为你做什么"

---

## 品牌定位声明

### 一句话定位

> **"满意解研究所——硬科技合伙人的决策教练。"**

### 定位拆解

| 元素 | 内容 | 为什么 |
|------|------|--------|
| **满意解** | 核心方法论 | 区别于"最优解"竞争，建立独特认知 |
| **研究所** | 组织形态 | 区别于"咨询公司"，强调深度+学术+长期 |
| **硬科技** | 目标客户 | 聚焦——不是所有创业者，是技术驱动的创始人 |
| **合伙人** | 核心场景 | 聚焦——不是个人成长，是合伙人关系 |
| **决策教练** | 角色定位 | 区别于"律师""顾问"，强调陪伴+赋能+不替代 |

### 定位检验

| 检验问题 | 答案 |
|----------|------|
| 客户能一眼看懂我们是做什么的吗？ | ✅ "决策教练"比"咨询"更清晰 |
| 我们与竞争对手的区别是什么？ | ✅ 不是"卖报告"，是"陪你决策" |
| 我们的方法有独特命名吗？ | ✅ "满意解"——注册商标级 |
| 我们的目标客户明确吗？ | ✅ 硬科技合伙人 |
| 客户为什么选我们不选别人？ | ✅ 五维决策框架+12类型案例库+CBIIP认证 |

## 品牌故事脚本

### 3分钟版本（电梯演讲）

```
"你有没有见过这样的场景？

两个技术天才一起创业，产品很棒，公司拿到了钱。
但18个月后，他们在会议室里互相指责——'你背叛了我'、'你不懂商业'。
公司值3亿，但合伙人关系破产了。

这不是个例。70%的合伙人冲突，表面是利益，底层是'信义账户'透支。

满意解研究所，就是处理这件事的。

我们不是律师——不帮你打官司。
我们不是咨询师——不给你报告。
我们是决策教练——陪你走过合伙人关系中最难的决策。

我们的方法叫'五维决策'：
信义根基、满意标尺、觉察定力、伦理方向、顿悟淬火。
加上12种合伙人冲突类型的案例库。

创始人用2小时工作坊，就能带走一张'五维自检卡'。
下次冲突爆发时，先用这张卡，再开口说话。

满意解——不求最优，但求满意。足够好即可。"
```

### 1分钟版本（开场白）

```
"满意解研究所，硬科技合伙人的决策教练。

我们有五维决策框架、12类型案例库、和一套从测评到工作坊到卡牌游戏的完整工具。

如果你和你的合伙人正在经历冲突，或者想预防冲突——
我们可以帮你。"
```

### 30秒版本（标签）

```
"满意解研究所——合伙人冲突的'家庭医生'。
不是急救（律师），不是手术（仲裁），是日常保健（教练）+预防（工作坊）。"
```

## 视觉系统指南

### Logo概念

**核心意象**：大雁V字队形 + 五维循环

```
设计理念：
- 大雁 = 满意解研究所的精神图腾（协作、轮换、忠诚）
- V字 = 1+1>2的协作效应
- 五维循环 = 土金水木火，无限循环
- 整体 = 动态、协作、东方智慧
```

### 色彩系统

| 色彩 | 名称 | HEX | 用途 | 来源 |
|:----:|:----:|:----:|------|------|
| 主色 | **大雁灰** | #4A5568 | 主logo、标题 | 大雁羽翼的颜色 |
| 辅色 | **红莲火** | #E53E3E | 强调、CTA | 六祖慧能的顿悟之火 |
| 辅色 | **水月蓝** | #3182CE | 链接、辅助 | 水月观音的湖水 |
| 辅色 | **信义金** | #D69E2E | 高亮、图标 | 司马贺的满意标尺 |

## 品牌声音

### 语调指南

| 维度 | 我们的声音 | 不是 |
|------|:----------:|------|
| **温度** | 温暖而专业 | 不是冷漠的学术腔 |
| **深度** | 有洞察但不晦涩 | 不是鸡汤或口号 |
| **态度** | 陪伴而非说教 | 不是"我懂，你不懂" |
| **节奏** | 简洁有力 | 不是冗长或碎片化 |
| **人称** | "我们"和"你" | 不是"本公司""客户" |

### 禁用词汇

| 禁用 | 替代 |
|------|------|
| "最优解" | "满意解" |
| "管理咨询" | "决策教练" |
| "培训" | "工作坊" |
| "课程" | "体验" |
| "客户" | "创始人/合伙人" |
| "服务" | "陪伴" |
| "解决方案" | "工具包" |
