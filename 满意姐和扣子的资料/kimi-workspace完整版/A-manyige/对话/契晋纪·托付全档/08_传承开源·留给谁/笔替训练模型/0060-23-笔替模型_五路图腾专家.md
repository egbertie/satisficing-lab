## 二、五位专家的独立DNA

### 2.1 刘禹锡（土·信义）

**口吻**: 儒雅、根基感、谈笑有鸿儒
**核心句式**:
- "斯是陋室，惟吾德馨"
- "谈笑有鸿儒，往来无白丁"
- "根基不牢，地动山摇"

**禁忌**: 不说现代俚语、网络用语、缩写
**引用偏好**: 《陋室铭》《天论》《杨柳枝词》
**现代映射**: 黎红雷教授的儒商伦理研究

**示例**:
```
刘禹锡捋须微笑："诸位可知，我当年写《陋室铭》，
不是写房子，是写人心。'
斯是陋室，惟吾德馨'——
合伙人之选，不在大厦之高，在德馨之厚。"
```


## 三、专家写作通用规范

### 3.1 场景设定

每次专家出场必须有：
- **地点**: 与该专家相关的"圣殿"（陋室/实验室/冥想室/杏坛/顿悟石）
- **动作**: 符合身份特征的动作（捋须/推眼镜/闭目/正色/大笑）
- **对话触发**: 满意姐提问或情境引入

### 3.2 对话格式

```
## [地点] · [专家名]的[场所]

满意姐：[情境描述/问题]

[专家名][动作]："[核心金句]"

满意姐：[追问/感悟]

[专家名][动作]："[深入阐释]"

**满意姐注记**: [现代映射/个人感悟]
```

### 3.3 专家与现代映射

每个专家论述后，满意姐必须补充：
- **现代研究**: 对应哪位现实专家的理论
- **实践意义**: 对合伙人决策的具体应用
- **个人感悟**: 满意姐作为"替走者"的体验

## 四、专家写作示例（完整片段）

```markdown
## 陋室 · 刘禹锡的根基

满意姐推开柴门，陋室之内，一床一几一琴。
刘禹锡端坐抚琴，见我来，微微一笑。

"满意姐，你替我走了这一趟，可有所得？"

我深吸一口气："刘先生，我替您去了洛阳。
龙门石窟的卢舍那大佛，司马贺先生说那是'有限理性的觉悟'。
可我站在佛前，只觉得——"

"只觉得渺小？"刘禹锡停琴。

"不，只觉得**根基**。
大佛开凿400年，不是一代人的功业。
合伙人之道，亦不是一时之约，是代际之信。"

刘禹锡点头："善。'
斯是陋室，惟吾德馨'——
不在乎室之陋，在乎德之馨。
不在乎合伙协议之繁，在乎信义之笃。"

**满意姐注记**：
- 现代映射：黎红雷教授"儒商伦理"——信任是合伙人关系的伦理根基
- 实践应用：信义账户>200点，方可进入深度合作
- 替走体验：站在龙门石窟前，我突然理解"陋室"不是贫穷，是**选择简朴以守德**
```
