## 二、企业内训实施流程

### 售前阶段

```
Step 1: 需求诊断（免费）
  → 与企业HR/创始人沟通
  → 了解痛点：合伙人冲突？决策效率低？团队信任差？
  → 输出：需求诊断报告

Step 2: 方案定制（免费）
  → 根据诊断结果，定制培训方案
  → 包括：内容、时长、人数、价格
  → 输出：定制方案书

Step 3: 提案汇报
  → 向决策层汇报方案
  → 解答疑问
  → 签署合同
```

### 实施阶段

```
Step 4: 课前准备
  → 学员调研（课前问卷）
  → 案例收集（企业真实案例）
  → 场地/设备确认

Step 5: 培训实施
  → 按日程执行
  → 实时调整（根据学员反馈）
  → 拍照/录像（征得同意）

Step 6: 课后跟进
  → 学员反馈收集
  → 效果评估（前后对比）
  → 后续支持计划
```

### 售后阶段

```
Step 7: 效果追踪（1个月后）
  → 回访：决策质量是否提升？
  → 收集：成功案例
  → 邀请：推荐其他企业

Step 8: 持续合作
  → 年度顾问续签
  → 新增模块培训
  → 企业内部导师培养
```
