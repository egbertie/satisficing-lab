### 3.3 促销原则

```
【原则1：不随意降价】
├─ 原价是锚，降价是促销
├─ 不能让用户觉得"原价就是虚高"
└─ 促销要有明确理由（节日、早鸟、团购）

【原则2：价值优先】
├─ 促销时强调"你将获得什么"，不是"省了多少钱"
├─ 例："早鸟价让你提前锁定名额"而不是"便宜300元"
└─ 用户买的是价值，不是折扣

【原则3：稀缺性】
├─ 限名额、限时间、限条件
├─ 稀缺性驱动行动
└─ 但不能虚假稀缺（"仅剩3个名额"但其实是真的只剩3个）

【原则4：不叠加】
├─ 一次只能用一个优惠
├─ 防止用户"等更好的优惠"
└─ 例：新人优惠和团购不能叠加

【原则5：透明】
├─ 促销规则清晰，不隐藏条件
├─ 退款政策明确
└─ 避免用户投诉"被套路"
```

## 第四部分：价格管理

### 4.1 价格调整机制

```
【涨价策略】
├─ 触发条件：
│   ├─ 成本上涨>20%
│   ├─ 产品升级（新增模块/服务）
│   ├─ 市场需求旺盛（供不应求）
│   └─ 品牌升级（从"新手"到"专家"）
├─ 调整幅度：5-20%
├─ 提前通知：至少30天
├─ 老用户保护：已付费用户不涨价
└─ 新用户引导："即将涨价，现在锁定原价"

【降价策略】
├─ 触发条件：
│   ├─ 产品生命周期末期
│   ├─ 清仓/淘汰
│   └─ 促销需要
├─ 调整幅度：10-30%
├─ 注意：不能频繁降价，损害品牌价值
└─ 替代方案：推出"轻量版"而非直接降价

【价格测试】
├─ A/B测试：不同用户看到不同价格
├─ 测试指标：转化率、收入、用户满意度
├─ 测试周期：至少2周
└─ 决策依据：数据说话
```

---

### 4.2 价格保护

```
【老用户保护】
├─ 已付费用户：价格不变，享受升级
├─ 续费优惠：老用户续费享受8折
├─ 升级优惠：低阶升高级，差价减半
└─ 目的：维护老用户，提高留存

【价格一致性】
├─ 全渠道价格一致（官网/公众号/小红书/代理）
├─ 避免用户"比价"发现差异
├─ 代理商价格：统一折扣（如7折），不得擅自调整
└─ 违规处罚：取消代理资格

【价格保密】
├─ 不向未付费用户透露"底价"
├─ 企业客户报价：根据需求定制，不公开
├─ 防止"等降价"心理
└─ 促销价格明确标注"限时"
```

> **核心原则**：
> 定价是"价值信号"，不是"成本回收"。
>
> 用户买的不是"14个模块"，
> 是"合伙人关系不崩"的确定性。
>
> 所以：
> ├─ 价格要反映价值（150-500万的隐性成本 vs 2999元课程）
> ├─ 价格要分层（199→2999→9999→29999，满足不同预算）
> ├─ 价格要稳定（不随意降价，保护品牌价值）
> └─ 价格要灵活（促销、团购、企业定制）
>
> 满意解的定价信仰：
> "不求最贵，但求最值。"
>
