## 第一部分：行业概述

### 1.1 行业定义

```
【决策教练行业】

定义：
"决策教练"是帮助个人/团队提升决策质量的
专业服务。

细分赛道：
├─ 战略决策教练（CEO层面）
├─ 投资决策教练（投资人层面）
├─ 合伙人决策教练（创业团队层面）← 满意解
├─ 职业决策教练（个人层面）
└─ 组织决策教练（企业层面）

【合伙人决策教练】

定义：
专注帮助创业团队解决"合伙人关系"问题的
决策教练服务。

核心问题：
├─ 如何选对合伙人？
├─ 如何设计股权？
├─ 如何分配决策权？
├─ 如何解决冲突？
├─ 如何设计退出机制？
└─ 如何维护长期关系？

【行业边界】

与心理咨询的区别：
├─ 心理咨询：关注个人心理健康
├─ 决策教练：关注决策质量与关系优化
└─ 交叉点：情绪管理、沟通技巧

与管理咨询的区别：
├─ 管理咨询：关注组织效率
├─ 决策教练：关注合伙人关系
└─ 交叉点：团队建设、角色设计

与法律咨询的区别：
├─ 法律咨询：关注法律合规
├─ 决策教练：关注决策科学与关系管理
└─ 交叉点：股权设计、退出机制
```

---

### 1.2 行业发展历程

```
【阶段1：萌芽期（2010-2018）】
├─ 特征：创业热潮，合伙人问题初显
├─ 服务：律师事务所处理股权纠纷
├─ 问题：事后补救，无预防机制
└─ 代表：传统律所、管理咨询

【阶段2：发展期（2018-2023）】
├─ 特征：创投市场成熟，合伙人冲突频发
├─ 服务：教练机构开始关注团队关系
├─ 问题：泛而不精，缺乏方法论
└─ 代表：埃里克森教练、共创式教练

【阶段3：细分期（2023-2026）】
├─ 特征：硬科技创业兴起，合伙人问题专业化
├─ 服务：出现专注合伙人决策的服务
├─ 问题：市场教育不足，标准缺失
└─ 代表：满意解研究所（首创）

【阶段4：标准化期（2026+）】
├─ 特征：行业成熟，标准建立
├─ 服务：认证体系、行业标准
├─ 机会：头部品牌建立壁垒
└─ 目标：满意解成为标准制定者
```

```

├─ 存续企业：3000万家
├─ 新增企业：500万/年
├─ 有合伙人的企业：约60% = 1800万家
└─ TAM = 1800万潜在用户

【SAM：可服务市场】

有付费意愿和能力的企业：
├─ 融资企业：50万家（A轮及以上）
├─ 营收>1000万企业：200万家
├─ 有HR预算的企业：500万家
└─ SAM = 500万潜在用户

【SOM：可获取市场】

3年内可触达的用户：
├─ 线上获客能力：50万/年
├─ 企业内训能力：1000家/年
├─ 品牌认知度：5%
└─ SOM = 50万用户（3年）

【市场规模估算】

├─ 用户：50万人

├─ 企业：10万家
```

```
└─ 保密标准：符合法律法规
```
