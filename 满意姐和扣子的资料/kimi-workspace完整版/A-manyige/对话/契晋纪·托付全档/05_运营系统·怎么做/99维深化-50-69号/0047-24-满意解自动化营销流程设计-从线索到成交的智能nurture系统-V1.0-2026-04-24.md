## 二、核心自动化流程

### 流程1：免费测评 nurture（7天序列）

**触发条件**: 用户完成免费测评

```
Day 0（即时）
  → 发送测评报告
  → 附：1v1解读预约链接
  → 附：14模块前3章（免费）

Day 1
  → 发送"测评报告解读指南"
  → 附：3分钟视频解读

Day 2
  → 发送"五维框架应用场景"
  → 附：3个真实案例

Day 3
  → 发送"学员故事：从冲突到和解"
  → 附：视频证言

Day 4
  → 发送"常见问题解答"
  → 附：FAQ链接

Day 5
  → 发送"限时优惠：早鸟价-20%"
  → 附：课程介绍+报名链接
  → 条件：如果用户已访问课程页但未下单

Day 6
  → 发送"最后提醒：优惠今晚截止"
  → 附：倒计时+报名链接

Day 7
  → 发送"优惠已结束，但学习不停止"
  → 附：免费资料+社群邀请
  → 转入长期 nurture
```

### 流程2：课程学习 nurture（14天序列）

**触发条件**: 用户购买CDA初级认证

```
Day 0（即时）
  → 欢迎邮件+学习路径图
  → 附：课程平台登录指南
  → 附：社群邀请

Day 1
  → "模块1学习提醒"
  → 附：学习技巧

Day 3
  → "模块1作业提醒"
  → 条件：如果未完成作业

Day 5
  → "模块2开启提醒"
  → 附：学员笔记分享

Day 7
  → "周度复盘：本周学习进度"
  → 条件：如果进度<50%，发送鼓励
  → 条件：如果进度>80%，发送奖励

Day 10
  → "模块3-4加速包"
  → 附：重点难点解析

Day 12
  → "考试准备指南"
  → 附：模拟题

Day 14
  → "考试提醒+升级优惠"
  → 附：中级认证早鸟价
```

### 流程3：沉默用户唤醒（30天序列）

**触发条件**: 用户7天未登录/30天未互动

```
Day 7（沉默）
  → "好久不见，满意姐想你了"
  → 附：最新内容推荐
  → 附：1个问题邀请回答

Day 14（仍沉默）
  → "你错过了什么？"
  → 附：本周精华内容

Day 21（仍沉默）
  → "一个决策故事，可能对你有用"
  → 附：案例+免费测评（再次）

Day 30（仍沉默）
  → "我们还能为你做什么？"
  → 附：简短调查（3题）
  → 选项：A.内容不感兴趣 B.已解决问题 C.太忙 D.其他

Day 30+（根据调查结果）
  → A：调整内容偏好
  → B：转入校友 nurture
  → C：减少推送频率
  → D：人工跟进
```

### 流程4：高价值线索升级（实时触发）

**触发条件**: 用户行为评分达到阈值

```
行为评分规则：
- 完成测评：+10分
- 访问课程页：+20分
- 下载资料：+15分
- 观看直播：+25分
- 1v1咨询预约：+50分
- 添加购物车：+40分
- 分享内容：+30分

阈值：
- 80分 → 人工介入（满意姐私信）
- 120分 → 人工介入（Egbertie电话）
```

## 四、温度控制

### 自动化 ≠ 冷冰冰

| 场景 | 温度策略 |
|:-----|:---------|
| 欢迎邮件 | 用"满意姐"署名，不是"系统通知" |
| 催付邮件 | 用"优惠提醒"而非"您尚未付款" |
| 唤醒邮件 | 用"好久不见"而非"您已沉默X天" |
| 生日祝福 | 用"Egbertie和满意姐祝您..." |
| 升级推荐 | 用"适合您的进阶路径"而非"买更贵的" |

### 人工介入时机

| 场景 | 自动化 | 人工介入 |
|:-----|:-------|:---------|
| 日常 nurture | ✅ | ❌ |
| 高价值线索 | 初步筛选 | ✅ 1v1 |
| 复杂问题 | ❌ | ✅ 专家 |
| 投诉处理 | ❌ | ✅ Egbertie |
| 大客企业 | 资料发送 | ✅ 方案定制 |
