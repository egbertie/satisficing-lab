## 一、NPS概述

### 什么是NPS

NPS（净推荐值）是衡量客户忠诚度的核心指标：

```
NPS = 推荐者% - 贬损者%

推荐者（9-10分）：愿意推荐
被动者（7-8分）：满意但不主动推荐
贬损者（0-6分）：不满意，可能负面传播
```

### 满意解NPS目标

| 等级 | NPS范围 | 说明 |
|:-----|:--------|:-----|
| 世界级 | >70 | 苹果、特斯拉水平 |
| 优秀 | 50-70 | 满意解目标 |
| 良好 | 30-50 | 行业平均 |
| 一般 | 0-30 | 需改进 |
| 差 | <0 | 严重问题 |

## 四、数据分析

### NPS计算

```
示例：100人参与调查

推荐者（9-10分）：50人 → 50%
被动者（7-8分）：30人 → 30%
贬损者（0-6分）：20人 → 20%

NPS = 50% - 20% = 30
```

### 五维分析

```
维度        平均分   与NPS相关性
─────────────────────────
土·伦理     8.5      强正相关
金·满意解   7.8      强正相关
水·洞察     7.2      中等相关
木·信任     6.5      强正相关
火·直觉     8.0      强正相关
─────────────────────────

洞察：木·信任（6.5分）是短板
行动：加强导师信任建设
```

### 文本分析

```
推荐原因高频词：
1. "方法论实用"（35%）
2. "有温度"（25%）
3. "Egbertie专业"（20%）

改进建议高频词：
1. "希望更多案例"（30%）
2. "价格有点高"（20%）
3. "APP功能不够"（15%）
```

## 五、行动计划

### NPS<30（紧急改进）

```
Step 1: 48小时内分析贬损者反馈
Step 2: 识别Top 3问题
Step 3: 制定改进计划（30天内）
Step 4: 向贬损者致歉+补偿
Step 5: 30天后复测
```

### NPS 30-50（持续优化）

```
Step 1: 分析被动者→推荐者的障碍
Step 2: 优化产品/服务
Step 3: 增加推荐激励
Step 4: 季度复测
```

### NPS>50（放大优势）

```
Step 1: 分析推荐者推荐原因
Step 2: 强化优势，复制成功
Step 3: 邀请推荐者成为KOC
Step 4: 收集案例，用于营销
```
