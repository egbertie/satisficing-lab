# 满意解APP产品需求文档（PRD）——移动端五维决策工具

> **产品**: 满意解APP（移动端）
> **编制者**: 满意姐（SAT-001）+ 蓝军 Skeptor-7（技术审计）
> **审核**: Egbertie（产品经理）
> **时间**: 2026-04-24
> **版本**: V1.0
> **平台**: iOS + Android
> **定位**: 随身携带的决策教练
> **核心**: 5分钟评估 + 即时报告 + 持续陪伴
> **目标**: 首年10万下载，5万注册用户

---

## 一、产品概述

### 一句话描述
> "口袋里的决策教练——随时随地，用五维框架做出更好的决策。"

### 核心场景

| 场景 | 用户痛点 | APP解决方案 |
|:-----|:---------|:------------|
| 见合伙人前 | 不知道怎么评估 | 5分钟测评，即时报告 |
| 决策犹豫时 | 思路混乱 | 五维卡牌，结构化思考 |
| 冲突发生时 | 情绪激动 | 冲突诊断，理性分析 |
| 学习提升 | 碎片时间学习 | 14模块微课，5分钟/节 |
| 日常复盘 | 忘记决策方法 | 每日推送，温故知新 |

## 三、核心流程

### 流程1：快速测评（5分钟）

```
[打开APP] → [首页点击"开始测评"]
    ↓
[选择测评类型]
  → 合伙人匹配
  → 决策质量
  → 冲突风险
    ↓
[答题]（每维3-5题，共15-25题）
  → 土·伦理：3题
  → 金·满意解：5题
  → 水·洞察：5题
  → 木·信任：5题
  → 火·直觉：3题
    ↓
[提交] → [计算评分]
    ↓
[查看报告]
  → 综合评分（0-50分）
  → 五维雷达图
  → 冲突风险预警
  → 行动建议
    ↓
[保存/分享/下载PDF]
```

### 流程2：五维卡牌（10分钟）

```
[打开APP] → [底部导航"卡牌"]
    ↓
[选择模式]
  → 单人：自我决策
  → 双人：与合伙人一起玩
  → 团队：工作坊模式
    ↓
[选择主题]
  → 合伙人评估
  → 投资决策
  → 招聘决策
  → 战略决策
    ↓
[抽卡]
  → 动画抽卡效果
  → 显示卡牌内容
  → 回答问题/执行行动
    ↓
[记录结果]
  → 保存决策记录
  → 生成决策日志
```

## 五、技术架构

### 前端

```
技术栈:
- React Native（跨平台）
- Redux（状态管理）
- Reanimated（动画）
- React Navigation（路由）

组件库:
- 自定义UI组件（品牌一致）
- 图表库（雷达图、柱状图）
- 动画库（抽卡、翻页）
```

### 后端

```
技术栈:
- Node.js + Express
- MongoDB（数据）
- Redis（缓存）
- AWS S3（文件存储）

API设计:
- RESTful API
- JWT认证
- 限速保护
```

### 算法

```
五维评估引擎:
- Python + scikit-learn
- 部署：AWS Lambda
- 响应时间：<500ms

冲突预测模型:
- 输入：五维分数+场景参数
- 输出：风险类型+概率
- 更新：每季度重训练
```
