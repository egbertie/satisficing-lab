## 一、裂变底层逻辑

### 满意解裂变飞轮

```
    优质产品/内容
          ↓
    用户获得价值
          ↓
    用户愿意分享
          ↓
    新用户进入
          ↓
    新用户获得价值
          ↓
    回到第一步
```

### 裂变三要素

| 要素 | 说明 | 满意解应用 |
|:-----|:-----|:-----------|
| **价值** | 用户为什么分享 | 免费测评、决策卡牌、金句 |
| **动力** | 分享后用户得到什么 | 优惠券、积分、称号 |
| **便利** | 分享有多容易 | 一键分享、海报生成 |

## 二、裂变产品矩阵

### 裂变产品1：免费测评

**机制**:
```
用户A完成测评 → 生成报告 → 分享海报
  → 用户B扫码 → 完成测评 → 生成报告 → 分享海报
    → 用户C扫码 → ...
```

**分享设计**:
```
海报内容：
┌─────────────────────────┐
│  我和合伙人的匹配度       │
│                         │
│     38/50               │
│  "建议合作，注意预防"      │
│                         │
│  [五维雷达图]            │
│                         │
│  扫码测测你的匹配度       │
│  [二维码]                │
│                         │
│  满意解研究所             │
└─────────────────────────┘
```

**激励**:
- 分享后解锁"深度解读"（额外内容）
- 每带来1人，获得10积分

### 裂变产品2：决策卡牌

**机制**:
```
用户购买卡牌 → 收到实物 → 拍照分享
  → 朋友看到 → 询问 → 推荐购买
    → 朋友购买 → 用户获得返佣
```

**社交货币**:
- 精美设计，适合拍照发朋友圈
- 五维图腾，引发好奇
- "我的决策工具"，彰显品味

**激励**:
- 推荐1人购买，返佣15%
- 推荐3人，升级为"推荐官"

## 四、裂变内容策略

### 内容裂变矩阵

| 内容类型 | 裂变机制 | 预期传播率 |
|:---------|:---------|:-----------|
| 测评报告 | 海报分享 | 20% |
| 金句卡片 | 朋友圈保存 | 15% |
| 案例故事 | 转发文章 | 10% |
| 直播回放 | 分享链接 | 8% |
| 课程笔记 | 学习打卡 | 12% |
| 优惠券 | 赠送好友 | 25% |

### 病毒式内容公式

```
病毒内容 = 情绪共鸣 + 实用价值 + 社交货币 + 分享便利

情绪共鸣：焦虑（合伙人冲突）/ 希望（解决方法）
实用价值：免费测评/工具/模板
社交货币："我在用五维框架" / "我是CDA持证者"
分享便利：一键生成海报/自动@好友/复制链接
```

| 数据分析 | 神策/GrowingIO | ¥10,000/年 |

### 邀请系统架构

```
用户A注册 → 生成唯一邀请码
  → 分享邀请码/链接/海报
    → 用户B通过邀请码注册
      → 系统记录：A邀请B
        → B完成测评/购买
          → A获得奖励
```
