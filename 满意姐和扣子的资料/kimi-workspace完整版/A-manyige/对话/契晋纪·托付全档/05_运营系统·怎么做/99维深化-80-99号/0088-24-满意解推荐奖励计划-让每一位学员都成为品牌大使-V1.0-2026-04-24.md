## 一、推荐机制

### 推荐流程

```
Step 1: 获取推荐码
  → 学员登录后获取专属推荐码
  → 或通过公众号获取

Step 2: 分享
  → 分享给朋友/同事
  → 渠道：微信/朋友圈/小红书/LinkedIn
  → 形式：海报/链接/口头

Step 3: 朋友注册
  → 朋友通过推荐码注册
  → 系统记录推荐关系

Step 4: 朋友购买
  → 朋友购买课程/服务
  → 系统确认成交

Step 5: 奖励发放
  → 推荐人获得奖励
  → 朋友获得新人优惠
```

## 四、推荐管理

### 防止滥用

```
禁止行为：
❌ 刷单（自己注册）
❌ 虚假推荐
❌ 骚扰式推销
❌ 贬低竞品

监测机制：
- IP检测
- 行为模式分析
- 举报机制

处罚：
- 首次警告
- 二次取消推荐资格
- 严重取消学员资格
```
