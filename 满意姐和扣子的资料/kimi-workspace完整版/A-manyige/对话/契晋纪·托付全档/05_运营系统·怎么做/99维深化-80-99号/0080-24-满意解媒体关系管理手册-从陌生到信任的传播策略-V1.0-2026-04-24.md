## 二、媒体合作流程

### 从接触到报道

```
Step 1: 识别机会
  → 监测：媒体选题趋势
  → 匹配：满意解与媒体需求的匹配点
  → 接触：通过FA/公关/直接联系

Step 2: 提供价值
  → 不是"请报道我们"
  → 是"我们有一个独家故事/数据/观点"
  → 提供：采访素材、数据、案例、专家

Step 3: 采访准备
  → 核心信息梳理
  → 常见问题准备
  → 禁忌话题清单
  →  spokesperson 培训

Step 4: 采访执行
  → 准时、专业、真诚
  → 提供补充素材
  → 采访后感谢

Step 5: 报道跟进
  → 监测报道发布
  → 转发+评论
  → 感谢记者
  → 存档

Step 6: 关系维护
  → 定期提供有价值的信息
  → 节日问候
  → 成为记者的"信息源"
```

## 四、危机公关中的媒体应对

### 负面报道应对

```
情况：媒体发布对满意解不利的报道

应对：
1. 立即评估：
   → 报道是否属实？
   → 影响范围多大？
   → 传播速度多快？

2. 内部决策（2小时内）：
   → 是否回应？
   → 如何回应？
   → 谁来回应？

3. 回应方式：
   → 如属实：承认+改进计划
   → 如不属实：提供证据+澄清
   → 如部分属实：承认部分+澄清部分

4. 后续：
   → 主动联系记者沟通
   → 提供更新信息
   → 邀请深度了解
```
