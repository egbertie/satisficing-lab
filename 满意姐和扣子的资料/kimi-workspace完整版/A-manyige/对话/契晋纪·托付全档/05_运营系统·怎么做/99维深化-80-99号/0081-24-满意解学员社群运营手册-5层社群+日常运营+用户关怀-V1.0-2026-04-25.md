## 第一部分：社群定位

### 1.1 社群价值观

```
【社群使命】
"让每一对合伙人，都能走到最后。"

【社群价值观】
├─ 诚实：真实分享，不装不端
├─ 互助：有问题，有人帮
├─ 成长：每天进步一点点
├─ 尊重：不同观点，互相尊重
└─ 保密：群内信息，不外传

【社群禁忌】
├─ ❌ 广告（除非授权）
├─ ❌ 攻击（人身攻击）
├─ ❌ 政治（敏感话题）
├─ ❌ 色情（违规内容）
├─ ❌ 诈骗（任何欺诈）
└─ ❌ 泄愤（纯负面情绪）

【违规处理】
├─ 初犯：警告
├─ 再犯：禁言24小时
├─ 三犯：移出群聊
└─ 严重：拉黑+公告
```

## 第二部分：社群架构

### 2.1 社群分层

```
【Layer 1：学员大群】（500人上限）
├─ 成员：所有付费学员
├─ 功能：通知、活动、答疑
├─ 频率：每日运营
├─ 内容：干货+互动+公告
└─ 目标：留存、活跃

【Layer 2：课程小群】（50-100人）
├─ 成员：同课程学员
├─ 功能：学习交流、作业讨论
├─ 频率：每周运营
├─ 内容：课程相关
└─ 目标：学习效果、课程完成率

【Layer 3：城市分群】（100-200人）
├─ 成员：同城学员
├─ 功能：线下活动、本地资源
├─ 频率：每月运营
├─ 内容：线下活动+本地话题
└─ 目标：线下转化、深度连接

【Layer 4：主题社群】（50-100人）
├─ 成员：对特定话题感兴趣
├─ 话题：股权、决策、沟通等
├─ 频率：每周运营
├─ 内容：深度讨论
└─ 目标：专业交流、内容生产

【Layer 5：VIP社群】（20-50人）
├─ 成员：高价值用户
├─ 功能：专属服务、深度交流
├─ 频率：每日运营
├─ 内容：专属内容+1v1服务
└─ 目标：高留存、高复购、高推荐
```

---

### 2.2 社群角色

```
【群主：Egbertie】
├─ 职责：品牌代表、重大决策
├─ 出现：每周1-2次
├─ 内容：金句、洞察、重大公告
└─ 风格：有温度、有高度

【管理员：满意姐/运营】
├─ 职责：日常运营、规则执行
├─ 出现：每日
├─ 内容：干货、互动、答疑
└─ 风格：专业、活跃

【助教/导师】
├─ 职责：课程答疑、专业支持
├─ 出现：每周2-3次
├─ 内容：课程相关、专业解答
└─ 风格：耐心、专业

【KOC（关键用户）】
├─ 职责：带动氛围、分享经验
├─ 出现：每日
├─ 内容：经验分享、回答问题
└─ 激励：积分、荣誉、特权

【普通学员】
├─ 职责：学习、互动、反馈
├─ 出现：按需求
├─ 内容：提问、分享、互动
└─ 目标：成长、连接
```

## 第三部分：日常运营

### 3.1 每日运营

```
【早间问候】（8:00-9:00）
├─ 内容：早安+今日主题+金句
├─ 形式：文字+图片
├─ 示例：
│   "早安，创始人！
│    今日主题：决策权分配
│    金句：'合伙人不是找的，是遇的。'
│    祝今天决策顺利！"
└─ 目标：开启一天

【午间干货】（12:00-13:00）
├─ 内容：干货知识/案例/工具
├─ 形式：图文/链接/短视频
├─ 示例：
│   "【午间干货】
│    股权分配的3个误区：
│    1. 按出资比例分配
│    2. 一次分定终身
│    3. 不考虑退出机制
│    你中了几个？"
└─ 目标：提供价值

【晚间互动】（20:00-21:00）
├─ 内容：话题讨论/QA/活动
├─ 形式：互动话题
├─ 示例：
│   "【晚间话题】
│    今日问题：
│    '你和合伙人最近一次分歧是什么？怎么解决的？'
│    欢迎分享，优质回答送积分！"
└─ 目标：促进互动

【日常维护】
├─ 回复问题：<2小时
├─ 处理违规：即时
├─ 精华整理：每日
└─ 用户关怀：生日/里程碑
```

---

### 3.2 每周运营

```
【周一：方法论日】
├─ 内容：五维决策方法论
├─ 形式：长文/视频
├─ 互动：讨论应用场景
└─ 目标：知识输入

【周三：案例日】
├─ 内容：真实案例解析
├─ 形式：故事+分析
├─ 互动："如果是你，会怎么做？"
└─ 目标：实战学习

【周五：QA日】
├─ 内容：回答学员问题
├─ 形式：集中答疑
├─ 互动：提前收集问题
└─ 目标：解决困惑

【周日：复盘日】
├─ 内容：本周精华整理
├─ 形式：周报/精华帖
├─ 互动：分享本周收获
└─ 目标：总结沉淀
```

---

### 3.3 每月运营

```
【月度活动】

活动1：主题分享会
├─ 形式：线上直播/语音
├─ 嘉宾：Egbertie/导师/优秀学员
├─ 主题：热点话题
├─ 时长：60-90分钟
└─ 目标：深度交流

活动2：作业点评
├─ 形式：提交作业+点评
├─ 内容：课程作业
├─ 奖励：优秀作业奖励
└─ 目标：督促学习

活动3：优秀学员评选
├─ 标准：活跃度+贡献度+成长度
├─ 奖励：证书+积分+特权
├─ 宣传：群内+公众号
└─ 目标：激励先进

活动4：线下Meetup（城市群）
├─ 形式：线下聚会
├─ 内容：交流+分享+资源对接
├─ 频率：每月1次
└─ 目标：深度连接
```

## 第四部分：内容运营

### 4.1 内容类型

```
【类型1：干货知识】（40%）
├─ 内容：方法论、工具、技巧
├─ 形式：图文、短视频
├─ 来源：课程、Egbertie、导师
└─ 目标：提供价值

【类型2：案例分享】（20%）
├─ 内容：真实案例（脱敏）
├─ 形式：故事、分析
├─ 来源：学员、导师
└─ 目标：实战学习

【类型3：互动话题】（20%）
├─ 内容：问题、投票、讨论
├─ 形式：文字、图片
├─ 来源：运营策划
└─ 目标：促进互动

【类型4：活动通知】（10%）
├─ 内容：课程、活动、优惠
├─ 形式：海报、文字
├─ 来源：运营
└─ 目标：转化

【类型5：用户UGC】（10%）
├─ 内容：学员分享、感悟
├─ 形式：文字、图片
├─ 来源：学员自发
└─ 目标：口碑、氛围
```

---

### 4.2 内容生产

```
【生产流程】

Step 1: 策划
├─ 确定主题
├─ 确定形式
├─ 确定时间
└─ 准备素材

Step 2: 生产
├─ 撰写内容
├─ 制作图片/视频
├─ 审核内容
└─ 排版美化

Step 3: 发布
├─ 选择时机
├─ 发布内容
├─ 引导互动
└─ 监测数据

Step 4: 跟进
├─ 回复评论
├─ 整理精华
├─ 二次传播
└─ 复盘效果

【内容日历】
├─ 每周一：发布本周内容计划
├─ 每日：按计划发布
├─ 每周日：复盘本周内容
└─ 每月：规划下月内容
```

## 第五部分：用户运营

### 5.1 用户分层

```
【分层标准】

S级（超级用户）
├─ 定义：活跃+贡献+付费高
├─ 数量：5%
├─ 权益：
│   ├─ 专属服务
│   ├─ 优先答疑
│   ├─ 线下活动VIP
│   ├─ 新产品内测
│   └─ 推荐奖励翻倍
└─ 策略：深度维护，发展为KOC

A级（活跃用户）
├─ 定义：活跃+付费
├─ 数量：20%
├─ 权益：
│   ├─ 课程优惠
│   ├─ 活动优先
│   ├─ 积分加速
│   └─ 专属内容
└─ 策略：激励活跃，促进升级

B级（普通用户）
├─ 定义：偶尔活跃
├─ 数量：50%
├─ 权益：
│   ├─ 基础服务
│   ├─ 标准优惠
│   └─ 常规内容
└─ 策略：激活活跃，提升价值

C级（沉睡用户）
├─ 定义：7天无互动
├─ 数量：25%
├─ 权益：基础
└─ 策略：激活召回，了解原因
```

## 第六部分：数据监测

### 6.1 核心指标

```
【活跃度指标】
├─ 日活：每日发言人数/总人数
├─ 周活：每周发言人数/总人数
├─ 发言量：每日总发言数
├─ 互动率：点赞+评论/总内容
└─ 目标：日活>30%，周活>60%

【质量指标】
├─ 精华内容数：每周精华帖数
├─ UGC比例：用户生产内容占比
├─ 问题解决率：提问得到回答的比例
├─ 满意度：用户调研评分
└─ 目标：满意度>4.5/5

【转化指标】
├─ 续费率：会员续费比例
├─ 推荐率：老带新比例
├─ 课程完课率：课程完成比例
├─ 咨询转化率：咨询预约比例
└─ 目标：续费率>40%，推荐率>20%

【负面指标】
├─ 退群率：每周退群人数
├─ 投诉率：投诉次数/总人数
├─ 违规率：违规次数/总发言
└─ 目标：退群率<2%，投诉率<0.1%
```
