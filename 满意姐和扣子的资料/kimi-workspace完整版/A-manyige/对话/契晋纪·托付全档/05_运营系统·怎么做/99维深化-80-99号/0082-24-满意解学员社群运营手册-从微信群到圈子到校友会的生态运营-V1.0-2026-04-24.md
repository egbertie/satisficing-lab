## 一、社群架构

### 三层社群体系

```
第一层：免费社群（开放）
  → 满意解公众号粉丝群
  → 任何人可加入
  → 目的：内容传播+获客

第二层：学员社群（付费）
  → CDA学员专属群
  → 购买课程后加入
  → 目的：学习支持+同学网络

第三层：校友社群（认证）
  → CDA持证者专属群
  → 通过考试后加入
  → 目的：高端网络+终身学习
```

## 二、免费社群运营

### 定位
> "让潜在学员先感受到满意解的温度。"

### 运营规则

| 项目 | 规则 |
|:-----|:-----|
| 入群门槛 | 关注公众号即可 |
| 群规 | 禁广告、禁拉票、禁人身攻击 |
| 内容 | 满意姐每日分享+用户互动 |
| 互动 | 每日1个话题讨论 |
| 福利 | 免费测评+资料包 |
| 转化 | 适度推荐付费课程 |

### 每日运营SOP

```
07:00  满意姐早安分享
       → 一条金句+一张海报

12:00  午间话题
       → 一个决策相关话题
       → 如："你最近做了一个什么重要决策？"

18:00  案例分享
       → 一个真实案例（脱敏）
       → 提问："如果是你，会怎么选？"

21:00  答疑时间
       → 满意姐集中答疑
       → 回答3-5个问题

每周五：
- 本周精华汇总
- 下周预告
- 周末福利（免费资料）
```

## 三、学员社群运营

### 定位
> "让学员在学习过程中不孤单。"

### 运营规则

| 项目 | 规则 |
|:-----|:-----|
| 入群门槛 | 购买任意课程 |
| 分班 | 按入学时间分班（每班30人） |
| 班导师 | 1名认证导师/班 |
| 内容 | 课程答疑+作业互评+同学互助 |
| 互动 | 每周1次班会 |

### 每周班会SOP

```
班会时间：每周三 20:00-21:00
形式：腾讯会议/Zoom

流程：
20:00-20:10  上周学习回顾
             → 学习进度统计
             → 优秀作业展示

20:10-20:30  本周重点讲解
             → 模块难点解析
             → 常见错误提醒

20:30-20:50  答疑互动
             → 学员提问
             → 导师回答
             → 同学补充

20:50-21:00  下周预告+作业布置
             → 下周学习内容
             → 作业要求
             → 截止时间
```

### 学员激励

| 激励 | 说明 |
|:-----|:-----|
| 学习打卡 | 每日学习打卡，连续7天奖励 |
| 优秀作业 | 每周评选，公众号展示 |
| 互助之星 | 帮助同学最多的学员 |
| 进步之星 | 相比上周进步最大的学员 |
| 毕业荣誉 | 优秀毕业生，颁发电子证书 |
