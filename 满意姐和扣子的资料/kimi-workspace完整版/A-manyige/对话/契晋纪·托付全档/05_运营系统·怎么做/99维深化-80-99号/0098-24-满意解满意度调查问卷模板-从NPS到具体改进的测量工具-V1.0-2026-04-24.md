## 五、调查实施

### 调查时机

| 时机 | 说明 | 方式 |
|:-----|:-----|:-----|
| **课程中** | 每模块后 | 1分钟问卷 |
| **课程后** | 毕业 survey | 10分钟问卷 |
| **毕业后30天** | 应用追踪 | 5分钟问卷 |
| **毕业后6个月** | 长期效果 | 5分钟问卷 |
| **年度** | 综合评估 | 10分钟问卷 |

### 激励机制

```
完成调查奖励：
- 课程中调查：10积分
- 毕业调查：100积分
- 长期追踪：50积分
- 年度调查：200积分
```

## 六、数据分析

### 核心指标

| 指标 | 计算 | 目标 |
|:-----|:-----|:-----|
| NPS | 推荐者%-批评者% | >50 |
| 整体满意度 | 平均分 | >8/10 |
| 完课满意度 | 毕业 survey | >8.5/10 |
| 应用率 | 实际使用比例 | >60% |
| 推荐意愿 | NPS得分 | >50 |
