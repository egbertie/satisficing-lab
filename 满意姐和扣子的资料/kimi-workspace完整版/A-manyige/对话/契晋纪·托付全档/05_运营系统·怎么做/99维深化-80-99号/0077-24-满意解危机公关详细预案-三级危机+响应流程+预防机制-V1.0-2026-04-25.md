## 第一部分：危机分级

### 1.1 三级危机

```
【一级：轻微（🟢）】
├─ 特征：个别负面评论、小范围投诉
├─ 影响：<100人
├─ 响应：客服处理
├─ 时间：24小时内
├─ 上报：部门负责人
└─ 示例：用户对课程不满意

【二级：中等（🟡）】
├─ 特征：集中投诉、局部传播、媒体关注
├─ 影响：100-1000人
├─ 响应：专项小组
├─ 时间：4小时内响应
├─ 上报：Egbertie
└─ 示例：课程效果争议、导师问题

【三级：严重（🔴）】
├─ 特征：大规模传播、主流媒体、法律风险
├─ 影响：>1000人
├─ 响应：危机指挥部
├─ 时间：1小时内响应
├─ 上报：Egbertie+法律顾问
└─ 示例：数据泄露、Egbertie重大负面、合规问题
```

## 第二部分：响应流程

### 2.1 危机响应SOP

```
【Step 1：监测发现】
├─ 来源：
│   ├─ 社交媒体监测
│   ├─ 客服反馈
│   ├─ 用户投诉
│   ├─ 媒体报道
│   └─ 内部发现
├─ 记录：
│   ├─ 时间、地点、人物
│   ├─ 内容、影响范围
│   └─ 证据截图
└─ 上报：立即上报

【Step 2：评估定级】
├─ 影响范围：多少人？
├─ 严重程度：多严重？
├─ 传播速度：多快？
├─ 法律风险：有吗？
├─ 分级：一级/二级/三级
└─ 决定：响应级别

【Step 3：启动响应】

一级响应：
├─ 负责人：客服主管
├─ 动作：客服处理
├─ 时间：24小时内
├─ 上报：每日汇总
└─ 记录：案例库

二级响应：
├─ 负责人：运营总监
├─ 小组：专项小组
├─ 动作：
│   ├─ 内部调查
│   ├─ 制定方案
│   ├─ 对外回应
│   └─ 跟进处理
├─ 时间：4小时内
├─ 上报：Egbertie
└─ 记录：详细记录

三级响应：
├─ 指挥：Egbertie
├─ 指挥部：危机指挥部
├─ 成员：
│   ├─ 发言人（对外）
│   ├─ 法务（法律）
│   ├─ 运营（执行）
│   ├─ 技术（产品）
│   └─ 蓝军（风控）
├─ 动作：
│   ├─ 紧急会议
│   ├─ 事实调查
│   ├─ 方案制定
│   ├─ 统一口径
│   ├─ 对外发布
│   ├─ 持续跟进
│   └─ 复盘总结
├─ 时间：1小时内
└─ 上报：持续上报

【Step 4：对外回应】

回应原则：
├─ 快速：第一时间回应
├─ 诚实：不隐瞒、不撒谎
├─ 专业：态度专业、措辞严谨
├─ 负责：承担责任
├─ 行动：给出解决方案
└─ 人性：有温度、有共情

回应模板：

模板1：产品问题
"关于[问题]，我们已第一时间展开调查。
初步发现[原因]。
我们对此深表歉意。
解决方案：[具体措施]。
预计[时间]完成。
感谢监督，我们会持续改进。"

模板2：服务争议
"关于[争议]，我们重视每一位用户的反馈。
我们已联系当事人，了解详情。
如果确实是我们的问题，我们会[补救措施]。
我们会完善[改进措施]，避免再次发生。"

模板3：人员问题
"关于[问题]，[个人行为不代表公司观点]。
我们正在[处理措施]。
满意解始终坚持[价值观]。
我们接受监督，欢迎反馈。"

模板4：恶意攻击
"关于[攻击]，我们已经[证据]。
[事实澄清]。
对于恶意诽谤，我们保留法律权利。
我们专注于[做好自己的事]。"

【Step 5：持续跟进】
├─ 监测：持续监测舆情
├─ 回应：回应新问题
├─ 更新：更新进展
├─ 关怀：关怀受影响用户
├─ 修复：修复问题
└─ 记录：详细记录

【Step 6：复盘总结】
├─ 原因：根本原因分析
├─ 责任：责任认定
├─ 改进：改进措施
├─ 制度：制度完善
├─ 培训：团队培训
└─ 记录：案例库
```

## 第三部分：危机预防

### 3.1 预防机制

```
【机制1：质量把控】
├─ 课程内容：三级审核
├─ 咨询服务：满意度追踪
├─ 导师管理：认证+评价
├─ 产品功能：测试+灰度
└─ 用户反馈：每日汇总

【机制2：舆情监测】
├─ 工具：舆情监测平台
├─ 范围：全平台
├─ 频率：7x24小时
├─ 预警：负面>10条/小时预警
└─ 报告：每日舆情报告

【机制3：法律合规】
├─ 合同审核：法务审核
├─ 广告宣传：合规审查
├─ 用户协议：定期更新
├─ 隐私保护：合规审计
└─ 知识产权：定期排查

【机制4：团队培训】
├─ 危机意识：定期培训
├─ 应对技能：模拟演练
├─ 口径统一：话术培训
├─ 案例学习：历史案例
└─ 考核：年度考核

【机制5：蓝军审计】
├─ 定期：每季度一次
├─ 内容：风险扫描
├─ 报告：风险报告
├─ 整改：限期整改
└─ 追踪：追踪落实
```
