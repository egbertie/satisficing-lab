# 合伙人退出路径图 V0.1

> **编制时间**: 2026-04-25
> **编制者**: 满意姐（SAT-001）+ 蓝军 Skeptor-7
> **用途**: 让"分手"有章可循——友好退出/争议退出/强制退出的完整路径
> **原则**: 每一种退出都有路径，每一条路径都有定价，每一次定价都有依据
> **配套**: 合伙人章程自检清单（第18-25项）+ 动态股权框架（回购条款）

## 第二部分：友好退出路径（Voluntary Exit）

### 2.1 触发条件

- 合伙人主动提出离开
- 无重大争议或违约
- 双方同意"和平分手"

**典型场景**：
- 家庭原因需要 relocation
- 找到更适合自己的新机会
- 创业方向与个人兴趣偏离
- 健康问题

---

### 2.2 流程步骤

```
Step 1: 提出退出意向（提前期）
├─ 建议提前期：3-6个月
├─ 书面通知（邮件即可）
└─ 说明原因（可选，但有助于保持良好关系）

Step 2: 股权处理
├─ 已成熟股权：按退出时价格回购或保留
├─ 未成熟股权：公司零成本回购
└─ 回购价格：按事先约定公式（见动态股权框架）

Step 3: 工作交接
├─ 客户/供应商关系移交
├─ 项目/代码/文档交接
├─ 账号/密码/权限移交
└─ 交接清单签字确认

Step 4: 法律文件签署
├─ 股权转让协议
├─ 离职确认书
├─ 竞业限制确认（如有）
└─ 保密协议重申

Step 5: 关系维护
├─ 创始人圈子保持联系
├─ 公司校友会/顾问身份（可选）
└─ 后续合作可能（保持开放）
```

---

### 2.3 定价公式（友好退出）

```
【推荐公式】原始出资 + 年化利息法

回购价格 = 原始出资额 × (1 + 年化利率10%) × 已成熟比例

示例：
├─ 合伙人C原始出资：10万元
├─ 已工作时间：2年
├─ 已成熟比例：50%（4年vesting，已过2年）
├─ 年化利率：10%
└─ 回购价格 = 10万 × (1 + 10%)² × 50% = 10万 × 1.21 × 0.5 = 6.05万

【替代方案】最近融资估值折扣法

回购价格 = 最近融资估值 × 股权比例 × 折扣率（30-50%）

示例：
├─ 最近融资估值：1000万
├─ 合伙人C股权比例：15%
├─ 折扣率：40%（流动性折扣）
└─ 回购价格 = 1000万 × 15% × 40% = 60万

注意：两种方案差距可能很大（6万 vs 60万），
务必事先约定用哪种！
```

---

### 2.4 友好退出时间线

```
Month 1-2: 提出 → 协商 → 确定退出日期
Month 2-3: 股权评估 → 确定回购价格 → 签署股权转让协议
Month 3-4: 工作交接 → 知识转移 → 客户关系移交
Month 4-6: 回购款支付（一次性或分期） → 最终结算
Month 6+: 保持联系 → 潜在顾问/合作

总计：4-6个月
```

## 第三部分：争议退出路径（Negotiated Exit）

### 3.1 触发条件

- 合伙人之间有分歧，但未达到"重大违约"
- 双方同意"分手是更好的选择"
- 需要第三方协助定价或调解

**典型场景**：
- 战略方向分歧（如"应该做B2B还是B2C"）
- 权力分配不满（如"我觉得我被边缘化了"）
- 贡献评估争议（如"我付出比他多，股权一样不公平"）

---

### 3.2 流程步骤

```
Step 1: 争议识别与升级
├─ 内部协商（合伙人之间直接谈）
├─ 如果无法达成一致 → 进入Step 2
└─ 如果达成退出共识 → 按友好退出流程

Step 2: 调解介入
├─ 选项A：独立董事/顾问调解
├─ 选项B：专业调解机构（如商会调解中心）
└─ 选项C：律师协助协商（非诉讼）

Step 3: 估值与定价
├─ 双方各聘请估值专家（各付各的）
├─ 或共同聘请一家独立估值机构
└─ 估值方法：市场法/收益法/资产法

Step 4: 达成协议
├─ 签署调解协议
├─ 包含：股权处理 + 回购价格 + 支付方式 + 竞业限制
└─ 双方签字，具有法律效力

Step 5: 执行与交割
├─ 按协议执行股权回购
├─ 完成工作交接
└─ 签署最终离职文件
```

---

### 3.3 调解成本对比

| 调解方式 | 成本 | 时间 | 关系影响 | 适用场景 |
|:---------|:-----|:-----|:---------|:---------|
| **内部协商** | 0 | 1-2月 | 最小 | 分歧较小，双方理性 |
| **顾问调解** | 1-3万 | 1-3月 | 较小 | 需要中立第三方 |
| **律师协商** | 3-10万 | 2-4月 | 中等 | 分歧较大，需要法律框架 |
| **仲裁** | 10-30万 | 3-6月 | 较大 | 调解失败，需强制裁决 |
| **诉讼** | 30万+ | 6-12月+ | 最大 | 所有方式失败 |

**建议**：尽量在"律师协商"阶段解决，不要走到仲裁/诉讼。

## 第四部分：强制退出路径（Forced Exit）

### 4.1 触发条件

- 合伙人重大违约（如挪用资金、竞业行为）
- 合伙人严重失职（如长期不履行义务）
- 合伙人道德问题（如欺诈、性骚扰）
- 合伙人丧失能力（如精神疾病、吸毒）

**注意**：强制退出必须有"事先约定的触发条件"，不能事后随意定性。

---

### 4.2 重大违约清单（事先约定）

```
一级违约（立即解雇，零回购或极低回购）：
├─ 1. 挪用公司资金或资产
├─ 2. 为竞争对手工作或泄露核心机密
├─ 3. 欺诈行为（虚假报销、伪造数据）
├─ 4. 严重违反法律法规（刑事责任）
└─ 5. 性骚扰或职场霸凌（经调查确认）

二级违约（可解雇，折扣回购）：
├─ 1. 连续3个月不履行核心职责
├─ 2. 未经同意从事竞争性业务
├─ 3. 重大过失导致公司损失（如泄露客户数据）
└─ 4. 违反竞业限制（情节较轻）

三级违约（警告+限期整改，不触发退出）：
├─ 1. 迟到/早退/缺勤频繁
├─ 2. 轻微工作失误
├─ 3. 与同事冲突（非霸凌性质）
└─ 4. 未按时完成非核心任务
```

---

### 4.3 强制退出流程

```
Step 1: 违约发现与证据收集
├─ 书面记录违约行为
├─ 收集证据（邮件、聊天记录、财务记录）
└─ 咨询法律顾问

Step 2: 内部调查
├─ 成立调查小组（其他合伙人+独立董事）
├─ 听取被调查方陈述
└─ 形成调查报告

Step 3: 通知与申辩
├─ 书面通知违约事实
├─ 给予申辩机会（建议7-14天）
└─ 听取申辩意见

Step 4: 决定与执行
├─ 根据调查结果做出决定
├─ 书面通知解雇决定
└─ 说明股权处理方案

Step 5: 股权强制回购
├─ 按违约条款执行回购
├─ 一级违约：零回购或原始出资50%回购
├─ 二级违约：原始出资50-80%回购
└─ 回购款支付（分期或一次性）

Step 6: 法律收尾
├─ 签署解雇确认书
├─ 股权强制转让
└─ 如对方不配合 → 启动法律程序
```

---

### 4.4 强制回购定价

```
一级违约（挪用资金/竞业/欺诈）：
└─ 回购价格 = 原始出资额 × 50% × 已成熟比例

二级违约（失职/过失）：
└─ 回购价格 = 原始出资额 × 80% × 已成熟比例

示例：
├─ 合伙人D原始出资：20万
├─ 已成熟比例：30%（第2年，4年vesting）
├─ 触发一级违约（挪用资金）
└─ 回购价格 = 20万 × 50% × 30% = 3万

注意：
- 强制回购不能为"零"（可能被法院认定为惩罚性条款而无效）
- 建议最低保留原始出资的30-50%
```

## 第五部分：竞业限制与保密义务

### 5.1 竞业限制（Non-Compete）

```
退出后的竞业限制：

├─ 限制期限：6-24个月（通常12个月）
├─ 限制范围：同一细分行业/同一客户群体
├─ 限制地域：公司主要市场范围
├─ 补偿：公司支付竞业补偿金（通常为月薪的30-50%）
└─ 违约后果：停止补偿 + 追偿损失

注意：
- 竞业限制必须"有补偿"才有效（中国劳动法要求）
- 期限不能过长（超过2年可能被法院调整）
- 范围不能过宽（"不能从事任何IT工作"无效）
```

---

### 5.2 保密义务（NDA）

```
退出后的保密义务：

├─ 永久保密：商业机密（算法、客户名单、财务数据）
├─ 限期保密：产品路线图、战略计划（通常2-3年）
├─ 公开信息除外：已公开的信息不受限
└─ 违约后果：赔偿实际损失 + 可能的惩罚性赔偿

保密信息清单（事先约定）：
1. 客户名单与联系方式
2. 供应商合同与价格
3. 技术方案与源代码
4. 财务数据与融资条款
5. 商业计划与战略方向
6. 员工薪酬信息
```

## 第六部分：知识产权归属

### 6.1 退出前开发的IP

```
退出前（在职期间）开发的知识产权：
└─ 归公司所有（这是劳动合同/合伙人协议的标准条款）

包括：
├─ 专利/著作权/商标
├─ 技术方案/算法/代码
├─ 产品设计/原型
└─ 商业计划/市场策略
```

---

### 6.2 退出后开发的IP

```
退出后开发的知识产权：
├─ 与原公司业务无关的新IP → 归退出者个人
├─ 利用原公司资源/信息开发的新IP → 可能归公司
└─ 模糊地带 → 事先约定或争议解决

建议条款：
"退出后12个月内开发的、与公司业务相关的知识产权，
公司有优先购买权，价格按独立评估确定。"
```

## 第七部分：创始人5分钟可用性检验

### 退出机制自检

| # | 检验项 | 通过标准 |
|:-:|--------|:---------|
| 1 | 你们讨论过退出机制吗？ | "讨论过，有书面约定" |
| 2 | 股权回购价格有公式吗？ | "有，按XX公式" |
| 3 | 重大违约的定义明确吗？ | "有清单，分三级" |
| 4 | 竞业限制有补偿吗？ | "有，每月XX元" |
| 5 | 知识产权归属约定了吗？ | "在职期间归公司" |

**如果5项都通过**：退出机制完备。
**如果有1-2项不清楚**：本周内补齐。
**如果有3项以上不清楚**：高风险——立即处理。

>
> 合伙创业是结婚。
