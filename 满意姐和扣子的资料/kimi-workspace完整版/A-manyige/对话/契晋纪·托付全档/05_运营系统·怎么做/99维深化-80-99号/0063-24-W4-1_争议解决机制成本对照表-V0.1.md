## 第二部分：五级机制详解

### Level 1：内部协商（0-1万成本）

**适用场景**：
- 分歧较小，双方理性
- 关系尚未破裂
- 争议不涉及重大利益

**典型争议**：
- 会议时间调整
- 供应商选择分歧
- 小型营销活动方案
- 非核心岗位职责

**操作流程**：
```
Step 1: 一方提出议题（书面或口头）
Step 2: 另一方24小时内回应
Step 3: 双方各陈述立场（各10分钟）
Step 4: 寻找共同点（"我们都希望..."）
Step 5: 提出折中方案
Step 6: 达成一致或进入Level 2
```

**成本**：
| 成本项 | 金额 | 说明 |
|:-------|:-----|:-----|
| 时间成本 | 2-4小时 | 合伙人会议 |
| 情绪成本 | 低 | 如果理性沟通 |
| 关系成本 | 极低 | 正常商业讨论 |
| 金钱成本 | 0 | 无外部费用 |
| **总成本** | **~0-1万** | 主要是时间价值 |

**成功关键**：
- 议题具体（不是"我觉得不公平"，是"我希望负责X业务"）
- 双方愿意妥协
- 有决策机制（如投票/CEO拍板）

---

### Level 2：五路图腾调解（1-3万成本）

**适用场景**：
- 内部协商失败
- 需要中立第三方
- 双方愿意继续合伙，但需要帮助

**典型争议**：
- 股权分配分歧
- 战略方向争议
- 角色边界模糊
- 贡献评估争议

**操作流程**：
```
Step 1: 双方同意引入调解人
Step 2: 选择调解人（独立董事/顾问/外部专家）
Step 3: 调解准备（各自提交争议说明）
Step 4: 五路图腾调解流程（见五路图腾调解法V0.1）
Step 5: 达成调解协议或进入Level 3
```

**成本**：
| 成本项 | 金额 | 说明 |
|:-------|:-----|:-----|
| 调解人费用 | 1-3万 | 按小时或按次收费 |
| 时间成本 | 4-8小时 | 调解会议 |
| 情绪成本 | 中等 | 需要敞开心扉 |
| 关系成本 | 低-中 | 如果成功，关系修复 |
| **总成本** | **1-3万** | |

**成功关键**：
- 调解人真正中立（不与任何一方有利益关系）
- 双方愿意"被调解"（不是来赢，是来解决问题）
- 调解方案有约束力（书面协议）

---

### Level 3：第三方调解/仲裁（3-10万成本）

**适用场景**：
- 五路图腾调解失败
- 双方对"公平"的定义差异大
- 需要专业评估（如股权估值）

**典型争议**：
- 股权回购价格分歧
- 合伙人退出条件争议
- 知识产权归属争议
- 重大财务纠纷

**操作流程**：
```
Step 1: 选择调解/仲裁机构
  ├─ 商会调解中心（经济纠纷）
  ├─ 行业仲裁机构（专业争议）
  └─ 法院诉前调解（司法确认）

Step 2: 提交争议材料
  ├─ 合伙人协议
  ├─ 财务记录
  └─ 沟通记录

Step 3: 调解/仲裁过程
  ├─ 调解：双方各陈述 → 调解员提出方案 → 双方接受/拒绝
  └─ 仲裁：双方举证 → 仲裁庭裁决 → 一裁终局

Step 4: 执行结果
  ├─ 调解协议：双方自愿执行
  └─ 仲裁裁决：可申请法院强制执行
```

**成本**：
| 成本项 | 调解 | 仲裁 | 说明 |
|:-------|:-----|:-----|:-----|
| 机构费用 | 1-3万 | 3-8万 | 按争议金额比例 |
| 律师费用 | 0-2万 | 2-5万 | 可选但建议有 |
| 评估费用 | 1-3万 | 1-3万 | 股权/资产评估 |
| 时间成本 | 1-2月 | 2-4月 | |
| 情绪成本 | 高 | 很高 | 对抗性增强 |
| 关系成本 | 中-高 | 高 | 调解优于仲裁 |
| **总成本** | **3-6万** | **8-15万** | |

**关键区别**：
- 调解：双方自愿接受，可反悔（但司法确认的调解协议不可反悔）
- 仲裁：一裁终局，不能上诉，可申请强制执行

---

### Level 4：律师协商/谈判（5-20万成本）

**适用场景**：
- 争议金额较大（50万以上）
- 涉及复杂法律问题
- 双方各执一词，需要法律框架

**典型争议**：
- 股权回购（金额大）
- 违约赔偿
- 知识产权侵权
- 竞业限制争议

**操作流程**：
```
Step 1: 各自聘请律师
Step 2: 律师发函（立场声明）
Step 3: 律师间协商
Step 4: 达成和解协议或进入Level 5
```

**成本**：
| 成本项 | 金额 | 说明 |
|:-------|:-----|:-----|
| 律师费（双方） | 5-15万 | 按小时或按阶段 |
| 调查取证 | 1-3万 | 查账/鉴定 |
| 专家证人 | 1-5万 | 如需 |
| 时间成本 | 2-4月 | |
| 情绪成本 | 很高 | 对抗性极强 |
| 关系成本 | 很高 | 几乎不可能恢复 |
| **总成本** | **10-30万** | |

**成功关键**：
- 双方都有"和解意愿"（不是来打到底）
- 律师是"解决问题型"不是"战斗型"
- 有明确的和解区间（双方都能接受的数字）

---

### Level 5：诉讼（20万+成本）

**适用场景**：
- 所有其他方式失败
- 涉及重大违约/欺诈
- 需要法院强制执行

**典型争议**：
- 合伙人挪用资金
- 严重竞业违约
- 股权纠纷（金额巨大）
- 公司控制权争夺

**操作流程**：
```
Step 1: 起诉/应诉
Step 2: 证据交换
Step 3: 开庭审理（可能多次）
Step 4: 一审判决
Step 5: 二审（如有上诉）
Step 6: 执行
```

**成本**：
| 成本项 | 金额 | 说明 |
|:-------|:-----|:-----|
| 诉讼费 | 1-5万 | 按争议金额比例 |
| 律师费 | 10-50万 | 按阶段收费 |
| 证据保全/鉴定 | 2-10万 | 查账/股权评估 |
| 保全担保 | 争议金额的30% | 如需财产保全 |
| 时间成本 | 6-12月+ | 一审+二审 |
| 情绪成本 | 极高 | 身心俱疲 |
| 关系成本 | 彻底破裂 | 不可能恢复 |
| **总成本** | **30-100万+** | |

**警告**：
诉讼是最后的手段。一旦进入诉讼，
合伙人关系彻底终结，公司可能半瘫痪，
双方精疲力尽，律师是唯一赢家。

## 第四部分：成本优化策略

### 策略1：预防性投入（最省钱）

```
在争议发生前投入：
├─ 合伙人协议起草：1-3万（律师费）
├─ 股权架构设计：2-5万（律师+税务）
├─ 退出机制约定：0（自己用模板）
└─ 争议解决条款：0（用本文件）

投入：3-8万
避免：未来可能的30-100万诉讼成本
ROI：10-30倍

核心原则：
"花3万写协议，比花30万打官司聪明。"
```

---

### 策略2：尽早调解（省时间+省关系）

```
争议发生后24小时内：
├─ 双方各写一份"争议说明"（1页纸）
├─ 交换阅读，理解对方立场
├─ 48小时内安排面对面沟通
└─ 72小时内决定是否引入调解人

为什么要快？
- 情绪在24-48小时内最容易失控
- 越早介入，关系越容易修复
- 信息尚未被"律师化"（双方还没被律师教着说"不承认"）
```

---

### 策略3："调解前置"条款（最强预防）

```
在合伙人协议中加入：

"任何合伙人争议，双方同意在提起诉讼或仲裁前，
必须先经过以下步骤：
1. 内部协商（不少于2次正式会议）
2. 第三方调解（不少于1次正式调解）
3. 上述步骤完成后，方可启动仲裁或诉讼。

违反调解前置条款直接起诉的一方，
如最终判决/裁决结果不优于调解方案，
应承担对方全部律师费。"

作用：
- 强制双方先尝试低成本方式
- 防止一方"一言不合就起诉"
- 给关系修复留时间窗口
```

## 第五部分：创始人5分钟可用性检验

### 争议解决自检

| # | 检验项 | 通过标准 |
|:-:|--------|:---------|
| 1 | 你们知道争议解决有几级阶梯吗？ | "知道，从内部协商到诉讼" |
| 2 | 你们的合伙人协议有"调解前置"条款吗？ | "有"或"这周补" |
| 3 | 如果争议金额50万，你们会选择什么方式？ | "调解或仲裁" |
| 4 | 你们有信任的调解人人选吗？ | "有，独立董事/顾问" |
| 5 | 你们会为避免诉讼投入多少预算？ | "愿意花3-5万做预防" |

**如果5项都通过**：争议解决机制完备。
**如果有1-2项不清楚**：本周内补齐。
**如果有3项以上不清楚**：高风险——立即处理。

---

> **核心原则**：
> 争议解决不是"打赢官司"，是"用最低成本恢复关系或体面分手"。
>
> 最好的争议解决是"不发生争议"——预防性投入。
> 次好的是"内部解决"——不伤和气。
> 最差的是"诉讼"——两败俱伤。
>
> 选择解决方式时问自己：
> "1年后回头看，我会为今天的选择后悔吗？"
