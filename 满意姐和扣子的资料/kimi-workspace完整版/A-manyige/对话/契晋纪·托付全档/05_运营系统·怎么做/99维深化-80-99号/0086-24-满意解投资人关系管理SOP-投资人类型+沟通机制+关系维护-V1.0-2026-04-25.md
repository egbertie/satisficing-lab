## 第一部分：投资人分类

### 1.1 投资人类型

```
【类型1：天使投资人】
├─ 特征：个人、早期、小额
├─ 金额：50-500万
├─ 关注点：团队、想法
├─ 维护频率：每季度1次
├─ 沟通方式：微信/电话
└─ 价值：早期支持、人脉

【类型2：VC机构】
├─ 特征：机构、成长期、中额
├─ 金额：500-5000万
├─ 关注点：数据、增长
├─ 维护频率：每月1次
├─ 沟通方式：邮件+会议
└─ 价值：资金、资源、品牌

【类型3：战略投资人】
├─ 特征：产业、战略、大额
├─ 金额：5000万+
├─ 关注点：协同、战略
├─ 维护频率：每月1-2次
├─ 沟通方式：正式会议
└─ 价值：资源、协同、背书

【类型4：PE机构】
├─ 特征：机构、成熟期、大额
├─ 金额：1亿+
├─ 关注点：财务、退出
├─ 维护频率：每季度1次
├─ 沟通方式：正式报告
└─ 价值：资金、退出支持

【类型5：潜在投资人】
├─ 特征：尚未投资，有兴趣
├─ 维护频率：每季度1次
├─ 沟通方式：内容推送+活动
└─ 价值：未来融资储备
```

## 第二部分：沟通机制

### 2.1 定期沟通

```
【月度更新】（已投资人）
├─ 内容：
│   ├─ 本月关键数据
│   ├─ 重要进展
│   ├─ 下月计划
│   └─ 需要帮助
├─ 形式：1-2页邮件
├─ 时间：每月5日前
└─ 目标：让投资人知情

【季度报告】（已投资人）
├─ 内容：
│   ├─ 财务数据
│   ├─ 业务进展
│   ├─ 市场动态
│   ├─ 团队变化
│   ├─ 风险与挑战
│   ├─ 下季度计划
│   └─ 融资进展（如有）
├─ 形式：PPT+数据表
├─ 时间：季度结束后15天内
└─ 目标：深度同步

【年度汇报】（所有投资人）
├─ 内容：
│   ├─ 年度总结
│   ├─ 财务审计
│   ├─ 战略规划
│   ├─ 下年计划
│   └─ 分红方案（如有）
├─ 形式：正式报告+会议
├─ 时间：年度结束后30天内
└─ 目标：全面同步

【临时沟通】（重大事项）
├─ 触发：
│   ├─ 重大好消息
│   ├─ 重大坏消息
│   ├─ 重大决策
│   ├─ 融资进展
│   └─ 需要帮助
├─ 形式：即时沟通
├─ 原则：好消息即时分享，坏消息不隐瞒
└─ 目标：透明沟通
```

---

### 2.2 沟通内容

```
【必报好消息】
├─ 重大合同签署
├─ 关键人才加入
├─ 产品重大突破
├─ 重要奖项获得
├─ 媒体重要报道
├─ 用户重大突破
└─ 融资进展

【必报坏消息】
├─ 核心人员离职
├─ 重大客户流失
├─ 产品重大问题
├─ 财务重大变化
├─ 法律风险
├─ 竞争重大变化
└─ 战略调整

【请求帮助】
├─ 资源对接
├─ 人才推荐
├─ 客户推荐
├─ 战略建议
├─ 危机处理
└─ 后续融资
```

## 第三部分：关系维护

### 3.1 维护策略

```
【策略1：内容输出】
├─ 形式：
│   ├─ 行业洞察（每月）
│   ├─ 公司动态（每周）
│   ├─ 数据报告（每季度）
│   └─ 成功案例（随时）
├─ 渠道：
│   ├─ 投资人专属群
│   ├─ 邮件列表
│   └─ 1v1推送
└─ 目标：保持存在感

【策略2：活动互动】
├─ 形式：
│   ├─ 投资人年会（每年）
│   ├─ 季度聚会（每季度）
│   ├─ 项目考察（邀请参观）
│   └─ 行业活动（共同参加）
├─ 目标：面对面交流
└─ 效果：加深关系

【策略3：价值提供】
├─ 形式：
│   ├─ 行业信息分享
│   ├─ 项目推荐（适合投资人）
│   ├─ 专家对接
│   └─ 资源互助
├─ 目标：互惠互利
└─ 效果：关系平等

【策略4：个人关怀】
├─ 形式：
│   ├─ 节日问候
│   ├─ 生日祝福
│   ├─ 个人成就祝贺
│   └─ 困难时关心
├─ 目标：人情味
└─ 效果：关系升温
```
