## 一、财务基础

### 会计科目

```
收入类：
- 课程收入（B2C）
- 企业培训收入（B2B）
- 工具产品收入
- 周边产品收入
- 其他收入

成本类：
- 内容制作成本
- 平台运营成本
- 营销推广成本
- 人力成本
- 办公成本

费用类：
- 管理费用
- 销售费用
- 研发费用
- 财务费用
```

### 记账规则

```
原则：
1. 收支分离
   → 收入账户 ≠ 支出账户
   
2. 日清月结
   → 每日记录
   → 每月结算
   
3. 凭证完整
   → 每笔收支有凭证
   → 电子存档
   
4. 定期对账
   → 银行对账
   → 平台对账
```

### 关键财务指标

| 指标 | 计算 | 目标 |
|:-----|:-----|:-----|
| **毛利率** | (收入-成本)/收入 | >60% |
| **净利率** | 净利润/收入 | >20% |
| **客单价** | 收入/付费用户 | >¥3,000 |
| **获客成本** | 营销成本/新用户 | <¥500 |
| **LTV/CAC** | 用户价值/获客成本 | >3 |
| **现金流** | 期末余额 | >6个月运营费用 |

### 预算控制

```
月度预算检查：

超支处理：
- 超支<10%：部门自行调整
- 超支10-20%：需Egbertie审批
- 超支>20%：暂停相关支出

节余处理：
- 节余转入下月
- 或用于紧急事项
```
