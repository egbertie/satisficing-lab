# 05_运营系统·怎么做

## 定位

存放满意解研究所的**运营执行层文件**：小红书运营、
公众号运营、年度日历、获客漏斗、SOP、渠道策略等。

## 子分类

| 子文件夹 | 文件数 | 说明 |
|----------|--------|------|
| `小红书运营/` | ~20 | 星月传奇·小红书版15篇+新增 |
| `公众号运营/` | ~20 | 星月传奇·公众号版 |
| `99维深化-50-69号/` | ~20 | 运营SOP、战略级文件 |
| `99维深化-80-99号/` | ~20 | 渠道、社群、内容策略 |
| `99维深化-100-115号/` | ~16 | 管理、合规、ESG |

## 核心文件速查

- **小红书15篇**：星月传奇系列小红书笔记
- **公众号版**：公众号内容矩阵
- **年度运营日历**：27_年度运营日历

- **定价手册**：81_定价手册
