## 第一部分：直播前准备

### 1.1 策划

```
【确定主题】
├─ 选用户最关心的问题
├─ 选有热度的话题
├─ 选能展示专业度的内容
└─ 示例："合伙人股权怎么分才公平？"

【确定时间】
├─ 工作日：晚上20:00-22:00
├─ 周末：下午15:00-17:00
├─ 时长：60-90分钟
└─ 提前3天预告

【确定形式】
├─ 单人分享：Egbertie主讲
├─ 双人对话：Egbertie+嘉宾
├─ 多人圆桌：3-5人讨论
└─ 连麦互动：回答用户问题

【准备材料】
├─ PPT/Keynote
├─ 案例素材
├─ 数据图表
├─ 互动道具（卡牌、白板）
└─ 优惠方案（直播专属）
```

---

### 1.2 预热

```
【预热时间线】

T-3天：
├─ 发布直播预告海报
├─ 公众号推文预告
├─ 社群通知
└─ 朋友圈预告

T-1天：
├─ 发布倒计时海报
├─ 放出部分干货（钩子）
├─ 提醒预约
└─ 准备问题征集

T-1小时：
├─ 朋友圈提醒
├─ 社群提醒
├─ 测试设备
└─ 准备开场

T-10分钟：
├─ 进入直播间
├─ 测试画面/声音
├─ 发布开播提醒
└─ 准备暖场
```

## 第二部分：直播脚本

### 2.1 开场（5-10分钟）

```
【暖场】（开播前5分钟）
├─ 播放背景音乐
├─ 展示倒计时
├─ 引导用户互动（"扣1""在吗"）
└─ 测试互动功能

【正式开场】（5分钟）

"Hi，各位创始人、合伙人，晚上好！
我是Egbertie，满意解研究所的创始人。

欢迎来到今天的直播。
今晚我们要聊的是：
[主题]

为什么聊这个？
因为最近有[数据/案例]显示，
[痛点描述]。

如果你也遇到这个问题，
扣个'1'，让我看到你们。

好，我看到[人数]个'1'了。
看来这个问题确实很普遍。

那我们就开始吧。

不过开始前，先说一下：
├─ 直播时长：约90分钟
├─ 互动方式：评论区提问，我会挑选回答
├─ 专属福利：今晚直播有[福利]
└─ 回放：结束后有回放，但福利仅限直播

好，进入正题。"

【开场检查】
├─ [ ] 热情、有活力
├─ [ ] 主题清晰
├─ [ ] 互动引导
├─ [ ] 福利预告
└─ [ ] 节奏紧凑
```

---

### 2.2 正文（40-60分钟）

```
【结构：3-4个部分，每部分15-20分钟】

第一部分：问题/痛点（15分钟）
├─ 引入：真实案例/数据
├─ 分析：为什么会这样
├─ 互动："你们遇到过吗？"
└─ 小结：核心问题

第二部分：方法论（20分钟）
├─ 引入：满意解方法
├─ 讲解：五维框架/12类型
├─ 案例：具体应用
├─ 互动："听懂了吗？扣'6'"
└─ 小结：核心要点

第三部分：实战/工具（20分钟）
├─ 引入：具体怎么做
├─ 演示：工具使用（卡牌/矩阵）
├─ 案例：用户故事
├─ 互动：评论区提问
└─ 小结：行动步骤

第四部分（可选）：QA（15分钟）
├─ 收集：评论区问题
├─ 筛选：有代表性的问题
├─ 回答：深度解答
└─ 互动：投票/选择

【互动技巧】
├─ 每10分钟一次互动
├─ 提问："你觉得呢？"
├─ 投票："A还是B？"
├─ 抽奖："扣666，抽[奖品]"
├─ 红包：发红包提醒
└─ 连麦：邀请用户上麦
```

---

### 2.3 结尾（10-15分钟）

```
【总结】（5分钟）

"好，今天的内容就到这里。
我们来回顾一下：

今晚讲了3个重点：
1. [重点1]
2. [重点2]
3. [重点3]

核心记住一句话：
[金句]

如果你今晚有收获，
扣个'收获'，让我看到。"

【福利】（5分钟）

"好，到福利时间了。
今晚直播专属福利：

福利1：[具体内容]
├─ 原价：XXX
├─ 直播价：XXX
├─ 限时：今晚24点前
└─ 领取方式：[链接/二维码]

福利2：[具体内容]
...

注意：仅限今晚直播，
回放不享受这个福利。"

【预告】（3分钟）

"最后，预告一下：
下一场直播是[时间]，
主题是[主题]，
会有[嘉宾/福利]。

点击预约，不错过。

感谢大家的陪伴，
我是Egbertie，
满意解，让每一对合伙人都能走到最后。

晚安，我们下期见！"

【结束】
├─ 放结束音乐
├─ 展示二维码
├─ 感谢观众
└─ 下播
```

## 第三部分：直播后

### 3.1 复盘

```
【数据复盘】
├─ 观看人数：峰值/均值
├─ 互动率：评论/点赞/分享
├─ 转化率：点击/购买/关注
├─ 留存率：平均观看时长
└─ 新增粉丝：数量/来源

【内容复盘】
├─ 哪些内容互动高
├─ 哪些内容互动低
├─ 用户最关心的问题
├─ 时间分配是否合理
└─ 节奏是否合适

【技术复盘】
├─ 画面/声音质量
├─ 网络稳定性
├─ 设备问题
└─ 改进方案

【用户反馈】
├─ 评论区反馈
├─ 私信反馈
├─ 社群反馈
└─ 改进方向
```
