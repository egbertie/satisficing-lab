## 场景一：首次接触（冷启动）

### 话术1-1：朋友介绍场景

```
【触发】客户通过朋友/合作伙伴介绍，第一次接触

【开场白】
"X总，我是Egbertie，满意解研究所的创始人。
XX（介绍人）跟我提起您正在[具体业务阶段，如A轮融资/寻找技术合伙人]，
说您可能对合伙人决策支持有兴趣。

我先不推销什么——
我想先听听，您目前在合伙人关系上，最头疼的是什么？"

【目的】
- 不急着介绍产品，先建立信任
- 用"最头疼的"打开话匣子（人都愿意吐槽）
- 留下"倾听者"而非"推销员"的印象

【常见回应与承接】
客户："我们合伙人之间还好，没什么问题。"
→ "那太好了。那您现在最关注的是什么呢？是融资？产品？还是团队扩张？"
→ 引导到"潜在合伙人决策场景"

客户："确实有些分歧，比如股权分配..."
→ "股权分配啊，这是我们最常见的案例类型。
您现在的分歧主要是在什么阶段？是刚创业时的初始分配，还是后来的调整？"
→ 进入需求诊断
```

```
【触发】在行业活动/峰会/论坛上偶遇潜在客户

【开场白】
"X总，刚才您在台上的分享很精彩，特别是[具体引用对方说的某句话]。

很多像您这样的创始人，在[对方提到的业务阶段]时，
都会面临一个选择：是独自扛，还是找合伙人。
您当时是怎么决定的？"

【目的】
- 先赞美对方（具体引用，不要泛泛）
- 用"选择"引发思考
- 听对方的"决策过程"（这是需求诊断的前奏）

【时间控制】
活动场合不宜长谈，目标：
├─ 3分钟内建立初步连接
├─ 拿到名片/微信
└─ 约下次深度沟通（"下周我给您发一个我们的案例，您看看有没有启发？"）
```

```

【下一步】
紧急："您方便这周打个电话吗？15分钟，我先了解一下情况。"
潜在："我给您发一份我们的[品牌故事/案例集]，您看完我们再聊？"
```

## 场景二：需求诊断（挖掘痛点）

### 话术2-1：痛点挖掘框架（SPIN改良版）

```
【结构】Situation → Problem → Implication → Need-payoff

【Situation（现状）】
"X总，您刚才提到公司目前[融资阶段/团队规模/业务状态]，
合伙人结构是[几人/分工/合作时长]。
这个背景我了解了。"

【Problem（问题）】
"在这个阶段，很多创始人会遇到一个共同的问题：
[股权分配争议/角色边界模糊/战略方向分歧/沟通机制缺失]。
您目前在这几个维度上，哪个感受最深？"

【Implication（影响）】
"如果这个[问题]不解决，
最坏的情况会是什么？
比如融资时投资人看到合伙人分歧，会不会影响估值？
或者核心团队看到创始人不合，会不会有人离职？"

【Need-payoff（需求确认）】
"如果有一个方法，能帮您[具体收益，如明确决策权/调整股权/建立沟通机制]，
您觉得对公司的价值有多大？"

【目的】
让客户自己说出"我需要这个"，而不是我们推销"你需要这个"。
```

### 话术2-2：五维决策诊断话术

```
【触发】客户已经表达了一些痛点，需要结构化诊断

【话术】
"X总，我理解您的困扰了。
让我用我们的五维决策框架，帮您梳理一下——

【土·刘禹锡】根基稳固吗？
"您和合伙人之间的信任基础，是因为共同经历建立的，还是因为利益绑定建立的？
如果是后者，当利益变化时，信任会不会动摇？"

【金·司马贺】规则明确吗？
"你们现在遇到分歧时，是怎么解决的？
是投票？是CEO拍板？还是看谁嗓门大？
有没有书面的决策规则？"

【水·观自在】信息透明吗？
"您合伙人知道公司的真实财务状况吗？
他知道您每天在想什么、担心什么吗？
你们多久有一次坦诚的对话？"

【木·孔子】伦理底线清楚吗？
"如果今天有人挪用了一笔钱，你们会怎么处理？
你们讨论过'什么情况下必须分手'吗？"

【火·六祖慧能】变革准备好了吗？
"如果明天需要调整股权，或者引入新合伙人，
你们有预案吗？还是到时候再吵架？"

【总结】
这五维中，您觉得哪一维是目前最薄弱的？
那一维，就是我们优先解决的问题。"

【目的】
- 展示专业度（用框架说话）
- 让客户自我诊断（参与感）
- 找到切入点（最薄弱的一维）
```

### 话术2-3：案例引导话术

```
【触发】客户对"咨询"有顾虑，不确定是否有用

【话术】
"X总，我理解您的顾虑——'我们情况特殊，你们的方法不一定适用'。
确实，每个公司都是独特的。

让我分享一个类似阶段的案例：
[简述一个12类型案例库中的相关案例，2-3句话]。
他们当时也是[与客户类似的情况]，
后来我们用[具体工具，如决策权矩阵/动态股权框架]，
帮他们在[时间]内解决了[问题]。

您觉得，他们的情况和您有几分相似？
如果有几分相似，我们的方法可能对您也有启发。"

【目的】
- 用案例降低不确定性
- 让客户自己判断"是否适用"
- 不强行推销，建立信任
```

## 场景三：方案呈现（价值展示）

### 话术3-1：满意解服务介绍（三级漏斗）

```
【触发】客户表达需求，进入方案介绍阶段

【话术】
"X总，基于您刚才提到的情况，
我介绍一下满意解研究所的三级服务——

【引流层】免费/低价产品
"首先，我们有免费的[合伙人章程自检清单]。
您可以在30分钟内，和合伙人一起做一次'关系体检'。
这个工具能帮您发现现在的盲区在哪里。

还有一个[五维决策测评]，15分钟完成，
生成一份个性化的合伙人关系诊断报告。"

【转化层】中端服务
"如果需要深度支持，我们有[合伙人决策教练服务]。
包含：
├─ 1对1合伙人关系诊断（3小时深度访谈）
├─ 定制化治理工具包（决策权矩阵+股权框架+退出机制）
├─ 3个月跟踪辅导（每月1次复盘）
└─ 费用：[具体价格，如5-10万]

这个服务适合已经有具体争议、需要解决的公司。"

【高客单层】高端定制
"对于更复杂的情况——比如涉及多轮融资、多合伙人、跨境架构——
我们有[高端定制服务]。
包含律师/税务/跨境架构专家的联合服务，
费用根据复杂度定制。"

【收尾】
"您觉得，目前哪个层级的服务对您最有价值？
或者，您想先从免费的自检清单开始？"

【目的】
- 三级漏斗降低决策压力
- 让客户自选（不强迫）
- 从低价/免费开始建立信任
```

### 话术3-2：差异化定位话术

```
【触发】客户问"你们和麦肯锡/其他咨询有什么区别？"

【话术】
"X总，好问题。
麦肯锡是'战略咨询'——帮公司定方向、做市场分析、设计组织架构。
他们是'医生'，诊断公司病在哪里。

满意解是'合伙人关系专科医生'——
我们不诊断公司，我们诊断'合伙人之间的关系'。

区别有三：

1. 专注度
麦肯锡什么都做，我们只做一件事：合伙人决策。
12种冲突类型、84份案例、五维决策框架——
这是我们的'专科'。

2. 方法论
麦肯锡用数据驱动、行业对标。
我们用'左脑逻辑+右脑直觉'——
既有决策矩阵、股权计算器的硬工具，
也有感知力训练、五路图腾调解的软技能。

3. 结果导向
麦肯锡交付一份报告。
我们交付一个'能用的工具包'——
决策权矩阵填完就能用，股权框架签完就生效。

简单说：
麦肯锡帮公司'做对的事'，
满意解帮合伙人'把事做对'。"

【目的】
- 不贬低对手（尊重麦肯锡）
- 明确定位差异（专科vs全科）
- 强调实用性（能用的工具包）
```

### 话术3-3：价值量化话术

```
【触发】客户对价格有顾虑，需要证明ROI

【话术】
"X总，我理解您对投入产出比的考虑。
让我帮您算一笔账——

【成本侧】合伙人冲突的隐性成本
├─ 时间成本：创始人每周花5小时处理合伙人摩擦 × 52周 = 260小时/年
├─ 机会成本：因为内部不合，错过1个融资机会 = 可能1000万+估值损失
├─ 人才成本：核心员工看到创始人不合，离职1人 = 招聘+培训+知识流失 = 50万+
├─ 情绪成本：创始人精力被内耗，无法专注业务 = 难以量化但真实存在
└─ 【隐性成本总计】：每年100-300万（保守估计）

【收益侧】满意解服务的显性收益
├─ 预防1次股权争议 = 节省律师费30万+ + 避免公司分裂
├─ 明确决策权矩阵 = 每周节省5小时会议 = 每年130小时创始人的专注时间
├─ 建立退出机制 = 如果真需要分手，节省诉讼费50万+ + 保留关系
└─ 【显性收益总计】：每年150-500万

【ROI】
投入：5-10万（中端服务）
回报：150-500万（隐性成本节省 + 显性收益）
ROI：15-50倍

而且，这不是'可能'的收益——
我们的案例库中，[X%]的客户在6个月内感受到了明显的合伙人关系改善。"

【目的】
- 用数字说话（量化价值）
- 对比"冲突成本"和"服务收益"
- 建立ROI框架
```

## 场景四：异议处理（化解顾虑）

### 话术4-1："我们自己能解决"异议

```
【触发】客户说"我们自己能解决，不需要外部咨询"

【话术】
"X总，我完全理解。
大多数创始人都是这么想的——'我们是聪明人，自己能搞定'。

确实，很多小问题自己能解决。
但问题是：
当合伙人之间出现分歧时，
你们是'解决问题'，还是'争对错'？

我们的案例库中，80%的'严重冲突'，
一开始都是'小问题'。
为什么演变成大问题？
因为创始人之间很难做到'中立'——
每个人都是当事人，都有立场，都有情绪。

我们不是来替代您做决定的。
我们是来给您一个'外部视角'——
就像公司做重大决策时会请独立董事一样，
合伙人关系做重大调整时，也需要一个'外部专业视角'。

您可以这么想：
满意解不是'您请的咨询公司'，
是'您合伙人关系上的独立董事'。"

【目的】
- 不反驳客户（"确实很多小问题自己能解决"）
- 指出盲点（当事人很难中立）
- 重新定位（不是咨询，是独立董事）
```

### 话术4-2："现在不是时候"异议

```
【触发】客户说"现在太忙了，过段时间再说"

【话术】
"X总，我懂。创业永远有'更重要的事'——融资、产品、客户。

但我想请您考虑一个时间点：
合伙人关系的'最佳修复期'是什么时候？

答案是：在问题还小的时候。

我们的案例库中，
那些在'种子期/天使期'就建立治理机制的创始团队，
后来在A轮/B轮时的合伙人争议，
比没有治理机制的团队少[X]%。

而那些在'出事了'才来找我们的，
修复成本是预防成本的10倍。

所以，'现在不是时候'——
如果现在合伙人关系还行，现在就是最好的时机。
如果现在已经有小摩擦，现在就是最后的好时机。"

【目的】
- 不强迫（尊重客户节奏）
- 重塑"时机"概念（预防>治疗）
- 用数据说话（案例库统计）
```

```
├─ 关系成本：合伙人反目成仇
├─ 机会成本：错过融资/上市窗口
└─ 总计：100万+，而且关系毁了

而我们的服务：
├─ 费用：5-10万
├─ 时间：2-3个月
├─ 结果：预防争议或体面解决
├─ 关系：保留甚至修复
└─ ROI：10-50倍

这不是'消费'，这是'保险'。
花5万买一份'合伙人关系保险'，
避免未来可能的100万+损失。

而且，如果您现在觉得中端服务有压力，
我们可以先从[免费自检清单]开始。
发现问题后，再决定是否需要深度服务。"

【目的】
- 不降价（维护价值感）
- 对比"冲突成本"（锚定效应）
- 提供低价入口（免费自检）
```

## 场景五：成交签约（临门一脚）

### 话术5-1：假设成交法

```
【触发】客户已经表达兴趣，需要推动决策

【话术】
"X总，基于我们今天聊的，
我觉得[中端服务]对您目前的情况最有价值。

如果您决定开始，
我们的流程是：

Week 1: 双方签署服务协议 + 支付首款（50%）
Week 2-3: 深度诊断（3小时访谈 + 资料收集）
Week 4-5: 工具包设计（决策权矩阵 + 股权框架）
Week 6: 交付 + 培训（教会你们怎么用）
Week 7-14: 跟踪辅导（每周1小时复盘）

您希望从什么时候开始？
下个月初还是这个月底？"

【目的】
- 用"如果您决定"假设成交
- 给出具体时间表（降低决策模糊性）
- 提供选择（月初/月底，不是"做不做"）
```

### 话术5-2：稀缺性推动法

```
【触发】客户犹豫，需要适度推动

【话术】
"X总，我需要诚实告诉您——
满意解的中端服务，我们每个月只接[X]个客户。
原因是：创始人深度诊断需要大量时间，
我们不想为了数量牺牲质量。

目前，我们下个月的名额还剩[X]个。

我不是在催您——
但如果您觉得满意解对您有价值，
建议您在这个月内确定，
这样我们可以安排在下月初启动。

如果下个月名额满了，
可能需要排到[下下个月]。

当然，无论您什么时候决定，
我们都欢迎。只是提前告诉您时间线。"

【目的】
- 真实稀缺（不虚假）
- 推动但不强迫
- 给客户"合理的时间压力"
```

### 话术5-3：风险逆转法

```
【触发】客户对效果有顾虑，担心"花了钱没效果"

【话术】
"X总，我理解您的顾虑——'如果花了钱，合伙人关系还是没改善怎么办？'

我们有'满意保证'机制：

如果在服务期内（3个月），
您觉得合伙人关系没有任何改善，
我们全额退款。

不是'部分退款'，是全额退款。

我们对我们的方法有信心——
案例库中，[X]%的客户在3个月内感受到了改善。
但我们也不想让您承担风险。

所以，如果您决定开始，
风险在我们这边，不在您那边。"

【目的】
- 消除"效果不确定"的顾虑
- 用"风险逆转"建立信任
- 展示信心（愿意全额退款）
```

## 附录：禁忌话术（绝对避免）

| # | 禁忌话术 | 为什么错 | 替代方案 |
|:-:|----------|:---------|:---------|
| 1 | "你们合伙人关系肯定有问题" | 攻击性，客户会防御 | "很多创始人在[阶段]会遇到[问题]，您呢？" |
| 2 | "麦肯锡不如我们专业" | 贬低对手，显得不自信 | "麦肯锡是战略咨询，我们是合伙人关系专科" |
| 3 | "这个价格已经很便宜了" | 显得廉价 | "这个投入相比冲突成本，ROI是15-50倍" |
| 4 | "您不懂，听我的" | 傲慢，破坏信任 | "让我用一个案例说明..." |
| 5 | "不买就错过机会了" | 高压销售 | "名额有限，但您有充分时间考虑" |
| 6 | "我们保证100%解决" | 过度承诺 | "[X]%的客户在3个月内感受到改善" |

---

> **核心原则**：
> 销售话术不是"说服"，是"帮助客户做出明智决策"。
> 
> 每一句话的背后，应该是：
> "我是真的相信，满意解能帮到你。
> 我不是在推销，是在分享一个可能对你有价值的选项。"
> 
> 如果客户最后不选择我们，
> 至少他带走了我们的自检清单，
> 对他的合伙人关系也有帮助。
> 
> 这就是满意解的"契·晋"——
> 即使不做生意，也做朋友。
>
> **契 · 晋。**
