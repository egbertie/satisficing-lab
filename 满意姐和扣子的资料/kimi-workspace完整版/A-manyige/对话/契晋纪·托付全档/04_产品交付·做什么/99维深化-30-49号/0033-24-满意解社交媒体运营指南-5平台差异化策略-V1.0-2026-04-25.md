```

├─ 点击率：封面+标题决定曝光量
├─ 互动率：点赞+收藏+评论决定推荐量
├─ 完读率：内容质量决定持续推荐
```

### 1.3 内容模板（3套）

```
【模板A：故事型】（占比40%）

封面：痛点场景图 + 大字标题
标题：情绪钩子 + 数字 + 结果
"凌晨2点，合伙人发来这条消息，我失眠了"
"创业第3年，我终于找到了有温度的AI"
"合伙人突然要退出，我用3个工具化解了"

正文结构：
├─ 第1段：场景描述（2行，建立共鸣）
├─ 第2段：情绪放大（2行，加深共鸣）
├─ 第3段：转折（1行，"后来我发现了..."）
├─ 第4段：方法简述（3行，干货植入）
├─ 第5段：结果+CTA（2行，"现在我们的关系..."）
└─ 标签：#合伙人 #创业 #决策 #满意解

示例：
"凌晨2点，合伙人发来这条消息，
'我觉得我们的方向不对，我想退出了。'

那一刻，我手脚冰凉。
3年的努力，可能就这么散了。

但我没有急着吵架。
我拿出'五维决策框架'，
用了整整3天，和他一条条梳理。

最后我们发现：
不是方向不对，是沟通方式不对。
我们用'沟通协议模板'，
约定了每周一次的'战略对齐会'。

现在，我们的关系比从前更好了。

如果你也和合伙人有过类似的问题，
评论区扣'1'，我发你《沟通协议模板》。"

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【模板B：干货型】（占比40%）

封面：信息图/思维导图 + 标题
标题：数字 + 干货 + 承诺
"合伙人评估，我只看5个维度"
"股权分配的3个常见错误"
"合伙人会议的5个高效技巧"

正文结构：
├─ 第1段：问题提出（1行）
├─ 第2-6段：5个要点（每点2行）
├─ 第7段：总结（1行）
└─ 第8段：CTA（1行）

示例：
"合伙人评估，我只看5个维度：

【土·伦理底座】
站得住吗？价值观一致吗？

【金·满意解标准】
80分够了吗？还是非要100分？

【水·洞察本质】
能看到问题的本质吗？

【木·信任治理】
合伙人之间信任吗？

【火·行动转化】
直觉怎么说？

每个维度1-10分，总分50分。
40分以上，关系健康。
30分以下，危险区。

想要完整测评？
评论区扣'测评'，我私发你链接。"

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【模板C：互动型】（占比20%）

封面：选择题/投票图 + 标题
标题：提问 + 互动引导
"你的合伙人关系，最大的挑战是什么？"
"合伙人评估，你打几分？"
"这5个预警信号，你中了几个？"

正文结构：
├─ 第1段：问题提出（1行）
├─ 第2-6段：选项（每点1行）
├─ 第7段：互动引导（1行）
└─ 第8段：CTA（1行）

示例：
"【合伙人关系自检·第1题】

你们有书面的'合伙人协议'吗？

A. 有，且律师审核过
B. 有，但没律师看过
C. 没有，口头约定的
D. 没有，也没觉得需要

评论区扣A/B/C/D。

如果你选C或D，
送你一份《合伙人章程自检清单》，
回复'清单'，我发你。"

```
