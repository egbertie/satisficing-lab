## 第一部分：品牌标志

### 1.1 LOGO设计

```
【主LOGO】

图形：
├─ 元素：五维交织（土金水木火）
├─ 形状：圆形或盾形
├─ 寓意：圆满、守护、完整
└─ 风格：简约、现代、东方

文字：
├─ 中文："满意解"
├─ 英文："Satisficing"
├─ 字体：思源黑体（定制微调）
└─ 风格：稳重、有力量

组合：
├─ 横版：图形+文字
├─ 竖版：图形在上，文字在下
├─ 图标版：仅图形
└─ 文字版：仅文字

【LOGO使用规范】

最小尺寸：
├─ 横版：宽≥80px
├─ 竖版：高≥60px
└─ 图标版：≥32px

安全空间：
├─ LOGO周围留白≥LOGO高度的1/4
└─ 不被其他元素侵入

禁止：
├─ ❌ 拉伸变形
├─ ❌ 改变颜色
├─ ❌ 添加阴影（除非规范允许）
├─ ❌ 旋转倾斜
├─ ❌ 改变比例
└─ ❌ 添加装饰

【LOGO颜色版本】

主色版：
├─ 深蓝背景+白色LOGO
└─ 用于：官网、APP、深色背景

反白版：
├─ 白色背景+深蓝LOGO
└─ 用于：文档、浅色背景

单色版：
├─ 全深色或全浅色
└─ 用于：特殊场景（印章、水印）
```

### 2.3 色彩使用比例

```
【6:3:1法则】

60%：主色（深蓝/白色）
├─ 背景、大面积
└─ 传达专业、信任

30%：辅助色（金色）
├─ 重点、标题、CTA
└─ 传达价值、品质

10%：点缀色（五维色）
├─ 图表、标签、高亮
└─ 传达活力、区分

【禁止组合】
├─ ❌ 红+绿（冲突）
├─ ❌ 蓝+紫（模糊）
├─ ❌ 过多颜色（>4种）
└─ ❌ 高饱和度大面积使用
```

## 第四部分：辅助图形

### 4.1 图形元素

```
【五维图形】
├─ 形状：五边形/五角星
├─ 用法：背景、装饰、图标
├─ 变体：
│   ├─ 实心版
│   ├─ 线条版
│   ├─ 渐变版
│   └─ 单色版
└─ 比例：按规范缩放

【线条元素】
├─ 风格：简洁、几何
├─ 粗细：1-3px
├─ 颜色：主色或金色
└─ 用法：分隔、引导、装饰

【圆点元素】
├─ 大小：4-8px
├─ 颜色：五维色
├─ 用法：列表标记、进度指示
└─ 组合：连线形成路径

【纹理元素】
├─ 风格： subtle，不抢镜
├─ 用途：背景纹理
├─ 密度：低密度
└─ 颜色：主色10%透明度
```

---

### 4.2 图片风格

```
【摄影风格】
├─ 色调：暖色调，自然光
├─ 构图：简洁，留白
├─ 人物：真实、自然、专业
├─ 场景：办公、会议、交流
└─ 后期：轻微调色，不过度

【插画风格】
├─ 风格：扁平、简约
├─ 颜色：品牌色
├─ 人物：抽象、友好
├─ 场景：工作、协作、决策
└─ 比例：统一风格

【图表风格】
├─ 配色：品牌色+五维色
├─ 字体：标准字体
├─ 样式：简洁、清晰
├─ 标注：规范、统一
└─ 导出：高清、矢量
```

## 第五部分：应用规范

### 5.1 办公用品

```
【名片】
├─ 尺寸：90mm × 54mm
├─ 材质：300g铜版纸
├─ 正面：LOGO+姓名+职位+联系方式
├─ 背面：Slogan+二维码
└─ 颜色：白底+深蓝+金色点缀

【信纸】
├─ 尺寸：A4
├─ 材质：100g胶版纸
├─ 页眉：LOGO+品牌色条
├─ 页脚：联系方式+网址
└─ 颜色：白底+深蓝

【信封】
├─ 尺寸：标准信封
├─ 正面：LOGO+地址
├─ 封口：品牌色
└─ 颜色：白底+深蓝

【PPT模板】
├─ 封面：LOGO+标题+副标题
├─ 目录：五维框架
├─ 内容页：标题+正文+图表
├─ 结尾页：LOGO+联系方式
└─ 配色：品牌色+白底
```

---

### 5.2 线上应用

```
【官网】
├─ 主色：深蓝+白
├─ 强调：金色
├─ 按钮：深蓝底+白字/金边
├─ 链接：金色
├─ 背景：白色/浅灰
└─ 图标：统一风格

【APP】
├─ 导航：底部/侧边
├─ 主色：深蓝+白
├─ 强调：金色
├─ 卡片：白底+阴影
├─ 按钮：圆角+品牌色
└─ 图标：线性+填充

【社交媒体】
├─ 头像：LOGO
├─ 封面：品牌色+Slogan
├─ 配图：统一风格
├─ 水印：右下角，半透明
└─ 模板：统一尺寸

【邮件】
├─ 页眉：LOGO
├─ 正文：标准字体
├─ CTA按钮：品牌色
├─ 页脚：联系方式+退订
└─ 配色：简洁、专业
```

### 5.3 宣传物料

```
【海报】
├─ 尺寸：根据用途
├─ 布局：LOGO+标题+内容+CTA
├─ 配色：品牌色为主
├─ 字体：标准字体
└─ 二维码：必须包含

【易拉宝】
├─ 尺寸：80cm × 200cm
├─ 布局：LOGO+核心价值+联系方式
├─ 配色：品牌色
├─ 字体：大号、易读
└─ 图片：高质量

【宣传册】
├─ 尺寸：A4或A5
├─ 页数：4-8页
├─ 封面：LOGO+主题
├─ 内页：内容+图表
├─ 封底：联系方式+二维码
└─ 装订：骑马钉或胶装

【展会物料】
├─ 背景板：品牌色+LOGO
├─ 桌布：品牌色
├─ 名片盒：品牌色
├─ 资料架：简洁
├─ 礼品：卡牌、笔记本
└─ 统一：所有物料视觉一致
```
