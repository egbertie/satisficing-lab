
## 第一部分：录制准备

### 1.1 设备清单

```
【必备设备】

相机：
├─ 推荐：Sony A7M4 / Canon R6
├─ 镜头：35mm f1.8（人像）
├─ 备用：iPhone 15 Pro Max（应急）
└─ 设置：4K 30fps

麦克风：
├─ 推荐：Rode Wireless GO II（无线）
├─ 备选：Blue Yeti（USB电容麦）
└─ 注意：远离空调、风扇噪音

灯光：
├─ 推荐：Godox SL-60W × 3（三点布光）
├─ 设置：
│   ├─ 主光：45°侧前方，最亮
│   ├─ 辅光：另一侧，补阴影
│   └─ 背景光：分离背景
└─ 色温：5600K（日光）

背景：
├─ 实体背景：书架/品牌墙/简约墙
├─ 虚拟背景：绿幕+后期
└─ 注意：不杂乱、不抢镜

【辅助设备】
├─ 三脚架：稳固、可调高度
├─ 提词器：iPad+提词器支架
├─ 监视器：检查画面
├─ 存储卡：128GB × 2
├─ 电池：备用电池×2
└─ 电脑：剪辑用

【软件工具】
├─ 录制：OBS / Camera
├─ 剪辑：Final Cut Pro / Premiere
├─ 调色：DaVinci Resolve
├─ 字幕：剪映 / Arctime
└─ 提词：PromptSmart
```

---

### 1.2 环境准备

```
【录制环境】

空间：
├─ 面积：>10平米

├─ 隔音：减少回声

检查清单：

├─ [ ] 光线均匀

```

## 第二部分：录制流程

### 2.1 录制前

```
【准备清单】

心态：
├─ 睡眠充足（前一晚）
├─ 状态放松（深呼吸）
├─ 目标明确（今天录哪几段）
└─ 接受不完美（可以NG）

形象：
├─ 着装：商务休闲，纯色
├─ 发型：整洁
├─ 妆容：自然（可选）
└─ 饰品：简洁

材料：
├─ 脚本：打印/提词器
├─ 道具：卡牌、白板、笔
├─ 水：温水（润喉）
└─ 笔记：记录灵感
```

---

### 2.2 录制中

```
【分段录制法】

每段5-10分钟，分段录制：
├─ 好处1：失误只影响本段
├─ 好处2：便于后期剪辑
├─ 好处3：减少疲劳
└─ 好处4：可调整状态

【开场录制】（每段）
"Hi，我是Egbertie，
欢迎来到满意解第X模块第X节。"

【正文录制】
├─ 看提词器，不要读稿
├─ 像聊天，不要背书
├─ 有停顿，有重点
├─ 有手势，有表情
└─ 有互动感（"你想想""你会发现"）

【结尾录制】（每段）
"这一节就到这里，
下一节我们讲...
记得点赞、关注、分享给需要的朋友。
满意解，让每一对合伙人都能走到最后。"

【NG处理】
├─ 停顿3秒
├─ 说"刚才这段重来"
├─ 从本段开头重新录
└─ 后期剪掉NG部分
```

---

### 2.3 录制后

```
【当日工作】

1. 备份素材
├─ 复制到电脑
├─ 复制到移动硬盘
└─ 云端备份（阿里云/OSS）

2. 检查素材
├─ 每个文件是否完整
├─ 画质是否清晰
├─ 音质是否清晰
└─ 标记问题片段

3. 记录日志
├─ 录制日期
├─ 模块/节
├─ 时长
├─ 问题/备注
└─ 下次改进点
```

## 第三部分：剪辑规范

### 3.1 粗剪

```
【步骤】

1. 导入素材
├─ 按模块/节分类
├─ 重命名：模块_节_序号
└─ 建立文件夹结构

2. 删除NG
├─ 剪掉明显失误
├─ 剪掉停顿过长
└─ 剪掉重复内容

3. 拼接片段
├─ 按逻辑顺序排列
├─ 转场：硬切（不要花哨）
└─ 节奏：紧凑、不拖沓

4. 粗剪时长
├─ 目标：比脚本短10%
├─ 原因：人都比脚本说得慢
└─ 原则：信息密度高
```

---

### 3.2 精剪

```
【添加元素】

1. 字幕
├─ 位置：底部居中
├─ 字体：思源黑体
├─ 大小：适中
├─ 颜色：白色+描边
└─ 同步：准确

2. 标题
├─ 开场：模块标题（3秒）
├─ 章节：小标题（2秒）
└─ 结尾：品牌LOGO（3秒）

3. 图表
├─ 插入：五维框架图、案例图
├─ 动效：简单淡入淡出
└─ 时长：足够看清

4. 标注
├─ 重点词：高亮
├─ 数据：放大
└─ 金句：停留

5. BGM
├─ 音量：比人声低20dB
├─ 风格：轻音乐、不抢戏
├─ 版权：使用免版权音乐
└─ 切换：淡入淡出

6. 片头片尾
├─ 片头（5秒）：
│   ├─ 品牌LOGO
│   ├─ 模块标题
│   └─ 背景音乐
├─ 片尾（10秒）：
│   ├─ 总结金句
│   ├─ CTA（关注/扫码）
│   ├─ 下期预告
│   └─ 品牌信息
```
