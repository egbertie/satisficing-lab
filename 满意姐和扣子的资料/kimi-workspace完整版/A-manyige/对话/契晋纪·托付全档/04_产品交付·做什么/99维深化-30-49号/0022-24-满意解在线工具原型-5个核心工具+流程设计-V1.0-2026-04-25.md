## 第一部分：工具设计

### 1.1 合伙人匹配度测评

```
【功能】
├─ 输入：合伙人信息
├─ 评估：五维度评分
├─ 输出：匹配度报告
└─ 建议：改进建议

【流程】
Step 1: 基本信息
├─ 合伙人A姓名、角色
├─ 合伙人B姓名、角色
├─ 公司阶段
└─ 行业

Step 2: 五维评估（各5题）
├─ 土·伦理：价值观、诚信
├─ 金·标准：目标、期望
├─ 水·洞察：认知、互补
├─ 木·信任：沟通、透明
└─ 火·行动：执行力、互补

Step 3: 生成报告
├─ 匹配度总分
├─ 五维雷达图
├─ 优势分析
├─ 风险提示
└─ 改进建议

【技术】
├─ 前端：React
├─ 后端：Node.js
├─ 数据：存储结果
├─ 分享：生成海报
└─ 时间：5分钟
```

---

### 1.2 决策权矩阵生成器

```
【功能】
├─ 输入：合伙人+决策事项
├─ 分配：决策权限
├─ 输出：矩阵图+文档
└─ 导出：PDF

【流程】
Step 1: 添加合伙人
├─ 姓名
├─ 角色
└─ 股权比例

Step 2: 添加决策事项
├─ 战略决策
├─ 财务决策
├─ 人事决策
├─ 产品决策
└─ 运营决策

Step 3: 分配权限
├─ 合伙人A：哪些决策
├─ 合伙人B：哪些决策
├─ 共同决策：哪些
├─ 一票否决：哪些
└─ 咨询：哪些

Step 4: 生成矩阵
├─ 可视化矩阵
├─ 文字说明
├─ 导出PDF
└─ 分享链接
```

### 1.3 股权计算器

```
【功能】
├─ 输入：合伙人贡献
├─ 计算：股权分配
├─ 输出：股权结构
└─ 建议：动态调整

【流程】
Step 1: 输入贡献
├─ 资金：各投入多少
├─ 技术：估值多少
├─ 资源：估值多少
├─ 时间：全职/兼职
├─ 经验：行业经验
└─ 其他：其他贡献

Step 2: 设置权重
├─ 资金权重
├─ 技术权重
├─ 资源权重
├─ 时间权重
└─ 经验权重

Step 3: 计算结果
├─ 股权分配比例
├─ 建议动态调整
├─ 里程碑设置
└─ 退出机制建议

Step 4: 生成方案
├─ 股权结构图
├─ 动态调整表
├─ 导出文档
└─ 分享链接
```

### 1.4 五维决策画布

```
【功能】
├─ 输入：决策问题
├─ 分析：五维分析
├─ 输出：画布图
└─ 导出：图片/PDF

Step 1: 输入决策问题
Step 2: 逐维分析

├─ 水·洞察：本质？
├─ 木·信任：信任影响？

Step 4: 生成画布
├─ 可视化画布
├─ 评分雷达图
├─ 决策建议
└─ 导出分享
```

Step 4: 生成章程
