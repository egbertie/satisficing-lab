## 二、功能设计

### 核心功能

```
[首页]
  → 选择评估类型（合伙人/投资/招聘/战略/其他）
  → 开始评估

[评估流程]
  Step 1: 土·伦理（5题，2分钟）
    → "这个决策站得住吗？"
    → 题目示例："如果明天上新闻，你怕吗？"
  
  Step 2: 金·满意解（5题，2分钟）
    → "80分够了吗？"
    → 题目示例："边界清晰吗？选项充分吗？"
  
  Step 3: 水·洞察（5题，2分钟）
    → "去掉包装，本质是什么？"
    → 题目示例："第一性原理是什么？"
  
  Step 4: 木·信任（5题，2分钟）
    → "合伙人信任吗？"
    → 题目示例："3年后还能一起喝咖啡吗？"
  
  Step 5: 火·直觉（3题，1分钟）
    → "直觉怎么说？"
    → 题目示例："闭眼30秒，你的直觉是什么？"

[结果页]
  → 综合评分（0-50分）
  → 五维雷达图
  → 冲突风险预测（13类型）
  → 行动建议
  → 保存/分享/下载PDF
```

## 四、技术架构

### 前端

```
技术栈:
- React 18
- TailwindCSS
- Chart.js（雷达图）
- html2canvas（PDF生成）

页面结构:
- /home → 首页
- /assess/:type → 评估页
- /result/:id → 结果页
- /history → 历史记录
- /profile → 个人中心
```

### 后端

```
技术栈:
- Python Flask
- PostgreSQL
- Redis（缓存）
- Celery（异步任务）

API设计:
- POST /api/assess/start → 开始评估
- POST /api/assess/answer → 提交答案
- GET /api/assess/result/:id → 获取结果
- GET /api/assess/history → 获取历史
- POST /api/assess/share → 分享结果
```

### 算法服务

```
五维评估引擎:
- 输入: 25个答案（每维5题）
- 处理: 加权计算 + 冲突预测
- 输出: 综合评分 + 五维分数 + 风险预测 + 建议

冲突预测模型:
- 基于13类型分类器
- 输入: 五维分数 + 场景参数
- 输出: Top 3风险类型 + 概率
```
