# 模块14：合伙人冲突诊断与干预

> **核心命题**: 13类型冲突不是理论，是创始人每天面对的真实战场——识别→评估→干预→复盘
> **血液化资产**: 12类型案例库、冲突诊断流程、干预工具箱
> **适用对象**: 创始人、合伙人、咨询师、投资人

---

## 一、核心理念

### 1.1 13类型冲突的本质

```
13类型冲突 = 合伙人关系的"疾病分类学"

不是"13种吵架方式"，是"13种深层结构问题":
  ├─ Type01 创始人过度干预 → 信任+边界问题
  ├─ Type02 合伙人能力错配 → 能力+期望问题
  ├─ Type03 资源争夺型 → 利益+公平问题
  ├─ Type04 战略方向分歧 → 愿景+决策问题
  ├─ Type05 价值观冲突型 → 根本+伦理问题
  ├─ Type06 股权结构不合理 → 制度+激励问题
  ├─ Type07 技术合伙人退出 → 信任+修复问题
  ├─ Type08 核心员工挖角 → 竞争+伦理问题
  ├─ Type09 第二代接班人挑战 → 传承+能力问题
  ├─ Type10 知识产权纠纷 → 法律+伦理问题
  ├─ Type11 财务不透明 → 信任+制度问题
  └─ Type12 外部压力型 → 外部+适应问题

每种类型有:
  ├─ 典型症状（怎么表现）
  ├─ 深层原因（为什么会发生）
  ├─ 五维映射（哪一维失衡）
  ├─ 干预方案（怎么处理）
  └─ 预防措施（怎么避免）
```

### 1.2 冲突诊断的流程

```
冲突发生
  ↓
识别类型: 对照13类型清单
  ↓
评估严重程度:
  ├─ 轻度: 沟通层面，可自行解决
  ├─ 中度: 需要第三方介入
  └─ 重度: 可能无法修复，准备退出机制
  ↓
五维扫描: 哪一维失衡最严重？
  ↓
选择干预方案:
  ├─ 土·信义修复 → 重建信任
  ├─ 金·标尺明确 → 设定边界
  ├─ 水·觉察恢复 → 情绪管理
  ├─ 木·伦理坚守 → 伦理对话
  └─ 火·顿悟触发 → 寻找突破
  ↓
执行干预 → 监控进展
  ↓
复盘: 干预效果如何？
```

## 二、血液化前 vs 血液化后

| 维度 | 血液化前 | 血液化后 |
|:-----|:---------|:---------|
| 冲突识别 | "我们吵架了"（模糊） | "Type07，信义崩塌"（精确） |
| 原因分析 | 情绪化指责 | 五维扫描找根因 |
| 干预方案 | 凭感觉处理 | 按类型选择方案 |
| 严重程度 | 凭感觉判断 | 轻/中/重度分级 |
| 预防措施 | 没有 | 类型对应预防 |
| 知识积累 | 每次重新摸索 | 案例库直接调用 |
| 外部求助 | 不知道找谁 | 按类型匹配专家 |
| 复盘方式 | "过去了就算了" | 结构化复盘 |

## 三、操作步骤

### Step 1: 快速识别冲突类型

**快速识别卡**:
```
冲突发生 → 问自己:

1. 谁在控制决策？
   ├─ 一方过度控制 → Type01
   └─ 双方争夺 → Type03

2. 能力匹配吗？
   ├─ 一方跟不上 → Type02
   └─ 核心人员离开 → Type07/08

3. 方向一致吗？
   ├─ 战略分歧 → Type04
   └─ 价值观不合 → Type05

4. 制度有问题吗？
   ├─ 股权不合理 → Type06
   ├─ 财务不透明 → Type11
   └─ IP纠纷 → Type10

5. 外部因素？
   ├─ 接班人问题 → Type09
   └─ 外部压力 → Type12

→ 确定类型 → 进入评估
```

### Step 2: 评估严重程度

**严重程度评估表**:
```
# 严重程度评估

## 冲突类型: Type[编号]_[名称]

## 评估维度
| 维度 | 轻度(1) | 中度(2) | 重度(3) |
|:-----|:--------|:--------|:--------|
| 频率 | 偶尔发生 | 经常发生 | 持续存在 |
| 影响 | 不影响工作 | 影响效率 | 影响生存 |
| 信任 | 基本完好 | 受损 | 崩塌 |
| 沟通 | 还能对话 | 回避沟通 | 完全断裂 |
| 修复意愿 | 双方愿意 | 一方愿意 | 双方不愿 |

## 评分
- 5-7分: 轻度 → 自行解决
- 8-11分: 中度 → 第三方介入
- 12-15分: 重度 → 准备退出机制

## 建议干预方式
[根据评分选择]
```

### Step 3: 五维扫描找根因

**五维扫描模板**:
```
# 五维扫描 - Type[编号]冲突

## 土·信义
□ 信义账户余额: 正/负/零
□ 关键时刻表现: 可靠/一般/不可靠
□ 修复意愿: 有/无

## 金·标尺
□ 边界清晰度: 清晰/模糊/无边界
□ 制度完善度: 完善/部分/缺失
□ 决策权分配: 明确/模糊/冲突

## 水·觉察
□ 情绪状态: 平静/波动/激动
□ 沟通意愿: 开放/回避/敌对
□ 自我觉察: 有/无

## 木·伦理
□ 伦理底线: 未触碰/灰色/已触碰
□ 程序正义: 符合/部分/不符合
□ 双方伦理观: 一致/部分/冲突

## 火·顿悟
□ 突破点: 可见/模糊/无
□ 行动readiness: ready/犹豫/拒绝
□ 创造性方案: 有/无

## 关键短板
[哪一维最低？这是干预重点]
```

### Step 4: 选择干预方案

**干预方案库**:
```
Type01 创始人过度干预:
  干预: 土·信义修复 + 金·标尺明确
  具体: 信义账户对话 + 边界协议

Type02 合伙人能力错配:
  干预: 金·标尺调整 + 土·信义维护
  具体: 职责重新定义 + 培训/补充

Type03 资源争夺:
  干预: 金·标尺公平 + 木·伦理对话
  具体: 资源分配制度 + 公平感重建

Type04 战略方向分歧:
  干预: 火·顿悟触发 + 金·标尺决策
  具体: 满意解决策 + 试点验证

Type05 价值观冲突:
  干预: 木·伦理坚守 + 水·觉察恢复
  具体: 伦理底线对话 + 情绪处理

[其他类型见完整方案库]
```

### Step 5: 执行与复盘

**执行检查清单**:
```
□ 1. 双方同意干预方案？
□ 2. 有明确的时间表？
□ 3. 有第三方监督（可选）？
□ 4. 有退出机制（重度时）？
□ 5. 每周检查进展？
□ 6. 记录关键对话？
□ 7. 信任修复行动在执行？
□ 8. 边界在遵守？
```

**复盘模板**:
```
# 复盘 - Type[编号]冲突干预

## 干预时间: YYYY-MM-DD 至 YYYY-MM-DD
## 干预方式: [描述]

## 结果
□ 成功 → 经验沉淀
□ 部分成功 → 继续干预
□ 失败 → 复盘原因

## 经验
- 做对了什么？
- 做错了什么？
- 下次如何改进？

## 沉淀
- 写入案例库: [文件路径]
- 更新干预方案: [修改内容]
```

## 六、常见误区

| 误区 | 表现 | 后果 | 纠正 |
|:-----|:-----|:-----|:-----|
| 类型识别错误 | 把Type01当Type05处理 | 干预无效 | 仔细对照识别卡 |
| 忽视严重程度 | 重度冲突当轻度处理 | 错失退出时机 | 严格评分 |
| 跳过五维扫描 | 凭感觉找原因 | 治标不治本 | 必须五维扫描 |
| 干预方案错配 | Type02用Type01方案 | 无效甚至恶化 | 对照速查表 |
| 不准备退出 | "一定能修复" | 被动应对 | 重度时准备退出 |
| 不复盘 | 干预完就结束 | 无法积累 | 必须结构化复盘 |
| 情绪化干预 | 被当事人情绪带走 | 失去客观 | 蓝军视角介入 |
| 忽视预防 | 只处理不预防 | 重复发生 | 建立预防机制 |
| 案例库不用 | 每次重新摸索 | 效率低下 | 先查案例库 |
| 一人处理 | 没有外部视角 | 盲区 | 团队协作 |

## 七、真实案例

### 案例1: "Type01→Type07"——从轻到重的演变

**背景**: 创始人过度干预（Type01）未处理，演变为CTO退出（Type07）。

**演变过程**:
```
阶段1（Type01轻度）:
  - 创始人频繁质疑CTO方案
  - 未处理，认为"正常沟通"

阶段2（Type01中度）:
  - CTO开始回避创始人
  - 仍认为"需要磨合"

阶段3（Type01重度→Type07）:
  - CTO突然提出退出
  - 信任崩塌，无法修复

教训:
  - 轻度时不处理 → 恶化
  - 五维扫描能早期发现土·信义下降
  - 早期干预成本远低于后期
```

### 案例2: "Type04战略分歧"——五维扫描成功干预

**背景**: 两位合伙人战略方向严重分歧。

**五维扫描**:
```
土·信义: 12/20（信任尚可）
金·标尺: 10/20（边界不清）
水·觉察: 8/20（情绪激动）
木·伦理: 15/20（伦理底线未触碰）
火·顿悟: 14/20（有突破可能）

关键短板: 水·觉察（情绪激动影响判断）
```

**干预**:
1. 先处理情绪（水）→ 0.3秒停练习
2. 明确决策边界（金）→ 满意解标准
3. 试点验证（火）→ 小步快跑

**结果**: 3周后达成共识，战略方向确定。
