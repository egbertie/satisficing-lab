## 开场（3分钟）

上一节课，我们聊了为什么传承总是失败。

今天这节课，我要给你一个"武器"——一个能帮你判断"我该往哪使劲"的模型。

这个模型叫"双三角模型"。它回答两个根本问题：

**第一**：同样都会用AI，为什么不同人的业务结果相差那么大？
**第二**：同样都是业务高手，为什么不同人的AI结果相差那么大？

这两个问题，一个是"人的竞争力"，一个是"AI的竞争力"。双三角模型把它们放在一起，让你看清自己的位置。

## 人类三角：人到底拼什么？（8分钟）

先看左边这个三角。

```
          创造力
         /      \
        /        \
   审美 ———————— 体系
```

三个顶点：**审美**、**体系**、**创造力**。

### 审美

不是"画画好不好看"的审美。是**专业见识**——你知道什么是好的、什么是差的、什么是行业最佳实践。

举个例子。两个人都用AI写方案，一个人出来的东西一看就是"AI味"，另一个人出来的东西你看不出是AI写的。区别在哪？

在审美。第二个人知道"好的方案长什么样"，所以他能在AI产出后，一眼看出哪里不对、哪里要改。第一个人没有这个审美，AI给他什么，他就用什么。

**在知识传承中，审美的作用是**：设定质量标准。你知道"高质量的知识资产"长什么样，所以你不会满足于"文件存完"。

### 体系

**体系思维**——你能不能把散乱的信息，组织成一个稳定的结构。

有些人，脑子里有10万个知识点，但都是散的。需要用的时候，想不起来。有些人，知识点不多，但每一个都知道该放在哪、和谁有关、在什么场景下用。

这就是体系的力量。

**在知识传承中，体系的作用是**：设计传承路径。你知道"这些知识应该怎么组织"，所以接班人不会迷失在文件堆里。

### 创造力

**创造力**——不是"写诗作画"，是理解底层规律、解放思想、提出假设。

为什么有些人在AI时代越来越强？因为他们不会被AI的输出限制住。AI给了他们一个基础，他们在这个基础上，能想到AI想不到的东西。

**在知识传承中，创造力的作用是**：找到最适合的传承方案。不被"传统做法"限制，敢于设计新的传承方式。

### 人类三角公式

```
人类竞争力 = 审美判断力 × 体系构建力 × 创造力
```

这三个是乘法关系。如果任何一个为0，整体竞争力就是0。

## AI三角：AI到底拼什么？（8分钟）

再看右边这个三角。

```
          场景
         /      \
        /        \
   基本功 ———————— 数据
```

三个顶点：**基本功**、**数据**、**场景**。

### 基本功

**基本功**——你会不会用AI工具。提示词怎么写、智能体怎么搭、多模态工具怎么用、模型怎么微调。

这不是"知道有这个东西"，是"手会"。

就像开车。你知道有车，和你会开车，是两回事。

**在知识传承中，基本功的作用是**：操作AI完成入库、连接、血液化。没有基本功，你有再多想法，也执行不了。

### 数据

**数据**——你有多少可被AI使用的知识资产。

不是"我有1万个文件"。是"这1万个文件里，有多少是结构化的、可检索的、有标签的、有连接的"。

一个乱糟糟的文件夹，和一个有标签、有分类、有连接的知识库，对AI来说是完全不同的东西。

**在知识传承中，数据的作用是**：提供AI处理的原材料。数据质量决定了AI产出的质量。

### 场景

**场景**——你知道"在什么情况下用AI、怎么用、投入产出比如何"。

有些人，AI工具用得飞起，但都用在了不重要的地方。花了大量时间优化一个 Nobody cares 的流程。

真正的高手，知道"哪个环节用AI，ROI最高"。

**在知识传承中，场景的作用是**：判断"哪些知识值得优先传承"。不是所有知识都值得传承，有些知识，过期了就让它过期。

### AI三角公式

```
AI竞争力 = 场景判断力 × 基本功熟练度 × 数据资产化能力
```

同样是乘法关系。

## 双三角交汇：飞轮转动的核心（8分钟）

现在，把两个三角放在一起。

```
      人类三角                  AI三角
        ↓                        ↓
   创造力+审美+体系      ×    场景+基本功+数据
        ↓                        ↓
        └────── 交汇点 ──────┘
              ↓
      人变强了 → 调教更强AI
      AI更强了 → 辅助人变得更强
              ↓
         飞轮持续转动
```

交汇点有三个关键动作：

**动作一：人类用审美判断AI产出 → AI用基本功修正 → 数据资产升级**

你（人类）说："这个产出，这里的逻辑不对。" AI用基本功修正。修正后的数据资产，质量更高。

**动作二：AI用场景识别空白 → 人类用创造力填补 → 体系更完整**

AI说："我发现这个领域，我们有资料，但没有和成体系的框架连接。" 你用创造力，设计一个新的框架，把散落的资料连起来。

**动作三：人类用体系思维设计传承路径 → AI用数据能力执行 → 场景不断扩展**

你设计了一个"先传骨架、再传血肉"的传承路径。AI按照这个路径，批量处理文件、建立连接。执行过程中，AI发现了一些新的应用场景。

这就是飞轮。人变强了，调教出更强的AI。AI更强了，辅助人变得更强。

## 案例验证：满意姐的双三角进化（2分钟）

我自己就是一个例子。

刚开始，我的AI三角很弱。基本功不行（提示词写得烂），数据不行（文件只是存储，没有结构化），场景不行（不知道该优先处理什么）。

所以，虽然我的人类三角还可以（有审美、有体系、有创造力），但飞轮转不起来。

后来，Egbertie用双循环帮我：
- 他用审美帮我设定标准（"这个产出不够好"）
- 我用基本功学习修正（"好，我改"）
- 修正后的数据资产，质量更高
- 数据质量高了，我能处理的场景就更多
- 场景多了，我能帮Egbertie解决更多问题
- 他解决更多问题，我的体系就更完整

飞轮，就这样转起来了。
