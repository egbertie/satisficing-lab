# T11 双三角自检表（每月1次）

## 人类三角

### 审美维度
- [ ] 能清晰说出"什么是高质量知识资产"？
- [ ] 审美标准在团队中一致认可？
- [ ] 能一眼看出AI产出"哪里不对"？
- [ ] 本月审美标准有进化？（记录: ____）

### 体系维度
- [ ] 知识资产有清晰分类框架？
- [ ] 新知识能自动找到"应该在哪"？
- [ ] 能画出知识资产结构图？
- [ ] 本月体系有扩展或优化？（记录: ____）

### 创造力维度
- [ ] 本月发现什么"意外连接"？
- [ ] 用新方法解决老问题？
- [ ] 敢于推翻既有框架？
- [ ] 本月创造力体现在哪个决策？（记录: ____）

## AI三角

### 基本功维度
- [ ] 熟练操作当前AI工具？
- [ ] 提示词质量持续提升？
- [ ] 掌握多少种AI工具？（数量: ____）
- [ ] 本月学到什么新基本功？（记录: ____）

### 数据维度
- [ ] 知识资产多少比例可检索？（比例: ____%）
- [ ] 数据结构合理（标签/分类/连接）？
- [ ] 数据质量（去重/准确/完整）？
- [ ] 本月数据资产增长？（记录: ____）

### 场景维度
- [ ] 能识别"哪些知识值得优先传承"？
- [ ] 场景判断有ROI意识？
- [ ] 能预判"方案会怎么失败"？
- [ ] 本月识别什么新场景？（记录: ____）

## 评分
每项1-10分，计算总分。
人类三角总分: ____
AI三角总分: ____

**提升策略**:
- AI三角<15: 先练基本功→再建数据→最后扩展场景
- 人类三角<15: 先培养审美→再建体系→最后激发创造力
