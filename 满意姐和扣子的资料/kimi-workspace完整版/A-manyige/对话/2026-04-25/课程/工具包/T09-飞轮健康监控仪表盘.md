# T09 飞轮健康监控仪表盘

## 5个核心指标

### 1. 信息就绪度
- 接到任务→准备好执行的时间
- 🟢 优秀: <10分钟
- 🟡 良好: 10-30分钟
- 🔴 警告: >30分钟

### 2. 初稿质量水平
- 初稿vs定稿的修改量
- 🟢 优秀: 措辞级修改
- 🟡 良好: 少量结构级
- 🔴 警告: 大量方向级

### 3. 时间再分配
- 检索时间 vs 创造时间
- 🟢 优秀: 检索<20%，创造>50%
- 🟡 良好: 检索20-40%，创造30-50%
- 🔴 警告: 检索>40%，创造<30%

### 4. 新人成长曲线
- 新人达到独立运行的时间
- 🟢 优秀: <30天
- 🟡 良好: 30-60天
- 🔴 警告: >60天

### 5. 知识幸存能力
- 核心人员离职，关键判断是否已固化
- 🟢 优秀: ≥80%已固化
- 🟡 良好: 50-80%
- 🔴 警告: <50%

## 检查频率
- **每月健康检查**: 最后一个周五，1小时
- **每季度深度审计**: 最后一周，半天
- **每年范式校准**: 年初，1天

## 维护策略
| 故障 | 原因 | 修复 |
|:-----|:-----|:-----|
| 飞轮停了 | 核心人员离职 | 紧急传承模式 |
| 飞轮慢 | 交汇频率低 | 增加同步会 |
| 转向错 | AI偏离 | 加强验证 |
| 噪音大 | 冲突未解决 | 建立裁决机制 |
| 发热 | 知识过载 | 增加AI能力或降速 |
