# 模块06口播稿：双轨并行——团队级的90天协同传承

> **时长**: 30分钟口播
> **风格**: 架构讲解+操作流程+协同机制
> **目标**: 让L2团队级听众理解双轨并行，建立团队知识传承流程

---

## 开场（2分钟）

上一节课，我们聊了个人级的六阶段渐进。

今天这节课，进入团队级。如果你负责一个5到20人的团队，或者你是一个部门的知识管理员，这节课是为你准备的。

团队传承和个人传承最大的区别是什么？

**不是规模，是协同。**

一个人干，你只需要对自己负责。团队干，你需要让多个人、多条轨道，同时运转，还要对账。

## 双轨架构（5分钟）

双轨并行，顾名思义，两条轨道同时跑：

**人类轨道（教授团）**：负责萃取、验证、映射、编码。
**AI轨道（小白群）**：负责入库、连接、产出、启动。

```
人类轨道（教授团）              AI轨道（小白群）
├─ 轨道1: 专家萃取              ├─ 轨道1: 结构化入库
│   ├─ 每周1次专家访谈          │   ├─ 每日批量处理
│   ├─ 关键决策录音→转录        │   ├─ 自动去重+分类
│   └─ "为什么这样决策"追问     │   └─ 生成初步摘要
│                              │
├─ 轨道2: 经验验证              ├─ 轨道2: 连接建立
│   ├─ 多专家交叉验证           │   ├─ 自动知识图谱
│   ├─ 冲突标记+待裁决          │   └─ 空白识别
│   └─ 形成"共识区"和"争议区"    │
│                              │
├─ 轨道3: 关系映射              ├─ 轨道3: 血液化产出
│   ├─ 画出"谁和谁讨论什么"网络  │   ├─ SOP片段生成
│   └─ 识别非正式沟通渠道       │   ├─ 模板自动生成
│                              │
└─ 轨道4: 文化编码              └─ 轨道4: 飞轮启动
    ├─ "我们在这里怎么做决定"      ├─ 团队共享知识库
    ├─ "不能明说的规则"            ├─ 新人上手速度提升
    └─ "谁值得信赖"                └─ 跨项目复用率提升
```

## 人类轨道详解（6分钟）

### 轨道1：专家萃取

每周1次，每次1小时，访谈团队里的专家。

不是"你做了什么"，是"你为什么这么做"。

关键问题：
- "当时你面对的选择有哪些？"
- "为什么选了A而不是B？"
- "如果重来一次，你会怎么做？"
- "有什么是你当时不知道、但后来知道的？"

产出：结构化访谈纪要 + 决策逻辑图谱。

### 轨道2：经验验证

多专家交叉验证。

同一个问题，问两个专家。如果他们的答案一致，进入"共识区"。如果不一致，标记为"争议区"，等待裁决。

产出：共识区清单 + 争议区清单（附裁决逻辑）。

### 轨道3：关系映射

画出团队的关系网。

不是组织架构图，是"谁和谁讨论什么"。

示例：
- 张三和李四：经常讨论技术方案
- 王五和赵六：只在项目结束时交流
- 所有人：每周五下午非正式聚会

产出：关系网络图 + 非正式沟通渠道清单。

### 轨道4：文化编码

把"我们在这里怎么做决定"写成文档。

包括：
- 正式的决策流程
- 不能明说的规则（比如"大事必须找老板过目"）
- 谁值得信赖（ expertise map ）

产出：文化手册。

## AI轨道详解（6分钟）

### 轨道1：结构化入库

每日批量处理。

不是"今天处理10个文件"，是"按优先级处理"。

优先级标准：
- P0：核心骨架（S级），必须今天处理
- P1：关键血肉（A级），本周处理
- P2：过程记录（B级），本月处理
- P3：文化基因（隐性），持续处理

产出：结构化知识库。

### 轨道2：连接建立

自动知识图谱。

不是手动一个个连接，是AI自动识别：
- 这个文件和那个文件有没有共同关键词？
- 这个人和那个人有没有共同项目？
- 这个知识点和那个知识点有没有引用关系？

产出：知识图谱 + 空白识别报告。

### 轨道3：血液化产出

SOP片段 + 模板自动生成。

不是"这里有份资料"，是"如果遇到X，执行Y"。

AI根据已入库的知识，自动生成：
- 常见任务的标准操作流程
- 项目启动模板
- 会议纪要模板
- 决策检查表

产出：可执行任务指令库。

### 轨道4：飞轮启动

团队共享知识库 + 新人上手速度提升 + 跨项目复用率提升。

验证指标：
- 新人上手时间：从60天缩短到30天？
- 同类任务复用率：从20%提升到60%？
- 知识查找时间：从30分钟缩短到5分钟？

## 关键机制：双周同步会（6分钟）

每两周一次，人类轨道和AI轨道对账。

**议程**：

1. **AI展示（5分钟）**
   - 本周入库了多少份
   - 发现了多少连接
   - 识别了多少空白
   - 产出了多少血液化成果

2. **人类验证（10分钟）**
   - 抽查2-3个AI产出
   - 判断：准确 / 需修正 / 不适用
   - 指出AI遗漏了什么

3. **冲突处理（5分钟）**
   - AI发现冲突：A说X，B说Y
   - 人类裁决：支持X / 支持Y / 待验证
   - 记录裁决逻辑

4. **优先级调整（5分钟）**
   - 下周重点处理什么
   - 有什么紧急插入
   - 有什么可以暂停

5. **飞轮检查（5分钟）**
   - 新人上手时间：缩短 / 持平 / 延长
   - 同类任务复用率：提升 / 持平 / 下降
   - 知识查找时间：缩短 / 持平 / 延长

**产出**：双周同步会议纪要 + 下两周行动计划。

## 双三角在双轨中的映射（3分钟）

| 维度 | 人类轨道 | AI轨道 |
|:-----|:---------|:-------|
| 审美 | 设定质量标准 | 执行一致性检查 |
| 体系 | 设计传承路径 | 维护知识图谱 |
| 创造力 | 解决冲突、设计新流程 | 识别新模式、生成创意 |
| 基本功 | 访谈技巧、验证方法 | AI工具操作、自动化 |
| 数据 | 提供原始经验 | 结构化处理、建立连接 |
| 场景 | 判断优先级 | 识别应用场景 |

## 本模块行动：启动你的双轨（1分钟）

如果你处于L2，现在就开始：

1. 确定人类轨道的"教授团"（1-2名专家）
2. 确定AI轨道的"操作员"（1名AI管理员）
3. 设定第一次双周同步会的时间
4. 完成第一次专家访谈
