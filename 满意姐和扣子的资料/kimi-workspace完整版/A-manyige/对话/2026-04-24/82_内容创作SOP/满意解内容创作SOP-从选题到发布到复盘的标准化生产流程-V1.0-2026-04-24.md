## 二、选题流程

### 选题来源

| 来源 | 方式 | 优先级 |
|:-----|:-----|:-------:|
| **学员问题** | 收集学员高频问题 | P0 |
| **热点结合** | 结合时事讲决策 | P0 |
| **案例更新** | 新案例、新故事 | P1 |
| **课程精华** | 14模块内容拆解 | P1 |
| **竞品空白** | 竞品没讲过的 | P1 |
| **数据驱动** | 高互动内容的延伸 | P2 |
| **节日节气** | 结合节日讲决策 | P2 |

### 选题评审

```
Step 1: 选题收集
  → 每周一，内容团队提交选题
  → 每人至少3个

Step 2: 选题评审会
  → 每周一 14:00
  → 参会：内容运营+Egbertie+满意姐
  → 评审标准：
    1. 是否符合品牌调性？
    2. 是否有传播潜力？
    3. 是否有教育价值？
    4. 是否能导向产品？

Step 3: 选题确定
  → 本周确定7个选题
  → 分配负责人
  → 确定发布时间
```

## 三、创作流程

### 文章创作SOP

```
Day 1: 大纲（1小时）
  → 标题3选1
  → 结构：引言-正文-总结-CTA
  → 金句预留位

Day 2: 初稿（2小时）
  → 按大纲写作
  → 不求完美，先完成

Day 3: 修改（1小时）
  → 自查清单
  → 品牌一致性检查
  → 互评（另一位编辑看）

Day 4: 排版+发布（1小时）
  → 排版
  → 配图
  → 预览
  → 定时发布
```

### 自查清单

```
□ 标题：有吸引力，不标题党
□ 开头：前3句抓住注意力
□ 金句：至少3句值得被记住的话
□ 结构：逻辑清晰，段落分明
□ 案例：至少1个真实案例
□ CTA：结尾有明确的行动号召
□ 品牌：提及五维框架或满意解
□ 温度：读起来像人对人说话
□ 字数：符合平台要求
□ 配图：至少3张高质量图片
```

## 四、发布流程

### 发布前检查

```
□ 标题：无错别字，标点正确
□ 正文：无错别字，格式统一
□ 链接：所有链接可点击
□ 图片：清晰，无水印，有版权
□ 排版：手机预览正常
□ 定时：设置正确的发布时间
□ 标签：添加合适的标签/话题
```

### 发布后动作

```
发布后30分钟：
  → 检查是否正常显示
  → 回复前3条评论

发布后2小时：
  → 分享到其他平台
  → 转发到社群

发布后24小时：
  → 数据统计
  → 互动回复
  → 记录表现
```

## 五、数据复盘

### 每周复盘

```
时间：每周一 10:00
内容：

1. 上周内容表现
   - 阅读量/播放量
   - 互动量（赞/评/转）
   - 转化率（内容→产品）

2. Top 3 表现最好
   - 为什么好？
   - 可复制吗？

3. Bottom 3 表现最差
   - 为什么差？
   - 怎么改进？

4. 本周优化方向
   - 选题调整
   - 形式调整
   - 发布时间调整
```

### 每月复盘

```
时间：每月1日
内容：

1. 月度数据总览
2. 内容类型效果对比
3. 平台效果对比
4. 下月内容日历
5. 下月重点选题
```

## 六、AI辅助创作
