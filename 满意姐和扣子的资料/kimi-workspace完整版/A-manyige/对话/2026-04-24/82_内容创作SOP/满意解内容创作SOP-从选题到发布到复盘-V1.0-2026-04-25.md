## 第一步：选题（每日30分钟）

### 1.1 选题来源（6大渠道）

```
【渠道1：用户问题】（占比30%）
├─ 社群提问：收集学员/用户常问的问题
├─ 咨询记录：1v1咨询中高频出现的问题
├─ 评论反馈：各平台评论区的疑问
└─ 选题示例：
    "合伙人要退出，股权怎么回购？"
    "如何开一次有效的合伙人会议？"
    "合伙人价值观分歧，还能继续吗？"

【渠道2：案例库】（占比25%）
├─ 84份案例库：每个案例可以改编为多篇内容
├─ 学员故事：成功案例、失败教训
└─ 选题示例：
    "Type05股权分配冲突：他们如何用动态股权框架化解？"
    "学员故事：从合伙人反目到重归于好"

【渠道3：热点借势】（占比15%）
├─ 行业新闻：知名公司合伙人变动
├─ 社会热点：与创业/决策相关的热点
├─ 节日节气：结合节日做主题内容
└─ 选题示例：
    "XX公司创始人反目：从满意解视角看，哪里出了问题？"
    "春节回家，如何和合伙人'和平分手'？"

【渠道4：方法论拆解】（占比20%）
├─ 五维决策框架：每个维度可以写多篇
├─ 12类型冲突：每种类型可以写多篇
├─ 工具使用：每个工具可以写使用指南
└─ 选题示例：
    "土·伦理底座：合伙人价值观评估清单"
    "决策权矩阵：如何设计？如何填写？"

【渠道5：竞争对手】（占比5%）
├─ 竞品内容分析：他们写什么，我们差异化
├─ 行业空白：他们没写的，我们填补
└─ 选题示例：
    "为什么麦肯锡不解决合伙人关系问题？"
    "心理咨询 vs 满意解：有什么区别？"

【渠道6：AI生成】（占比5%）
├─ 使用AI（满意姐）生成选题建议
├─ 输入："生成10个关于合伙人沟通的选题"
└─ 筛选：人工筛选最有价值的5个
```

### 1.2 选题评估标准

```
【5维选题评估】

维度1：用户需求（权重30%）
├─ 这个问题有多少人有？
├─ 用户有多痛？
└─ 评分：1-10

维度2：内容价值（权重25%）
├─ 读完有收获吗？
├─ 能给出具体建议/工具吗？
└─ 评分：1-10

维度3：传播潜力（权重20%）
├─ 标题有吸引力吗？
├─ 容易引发共鸣/讨论吗？
└─ 评分：1-10

维度4：品牌关联（权重15%）
├─ 能自然植入满意解吗？
├─ 能展示专业度吗？
└─ 评分：1-10

维度5：创作难度（权重10%）
├─ 创作需要多少时间？
├─ 有现成素材吗？
└─ 评分：1-10（越高越容易）

【总分计算】
总分 = 需求×0.3 + 价值×0.25 + 传播×0.2 + 品牌×0.15 + 难度×0.1

【决策标准】
├─ 总分≥8：立即创作
├─ 总分6-7：排队创作
├─ 总分<6：放弃或改造
```

### 1.3 选题库管理

```
【选题库结构】

待创作队列（30个选题）
├─ 高优先级（10个）：本周创作
├─ 中优先级（10个）：下周创作
└─ 低优先级（10个）：备用选题

选题库来源：
├─ 腾讯文档/Notion/飞书多维表格
├─ 字段：选题标题、来源、评分、状态、平台、责任人
└─ 每周一更新，每月清理

【选题日历】
├─ 每月最后一天：确定下月选题（30个）
├─ 每周一：确定本周选题（7-10个）
└─ 每日早上：确定当日选题（1-2个）
```

## 第二步：创作（每篇30-120分钟）

### 2.1 创作流程

```
【Step 1：大纲（5分钟）】
├─ 确定文章结构
├─ 常用结构：
│   A. 故事型：场景→冲突→转折→解决→总结
│   B. 干货型：问题→方法论→步骤→案例→工具
│   C. 观点型：现象→分析→观点→论证→呼吁
│   D. 清单型：引言→清单1-5→总结→CTA
└─ 输出：100字大纲

【Step 2：初稿（15-60分钟）】
├─ 快速写作，不停顿
├─ 不追求完美，先完成
├─ 使用AI辅助（满意姐）：输入大纲，生成初稿
└─ 输出：完整初稿

【Step 3：修改（10-30分钟）】
├─ 检查逻辑：结构清晰？论证有力？
├─ 检查语言：口语化？有温度？无错别字？
├─ 检查CTA：自然植入？不硬推销？
├─ 检查金句：有记忆点？易传播？
└─ 输出：修改稿

【Step 4：排版（5-10分钟）】
├─ 标题：优化标题（使用标题公式）
├─ 段落：短段落，每段不超过3行
├─ 重点：加粗/高亮关键信息
├─ 配图：插入信息图/截图/插图
├─ CTA：文末添加行动引导
└─ 输出：排版稿

【Step 5：审核（5-10分钟）】
├─ 自审：作者自己检查
├─ 蓝军审：AI审核（事实核查/风险检查）
├─ 终审：Egbertie抽查（重要内容）
└─ 输出：终稿
```

### 2.2 标题公式

```
【公式1：数字+痛点+承诺】
"合伙人评估，我只看5个维度"
"股权分配的3个常见错误"
"合伙人会议的5个高效技巧"

【公式2：场景+情绪+悬念】
"凌晨2点，合伙人发来这条消息..."
"创业第3年，我终于找到了有温度的AI"
"合伙人突然要退出，我该怎么办？"

【公式3：数据+震惊+问题】
"73%的创业公司死于合伙人冲突"
"65%的合伙人关系在3年内破裂"
"花了300万买来的教训"

【公式4：对比+差异+好奇】
"麦肯锡不解决合伙人问题，满意解可以"
"心理咨询 vs 满意解：有什么区别？"
"为什么最好的合伙人不是能力最强的？"

【公式5：提问+共鸣+答案】
"你的合伙人关系，有这5个预警信号吗？"
"合伙人价值观分歧，还能继续吗？"
"如何评估合伙人是否合适？"

【标题测试】
├─ 写出3个备选标题
├─ 内部投票（团队成员）
├─ 或A/B测试（2个标题同时发，看数据）
└─ 选择点击率最高的
```

---

### 2.3 内容质量标准

```
【7项质量检查清单】

1. 开头钩子（0-10秒抓住注意力）
   □ 有故事/数据/问题/冲突
   □ 让用户想继续读
   □ 评分：1-10（目标≥8）

2. 价值密度（每100字有1个价值点）
   □ 有干货/工具/案例/洞察
   □ 用户读完有收获
   □ 评分：1-10（目标≥8）

3. 逻辑清晰（结构合理，论证有力）
   □ 段落之间有逻辑关系
   □ 论点有论据支撑
   □ 评分：1-10（目标≥7）

4. 语言温度（不冷冰冰，有人情味）
   □ 有情感共鸣点
   □ 有"我"的故事/经历
   □ 评分：1-10（目标≥7）

5. 金句点缀（有记忆点，易传播）
   □ 至少1个金句
   □ 金句简短有力
   □ 评分：1-10（目标≥6）

6. CTA自然（不硬推销，有价值引导）
   □ CTA与内容相关
   □ 给用户明确行动
   □ 评分：1-10（目标≥7）

7. 无硬伤（无错别字、无事实错误、无风险）
   □ 蓝军审核通过
   □ 无敏感信息
   □ 评分：通过/不通过（必须通过）

【总分标准】
├─ 总分≥50：优秀，可发布
├─ 总分40-49：良好，小修改后发布
├─ 总分<40：不合格，重写或放弃
```

## 第三步：审核（每篇5-10分钟）

### 3.1 三级审核制度

```
【一级：自审（作者）】
├─ 检查清单：7项质量检查
├─ 修改：根据清单修改
└─ 通过：自评≥40分，进入二审

【二级：蓝军审（AI审核）】
├─ 事实核查：数据、案例、引用是否准确
├─ 风险检查：有无敏感信息、法律风险、品牌风险
├─ 语法检查：错别字、标点、格式
├─ 一致性检查：与品牌调性、已有内容是否一致
└─ 通过：无硬伤，进入三审

【三级：终审（Egbertie）】
├─ 重要内容（品牌相关、重大发布）终审
├─ 抽查：普通内容抽查10%
├─ 决策：通过/修改/驳回
└─ 通过：可发布
```

---

### 3.2 蓝军审核清单

```
【事实核查】
├─ 数据来源是否可靠？
├─ 案例是否真实？（脱敏处理）
├─ 引用是否准确？
├─ 法律术语是否正确？
└─ 如有疑问，标注"待核实"

【风险检查】
├─ 有无敏感政治内容？
├─ 有无歧视/攻击内容？
├─ 有无泄露用户隐私？
├─ 有无贬低竞争对手？（是否客观）
├─ 有无过度承诺？（"保证100%解决"→改）
└─ 如有风险，标注"风险"并建议修改

【品牌一致性】
├─ 是否符合满意解品牌调性？
├─ 五维框架表述是否一致？
├─ 金句使用是否准确？
├─ CTA是否统一？
└─ 如有不一致，标注"不一致"并建议修改

【法律合规】
├─ 有无虚假宣传？
├─ 有无侵权内容？
├─ 有无违规承诺？
├─ 符合广告法吗？
└─ 如有问题，标注"法律风险"并建议修改
```

## 第四步：发布（每篇5分钟）

### 4.1 发布流程

```
【Step 1：平台选择】
├─ 根据内容类型选择平台
├─ 故事型 → 小红书+公众号
├─ 干货型 → 知乎+公众号
├─ 短视频 → 抖音+视频号
├─ 音频 → 播客
└─ 互动型 → 小红书+社群

【Step 2：格式适配】
├─ 小红书：短文案+9图/视频+标签
├─ 公众号：长文+排版+配图+封面
├─ 抖音：视频+字幕+标题+话题
├─ 知乎：问答/文章+结构化排版
├─ 播客：音频+封面+简介
└─ 社群：简化版+互动引导

【Step 3：发布检查】
├─ 标题：无错别字，吸引人
├─ 封面：清晰、美观、符合平台规范
├─ 正文：排版正确，链接有效
├─ CTA：明确、可执行
├─ 标签/话题：相关、热门
└─ 发布时间：符合最佳时间

【Step 4：发布后】
├─ 10分钟内：检查是否正常显示
├─ 30分钟内：回复早期评论
├─ 2小时内：监控数据（阅读量/互动）
└─ 24小时内：总结数据
```

### AI辅助创作流程

```
【Step 1：AI生成选题】
提示词：
"你是满意解决策教练的内容策划。
请基于'合伙人决策'主题，生成10个选题。
要求：
1. 有痛点共鸣
2. 有干货价值
3. 适合小红书/公众号/抖音
4. 每个选题给出标题和简述"
```
