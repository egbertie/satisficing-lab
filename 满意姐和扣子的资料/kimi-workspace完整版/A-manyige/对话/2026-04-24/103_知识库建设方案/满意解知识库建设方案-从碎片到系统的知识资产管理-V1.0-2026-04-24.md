---

## 一、知识库架构

### 五层知识库

```
Level 1: 原始素材
  → 对话记录、会议纪要、调研笔记
  → 未经加工的一手资料

Level 2: 整理归档
  → 分类、标签、摘要
  → 可检索的文档

Level 3: 方法论提炼
  → 从实践中提炼的方法
  → 可复制、可教学

Level 4: 产品化知识
  → 课程、工具、模板
  → 可直接使用

Level 5: 品牌资产
  → 论文、书籍、标准
  → 行业影响力
```

## 三、知识管理流程

### 知识生命周期

```
Step 1: 收集
  → 每日：对话、会议、灵感
  → 每周：案例、反馈、数据
  → 每月：报告、总结、复盘

Step 2: 整理
  → 分类：归入对应类别
  → 标签：打标签便于检索
  → 摘要：提炼核心要点

Step 3: 审核
  → 准确性：事实核查
  → 完整性：是否全面
  → 保密性：是否涉密

Step 4: 存储
  → 命名规范
  → 版本管理
  → 备份策略

Step 5: 共享
  → 权限设置
  → 检索系统
  → 推送机制

Step 6: 复用
  → 课程开发
  → 产品迭代
  → 品牌传播
```

## 五、知识共享

### 共享机制

```
内部共享：
- 全员可访问：品牌素材、运营SOP
- 部门级：教研资料、技术文档
- 核心层：战略、财务、人事

外部共享（有限）：
- 学员：课程资料、工具模板
- 导师：教学资料、案例库
- 合作伙伴：品牌素材、合作指南
```
