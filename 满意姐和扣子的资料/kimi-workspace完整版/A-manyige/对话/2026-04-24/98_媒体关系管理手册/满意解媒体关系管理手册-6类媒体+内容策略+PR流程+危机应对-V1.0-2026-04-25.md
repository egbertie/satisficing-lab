## 第一部分：媒体分类

### 1.1 媒体类型

```
【类型1：科技/创业媒体】
├─ 代表：36氪、创业邦、虎嗅、钛媒体
├─ 特点：关注创新、创业公司
├─ 内容：公司动态、融资、产品
├─ 频率：每月1-2次
├─ 价值：创业圈曝光
└─ 维护：PR主动推送

【类型2：财经/商业媒体】
├─ 代表：财新、第一财经、哈佛商业评论
├─ 特点：关注商业模式、管理
├─ 内容：方法论、案例、行业洞察
├─ 频率：每季度1次
├─ 价值：商业圈权威
└─ 维护：深度内容合作

【类型3：行业垂直媒体】
├─ 代表：硬科技、创投圈、法律科技
├─ 特点：垂直领域深度
├─ 内容：专业内容、行业报告
├─ 频率：每月1次
├─ 价值：精准获客
└─ 维护：专家合作

【类型4：自媒体/KOL】
├─ 代表：行业大V、公众号、播客
├─ 特点：个人影响力、互动性强
├─ 内容：推荐、评测、访谈
├─ 频率：持续合作
├─ 价值：精准触达、信任度高
└─ 维护：内容合作、互推

【类型5：视频/直播媒体】
├─ 代表：抖音、视频号、B站
├─ 特点：视觉化、传播快
├─ 内容：短视频、直播、访谈
├─ 频率：每周1-2次
├─ 价值：广泛传播
└─ 维护：内容供应

【类型6：学术媒体】
├─ 代表：学术期刊、会议、论文
├─ 特点：学术严谨、长期价值
├─ 内容：研究成果、方法论
├─ 频率：每年1-2篇
├─ 价值：学术权威
└─ 维护：研究合作
```

## 第二部分：内容策略

### 2.1 内容类型

```
【类型1：公司新闻】
├─ 内容：融资、产品发布、重大合作
├─ 形式：新闻稿
├─ 频率：有新闻时
├─ 渠道：全渠道发布
└─ 目标：告知市场

【类型2：深度文章】
├─ 内容：方法论、行业洞察、案例
├─ 形式：3000-5000字长文
├─ 频率：每月2-4篇
├─ 渠道：公众号、知乎、媒体投稿
└─ 目标：建立专业形象

【类型3：行业报告】
├─ 内容：白皮书、数据报告
├─ 形式：PDF报告
├─ 频率：每季度1份
├─ 渠道：媒体合作发布
└─ 目标：行业影响力

【类型4：专家观点】
├─ 内容：Egbertie对热点事件的评论
├─ 形式：短评、采访
├─ 频率：热点时
├─ 渠道：媒体采访、社交媒体
└─ 目标：提升个人IP

【类型5：案例故事】
├─ 内容：用户成功案例
├─ 形式：文章、视频
├─ 频率：每月1-2个
├─ 渠道：媒体投稿、自有渠道
└─ 目标：口碑传播

【类型6：工具内容】
├─ 内容：测评、工具、模板
├─ 形式：清单、模板、工具
├─ 频率：每月2-4个
├─ 渠道：小红书、知乎、公众号
└─ 目标：获客引流
```

## 第三部分：PR流程

### 3.1 新闻发布流程

```
【Step 1：策划】
├─ 确定新闻点
├─ 确定目标媒体
├─ 确定发布时间
├─ 准备素材
└─ 产出：PR计划

【Step 2：内容准备】
├─ 新闻稿撰写
├─ 配图准备
├─ 数据核实
├─ 引用确认
└─ 产出：新闻稿+素材包

【Step 3：媒体沟通】
├─ 核心媒体：提前沟通、独家或首发
├─ 主流媒体：同步发布
├─ 垂直媒体：定向推送
├─ KOL：同步配合
└─ 产出：媒体覆盖

【Step 4：发布监控】
├─ 监控发布情况
├─ 收集报道链接
├─ 监测舆情
├─ 二次传播
└─ 产出：报道汇总

【Step 5：效果评估】
├─ 统计报道数量
├─ 统计阅读量
├─ 统计转发量
├─ 监测引流效果
├─ 用户反馈
└─ 产出：PR报告

【Step 6：关系维护】
├─ 感谢记者
├─ 提供后续信息
├─ 建立长期联系
└─ 产出：媒体关系加深
```

---

### 3.2 危机媒体应对

```
【危机发生时】

Step 1：快速响应（1小时内）
├─ 监测：发现负面报道
├─ 评估：影响范围、严重程度
├─ 准备：准备回应材料
├─ 沟通：与核心媒体沟通
└─ 产出：初步回应

Step 2：统一口径（4小时内）
├─ 制定：统一回应口径
├─ 准备：QA文档
├─ 培训：发言人培训
├─ 发布：官方声明
└─ 产出：官方回应

Step 3：主动沟通（24小时内）
├─ 核心媒体：1v1沟通
├─ 提供：事实、数据、解决方案
├─ 争取：公正报道
├─ 建立：信任关系
└─ 产出：媒体理解

Step 4：持续跟进（持续）
├─ 监测：报道动态
├─ 回应：新出现的问题
├─ 更新：进展
├─ 修复：关系修复
└─ 产出：危机平息
```

---

> **核心原则**：
> 媒体关系不是"求报道"，是"供价值"。
>
> 好的媒体关系：
> ├─ 让记者有料可写（内容价值）
> ├─ 让报道客观公正（信任基础）
> ├─ 让关系长期稳定（持续经营）
> └─ 让危机有人帮（平时积累）
>
> 满意解的媒体信仰：
> "让媒体看见我们的价值，让市场听见我们的声音。"
