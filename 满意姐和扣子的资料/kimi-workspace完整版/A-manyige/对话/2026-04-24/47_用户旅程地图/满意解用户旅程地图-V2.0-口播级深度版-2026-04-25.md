## 使用说明

```
🗺️ 满意解用户旅程地图 —— "从陌生人到家人的完整路径"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

为什么需要用户旅程地图？
因为大多数创始人"知道要做什么"，
但不知道"用户在每个阶段的感受"。

用户旅程地图不是"流程图"，
是"情感地图"——
标注用户在每个阶段的：
- 想什么（Thoughts）
- 感受什么（Feelings）
- 做什么（Actions）
- 痛点是什么（Pain Points）
- 我们的机会是什么（Opportunities）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

6个阶段：
1. 认知（Awareness）—— 第一次听说满意解
2. 考虑（Consideration）—— 开始了解满意解
3. 购买（Purchase）—— 决定购买产品
4. 使用（Usage）—— 体验产品/服务
5. 忠诚（Loyalty）—— 持续使用，建立信任
6. 推荐（Advocacy）—— 主动推荐，成为品牌大使

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 阶段一：认知（Awareness）

### 用户画像

```
【典型用户】
姓名：张总（虚构）
年龄：35岁
身份：硬科技公司创始人
痛点：和CTO合伙人最近因为股权分配有分歧
场景：凌晨刷小红书，看到一篇"合伙人冲突"的文章

【用户目标】
找到解决合伙人问题的方法

【用户行为】
刷小红书/知乎/公众号，搜索"合伙人冲突怎么办"

【用户感受】
焦虑（"我们的分歧会不会毁掉公司？"）
+ 希望（"也许有方法能解决"）

【触点】
小红书文章、知乎回答、短视频、播客、朋友推荐
```

---

### 触点设计

```
【触点1：小红书文章】

用户行为：刷到一篇"凌晨2点，合伙人发来这条消息..."
用户感受：共鸣（"我也是这样！"）

我们的行动：
├─ 文章标题：痛点场景化（"凌晨2点..."）
├─ 文章内容：情绪共鸣 + 方法暗示
├─ 文章结尾：CTA（"想知道你和合伙人的匹配度？评论区扣1"）
└─ 评论区运营：及时回复，引导加微信

衡量标准：
├─ 阅读量 > 1000
├─ 点赞率 > 5%
├─ 评论率 > 2%
└─ 加微信转化率 > 10%

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【触点2：短视频】

用户行为：刷到一条"合伙人评估5个维度"的视频
用户感受：好奇（"原来还可以这样评估？"）

我们的行动：
├─ 视频开头：钩子（"73%创业公司死于合伙人冲突"）
├─ 视频中间：干货（5个维度快速讲解）
├─ 视频结尾：CTA（"想要完整测评？评论区扣'测评'"）
└─ 评论区：置顶链接，引导扫码

衡量标准：
├─ 完播率 > 30%
├─ 点赞率 > 5%
├─ 评论率 > 3%
└─ 扫码转化率 > 8%

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【触点3：朋友推荐】

用户行为：朋友在微信上说"你可以试试满意解"
用户感受：信任（"朋友推荐的，应该靠谱"）

我们的行动：
├─ 为老学员提供"推荐话术"（降低推荐门槛）
├─ 推荐奖励机制（推荐人+被推荐人双赢）
└─ 被推荐人专属优惠（"朋友推荐，额外优惠200元"）

衡量标准：
├─ 推荐率 > 15%
├─ 被推荐人转化率 > 40%
└─ 推荐人满意度 > 80%
```

---

### 阶段一痛点与机会

| 痛点 | 机会 | 我们的行动 |
|:-----|:-----|:-----------|
| 信息过载，不知道选谁 | 差异化定位 | "合伙人决策专科医生" |
| 担心被推销 | 免费价值先行 | 免费测评+干货内容 |
| 不信任线上内容 | 真实案例 | 84份真实案例库 |
| 不知道是否适合自己 | 个性化 | "5分钟测评，看清匹配度" |

## 阶段二：考虑（Consideration）

### 用户画像

```
【典型用户】
张总加了我们微信，完成了免费测评

【用户目标】
确认满意解是否能真正帮到自己

【用户行为】
├─ 看测评报告（个性化诊断）
├─ 浏览朋友圈内容（了解专业度）
├─ 看案例故事（验证效果）
├─ 对比其他选择（麦肯锡/心理咨询/其他课程）
└─ 犹豫（"花2999元值不值？"）

【用户感受】
好奇（"这个测评挺准的"）
+ 犹豫（"但真的有用吗？"）
+ 比较（"和其他家有什么区别？"）
```

---

### 触点设计

```
【触点4：测评报告】

用户行为：完成测评，收到个性化报告
用户感受：惊讶（"原来我们最弱的是信任维度！"）

我们的行动：
├─ 报告内容：具体得分 + 薄弱维度分析 + 3个行动建议
├─ 报告设计：视觉化（雷达图+色彩标注）
├─ 报告结尾：CTA（"想要完整解决方案？预约15分钟免费咨询"）
└─ 跟进：3天后发送"薄弱维度"的干货文章

衡量标准：
├─ 报告打开率 > 80%
├─ 报告阅读完成率 > 60%
├─ 预约咨询率 > 20%
└─ 7天内付费转化率 > 10%

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【触点5：朋友圈内容】

用户行为：翻看Egbertie朋友圈，了解这个人/品牌
用户感受：信任积累（"他每天分享干货，不是广告"）

我们的行动：
├─ 每日2-3条朋友圈（干货40%+故事40%+互动20%）
├─ 展示真实案例（脱敏处理后分享）
├─ 展示学员反馈（截图/视频）
└─ 展示个人生活（适度，建立人设）

衡量标准：
├─ 朋友圈点赞率 > 5%
├─ 评论互动率 > 2%
├─ 私信咨询率 > 1%
└─ 朋友圈→付费转化率 > 3%

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【触点6：1v1免费咨询】

用户行为：预约并参加15分钟免费咨询
用户感受：被重视（"创始人亲自给我诊断"）

我们的行动：
├─ 咨询前：了解用户背景，准备个性化建议
├─ 咨询中：真诚帮助，不推销，先给价值
├─ 咨询后：发送总结邮件+相关资料
└─ 跟进：3天后询问"建议是否有帮助"

衡量标准：
├─ 咨询到场率 > 80%
├─ 用户满意度 > 90%
├─ 咨询→付费转化率 > 30%
└─ 咨询→推荐率 > 10%
```

---

### 阶段二痛点与机会

| 痛点 | 机会 | 我们的行动 |
|:-----|:-----|:-----------|
| 不知道效果怎样 | 案例验证 | 84份案例+学员视频见证 |
| 担心买了没用 | 退款保障 | "不满意全额退款" |
| 价格犹豫 | 价值量化 | "ROI 15-50倍" |
| 怕推销 | 无压力咨询 | "15分钟免费咨询，不推销" |

## 阶段三：购买（Purchase）

### 用户画像

```
【典型用户】
张总决定购买CDA初级课程（2999元）

【用户目标】
顺利完成购买，开始课程

【用户行为】
├─ 点击购买链接
├─ 填写信息
├─ 支付
├─ 等待确认
└─ 开始第一模块

【用户感受】
期待（"希望能解决我的问题"）
+ 紧张（"花了2999，会不会不值？"）
+ 兴奋（"终于要开始了！"）
```

---

### 触点设计

```
【触点7：购买页面】

用户行为：点击购买链接，浏览课程详情

我们的行动：
├─ 页面设计：清晰展示课程大纲、讲师介绍、学员评价
├─ 价格展示：原价vs优惠价，限时倒计时
├─ 信任背书：认证证书样本、学员成功案例
├─ 支付便利：微信支付/支付宝/信用卡
└─ 支付后：立即发送确认邮件+学习指南

├─ 页面转化率 > 15%
├─ 支付成功率 > 95%
├─ 支付放弃率 < 20%
└─ 支付后24小时内开始率 > 70%

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【触点8：支付后欢迎】

用户行为：支付成功，收到欢迎邮件/消息

我们的行动：
├─ 即时确认：支付成功页面+邮件+微信消息

├─ 欢迎邮件打开率 > 80%

【触点9：开始学习】

用户行为：打开第一模块，开始学习
用户感受：好奇（"内容质量如何？"）

我们的行动：
├─ 第一模块设计：短小精悍（15-20分钟），降低门槛

├─ 进度追踪：可视化进度条
└─ 完成奖励：模块完成证书/积分

衡量标准：
├─ 第一模块完课率 > 70%
├─ 模块测验通过率 > 80%
├─ 学员满意度 > 85%
└─ 当日继续学习率 > 40%
```

## 阶段四：使用（Usage）

### 用户画像

```
【典型用户】
张总正在学习CDA初级课程，进行到第5模块

【用户目标】
学完课程，解决合伙人问题

【用户行为】
├─ 每周学习2-3个模块
├─ 做模块测验
├─ 在社群提问
├─ 尝试用工具解决实际问题
└─ 遇到困难时寻求帮助

【用户感受】
充实（"学到了很多"）
+ 挑战（"有些内容挺难的"）
+ 成就（"测验通过了！"）
+ 焦虑（"学完了能解决我的问题吗？"）
```

---

### 触点设计

```
【触点10：学习过程】

用户行为：学习模块，完成测验
用户感受：成长（"我懂了！"）

我们的行动：
├─ 内容设计：理论+案例+工具+练习

├─ 模块完课率 > 70%

├─ 测验通过率 > 80%

衡量标准：
├─ 社群活跃率 > 30%
├─ 提问解决率 > 90%
├─ 学员互评满意度 > 85%
└─ 社群→复购转化率 > 15%

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【触点12：实战应用】

用户行为：用学到的工具解决合伙人问题
用户感受：成就感（"真的有用！"）

我们的行动：
├─ 工具包：提供可打印/可填写的工具模板
├─ 实战指导：如何用工具解决具体问题
├─ 案例库：84份案例对照学习
├─ 反馈收集："你用工具解决了什么问题？"
└─ 成功展示：征得同意后，作为案例分享

衡量标准：
├─ 工具使用率 > 60%
├─ 实战问题解决率 > 70%
├─ 用户满意度 > 85%
└─ 成功案例收集率 > 20%
```

```
├─ 节日问候：生日/节日祝福+优惠券
├─ 新内容推送：新课程/新工具/新案例
├─ 复购触发：检测到新痛点时推荐对应产品
└─ 一对一关怀：高价值用户定期电话问候

衡量标准：
├─ 邮件打开率 > 40%
├─ 复购率 > 25%
├─ 用户流失率 < 10%/年
└─ NPS > 50
```
