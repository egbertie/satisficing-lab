## 第一部分：活动类型

### 1.1 城市Meetup

```
【活动信息】
├─ 时长：2小时（19:00-21:00）
├─ 人数：20-50人
├─ 频率：每月1次/城市
├─ 费用：免费或99元（含茶歇）
└─ 地点：联合办公空间/咖啡馆

【活动流程】

19:00-19:15 签到
├─ 签到台：品牌物料
├─ 资料袋：名片+介绍+小礼品
├─ 引导入座
└─ 背景音乐

19:15-19:30 开场
├─ 主持人开场
├─ 破冰：每人30秒自我介绍
├─ 主题介绍
└─ 规则说明

19:30-20:15 主题分享
├─ Egbertie/导师分享
├─ 案例解析
├─ 方法论介绍
└─ 互动提问

20:15-20:45 小组讨论
├─ 分组：4-6人/组
├─ 话题：与主题相关
├─ 讨论：15分钟
└─ 分享：每组2分钟

20:45-21:00 收尾
├─ 总结要点
├─ 预告下次活动
├─ 推荐课程/咨询
├─ 合影
└─ 自由交流

【物料清单】
├─ 背景板：品牌背景
├─ 易拉宝：2个
├─ 资料袋：名片+宣传单+小礼品
├─ 签到表：姓名+公司+联系方式
├─ 茶歇：饮料+小食
├─ 相机：拍照+录像
└─ 礼品：决策卡牌/笔记本

【人员分工】
├─ 主讲：Egbertie/导师
├─ 主持：运营
├─ 签到：1人
├─ 摄影：1人
├─ 后勤：1人
└─ 销售：1人（现场转化）
```

### 1.2 主题工作坊

```
【活动信息】
├─ 时长：半天（9:00-12:00 或 14:00-17:00）
├─ 人数：10-20人
├─ 频率：每季度1次
├─ 费用：999-2999元/人
└─ 地点：培训教室/酒店会议室

【活动流程】

开场（30分钟）
├─ 签到
├─ 开场白
├─ 破冰游戏
├─ 议程介绍
└─ 分组

主题讲解（90分钟）
├─ 理论讲解
├─ 案例分析
├─ 工具介绍
└─ 互动问答

实战演练（90分钟）
├─ 小组练习
├─ 导师辅导
├─ 成果展示
└─ 互相点评

总结（30分钟）
├─ 要点回顾
├─ 行动计划
├─ 反馈收集
├─ 合影
└─ 推荐进阶课程

【主题示例】
├─ "合伙人股权设计实战"

├─ "合伙人冲突调解模拟"

【物料清单】
├─ 背景板
├─ 投影设备
├─ 白板+笔
├─ 资料袋（教材+工具+证书）
├─ 茶歇
├─ 证书
└─ 相机
```

## 第二部分：策划流程

### 2.1 策划阶段

```
【Step 1：确定目标】（提前4周）
├─ 品牌目标：提升品牌认知
├─ 获客目标：获取潜在客户
├─ 转化目标：现场成交
├─ 内容目标：生产内容素材
└─ 社群目标：增强用户粘性

【Step 2：确定主题】（提前4周）
├─ 用户调研：用户关心什么
├─ 热点结合：结合时事热点
├─ 品牌关联：与满意解相关
├─ 差异化：与竞品不同
└─ 示例："硬科技创业，合伙人怎么选？"

【Step 3：确定时间地点】（提前3周）
├─ 时间：工作日晚上或周末
├─ 地点：交通便利、环境舒适
├─ 容量：预计人数的1.2倍
├─ 设备：投影、音响、网络
└─ 预算：符合预期

【Step 4：确定嘉宾】（提前3周）
├─ 主讲：Egbertie/导师
├─ 嘉宾：行业专家/成功学员
├─ 主持：运营/志愿者
├─ 确认：提前沟通、确认档期
└─ 准备：提供主题、资料

【Step 5：制定预算】（提前3周）

| 项目 | 金额 | 备注 |
|:-----|:-----|:-----|
| 场地 | 2000 | 含设备 |
| 茶歇 | 1000 | 50人 |
| 物料 | 1500 | 背景板+资料袋 |
| 礼品 | 1000 | 卡牌+笔记本 |
| 宣传 | 1000 | 海报+推广 |
| 人员 | 1000 | 交通+餐饮 |
| 备用 | 500 | 应急 |
| 总计 | 8000 | |

【Step 6：制定流程】（提前2周）
├─ 详细流程表（精确到分钟）
├─ 人员分工表
├─ 物料清单表
├─ 应急预案
└─ 彩排计划

【Step 7：宣传推广】（提前2周）
├─ 海报设计
├─ 文案撰写
├─ 渠道发布
├─ KOL邀请
├─ 老用户邀请
└─ 报名链接

【Step 8：报名管理】（提前1周）
├─ 报名渠道：小程序/公众号
├─ 报名信息：姓名+公司+职位
├─ 确认通知：短信+微信
├─ 提醒：活动前1天、前2小时
└─ 名额管理：限额+候补

【Step 9：现场执行】（当天）
├─ 提前2小时到场布置
├─ 设备测试
├─ 签到接待
├─ 按流程执行
├─ 拍照录像
├─ 现场转化
└─ 收尾清理

【Step 10：复盘总结】（活动后3天）
├─ 数据统计：参与人数、满意度
├─ 财务结算
├─ 内容整理：照片、视频、精华
├─ 二次传播
├─ 用户跟进
└─ 经验总结
```

## 第三部分：现场执行

### 3.1 签到接待

```
【签到台】
├─ 位置：入口处
├─ 布置：品牌背景+签到表+资料袋
├─ 人员：1-2人
├─ 流程：
│   ├─ 核对报名信息
│   ├─ 发放资料袋
│   ├─ 引导签名/合影
│   └─ 引导入座
└─ 时间：活动前30分钟开始

【资料袋内容】
├─ 宣传单：课程介绍
├─ 名片：Egbertie/工作人员
├─ 笔记本：满意解定制
├─ 笔：品牌笔
├─ 卡牌：决策卡牌1张
└─ 反馈表：活动反馈
```

---

### 3.2 现场转化

```
【转化策略】

策略1：现场优惠
├─ 限时优惠：仅限现场
├─ 折扣：8折或立减500
├─ 赠品：送卡牌/咨询
└─ 倒计时：活动结束前

策略2：案例展示
├─ 成功学员分享
├─ 数据展示
├─ 成果对比
└─ 增强信任

策略3：1v1咨询
├─ 现场预约
├─ 免费咨询15分钟
├─ 深度需求挖掘
└─ 促成付费

策略4：团购优惠
├─ 2人成团：各减200
├─ 3人成团：各减300
├─ 现场组队
└─ 促进推荐

【转化流程】
├─ 活动结束→发放优惠码
├─ 24小时内→跟进未转化
├─ 3天内→社群提醒
├─ 7天内→最后机会
└─ 持续→内容培育
```

## 第四部分：应急预案

### 4.1 常见问题

```
【问题1：人数不足】
├─ 预防：提前2周确认、候补机制
├─ 应对：
│   ├─ 放宽报名条件
│   ├─ 邀请老用户
│   ├─ 临时推广
│   └─ 改小场地
└─ 底线：10人以上即举办

【问题2：设备故障】
├─ 预防：提前测试、备用设备
├─ 应对：
│   ├─ 备用投影
│   ├─ 备用电脑
│   ├─ 备用音响
│   └─ 无投影时：口头讲解

【问题3：嘉宾缺席】
├─ 预防：提前确认、备选嘉宾
├─ 应对：
│   ├─ 备选嘉宾顶上
│   ├─ Egbertie亲自讲
│   ├─ 播放录播视频
│   └─ 改为讨论会

【问题4：现场冲突】
├─ 预防：明确规则、主持人控场
├─ 应对：
│   ├─ 主持人介入
│   ├─ 私下沟通
│   ├─ 必要时请离
│   └─ 不影响其他人

【问题5：安全问题】
├─ 预防：场地安全检查、保险
├─ 应对：
│   ├─ 急救箱
│   ├─ 紧急联系人
│   ├─ 疏散路线
│   └─ 保险理赔
```
