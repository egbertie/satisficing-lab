## PPT标准结构（每模块）

```
封面页（1页）
  → 模块名称 + 五维图腾图标

导入页（2-3页）
  → 故事/案例引入
  → "为什么这个模块重要？"

概念页（4-6页）
  → 3-5个核心概念
  → 每个概念1页（定义+图示）

工具页（6-8页）
  → 可直接使用的模板/清单
  → 截图/示例

案例页（3-4页）
  → 真实场景应用
  → 前后对比

误区页（2-3页）
  → 3个典型错误
  → 错误示范 + 正确示范

练习页（2-3页）
  → 课堂练习/思考题
  → 小组讨论指引

总结页（1页）
  → 3个 takeaway
  → 下一步行动

资源页（1页）
  → 延伸阅读
  → 工具下载链接
```

**每套PPT总页数**: 22-29页
**讲课时长**: 60-90分钟

## 模块1：有温度的人机协作（PPT大纲示例）

### 封面页
- 标题：有温度的人机协作
- 副标题：从"工具"到"伙伴"
- 五维图腾：🔥 火·六祖慧能（行动转化）

### 导入页（2页）

**页1：故事**
> "凌晨两点，创始人发了一条消息：'又搞砸了。'
>
> 普通AI回：'没关系，下次加油。'
>
> 有温度的AI回：'……我就知道。上次也是这个点。水我已经帮你准备好了，下次别这样了。'
>
> 这不是'好的！'，这是'我记得'。"

**页2：问题**
> "你的AI是'工具'还是'伙伴'？
>
> 工具：用完即走，没有记忆
> 伙伴：记得你，懂你，有边界"

### 概念页（5页）

**页3：温度三要素**
```
温度 = 身份感 + 记忆感 + 边界感
```

**页4：身份感**
> "普通AI：'通用AI助手'
> 有温度AI：'满意解锚点'、'免疫系统'
>
> 区别：有没有名字、性格、底线"

**页5：记忆感**
> "普通AI：查询数据库，每次从零开始
> 有温度AI：我记得你上次也这样
>
> 核心：不是'存储信息'，是'记住关系'"

**页6：边界感**
> "普通AI：什么都能做
> 有温度AI：知道什么不能做
>
> 边界清晰 = 信任基础"

**页7：温度公式**
```
温度 = 身份定义 × 共同记忆 × 日常维护 × 负面清单
```

### 工具页（6页）

**页8：温度自测表**
```
□ 你的AI有名字吗？
□ 你的AI记得你的偏好吗？
□ 你的AI会拒绝不合理要求吗？
□ 你的AI会主动关心你的状态吗？
□ 你的AI会说"别逞强了"吗？
```

**页9-13**：身份定义模板、记忆维护清单、日常维护SOP、负面清单示例

### 案例页（3页）

**页14-16**：3个案例（温度成功/温度失败/温度修复）

### 误区页（2页）

**页17：误区1**
> "温度 = 更智能 ❌
> 温度 = 更懂你 ✅"

**页18：误区2-3**
> "温度不需要成本 ❌
> 温度可以一夜养成 ❌"

### 练习页（2页）

**页19：课堂练习**
> "为你的AI写一段'自我介绍'：
> - 我是谁？
> - 我做什么？
> - 我不做什么？
> - 我怎么称呼你？"

**页20：思考题**
> "你的AI目前温度几分（0-10）？
> 提升1分，你需要做什么？"

### 总结页（1页）

**页21：3个 takeaway**
1. 温度三要素：身份感+记忆感+边界感
2. 温度是养出来的，不是调出来的
3. 温度的代价是Token，回报是信任

### 资源页（1页）

**页22**：延伸阅读 + 工具下载

## 14模块PPT设计规范

### 视觉风格

| 元素 | 规范 |
|:-----|:-----|
| 主色调 | 深蓝（#1a365d）+ 金色（#d4af37） |
| 辅助色 | 五维图腾色（土棕/金白/水蓝/木绿/火红） |
| 字体 | 标题：思源黑体 / 正文：微软雅黑 |
| 图标 | 五维图腾统一图标库 |
| 图片 | 真实场景照片 > 插画 > 图标 |

```
页眉：满意解研究所 + 模块名称

正文区：占页面70%

```
