## 第二阶段：增长期（Day 31-60）

### Week 5-8：放量与优化

```
【内容升级】

公众号：
├─ 频率：每周2篇→3篇
├─ 新增：系列文章（如"合伙人决策5讲"）
├─ 互动：评论区QA、用户投稿
└─ 目标：阅读量>500/篇

小红书：
├─ 频率：每周3篇→5篇
├─ 新增：视频笔记、合集
├─ 互动：评论回复、私信
└─ 目标：点赞>50/篇

知乎：
├─ 频率：每周2个回答→3个
├─ 新增：专栏文章
├─ 互动：回答评论
└─ 目标：赞同>20/回答

抖音/视频号：
├─ 频率：每周1个→2个
├─ 新增：直播预告、课程片段
├─ 互动：评论回复
└─ 目标：播放>1000/个

【新增动作】

动作1：活动引流
├─ 免费测评活动
├─ 抽奖活动
├─ 打卡活动
└─ 目标：每次活动引流100+

动作2：KOL合作
├─ 找相关领域KOL互推
├─ 参与话题讨论
├─ 投稿到大号
└─ 目标：每次合作引流200+

动作3：社群引流
├─ 建立微信社群
├─ 定期分享干货
├─ 组织线上活动
└─ 目标：社群500人

【关键指标】
├─ 发布频率：每周7-10条
├─ 总粉丝：2000+
├─ 阅读量：>1000/篇
└─ 互动率：>8%
```
