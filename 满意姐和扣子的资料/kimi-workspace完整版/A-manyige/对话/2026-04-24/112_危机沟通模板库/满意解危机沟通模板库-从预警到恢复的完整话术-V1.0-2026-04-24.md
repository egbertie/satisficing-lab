## 二、危机沟通模板

### 模板1：学员投诉

```
尊敬的同学，

感谢您反馈[具体问题]。

我们已收到您的反馈，并立即启动调查。

初步了解：
[简述情况]

我们的解决方案：
1. [具体措施1]
2. [具体措施2]
3. [补偿方案]

预计解决时间：[时间]

再次感谢您的反馈，
这让我们有机会做得更好。

满意解团队
[日期]
```

### 模板2：媒体负面报道

```
关于[报道标题]的说明

我们注意到[媒体]于[日期]发布的报道。

事实情况：
[澄清事实]

我们的态度：
[诚恳回应]

我们的行动：
[已采取/将采取的措施]

欢迎媒体朋友进一步沟通，
联系方式：[邮箱/电话]

满意解研究所
[日期]
```

### 模板3：产品故障

```
【重要通知】[产品名称]故障说明

各位用户：

[产品名称]于[时间]出现故障，
影响范围：[具体范围]

故障原因：[简述]

当前状态：[修复中/已修复]

预计恢复：[时间]

临时方案：[如有]

我们深表歉意，
将提供[补偿方案]。

满意解团队
[日期]
```

## 三、恢复策略

```
危机后三步：

1. 复盘（3天内）
   → 原因分析
   → 责任认定
   → 改进措施

2. 改进（1个月内）
   → 落实改进
   → 制度完善
   → 培训强化

3. 重建（3个月内）
   → 品牌修复
   → 信任重建
   → 案例沉淀
```
