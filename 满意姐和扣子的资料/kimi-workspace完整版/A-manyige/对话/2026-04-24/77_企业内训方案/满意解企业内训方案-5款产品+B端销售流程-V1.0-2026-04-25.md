## 第一部分：内训产品体系

### 1.1 标准产品（5款）

```
【产品1：合伙人决策工作坊】
├─ 时长：2天（14小时）
├─ 人数：10-30人
├─ 目标：解决企业合伙人/核心团队的决策问题
├─ 内容：
│   Day 1:
│   ├─ 上午：五维决策框架（理论+测评）
│   ├─ 下午：合伙人评估与匹配（实操+案例）
│   └─ 晚上：小组讨论（真实问题诊断）
│   Day 2:
│   ├─ 上午：决策权与股权设计（工具+模板）
│   ├─ 下午：沟通与冲突解决（演练+反馈）
│   └─ 收尾：行动计划制定（每人输出1份计划）
├─ 交付物：
│   ├─ 每人1份个性化测评报告
│   ├─ 团队1份决策权矩阵
│   ├─ 团队1份股权框架建议
│   └─ 每人1份行动计划
├─ 价格：10万/次（含讲师费+材料费+场地费）
└─ 适合：创业团队、高管团队、合伙人团队

【产品2：高管决策力提升】
├─ 时长：1天（7小时）
├─ 人数：10-20人
├─ 目标：提升高管的决策质量和效率

│   ├─ 上午：决策科学基础（认知偏差、决策陷阱）

│   ├─ 每人1份决策风格测评报告

├─ 价格：5万/次
└─ 适合：中高层管理者、部门负责人

【产品3：团队沟通与协作】
├─ 时长：1天（7小时）
├─ 人数：20-50人
├─ 目标：提升团队协作效率，减少内耗
├─ 内容：

│   ├─ 每人1份沟通风格报告

├─ 价格：5万/次
└─ 适合：项目团队、跨部门团队、新组建团队

【产品4：股权设计与治理】
├─ 时长：1天（7小时）
├─ 人数：5-15人
```

## 第三部分：培训实施

### 3.1 培训前准备

```
【讲师准备】
├─ 了解企业背景（行业、阶段、规模、文化）
├─ 了解学员背景（职位、经验、需求）
├─ 熟悉课前测评结果（团队问题诊断）
├─ 调整案例（选择行业相关的案例）
├─ 准备个性化开场（引用企业具体问题）
└─ 检查设备（投影、音响、网络、激光笔）

【材料准备】
├─ 学员手册（每人1本）
├─ 工具模板（打印版+电子版）
├─ 案例资料（脱敏处理）
├─ 测评报告（每人1份个性化报告）
├─ 反馈表（课后填写）
├─ 证书（培训结业证书）
└─ 礼品（满意解品牌周边，如决策卡牌）

【场地准备】
├─ 座位：U型或岛型（便于讨论）
├─ 白板：至少2块
├─ 投影：清晰、亮度足够
├─ 音响：全场听得清
├─ 茶歇：咖啡、茶、点心
├─ 网络：WiFi密码提前告知
└─ 温度：舒适（提前调节空调）
```

## 第四部分：质量管理

### 4.1 培训效果评估

```
【四级评估模型】

Level 1：反应评估（学员满意度）
├─ 评估方式：课后满意度调查
├─ 指标：内容、讲师、形式、组织、整体满意度
├─ 目标：满意度>90%
└─ 时间：课后立即

Level 2：学习评估（知识掌握）
├─ 评估方式：课后测试/作业
├─ 指标：知识点掌握率、工具使用熟练度
├─ 目标：掌握率>80%
└─ 时间：课后1周

Level 3：行为评估（行为改变）
├─ 评估方式：3个月后问卷调查+访谈
├─ 指标：是否使用了所学工具、合伙人关系是否改善
├─ 目标：行为改变率>60%
└─ 时间：培训后3个月

Level 4：结果评估（业务影响）
├─ 评估方式：6个月后与HR/决策者访谈
├─ 指标：合伙人冲突减少、决策效率提升、团队稳定性
├─ 目标：有明确的业务改善证据
└─ 时间：培训后6个月

【评估工具】
├─ 满意度调查表（纸质/电子）
├─ 知识测试题（在线测试）
├─ 行为改变问卷（3个月后）
├─ 业务影响访谈（6个月后）
└─ 案例追踪表（长期跟踪）
```

```
├─ 收集学员反馈（建议、需求、问题）

├─ 更新测评问卷（根据效度分析调整）
```
