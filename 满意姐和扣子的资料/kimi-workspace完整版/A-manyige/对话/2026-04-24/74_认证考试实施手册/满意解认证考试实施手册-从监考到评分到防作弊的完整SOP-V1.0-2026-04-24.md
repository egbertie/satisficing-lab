## 二、考前准备

### 设备检查清单

| 检查项 | 标准 | 不合格处理 |
|:-----|:-----|:-----------|
| 摄像头 | 清晰，覆盖考生面部 | 更换设备或延期 |
| 麦克风 | 正常收音 | 文字答题替代 |
| 网络 | 稳定，带宽>2Mbps | 手机热点备用 |
| 浏览器 | Chrome/Firefox最新版 | 提前安装 |
| 身份证 | 原件在手边 | 无法参加考试 |

### 环境检查

```
✅ 独立空间，无他人
✅ 桌面整洁，无资料
✅ 手机静音，放远处
✅ 关闭所有无关软件
✅ 准备纸笔（用于草稿）
```

## 三、监考流程

### 初级考试（自动监考）

```
Step 1: 身份验证（考前5分钟）
  → 考生展示身份证
  → 系统人脸识别比对
  → 通过后方可进入

Step 2: 环境扫描（考前2分钟）
  → 摄像头360度扫描房间
  → 确认无他人、无资料
  → 系统截图存档

Step 3: 考试进行（60分钟）
  → 系统自动计时
  → 切屏检测：切屏3次自动交卷
  → 人脸检测：离开摄像头超30秒告警
  → 异常行为AI检测

Step 4: 自动交卷
  → 时间到自动交卷
  → 或考生主动交卷
  → 成绩即时显示
```

### 中级考试（人工+自动）

```
Step 1-3: 同初级

Step 4: 案例题提交
  → 系统自动保存每5分钟
  → 考生主动提交

Step 5: 人工复核（48小时内）
  → 考官逐题评分
  → 评分标准对照
  → 分数录入系统

Step 6: 成绩发布
  → 邮件通知
  → 证书生成
```

### 高级考试（线下答辩）

```
Step 1: 论文提交（考前1周）
  → 查重检测（<15%）
  → 格式审查
  → 分配答辩导师

Step 2: 答辩准备
  → PPT准备（15分钟）
  → 论文熟悉
  → 常见问题准备

Step 3: 答辩当天
  → 提前30分钟到场
  → 设备测试
  → 答辩委员会到场

Step 4: 答辩流程
  → 论文陈述：15分钟
  → 导师提问：20分钟
  → 委员评议：10分钟
  → 结果宣布：5分钟

Step 5: 结果
  → 通过：当场颁发证书
  → 不通过：3个月后重答辩
```

## 四、评分标准

### 初级评分

```
自动评分：
- 每题1分，共100题
- 答对得分，答错不扣分
- 总分≥70分通过

分数等级：
- 90-100：优秀
- 80-89：良好
- 70-79：合格
- <70：不合格
```

### 中级评分

```
案例题评分标准（每题25分）：

维度1：问题识别（5分）
  - 5分：准确识别核心问题
  - 3分：识别部分问题
  - 1分：问题识别偏差

维度2：分析深度（10分）
  - 10分：多维度深入分析
  - 6分：单维度分析
  - 2分：分析表面

维度3：方案可行性（5分）
  - 5分：方案具体可执行
  - 3分：方案方向正确但不够具体
  - 1分：方案不可行

维度4：表达清晰（5分）
  - 5分：逻辑清晰，表达准确
  - 3分：基本清晰
  - 1分：表达混乱

通过标准：
- 每题≥15分
- 总分≥60分（4题）
```

### 高级评分

```
论文评分（100分）：

选题价值（15分）
文献综述（15分）
方法论（20分）
分析深度（25分）
创新性（15分）
写作规范（10分）

通过标准：≥80分

答辩评分（通过/不通过）：
- 论文理解度
- 回答准确性
- 思维深度
- 表达能力

需3/5委员通过
```

## 五、防作弊机制

### 技术防作弊

| 机制 | 说明 | 触发 |
|:-----|:-----|:-----|
| 人脸比对 | 考前身份证+实时人脸 | 不匹配则禁止考试 |
| 切屏检测 | 监测考生离开考试页面 | 切屏3次自动交卷 |
| 多设备检测 | 检测同一账号多设备登录 | 强制下线 |
| 答案乱序 | 每考生题目顺序不同 | 防止抄袭 |
| 选项乱序 | 每考生选项顺序不同 | 防止抄袭 |
| IP限制 | 检测异常IP | 标记复核 |

### 人工防作弊

| 机制 | 说明 |
|:-----|:-----|
| 考后复核 | 成绩异常考生人工复核 |
| 视频抽查 | 随机抽查考试录像 |
| 雷同检测 | 答案相似度检测 |
| 举报机制 | 其他考生举报渠道 |

## 六、异常情况处理

### 常见异常

| 异常 | 处理 |
|:-----|:-----|
| 断网 | 自动保存，重新连接后继续 |
| 设备故障 | 更换设备，已答题目保留 |
| 身体不适 | 可申请延期（需提供证明） |
| 被干扰 | 标记时间戳，考后申诉 |
| 系统故障 | 技术团队介入，统一处理 |

### 申诉流程

```
Step 1: 考后24小时内提交申诉
Step 2: 提供证据（截图/录像/证明）
Step 3: 仲裁委员会审核（3个工作日内）
Step 4: 结果通知
Step 5: 如不满意，可向Egbertie直接申诉
```

## 七、证书颁发

### 初级证书

```
颁发时间：考后即时
形式：电子证书（PDF）
内容：姓名、编号、级别、日期、签名
查询：官网验证
```

### 中级证书

```
颁发时间：人工复核后48小时
形式：电子证书 + 实体证书（邮寄）
内容：+ 案例成绩明细
查询：官网验证
```

### 高级证书

```
颁发时间：答辩当场
形式：实体证书 + 电子版
内容：+ 论文题目 + 答辩导师签名
查询：官网验证
特权：导师资格、企业内训资格
```
