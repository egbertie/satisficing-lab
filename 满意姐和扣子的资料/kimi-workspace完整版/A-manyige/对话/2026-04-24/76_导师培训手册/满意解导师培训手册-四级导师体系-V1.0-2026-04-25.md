### 1.2 导师申请流程

```
【Step 1：资格申请】
├─ 提交申请表（个人信息、经验、动机）
├─ 提交CDA高级证书
├─ 提交2份学员推荐信
├─ 提交1份独立辅导案例报告
└─ 缴纳申请费：500元（审核不通过全额退还）

【Step 2：资格审核】
├─ Egbertie审核申请材料
├─ 背景调查（工作经历、学员反馈）
├─ 面试（30分钟，线上）
└─ 审核周期：15个工作日

【Step 3：导师培训】
├─ 通过审核后，进入导师培训营
├─ 培训周期：2个月（线上+线下）
├─ 培训内容：见"第二部分"
└─ 培训费用：包含在申请费中

【Step 4：导师认证】
├─ 培训结束后，参加导师认证考试
├─ 考试形式：试讲+答辩
├─ 通过标准：试讲评分>80分+答辩通过
└─ 认证通过后，颁发"满意解认证导师"证书

【Step 5：持续管理】
├─ 每年至少授课2次（维持认证）
├─ 每年参加1次导师复训
├─ 每年提交1份教学反思报告
└─ 学员满意度>85%（低于则暂停授课）
```

## 第二部分：导师培训内容

### 2.1 培训模块（8模块，8周）

```
【模块1：满意解方法论深化】（Week 1）
├─ 五维决策框架的深度理解
├─ 12类型冲突模型的诊断技巧
├─ 工具包的定制化应用
├─ 案例库的灵活使用
└─ 练习：用五维框架分析3个真实案例

【模块2：教学设计】（Week 2）
├─ 成人学习原理（Andragogy）
├─ 课程设计：目标→内容→活动→评估
├─ 教案编写：每节课的详细设计
├─ 课件制作：PPT/白板/信息图
└─ 练习：设计1节60分钟的课程

【模块3：授课技巧】（Week 3）
├─ 开场技巧（钩子设计）
├─ 讲解技巧（清晰、生动、有逻辑）
├─ 互动技巧（提问、讨论、小组活动）
├─ 控场技巧（时间管理、情绪管理、突发事件）
├─ 收尾技巧（总结、金句、CTA）
└─ 练习：录制1节15分钟试讲视频

【模块4：引导与答疑】（Week 4）
├─ 提问技巧（开放式/封闭式/追问）
├─ 倾听技巧（积极倾听、复述、澄清）
├─ 反馈技巧（肯定、建议、纠正）
├─ 难缠学员处理（质疑、沉默、打断）
├─ 深度答疑（从表面问题到本质问题）
└─ 练习：模拟10个学员提问，练习答疑

【模块5：案例分析】（Week 5）
├─ 案例教学法（哈佛案例法）
├─ 案例选择（真实、脱敏、有代表性）
├─ 案例引导（不直接给答案，引导思考）
├─ 案例讨论（小组讨论、全班分享）
├─ 案例总结（提炼方法论、给出工具）
└─ 练习：引导1个完整案例分析（60分钟）

【模块6：工具使用】（Week 6）
├─ 测评系统操作（如何帮学员做测评）
├─ 工具模板使用（如何指导学员填写）
├─ 在线平台使用（直播/录播/互动工具）
├─ 数据解读（如何解读测评报告）
└─ 练习：指导1位"模拟学员"完成测评+工具使用

【模块7：线上授课】（Week 7）
├─ 线上授课特点（没有面对面，如何建立连接）
├─ 直播技巧（镜头感、语速、互动设计）
├─ 录播技巧（脚本、剪辑、字幕）
├─ 线上互动（投票、问答、弹幕）
├─ 线上工具（Zoom/腾讯会议/小鹅通）
└─ 练习：完成1次60分钟线上直播试讲

【模块8：线下授课】（Week 8）
├─ 线下授课特点（氛围、肢体语言、场地）
├─ 工作坊设计（2天/1天的流程设计）
├─ 场地布置（座位、白板、资料、茶歇）
├─ 物料准备（手册、工具、案例、证书）
├─ 现场应急（设备故障、学员冲突、时间超时）
└─ 练习：完成1次2天线下工作坊试讲
```

---

### 2.2 培训方式

```
【线上培训】（70%）
├─ 视频课程：自学满意解方法论深化
├─ 直播互动：每周1次直播答疑+练习
├─ 小组讨论：3-5人小组，互相练习
├─ 作业提交：每周1份作业，导师点评
└─ 平台：飞书/腾讯会议/小鹅通

【线下培训】（30%）
├─ 集中培训：2天（第7-8周）
├─ 地点：深圳（满意解总部）
├─ 内容：线下授课实操、工作坊演练
├─ 考核：试讲+答辩
└─ 费用：交通自理，住宿由满意解安排

【导师辅导】
├─ 每位学员分配1位高级导师作为导师
├─ 导师每周1次1v1辅导（30分钟）
├─ 导师点评作业、答疑、提供建议
└─ 导师评估学员表现，给出认证建议
```

---

### 2.3 培训考核

```
【考核维度】

维度1：知识掌握（30%）
├─ 五维框架理解深度
├─ 案例诊断准确性
├─ 工具应用熟练度
└─ 考核方式：笔试+案例分析

维度2：授课能力（40%）
├─ 开场吸引力
├─ 讲解清晰度
├─ 互动设计
├─ 控场能力
├─ 收尾效果
└─ 考核方式：试讲录像评审

维度3：引导能力（20%）
├─ 提问设计
├─ 答疑深度
├─ 难缠学员处理
└─ 考核方式：模拟场景演练

维度4：品牌认同（10%）
├─ 对满意解价值观的认同
├─ 对五维框架的信心
├─ 对学员的真诚度
└─ 考核方式：面试+教学反思报告

【通过标准】
├─ 总分≥80分
├─ 各维度≥70分
├─ 试讲评分≥80分
├─ 答辩通过
└─ 导师推荐（导师认为具备独立授课能力）

【补考机制】
├─ 未通过：1次免费补考机会（1个月后）
├─ 补考内容：未通过的维度
├─ 仍不通过：需重新参加培训（费用半价）
└─ 连续2次不通过：取消导师资格申请
```

### 4.2 导师评估与晋升

```
【年度评估】
├─ 授课次数：是否达标（≥2次/年）
├─ 学员满意度：平均评分（目标>85%）
├─ 学员成果：学员通过率、学员反馈
├─ 教学创新：是否有新的教学方法/工具
├─ 品牌贡献：是否维护品牌形象
├─ 社群参与：是否积极参与导师社群
└─ 综合评分：优秀/良好/合格/不合格

【晋升机制】
├─ 认证导师→高级导师：
│   ├─ 条件：5年经验、100+学员、满意度>90%
│   ├─ 能力：能培训新导师、能开发新课程
│   └─ 评审：高级导师评审委员会
├─ 高级导师→荣誉导师：
│   ├─ 条件：10年经验、行业影响力
│   └─ 邀请制：Egbertie邀请
└─ 降级机制：
    ├─ 年度评估不合格：暂停授课，需复训
    ├─ 连续2年不合格：取消导师资格
    └─ 严重违规：立即取消资格

【退出机制】
├─ 主动退出：提前3个月通知
├─ 被动退出：取消资格后，不得使用满意解品牌
├─ 交接要求：完成已承诺的授课任务
└─ 后续关系：欢迎作为校友参与社群
```
