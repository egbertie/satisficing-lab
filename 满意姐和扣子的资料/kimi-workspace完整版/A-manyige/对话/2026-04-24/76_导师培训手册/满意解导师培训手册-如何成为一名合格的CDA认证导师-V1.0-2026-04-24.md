## 一、导师标准

### 成为导师的条件

| 条件 | 要求 | 说明 |
|:-----|:-----|:-----|
| **认证** | CDA高级认证 | 必须先成为优秀学员 |
| **经验** | 辅导至少3名学员毕业 | 实战经验 |
| **考核** | 通过导师资格考试 | 教学能力验证 |
| **伦理** | 签署导师伦理守则 | 职业规范 |
| **持续** | 每年参加导师复训 | 持续学习 |

### 导师能力模型

```
满意解导师五维能力

土·伦理底座
  → 诚信、公正、对学员负责
  → 不夸大效果，不贬低竞品
  → 保护学员隐私

金·教学标准
  → 80分就够？不，导师要90分
  → 每节课有目标、有产出、有反馈
  → 减法优先：少讲一点，讲透一点

水·洞察本质
  → 不教"怎么做"，教"怎么想"
  → 追问本质，拒绝套话
  → 用学员的真实案例教学

木·信任建立
  → 和学员建立信任关系
  → 不是权威，是伙伴
  → 记住学员的名字、故事、成长

火·热情传递
  → 你对五维框架的热情感染学员
  → 不是"完成任务"，是"点燃火焰"
  → 让学员爱上决策科学
```

## 二、导师培训课程

### 培训模块

| 模块 | 内容 | 时长 | 方式 |
|:-----|:-----|:-----|:-----|

| **M4** | 案例教学法 | 4小时 | 实操+互评 |
| **M5** | 决策卡牌游戏引导 | 2小时 | 实操 |

| **M7** | 在线教学技巧 | 2小时 | 讲授+实操 |

## 三、教学方法论

### 满意解教学法（Satisficing Pedagogy）

```
核心原则：
1. 以学员为中心，而非以内容为中心
2. 以问题为导向，而非以知识为导向
3. 以实践为检验，而非以考试为检验
4. 以成长为目标，而非以通过为目标
```

### 五维教学法

| 教学环节 | 对应五维 | 具体做法 |
|:---------|:---------|:---------|
| **开场** | 火·点燃 | 用一个真实故事开场，激发兴趣 |
| **讲解** | 水·洞察 | 追问本质，拒绝套话 |
| **练习** | 金·满意解 | 给足够的时间，不求完美但求完成 |
| **反馈** | 木·信任 | 建设性反馈，保护学员信心 |
| **收尾** | 土·伦理 | 强调伦理底线，提醒责任 |

## 四、课堂管理

### 课前准备清单

```
□ 备课完成（口播级教案）
□ 设备测试（摄像头/麦克风/网络）
□ PPT/教具准备
□ 学员名单确认
□ 破冰活动设计
□ 意外情况预案
```

### 课中管理

```
时间管理：
- 严格按教案时间执行
- 预留5分钟缓冲
- 如超时，标记为课后补充

互动管理：
- 每15分钟至少一次互动
- 提问：先思考30秒，再回答
- 分组：3-5人一组

纪律管理：
- 迟到：课后单独沟通
- 缺席：提供录播+补课
- 不积极参与：私下了解原因
```

### 课后跟进

```
24小时内：
- 发送课程回放
- 发送课件
- 布置作业

48小时内：
- 批改作业
- 发送反馈

1周内：
- 答疑
- 收集课程反馈
```
