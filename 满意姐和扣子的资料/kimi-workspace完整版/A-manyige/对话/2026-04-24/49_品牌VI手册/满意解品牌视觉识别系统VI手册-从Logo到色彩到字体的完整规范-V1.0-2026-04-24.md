## 二、Logo系统

### 主Logo

```
规范：
- 图形+文字组合
- 图形：五维图腾抽象化
- 文字："满意解"（思源黑体，粗体）
- 英文："Satisficing"（思源黑体，常规）
- 副标："研究所"（思源宋体，常规）

最小尺寸：
- 印刷：30mm宽
- 屏幕：100px宽

安全空间：
- Logo周围留出1/2 Logo高度的空白
```

### 图形Logo（单独使用）

```
五维图腾抽象图形：
- 土：山形，稳固
- 金：天平，平衡
- 水：波浪，流动
- 木：树木，生长
- 火：莲花，绽放

组合方式：
- 五元素环绕中心点
- 中心为"契"字印章
- 整体呈圆形，象征完整

颜色：
- 单色版：金色#D4AF37
- 反白版：白色
- 深色背景：金色+白色描边
```

### Logo变体

| 变体 | 使用场景 | 说明 |
|:-----|:---------|:-----|
| **横版** | 网站/海报/名片 | 图形左，文字右 |
| **竖版** | 社交媒体头像/徽章 | 图形上，文字下 |
| **图标版** | APP/小程序/ favicon | 仅图形 |
| **单色版** | 印刷/单色场景 | 金色或黑色 |
| **反白版** | 深色背景 | 白色 |

### Logo禁用

❌ 不得：
- 拉伸变形
- 改变颜色
- 添加阴影/描边（除反白版）
- 旋转超过15度
- 与无关图形组合

## 三、色彩系统

### 主色

| 名称 | 色值 | 用途 |
|:-----|:-----|:-----|
| **满意蓝** | #1A365D | 主背景、标题、按钮 |
| **满意金** | #D4AF37 | Logo、强调、装饰 |

### 辅助色（五维色）

| 维度 | 名称 | 色值 | 用途 |
|:-----|:-----|:-----|:---------|
| 土 | 土棕 | #8B6914 | 伦理相关 |
| 金 | 金白 | #F5F5F0 | 满意解标准 |
| 水 | 水蓝 | #4A90D9 | 洞察相关 |
| 木 | 木绿 | #2D5A3D | 信任相关 |
| 火 | 火红 | #C0392B | 直觉相关 |

### 中性色

| 名称 | 色值 | 用途 |
|:-----|:-----|:-----|
| 深灰 | #333333 | 正文 |
| 中灰 | #666666 | 次要文字 |
| 浅灰 | #F5F5F5 | 背景 |
| 白色 | #FFFFFF | 反白 |

### 色彩搭配规则

```
主色+辅助色 = 70% + 30%
满意蓝 + 满意金 = 专业+温度
五维色 = 按场景选择1-2个
中性色 = 文字+背景
```

## 五、图形元素

### 五维图腾图标

```
规范：
- 尺寸：24×24px（小）/ 48×48px（中）/ 96×96px（大）
- 颜色：五维色或单色
- 风格：线框+填充
- 圆角：2px
```

### 辅助图形

```
元素1：波浪线
- 用途：分隔线、装饰
- 颜色：满意金
- 粗细：2px

元素2：圆点阵列
- 用途：背景装饰
- 颜色：浅灰
- 密度：稀疏

元素3：五维几何
- 用途：章节标识
- 颜色：五维色
- 风格：抽象几何
```

### 摄影风格

```
人像：
- 自然光，柔和阴影
- 真实场景，不摆拍
- 表情自然，有温度

场景：
- 办公环境，整洁专业
- 自然元素（植物、光线）
- 避免过度修饰
```

## 七、品牌禁用

### 绝对禁止

❌ 不得：
- 改变Logo颜色（除规定变体）
- 拉伸/压缩Logo
- 使用非品牌字体
- 使用非品牌色彩
- 在复杂背景上使用Logo
- 将Logo与无关元素组合

### 相对禁止

⚠️ 避免：
- 过多使用五维色（最多2个/画面）
- 使用饱和度过高的颜色
- 正文使用浅色（<#666）
- 图片过度PS
