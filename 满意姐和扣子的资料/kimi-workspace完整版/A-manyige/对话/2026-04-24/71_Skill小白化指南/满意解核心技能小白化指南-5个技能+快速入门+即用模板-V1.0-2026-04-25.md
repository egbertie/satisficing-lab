## 第二部分：合伙人测评（3分钟完成）

### 2.1 快速测评

```
【Step 1：基本信息】（30秒）
├─ 你的角色：________
├─ 合伙人角色：________
├─ 合作时长：________
└─ 公司阶段：________

【Step 2：快速评估】（2分钟）

土·价值观：
"我和合伙人在核心目标上是一致的。"
├─ 完全不同意 1 2 3 4 5 完全同意

金·目标：
"我和合伙人对公司发展方向有共识。"
├─ 完全不同意 1 2 3 4 5 完全同意

水·互补：
"我和合伙人的能力是互补的。"
├─ 完全不同意 1 2 3 4 5 完全同意

木·信任：
"我可以完全信任我的合伙人。"
├─ 完全不同意 1 2 3 4 5 完全同意

火·行动：
"我和合伙人在执行上配合默契。"
├─ 完全不同意 1 2 3 4 5 完全同意

【Step 3：看结果】（30秒）

计算总分：
├─ 5-10分：⚠️ 高风险，需要深入沟通
├─ 11-15分：⚡ 中等，有改进空间
├─ 16-20分：✅ 较好，继续保持
└─ 21-25分：🌟 优秀，黄金搭档

单项<3分：重点关注该维度

【建议】
├─ 低分项：和合伙人讨论改进
├─ 高分项：继续保持
└─ 整体：定期复测
```

## 第三部分：冲突类型识别（2分钟判断）

### 3.1 快速识别

```
【问题】你和合伙人为什么事吵架？

A. 股权/钱的事 → Type 1 股权之争
B. 谁说了算 → Type 2 决策权之争
C. 公司方向 → Type 3 战略分歧
D. 谁干活多 → Type 4 贡献不均
E. 信任问题 → Type 5 信任危机
F. 能力怀疑 → Type 6 能力质疑
G. 工作方式 → Type 7 工作风格
H. 价值观 → Type 8 价值观冲突
I. 退出问题 → Type 9 退出争议
J. 家庭介入 → Type 10 家庭因素
K. 第三方 → Type 11 第三方介入
L. 其他 → Type 12 其他冲突

【快速解决】
├─ 识别类型 → 查看该类型解决思路
```
