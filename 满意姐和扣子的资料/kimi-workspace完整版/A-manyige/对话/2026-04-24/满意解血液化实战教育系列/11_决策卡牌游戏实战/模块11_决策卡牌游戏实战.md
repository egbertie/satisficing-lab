# 模块11：决策卡牌游戏实战

> **核心命题**: 把复杂决策变成可触摸的卡牌——13类型冲突的可视化决策工具
> **血液化资产**: 12类型案例库、决策卡牌原型、教学应用指南SPM-041
> **适用对象**: 培训师、咨询师、团队教练

---

## 一、核心理念

### 1.1 为什么需要卡牌游戏？

```
传统决策培训:
  ├─ 讲课 → 听懂了 → 回去忘了
  ├─ 案例分析 → 看懂了 → 自己遇到不会用
  └─ 结果: 知识传递了，能力没形成

卡牌游戏:
  ├─ 拿到卡牌 → 触摸到问题
  ├─ 模拟决策 → 在低风险环境练习
  ├─ 复盘讨论 → 从错误中学习
  └─ 结果: 知识内化为能力

关键: 不是"教"，是"练"。不是"知道"，是"做到"。
```

### 1.2 卡牌的本质

```
每张卡牌 = 一个决策场景

卡牌结构:
  ├─ 正面: 场景描述（创始人面临的困境）
  ├─ 背面: 五维提示（土金水木火的扫描指引）
  └─ 边框: 类型标识（Type01-12）

玩法:
  1. 抽卡 → 获得场景
  2. 五维扫描 → 分析场景
  3. 决策 → 选择行动方案
  4. 翻开背面 → 对照专家解法
  5. 复盘 → 讨论差异
```

## 二、血液化前 vs 血液化后

| 维度 | 血液化前 | 血液化后 |
|:-----|:---------|:---------|
| 决策学习 | 看书听课 | 卡牌模拟实战 |
| 知识传递 | 单向讲授 | 双向互动 |
| 场景理解 | 抽象概念 | 具体情境 |
| 练习频率 | 低（真实决策成本高） | 高（模拟决策低成本） |
| 错误成本 | 高（真实决策失误） | 低（模拟环境） |
| 团队共识 | 难达成 | 卡牌讨论自然形成 |
| 知识留存 | 低（听过就忘） | 高（动手过） |
| 外部价值 | 培训产品 | 可销售的决策训练工具 |

## 三、操作步骤

### Step 1: 设计卡牌结构

**卡牌正面（场景面）**:
```
━━━━━━━━━━━━━━━━━━━━
[类型标识] Type01 创始人过度干预型

## 场景
你是创始人，和CTO合伙人共事3年。
最近你发现CTO的技术决策
越来越不符合你的预期。
你连续3次在会议上公开
质疑CTO的方案，CTO开始
避免和你单独沟通。

## 关键信息
- 团队规模: 15人
- 融资阶段: A轮
- 冲突触发: 技术架构选型
- 你的情绪: 焦虑、控制欲

## 问题
你该怎么办？
━━━━━━━━━━━━━━━━━━━━
```

**卡牌背面（五维提示面）**:
```
━━━━━━━━━━━━━━━━━━━━
## 五维扫描提示

□ 土·信义: 你和CTO的信义账户余额如何？
□ 金·标尺: 你的干预边界在哪里？
□ 水·觉察: 你的焦虑来自哪里？
□ 木·伦理: 公开质疑是否合适？
□ 火·顿悟: 如果继续这样下去，3个月后会怎样？

## 满意解方向
[不透露，用于复盘对照]
━━━━━━━━━━━━━━━━━━━━
```

### Step 2: 设计游戏流程

**单人练习版（30分钟）**:
```
1. 抽卡（随机或针对性选择类型）
2. 阅读场景（2分钟）
3. 五维扫描（5分钟）
   ├─ 逐项过五维
   └─ 记录评分
4. 决策（3分钟）
   ├─ 写出你的行动方案
   └─ 说明理由
5. 翻开背面（1分钟）
   ├─ 对照五维提示
   └─ 检查是否漏了哪一维
6. 复盘（10分钟）
   ├─ 你的决策 vs 满意解方向
   ├─ 差异在哪里？
   └─ 下次如何改进？
7. 记录（5分钟）
   ├─ 写入决策日志
   └─ 标记需要加强的维度
```

**团队工作坊版（2小时）**:
```
1. 开场（10分钟）
   ├─ 介绍五维决策框架
   └─ 说明卡牌规则

2. 分组抽卡（5分钟）
   ├─ 3-5人一组
   └─ 每组抽1张卡

3. 组内讨论（20分钟）
   ├─ 五维扫描
   ├─ 形成共识决策
   └─ 准备展示

4. 组间展示（30分钟）
   ├─ 每组3分钟展示决策
   ├─ 其他组提问
   └─ 教练点评

5. 翻开背面（5分钟）
   ├─ 对照满意解方向
   └─ 各组自评偏差

6. 复盘总结（30分钟）
   ├─ 讨论常见盲区
   ├─ 分享收获
   └─ 制定改进计划

7. 收尾（10分钟）
   ├─ 金点子收集
   └─ 下次练习约定
```

### Step 3: 建立卡牌库管理

**卡牌库结构**:
```
卡牌库/
  ├─ Type01_创始人过度干预型/
  │   ├─ 卡牌01-场景A.md
  │   ├─ 卡牌02-场景B.md
  │   └─ ...
  ├─ Type02_合伙人能力错配型/
  │   └─ ...
  ├─ ...
  └─ Type12_外部压力型/
      └─ ...

每张卡牌:
  ├─ 正面: 场景描述（300-500字）
  ├─ 背面: 五维提示 + 满意解方向
  └─ 难度: 初级/中级/高级
```

**卡牌更新机制**:
```
新增卡牌来源:
  ├─ 真实案例改编（脱敏处理）
  ├─ 学员贡献（匿名）
  ├─ 市场热点转化
  └─ 经典理论场景化

更新频率:
  ├─ 每月新增2-3张
  ├─ 每季度淘汰过时卡牌
  └─ 每年更新难度分级
```

## 六、常见误区

| 误区 | 表现 | 后果 | 纠正 |
|:-----|:-----|:-----|:-----|
| 卡牌=游戏 | 只玩不思考 | 娱乐化 | 强调复盘 |
| 追求标准答案 | 翻背面找"正确答案" | 固化思维 | 满意解是方向，不是唯一 |
| 跳过五维 | 凭直觉决策 | 遗漏维度 | 强制五维扫描 |
| 只做简单卡 | 只抽初级 | 无法成长 | 挑战中级/高级 |
| 不复盘 | 练完就结束 | 无法改进 | 必须复盘记录 |
| 一个人练 | 缺乏外部视角 | 盲区未被发现 | 团队练习 |
| 卡牌过时 | 场景不再适用 | 失去 relevance | 定期更新 |
| 过于复杂 | 场景太长 | 参与度下降 | 300-500字 |
| 没有真实感 | 场景太抽象 | 无法代入 | 基于真实案例 |
| 忽视背面设计 | 五维提示模糊 | 复盘效果差 | 精心设计提示 |

## 七、真实案例

### 案例1: "Type07技术合伙人退出"——卡牌设计实战

**真实事件**: 某技术合伙人突然退出，创始人慌乱。

**卡牌设计**:
```
正面:
  场景: 你的CTO合伙人今天早上发邮件说要退出。
        没有提前沟通，没有交接计划。
        团队15人，A轮，产品即将发布。
        你感到愤怒、被背叛、焦虑。

背面五维提示:
  土·信义: 信义账户余额？近期是否有透支？
  金·标尺: 退出条款？法律边界？
  水·觉察: 你的愤怒来自哪里？被背叛？还是恐惧？
  木·伦理: 他的退出方式是否合规？你是否要体面处理？
  火·顿悟: 如果冷静处理，3个月后可能有什么转机？

满意解方向:
  先处理情绪（水），再处理法律（金），
  再处理信任（土），保持体面（木），寻找新机会（火）。
```

**工作坊效果**:
- 学员普遍表示"代入感强"
- 复盘时发现多数人跳过"水·觉察"
- 多次练习后，五维扫描更完整
