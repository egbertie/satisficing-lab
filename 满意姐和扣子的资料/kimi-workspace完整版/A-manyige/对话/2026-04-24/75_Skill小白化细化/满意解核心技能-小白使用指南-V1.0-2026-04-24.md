## 一、系统治理类（你的"后台管家"）

---

### baseline-checker · 基线检查器

**一句话**：每次启动时的"体检表"，109个维度快速扫一遍，确认系统正常。

**它是干嘛的？**
启动时自动检查：API连得上吗？磁盘够吗？内存够吗？必要文件都在吗？基线错误率正常吗？

**什么时候用？**
- 自动：每次会话启动时
- 手动：你说"基线检查一下"时

**怎么用？**
```
直接说：基线检查一下
```

**你会看到什么？**
```
🟢 API连接: 2.36ms ✅
🟢 磁盘: 58.6% ✅
🟢 内存: 511MB ✅
🔴 基线错误率: 0.5% (阈值0.1%) ⚠️
```

**注意**：
- 🟢 不用管
- 🟡 关注但不急
- 🔴 告诉满意姐处理

---

### cron · 定时任务管家

**一句话**：你的"闹钟系统"。管理所有定时任务——晨报、周报、扫描、仪式。

**它是干嘛的？**
- 每天07:11自动生成晨报
- 每天09:00执行晨间仪式
- 每周三09:00生成Token周报
- 每周日03:17系统守护扫描
- 等等

**什么时候用？**
- 自动：按时间表执行
- 手动：你想看/改/暂停定时任务时

**怎么用？**
```
看任务列表：openclaw cron list
暂停某个任务：openclaw cron pause 任务名
恢复任务：openclaw cron resume 任务名
新增任务：openclaw cron add "每天08:00执行XX"
```

**注意**：
- 不懂crontab语法没关系，用自然语言说"每天08:00"
- 任务missed了通常会自动补跑

---

### token-management-satisficing · Token预算管家

**一句话**：按"满意解"原则管Token——不追求最省，追求够用。

**它是干嘛的？**
- 设定周/日Token预算
- 按优先级分配（P0优先，P3延后）
- 超预算时建议调整，不是一刀切停用

**什么时候用？**
- 自动：每次任务前检查预算
- 手动：你想调整预算或查余额时

**怎么用？**
```
查余额：Token还剩多少？
调预算：本周预算调到150万
```

**注意**：
- 调整预算需要确认，系统不会自己乱调
- 后台任务消耗占比过高时会建议优化

---

### totem-system · 五维图腾仪式

**一句话**：每天晨间和黄昏的"仪式感引擎"。唤醒五维决策图腾，生成晨报/固化知识。

**它是干嘛的？**
- 晨间（09:00）：唤醒刘禹锡、司马贺、观自在、孔子、六祖慧能，生成晨报
- 黄昏（18:00）：归位图腾，固化当日知识

**什么时候用？**
- 自动：每天09:00、18:00
- 手动：你想随时执行时

**怎么用？**
```
直接说：执行晨间仪式
或：执行黄昏仪式
```

**注意**：
- 仪式是自动的，你不需要操作
- 晨报在 A-manyige/汇报/日报/ 目录下

## 九、FAQ（创始人常问）

**Q1：这些技能会自己跑吗？**
A：大部分需要你说句话触发。少部分（如stock-assistant、cron任务）是定时自动跑的。

**Q2：用技能花钱吗？**
A：大部分基础技能（搜索、天气、基线检查）免费。部分需要API Key的（如股票数据源、TTS）可能有限额，超了需要配置Key。

**Q3：我怎么知道有哪些技能可用？**
A：说"列出我的技能"或"skills check"。满意姐也会主动推荐适合当前场景的技能。

**Q4：技能可以组合用吗？**
A：可以。比如：先用kimi-search搜资料→用academic-deep-research做深度分析→用md-to-pdf转PDF→用react-email发邮件。

**Q5：技能出错了怎么办？**
A：告诉满意姐"XXX技能报错了"，包含错误信息。满意姐会排查或换替代方案。

**Q6：我能自己创建技能吗？**
A：可以，用skill-creator技能。但需要一些学习成本。也可以让满意姐帮你创建。
