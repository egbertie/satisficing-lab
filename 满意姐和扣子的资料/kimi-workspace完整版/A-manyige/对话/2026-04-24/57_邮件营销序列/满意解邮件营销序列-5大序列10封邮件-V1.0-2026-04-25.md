## 第六部分：邮件规范

### 6.1 邮件设计规范

```
【主题行】
├─ 长度：30-40字（移动端显示完整）
├─ 结构：个性化+价值+紧迫感
├─ 示例：
│   ├─ ❌ "满意解课程优惠"
│   ├─ ✅ "Egbertie有话对你说：合伙人决策的第一课"
│   └─ ✅ "最后3小时：你的专属优惠即将失效"
└─ A/B测试：每次发2个主题行，看哪个打开率高

【预览文本】
├─ 长度：50-80字
├─ 作用：补充主题行，吸引打开
├─ 示例：
│   ├─ ❌ "点击了解更多"
│   └─ ✅ "根据你的测评结果，我们发现了3个风险点..."
└─ 与主题行配合，不重复

【正文】
├─ 长度：300-800字（3分钟读完）
├─ 结构：问候→价值→CTA→签名
├─ 段落：每段2-3行，留白充足
├─ 重点：加粗关键信息
├─ 语气：像朋友写信，不官方
└─ 个性化：提及用户姓名、行为

【CTA】
├─ 数量：每封邮件1-2个CTA
├─ 设计：按钮形式，醒目
├─ 文案：动词开头，具体
│   ├─ ❌ "点击这里"
│   └─ ✅ "立即预约免费咨询"
└─ 位置：邮件中部+底部

【签名】
├─ 姓名：Egbertie / 满意姐
├─ 职位：创始人 / AI助手
├─ 联系方式：微信/邮箱
├─ PS：可加一句P.S.（打开率最高的部分）
└─ 示例："P.S. 回复这封邮件，我亲自回复。"
```

### 6.2 发送节奏

```
【新用户】（注册后30天）
Day 0：欢迎邮件
Day 3：测评解读（如果已完成）
Day 7：案例故事
Day 14：干货内容
Day 21：限时优惠
Day 30：最后机会
总计：6封

【付费用户】（购买后90天）
每周1封：学习提醒/关怀
购买后30天：满意度调查
购买后60天：复购推荐
购买后90天：进阶推荐
总计：约12封

【沉睡用户】（30/60/90天）
Day 30：温和召回
Day 60：优惠召回
Day 90：最后召回
总计：3封

【频率控制】
├─ 同一用户：最多每周1封
├─ 避免邮件疲劳
├─ 根据打开率调整频率
└─ 打开率低→降低频率
```

---

> **核心原则**：
> 邮件不是"广告"，是"信"。
>
> 好的邮件：
> ├─ 让人期待打开（主题行吸引）
> ├─ 让人愿意读完（内容有价值）
> ├─ 让人愿意行动（CTA清晰）
> └─ 让人感觉被尊重（可随时取消）
>
> 满意解的邮件信仰：
> "每一封邮件，都是一次对话。"
