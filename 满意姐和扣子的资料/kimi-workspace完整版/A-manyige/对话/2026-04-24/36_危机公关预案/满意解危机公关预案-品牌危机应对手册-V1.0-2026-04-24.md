## 二、P0级危机预案

### 场景1：创始人Egbertie个人声誉危机

**触发条件**:
- 负面新闻/不实报道
- 社交媒体恶意攻击
- 法律诉讼

**响应流程**:

```
T+0min: 蓝军监测到危机信号
       → 立即通知Egbertie
       → 启动危机响应小组

T+30min: 事实核查
        → 蓝军独立审计（信源/时效/因果）
        → 确认：真实问题 vs 虚假信息

T+60min: Egbertie决策
        → 如果是真实问题：承认+道歉+改进
        → 如果是虚假信息：澄清+法律手段

T+2h: 发布声明
      → 统一口径
      → 官方渠道发布
      → 不回应匿名攻击

T+24h: 持续跟进
       → 监测舆情变化
       → 准备深度回应（如需要）
       → 修复措施执行
```

**声明模板（真实问题）**:
```
关于[具体问题]，我们承认：[具体错误]

我们的反思：
1. [反思1]
2. [反思2]
3. [反思3]

改进措施：
1. [措施1]，完成时间：[日期]
2. [措施2]，完成时间：[日期]

感谢大家的监督和包容。
满意解研究所
日期
```

**声明模板（虚假信息）**:
```
关于[具体不实信息]，我们澄清：

事实1: [具体事实]
事实2: [具体事实]
事实3: [具体事实]

我们已委托律师处理此事。
对于恶意造谣者，我们将依法追究责任。

满意解研究所
日期
```

### 场景2：产品/服务质量危机

**触发条件**:
- 认证课程质量被质疑
- 测评系统出现重大错误
- 学员投诉批量爆发

**响应流程**:

```
T+0: 蓝军审计启动
     → 核查投诉真实性
     → 评估影响范围

T+4h: 满意姐制定应对方案
      → 如果是产品问题：立即修复+补偿
      → 如果是误解：澄清+教育

T+24h: 公开回应
       → 承认问题（如真实）
       → 说明改进措施
       → 补偿方案（如需要）

T+7d: 整改完成
      → 蓝军验收
      → 公开报告
```

## 三、P1级危机预案

### 场景3：竞品恶意攻击

**触发条件**:
- 竞品发布对比文章，贬低满意解
- 竞品挖角满意解导师/学员
- 竞品抄袭满意解方法论

**响应原则**:
- 不主动攻击竞品
- 用数据和事实回应
- 强化差异化价值

**回应模板**:
```
我们注意到[竞品名称]的[具体内容]。

满意解的定位是[具体定位]，
我们的优势是[具体优势]。

我们相信：
- 市场足够大，容得下不同的方法论
- 创业者需要的是"适合"，不是"最好"
- 竞争让我们更好

我们欢迎良性竞争，共同推动行业进步。

但如果是恶意中伤，我们将保留法律追究权利。
```

### 场景4：学员负面评价传播

**触发条件**:
- 学员在社交媒体发布负面评价
- 学员投诉被媒体关注
- 学员集体退费

**响应原则**:
- 先倾听，不辩解
- 再诊断，找原因
- 后行动，给方案

**回应模板**:
```
我们注意到[学员姓名]的反馈。

首先，道歉：
我们没有达到您的期望，这是我们的责任。

其次，诊断：
我们已启动内部审计，找出问题根源。

最后，行动：
1. [具体改进措施]
2. [补偿方案]
3. [跟进机制]

我们重视每一位学员的声音。
满意解的成长，离不开大家的监督。
```

## 五、危机后修复

### 修复流程

```
Step 1: 危机复盘（危机后7天内）
  → 事实梳理
  → 责任认定
  → 教训总结

Step 2: 改进措施（危机后30天内）
  → 制度完善
  → 流程优化
  → 培训加强

Step 3: 信任重建（危机后90天内）
  → 透明沟通
  → 持续改进
  → 正面内容

Step 4: 品牌修复（危机后180天内）
  → 成功案例
  → 权威背书
  → 行业影响
```

### 信任重建指标

| 指标 | 危机前 | 危机后目标 |
|:-----|:-------|:-----------|
| 品牌搜索量 | 100% | 恢复至80%+ |
| 客户满意度 | 8.5 | 恢复至8.0+ |
| 推荐率 | 60% | 恢复至50%+ |
| 负面提及占比 | <5% | 恢复至<10% |
