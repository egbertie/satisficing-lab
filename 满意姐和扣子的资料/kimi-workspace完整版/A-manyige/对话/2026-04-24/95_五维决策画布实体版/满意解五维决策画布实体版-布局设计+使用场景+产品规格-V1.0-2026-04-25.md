```
土·刘禹锡 —— 伦理底座
├─ 问题1：这个决策涉及哪些人？
├─ 问题2：各方的利益是什么？
├─ 问题3：是否存在利益冲突？
├─ 问题4：是否符合我们的价值观？
├─ 问题5：这个决策经得起道德考验吗？
└─ 评分：1-5分 _____

金·司马贺 —— 满意解标准
├─ 问题1：这个决策的可接受性如何？
├─ 问题2：这个决策的可行性如何？
├─ 问题3：这个决策的可持续性如何？
├─ 问题4：是否有更好的替代方案？
├─ 问题5：这个决策足够好吗？
└─ 评分：1-5分 _____

水·观自在 —— 洞察本质
├─ 问题1：这个问题的本质是什么？
├─ 问题2：我看见了什么？忽略了什么？
├─ 问题3：系统思考：会带来什么连锁反应？
├─ 问题4：情绪觉察：我的情绪在影响判断吗？
├─ 问题5：第一性原理：最基本的真理是什么？
└─ 评分：1-5分 _____

木·孔子 —— 信任治理
├─ 问题1：这个决策会如何影响信任？
├─ 问题2：透明度足够吗？
├─ 问题3：各方是否感到被尊重？
├─ 问题4：决策过程是否公平？
├─ 问题5：如何维护长期关系？
└─ 评分：1-5分 _____

火·六祖慧能 —— 行动转化
├─ 问题1：下一步具体行动是什么？
├─ 问题2：谁负责？什么时候完成？
├─ 问题3：如何快速验证？
├─ 问题4：如果错了，怎么调整？
├─ 问题5：如何持续迭代？
└─ 评分：1-5分 _____

【评分规则】
├─ 总分：5-25分
├─ 5-10分：高风险，需要重新审视
├─ 11-15分：中等，需要优化
├─ 16-20分：较好，可以执行
├─ 21-25分：优秀，果断执行
└─ 单项<3分：重点关注该维度
```

## 第二部分：使用场景

### 2.1 个人使用

```
【场景1：重大决策】
├─ 步骤：
│   1. 把画布铺在桌上
│   2. 写下决策问题
│   3. 逐维度填写
│   4. 评分
│   5. 总结决策
│   6. 拍照存档
└─ 时间：30-60分钟

【场景2：每日反思】
├─ 步骤：
│   1. 选当天一个重要决策
│   2. 快速填写（每维度5分钟）
│   3. 评分
│   4. 记录感受
└─ 时间：30分钟

【场景3：学习练习】
├─ 步骤：
│   1. 选一个案例
│   2. 用画布分析
│   3. 对比标准答案
│   4. 反思差异
└─ 时间：60分钟
```

---

### 2.2 团队使用

```
【场景1：团队决策会议】
├─ 步骤：
│   1. 把画布挂在墙上
│   2. 团队共同填写
│   3. 每人发表意见
│   4. 逐维度讨论
│   5. 达成共识
│   6. 记录决策
└─ 时间：1-2小时

【场景2：培训教学】
├─ 步骤：
│   1. 讲师讲解画布
│   2. 学员分组练习
│   3. 各组展示
│   4. 讲师点评
│   5. 总结要点
└─ 时间：2小时

【场景3：合伙人沟通】
├─ 步骤：
│   1. 双方共同填写
│   2. 了解对方视角
│   3. 发现分歧点
│   4. 协商解决
│   5. 达成共识
└─ 时间：1-2小时
```
