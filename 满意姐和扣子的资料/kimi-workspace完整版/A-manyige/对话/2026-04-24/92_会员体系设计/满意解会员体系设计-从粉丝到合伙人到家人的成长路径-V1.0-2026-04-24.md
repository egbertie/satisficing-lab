## 一、会员等级

### 五级会员体系

```
Level 1: 访客（Visitor）
  → 免费内容消费者
  → 门槛：关注公众号/注册
  → 权益：免费内容+测评

Level 2: 学员（Learner）
  → 付费课程消费者
  → 门槛：购买任意课程
  → 权益：课程+学员社群

Level 3: 持证者（Certified）
  → CDA认证获得者
  → 门槛：通过CDA考试
  → 权益：证书+校友社群+复训

Level 4: 导师（Mentor）
  → 教学贡献者
  → 门槛：CDA高级+导师认证
  → 权益：授课权+分成+荣誉

Level 5: 合伙人（Partner）
  → 深度绑定者
  → 门槛：推荐10人+贡献卓越
  → 权益：战略参与+终身权益
```

## 三、成长路径

### 从访客到学员

```
触发：完成免费测评
行动：推送课程介绍
激励：早鸟优惠+赠送资料
目标：购买初级认证
```

### 从学员到持证者

```
触发：完成课程学习
行动：推送考试提醒
激励：考试通过奖励+证书
目标：通过CDA考试
```

### 从持证者到导师

```
触发：持证1年+辅导经验
行动：推送导师招募
激励：导师培训+分成
目标：通过导师认证
```

### 从导师到合伙人

```
触发：推荐10人+贡献卓越
行动：邀请成为合伙人
激励：战略参与+分红
目标：签署合伙人协议
```

## 五、会员生命周期

### 生命周期管理

```
获客期（Visitor）
  → 内容触达
  → 免费测评
  → 邮件 nurture

激活期（Learner）
  → 课程学习
  → 社群融入
  → 作业完成

成长期（Certified）
  → 考试通过
  → 校友网络
  → 复训学习

成熟期（Mentor）
  → 教学贡献
  → 经验分享
  → 品牌代言

忠诚期（Partner）
  → 战略参与
  → 终身绑定
  → 共同成长

流失预警
  → 7天未登录 → 推送提醒
  → 30天未互动 → 专属优惠
  → 90天沉默 → 人工关怀
```
