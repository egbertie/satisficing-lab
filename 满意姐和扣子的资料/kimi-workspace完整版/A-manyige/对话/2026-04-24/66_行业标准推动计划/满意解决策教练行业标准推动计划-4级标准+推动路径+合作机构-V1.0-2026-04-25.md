## 第一部分：标准体系

### 1.1 职业标准

```
【合伙人决策教练职业能力标准】

Level 1：初级教练
├─ 知识：
│   ├─ 五维决策框架基础
│   ├─ 12类型冲突识别
│   └─ 基础测评方法
├─ 技能：
│   ├─ 能进行基础测评
│   ├─ 能识别冲突类型
│   └─ 能提供基础建议
├─ 经验：完成100小时学习
└─ 认证：CDA初级

Level 2：中级教练
├─ 知识：
│   ├─ 五维框架深入
│   ├─ 冲突调解方法
│   └─ 股权设计基础
├─ 技能：
│   ├─ 能进行深度咨询
│   ├─ 能调解冲突
│   └─ 能设计方案
├─ 经验：完成50个案例
└─ 认证：CDA中级

Level 3：高级教练
├─ 知识：
│   ├─ 全方法论精通
│   ├─ 复杂案例处理
│   └─ 团队/组织治理
├─ 技能：
│   ├─ 能处理复杂案例
│   ├─ 能培训教练
│   └─ 能设计组织方案
├─ 经验：完成200个案例
└─ 认证：CDA高级

Level 4：导师
├─ 要求：
│   ├─ 高级教练+5年经验
│   ├─ 有学术贡献
│   ├─ 有行业影响
│   └─ 能培养高级教练
└─ 认证：CDA导师
```

### 1.2 服务标准

```
【合伙人决策教练服务标准】

服务流程标准：
├─ Step 1：需求诊断（30分钟）
├─ Step 2：方案设计（1小时）
├─ Step 3：服务交付（按方案）
├─ Step 4：效果评估（30分钟）
└─ Step 5：跟进服务（持续）

服务质量标准：
├─ 响应时间：<24小时
├─ 服务时长：不少于约定
├─ 专业态度：客观、中立
├─ 保密义务：严格保密
├─ 效果追踪：3个月追踪
└─ 投诉处理：<48小时

服务收费标准：
├─ 初级教练：500-1000元/小时
├─ 中级教练：1000-2000元/小时
├─ 高级教练：2000-5000元/小时
├─ 导师：5000-10000元/小时
└─ 企业项目：按项目报价
```

## 第二部分：推动策略

### 2.1 推动路径

```
【第一阶段：内部建设】（2026）
├─ 完善认证体系
```
