## 第一部分：退出触发条件

### 1.1 主动退出（Voluntary Exit）

```
【定义】合伙人主动提出离开，无重大争议

【典型场景】
├─ 家庭原因需要 relocation
├─ 找到更适合自己的新机会
├─ 创业方向与个人兴趣偏离
├─ 健康问题
├─ 财务需求（需要变现股权）
└─ 个人发展（想尝试新领域）

【触发条件】
├─ 提前3-6个月书面通知
├─ 说明退出原因（可选，但有助于关系维护）
├─ 无重大违约行为
└─ 双方同意"和平分手"

【退出流程】
Step 1: 提出退出意向（书面通知）
Step 2: 股权评估（已成熟/未成熟股权）
Step 3: 工作交接（客户/项目/文档）
Step 4: 法律文件签署（股权转让+离职确认）
Step 5: 回购款支付（按约定方式）
Step 6: 关系维护（保持联系，潜在顾问/合作）

【时间线】
Month 1-2: 提出 → 协商 → 确定退出日期
Month 2-3: 股权评估 → 确定回购价格 → 签署协议
Month 3-4: 工作交接 → 知识转移 → 客户关系移交
Month 4-6: 回购款支付（一次性或分期）
Month 6+: 保持联系 → 潜在顾问/合作

总计：4-6个月
```

---

### 1.2 协商退出（Negotiated Exit）

```
【定义】合伙人之间有分歧，但同意"分手是更好的选择"

【典型场景】
├─ 战略方向分歧（如"应该做B2B还是B2C"）
├─ 权力分配不满（如"我觉得我被边缘化了"）
├─ 贡献评估争议（如"我付出比他多，股权一样不公平"）
├─ 价值观分歧（如"对公司文化有不同理解"）
└─ 长期沟通不畅（信任破裂但未达违约）

【触发条件】
├─ 双方同意分手
├─ 需要第三方协助定价或调解
└─ 可能涉及股权调整或回购

【退出流程】
Step 1: 争议识别与升级（内部协商）
Step 2: 调解介入（独立董事/顾问/专业机构）
Step 3: 估值与定价（双方各聘请估值专家或共同聘请）
Step 4: 达成协议（签署调解协议）
Step 5: 执行与交割（按协议执行股权回购）

【调解成本】
├─ 内部协商：0成本
├─ 顾问调解：1-3万
├─ 律师协商：3-10万
├─ 仲裁：10-30万
└─ 诉讼：30万+

【建议】尽量在"律师协商"阶段解决，不要走到仲裁/诉讼。
```

---

### 1.3 强制退出（Forced Exit）

```
【定义】因重大违约/失职/道德问题，被迫退出

【典型场景】
├─ 挪用公司资金或资产
├─ 为竞争对手工作或泄露核心机密
├─ 欺诈行为（虚假报销、伪造数据）
├─ 严重违反法律法规（刑事责任）
├─ 性骚扰或职场霸凌（经调查确认）
├─ 连续3个月不履行核心职责
├─ 未经同意从事竞争性业务
├─ 重大过失导致公司损失（如泄露客户数据）
└─ 违反竞业限制（情节较轻）

【触发条件】
├─ 事先约定的"重大违约清单"
├─ 调查小组成立（其他合伙人+独立董事）
├─ 给予申辩机会（7-14天）
├─ 根据调查结果做出决定
└─ 书面通知解雇决定

【退出流程】
Step 1: 违约发现与证据收集（书面记录+证据）
Step 2: 内部调查（调查小组+听取陈述）
Step 3: 通知与申辩（书面通知+申辩期）
Step 4: 决定与执行（解雇决定+股权处理）
Step 5: 股权强制回购（按违约条款）
Step 6: 法律收尾（签署文件，如不配合则法律程序）

【回购定价】
├─ 一级违约（挪用资金/竞业/欺诈）：回购价格 = 原始出资额 × 50% × 已成熟比例
├─ 二级违约（失职/过失）：回购价格 = 原始出资额 × 80% × 已成熟比例
└─ 注意：强制回购不能为"零"（可能被法院认定为惩罚性条款而无效）
```

## 第二部分：股权处理机制

### 2.1 成熟股权处理

```
【定义】合伙人已按照Vesting计划获得的股权

【处理方式】
├─ 选项A：公司回购（公司出钱买回去）
├─ 选项B：其他合伙人购买（按比例或协商）
├─ 选项C：保留股权（退出者保留少数股权，成为被动股东）
└─ 选项D：转让给第三方（需全体合伙人同意）

【回购价格公式】（事先约定）

公式A：原始出资 + 年化利息法
回购价格 = 原始出资额 × (1 + 年化利率10%) × 已成熟比例

公式B：最近融资估值折扣法
回购价格 = 最近融资估值 × 股权比例 × 折扣率（30-50%）

公式C：账面净资产法
回购价格 = 公司净资产 × 股权比例

【建议】事先约定用哪种公式，避免争议时临时定价。

【回购方式】
├─ 一次性支付（公司现金流允许）
├─ 分期24个月支付（减轻公司压力）
└─ 转为债权（公司承诺未来某个时间点支付）
```

---

### 2.2 未成熟股权处理

```
【定义】合伙人尚未按照Vesting计划获得的股权

【处理方式】
├─ 友好退出：公司零成本回购（未成熟股权作废）
├─ 争议退出：协商决定是否给予部分成熟
└─ 强制退出：公司零成本回购（未成熟股权作废）

【特殊情况】
├─ 被公司解雇（非主动退出）：按实际工作时间比例成熟
├─ 重大疾病/家庭变故：董事会酌情决定
└─ 死亡/丧失能力：公司回购，家属获得回购款

【回购价格】
未成熟股权通常零成本回购，
但如果是公司单方面解雇（非合伙人过错），
建议给予一定补偿（如原始出资额的50%）。
```

---

### 2.3 股权调整池

```
【定义】初始分配时预留的"调整池"，用于里程碑调整

【用途】
├─ 当合伙人贡献超预期时，从调整池划拨股权奖励
├─ 当新增合伙人时，从调整池分配股权
└─ 当合伙人退出时，调整池回收股权

【规则】
├─ 调整池通常占初始股权的5-10%
├─ 调整需全体一致同意
├─ 调整池用完不再追加（除非新一轮融资稀释后重建）
└─ 调整幅度单次不超过2-3%

【示例】
初始分配：
├─ 合伙人A：40%
├─ 合伙人B：35%
├─ 合伙人C：20%
└─ 调整池：5%

当合伙人C贡献超预期：
→ 从调整池划拨2%给C
→ C变为22%，调整池变为3%

当合伙人C退出：
→ C的22%股权由公司回购
→ 回购的股权进入期权池或重新分配
```

## 第三部分：资产分割

### 3.1 知识产权归属

```
【退出前开发的IP】
├─ 归公司所有（劳动合同/合伙人协议的标准条款）
├─ 包括：专利、著作权、商标、技术方案、代码、产品设计
└─ 退出者无权带走或使用

【退出后开发的IP】
├─ 与原公司业务无关的新IP → 归退出者个人
├─ 利用原公司资源/信息开发的新IP → 可能归公司
└─ 模糊地带 → 事先约定或争议解决

【建议条款】
"退出后12个月内开发的、与公司业务相关的知识产权，
公司有优先购买权，价格按独立评估确定。"
```

---

### 3.2 客户关系移交

```
【移交内容】
├─ 客户名单与联系方式
├─ 客户历史沟通记录
├─ 客户合同/协议
├─ 客户需求与偏好
└─ 客户关系维护计划

【移交流程】
Step 1: 退出者提供客户清单
Step 2: 公司指定接收人（其他合伙人或新负责人）
Step 3: 退出者协助介绍（"这是我同事，以后由TA负责"）
Step 4: 公司向客户发送正式通知（"负责人变更"）
Step 5: 接收人跟进客户关系（确保平稳过渡）

【保密义务】
退出者不得利用客户关系从事竞争性业务，
不得向第三方泄露客户信息。
```

---

### 3.3 数据与资料移交

```
【移交内容】
├─ 项目文档/代码/设计稿
├─ 财务记录/报销凭证
├─ 供应商/合作伙伴合同
├─ 内部流程/制度文件
├─ 账号/密码/权限
└─ 其他公司资料

【移交流程】
Step 1: 列出资料清单
Step 2: 逐项移交（签字确认）
Step 3: 电子资料拷贝/移交
Step 4: 账号权限回收
Step 5: 删除个人资料（保留公司资料）

【注意事项】
├─ 退出者不得删除/破坏公司资料
├─ 退出者不得保留公司机密资料
├─ 公司不得保留退出者个人隐私资料
└─ 双方签署"资料移交确认书"
```

## 第四部分：竞业限制与保密

### 4.1 竞业限制（Non-Compete）

```
【限制范围】
├─ 限制期限：6-24个月（通常12个月）
├─ 限制行业：同一细分行业/同一客户群体
├─ 限制地域：公司主要市场范围
├─ 限制行为：不得创办竞争性公司/不得加入竞争对手
└─ 补偿：公司支付竞业补偿金（通常为月薪的30-50%）

【违约后果】
├─ 停止补偿
├─ 追偿损失
├─ 法律诉讼
└─ 注意：竞业限制必须"有补偿"才有效（中国劳动法要求）

【建议条款】
"退出后12个月内，不得从事与满意解直接竞争的业务。
公司每月支付竞业补偿金[X]元。
如违约，需赔偿公司实际损失。"
```

---

### 4.2 保密义务（NDA）

```
【保密信息清单】
├─ 客户名单与联系方式
├─ 供应商合同与价格
├─ 技术方案与源代码
├─ 财务数据与融资条款
├─ 商业计划与战略方向
├─ 员工薪酬信息
└─ 其他公司机密信息

【保密期限】
├─ 永久保密：商业机密
├─ 限期保密：产品路线图、战略计划（通常2-3年）
├─ 公开信息除外：已公开的信息不受限
└─ 法律要求除外：法院/监管机构要求披露时

【违约后果】
├─ 赔偿实际损失
├─ 可能的惩罚性赔偿
└─ 法律诉讼
```

## 第五部分：争议解决机制

### 5.1 五级争议解决阶梯

```
┌─────────────────────────────────────────────────────────┐
│              争议解决成本阶梯（从低到高）                  │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  Level 1: 内部协商（0成本）                              │
│     ↑ 如果失败 →                                        │
│  Level 2: 五路图腾调解（低关系成本）                       │
│     ↑ 如果失败 →                                        │
│  Level 3: 第三方调解/仲裁（中等成本）                     │
│     ↑ 如果失败 →                                        │
│  Level 4: 律师协商/谈判（较高成本）                       │
│     ↑ 如果失败 →                                        │
│  Level 5: 诉讼（最高成本）                                │
│                                                         │
│  核心原则："能不走法律程序就不走，但该走时必须走。"      │
│                                                         │
└─────────────────────────────────────────────────────────┘

【调解成本对比】

| 调解方式 | 成本 | 时间 | 关系影响 | 适用场景 |
|:---------|:-----|:-----|:---------|:---------|
| 内部协商 | 0 | 1-2月 | 最小 | 分歧较小，双方理性 |
| 顾问调解 | 1-3万 | 1-3月 | 较小 | 需要中立第三方 |
| 律师协商 | 3-10万 | 2-4月 | 中等 | 分歧较大，需要法律框架 |
| 仲裁 | 10-30万 | 3-6月 | 较大 | 调解失败，需强制裁决 |
| 诉讼 | 30万+ | 6-12月+ | 最大 | 所有方式失败 |

【建议】尽量在"律师协商"阶段解决，不要走到仲裁/诉讼。
```

---

### 5.2 "调解前置"条款

```
【在合伙人协议中加入】

"任何合伙人争议，双方同意在提起诉讼或仲裁前，
必须先经过以下步骤：

1. 内部协商（不少于2次正式会议）
2. 第三方调解（不少于1次正式调解）

上述步骤完成后，方可启动仲裁或诉讼。

违反调解前置条款直接起诉的一方，
如最终判决/裁决结果不优于调解方案，
应承担对方全部律师费。"

【作用】
├─ 强制双方先尝试低成本方式
├─ 防止一方"一言不合就起诉"
├─ 给关系修复留时间窗口
└─ 降低争议解决成本
```

## 第六部分：创始人5分钟可用性检验

### 退出机制自检清单

| # | 检验项 | 通过标准 |
|:-:|--------|:---------|
| 1 | 你们讨论过退出机制吗？ | "讨论过，有书面约定" |
| 2 | 股权回购价格有公式吗？ | "有，按XX公式" |
| 3 | Vesting条款明确吗？ | "有，4年vesting，1年cliff" |
| 4 | 重大违约的定义明确吗？ | "有清单，分三级" |
| 5 | 竞业限制有补偿吗？ | "有，每月XX元" |
| 6 | 知识产权归属约定了吗？ | "在职期间归公司" |
| 7 | 客户关系移交流程明确吗？ | "有，分5步" |
| 8 | 争议解决路径约定了吗？ | "有，调解前置" |

**如果8项都通过**：退出机制完备。
**如果有1-2项不清楚**：本周内补齐。
**如果有3项以上不清楚**：高风险——立即处理。
