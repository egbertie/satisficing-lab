## 第一部分：项目设计

### 1.1 公益组织合伙人支持计划

```
【项目名称】
"公益合伙人——让做好事的人，也能走到最后"

【目标对象】
├─ 社会企业
├─ 公益基金会
├─ NGO/NPO
├─ 志愿者组织
└─ 社会创新团队

【服务内容】
├─ 免费测评：合伙人匹配度测评
├─ 免费咨询：1次免费咨询
├─ 免费课程：CDA初级课程（限名额）
├─ 工具包：免费工具包
└─ 社群：公益组织专属社群

【执行方式】
├─ 申请制：提交申请
├─ 审核制：审核资质
├─ 配额制：每年100家
├─ 服务期：1年
└─ 续期：评估后续期

【资源投入】
├─ 人力：导师志愿时间
├─ 资金：年度预算10万
├─ 产品：免费产品
└─ 品牌：联合品牌
```

## 第二部分：执行机制

### 2.1 组织架构

```
【公益委员会】
├─ 组成：Egbertie+员工代表+外部专家
├─ 职责：
│   ├─ 制定公益战略
│   ├─ 审批公益项目
│   ├─ 监督执行
│   └─ 年度报告
└─ 会议：每季度1次

【公益执行组】
├─ 组成：1名专职+志愿者
├─ 职责：
│   ├─ 项目执行
│   ├─ 合作对接
│   ├─ 效果评估
│   └─ 宣传报道
└─ 汇报：向委员会汇报
```

---

### 2.2 资金来源

```
【来源1：公司拨款】
├─ 比例：年度利润的1%
├─ 用途：公益项目运营
└─ 管理：专项管理

【来源2：产品捐赠】
├─ 形式：免费提供服务
├─ 价值：按市场价计算
└─ 记录：记录捐赠

【来源3：员工志愿】
├─ 形式：员工志愿时间
├─ 激励：计入绩效
└─ 文化：鼓励参与

【来源4：社会捐赠】
├─ 形式：接受定向捐赠
├─ 用途：指定项目
└─ 管理：透明公开
```

> **核心原则**：
> 公益不是"施舍"，是"赋能"。
>
> 好的公益：
> ├─ 解决真问题（不是作秀）
> ├─ 可持续（不是一次性的）
> ├─ 有专业（用专业能力）
> └─ 可衡量（有数据）
>
> 满意解的公益信仰：
> "让每一对合伙人，无论贫富，都能走到最后。"
