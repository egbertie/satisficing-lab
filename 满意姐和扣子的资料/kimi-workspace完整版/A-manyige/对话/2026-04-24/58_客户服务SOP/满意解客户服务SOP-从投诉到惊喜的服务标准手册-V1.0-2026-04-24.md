## 一、服务哲学

### 满意解服务标准

| 维度 | 标准 | 说明 |
|:-----|:-----|:-----|
| **速度** | <30分钟首次响应 | 让客户感到被重视 |
| **专业** | 用五维框架分析问题 | 展示方法论价值 |
| **温度** | 像朋友一样沟通 | 不官方、不冷漠 |
| **解决** | 一次性解决或明确时间表 | 不让客户等待 |
| **惊喜** | 超预期服务 | 超出期望的10% |

### 服务原则

> "客户不是'投诉者'，是'帮助我们改进的人'。"
>
> "每一个投诉，都是一次建立信任的机会。"
>
> "解决客户的问题，比成交一个新客户更有价值。"

## 二、服务场景SOP

### 场景1：产品咨询

**触发**: 客户询问课程/服务/价格

**响应时间**: <15分钟

**流程**:

```
Step 1: 问候+确认需求
"您好！感谢咨询满意解。
想了解哪方面的服务？
合伙人匹配测评 / CDA认证 / 1v1教练 / 企业内训？"

Step 2: 诊断+推荐
"根据您的情况，我建议：
- 如果是初步了解 → 免费测评
- 如果想系统学习 → CDA初级认证
- 如果有紧急问题 → 1v1教练"

Step 3: 价值说明+CTA
"这个服务能帮您：[具体价值]
现在报名：[优惠/福利]
[链接]"

Step 4: 跟进（24小时后未成交）
"昨天咨询的[服务]，还有疑问吗？
我可以为您解答。"
```

---

### 场景2：退款申请

**触发**: 客户申请退款

**响应时间**: <30分钟

**流程**:

```
Step 1: 确认+致歉
"收到您的退款申请，非常抱歉没能让您满意。
7天无理由退款是我们的承诺，立即处理。"

Step 2: 诊断原因
"能否告诉我，是什么让您不满意？
是内容、服务、还是其他？
您的反馈对我们非常宝贵。"

Step 3: 处理退款
"退款已提交，3-5个工作日原路返回。
退款金额：¥[金额]
如有疑问，随时联系。"

Step 4: 挽留（可选）
"如果您愿意，我们可以：
- 换其他课程
- 延期学习
- 1v1辅导解决问题
无论选择什么，尊重您的决定。"

Step 5: 复盘
记录退款原因，每周汇总分析。
```

### 场景3：投诉处理

**触发**: 客户表达不满/投诉

**响应时间**: <15分钟（紧急）/ <1小时（一般）

**流程**:

```
Step 1: 安抚情绪
"非常抱歉给您带来不好的体验。
我理解您的感受，换成是我也会生气。
请给我一点时间，我一定解决。"

Step 2: 了解详情
"能否详细描述一下发生了什么？
时间、人物、问题。
越详细，我解决得越快。"

Step 3: 快速解决
- 能立即解决的：立即执行
- 需要时间的：明确时间表
"问题已记录，[具体解决时间]前给您答复。"

Step 4: 补偿（如需要）
"为表达歉意，我们提供：
- [补偿方案]
希望您能给我们一次改进的机会。"

Step 5: 跟进+复盘
解决后24小时内回访：
"问题是否已解决？还有哪里需要改进？"

投诉记录归档，每周分析Top 3问题。
```

### 场景4：技术支持

**触发**: 客户遇到技术问题（登录/支付/报告生成）

**响应时间**: <30分钟

**流程**:

```
Step 1: 确认问题
"遇到技术问题，我来帮您。
请描述：
1. 什么问题？
2. 什么时候开始的？
3. 用的什么设备/浏览器？"

Step 2: 自助解决（80%问题）
"请尝试：
1. 清除缓存
2. 换浏览器
3. 重启设备
如仍有问题，告诉我具体错误提示。"

Step 3: 人工解决（20%问题）
"问题已转技术团队，[时间]内解决。
解决后第一时间通知您。"

Step 4: 确认解决
"问题已修复，请再次尝试。
如还有问题，随时联系。"
```

### 场景5：学习支持

**触发**: 学员学习过程中遇到问题

**响应时间**: <2小时（工作日）/ <24小时（周末）

**流程**:

```
Step 1: 诊断学习障碍
"学习遇到什么问题？
是内容理解、时间管理、还是动力不足？"

Step 2: 针对性支持
- 内容理解 → 提供补充资料/视频
- 时间管理 → 提供学习计划模板
- 动力不足 → 社群鼓励+导师1v1

Step 3: 进度跟进
"本周目标：完成模块[X]
每天投入：[X]分钟
加油！"

Step 4: 庆祝里程碑
"恭喜完成模块[X]！
您的进度：[X]%
继续保持！"
```

## 三、服务话术库

### 温度话术

| 场景 | ❌ 禁止 | ✅ 推荐 |
|:-----|:--------|:--------|
| 问候 | "您好，有什么可以帮您？" | "Hi [名字]，很高兴收到您的消息" |
| 等待 | "请稍等" | "给我2分钟，我查一下" |
| 道歉 | "抱歉" | "非常抱歉，这是我的责任" |
| 感谢 | "谢谢" | "感谢您的耐心，这对我很重要" |
| 结束 | "还有什么可以帮您？" | "还有其他需要我帮忙的吗？" |
| 跟进 | "稍后联系" | "明天下午3点，我再来确认" |

### 专业话术

| 场景 | 话术 |
|:-----|:-----|
| 解释五维框架 | "用五维框架帮您分析一下：土（伦理）、金（满意解）、水（洞察）、木（信任）、火（直觉）..." |
| 推荐产品 | "根据您的情况，[产品]最适合，因为[原因]。如果不合适，[替代方案]也可以。" |
| 处理投诉 | "我理解您的感受。用五维框架看，这是[类型]问题，解决方法是[方案]。" |
| 拒绝不合理要求 | "这个要求超出了我们的服务范围，但我可以帮您[替代方案]。" |
