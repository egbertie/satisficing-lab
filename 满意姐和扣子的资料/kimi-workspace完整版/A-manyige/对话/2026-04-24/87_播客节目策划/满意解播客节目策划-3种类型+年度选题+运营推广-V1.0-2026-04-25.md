## 使用说明

```
🎧 满意解播客节目策划 —— "创始人耳机里的决策顾问"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

为什么需要播客？
因为"开车时不能看视频"，"但可以听播客"。

播客价值：
├─ 深度内容：音频适合长内容
├─ 陪伴感：像朋友聊天
├─ 场景多：开车、运动、家务
├─ 粘性高：听众忠诚度高
├─ 成本低：制作成本相对低
└─ 变现强：广告+付费内容

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

节目规划：
├─ 名称：满意解电台
├─ 频率：每月2期
├─ 时长：45-60分钟
├─ 形式：对谈/独白/访谈
└─ 平台：小宇宙/喜马拉雅/Spotify

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 第一部分：节目架构

### 1.1 节目类型

```
【类型1：创始人访谈】（50%）
├─ 主题：创始人的合伙人故事
├─ 嘉宾：成功/踩坑的创始人
├─ 时长：60分钟
├─ 结构：
│   ├─ 开场（5分钟）：嘉宾介绍
│   ├─ 故事（30分钟）：合伙人经历
│   ├─ 方法（15分钟）：用到的决策方法
│   ├─ 建议（10分钟）：给听众的建议
│   └─ 结尾（5分钟）：金句+预告
└─ 示例："从合伙人反目到重归于好，他用了什么方法？"

【类型2：方法论讲解】（30%）
├─ 主题：五维决策/12类型/工具
├─ 嘉宾：Egbertie/导师
├─ 时长：45分钟
├─ 结构：
│   ├─ 开场（5分钟）：问题引入
│   ├─ 理论（20分钟）：方法论讲解
│   ├─ 案例（15分钟）：实际应用
│   ├─ 工具（5分钟）：工具介绍
│   └─ 结尾（5分钟）：总结+行动
└─ 示例："五维决策框架：让直觉有科学依据"

【类型3：QA答疑】（20%）
├─ 主题：回答听众问题
├─ 嘉宾：Egbertie
├─ 时长：45分钟
├─ 结构：
│   ├─ 开场（5分钟）：主题介绍
│   ├─ 问答（35分钟）：回答3-5个问题
│   ├─ 深度（5分钟）：深入分析
│   └─ 结尾（5分钟）：总结+预告
└─ 示例："合伙人股权怎么分？这5个问题帮你理清"
```

---

### 1.2 节目格式

```
【片头】（30秒）
├─ 音乐：品牌音乐
├─ 旁白："欢迎收听满意解电台..."
├─ 本期预告
└─ 音乐过渡

【开场】（5分钟）
├─ 主持人开场
├─ 本期主题介绍
├─ 嘉宾介绍
└─ 轻松寒暄

【正文】（30-45分钟）
├─ 核心内容
├─ 互动问答
├─ 故事讲述
└─ 方法分享

【结尾】（5分钟）
├─ 本期要点回顾
├─ 金句总结
├─ 下期预告
├─ CTA：关注/订阅/扫码
└─ 片尾音乐
```

## 第二部分：内容策划

### 2.1 年度选题规划

```
【2026年选题】

Q1：
├─ 1月：新年规划——创始人如何规划新的一年
├─ 2月：情人节特辑——合伙人关系中的"爱"与"恨"
└─ 3月：女性创始人——女性视角下的合伙人决策

Q2：
├─ 4月：春季招聘——招合伙人还是招员工？
├─ 5月：股权设计——合伙人股权怎么分才公平
└─ 6月：年中复盘——半年了，合伙人关系健康吗？

Q3：
├─ 7月：毕业季——从同学到合伙人
├─ 8月：创业低谷——合伙人如何共渡难关
└─ 9月：秋季启动——新合伙人加入怎么办？

Q4：
├─ 10月：国庆特辑——合伙人的"家国情怀"
├─ 11月：年终盘点——合伙人年度关系体检
└─ 12月：新年展望——明年的合伙人规划
```

---

### 2.2 单期策划流程

```
【Step 1：选题】（提前2周）
├─ 来源：
│   ├─ 热点事件
│   ├─ 用户问题
│   ├─ 季节节点
│   └─ 系列规划
├─ 标准：
│   ├─ 听众关心
│   ├─ 有话题性
│   ├─ 能讲深度
│   └─ 符合品牌
└─ 产出：选题+大纲

【Step 2：嘉宾邀请】（提前2周）
├─ 确认：嘉宾档期
├─ 沟通：节目流程
├─ 准备：背景资料
└─ 产出：嘉宾确认

【Step 3：脚本准备】（提前1周）
├─ 大纲：节目大纲
├─ 问题：提问清单
├─ 资料：案例/数据
├─ 金句：预备金句
└─ 产出：完整脚本

【Step 4：录制】（提前3天）
├─ 设备：麦克风+录音环境
├─ 流程：按脚本录制
├─ 备份：双机备份
├─ 时长：录制1.5小时
└─ 产出：原始音频

【Step 5：剪辑】（提前2天）
├─ 粗剪：剪掉NG
├─ 精剪：调整节奏
├─ 包装：片头片尾+音乐
├─ 字幕：重点内容字幕
└─ 产出：成品音频

【Step 6：发布】（当天）
├─ 上传：各平台
├─ 文案：节目介绍
├─ 推广：社交媒体
├─ 互动：评论区互动
└─ 产出：上线节目

【Step 7：复盘】（次日）
├─ 数据：播放量/评论
├─ 反馈：用户反馈
├─ 总结：经验教训
└─ 产出：复盘报告
```

## 第三部分：运营推广

### 3.1 平台运营

```
【平台选择】

国内：
├─ 小宇宙：播客主阵地，用户质量高
├─ 喜马拉雅：流量大，覆盖广
├─ 网易云音乐：音乐用户转化
├─ 荔枝FM：年轻用户
└─ 微信听书：私域流量

国际：
├─ Spotify：国际市场
├─ Apple Podcasts：苹果用户
├─ Google Podcasts：安卓用户
└─ Overcast：播客爱好者

【运营策略】
├─ 同步发布：全平台同步
├─ 封面统一：品牌封面
├─ 描述优化：SEO优化
├─ 标签设置：精准标签
├─ 更新稳定：按时更新
└─ 互动回复：评论互动
```

---

### 3.2 变现模式

```
【模式1：付费订阅】
├─ 形式：部分节目付费
├─ 价格：9.9-29.9元/期
├─ 内容：深度内容/独家访谈
└─ 平台：小宇宙/得到

【模式2：广告合作】
├─ 形式：口播广告/片尾广告
├─ 价格：5000-20000元/期
├─ 品牌：与创业相关品牌
└─ 标准：不影响内容质量

【模式3：内容联动】
├─ 形式：播客→课程→咨询
├─ 路径：免费播客→付费课程→1v1咨询
├─ 转化：播客听众→用户
└─ 目标：转化率>5%

【模式4：会员专享】
├─ 形式：会员专属播客
├─ 内容：深度/独家/提前
├─ 权益：会员权益之一
└─ 目标：促进会员转化
```

---

> **核心原则**：
> 播客不是"广播"，是"对话"。
>
> 好的播客：
> ├─ 像朋友聊天（不端着）
> ├─ 有深度内容（不肤浅）
> ├─ 有陪伴感（不孤单）
> └─ 有记忆点（不忘记）
>
> 满意解的播客信仰：
> "让每一位创始人，在开车时也能成长。"
