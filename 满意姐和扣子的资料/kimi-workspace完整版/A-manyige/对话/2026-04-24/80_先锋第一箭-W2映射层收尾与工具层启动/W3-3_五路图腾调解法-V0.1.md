# 五路图腾调解法 V0.1

> **编制时间**: 2026-04-25
> **编制者**: 满意姐（SAT-001）+ 蓝军 Skeptor-7
> **用途**: 当合伙人之间产生争议，用五维决策框架进行调解
> **原则**: 不是"判对错"，是"找满意解"——让双方都能接受的解决方案
> **配套**: 合伙人退出路径图（争议退出路径）+ 动态股权框架（回购定价）

## 使用说明

```
🧘 五路图腾调解法 —— 用满意解的哲学解决合伙人争议
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

为什么需要这个？
因为大多数合伙人调解失败，不是因为问题太难，
是因为调解者（或其他合伙人）在"站队"。

五路图腾调解法的核心：
不站队，站"关系"。
不是"谁对谁错"，是"怎么让这段关系活下去"。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 第二部分：调解五步流程

### Step 1：土·建立安全空间（刘禹锡）

**目标**：让双方愿意开口说真话。

**操作**：
```
环境准备：
├─ 中立地点（不在任何一方的办公室）
├─ 充足时间（至少2小时，不赶时间）
├─ 无干扰（手机静音，不接电话）
└─ 可选：第三方调解人（非利益相关者）

开场话术（调解人）：
"我们今天不是来分对错的。
我们是来找出一条让双方都能接受的出路。
在这里，说什么都不会被秋后算账。
我们唯一的目标：找到一个满意解。"

规则设定：
├─ 1. 一人说话，另一人不打断
├─ 2. 先讲"我需要什么"，再讲"他做错了什么"
├─ 3. 不翻旧账（只讨论当前争议）
└─ 4. 任何方案都可以提，不批评
```

---

### Step 2：金·明确争议焦点（司马贺）

**目标**：把"我很不爽"变成"我们争议的具体问题是什么"。

**操作**：
```
争议分类（帮助双方定位问题）：

┌────────────────────────────────────────┐
│  Type A: 事实争议                        │
│  "他上周没来上班" vs "我来了，只是没打卡"  │
│  → 解决：查考勤记录/监控/邮件时间戳       │
├────────────────────────────────────────┤
│  Type B: 价值争议                         │
│  "我们应该做B2B" vs "B2C才是未来"         │
│  → 解决：市场数据验证/小规模测试/投票     │
├────────────────────────────────────────┤
│  Type C: 利益争议                         │
│  "我的股权应该更多" vs "现在的分配很公平"  │
│  → 解决：贡献评估/市场参照/调整机制       │
├────────────────────────────────────────┤
│  Type D: 关系争议                         │
│  "他不尊重我" vs "我尊重他，只是比较直接"  │
│  → 解决：沟通方式调整/角色边界明确        │
└────────────────────────────────────────┘

问题聚焦话术：
"我们现在争议的核心，属于哪一类？
是事实不清楚、方向不统一、利益分配不均，还是相处方式有问题？"
```

---

### Step 3：水·深度倾听需求（观自在）

**目标**：听到"立场"背后的"利益"——双方到底要什么。

**操作**：
```
经典对话重构：

表面立场（双方说的）：
A: "我要股权增加到30%"
B: "股权不能动，现在的分配很公平"

深层利益（调解人引导发现）：
├─ A的真实需求："我觉得我的贡献被低估了，我需要被认可"
├─ B的真实需求："我担心股权变动会破坏团队稳定"
└─ 共同点：都希望公司好，都担心不公平

引导话术：
"A说想要30%股权——A，如果我们不调整股权，
还有什么方式能让你感到你的贡献被认可？

B说不能动股权——B，如果A的贡献确实超预期了，
除了股权，还有什么方式可以奖励他？"

关键洞察：
70%的股权争议，其实不是"要更多钱"，是"要更多认可"。
如果找到非股权的认可方式，争议可能迎刃而解。
```

---

### Step 4：木·伦理底线检查（孔子）

**目标**：确保任何解决方案不违背伦理和长期信任。

**操作**：
```
伦理检查清单：

| # | 检查项 | 如果为"是"，方案需要调整 |
|:-:|--------|:------------------------|
| 1 | 这个方案会让任何一方感到被羞辱吗？ | 是 → 修改方案 |
| 2 | 这个方案会留下长期怨恨吗？ | 是 → 增加补偿/道歉环节 |
| 3 | 这个方案对未来合伙人有不好的先例吗？ | 是 → 增加"本次特殊"说明 |
| 4 | 这个方案有人"赢"有人"输"吗？ | 是 → 寻找双赢变体 |
| 5 | 这个方案执行后，双方还能一起工作吗？ | 否 → 重新设计 |

孔子式提问：
"如果我们按这个方案执行，5年后回头看，
我们会为今天的决定骄傲吗？
还是会觉得有一方被欺负了？"
```

---

### Step 5：火·创造性破局（六祖慧能）

**目标**：当A和B僵持不下时，引入C选项。

**操作**：
```
第三选项生成法：

场景：A想转型B2B，B坚持做B2C，僵持不下。

传统思路：投票/CEO拍板/一方妥协。
满意解思路：有没有C选项，让双方都能实现核心诉求？

示例C选项：
├─ C1: 双轨测试（3个月B2B试点 + 3个月B2C试点，数据决定）
├─ C2: 分拆团队（A带B2B小组，B带B2C小组，赛马机制）
├─ C3: 寻找交集（B2B2C模式，企业客户的个人用户）
├─ C4: 阶段性切换（先做B2C积累用户，6个月后切入B2B）
└─ C5: 外部验证（请3个客户/投资人投票，听市场的）

六祖慧能式提问：
"如果A的方案和B的方案都不可行，
有没有第三种方式，能同时满足A的'稳定收入需求'和B的'规模增长需求'？"

关键原则：
不是"谁对谁错"，是"怎么让双方都得到最核心的东西"。
```

## 第三部分：典型争议场景调解方案

### 场景1：股权分配争议

```
争议：A认为贡献大应增持，B认为现有分配公平。

五路图腾调解：

土（刘禹锡）：
"我们先不讨论具体数字，先确认一下：
双方都同意'贡献和股权应该挂钩'，对吗？"
→ 建立共识基础

金（司马贺）：
"争议焦点：A的实际贡献是否超过初始预期？
我们怎么衡量贡献？"
→ 引入贡献评估标准（时间/目标/不可替代性/资源/文化）

水（观自在）：
"A，如果你不能增持股权，你最不能接受的是什么？
B，如果A的贡献确实超预期，你最担心的是什么？"
→ A：担心长期不公平 → B：担心先例导致频繁调整

木（孔子）：
"如果我们调整股权，怎么确保未来不频繁调整？"
→ 建立"调整池+年度评估"机制

火（六祖慧能）：
"除了调整股权，还有什么方式让A感到被认可？"
→ 方案C：股权不动，但A获得额外期权/奖金/决策权

满意解：
股权结构不变（保护B的稳定感），
但建立年度贡献评估机制（满足A的公平感），
超额贡献用期权池奖励（不稀释现有股权）。
```

---

### 场景2：战略方向争议

```
争议：A想做B2B，B想做B2C。

五路图腾调解：

土（刘禹锡）：
"双方都认同公司需要增长，只是路径不同。对吗？"

金（司马贺）：
"我们争议的焦点是'哪个路径更快'，不是'要不要增长'。
我们能不能用数据说话？"

水（观自在）：
"A，B2B对你意味着什么？（稳定客户/高客单/可预测）
B，B2C对你意味着什么？（规模效应/品牌知名度/网络效应）"
→ 发现：A要稳定，B要规模

木（孔子）：
"如果我们现在选A，B会不会觉得被否定？
如果我们现在选B，A会不会觉得风险太大？"

火（六祖慧能）：
"有没有一条路径，既有稳定客户，又能做规模？"
→ 方案C：B2B2C（先服务大企业，通过大企业触达个人用户）

满意解：
双轨测试（3个月），A负责B2B线索，B负责B2C线索，
用数据决定主攻方向。
```

### 场景3：角色边界争议

```
争议：A是CEO，B是CTO。A经常介入技术决策，B不满。

五路图腾调解：

土（刘禹锡）：
"A介入技术，是因为不信任B，还是因为A自己懂技术、忍不住？"
→ 区分"不信任"和"手痒"

金（司马贺）：
"明确争议：是'谁有技术决策权'，还是'A能不能提技术建议'？"

水（观自在）：
"B，你反对的是A'做决定'，还是A'提意见'？
A，你介入是因为担心B走错，还是因为你享受技术讨论？"

木（孔子）：
"如果A完全不介入技术，B会不会觉得被抛弃？
如果A继续介入，B的自主权怎么保障？"

火（六祖慧能）：
"有没有一个'建议权'和'决策权'分离的机制？"
→ 方案C：
   - A有"技术建议权"（可以提意见，但不能否决B的决定）
   - B有"技术决策权"（最终决定，但重大技术选型需同步A）
   - 设立"技术-商业对齐会"（每周30分钟，A提商业需求，B提技术限制）

满意解：
划分"决策权"和"建议权"，
A保留知情权和建议权，B保留决策权，
建立对齐机制减少信息不对称。
```

## 第四部分：调解失败时的退出路径

### 如果调解失败怎么办？

```
调解失败信号：
├─ 双方拒绝接受任何第三选项
├─ 一方或双方开始人身攻击
├─ 连续3次调解无进展
└─ 任何一方明确表示"不想继续合伙"

退出路径选择：

路径A：友好退出（推荐）
├─ 适用：双方同意分手，但对条件有分歧
├─ 方法：回到"退出路径图"的友好退出流程
└─ 目标：好聚好散，保持关系

路径B：争议退出
├─ 适用：双方对股权/回购价格分歧大
├─ 方法：第三方估值 + 律师协商
└─ 目标：公平分手，成本可控

路径C：强制退出
├─ 适用：一方严重违约，另一方要求解雇
├─ 方法：按违约条款执行
└─ 目标：保护公司和守约方

调解人的最后一句话：
"如果今天的争议最终无法弥合，
我唯一的请求是：让我们按照之前约定好的规则分手，
不互相伤害。
那些规则（退出机制、回购价格、竞业限制），
是我们曾经互相信任的证据。"
```

> **核心原则**：
> 五路图腾调解法不是"判对错"的工具，
> 是"找满意解"的艺术。
>
> 最好的调解结果不是"一方赢一方输"，
> 是"双方都得到了最在乎的东西，同时放下了不那么在乎的东西"。
>
> 这就是满意解的哲学：
> 不求最优，但求最适。
> 结果为本，满意为尺。
