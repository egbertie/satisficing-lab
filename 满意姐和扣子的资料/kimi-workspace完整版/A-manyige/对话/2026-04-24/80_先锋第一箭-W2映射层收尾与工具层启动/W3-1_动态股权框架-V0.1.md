# 动态股权框架 V0.1

> **编制时间**: 2026-04-25
> **编制者**: 满意姐（SAT-001）+ 蓝军 Skeptor-7
> **用途**: 解决"合伙人贡献变化了，股权怎么办"的核心问题
> **原则**: 不是一次性分完，是"跟着贡献走"的活的股权
> **配套**: 合伙人章程自检清单（第10-17项）+ 决策权矩阵（股权调整触发条件）

## 使用说明

```
📊 动态股权框架 —— 让股权跟着贡献走
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

为什么需要这个？
因为创业最大的谎言是"我们按现在的贡献分股权就好了"。
一年后发现：有人全职all-in，有人兼职失联，有人贡献超预期，
有人低于预期——但股权还是按一年前的口头约定。

动态股权 = 承认"我现在不知道未来会怎样"，
但约定好"当未来发生时，我们怎么调整"。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 第一部分：股权成熟机制（Vesting）

### 1.1 标准成熟方案

```
┌──────────────────────────────────────────────────────┐
│           股权成熟时间表（4年标准版）                 │
├──────────────────────────────────────────────────────┤
│                                                      │
│  总股权：100%                                        │
│                                                      │
│  Year 1（第1年）                                     │
│  ├─ 前6个月：Cliff（悬崖期）                          │
│  │   └── 成熟比例：0%                                │
│  │   └── 如果此时退出：零股权，公司回购全部           │
│  │                                                   │
│  └─ 第7-12个月：开始成熟                             │
│      └── 成熟比例：25%（第1年末）                    │
│                                                      │
│  Year 2（第2年）                                     │
│  └── 每月成熟 1/48                                   │
│      └── 累计：50%（第2年末）                        │
│                                                      │
│  Year 3（第3年）                                     │
│  └── 每月成熟 1/48                                   │
│      └── 累计：75%（第3年末）                        │
│                                                      │
│  Year 4（第4年）                                     │
│  └── 每月成熟 1/48                                   │
│      └── 累计：100%（第4年末）                      │
│                                                      │
│  【加速条款】公司被收购/IPO时，未成熟股权立即100%成熟 │
│                                                      │
└──────────────────────────────────────────────────────┘
```

---

### 1.2 Cliff（悬崖期）设计

**什么是Cliff？**
前6个月（或12个月）不成熟的保护期。如果合伙人在此期间退出，零股权。

**为什么需要？**
防止"来试试，3个月发现不合适，拿走一堆股权"。

**Cliff长度选择**：

| 公司阶段 | 建议Cliff | 理由 |
|:---------|:---------|:-----|
| 种子期 | 6个月 | 快速试错，不能太长 |
| 天使期 | 6-12个月 | 需要验证全职承诺 |
| A轮后 | 12个月 | 团队稳定，需要长期绑定 |

**Cliff内的特殊情况**：
- 被公司解雇（非主动退出）：按实际工作时间比例成熟（保护创始人）
- 重大疾病/家庭变故：董事会酌情决定（人性化条款）

---

### 1.3 成熟加速条款

**单触发加速**（1x）：
- 公司被收购 → 未成熟股权立即100%成熟
- 公司IPO → 同上
- 创始人被无故解雇 → 已工作时间的2倍加速成熟

**双触发加速**（2x）：
- 公司被收购 + 创始人在收购后12个月内被解雇
- 适用：保护创始人在收购后的位置

## 第二部分：里程碑触发调整机制

### 2.1 核心逻辑

```
初始分配 → 里程碑达成 → 股权调整 → 新里程碑设定 → 循环
```

**不是惩罚，是校准**。
初始分配基于"预期贡献"。一年后看"实际贡献"。差距太大就调整。

---

### 2.2 里程碑类型

| 类型 | 示例 | 股权调整方向 |
|:-----|:-----|:-------------|
| **融资里程碑** | 完成A轮/B轮/C轮 | 通常不变（融资稀释另算） |
| **产品里程碑** | MVP上线/PMF验证/规模化 | 技术合伙人可能增持 |
| **收入里程碑** | 首单/100万/1000万ARR | 销售合伙人可能增持 |
| **团队里程碑** | 核心团队搭建完成 | HR/COO可能增持 |
| **个人里程碑** | 某人贡献超预期/低于预期 | 个人股权调整 |

---

### 2.3 调整机制设计

#### 方案A：股权池预留法（推荐）

```
初始分配时预留"调整池"：

├─ 合伙人A：40%（初始）
├─ 合伙人B：35%（初始）
├─ 合伙人C：20%（初始）
└─ 调整池：5%（预留，用于里程碑调整）

当某人贡献超预期时：
→ 从调整池划拨1-3%给该人
→ 需要全体一致同意
→ 调整池用完不再追加（除非新一轮融资稀释后重建）
```

**优点**：不触动已有股权，调整温和。
**缺点**：调整池有限（通常5-10%），大调整不够用。

---

#### 方案B：股权回购+重新分配法

```
当贡献严重不匹配时：

Step 1: 评估实际贡献 vs 预期贡献
Step 2: 如果差距>30%，触发调整谈判
Step 3: 公司或现有合伙人回购低贡献者部分股权
Step 4: 回购的股权进入期权池或分配给高贡献者
Step 5: 重新签订股权确认书
```

**回购定价公式**：
```
回购价格 = 原始出资额 × (1 + 年化利率10%) × 已成熟比例
```

**注意**：必须事先约定！不能在争议时临时定价。

---

### 2.4 贡献评估标准（客观化）

**避免"我觉得他不够努力"的主观判断**：

| 维度 | 量化指标 | 数据来源 |
|:-----|:---------|:---------|
| **时间投入** | 每周工作小时数 | 考勤/项目管理系统 |
| **目标达成** | OKR/KPI完成率 | 季度评估 |
| **不可替代性** | 关键技能稀缺度 | 市场招聘成本 |
| **资源引入** | 融资/客户/合作方 | 合同/协议 |
| **文化贡献** | 团队协作评分 | 360度反馈 |

**评估周期**：每季度一次，年度大调整。

## 第三部分：股权回购条款

### 3.1 友好退出回购

```
触发条件：合伙人主动退出（非争议/非解雇）

回购价格选项（事先约定，选一种）：
├─ A. 账面净资产法：公司净资产 × 股权比例
├─ B. 最近融资估值法：最近估值 × 股权比例 × 折扣（通常30-50%）
├─ C. 原始出资+利息法：原始出资 × (1 + 年化10%) × 已成熟比例
├─ D. 协商定价法：双方协商（适用于早期无估值时）
└─ 【推荐C】最简单、最不容易争议

回购方式：
├─ 一次性支付（公司现金流允许）
├─ 分期24个月支付（减轻公司压力）
└─ 转为债权（公司承诺未来某个时间点支付）
```

---

### 3.2 争议退出回购

```
触发条件：合伙人因重大违约/道德问题被解雇

回购价格：
└─ 通常大幅折扣，或零回购

示例条款：
"如果合伙人因挪用资金/竞业违约/重大失职被解雇，
公司有权以原始出资额的50%回购其全部股权（含未成熟部分）。"
```

---

### 3.3 死亡/丧失能力回购

```
触发条件：合伙人死亡或永久丧失工作能力

处理方式：
├─ 公司回购股权（家属获得回购款）
├─ 回购价格按"友好退出"标准
└─ 建议购买关键人保险，保险赔付用于回购

为什么需要？
防止家属成为被动股东（不参与经营但享有决策权）。
```

## 第四部分：稀释保护条款

### 4.1 反稀释保护

```
当公司融资，股权被稀释时：

├─ 优先股反稀释：优先股股东获得额外股权补偿
├─ 普通合伙人通常不享受反稀释
└─ 但可约定"创始团队整体比例不低于XX%"

示例：
"无论经历多少轮融资，创始团队整体持股比例不得低于30%。
如果低于30%，创始团队有权以象征性价格获得额外股权补偿。"
```

---

### 4.2 优先认购权

```
当公司发行新股时：
现有合伙人有权按当前持股比例优先认购。

示例：
"公司计划增发10%新股融资。
合伙人A持股40%，有权优先认购新增股权的40%（即总增发的4%）。
如果A放弃认购，其他合伙人可按比例分配。"
```

## 第五部分：创始人5分钟可用性检验

### 检验清单

| # | 检验项 | 通过标准 |
|:-:|--------|:---------|
| 1 | 你能用1句话解释vesting吗？ | "干满4年才能拿全股权，不满就按比例" |
| 2 | 你知道你们公司的cliff是几个月吗？ | 明确数字 |
| 3 | 如果有人贡献超预期，你们有调整机制吗？ | "有，从调整池划拨"或"有回购重分机制" |
| 4 | 退出时股权回购价格怎么算？ | 明确公式（如"原始出资+10%年化"） |
| 5 | 融资稀释时创始团队有保护吗？ | "有，整体不低于30%"或"没有，接受稀释" |

**如果5项都通过**：你的股权设计合格。
**如果有1-2项不清楚**：本周内找合伙人聊清楚。
**如果有3项以上不清楚**：股权是定时炸弹，立即处理。

## 第六部分：常见问题（FAQ）

### Q1：Vesting是不是对合伙人不信任？

**A**：恰恰相反。Vesting是"对关系的保护"。
- 没有Vesting：口头约定"我们55/45分"——一年后关系变了，但没依据调整。
- 有Vesting：书面约定"55/45，分4年拿满"——如果关系变了，按规则处理，不撕破脸。

**Vesting保护的是"好聚好散"的可能。**

---

### Q2： milestone调整会不会导致合伙人之间互相猜忌？

**A**：如果规则不透明、不事先约定，会。
如果规则透明、定期评估、数据说话，反而减少猜忌。

**关键是**：
- 调整标准事先约定（不是临时拍脑袋）
- 评估数据公开（不是"我觉得"）
- 调整幅度有限（单次不超过2-3%）

---

### Q3：我们已经口头分了股权，现在补签vesting晚不晚？

**A**：不晚。越早补越好。
建议话术：
> "我们之前口头约定的股权不变，但为了保护大家，我建议我们补一个vesting协议。
> 不是针对谁，是万一有人生病/家庭变故需要退出，我们知道怎么处理。
> 这是保险，不是不信任。"

---

### Q4：兼职合伙人怎么算vesting？

**A**：标准vesting假设全职。兼职需要调整：

| 兼职程度 | Vesting调整 |
|:---------|:------------|
| 半职（50%时间） | Vesting速度减半（8年拿满） |
| 顾问（10-20%时间） | 不享受vesting，改发期权/顾问费 |
| 待命状态 | 暂停vesting，恢复全职时继续 |

---

### Q5：股权回购时公司没钱怎么办？

**A**：事先约定分期或债权转换：
```
"公司现金流紧张时，回购款可分24个月支付，
或转为公司债权（年化利息8%），
公司承诺在获得下一轮融资时优先偿还。"
```

> 创业最大的风险不是失败，是"成功了但合伙人反目"。
> 动态股权框架让成功后的分配有章可循。
