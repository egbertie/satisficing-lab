## 一、联盟定位

### 联盟名称

> 中国合伙人决策科学联盟（China Partnership Decision Science Alliance, CPDSA）

### 联盟使命

```
1. 制定合伙人决策行业标准
2. 推动决策科学教育普及
3. 建立行业诚信体系
4. 促进创业者合伙人关系健康发展
```

---

## 二、联盟成员

### 成员类型

| 类型 | 条件 | 权益 |
|:-----|:-----|:-----|
| **创始成员** | 首批8家 | 理事会席位 |
| **核心成员** | 年营收>1000万 | 投票权 |
| **普通成员** | 认同使命 | 参与权 |
| **观察员** | 个人/学者 | 知情权 |

### 目标成员

- 创业孵化器
- 投资机构
- 商学院
- 咨询公司
- 法律事务所
- HR服务机构
- 创业服务平台

## 四、标准制定

### 标准体系

```
CPDSA标准体系：

1. 合伙人评估标准
   → 五维评估框架
   → 测评工具标准

2. 合伙人匹配标准
   → 匹配算法标准
   → 匹配流程标准

3. 冲突诊断标准
   → 13类型冲突分类
   → 干预标准流程

4. 退出机制标准
   → 体面分手标准
   → 股权处理标准

5. 决策教练认证标准
   → CDA认证标准
   → 导师认证标准
```
