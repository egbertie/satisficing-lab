## 📚 核心思想回顾

**来源**: 微信学术快报105条中的分层服务模型研究  
**核心洞察**: 
- **深度访谈** - 高成本、高质量、高投入的初始诊断（P2级）
- **Critic模式** - 中等频率的深度复盘与关键节点评估（P3级）
- **轻量跟踪** - 低成本、高频率的日常状态监测（P1级延伸）
- **分层SKU** - 不同投入度的服务组合，满足客户不同阶段需求

## 🎯 融入成果：两阶段产品SKU设计升级版

### 阶段一：深度访谈（Deep Interview）- P2核心服务

**服务定位**: 高投入、高质量的初始诊断与方案设计

| 项目 | 内容 |
|:-----|:-----|
| **时长** | 2-3周密集服务 + 3-6个月跟踪 |
| **定价** | ¥3.8-5.8万 |
| **交付物** | 合伙人评估报告 + 决策方案 + 谈判策略 |
| **服务形式** | 1v1深度访谈 + 专家咨询 + 方案共创 |
| **目标客户** | 面临关键合伙人决策、愿意深度投入的创始人 |

**深度访谈流程**:
```
Week 1: 诊断
  ├─ 五维罗盘深度评估（3小时）
  ├─ 12类型案例库匹配（2小时）
  ├─ 合伙人背景尽调（2小时）
  └─ 问题根源分析报告

Week 2-3: 方案
  ├─ 定制化决策框架设计（4小时）
  ├─ 股权/决策权/退出机制建议（3小时）
  ├─ 风险预警与应对预案（2小时）
  └─ 专家网络对接（按需）

Month 1-6: 执行
  ├─ 谈判策略指导（按需）
  ├─ 协议条款审核（按需）
  ├─ 定期决策复盘（月度）
  └─ 冲突调解支持（按需）
```

---

### 阶段二：Critic模式（Critical Review）- P3增值服务

**服务定位**: 中等频率的深度复盘与关键节点评估

| 项目 | 内容 |
|:-----|:-----|
| **时长** | 年费，每月1次深度复盘 |
| **定价** | ¥5.8-12万/年 |
| **交付物** | 季度决策健康报告 + 关键节点评估 |
| **服务形式** | 月度Critic会议 + 紧急事件介入 |
| **目标客户** | 已完成深度访谈、需要持续决策支持的客户 |

**Critic模式流程**:
```
每月Critic会议（2小时）:
  ├─ 回顾：上月决策执行回顾（30分钟）
  ├─ 评估：决策质量评估（30分钟）
  ├─ 诊断：新出现的问题诊断（30分钟）
  ├─ 调整：策略调整建议（30分钟）
  └─ 记录：决策日志更新

关键节点介入（按需）:
  ├─ 融资谈判前评估
  ├─ 合伙人冲突升级时
  ├─ 重大战略决策前
  └─ 退出机制触发时
```

---

### 阶段三：轻量跟踪（Light Tracking）- P1延伸服务

**服务定位**: 低成本、高频率的日常状态监测

| 项目 | 内容 |
|:-----|:-----|
| **时长** | 年费，每周1次轻量检查 |
| **定价** | ¥1.9-3.8万/年（P1价格延伸） |
| **交付物** | 周度状态报告 + 预警信号 |
| **服务形式** | 自动化监测 + 轻量人工检查 |
| **目标客户** | 预算有限但需要持续关注的创始人 |

**轻量跟踪流程**:
```
自动化监测（每日）:
  ├─ 五维罗盘状态追踪（自动）
  ├─ 情绪温度监测（小程序自填）
  └─ 关键事件标记（客户自填）

轻量人工检查（每周1次，30分钟）:
  ├─ 自动化报告解读（10分钟）
  ├─ 异常信号识别（10分钟）
  └─ 预警或鼓励（10分钟）

升级触发:
  ├─ 连续2周异常 → 建议Critic介入
  ├─ 紧急事件 → 立即升级P2
  └─ 季度总结 → 评估是否需深度服务
```

## 📊 分层SKU对比矩阵

| 维度 | 深度访谈(P2) | Critic模式(P3) | 轻量跟踪(P1延伸) |
|:-----|:-------------|:---------------|:-----------------|
| **投入度** | 高（2-3周密集） | 中（月度2小时） | 低（周度30分钟） |
| **成本** | ¥3.8-5.8万/次 | ¥5.8-12万/年 | ¥1.9-3.8万/年 |
| **频率** | 一次性+6月跟踪 | 月度 | 周度 |
| **深度** | 全面诊断+方案 | 复盘+调整 | 监测+预警 |
| **适用阶段** | 关键决策前 | 持续优化期 | 日常维护期 |
| **升级路径** | → Critic → 轻量 | → 轻量 → Critic | → Critic → 深度 |
| **降级路径** | — | → 深度（新决策） | → Critic（异常） |

## 🔄 客户旅程与SKU切换

```
客户旅程:

潜在客户
    │
    ├─ 免费测评(P0) ──→ 发现需求
    │
    ↓
初次接触
    │
    ├─ 低价自测(P1) ──→ 明确类型
    │
    ↓
关键决策期
    │
    ├─ 深度访谈(P2) ──→ 全面诊断+方案
    │
    ↓
执行期
    │
    ├─ Critic模式(P3) ──→ 月度复盘+调整
    │ 或
    ├─ 轻量跟踪(P1') ──→ 周度监测+预警
    │
    ↓
新决策点
    │
    └─ 循环回深度访谈(P2)
```

## 🛠️ 落地工具：SKU销售手册

### 场景一：从P0/P1升级到P2

**客户状态**: 已完成免费测评或低价自测，意识到问题严重性

**销售话术**:
"基于您的测评结果，您当前面临的是[TypeXX]类型的合伙人决策挑战。

这类决策的典型特点是：
- 不可逆性高（一旦选定，难以更换）
- 影响深远（影响企业3-5年发展）
- 信息复杂（需要评估多维度因素）

我们建议您考虑'深度访谈'服务：
- 2-3周密集服务，全面诊断
- 输出定制化的决策方案
- 3-6个月跟踪执行

投资¥3.8-5.8万，避免数百万的潜在损失。"

---

### 场景二：从P2升级到P3

**客户状态**: 已完成深度访谈，方案正在执行中

**销售话术**:
"您的合伙人决策方案已进入执行阶段。

经验表明，执行过程中会出现：
- 新信息的涌入，需要调整策略
- 合伙人行为的偏差，需要及时纠偏
- 外部环境的变动，需要重新评估

我们建议您考虑'Critic模式'：
- 每月1次深度复盘（2小时）
- 关键节点即时介入
- 年度决策健康报告

年费¥5.8-12万，相当于每月¥0.5-1万，获得持续的决策外脑支持。"

---

### 场景三：P3降级到P1'（或并行）

**客户状态**: Critic模式执行良好，状态稳定，希望降低成本

**销售话术**:
"过去6个月的Critic服务显示，您的合伙人决策已进入稳定期。

考虑到您当前的预算优化需求，我们建议您：
- 保留Critic模式的核心（月度复盘）
- 增加轻量跟踪作为日常监测（周度30分钟）
- 两者结合，既保证深度又控制成本

轻量跟踪年费¥1.9-3.8万，可以：
- 自动化监测日常状态
- 周度人工检查异常信号
- 及时预警，避免问题升级"
