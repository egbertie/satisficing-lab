## 四、代码级 KIA 标准定义（新增）

由于 Python 代码资产无法直接套用 Markdown 文档的 KIA 头部，蓝军建议采用「代码级 KIA 注释块」：

```python
"""
KIA-Loop 元数据
- 资产名称: partner_match_consultation_kit.py
- 功能定位: SKU-A 合伙人匹配咨询报告自动生成
- 上游来源: confucian_business_philosophy_core.py / hardtech_partner_risk_scanner.py / satisficing_decision_engine.py
- 下游交付: SKU-A 合伙人诊断报告（可直接交付创始人）
- 血液化状态: 已嵌入行为面谈四问、儒商评估、风险扫描
- 任务清单: 
  - [ ] 增加可视化雷达图输出
  - [ ] 对接 partner_matching_db.py 自动填充候选人数据
- 更新时间: 2026-04-12
- 负责人: 蓝军
"""
```

**规则**: 每个核心 `.py` 文件顶部必须包含此注释块，否则视为未入库。

## 七、执行规则（血液化条款）

1. **批量优先原则**：同类型文件统一处理（如 12 类型案例按 Type 批量补 KIA），禁止逐份高 Token 精读。
2. **本地优先原则**：优先使用 head/grep/sed 本地扫描，仅在必须时才调用 LLM 生成血液化内容。
3. **双位置同步原则**：所有 KIA 补完后的文件，必须同时更新到当日对话文件夹（`A-manyige/对话/YYYY-MM-DD/`）。
4. **不返工原则**：旧版文件一旦补完 KIA，立即 Git commit，禁止反复修改同一文件。
5. **诚实审计原则**：每 Wave 完成后，蓝军必须抽样 10% 核对「头部是否存在、映射是否真实、任务是否可执行」。
