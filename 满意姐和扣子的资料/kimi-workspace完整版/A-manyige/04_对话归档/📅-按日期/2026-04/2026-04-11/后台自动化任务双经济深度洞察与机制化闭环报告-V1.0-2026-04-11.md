def main():

    hibernation_state_file = Path("/root/.openclaw/workspace/memory/hibernation-state.json")
    last_tracker_run_file = MEMORY_DIR / "token-zero-tracker-last-run.json"
    if hibernation_state_file.exists():
        try:
            with open(hibernation_state_file, 'r', encoding='utf-8') as f:
                hstate = json.load(f)
            level = hstate.get("status", "normal")
            heartbeat_min = {"normal": 30, "turbo": 60, "hibernating": 30, "silent": 120, "deep-silent": 720}.get(level, 30)
            if last_tracker_run_file.exists():
                with open(last_tracker_run_file, 'r', encoding='utf-8') as f:
                    last_run = datetime.fromisoformat(json.load(f).get("timestamp", ""))
                minutes_since = (datetime.now() - last_run).total_seconds() / 60
                if minutes_since < heartbeat_min:
                    print(f"[{datetime.now().strftime('%Y-%m-%d %H:%M:%S')}] {level} 模式节流中，上次运行 {minutes_since:.1f} 分钟前，间隔 {heartbeat_min} 分钟，跳过")

        except Exception:
            pass

### 2.3 已血液化的机制规则（已写入 `AGENTS.md`）

> 以下规则为 **P0 级强制约束**，违反即触发告警

1. **新增任务双经济审计**：每一条新增 cron/agentTurn/systemEvent 任务必须通过 Token消耗 vs 业务价值 的审计，否则禁止注册
2. **五级光谱 Gate**：
   - **L0/L1**：全部任务正常运行
   - **L2**：暂停 `EXPENSIVE_JOBS`（daily-asset-activation / evening-totem / token-optimizer），保留 `ESSENTIAL_JOBS`
   - **L3**：仅运行保活任务 + 休眠检查（已节流 to 120min）
   - **L4**：仅运行保活任务 + 休眠检查（已节流 to 720min），其余全部冻结
3. **入口节流原则**：所有脚本必须在入口处读取 `hibernation-state.json` 并做同级节流，无状态变化时直接 no-op
4. **注册表强制同步**：任何新 cron 必须同时更新 `hibernation-control.py` 的 `ESSENTIAL_JOBS` 或 `EXPENSIVE_JOBS`
5. **淘汰机制**：连续 7 天未产生可验证价值的 `agentTurn` 类任务，必须提交停用方案
