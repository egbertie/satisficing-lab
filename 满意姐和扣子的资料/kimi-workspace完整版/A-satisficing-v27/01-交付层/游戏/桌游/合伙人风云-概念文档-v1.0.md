# 《合伙人风云：硬科技创业之路》桌游概念文档

---

## 一、核心机制

### 游戏目标
玩家扮演硬科技创业公司的联合创始人，在融资、研发、市场扩张的过程中，通过合伙人协作与博弈，最终达成**公司上市**或**被收购**的胜利条件，成为最成功的创业团队。

### 游戏流程（回合制）
1. **事件阶段**：抽取市场/政策事件卡（利好/利空）
2. **行动阶段**：玩家掷骰子移动棋盘，执行格子效果（融资/研发/招聘/市场）
3. **协作阶段**：触发合伙人协作或冲突事件
4. **谈判阶段**：股权调整、资源置换、分家/合并选择

### 冲突来源
- **目标分歧**：技术派追求技术壁垒 vs 市场派追求快速变现
- **资源争夺**：有限融资额度的分配争议
- **信任危机**：暗骰决策导致的信息不对称（类似狼人杀隐藏身份机制）
- **外部压力**：竞品追赶、政策变化、投资人介入

### 胜利条件（多结局）
| 结局类型 | 条件 | 胜利者 |
|---------|------|--------|
| **上市成功** | 估值达到5000万，所有合伙人信任度≥60% | 全体合伙人共赢 |
| **并购退出** | 被大厂收购，价格谈判成功 | 股权占比高者胜出 |
| **独走成功** | 单方面收购其他合伙人股权，独立IPO | 单人胜利 |
| **分家散伙** | 信任度跌破阈值，触发分家清算 | 资产变现最高者胜出 |
| **破产出局** | 现金流断裂，全员失败 | 无 |

## 二、角色设计（四派合伙人）

### 🔧 技术派（CTO路线）
- **核心能力**：技术壁垒构建、专利申请、产品研发加速
- **特殊技能**：【技术预判】查看下一轮技术趋势牌
- **弱点**：市场敏感度低，谈判中易被资本派压制
- **胜利偏好**：上市成功（技术价值最大化）

### 📈 市场派（CMO路线）
- **核心能力**：客户获取、品牌建设、渠道拓展
- **特殊技能**：【风口嗅觉】首轮行动时多掷1颗骰子
- **弱点**：技术依赖度高，产品断供时收益归零
- **胜利偏好**：并购退出（快速变现）

### 💰 资本派（CFO/投资人代表）
- **核心能力**：融资谈判、财务操控、股权稀释
- **特殊技能**：【对赌协议】强制要求其他玩家承诺业绩目标
- **弱点**：信任度消耗快，易被孤立
- **胜利偏好**：独走成功（控股套现）

### ⚙️ 运营派（COO路线）
- **核心能力**：团队管理、流程优化、成本压缩
- **特殊技能**：【粘合剂】可在冲突时进行调解，恢复信任度
- **弱点**：缺乏爆发性收益，容易被边缘化
- **胜利偏好**：上市成功（稳定分红）

**角色组合建议**：
- 3人局：技术+市场+资本（经典铁三角）
- 4人局：四派各一人（完整博弈）
- 5-6人局：可重复角色或加入"天使投资人"NPC角色

## 三、关键机制详解

### 1. 合伙人匹配机制
- **初始配对**：随机抽取角色卡，根据角色特性决定初始信任度
- **动态结盟**：游戏中可形成临时联盟（如技术+市场对抗资本派）
- **信任度系统**：
  - 0-30%：敌对状态，可发起股权争夺
  - 31-60%：竞争状态，交易需额外成本
  - 61-80%：合作状态，共享部分资源
  - 81-100%：铁盟状态，行动绑定、共担风险

### 2. 冲突骰子（Chaos Dice）
当玩家行动触发冲突时，投掷**冲突骰子**（6面特殊骰）：
| 点数 | 效果 |
|-----|------|
| 1 | 信任崩塌：双方信任度-20% |
| 2 | 僵局：本回合无法协作 |
| 3 | 小摩擦：信任度-5%，获得1张"补偿卡" |
| 4 | 妥协：各退一步，资源均分 |
| 5 | 握手言和：信任度+10% |
| 6 | 灵魂共鸣：信任度+20%，本回合行动+1 |

*特殊规则*：资本派可强制重投1次，技术派可预览骰子结果（先知道再决定是否触发冲突）

### 3. 股权谈判系统
- **股权初始分配**：创始人各33.3%（3人局）或根据角色调整
- **融资稀释**：每轮融资全体股东同比稀释，或协商非同比方案
- **对赌协议**：资本派可发起对赌，失败方转让股权
- **回购权**：运营派可在特定节点提议股权回购
- **谈判筹码**：现金、技术专利、客户资源、承诺未来收益

### 4. 分家选择机制
当信任度跌破阈值或战略分歧不可调和时，触发**分家事件**：
- **友好分家**：协商资产分割，按比例清算
- **敌意收购**：一方强制收购其他方股权（需资金+支持率）
- **独立门户**：一方带技术/客户资源出走，原公司估值受损
- **IPO阻击**：分家期间如有外部IPO机会，可抢先上市

## 四、游戏规格

| 项目 | 参数 |
|-----|------|
| **游戏时长** | 45-60分钟 |
| **玩家人数** | 3-6人 |
| **推荐年龄** | 16+（涉及商业策略与博弈） |
| **核心机制** | 区域移动 + 隐藏信息 + 谈判博弈 |

### 游戏组件清单
- 游戏棋盘（创业之路地图）×1
- 角色卡 ×6（四派+2个扩展角色）
- 事件卡 ×60（市场/政策/技术/危机各15张）
- 冲突骰子 ×3
- 行动骰子 ×2
- 股权代币 ×100
- 现金代币 ×若干
- 信任度计分板 ×1
- 技术/客户/专利资源卡 ×各20张

### 风格融合说明
| 《大富翁》元素 | 《狼人杀》元素 | 本作创新 |
|-------------|-------------|---------|
| 掷骰走格子 | 隐藏身份/动机 | 角色能力差异化 |
| 买地收租 | 信息不对称 | 信任度动态系统 |
| 随机事件 | 投票决策 | 股权谈判机制 |
| 破产出局 | 阵营对抗 | 多结局胜利条件 |

## 五、游戏卖点

1. **真实创业体验**：还原硬科技创业从0到1的完整历程
2. **高重玩性**：随机事件+多结局+角色组合，每局体验不同
3. **社交博弈**：谈判、背叛、结盟，适合朋友聚会破冰
4. **教育价值**：了解股权结构、融资流程、合伙人关系管理
