## 📂 各层说明

### 00-🔥-INBOX

### 00-认知层
满意解的理论根基与研究方法。

| 子文件夹 | 内容 |
|----------|------|
| `底层方法论/` | 满意解理论、儒商哲学、五路图腾 |

| `研究/` | Skill搜寻、研究计划 |

### 01-交付层
面向用户的产品与服务交付物。

| 子文件夹 | 内容 |
|----------|------|
| `产品-合伙人踩雷检测/` | 核心产品文档、案例脚本 |
| `产品-第二层危机预警/` | 危机预警系统 |
| `产品-知识复利飞轮/` | 知识复利系统 |
| `产品-游戏化/` | 桌游、游戏化产品 |
| `内容/` | 文章、视频脚本 |
| `课程/` | 课程体系 |
| `游戏/` | 游戏化产品 |
| `运营文档/` | 运营SOP与流程 |

### 02-运营层

| 子文件夹 | 内容 |
|----------|------|
| `系统/` | AI系统、自动化流程 |
| `流程/` | 标准操作流程 |
| `数据/` | 运营数据、指标 |

### 03-资产层
可复用的知识资产。

| 子文件夹 | 内容 |
|----------|------|
| `知识库/` | 68Entry理论体系 |
