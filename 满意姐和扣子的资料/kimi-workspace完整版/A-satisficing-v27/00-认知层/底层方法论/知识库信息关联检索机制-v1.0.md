# 🔒 知识库信息关联检索机制 V1.0

> **问题发现**：李泽湘教授信息已在知识库（LI-ZEXIANG-DEEP-RESEARCH-V2.0），但检索关联不到位  
> **根因分析**：信息孤岛、检索机制缺失、关联图谱未建立  
> **机制目标**：确保任何相关信息都能被即时检索和关联  
> **生效时间**：立即生效

## 一、漏洞根因分析

### 1.1 问题表现
| 现象 | 影响 |
|------|------|
| 李泽湘Entry已存在，但未主动检索 | 重复劳动、信息断层 |
| 用户提示后才找到 | 用户体验下降、信任损耗 |
| 专家档案与案例库割裂 | 知识体系碎片化 |

### 1.2 根本原因
1. **被动检索**：依赖用户上传触发，缺乏主动关联检索
2. **关键词缺失**：没有建立专家-案例-主题的关联图谱
3. **检索范围窄**：只在当前会话检索，未跨Entry关联
4. **索引不完善**：MEMORY.md轻量索引未覆盖专家-案例关系

## 三、长期机制设计（本周完成）

### 3.1 自动化检索脚本

**开发任务**：`scripts/knowledge-retrieval.py`
- 输入：关键词（专家名/主题/案例名）
- 输出：所有关联Entry列表 + 摘要
- 触发：每次用户提出新任务时自动执行

**伪代码**：
```python
def retrieve_related_entries(keywords):
    # 1. 全文检索knowledge-base/raw/
    entries = grep_files(keywords, path="knowledge-base/raw/")
    
    # 2. 关联Entry二次检索
    related = extract_related_entries(entries)
    
    # 3. 按相关度排序
    sorted_entries = rank_by_relevance(entries + related)
    
    # 4. 生成摘要报告
    report = generate_summary(sorted_entries)
    
    return report
```

### 3.2 知识图谱可视化

**节点类型**：
