## 六、🔄 知识内化流程

### 6.1 内化五步法

```
输入 → 摘录 → 总结 → 内化 → 创造
(Input → Extract → Summarize → Internalize → Create)
```

### 6.2 渐进式总结

| 层级 | 操作 | 输出 |
|------|------|------|
| L1 | 原始捕获 | 原文/截图/链接 |
| L2 | 高亮重点 | 标记关键段落 |
| L3 | 总结大纲 |  bullet points |
| L4 | 浓缩金句 | 核心观点 |
| L5 | 内化创造 | 自己的话重写 |

### 6.3 内化检查清单

- [ ] 能用自己的话解释吗？
- [ ] 能举出3个例子吗？
- [ ] 能和已有知识链接吗？
- [ ] 能指导实际行动吗？
- [ ] 能传授给他人吗？
