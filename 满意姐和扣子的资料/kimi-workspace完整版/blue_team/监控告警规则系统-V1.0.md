## 二、具体监控规则

### 规则1：流程合规性监控

**监控点**: 7阶段流程必须完整执行

**检查清单**:
- [ ] 阶段0: 前置确认（文件名、上文件记录、重复检测、完整性）
- [ ] 阶段1: 全量提取（100%段落）
- [ ] 阶段2: 深度洞察（架构、数据源识别）
- [ ] 阶段3: 能力评估（可实现性分析）
- [ ] 阶段4: 实际实施（代码/文档交付）
- [ ] 阶段5: 条件记录（专门存放）
- [ ] 阶段6: 资产整合（与已有系统对接）
- [ ] 阶段7: 任务登记（全过程记录）

**告警触发**: 任一阶段未执行或未记录
**告警动作**: 立即暂停，强制回退到该阶段
**告警接收人**: 满意姐 + 蓝军Skeptor-7

---

### 规则2：文件完整性监控

**监控点**: 正文段落必须100%提取

**检查方法**:
```python
def check_completeness(file_path):
    # 提取实际段落数
    actual_paragraphs = extract_paragraphs(file_path)
    
    # 与文档声明对比
    if actual_paragraphs < declared_paragraphs:
        trigger_alert(
            level="P0",
            message=f"段落提取不完整: {actual}/{declared}",
            action="重新提取"
        )
```

**告警触发**: 提取段落数 < 文档实际段落数
**告警动作**: 立即停止，重新提取
**验证方式**: 二次核对段落编号连续性

### 规则3：重复文件检测监控

**监控点**: docx文件处理前必须检测重复

**检查清单**:
- [ ] 列出所有同名/相似名文件
- [ ] 对比文件大小
- [ ] 对比修改时间
- [ ] 识别版本号（_1_, _2_, _V1_等）
- [ ] 生成重复检测报告
- [ ] 明确告知用户处理哪个版本

**告警触发**: 
- 未执行重复检测
- 重复文件未识别
- 未告知用户处理版本

**告警动作**: 暂停处理，执行检测
**特殊要求**: 必须用户确认后方可继续

### 规则5：Token消耗监控

**监控点**: 单文件处理消耗控制

**消耗基准**:

|----------|----------|----------|----------|

- 红线（熔断阈值）: 暂停处理，分析原因

## 四、监控执行脚本

### 4.1 流程合规性检查脚本

```python
# blue_team_monitor.py

class BlueTeamMonitor:
    """蓝军监控系统"""
    
    def __init__(self):
        self.alerts = []
        self.checkpoints = {}
    
    def check_phase0(self, file_info, prev_file_saved, duplicate_checked, completeness):
        """检查阶段0执行"""
        if not file_info:
            self.trigger_alert("P0", "阶段0缺失: 未告知文件名")
        if not prev_file_saved:
            self.trigger_alert("P0", "阶段0缺失: 未确认上文件记录")
        if not duplicate_checked:
            self.trigger_alert("P0", "阶段0缺失: 未检查重复文件")
        if not completeness:
            self.trigger_alert("P0", "阶段0缺失: 未检查完整性")
    
    def check_phase1(self, paragraph_count, declared_count):
        """检查阶段1执行"""
        if paragraph_count < declared_count:
            self.trigger_alert("P0", f"阶段1不完整: {paragraph_count}/{declared_count}")
    
    def check_duplicate_detection(self, file_name, all_files):
        """检查重复检测"""
        similar_files = [f for f in all_files if file_name.split('_')[1] in f]
        if len(similar_files) > 1:
            if not self.has_duplicate_report():
                self.trigger_alert("P0", f"检测到{len(similar_files)}个相似文件，但未生成报告")
    
    def check_implementation_quality(self, test_results):
        """检查实施质量"""
        pass_rate = sum(test_results) / len(test_results)
        if pass_rate < 0.8:
            self.trigger_alert("P1", f"测试通过率{pass_rate:.0%}，低于80%")
    
    def check_token_consumption(self, tokens, file_type):
        """检查Token消耗"""
        thresholds = {
            'case_analysis': 5000,
            'tech_scheme': 8000,
            'deep_insight': 10000
        }
        if tokens > thresholds.get(file_type, 5000):
            self.trigger_alert("P1", f"Token消耗{tokens}，超过阈值")
    
    def trigger_alert(self, level, message):
        """触发告警"""
        alert = {
            'timestamp': datetime.now(),
            'level': level,
            'message': message,
            'status': 'active'
        }
        self.alerts.append(alert)
        print(f"🔴 [{level}] {message}")
```
