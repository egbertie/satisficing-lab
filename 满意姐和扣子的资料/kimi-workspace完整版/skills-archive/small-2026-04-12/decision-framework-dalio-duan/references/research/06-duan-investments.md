## 一、投资哲学总纲

### 核心原则
段永平的投资哲学以**"买股票就是买公司，买公司就是买其未来现金流折现"**为核心，融合"本分"与"平常心"的东方智慧。

**三大铁律：**
- 不借钱（不使用杠杆）
- 不做空
- 不做不懂的东西

**选股三维标准：**
1. Right Business（对的商业模式）——护城河、自由现金流、差异化
2. Right People（对的人）——企业文化、管理层诚信、本分
3. Right Price（对的价钱）——合理估值、安全边际

**持仓特征：**
- 高度集中：核心持仓聚焦苹果、茅台、腾讯，单一标的占比可超70%
- 长期持有：以10年为单位计算，践行巴菲特"20个打孔位"原则，自称"10个孔还没打完"
- 逆向投资：在市场恐慌时买入，好公司下跌是加仓机会而非风险

## 二、重大投资案例

### 1. 网易（2001-2011）：封神之作

#### 背景
- **时间**：2001年互联网泡沫破裂后
- **标的状况**：
  - 2000年6月在纳斯达克上市，发行价15.5美元
  - 2001年5月因财务误报问题股价暴跌至0.8美元
  - 纳斯达克发出退市警告，市值一度不足2000万美元
  - 公司账面现金高达4.8亿人民币（约2美元/股）
- **外部环境**：纳斯达克指数从5048点暴跌，超过200家互联网公司破产

#### 投资逻辑
**公开表达**：
- "我本身做游戏出身，跟他们游戏团队聊聊，觉得他们是一帮很热爱游戏的人"
- "商业模式我觉得它很有道理，加上它的现金当时比市值高"
- "我作为风投一样的，买进去很简单"

**实际行为**：
1. 聘请专业律师评估集体诉讼风险和摘牌可能性
2. 安排团队深入调研网易游戏竞争力
3. 综合成本约1美元/股（自称甚至在摘牌风险最后一天购入50万股）
4. 动用约150-200万美元（含部分借贷），持有超过150万股，占总股本6.8%

#### 投资结果
| 指标 | 数据 |
|------|------|
| 买入均价 | 约0.25-1美元/股 |
| 持有时间 | 约10年（2001-2011） |
| 卖出价格 | 约100美元/股（2011年前后） |
| **收益率** | **超过100倍** |
| **盈利金额** | **超过1亿美元** |
| 最高复权价 | 约3500美元（2025年），若持有至今涨幅超3500倍 |

#### 反思与公开言论
- **承认局限**："你说我看懂了吗，我要看懂了，我应该把整个网易买下来"
- **卖出反思**："卖的时候赚了100多倍，如果持有到现在可能有1000多倍了，所以不要轻易卖掉好公司"
- **关于孤独**："最后一天买入50万股时，感觉很孤独"
- **核心洞察**：网易的真实情况比市场担忧的好得多，股价低于现金、摘牌概率很小

### 2. 苹果（2011至今）：持仓之王

#### 背景
- **时间**：2011年开始建仓，持续至今（14年+）
- **市场背景**：
  - 乔布斯于2011年10月去世，市场担忧苹果创新能力
  - 苹果市值约3000亿美元，市盈率仅12-13倍
  - 账上现金超800亿美元
- **建仓价格**：约44美元/股（复权后约10美元），对应市值不到3000亿

#### 投资逻辑
**公开表达**：
- "苹果有可能会是地球上第一家年利润过500亿美金利润的公司"
- "苹果的盈利在两到三年内大概就可以达到每股40-50块/年，再加上那时每股现金100多块，给他个600的价钱应该不算太过分"
- "我对苹果完全不操心，掉多少都不往心里去"

**实际行为**：
1. 2011年重仓买入，持续增持
2. 带领OPPO、vivo员工一起低价购买苹果股票
3. 通过卖出看跌期权降低持仓成本
4. 截至2025年Q2，持有约3511.86万股，占H&H基金总资产62.47%

#### 投资结果
| 指标 | 数据 |
|------|------|
| 初始投资 | 约5-8亿美元 |
| 当前持仓市值 | 约72.1亿美元（2025年Q2） |
| **总回报率** | **超过8倍** |
| **年化回报率** | **约18%** |
| 苹果复权股价 | 从10美元涨至220美元（2025年） |
| 持有期间分红+回购 | 远超3000亿美元 |

#### 反思
- **错过早期**：2003年苹果12块多时感兴趣，但没投资（"高成长的公司，一般市盈率比较高，必须对它的未来看得足够清楚"）
- **认知进化**：从早期烟蒂股策略转向成长股长期持有策略

### 3. 茅台（2013至今）：逆势抄底典范

#### 背景
- **时间**：2013年开始建仓，持续至今（约12年）
- **市场背景**：
  - 2012年"塑化剂事件"叠加"三公消费禁令"
  - 茅台市盈率跌至10倍以下
  - 股价从217元跌至122元
- **建仓价格**：120-180元/股区间

#### 投资逻辑
**公开表达**：
- "茅台将来一定会回来，但是什么时候我不知道，可能五年、十年，没有人知道"
- "像茅台现在这种情况，放在那里股息可能都能拿到你目前投资的3%、4%了，肯定比放银行好"
- "如果找不到比茅台商业模式更优的标的，持有现金不如持有茅台"

**实际行为**：
1. 2013年在塑化剂危机中逆势建仓
2. 2025年1月27日卖出中国神华，加仓茅台约1.03亿元（7.72万股）
3. 2025年多次公开增持，包括1365元买入2万股
4. 2026年继续在低位加仓

#### 投资结果
| 指标 | 数据 |
|------|------|
| 初始建仓成本 | 约120-180元/股 |
| 当前股价 | 约1500-1547元（2026年） |
| **涨幅** | **超过10倍** |
| 持仓市值 | 超过200亿人民币 |
| 2025年茅台净利润 | 约826亿元 |
| 股息率 | 约3.6% |

#### 核心持仓逻辑
- 品牌垄断+产能稀缺（离开茅台镇就酿不出茅台酒）
- 无负债经营，毛利率91.3%
- i茅台直销改革释放真实消费需求
- "库存老酒越存越值钱"的独特属性

### 4. 腾讯（2018至今）：认知进化之路

#### 背景
- **时间**：2018年开始建仓，持续至今
- **市场背景**：
  - 2018年游戏版号停发，腾讯股价腰斩
  - 2021年反垄断监管，股价再跌
  - 2022年10月最低跌至180港元，从高点775港元跌幅77%
- **建仓路径**：从2018年的试探性建仓到2024年的系统性增持

#### 投资逻辑演变
**公开表达（认知进化）**：

| 阶段 | 时间 | 观点 |
|------|------|------|
| 早期认可 | 2018-2020 | "最近确实投了一些，但比例还很小。用苹果换似乎有点不舍得，我似乎更懂苹果些" |
| 深度困惑 | 2022 | "我对腾讯的理解度远不如苹果""腾讯总是觉得懂得不透（未来现金流），下不了重手" |
| 认知突破 | 2024 | "如果考虑腾讯的投资部分，PE实际上已低过20了""可以假设腾讯把投资都卖掉，把钱还完债务后全部用来回购，完了再算PE就比较真实了" |

**实际行为**：
1. 2018年10月首次买入，但仓位不到1%
2. 2021-2022年大跌期间至少6次公开加仓
3. 2024年宣布"卖put到1%腾讯"的战略目标
4. 使用卖出看跌期权策略降低持仓成本

#### 投资结果
| 指标 | 数据 |
|------|------|
| 建仓均价 | 约370-440港元（实际买入区间） |
| 当前持仓 | 港股正股为主，美股ADR为辅 |
| 2024年腾讯回购 | 1120亿港元（占股本3.07%） |
| 2025年市值目标 | 6000亿美元（已实现） |

#### 核心持仓逻辑
- 微信的13亿月活用户和社交关系链是"不可替代的护城河"
- "如果这个产品消失了，你会难受多久？"——答案是"3天"
- 腾讯的商业模式韧性：只要社交根基在，就能源源不断变现

- **背景**：香港上市公司，市值仅10多亿港元

- **结果**：涨至5-8港元卖出，获利约5倍

- **背景**：2008年金融危机期间买入

### 6. 雅虎（Yahoo）

- **逻辑**：买入是为了获得淘宝和阿里巴巴集团的股权

- **反思**："yahoo并不是最理想的投资"

## 七、言行一致性验证

### 公开表达的核心理念 vs 实际行为

| 理念 | 公开表达 | 实际行为 | 一致性 |
|------|----------|----------|--------|
| 买股票就是买公司 | 反复强调 | 持仓周期以10年为单位，苹果持有14年+，茅台12年+ | ✅ 完全一致 |
| 不借钱 | "任何时候都不应该用margin" | 网易投资曾部分借贷（事后反思），但此后坚持不借钱 | ⚠️ 早期有过借贷，但已纠正 |
| 不做空 | "永远不要做空" | 做空百度亏损1.5-2亿美元 | ❌ 有过重大违背，吸取教训后回归 |
| 不懂不做 | "能力圈不是边界，而是认知半径" | 承认错过谷歌、英伟达；做空百度、做空纳指3X | ⚠️ 有过违背，但持续反思修正 |
| 逆向投资 | "别人恐慌时贪婪" | 2013年茅台、2011年苹果、2022年腾讯大跌时买入 | ✅ 完全一致 |
| 集中持仓 | "10个孔还没打完" | 苹果占组合62%+，前三大持仓超85% | ✅ 完全一致 |
| 本分文化 | "做对的事情，把事情做对" | 步步高系30年持续践行；投资时重视企业文化 | ✅ 完全一致 |

### 关键认知进化路径
1. **2001年前**：以实业为主
2. **2001-2011**：烟蒂股策略（网易、UHAL、创维、万科）
3. **2011至今**：成长股策略（苹果、茅台、腾讯）
4. **投资工具**：从纯股票到灵活运用期权策略（卖Put/卖Call）

## 八、总结：决策框架精华

### 1. 商业判断优先于财务估值
> "决定投资不是由市盈率来决定的，是由你未来的现金流来决定"

### 2. 理解深度决定持仓比例
> "好容易找到一个好价格的好股票，不集中是不明白的表现"

### 3. 长期视角化解短期焦虑
> "10年20年维度看问题，很多纠结自然消失"

### 4. 不为清单比作为清单更重要
> "我之所以是我，大多是因为我不做什么"

### 5. 知错就改，不拖泥带水
> "发现错误要尽快改，不管多大的代价都可能是最小的代价"
