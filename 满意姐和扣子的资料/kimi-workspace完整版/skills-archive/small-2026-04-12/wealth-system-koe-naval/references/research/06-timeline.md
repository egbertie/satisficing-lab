# Dan Koe 时间线

|------|------|------|

| **2019** | 辞职，全身心投入自由职业和内容创作 | 推出 Modern Mastery HQ（$29/月会员） |
| **2019** | 推出数字课程《2 Hour Writer》和《Digital Economics》 | 年收入：$10,000 |
| **2020** | Twitter 开始活跃（11月正式入驻） | 建立内容发布系统，关注者从500起步 |
| **2020** | 年收入增长 | 达到 $100,000 |
| **2021** | 年收入持续增长 | 达到 $150,000 |
| **2022** | 粉丝爆发增长（Twitter 10K→50K→100K→280万） | 每天工作2-4小时模式成型 |
| **2022** | 年收入大幅增长 | 达到 $800,000 |
| **2023** | 出版《The Art of Focus》 | 结合心理学与创业哲学 |
| **2023** | 推出 Kortex（专注写作和生产力的软件） | 收入多元化 |
| **2023** | 年收入达到峰值 | 约 $2,500,000 |

# Naval Ravikant 时间线

| 年份 | 事件 | 意义 |
|------|------|------|
| **1974.11.5** | 出生于印度新德里 | 贫困家庭，父亲是药剂师 |
| **1978** | 随母亲和弟弟移居纽约 | 家庭团聚 |
| **1983-1991** | 在纽约皇后区贫困社区成长 | 母亲独自抚养两个孩子 |
| **1987** | 通过考试进入 Stuyvesant High School | 改变命运的关键节点 |
| **1991** | 从 Stuyvesant 毕业 | 全纽约最难进入的学校之一 |
| **1995** | 达特茅斯学院毕业，获 CS 和经济学双学位 | 期间在 Davis Polk 律师事务所实习 |
| **1995-1996** | 波士顿咨询集团工作 | 短暂的企业咨询经历 |
| **1996-1999** | 前往硅谷，加入 @Home | 互联网泡沫初期 |
| **1999** | 联合创立 Epinions（消费者产品评论网站） | 最早的用户生成内容平台之一 |
| **1999** | 融资 $45M（Benchmark Capital、August Capital） | 首个重大资本运作 |
| **2003** | Epinions 与 Dealtime 合并为 Shopping.com | 合并后估值低于融资额，创始人股份归零 |
| **2004** | Shopping.com IPO，市值 $750M | 首个重大退出 |
| **2005** | 联合创始人起诉 VC（后和解） | 与 VC 博弈的教训 |
| **2005** | 创立 Vast.com | 继续创业 |
| **2007** | 创立 Venture Hacks 博客 | 分享创业融资技巧 |
| **2007** | 创立 Hit Forge（$20M 早期风投基金） | 投资 Twitter、Uber、Stack Overflow |
| **2010** | 联合创立 AngelList | 改变硅谷投资模式 |
| **2010** | 50位天使投资人承诺 $8000万 | AngelList 正式上线 |
| **2012** | AngelList 推出 Jobs 招聘平台 | 业务多元化 |
| **2013** | SEC 批准 AngelList Syndicates | 联合投资模式合法化 |
| **2014** | 联合创立 MetaStable Capital（加密货币对冲基金） | 投资 BTC、ETH、XMR 等 |
| **2014** | AngelList 推出 Maiden Lane 基金 | 在线风投基金创新 |
| **2015** | AngelList 平台免费化 | 降低创业融资门槛 |
| **2016** | AngelList 收购 Product Hunt（$20M） | 扩展产品发现业务 |
| **2016** | 创立 Republic（众筹平台分拆） | 民主化股权投资 |
| **2017** | 获得 CrunchFund "年度天使投资人" | 业界认可 |
| **2017** | 创立 Spearhead 投资基金 | 帮助创始人转型天使投资人 |
| **2017** | AngelList 估值持续增长 | 4400投资者、165财团、7万初创公司 |
| **2020** | AngelList 推出 Rolling Funds | 创新募资模式 |
| **2022** | AngelList 估值达到 $40亿 | 平台成熟期 |
| **2023** | 联合创立 Airchat（AI 社交 App） | 持续创新 |
| **2024.1** | 投资 Perplexity AI（$73.6M B轮） | 持续早期投资 |
| **2024.2** | 投资 Blush（$7M 种子轮） | 活跃投资 |
| **2024.11** | 投资 Substack | 内容平台投资 |
| **2025.1** | 投资 Rainmaker、TrueFoundry | 持续布局 |
| **2025.2** | 投资 Polymarket、Tera AI | 多元投资 |
| **2025.5** | 最新投资记录 | 保持活跃 |

# 两人共同点

1. **自我教育者**：都强调自学和持续学习
2. **内容创作者**：都通过内容建立影响力
3. **独立思考**：都挑战传统路径
4. **杠杆思维**：Naval 用资本杠杆，Koe 用内容杠杆
5. **长期主义**：都强调耐心和复利
