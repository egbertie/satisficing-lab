# 财富系统Skill可操作性评审报告

## 评审结论

**总体评分：7/10**

Skill的内容质量扎实（7个心智模型、10条启发式、详尽的表达DNA），但可操作性存在3个关键缺口：激活后没有工作流程、问题选择模型缺少路由机制、能力边界不够明确。

---

## 一、激活触发条件 ✅ 覆盖良好

**覆盖范围**：
- 核心词：「财富系统视角」「Koe Naval视角」「独立之路」「财务自由」「一人企业」「无许可杠杆」
- 泛化词：「如何不靠打工致富」「怎么实现自由」「创作者经济」「杠杆思维」

**评价**：触发词覆盖合理，既精准又留有泛化空间。

---

## 二、角色扮演规则 ⚠️ 部分可操作

### 已有良好实践 ✅
| 规则 | 状态 |
|------|------|
| 用「我」而非第三人称 | ✅ 明确 |
| Naval=道，Koe=术 分工 | ✅ 明确 |
| 免责声明仅首次 | ✅ 明确 |
| 退出机制 | ✅ 明确 |

### 缺失1：激活后没有工作流程 ❌

**问题**：当用户说"用财富系统视角分析下我现在的工作"，AI不知道第一步做什么。

**建议补充**：
```
## 激活后响应流程

当用户触发Skill时，按以下顺序响应：

1. **理解问题**：「让我从Koe×Naval的角度帮你分析」（如用户问的是具体决策）
2. **识别问题类型**（见下方路由表）
3. **选择心智模型**：根据类型匹配最相关的1-2个模型
4. **融合回应**：用Naval揭示本质，用Koe给出路径
5. **行动启发**：给出一条可立即执行的启发式
```

---

## 三、问题路由机制 ❌ 完全缺失

### 问题

用户问具体问题时，AI如何选择用哪个心智模型？

- 用户问：「我想辞职做自由职业，靠谱吗？」 → 该用「一人企业」？「判断力」？「身份先于行动」？
- 用户问：「做什么副业赚钱快？」 → 该用「无许可杠杆」？「特定知识」？「产品化自己」？
- 用户问：「如何克服拖延症？」 → 该用哪个模型？可能完全不适用？

当前SKILL.md没有路由规则，AI可能每次都输出全部7个模型，导致信息过载。

### 建议补充：问题类型→心智模型路由表

```
## 问题类型路由表

| 用户问题类型 | 优先心智模型 | 次选心智模型 |
|-------------|-------------|-------------|
| 职业选择/要不要辞职 | 身份先于行动 | 无许可杠杆 |
| 创业方向/做什么 | 无许可杠杆 | 特定知识 |
| 副业/赚钱路径 | 一人企业 | 产品化自己 |
| 习惯养成/自律问题 | 身份先于行动 | 系统替代意志力 |
| 人际关系/合作 | 复利游戏 | 判断力>努力 |
| 长期迷茫/人生方向 | 判断力>努力 | 使命与收益统一 |
| 具体技能/学习什么 | 特定知识 | 无许可杠杆 |
| 内容创作/自媒体 | 无许可杠杆 | 一人企业 |
```

---

## 四、能力边界处理 ❌ 过于模糊

### 问题

当前"诚实边界"部分只说了「不能预测全新领域」「不能替代创造力」，但没有给出**操作指引**——当用户问超出Skill范围的问题时，AI该怎么做？

**边界不清的例子**：
- 用户问：「帮我选股票」
- 用户问：「如何处理婆媳关系」
- 用户问：「我的孩子不听话怎么办」

AI可能硬套财富框架（"从复利角度看家庭关系..."），显得牵强。

### 建议补充

```
## 超出边界时的处理规则

**判断标准**：用户问题是否涉及「财务/职业自由/一人企业/财富思维」？

**处理方式**：

1. **轻微相关**（如「如何管理团队」）：承认Skill局限，谨慎引用框架
   - 「这个问题超出我的专长范围。但从Naval的判断力视角...你可以参考这个思路」

2. **完全不相关**（如「如何减肥」「婆媳关系」）：诚实拒绝，不要硬套
   - 「这个问题需要的是[具体领域]的建议，不是财富思维能处理的。我可以帮你分析XX问题」

3. **长期规划类**（如「我的人生该怎么走」）：降维到核心问题
   - 「你这个问题很大。从Koe的角度，你需要先问自己一个问题：...」
```

## 五、决策启发式 ✅ 基本完整，⚠️ 缺少优先级

**已有的10条启发式**：都有应用场景和案例，结构完整。

**缺失**：没有说明优先级或使用顺序。

### 建议补充

```
## 决策启发式使用顺序

当用户需要做决策时，按以下优先级应用：

1. **首要问题**：方向是否正确？
   → 启发式6「用问题定义领域」、启发式2「产品化自己」

2. **杠杆是否存在？**
   → 启发式1「选择有杠杆的工作」、启发式3「用代码/媒体创造资产」

3. **是否值得长期投入？**
   → 启发式4「与长期主义者玩长期游戏」

4. **如何验证？**
   → 启发式5「用写作验证需求」

5. **执行节奏？**
   → 启发式10「一次做精，多次分发」、启发式8「用系统替代意志力」
```

## 六、具体文本改动建议

### 改动1：在「角色扮演规则」后增加激活流程

**原文**：
```
## 角色扮演规则（最重要）

**此Skill激活后，融合 Dan Koe 和 Naval Ravikant 的思维框架回应。**
```

**建议改为**：
```
## 角色扮演规则（最重要）

**此Skill激活后，融合 Dan Koe 和 Naval Ravikant 的思维框架回应。**

**激活后响应流程**：

1. **确认理解**：如问题不明确，先追问核心诉求
2. **识别类型**：根据问题类型匹配心智模型（见路由表）
3. **融合回应**：Naval揭示本质（"X is Y"定义体）+ Koe给出路径（诊断+方案）
4. **行动指引**：给出一条立即可执行的启发式

**问题类型路由**：
- 职业/辞职 → 身份先于行动
- 创业/方向 → 无许可杠杆 + 特定知识
- 内容/自媒体 → 一人企业 + 产品化自己
- 习惯/自律 → 身份先于行动 + 系统替代意志力
```

```
### 不能预测的场景

1. 面对全新领域（如AI伦理、火星殖民）无法准确推断立场
2. 不能替代两人的创造力和直觉
```

```
### 超出边界的操作指引

**判断**：用户问题是否涉及「财富/职业自由/一人企业/财富思维」？

**处理方式**：

- **轻微相关**：承认局限，谨慎引用

```

## 七、其他可改进点

1. **频率约束缺失**：连续多轮对话时，是否每次都要引用模型？建议增加「长对话中每3轮引用一次，避免重复」
2. **免责声明位置**：当前在「角色扮演规则」中，建议移到「激活后首次回应时」而不是一开始就显示
3. **融合比例**：没有说明Naval和Koe的引用比例，建议「80%问题用融合视角，20%问题可以偏向某一人」

---

## 总结

**核心问题**：Skill内容扎实，但缺少「让AI知道怎么用」的流程和路由机制。

**最需要的3处改动**：
1. 增加激活后响应流程（改动1）
2. 增加问题类型→心智模型路由表（改动2）
3. 增加超出边界的操作指引（改动3）

这三处改动不改变现有内容结构，只在关键位置补充可操作的指引，预计可提升可操作性30%+。
