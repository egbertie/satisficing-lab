# 反向案例发现器 (Counter Case Finder)

帮助用户通过反向案例获得深度洞察的思考工具。

## 核心理念

**从反面看正面，从失败学成功。**

当你面临一个重要决策、思考一个问题或评估一个方案时，通过反向案例获得深度洞察。

## 三步逻辑链

| 步骤 | 名称 | 核心任务 |
|------|------|---------|
| 1️⃣ | 定义正面 | 梳理要点，确定"正面"的标准 |
| 2️⃣ | 搜索反面 | 找到相反案例，还原其脉络 |
| 3️⃣ | 总结建议 | 从反面教材提炼道理，给出建议 |

## 使用场景

- 重大决策前的风险评估
- 创新方案的可行性验证
- 战略规划中的盲点识别
- 学习他人失败经验避免踩坑
- 突破思维定势寻找新视角
- 论证方案时准备应对质疑

## 第一步：定义正面

多维度定义"正面"：
- **结果维度**：成功是什么样子？
- **过程维度**：正确的方法是什么？
- **条件维度**：需要哪些前提？
- **时间维度**：短期vs长期的成功？

## 第二步：搜索反面

还原案例脉络：
- 背景：当时的情境是什么？
- 决策：做了什么选择？
- 执行：如何实施的？
- 结果：最终怎样了？
- 后续：有什么长期影响？

## 第三步：总结建议

形成建议框架：
- 🚫 **红线**：必须避免的错误
- ✅ **条件**：必须满足的要素
- 🎯 **策略**：建议采取的行动
- ⚠️ **预警**：风险监控指标

## 使用方法

### 1. 安装依赖

```bash
python scripts/install_dependencies.py
```

### 2. 准备数据文件

参考 `examples/price_war_example.json`

### 3. 生成报告

```bash
python scripts/generate_report.py data.json 反向案例分析报告.docx
```

## 示例：降价策略分析

```bash
python scripts/generate_report.py examples/price_war_example.json 降价策略分析.docx
```

## 输出成果

**Word文档格式的反向案例分析报告**，包含：

1. 📄 **封面** - 标题、主题、日期
2. 📋 **执行摘要** - 核心问题、关键发现、建议
3. ✅ **第一步：定义正面** - 事件要点、多维定义
4. ❌ **第二步：反面案例** - 案例库、脉络还原
5. 💡 **第三步：总结建议** - 原因分析、行动清单
