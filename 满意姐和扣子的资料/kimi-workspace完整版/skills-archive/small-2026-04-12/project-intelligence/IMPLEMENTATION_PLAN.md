## 数据源配置

### 1. IT桔子融资事件
**频率**: 每日9:00
**指令模板**:
```
【IT桔子定时采集任务 - 每日9:00执行】
任务名称：itjuzi_daily_funding
执行指令：
1. 使用浏览器打开 https://www.itjuzi.com/investevents
2. 等待页面加载完成，截图保存到 /intelligence/raw/itjuzi_{日期}.png
3. 分析截图内容，提取最近7天内符合以下条件的事件：
   - 行业关键词：人工智能、芯片、生物医药、新能源、新材料、机器人、航空航天
   - 轮次：天使轮、Pre-A轮、A轮
4. 生成标准格式的融资快讯
5. 推送到飞书群并归档
```

### 2. 36氪硬科技新闻
**频率**: 每日10:00和16:00
**RSS源**: https://36kr.com/information/technology/feed

### 3. 动脉网生物医药
**频率**: 每日10:00
**领域**: 生物医药投融资

### 4. 政府政策扫描
**频率**: 每周一9:00
**来源**: 深圳科创委、上海市科委、北京市科委
