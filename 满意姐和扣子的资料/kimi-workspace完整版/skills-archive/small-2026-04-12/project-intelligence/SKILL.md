# project-intelligence - 项目情报采集系统

## 描述
满意解研究所的自动化情报采集系统实施方案。覆盖融资快讯、硬科技行业动态、政府政策扫描，为合伙人匹配业务提供市场情报支持。

## 触发条件
- 用户要求"采集融资信息"、"行业动态"、"政策新闻"
- 早晨站会需要融资快讯摘要
- 需要为潜在客户提供市场情报增值服务

## 核心架构
```
定时触发层 → 采集执行层 → 处理存储层
   │              │              │
   ▼              ▼              ▼
每日9:00      IT桔子/36Kr     飞书文档/多维表格
每周一政策    政府官网抓取    Telegram/本地归档
```

## 数据源配置
| 数据源 | 频率 | 内容 |
|--------|------|------|
| IT桔子融资事件 | 每日9:00 | 人工智能、芯片、生物医药、新能源等早期融资 |
| 36氪硬科技 | 每日10:00/16:00 | 硬科技赛道新闻 |
| 动脉网生物医药 | 每日10:00 | 生物医药投融资 |
| 政府政策扫描 | 每周一9:00 | 深圳/上海/北京科创委政策 |

## 输出格式
- **融资快讯**：标准Markdown格式，含合伙人视角分析
- **深度分析**：项目概况、核心团队、技术/产品分析、合伙人匹配建议、风险提示

## 存储结构
```
intelligence/
├── raw/           # 原始截图/网页
├── processed/     # 处理后数据
└── archive/       # 归档
```

- `kimi_search` - 补充搜索
- `feishu_im_user_message` / `feishu_bitable_app` - 推送与存储
