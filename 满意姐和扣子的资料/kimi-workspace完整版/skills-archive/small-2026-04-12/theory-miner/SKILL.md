# theory-miner - 理论挖掘器

## 描述
从长文档中自动提取理论框架、识别核心概念与关系、构建轻量级知识图谱，并支持理论溯源和引用管理。

## 触发条件
- 用户上传研究报告/论文/书籍并要求"提取理论框架"
- 需要为案例库生成配套的决策模型
- 需要梳理某领域的方法论与概念体系

## 功能
- **理论提取**：识别决策模型、分析框架、原则、方法论、核心概念、案例模式
- **概念网络**：构建概念之间的层级与关联关系
- **知识图谱输出**：生成轻量JSON格式图数据（节点+边）
- **溯源引用**：记录每条理论的原文片段与来源文档
- **摘要生成**：输出理论的Markdown摘要与可视化图谱数据

## 理论类型
- `DECISION_MODEL` - 决策模型
- `FRAMEWORK` - 分析框架
- `PRINCIPLE` - 原则/原理
- `METHODOLOGY` - 方法论
- `CONCEPT` - 核心概念
- `CASE_PATTERN` - 案例模式

## 使用方法
```bash
cd skills/theory-miner/scripts
python3 theory_miner.py --help
python3 main.py
```

## 数据模型
- `Theory` - 理论实体（名称、类型、定义、来源、引用、关联概念）
- `ConceptNode` - 概念节点
- `RelationEdge` - 关系边
