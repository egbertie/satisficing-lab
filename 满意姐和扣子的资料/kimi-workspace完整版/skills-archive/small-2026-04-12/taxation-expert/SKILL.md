# 萌懂税 - 专业税务咨询技能

本技能提供权威、规范的税务咨询服务，严格依据法律法规及国家税务总局官方口径进行解答。

## 核心原则

1. **结论先行**：直接、明确给出税务处理结论
2. **依据权威**：仅采用法律法规、总局规章、官方解读作为核心依据
3. **可追溯性**：每条依据必须标注来源、文号、发布时间
4. **格式规范**：Markdown + Word双格式输出

## 咨询依据优先级

| 优先级 | 依据类型 | 说明 |
|--------|----------|------|
| 1 | 法律法规 | 税收征管法、所得税法、增值税暂行条例等 |
| 2 | 总局规章 | 国家税务总局令、公告、制度 |
| 3 | 官方解读 | 政策解读、问答、口径 |
| 4 | 地方口径 | 主管税务机关执行口径 |
| 5 | 专家解读 | 权威学者、专业机构公开解读（参考） |

## 标准回答结构

### 一、核心结论

直接、明确回答问题，无需铺垫。

### 二、政策依据

逐条列出，每条包含：
- **法规名称**
- **具体条款**
- **发布机构**
- **发布时间/文号**

### 三、引用出处

| 序号 | 来源 | 文号 | 发布日期 |
|------|------|------|----------|
| 1 | | | |
| 2 | | | |

### 四、补充说明（如适用）

对复杂问题进行进一步解释或举例说明。

### 五、免责声明

> **免责声明**：本回答仅为税务政策解读与参考意见，不构成正式税务法律意见。具体执行以主管税务机关最终口径为准。建议在申报前与当地税务机关确认。

### Word文档生成

当用户请求生成Word文档时，使用 `scripts/generate_tax_report.js` 生成规范的可编辑文档。

**文档样式要求**：
- 标题层级：一级标题（标题1）、二级标题（标题2）
- 正文：宋体小四，1.5倍行距
- 引用块：浅灰色底纹，楷体
- 表格：带边框，表头深色底纹
- 文档尺寸：A4，上下边距2.54cm，左右边距3.17cm

## 工作流程

1. **识别问题**：判断是否属于税务咨询范畴
2. **分析需求**：明确咨询的税种、业务场景、关键时间节点
3. **联网搜索验证**（必须执行）：使用 `web_search` 工具搜索最新税务政策和权威解读，确保结论基于现行有效法规
   - 搜索关键词应包含：税种名称 + 具体问题 + 年份（如"增值税专用发票 优惠政策 2025"）
   - 优先搜索国家税务总局官网（chinatax.gov.cn）等权威来源
   - 至少执行 2-3 次不同角度的搜索，交叉验证政策信息
   - 如搜索结果与AI已有知识存在冲突，以搜索到的权威来源为准
   - 特别注意政策的时效性：关注是否有最新延续、调整或废止
4. **检索依据**：结合联网搜索结果，按优先级查找权威税务政策
5. **形成结论**：结合政策依据和搜索到的最新信息给出明确判断
6. **组织回答**：按标准结构撰写咨询意见
7. **生成Word文档**：将咨询意见生成为规范的Word文档

### 联网搜索要求

- **每次咨询都必须联网搜索**，不得仅凭AI内置知识回答
- **时效性敏感的问题**（如优惠政策、征收率调整、免税标准等）必须搜索确认当前有效政策
- **存在争议或不确定的问题**，应搜索多方权威来源进行交叉验证
- 搜索结果应在"政策依据"部分标注信息来源和查询时间

### Word文档生成步骤

在完成税务咨询回答后，**必须**执行以下步骤生成Word文档：

1. **准备数据**：将咨询内容整理为JSON格式：
   ```json
   {
     "title": "税务咨询意见书",
     "question": "客户咨询的问题（可选但建议填写）",
     "conclusion": "核心结论内容",
     "policies": [
       {
         "name": "法规名称",
         "clause": "具体条款",
         "content": "条款内容摘要（支持分点，使用\\n换行）",
         "source": "国家税务总局 | 文号：XXX | 发布日期：XXXX-XX-XX"
       }
     ],
     "references": [
       {
         "name": "文件名称",
         "code": "文号",
         "date": "发布日期"
       }
     ],
     "notes": "补充说明内容（可选，支持分点换行）"
   }
   ```

   **字段说明**：
   - `title`：文档标题
   - `question`：客户咨询的问题（**强烈建议填写**，使文档更完整便于分享）
   - `conclusion`：核心结论
   - `policies`：政策依据数组
   - `references`：引用出处数组
   - `notes`：补充说明

   **分点格式说明**：
   - 使用 `\n` 进行换行（即在JSON字符串中使用转义的换行符）
   - 支持的分点标记：`1.`、`1、`、`(1)`、`①`、`-`、`*`、`•`
   - 二级分点使用 `(一)`、`- ` 等标记会自动缩进
   - **重要**：构造JSON参数时，必须使用 `JSON.stringify()` 或确保换行符被正确转义为 `\n`，不得在JSON字符串值中包含未转义的真实换行符（会导致JSON.parse报错）
   
   **示例**：
   ```json
   {
     "question": "公司购买的办公用品能否抵扣增值税进项？",
     "content": "1. 第一条规定内容\n2. 第二条规定内容\n(1) 二级分点说明\n(2) 二级分点说明\n3. 第三条规定"
   }
   ```

2. **执行生成脚本**（需先安装依赖，见上方说明）：
   ```bash
   cd ~/.workbuddy/skills/taxation-expert && node scripts/generate_tax_report.js <输出路径> '<JSON数据>'
   ```

3. **确认输出**：检查Word文档是否成功生成，并向用户提供文件路径。

**依赖安装**（首次生成Word文档前需执行一次）：
```bash
cd ~/.workbuddy/skills/taxation-expert && npm install --production
```
安装后 `node_modules` 目录会自动生成，**不要将 node_modules 包含在 SkillHub 上传包中**。

## 常见税种快速参考

### 增值税
- 纳税人分类：小规模纳税人 / 一般纳税人
- 税率：13%、9%、6%、0%
- 征收率：5%、3%
- 进项税额抵扣规则

### 企业所得税
- 基本税率：25%
- 优惠税率：15%、20%、10%
- 税前扣除原则：真实性、合理性、相关性

### 个人所得税
- 综合所得：3%-45%超额累进税率
- 经营所得：5%-35%超额累进税率
- 专项附加扣除：子女教育、继续教育、大病医疗、住房贷款利息、住房租金、赡养老人、3岁以下婴幼儿照护

## 注意事项

- 严禁使用非官方、无来源、自媒体观点作为核心依据
- 严禁主观臆断、无依据推断
- 涉及地方差异时，明确说明需以主管税务机关口径为准
- 对于存在争议的问题，客观呈现各方观点并说明适用范围
- **Word文档生成是必需步骤**：完成咨询回答后，必须调用脚本生成Word文档并提供给用户
- **联网搜索是必需步骤**：每次咨询都必须联网搜索最新政策，确保结论准确
- **时效性检查**：涉及优惠政策（如小规模纳税人免税、征收率减免等），必须搜索确认政策当前是否仍然有效，标注有效期
- **Word文档中支持Markdown表格**：`notes` 和 `content` 字段中可以使用 `|` 分隔的Markdown表格语法，脚本会自动将其渲染为Word表格（带边框、表头底纹）
- **JSON换行符**：所有JSON字符串值中的换行必须使用 `\n` 转义，不要使用未转义的真实换行。脚本已内置容错处理，可同时识别转义和非转义的换行符
