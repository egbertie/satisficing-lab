# 7层标准化定义 - 知识入库最高标准

## 概述

本文件定义知识入库的7层标准化流程，对标深度研究论文标准。
所有通过本Skill入库的知识必须完整通过S1-S7全部7层。

---

## S1: 输入定义层 (Input Definition)

**目的**: 确保数据来源可追溯、可验证

### 必填字段

| 字段 | 说明 | 示例 |
|------|------|------|
| `knowledge_id` | 唯一知识标识符 | KNOW-P0-CORE-001-v1.0 |
| `title` | 知识标题 | SOUL.md - AI身份定义 |
| `original_filename` | 原始文件名 | SOUL.md |
| `source_path` | 完整源路径 | /root/.openclaw/workspace/SOUL.md |
| `file_hash` | SHA256哈希 | sha256:abc123... |
| `source_type` | 来源类型 | system_gen / user_upload / external |
| `created_at` | 创建时间 | 2026-03-20T08:27:29+08:00 |
| `modified_at` | 修改时间 | 2026-03-20T08:27:29+08:00 |
| `ingested_at` | 入库时间 | 2026-03-28T00:21:00+08:00 |
| `version` | 版本号 | 1.0.0 |
| `line_count` | 行数 | 139 |
| `byte_count` | 字节数 | 8724 |

### 验证规则
- [ ] knowledge_id 符合命名规范
- [ ] file_hash 已计算并记录
- [ ] 所有时间戳使用 ISO 8601 格式
- [ ] source_type 为枚举值之一

## S2: 内容处理层 (Content Processing)

**目的**: 提取核心知识，建立语义结构

### 处理步骤

1. **全文阅读**: 完整理解文档内容
2. **语义分块**: 按逻辑结构分块（章节/段落/列表）
3. **概念提取**: 识别核心概念、术语、实体
4. **关系图谱**: 建立概念间的关系网络
5. **关键引用**: 提取原文关键段落

### 输出格式

```markdown
# S2: 内容处理层 - 知识提取

## 核心架构
[Mermaid图表或逻辑结构]

## 关键概念提取
| 概念 | 定义 | 关联 |
|------|------|------|
| ... | ... | ... |

## 关键引用原文
> "..."

## 关联知识
- [KNOW-XXX] 文档名 - 关联说明
```

### 验证规则
- [ ] 包含Mermaid图表或等效结构图
- [ ] 至少3个关键概念提取
- [ ] 至少2段关键引用原文
- [ ] 列出所有关联知识

## S5: 准确性验证层 (Accuracy Validation)

**目的**: 确保知识质量，防止错误入库

### 验证流程

| 级别 | 验证方式 | 覆盖率 | 执行者 |
|------|----------|--------|--------|
| P0核心 | 100%逐项验证 | 100% | 蓝军 |
| P1重要 | 抽检20% | 20% | 蓝军 |
| P2一般 | 抽检15% | 15% | 蓝军 |
| P3参考 | 抽检10% | 10% | 蓝军 |

### 必填字段

```yaml
quality_score: 100        # 质量评分 0-100
validation_status: pending # pending / passed / failed
validator: blue_army      # 验证者标识
```

### 验证清单

- [ ] S1输入定义完整
- [ ] S2内容处理充分
- [ ] S3结构分类正确
- [ ] S4集成标记完成
- [ ] 关键概念准确
- [ ] 引用原文无误
- [ ] 交叉引用有效

### 验证规则

## S6: 局限标注层 (Limitation Annotation)

**目的**: 明确知识的适用范围和限制

### 必填字段

| 字段 | 说明 | 示例 |
|------|------|------|
| `valid_until` | 有效期至 | 2026-12-31 |
| `limitations` | 局限性列表 | ["可能随系统演化更新"] |
| `dependencies` | 依赖知识 | ["KNOW-P0-CORE-001"] |
| `confidence` | 置信度 | high / medium / low |

### 局限类型

- **时效性**: 知识可能随时间失效
- **范围性**: 知识仅适用于特定场景
- **依赖性**: 知识依赖其他知识
- **置信度**: 知识的可靠程度

### 验证规则
- [ ] valid_until 已设置
- [ ] limitations 数量 >= 1
- [ ] dependencies 已列出（如有）
- [ ] confidence 为枚举值之一

## S7: 对抗测试层 (Adversarial Testing)

**目的**: 测试知识在边界/错误场景下的鲁棒性

### 测试场景

| 场景类型 | 测试内容 | 通过标准 |
|----------|----------|----------|
| 边界测试 | 知识适用边界 | 明确边界定义 |
| 错误测试 | 常见错误识别 | 错误可被检测 |
| 一致性测试 | 与其他知识冲突 | 无冲突或已标注 |
| 失效测试 | 知识过期处理 | 有失效预案 |

### 输出格式

```markdown
## S7: 对抗测试结果

| 测试场景 | 结果 | 说明 |
|----------|------|------|
| 边界测试 | ✅ 通过 | ... |
| 错误测试 | ✅ 通过 | ... |
| 一致性测试 | ✅ 通过 | ... |
| 失效测试 | ✅ 通过 | ... |
```

### 验证规则
- [ ] 至少4个测试场景
- [ ] 每个场景有明确结果
- [ ] 失败场景有改进计划
