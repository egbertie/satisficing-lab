SlicingPie·计算练习

Moyer的动态股权公式：每个人的股权 = 贡献(公平市价-已获报酬) / 总贡献。用这个练习算一下你的团队。

练习

合伙人A：全职·12个月·放弃年薪60万·已获报酬0·现金投入10万
合伙人B：全职·12个月·放弃年薪50万·已获报酬0·现金投入5万

A的时间贡献 = 60万/12 × 100% × 12 = 60万
A的总贡献 = 60万 + 10万 - 0 = 70万

B的时间贡献 = 50万/12 × 100% × 12 = 50万
B的总贡献 = 50万 + 5万 - 0 = 55万

A的股权 = 70/125 = 56%
B的股权 = 55/125 = 44%

如果你们现在是50/50——差距6%。不算大——但已经偏离了实际贡献。建议每6个月重新算一次。
