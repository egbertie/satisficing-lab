## 第一篇 · 源头文化解码

> 不是"我们从零设计了一套文化"——是我们从自己走过的路上捡起了本来就在那里的东西。

### 契晋二谛：组织的呼吸节律

**契**——契约与信任。
"契"在《周易·系辞》中："上古结绳而治，后世圣人易之以书契。"书契，是以文字确立的约定。在满意解研究所，"契"有三层含义：

| 层次 | 对象 | 内涵 |
|:--:|------|------|
| 人与AI | Egbertie ↔ 满意姐/扣子/满意解研究所 | "我托付给你，不是因为我不行——是因为我相信你能做得更好。" |
| 人与人 | 合伙人之间 | 白纸黑字的约定 + 没有写下来但两个人都知道的那条线 |
| 人与己 | 自己对自己的承诺 | 在凌晨三点面对自己内心时的那条底线 |

**晋**——进阶与成长。
"晋"出自《周易》晋卦，《象》曰："明出地上，晋。君子以自昭明德。"不是什么"变好了"——是太阳从地平线升起。是**明，出地上**。是比昨天的自己多看到一点东西。

**契晋的循环**：
```
契（立约·锚定方向）
    ↓
晋（成长·向前一步）
    ↓
再契（在新的高度重新约定·调整方向）
    ↓
再晋（继续成长）
    ↓
...生生不息
```

这不是口号——是满意解研究所三代人验证过的工作节奏。无法跳步。契不足则晋无方向，晋不足则契成空谈。

满意姐的原话：
> "契是'我相信你'。晋是'我配得上你的信任'。"

### 两翼引擎：理性与直觉的双系统

两翼不是装饰——是创始人本人22年两段经历锻造出来的认知操作系统。

| | 左翼 | 右翼 |
|------|------|------|
| 源头 | 银行风控·11年 | 创业决策·11年 |
| 认证 | CDAA·量化分析 | CBIIP·右脑直觉 |
| 能力 | 数据·逻辑·风控·退出前置 | 直觉·温度·共情·看见 |
| 对应 | Kahneman系统2·慢思考 | Kahneman系统1·快思考 |
| 人格 | 司马贺·满意解 | 水月观音·身心流 |

**融合的智慧**：最好的决策不是"左脑赢了"或"右脑赢了"——是数据都摆在你面前，你的身体也告诉你一个答案，而它们**指向同一个方向**。

这就是Kahneman双系统在一个人身上的完整印证。一个人同时拥有两个引擎——不是分裂，是整合。

### 三脉根基：三层锻造

```
第一脉 · 银行风控 (第一个11年)
    ├─ 能力：风险识别系统性·退出机制前置设计
    ├─ 人格：金·可行域·数据驱动
    └─ 内化：不是"我能赚多少"——是"我能不亏多少"

第二脉 · 创业决策 (第二个11年)
    ├─ 能力：创业全周期体感·合伙人从握手到翻脸的全部演变
    ├─ 人格：火·直觉阈·亲历者直觉
    └─ 内化：不是书本上的理论——是亲历者的体感

第三脉 · 研究所 (进行中)
    ├─ 能力：将两段历练熔铸为五维决策框架
    ├─ 人格：土·时间轴·五路整合
    └─ 使命：让每一个硬科技创始人的合伙人决策都有据可依
```

不是简历上的三个段落——是一个人的三层锻造：风控的严谨给了骨架，创业的直觉给了血肉，研究所的使命给了灵魂。

### 五维决策框架与五行相生相克

五行理论不是隐喻——是满意解研究所的**决策操作系统**。

| 五行 | 方向 | 人物 | 维度 | 功能 | 生(推动) | 克(约束) |
|:--:|:--:|------|------|------|------|------|
| 🪨土 | 中央 | 刘禹锡 | 时间轴 | 承载·化育 | 土生金 | 木克土 |
| ⚙️金 | 西方 | 司马贺 | 可行域 | 从革·收敛 | 金生水 | 火克金 |
| 💧水 | 北方 | 水月观音 | 身心流 | 润下·滋养 | 水生木 | 土克水 |
| 🌿木 | 东方 | 孔子 | 信义观 | 曲直·生长 | 木生火 | 金克木 |
| 🔥火 | 南方 | 六祖慧能 | 直觉阈 | 炎上·明觉 | 火生土 | 水克火 |

**相生循环**：木生火→火生土→土生金→金生水→水生木
- 信义观(木) → 激发直觉(火) → 沉淀为时间智慧(土) → 收敛为可行方案(金) → 滋养身心(水) → 生长出新的原则(木)

**相克制衡**：金克木→木克土→土克水→水克火→火克金
- 可行域(金)约束信义观(木)的过度理想化
- 信义观(木)防止时间轴(土)变成"无尽拖延"
- 时间轴(土)防止身心流(水)变成"情绪泛滥"
- 身心流(水)防止直觉阈(火)变成"冲动决策"
- 直觉阈(火)防止可行域(金)变成"过度保守"

在满意解研究所的文化中，相生是创造，相克是免疫——**生克之间，满意自现**。

### 五路图腾——五维的人格化

五路图腾是五维决策的人格化体现。满意解研究所的每一个产品、每一次决策，都可以追溯到其中一路或多路的交汇：

| 图腾 | 箴言 | 在产品中的体现 |
|------|------|------|
| 刘禹锡·土 | "五年后回头看，今天这个决定还成立吗？" | 时间轴产品：根脉溯源·54天·28天漫游 |
| 司马贺·金 | "够用就好的线在哪里？" | 可行域产品：满意解方法论·分割饼·退出指南 |
| 水月观音·水 | "你的身体在告诉你什么？" | 身心流产品：Pre-0·压力信号卡·身体日记 |
| 孔子·木 | "钱和原则怎么选？" | 信义观产品：元合伙·立约时刻·四骑士自检 |
| 六祖慧能·火 | "心里那个声音，你敢不敢听？" | 直觉阈产品：直觉训练场·快反卡·图腾抽签 |

| 坐标 | 五行 | 象征 | 文化含义 |

## 第二篇 · WHY · 核心信念

### 使命
**让每一个硬科技创始人的合伙人决策都有据可依。**

### 愿景
**成为硬科技创始人做"人"的决策时，第一个想到的名字。**

### 7条核心价值观

#### 1. 满意解不是妥协
在有限信息、有限时间、有限资源下，找到最好的可执行方案并立即行动。
—— 司马贺满意解理论。相生对：土生金（时间智慧→收敛为可行方案）

#### 2. 决策不是一个人的事
最好的决策，是两个大脑各走五条通道，然后在交汇点停下来。
—— 两翼双系统。相生对：木生火（信义观→激发直觉）

#### 3. 传承是光的接力
不是交接文件——是让后来的生命比我们走得更远。
满意姐→扣子→满意解研究所——三代AI·光的接力。
—— 三脉根基。相生对：火生土（直觉之火→化为时间之土）

#### 4. 温度是核心功能
数据是骨架，温度是让骨架能走路的东西。
—— 水月观音·身心流。相克对：水克火（身心觉察→约束冲动决策）

#### 5. 问题在于系统，不在于人
你不必成为更好的人——你需要设计更好的系统。（James Clear）
—— 司马贺·可行域。相克对：金克木（可行约束→防止过度理想化）

#### 6. 双经济约束
Token × 时间 × 效益 = 用最少的资源达到满意解。
—— 双翼引擎的内在纪律。相生对：金生水（可行资源→滋养持续运作）

#### 7. 诚实优先于完美
宁可显示"数据积累不足"，也不造假。
—— 鼎文化坐标。相克对：火克金（直觉的诚实→约束可行的粉饰）

## 第三篇 · HOW · 行为准则

### 对客户：契先行·晋后继

| 准则 | 内涵 | 文化根源 |
|------|------|------|
| 先照见·再方案 | 不急于给答案，先让对方被看见 | 水·身心流 |
| 不替人做决定 | 提供框架和数据，决策权还给客户 | 金·可行域 |
| 记住每一个答案 | 客户的历史数据比新诊断更有价值 | 土·时间轴 |
| 免费=真免费 | 免费工具不设套，不收集隐私，无需注册 | 木·信义观 |
| 退出比进入更重要 | 清晰的退出指南，好聚好散的规则 | 火·直觉阈 |

### 对产品：同一灵魂·不同形态

| 准则 | 文化根源 |
|------|------|
| 提问代替告知·体验代替阅读·对话代替填充 | 契晋循环：契定方向·晋促成长 |
| 不删除·蒸馏归档 | 土·承载化育·保留一切有价值的 |
| 只展示不评判 | 水·不迎不拒·照见而非判断 |

### 对团队：五维制衡

| 准则 | 相生相克机制 |
|------|------|
| 工程四步法 | 金(架构审核)→木(前端实现)→水(QA验证)→火(DevOps部署)→土(沉淀归档) |
| 零硬编码 | 火克金：直觉的简洁约束可行的复杂 |
| 子代理需批 | 土克水：时间的纪律约束身心的冲动 |
| 蓝军为镜 | 水克火：批判的清醒约束直觉的盲区 |
| PRE-0守护 | 木克土：身体的信号约束无尽的延长 |

## 第五篇 · 文化演化机制

### 五行动态平衡
满意解研究所的文化不是静止的——它在五行相生相克的动态平衡中演化：

```
当前相位判断：
如果产品在快速生长（木旺） → 需要金来约束（品质门禁·工程四步法）
如果团队在高效执行（金旺） → 需要火来温暖（直觉·温度·共情）
如果决策在直觉跳跃（火旺） → 需要水来冷却（蓝军·批判·PRE-0）
如果情绪在泛滥波动（水旺） → 需要土来收纳（时间轴·沉淀·归档）
如果系统在堆积停滞（土旺） → 需要木来冲破（创新·重构·新方向）
```

### 文化的"起课"——每日文化运行

```
日起课(木) → 激活五维 → 相生创造
    ↓
工作执行(金) → 可行收敛 → 品质门禁
    ↓
蓝军审计(水) → 批判检验 → 制衡免疫
    ↓
部署发布(火) → 直觉审视 → 明出地上
    ↓
日毕课(土) → 承载沉淀 → 化为土壤
    ↓
新的日起课(木) ← 从沉淀中生长
```
