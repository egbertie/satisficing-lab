# 满意解研究所 · 产品体系深度重构方案 v6.0

> 编制: 软件架构师 + 专家团队 | 2026-06-01
> 核心原则: **以客户价值最大化为中心，以客户全生命周期价值为主线**

---

## 一、指导原则——不是"我们有什么"，而是"客户获得什么"

### 1.1 核心转变

| 之前（v4/v5） | 之后（v6） |
|------|------|
| 以产品为中心：产品分层(L0-L3)→客户匹配 | **以客户价值为中心**：客户每阶段只获得3-5个产品，解决一个确定性问题 |
| 按产品形态分类：测评·交互·诊断·框架 | **按客户效益分类**：认知收益→行动收益→关系收益→资产收益 |
| 产品→客户匹配：按阶段推荐产品 | **客户→问题→产品→效益**：客户的问题决定推荐，推荐后跟踪效益 |

### 1.2 客户价值金字塔（四层效益）

```
        ┌──────────────────────┐
        │  💰 资产收益(A-Level) │  客户获得可长期使用和传播的方法论·认证·知识产权
        │  品牌背书·方法论体系  │  例: 白皮书联合署名·认证引导师·案例共创
        ├──────────────────────┤
        │  🤝 关系收益(R-Level) │  客户与合伙人的关系发生实质性改善
        │  信任重建·冲突解决    │  例: 退出方案执行·元合伙章程·匹配成功
        ├──────────────────────┤
        │  🎯 行动收益(D-Level) │  客户做出了一个更好的决策
        │  决策质量·行动路径    │  例: 完成卡牌对局·使用分割饼谈股权·写好了退出协议
        └──────────────────────┘
```

**设计原则**：客户进入时在最底层（认知收益），逐步向上走。每升一层，客户的LTV（生命周期价值）提升一个量级。

### 1.3 客户全生命周期价值(LTV)模型

```
LTV = 认知收益(1x) × 行动收益(3x) × 关系收益(10x) × 资产收益(30x)

解释:
- 认知收益: 客户免费获得洞察 → 价值感较低，但不可或缺的入口
- 行动收益: 客户花钱买个行动方案 → 价值3x认知
- 关系收益: 客户花钱解决一个关系危机 → 价值10x认知（合伙企业估值影响）
- 资产收益: 客户成为方法论的传播者 → 价值30x认知（新客户来源+品牌增值）
```

**核心洞察**：只要让客户攀登这个价值阶梯，单个客户的LTV可以轻松做到30倍。不push产品，而是让客户在不同阶段自然地要下一个。

## 二、产品体系重构：从"产品清单"到"客户价值路径"

### 2.1 不是所有产品都有同等价值

当前315个产品中：

| 产品类型 | 数量 | 客户价值 | 处理方式 |
|------|:--:|------|------|
| 价值核心 | ~15个 | 每个都对应一种客户效益 | 精选·打磨·精品化 |
| 价值卫星 | ~50个 | 支持核心·特定场景深度 | 线上·按需展示 |
| 历史资产 | ~100个 | 早期版本·已被替代 | 归档·内部参考 |
| 内部工具 | ~150个 | 仅内部价值 | 驾驶舱可见·客户不可见 |

**结论：客户只需要15个产品完成全程，其他产品是支持、是资产、是历史。**

### 2.3 客户价值路径：6条标准旅程

#### 路径1: 新认识的合伙人 → 如何确认对方合适
```
五维自评 → 雷达图对比 → 决策前自检清单 → 30分钟轻咨询
效益: 认知(看清差异) → 行动(清单检查) → 认知(咨询确认)
```

#### 路径2: 股权没谈好 → 如何量化分配
```
五维自评 → 分割饼 → 卡牌对局(股权场景) → 元合伙章程
效益: 认知 → 行动(量化) → 行动(沟通) → 资产(规则)
```

#### 路径3: 感觉关系变冷 → 如何检测
```
关系温度计 → 四骑士 → 卡牌对局(信任场景) → 完整诊断报告
效益: 认知(量化) → 认知(识别) → 行动(沟通) → 关系(系统性方案)
```

#### 路径4: 走到了分手这一步 → 如何体面退出
```
完整诊断报告 → 退出指引 → 30分钟轻咨询 → 案例库(退出案例)
效益: 关系 → 行动 → 认知 → 认知
```

#### 路径5: 已经解决了自己的问题 → 如何帮助别人
```
案例共创 → 白皮书联合署名 → 认证引导师 → 闭门活动
效益: 资产(贡献) → 资产(权威) → 资产(能力) → 资产(网络)
```

#### 路径6: 快速自检 → 不需要深度介入
```
五维自评 → 自检清单 → 案例库
全免费·15分钟完成·无后续push
效益: 认知(看清) → 行动(检查) → 认知(参考)
```

## 三、产品审核标准 (基于5/30讨论升级)

### 3.1 审核维度与权重

| 维度 | 权重 | 评估问题 | 评分标准 |
|------|:--:|------|------|
| 客户效益 | 35% | 这个产品能给客户什么实质价值？ | 客户会说"帮我省了XXX/帮我解决了XXX"→90分 |
| 完成度 | 25% | 产品是否可以独立交付？ | 完整·无已知BUG·可独立使用→90分 |
| 设计标准 | 15% | 是否符合VI规范和产品设计标准？ | 严格符合→90分 |
| 反馈闭环 | 10% | 是否有使用数据或反馈机制？ | 有真实使用记录和改进→90分 |
| 独特性 | 10% | 是否和客户已有的选择不同？ | 显著差异→90分 |
| 更新及时性 | 5% | 是否近90天有迭代？ | 近30天更新→90分 |

### 3.2 KKC决策矩阵

```
评分 ≥ 80分: Keep (保留·精品) → 品牌首页优先展示
评分 60-79: Keep (保留·线上) → 产品目录·驾驶舱展示
评分 40-59: Combine (考虑合并或重组) → 评估中
评分 < 40: Archive (归档为知识库或内部) → 客户不可见
```
