## 补一、之前遗漏的模块

### 1.1 密码生成器 (Password Manager)

**定位**: 驾驶舱不仅是密码门的"消费者"，更是全站密码管理的"生产者"

| 功能 | 说明 |
|------|------|
| 密码生成 | 按规则生成（长度/复杂度/特殊字符） |
| 密码分级 | L1公开/L2产品体验/L3内部管理 —— 不同层不同密码策略 |
| 密码轮换 | 定期提醒更换，记录历史 |
| 密码分发 | 生成后复制到剪贴板，不落盘明文 |
| 访问日志 | 记录密码使用时间/IP（隐私模式下仅时间） |
| 统一门控 | gate.html → dashboard-v2 统一调用同一密码策略 |

**驾驶舱内位置**: 系统设置 tab → 密码管理面板

### 1.2 统一口径引擎 (Canonical Terminology Engine)

**定位**: 全站所有文本的**单一事实来源（Single Source of Truth）**。任何术语变更自动传播到所有引用页面。

**工作原理**:
```
┌──────────────────────────────────┐
│  核心词汇产权表 (词汇-Knowledge Base) │
│  {                               │
│    "观自在": "水月观音",            │
│    "四骑士": "关系危机信号",          │
│    "决策教练": "决策外脑",           │
│    "满意红/扣子": "研究积累",         │
│    ... 更多标准化映射               │
│  }                               │
└──────────────┬───────────────────┘
               │ 术语变更事件
               ▼
┌──────────────────────────────────┐
│  术语同步引擎 (Term Sync Engine)    │
│  1. 扫描全站 248 HTML / Markdown    │
│  2. 找到所有包含旧术语的文件          │
│  3. 自动替换（标记审核状态）          │
│  4. 生成变更影响报告                 │
└──────────────┬───────────────────┘
               │ 批量更新
               ▼
┌──────────────────────────────────┐
│  页面自动更新                       │
│  ✅ index.html: "观自在" → "水月观音" │
│  ✅ about.html: "观自在" → "水月观音" │
│  ✅ decision-theatre.html: 同上      │
│  ⚠️ 对话/2026-05-11/某文件: 人工审核  │
└──────────────────────────────────┘
```

**驾驶舱内位置**: 术语管理 tab → 统一口径面板

**核心词汇产权表 V2.0 升级**: 从 Markdown 进化为交互式面板
- 每条词汇显示: 旧词→新词、影响文件数、变更状态、审核状态
- 一键传播: 确认变更后自动替换所有引用
- 回滚能力: 误改可一键回退
- 冲突检测: 同一文件多次修改时合并提示

### 1.3 指令体系 (Command Registry)

**定位**: 驾驶舱内集成所有可用指令，作为操作的快捷入口

| 指令类别 | 示例 | 驾驶舱操作 |
|----------|------|-----------|
| `/backup` | 全站备份 | 一键触发备份脚本 |
| `/deploy` | 部署到 GitHub Pages | 一键 git push |
| `/scan` | 全站质量体检 | 运行 quality-check.sh |
| `/sync-feishu` | 同步飞书数据 | 拉取最新 Base 数据 |
| `/rollback` | 回滚到指定版本 | 交互式选择 tag |
| `/seed` | 重新种子数据 | 重置 localStorage |
| `/term-update` | 术语批量更新 | 触发统一口径引擎 |
| `/asset-scan` | 扫描休眠资产 | 触发资产激活管道 |
| `/health` | 系统健康检查 | Cron + API + 文件完整性 |
| `/report` | 生成日报/周报 | 自动汇总今日变更 |

**驾驶舱内位置**: 顶部脉搏层 → 命令输入框（类似 VS Code Command Palette）

## 补二、四个核心概念落地

### 2.1 休眠资产激活管道（Asset Activation Pipeline）

> 核心理念：不是手动整理——是让 AI 自动扫描、提取、连接、可视化

**五阶段管道**:

```
扫描 ──→ 标签 ──→ 脱水 ──→ 索引 ──→ 连接 ──→ 可视化
 │         │         │         │         │          │
 │         │         │         │         │          └→ 驾驶舱资产图谱
 │         │         │         │         └→ 知识图谱关系边
 │         │         │         └→ 全文搜索引擎索引
 │         │         └→ 提取摘要、关键词、行动点
 │         └→ NLP自动分类、打标签
 └→ 扫描所有文件（MD/HTML/JSON/对话记录）
```

**驾驶舱落地**:
- 「资产图谱」tab: 显示休眠资产/活跃资产/废弃资产的数量和分布
- 「新发现」通知: 每次扫描后发现的新知识连接
- 「激活队列」: 待审核的休眠资产列表，一键激活或归档
- 「连接密度」热力图: 哪些话题之间缺乏连接（需要补充）

### 2.2 事件驱动架构（Event Bus）

> 核心理念：不是定期轮询——是事件触发立即同步。驾驶舱是事件中枢。

**事件类型定义**:

| 事件 | 触发条件 | 驾驶舱响应 |
|------|----------|-----------|
| `term.changed` | 术语变更确认 | 自动扫描+替换+报告 |
| `task.completed` | 任务标记完成 | 更新KPI + 刷新关联视图 |
| `page.updated` | 任何页面被修改 | 更新资产图谱 + 标记新鲜度 |
| `milestone.due` | 里程碑即将到期 | 告警推送 |
| `cron.failed` | Cron任务失败 | 红色告警 |
| `customer.action` | 客户有互动 | 更新客户活跃度 |
| `product.published` | 新产品上线 | 产品计数+1 + 资产图更新 |
| `system.anomaly` | 系统异常 | 立即告警 + 影响范围估计 |

**驾驶舱落地**:
- 事件日志流（实时滚动，类似 CI/CD pipeline）
- 事件类型过滤器
- 事件 → 关联实体跳转

### 2.3 数字孪生（Digital Twin）

> 核心理念：驾驶舱 = 满意解研究所的数字孪生，物理世界和数字世界双向实时同步

**映射关系**:

| 物理世界 | 数字孪生（驾驶舱） |
|----------|-------------------|
| 文件数量 | 资产计数 + 变化趋势 |
| 任务状态 | 实时任务看板 |
| 客户互动 | 客户活跃度热力 |
| 产品质量 | 产品成熟度仪表 |
| 知识结构 | 知识图谱可视化 |
| 系统健康 | Cron/API 状态灯 |
| 团队节奏 | 每日脉冲图（commit数/对话数/决策数） |
| 品牌一致性 | 术语标准化度评分 |

**数字孪生可视化**: 
- 首页概览 = 项目的「生命体征监测仪」
- 脉搏层 = 心跳（系统是否活着）
- 态势层 = 血压/体温（是否在正常范围）
- 操作层 = 处方/治疗（如何干预）

### 2.4 知识图谱（Knowledge Graph）

> 核心理念：不是表格罗列——是实体之间的连接网络

**知识图谱节点类型**:
- 任务 ↔ 客户（谁的任务服务于哪个客户）
- 任务 ↔ 产品（哪个任务关联哪个产品线）
- 客户 ↔ 产品（哪个客户在使用哪个产品）
- 替身 ↔ 任务（哪个替身参与了哪个决策）
- 术语 ↔ 页面（哪个术语出现在哪些页面）
- 决策 ↔ 任务（哪个决策关联了哪些执行）

**驾驶舱落地**:
- 「关联图谱」tab: 力导向图可视化
- 点击任意节点 → 高亮所有关联实体
- 发现「连接空洞」→ 提示需要建立联系

## 补四、分期路线调整

### Phase 1 · 心脏重建 (现在-2天) 
**新加入**: 统一口径引擎 + 口令系统 + 指令面板基础框架
- 数据模型重建（含术语表/事件日志/指令注册表）
- 脉搏层 + 态势层 + 操作层布局
- 任务 CRUD + 预警 + 筛选搜索
- **术语产权表面板（核心词汇表交互版）**
- **术语同步扫描引擎（一键检测全站）**
- **密码生成器 + 分级管理**
- **快捷指令栏（/backup /scan /deploy）**

### Phase 2 · 数据融合 (2-3天)
**新加入**: 资产激活管道首次运行
- 飞书数据全量导入
- 资产扫描管道第一期：扫描248 HTML + 全部 Markdown → 生成资产清单
- 自动打标签（NLP分类：产品/客户/工具/内容/系统/其他）
- 休眠资产识别 + 激活建议
- 血液化进度 + 四Week可视化

### Phase 3 · 智能增强 (3-5天)
**新加入**: 事件总线 + 数字孪生可视化
- 事件日志流 + 触发-响应链路
- 数字孪生面板（生命体征仪表）
- 知识图谱：任务-客户-产品-替身关系网
- 术语同步自动化（变更→扫描→替换→报告）
- 每日摘要 + 异常检测 + 趋势图表

### Phase 4 · 心脏连通 (持续)
- 飞书 API 实时同步
- 全站「← 驾驶舱」返回入口
- Webhook 事件接收
- 自动日报/周报生成

## 补五、数据模型扩展

```javascript
// === 新增实体 ===

// 术语条目 (统一口径引擎)
Term {
  id, oldTerm, newTerm,
  category, // '对外表述'|'内部表述'|'品牌叙事'|'产品术语'
  reason, // 变更原因
  status, // '已确认'|'审核中'|'已传播'
  affectedFiles[], // 影响的文件列表
  lastSynced, syncedBy
}

// 事件日志 (事件总线)
Event {
  id, timestamp, type, // term.changed | task.completed | page.updated ...
  source, // 触发来源
  payload, // 事件数据
  status, // '待处理'|'已处理'|'忽略'
  relatedEntities[] // 关联实体ID
}

// 资产条目 (资产激活管道)
Asset {
  id, path, type, // 'html'|'md'|'json'|'pdf'|'飞书文档'
  status, // '活跃'|'休眠'|'废弃'|'待审核'
  lastModified, lastAccessed,
  tags[], // NLP自动分类
  summary, // 自动摘要
  connections[], // 关联的其他资产ID
  connectionDensity // 连接密度评分
}

// 指令注册 (指令面板)
Command {
  id, name, shortcut,
  description, category,
  action, // 执行的函数或脚本
  requiresConfirm // 是否需要二次确认
}

// 密码策略 (口令系统)
PasswordPolicy {
  layer, // 'L1公开'|'L2体验'|'L3管理'
  currentPassword, hash,
  generatedAt, expiresAt,
  history[], // 历史密码哈希
  accessLog[] // 访问记录
}

// 知识连接 (知识图谱)
KnowledgeEdge {
  id, sourceEntity, targetEntity,
  relationType, // '关联'|'依赖'|'产出'|'引用'
  strength, // 1-10
  discoveredAt, // 自动发现时间
  verifiedBy // 人工确认
}
```

## 补六、关键度量补充

### 系统性健康度量

| 指标 | 计算方式 | 目标值 |
|------|----------|:------:|
| **资产覆盖率** | 已索引资产 / 总文件数 | >90% |
| **术语一致性** | 已统一术语的页面 / 应统一页面 | 100% |
| **连接密度** | 有连接的实体 / 总实体 | >60% |
| **休眠率** | 休眠资产 / 总资产 | <20% |
| **事件响应率** | 已处理事件 / 总事件 | >95% |
| **数字孪生同步延迟** | 最后变更时间 - 现在 | <5分钟 |
| **知识图谱完备度** | 已建立的边 / 应有的边 | >70% |
