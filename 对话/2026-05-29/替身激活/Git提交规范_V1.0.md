# Git提交规范

> 版本: V1.0 | 生效: 2026-05-29
> 来源: 代码工程师+数据分析师独立审核发现

---

## 原则

一次提交 = 一个逻辑变更。不批量提交。

## 提交消息格式

```
<type>: <简短描述>

<详细说明（可选）>
```

type: feat(功能) | fix(修复) | docs(文档) | style(样式) | refactor(重构) | chore(杂项)

## 禁止

- ❌ 一个大提交包含50+个文件变更
- ❌ 不同逻辑修改混在一次提交
- ❌ 无提交消息或单字提交消息
