## 域名过渡方案

```
阶段一（现在）：GitHub Pages 继续服务 + 腾讯云资源搭建
阶段二（备案通过）：新域名指向腾讯云 + GitHub Pages 保留1周
阶段三（完全迁移）：GitHub Pages 归档·飞书邮箱启用·网站闭环
```

---

## 技术迁移路径

| 现状 | 目标 |
|------|------|
| GitHub Pages | COS + EdgeOne Pages |
| 纯静态 | 静态层（不变）+ Flask API（新增） |
| 飞书多维表格 | 保持 + 后端自动同步 |
| 无邮件 | 飞书邮箱 API |
| 无数据库 | SQLite（本地）→ MySQL/PostgreSQL（腾讯云） |
| 无认证 | JWT（本地）→ 腾讯云不变 |

---

## 迁移时只需改两处

```js
// sri-api.js / sri-track.js
base: "http://127.0.0.1:5050" → "https://api.你的域名.com"

// server/config.py
CORS_ORIGINS → ["https://你的域名.com"]
```
