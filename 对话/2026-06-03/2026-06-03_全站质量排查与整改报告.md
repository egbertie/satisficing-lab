## 一、发现的问题

### 1. 管理后台标题裸露
- **现象**：`admin-windows.html` 页面左上角显示 `admin-windows`
- **根因**：HTML body 中硬编码 `<h1>admin-windows</h1>`，JS 失败时直接暴露
- **修复**：改为 `<h1>🏢 管理后台 · 满意解研究所</h1>`

### 2. 驾驶舱密码门明文泄漏
- **现象**：驾驶舱页面直接显示密码 `123654`，源码中存有完整密码逻辑
- **根因**：旧版 `dashboard-v3.html` 保留了 sessionStorage 密码门，密码写死在 JS 源码
- **修复**：彻底移除密码门（CSS 样式 + HTML 布局 + JS unlock 函数 + PASSCODE 变量），改为直接启动

### 3. 驾驶舱快捷入口混乱
- **现象**：快捷按钮 `🔐密码管理` `📖数据字典` `📊V1面板` 要么失效要么指向错误页面
- **根因**：链接指向不存在的 `gate.html` 或已废弃的 `dashboard.html`
- **修复**：精简为 `🏢管理后台` `🧭产品地图` `🤝客户通道` `👤个人中心` 四个有效入口

### 4. 首页 Footer 链接不完整
- **现象**：只有「产品大脑」指向驾驶舱，底部还有一个无意义的 🔧 图标链接
- **根因**：`index.html` footer 久未更新，新增的客户通道、个人中心页面没有入口
- **修复**：Footer 新增 `🤝客户通道` `👤个人中心` `📊驾驶舱` `🏢管理后台`，移除密码图标

### 5. sri-design.css 被批量脚本截断（最严重）
- **现象**：`go.html`、`guide.html` 等 6 个页面排版完全崩溃
- **根因**：批量注入 `sri-track.js` 时，sed 命令同时覆盖了非 HTML 文件的头部内容
- **受损文件**：`sri-design.css`(6166→117B) `flywheel-engine.js`(6667→119B) `gate-check.js`(14757→943B) `password.js`(545→121B)
- **修复**：`git show HEAD:文件名 > 文件名` 逐个恢复
- **预防**：注入脚本改为 Python 精确匹配 `</head>`，跳过非 `.html` 文件

### 6. admin-windows.html JS 语法错误
- **现象**：页面一直显示 loading，超过 1 分钟无变化
- **根因**：JS 代码块末尾残留了裸 `</div>` 标签（旧 gate 门禁的 HTML 碎片），导致 `Unexpected token '<'` 整个脚本崩溃
- **修复**：清理 `<script>` 标签内所有非 JS 代码的 HTML 标签

### 7. go.html 缺少客户通道链接
- **现象**：产品导航页 footer 无客户通道入口
- **修复**：新增 `🤝 客户通道` 链接

### 8. admin-windows.html 缺少 `</body></html>` 结束标签
- **根因**：编辑时截断了页面尾部
- **修复**：补全结束标签

## 三、核心教训

### 🚫 批量脚本必须限定目标文件类型
**2026-06-03 教训**：用 sed 批量修改 HTML 时，没有排除 `.css` `.js` 等非 HTML 文件，导致 4 个关键文件被截断为几字节。
**预防**：批量注入改用 Python `os.listdir` + `endswith('.html')` 精确过滤。

### 🚫 修改遗留代码时必须全量检查
**2026-06-03 教训**：admin-windows.html 有多处历史遗留——旧 gate 的 `</div>` 残留在 `<script>` 内、缺少 `</body></html>` 标签。
**预防**：`dev.sh verify` 新增「JS 括号平衡」和「HTML 标签完整性」检查。

### 🚫 安全敏感信息不能留存在公开仓库
**2026-06-03 教训**：`dashboard-v3.html` 源码含明文密码 `123654`，任何人查看页面源码即可获取。
**预防**：`dev.sh verify` 新增「密码泄漏检查」，任何包含 `PASSCODE` / `password` 明文的关键页面自动告警。
