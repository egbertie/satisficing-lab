# 2026-06-03 · 后端服务体系 v2.0 搭建报告

> 产出时间: 2026-06-03 18:00-19:15

---

## 核心产出

### 1. 技术架构
```
前端层: GitHub Pages + sri-track.js(事件采集) + sri-api.js(API SDK)
中端层: Flask REST API(20+ endpoints) + JWT认证 + IP限流 + 审计日志
后端层: SQLite 12表 + 飞书集成(通知/表格/邮箱)
驾驶舱: /api/admin/* 6面板实时数据接口
```

### 2. 12 张数据表
customers(360°画像) · events(行为事件) · sessions_tracking(会话链路)
deliveries(产品交付) · inquiries(客户留言) · referrals(转介绍追踪)
email_logs(邮件日志) · api_logs(安全审计) · decision_cases(决策案例)
system_config(系统配置) · sessions(JWT) · verification_codes(验证码)

### 3. API 清单（20个接口）
- 认证：register / login / me / logout
- 交互：contact / inquiries / profile / deliveries
- 事件：track / session_start / session_end
- 转介绍：referral_create / referrals
- 管理：dashboard_summary / funnel / dau / products / events_recent / customers

### 4. 前端适配
- sri-track.js 自动注入 264 个 HTML 页面
- sri-api.js 封装所有后端调用（含Referral API）
- account.html 重建为个人中心（登录/注册/档案/产品/推荐）
- 首页增加「👤 个人中心」入口

### 5. 飞书邮箱集成
- API 方式：飞书 mail/v1 API（需 user_token + mail权限）
- SMTP 备选：smtp.feishu.cn:465
- 5 套邮件模板：欢迎/留言回复/产品交付/转介绍邀请

### 6. 安全体系
- JWT 72h 过期
- IP 级别限流（60次/分钟）
- API 审计日志（请求体脱敏）
- 管理员权限白名单

## 关键决策

| 决策 | 内容 |
|------|------|
| 数据库 | SQLite（零依赖·足够支撑万级客户） |
| 事件模型 | category + action + properties JSON（灵活扩展） |
| 邮件 | 飞书API优先·SMTP备选 |
| 认证 | JWT + bcrypt 密码哈希 |
| PLG策略 | 事件漏斗驱动获客→激活→付费→转介绍 |
