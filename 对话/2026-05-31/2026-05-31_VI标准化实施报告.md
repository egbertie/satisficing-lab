## 三、设计规范（禁止事项）

| ❌ 禁止 | ✅ 正确 |
|------|------|
| 拉伸/变形Logo | 保持原始比例 |
| 改为正红 #FF0000 | 使用赭石红 #C23B22 |
| 添加阴影/描边/立体 | 平面·金石拓印质感 |
| 去斑驳质感变完美几何 | 保留手工雕刻线条 |
| 复杂背景上使用 | 米白底·充足留白 |
| 小于24px(数字)/15mm(印刷) | 遵循最小尺寸 |
| 用其他字体替代Logo | 方正宋刻本秀楷 |

## 五、后续使用规则

1. **所有新增页面**必须引用对应Logo
2. **Logo替换**从桌面VI文件夹更新，通过 sips -Z 200 生成压缩版
3. **色彩**统一使用 CSS 变量（--red / --gold / --bg / --ink / --title / --border）
4. **字体**网页端统一 PingFang SC
5. **质疑**参照 `memory/VI_视觉识别系统.md`
