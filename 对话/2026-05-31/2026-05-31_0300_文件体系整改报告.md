## 四、文件体系新约定

### 目录结构标准

```
workspace/
├── AGENTS.md          # 工作规则
├── SOUL.md            # 身份描述
├── MEMORY.md          # 长期记忆
├── TOOLS.md           # 工具配置
├── memory/            # 记忆文件
│   ├── YYYY-MM-DD.md  # 每日日志（日毕课时生成）
│   ├── deep/          # 深层学习
│   ├── light/         # 浅层笔记
│   ├── knowledge/     # 知识条目
│   ├── _data/         # 结构化数据（JSON）
│   ├── _scripts/      # 基础设施脚本
│   └── Archives/      # 历史归档
├── 对话/              # 对话记录
│   └── YYYY-MM-DD/    # 按日期
│       ├── 主题1/     # 按主题
│       └── 备份/      # 压缩前保存
├── site/              # 静态站点（子模块）
├── Projects/          # 项目文件
├── Resources/         # 资源文件
├── skills/            # 技能定义
├── 扣子资料_*         # 扣子历史资料
└── 替身/              # 替身数据
```

### 规则

1. **根目录不散落任何 HTML 文件** — HTML 属于 site/
2. **每次压缩前保存到** `对话/YYYY-MM-DD/备份/`
3. **每个重大事件生成一份报告到** `对话/YYYY-MM-DD/主题/`
4. **每日日志在日毕课时写入** `memory/YYYY-MM-DD.md`
5. **临时脚本/补丁在执行完成后删除或归档**

## 五、治理机制

### 抗碎片化检测器

在 HEARTBEAT 中增加以下检查：
1. **根目录 HTML 散落检查**: `ls *.html | wc -l` > 10 → 告警
2. **对话报告缺失检查**: 对比 memory/ 日志的工作量 vs 对话/ 报告数量
3. **双份文件检查**: 同名文件在 site/ 和 根目录同时存在 → 告警
4. **临时文件残留检查**: `_patch*.py` / `.trigger*` 类型文件
