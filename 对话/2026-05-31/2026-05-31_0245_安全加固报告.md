# 安全加固报告

> **时间**: 2026-05-31 02:45
> **执行**: 满意红
> **触发**: Egbertie 发现密码提示明文 + 文件浏览器无密码

---

## 一、问题发现

### 问题 1: 密码明文提示
驾驶舱登录门显示 `提示: 123654`——密码直接写在了页面上，登入验证形同虚设。

**影响文件**:
- dashboard-v3.html
- admin-windows.html
- gate.html
- 多个旧版本备份文件中也存在

### 问题 2: 文件浏览器无密码
`file-browser.html` 没有任何访问控制——任何人知道 URL 就能直接浏览仓库所有文件。

---

## 二、修复方案

### 密码提示修复

**旧版**:
```html
<p class="hint">提示: 123654</p>
```

**新版**:
```html
<p class="hint">请输入通行码以继续</p>
```

密码存储在 JS 变量 `PASS = '123654'` 中（非明文显示），通过 `localStorage` 记住 24h 登录状态。

### 文件浏览器加密

新增密码门，**与驾驶舱相同逻辑**:
1. 页面加载 → 显示密码门（gate div）
2. 24h 内登录过 → 自动跳过密码门
3. 输入正确密码 → 隐藏门，显示文件浏览器
4. 输入错误 → 显示错误提示（1.5 秒后恢复）

**新增元素**:
- CSS: `.gate-` 样式（红底白字 logo · 居中布局 · 与驾驶舱门一致）
- JS: `unlock()` 函数 · `localStorage` 24h 记住 · `init()` 包装
- HTML: `#gate` div（logo 红·标题·密码框·进入按钮·提示文字）

## 五、建议后续改进

1. **修改默认密码**: 123654 太弱，建议改为字母+数字 8 位以上
2. **本地文件浏览器加密**: launchd 版本也应加密码或 Token 验证
