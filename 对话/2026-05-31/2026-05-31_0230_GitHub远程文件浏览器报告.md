# GitHub 远程文件浏览器报告

> **时间**: 2026-05-31 02:30
> **执行**: 满意红（子代理生成）
> **触发**: 本地版需要对应一个随时可用的远程版

---

## 一、设计理念

纯前端 HTML 文件浏览器，零后端依赖，通过 GitHub REST API 读取仓库文件树和内容。部署到任何能渲染 HTML 的 URL 即可使用。

---

## 二、技术实现

### 数据流

```
浏览器 fetch → GitHub REST API
  ├─ GET /git/trees/main?recursive=1  (仅一次，缓存)
  └─ GET /contents/{path}  (按需 base64 解码)
```

### 架构特点

| 特点 | 说明 |
|------|------|
| **纯前端** | HTML + CSS + JS，零构建工具，零 server |
| **独立可用** | 不依赖外部 CDN，所有功能自己实现 |
| **API 友好** | ETag 条件请求 + 速率限制显示 |
| **Markdown 渲染** | 自实现解析器（#标题/**粗体/·列表/```代码块/|表格\|/引用) |
| **密码门** | 与驾驶舱相同密码，24h localStorage |

### 文件预览

| 格式 | 方法 |
|------|------|
| .md | 自实现 Markdown→HTML 渲染 |
| .html .htm | iframe→raw.githubusercontent |
| 图片 | 原始 URL 直接显示 |
| .pdf | iframe 内嵌 |
| .py .js .json .txt 等 | 等宽字体 `<pre>` 显示 |
| .docx .pptx .xlsx | 下载按钮（原始文件 URL） |
| 其他 | 下载 |

### 文件树
- 单次 `recursive=1` 获取完整树，JS 端构建层级
- 过滤 .git / __pycache__ / .DS_Store
- 默认展开第一层，按需展开子目录
- 实时搜索过滤文件名

## 三、部署问题与解决

### 问题 1: raw URL 不渲染 HTML
`raw.githubusercontent.com` 返回 `Content-Type: text/plain` + `nosniff`，浏览器显示源代码而非渲染页面。

**解决**: 使用 `htmlpreview.github.io` 代理
```
https://htmlpreview.github.io/?https://raw.githubusercontent.com/egbertie/satisficing-lab/main/file-browser.html
```

### 问题 2: GitHub Pages 路径不匹配
Pages 配置为 root `/`，但 file-browser.html 在子模块 site/ 中。部署结果走的是主仓库版本（旧版）。

**解决**: 将 file-browser.html 同步到主仓库根目录。
