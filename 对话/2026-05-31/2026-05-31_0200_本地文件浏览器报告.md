# 本地文件浏览器报告

> **时间**: 2026-05-31 02:00
> **执行**: 满意红
> **触发**: Egbertie 要求一个远程文件浏览器查看本地 workspace 文件

---

## 一、背景

Egbertie 希望像网盘一样浏览 Mac mini 上的 worksapce 文件——支持目录树、文件预览、下载。初始设计是纯远程方案，后来发现需要两个版本。

---

## 二、file-browser.py 设计

### 技术栈
- Python 3 + http.server + socketserver
- 端口 8765
- 零外部框架（纯标准库）

### 文件预览支持

| 预览类型 | 格式 | 方法 |
|------|------|------|
| 📝 Markdown | .md .markdown | Python markdown 库渲染 + HTML |
| 🌐 HTML | .html .htm | iframe 内嵌 |
| 🖼️ 图片 | .png .jpg .gif .webp .svg | 直接显示 |
| 📕 PDF | .pdf | iframe + pdfplumber 文本提取 |
| 📄 DOCX | .docx | python-docx 段落+表格渲染 |
| 📊 PPTX | .pptx | python-pptx 幻灯片文本提取 |
| 📈 XLSX | .xlsx | openpyxl 工作表表格渲染（限 500 行） |
| 🐍 代码 | .py .js .json .txt 等 | 等宽字体文本预览 |
| 📦 其他 | .zip .mp4 等 | 下载按钮 |

### API 端点
- `GET /` — 主页面
- `GET /api/tree?dir={path}` — 目录树 JSON（懒加载）
- `GET /api/download/{path}` — 文件下载
- `GET /?dir={path}` — 目录浏览
- `GET /?file={path}` — 文件预览

### 安全
- `is_safe_path()` 路径穿越防护
- `is_relative_to(ROOT)` 验证
- 隐藏文件/夹自动过滤

### 统计
- **940 行** Python 代码
- ~500 行 HTML/CSS 模板
- 暖色 VI 色系（与驾驶舱统一）
- 响应式布局（桌面侧边栏 + 移动端折叠）

## 三、launchd 常驻服务

### 配置
```
com.satisfice.filebrowser.plist
→ RunAtLoad: true
→ KeepAlive: true（崩溃自动重启）
→ 工作目录: ~/.openclaw/workspace
→ 日志: .fb-launchd.log
```

### 生命周期
- ✅ 开机自启
- ✅ 终端关闭不受影响
- ✅ 崩溃自动重启
- ✅ 局域网可访问（绑定 0.0.0.0）

### 管理脚本
`start-fb.sh` — 启动/停止/重启/状态管理

## 四、与远程版的关系

| | 本地版 | GitHub 远程版 |
|------|------|------|
| **看到什么** | 实时本地文件（含未推送） | 已推送的仓库文件 |
| **更新频率** | 实时（文件系统直接读取） | 延迟（需 git push 后可用） |
| **适用场景** | Mac mini 本机·局域网 | 任何地方·手机·微信 |
| **依赖** | Python 3 + launchd | 零（纯前端 HTML） |
