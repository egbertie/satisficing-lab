知识飞轮系统 · 完整操作指南

满意解研究所是什么？

满意解研究所不是一个普通的「软件」或「工具」。它是一个知识飞轮系统。

想象一个会自动学习、持续进化的大脑：它不断吸收信息（产品、客户反馈、操作记录），通过多个「替身」（AI 视角）进行思考和评价，然后得出洞察与结论，再反过来优化自己的思考方式。这个过程就像飞轮一样，越转越快，越转越稳。

系统三大支柱
📦 产品库
217+ 件产品，覆盖策略咨询、决策工具、知识内容、可视化、模拟演练等。每件产品都有唯一编号、五族分类、深度评级（L1-L4）和 LLM 替身评分。
👥 客户体系
客户 360 画像、销售管道、交付记录、满意度追踪。让每个客户从「第一次接触」到「长期合作」的完整旅程都有迹可循。
⚙️ 自动化运维
Cron 定时任务、免疫系统监控、质量门禁、规则引擎。系统自己在后台默默运转，健康状态一目了然。

谁应该读这本手册？

  • Egbertie——满意解研究所的创建者和核心用户。你需要知道系统的每个部分怎么用、怎么看、怎么理解。
  • 使用满意解研究所产品 / 服务的客户——你可以通过这本手册了解你能看到什么、怎么找到你需要的东西。
  • 协作伙伴——当别人想知道「这个系统到底是怎么回事」，你可以把手册发给他们。

手册不预设任何技术背景。只要你会用浏览器，就能看懂。

⚡ 快速上手（3 分钟）

第一次打开满意解研究所？只需三步，就能对整个系统有一个整体的感觉。

1 打开驾驶舱，看总体状态

打开 dashboard-v3.html，输入访问密码（向 Egbertie 索取），进入驾驶舱。

你会立刻看到一张「📊 总览」页面，上面展示了系统的核心指标：产品总数、知识图谱密度、未闭环任务数、免疫系统评分等。花半分钟扫一眼——这就是系统的「脉搏」。

2 浏览产品目录

点击导航跳转，或直接打开 product-catalog.html。你会看到所有产品列表。可以用顶部的搜索框搜索，也可以用筛选按钮按「五族」（镜·衡·觉·契·章）分类浏览。

试试搜索一个你感兴趣的关键词，看看有没有相关产品。

3 看化学面板

回到驾驶舱，点击 「🧬 化学与控制」 标签。这里展示了系统的「化学反应」状态——你可以把它理解为系统的温度计和 pH 试纸。绿色代表正常，黄色需要关注，红色则需要处理。

看不懂没关系，后面第 3 章会有详细解释。

📦 产品目录（product-catalog.html）

如何浏览

打开产品目录后，你会看到一张包含所有产品的表格。每条行代表一个产品，列代表该产品的属性。表格支持：

  • 搜索：在顶部搜索框输入关键词，实时过滤表格。可以搜索产品名、文件名。
  • 筛选：点击搜索框下方的筛选按钮，按「五族」分类查看。点击「全部」恢复完整视图。
  • 排序：点击表头（如编号、产品名、深度等）可按该列排序。

五族分类

产品按「五族」分类，每个族代表一种产品类型和价值取向：

族名含义代表什么
🪞 镜·觉察镜子——看清现状诊断、分析、评估类产品。帮你「看清自己在哪里」。
🪙 衡·量化秤——衡量得失量化、对比、权衡类产品。帮你「算清楚利弊」。
🔥 觉·淬炼火——淬炼真知训练、模拟、演习类产品。帮你「通过实践磨砺能力」。
🤝 契·约定契约——承诺协作框架、协议、流程类产品。帮你「立规矩、建体系」。
📜 章·传承篇章——知识永续文档、知识库、故事类产品。帮你「把经验留下来、传下去」。

产品深度（L1-L4）

每个产品都有一个深度评级，表示该产品的成熟度和复杂度：

  • L1 · 浅层 —— 概念阶段或快速作品。可以直接使用，但可能不够深入。
  • L2 · 中层 —— 有一定复杂度，经过初步验证。可以直接交付。
  • L3 · 深层 —— 深入研究、多层结构。代表满意解研究所的核心能力。
  • L4 · 精品 —— 打磨至成熟。旗舰级产品，可直接展示给重要客户。

🤖 LLM 替身评分列的含义

表格最右侧有一列「🤖 LLM」，显示的是该产品在多个维度的综合评分。这个评分由五个 AI 替身（详见下文「核心概念」章节）分别给出，然后加权综合。

  • 分数范围：1-10 分，10 分最高。
  • 颜色编码：高分→绿色，中等→金色/橙色，低分→红色。
  • — 表示该产品尚未被替身评分。
  • 用途：快速了解产品在不同视角下的表现。比如一个产品可能在「长期价值」维度很高，但在「可行性」维度偏低——这本身就是有价值的信号。

特色：三级数据穿透

管理窗口的一个核心特色是「三级穿透」：

  1. L1 · 总览：每个视图顶部显示汇总统计卡片（如总数、占比、趋势）。

这个设计让你既能「看全局」，也能「查细节」，不需要在多个页面间反复跳转。

🔄 核心概念：知识飞轮

什么是知识飞轮？

「飞轮」是一个工程学概念：一个很重的轮子，刚开始推很费劲，但一旦转起来，就会保持惯性，越转越快、越转越稳。

满意解研究所的知识飞轮就是这个意思：

  1. 输入：每个产品、每次客户交互、每条操作记录，都被系统收集和记录。
  2. 加工：五个 AI 替身从不同角度对这些信息进行评价和思考。
  3. 输出：系统生成洞察、建议、预警——帮助做出更好的决策。
  4. 反馈：这些决策的结果又被系统吸收，用于优化下一次的分析。
  5. 加速：信息越多、分析越准、决策越好——形成一个正向循环。
💡 一句话总结
满意解研究所不是一个「给你答案」的系统。它是一个「帮你更好地提问和思考」的系统。飞轮转动得越久，你的决策质量就越稳定。

飞轮和普通工具的区别

  • 普通工具：每次使用都是独立的。用完就完了，不会「记住」什么。
  • 知识飞轮：每次使用都在为下一次使用积累信息。用得越多，系统越了解你、越了解你的业务。

🧪 核心概念：化学与控制

通俗解释

就像人体有自己的温度调节系统（体温维持在 36.5°C 左右）、pH 平衡系统（血液 pH 维持在 7.35-7.45），满意解研究所也有自己的「化学生态」。

🫀 化学与控制的三个维度
热力（活跃度）：系统有多「活跃」？最近有多少新信息流入？多少产品在被使用？多少任务在推进？

评分（质量趋势）：产品的平均评分在上升还是下降？客户满意度在变好还是变差？

永续控制（自我调节）：系统是否在主动发现和修复问题？免疫系统的拦截率是多少？是否有风险信号被遗漏？

你可以把「化学与控制」理解为系统的温度计、pH 试纸和免疫系统的总称。在驾驶舱的「🧬 化学与控制」标签页中，所有指标都是可视化的——绿色代表正常范围，黄色代表需要关注，红色代表需要立即处理。

为什么叫「化学」？

在满意解研究所的四层模型（物理→化学→生物→心理）中，「化学层」指的是不能直接看到的、但真实发生的相互作用。就像你不能「看到」体内的激素水平，但激素确实在影响你的情绪和行为。

同样，系统的化学反应——比如知识图谱中两个概念之间的连接强度、某个产品与客户需求的匹配度——虽然不直观，但它们是系统真正「活着」的证据。

🤖 核心概念：LLM 替身评分

每件产品都有一个「🤖 LLM」评分。这个评分不是一个人给的，而是由五个 AI 替身分别从不同视角打分后综合得出。

每个替身代表一种思考维度，相当于你的五个顾问，各自有不同的专业背景和价值取向：

🏛️
刘禹锡
长期价值 · 永恒视角
问什么：这个产品有持续价值吗？一年后、三年后还值得关注吗？
高分意义：产品具有穿越周期的价值，不是一时的热点。
低分意义：可能是时效性强的产品，或者核心假设很快就会过时。
🔧
司马贺
可行性 · 工程视角
问什么：这个产品的思路可行吗？有实现路径吗？资源够吗？
高分意义：产品有明确可执行的路径，落地风险可控。
低分意义：可能想法很好但缺乏操作细节，或者需要的资源远超现有条件。
📜
孔子
诚信 · 伦理视角
问什么：这个产品符合价值观吗？对客户诚实吗？有没有夸大或不实的成分？
高分意义：产品经得起伦理审视，经得起客户和市场的检验。
低分意义：可能存在过度承诺、信息不对称或潜在的道德风险。
🌸
水月观音
体验 · 感知视角
问什么：这个产品给人什么感觉？使用起来流畅吗？美吗？
高分意义：产品体验优雅、直观、有美感，客户会愿意反复使用。
低分意义：产品可能功能齐全但不好用、不好看，或体验有割裂感。
🌌
六祖慧能
独特性 · 本质视角
问什么：这个产品有什么是别人无法替代的？它的本质独特性在哪里？
高分意义：产品有鲜明的独特价值主张，难以被复制或替代。
低分意义：产品可能和市场上已有方案没有本质区别，容易被替代。

如何解读综合评分？

  • 很高（8-10 分）：五个替身都认可该产品。通常意味着产品在价值、可行、诚信、体验、独特性上都没有明显短板。
  • 中等（5-7 分）：部分替身有保留。不需要紧张——这反而是有价值的信号：比如孔子给低分说明可能需要检查措辞，司马贺给低分说明需要补齐操作细节。
  • 较低（1-4 分）：多数替身有顾虑。需要认真对待，但不是判死刑——可能产品处于早期阶段，或者定位需要调整。
⚠️ 重要提醒
LLM 评分是 AI 替身基于当前信息的判断，不是绝对的真理。高分不意味着完美，低分不意味着要放弃。这些评分最适合用作讨论的起点——「为什么这个替身给这么低的分？」这个问题本身就很有价值。

🌊 核心概念：五层流模型

满意解研究所将一切活动建模为一个五层的流动过程：

这五层对应了人类处理信息的自然方式：

  1. 📡 信号层：接收信息。客户问了什么？市场发生了什么变化？系统记录了什么日志？——这是「听」的过程。
  2. 🧠 认知层：理解信息。收到的信号意味着什么？与已知的知识有什么关系？——这是「想」的过程。
  3. ⚡ 行动层：做出反应。基于理解，我们要做什么？生成什么产品？给客户什么建议？——这是「做」的过程。
  4. ✅ 验证层：检查结果。行动的效果如何？客户反馈怎样？指标有没有改善？——这是「验」的过程。
  5. 📚 学习层：沉淀经验。从这次经历中学到了什么？哪些知识需要更新？哪些做法值得保留？——这是「悟」的过程。
🔍 为什么要分五层？
分层的好处是诊断。如果系统遇到的问题被模糊地描述为「运转不畅」，你没办法改进。但如果能定位到「验证层流动率为零——我们做了很多事但没有检查效果」，改进方向就非常明确了。

在驾驶舱的「🔌 流仪表板」标签中，你可以看到每一层的实时流量和健康状态，就像系统的心电图。

五层流与知识飞轮的关系

五层流模型是知识飞轮的实现方式。每一轮飞轮转动，就是一次完整的信号→认知→行动→验证→学习的循环。循环越快、越完整，飞轮转得越稳。

📋 常见操作场景

场景一：「我想看看系统状态怎么样」

→ 打开驾驶舱 · 📊 总览标签

总览页面会显示所有核心指标的当前值。如果某个数字明显偏离正常范围，它会用颜色（黄色/红色）提示你。这是一天中最重要的第一眼。

然后可以快速扫一眼 🫀 健康仪表——免疫系统的分数。如果健康评分低于某个阈值，点击进去看看哪层出了问题。

场景二：「我想找一个产品」

→ 打开产品目录 · 搜索框

在搜索框中输入产品名或关键词（如「决策」「危机」「客户」），表格会实时过滤。如果记得产品在哪个族，也可以用筛选按钮先缩小范围再搜。

找到后点击「链接」列可以直接打开该产品页面。

场景三：「我想了解某个产品的替身评价」

→ 产品目录 · 看 🤖 LLM 列

在产品目录中找到该产品，看最右侧的「🤖 LLM」列。数字越高越好。如果分数不太理解，可以去 管理窗口 → 组织与人 → 替身管理 查看该产品在各替身视角下的分项评分。

场景四：「我想看化学反应是否正常」

→ 驾驶舱 · 🧬 化学与控制标签
或 管理窗口 → 战略仪表盘 → KPI仪表盘

化学与控制标签显示热力（活跃度）、评分趋势和永续控制状态。如果所有指标都是绿的，系统化学状态良好。如果某个指标黄了或红了，点击下钻查看具体是什么触发了警报。

场景五：「我想看最近的客户互动」

→ 管理窗口 → 客户关系 → 客户 360

搜索客户名，查看客户档案和最近的交互记录。也可以通过 管理窗口 → 运营与流程 → 决策记录 查看与客户相关的决策链条。

场景六：「我想知道有没有紧急任务」

→ 驾驶舱 · ✅ 待办任务标签

筛选优先级为 P0 的任务。P0 就是最紧急、需要立即处理的任务。也可以看到任务的负责人和截止日期。

场景七：「我想回顾项目历史」

→ 管理窗口 → 考古与洞察 → 时间线

这里记录了项目发展的关键事件。可以按时间浏览，也可以搜索特定事件。旁边的「发现与洞察」视图还有从历史数据中提取的模式和教训。

❓ FAQ · 常见问题

Q：三个入口（驾驶舱、产品目录、管理窗口）有什么区别？什么时候用哪个？▼

驾驶舱：了解整体状态。每天早上打开看一眼。
产品目录：找产品、看评价。当你需要浏览或搜索产品时用。
管理窗口：做具体操作和管理。当你要加客户、看风险、改配置时用。

简单来说：驾驶舱是「看天气」，产品目录是「查地图」，管理窗口是「装修房间」。三者互补，缺一不可。

Q：LLM 替身评分是 AI 自动打的吗？会更新吗？▼

是的，LLM 替身评分由五个 AI 替身（刘禹锡、司马贺、孔子、水月观音、六祖慧能）基于产品内容和上下文自动评估。评分会随着产品的更新而重新计算。如果某个产品被大幅修改，评分也可能随之变化。

不过评分更新不是实时的——通常在产品审核流程中触发。

Q：「五族」和「七族」是什么关系？▼

产品目录用的是五族（镜·衡·觉·契·章），这是产品分类的简化模型，适合日常浏览和搜索。

驾驶舱的产品资产标签用的是七族（镜·契·衡·觉·人·道·章），比五族多了「人」和「道」两个类别，用于更精细的分析。

两者的关系是：五族是七族的子集。日常使用时，五族足够；深度分析时，七族提供了更多维度。

Q：化学面板里的指标红了怎么办？▼

首先不要慌——红色表示「需要关注」而不是「系统崩了」。

建议步骤：

  1. 点击红色指标，下钻查看触发警报的具体数据。
  2. 去管理窗口的「🛡️ 免疫与治理 → 免疫系统」查看是否有相关事件记录。
  3. 去「📜 活动日志」看最近的操作记录，判断是否有异常操作。
  4. 如果无法判断原因，去「⚙️ 运营与流程 → 决策记录」查看相关决策链条。

大多数红色指标都有明确的解释和推荐操作。如果持续红色且无解释，那本身就是一个需要创建的任务。

Q：产品深度 L1-L4 是怎么决定的？▼

产品深度是一个综合评估，主要基于：

  • 内容结构：是单页文档还是多层知识体系？
  • 引用密度：引用了多少其他产品和外部资源？
  • 被引用次数：被其他产品引用了多少次？
  • 迭代次数：经历了多少轮修改？
  • 审核状态：是否通过了四关审核？

深度是客观数据和主观判断的结合。L1 不意味着「差」——可能是一个刚刚起步但潜力很大的产品。

Q：三级数据穿透具体怎么操作？▼

在管理窗口的任何视图中：

  1. L1 总览：页面顶部显示的统计卡片。比如「产品总数：217」。这是第一层。
  2. L2 明细：点击任何统计卡片或表格行，会展开该统计的详细列表。比如点击客户数的卡片，会看到客户列表。
  3. L3 原始记录：在明细列表中，点击某个具体条目会展开完整的数据视图，包括所有字段、原始值和注释。

不需要记。实际操作一次就明白了——就是「点进去、再点进去」的过程。

Q：为什么有些产品在驾驶舱能看到，在产品目录看不到？▼

产品目录只显示已上线的产品。处于概念阶段（L0）、退役（L6）或标记为「内部」的产品不会出现在目录中。

驾驶舱的产品资产标签会显示所有阶段的产品分布（按七族汇总），但不会列出每个内部产品。

如果需要查看所有产品（包括未公开的），去管理窗口 → 产品全生命周期 → 产品总览。

Q：我需要记住所有概念吗？▼

不需要。手册放在这里就是让你随时查阅的。

不过有两个概念值得先理解：知识飞轮（系统的核心理念）和化学与控制（系统的健康指标）。掌握了这两个概念，其他都能在用中学。

另外，驾驶舱本身的标签命名已经足够直观——「📊 总览」就是看总览，「✅ 待办任务」就是看任务。不需要额外记忆。

Q：发现手册里有需要更新或补充的内容怎么办？▼

告诉 Egbertie。手册的源文件是 help-user.html，可以直接编辑。如果是小改动（比如某个标签页的描述需要更新），Egbertie 可以很快修改。

另外，如果你在使用的过程中发现某个操作场景手册没有覆盖，那可能是一个很好的补充建议。

Q：可以从手机上看吗？▼

可以。手册的排版已经适配了桌面和移动端。在手机上，左侧导航会收起到顶部，主内容区会自适应屏幕宽度。

不过，驾驶舱、产品目录和管理窗口这三个应用页面本身也支持响应式，但在手机上体验不如桌面（毕竟是数据密集型页面）。如果你需要在手机上做简单查看——比如看一看总览指标——完全没问题。深度操作建议在桌面上进行。
