## 二、升级方案

### 阶段一: 客户互动增强（今晚）

#### 1.1 客户门户合并 (client.html → 升级)
```
client.html (新版)
├── 三合一: client + register + gate → 一个页面
├── 步骤1: 你是谁？(新客户/老客户)
├── 步骤2: 你想做什么？(自评/咨询/看案例)
├── 步骤2.1: 留联系方式 → 飞书通知 + 自动Bitable入库
├── 步骤3: 结果页 (推荐产品/下一步指引)
└── 飞书 Webhook 实时通知
```

#### 1.2 用户中心增强 (account.html → 升级)
```
account.html (新版)
├── 仪表盘: 我的产品/进度/推荐记录
├── 自评工具: 直接启动 assessment.html
├── 消息中心: 系统通知/产品更新
├── 推荐计划: 可见的推荐码 + 奖励追踪
└── 一键联系顾问 (飞书)
```

#### 1.3 新增引导式对话
```
新建 interact.html
├── 五维快问 (10题 → 推荐产品)
├── 合伙人匹配 (需求 → 匹配顾问)
├── 危机检测 (3题 → 紧急程度)
└── 每一步 → API 追踪 + Webhook 通知
```

### 阶段二: 中端数据管道增强

#### 2.1 客户行为追踪 (routes/events.py + 升级)
```
新增端点:
POST /api/analytics/pageview     - 页面浏览
POST /api/analytics/click        - 点击事件  
POST /api/analytics/conversion   - 转化事件
POST /api/analytics/session      - 会话追踪

数据用途:
→ admin-windows.html 新增: 热力图/转化漏斗/客户旅程
→ dashboard-v3.html 新增: 实时访客/活跃用户
```

#### 2.2 飞书集成完整打通
```
优先级:
1. 确认 FEISHU_APP_SECRET → 跑通 token
2. Bitable 双向同步: 客户注册 → 自动插入行
3. Webhook: 新客户/新咨询/产品下载 → 飞书群通知
4. 邮件: 域名备案后 → 自动发送欢迎邮件/产品交付
```

### 阶段三: 后端能力扩展

#### 3.1 数据库增强
```sql
-- 新增表
CREATE TABLE customer_journey   -- 客户旅程 (pageview/click/conversion)
CREATE TABLE product_downloads  -- 产品下载记录
CREATE TABLE notification_log   -- 通知发送记录
CREATE TABLE email_templates    -- 邮件模板管理
```

#### 3.2 新增服务
```python
server/services/analytics.py    -- 行为分析
server/services/notification.py -- 多通道通知 (飞书/邮件/站内)
server/services/recommender.py  -- 产品推荐引擎
```
