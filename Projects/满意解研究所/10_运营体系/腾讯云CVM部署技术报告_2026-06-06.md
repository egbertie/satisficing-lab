## 四、安全配置

### 4.1 SSH 加固
```
Port 22
PermitRootLogin prohibit-password
PasswordAuthentication no
PubkeyAuthentication yes
ChallengeResponseAuthentication no
X11Forwarding no
MaxAuthTries 3
ClientAliveInterval 300
ClientAliveCountMax 2
```
- **authorized_keys**: 1 个密钥 (本机 ~/.ssh/id_rsa.pub)
- **恢复方式**: VNC 登录 → `cp /etc/ssh/sshd_config.orig /etc/ssh/sshd_config` → `systemctl restart sshd`

### 4.2 iptables 防火墙
```
Chain INPUT (policy DROP)
 1  ACCEPT  --  state RELATED,ESTABLISHED
 2  ACCEPT  --  lo
 3  ACCEPT  --  tcp dpt:22
 4  ACCEPT  --  tcp dpt:80
 5  ACCEPT  --  tcp dpt:443
 6  ACCEPT  --  icmp type 8 (ping)
```
- **持久化**: `/etc/iptables/rules.v4`
- **恢复方式**: VNC → `iptables -F`（内存清空）或删除 rules.v4 后重启

### 4.3 环境变量
- **路径**: `/etc/sriserver/env` (chmod 600)
- **字段**: FEISHU_APP_ID / FEISHU_APP_SECRET / FEISHU_WEBHOOK / FEISHU_BITABLE_TOKEN / FEISHU_BITABLE_TABLE_ID
- **注入方式**: systemd EnvironmentFile → sri-api.service.d/env.conf

### 4.4 Nginx 安全头
- `/etc/nginx/conf.d/security-headers.conf`
- X-Frame-Options: SAMEORIGIN
- X-Content-Type-Options: nosniff
- X-XSS-Protection: 1; mode=block
- Referrer-Policy: strict-origin-when-cross-origin

## 十、部署过程问题记录

### 问题1: tar 打包解压后文件丢失
- **原因**: macOS tar 扩展属性导致打包不完整
- **解决**: 改用 `rsync -avz` 直接同步

### 问题2: Nginx 403 Permission Denied
- **原因**: 上传后文件权限 700/600
- **解决**: `chmod -R a+rX`

### 问题3: 端口不匹配
- **原因**: config.py 默认 PORT=5000，Nginx 代理到 5050
- **解决**: 统一为 5050

### 问题4: SSH 多次被锁死
- **原因**: sed 替换 sshd_config 时误改
- **解决**: VNC 登录恢复 orig 备份。后改用 iptables 独立控制暴露面，不动 sshd_config 端口。

### 问题5: 飞书 App Secret 被截断
- **原因**: grep + sed 提取时格式不匹配
- **解决**: 从本地项目仓库恢复原始值。但仍报 invalid，待用户确认。

### 问题6: Gunicorn 找不到 app 对象
- **原因**: Flask app 在 `if __name__ == "__main__"` 内创建
- **解决**: 在 app.py 末尾添加 `app = create_app()`

## 十一、配置快照 (2026-06-06 23:07)

### Nginx 站点配置 (satisfising-lab.conf)
```nginx
server {
    listen 80;
    server_name 101.33.219.144;
    include /etc/nginx/conf.d/security-headers.conf;

    root /mnt/datadisk0/satisficing-lab;
    index index.html;

    location /api/ {
        proxy_pass http://127.0.0.1:5050;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    location ~* \.(html|css|js|png|jpg|svg|ico)$ {
        expires 7d;
        add_header Cache-Control "public, immutable";
    }

    location ~* \.json$ {
        expires 1h;
    }
}
```

### systemd 服务 (sri-api.service)
```ini
[Unit]
Description=满意解研究所 API (Gunicorn)
After=network.target

[Service]
Type=notify
User=root
WorkingDirectory=/mnt/datadisk0/satisficing-lab
EnvironmentFile=/etc/sriserver/env
Environment=PYTHONUNBUFFERED=1
ExecStart=/usr/local/bin/gunicorn --bind 127.0.0.1:5050 --workers 2 --timeout 60 --access-logfile /var/log/sri-access.log --error-logfile /var/log/sri-error.log server.app:app
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```
