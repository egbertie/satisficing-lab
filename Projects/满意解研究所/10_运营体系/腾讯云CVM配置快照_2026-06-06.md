## 部署问题教训
1. 永远不用 sed 改 sshd_config → 改用追加 + 仅改认证
2. 端口隔离用 iptables，不碰 sshd Port
3. macOS tar 不可靠 → 用 rsync
4. pip3 安装后立即 systemd 化
5. Flask dev server 改用 Gunicorn 2 workers
6. Secret 必须环境变量注入，禁止 config.py 明文
7. 任何危险操作前备份 orig → 验证 sshd -t → 再应用
