## 四、数据接口

### 4.1 新增 API 端点
```
GET /api/admin/infra/summary          → 总览数据 (所有卡片)
GET /api/admin/infra/services         → 服务列表
GET /api/admin/infra/backups          → 备份历史
GET /api/admin/infra/cron             → Cron 状态
GET /api/admin/infra/disk             → 磁盘详情
GET /api/admin/infra/network          → 网络详情
GET /api/admin/infra/security         → 安全状态
GET /api/admin/infra/feishu           → 飞书集成状态
```

### 4.2 数据采集方式
- 优先: SSH 本地采集 (os.popen / subprocess)
- 备选: 写一个定时 Python 脚本将数据 dump 为 JSON → API 读取
- 最优: 腾讯云云监控 API (如果装了 Agent)

## 七、技术方案

**推荐方案**: 新增 `server/routes/infra.py` → 提供 API → dashboard-v3.html 新增标签页

**数据采集脚本** (部署到 CVM, 每分钟 Cron):
```python
#!/usr/bin/env python3
# /usr/local/bin/sri-infra-collect.py
# 采集系统数据 → JSON → API 读取
import subprocess, json, os

data = {
    "timestamp": subprocess.run(["date", "+%Y-%m-%d %H:%M:%S"], capture_output=True, text=True).stdout.strip(),
    "disk": {
        "system": {"total": "50G", "used": "4.0G", "used_pct": 8},
        "data": {"total": "49G", "used": "1.4G", "used_pct": 3},
    },
    "memory": {"total": "3.6G", "used": "633M", "used_pct": 17},
    "cpu": {"load": [0.00, 0.00, 0.00]},
    "services": {
        "nginx": True, "sri_api": True, "sshd": True
    },
    "backups": {
        "last": "2026-06-06 23:02",
        "size": "520M",
        "count": 1
    }
}

with open("/mnt/datadisk0/satisficing-lab/infra_state.json", "w") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)
```
