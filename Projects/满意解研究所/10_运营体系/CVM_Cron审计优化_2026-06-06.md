# 腾讯云 CVM Cron 审计与优化方案

> 2026-06-06 23:32 · 双经济约束审计  
> 原则: 能用简单方案不用高频轮询 · 能用 systemd timer 不用 cron · 能合并不分散

## 当前 6 条 Cron (冗余分析)

| # | 任务 | 频率 | 日均 | 合理性 | 问题 |
|:--|:--|:--|:--|:--|:--|
| 1 | 备份 | 每天1次 | 1 | ✅ | 合理，代码+配置打包 |
| 2 | 健康检查+重启 | 每30分钟 | 48 | ❌ | systemd 自带 restart=always，重复 |
| 3 | 日志清理 | 每周1次 | 0.14 | ⚠️ | logrotate 已经做了，重复 |
| 4 | 磁盘监控 | 每天1次 | 1 | ⚠️ | 50GB 数据盘，8%使用率，早期不需要 |
| 5 | 日志轮转(--force) | 每周1次 | 0.14 | ❌ | logrotate 本身有 daily cron，--force 冲突 |
| 6 | 采集 infra_state | 每5分钟 | 288 | ⚠️ | 监控面板刷新是30s，采集5min没问题，但288次/天过多 |

## 核心结论

**问题最大的 3 条**:
1. **#2 健康检查** 完全冗余 — systemd 本身 `Restart=always` 已经自带故障恢复
2. **#3 日志清理** 与 #5 日志轮转功能重叠 — logrotate 已经有 daily cron
3. **#2+#6 共 336次/天** — 双经济约束上 这是过度设置

## 优化方案

### 方案: 精简到 3 条，日均 3 次

```
# 1. 每日备份 (保留)
0 3 * * * root /usr/local/bin/sri-backup.sh >> /var/log/sri-backup.log 2>&1

# 2. 每日综合健康简报 (合并 #2/#4/#6)  
0 8 * * * root /usr/local/bin/sri-health-check.sh >> /var/log/sri-health.log 2>&1

# 3. 每周日志维护 (合并 #3/#5)
0 4 * * 0 root /usr/sbin/logrotate /etc/logrotate.d/satisficing-lab && find /var/log -name "*.gz" -mtime +30 -delete >> /var/log/sri-logclean.log 2>&1
```

### 新增综合健康检查脚本
```bash
#!/bin/bash
# /usr/local/bin/sri-health-check.sh
# 替代: cron健康检查 + 磁盘监控 + infra采集

echo "=== $(date) 健康检查 ==="

# 1. 服务状态 (systemd already handles restart)
for svc in nginx sri-api sshd; do
    status=$(systemctl is-active $svc)
    echo "$svc: $status"
    [ "$status" != "active" ] && systemctl restart $svc
done

# 2. 磁盘
df -h / /mnt/datadisk0 | grep -v Filesystem

# 3. 备份
ls -lh /mnt/datadisk0/backups/*.tar.gz | tail -1

# 4. infra 采集
python3 /usr/local/bin/infra_collector.py --role=cvm
```

### 节省
- Cron 从 6 条 → 3 条 (-50%)
- 日均执行从 340 次 → 3 次 (-99%)
- 所有关键功能保留，无能力损失

## 关于「本地模型处理 Cron」

你提到 OpenClaw 的 Cron 可以用本地模型——这个可行：
- OpenClaw Cron jobs 可以用 `qwen-agent` 或 `doubao-seed-2.0-code` 来跑
- 轻量任务（如状态检查、数据采集）用 Flash 级模型即可
- 云端 CVM 的 Cron 属于系统级任务，不需要模型参与，用 bash 脚本即可

## 推荐分工

| 层级 | 谁来做 | 用什么 | 例子 |
|:--|:--|:--|:--|
| **系统运维** | 腾讯云 CVM cron.d | bash 脚本 | 备份、健康检查、日志 |
