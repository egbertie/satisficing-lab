## 二、迁移步骤

### 阶段1: Git 仓库迁移
```
# 在 CVM 上创建裸仓库
git init --bare /mnt/datadisk0/git/satisficing-lab.git

# 配置 post-receive hook 自动部署
cat > /mnt/datadisk0/git/satisficing-lab.git/hooks/post-receive << 'EOF'
#!/bin/bash
GIT_WORK_TREE=/mnt/datadisk0/satisficing-lab git checkout -f
systemctl restart sri-api
EOF

# 本地推送
git remote add tencent ssh://root@101.33.219.144/mnt/datadisk0/git/satisficing-lab.git
git push tencent main
```
